# Overview of Vector Embedding Technology

This topic provides an overview of the concepts and usage of vector embedding technology.

## What is vector embedding?

Vector embedding is a technique that converts unstructured data into numerical vectors. These vectors capture the semantic information of unstructured data, enabling computers to "understand" and process the meaning of unstructured data. Specifically:

* Vector embedding maps unstructured data such as text, images, or audio/video into points in a high-dimensional vector space.
* In this vector space, semantically similar unstructured data is mapped to nearby positions.
* Vectors typically consist of hundreds of numbers (for example, 512 dimensions, 1024 dimensions).
* Mathematical methods (such as cosine similarity) can be used to calculate the similarity between vectors.
* Common vector embedding models include Word2Vec, BERT, and BGE. For example, when developing an RAG application, you usually need to embed text data into vector format before storing it in a vector database, while other structured data is stored in a relational database.

OceanBase AI Database supports storing vector data as a data type in relational tables, allowing vectors and traditional scalar data to be stored in OceanBase AI Database in an orderly and efficient manner.
