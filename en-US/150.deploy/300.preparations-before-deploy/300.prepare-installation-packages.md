# Prepare installation packages

Before deployment, ensure you have obtained the images and installation packages for each product to be used in the subsequent installation and deployment.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>The installation packages are not publicly available for download. Please contact technical support to obtain them.</p>
</main>

## Images and installation packages for deploying the OceanBase AI database cluster

### Deploy OceanBase Admin Tool (OAT)

To deploy OAT, you can use either the OAT Docker image or the oat-all-in-one installation package. For new environments, the oat-all-in-one installation package is recommended. It includes Docker, OAT, MetaDB, NLB images, and commonly used utility packages.

Different platforms require different packages:

* OAT Docker image
  
  * X86_64 platform: oat_x.x.x_xxxxxxxx_x86.tgz
  * ARM_64 platform: oat_x.x.x_xxxxxxxx_arm.tgz

* oat-all-in-one installation package

  * X86_64 platform: oat-all-in-one-x86-xxx.tar
  * ARM_64 platform: oat-all-in-one-arm-xxx.tar

### Deploy OceanBase Cloud Platform (OCP)

To deploy OceanBase Cloud Platform (OCP), you can use the OCP Docker image and the MetaDB Docker image package. The OCP version to be deployed must be V4.5.0 or later.

* OCP Docker image: Used to deploy OCP

  * X86_64: ocpxxx.tar.gz
  * ARM_64: ocpxxx.arm.tar.gz

* MetaDB Docker image: Used to deploy OCP MetaDB and MonitorDB

    <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>If OAT is deployed using the OAT Docker image, you must provide the MetaDB Docker image when deploying OCP.</p>
    </main>

  * X86_64: meta_xxxxxx_xxxxxx_x86_xxxxxxxx.tgz
  * ARM_64: meta_xxxxxx_xxxxxx_arm_xxxxxxxx.tgz
  
## Deploy OceanBase AI Database

To deploy an OceanBase AI Database cluster, you need to deploy OBServer and LogService. The required installation packages are as follows:

<main id="notice" type='explain'>
  <h4>Note</h4>
  <ul><li>The OceanBase AI Database RPM package and Logservice RPM package are not publicly available for download. Please contact technical support to obtain them.</li>
  <li>For Rocky Linux 9 and Alibaba Cloud Linux 3, the al8 RPM package is recommended.</li>
  <li>The Linux kernel version must be 4.19 or later.</li></ul>
</main>

* OceanBase AI Database RPM packages

  * x86_64 platform:

    * el7: oceanbase.ai-x.x.x.x-xxxxxxxxxxxxxxxxxx.el7.x86_64.rpm
    * al8: oceanbase.ai-x.x.x.x-xxxxxxxxxxxxxxxxxx.al8.x86_64.rpm

  * arm_64 platform:

    * el7:

      * With LSE enabled (default): oceanbase.ai-x.x.x.x-xxxxxxxxxxxxxxxxxx.el7.aarch64.rpm
      * With LSE disabled: oceanbase.ai-x.x.x.x-xxxxxxxxxxxxxxxxxx.nonlse.el7.aarch64.rpm

    * al8: oceanbase.ai-x.x.x.x-xxxxxxxxxxxxxxxxxx.al8.aarch64.rpm

* Logservice RPM packages

  * x86_64 platform:

    * el7: oblogservice-x.x.x-xxxxxxxxxxx.el7.x86_64.rpm
    * al8: oblogservice-x.x.x-xxxxxxxxxxx.al8.x86_64.rpm

  * arm_64 platform:

    * el7: oblogservice-x.x.x-xxxxxxxxxxx.el7.aarch64.rpm
    * al8: oblogservice-x.x.x-xxxxxxxxxxx.al8.aarch64.rpm

### Deploy OceanBase Database Proxy (Optional)

The RPM packages for deploying OceanBase Database Proxy are as follows:

    <li>The Linux kernel version must be 4.19 or later.</li></ul>

* x86_64 platform:

  * el7: obproxy-x.x.x.x-xxxxxxxxxxxxxx.el7.x86_64.rpm
  * al8: obproxy-x.x.x.x-xxxxxxxxxxxxxx.al8.x86_64.rpm

* ARM_64 platform:

  * el7: obproxy-x.x.x.x-xxxxxxxxxxxxxx.el7.aarch64.rpm
  * al8: obproxy-x.x.x.x-xxxxxxxxxxxxxx.al8.aarch64.rpm
