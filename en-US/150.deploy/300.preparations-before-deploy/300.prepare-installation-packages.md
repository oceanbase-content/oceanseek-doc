# Prepare installation packages

Before deployment, ensure you have obtained the images and installation packages for each product to be used in the subsequent installation and deployment.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>The installation packages are not publicly available for download. Please contact technical support to obtain them.</p>
</main>

## Deploy OceanSeek

To deploy an OceanSeek cluster, you need to deploy OBServer and LogService. The required installation packages are as follows:

<main id="notice" type='explain'>
  <h4>Note</h4>
  <ul>
  <li>For Rocky Linux 9 and Alibaba Cloud Linux 3, the al8 RPM package is recommended.</li>
  <li>The Linux kernel version must be 4.19 or later.</li></ul>
</main>

* OceanSeek RPM packages

  * x86_64 platform:

    * el7: oceanseek-x.x.x.x-xxxxxxxxxxxxxxxxxx.el7.x86_64.rpm
    * al8: oceanseek-x.x.x.x-xxxxxxxxxxxxxxxxxx.al8.x86_64.rpm

  * arm_64 platform:

    * el7:

      * With LSE enabled (default): oceanseek-x.x.x.x-xxxxxxxxxxxxxxxxxx.el7.aarch64.rpm
      * With LSE disabled: oceanseek-x.x.x.x-xxxxxxxxxxxxxxxxxx.nonlse.el7.aarch64.rpm

    * al8: oceanseek-x.x.x.x-xxxxxxxxxxxxxxxxxx.al8.aarch64.rpm

* LogService RPM packages

  * x86_64 platform:

    * el7: oblogservice-ce-x.x.x-xxxxxxxxxxx.el7.x86_64.rpm
    * al8: oblogservice-ce-x.x.x-xxxxxxxxxxx.al8.x86_64.rpm

  * arm_64 platform:

    * el7: oblogservice-ce-x.x.x-xxxxxxxxxxx.el7.aarch64.rpm
    * al8: oblogservice-ce-x.x.x-xxxxxxxxxxx.al8.aarch64.rpm
  
  In addition, you need to prepare the oceanseek-libs and oceanseek-utils installation packages that match the architecture and version of OceanSeek, and upload them to OCP together.

### Deploy OceanBase Database Proxy (Optional)

The RPM packages for deploying OceanBase Database Proxy are as follows:

<main id="notice" type='explain'>
    <h4>Note</h4>
    <ul><li>For Debian/Ubuntu systems, you can directly use the RPM package. OCP is responsible for installation and deployment, so there is no need to convert it to a <code>.deb</code> package.</li>
    <li>For Rocky Linux 9 and Alibaba Cloud Linux 3, the al8 RPM package is recommended.</li>
    <li>The Linux kernel version must be 4.19 or later.</li></ul>
</main>

* x86_64 platform:

  * el7: obproxy-x.x.x.x-xxxxxxxxxxxxxx.el7.x86_64.rpm
  * al8: obproxy-x.x.x.x-xxxxxxxxxxxxxx.al8.x86_64.rpm

* ARM_64 platform:

  * el7: obproxy-x.x.x.x-xxxxxxxxxxxxxx.el7.aarch64.rpm
  * al8: obproxy-x.x.x.x-xxxxxxxxxxxxxx.al8.aarch64.rpm
