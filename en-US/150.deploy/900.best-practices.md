# Recommended configurations

To ensure that users can achieve good performance with OceanSeek across various business scenarios, OceanBase has summarized recommended configurations for key parameters and system variables based on extensive optimization experience from real-world scenarios.

OceanBase Cloud Platform (OCP) supports selecting a parameter template in the parameter settings when creating a tenant. Based on the selected template, OCP reads the RPM package content of the corresponding kernel version to obtain the recommended parameter values. For information about creating tenants with OCP, see [Create Primary Tenant](https://docs.oceanbase.com/ocp/create-a-primary-tenant).

This topic mainly introduces the recommended configurations of key parameters and system variables for different business scenarios.

## Parameter configuration templates

After installing the OceanSeek RPM package, you can view the parameter configuration templates for different business scenarios in the `/home/admin/oceanbase/etc` directory.

* `default_parameter.json`: Stores the recommended parameter configurations.
* `default_system_variable.json`: Stores the recommended system variable configurations.

**Template categories in the parameter configuration files:**

* `express_oltp`: This template is suitable for workloads such as transaction systems, core payment systems, and high-throughput internet applications, with no foreign key constraints, stored procedures, long transactions, large transactions, complex joins, or complex subqueries. It is recommended for AI workloads like vector hybrid search and historical database workloads. For detailed information about the recommended configurations in this scenario, see [express_oltp](#express_oltp) below.

* `olap`: This template is primarily used for real-time data warehouse analytics applications. For detailed information about the recommended configurations in this scenario, see [olap](#olap) below.

* `kv`: This template is suitable for HBase compatibility and Key-Value table model access modes, single partition access, and no SQL layer. This scenario typically requires extremely high data throughput and is very sensitive to latency. For detailed information about the recommended configurations in this scenario, see [KV](#KV) below.

## express_oltp

Currently, there are no recommended variable configurations for this scenario.

**Detailed information about the recommended parameter values for the express_oltp scenario is as follows:**

| **Parameter** | **Recommended value** | **Description** | **Level** |
| -------------------------- | ------------- | ---------------- | ---------- |
| [enable_record_trace_log](../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/300.cluster-level-configuration-items/7900.enable_record_trace_log.md) | False | SQL logging and transaction tracking events are prohibited. | cluster |
| [enable_syslog_recycle](../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/300.cluster-level-configuration-items/9000.enable_syslog_recycle.md) | True | Enabling automatic syslog recycling can prevent log files from filling up disk space. | cluster |
| [max_syslog_file_count](../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/300.cluster-level-configuration-items/13300.max_syslog_file_count.md) | 300 | When `enable_syslog_recycle` is enabled, this value should be set to an appropriate level. 300 is an empirical value. | cluster |
| [large_query_threshold](../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/300.cluster-level-configuration-items/11100.large_query_threshold.md) | 600s | In complex OLTP scenarios, some queries may take a long time to run. | cluster |
| [inc_sstable_upload_thread_score](../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/3650.inc_sstable_upload_thread_score.md) | 30 | The number of threads used by a tenant to execute data-sharing tasks in shared storage mode. | tenant |
| [enable_rebalance](../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/2800.enable_rebalance.md) | False | Disable automatic load balancing. | tenant |

### Example configuration for the express_oltp scenario

1. Execute the following statement in the sys tenant to configure cluster-level parameters.

    ```sql
    ALTER SYSTEM SET enable_record_trace_log = False;
    ALTER SYSTEM SET enable_syslog_recycle = True;
    ALTER SYSTEM SET max_syslog_file_count = 300;
    ALTER SYSTEM SET large_query_threshold = '600s';
    ```

2. Execute the following statement in a user tenant to configure tenant-level parameters.

     ```sql
     ALTER SYSTEM SET inc_sstable_upload_thread_score = 30;
     ALTER SYSTEM SET enable_rebalance = False;
     ```

### OLAP scenario configuration example

1. Execute the following statement in the sys tenant to configure cluster-level parameters.

    ```sql
    ALTER SYSTEM SET enable_record_trace_log = False;
    ALTER SYSTEM SET trace_log_slow_query_watermark = '7d';
    ALTER SYSTEM SET large_query_threshold = '0ms';
    ALTER SYSTEM SET enable_syslog_recycle = True;
    ALTER SYSTEM SET max_syslog_file_count = 300;
    ```

2. Execute the following statement in a user tenant to configure tenant-level parameters.

     ```sql
     ALTER SYSTEM SET inc_sstable_upload_thread_score = 30;
     ALTER SYSTEM SET ha_high_thread_score = 20;
     ALTER SYSTEM SET direct_load_allow_fallback = False;
     ALTER SYSTEM SET default_table_merge_engine = 'DELETE_INSERT';
     ALTER SYSTEM SET default_table_store_format = 'column';
     ALTER SYSTEM SET default_table_organization = 'HEAP';
     ALTER SYSTEM SET max_partition_num = 65536;
     ALTER SYSTEM SET default_skip_index_level = 1;
     ALTER SYSTEM SET default_delta_format = 'encoding';
     ALTER SYSTEM SET enable_rebalance = False;
     ```

3. Execute the following statement in a user tenant to configure tenant-level variables.

     ```sql
     SET GLOBAL ob_query_timeout = 604800000000;
     SET GLOBAL ob_trx_timeout = 604800000000;
     SET GLOBAL parallel_min_scan_time_threshold = 10;
     SET GLOBAL ob_sql_work_area_percentage = 30;
     SET GLOBAL parallel_degree_policy = AUTO;
     SET GLOBAL collation_server = utf8mb4_bin;
     SET GLOBAL collation_connection = utf8mb4_bin;
     ```

## View parameters and variables

* You can use the `SHOW PARAMETERS LIKE 'parameter_name';` statement to query parameter information.

  Example:

  ```sql
  SHOW PARAMETERS LIKE 'enable_syslog_recycle';
  ```

* You can use the following statements to query variable information.

   You can use the `SHOW [GLOBAL] VARIABLES LIKE 'variables_name';` statement to query.
  
    Example:

    ```sql
    SHOW VARIABLES LIKE 'ob_query_timeout';
    ```

    ```sql
    SHOW GLOBAL VARIABLES LIKE 'ob_query_timeout';
    ```
