# Deployment process

This topic describes the deployment process for OceanBase AI Database.

OceanBase AI Database consists of two components, OBServer and LogService. During deployment, you need to complete the deployment of these two components in sequence.

![1](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/ai-database/deployprocess.png)

1. Prepare before deployment.

   1. Before deployment, you need to choose an appropriate deployment plan based on your business requirements, so that you can determine the required machine resources and specifications, and complete the related server configurations. For details, see [Prepare servers](300.preparations-before-deploy/100.prepare-servers.md) and [Configure Servers](300.preparations-before-deploy/200.configure-servers.md).
   2. Prepare object storage that is compatible with the S3 protocol. For details, see [Prepare object storage](300.preparations-before-deploy/250.prepare-object-storage.md).
   3. Prepare the installation packages. For details, see [Prepare installation packages](300.preparations-before-deploy/300.prepare-installation-packages.md).
   4. Deploy OAT. For details, see [Deploy OAT](300.preparations-before-deploy/400.deploy-oat.md).

2. Add the servers to OAT. For details, see [Add a server](400.add-server.md).
3. Deploy OCP through OAT. You need to first create a MetaDB in OAT, then deploy OCP. For details, see [OCP deployment overview](500.deploy-ocp-use-oat/100.deployment-instructions.md).
4. Create an object storage configuration in OCP. For details, see [Create an object storage configuration](600.deploy-oceanbase-cluster-use-ocp/200.create-an-object-storage.md).
5. Create a LogService cluster in OCP. For details, see [Deploy a LogService cluster by using OCP](600.deploy-oceanbase-cluster-use-ocp/300.deploy-the-logservice-use-ocp.md).
6. Create an OceanBase AI Database cluster in OCP. For details, see [Deploy an OceanBase AI Database cluster using OCP](600.deploy-oceanbase-cluster-use-ocp/400.deploy-oceanbase-ai-cluster-using-ocp.md).
