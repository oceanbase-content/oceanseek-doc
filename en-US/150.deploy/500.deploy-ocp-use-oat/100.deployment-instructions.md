# OCP deployment overview

OceanBase Cloud Platform (OCP) runs in a Docker container. OCP and OceanBase AI Database have the same requirements on the server architecture and Linux OS.

## Introduction to OCP

OCP is an enterprise-level database management platform designed for OceanBase databases. With OCP, you can install, upgrade, scale out, or uninstall an OceanBase database cluster with a few clicks, create and manage O&M tasks, monitor the running status of clusters, and view alerts.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>OCP supports OceanBase AI Database starting from version V4.5.0.</p>
</main>

OCP supports all major versions of OceanBase AI Database and the full-lifecycle management of components such as OceanBase AI Database clusters and OceanBase AI Database tenants. It manages OceanBase AI Database resources such as hosts, networks, and software packages. You can use OCP to manage OceanBase AI Database clusters more efficiently at reduced IT O&M costs.

OCP supports two deployment modes: single-node deployment and high-availability deployment.

## Single-node deployment

In single-node deployment, all features of OCP are deployed on one node, including OCP-Server, MetaDB, MonitorDB, and OceanBase Database Proxy (ODP).

This deployment mode has the following benefits:

* Resource saving: All services are deployed on one host, which minimizes the required resources.

* Easy debugging: All requests are handled on one host without distributed processing, which facilitates log lookup and debugging.

* Few dependencies: In this deployment mode, OCP depends on fewer services and does not require server load balancing.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>Single-node deployment applies to scenarios with low availability and fast verification requirements. </p>
  </main>

## Multi-node deployment

Multi-node deployment means that OCP is deployed across multiple nodes, with all OCP components deployed on each node. The components include: OCP-Server, MetaDB, MonitorDB, and OBProxy. The deployment method on each node follows the single-node deployment pattern.

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>Multi-node deployment is commonly used in production environments where high system availability is required.</p>
</main>
