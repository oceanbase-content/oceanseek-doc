# Create an object storage configuration

Before deploying an OceanBase AI Database cluster, you must first create an object storage configuration. It is recommended that different object storage buckets be configured for OBServer and LogService in the OceanBase AI Database cluster.

This topic describes how to create an object storage configuration in OCP to provide storage support for AI clusters.

## Prerequisites

* An object storage service has been prepared. Supported services include S3-compatible object storage services such as Alibaba Cloud OSS, AWS S3, Tencent Cloud COS, Huawei Cloud OBS, and Azure Blob.
* You have obtained the following information for the object storage service:
  * Endpoint address
  * Region
  * AccessKey ID
  * AccessKey Secret
* The nodes where OBServer and LogService run can access the configured object storage.

## Procedure

1. After logging in to OCP, select **System Management** > **External Integration** from the bottom icon in the left navigation bar to go to the External Integrations page.

2. On the External Integrations page, click the **Object Storage** tab.

3. Click **Create** to open the **Create Object Storage** dialog box.

4. Fill in the object storage configuration information:

    <main id="notice" type='explain'>
    <h4>Note</h4>
    <ul>
    <li>When creating an object storage configuration, the system verifies whether the Endpoint is reachable and whether the AccessKey credentials are valid.</li>
    <li>It is recommended to use distinctive names for object storage configurations used by different business scenarios or environments to make later management easier.</li>
    <li>Currently, only AccessKey ID and AccessKey Secret authentication is supported for accessing object storage. Authorization through a RAM URL is not supported.</li>
    </ul>
    </main>

    | Parameter | Description | Required |
    |------|------|---------|
    | **Name** | The name of the object storage configuration, used to identify and distinguish between different configurations. The name must be 2 to 32 characters long and can contain Chinese characters, English letters, numbers, and underscores. | Yes |
    | **Protocol Type** | The protocol type of the object storage service. Only S3 is supported. | Yes |
    | **Endpoint** | The object storage access domain name, for example, `oss-cn-hangzhou.aliyuncs.com`. | Yes |
    | **AccessKey ID** | The object storage access ID, used to identify the user. | Yes |
    | **AccessKey Secret** | The key used to encrypt the signature string and for the signature service to verify the signature string. Please keep your AccessKey Secret secure. | Yes |
    | **Region** | The current private cloud region, for example, `cn-hangzhou`. | Yes |
    | **Remarks** | Remarks for this object storage configuration. Optional. | No |

5. After filling in the information, click **Verify** to check whether the configuration is valid.

6. If verification passes, click **OK** to successfully create the object storage configuration.

## Edit object storage configuration

For an existing object storage configuration, only the remarks can be edited. Click Edit for the corresponding configuration in the object storage list, modify the remarks in the dialog box, and save the changes.

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For security reasons, only the remarks can be modified at present. AccessKey values cannot be edited directly on the edit page.</p>
</main>
