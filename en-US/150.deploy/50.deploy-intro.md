# Deployment overview

OceanSeek supports multiple deployment methods. You can choose an appropriate method based on your scenario.

* If you want to quickly deploy OceanSeek for feature experience or testing, see [Get started with OceanSeek](../100.experience-oceanseek/100.get-started.md).

* If you want to perform a standardized deployment in a production environment, see the topics in this chapter to choose an appropriate deployment plan and deploy a production environment.

## Deployment process

OceanSeek consists of two components: OBServer and LogService. During deployment, you need to deploy the two components in sequence.

![1](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/oceanseek/oceanseek-deploy-process.png)

1. Before deployment, you need to choose an appropriate deployment plan based on your business requirements. For details, see [Choose a deployment plan](100.deploy-overview.md).

2. Prepare for deployment.

   1. Determine the required machine resources and specifications based on the selected deployment plan, and complete the related server configurations. For details, see [Prepare servers](300.preparations-before-deploy/100.prepare-servers.md) and [Configure servers](300.preparations-before-deploy/200.configure-servers.md).
   2. Prepare object storage that is compatible with the S3 protocol. For details, see [Prepare object storage](300.preparations-before-deploy/250.prepare-object-storage.md).
   3. Prepare the installation packages. For details, see [Prepare installation packages](300.preparations-before-deploy/300.prepare-installation-packages.md).

3. Create an object storage configuration in OCP. For details, see [Create an object storage configuration](600.deploy-oceanbase-cluster-use-ocp/200.create-an-object-storage.md).
4. Create a LogService cluster in OCP. For details, see [Deploy a LogService cluster by using OCP](600.deploy-oceanbase-cluster-use-ocp/300.deploy-the-logservice-use-ocp.md).
5. Create an OceanSeek cluster in OCP. For details, see [Deploy an OceanSeek cluster by using OCP](600.deploy-oceanbase-cluster-use-ocp/400.deploy-oceanbase-ai-cluster-using-ocp.md).
