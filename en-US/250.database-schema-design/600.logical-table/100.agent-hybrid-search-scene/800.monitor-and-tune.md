# Monitoring and maintenance

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This feature is an experimental feature in the current version.</p>
</main>

This topic describes the operation, maintenance, and tuning of Agent hybrid search scenario. Operations such as deleting Collections or Namespaces are asynchronous background tasks. You can view the progress through system views and adjust the deletion concurrency and the hot Namespace cache TTL via tenant-level parameters.

## Monitoring

You can query relevant views via SQL to view the progress of background tasks.

| **View** | **Note** |
| --- | --- |
| [oceanbase.DBA_OB_AGENT_DB_BACKGROUND_TASKS](../../../700.reference/700.system-views/400.system-view-of-mysql-mode/200.dictionary-view-of-mysql-mode/5730.o-dba_ob_agent_db_background_tasks-of-mysql-mode.md) | Background tasks currently in progress for the tenant (such as deletions or hot namespace expirations). |
| [oceanbase.DBA_OB_AGENT_DB_BACKGROUND_TASK_HISTORY](../../../700.reference/700.system-views/400.system-view-of-mysql-mode/200.dictionary-view-of-mysql-mode/5740.o-dba_ob_agent_db_background_task_history-of-mysql-mode.md) | The history of completed background tasks in the current tenant. |
| [oceanbase.CDB_OB_AGENT_DB_BACKGROUND_TASKS](../../../700.reference/700.system-views/300.system-view-of-sys-tenant/200.dictionary-view-of-sys-tenant/5630.o-cdb_ob_agent_db_background_tasks-of-sys-tenant.md) | All tenants: background tasks in progress (such as deletions or hot namespace expirations). |
| [oceanbase.CDB_OB_AGENT_DB_BACKGROUND_TASK_HISTORY](../../../700.reference/700.system-views/300.system-view-of-sys-tenant/200.dictionary-view-of-sys-tenant/5640.o-cdb_ob_agent_db_background_task_history-of-sys-tenant.md) | The history of completed background tasks for all tenants. |

## Maintenance

| **Parameter** | **Type** | **Default value** | **Note** |
| --- | --- | --- | --- |
| [enable_agent_db_background_task](../../../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/2320.enable_agent_db_background_task.md) | bool | True | Whether to enable background deletion tasks for logical tables. |
| [agent_db_background_delete_thread_score](../../../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/50.agent_db_background_delete_thread_score.md) | int | 0 (indicating the use of the default value 2) | Number of background deletion threads. Range: `[0, 100]`. A larger value means faster data deletion but more resource consumption. |
| [agent_db_hot_namespace_ttl](../../../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/55.agent_db_hot_namespace_ttl.md) | Time | `1h` | Hot namespace cache (vector index cluster centers) lifetime. Expired and unused caches are automatically evicted. Range: `[1s, 180d]`. After eviction, the data is reloaded on first access. You can use `ns.prewarm()` to preheat it. |
