## Prerequisites

* You have installed Python 3.x and pip.
* You have installed OceanBase AI Database and created a user tenant.

## Procedure

1. Check the versions of `Python` and `pip`.
2. Install the PyMySQL library.
3. Obtain the connection information for OceanBase AI Database.
4. Modify the database connection information in the `config.py` file.
5. Run the `main.py` file.

### Step 1: Check the versions of Python and pip

Open a command prompt or PowerShell terminal, and run the `python --version` and `pip --version` commands to ensure that Python and pip are properly installed.

**Example:**

```shell
PS C:\Windows\system32> python --version
Python 3.7.0
PS C:\Windows\system32> pip --version
pip 22.3.1 from d:\python\python37\lib\site-packages\pip (python 3.7)
```

### Step 2: Install the PyMySQL library

PyMySQL is a pure Python implementation of the MySQL client library. It is easy to install, does not require compilation, and has good cross-platform compatibility. It provides an interface for interacting with MySQL databases and supports Python 3.x.

Open a command prompt or PowerShell terminal, and run the following commands to install the PyMySQL library.

1. Run the following command to navigate to the `python-pymysql` directory of the code.

    **Example:**

    ```shell
    cd python-pymysql
    ```

2. Run the following command to install the Python libraries required by the project.

    **Example:**

    ```shell
    pip install -r requirements.txt
    ```

### Step 3: Obtain the connection information for OceanBase AI Database

Contact the deployment personnel or administrator of OceanBase AI Database to obtain the corresponding database connection string.

```shell
obclient -h$host -P$port -u$user_name -p$password -D$database_name
```

**Parameter description:**

* `$host`: The IP address for connecting to OceanBase AI Database. For connections through OceanBase Database Proxy (ODP), use an ODP address; for direct connections, use the IP address of an OBServer node.
* `$port`: The port for connecting to OceanBase AI Database. For ODP connections, the default port is `2883`, which can be customized during ODP deployment; for direct connections, the default port is `2881`, which can be customized during OceanBase AI Database deployment.
* `$database_name`: The name of the database to access.

    <main id="notice" type='notice'>
        <h4>Notice</h4>
        <p>The user connecting to the tenant must have the <code>CREATE</code>, <code>INSERT</code>, <code>DROP</code>, and <code>SELECT</code> privileges on this database. For more information about user privileges, see <a href="../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md">Privilege types</a>.</p>
    </main>

* `$user_name`: The connection account for the tenant. Common formats for ODP connections are `username@tenant_name#cluster_name` or `cluster_name:tenant_name:username`. For direct connection, the format is `username@tenant_name`.
* `$password`: The account password.

For more information about the connection string, see [Connect to OceanBase AI Database by using OBClient](../../../200.client/300.connect-to-an-oceanbase-tenant-by-using-obclient.md).

**Example:**

```shell
obclient -hxxx.xxx.xxx.xxx -P2881 -utest_user001@mysql001 -p****** -Dtest
```

## Error handling

When using PyMySQL to connect to OceanBase AI Database, you may encounter various errors. The following are some common errors and their handling methods:

1. **Connection error**: If you cannot connect to the database, check whether the connection parameters, including the hostname, port, username, password, and database name, are correct.

2. **Permission error**: If you encounter a permission-related error, ensure that the user has sufficient permissions to perform the required operation.

3. **SQL syntax error**: If an SQL statement contains a syntax error, check whether the SQL statement is correctly written.

4. **Data type error**: If the data type of the inserted value does not match the table definition, ensure that the data type is correct.

In your code, use `try-except` statements to catch and handle these errors, ensuring that the program handles errors gracefully instead of crashing directly. Also, use the `logging` module to record error information for easier debugging and troubleshooting.
