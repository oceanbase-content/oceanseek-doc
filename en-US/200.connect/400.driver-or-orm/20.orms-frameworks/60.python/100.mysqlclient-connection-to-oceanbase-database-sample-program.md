## Prerequisites

* You have installed Python 3.x and pip.
* You have installed OceanSeek and created a user tenant.

## Procedure

1. Check the versions of Python and pip.
2. Install the mysqlclient library.
3. Obtain the connection information for OceanSeek.
4. Modify the database connection information in the `config.py` file.
5. Run the `main.py` file.
6. Perform operations in the interactive command-line interface.

### Step 1: Check the versions of Python and pip

Open a Command Prompt or PowerShell terminal, and run the `python --version` and `pip --version` commands to ensure that Python and pip are properly installed.

**Example:**

```shell
PS C:\Windows\system32> python --version
Python 3.11.2
PS C:\Windows\system32> pip --version
pip 23.3.1 from C:\Users\xxx\AppData\Local\Programs\Python\Python311\Lib\site-packages\pip (python 3.11)
```

### Step 2: Install the mysqlclient library

mysqlclient is a C-language-based MySQL client library with high performance, suitable for scenarios requiring high performance. When installing the mysqlclient library, you need to compile and link the MySQL C API to connect to OceanSeek.

:::tab
tab Windows environment

**Method 1: Install using precompiled binaries (recommended)**

1. Download the `whl` file compatible with your Python version and operating system platform from [Download files](https://pypi.org/project/mysqlclient/#files).

2. Open a Command Prompt or PowerShell terminal, navigate to the directory where the `whl` file is located, and run the following command to install it:

    ```shell
    pip install mysqlclient-2.2.0-cp311-cp311-win_amd64.whl
    ```

**Method 2: Install directly**

1. Install MySQL or MySQL Connector/C, ensuring the development components are installed.

2. Install a C compiler (such as Visual Studio or MinGW).

3. Run the following command to install the mysqlclient library:

    ```shell
    pip install mysqlclient
    ```

tab Linux environment

1. Install the Python development package:

    ```shell
    sudo yum install python3-devel
    ```

2. Install the MySQL development libraries:

    ```shell
    sudo yum install mysql-devel
    ```

3. Run the following command to install the mysqlclient library:

    ```shell
    sudo pip install mysqlclient
    ```

### Step 3: Obtain OceanSeek connection information

Contact the OceanSeek deployment personnel or administrator to obtain the corresponding database connection string.

```shell
obclient -h$host -P$port -u$user_name -p$password -D$database_name
```

**Parameter description:**

* `$host`: The IP address for connecting to OceanSeek. For connections through OceanBase Database Proxy (ODP), use an ODP address; for direct connections, use the IP address of an OBServer node.
* `$port`: The port for connecting to OceanSeek. For ODP connections, the default port is `2883`, which can be customized during ODP deployment. For direct connections, the default port is `2881`, which can be customized during OceanSeek deployment.
* `$database_name`: The name of the database to access.

    <main id="notice" type='notice'>
      <h4>Notice</h4>
      <p>The user connecting to the tenant must have the <code>CREATE</code>, <code>INSERT</code>, and <code>SELECT</code> privileges on this database. For more information about user privileges, see <a href="../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md">Privilege types</a>.</p>
    </main>

* `$user_name`: The connection account for the tenant. For ODP connections, the common formats are `username@tenant_name#cluster_name` or `cluster_name:tenant_name:username`. For direct connections, the format is `username@tenant_name`.
* `$password`: The account password.

For more information about the connection string, see [Connect to OceanSeek by using OBClient](../../../200.client/300.connect-to-an-oceanbase-tenant-by-using-obclient.md).

**Example:**

```shell
obclient -hxxx.xxx.xxx.xxx -P2881 -utest_user001@mysql001 -p****** -Dtest
```

### Code in db.py

The `db.py` file is a Python module that encapsulates database operations, primarily used to implement create, read, update, and delete (CRUD) operations on a database.

This file mainly includes the following parts:

1. Import the MySQLdb module and the database connection parameters.

    **The sample code is as follows:**

    ```python
    import MySQLdb
    from config import OCEANBASE_CONFIG
    ```

2. Define a function to create a table.

    Define the `create_table` function, which creates a table named `test_tbl1` in OceanSeek. Use the `with` statement to manage the lifecycle of database connections and cursor objects, ensuring they are closed securely and avoiding issues like memory leaks. Define an SQL statement, execute it, and print the execution result or error message.

    **The sample code is as follows:**

    ```python
    def create_table():
        with MySQLdb.connect(**OCEANBASE_CONFIG) as conn:
            with conn.cursor() as cursor:
                try:
                    create_table_sql = """
                        CREATE TABLE test_tbl1 (
                            id INT UNSIGNED NOT NULL AUTO_INCREMENT,
                            name VARCHAR(50) NOT NULL,
                            age INT UNSIGNED NOT NULL,
                            PRIMARY KEY (id)
                        ) ENGINE=OCEANBASE AUTO_INCREMENT=1
                    """
                    cursor.execute(create_table_sql)

                    print("Table created successfully")
                except MySQLdb.Error as err:
                    print(err)
    ```

3. Define a function for inserting data.

    Define the `insert_record` function, which inserts a record into a specified table. The record contains two fields: `name` and `age`. Use the `with` statement to manage the lifecycle of database connections and cursor objects, ensuring they are closed securely and avoiding issues like memory leaks. Define the SQL statement, perform the insertion operation, commit the transaction, and print the execution result or error message.

    **The sample code is as follows:**

    ```python
    def insert_record(table_name, name, age):
        with MySQLdb.connect(**OCEANBASE_CONFIG) as conn:
            with conn.cursor() as cursor:
                try:
                    insert_sql = f"INSERT INTO {table_name} (name, age) VALUES (%s, %s)"
                    cursor.execute(insert_sql, (name, age))
                    conn.commit()

                    print("Record inserted successfully")
                except MySQLdb.Error as err:
                    print(err)
    ```

4. Define a function for querying table data.

    Define the `select_all` function, which queries all records in a specified table. Use the `with` statement to manage the lifecycle of database connections and cursor objects, ensuring they are closed securely and avoiding issues like memory leaks. Define the SQL statement, execute the query, iterate through the results, and print all records. If an exception occurs, catch it and print the error message.

    **The sample code is as follows:**

    ```python
    def select_all(table_name):
        with MySQLdb.connect(**OCEANBASE_CONFIG) as conn:
            with conn.cursor() as cursor:
                try:
                    select_sql = f"SELECT * FROM {table_name}"
                    cursor.execute(select_sql)
                    result = cursor.fetchall()
                    for row in result:
                        print(row)

You can use this program to create tables, insert records, and query all records, implementing basic database operations.

It first calls the `create_table` function to create a table named `test_tbl1`, then enters a `while` loop to wait for user input. Based on the user's selection, the program calls different functions to perform insertion or query operations until the user enters the `3` command to exit. ## Error handling

When using mysqlclient to connect to OceanSeek, you may encounter various errors. The following are some common errors and their handling methods:

1. **Connection error**: If you cannot connect to the database, check whether the connection parameters, including the hostname, port, username, password, and database name, are correct.

2. **Permission error**: If you encounter a permission-related error, ensure that the user has sufficient permissions to perform the required operation.

3. **SQL syntax error**: If an SQL statement contains a syntax error, check whether the SQL statement is correctly structured.

4. **Data type error**: If the data type of the inserted value does not match the table definition, ensure that the inserted data type is correct.

In your code, use `try-except` statements to catch and handle these errors, ensuring that the program can handle errors gracefully instead of crashing directly.
