# Connect to OceanSeek using Django

This topic describes how to connect to OceanSeek using Django and perform basic database operations, including creating tables, inserting data, updating data, and querying data.

## Prerequisites

* You have installed Python 3.x and pip.
* You have installed OceanSeek and created a user tenant.

## Procedure

1. Obtain the connection string for OceanSeek.
2. Install Django and the MySQL client libraries.
3. Create a Django project and application.
4. Configure the database connection.
5. Create models.
6. Run migrations.
7. Write views and configure URLs.
8. Run the development server.

### Step 1: Obtain the connection string for OceanSeek

Contact the deployment personnel or administrator of OceanSeek to obtain the corresponding database connection string.

```shell
obclient -h$host -P$port -u$user_name -p$password -D$database_name
```

**Parameter description:**

* `$host`: The IP address for connecting to OceanSeek. For connections through OceanBase Database Proxy (ODP), use an ODP address; for direct connections, use the IP address of an OBServer node.
* `$port`: The port for connecting to OceanSeek. For ODP connections, the default port is `2883`, which can be customized during ODP deployment. For direct connections, the default port is `2881`, which can be customized during OceanSeek deployment.
* `$database_name`: The name of the database to access.

    <main id="notice" type='notice'>
        <h4>Notice</h4>
        <p>The user connecting to the tenant must have the <code>CREATE</code>, <code>INSERT</code>, <code>UPDATE</code>, and <code>SELECT</code> privileges on this database. For more information about user privileges, see <a href="../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md">Privilege types</a>.</p>
    </main>

* `$user_name`: The connection account for the tenant. For ODP connections, the common formats are `username@tenant_name#cluster_name` or `cluster_name:tenant_name:username`. For direct connections, the format is `username@tenant_name`.
* `$password`: The account password.

For more information about the connection string, see [Connect to OceanSeek by using OBClient](../../../200.client/300.connect-to-an-oceanbase-tenant-by-using-obclient.md).

**Example:**

```shell
obclient -hxxx.xxx.xxx.xxx -P2881 -utest_user001@mysql001 -p****** -Dtest
```

### Step 2: Install Django and the MySQL client libraries

Django is an advanced Python web framework that provides an Object-Relational Mapping (ORM) system to simplify database operations. Django supports a variety of database backends, including MySQL, PostgreSQL, and SQLite.

Open the command prompt or PowerShell terminal and run the following commands to install Django and the MySQL client library.

```shell
pip install django mysqlclient
```

After installation, you can verify the installation by running the following command:

```shell
pip list | grep -i django
```

### Step 3: Create a Django project and application

1. Create a Django project named `oceanbase_demo`.

    ```shell
    django-admin startproject oceanbase_demo
    ```

2. Navigate to the project directory.

    ```shell
    cd oceanbase_demo
    ```

3. Create an application named `users`.

    ```shell
    python manage.py startapp users
    ```

### Step 4: Configure the database connection

1. Open the `oceanbase_demo/settings.py` file and modify the database configuration.

    ```python
    DATABASES = {
        'default': {
            'ENGINE': 'django.db.backends.mysql',
            'NAME': 'test',
            'USER': 'test_user001@mysql001',
            'PASSWORD': '******',
            'HOST': 'xxx.xxx.xxx.xxx',
            'PORT': '2881',
            'OPTIONS': {
                'charset': 'utf8mb4',
            },
        }
    }
    ```

2. Add the `users` application to `INSTALLED_APPS`.

    ```python
    INSTALLED_APPS = [
        'django.contrib.admin',
        'django.contrib.auth',
        'django.contrib.contenttypes',
        'django.contrib.sessions',
        'django.contrib.messages',
        'django.contrib.staticfiles',
        'users',
    ]
    ```

### Step 5: Create models

1. Open the `users/models.py` file and create the `User` model.

    ```python
    from django.db import models

    class User(models.Model):
        name = models.CharField(max_length=50)
        age = models.IntegerField()

        def __str__(self):
            return f"{self.name} ({self.age})"
    ```

### Step 6: Run migrations

1. Create a migration file.

    ```shell
    python manage.py makemigrations
    ```

2. Perform application migration.

    ```shell
    python manage.py migrate
    ```

### Step 7: Write view and URL configuration

1. Open the `users/views.py` file and create a view function.

    ```python
    from django.shortcuts import render
    from django.http import HttpResponse
    from .models import User

    def index(request):
        # Insert data
        User.objects.create(name='John', age=20)
        User.objects.create(name='Lucy', age=25)
        User.objects.create(name='Tom', age=30)

        # Update data
        user = User.objects.get(name='Lucy')
        user.age = 26
        user.save()

        # Query data
        users = User.objects.all()
        result = "<h1>Users</h1><ul>"
        for user in users:
            result += f"<li>{user}</li>"
        result += "</ul>"

        return HttpResponse(result)
    ```

2. Open the `oceanbase_demo/urls.py` file and configure the URL.

    ```python
    from django.contrib import admin
    from django.urls import path
    from users import views

    urlpatterns = [
        path('admin/', admin.site.urls),
        path('', views.index, name='index'),
    ]
    ```

### Step 8: Run the development server

1. Run the development server.

    ```shell
    python manage.py runserver
    ```

2. Access `http://127.0.0.1:8000/` in your browser to view the result.

    The expected response is as follows:

    ```html
    <h1>Users</h1>
    <ul>
        <li>John (20)</li>
        <li>Lucy (26)</li>
        <li>Tom (30)</li>
    </ul>
    ```

## Error handling

When connecting to OceanSeek using Django, you may encounter various errors. Below are some common errors and their handling methods:

1. **Connection error**: If you cannot connect to the database, check whether the connection parameters are correct, including the hostname, port, username, password, and database name.

2. **Permission error**: If you encounter a permission-related error, ensure the user has sufficient permissions to perform the required operation.

3. **SQL syntax error**: If an SQL statement contains a syntax error, check whether the SQL statement syntax is correct.

4. **Data type error**: If the data type of the inserted value does not match the table definition, ensure the inserted data type is correct.

In Django, you can use `try-except` statements to catch and handle these errors, ensuring the program handles errors gracefully instead of crashing directly. Additionally, you can use Django's logging system to record error information, facilitating debugging and troubleshooting.
