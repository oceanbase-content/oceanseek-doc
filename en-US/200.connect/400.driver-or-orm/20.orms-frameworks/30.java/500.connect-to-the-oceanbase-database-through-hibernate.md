### Step 1: Obtain the OceanBase AI Database connection string

1. Contact the deployment personnel or administrator of OceanBase AI Database to obtain the connection string.

    ```shell
    obclient -hxx.xx.xx.xx -P2883 -uroot@sys#cluster -p**** -A
    ```

2. Enter the URL of OceanBase AI Database.

    <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>This URL information is required in the <code>hibernate.cfg.xml</code> file.</p>
    </main>

    ```java
    jdbc:oceanbase://host:port/schema_name?user=$user_name&password=$password
    ```

    **Parameter description:**

    * `host`: The IP address for connecting to OceanBase AI Database. For ODP connections, use an ODP address; for direct connections, use the IP address of an OBServer node.
    * `port`: The port for connecting to OceanBase AI Database. For ODP connections, the default port is `2883`, which can be customized during ODP deployment. For direct connections, the default port is `2881`, which can be customized during OceanBase AI Database deployment.
    * `schema_name`: The name of the schema to access.
    * `user_name`: Specified using the `-u` parameter, in the format **user@tenant#cluster_name** or **username@SERVICE:service_name**. When using the **user@tenant#cluster_name** format, the default tenant is `sys` and the administrator user is `root`. The cluster name can be omitted when directly connecting to the database, but is required for ODP connections.
    * `password`: The account password.

For more information about URL parameters, see [Database URL](https://docs.oceanbase.com/oceanbase-connector-j/database-url).

### Code in User.hbm.xml

The `User.hbm.xml` file is a Hibernate mapping file that maps Java objects to tables in the database.

The code in the `User.hbm.xml` file mainly consists of the following parts:

1. File declaration statement.

    Declares this file as an XML file, using XML version `1.0` and character encoding `UTF-8`. It also specifies the DTD version and location for the Hibernate mapping file, setting the DTD document type to `hibernate-mapping`, version 3.0, language EN, and the file URL to `http://www.hibernate.org/dtd/hibernate-mapping-3.0.dtd``

    **The sample code is as follows:**

    ```xml
    <?xml version="1.0" encoding="UTF-8"?>
    <!DOCTYPE hibernate-mapping PUBLIC
            "-//Hibernate/Hibernate Mapping DTD 3.0//EN"
            "http://www.hibernate.org/dtd/hibernate-mapping-3.0.dtd">
    ```

2. Configuration of the mapping file.

    Defines a Hibernate mapping file that maps the entity class named `User` to a database table named `test_hibernate_mysql`.
    1. Uses the `package` attribute to specify the Java package in the mapping file as `com.oceanbase.pojo`.
    2. Uses the `class` tag to map data from the database table. The `name` attribute specifies the Java class name as `User`, and the `table` attribute specifies the database table name as `test_hibernate_mysql`.
    3. Defines the primary key attribute using `id`. The `name` attribute specifies the member variable `id` of the Java class `User`, and the `column` attribute specifies the database field name as `USER_ID`.
    4. Defines the primary key generation strategy using `generator`. The `class` attribute specifies the primary key generator type as `sequence`. The `param` element specifies the sequence name in the database as `SQ_USER`. The `name` attribute specifies this attribute corresponds to the `USER_NAME` column in the database table and sets its data type to string.

    **The sample code is as follows:**

    ```xml
    <hibernate-mapping package="com.oceanbase.pojo">
    <class name="User" table="test_hibernate_mysql">
        <!-- Configure primary key generation strategy -->
        <id name="id" column="USER_ID">
            <generator class="sequence">
                <param name="sequence">SQ_USER</param>
            </generator>
        </id>
        <!-- Configuration Tables and Properties -->
        <property name="name" column="USER_NAME" type="string"/>
    </class>
    </hibernate-mapping>
    ```

### Code in UserDao.java

The `UserDao.java` file implements user data CRUD operations using a Session object through the User Data Access Object (DAO) class.

The code in the `UserDao.java` file mainly consists of the following parts:

1. References to other classes and interfaces.

    * `User` class: used to manipulate user objects.
    * `Session` class: used to interact with the database.
    * `SessionFactory` class: used to create Session instances.
    * `Transaction` class: used to manage database transactions.
    * `Configuration` class: used to load the Hibernate configuration file.
    * `Query` class: used to execute query operations.
    * `List` interface: used to manipulate query result sets.

    **The sample code is as follows:**

    ```java
    import com.oceanbase.pojo.User;
    import org.hibernate.Session;
    import org.hibernate.SessionFactory;
    import org.hibernate.Transaction;
    import org.hibernate.cfg.Configuration;
    import org.hibernate.query.Query;
    import java.util.List;
    ```

2. Definition of the `UserDao` class.

  The `UserDao` Java class serves as a data access object for persisting user objects. It encapsulates a series of methods related to database interaction, performing CRUD operations on user objects. By calling the methods in the `UserDao` class, you can conveniently interact with the database and implement persistent operations.

  1. Initialization of a `UserDao` class instance.

     Uses an object initialization block to initialize a `Session` object during the class instantiation process.

     First, create a `Configuration` object and call its `configure` method to read the Hibernate configuration file (`hibernate.cfg.xml`). Then, create a `SessionFactory` object by calling the `buildSessionFactory` method. Finally, create a `Session` object by calling the `openSession` method and assign it to the `session` variable.

      **The sample code is as follows:**

      ```java
      private Session session;
      {
          Configuration cfg = new Configuration().configure();
          // Create SessionFactory
          SessionFactory sessionFactory = cfg.buildSessionFactory();
          session = sessionFactory.openSession();
      } //Read the hibernate.cfg.xml file
      ```

  2. Querying corresponding user information by ID.

     Uses the `selectUserById` method to query corresponding user information based on the provided ID parameter.

     Uses the `get` method of `session`. By passing in `User.class` and the `ID` parameter, it retrieves the User record with the corresponding ID from the database and stores it in the `user` variable.

     **The sample code is as follows:**

      ```java
      public User selectUserById(int ID) {
          User user = session.get(User.class, ID);
          return user;
      }
      ```

  3. Querying user information by username.

     Uses the `selectUserbyName` method to query user information by username.
     First, defines an HQL (Hibernate Query Language) statement to query user data with a specified name. The table name is `test_hibernate_mysql`, the table alias is `u`, and the query field name is `name`. Creates a `Query` object using the `createQuery` method of the `Session` object, passing the HQL statement and the entity class as parameters. Sets query parameters using the `setParameter` method of the `Query` object, where `0` indicates the parameter position and `name` indicates the parameter value. Executes the query using the `list` method of the `Query` object and converts the query results into a list of `User` objects.

     **The sample code is as follows:**

      ```java
      public List<User> selectUserbyName(String name) {
        String sql = "FROM test_hibernate_mysql u WHERE u.name =?";
        Query<User> query = session.createQuery(sql, User.class);
        query.setParameter(0, name);
        List<User> users = query.list();
        return users;
      }
      ```

  4. Query all user data.

     The `selectUser` method is used to query all user data.
     Define an SQL statement to query all user data. Use the `createNativeQuery` method of the `Session` object to create a `Query` object and pass the SQL statement as a parameter. Then, use the `addEntity` method to add the entity class `User` to the query so that the query result can be converted into a list of `User` objects. Execute the query using the `getResultList` method of the `Query` object and convert the query result into a list of User objects.

     **The sample code is as follows:**

      ```java
      public List<User> selectUser() {
          String sql = "SELECT * FROM test_hibernate_mysql";
      ```
