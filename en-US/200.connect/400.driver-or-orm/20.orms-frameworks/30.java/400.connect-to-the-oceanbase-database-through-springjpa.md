### Step 1: Obtain the OceanBase AI Database connection string

1. Contact the deployment personnel or administrator of OceanBase AI Database to obtain the connection string.

    ```shell
    obclient -hxx.xx.xx.xx -P2883 -uroot@sys#cluster -p**** -A
    ```

2. Enter the URL of OceanBase AI Database.

    <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>This URL information is required in the <code>application.yml</code> file.</p>
    </main>

    ```java
    jdbc:oceanbase://host:port/schema_name?user=$user_name&password=$password&characterEncoding=utf-8&useSSL=false&serverTimezone=GMT%2B8
    ```

    **Parameter description:**

    * `host`: The IP address for connecting to OceanBase AI Database. For ODP connections, use an ODP address; for direct connections, use the IP address of an OBServer node.
    * `port`: The port for connecting to OceanBase AI Database. For ODP connections, the default port is `2883`, which can be customized during ODP deployment. For direct connections, the default port is `2881`, which can be customized during OceanBase AI Database deployment.
    * `schema_name`: The name of the schema to access.
    * `user_name`: Specified using the `-u` parameter, in the format **user@tenant#cluster_name** or **username@SERVICE:service_name**. When using the **user@tenant#cluster_name** format, the default tenant is `sys` and the administrator user is `root`. The cluster name can be omitted when connecting directly to the database, but is required for ODP connections.
    * `password`: The account password.
    * `characterEncoding=utf-8&useSSL=false&serverTimezone=GMT%2B8`: Additional connection properties.

        * `characterEncoding`: The character encoding supported by the database URL option. Default value is `utf8`.
        * `useSSL`: Whether to force the use of `SSL/TLS` for the connection. Default value is `false`.
        * `serverTimezone`: Sets the server timezone. Default value is China Standard Time.

For more information about URL parameters, see [Database URL](https://docs.oceanbase.com/oceanbase-connector-j/database-url).

@Repository("userRepository")
public interface UserRepository extends JpaRepository<User, Integer> {
