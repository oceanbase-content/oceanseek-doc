### Step 1: (Optional) Install the Go language and its driver

If you have already installed the Go language and the Go-SQL-Driver/MySQL driver, skip this step. If not, follow these steps to install them.

### Step 2: Obtain OceanBase AI Database connection information

Contact the OceanBase AI Database deployment personnel or administrator to obtain the corresponding database connection information.

```sql
obclient  -h{host} -u{user_name} -p****** -P{port} -D{schema_name}
```

The database connection string contains the parameters required to access the database. You can use the connection string to log in to the database and verify that the parameter information is correct.

<main id="notice" type='explain'>
 <h4>Note</h4>
 <p>The URL information here is required in the <code>test.go</code> file.</p>
</main>

**Parameter description:**

* `host`: The IP address for connecting to OceanBase AI Database. For connections through ODP, this is an ODP address; for direct connections, it is the IP address of an OBServer node.
* `user_name`: The connection account for the tenant. For connections through ODP, the common formats are `username@tenant_name#cluster_name` or `cluster_name:tenant_name:username`. For direct connections, the format is `username@tenant_name`.
* `password`: The account password.
* `port`: The port for connecting to OceanBase AI Database. For connections through ODP, the default port is `2883`, which can be customized during ODP deployment. For direct connections, the default port is `2881`, which can be customized during OceanBase AI Database deployment.
* `schema_name`: The name of the schema to access.

The `test.go` file defines how to use the Go-SQL-Driver/MySQL driver to connect to a MySQL database and perform database operations using APIs provided by GORM.
The `test.go` file contains the following sections:

2. Define the `import` statements.

3. Define the `User` struct.

     Defines a struct named `User` to represent a user's basic information. It contains four fields: the user's unique identifier `ID`, the user's name `Name`, the user's age `Age`, and the user's birthday `Birthday`.

    **The sample code is as follows:**

    ```go
    type User struct {
    ID       int
    Name     string
    Age      int
    Birthday time.Time

    }
    ```

4. Define the `transformString` function.
   Defines a function named `transformString` to convert a string to a specified encoding format. It accepts two parameters: `str` and `encoder`. The function calls `transform.String` to convert the string to the specified encoding format. If an error occurs during the conversion, it returns the original string. Finally, the function returns the converted string or the original string.

    **The sample code is as follows:**

    ```go
    func transformString(str string, encoder transform.Transformer) string {
        result, _, err := transform.String(encoder, str)
        if err != nil {
            return str
        }
        return result
    }
    ```

5. Define the `main` function.

    By calling the `main` function, operations such as creating, reading, updating, and deleting user information are performed on the created user information, and `logrus` is used to output corresponding debug logs to the console.

   1. Initialize `logrus`.

        Use the `logrus` package to initialize log output, set the log output format to text, the log level to `Debug`, and output to the standard output stream.

        **The sample code is as follows:**

        ```go
        logrus.SetFormatter(&logrus.TextFormatter{})
        logrus.SetLevel(logrus.DebugLevel)
        logrus.SetOutput(os.Stdout)
        ```

   2. Connect to the database.

        Define a string variable named `dsn`, which contains the information required to connect to a MySQL database, including the username, password, host address, port number, database name, character set, etc. Call the `gorm.Open` function to connect to the MySQL database, passing in the `dsn` variable and a parameter of type `gorm.Config`, and return a connection object. If an error occurs during the connection, output the error message and exit the program.

        **The sample code is as follows:**

        ```go
        dsn := "user_name:******@tcp(host:port)/schema_name?charset=utf8mb4&parseTime=True&loc=Local"
        db, err := gorm.Open(mysql.Open(dsn), &gorm.Config{})
        if err != nil {
            fmt.Println(err.Error())
            return
        }
        ```

   3. Database operations.

        Use a `gorm.DB` object to perform database operations, including automatic migration, inserting data, querying data, updating data, and deleting data. The specific process is as follows:

        1. Call the `db.AutoMigrate` function to automatically migrate the table corresponding to the `User` struct. If the table does not exist, create it. Use the `defer` keyword and the `db.Migrator().DropTable` function to defer the deletion of the `users` table, meaning the table will be deleted when the program exits.
        2. Create a `User` struct instance named `user` and insert it into the database.
        3. Query the user with ID 1 and output the query result.
        4. Update the information for the user with ID 1 and save it to the database.
        5. Delete the user with ID 1 and output the deletion result.

       **The sample code is as follows:**

       ```go
       db.AutoMigrate(&User{})
       defer db.Migrator().DropTable("users")
       // Record Start Time
       start := time.Now()
       // Create a User instance named user and insert it into the database.
       user := User{Name: "OceanBase", Age: 12, Birthday: time.Date(2022, 06, 01, 00, 00, 00, 00, time.UTC)}
       result := db.Create(&user)
       fmt.Println(user.ID)
       fmt.Println(result.Error)
       fmt.Println(result.RowsAffected)
       // Query the user with ID 1 and output the query result.
       user = User{ID: 1}
       result = db.First(&user)
       fmt.Println(user)
       fmt.Println(result.Error)
       fmt.Println(result.RowsAffected)
       // Update the information of the user with ID 1 and save it to the database.
       user = User{ID: 1, Name: "ob", Age: 13, Birthday: time.Date(2023, 06, 01, 00, 00, 00, 00, time.UTC)}
       result = db.Save(&user)
       fmt.Println(user)
       fmt.Println(result.Error)
       fmt.Println(result.RowsAffected)
       // Delete the user with ID 1 and output the deletion result.
       user = User{ID: 1}
       result = db.Delete(&user)
       fmt.Println(user.ID)
       fmt.Println(result.Error)
       fmt.Println(result.RowsAffected)
       ```

6. Output logs.

   Call the `time.Since` function to calculate the program runtime, call the `logrus.WithFields` function to create a logger with fields, and call the `Debug` function to output log information.
