## Prerequisites

Install OceanBase AI Database, the Go language, and related drivers, and ensure that environment variables are correctly configured.

* Install OceanBase AI Database.
* Install the Go language.
* Install the Go-SQL-Driver/MySQL driver.

### Step 1: (Optional) Install the Go language and its drivers

If you have already installed the Go language and the Go-SQL-Driver/MySQL driver, skip this step. If not, follow these steps to install them.

1. Install the Go language

    1. Download the Go installation package: You can download the appropriate package for your operating system from the [Go official website](https://golang.org/dl/).

        <main id="notice" type='explain'>
         <h4>Note</h4>
         <p>The Go installation package used in this document is named go1.20.6.windows-amd64.msi.</p>
        </main>

    2. Install the Go language: Double-click the downloaded package and follow the prompts to install it.

    3. Configure environment variables: Add the Go installation path to the system's PATH environment variable.
       * In a Windows environment, you can add `C:\usr\local\go\bin` to the Path value in **Control Panel > System and Security > System > Advanced system settings > Environment Variables > System Variables**.
       * In a Linux or macOS environment, edit the `~/.bashrc` or `~/.bash_profile` file and add the following content:

            ```shell
            export PATH=$PATH:/usr/local/go/bin
            ```

        <main id="notice" type='explain'>
         <h4>Note</h4>
         <p><code>\usr\local\go\bin</code> is the default installation directory. If you modified the installation directory during Go installation, replace it with the corresponding directory.</p>
        </main>

    4. Verify the installation: Enter the following command in the shell command line to check the Go version and verify the installation:

        ```shell
        C:\Users\admin\> go version
        go version go1.20.6 windows/amd64
        ```

2. Install the Go-SQL-Driver/MySQL driver

    You can choose different installation methods depending on the version of the Go language. When installing the Go-SQL-Driver/MySQL driver, navigate to the corresponding project directory and open a command-line terminal. For more information about `Go-SQL-Driver/MySQL`, visit [Github](https://github.com/go-sql-driver/mysql).

    The installation command is as follows:

    ```shell
    C:\Users\admin\Desktop\go-oceanbase>go get -u github.com/go-sql-driver/mysql
    go: downloading github.com/go-sql-driver/mysql v1.7.1
    go: added github.com/go-sql-driver/mysql v1.7.1
    ```

    If you cannot install it using the `go get` command due to version or network issues, you can use the `go install` command to install `go-sql-driver/mysql`.

   1. Clone the `go-sql-driver/mysql` repository from GitHub into the `go/src` directory.

        ```bash
        cd /usr/local/go/src   
        git clone https://github.com/go-sql-driver/mysql.git 
        ```

        <main id="notice" type='notice'>
            <h4>Note</h4>
            <p><code>/usr/local/go/src</code> must be replaced with the actual installation directory of Go.</p>
        </main>

   2. Install it using `go install`.

        ```bash
        go install mysql
        ```

        <main id="notice" type='notice'>
            <h4>Note</h4>

For example, if the error <code>cannot find package &quot;mysql&quot; in: /usr/local/go/src/vendor/mysql</code> occurs, place the mysql folder in the <code>/src/vendor</code> directory before running the installation command.</p>
        </main>

   3. Check whether the Go-SQL-Driver/MySQL driver has been installed. If the installation fails, modify the configuration according to the error message.

        ```bash

        ```

### Step 2: Obtain OceanBase AI Database connection information

Contact the OceanBase AI Database deployment personnel or administrator to obtain the corresponding database connection string.

```sql
obclient  -h{host} -u{username} -p****** -P{port} -D{schema_name}
```

The database connection string contains the parameters required to access the database. You can use it to log in to the database and verify that the parameter information is correct.

<main id="notice" type='explain'>
 <h4>Note</h4>
 <p>The URL information here is required in the <code>test.go</code> file.</p>
</main>

**Parameter description:**

* `host`: The IP address for connecting to OceanBase AI Database. For ODP connections, this is an ODP address; for direct connections, this is the IP address of an OBServer node.
* `user_name`: The connection account for the tenant. For ODP connections, the common formats are `username@tenant_name#cluster_name` or `cluster_name:tenant_name:username`. For direct connections, the format is `username@tenant_name`.
* `password`: The account password.
* `port`: The port for connecting to OceanBase AI Database. For ODP connections, the default port is `2883`, which can be customized during ODP deployment. For direct connections, the default port is `2881`, which can be customized during OceanBase AI Database deployment.
* `schema_name`: The name of the schema to access.

### Code in go.mod

The `go.mod` file is used to define the project's module name, Go version number, and dependency declarations.

The `go.mod` file contains the following content:

* `module go-oceanbase`: This is the project's module name, which defines its namespace. In Go 1.16 and later, the module name must match the name of the project's root directory.
* `go 1.20`: This is the Go version required by the project.
* `require github.com/go-sql-driver/mysql v1.7.1 // indirect`: This is the project's dependency declaration. It specifies that the project requires the `github.com/go-sql-driver/mysql` module version V1.7.1, and that this dependency is an indirect dependency, associated with another dependency `go.sum`.

### Code in test.go

The `test.go` file defines how to interact with OceanBase AI Database using the Go language, including operations such as connecting to the database, creating tables, inserting data, querying data, and deleting tables.
The `test.go` file contains the following content:

1. Define the `main` package.
     `package main` indicates that this is a package for a runnable program. This package contains a `main()` function, which is executed when the program runs.

2. Define the `import` statements.

    The `import` statement imports the following four packages:

    * `database/sql`: Provides a general SQL database access interface. It defines a set of general interfaces and functions for connecting to and operating various types of SQL databases.
    * `fmt`: Provides functions for formatted input and output. It defines a set of functions for formatting data into strings and outputting them to the console or other devices.
    * `log`: Provides functions for logging information. It defines a set of functions for outputting log information to the console or other devices.
    * `github.com/go-sql-driver/mysql`: Provides the driver. It implements the interfaces defined in the `database/sql` package to connect to and operate on databases in Go. You must provide the correct installation path for `go-sql-driver/mysql`.

    **The sample code is as follows:**

    ```go
    import (
    "database/sql"
    "fmt"
    "log"

    _ "github.com/go-sql-driver/mysql"
    // Enter the installation path of go-sql-driver/mysql.
    )
    ```

3. Define the `Str` struct.
   It contains a field `Name` to store query results. A `main()` function is defined, which includes a `selectAll()` function to perform operations such as creating a table, inserting data, querying data, and dropping a table.

    **The sample code is as follows:**

    ```go
    type Str struct {
    Name string
    }

    func main() {
    selectAll()
    }
    ````

4. Define the `selectAll()` function.

    The `selectAll()` function encompasses operations such as connecting to a database, creating a table, inserting data, querying data, and dropping a table.

    1. Connect to the database.
       Define the connection string `conn`, which includes connection parameters such as the username, password, IP address, port number, and database name. Call the `sql.Open()` function to open a database connection. If an error occurs, log it and exit the program. Use the `defer` keyword to delay closing the database connection, ensuring it is closed at the end of the function.

        **The sample code is as follows:**

        ```go
        conn := "user_name:******@tcp(host:port)/schema_name"
        // Database connection parameters

        db, err := sql.Open("mysql", conn)
        if err != nil {
            log.Fatal(err)
        }
        ```

    2. Print a message to the console.
       Use the `defer` keyword to delay executing the `db.Close()` function, ensuring the database connection is closed at the end of the function. Use the `fmt.Printf()` function to output a success message to the console.

        **The sample code is as follows:**

        ```go
        defer db.Close()

        if err != nil {
            log.Fatal(err)
        }

        fmt.Printf("success to connect OceanBase with go_mysql driver\n")
        ```

    3. Create data.
       Create a table named `t1` with a string-type field `str` of length `256`.

        **The sample code is as follows:**

        ```go
            _, err = db.Query("create table t1(str varchar(256))")
        if err != nil {
            log.Fatal(err)
        }
        ```

    4. Insert data.
       Insert a row of data into table `t1`, setting the value of the `str` field to `Hello OceanBase`.

        **The sample code is as follows:**

        ```go
        _, err = db.Query("insert into t1 values ('Hello OceanBase')")
        if err != nil {
            log.Fatal(err)
        }
        ```

    5. Query data.
       Query all data from table `t1` and assign the query result to the variable `res`. If the query fails, return an error message.

        **The sample code is as follows:**

        ```go
        res, err := db.Query("SELECT * FROM t1")
        if err != nil {
            log.Fatal(err)
        }
        defer res.Close()

        for res.Next() {
            var str Str
            res.Scan(&str.Name)
            fmt.Printf("%s\n", str.Name)
        }
        ```

    6. Delete data.
       Delete table `t1`. If the deletion fails, return an error message.

        **The sample code is as follows:**

        ```go
        _, err = db.Query("drop table t1")
        if err != nil {
            log.Fatal(err)
        }
        ```
