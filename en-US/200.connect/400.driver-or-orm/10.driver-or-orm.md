# Connect via driver or ORM framework

OceanSeek supports connections through drivers or ORM frameworks, providing flexible access solutions for different programming languages and development scenarios.

## C

* C driver (OceanBase Connector/C)

  OceanBase Connector/C is a C/C++-based client development component for OceanBase, supporting the C API library.

  OceanBase Connector/C allows C/C++ programs to access OceanSeek at a relatively low level, performing operations such as database connection, data access, error handling, and prepared statement processing.

  OceanBase Connector/C, also known as LibOBClient, is used by applications as an independent server process to communicate with the database server OBServer node over the network. The client program references C API header files during compilation and can connect to the C API library files.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>The so file generated by LibOBClient is <code>libobclient.so</code> (corresponding to MySQL's <code>libmysqlclient.so</code>), and the command-line tool after OceanSeek installation is OBClient (corresponding to MySQL's command-line tool). </p>
  </main>

  For specific examples of connecting to OceanSeek using C applications, see [Connect to OceanSeek by using MySQL Connector/C](../400.driver-or-orm/20.orms-frameworks/10.c-sharp/100.connect-to-the-oceanbase-database-through-mysql-connector-c-of-mysql-mode.md).

    PyMySQL is a library for connecting to MySQL servers in Python 3.x. It follows the Python Database API v2.0 specification and includes a pure-Python MySQL client library. You can use the PyMySQL driver to provide connections from Python applications to OceanSeek. For more information about how to connect Python applications to OceanSeek, see [Connect to OceanSeek by using PyMySQL](../400.driver-or-orm/20.orms-frameworks/60.python/50.pymysql-connection-to-oceanbase-database-sample-program.md).

    MySQL-connector-python is a MySQL database driver officially provided by Oracle and specifically designed for Python. It complies with the Python Database API v2.0 specification and provides a complete set of features to conveniently interact with MySQL databases through Python code. This library is cross-platform, supports Python 2 and 3, and is implemented in pure Python without relying on any external libraries. MySQL-connector-python can also be used to establish connections to OceanSeek for querying and managing data. For example code on how to use MySQL-connector-python to connect to OceanSeek, see [Connect to OceanSeek by using MySQL Connector/Python](../400.driver-or-orm/20.orms-frameworks/60.python/150.mysql-connector-py-connection-to-oceanbase-database-sample-program.md).
