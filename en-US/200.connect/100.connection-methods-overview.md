# Overview of connection methods

This topic describes how to connect to and access OceanBase AI Database. Currently, you can connect to OceanBase AI Database by using a client, GUI, driver, ORM framework, or connection pool.

## Choose a client

You can use any of the following clients to connect to OceanBase AI Database:

* MySQL client (mysql)

  The mysql client is a command-line client for MySQL databases. You must install it separately.

  After connecting to OceanBase AI Database, you can run MySQL O&M commands and execute SQL statements on the mysql command line to perform the following tasks:

  * Compute, store, and print query results.

  * Create database objects, check and modify object definitions.

  * Perform database management and modify parameters.

  For more information about how to connect to OceanBase AI Database by using the mysql client, see [Connect to OceanBase AI Database by using the MySQL client](200.client/200.connect-to-an-oceanbase-tenant-by-using-a-mysql-client.md).

* OceanBase Client (OBClient)

  OBClient is an interactive query tool that supports batch processing. It must be installed separately. OBClient provides a command-line user interface and acts as the client when it is connected to a database. It can connect to OceanBase AI Database.

  When you run OBClient, you must specify the connection information of the OceanBase AI Database tenant. After you connect to OceanBase AI Database, you can use OBClient to run database commands (including common MySQL commands), SQL statements, and PL statements to perform the following tasks:

  * Compute, store, and print query results.

  * Create database objects, check and modify object definitions.

  * Develop and run batch processing scripts.

  * Perform database management and modify parameters.

  For more information about how to connect to an OceanBase AI Database tenant by using OBClient, see [Connect to OceanBase AI Database by using OBClient](200.client/300.connect-to-an-oceanbase-tenant-by-using-obclient.md).

* OceanBase Developer Center (ODC)

  OceanBase Developer Center (ODC) is an enterprise-level database development platform tailored for OceanBase AI Database.

  ODC supports connecting to OceanBase AI Database and provides database developers with features such as daily development operations, WebSQL, SQL diagnostics, session management, and data import and export.

  For more information about how to connect to OceanBase AI Database by using ODC, see [Connect to OceanBase AI Database by using ODC](200.client/400.connect-to-the-oceanbase-database-through-odc.md).

## Choose a GUI client

* DBeaver

  DBeaver is a general-purpose database client tool. It connects to databases using the JDBC drivers provided by each database and supports common relational databases, non-relational databases, distributed databases, and more.

  For more information, see [Connect to OceanBase AI Database by using DBeaver](300.gui/100.connect-to-oceanbase-database-through-dbeaver.md).

* Navicat

  Similar to DBeaver, Navicat is also a general-purpose database client tool. It connects to databases using the JDBC drivers provided by each database and supports common relational databases, non-relational databases, distributed databases, and more.

  For more information, see [Connect to OceanBase AI Database by using Navicat](300.gui/200.connect-to-oceanbase-database-through-navicat.md).

## Choose a driver or ORM framework

OceanBase AI Database supports connections through drivers or ORM frameworks, providing flexible access solutions for different programming languages and development scenarios. For more information, see [Connect via driver or ORM framework](400.driver-or-orm/10.driver-or-orm.md).
