# Connect to OceanSeek by using the MySQL client

You can use the MySQL client to connect to a user tenant of OceanSeek. This topic describes the prerequisites and procedure, and provides an example to help you get started.

## Prerequisites

Before you connect to OceanSeek by using the MySQL client, make sure that the following conditions are met:

* The MySQL client is installed on your local server. OceanSeek supports MySQL client versions 5.5, 5.6, and 5.7.

* The environment variable `PATH` contains the directory where the MySQL client is located.

* The client is in the allowlist of the tenant. For more information about how to query and configure a tenant allowlist, see [View and set tenant allowlists](../../600.manage/200.tenant-management/600.common-tenant-operations/500.view-and-set-whitelist.md).

## Procedure

### Connect through ODP

Run the following MySQL command to connect to OceanSeek by using OceanBase Database Proxy (ODP):

```shell
mysql -h$host -P$port -u$user_name -p****** [-c] [-A] [$database_name]
```

**Parameter description:**

* `-h` specifies the IP address for connecting to OceanSeek. Replace `$host` with the actual IP address of ODP used for connection.
* `-P` specifies the port for connecting to OceanSeek. Replace `$port` with the port customized when ODP is deployed. The default value is `2883`.
* `-u` specifies the tenant account for connecting to OceanSeek. `$user_name` can be in any of the following formats: `username@tenant_name#cluster_name`, `cluster_name:tenant_name:username`, `cluster_name-tenant_name-username`, and `cluster_name.tenant_name.username`. You can use the MySQL client only to connect to a user tenant. The default username of the administrator of a user tenant is `root`.

   <main id="notice" type='explain'>
      <h4>Note</h4>
      <p><ul><li>When connecting to OceanSeek through ODP, you can obtain the cluster name as follows:</br>First, connect directly to OceanSeek. Then, use the <code>SHOW PARAMETERS LIKE 'cluster';</code> command to get the cluster name. The value of <code>VALUE</code> in the returned result corresponds to the name of the OceanSeek cluster.</li><li>If ODP proxies multiple clusters, you must specify the cluster name when connecting. If ODP proxies only one cluster, specifying the cluster name is not required.</li></ul></p>
   </main>

* `-p` specifies the account password for connecting to OceanSeek. Replace `******` with the actual password.

   <main id="notice" type='explain'>
      <h4>Note</h4>
      <p>For security purposes, we recommend that you do not directly enter the password on the CLI, especially in an environment where the script or historical records are visible. You can skip this option and enter the password when being prompted to.</p>
   </main>

* `-c` is optional, which specifies that comments are not ignored in the runtime environment of MySQL.

   <main id="notice" type='explain'>
      <h4>Note</h4>
      <p>Hints are special comments that are not affected by the <code>-c</code> option.</p>
   </main>

* `-A` is optional, which specifies not to automatically retrieve the statistical information when the client connects to OceanSeek.
* `$database_name` is optional, which specifies the default database to be used after the connection to OceanSeek is established. By default, no database is accessed after the connection is established if you do not specify this option. You need to manually select a database.

**Example:**

```shell
mysql -h10.10.10.1 -uuser001@obmysql#obdemo -P2883 -p****** -c -A oceanbase
```

### Connect via direct connection

Run the following MySQL command to directly connect to OceanSeek:

```shell
mysql -h$host -P$port -u$user_name -p****** [-c] [-A] [$database_name]
```

**Parameter description:**

* `-h` specifies the IP address for connecting to OceanSeek. Replace `$host` with the actual IP address of the OBServer node for direct connection.

   <main id="notice" type='notice'>
     <h4>Notice</h4>
     <p>When you use the direct connection method, make sure that the tenant resources are distributed on the OBServer node you specified. Otherwise, you cannot connect to the tenant by using this OBServer node.</p>
   </main>

* `-P` specifies the port for connecting to OceanSeek. Replace `$port` with the port customized when OceanSeek is deployed. The default value is `2881`.
* `-u` specifies the tenant account for connecting to OceanSeek. The format of `$user_name` is `username@tenant_name`. The default username of the administrator of a user tenant is `root`.

   <main id="notice" type='notice'>
      <h4>Notice</h4>
      <p>When you directly connect to OceanSeek, specify the username and tenant name in the format of <code>username@tenant_name</code> for the <code>-u</code> option, and do not specify the cluster name. If you include the cluster name in <code>-u</code>, a connection error is returned.</p>
   </main>

* `-p` specifies the account password for connecting to OceanSeek. Replace `******` with the actual password.

   <main id="notice" type='explain'>
      <h4>Note</h4>
      <p>For security purposes, we recommend that you do not directly enter the password on the CLI, especially in an environment where the script or historical records are visible. You can skip this option and enter the password when being prompted to.</p>
   </main>

* `-c` is optional, which specifies that comments are not ignored in the runtime environment of MySQL.

   <main id="notice" type='explain'>
      <h4>Note</h4>
      <p>Hints are special comments that are not affected by the <code>-c</code> option.</p>
   </main>

* `-A` is optional, which specifies not to automatically retrieve the statistical information when the client connects to OceanSeek.
* `$database_name` is optional, which specifies the default database to be used after the connection to OceanSeek is established. By default, no database is accessed after the connection is established if you do not specify this option. You need to manually select a database.

**Example:**

```shell
mysql -h10.10.10.1 -uuser001@obmysql -P2881 -p****** -c -A oceanbase
```

## Connection example

1. Open a command-line terminal.
2. Run the following command to connect to a user tenant of OceanSeek by using the MySQL client:

   ```shell
   mysql -hxxx.xx.xxx.xxx -P2883 -uroot@mysql001#test432 -p****** -A oceanbase
   ```

   The return result is as follows:

   ```shell
   Welcome to the MariaDB monitor.  Commands end with ; or \g.
   Your MySQL connection id is 15
   Server version: 5.6.25 OceanBase 4.3.2.0 (r200000272024061717-93c0ed73ebbcac6edbf7b585860b75d825935358) (Built Jun 17 2024 18:06:04)

   <...>

   Type 'help;' or '\h' for help. Type '\c' to clear the current input statement.

   MySQL [oceanbase]>
   ```

3. To exit the MySQL client, enter `exit` and press **Enter**, or press the keyboard shortcut **Ctrl** + **D**.

## More information

If errors occur when you connect to OceanSeek by using the MySQL client, we recommend that you refer to the official MySQL documentation for troubleshooting.
