### Step 2: Obtain the URL of OceanBase AI Database

1. Contact the deployment personnel or administrator of OceanBase AI Database to obtain the connection string.

    **Here is an example:**

    ```shell
    obclient -hxxx.xxx.xxx.xxx -P2881 -utest_user001@mysql001 -p****** -Dtest
    ```

    For more information about connection strings, see [Connect to OceanBase AI Database by using OBClient](../200.client/300.connect-to-an-oceanbase-tenant-by-using-obclient.md).

2. Fill in the URL below based on the OceanBase AI Database connection string.

    ```shell
    jdbc:mysql://$host:$port/$database_name?user=$user_name&password=$password&useSSL=false
    ```

    **Parameter description:**

    * `$host` specifies the IP address for connecting to OceanBase AI Database. For connection through OceanBase Database Proxy (ODP), this parameter is the IP address of an ODP. For direct connection, this parameter is the IP address of an OBServer node.
    * `$port` specifies the port for connecting to OceanBase AI Database. For connection through ODP, the default value is `2883`, which can be customized when ODP is deployed. For direct connection, the default value is `2881`, which can be customized when OceanBase AI Database is deployed.
    * `$database_name` specifies the name of the database to be accessed.

        <main id="notice" type='notice'>
          <h4>Notice</h4>
          <p>The user used to connect to the tenant must have the <code>CREATE</code>, <code>INSERT</code>, <code>DELETE</code>, <code>UPDATE</code>, and <code>SELECT</code> privileges on the database. For more information about user privileges, see <a href="../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md">Privilege types in MySQL-compatible mode</a>.</p>
        </main>

    * `$user_name` specifies the tenant account. For connection through ODP, the tenant account can be in the `username@tenant_name#cluster_name` or `cluster_name:tenant_name:username` format. For direct connection, the tenant account is in the `username@tenant_name` format.
    * `$password` specifies the password of the account.

    For more information about the connection properties of MySQL Connector/J, see [Configuration Properties](https://dev.mysql.com/doc/connector-j/en/connector-j-reference-configuration-properties.html).

    **Here is an example:**

    ```shell
    jdbc:mysql://xxx.xxx.xxx.xxx:2881/test?user=test_user001@mysql001&password=******&useSSL=false
    ```

    2. `xmlns:xsi`: the namespace for XML elements prefixed with `xsi`, which is set to `http://www.w3.org/2001/XMLSchema-instance`.
    3. `xsi:schemaLocation`: the mapping between the XML namespace and its corresponding XML schema definition (XSD) file. The value typically consists of paired strings separated by spaces. Each pair consists of a default XML namespace (`http://maven.apache.org/POM/4.0.0`) in the first part, and the URI of the corresponding XSD file (`http://maven.apache.org/xsd/maven-4.0.0.xsd`) in the second part.

    1. Define a private static method `createTable`, which accepts a Connection object as a parameter and declares that it may throw an `SQLException` exception.

4. Define a method for inserting data.

    Define a private static method named `insertData` to insert data into the `test_hikaricp` table in the database. The specific steps are as follows:

    1. Define a private static method named `insertData`. This method accepts a Connection object, an integer `id` parameter, and a string `name` parameter, and declares that it may throw an `SQLException`.
    2. Define an SQL statement string for inserting data into the table named `test_hikaricp`, including the `id` and `name` columns.
    3. Create a precompiled SQL statement object `pstmt` using the connection object `conn`, and use this object within a `try-with-resources` block.
    4. Set the value of the first parameter `?` in the SQL statement to `id`.
    5. Set the value of the second parameter `?` in the SQL statement to `name`.
    6. Execute the SQL statement to insert data into the table.
    7. Print a message to the console indicating that the data has been inserted successfully.

    **The sample code is as follows:**

    ```java
        private static void insertData(Connection conn, int id, String name) throws SQLException {
            String sql = "INSERT INTO test_hikaricp (id, name) VALUES (?, ?)";
            try (PreparedStatement pstmt = conn.prepareStatement(sql)) {
                pstmt.setInt(1, id);
                pstmt.setString(2, name);
                pstmt.executeUpdate();
                System.out.println("Data inserted successfully.");
            }
    ```

```java
                insertData(conn, 1, "A1");

                updateData(conn, "test_update", 1);
```
