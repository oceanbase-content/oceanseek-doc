# Connect to OceanBase AI Database by using Navicat

Navicat is a universal database client. It connects to a database through the Java Database Connectivity (JDBC) driver provided by this database. It supports normal relational databases, non-relational databases, and distributed databases.

You can connect to a user tenant of OceanBase AI Database by using the OceanBase or MySQL driver that comes with Navicat. This topic describes how to connect to a user tenant of OceanBase AI Database by using the OceanBase driver of Navicat.

## Prerequisites

* You have downloaded and installed Navicat. You can download the Navicat installation package for your operating system from the [Navicat Premium website](https://www.navicat.com/en/download/navicat-premium).

* The IP address of the OBServer node to be connected has access to the server where Navicat is installed.

* You have installed OceanBase AI Database and created a user tenant.

## Procedure

### Step 1: Obtain the database connection string

Contact the deployment personnel or administrator of OceanBase AI Database to obtain the connection string. The following is a connection string example:

```shell
obclient -h$host -P$port -u$user_name -p$password -D$database_name
```

**Parameter description:**

* `$host` specifies the IP address for connecting to OceanBase AI Database. It is the IP address of ODP for connection through ODP, or the IP address of an OBServer node for direct connection.
* `$port` specifies the port for connecting to OceanBase AI Database. For connection through ODP, the default value is `2883`, which can be customized when ODP is deployed. For direct connection, the default value is `2881`, which can be customized when OceanBase AI Database is deployed.
* `$database_name` specifies the name of the database to be accessed.

    <main id="notice" type='notice'>
        <h4>Notice</h4>
        <p>The user connecting to the tenant must have the <code>CREATE</code>, <code>INSERT</code>, <code>DROP</code>, and <code>SELECT</code> privileges on this database. For more information about user privileges, see <a href="../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md">Privilege types in MySQL-compatible mode</a>.</p>
    </main>

* `$user_name` specifies the tenant account. Two formats are supported in the case of connection through ODP: `username@tenant_name#cluster_name` and `cluster_name:tenant_name:username`. In the case of direct connection, the format is `username@tenant_name`.
* `$password` specifies the password of the account.

For more information about the connection string, see [Connect to OceanBase AI Database by using OBClient](../200.client/300.connect-to-an-oceanbase-tenant-by-using-obclient.md).

**Example:**

```shell
obclient -hxxx.xxx.xxx.xxx -P2881 -utest_user001@mysql001 -p****** -Dtest
```

### Step 2: Connect to OceanBase AI Database by using the Navicat console

<main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>The GUI of Navicat varies based on the product versions. This topic describes how to connect to OceanBase AI Database by using Navicat 16.3.7. For more information about the operations in other versions, see Navicat documentation of the corresponding versions. </p>
</main>

1. Click **Connect** <img src=https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.0/develop/sample-program/navicat/4.connect-to-oceanbase-database-through-Navicat-01.png width=8% /> > **OceanBase** > **OceanBase Enterprise Edition (MySQL-compatible mode)** to go to the **Create Connection** page.

   ![Select your database](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.0/develop/sample-program/navicat/4.connect-to-oceanbase-database-through-Navicat-02.png)

2. On the **Create Connection** page, enter the information for the database you want to connect to, and then click **Test Connection**.

   ![Test](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.0/develop/sample-program/navicat/4.connect-to-oceanbase-database-through-Navicat-03.png)

   <main id="notice" type='notice'>
       <h4>Notice</h4>
       <p>You can connect to OceanBase AI Database by using an IP address or ODP. When you use an IP address, enter the port number specified by the <code>mysql_port</code> parameter. The default port number is <code>2881</code>. When you use ODP, enter the port number specified by the <code>proxy_port</code> parameter. The default port number is <code>2883</code>.</p>
   </main>

3. If **Connected** is displayed in the **Test Connection** pop-up window, the database can be connected. Then, click **Save**.

4. Double-click the database name on the **Database Navigator** tab. If the database instances appear under the database, you have connected to OceanBase AI Database.

   ![Connection result](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.0/develop/sample-program/navicat/4.connect-to-oceanbase-database-through-Navicat-05.png)
