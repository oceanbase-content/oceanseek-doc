# Overview of security permissions

Security is one of the top priorities for a database. A database management system is required to prevent unauthorized use of the database and protect the files and data of the database. This topic describes the security system of OceanSeek.

As the final data carrier, OceanSeek prioritizes data security. OceanSeek provides a full range of enterprise-level security features to ensure data security. The security features include authentication, access control, data encryption, monitoring and alerting.

* Authentication

  OceanSeek supports identity authentication and user and role management to improve database security. For more information, see [Identity authentication](200.identification-and-authentication/100.identification-and-authentication-of-mysql-mode/100.identification-of-mysql-mode.md).
  
* Access control

  OceanSeek manages user access to data by defining system and object permissions and roles. It also supports row-level access control (RLS), which allows you to restrict readable and writable data on a row basis without modifying the business SQL. For more information, see [Overview of access control](300.access-control/100.access-control-overview.md) and [Row-level security](300.access-control/250.row-level-security/100.row-level-access-control.md).
  
* Data encryption

  OceanSeek supports encrypting data for transmission and storage. OceanSeek supports end-to-end data encryption at the transport layer. For more information, see [Overview of data transmission encryption](500.data-transfer-encryption/100.data-transfer-encryption-overview.md).

  OceanSeek supports AES encryption and decryption of data by manually invoking functions. For more information, see the encryption tool functions [ENHANCED_AES_ENCRYPT](../../700.reference/500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/400.functions-of-mysql-mode/500.encryption-and-compression-functions-of-mysql-mode/820.enhanced-aes-encrypt-of-mysql-mode.md) and [ENHANCED_AES_DECRYPT](../../700.reference/500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/400.functions-of-mysql-mode/500.encryption-and-compression-functions-of-mysql-mode/830.enhanced-aes-decrypt-of-mysql-mode.md).
