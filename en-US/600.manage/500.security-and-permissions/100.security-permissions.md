# Overview of security permissions

Security is one of the top priorities for a database. A database management system is required to prevent unauthorized use of the database and protect the files and data of the database. This topic describes the security system of OceanBase AI Database.

As the final data carrier, OceanBase AI Database prioritizes data security. OceanBase AI Database provides a full range of enterprise-level security features to ensure data security. The security features include authentication, access control, data encryption, monitoring and alerting, and security audit.

![Security](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.2.1/manage/security.jpg)

* Authentication

  OceanBase AI Database supports identity authentication and user and role management to improve database security. For more information, see [Identity authentication](200.identification-and-authentication/100.identification-and-authentication-of-mysql-mode/100.identification-of-mysql-mode.md).
  
* Access control

  OceanBase AI Database manages user access to data by defining system and object permissions and roles. It also supports row-level access control (RLS), which allows you to restrict readable and writable data on a row basis without modifying the business SQL. For more information, see [Overview of access control](300.access-control/100.access-control-overview.md) and [Row-level security](300.access-control/250.row-level-security/100.row-level-access-control.md).
  
* Data encryption

  OceanBase AI Database supports encrypting data for transmission and storage. OceanBase AI Database supports end-to-end data encryption at the transport layer. In addition, OceanBase AI Database supports transparent encryption of stored data to maximize data security even when the storage medium is lost. Column encryption is also supported, allowing users with the relevant permissions to create column-level sensitive data protection rules on tables. For more information, see [Overview of data transmission encryption](500.data-encryption/200.data-transfer-encryption/100.data-transfer-encryption-overview.md), [Overview of database transparent encryption](500.data-encryption/400.data-storage-encryption/100.datastore-encryption-overview.md), and [Column encryption overview](500.data-encryption/500.column-encryption/100.column-encryption-overview.md).

  OceanBase AI Database supports AES encryption and decryption of data by manually invoking functions. For more information, see the encryption tool functions [ENHANCED_AES_ENCRYPT](../../700.reference/500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/400.functions-of-mysql-mode/500.encryption-and-compression-functions-of-mysql-mode/820.enhanced-aes-encrypt-of-mysql-mode.md) and [ENHANCED_AES_DECRYPT](../../700.reference/500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/400.functions-of-mysql-mode/500.encryption-and-compression-functions-of-mysql-mode/830.enhanced-aes-decrypt-of-mysql-mode.md).
  
* Security audit

  OceanBase AI Database audits user behavior and records user operations. OceanBase AI Database also supports the audit of database objects. Audit information is generated when you access data to ensure that data access behavior is correctly recorded. For more information, see [Security audit overview](600.security-audit/100.security-audit-overview.md).
