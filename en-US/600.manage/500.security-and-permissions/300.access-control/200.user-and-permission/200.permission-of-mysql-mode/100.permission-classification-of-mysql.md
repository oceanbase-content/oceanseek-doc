# Permission classification

This topic describes the permission classification in OceanBase AI Database.

## Classification

Permissions are classified into the following three levels:

* Global permissions: Permissions that affect the entire tenant, such as modifying system settings and accessing all tables.
* Database permissions: Permissions that affect all objects in a specific database, such as creating and dropping tables in the database and accessing tables.
* Object permissions: Permissions that affect a specific object, such as accessing a specific table, view, or index.
