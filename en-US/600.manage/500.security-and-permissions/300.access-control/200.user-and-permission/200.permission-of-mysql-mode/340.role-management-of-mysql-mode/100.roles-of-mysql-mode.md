# Role management overview

OceanBase AI Database supports user role management.

A role is a set of privileges. You can use roles to manage user privileges.

In OceanBase AI Database, roles have the following features:

* Roles, like regular users, can be granted privileges.

* Roles can be granted to other roles; that is, a role can contain other roles.

* A user can be granted multiple roles, and a role can also be granted to multiple users.
 
Currently, OceanBase AI Database does not support default system roles.
