# Add privileges to a role

This topic describes how to grant privileges to a role after the role is created, so that users granted the role can use the privileges of the role.

## Prerequisites

You have the privileges to be granted and the `GRANT OPTION` privilege. For more information about how to view your privileges, see [View user privileges](../400.view-user-permissions-of-mysql-mode.md). If you do not have the required privilege, contact the administrator to obtain the privilege. For more information about how to grant privileges to a user, see [Grant privileges directly](../200.authority-of-mysql-mode.md).

## Examples

* Grant the `ALTER SYSTEM` privilege to the role `role1`.

  ```shell
  obclient [oceanbase]> GRANT ALTER SYSTEM ON *.* TO role1;
  ```

* Grant the `SELECT` privilege on all objects in the database `dbtest` to the role `role1`.

  ```shell
  obclient [oceanbase]> GRANT SELECT ON dbtest.* TO role1;
  ```

  You can add one or more privileges to multiple roles at the same time.

  ```shell
  obclient [oceanbase]> GRANT SELECT,UPDATE ON dbtest.* TO role1,role2;
  ```

* Grant the `SELECT` privilege on the table `test1.tbl1` to the role `role1`.

  ```shell
  obclient [oceanbase]> GRANT SELECT ON test1.tbl1 TO role1;
  ```

* Grant the `SELECT` privilege on column `c1` of the table `test1.tbl1` to the role `role1`.

  ```shell
  obclient [oceanbase]> GRANT SELECT(c1) ON test1.tbl1 TO role1;
  ```
