# Manually clear a backup or archive path

After you replace a backup or archive path, you can clear the replaced backup or archive path that is no longer in use. Clearing a data backup or archive path means clearing all backup sets or log archive pieces in that path.

## Limitations

* Only a replaced backup or archive path can be cleared. You cannot clear the backup or archive path currently in use.

* An old path that is being cleared cannot be reset as a backup or archive path.

## Clear a backup path

### Clear the backup path of a specified user tenant from the sys tenant

1. Log in to the `sys` tenant of the cluster as the `root` user.

   Here is an example of how to connect to the database. Use the actual environment settings when you connect to the database.

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@sys#obdemo -p***** -A
   ```

2. Query tenant information to obtain the tenant's `TENANT_ID`.

   This topic uses the `mysql001` tenant as an example. A sample query is as follows:

   ```shell
   obclient(root@sys)[(none)]> SELECT TENANT_ID, TENANT_NAME, TENANT_TYPE FROM oceanbase.DBA_OB_TENANTS WHERE TENANT_NAME = 'mysql001';
   ```

   The query result is as follows:

   ```shell
   +-----------+-------------+-------------+
   | TENANT_ID | TENANT_NAME | TENANT_TYPE |
   +-----------+-------------+-------------+
   |      1002 | mysql001    | USER        |
   +-----------+-------------+-------------+
   1 row in set
   ```

   According to the query result, the `TENANT_ID` of this tenant is 1002.

3. Obtain the backup path to be cleared.

   1. Query all backup paths in the specified tenant.

      ```shell
      obclient(root@sys)[(none)]> SELECT TENANT_ID, PATH, DEST_TYPE, STATUS FROM oceanbase.CDB_OB_BACKUP_STORAGE_INFO WHERE TENANT_ID = 1002 AND DEST_TYPE = 'backup_data';
      ```

      The query result is as follows:

      ```shell
      +-----------+-------------------------------+-------------+--------+
      | TENANT_ID | PATH                          | DEST_TYPE   | STATUS |
      +-----------+-------------------------------+-------------+--------+
      |      1002 | s3://oceanbase-test-bucket/backup/data2?host=obs.****.myhuaweicloud.com | backup_data | NORMAL |
      |      1002 | s3://oceanbase-test-bucket/backup/data1?host=obs.****.myhuaweicloud.com | backup_data | NORMAL |
      +-----------+-------------------------------+-------------+--------+
      2 rows in set
      ```

      According to the query result, there are two backup paths in this tenant.

   2. Query the backup path currently in use by the specified tenant.

      ```shell
      obclient(root@sys)[(none)]> SELECT * FROM oceanbase.CDB_OB_BACKUP_PARAMETER WHERE TENANT_ID = 1002;
      ```

      The query result is as follows:

      ```shell
      +-----------+------------------+-------------------------------+
      | TENANT_ID | NAME             | VALUE                         |
      +-----------+------------------+-------------------------------+
      |      1002 | data_backup_dest | s3://oceanbase-test-bucket/backup/data2?host=obs.****.myhuaweicloud.com |
      +-----------+------------------+-------------------------------+
      1 row in set
      ```

      According to the query result, the currently in-use backup path is `s3://oceanbase-test-bucket/backup/data2?host=obs.****.myhuaweicloud.com`. Therefore, the backup path `s3://oceanbase-test-bucket/backup/data1?host=obs.****.myhuaweicloud.com` to be cleared is not currently in use and can be cleared.

4. Execute the following statement to clear the specified backup path:

   ```sql
   ALTER SYSTEM DELETE BACKUP ALL DATA_BACKUP_DEST [=] 'data_backup_path' TENANT [=] tenant_name;
   ```

   The parameters in the statement are described as follows:

   * `data_backup_path`: the data backup path to be cleared.

   * `tenant_name`: the user tenant for which the backup path is to be cleared.

   Here is an example:

   The system tenant clears the S3 backup path `s3://oceanbase-test-bucket/backup/data1?host=obs.****.myhuaweicloud.com` of the `mysql001` tenant.

   ```shell
   obclient(root@sys)[(none)]> ALTER SYSTEM DELETE BACKUP ALL DATA_BACKUP_DEST ='s3://oceanbase-test-bucket/backup/data1?host=obs.****.myhuaweicloud.com' TENANT = mysql001;
   ```

5. After the statement is successfully executed, you can query the view to view the path being cleared.

   ```shell
   obclient(root@sys)[(none)]> SELECT TENANT_ID, PATH, DEST_TYPE, STATUS FROM oceanbase.CDB_OB_BACKUP_STORAGE_INFO WHERE TENANT_ID = 1002 AND PATH = 's3://oceanbase-test-bucket/backup/data1?host=obs.****.myhuaweicloud.com';
   ```

   A sample query result is as follows:

   ```shell
   +-----------+-------------------------------+-------------+----------+
   | TENANT_ID | PATH                          | DEST_TYPE   | STATUS   |
   +-----------+-------------------------------+-------------+----------+
   |      1002 | s3://oceanbase-test-bucket/backup/data1?host=obs.****.myhuaweicloud.com | backup_data | DELETING |
   +-----------+-------------------------------+-------------+----------+
   1 row in set
   ```

   According to the query result, during the path clearing process, you can see the value of the `STATUS` field for the corresponding path change to `DELETING`. Once the clearing is complete, the corresponding row will be deleted.

### Clear the backup path in a user tenant

1. Log in to the database as a tenant administrator.

   <h4>Note</h4>
   <p>The administrator user of a user tenant is the <code>root</code> user.</p>
   </main>

   Here is an example of how to connect to the database. Use the actual environment settings when you connect to the database.

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@mysql001#obdemo -p***** -A
   ```

2. Obtain the backup path to be cleared.

   1. View all backup paths in the current tenant.

      A sample query is as follows:

      ```shell
      obclient(root@mysql001)[(none)]> SELECT PATH, DEST_TYPE, STATUS FROM oceanbase.DBA_OB_BACKUP_STORAGE_INFO WHERE DEST_TYPE = 'backup_data';
      ```

      A sample query result is as follows:

      ```shell

      +-------------------------------+-------------+--------+
      2 rows in set
      ```

      According to the query result, there are two backup paths in this tenant.

   2. View the backup path currently used by the tenant.

      A sample query is as follows:

      ```shell
      obclient(root@mysql001)[(none)]> SELECT * FROM oceanbase.DBA_OB_BACKUP_PARAMETER;
      ```

      A sample query result is as follows:

      ```shell
      +------------------+-------------------------------+
      | NAME             | VALUE                         |
      +------------------+-------------------------------+
      | data_backup_dest | s3://oceanbase-test-bucket/backup/data2?host=obs.****.myhuaweicloud.com |
      ```

   Here, `data_backup_path` specifies the data backup path to be cleared.

   ```shell

   ```

   A sample query result is as follows:

   ```shell
   +-------------------------------+-------------+----------+
   | PATH                          | DEST_TYPE   | STATUS   |
   +-------------------------------+-------------+----------+
   | s3://oceanbase-test-bucket/backup/data1?host=obs.****.myhuaweicloud.com | backup_data | DELETING |
   +-------------------------------+-------------+----------+
   ```

