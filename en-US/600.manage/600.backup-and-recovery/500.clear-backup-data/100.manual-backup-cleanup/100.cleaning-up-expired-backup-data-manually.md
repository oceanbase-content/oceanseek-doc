# Manually trigger expired backup cleanup

After a cleanup policy is set, if you want to perform an expired backup cleanup as soon as possible, you can immediately trigger an expired cleanup task manually. After the cleanup is manually triggered, the system performs the cleanup based on the cleanup policy configured for the tenant.

## Prerequisites

Make sure that an automatic cleanup policy is set for the current tenant. For more information about how to set and verify an automatic cleanup policy, see [Automatically clean up expired backups](../50.automatic-backup-cleanup/100.cleaning-up-backed-up-data-automatically.md).

## Trigger expired backup cleanup for a specified user tenant from the sys tenant

1. Log in to the `sys` tenant of the cluster as the `root` user.

   Here is an example of how to connect to the database. Use the actual environment settings when you connect to the database.

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@sys#obdemo -p***** -A
   ```

2. Execute the following statement to manually trigger an expired backup cleanup:

   ```sql
   ALTER SYSTEM DELETE OBSOLETE BACKUP [TENANT [=] tenant_name]; 
   ```

   Here, `TENANT [=] tenant_name` specifies the user tenant for which you want to trigger the cleanup. If you do not specify a tenant, the cleanup is triggered for all user tenants by default.

   Here are some examples:

   * Trigger an expired backup cleanup for the `mysql001` tenant from the sys tenant.

     ```shell
     obclient(root@sys)[(none)]> ALTER SYSTEM DELETE OBSOLETE BACKUP TENANT mysql001;
     ```

   * Trigger an expired backup cleanup for all user tenants from the sys tenant.

     ```shell
     obclient(root@sys)[(none)]> ALTER SYSTEM DELETE OBSOLETE BACKUP;
     ```

## Trigger expired backup cleanup for the current tenant from a user tenant

1. Log in to the database as a tenant administrator.

   <main id="notice" type='explain'>
   <h4>Note</h4>
   <p>The administrator user of a user tenant is the <code>root</code> user.</p>
   </main>

   Here is an example of how to connect to the database. Use the actual environment settings when you connect to the database.

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@mysql001#obdemo -p***** -A
   ```

2. Execute the following statement to manually trigger an expired backup cleanup for the current tenant.

   ```shell
   obclient> ALTER SYSTEM DELETE OBSOLETE BACKUP;
   ```
