# View backup cleanup results

After a cleanup policy is successfully configured and automatic cleanup is triggered, when a cleanup task is completed, you can query the history views to view the execution result of the cleanup task.

## View cleanup task history in the sys tenant

1. Log in to the `sys` tenant of the cluster as the `root` user.

   Here is an example of how to connect to the database. Use the actual environment settings when you connect to the database.

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@sys#obdemo -p***** -A
   ```

2. View the cleanup task history.

## View cleanup task history in a user tenant

1. Log in to the database as a tenant administrator.

   <main id="notice" type='explain'>
   <h4>Note</h4>
   <p>The administrator user of a user tenant is the <code>root</code> user.</p>
   </main>

   Here is an example of how to connect to the database. Use the actual environment settings when you connect to the database.

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@mysql001#obdemo -p***** -A
   ```

2. View the cleanup task history.

   * View the job history.

     The job history records information related to the initiation of cleanup tasks.

     A sample query is as follows:

     ```shell
     obclient(root@mysql001)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_BACKUP_DELETE_JOB_HISTORY\G
     ```

     Except for the absence of the `TENANT_ID` column, all columns in the `DBA_OB_BACKUP_DELETE_JOB_HISTORY` view correspond to those in the `CDB_OB_BACKUP_DELETE_JOB_HISTORY` view. For more information about the query result, see **View cleanup task history in the sys tenant**.

   * View the task history.

     The task history records the details of the cleaned-up `backup_set/backup_piece`.

     A sample query is as follows:

     ```shell
     obclient(root@mysql001)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_BACKUP_DELETE_TASK_HISTORY\G
     ```

     Except for the absence of the `TENANT_ID` column, all columns in the `DBA_OB_BACKUP_DELETE_TASK_HISTORY` view correspond to those in the `CDB_OB_BACKUP_DELETE_TASK_HISTORY` view. For more information about the query result, see **View cleanup task history in the sys tenant**.
