# View the result of physical restore

After a restore is complete, you can view the restore result in views.

## Procedure

1. Log in to the `sys` tenant of the cluster as the `root` user.

2. After the restore is complete, execute the following statement to view the restore task result of the cluster.

   ```sql
   obclient [(none)]> SELECT * FROM oceanbase.CDB_OB_RESTORE_HISTORY\G
   ```

   If the restore failed, you can cancel the restore by deleting the tenant. For more information, see [Cancel physical restore](../600.restore-data/300.cancel-a-restore.md).

## What to do next

After the physical restore is completed, the restored tenant is a standby tenant. You can perform the following operations:

* Execute the `recover` command to continue replaying logs from the source tenant as a standby tenant. For more information, see [Segment-based log replay for a standby tenant](510.recover-the-standby-tenant.md).

* Execute the standby-to-primary switchover command to convert the standby tenant into the primary tenant. For more information, see [Convert a standby tenant into a primary tenant](600.active-standby-tenant.md).
