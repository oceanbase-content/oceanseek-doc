# Introduction to views related to physical restore

OceanBase AI Database allows you to query views for the restore progress and results.

## CDB_OB_RESTORE_PROGRESS

[CDB_OB_RESTORE_PROGRESS](../../../700.reference/700.system-views/300.system-view-of-sys-tenant/200.dictionary-view-of-sys-tenant/10400.o-cdb_ob_restore_progress-of-sys-tenant.md) displays the restore progress of tenants.

## DBA_OB_RESTORE_PROGRESS

`DBA_OB_RESTORE_PROGRESS` displays ongoing restore tasks.

* For the system tenant, see [DBA_OB_RESTORE_PROGRESS](../../../700.reference/700.system-views/300.system-view-of-sys-tenant/200.dictionary-view-of-sys-tenant/21200.o-dba_ob_restore_progress-of-sys-tenant.md).

* For user tenants, see [DBA_OB_RESTORE_PROGRESS](../../../700.reference/700.system-views/400.system-view-of-mysql-mode/200.dictionary-view-of-mysql-mode/10900.o-dba_ob_restore_progress-of-mysql-mode.md).

## CDB_OB_RESTORE_HISTORY

[CDB_OB_RESTORE_HISTORY](../../../700.reference/700.system-views/300.system-view-of-sys-tenant/200.dictionary-view-of-sys-tenant/10300.o-cdb_ob_restore_history-of-sys-tenant.md) displays the restore results of tenants.

## DBA_OB_RESTORE_HISTORY

`DBA_OB_RESTORE_HISTORY` displays the restore tasks that have been completed.

* For the system tenant, see [DBA_OB_RESTORE_HISTORY](../../../700.reference/700.system-views/300.system-view-of-sys-tenant/200.dictionary-view-of-sys-tenant/21100.o-dba_ob_restore_history-of-sys-tenant.md).

* For user tenants, see [DBA_OB_RESTORE_HISTORY](../../../700.reference/700.system-views/400.system-view-of-mysql-mode/200.dictionary-view-of-mysql-mode/10800.o-dba_ob_restore_history-of-mysql-mode.md).

## DBA_OB_TENANTS

`DBA_OB_TENANTS` displays the basic information of tenants. The `RESTORE_DATA_MODE` column contains physical restore information.

* For the system tenant, see [DBA_OB_TENANTS](../../../700.reference/700.system-views/300.system-view-of-sys-tenant/200.dictionary-view-of-sys-tenant/23100.o-dba_ob_tenants-of-sys-tenant.md).

* For user tenants, see [DBA_OB_TENANTS](../../../700.reference/700.system-views/400.system-view-of-mysql-mode/200.dictionary-view-of-mysql-mode/12300.o-dba_ob_tenants-of-mysql-mode.md).
