# Convert a standby tenant into a primary tenant

After a restore succeeds, all restored tenants are standby tenants. You can execute the `ACTIVATE STANDBY` statement to convert a standby tenant into a primary tenant.

## Background information

A tenant restored by using physical restore serves as a standby tenant. Subsequently, the tenant can provide services as a standby tenant or be converted into the primary tenant to provide services.

## Prerequisites

Make sure that the restore has succeeded. For more information about how to view the restore result, see [View the result of physical restore](../600.restore-data/500.view-the-restore-history.md).

## Convert a standby tenant into a primary tenant in the sys tenant

The `sys` tenant can convert a standby tenant in the system into a primary tenant.

1. Log in to the `sys` tenant of the cluster as the `root` user.

2. Execute the following statement to perform the standby-to-primary switchover:

   ```shell
   obclient [(none)]> ALTER SYSTEM ACTIVATE STANDBY TENANT tenant_name;
   ```

   <main id="notice" type='explain'>
   <h4>Note</h4>
   <p>This statement allows you to switch only one tenant at a time. If you need to switch multiple tenants, execute this statement repeatedly.</p>
   </main>

   Here is an example:

   ```shell
   obclient [(none)]> ALTER SYSTEM ACTIVATE STANDBY TENANT mysql;
   ```

   For more information about the parameters in the statement, see [Introduction to physical restore parameters](../600.restore-data/800.parameters-of-the-restore.md).

## Convert a standby tenant into a primary tenant in a user tenant

A user tenant can convert itself from a standby tenant into a primary tenant.

1. Log in to the database as the tenant administrator of a user tenant.

   <main id="notice" type='explain'>
   <h4>Note</h4>
   <p>The administrator user of a user tenant is the <code>root</code> user.</p>
   </main>

2. Execute the following statement to perform the standby-to-primary switchover:

   ```shell
   obclient [(none)]> ALTER SYSTEM ACTIVATE STANDBY;
   ```
