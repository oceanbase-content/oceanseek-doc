# Cancel physical restore

During the process of restoring tenant data, you can execute the `ALTER SYSTEM CANCEL RESTORE` statement to stop the restore. This statement deletes the tenant that is in the restoring state.

## Procedure

1. Log in as the `root` user to the `sys` tenant of the cluster to which the tenant to be restored belongs.

2. Execute the following statement to immediately cancel the restore and delete the tenant to be restored.

   ```sql
   ALTER SYSTEM CANCEL RESTORE tenant_name;
   ```

   Here, `tenant_name` is the name of the tenant to be restored.
