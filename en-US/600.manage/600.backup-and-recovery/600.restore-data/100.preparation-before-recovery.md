# Preparations before restore

Before you perform a restore operation, you must create the resources required for the tenant to be restored.

## Precautions

Before you perform a restore operation, make sure that the version of the backup data to be restored is confirmed. Generally, the supported backup data versions for restore are consistent with the upgrade path of the OceanBase cluster (the sequence of versions that can be directly upgraded).

## Preparations for restore

1. Log in to the `sys` tenant of the cluster as the `root` user.

2. Create a unit.

   Here is an example:

   ```shell
   obclient [(none)]> CREATE RESOURCE UNIT box_16c96g MAX_CPU 16, MEMORY_SIZE = '5G', MAX_IOPS 10240, MIN_IOPS=10240;
   ```

   For more information about how to create a resource unit, see [Create a tenant](../../200.tenant-management/600.common-tenant-operations/200.manage-create-tenant.md).

3. Create a resource pool.

   When you create a resource pool for the tenant to be restored, we recommend that the resource pool be consistent with that of the source tenant. That is, the number of `unit_num` in the resource pool of the tenant to be restored should be the same as that of the source tenant.

   Here is an example:

   ```shell
   obclient [(none)]> CREATE RESOURCE POOL restore_pool unit = 'box_16c96g', unit_num = 1, zone_list = ('z1','z2','z3');
   ```

   For more information about how to create a resource pool, see [Create a tenant](../../200.tenant-management/600.common-tenant-operations/200.manage-create-tenant.md).
