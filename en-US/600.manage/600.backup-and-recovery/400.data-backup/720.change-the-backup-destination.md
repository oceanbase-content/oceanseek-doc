# Change the backup destination

After you enable data backup, you can change the backup destination based on your business needs.

## Precautions

Automatic cleanup only supports cleaning up the backup and archive data in the paths currently specified by `DATA_BACKUP_DEST` and `LOG_ARCHIVE_DEST`. After you change the backup destination, the data in the original backup path can only be cleaned up manually. For more information about manually cleaning up backup data, see [Manually clean up specified backup or archive data](../500.clear-backup-data/100.manual-backup-cleanup/200.cleaning-up-specified-backup-data.md) and [Manually clear a backup or archive path](../500.clear-backup-data/100.manual-backup-cleanup/300.clear-the-backup_dest_or_archivelog_dest.md).

## Procedure

1. Log in to the `sys` tenant or a user tenant as a tenant administrator.

2. Check whether ongoing backup tasks exist. For more information, see [View the data backup progress](500.view-data-backup-progress.md).

   If the query result is not empty, ongoing data backup tasks exist. In this case, you must stop the ongoing backup tasks. For more information, see [Stop a backup](400.stop-data-backup.md).

3. Reconfigure the backup destination.

   When you reconfigure the backup destination, if the directory to be replaced is a backup directory that the tenant has used before, the `format` file in the directory must exist. Otherwise, the directory to be replaced must be empty.
   
   For more information about how to configure a backup destination, see [Prepare for backup](100.preparation-before-data-backup.md).
   
4. After the reconfiguration is completed, query the `CDB_OB_BACKUP_PARAMETER` view in the `sys` tenant or the `DBA_OB_BACKUP_PARAMETER` view in a user tenant to verify whether the new backup destination is successfully configured. For more information, see [View data backup parameters](700.parameters-of-data-backup.md).

## What to do next

After the backup destination is changed, you must re-initiate a full data backup. For more information about how to initiate a full data backup, see [Initiate a full data backup](200.initiate-full-data-backup.md).
