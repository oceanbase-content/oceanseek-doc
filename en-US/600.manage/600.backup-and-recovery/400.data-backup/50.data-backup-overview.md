# Data backup overview

This topic describes the architecture and storage mechanism of data backup.

## Data backup architecture

Data backup preferentially uses a follower replica for backup. The data backup architecture is shown in the following figure.

![Data backup architecture](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oceanbase-database-ai/manage/backup-and-recovery/log-archive/log-archivelog-architeture.jpg)

## Storage mechanism of data backup files

In data backup scenarios, the backup data of OceanBase AI Database is homogeneous with the data on shared storage. The backup directory structure is consistent with that of the OBServer data directory. Essentially, it is a mirror image of specific version data on shared storage. Data backup is scheduled and copied at macroblock granularity, and macroblocks are independent of each other.
