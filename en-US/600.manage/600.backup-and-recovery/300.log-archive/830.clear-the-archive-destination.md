# Clear the archive path configuration

After log archiving stops, you can clear the archive path configuration as needed. Clearing the archive path configuration does not delete any files in the original archive path. If you want to use the original path again, you can configure the archive path as the original path by using the `SET LOG_ARCHIVE_DEST` command.

## Considerations

Before you clear the archive path configuration, make sure that the archiving status of the tenant is `STOP`. For more information about how to query the archiving status, see [View archiving progress](600.view-log-archive-progress.md).

## Procedure

1. Log in to the database as an administrator of the `sys` tenant or a user tenant.

   <main id="notice" type='explain'>
   <h4>Note</h4>
   <p>The administrator user of a user tenant is the <code>root</code> user.</p>
   </main>

2. Clear the archive path configuration. Here are some examples:

   * Clear the archive path configuration for a specified tenant in the `sys` tenant

     ```shell
     obclient> ALTER SYSTEM SET LOG_ARCHIVE_DEST='' TENANT = tenant_name;
     ```

   * Clear the archive path configuration for the current tenant in a user tenant
  
     ```shell
     obclient> ALTER SYSTEM SET LOG_ARCHIVE_DEST='';
     ```
