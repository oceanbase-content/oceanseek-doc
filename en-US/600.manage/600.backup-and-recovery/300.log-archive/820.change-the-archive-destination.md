# Change the archive destination

After enabling log archiving, you can change the archive destination based on your business needs.

## Limitations and considerations

* If you use AWS S3 or another object storage service compatible with the S3 protocol as the archive medium, the lag of log archiving, which is specified by the `archive_lag_target` parameter, must be greater than or equal to 60 seconds.

* Automatic cleanup only supports cleaning up the backup and archive data in the paths currently specified by `DATA_BACKUP_DEST` and `LOG_ARCHIVE_DEST`. After you change the archive destination, the data in the original archive path can only be cleaned up manually. For more information about manually cleaning up backup data, see [Manually clean up specified backup or archive data](../500.clear-backup-data/100.manual-backup-cleanup/200.cleaning-up-specified-backup-data.md) and [Manually clear a backup or archive path](../500.clear-backup-data/100.manual-backup-cleanup/300.clear-the-backup_dest_or_archivelog_dest.md).

## Procedure

1. Log in to the `sys` tenant or a user tenant as the administrator.

2. Disable log archiving. For more information, see [Disable archiving mode](400.close-the-log-archive-mode.md).

3. Reconfigure the log archive destination.

   When you reconfigure the archive destination, if the destination directory is an archive directory that has been used by the tenant before, the `format` file in the directory must exist. Otherwise, the destination directory must be empty.

   For more information about how to configure the archive destination, see the **Configure the archiving destination** section in [Prepare for log archiving](200.preparation-before-log-archive.md).

4. Query the `CDB_OB_ARCHIVE_DEST` view in the `sys` tenant or the `DBA_OB_ARCHIVE_DEST` view in a user tenant to verify whether the new archive destination is successfully configured. For more information, see [View archive parameters](800.view-parameters-of-log-archive.md).

## What to do next

After you change the archive destination, you must enable log archiving again. For more information, see [Enable archiving mode](300.open-the-log-archive-mode.md).
