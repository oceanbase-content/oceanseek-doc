# Log compression and decompression

OceanSeek supports system log compression, with a compression ratio of 15 to 20 times.

Compression reduces the size of log files, saves disk space, and facilitates transmission and storage. Decompression restores compressed log files to their original readable format, facilitating log viewing and analysis.

## Log compression

To control system log compression, perform the following steps:

1. Enable system log compression.

   After system log compression is enabled, the `observer.log`, `rootservice.log`, `election.log`, and `trace.log` files suffixed with a timestamp are compressed, and those suffixed with `.wf` are not compressed.
   You can specify a compression algorithm by using the `syslog_compress_func` configuration item to enable system log compression. Supported algorithms are `zstd_1.0` and `zstd_1.3.8`. For example, you can set the system log compression algorithm to `zstd_1.3.8`. For more information about `syslog_compress_func`, see [syslog_compress_func](../../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/300.cluster-level-configuration-items/22040.syslog_compress_func.md).

    ```shell
    obclient> ALTER SYSTEM SET syslog_compress_func = 'zstd_1.3.8';
    ```

2. Set the disk space available for system logs.

    When the total size of system logs is about to reach the specified upper limit, log files are deleted from the oldest ones, including those that are compressed.
    You can specify the `syslog_disk_size` configuration item to set the maximum disk space available for system logs. For example, you can set it to 100 GB. For more information about `syslog_disk_size`, see [syslog_disk_size](../../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/300.cluster-level-configuration-items/22050.syslog_disk_size.md).

    <main id="notice" type='explain'>
      <h4>Note</h4>
      <p>The actual disk space is subject to the hardware specifications and actual requirements. If you want system logs to occupy the entire disk, you can set the value to 0 GB.</p>
    </main>

    ```shell
    obclient> ALTER SYSTEM SET syslog_disk_size='100GB';
    ```

3. Set the number of uncompressed log files.
   You can control the minimum number of uncompressed files of each log type to facilitate problem analysis based on logs. In practice, the number of uncompressed files can exceed the specified value but will not be smaller than this value.
   You can specify the `syslog_file_uncompressed_count` configuration item to set the number of uncompressed system log files. For example, you can set it to 50. For more information about `syslog_file_uncompressed_count`, see [syslog_file_uncompressed_count](../../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/300.cluster-level-configuration-items/22060.syslog_file_uncompressed_count.md).

    <main id="notice" type='explain'>
      <h4>Note</h4>
      <p>Set the value based on actual requirements. For example, if you set the value to 50, a total of 200 system log files are not compressed for the four log types, and the total size is about 50 GB (256 MB × 200).</p>
    </main>

    ```shell
    obclient> ALTER SYSTEM SET syslog_file_uncompressed_count=50;
    ```

## Log decompression

You can view compressed log files by using either of the following tools:

* Use the zstd tool.
  
  1. Install the zstd tool.

     Download the zstd tool from the [official zstd website](https://github.com/facebook/zstd).

  2. Use the zstd tool to decompress files.

     * Decompress a file and then view its content.

       1. Run the `zstd -d xxx.zst` command to decompress the file. In the command, `xxx.zst` indicates the name of the file to be decompressed.

       2. Run the `vim xxx` command to view the file content. In the command, `xxx` indicates the name of the decompressed file.

     * Directly view the content of the compressed file.

        Run the `zstd -dc xxx.zst` command to directly view the content of the compressed file. In the command, `xxx.zst` indicates the name of the compressed file.

* Use the obdiag tool.

  1. Install the obdiag tool.

     For information about how to install obdiag, see [Install obdiag](https://docs.oceanbase.com/obdiag/obdiag-installation).

  2. Use the obdiag tool to decompress files.

     Run the `obdiag gather log [options]` command to search for compressed log files. For more information about obdiag, see [obdiag gather log](https://docs.oceanbase.com/obdiag/oceanbase-cluster-log-collection).
