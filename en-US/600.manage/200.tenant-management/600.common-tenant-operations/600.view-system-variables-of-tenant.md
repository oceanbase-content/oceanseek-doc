# View tenant system variables

You can set system variables to make OceanBase AI Database behave according to your business requirements. This topic describes how to view tenant system variables.

## View tenant system variables by using the SHOW statement

1. Log in to the user tenant of the cluster as the `root` user.

   Take the `mq_t1` tenant as an example:

    ```shell
    obclient -h172.30.xx.xx -P2883 -uroot@mq_t1#cluster -p**** -A
    ```

2. Query system variable information by using the `SHOW` statement.

   The syntax is as follows:

   ```sql
   SHOW [SESSION | GLOBAL] VARIABLES [LIKE 'pattern' | WHERE expr]
   ```

   where:

   * `SESSION | GLOBAL`: `SESSION` indicates session variables, and `GLOBAL` indicates global variables. If you do not specify this parameter, session variables are queried by default.
   * `pattern`: the keyword of the variable.

   Here are some examples:

   * Query the session-level variable `ob_query_timeout`.

      ```shell
      obclient [oceanbase]> SHOW VARIABLES LIKE 'ob_query_timeout';
      ```
      
      Alternatively,
      
      ```shell
      obclient [oceanbase]> SHOW SESSION VARIABLES LIKE 'ob_query_timeout';
      ```

      The query result is as follows:

      ```shell
      +------------------+-------------+
      | Variable_name    | Value       |
      +------------------+-------------+
      | ob_query_timeout | 10000000    |
      +------------------+-------------+
      1 row in set
      ```

   * Query the global variable `ob_query_timeout`.

      ```shell
      obclient [oceanbase]> SHOW GLOBAL VARIABLES WHERE variable_name LIKE 'ob_query_timeout';
      ```

      The query result is as follows:

      ```shell
      +------------------+-------------+
      | Variable_name    | Value       |
      +------------------+-------------+
      | ob_query_timeout | 10000000    |
      +------------------+-------------+
      1 row in set
      ```

## View tenant system variables by using a view

1. Log in to the `mysql001` tenant of the cluster as the `root` user.

   ```shell
   obclient -P2881 -h172.30.xx.xx -uroot@mysql001#cluster -p**** -A -Doceanbase
   ```

2. Access the database named `oceanbase`.

   ```shell
   obclient [(none)]> USE oceanbase;
   ```

3. Query variable values by using views.

   * Query the value of the session-level variable `ob_query_timeout` from the `INFORMATION_SCHEMA.SESSION_VARIABLES` view.

      ```shell
      obclient [oceanbase]> SELECT * FROM INFORMATION_SCHEMA.SESSION_VARIABLES WHERE VARIABLE_NAME = 'ob_query_timeout';
      ```

      The query result is as follows:

      ```shell
      +------------------+----------------+
      | VARIABLE_NAME    | VARIABLE_VALUE |
      +------------------+----------------+
      | ob_query_timeout | 10000000       |
      +------------------+----------------+
      1 row in set
      ```

   * Query the value of the global-level variable `ob_query_timeout` from the `INFORMATION_SCHEMA.GLOBAL_VARIABLES` view.

      ```shell
      obclient [oceanbase]> SELECT * FROM INFORMATION_SCHEMA.GLOBAL_VARIABLES WHERE VARIABLE_NAME = 'ob_query_timeout';
      ```

      The query result is as follows:

      ```shell
      +------------------+----------------+
      | VARIABLE_NAME    | VARIABLE_VALUE |
      +------------------+----------------+
      | ob_query_timeout | 10000000       |
      +------------------+----------------+
      1 row in set
      ```

   * Query the modification history and default value of the `ob_query_timeout` variable from the `DBA_OB_SYS_VARIABLES` view.

     ```shell
     obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_SYS_VARIABLES WHERE NAME='ob_query_timeout';
     ```

     The query result is as follows:

     ```shell
     +----------------------------+----------------------------+------------------+----------+-----------+-----------+------------------+----------------------------------+---------------+-----------+
     | CREATE_TIME                | MODIFY_TIME                | NAME             | VALUE    | MIN_VALUE | MAX_VALUE | SCOPE            | INFO                             | DEFAULT_VALUE | ISDEFAULT |
     +----------------------------+----------------------------+------------------+----------+-----------+-----------+------------------+----------------------------------+---------------+-----------+
     | 2024-05-08 14:22:06.882646 | 2024-05-08 14:22:06.882646 | ob_query_timeout | 10000000 |           |           | GLOBAL | SESSION | Query timeout in microsecond(us) | 10000000      | YES       |
     +----------------------------+----------------------------+------------------+----------+-----------+-----------+------------------+----------------------------------+---------------+-----------+
     1 row in set
     ```
