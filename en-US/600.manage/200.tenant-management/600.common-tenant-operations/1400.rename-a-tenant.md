# Rename a tenant

The `sys` tenant can rename a user tenant.

Currently, OceanSeek supports renaming only user tenants.

## Considerations

Renaming a tenant by using the command-line method (the `ALTER TENANT` statement) causes the tenant to appear unavailable in OCP. If you need to manage the tenant by using OCP, perform the renaming operation directly in OCP. 

## Procedure

1. Log in to the `sys` tenant of the cluster as the `root` user.

2. Rename a user tenant.

   The statement is as follows:

   ```sql
   ALTER TENANT old_tenant_name RENAME GLOBAL_NAME TO new_tenant_name;
   ```

   For example, to change the tenant name from `tenant1` to `tenant2`:

   ```shell
   obclient> ALTER TENANT tenant1 RENAME GLOBAL_NAME TO tenant2;
   ```
