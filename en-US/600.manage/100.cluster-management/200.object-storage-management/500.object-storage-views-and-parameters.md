# Object storage-related views and parameters

In the storage-compute separation architecture based on shared storage, you can query the configuration information and runtime status of object storage by using system views. This topic describes the object storage-related system views and parameters.

## System views

The following system views can be used to query the object storage configuration and I/O access resources of the OBServer cluster:

| Name | Description |
| ------ | ------ |
| [oceanbase.DBA_OB_ZONE_STORAGE](../../../700.reference/700.system-views/300.system-view-of-sys-tenant/200.dictionary-view-of-sys-tenant/24350.o-dba_ob_zone_storage-of-sys-tenant.md) | Displays the object storage configuration of the cluster in each zone. |
| [GV$OB_SERVER_STORAGE](../../../700.reference/700.system-views/300.system-view-of-sys-tenant/300.performance-view-of-sys-tenant/3250.gv-ob_server_storage-of-sys-tenant.md) | Displays the object storage configuration of the cluster on all OBServer nodes. |
| [V$OB_SERVER_STORAGE](../../../700.reference/700.system-views/300.system-view-of-sys-tenant/300.performance-view-of-sys-tenant/33650.v-ob_server_storage-of-sys-tenant.md) | Displays the object storage configuration of the cluster on the current OBServer node. |
| [GV$OB_SHARED_STORAGE_QUOTA](../../../700.reference/700.system-views/300.system-view-of-sys-tenant/300.performance-view-of-sys-tenant/3420.gv-ob_shared_storage_quota-of-sys-tenant.md) | Displays the I/O access resource information on all OBServer nodes. |
| [V$OB_SHARED_STORAGE_QUOTA](../../../700.reference/700.system-views/300.system-view-of-sys-tenant/300.performance-view-of-sys-tenant/33920.v-ob_shared_storage_quota-of-sys-tenant.md) | Displays the I/O access resource information on the current OBServer node. |
| [oceanbase.DBA_OB_STORAGE_SPACE_USAGE](../../../700.reference/700.system-views/400.system-view-of-mysql-mode/200.dictionary-view-of-mysql-mode/11110.o-dba_ob_ss_space_usage-of-mysql-mode.md) | Records the storage space usage of the object storage in the current tenant. |

## Parameters

| Name | Description |
| ------ | ------ |
| [logservice_access_point](../../../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/300.cluster-level-configuration-items/12750.logservice_access_point.md) | Specifies the access point configuration of LogService for updating the log storage access credentials. |
| [sts_credential](../../../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/7730.sts_credential.md) | Specifies the credentials for accessing the STS service provided by OceanBase Cloud Platform (OCP). |
