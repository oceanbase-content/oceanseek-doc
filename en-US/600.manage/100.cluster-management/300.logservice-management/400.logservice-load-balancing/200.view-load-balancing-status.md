# View the load balancing status

You can use the `show v-table` command of the LS-CTRL tool to view the load information of a LogService cluster, including node load, Zone load, and I/O statistics of log stream replicas.

## View node load

Run the following command to view the IOPS and bandwidth usage of each LN:

```shell
ls_ctrl -H <HOST_ADDRESS> show v-table node_load
```

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>In the preceding command, <code>HOST_ADDRESS</code> is the HTTP address (including the port number) of any LogService node, for example, <code>127.0.0.1:8080</code>. For more information about LS-CTRL commands, see <a href="../../../../700.reference/950.logservice-reference/100.logservice-commands/100.ls-ctrl-overview.md">Overview of LS-CTRL</a>.</p>
</main>

In the returned result, each row contains the following information about a node: node ID, zone name, IOPS usage, IOPS capacity, IOPS utilization, bandwidth usage, bandwidth capacity, and bandwidth utilization.

## View Zone load

Run the following command to view the IOPS and bandwidth usage of each Zone:

```shell
ls_ctrl -H <HOST_ADDRESS> show v-table az_load
```

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>In the preceding command, <code>HOST_ADDRESS</code> is the HTTP address (including the port number) of any LogService node, for example, <code>127.0.0.1:8080</code>. For more information about LS-CTRL commands, see <a href="../../../../700.reference/950.logservice-reference/100.logservice-commands/100.ls-ctrl-overview.md">Overview of LS-CTRL</a>.</p>
</main>

In the returned result, each row contains the following information about a Zone: Zone name, IOPS usage, IOPS capacity, IOPS utilization, bandwidth usage, bandwidth capacity, and bandwidth utilization.

## View log stream replica I/O

Run the following command to view the I/O statistics of each log stream replica:

```shell
ls_ctrl -H <HOST_ADDRESS> show v-table stream_replica_io
```

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>In the preceding command, <code>HOST_ADDRESS</code> is the HTTP address (including the port number) of any LogService node, for example, <code>127.0.0.1:8080</code>. For more information about LS-CTRL commands, see <a href="../../../../700.reference/950.logservice-reference/100.logservice-commands/100.ls-ctrl-overview.md">Overview of LS-CTRL</a>.</p>
</main>

In the returned result, each record contains the following information: log stream ID, node ID, I/O type, replica type, bandwidth, and IOPS.
