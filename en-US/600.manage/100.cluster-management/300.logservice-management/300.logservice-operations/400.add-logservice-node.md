# Add a LogService node

LogService supports dynamic scaling. You can use the `add ln` command of the LS-CTRL tool to add a LogService node (LN) to a specified Zone in a LogService cluster.

## Procedure

Add an LN to a specified Zone in the cluster.

```shell
ls_ctrl -H <HOST_ADDRESS> add ln <host:port> <az>
```

where:

* `<host:port>`: The address of the node to be added. This parameter is required. The port must be the same as the `rpc_port` value in the configuration file.
* `<az>`: The name of the target Zone. This parameter is required.

After the command is executed successfully, you can run the `ls_ctrl show ln` command to check whether the node is added.

```shell
ls_ctrl -H <HOST_ADDRESS> show ln
```

If the new node appears in the list, the node is successfully added.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>In the preceding command, <code>HOST_ADDRESS</code> is the HTTP address (including the port number) of any LogService node, for example, <code>127.0.0.1:8080</code>. For more information about LS-CTRL commands, see <a href="../../../../700.reference/950.logservice-reference/100.logservice-commands/100.ls-ctrl-overview.md">Overview of LS-CTRL</a>.</p>
</main>
