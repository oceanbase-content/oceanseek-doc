# View a LogService node

A LogService node is called an LN (LogServiceNode). Each node is uniquely identified by an `ln_id` and an address (`host:port`). You can use the `show ln` command of the LS-CTRL tool to view the information about a specified LN or all LNs in the cluster.

## Procedure

* Execute the following command to view the information about all LNs:

    ```shell
    ls_ctrl -H <HOST_ADDRESS> show ln
    ```

* Execute the following command to query the information about a specified LN by address:

    ```shell
    ls_ctrl -H <HOST_ADDRESS> show ln <host:port>
    ```

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>In the preceding commands, <code>HOST_ADDRESS</code> is the HTTP address (including the port number) of any LogService node, for example, <code>127.0.0.1:8080</code>. For more information about LS-CTRL commands, see <a href="../../../../700.reference/950.logservice-reference/100.logservice-commands/100.ls-ctrl-overview.md">Overview of LS-CTRL</a>.</p>
</main>
