# Modify LogService parameters

You can set runtime parameters for LogService by using the LS-CTRL tool.

## Set cluster-level parameters

```shell
ls_ctrl -H <HOST_ADDRESS> set param <name> <value>
```

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>In the preceding command, <code>HOST_ADDRESS</code> is the HTTP address (including the port number) of any LogService node, for example, <code>127.0.0.1:8080</code>. For more information about LS-CTRL commands, see <a href="../../../../700.reference/950.logservice-reference/100.logservice-commands/100.ls-ctrl-overview.md">Overview of LS-CTRL</a>.</p>
</main>

Here is an example:

```shell
# Enable log stream load balancing
ls_ctrl -H 127.0.0.1:50052 set param enable_rebalance true

# Set the permanent offline timeout period of a node to 3,600 seconds.
ls_ctrl -H 127.0.0.1:50052 set param node_permanent_offline_time_sec 3600
```

## Set node-level parameters

```shell
ls_ctrl -H <HOST_ADDRESS> set param --server-only <name> <value>
```

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>In the preceding command, <code>HOST_ADDRESS</code> is the HTTP address (including the port number) of any LogService node, for example, <code>127.0.0.1:8080</code>. For more information about LS-CTRL commands, see <a href="../../../../700.reference/950.logservice-reference/100.logservice-commands/100.ls-ctrl-overview.md">Overview of LS-CTRL</a>.</p>
</main>

Here is an example:

```shell
# Set the log level to debug.
ls_ctrl -H 127.0.0.1:50052 set param --server-only log_level debug

# Set the upper limit of log disk size to 100 GB.
ls_ctrl -H 127.0.0.1:50052 set param --server-only log_disk_size 100GB
```

## Parameters

| Parameter | Description |
| ------ | ------ |
| `--server-only` | Specifies whether the change takes effect only on the node specified by `-H` (server level). If this parameter is not specified, the change takes effect on the entire cluster (cluster level). The default value is `false`. |
| `<name>` | The parameter name. This parameter is required. |
| `<value>` | The parameter value. This parameter is required. |
