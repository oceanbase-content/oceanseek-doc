# Delete a LogService node

LogService supports dynamic scale-in. You can use the `delete ln` command of the LS-CTRL tool to delete a LogService node (LN) from a LogService cluster.

## Procedure

Run the following command to delete an LN:

```shell
ls_ctrl -H <HOST_ADDRESS> delete ln <ln>
```

Here, `<ln>` is the ID or address (`host:port`) of the node to be deleted.

After the command is executed successfully, you can run the `ls_ctrl show ln` command to check whether the node is deleted.

```shell
ls_ctrl -H <HOST_ADDRESS> show ln
```

If the node no longer appears in the list, the node is successfully deleted.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>In the preceding command, <code>HOST_ADDRESS</code> is the HTTP address (including the port number) of any LogService node, for example, <code>127.0.0.1:8080</code>. For more information about LS-CTRL commands, see <a href="../../../../700.reference/950.logservice-reference/100.logservice-commands/100.ls-ctrl-overview.md">LS-CTRL overview</a>.</p>
</main>
