# View LogService parameters

You can use the LS-CTRL tool to query the runtime parameters of LogService.

## View cluster-level parameters

Run the following command to view cluster-level parameters:

```shell
ls_ctrl -H <HOST_ADDRESS> show parameter <name>
```

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>In the preceding command, <code>HOST_ADDRESS</code> is the HTTP address (including the port number) of any LogService node, for example, <code>127.0.0.1:8080</code>. For more information about LS-CTRL commands, see <a href="../../../../700.reference/950.logservice-reference/100.logservice-commands/100.ls-ctrl-overview.md">Overview of LS-CTRL</a>.</p>
</main>

## View node-level parameters

Run the following command (specify `--server-only`) to view node-level parameters:

```shell
ls_ctrl -H <HOST_ADDRESS> show parameter <name> --server-only
```

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>In the preceding command, <code>HOST_ADDRESS</code> is the HTTP address (including the port number) of any LogService node, for example, <code>127.0.0.1:8080</code>. For more information about LS-CTRL commands, see <a href="../../../../700.reference/950.logservice-reference/100.logservice-commands/100.ls-ctrl-overview.md">Overview of LS-CTRL</a>.</p>
</main>

## Parameters

The following table describes the parameters of the `show parameter` command.

| Parameter | Description |
| ------ | ------ |
| `<name>` | The parameter name. This parameter is required. |
| `--server-only` | Specifies whether to read the local configuration of the target node specified by `-H` instead of reading cluster-level parameters from the LM leader. The default value is `false`. |
