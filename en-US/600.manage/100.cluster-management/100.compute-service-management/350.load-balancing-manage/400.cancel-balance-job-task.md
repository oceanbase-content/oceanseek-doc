# Cancel a balance job

Each tenant can only have one balance job running at a time. If the current balance job does not meet business requirements, you can cancel it. Alternatively, if you have initiated a partition transfer but find that an ongoing balance job is delaying the scheduling of the partition transfer task, you can first cancel the current balance job.

## Background information

Each tenant can only have one balance job running at a time. These balance jobs include scaling up, scaling down, migration balancing, and partition balancing. Each balance job generates multiple balancing tasks to perform specific load balancing operations. Canceling a balance job will cancel all running tasks under that job.

## Cancel a balance job in the sys tenant

1. Log in to the `sys` tenant of the cluster as the `root` user.

   Note that you must specify the corresponding options in the following sample code based on your actual database configurations.

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@sys#obdemo -p***** -A
   ```

2. Query the `CDB_OB_BALANCE_JOBS` view for the status of the current job.

   ```shell
   obclient(root@sys)[oceanbase]> SELECT TENANT_ID, JOB_ID, BALANCE_STRATEGY, JOB_TYPE, STATUS FROM oceanbase.CDB_OB_BALANCE_JOBS WHERE TENANT_ID = 1002;
   ```

   A sample query result is shown below:

   ```shell
   +-----------+--------+----------------------+------------+--------+
   | TENANT_ID | JOB_ID | BALANCE_STRATEGY     | JOB_TYPE   | STATUS |
   +-----------+--------+----------------------+------------+--------+
   |      1002 | 520683 | LS balance by shrink | LS_BALANCE | DOING  |
   +-----------+--------+----------------------+------------+--------+
   1 row in set
   ```

3. If the query result shows that the job is not as expected, you can execute the following statement to cancel it.

   ```sql
   ALTER SYSTEM CANCEL BALANCE JOB TENANT = 'tenant_name';
   ```

   A sample execution is shown below:

   ```shell
   obclient(root@sys)[oceanbase]> ALTER SYSTEM CANCEL BALANCE JOB TENANT ='mysql_tenant';
   ```

## Cancel a balance job in a user tenant

1. Connect to the database as the tenant administrator of the user tenant.

   Note that you must specify the corresponding options in the following sample code based on your actual database configurations.

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@mysql_tenant#obdemo -p***** -A
   ```

2. Query the `DBA_OB_BALANCE_JOBS` view for the status of the current job.

   The query statement is as follows:

   ```shell
   obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_BALANCE_JOBS;
   ```

3. If the query result shows that the job is not as expected, you can execute the following statement to cancel it.

   ```shell
   obclient> ALTER SYSTEM CANCEL BALANCE JOB;
   ```
