# View the configurations of a scheduled partition balancing task

The system provides a built-in scheduled partition balancing task named `SCHEDULED_TRIGGER_PARTITION_BALANCE`. You can view the parameter configurations of this task for your tenant as needed.

## Procedure

1. Log in to the user tenant of the cluster.

   Note that you must specify the corresponding options in the following sample code based on your actual database configurations.

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@mysql_tenant#obdemo -p***** -A
   ```

2. Execute the following statement to view the configurations of the scheduled partition balancing task for the current tenant.

   The `DBA_SCHEDULER_JOBS` view displays information about all scheduled tasks in the current tenant.

   The statement is as follows:

   ```shell
   obclient [oceanbase]> SELECT JOB_NAME, JOB_ACTION, START_DATE, REPEAT_INTERVAL, ENABLED, NEXT_RUN_DATE,MAX_RUN_DURATION, COMMENTS FROM oceanbase.DBA_SCHEDULER_JOBS WHERE job_name = 'SCHEDULED_TRIGGER_PARTITION_BALANCE'\G
   ```

   The query result is as follows:

   ```shell
   *************************** 1. row ***************************
            JOB_NAME: SCHEDULED_TRIGGER_PARTITION_BALANCE
          JOB_ACTION: DBMS_BALANCE.TRIGGER_PARTITION_BALANCE()
          START_DATE: 2024-06-14 00:00:00.000000
     REPEAT_INTERVAL: FREQ=DAILY; INTERVAL=1
             ENABLED: 1
       NEXT_RUN_DATE: 2024-06-15 00:00:00.000000
    MAX_RUN_DURATION: 7200
            COMMENTS: used to auto trigger partition balance
   1 row in set
   ```

   where:

   * `JOB_NAME`: the name of the scheduled task. In this example, `SCHEDULED_TRIGGER_PARTITION_BALANCE` is the name of the scheduled partition balancing task.
   * `JOB_ACTION`: the operation to be performed by the scheduled partition balancing task.
   * `START_DATE`: the trigger time of the scheduled partition balancing task. The default value is 00:00 every day.
   * `REPEAT_INTERVAL`: the interval and frequency of the scheduled partition balancing task. The default value is once a day.
   * `ENABLED`: specifies whether the scheduled partition balancing task is enabled. `1` indicates enabled, and `0` indicates disabled. The default value is `1`.
   * `NEXT_RUN_DATE`: the next trigger time of the scheduled partition balancing task.
   * `MAX_RUN_DURATION`: the timeout period for executing `JOB_ACTION`. The default value is 7200, in seconds.

   For more information about the columns in the `DBA_SCHEDULER_JOBS` view, see [DBA_SCHEDULER_JOBS](../../../../../700.reference/700.system-views/400.system-view-of-mysql-mode/200.dictionary-view-of-mysql-mode/14100.o-dba_scheduler_jobs-of-mysql-mode.md).
