# View the trigger history of scheduled partition balancing tasks

After a scheduled partition balancing task is triggered, you can view its trigger history by querying a view.

## View the trigger history of scheduled partition balancing tasks in the sys tenant

1. Log in to the `sys` tenant of the cluster as the `root` user.

   Note that you must specify the corresponding options in the following sample code based on your actual database configurations.

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@sys#obdemo -p***** -A
   ```

2. Execute the following statement to view the trigger history of the scheduled partition balancing task for a specified tenant.

   The `CDB_SCHEDULER_JOB_RUN_DETAILS` view displays the execution records of the `SCHEDULED_TRIGGER_PARTITION_BALANCE` job of all tenants.

   ```shell
   obclient [oceanbase]> SELECT * FROM oceanbase.CDB_SCHEDULER_JOB_RUN_DETAILS WHERE TENANT_ID = 1002 AND JOB_NAME = 'SCHEDULED_TRIGGER_PARTITION_BALANCE'\G
   ```

## View the trigger history of scheduled partition balancing tasks in a user tenant

1. Log in to the cluster as the tenant administrator of a user tenant.

   Note that you must specify the corresponding options in the following sample code based on your actual database configurations.

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@mysql_tenant#obdemo -p***** -A
   ```

2. Execute the following statement to view the trigger history of the scheduled partition balancing task for the current tenant.

   The `DBA_SCHEDULER_JOB_RUN_DETAILS` view displays the execution records of the `SCHEDULED_TRIGGER_PARTITION_BALANCE` job of the current tenant.

   The statement is as follows:

   ```shell
   obclient [oceanbase]> SELECT * FROM oceanbase.DBA_SCHEDULER_JOB_RUN_DETAILS WHERE JOB_NAME = 'SCHEDULED_TRIGGER_PARTITION_BALANCE'\G
   ```
