# View background partition balancing tasks

After a partition balancing task is triggered, you can view the execution status of the task by querying a view.

## View background partition balancing tasks in the sys tenant

1. Log in to the sys tenant of the cluster as the `root` user.

   Note that you must specify the corresponding options in the following sample code based on your actual database configurations.

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@sys#obdemo -p***** -A
   ```

2. Execute the following statements to view the partition balancing tasks currently running in the background for a specified tenant.

   * View partition balancing tasks being executed by a specified tenant.

     The `CDB_OB_BALANCE_JOBS` view displays macro-level balancing tasks currently in progress for all tenants, including expansion, contraction, migration balancing, and partition balancing tasks.

     ```shell
     obclient(root@sys)[oceanbase]> SELECT * FROM oceanbase.CDB_OB_BALANCE_JOBS WHERE TENANT_ID = 1002 AND JOB_TYPE = 'PARTITION_BALANCE';
     ```

     The query result is as follows:

     ```shell

     | TENANT_ID | JOB_ID | CREATE_TIME                | MODIFY_TIME                | BALANCE_STRATEGY                | JOB_TYPE          | TARGET_UNIT_NUM | TARGET_PRIMARY_ZONE_NUM | STATUS | COMMENT | MAX_END_TIME | ZONE_UNIT_NUM_LIST | PARAMETER_LIST                                                                               |
     +-----------+--------+----------------------------+----------------------------+---------------------------------+-------------------+-----------------+-------------------------+--------+---------+--------------+--------------------+----------------------------------------------------------------------------------------------+
     |      1002 | 374412 | 2024-06-14 14:39:38.710194 | 2024-06-14 14:39:38.710194 | partition attribution alignment | PARTITION_BALANCE |            NULL |                       1 | DOING  | NULL    | NULL         | zone1:1            | ls_scale_out_factor:1,enable_rebalance:true,enable_transfer:true,enable_gts_standalone:false |
     +-----------+--------+----------------------------+----------------------------+---------------------------------+-------------------+-----------------+-------------------------+--------+---------+--------------+--------------------+----------------------------------------------------------------------------------------------+
     1 row in set
     ```

     For more information about the fields in the `CDB_OB_BALANCE_JOBS` view, see [CDB_OB_BALANCE_JOBS](../../../../../700.reference/700.system-views/300.system-view-of-sys-tenant/200.dictionary-view-of-sys-tenant/7800.o-cdb_ob_balance_jobs-of-sys-tenant.md).

   * View log stream (LS)-level partition balancing tasks being executed by a specified tenant.

     The `CDB_OB_BALANCE_TASKS` view displays log stream-level tasks currently in progress for all tenants, including log stream split (`LS_SPLIT`), log stream merge (`LS_MERGE`), log stream transfer (`LS_TRANSFER`), and log stream attribute modification (`LS_ALTER`) tasks.

     ```shell
     obclient(root@sys)[oceanbase]> SELECT * FROM oceanbase.CDB_OB_BALANCE_TASKS WHERE TENANT_ID = 1002 AND BALANCE_STRATEGY LIKE '%partition%';
     ```

     The query result is as follows:

     For more information about the fields in the `CDB_OB_BALANCE_TASKS` view, see [CDB_OB_BALANCE_TASKS](../../../../../700.reference/700.system-views/300.system-view-of-sys-tenant/200.dictionary-view-of-sys-tenant/8000.o-cdb_ob_balance_tasks-of-sys-tenant.md).

   * View tablet-level partition balancing tasks being executed by a specified tenant.

     The `CDB_OB_TRANSFER_TASKS` view displays tablet-level tasks currently in progress for all tenants, showing which specific partitions and tablets within the tenant are undergoing transfer operations.

## View partition balancing tasks in the background of a user tenant

1. Log in to the cluster as the tenant administrator of the user tenant.

   Note that you must specify the corresponding options in the following sample code based on your actual database configurations.

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@mysql_tenant#obdemo -p***** -A
   ```

2. Execute the following statements to view the partition balancing tasks currently running in the background of the tenant.

   * View the partition balancing tasks being executed for the current tenant.

     The `DBA_OB_BALANCE_JOBS` view displays macro-level balancing tasks currently being executed for the current tenant, including expansion, contraction, migration balancing, and partition balancing tasks.

     ```shell
     obclient(root@mysql001)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_BALANCE_JOBS WHERE JOB_TYPE = 'PARTITION_BALANCE';
     ```

     The query result is as follows:

