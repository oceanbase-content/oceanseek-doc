# Stop and resume a balance job

When a tenant has a running balance job and other urgent changes need to be performed, you can stop the current balance job to prevent its execution from affecting the urgent changes. After the urgent changes are completed, you can resume the job to continue its execution.

## Limitations

* The status of the balance job must not be `CANCELING` when stopping or resuming it.

## Stop a running balance job

### Stop a running balance job of a user tenant in the sys tenant

1. Log in to the `sys` tenant of the cluster as the `root` user.

   Note that you must specify the corresponding parameters in the following sample code based on your actual database configuration.

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@sys#obdemo -p***** -A
   ```

2. Query the tenant information.

   ```shell
   obclient(root@sys)[oceanbase]> SELECT TENANT_ID, TENANT_NAME, TENANT_ROLE FROM oceanbase.DBA_OB_TENANTS WHERE tenant_name = 'mq_t1';
   ```

   A sample query result is as follows:

   ```shell
   +-------------+-----------+-------------+
   | TENANT_NAME | TENANT_ID | TENANT_ROLE |
   +-------------+-----------+-------------+
   | mq_t1       |      1002 | PRIMARY     |
   +-------------+-----------+-------------+
   1 row in set
   ```

3. Query the `CDB_OB_BALANCE_JOBS` view for the status and information about the current job.

   ```shell
   obclient(root@sys)[oceanbase]> SELECT TENANT_ID, JOB_ID, JOB_TYPE, STATUS FROM oceanbase.CDB_OB_BALANCE_JOBS WHERE TENANT_ID = 1002;
   ```

   A sample query result is as follows:

   ```shell
   +-----------+--------+--------------------+--------+
   | TENANT_ID | JOB_ID | JOB_TYPE           | STATUS |
   +-----------+--------+--------------------+--------+
   |      1002 |  62944 | TRANSFER_PARTITION | DOING  |
   +-----------+--------+--------------------+--------+
   1 row in set
   ```

   In the query result, if the status of the current job is `DOING` instead of `CANCELING`, you can stop the job.

4. Execute the following statement to stop the balance job.

   ```sql
   ALTER SYSTEM SUSPEND BALANCE JOB TENANT = 'tenant_name';
   ```

   A sample execution is as follows:

   ```shell
   obclient(root@sys)[oceanbase]> ALTER SYSTEM SUSPEND BALANCE JOB TENANT ='mq_t1';
   ```

5. After the job is stopped, query the `CDB_OB_BALANCE_JOBS` view again. The status of the job should have changed to `SUSPEND`.

   ```shell
   obclient(root@sys)[oceanbase]> SELECT TENANT_ID, JOB_ID, JOB_TYPE, STATUS FROM oceanbase.CDB_OB_BALANCE_JOBS WHERE TENANT_ID = 1002;
   ```

   The query result is as follows:

   ```shell
   +-----------+--------+--------------------+---------+
   | TENANT_ID | JOB_ID | JOB_TYPE           | STATUS  |
   +-----------+--------+--------------------+---------+
   |      1002 |  62944 | TRANSFER_PARTITION | SUSPEND |
   +-----------+--------+--------------------+---------+
   1 row in set
   ```

### Stop a running balance job in the current tenant as a user tenant

1. The tenant administrator of the user tenant connects to the database.

   Note that you must specify the corresponding options in the following sample code based on your actual database configurations.

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@mysql_tenant#obdemo -p***** -A
   ```

2. Query the `DBA_OB_BALANCE_JOBS` view for information about the currently running tasks and their status.

   The query statement is as follows:

   ```shell
   obclient(root@mysql001)[oceanbase]> SELECT JOB_ID, JOB_TYPE, STATUS FROM oceanbase.DBA_OB_BALANCE_JOBS;
   ```



   An example of the query result is as follows:

   ```shell
   +--------+--------------------+---------+
   | JOB_ID | JOB_TYPE           | STATUS  |
   +--------+--------------------+---------+
   |  62944 | TRANSFER_PARTITION |   DOING |
   +--------+--------------------+---------+
   1 row in set
   ```

   According to the query result, the status of the current balance job is `DOING`, not `CANCELING`, so the job can be suspended.

3. Execute the following statement to suspend the balance job.

   ```shell
   obclient> ALTER SYSTEM SUSPEND BALANCE JOB;
   ```

4. After the job is successfully suspended, query the `DBA_OB_BALANCE_JOBS` view again. You will see that the status of the current task has changed to `SUSPEND`.

   The query statement is as follows:

   ```shell
   obclient(root@mysql001)[oceanbase]> SELECT JOB_ID, JOB_TYPE, STATUS FROM oceanbase.DBA_OB_BALANCE_JOBS;
   ```



   An example of the query result is as follows:

   ```shell
   +--------+--------------------+---------+
   | JOB_ID | JOB_TYPE           | STATUS  |
   +--------+--------------------+---------+
   |  62944 | TRANSFER_PARTITION | SUSPEND |
   +--------+--------------------+---------+
   1 row in set
   ```

## Resume a suspended balance job

### Resume a suspended balance job of a user tenant in the sys tenant

1. Log in to the `sys` tenant of the cluster as the `root` user.

   Note that you must specify the corresponding options in the following sample code based on your actual database configurations.

   ```shell
   obclient -h10.xx.xx.xx -P2883 -uroot@sys#obdemo -p***** -A
   ```

2. Retrieve tenant-related information.

   ```shell
   obclient(root@sys)[oceanbase]> SELECT TENANT_ID, TENANT_NAME, TENANT_ROLE FROM oceanbase.DBA_OB_TENANTS WHERE tenant_name = 'mq_t1';
   ```

   The query result is as follows:

   ```shell
   +-------------+-----------+-------------+
   | TENANT_NAME | TENANT_ID | TENANT_ROLE |
   +-------------+-----------+-------------+
   | mq_t1       |      1002 | PRIMARY     |
   +-------------+-----------+-------------+
   1 row in set
   ```

3. Query the `CDB_OB_BALANCE_JOBS` view for the status of the current suspended job.

   ```shell
   obclient(root@sys)[oceanbase]> SELECT TENANT_ID, JOB_ID, JOB_TYPE, STATUS FROM oceanbase.CDB_OB_BALANCE_JOBS WHERE TENANT_ID = 1002;
   ```

   An example of the query result is shown below:

   ```shell
   +-----------+--------+--------------------+---------+
   | TENANT_ID | JOB_ID | JOB_TYPE           | STATUS  |
   +-----------+--------+--------------------+---------+
   |      1002 |  62944 | TRANSFER_PARTITION | SUSPEND |
   +-----------+--------+--------------------+---------+
   1 row in set
   ```

   According to the query result, the status of the current balance job is `SUSPEND`.

4. Execute the following statement to resume the suspended balance job.

   ```sql
   ALTER SYSTEM SUSPEND BALANCE JOB TENANT = 'tenant_name';
   ```

   An example is shown below:

   ```shell
   obclient(root@sys)[oceanbase]> ALTER SYSTEM RESUME BALANCE JOB TENANT ='mq_t1';
   ```

5. After successful execution, query the `CDB_OB_BALANCE_JOBS` view again, and you will see that the status of the current job has changed to `DOING`.

   ```shell
   obclient(root@sys)[oceanbase]> SELECT TENANT_ID, JOB_ID, JOB_TYPE, STATUS FROM oceanbase.CDB_OB_BALANCE_JOBS WHERE TENANT_ID = 1002;
   ```

   An example of the query result is shown below:

   ```shell
   +-----------+--------+--------------------+---------+
   | TENANT_ID | JOB_ID | JOB_TYPE           | STATUS  |
   +-----------+--------+--------------------+---------+
   |      1002 |  62944 | TRANSFER_PARTITION |  DOING  |
   +-----------+--------+--------------------+---------+
   1 row in set
   ```
