## Test plan

In this test, the TPC-H 22 queries were executed at two data scales: 100G and 1T. Each data scale included both Hot and Cold test scenarios.

* For the test procedure, parameter settings, table creation, data loading, and statistics collection methods, see [OceanSeek TPC-H test](5.tpc-h-performance-test.md).
* Hot scenario: Queries are executed while the cache is warm. Each query is run three times in a row, and the average time of the last two runs is taken as the RT for that query.
* Cold scenario: The cache is cleared and waits for expiration before each query is executed. The execution time for a single query is taken as its RT, excluding cache clearance and wait time.
* For each data scale, the standard TPC-H 22 queries are executed. In both scenarios, all 22 queries must execute successfully.
* Data loading time only accumulates the client execution time of the final successful `LOAD DATA` statement, excluding row count verification, failed retry attempts, major compactions, statistics collection, and queries.
