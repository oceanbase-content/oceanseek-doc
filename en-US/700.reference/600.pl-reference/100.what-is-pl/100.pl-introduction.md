# PL Overview

PL is a procedural language (Procedural Language, PL). It extends SQL by adding programming language features to standard SQL statements. It organizes data manipulation and query statements within procedural PL code, enabling complex functionality through logical judgments, loops, and other operations.

PL allows you to write programs with many advanced features. It encapsulates business logic within the database, providing better abstraction and security. At the same time, it reduces network interactions, speeds up calls, and improves overall performance.

The main advantages of PL are as follows:

* High performance

  When using PL to interact with the database, all processing logic resides on the database server, which only returns the required results to the client. This significantly reduces data exchange between the application server and the database server, saving network resources and processing time.

  PL objects are stored in the database in a precompiled form. Compared with regular SQL, the optimizer can optimize PLs more effectively, resulting in more efficient execution.

* Easy to develop

  Many features of PL enable developers to save time on development, design, and troubleshooting. Developers can use OceanBase Developer Center (ODC), a dedicated tool provided by OceanSeek, for efficient development.

  For more information, see the ODC documentation on the OceanBase official website.

* Portable

  For database developers, PL is a portable standard language. PL applications can run in any OceanBase AI database.

* Easy to manage

  PL objects are stored in the database. When an application is modified or a version is updated, you only need to modify the corresponding PL object in the database, and the changes take effect immediately for all applications. This eliminates the need to worry about discrepancies in client code updates.
