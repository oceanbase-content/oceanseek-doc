# REFRESH

`REFRESHE` is used to refresh a specified materialized view.

## Syntax

```sql
DBMS_MVIEW.REFRESH (
    mv_name                IN    VARCHAR(65535)
    [, method              IN    VARCHAR(65535) DEFAULT NULL]
    [, refresh_parallel    IN    INT DEFAULT 0]
    [, nested              IN    BOOLEAN DEFAULT FALSE]
    [, nested_refresh_mode IN    VARCHAR DEFAULT NULL]
    [, async               IN    BOOLEAN DEFAULT FALSE]
);
```

## Parameters

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>Non-nested materialized views do not support cascading refresh. Specifying the <code>nested</code> and <code>nested_refresh_mode</code> parameters is meaningless; by default, they are refreshed independently.</p>
</main>

| **Parameter** | **Note** |
| --------------------- | ----------------------- |
| mv_name | The name of the materialized view to be refreshed. |
| method | You can define a refresh strategy for a materialized view by specifying the default strategy when creating the view. Valid methods include:<ul><li>`F` or `f`: Quickly refreshes.</li><li>`?`: forces a refresh. </li><li>`C` or `c`: Performs a complete refresh.</li><li>`A` or `a`: Always refresh, equivalent to `C`.</li></ul> |
| refresh_parallel | The concurrency level of the refresh operation, which is the number of threads that perform the refresh operation simultaneously. |
| nested | Specifies the refresh mode for a nested materialized view. Valid values: <ul><li>`FALSE`: The default value, which indicates to independently refresh the nested materialized view.</li><li>`TRUE`: Indicates cascading refresh of nested materialized views.</li></ul> |
| nested_refresh_mode | Specifies whether the cascading refresh of nested materialized views is a consistent or non-consistent refresh. Valid values: <ul><li>When the parameter `nested` is `FALSE` When using the  command, specify the parameter `nested_refresh_mode` An error will be returned. </li><li>If the parameter `nested` is `TRUE` Time: <ul><li>Specify the parameter. `nested_refresh_mode` Valid values: <ul><li>`inconsistent`: Indicates a cascading non-consistent refresh. </li><li>`consistent`: Indicates a cascading consistent refresh. </li></ul> </li><li>If this parameter is not specified, `nested_refresh_mode` The default is a cascading non-consistent refresh. </li></ul> </li></ul> |
| async | Specifies whether to perform an asynchronous refresh. Valid values: <ul><li>`FALSE`: The default value, which indicates that the method returns only after the refresh task is completed.</li><li>`TRUE`: Indicates the call. `REFRESH`</li></ul> |

## Examples

* Independent refresh mode:

  * Only the `mv_name` parameter is specified.

    ```shell
    obclient> CALL DBMS_MVIEW.REFRESH('mv1');
    ```

  * The `mv_name` parameter and the `nested` parameter are specified with a value of `false`.

    ```shell
    obclient> CALL DBMS_MVIEW.REFRESH(
        'mv1',
        nested=> false);
    ```

* Cascading non-consistent refresh mode:

  * The `mv_name` parameter is specified, the value of the `nested` parameter is `true`, and the `nested_refresh_mode` parameter is not specified.

    ```shell
    obclient> CALL DBMS_MVIEW.REFRESH(
        'mv1',
        nested=> true);
    ```

  * The `mv_name` parameter is specified, the value of the `nested` parameter is `true`, and the value of the `nested_refresh_mode` parameter is `inconsistent`.

    ```shell
    obclient> CALL DBMS_MVIEW.REFRESH(
        'mv1',
        nested=> true,
        nested_refresh_mode => 'inconsistent');
    ```

* Cascade consistent refresh mode:

  Specify the parameter `mv_name`, set the value of the `nested` parameter to `true`, and set the value of the `nested_refresh_mode` parameter to `consistent`.

  ```shell
  obclient> CALL DBMS_MVIEW.REFRESH(
      'mv1',
      nested=> true,
      nested_refresh_mode => 'consistent');
  ```

* The following are the error scenarios:

  * An error is reported when the value of the `nested` parameter is `false` and the value of the `nested_refresh_mode` parameter is specified.

    ```shell
    obclient> CALL DBMS_MVIEW.REFRESH(
        'mv1',
        nested=> false,
        nested_refresh_mode => 'xxxx');
    ```

  * An error is returned if the value of the `nested_refresh_mode` parameter is specified but the value of the `nested` parameter is not specified.

    ```shell
    obclient> CALL DBMS_MVIEW.REFRESH(
        'mv1',
        nested_refresh_mode => 'xxxx');
    ```

  * The value of the `nested` parameter is `true`, and the value of the `nested_refresh_mode` parameter is an invalid string, causing an error.

    ```shell
    obclient> CALL DBMS_MVIEW.REFRESH(
        'mv1',
        nested=> true,
        nested_refresh_mode => 'Invalid string');
    ```
