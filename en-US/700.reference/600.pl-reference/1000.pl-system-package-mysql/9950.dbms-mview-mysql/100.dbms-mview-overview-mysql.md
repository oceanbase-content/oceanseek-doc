# Overview of DBMS_MVIEW

The `DBMS_MVIEW` system package is used to refresh materialized views and purge materialized view logs.

## Overview of DBMS_MVIEW Subprograms

The following table lists the `DBMS_MVIEW` subprograms supported by the current version of OceanSeek and provides brief descriptions.

| subprogram | Description |
| --------- | ----------------------------------------- |
| [PURGE_LOG](200.purge-log-mysql.md) | This statement is used to purge materialized view logs. Purging materialized view logs deletes all log records related to the table. |
| [REFRESH](300.refresh-mysql.md) | Refreshes one or more specified materialized views. |
| [KILL_REFRESH](400.kill_refresh-mysql.md) | This API is used to actively terminate a materialized view refresh batch that is still in progress and managed by the new scheduling framework. |
| [REFRESH_REPORT](500.refresh_report-mysql.md)| Generates a hierarchical diagnostic report for a single materialized view refresh task. |
