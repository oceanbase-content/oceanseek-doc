# PURGE_LOG

The `PURGE_LOG` statement is used to purge materialized view logs, thereby reducing the size of log files. Purging materialized view logs deletes all log records related to that table.

## Syntax

```sql
PROCEDURE purge_log(
    IN     master_name            VARCHAR(65535));
```

## Parameters

| **Parameter** | **Explanation** |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| master      | The name of the primary table whose materialized view logs need to be cleared.
The format is `schema.object or object`.                                                                         |
