# SET_THREAD_COUNT

The `SET_THREAD_COUNT` subprogram is used to set the number of threads for [window merging](../../../200.system-management/500.manage-data-storage/200.merge-management/310.window-compaction.md).

## Syntax

```sql
DBMS_DAILY_MAINTENANCE.SET_THREAD_COUNT(thread_count INT);
```

## Parameters

| Parameter | Description |
| ------------------ | ----------------------------------------------------- |
| thread_count | Specifies the number of threads for window merging. The default value is 0, which means the system automatically determines the number of threads based on the tenant's configuration. If you manually set a value other than 0, the system will use the user-defined value as the number of threads for window merging. |

## Usage instructions

* Can only be initiated by a user tenant. The system tenant (`sys` tenant) does not support this operation.

* During window-based major compaction, the number of compaction threads is not controlled by the tenant-level parameter `compaction_low_thread_score`. It can only be set using the `thread_count` parameter in the `DBMS_DAILY_MAINTENANCE.SET_THREAD_COUNT` subprogram.

## Examples

* Set the number of threads for window merging to 10.

  ```shell
  obclient(root@mysql001)[(none)]> CALL DBMS_DAILY_MAINTENANCE.SET_THREAD_COUNT(10);
  ```

* Set the number of threads for window merging to a value automatically calculated by the system.

  ```shell
  obclient(root@mysql001)[(none)]> CALL DBMS_DAILY_MAINTENANCE.SET_THREAD_COUNT(0);
  ```
