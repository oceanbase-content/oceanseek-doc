# Overview of DBMS_DAILY_MAINTENANCE

The `DBMS_DAILY_MAINTENANCE` system package is primarily used for managing and maintaining window compactions. Scheduled tasks are triggered based on this package to perform window compactions.

## Overview of DBMS_DAILY_MAINTENANCE Subprogram

The following table lists the `DBMS_DAILY_MAINTENANCE` subprograms supported by the current version of OceanBase AI Database and provides brief descriptions.

| **Subprogram** | **Description** |
| ---------------------------------------------------------------------- | ------------------------- |
| [TRIGGER_WINDOW_COMPACTION_PROC](200.trigger-window-compaction-proc-mysql.md) | Manually triggers a major compaction. |
| [SET_THREAD_COUNT](300.set-thread-count-mysql.md) | Sets the number of threads for window merging. |
