# Overview of DBMS_PARTITION

The `DBMS_PARTITION` system package provides interfaces for managing dynamic partitions.

## Privileges

The operation is only supported in user tenants.

## Overview of Subprograms

The following table lists the `DBMS_PARTITION` subprograms supported by the current version of OceanSeek and provides brief descriptions.

| subprogram | Description |
| -------------------------------------------------------------------------- | ------------------------ |
| [MANAGE_DYNAMIC_PARTITION](200.manage_dynamic_partition-of-mysql-mode.md) | Executes a dynamic partition management task to pre-create future partitions and delete expired partitions for dynamic partitioned tables under the current tenant. |
