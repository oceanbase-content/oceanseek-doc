# Overview of DBMS_XPROFILE

The `DBMS_XPROFILE` system package is a performance analysis toolkit used to deeply parse resource consumption and operator-level performance metrics during SQL execution.

## DBMS_XPROFILE Privilege Description

Users with the privilege to execute PL/SQL can use this feature.

## Overview of DBMS_XPROFILE Subprograms

The following table lists the `DBMS_XPROFILE` subprograms supported by OceanBase AI Database and provides brief descriptions.

| subprogram | Description |
| -------- | ------ |
| [DISPLAY_PROFILE](200.display-profile-of-mysql-mode.md)| Displays the performance analysis data of an SQL execution plan, allowing you to view operator-level diagnostic information for the execution corresponding to the specified `trace_id`.|
