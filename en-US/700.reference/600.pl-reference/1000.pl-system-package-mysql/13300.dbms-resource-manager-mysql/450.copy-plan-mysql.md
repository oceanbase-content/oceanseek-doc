# COPY_PLAN

The `COPY_PLAN` subroutine is used to copy an existing resource management plan and its associated resource plan directives.

## Syntax

```sql
DBMS_RESOURCE_MANAGER.COPY_PLAN (
    source_plan  VARCHAR(65535),
    target_plan  VARCHAR(65535),
    comment      VARCHAR(65535) DEFAULT '');
```

## Parameters

| Parameter | Description |
| ------------------- | -------------------------- |
| source_plan | Name of the source resource plan. |
| target_plan | The name of the copied target resource plan. The target resource plan cannot be an existing resource plan under the tenant. |
| comment | User Comments |

## Examples

Assume that resource plans named `SOURCE_PLAN` and `TARGET_PLAN` have been created. Copy the instructions of `SOURCE_PLAN` to resource plan `TARGET_PLAN`.

```shell
obclient(root@mysql001)[(none)]> CALL DBMS_RESOURCE_MANAGER.COPY_PLAN(
  SOURCE_PLAN => 'SOURCE_PLAN',
  TARGET_PLAN => 'TARGET_PLAN',
  COMMENT => 'copy plan from SOURCE_PLAN');
```
