# CREATE_PLAN_DIRECTIVE

The `CREATE_PLAN_DIRECTIVE` procedure is used to create a resource plan directive.

## Syntax

```sql
DBMS_RESOURCE_MANAGER.CREATE_PLAN_DIRECTIVE (
    PLAN                      VARCHAR(65535),
    GROUP_OR_SUBPLAN          VARCHAR(65535),
    COMMENT                   VARCHAR(65535) DEFAULT '',
    MGMT_P1                   INT DEFAULT 100,
    UTILIZATION_LIMIT         INT DEFAULT 100,
    MIN_IOPS                  INT DEFAULT 0,
    MAX_IOPS                  INT DEFAULT 100,
    WEIGHT_IOPS               INT DEFAULT 0,
    MAX_NET_BANDWIDTH         INT DEFAULT 100,
    NET_BANDWIDTH_WEIGHT      INT DEFAULT 0);
```

## Parameters

| Parameter | Description |
| ------------------- | -------------------------- |
| PLAN | The name of the resource plan. |
| GROUP_OR_SUBPLAN | The name of the resource usage group or subplan. |
| COMMENT | Comments on plan directives. |
| MGMT_P1 | Specifies the maximum relative CPU utilization that is available when the system is at full load. |
| UTILIZATION_LIMIT | The upper limit of CPU resource usage. The value range of this parameter is \[0, 100\]. `100` indicates that the tenant can use all CPU resources. If the value is `20` indicates that the tenant can use up to 20% of the CPU resources. |
| MIN_IOPS | Refers to the reserved IOPS resources during I/O contention. It is shared by all resource groups. `MIN_IOPS` The sum must not exceed 100. The default value is 0. |
| MAX_IOPS | IOPS resource cap for all resource groups `MAX_IOPS` The total can exceed 100. Default value: 100. |
| WEIGHT_IOPS | IOPS resource weight in case of I/O resource contention. It is the same for all resource groups. `WEIGHT_IOPS` The sum can exceed 100 and will be normalized. The default value is 0. |
| MAX_NET_BANDWIDTH | Specify the maximum network bandwidth resources that can be used. The total can exceed 100. Default value: `100`. |
| NET_BANDWIDTH_WEIGHT | Specifies the weight value of network bandwidth. The sum of the weights can exceed 100, and the bandwidth is allocated proportionally. Default value: `0`. |

## Examples

* Bind the resource group `group1` to the resource plan `DAY`, and specify the CPU resources for the resource group in the resource plan directive.

  ```shell
  obclient> CALL DBMS_RESOURCE_MANAGER.CREATE_PLAN_DIRECTIVE(
      PLAN=>'DAY',
      GROUP_OR_SUBPLAN=>'group1',
      mgmt_p1=>80,
      utilization_limit=>100);
  ```

* Bind the resource group `interactive_group` to the resource plan `daytime`, and specify the resource plan directives for resources such as CPU, IOPS, and network bandwidth within the resource group.

  ```shell
  obclient> CALL DBMS_RESOURCE_MANAGER.CREATE_PLAN_DIRECTIVE(
      PLAN => 'daytime',
      GROUP_OR_SUBPLAN => 'interactive_group' ,
      MGMT_P1 => 30,
      UTILIZATION_LIMIT =>80,
      MIN_IOPS => 30,
      MAX_IOPS => 90,
      WEIGHT_IOPS => 80,
      MAX_NET_BANDWIDTH => 50,
      NET_BANDWIDTH_WEIGHT => 50);
  ```
