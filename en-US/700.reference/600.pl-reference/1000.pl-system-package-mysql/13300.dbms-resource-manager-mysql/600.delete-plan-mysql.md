# DELETE_PLAN

The `DELETE_PLAN` procedure is used to drop a specified plan and all plan directives that reference it.

## Syntax

```sql
DBMS_RESOURCE_MANAGER.DELETE_PLAN (
    plan IN VARCHAR2);
```

## Parameters

`plan` specifies the name of the resource plan to be dropped.

## Examples

```sql
obclient> CALL DBMS_RESOURCE_MANAGER.DELETE_PLAN('NIGHT');
Query OK, 0 rows affected
```
