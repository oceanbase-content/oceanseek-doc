# Overview of DBMS_RESOURCE_MANAGER

The `DBMS_RESOURCE_MANAGER` system package is used to maintain resource usage plans, resource usage groups, and resource plan directives.

## Privileges

The caller must have the `ADMINISTER_RESOURCE_MANAGER` system privilege to execute the procedures in the `DBMS_RESOURCE_MANAGER` system package.

The following table lists the `DBMS_RESOURCE_MANAGER` subprograms supported by the current version of OceanSeek and provides brief descriptions.
