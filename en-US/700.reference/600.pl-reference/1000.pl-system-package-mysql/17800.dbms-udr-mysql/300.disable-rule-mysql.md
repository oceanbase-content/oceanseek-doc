# DISABLE_RULE

The `DISABLE_RULE` procedure is used to disable custom rewrite rules and make them invalid.

## Syntax

```sql
PROCEDURE DISABLE_RULE (
    rule_name          VARCHAR(256));
```

## Parameters

| Parameter | Description |
| --- | --- |
| rule_name | Rule name. |

## Examples

```shell
obclient> CALL DBMS_UDR.DISABLE_RULE('rule1');
Query OK, 0 rows affected

obclient> SELECT 1 FROM DUAL;
+---+
| 1 |
+---+
| 1 |
+---+
1 row in set
```
