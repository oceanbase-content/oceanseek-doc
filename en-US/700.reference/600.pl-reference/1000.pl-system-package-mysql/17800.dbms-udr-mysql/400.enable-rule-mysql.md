# ENABLE_RULE

The `ENABLE_RULE` procedure is used to enable custom rewrite rules and make them effective.

## Syntax

```sql
PROCEDURE ENABLE_RULE (
    rule_name          VARCHAR(256));
```

## Parameters

| Parameter | Description |
| --- | --- |
| rule_name | Rule name. |

## Examples

```shell
obclient> CALL DBMS_UDR.ENABLE_RULE('rule1');
Query OK, 0 rows affected

obclient> SELECT 1 FROM DUAL;
+-------+
| ? + 1 |
+-------+
|     2 |
+-------+
1 row in set
```
