# Overview of DBMS_HYBRID_SEARCH

The `DBMS_HYBRID_SEARCH` system package is used to manage hybrid vector indexes.

## Overview of DBMS_HYBRID_SEARCH Subfunctions

The following table lists the `DBMS_HYBRID_SEARCH` subfunctions supported by the current version of OceanSeek and provides brief descriptions.

| **Subfunction** | **Description** |
| --- | --- |
| [SEARCH](200.search-mysql.md) | This API is used to return search results in JSON format. The returned results are sorted by relevance. |
| [GET_SQL](300.get_sql-mysql.md) | Returns the actual executed SQL statement as a string. |
