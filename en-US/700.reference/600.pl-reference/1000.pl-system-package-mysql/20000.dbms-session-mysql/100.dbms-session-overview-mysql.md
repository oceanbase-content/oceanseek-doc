# Overview of DBMS_SESSION

The `DBMS_SESSION` system package provides access to `ALTER SESSION` SQL statements and other session information from PL. You can use `DBMS_SESSION` to set the client identifier.

## DBMS_SESSION Privilege Description

The `DBMS_SESSION` system package calls user privileges, and does not require `SYS` privileges.

## Overview of DBMS_SESSION Subprograms

The following table lists the `DBMS_SESSION` subprograms supported by OceanSeek and provides brief descriptions.

| subprogram | Description |
| -------------------------- | --------------- |
| [SET_IDENTIFIER](200.set-identifier-mysql.md) | Sets the client ID in the session. |
| [CLEAR_IDENTIFIER](300.clear-identifier-mysql.md) | Clears the identifier. |
