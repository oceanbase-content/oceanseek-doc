# CLEAR_IDENTIFIER

The `CLEAR_IDENTIFIER` procedure sets the identifier for the current session to `NULL`.

## Syntax

```sql
DBMS_SESSION.CLEAR_IDENTIFIER;
```

## Usage instructions

The `CLEAR_IDENTIFIER` procedure can be executed by `PUBLIC`.

## Examples

```sql
obclient> BEGIN
    DBMS_SESSION.CLEAR_IDENTIFIER;
END;
```
