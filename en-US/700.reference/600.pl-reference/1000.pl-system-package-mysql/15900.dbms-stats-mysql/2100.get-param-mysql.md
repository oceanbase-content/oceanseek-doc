# GET_PARAM

The `GET_PARAM` function is used to obtain the default value of a parameter for a procedure in the `DBMS_STATS` system package.

## Syntax

```sql
DBMS_STATS.GET_PARAM (
   pname     IN   VARCHAR2)
 RETURN VARCHAR2;
```

## Parameters

The `pname` parameter specifies the name of the parameter for which you want to retrieve the default value.

## Exceptions

Error code `HY000` indicates an invalid input value.

## Examples

Gets the default value of the `METHOD_OPT` parameter.

```sql
obclient> SELECT DBMS_STATS.GET_PARAM ('METHOD_OPT') FROM DUAL;
+-------------------------------------+
| DBMS_STATS.GET_PARAM ('METHOD_OPT') |
+-------------------------------------+
| FOR ALL COLUMNS SIZE AUTO           |
+-------------------------------------+
1 row in set
```
