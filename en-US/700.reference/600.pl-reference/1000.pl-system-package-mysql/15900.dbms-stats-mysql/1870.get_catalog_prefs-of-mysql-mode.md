# GET_CATALOG_PREFS

The `GET_CATALOG_PREFS` statement is used to retrieve the value of table-level preferences from the catalog.

## Syntax

```sql
DBMS_STATS.GET_CATALOG_PREFS (
    pname           VARCHAR(65535),
    catname         VARCHAR(65535),
    dbname          VARCHAR(65535),
    tabname         VARCHAR(65535)
    ) RETURN VARCHAR(65535);
```

## Parameters

| **Parameter** | **Explanation** |
| ---------- | ---------- |
| pname | Specifies the name of the preference to retrieve. Valid values: <ul><li>`CATALOG_STATS_BATCH_SIZE`: Specifies the maximum number of partitions that can be merged for processing in a single Catalog statistics collection task. `partition`</li></ul> |
| catname | Specifies the catalog name. |
| dbname | Specify the database name. |
| tabname | Specifies the table name. |

## Examples

```shell
obclient> SELECT DBMS_STATS.GET_CATALOG_PREFS (
    'CATALOG_STATS_BATCH_SIZE',
    'hive_catalog',
    'test_oss',
    'lineitem'
    );
```
