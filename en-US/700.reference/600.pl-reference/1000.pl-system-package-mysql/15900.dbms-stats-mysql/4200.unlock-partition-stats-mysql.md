# UNLOCK_PARTITION_STATS

The `UNLOCK_PARTITION_STATS` procedure is used to unlock partition statistics.

## Syntax

```sql
DBMS_STATS.UNLOCK_PARTITION_STATS (
  ownname      VARCHAR2,
  tabname      VARCHAR2,
  partname     VARCHAR2);
```

## Parameters

| Parameter | Explanation |
| ---------- | ----------------------------------- |
| ownname | Username. If the username is set to `NULL`, the current login username will be used by default. |
| tabname | Table name. |
| partname | The name of the (sub)partition. |

## Usage instructions

To call this procedure, you must be the owner of the table. For objects owned by `SYS`, you must be the table owner or have the `SYSDBA` privilege to call this procedure.

## Examples

Unlock the statistics lock on partition `p0` of table `t1` for user `testUser01`.

```sql
obclient> CALL DBMS_STATS.UNLOCK_PARTITION_STATS ('testUser01', 't1', 'p0');
Query OK, 0 rows affected
```
