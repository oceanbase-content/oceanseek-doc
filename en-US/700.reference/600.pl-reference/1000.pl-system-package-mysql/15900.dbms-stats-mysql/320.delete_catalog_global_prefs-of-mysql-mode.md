# DELETE_CATALOG_GLOBAL_PREFS

`DELETE_CATALOG_GLOBAL_PREFS` is used to delete global preferences from the catalog.

## Syntax

```sql
DBMS_STATS.DELETE_CATALOG_GLOBAL_PREFS (
    pname          VARCHAR(65535)
    );
```

## Parameters

| **Parameter** | **Explanation** |
| ---------- | ---------- |
| pname | Specifies the name of the preference to delete. Valid values: <ul><li>`CATALOG_STATS_BATCH_SIZE`: Specifies the maximum number of partitions that can be merged for processing in a single Catalog statistics collection task. `partition`</li></ul> |

## Examples

Delete the global parameter `CATALOG_STATS_BATCH_SIZE`.

```shell
obclient> CALL DBMS_STATS.DELETE_CATALOG_GLOBAL_PREFS('CATALOG_STATS_BATCH_SIZE');
```
