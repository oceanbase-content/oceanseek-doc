# IMPORT_COLUMN_STATS

The `IMPORT_COLUMN_STATS` procedure is used to import column-level statistics.

## Syntax

```sql
DBMS_STATS.IMPORT_COLUMN_STATS (
  ownname          VARCHAR2,
  tabname          VARCHAR2,
  colname          VARCHAR2,
  partname         VARCHAR2 DEFAULT NULL,
  stattab          VARCHAR2,
  statown          VARCHAR2 DEFAULT NULL,
  no_invalidate    BOOLEAN DEFAULT  FALSE,
  force            BOOLEAN DEFAULT FALSE);
```

## Parameters

| Parameter | Explanation |
| --------------- | ------------------------------------------------------------------------------ |
| ownname | Username. If the username is set to `NULL`, the current logged-in username is used by default. |
| tabname | The name of the table to which this column belongs. |
| colname | Column name. |
| partname | The name of the table partition. If the table is partitioned and `partname` is `NULL`, global and partition column statistics are imported. |
| stattab | Specifies the name of the table that imports user statistics. |
| statown | Specifies the username for importing user statistics tables. |
| no_invalidate | Whether to flush the plan cache during statistics collection. Valid values: `TRUE` Indicates that the plan cache is not flushed during statistics collection. |
| force | Whether to forcibly import and ignore the lock status. Default is `FALSE`. If set to `TRUE`, the statistics will still be imported even if they are locked. |

## Exceptions

| Error Code | Description |
| ----------- | ------------------- |
| HY000 | <ul><li>The object does not exist or you do not have sufficient permissions.</li><li>The values in the user information statistics table are invalid or inconsistent.</li><li>The statistics for this object are locked.</li></ul> |

## Usage instructions

To call this procedure, you must be the owner of the table. For objects owned by `SYS`, you must be the table owner or have the `SYSDBA` privilege to call this procedure.

## Examples

Import the statistics of column `col1` from table `tbl1` under user `testUser01` from `test_stat`.

```sql
obclient> CALL DBMS_STATS.IMPORT_COLUMN_STATS ('testUser01', 'tbl1','col1',null, stattab=>'test_stat',
    statown=>'testUser01');
Query OK, 0 rows affected
```
