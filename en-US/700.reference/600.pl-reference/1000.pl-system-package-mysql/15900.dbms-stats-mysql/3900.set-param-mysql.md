# SET_PARAM

The `SET_PARAM` procedure allows you to set default values for parameters in procedures of the `DBMS_STATS` system package. You can use the `GET_PARAM` function to retrieve the default value of a parameter.

## Syntax

```sql
DBMS_STATS.SET_PARAM (
  pname      IN    VARCHAR2,
  pval       IN    VARCHAR2);
```

## Parameters

| Parameter | Description |
| -------- | -------- |
| pname | The name of the parameter. |
| pvalue | Parameter value. |

## Exceptions

| Error Code | Description |
| ----------- | -------------- |
| HY000 | <ul><li>The object does not exist or you do not have sufficient permissions.</li><<li>Invalid values or illegal input values.</li></ul> |

## Usage instructions

* To perform this procedure, you must have the `SYSDBA` role.

* Both parameters in this procedure are of the `VARCHAR2` type, and their values must be enclosed in quotation marks.

* `NULL` and `'NULL'` are different. When `NULL` is used without quotes, it means the parameter will be set to its recommended value; whereas `'NULL'` means the parameter's value will be set to `NULL`.

## Examples

Sets the default value of the `DEGREE` parameter.

```sql
obclient> CALL DBMS_STATS.SET_PARAM('DEGREE','20');
Query OK, 0 rows affected
```
