# LOCK_PARTITION_STATS

The `LOCK_PARTITION_STATS` procedure is used to lock partition statistics.

```sql
DBMS_STATS.LOCK_PARTITION_STATS (
  ownname      VARCHAR2,
  tabname      VARCHAR2,
  partname     VARCHAR2);
```

## Parameters

| Parameter | Explanation |
| ---------- | ----------------------------------- |
| ownname | Username. If the username is set to `NULL`, the current login username will be used by default. |
| tabname | Table name. |
| partname | The name of the table (or subpartition). |

## Usage instructions

To call this procedure, you must be the owner of the table. For objects owned by `SYS`, you must be the table owner or have the `SYSDBA` privilege to call this procedure.

## Examples

Lock the statistics of partition `p0` on table `t1` under user `testUser01`.

```sql
obclient> CALL DBMS_STATS.LOCK_PARTITION_STATS('testUser01', 't1', 'p0');
Query OK, 0 rows affected
```
