# DELETE_SYSTEM_STATS

The `DELETE_SYSTEM_STATS` procedure is used to delete system statistics.

## Syntax

```sql
DBMS_STATS.DELETE_SYSTEM_STATS();
```

## Exceptions

| Error Code | Description |
| ----------- | ------------------ |
| HY000 | The system statistics name entered is incorrect. |

## Usage instructions

* To run this procedure, you must be connected as the specified user or have the `SYSDBA` privilege.

## Examples

You can easily execute the `DBMS_STATS>Delete_SYSTEM_STATS` stored procedure to delete all system statistics, as it does not require any parameters.

```sql
BEGIN
    -- Delete all system statistics.
    DBMS_STATS.DELETE_SYSTEM_STATS();
END;
/
```
