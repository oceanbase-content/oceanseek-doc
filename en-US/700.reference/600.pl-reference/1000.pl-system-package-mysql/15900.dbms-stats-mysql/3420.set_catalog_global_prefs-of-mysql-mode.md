# SET_CATALOG_GLOBAL_PREFS

The `SET_CATALOG_GLOBAL_PREFS` statement is used to set global preference values in the catalog.

## Syntax

```sql
DBMS_STATS.SET_CATALOG_GLOBAL_PREFS (
    pname          VARCHAR(65535),
    pvalue         VARCHAR(65535)
    );
```

## Parameters

| **Parameter** | **Explanation** |
| ---------- | ---------- |
| pname | Specifies the name of the preference to be set. Valid values: <ul><li>`CATALOG_STATS_BATCH_SIZE`: Specifies the maximum number of partitions that can be merged for processing in a single Catalog statistics collection task. `partition`</li></ul> |
| pvalue | Specifies the value of the preference. |

## Examples

Set the global-level `CATALOG_STATS_BATCH_SIZE` value in the catalog to `100`.

```shell
obclient> CALL DBMS_STATS.SET_CATALOG_GLOBAL_PREFS ('CATALOG_STATS_BATCH_SIZE', 100);
```
