# GET_STATS_HISTORY_AVAILABILITY

The `GET_STATS_HISTORY_AVAILABILITY` function is used to obtain the earliest point in time from which historical statistics are currently available. Historical statistics from a time earlier than this cannot be restored.

## Syntax

```sql
DBMS_STATS.GET_STATS_HISTORY_AVAILABILITY
  RETURN TIMESTAMP WITH TIMEZONE;
```

## Examples

Gets the earliest time point in history for which statistics are currently available.

```sql
obclient> SELECT DBMS_STATS.GET_STATS_HISTORY_AVAILABILITY() FROM DUAL;
+---------------------------------------------+
| DBMS_STATS.GET_STATS_HISTORY_AVAILABILITY() |
+---------------------------------------------+
| 2022-12-06 22:00:01.007146                  |
+---------------------------------------------+
1 row in set
```
