# GET_CATALOG_GLOBAL_PREFS

`GET_CATALOG_GLOBAL_PREFS` is used to retrieve the values of global preferences from the catalog.

## Syntax

```sql
DBMS_STATS.GET_CATALOG_GLOBAL_PREFS (
    pname          VARCHAR(65535)
    ) RETURN VARCHAR(65535);
```

## Parameters

| **Parameter** | **Explanation** |
| ---------- | ---------- |
| pname | Specifies the name of the preference to retrieve. Valid values: <ul><li>`CATALOG_STATS_BATCH_SIZE`: Specifies the maximum number of partitions that can be merged for processing in a single Catalog statistics collection task. `partition`</li></ul> |

## Examples

Retrieves global preferences from the catalog.

```shell
obclient> SELECT DBMS_STATS.GET_CATALOG_GLOBAL_PREFS('CATALOG_STATS_BATCH_SIZE');
```

The return result is as follows:

```shell
+-----------------------------------------------------------------+
| DBMS_STATS.GET_CATALOG_GLOBAL_PREFS('CATALOG_STATS_BATCH_SIZE') |
+-----------------------------------------------------------------+
| 100                                                             |
+-----------------------------------------------------------------+
1 row in set
```
