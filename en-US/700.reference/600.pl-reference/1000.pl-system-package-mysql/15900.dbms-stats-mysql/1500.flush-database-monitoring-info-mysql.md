# FLUSH_DATABASE_MONITORING_INFO

The `FLUSH_DATABASE_MONITORING_INFO` procedure is used to flush the memory monitoring information for all tables in the dictionary.

## Syntax

```sql
DBMS_STATS.FLUSH_DATABASE_MONITORING_INFO;
```

## Exceptions

Error code `HY000` indicates insufficient privileges.

## Usage instructions

The `FLUSH_DATABASE_MONITORING_INFO` statement immediately updates the corresponding information in the `*_TAB_STATISTICS` and `*_IND_STATISTICS` views, without waiting for the periodic database refresh. The `GATHER_*_STATS` procedure refreshes monitoring information internally, so there is no need to run it before collecting statistics.

## Examples

```sql
obclient> CALL DBMS_STATS.FLUSH_DATABASE_MONITORING_INFO;
Query OK, 0 rows affected
```
