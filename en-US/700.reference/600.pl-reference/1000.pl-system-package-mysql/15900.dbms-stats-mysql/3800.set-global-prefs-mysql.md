# SET_GLOBAL_PREFS

The `SET_GLOBAL_PREFS` procedure is used to set global statistics preferences.

## Syntax

```sql
DBMS_STATS.SET_GLOBAL_PREFS (
  pname     IN   VARCHAR2,
  pvalue    IN   VARCHAR2);
```

## Parameters

| Parameter | Description |
| -------- | ------------ |
| pname | The name of the Prefs. |
| pvalue | The value of Prefs. |

## Exceptions

| Error Code | Description |
| ----------- | ------------- |
| HY000 | <ul><li>Insufficient privileges.</li><<li>Invalid or illegal input values.</li></ul> |

## Usage instructions

* To call this procedure, you must have the `SYSDBA` privilege.

* Both parameters in this procedure are of the `VARCHAR2` type, and their values must be enclosed in quotation marks.

## Examples

The global default value of `APPROXIMATE_NDV` is set to `FALSE`.

```sql
obclient> CALL DBMS_STATS.SET_GLOBAL_PREFS ('APPROXIMATE_NDV', 'FALSE');
Query OK, 0 rows affected
```
