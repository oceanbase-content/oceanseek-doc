# UNLOCK_CATALOG_TABLE_STAT

`UNLOCK_CATALOG_TABLE_STAT` is used to unlock external table statistics in the catalog.

## Syntax

```sql
DBMS_STATS.UNLOCK_CATALOG_TABLE_STAT (
    catname            VARCHAR(65535),
    dbname             VARCHAR(65535),
    tabname            VARCHAR(65535),
    partname           VARCHAR(65535) DEFAULT NULL,
    stattype           VARCHAR(65535) DEFAULT 'ALL'
    );
```

## Parameters

| **Parameter** | **Explanation** |
| ---------- | ---------- |
| catname | Specifies the catalog name. |
| dbname | Specify the database name. |
| tabname | Specifies the name of the table to lock. |
| partname | Specifies the partition name. `NULL` Represents the entire table. |
| stattype | Specifies the type of information to be unlocked, that is, which category of statistics to unlock. Valid values: <ul><li>`ALL`: Default value. Indicates all statistics (mapped to `TABLE_ALL_TYPE`).</li><li>`DATA`: Indicates data statistics (mapped). `DATA_TYPE`, such as row count or data volume. </li><li>`CACHE`: Indicates cache statistics (mapping). `CACHE_TYPE`</li><li>An empty string is also treated as `ALL`.</li></ul> |

## Examples

Unlock the statistics for the entire `lineitem` table under the `hive_catalog` catalog and `test_oss` database. The unlock type is `ALL`.

```shell
obclient> CALL DBMS_STATS.GATHER_CATALOG_TABLE_STATS (
    'hive_catalog',
    'test_oss',
    'lineitem',
    NULL
    'ALL'
);
```
