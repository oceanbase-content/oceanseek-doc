# DELETE_TABLE_PREFS

The `DELETE_TABLE_PREFS` procedure is used to drop the statistics preferences for a table owned by a specified user.

## Syntax

```sql
DBMS_STATS.DELETE_TABLE_PREFS (
  ownname    IN  VARCHAR2,
  tabname    IN  VARCHAR2,
  pname      IN  VARCHAR2);
```

## Parameters

| Parameter | Description |
| --------- | ----------------------------------- |
| ownname | Username. If the username is set to `NULL`, the current login username will be used by default. |
| tabname | Table name. |
| pname | The name of the Prefs. |

## Exceptions

| Error Code | Description |
| ----------- | ------------- |
| HY000 | <ul><li>Insufficient privileges.</li> <li>Invalid or illegal input values.</li></ul> |

## Usage instructions

* To run this procedure, you must be connected to the database as the specified user or have the `SYSDBA` privilege.

* All parameters in this process are of the `VARCHAR2` type, and their values must be enclosed in quotes.

## Examples

Delete the `DEGREE` column from the `tbl1` table for user `testUser01`.

```sql
obclient> CALL DBMS_STATS.DELETE_TABLE_PREFS('testUser01', 'tbl1', 'DEGREE');
Query OK, 0 rows affected
```
