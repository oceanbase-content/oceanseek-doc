# DELETE_CATALOG_TABLE_PREFS

`DELETE_CATALOG_TABLE_PREFS` is used to drop table-level preferences from the catalog.

## Syntax

```sql
DBMS_STATS.DELETE_CATALOG_TABLE_PREFS (
    catname        VARCHAR(65535),
    dbname         VARCHAR(65535),
    tabname        VARCHAR(65535),
    pname          VARCHAR(65535)
    );
```

## Parameters

| **Parameter** | **Explanation** |
| ---------- | ---------- |
| catname | Specifies the catalog name. |
| dbname | Specify the database name. |
| tabname | Specifies the table name. |
| pname | Specifies the name of the preference to delete. Valid values: <ul><li>`CATALOG_STATS_BATCH_SIZE`: Specifies the maximum number of partitions that can be merged for processing in a single Catalog statistics collection task. `partition`</li></ul> |

## Examples

The table-level preference `CATALOG_STATS_BATCH_SIZE` is dropped.

```shell
obclient> CALL DBMS_STATS.GATHER_CATALOG_TABLE_STATS (
    'hive_catalog',
    'test_oss',
    'lineitem',
    'CATALOG_STATS_BATCH_SIZE'
);
```
