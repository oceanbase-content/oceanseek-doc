# RESET_GLOBAL_PREF_DEFAULTS

The `RESET_GLOBAL_PREF_DEFAULTS` procedure is used to set global preferences to their default values.

## Syntax

```sql
DBMS_STATS.RESET_GLOBAL_PREF_DEFAULTS;
```

## Examples

Restore the default values for all global Prefs.

```sql
obclient> CALL DBMS_STATS.RESET_GLOBAL_PREF_DEFAULTS();
Query OK, 0 rows affected
```
