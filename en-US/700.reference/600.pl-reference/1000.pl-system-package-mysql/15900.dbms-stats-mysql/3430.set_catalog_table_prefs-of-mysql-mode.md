# SET_CATALOG_TABLE_PREFS

The `SET_CATALOG_TABLE_PREFS` statement is used to set the value of table-level preferences in the catalog.

## Syntax

```sql
DBMS_STATS.SET_CATALOG_TABLE_PREFS (
    catname        VARCHAR(65535),
    dbname         VARCHAR(65535),
    tabname        VARCHAR(65535),
    pname          VARCHAR(65535),
    pvalue         VARCHAR(65535)
    );
```

## Parameters

| **Parameter** | **Explanation** |
| ---------- | ---------- |
| catname | Specifies the catalog name. |
| dbname | Specify the database name. |
| tabname | Specifies the table name. |
| pname | Specifies the name of the preference to be set. Valid values: <ul><li>`CATALOG_STATS_BATCH_SIZE`: Specifies the maximum number of partitions that can be merged for processing in a single Catalog statistics collection task. `partition`</li></ul> |
| pvalue | Specifies the value of the preference. |

## Examples

Set the `CATALOG_STATS_BATCH_SIZE` value to `100` for the `lineitem` table under the `hive_catalog` catalog and `test_oss` database.

```shell
obclient> CALL DBMS_STATS.GATHER_CATALOG_TABLE_STATS (
    'hive_catalog',
    'test_oss',
    'lineitem',
    'CATALOG_STATS_BATCH_SIZE',
    100
);
```
