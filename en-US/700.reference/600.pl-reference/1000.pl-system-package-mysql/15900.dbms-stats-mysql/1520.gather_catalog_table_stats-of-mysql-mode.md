# GATHER_CATALOG_TABLE_STATS

`GATHER_CATALOG_TABLE_STATS` is used to collect statistics on external tables in the catalog.

## Syntax

```sql
DBMS_STATS.GATHER_CATALOG_TABLE_STATS (
    catname            VARCHAR(65535),
    dbname             VARCHAR(65535),
    tabname            VARCHAR(65535),
    partname           VARCHAR(65535) DEFAULT NULL,
    estimate_percent   DECIMAL(30, 10) DEFAULT AUTO_SAMPLE_SIZE,
    sample_type        VARCHAR(65535) DEFAULT NULL,
    method_opt         VARCHAR(65535) DEFAULT DEFAULT_METHOD_OPT,
    degree             DECIMAL(30, 10) DEFAULT NULL,
    granularity        VARCHAR(65535) DEFAULT DEFAULT_GRANULARITY,
    force              BOOLEAN DEFAULT FALSE
    );
```

## Parameters

| **Parameter** | **Explanation** |
| ------------------ | ---------- |
| catname | Specifies the catalog name. |
| dbname | Specify the database name. |
| tabname | Specifies the table name. |
| partname | Specifies the partition name. `NULL` Represents the entire table. |
| estimate_percent | Specifies the sampling percentage. 100 indicates a full scan. |
| sample_type | Specifies the sampling method. Valid values: <ul><li>Empty string. `''` or `NULL`: Indicates that the sampling method is not explicitly specified, and the system will adapt based on the underlying storage.</li><li>`ROW`: Indicates row sampling, which samples data on a row basis. `CSV` the sampling method specific to the format. </li><li>`BLOCK`: Indicates block sampling, which samples data in units of the smallest logical storage unit in the file. <ul><li>For the Parquet format, the smallest unit is a page, so sampling is performed on a page basis.</li><li>For the ORC format, the smallest unit is a row group, so sampling is performed on a row group basis.</li></ul> </li><li>`FILE`: Indicates file sampling, where the entire file is sampled as a whole.</li></ul> |
| method_opt | Specifies the method for collecting statistics on columns. Default value: `FOR ALL COLUMNS SIZE AUTO`. Only the following characters are allowed: `FOR ALL` Syntax. For details, see [method_opt](#method_opt). |
| degree | Specifies the degree of parallelism. `NULL` Indicates to use the default value. |
| granularity | Specifies the collection granularity. Valid values: <ul><li>`DEFAULT`: Collects global and partition-level statistics. </li><li>`GLOBAL`: Collects global statistics.</li><li>`PARTITION`: Collects partition-level statistics. </li><li>`ALL`: Collects all statistics (subpartition, partition, and global).</li></ul> |
| force | Specifies whether to force collection (ignoring statistics lock and freshness check). |

### method_opt

`method_opt` can only be one of the following options, or a combination of both:

* `FOR ALL COLUMNS [size_clause]`: where `size_clause` is defined as `size_clause := SIZE {integer | REPEAT | AUTO | SKEWONLY}`.

  * `integer`: The number of histogram buckets. The valid range is [1,2048].
  * `REPEAT`: Collects histograms only for columns that already have histograms.
  * `AUTO`: Determines the columns for which histograms should be collected based on data distribution and column workload.
  * `SKEWONLY`: Determines the columns for which histograms are collected based on their data distribution.

* `FOR COLUMNS [column_clause]`: where `column_clause` is defined as `column_clause := column_name | extension`.

  * `column_name`: the name of the column.
  * `extension`: A column group or expression in the format `(column_name, colume_name [, ...])`.

## Examples

Collect statistics on the `lineitem` table under the Catalog name `hive_catalog` and Database name `test_oss`. Specifically:

* Setting the partition name to `NULL` indicates the entire table.
* Setting the sampling percentage to 100 indicates a full sample.
* The sampling method is set to `BLOCK`, indicating block sampling.
* Column statistics collection method is set to `NULL`, indicating the use of the default.
* The degree of parallelism is set to 32.

```shell
obclient> CALL DBMS_STATS.GATHER_CATALOG_TABLE_STATS (
    'hive_catalog',
    'test_oss',
    'lineitem',
    NULL,
    100,
    'BLOCK',
    NULL,
    32
);
```
