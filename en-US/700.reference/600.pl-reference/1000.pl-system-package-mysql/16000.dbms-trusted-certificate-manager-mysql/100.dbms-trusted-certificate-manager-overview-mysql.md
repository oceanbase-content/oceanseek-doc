# Overview of DBMS_TRUSTED_CERTIFICATE_MANAGER

The `DBMS_TRUSTED_CERTIFICATE_MANAGER` system package is used to add, delete, and modify CA root certificates trusted by the OBserver cluster for RPC security authentication.

## Privileges

The caller must be the sys tenant to call system packages.

## Overview of the DBMS_TRUSTED_CERTIFICATE_MANAGER Subprogram

The following table lists the `DBMS_TRUSTED_CERTIFICATE_MANAGER` subprograms supported by OceanBase AI Database and provides brief descriptions.

| subprogram | Description |
| --------- | ----------------------------------------- |
| [ADD_TRUSTED_CERTIFICATE](200.add-trusted-certificate-mysql.md) | Add a CA root certificate so that components such as OBServer clusters or OMS, which use digital certificates issued by this certificate, can securely pass RPC authentication and connect to the cluster. |
| [DELETE_TRUSTED_CERTIFICATE](300.delete-trusted-certificat-mysql.md) | Remove a CA root certificate, preventing OBServer clusters or components such as OMS that use digital certificates issued by this certificate from continuing to connect to the cluster. |
| [UPDATE_TRUSTED_CERTIFICATE](400.update-trusted-certificat-mysql.md)	| Updates the information about the CA root certificate trusted by the OBServer cluster.           |
