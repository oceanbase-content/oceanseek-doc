# DELETE_TRUSTED_CERTIFICATE

The `DELETE_TRUSTED_CERTIFICATE` statement is used to remove a CA root certificate, preventing OBServer clusters or components such as OMS that use digital certificates issued by this certificate from continuing to connect to the cluster.

## Syntax

```sql
PROCEDURE DELETE_TRUSTED_CERTIFICATE(common_name VARCHAR(256));
```

## Parameters

| **Parameter** | **Description** |
| ------------ | ---------------------------------------- |
| common_name | The unique identifier of a certificate, used to distinguish between different certificates. |

## Examples

```shell
obclient>CALL DBMS_TRUSTED_CERTIFICATE_MANAGER.DELETE_TRUSTED_CERTIFICATE('MySQL_Server_5.7.2_Auto_Geanrateed_C_Certificate');
Query OK, 0 rows affected
```
