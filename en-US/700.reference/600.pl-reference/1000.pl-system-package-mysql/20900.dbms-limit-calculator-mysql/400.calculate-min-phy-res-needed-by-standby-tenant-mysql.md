# CALCULATE_MIN_PHY_RES_NEEDED_BY_STANDBY_TENANT

`CALCULATE_MINPHY_RES_NEEDED_BY_STANDBY_TENANT` specifies the primary tenant and the number of resource units for the standby tenant to be created, allowing you to calculate the minimum physical resources required per unit.

## Syntax

```sql
DBMS_OB_LIMIT_CALCULATOR.CALCULATE_MIN_PHY_RES_NEEDED_BY_STANDBY_TENANT(primary_tenant_id           IN  INTEGER,
                                                                        standby_tenant_unit_num     IN  INTEGER);
```

## Parameters

| **Parameter** | **Note** |
| ------------------ | ----------------------------------------------------- |
| primary_tenant_id | The tenant ID of the primary tenant. |
| standby_tenant_unit_num | The number of standby tenant units. |

## Examples

You can specify the number of primary tenants and the estimated number of standby tenants, then use the following command to calculate the physical resources required per unit.

```shell
obclient> CALL DBMS_OB_LIMIT_CALCULATOR.CALCULATE_MIN_PHY_RES_NEEDED_BY_STANDBY_TENANT(PRIMARY_TENANT_ID => 1001, STANDBY_TENANT_UNIT_NUM => 2);
```
