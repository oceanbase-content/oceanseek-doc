# Overview of DBMS_OB_LIMIT_CALCULATOR

The `DBMS_OB_LIMIT_CALCULATOR` system package is used to obtain the current resource usage of a cluster, which can then be used to plan operations such as scaling, node replacement, and standby tenant creation.

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>This system package can only be used in the SYS tenant.</p>
</main>

## Overview of the DBMS_OB_LIMIT_CALCULATOR Subprogram

The following table lists the `DBMS_OB_LIMIT_CALCULATOR` subprograms supported by OceanBase AI Database and provides brief descriptions.

| subprogram | Description |
| ----------------------- | --------------------- |
| [CALCULATE_MIN_PHY_RES_NEEDED_BY_UNIT](200.calculate-min-phy-res-needed-by-unit-mysql.md) | You can specify a tenant and node to calculate the minimum physical resources required on a particular node. |
| [CALCULATE_MIN_PHY_RES_NEEDED_BY_LOGIC_RES](300.calculate-min-phy-res-needed-by-loglc-res-mysql.md) | You can specify the logical resource types and quantities required by a tenant to calculate the physical resources needed to accommodate them. |
|[CALCULATE_MIN_PHY_RES_NEEDED_BY_STANDBY_TENANT](400.calculate-min-phy-res-needed-by-standby-tenant-mysql.md)|You can specify the primary tenant and the number of resource units for the standby tenant to be created, so that the system calculates the physical resources required per unit.|
