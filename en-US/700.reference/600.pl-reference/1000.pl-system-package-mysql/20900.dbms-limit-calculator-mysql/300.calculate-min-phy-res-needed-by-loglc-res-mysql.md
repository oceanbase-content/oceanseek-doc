# CALCULATE_MIN_PHY_RES_NEEDED_BY_LOGIC_RES

`CALCULATE_MINPHY_RES_NEEDED_BY_LOGIC_RES` is used to specify the tenant's logical resource type and required quantity, allowing you to calculate the physical resources needed to accommodate these logical resources.

## Syntax

```sql
DBMS_OB_LIMIT_CALCULATOR.CALCULATE_MIN_PHY_RES_NEEDED_BY_LOGIC_RES(args IN VARCHAR);
```

## Parameters

where args is a string in the following format:

```sql
'ls: 1, tablet: 20000';
'ls: 10';
'tablet: 20000'
```

| **Parameter** | **Note** |
| ------------------ | ----------------------------------------------------- |
| ls | Specifies the number of logical resources ls required. |
| tablet | Specifies the number of logical resource tablets required. |

## Examples

You can calculate the required physical resources using the following method.

```shell
obclient> CALL DBMS_OB_LIMIT_CALCULATOR.CALCULATE_MIN_PHY_RES_NEEDED_BY_LOGIC_RES("LS: 15, TABLET:40000");
+------------------------+-------------+
| PHYSICAL_RESOURCE_NAME | MIN_VALUE   |
+------------------------+-------------+
| MEMSTORE               |           0 |
| MEMORY                 |  4194304000 |
| DATA_DISK              |           0 |
| CLOG_DISK              | 10737418240 |
| CPU                    |           0 |
+------------------------+-------------+
5 rows in set (0.003 sec)
```
