# CALCULATE_MIN_PHY_RES_NEEDED_BY_UNIT

The `CALCULATE_MINPHY_RES_NEEDED_BY_UNIT` clause is used to specify a tenant and node, and can calculate the minimum physical resources required on a node.

## Syntax

```sql
DBMS_OB_LIMIT_CALCULATOR.CALCULATE_MIN_PHY_RES_NEEDED_BY_UNIT(tenant_id     IN INTEGER,
                                                              server        IN VARCHAR);
```

## Parameters

| **Parameter** | **Note** |
| ------------------ | ----------------------------------------------------- |
| tenant_id | Specifies the tenant ID to be queried. |
| server | Specify the IP address of the server. |

## Examples

You can run the following command to calculate the minimum physical resources required for each unit.

```shell
obclient> CALL DBMS_OB_LIMIT_CALCULATOR.CALCULATE_MIN_PHY_RES_NEEDED_BY_UNIT(TENANT_ID => 1001, SERVER => "1.1.1.1:12104");
+------------------------+-------------+

| MEMSTORE               |           0 |
| MEMORY                 |  4194304000 |
| DATA_DISK              |           0 |
| CLOG_DISK              | 10737418240 |
| CPU                    |           0 |
+------------------------+-------------+
5 rows in set (0.003 sec)
```
