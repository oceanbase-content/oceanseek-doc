# Overview of DBMS_ASYNC_INDEX

The `DBMS_ASYNC_INDEX` system package is used to manage asynchronous indexes and provides an interface for manually triggering a major compaction. It applies to tables that have created asynchronous full-text indexes (`ASYNC FULLTEXT`) or asynchronous search indexes (`ASYNC SEARCH INDEX`).

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This system package is supported starting from V4.6.2.1.</p>
</main>

## Overview of the DBMS_ASYNC_INDEX Subprogram

The following table lists the `DBMS_ASYNC_INDEX` subprograms supported by the current version of OceanSeek and provides brief descriptions.

| **Subprogram** | **Description** |
| --- | --- |
| [FORCEMERGE](300.forcemerge-mysql.md) | Manually trigger a major compaction for asynchronous indexes on a specified table. |
