# FORCEMERGE

`FORCEMERGE` is used to manually trigger a major compaction for asynchronous indexes on a specified table, integrating incremental data with baseline data to optimize storage and improve query efficiency.

## Syntax

```sql
PROCEDURE FORCEMERGE(
    IN table_name VARCHAR(65535)
);
```

## Parameters

| **Parameter** | **Description** | **Type** | **Nullable** |
| --- | --- | --- | --- |
| table_name | The name of the target table for which an asynchronous index is created. | VARCHAR(65535) | No |

## Examples

```sql
CALL DBMS_ASYNC_INDEX.FORCEMERGE('doc_async');
```
