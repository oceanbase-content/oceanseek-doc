# MODIFY_SNAPSHOT_SETTINGS

The `MODIFY_SNAPSHOT_SETTINGS` procedure is used to modify the WORKLOAD_REPOSITORY configuration and is available only in the SYS tenant.

## Syntax

```sql
DBMS_WORKLOAD_REPOSITORY.MODIFY_SNAPSHOT_SETTINGS(
   retention          INT    DEFAULT  NULL,
   interval           INT    DEFAULT  NULL);
```

## Parameters

| **Parameter** | **Note** |
| --- | --- |
| retention | The retention period for a snapshot. Snapshots older than this period will be automatically deleted. The unit is minutes. Value range: [1,440 minutes (1 day), 52,560,000 minutes (100 years)]. <ul><li>If the value is set to 0, snapshots are retained permanently. The retention period is set to 57,816,000 minutes (110 years).  </li><li>If the value is set to NULL, the original retention period is retained. </li></ul> |
| interval | The interval between snapshots, in minutes. Value range: [10 minutes, 525600 minutes (1 year)].<ul><li>If the value is set to 0, automatic and manual snapshots are disabled, and a large system-defined value (110 years) is used as the retention period.</li><li>If the value is set to NULL, the current interval setting is retained.</li></ul> |

## Examples

```shell
obclient> CALL DBMS_WORKLOAD_REPOSITORY.MODIFY_SNAPSHOT_SETTINGS('2265','16');
Query OK, 0 rows affected
```
