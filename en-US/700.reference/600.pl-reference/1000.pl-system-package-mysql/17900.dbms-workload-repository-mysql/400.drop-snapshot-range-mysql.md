# DROP_SNAPSHOT_RANGE

The `DROP_SNAPSHOT_RANGE` procedure is used to drop snapshots within a specified range. It is available only in the SYS tenant.

## Syntax

```sql
DBMS_WORKLOAD_REPOSITORY.DROP_SNAPSHOT_RANGE(
    low_snap_id    INT,
    high_snap_id   INT
);
```

## Parameters

| **Parameter** | **Note** |
| --- | --- |
| low_snap_id | The ID of the low snapshot to be deleted. |
| high_snap_id | The ID of the high snapshot to be deleted. |

## Examples

```shell
obclient> CALL DBMS_WORKLOAD_REPOSITORY.DROP_SNAPSHOT_RANGE('123','456');
Query OK, 0 rows affected
```
