# CREATE_AI_MODEL

The `CREATE_AI_MODEL` procedure is used to create an AI model object, requiring the specification of attributes such as the model's name and type.

## Syntax

```sql
PROCEDURE create_ai_model(
    IN name VARCHAR(128), 
    IN params JSON);
```

## Examples

Create an AI model object of type `dense_embedding` and the large model `text-embedding-v2`.

```sql
CALL DBMS_AI_SERVICE.CREATE_AI_MODEL (
'my_ai_model_1', '{
    "type": "dense_embedding",
    "model_name": "text-embedding-v2"
  }');
```
