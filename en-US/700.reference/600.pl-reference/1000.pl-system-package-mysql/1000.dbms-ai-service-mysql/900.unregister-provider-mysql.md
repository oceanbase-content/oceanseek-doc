# UNREGISTER_PROVIDER

The `UNREGISTER_PROVIDER` procedure is used to unregister a registered vendor configuration.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This process is supported starting from V4.6.2.1.</p>
</main>

## Syntax

```sql
PROCEDURE unregister_provider(
    IN provider_name VARCHAR(256));
```

## Parameters

| Parameter | Description | Type | Value range | Nullable |
| ------ | ------ | ------ | ---------- | ---------- |
| provider_name | Vendor name. | VARCHAR(256) | Up to 256 bytes | NO |


<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>If the vendor configuration is still referenced by a gateway, the cancellation will fail. Please delete the gateway that references this vendor before performing this procedure.</p>
</main>

## Examples

```sql
CALL DBMS_AI_SERVICE.UNREGISTER_PROVIDER('ob-mass');
```
