# Overview of DBMS_AI_SERVICE

The `DBMS.AI_SERVICE` system package is used to manage AI services, including AI model objects and AI model service endpoint objects from the legacy API, as well as vendor configurations, model parameters, and gateway configurations from the new API.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>New subprograms related to vendor configuration, model parameters, and gateway configuration are available starting from V4.6.2.1. The legacy interfaces <code>CREATE_AI_MODEL</code>, <code>DROP.AI_MODEL</code>, <code>CREATE_AI_MODEL_ENDPOINT</code>, <code>ALTER_AI_MODEL_ENDPOINT</code>, and <code>DROP_AI_MODEL_ENDPOINT</code> are fully retained, so existing usage can continue without interruption.</p>
</main>

## Configuration object description

| **Object** | **Note** | **Management Subprograms** |
| --- | --- | --- |
| AI Model/Endpoint (Legacy) | Manage remote model access by using model names and endpoint URLs | `CREATE_AI_MODEL`, `DROP_AI_MODEL`, `CREATE_AI_MODEL_ENDPOINT`, `ALTER_AI_MODEL_ENDPOINT`, and `DROP_AI_MODEL_ENDPOINT` |
| Vendor Configuration (New) | Manage vendor connection information and access credentials | `REGISTER_PROVIDER`, `ALTER_PROVIDER`, and `UNREGISTER_PROVIDER` |
| Model Parameter (New) | Set and manage parameters for each model, such as the maximum number of tokens and temperature, to customize model behavior. | `ALTER_MODEL_PROFILE`(Creating or modifying parameters), `DROP_MODEL_PROFILE`>Delete Parameter Configuration) |
| Gateway Configuration (New) | Manage weighted routing and circuit breaking disaster recovery for multiple endpoints | `CREATE_AI_GATEWAY`, `ALTER_AI_GATEWAY`, and `DROP_AI_GATEWAY` |
