# DROP_MODEL_PROFILE

The `DROP_MODEL_PROFILE` procedure is used to drop a registered model parameter.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This procedure is supported starting with V4.6.2.1.</p>
</main>

## Syntax

```sql
PROCEDURE drop_model_profile(
    IN model VARCHAR(512));
```

## Parameters

| Parameter | Description | Type | Value range | Nullable |
| ------ | ------ | ------ | ---------- | ---------- |
| model | The full model name, in the format of `provider/model_name`. | VARCHAR(512) |  | NO |

## Examples

```sql
CALL DBMS_AI_SERVICE.DROP_MODEL_PROFILE('aliyun/qwen-plus');
```
