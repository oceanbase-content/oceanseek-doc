# DROP_AI_GATEWAY

The `DROP_AI_GATEWAY` procedure is used to drop a specified gateway.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This procedure is supported starting from V4.6.2.1.</p>
</main>

## Syntax

```sql
PROCEDURE drop_ai_gateway(
    IN gateway_name VARCHAR(256));
```

## Parameters

| Parameter | Description | Type | Value range | Nullable |
| ------ | ------ | ------ | ---------- | ---------- |
| gateway_name | Gateway name. | VARCHAR(256) | Up to 256 bytes | NO |

## Examples

```sql
CALL DBMS_AI_SERVICE.DROP_AI_GATEWAY('prod_gateway');
```
