# CREATE_AI_MODEL_ENDPOINT

The `CREATE_AI_MODEL_ENDPOINT` procedure is used to create an endpoint for accessing an AI model object. You must specify the endpoint's address, access key, model provider, and other attributes.

## Syntax

```sql
PROCEDURE create_ai_model_endpoint(
    IN name VARCHAR(128), 
    IN params JSON);
```

## Examples

Create an AI model object of type `dense_embedding` and the large model `text-embedding-v2`.

```sql
CALL DBMS_AI_SERVICE.CREATE_AI_MODEL_ENDPOINT (
  'my_model_endpoint1', '{
    "ai_model_name": "my_model1",
    "url": "https://api.deepseek.com/chat/completions",
    "access_key": "sk-xxxxxxxxxxxx",
    "request_model_name": "deepseek-chat",
    "provider": "deepseek"
  }');
```
