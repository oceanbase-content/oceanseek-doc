# ALTER_AI_GATEWAY

The `ALTER_AI_GATEWAY` procedure is used to completely replace the existing gateway configuration.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This process is supported starting from V4.6.2.1.</p>
</main>

## Syntax

```sql
PROCEDURE alter_ai_gateway(
    IN gateway_name VARCHAR(256),
    IN json_params JSON);
```

## Parameters

| Parameter | Description | Type | Value range | Nullable |
| ------ | ------ | ------ | ---------- | ---------- |
| gateway_name | Gateway name. | VARCHAR(256) | Up to 256 bytes | NO |
| json_params | Gateway configuration, which must be a JSON object. | JSON | The description of the <code>json_params</code> field is consistent with that in [CREATE_AI_GATEWAY](1200.create-ai-gateway-mysql.md). | NO |

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>This process has a full replacement semantics and does not support partial addition or deletion of endpoints. You must pass the complete <code>endpoints</code> configuration when calling it.</p>
</main>

## Examples

```sql
CALL DBMS_AI_SERVICE.ALTER_AI_GATEWAY('prod_gateway', '{
  "endpoints": [
    {"name":"ep1","model":"aliyun/qwen-plus","weight":50},
    {"name":"ep2","model":"siliconflow/qwen-plus","weight":50}
  ]
}');
```
