# DISABLE_PERMISSION

The `DBMS_JAVA.DISABLE_PERMISSION` procedure is used to disable a specified Java permission record based on its primary key.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This subprogram is available starting with OceanSeek V4.6.3. </p>
</main>

## Syntax

```sql
DBMS_JAVA.DISABLE_PERMISSION(IN key BIGINT);
```

## Parameters

| **Parameter** | **Note** |
| -------- | ------------ |
| key | The primary key of the privilege record to be disabled, which is returned when granting or restricting privileges. `key` Value. |

## Usage instructions

- Before calling `DBMS_JAVA.DISABLE_PERMISSION`, ensure that the tenant parameter `ob_enable_java_udf` is enabled. Otherwise, an unsupported error will be returned.
- Only the root user can operate Java permissions. Other users will receive an error indicating insufficient permissions when calling them.
- Disabled privilege records are retained and can be re-enabled using `DBMS_JAVA.ENABLE_PERMISSION`.
