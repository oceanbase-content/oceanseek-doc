# Overview of DBMS_JAVA

`DBMS_JAVA` is used to integrate and manage Java programs within a database, supporting the implementation of Java stored procedures, functions, and security policies.

## DBMS_JAVA Privilege Description

Java UDF access is prohibited. The `DBMS_JAVA` package no longer supports accessing files or networks.

## Overview of DBMS_JAVA Subprograms

The following table lists the `DBMS_JAVA` subprograms supported by OceanBase AI Database and provides brief descriptions.

| **Subprogram** | **Description** |
| ----------------------------------------- | ------------------------------------------------ |
| [LOADJAVA](200.loadjava-mysql.md) | Used to upload a JAR package as an external resource to the OBServer. |
| [DROPJAVA](300.dropjava-mysql.md) | Deletes an uploaded external resource JAR package. |
| [GRANT_PERMISSION](400.grant-permission-mysql.md) | Grants Java privileges to the specified user or role. |
| [RESTRICT_PERMISSION](500.restrict-permission-mysql.md) | Used to set Java permission limits for a specified user or role. |
| [REVOKE_PERMISSION](600.revoke-permission-mysql.md) | Retrieves Java permissions for a specified user or role. |
| [DISABLE_PERMISSION](700.disable-permission-mysql.md) | Used to disable specified Java permission records based on the primary key in the permission record. |
| [ENABLE_PERMISSION](800.enable-permission-mysql.md) | Used to enable specified Java permission recording based on the primary key in permission records. |
| [DELETE_PERMISSION](900.delete-permission-mysql.md) | Deletes a specified Java permission record based on its primary key. |
