# DROPJAVA

`DBMS_JAVA.DROPJAVA` is used to drop an uploaded external resource JAR package.

## Syntax

```sql
DBMS_JAVA.DROPJAVA(IN jar_name VARCHAR(65535));
```

`jar_name` is the `jar_name` for `loadjava` during upload.

## Examples

Run the following command to delete the uploaded external resource JAR package:

```shell
obclient> CALL DBMS_JAVA.DROPJAVA('my_add_jar');
```
