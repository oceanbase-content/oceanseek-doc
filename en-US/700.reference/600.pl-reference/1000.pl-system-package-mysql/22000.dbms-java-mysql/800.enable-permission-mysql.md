# ENABLE_PERMISSION

`DBMS_JAVA.ENABLE_PERMISSION` is used to enable specified Java permission records based on the primary key in the permission record.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This subprogram is available starting with OceanSeek V4.6.3. </p>
</main>

## Syntax

```sql
DBMS_JAVA.ENABLE_PERMISSION(IN key BIGINT);
```

## Parameters

| **Parameter** | **Note** |
| -------- | ------------------------------------------------------------------- |
| key | The primary key of the privilege record to be enabled, which is returned when granting or restricting privileges. `key` Value. |

## Usage instructions

- Before calling `DBMS_JAVA.ENABLE_PERMISSION`, ensure that the tenant parameter `ob_enable_java_udf` is enabled. Otherwise, an unsupported error will be returned.
- Only the root user can operate Java permissions. Other users will receive an insufficient permission error when calling.
- This subprogram can re-enable a privilege that has been disabled by `DBMS_JAVA.DISABLE_PERMISSION`.
