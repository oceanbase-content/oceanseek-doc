# DELETE_PERMISSION

The `DBMS_JAVA_DELETE_PERMISSION` procedure is used to delete a specified Java permission record from the privilege records based on its primary key.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This subprogram is available starting with OceanBase AI Database V4.6.3.</p>
</main>

## Syntax

```sql
DBMS_JAVA.DELETE_PERMISSION(IN key BIGINT);
```

## Parameters

| **Parameter** | **Note** |
| -------- | ------------------------------------------------------------------- |
| key | Primary key of the privilege record to be deleted, which is returned when granting or restricting privileges. `key` Value. |

## Usage instructions

- Before calling `DBMS_JAVA_DELETE_PERMISSION`, ensure that the tenant parameter `ob_enable_java_udf` is enabled. Otherwise, an unsupported error will be returned.
- Only the root user can operate Java permissions. Other users will receive an error indicating insufficient permissions when they attempt to call it.
- The delete operation permanently removes the permission record. To temporarily disable a permission, use `DBMS_JAVA.DISABLE_PERMISSION`.
