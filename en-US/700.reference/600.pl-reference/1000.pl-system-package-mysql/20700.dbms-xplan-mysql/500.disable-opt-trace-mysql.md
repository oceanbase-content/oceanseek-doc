# DISABLE_OPT_TRACE

The `DISABLE_OPT_TRACE` procedure is used to disable the end-to-end tracing feature for the optimizer of the current session.

## Syntax

```sql
DBMS_XPLAN.DISABLE_OPT_TRACE;
```

## Examples

Disables optimizer tracing for the current session.

```shell
obclient> CALL DBMS_XPLAN.DISABLE_OPT_TRACE();
Query OK, 0 rows affected
```
