# DISPLAY_ACTIVE_SESSION_PLAN

The `DISPLAY_ACTIVE_SESSION_PLAN` function is used to display the real-time plan details of a specified session.

## Function definition

```sql
DBMS_XPLAN.DISPLAY_ACTIVE_SESSION_PLAN(
           session_id   INTEGER DEFAULT 0,
           format       VARCHAR2  DEFAULT  'TYPICAL',
           svr_ip       VARCHAR2  DEFAULT  NULL,      -- default value: server connected by client
           svr_port     INTEGER DEFAULT 0           -- default value: server connected by client
           )
return DISPLAY_ACTIVE_SESSION_PLAN;
```

## Parameters

| Parameter | Description |
| --- | --- |
| session_id | The session ID of the user connection. Note that this is not the proxy session ID but the server session ID. |
| format | Specifies the plan format. Valid values: <ul><li>`'BASIC'`: Displays a small amount of information, such as the operator ID, operator name, operator remarks, and expression information. </li><li>`'TYPICAL'`: Displays basic information, such as the operator ID, operator name, operator remarks, optimizer-estimated output rows, optimizer-estimated execution time, and expression information. If the plan has been executed, it also displays the actual feedback from the first execution, such as the actual number of rows and cost.</li><li>`'ALL'`: Displays comprehensive plan information, such as operator ID, operator name, operator remarks, optimizer-estimated output rows, optimizer-estimated execution time, expression information, effective hints, Query Block Name Trace information, outline information, base table optimization information, constant parameterization information, constraint information, and plan notes. </li><li>`'ADVANCED'`: Displays comprehensive plan information, which is consistent with the 'ALL' parameter. Additionally, it shows hierarchical tree structure details for complex plans.</li></ul> |
| svr_ip | The IP address of the node where the plan resides. By default, it is the IP address of the node to which the session is connected. |
| svr_port | Port number of the node where the plan resides. By default, it is the port number of the node to which the session is connected. |
