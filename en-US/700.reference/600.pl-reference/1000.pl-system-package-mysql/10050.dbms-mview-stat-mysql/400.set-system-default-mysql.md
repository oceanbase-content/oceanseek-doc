# SET_SYSTEM_DEFAULT

`SET_SYSTEM_DEFAULT` sets the system default value for the refresh statistics parameter.

## Syntax

```sql
PROCEDURE set_system_default(
    IN     parameter_name         VARCHAR(65535),
    IN     value                  VARCHAR(65535));
```

## Parameters

| **Parameter** | **Note** |
| ------------------ | -------------------------------------------------------------------------------------------------- |
| parameter_name | Parameter name. Valid values: <ul><li>COLLECTION_LEVEL: the statistics collection level. The system default is TYPICAL.</li></ul><ul><li>RETENTION_PERIOD: the number of days for which statistics are retained. The system default is 31 days.</li></ul> |
| value | <p>When the parameter name is COLLECTION_LEVEL:<ul><li>NONE: No statistics are collected.</ul></li><ul><li>TYPICAL: Basic refresh statistics are collected.</ul></li><ul><li>ADVANCED: Detailed refresh statistics are collected.</ul></li><ul><li>NULL: The system default value, which is TYPICAL, is used.</li></ul></p> <p>When the parameter name is RETENTION_PERIOD, the parameter value indicates the number of days for retaining statistics: 1 to 365000.<ul><li>NULL: The system default value is used.</ul></li><ul><li>-1: Statistics are retained permanently.</ul></li></br> </p>|
