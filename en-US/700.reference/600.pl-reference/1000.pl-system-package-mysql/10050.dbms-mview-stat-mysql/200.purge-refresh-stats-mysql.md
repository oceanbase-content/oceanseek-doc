# PURGE_REFRESH_STATS

The `PURGE_REFRESH_STATS` statement is used to forcibly and automatically purge materialized view refresh statistics that exceed the specified retention period.
## Syntax

```sql
PROCEDURE purge_refresh_stats(
    IN     mv_name                VARCHAR(65535),
    IN     retention_period       INT);
```

## Parameters

| **Parameter** | **Note** |
| ------------------ | ----------------------------------------------------- |
| mv_name | The name of the materialized view.<ul><li>If this parameter is set to NULL, the operation is performed on all materialized views.</li></ul> |
| retention_period | Specifies the number of days for which statistics are retained. The value range is from 1 to 365,000 days. Statistical records will be automatically deleted after the specified number of days. The system default is 31 days.<ul><li>If the value is NULL, the default cleanup strategy of the automatic statistics purge mechanism is used.</ul></li><ul><li>If set to -1, all related statistical information records will be deleted.</ul></li> |
