# Overview of DBMS_MVIEW_STATS

The `DBMS_MVIEW_STATS` system package provides users with an interface to manage the collection and retention of statistics for materialized view refresh operations.

## Overview of the DBMS_MVIEW_STATS Subprogram

The following table lists the `DBMS_MVIEW_STATS` subprograms supported by the current version of OceanSeek and provides brief descriptions.

| subprogram | Description |
| ----------------------- | --------------------- |
| [PURGE_REFRESH_STATS](200.purge-refresh-stats-mysql.md) | This statement is used to force the automatic deletion of materialized views that exceed the specified retention period and refresh their statistics. |
| [SET_MVREF_STATS_PARAMS](300.set-mvref-stats-params-mysql.md) | The parameters used to configure the collection level and data retention period for materialized view refresh statistics. |
| [SET_SYSTEM_DEFAULT](400.set-system-default-mysql.md)  |Sets the system default value for the statistics refresh parameter.|
