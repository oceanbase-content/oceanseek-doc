# SET_MVREF_STATS_PARAMS

The `SET_MVREF_STATS_PARAMS` statement is used to configure the collection level and data retention period for materialized view refresh statistics.

## Syntax

```sql
PROCEDURE set_mvref_stats_params(
    IN     mv_name                VARCHAR(65535),
    IN     collection_level       VARCHAR(65535)     DEFAULT NULL,
    IN     retention_period       INT                DEFAULT NULL);
```

## Parameters

| **Parameter** | **Note** |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| mv_name | The name of the materialized view. <ul><li>If NULL, the operation applies to all materialized views.  </ul></li> |
| collection_level | The collection level of statistics. The system default is TYPICAL. Valid values: <ul><li>NONE: no statistics are collected.</ul></li><ul><li>TYPICAL: basic statistics are collected.</ul></li><ul><li>ADVANCED: detailed statistics are collected.</ul></li><ul><li>NULL: the system default value, which is TYPICAL, is used.</ul></li> |
| retention_period | Specifies the number of days for which statistics are retained. The value range is from 1 to 365,000 days. Statistical records will be automatically deleted after the specified number of days. The system default is 31 days.<ul><li>If set to NULL, the system default is used.</ul></li><ul><li>If set to -1, statistics will be retained indefinitely.</ul></li>                               |
