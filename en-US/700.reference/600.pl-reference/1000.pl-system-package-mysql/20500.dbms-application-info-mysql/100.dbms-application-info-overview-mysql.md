# Overview of DBMS_APPLICATION_INFO

The `DBMS_APPLICATION_INFO` system package is used to register application names in the database for auditing or performance tracking.

## DBMS_APPLICATION_INFO Privilege Description

Using the `DBMS_APPLICATION_INFO` system package does not require any special privileges. When an application registers with the database, its name and operations are recorded in the `GV$OB_PROCESSLIST` view.

## Overview of the DBMS_APPLICATION_INFO Subprogram

The following table lists the `DBMS_APPLICATION_INFO` subprograms supported by OceanBase AI Database and provides brief descriptions.

| subprogram | Description |
| --------------- | --------------- |
| [READ_CLIENT_INFO](200.read-client-info-mysql.md) | Retrieves the value of the client_info field for the current session. |
| [READ_MODULE](300.read-module-mysql.md) | Retrieves the values of the module and operation fields for the current session. |
| [SET_ACTION](400.set-action-mysql.md) | Sets the name of the current operation in the current module. |
| [SET_CLIENT_INFO](500.set-client-info-mysql.md) | Sets additional information for the client application. |
| [SET_MODULE](600.set-module-mysql.md) | Sets the name of the currently running module to the new module. |
