# DROPPYTHON

The `DBMS_PYTHON.DROPPYTHON` procedure is used to drop Python external resources.

## Syntax

```sql
DBMS_PYTHON.DROPPYTHON(IN py_name VARCHAR(65535));
```

`py_name` is the `python_name` for `loadpython` during upload.

## Examples

Run the following command to delete the uploaded Python external resource:

```shell
obclient> CALL DBMS_PYTHON.DROPPYTHON('my_add_python');
```
