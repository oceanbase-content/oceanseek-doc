# Overview of DBMS_PYTHON

`DBMS_PYTHON` is used to integrate and manage Python programs within a database, supporting the implementation of Python stored procedures, functions, and security policies.

## Overview of DBMS_PYTHON Subprograms

The following table lists the `DBMS_PYTHON` subprograms supported by OceanBase AI Database and provides brief descriptions.

| **Subprogram** | **Description** |
| ----------------------------------------- | ------------------------------------------------ |
| [DROPPYTHON](200.dbms_python_droppython-mysql.md) | Creates a Python external resource. |
| [LOADPYTHON](300.dbms_python_loadpython-mysql.md) | Used to delete Python external resources. |
