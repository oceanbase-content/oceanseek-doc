# Overview of system packages

OceanSeek supports the PL system package to extend database functionality and provide PL access to SQL features.

You can use the provided system packages when creating applications or when creating your own stored procedures. This topic describes the system packages supported by the current version of OceanSeek Server.

A system package is a encapsulated collection of related program objects stored in the database. These program objects include stored procedures, functions, variables, constants, cursors, and exceptions.

After obtaining the necessary privileges, run the following statement in the `oceanbase` schema to query the currently supported system packages and their related information:

```sql
SELECT * FROM __all_package;
```

## Components of the PL system package

A PL package consists of two parts: the package header (`SPECIFICATION`) and the package body (`BODY`). The package header serves as the application interface, containing public declarations visible to the application that define usable types, variables, constants, exceptions, cursors, and subprograms. The package body contains implementation details and private declarations hidden from the application, fully defining cursors and subprograms to support the implementation of the package header.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>The current version of OceanSeek does not support user modification of system packages.</p>
  </main>

## Usage of the PL system package

When you create a database, the system packages provided by OceanSeek are automatically installed.
