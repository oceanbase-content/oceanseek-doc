# AUTO_REFRESH_EXTERNAL_TABLE

The `auto_refresh_external_table` clause is used to periodically refresh the external table's meta data.

## Syntax

```sql
DBMS_EXTERNAL_TABLE.auto_refresh_external_table(interval int)
```

## Parameters

| **Parameter** | **Note** |
| ------------------ | ----------------------------------------------------- |
| interval int | Specifies the time interval for refreshing tasks. The value range is [-1, ∞], in seconds.<ul><li>A value of -1 disables scheduled refresh tasks.</li><li>A value of 0 refreshes the META of external tables immediately.</li><li>A value greater than 0 specifies the interval in seconds for refreshing the META of external tables.</li></ul> |

## Examples

Run the following command to disable scheduled refresh tasks.

```shell
obclient> CALL DBMS_EXTERNAL_TABLE.auto_refresh_external_table(-1);
Query OK, 0 rows affected (0.104 sec)
```
