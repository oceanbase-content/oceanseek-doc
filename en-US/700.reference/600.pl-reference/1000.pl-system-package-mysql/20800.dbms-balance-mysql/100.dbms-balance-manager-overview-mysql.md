# Overview of DBMS_BALANCE

The `DBMS_BALANCE` system package provides methods related to partition balancing.

## DBMS_BALANCE Privilege Description

Users with the privilege to execute PL/SQL can use this feature. Calling it from the `sys` tenant will result in the error `OB_OP_NOT_ALLOW`.

## Overview of DBMS_BALANCE Subprograms

The following table describes the `DBMS_BALANCE` subprograms supported by OceanBase AI Database.

| subprogram | Description |
| --- | --- |
| [TRIGGER_PARTITION_BALANCE](200.trigger-partition-balance-mysql.md) | Manually trigger partition balancing. |
| [SET_BALANCE_WEIGHT](150.set-balance-weight-mysql.md) | Used to manually set partition weights. |
| [CLEAR_BALANCE_WEIGHT](160.clear-balance-weight-mysql.md) | Used to manually clear partition weights. |
| [SET_TABLEGROUP_BALANCE_WEIGHT](300.set-tablegroup-balance-weight-of-mysql-mode.md) | Used to set `SHARDING NONE` The load balancing weight of the type table group. |
| [CLEAR_TABLEGROUP_BALANCE_WEIGHT](400.clear-tablegroup-balance-weight-of-mysql-mode.md) | Deletes the load balancing weight of a table group of the `SHARDING NONE` type. |
