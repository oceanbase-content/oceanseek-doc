# CLEAR_TABLEGROUP_BALANCE_WEIGHT

The subprogram `CLEAR_TABLEGROUP_BALANCE_WEIGHT` is used to delete the weights of a table group of type `SHARDING NONE`.

## Syntax

```sql
DBMS_BALANCE.CLEAR_TABLEGROUP_BALANCE_WEIGHT(
    tablegroup_name       VARCHAR(65535)
    ); 
```

## Parameters

| Parameter | Description |
| ------ | ------ |
| tablegroup_name | Table group name. |

## Usage instructions

The `DBMS_BALANCE.CLEAR_TABLEGROUP_BALANCE_WEIGHT` statement is used to delete the weight of a table group with the specified name in sharding none mode.

## Examples

* Call in the sys tenant to drop the weight of the table group `TG_TD_test` under the `mysql` tenant.

    ```shell
    obclient> CALL DBMS_BALANCE.CLEAR_TABLEGROUP_BALANCE_WEIGHT('TG_TD_test') TENANT = 'mysql';
    ```

* Delete the weight of the table group `TG_TD_test` under the current tenant when called by a user tenant.

    ```shell
    obclient> CALL DBMS_BALANCE.CLEAR_TABLEGROUP_BALANCE_WEIGHT('TG_TD_test');
    ```
