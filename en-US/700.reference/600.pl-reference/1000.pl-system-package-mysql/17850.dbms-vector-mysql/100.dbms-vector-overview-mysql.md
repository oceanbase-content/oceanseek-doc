# Overview of DBMS_VECTOR

The `DBMS_VECTOR` system package is used to manage vector indexes.

## Overview of DBMS_VECTOR Subprograms

The following table lists the `DBMS_VECTOR` subprograms supported by OceanBase AI Database and provides brief descriptions.

| **Subprogram** | **Description** |
| --- | --- |
| [REBUILD_INDEX](300.rebuild-index-mysql.md) | Rebuild the vector index. |
| [ALTER_INDEX_PARAMS](900.alter-index-params-mysql.md) | Online modification of HNSW series vector index parameters, if construction parameters are modified, triggers asynchronous partition-level rebuilding. |
| [INDEX_VECTOR_MEMORY_ESTIMATE](400.index-vector-memory-estimate-mysql.md) | Estimates the memory usage of vector indexes. |
| [INDEX_VECTOR_MEMORY_ADVISOR](500.index-vector-memory-advisor-mysql.md) | Vector index memory usage analysis. |
| [FLUSH_INDEX](600.flush-index-mysql.md) | Manually force the triggering of a minor compaction task. |
| [COMPACT_INDEX](700.compact-index-mysql.md) | Manually force the trigger of a major compaction task. |
| [TRIGGER_ASYNC_TASK](800.trigger-async-task-mysql.md) | Manually create a background task for a vector index of the specified type. |
