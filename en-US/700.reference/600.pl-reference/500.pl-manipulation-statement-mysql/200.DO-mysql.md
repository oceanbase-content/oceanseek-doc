# DO

The `DO` statement is used to execute an SQL expression without returning any result.

## Syntax

```sql
DO expr [, expr ...]
```

## Parameters

| **Parameter** | **Note** |
| -------------- | ---------- |
| expr | The SQL expression to be executed. Multiple expressions can be specified, separated by commas. |

In some scenarios, a `DO` statement is equivalent to a `SELECT expr` statement when used to achieve fast response without returning results.

## Examples

Executes an expression without returning a result.

```sql
obclient> DO SLEEP(5);
```

Execute multiple expressions:

```sql
obclient> DO @var1 := 10, @var2 := 20, @var3 := @var1 + @var2;

obclient> SELECT @var1, @var2, @var3;
```

The query result is as follows:

```sql
+-------+-------+-------+
| @var1 | @var2 | @var3 |
+-------+-------+-------+
|    10 |    20 |    30 |
+-------+-------+-------+
1 row in set
```
