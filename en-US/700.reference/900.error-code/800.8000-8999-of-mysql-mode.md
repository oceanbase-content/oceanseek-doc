# 8000 ~ 8999

This range indicates error codes for critical errors. When the client receives an 8xxx error, it must close the SQL connection.

## ERROR 8001 (08004) : Server is initializing

* OceanBase error code: 8001

* Cause: An RPC request was received during the startup of the OBServer node.

* Solution: Wait for the OBServer node to complete its restart.

## ERROR 8002 (08004) : Server is stopping

* OceanBase error code: 8002

* Cause: An RPC request was received during the exit of the OBServer node.

* Solution: Wait for the OBServer node to exit normally. Alternatively, execute `kill -9` to forcibly terminate the observer process.

## ERROR 8003 (08004) : Packet checksum error

* OceanBase error code: 8003

* Cause: The OBServer node received an RPC packet with a failed `checksum` verification. A common cause is version compatibility issues.

* Solution: Contact technical support for assistance in troubleshooting.

## ERROR 8004 (08004) : Packet cluster_id not match

* OceanBase error code: 8004

* Cause: The `cluster_id` in the RPC packet received by the OBServer node is unexpected. A common cause is that a server from another OceanBase AI database cluster has connected to this cluster.

* Solution: If it is confirmed that an OBServer node from another cluster has incorrectly connected to this cluster, this is a deployment error and the cluster with the incorrect deployment must be stopped as soon as possible. If the issue is caused by other reasons, it is recommended to contact technical support for assistance in troubleshooting.

## ERROR 8005 (08005) : Tenant id not match

* OceanBase error code: 8005
* Cause: A tenant name change occurred during SQL execution over a proxy connection.
* Solution: It is recommended that you disconnect the proxy connection before renaming the tenant, and then reconnect after the rename.
