# 22998, 30926, 38104, 38105

This range indicates BLOB/CLOB error codes.

## ERROR 22998 (HY000) : CLOB or NCLOB in multibyte character set not supported

* OceanBase error code: 22998

* Cause: SQL string functions do not support the `CLOB` or `NCLOB` data type.

* Solution: Use the relevant functions in the `DBMS_LOG` package.

## ERROR 30926 (HY000) : unable to get a stable set of rows in the source tables

* OceanBase error code: 30926

* Cause: A stable row set cannot be generated because the DML statement contains non-deterministic `WHERE` conditions.

* Solution: Remove the non-deterministic conditions and re-execute the DML statement.

## ERROR 38104 (HY000) : Columns referenced in the ON Clause cannot be updated:'%.\*s'.'%.\*s'

* OceanBase error code: 38104

* Cause: Columns specified in the `ON` clause cannot be updated.

## ERROR 38105 (HY000) : specified row no longer exists

* OceanBase error code: 38105

* Cause: The row has been deleted by another user after the operation started.

* Solution: Re-execute the operation to process other data rows.
