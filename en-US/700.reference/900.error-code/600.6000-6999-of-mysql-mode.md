# 6000 ~ 6999

This range indicates transaction layer error codes, including those related to transactions, MVCC, and clogs.

## ERROR 6001 (25000) : Transaction set changed during the execution

* OceanBase error code: 6001

* Cause: An update request must first read data before updating it. If the data changes before the update, this error code is returned to the upper layer, and the operation is retried.

* Solution: This is an internal error code. Contact technical support for assistance.
