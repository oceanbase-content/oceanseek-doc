# Overview of error messages

This topic describes the error messages for user tenants in OceanSeek.

## Error message format

OceanSeek is highly compatible with MySQL, which is reflected not only in common MySQL features and the MySQL client-server protocol but also in the native error messages of OceanSeek, which are compatible with MySQL. Therefore, the error message format for user tenants in OceanSeek is consistent with MySQL.

The error message format is as follows:

```shell
ERROR <err_num> (<sql_stat>) : err_msg
```

The parameters are described as follows:

* `err_num` indicates the error code.

* `sql_stat` indicates the SQL STATE.

* `err_msg` indicates the error message.

## Variables in error messages

To help you locate and resolve errors, OceanSeek embeds parameters into error messages. In this topic, these parameters are displayed as percent signs (%).

Example:

```shell
ERROR 4626 (HY000) : resource pool '%s' has already been granted to a tenant
```

The actual message may be displayed as follows:

```shell
ERROR 4626 (HY000) : resource pool 'pool1' has already been granted to a tenant
```
