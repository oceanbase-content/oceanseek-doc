# 4500 ~ 4999

This error code range indicates Root Service error codes.

## ERROR 4507 (42000) : Convert error

* OceanBase error code: 4507

* Cause: An IP address was printed to a string.

* Solution: This is an internal error code. Contact technical support for assistance.

## ERROR 4512 (HY000) : RootServer state error

* OceanBase error code: 4512

* Cause: The current state of the RootServer does not allow the operation.

* Solution: Check the current state of the RootServer. You can query the `__all_virtual_core_meta_table` to determine if any RootServer is online.

## ERROR 4515 (HY000) : No replica is valid

* OceanBase error code: 4515

* Cause: The replica status is incorrect.

* Solution: This is an internal error code. Contact technical support for assistance.

## ERROR 4519 (HY000) : Iteration was stopped

* OceanBase error code: 4519

* Cause: This is not an error code; it indicates that the MemTable iteration has ended.

* Solution: No action required.

## ERROR 4530 (HY000) : Zone info \\'%s\\' not exist

* OceanBase error code: 4530

* Cause: The zone does not exist. This usually occurs during a major compaction in a specified zone or when reporting a leader switchover error.

* Solution: Check if the specified zone exists. You can query the `DBA_OB_ZONES` table to resolve this.

## ERROR 4544 (42000) : Root not integrated

* OceanBase error code: 4544

* Cause: During the rotation major compaction, this error is reported if the number of replicas for a partition does not reach a majority. It is reported for partitions with fewer than a majority of replicas.

* Solution: Immediate manual intervention is required to check the reason why the majority was lost for that partition.

## ERROR 4547 (HY000) : global merge not started

* OceanBase error code: 4547

* Cause: Pre-check before manual major compaction rotation. If the cluster has not initiated a major freeze, manual compaction cannot be initiated.

* Solution: Check whether the cluster has initiated a major freeze.

## ERROR 4548 (HY000) : merge already started

* OceanBase error code: 4548

* Cause: Pre-check before manual major compaction rotation. If a zone has already initiated manual compaction, manual compaction cannot be initiated for that zone again.

* Solution: Check whether manual compaction has already been initiated for that zone.

## ERROR 4549 (HY000) : rootservice already exist

* OceanBase error code: 4549

* Cause: Self-check during the startup of the current RS. If another replica is already the RS, the current RS abandons the role.

* Solution: This is a self-check before RS startup and does not require handling.

## ERROR 4550 (HY000) : rootservice is shutdown

* OceanBase error code: 4550

* Cause: The RS replica to which the request was sent is not in the working state. This may be because the RS is currently leaderless, or the request was sent to a standby replica of the RS.

* Solution: Usually, retrying the request resolves the issue. When the RS is leaderless, further investigation is required.

## ERROR 4551 (HY000) : server migrate in denied

* OceanBase error code: 4551

* Cause: During the execution of a `balance task`, an OBServer node may fail if the disk is full or there are too many partitions. In this case, the OBServer node returns a packet to the RS indicating the failure of the `balance task` and reports this error code.

* Solution: The RS stops scheduling tasks to the server and retries after a specified period. If the server continuously reports this error code, manual intervention is required to check for disk overload or excessive partitions.

## ERROR 4552 (HY000) : rebalance task can not executing now

* OceanBase error code: 4552

* Cause: Before executing a `balance task`, the RS performs a series of checks, such as whether the leader switchover succeeded, whether the target machine already has the replica, and whether the replica schema exists. If these checks indicate the `balance task` cannot be executed, the task ends and this error code is reported.

* Solution: Check the pre-execution conditions of the `balance task` and troubleshoot based on the specific error. For example, if the leader switchover failed before migrating the leader, further investigation is needed to determine the cause of the leader switchover failure.

## ERROR 4554 (HY000) : rebalance task not in progress on observer

* OceanBase error code: 4554

* Cause: The RS periodically sends an RPC to the OBServer node to check whether each `balance task` exists. If a `balance task` no longer exists, the RS marks the `balance task` as completed and returns this error code.

* Solution: This error is usually caused by a delay in reporting from the meta_table or packet loss when the `balance task` returns a packet to the RS. Generally, no action is required.

## ERROR 4605 (HY000) : Data source timeout

* OceanBase error code: 4605

* Cause: An RPC timed out during storage layer migration replication.

* Solution: Check the cause of the long duration or increase the timeout period.

## ERROR 4615 (HY000) : tablegroup is not empty

* OceanBase error code: 4615

* Cause: This error is reported when deleting a table group if any of the following conditions exist:

  * Tables are present in the table group.

  * The table group is the database's `default_tablegroup_id`.

  * The table group is the tenant's `default_tablegroup_id`.

* Solution: Delete the tables in the table group but do not delete the `default_tablegroup_id` table group.

## ERROR 4620 (HY000) : server status is not valid

* OceanBase error code: 4620

* Cause: This error is reported when the server value is invalid.

* Solution: Change the invalid server value.

## ERROR 4621 (HY000) : wait elect partition leader timeout

* OceanBase error code: 4621

* Cause: Timeout occurred while waiting for leader election.

* Solution: Check the cause of the long duration or increase the timeout period.

## ERROR 4622 (HY000) : wait all rs online timeout

* OceanBase error code: 4622

* Cause:

  1. Used during bootstrap to check whether the server where the RS resides is `ALIVE`. If it is not `ALIVE`, this error is reported.

  2. Used during Bootstrap to check whether the server where the RS resides is `in_service` or whether its `start_service_time` is `0`. If it is not `in_service` or `start_service_time` is `0`, this error is reported.

* Solution: Investigate the cause of the long duration or increase the timeout period.

## ERROR 4624 (HY000) : zone '%s' server \'%s\' %s resource is not enough to hold a new unit

* OceanBase error code: 4624

* Cause:

  1. When allocating resources (including scenarios such as resource pool creation and modification, unit migration, and replica replenishment), checks are performed to ensure sufficient resources are available. If resources are insufficient, this error is reported.

  2. When creating a table, checks are performed to ensure sufficient resources are available. If resources are insufficient, this error is reported.

* Solution: Adjust the resource allocation based on the specific cause.

## ERROR 4626 (HY000) : resource pool \\'%s\\' has already been granted to a tenant

* OceanBase error code: 4626

* Cause: A tenant is already using this resource pool.

* Solution: Check `__all_resource_pool` to obtain the tenant ID (`tenant_id`) that references this resource pool. You can use the following solutions:

  * Delete the corresponding tenant.

  * Scale down the tenant to reduce its resource pool usage.

  * Create another resource pool that does not consume this resource pool.

## ERROR 4628 (HY000) : server has already been deleted

* OceanBase error code: 4628

* Cause: The server is already in the Deleting state and cannot be deleted again with the `delete server` command.

* Solution: A defensive error message; no need to execute the `delete server` command again.

## ERROR 4629 (HY000) : server is not in deleting status

* OceanBase error code: 4629

* Cause: An internal error. A defensive error message to terminate the `delete server` task.

* Solution: An internal error code. Please contact technical support for assistance.

## ERROR 4630 (HY000) : server not in server white list

* OceanBase error code: 4630

* Cause: Internal error. The server is not in the current cluster. Common scenarios include:

  * A brief error message is displayed before service is provided after an RS switchover.

  * A brief error message is displayed during the cluster Bootstrap process.

  * A newly added machine has not been added using the `add server` command.

  * Database migration from another cluster.

* Solution:

  * For the scenarios where no service is provided after an RS switchover or during the cluster Bootstrap process, if the error persists for only a short time, no action is required.

  * For the scenario where a newly added machine has not been added using the `add server` command, confirm whether the `add server` operation was missed.

  * For the scenario of database migration from another cluster, confirm whether database migration has occurred. If so, contact technical support for assistance in troubleshooting.

## ERROR 4631 (HY000) : server zone not match

* OceanBase error code: 4631

* Cause: Defensive validation. The Server and Zone information specified during `start server`, `delete server`, or `stop server` does not match.

* Solution: In cases where a Zone is specified, confirm whether the Server and Zone in `__all_server` match.

## ERROR 4632 (HY000) : zone num has reach max zone num

* OceanBase error code: 4632

* Solution: Remove unnecessary Zone information using the `delete zone` command.

## ERROR 4633 (HY000) : zone status not match

* OceanBase error code: 4633

* Cause: A defensive error of the `delete/start zone` command. When you execute the `DELETE ZONE` statement, the zone status must be `inactive`. When you execute the `START ZONE` statement, the zone status must be other than `active`.

* Solution: Query the content of the `DBA_OB_ZONES` table to confirm the zone status. If the status does not meet expectations, contact technical support for assistance.

## ERROR 4634 (HY000) : resource unit \\'%s\\' is referenced by some resource pool

* OceanBase error code: 4634

* Cause: When you delete or use a resource unit, it is found that the resource unit is referenced by a resource pool.

* Solution:

  1. Check the `__all_unit_config` or `__all_resource_pool` table to see which resource pool references the resource unit.

  2. Execute the `ALTER RESOURCE POOL` statement to modify the resource units referenced by the resource pool so that it no longer references this resource unit. Alternatively, execute the `DROP RESOURCE POOL` statement to directly drop the resource pool.

  3. Execute the `DROP RESOURCE UNIT` or `ALTER RESOURCE POOL` statement to delete or use the resource unit.

## ERROR 4636 (HY000) : table schema primary zone different with other table in same tablegroup

* Cause: A defensive error. The `primary_zone` of the table does not match that of the other tables in the same tablegroup.

* Solution: The `primary_zone` of all tables in the same tablegroup must match.
