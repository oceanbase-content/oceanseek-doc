## Performance views

The `GV$OB_SQL_AUDIT` view displays execution records of Table commands. Execute the following SQL statement in a business tenant to query the execution records of Table commands. `entity_type:1` indicates that the request type is Table.

```sql
SELECT * FROM oceanbase.GV$OB_SQL_AUDIT WHERE query_sql LIKE '%entity_type:1%' \G
```
