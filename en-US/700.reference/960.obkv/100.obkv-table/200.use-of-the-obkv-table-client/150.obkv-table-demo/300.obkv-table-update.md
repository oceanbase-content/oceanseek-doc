# Update data in OBKV-Table

The OBKV-Table Java client supports single-row and batch data updates. You can choose the appropriate interface based on your requirements.

## Supported update interfaces

The following interfaces of ObTableClient support data updates:

| **API** | **Description** | **Considerations** |
| --- | --- | --- |
| `update(String tableName)` | Updates a row of data. You can set update conditions. |  |
| `insertOrUpdate(String tableName)` | Inserts or updates a row of data. |  |
| `replace(String tableName)` | Replaces a row of data (using delete-then-insert logic). |  |
| `put(String tableName)` | Overwrites a row of data. | <ul><li>All columns must be updated.</li><li>The table must not contain indexes.</li><li>The table must not contain LOB types.</li><li>The `binlog_row_image` variable of the tenant must be set to `minimal`.</li></ul> |
| `increment(String tableName)` | Atomically increments the value of an integer column. | If the old row does not exist, the specified delta value is written to a new row. |
| `append(String tableName)` | Atomically appends a string to a string column. | If the old row does not exist, the specified delta value is written to a new row. |
| `checkAndInsUp(String tableName, ObTableFilter filter, InsertOrUpdate insUp, boolean checkExists, boolean rollbackWhenCheckFailed)` | Updates or inserts a row if the conditions are met. | <ul><li>The `check` operation in this interface has two meanings.</li><ul><li>The row does not exist (determined based on the primary key, not because the filter condition is not met).</li><li>The row exists but does not meet the filter condition.</li></ul><li>If the row exists, the interface behaves as follows:<ul><li>If the filter condition is met, performs the update operation.</li><li>If the filter condition is not met, does nothing.</li></ul><li>If the row does not exist, the interface behaves as follows:<ul><li>`checkExists = true`: Does nothing.</li><li>`checkExists = false`: Performs an insert operation.</li></ul><li>If the check fails, the interface behaves as follows:<ul><li>`rollbackWhenCheckFailed = false`: No error is returned.</li><li>`rollbackWhenCheckFailed = true`: Throws an `ObTableException` with the error message `[-10518][OB_KV_CHECK_FAILED][Check failed in CheckAndInsUp]`.</li></ul> |

## Update examples

### Prerequisites

1. Your ObTableClient has been initialized.
2. You have created a relational table in your database. The following example uses this table:
    ```sql
    CREATE TABLE IF NOT EXISTS `employees` (
    `employeeId` int NOT NULL, 
    `name` varchar(100) NOT NULL,
    `department` varchar(50),
    `position` varchar(50),
    `workYear` int,
    `comment` varchar(100),
    PRIMARY KEY (`employeeId`)
    ) PARTITION BY KEY(`employeeId`) PARTITIONS 97;
    ```

### Single-row update

#### update

The sample code updates the `workYear` of the record whose primary key `employeeId` is `1001` to `11`.

```java
// Assume the following data already exists in the database:
/*
+------------+----------+------------+----------+----------+---------+
| employeeId | name     | department | position | workYear | comment |
+------------+----------+------------+----------+----------+---------+
|       1001 | zhangsan | R&D        | dev      |       10 | NULL    |
+------------+----------+------------+----------+----------+---------+
*/
private static void updateRow(ObTableClient obkvHandle) throws Exception {
    Row rowKey = row().add(colVal("employeeId", 1001));
    Row properties = row().add(colVal("workYear", 11));
    obkvHandle.update("employees")
            .setRowKey(rowKey)
            .addMutateRow(properties)
            .execute();
}
```

The sample code updates the `workYear` of the record whose primary key `employeeId` is `1001` to `11` if the current value is greater than or equal to `3`.

```java
// Assume the following data already exists in the database:
/*
+------------+----------+------------+----------+----------+---------+
| employeeId | name     | department | position | workYear | comment |
+------------+----------+------------+----------+----------+---------+
|       1001 | zhangsan | R&D        | dev      |       10 | NULL    |
+------------+----------+------------+----------+----------+---------+
*/
private static void updateRowWithFilter(ObTableClient obkvHandle) throws Exception {
    Row rowKey = row().add(colVal("employeeId", 1001));
    Row properties = row().add(colVal("workYear", 11));

            .execute();
}
```

### Batch updates

#### batchUpdate

The sample code updates two rows in a batch, setting `workYear` to `11` for the records whose `employeeId` is `1001` and `1002`.

```java
// Assume the following data already exists in the database:
/*
+------------+----------+------------+----------+----------+---------+
| employeeId | name     | department | position | workYear | comment |
+------------+----------+------------+----------+----------+---------+
|       1001 | zhangsan | R&D        | dev      |       10 | NULL    |
|       1002 | lisi     | R&D        | dev      |       10 | NULL    |
+------------+----------+------------+----------+----------+---------+
*/
private static void batchUpdateRow(ObTableClient obkvHandle) throws Exception {
    Row rowKey1 = row().add(colVal("employeeId", 1001));
    Row rowKey2 = row().add(colVal("employeeId", 1002));
    Row properties1 = row().add(colVal("workYear", 11));
    Row properties2 = row().add(colVal("workYear", 11));
    Update updateOp1 = update().setRowKey(rowKey1).addMutateRow(properties1);
    Update updateOp2 = update().setRowKey(rowKey2).addMutateRow(properties2);
    BatchOperationResult res = obkvHandle.batchOperation("employees")
            .addOperation(updateOp1,updateOp2)
            .execute();
    System.out.println(res.hasError());
}
```
