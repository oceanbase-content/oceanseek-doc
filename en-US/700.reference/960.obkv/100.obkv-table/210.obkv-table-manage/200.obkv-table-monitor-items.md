# OBKV-Table monitoring metrics

## Statistics

You can use the following example to query the monitoring metrics of OBKV-Table, with metric IDs in the range of (190000, 190800).

```sql
MySQL [oceanbase]> SELECT distinct class,stat_id,name, value FROM gv$sysstat WHERE stat_id > 190000 AND stat_id < 190800;
```

The semantics of Batch and Multi in the metric names are described as follows:

* Multi refers to batches of single operations of the same type.
* Batch Scan refers to batches of multiple scans.
* Batch Hybrid refers to mixed batches, such as batches of single operations of different types.

The metrics are described as follows:

| Name | Description |
| --- | --- |
| single retrieve execute count | Number of GET requests. |
| single retrieve execute time | Total execution time of GET. |
| multi retrieve execute count | Number of multi-get operations. |
| multi retrieve execute time | Total execution time of multi-get. |
| multi retrieve rows | Total number of rows in multi-get operations. |
| single insert execute count | Number of INSERT executions. |
| single insert execute time | Total execution time of INSERT. |
| multi insert execute count | Number of multi-insert executions. |
| multi insert execute time | Total execution time of multi-insert. |
| multi insert rows | Total number of rows in multi-insert operations. |
| single delete execute count | Number of DELETE operations. |
| single delete execute time | Total execution time of DELETE. |
| multi delete execute count | Number of multi-delete executions. |
| multi delete execute time | Total execution time of multi-delete. |
| multi delete rows | Total number of rows deleted by multi-delete operations. |
| single update execute count | Number of UPDATE operations. |
| single update execute time | Total execution time of UPDATE. |
| multi update execute count | Number of multi-update operations. |
| multi update execute time | Total execution time of multi-update. |
| multi update rows | Total number of rows in multi-update operations. |
| single insert_or_update execute count | Number of insert_or_update operations. |
| single insert_or_update execute time | Total execution time of insert_or_update. |
| multi insert_or_update execute count | Number of multi insert_or_update executions. |
| multi insert_or_update execute time | Total execution time of multi insert_or_update. |

| single replace execute count | Number of REPLACE operations. |
| single replace execute time | Total execution time of REPLACE. |
| multi replace execute count | Number of multi-replace executions. |
| multi replace execute time | Total execution time of multi-replace. |

| batch retrieve execute count | Number of batch scan executions. |

| batch retrieve rows | Total number of rows scanned in batches. |
