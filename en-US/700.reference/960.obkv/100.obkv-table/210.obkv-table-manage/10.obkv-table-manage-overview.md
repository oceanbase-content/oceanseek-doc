# OBKV-Table management overview

This topic describes the O&M and management operations for OBKV-Table.

## Cluster management

The O&M and management operations for an OBKV-Table cluster are the same as those for an OceanBase AI Database cluster.

For more information about cluster management, see [Cluster management](../../../../600.manage/100.cluster-management/100.cluster-management-overview.md).

## Tenant management

The O&M and management operations for an OBKV-Table tenant are the same as those for a tenant in OceanBase AI Database.

For more information about tenant management, see [Tenant management](../../../../600.manage/200.tenant-management/100.tenant-introduction.md).

## Replica management

The O&M and management operations for OBKV-Table replicas are the same as the replica management operations for OceanBase AI Database.

For more information about replica management, see [Replica management](../../../../600.manage/300.replica-management/100.replica-introduction.md).

## High availability

The high availability of OBKV-Table depends on the high availability of the entire data link. In addition to the high availability of OBServer nodes, it also relies on the high availability of proxies and clients along the link. OBKV-Table inherits the high availability capabilities of OceanBase AI Database on the database server side and supports both direct connection mode and proxy mode in deployment.

OceanBase AI Database provides diverse high availability technologies for services, including multi-replica disaster recovery within a cluster, arbitration-based disaster recovery, and physical standby database disaster recovery between clusters. For more details and usage information, see [High availability of OceanBase AI Database](../../../../600.manage/400.high-availability/100.disaster-recovery-management-overview.md).

For more information about the high availability of the OBKV-Table link, see [High availability of OBKV-Table](50.obkv-table-high-availability.md).

## Security permissions

As the ultimate carrier of data, OceanBase AI Database places great emphasis on protecting data security. It supports comprehensive enterprise-level security features, including identity authentication, access control, and data encryption, which effectively ensure user data security.

For more information about security permissions in OBKV-Table, see [Security permissions of OBKV-Table](100.obkv-table-security.md).

## Backup and recovery

OBKV-Table reuses the backup and recovery capabilities of OceanBase AI Database.

For more information about backup and recovery, see [Backup and recovery](../../../../600.manage/600.backup-and-recovery/100.overview-of-physical-backup-and-recovery.md).
