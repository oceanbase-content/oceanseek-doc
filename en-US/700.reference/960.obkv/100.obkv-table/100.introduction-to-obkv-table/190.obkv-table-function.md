# Core features of OBKV-Table

This topic describes the core features of OBKV-Table.

## Client

| **Client** | **Description** |
| --- | --- |
| Java | Supports Java clients. |

## Model features of OBKV-Table

### Basic features

| **Feature** | **Description** |
| --- | --- |
| Single operations | <ul><li>Supports individual operations such as insert, put, update, delete, get, insertOrUpdate, increment, append, and checkAndInsertup.</li> |
| Query | <ul><li>Supports queries with conditions or ranges.</li><li>Supports ordered scans (scanOrder).</li><li>Supports paginated queries.</li></ul> |
| Batch operations | <ul><li>Supports batch processing of single operations.</li><li>Supports batch queries.</li><li>Supports batch processing of mixed operations.</li></ul> |
| Aggregation | <ul><li>Supports basic aggregation functions, including MIN, MAX, SUM, AVG, and COUNT.</li><li>Supports aggregation with conditions or range queries.</li></ul> |
| Indexes | <ul><li>Supports local indexes.</li><li>Supports [Scope of use and examples of global indexes in OBKV-Table](../700.obkv-table-reference/280.scope-and-examples-of-using-obkv-table-global-indexes.md).</li><li>Supports [Full-text indexes in OBKV-Table](../700.obkv-table-reference/260.obkv-table-full-text-search.md).</li></ul> |

### Performance optimization features

| **Feature** | **Description** |
| --- | --- |
| [Delete expired data from OBKV-Table](../700.obkv-table-reference/290.obkv-table-ttl.md) | <ul><li>Supports table-level TTL, where the TTL policy is set at the table level and all rows expire according to the table's policy.</li><li>Automatically deletes expired data.</li></ul><main id="notice" type='notice'><h4>Notice</h4><p>The expired data deletion (TTL) feature is available only in OceanSeek KV scenarios. It is disabled in SQL scenarios to prevent unexpected data loss.</p></main> |
| [Group commit in OBKV-Table](../700.obkv-table-reference/295.obkv-table-group-commit.md) | <ul><li>Supports group commit to improve write performance.</li></ul> |
| [Weak-consistency reads and near reads in OBKV-Table](../700.obkv-table-reference/300.obkv-table-weak-read.md) | <ul><li>Supports reading data from follower replicas to reduce leader load and network latency.</li></ul> |

### Advanced features

| **Feature** | **Description** |
| --- | --- |
| Transactions | <ul><li>Supports row-level transactions for single operations.</li><li>Supports single-machine transactions for batch operations.</li><li>Distributed transactions across nodes are not currently supported.</li></ul> |
| Disaster recovery | Reuses all disaster recovery capabilities of OceanSeek, such as multi-replica architecture, primary/standby databases, and two-region-three-IDC or three-region-five-IDC deployment. |
| Multi-tenancy | Reuses the multi-tenancy capabilities of OceanSeek. |
| Scalability | Reuses the data partitioning and elastic scaling capabilities of OceanSeek. |
| Backup and restore | Reuses the backup and restore capabilities of OceanSeek. |
| Data compression | Supports storage data compression. |
| Data encryption | Supports transparent data encryption (TDE). |
