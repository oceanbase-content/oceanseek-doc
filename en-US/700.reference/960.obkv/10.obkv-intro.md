# OBKV overview

OBKV is a NoSQL product suite built on the distributed storage engine of OceanSeek. Currently, it supports two product forms: OBKV-Table and OBKV-HBase. OBKV inherits OceanSeek's core strengths: high performance, transactional support, distributed architecture, multi-tenancy, and robust reliability. The OceanSeek tool ecosystem, including OceanBase Cloud Platform (OCP), OceanBase Migration Service (OMS), and OceanBase Change Data Capture (obcdc), also natively supports OBKV. This ensures that managing any OBKV product is just as straightforward as operating OceanBase SQL clusters. OBKV enables enterprises to unify their technology stack, meeting diverse NoSQL requirements while significantly reducing the complexity of database operations and maintenance.

## Product models

### OBKV-Table

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>OBKV-Table supports only the Java client.</p>
</main>

OBKV-Table delivers high-performance, large-scale data access by using a table-based model. It offers global and local secondary indexes, advanced filtering, TTL, and more. This solution is ideal for workloads that demand rapid access to massive datasets without complex query requirements.

For more details, see [OBKV-Table overview](100.obkv-table/100.introduction-to-obkv-table/100.implementation-of-obkv-table.md).

### OBKV-HBase

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>OBKV-HBase supports only the Java client.</p>
</main>

OBKV-HBase provides a wide-table service that is compatible with HBase interfaces. It offers read performance several times faster than open-source HBase, with lower operational costs. For recommended use cases, see [Overview of OBKV-HBase](200.obkv-hbase/10.obkv-hbase-intro.md).

For more information, refer to [Overview of OBKV-HBase](200.obkv-hbase/10.obkv-hbase-intro.md).
