# OBKV-HBase monitoring metrics

This topic describes the server-side and client-side monitoring metrics of OBKV-HBase, including metric descriptions and usage.

## Server-side monitoring metrics

You can query the following views for server-side monitoring metrics of OBKV-HBase:

| View | Description |
| --- | --- |
| [GV$SYSSTAT](../../../700.system-views/400.system-view-of-mysql-mode/300.performance-view-of-mysql-mode/5600.gv-sysstat-of-mysql-mode.md) | Query the QPS, RT, and ROWS metrics of OBKV-HBase. |
| [GV$OB_SQL_AUDIT](../../../700.system-views/400.system-view-of-mysql-mode/300.performance-view-of-mysql-mode/3500.gv-ob_sql_audit-of-mysql-mode.md) | Locate slow queries in OBKV-HBase. |
| [GV$OB_QUERY_RESPONSE_TIME_HISTOGRAM](../../../700.system-views/400.system-view-of-mysql-mode/300.performance-view-of-mysql-mode/3050.gv-ob_query_response_time_histogram-of-mysql-mode.md) | Query performance metrics such as P99 of OBKV-HBase. |

Specifically:

### QPS/RT/ROWS-related metrics

You can query the QPS, RT, and ROWS metrics from the `GV$SYSSTAT` view.

#### Query all monitoring metrics

```shell
MySQL [oceanbase]> SELECT DISTINCT class,stat_id,name, value_type FROM GV$SYSSTAT WHERE name LIKE "hbase%";
```

A sample return result is as follows. The return result includes all HBase monitoring metrics. For the complete list, see the parameter description table below:

```shell
+-------+---------+------------------------------+------------+
| class | stat_id | name                         | value_type |
+-------+---------+------------------------------+------------+
|  4096 |  191001 | hbase scan count             | ADD_VALUE  |
+-------+---------+------------------------------+------------+
```

#### (Recommended) Query specific monitoring metrics by tenant

A sample query is as follows:

```shell
# Query the checkAndMutate metrics.
MySQL [oceanbase]> SELECT * FROM oceanbase.GV$SYSSTAT 
    WHERE name LIKE '%hbase check_mutate%' 
    AND con_id = (SELECT tenant_id FROM oceanbase.DBA_OB_TENANTS WHERE tenant_name = 'your_tenant_name'); -- Specify the tenant name.
```

### Locate slow HBase requests

SQL Audit is an important diagnostic tool in OceanBase AI Database. It records diagnostic information about each request, such as the cache hit rate, the number of rows scanned in the MemTable/SSTable, and the execution time. Based on this information, you can easily identify the bottleneck of a slow request. OBKV-HBase supports SQL Audit. You can execute the following statement to query diagnostic records related to OBKV-HBase:

```shell
MySQL [oceanbase]> SELECT * FROM v$OB_SQL_AUDIT WHERE query_sql LIKE "table api: hbase%" \G; 
```

### Performance metrics such as P99

OBKV-HBase collects execution time statistics for each operation and presents them in histograms. You can use the `V$OB_QUERY_RESPONSE_TIME_HISTOGRAM` view together with Prometheus to view performance metrics such as P95 and P99 for each operation.

A sample query is as follows:

```shell
# Query the checkAndMutate metrics.
MySQL [oceanbase]> SELECT * FROM oceanbase.GV$OB_QUERY_RESPONSE_TIME_HISTOGRAM 
    WHERE sql_type LIKE '%HBASE CHECK AND MUTATE%'; -- Specify the operation type.
```

For more information about the supported `sql_type` values and other details, see [GV$OB_QUERY_RESPONSE_TIME_HISTOGRAM](../../../700.system-views/400.system-view-of-mysql-mode/300.performance-view-of-mysql-mode/3050.gv-ob_query_response_time_histogram-of-mysql-mode.md).

## Client monitoring metrics

This section describes how to use MetricsExporter and jconsole of OBKV-HBase to view client operation monitoring metrics.

### Obtain operation monitoring metrics by using MetricsExporter

MetricsExporter includes the following metrics:

| Metric | Description |
| --- | --- |
| FailRate | The average failure rate of the corresponding interface. |
| FailCount | The number of failures of the corresponding interface. |
| TotalRuntime | The total execution time of the corresponding API. |
| AverageSingleOpCount | The number of operations involved in the corresponding API. For batch operations, this is the length of the batch operation list. |
| Count | The number of API calls. |
| AverageOps | The average OPS of the corresponding interface. |
| OneMinuteAverageOps | The average OPS of the corresponding interface in 1 minute. |
| FiveMinuteAverageOps | The average OPS of the corresponding interface in 5 minutes. |
| FifteenMinuteAverageOps | The average OPS of the corresponding interface in 15 minutes. |
| AverageLatency | The average RT of the corresponding interface. |
| MaxLatency | The maximum RT of the corresponding interface. |
| MinLatency | The minimum RT of the corresponding interface. |
| MedianLatency | The median RT of the corresponding interface. |
| P75thPercentile | The P75 RT of the corresponding interface. |
| P95thPercentile | The P95 RT of the corresponding interface. |
| P98thPercentile | The P98 RT of the corresponding interface. |
| P99thPercentile | The P99 RT of the corresponding interface. |
| P999thPercentile | The P999 RT of the corresponding interface. |

#### Usage

```java
// Sample code.
Configuration conf = ObHTableTestUtil.newConfiguration();
// Enable client-side metrics.
conf.set(CLIENT_SIDE_METRICS_ENABLED_KEY, "true"); 
Connection connection = ConnectionFactory.createConnection(conf);
Table hTable = connection.getTable(TableName.valueOf("test_metrics"));
OHMetrics metrics = ((OHTable) hTable).getMetrics();
// GET_LIST metrics.
MetricsExporter exporter = metrics.acquireMetrics(OHOperationType.GET_LIST);
System.out.println("AverageOps: " + exporter.getAverageOps());
System.out.println("99thPercentile: " + exporter.get99thPercentile());
System.out.println("AverageSingleOpCount: " + exporter.getAverageSingleOpCount());
```

### View client monitoring metrics by using JMX

You can view client monitoring metrics in either of the following ways:

* View them by using MBeanServer.
* View them by using jconsole.

#### View by using MBeanServer

The following sample code shows how to view client monitoring metrics by using MBeanServer:

:::collapse
```java
// Sample code.
import javax.management.*;
import java.lang.management.ManagementFactory;

MBeanServer mBeanServer = ManagementFactory.getPlatformMBeanServer();
/**
 * Get the ObjectName of a specific attribute in JMX.
 * 
 * @param opType The OHOperationType.
 * @param metricsName The metrics name.
 * @param attributeName The attribute name (latencyHistogram, failedOpCounter, totalSingleOpCount, or totalRuntime).
 * @return The ObjectName.
 */
public ObjectName getObjectName(OHOperationType opType, String metricsName, 
                                String attributeName) {
    try {
        // The JMX name format is domain:name=metricName.
        // Example: com.alipay.oceanbase.hbase.util.OHMetrics.PUT.latencyHistogram.metricsName
        String name = String.format("%s.%s.%s.%s",
                OHMetrics.class.getName(),
                opType.name(),
                attributeName,
                metricsName);
        
        String objectNameStr = String.format("%s:name=%s",
            JMX_DOMAIN, name);
        return new ObjectName(objectNameStr);
    } catch (MalformedObjectNameException e) {
        throw new RuntimeException("Failed to create ObjectName", e);
    }
}

/**
 * Get the latency attribute.
 * Timer attributes: Count, MeanRate, OneMinuteRate, FiveMinuteRate, FifteenMinuteRate,
 * Min, Max, Mean, StdDev, 50thPercentile, 75thPercentile, 95thPercentile, 98thPercentile, 99thPercentile, 999thPercentile
 */
public Object getTimerAttribute(OHOperationType opType, String metricsName, String attributeName) {
    try {
        ObjectName objectName = getObjectName(opType, metricsName, "latencyHistogram");
        return mBeanServer.getAttribute(objectName, attributeName);
    } catch (Exception e) {
        throw new RuntimeException("Failed to get Timer attribute: " + attributeName, e);
    }
}

/**
 * Get the failed operations attribute.
 * Meter attributes: Count, MeanRate, OneMinuteRate, FiveMinuteRate, FifteenMinuteRate
 */
public Object getMeterAttribute(OHOperationType opType, String metricsName, String attributeName) {
    try {
        ObjectName objectName = getObjectName(opType, metricsName, "failedOpCounter");
        return mBeanServer.getAttribute(objectName, attributeName);
    } catch (Exception e) {
        throw new RuntimeException("Failed to get Meter attribute: " + attributeName, e);
    }
}

/**
 * Get the Counter attribute.
 * Counter attributes: Count
 */
public Object getCounterAttribute(OHOperationType opType, String metricsName, 
                                 String counterName, String attributeName) {
    try {
        ObjectName objectName = getObjectName(opType, metricsName, counterName);
        return mBeanServer.getAttribute(objectName, attributeName);
    } catch (Exception e) {
        throw new RuntimeException("Failed to get Counter attribute: " + attributeName, e);
    }
}

Configuration config = ObHTableTestUtil.newConfiguration();
// Enable client-side metrics.
config.set(CLIENT_SIDE_METRICS_ENABLED_KEY, "true");
Connection connection = ConnectionFactory.createConnection(config);
Table hTable = connection.getTable(TableName.valueOf("test_multi_cf"));
String metricsName;
if (hTable instanceof OHTable) {
    OHMetrics metrics = ((OHTable) hTable).getMetrics();
    if (metrics != null) {
        metricsName = metrics.getMetricsName();
    }
}
// PUT metrics
// Latency histogram.
Long totalOpCount = (Long) getTimerAttribute(OHOperationType.PUT, metricsName, "Count");
Double meanOps = (Double) getTimerAttribute(OHOperationType.PUT, metricsName, "MeanRate");
Double oneMinuteRateOps = (Double) getTimerAttribute(OHOperationType.PUT, metricsName, "OneMinuteRate");
Double meanLatency = (Double) getTimerAttribute(OHOperationType.PUT, metricsName, "Mean");
Double minLatency = (Double) getTimerAttribute(OHOperationType.PUT, metricsName, "Min");
Double maxLatency = (Double) getTimerAttribute(OHOperationType.PUT, metricsName, "Max");
Double P99thPercentile = (Double) getTimerAttribute(OHOperationType.PUT, metricsName, "99thPercentile");

// Failed operations.
Long failedOpCount = (Long) getMeterAttribute(OHOperationType.PUT, metricsName, "Count");
Double meanFailRate = (Double) getMeterAttribute(OHOperationType.PUT, metricsName, "MeanRate");
Double oneMinuteFailRate = (Double) getMeterAttribute(OHOperationType.PUT, metricsName, "OneMinuteRate");

// Counter
Double totalSingleOpCount = (Long) getCounterAttribute(OHOperationType.PUT, metricsName, "totalSingleOpCount", "Count");
Double totalRuntime = (Long) getCounterAttribute(OHOperationType.PUT, metricsName, "totalRuntime", "Count");
```
:::

#### View by using jconsole

Set `CLIENT_SIDE_METRICS_ENABLED_KEY` to `true` in the Hadoop Configuration, and then start the OBKV-HBase client process. Run `ps -ef | grep idea` in the terminal to view the process PID. Run `jconsole $PID` in the terminal to open the JMX interface. Under MBeans, the `com.oceanbase.hbase.metrics` folder contains the monitoring items for all interface operations.
