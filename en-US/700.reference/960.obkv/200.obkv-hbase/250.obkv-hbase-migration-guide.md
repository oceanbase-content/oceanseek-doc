# OBKV-HBase migration guide

OceanBase AI Database provides a comprehensive OBKV-HBase data migration solution to help you migrate data from an existing HBase database to OceanBase AI Database or migrate incremental data back to the HBase database.

## Migrate data from an HBase database to OBKV-HBase

You can use the OceanBase Migration Service (OMS) Community Edition console to create a data migration task that migrates data from an HBase database to OBKV-HBase. The task supports schema migration, full migration, and incremental synchronization, which seamlessly migrate the existing business data and incremental data from the source database to OBKV-HBase. For more information, see [Migrate data from an HBase database to OBKV-HBase](https://docs.oceanbase.com/oms-community/migrate-data-from-hbase-to-obkv).

## Migrate incremental data from OBKV-HBase to an HBase database

You can use the OMS Community Edition console to create a data migration task that migrates incremental data from OBKV-HBase back to an HBase database. For more information, see [Migrate incremental data from OBKV-HBase to an HBase database](https://docs.oceanbase.com/oms-community/migrate-incremental-data-from-obkv-to-hbase).

With the data migration capability of OceanBase AI Database, you can:

* Simplify data management processes: Centrally manage data, significantly reducing the cost and complexity of maintaining multiple databases.
* Improve data processing performance: Leverage the high-performance storage engine and optimized query capabilities of OceanBase AI Database to improve data processing efficiency.
* Ensure business continuity: Support online migration and real-time synchronization to ensure zero-downtime business switchover.
* Use flexible migration strategies: Support schema migration, full migration, and incremental synchronization.
