# Overview of OBKV-HBase application development

OBKV-HBase allows you to connect to an OBKV-HBase cluster by using the OBKV-HBase client and to perform data operations through HBase-compatible APIs. If your business currently uses native HBase data access logic, you can deploy an OceanBase AI Database cluster, create HBase tables on the OBServer node, and manage data by using the OBKV-HBase client.

## OBKV-HBase data model

You can use the wide column (WideColumn) model for data modeling to ensure better compatibility with HBase data and easier maintenance through OBKV-HBase. For more information, see [OBKV-HBase data model](../700.obkv-hbase-reference/50.obkv-hbase-data-model.md) and [OBKV-HBase data model](../700.obkv-hbase-reference/100.obkv-hbase-schema-design.md).

If you want to learn more about the HBase storage model, see the [Apache HBase data model](https://hbase.apache.org/book.html#datamodel).

## Develop applications with the OBKV-HBase Java client

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>OBKV-HBase supports only the Java client.</p>

You can use the OBKV-HBase Java client to perform data operations through HBase-compatible APIs. For more information, see [Connect to a cluster by using the OBKV-HBase Java client](200.connecting-by-using-obkv-hbase-client.md).

## Data operation examples

For usage examples of OBKV-HBase, see [Data operation examples](300.obkv-hbase-demo.md).

If you want a deeper understanding of HBase, see the [Apache HBase official website](https://hbase.apache.org/) and [Apache HBase interfaces](https://hbase.apache.org/1.1/apidocs/org/apache/hadoop/hbase/client/Table.html).

## Interfaces and filters

The OBKV-HBase client implements the [HTableInterface](https://svn.apache.org/repos/asf/hbase/hbase.apache.org/trunk/0.94/apidocs/org/apache/hadoop/hbase/client/HTableInterface.html) interface:

* For a list of supported interfaces, see [HBase-compatible interfaces](../700.obkv-hbase-reference/150.obkv-hbase-interface-compatibility.md).
* For a list of supported filters, see [HBase-compatible filters](../700.obkv-hbase-reference/200.obkv-hbase-filter-compatibility.md).
