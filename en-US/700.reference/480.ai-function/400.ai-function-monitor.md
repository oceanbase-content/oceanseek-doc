# View AI model information

This topic describes how to view information about AI models through views.

## View provider, model parameter, and gateway information (new interface)

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>All views in this section are supported starting from V4.6.2.1.</p>
</main>

OceanBase AI Database supports viewing registered provider configurations, model parameters, and gateway information through views. For details, see:

| **View** | **Description** |
| --- | --- |
| [oceanbase.DBA_OB_AI_MODEL_PROVIDERS](../700.system-views/400.system-view-of-mysql-mode/200.dictionary-view-of-mysql-mode/5714.o-dba_ob_ai_model_providers-of-mysql-mode.md) | View registered provider configuration information. |
| [oceanbase.DBA_OB_AI_MODEL_PROFILES](../700.system-views/400.system-view-of-mysql-mode/200.dictionary-view-of-mysql-mode/5713.o-dba_ob_ai_model_profiles-of-mysql-mode.md) | View the parameter information of registered models. |
| [oceanbase.DBA_OB_AI_GATEWAYS](../700.system-views/400.system-view-of-mysql-mode/200.dictionary-view-of-mysql-mode/5705.o-dba_ob_ai_gateways-of-mysql-mode.md) | View the registered gateway information. |
| [oceanbase.DBA_OB_AI_GATEWAY_ENDPOINTS](../700.system-views/400.system-view-of-mysql-mode/200.dictionary-view-of-mysql-mode/5704.o-dba_ob_ai_gateway_endpoint-of-mysql-mode.md) | View the registered gateway endpoint information. |
