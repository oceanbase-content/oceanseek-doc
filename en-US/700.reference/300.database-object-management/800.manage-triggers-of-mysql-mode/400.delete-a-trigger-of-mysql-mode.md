# Drop a trigger

You can use the `DROP TRIGGER` statement to drop a trigger.

The user who drops the trigger must have privileges on the table related to the trigger. If you drop a table, the triggers associated with that table will also be dropped.

The syntax for dropping a trigger is as follows:

```sql
obclient> DROP TRIGGER [IF EXISTS] [database_name.]trigger_name;
```

The parameters are described as follows:

* `IF EXISTS` indicates that if the specified trigger exists, the trigger is dropped.

* `database_name` indicates the database name. This is an optional parameter; if not specified, the trigger is dropped from the current database.

Example:

```sql
obclient> DROP TRIGGER test.test_trg;
```
