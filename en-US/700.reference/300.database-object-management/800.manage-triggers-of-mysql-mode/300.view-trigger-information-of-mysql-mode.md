# View trigger information

Viewing trigger information refers to viewing the definitions, status, and syntax of existing triggers in a database.

You can view trigger information using the following methods:

* Using the `SHOW` statement

  ```sql
  obclient>SHOW TRIGGERS [FROM database_name];
  ```

  Here, `database_name` specifies the name of the database. If `FROM database_name` is not used, it means viewing trigger information for the current database.
  
* Using a view

  ```sql
  obclient>SELECT * FROM information_schema.triggers [where trigger_name = 'xx'];
  ```

  If no query conditions are specified, it means viewing information for all triggers.
