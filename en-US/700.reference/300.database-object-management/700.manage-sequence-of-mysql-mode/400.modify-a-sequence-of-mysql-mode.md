# Modify a sequence

After a sequence is created, you can use the `ALTER SEQUENCE` statement to modify its attributes. OceanBase AI Database supports modifying the start value, minimum value, maximum value, increment step, and cycle attribute of a sequence.

The SQL syntax for modifying a sequence is as follows:

```sql
ALTER SEQUENCE [database_name.]sequence_name
{
[RESTART]
|[START WITH int_value]
|[MINVALUE int_value | NOMINVALUE]
|[MAXVALUE int_value | NOMAXVALUE]
|[INCREMENT BY int_value]
|[CACHE int_value | NOCACHE]
|[ORDER | NOORDER]
|[CYCLE | NOCYCLE]
};
```

To execute this statement, you must have the `ALTER` privilege.

Examples:

1. Modify the maximum value of the sequence `seq2` and specify cyclic generation of sequence values.

   ```sql
   obclient> ALTER SEQUENCE seq2 MAXVALUE 1024 CYCLE;
   ```

2. Modify the start value of a sequence.

   * If the value of `INCREMENT BY` is greater than `0`, you can reset the sequence so that it starts from `MINVALUE`. If the value of `INCREMENT BY` is less than `0`, you can reset the sequence so that it starts from `MAXVALUE`. The statements are as follows:

     ```sql
     obclient> ALTER SEQUENCE seq3 RESTART;
     Query OK, 0 rows affected
     ```

   * Reset the sequence so that it starts from `3`. The statement is as follows:

     ```sql
     obclient> ALTER SEQUENCE seq4 RESTART START WITH 3;
     Query OK, 0 rows affected
     ```

   When you modify the start value of a sequence, `RESTART` does not have to be placed after the sequence name; it can be anywhere in the statement. Example:

   ```sql
   obclient> ALTER SEQUENCE seq4 START WITH 3 RESTART MINVALUE -100 CYCLE;
   Query OK, 0 rows affected
   ```

For more information about the `ALTER SEQUENCE` statement, see [ALTER SEQUENCE](../../500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/1400.alter-sequence-of-mysql-mode.md).
