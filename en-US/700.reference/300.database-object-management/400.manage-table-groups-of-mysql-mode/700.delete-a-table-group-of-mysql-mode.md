# Delete a table group

You can delete a table group that contains no table, that is, when the table group is not referenced by any table.

## Prerequisites

Before you delete a table group, query the `CDB_OB_TABLEGROUP_TABLES` or `DBA_OB_TABLEGROUP_TABLES` view to check whether the table group contains tables. You can delete only an empty table group. For more information about how to check whether a table group contains tables by using views, see [View table group information](../400.manage-table-groups-of-mysql-mode/300.view-the-information-of-a-table-group-of-mysql-mode.md).

## Delete a table group

The SQL statement for deleting a table group is as follows:

```sql
DROP TABLEGROUP [IF EXISTS] tablegroup_name;
```

In the statement, `tablegroup_name` is the name of the table group to be deleted. If the table group to be deleted does not exist and the `IF EXISTS` clause is not specified, the system returns an error. To execute this statement, you must have the global `DROP` privilege.

The following example deletes the table group named `tblgroup1`:

```sql
DROP TABLEGROUP IF EXISTS tblgroup1;
```
