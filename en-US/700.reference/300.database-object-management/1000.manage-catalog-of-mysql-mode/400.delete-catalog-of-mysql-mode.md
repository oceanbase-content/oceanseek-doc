# Drop a catalog

When a catalog is no longer needed, you can use the `DROP CATALOG [IF EXISTS] external_catalog_name;` statement to drop it.

When dropping a catalog, if `IF EXISTS` is specified, no error is returned even if the catalog to be dropped does not exist. If `IF EXISTS` is not specified, an error is returned.

**Here is an example:**

```shell
obclient> DROP CATALOG IF EXISTS test_odps_catalog;
```
