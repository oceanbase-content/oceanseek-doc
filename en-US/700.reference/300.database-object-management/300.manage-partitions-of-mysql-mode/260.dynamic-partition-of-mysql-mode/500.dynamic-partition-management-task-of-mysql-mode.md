# Dynamic partition management tasks

OceanBase AI Database introduces the system package `DBMS_PARTITION` for dynamic partition management, providing the subprogram `MANAGE_DYNAMIC_PARTITION()` to trigger dynamic partition management.

## Scheduled dynamic partition management

Dynamic partition management tasks are scheduled based on the PL system package `DBMS_SCHEDULER`. When a user tenant is created, two scheduled dynamic partition management tasks are built-in: `SCHEDULED_MANAGE_DYNAMIC_PARTITION_HOURLY` and `SCHEDULED_MANAGE_DYNAMIC_PARTITION_DAILY`, which periodically call `DBMS_PARTITION.MANAGE_DYNAMIC_PARTITION()`.

* `SCHEDULED_MANAGE_DYNAMIC_PARTITION_HOURLY` schedules dynamic partition management with `TIME_UNIT` set to `hour`. It runs once per hour at the hour mark and its schedule cannot be modified.
* `SCHEDULED_MANAGE_DYNAMIC_PARTITION_DAILY` schedules dynamic partition management with `TIME_UNIT` set to `day`, `week`, `month`, or `year`. It runs once per day by default at 00:00. Users can modify the scheduled time to avoid peak DDL operation periods.

### Query scheduled dynamic partition management tasks

In a user tenant, you can query scheduled dynamic partition management tasks by specifying `JOB_NAME` as `SCHEDULED_MANAGE_DYNAMIC_PARTITION_DAILY` or `SCHEDULED_MANAGE_DYNAMIC_PARTITION_HOURLY` in the `oceanbase.DBA_SCHEDULER_JOBS` view.

**Here are some examples:**

* Specify `JOB_NAME` as `SCHEDULED_MANAGE_DYNAMIC_PARTITION_DAILY`.

    ```sql
    SELECT JOB_NAME, JOB_ACTION, START_DATE, REPEAT_INTERVAL, ENABLED, NEXT_RUN_DATE, MAX_RUN_DURATION, COMMENTS 
    FROM oceanbase.DBA_SCHEDULER_JOBS
    WHERE JOB_NAME = 'SCHEDULED_MANAGE_DYNAMIC_PARTITION_DAILY'\G
    ```

    The query result is as follows:

    ```shell
    *************************** 1. row ***************************
            JOB_NAME: SCHEDULED_MANAGE_DYNAMIC_PARTITION_DAILY
          JOB_ACTION: DBMS_PARTITION.MANAGE_DYNAMIC_PARTITION(null, 'DAY,WEEK,MONTH,YEAR')
          START_DATE: 2025-04-16 00:00:00.000000
     REPEAT_INTERVAL: FREQ=DAILY;INTERVAL=1
             ENABLED: 1
       NEXT_RUN_DATE: 2025-04-17 00:00:00.000000
    MAX_RUN_DURATION: 3600
            COMMENTS: used to perform manage dynamic partition periodically
    1 row in set
    ```

* Specify `JOB_NAME` as `SCHEDULED_MANAGE_DYNAMIC_PARTITION_HOURLY`.

    ```sql
    SELECT JOB_NAME, JOB_ACTION, START_DATE, REPEAT_INTERVAL, ENABLED, NEXT_RUN_DATE, MAX_RUN_DURATION, COMMENTS
    FROM oceanbase.DBA_SCHEDULER_JOBS
    WHERE JOB_NAME = 'SCHEDULED_MANAGE_DYNAMIC_PARTITION_HOURLY'\G
    ```

    The query result is as follows:

    ```shell
    *************************** 1. row ***************************
            JOB_NAME: SCHEDULED_MANAGE_DYNAMIC_PARTITION_HOURLY
          JOB_ACTION: DBMS_PARTITION.MANAGE_DYNAMIC_PARTITION(null, 'HOUR')
          START_DATE: 2025-04-15 15:00:00.000000
     REPEAT_INTERVAL: FREQ=HOURLY;INTERVAL=1
             ENABLED: 1
       NEXT_RUN_DATE: 2025-04-16 18:00:00.000000
    MAX_RUN_DURATION: 3600
            COMMENTS: used to perform manage dynamic partition periodically
    1 row in set
    ```

### Modify scheduled dynamic partition management tasks

You can modify the scheduled dynamic partition management tasks for the current tenant in a user tenant.

#### Disable a scheduled partition management task

```sql
CALL DBMS_SCHEDULER.DISABLE('SCHEDULED_MANAGE_DYNAMIC_PARTITION_DAILY');
```

```sql
CALL DBMS_SCHEDULER.DISABLE('SCHEDULED_MANAGE_DYNAMIC_PARTITION_HOURLY');
```

#### Enable a scheduled partition management task

```sql
CALL DBMS_SCHEDULER.ENABLE('SCHEDULED_MANAGE_DYNAMIC_PARTITION_DAILY');
```

```sql
CALL DBMS_SCHEDULER.ENABLE('SCHEDULED_MANAGE_DYNAMIC_PARTITION_HOURLY');
```

#### Modify the daily schedule time of a scheduled partition management task

You can only modify the daily schedule time for the `SCHEDULED_MANAGE_DYNAMIC_PARTITION_DAILY` scheduled task. For example, assume that the current time is `2025-03-11 10:00:00` and you want to change the schedule to 12:00 every day:

```sql
CALL DBMS_SCHEDULER.SET_ATTRIBUTE('SCHEDULED_MANAGE_DYNAMIC_PARTITION_DAILY', 'START_DATE', '2025-03-11 12:00:00');
```

The next scheduled run will be at `2025-03-11 12:00:00`, and it will continue to run at 12:00 every day thereafter.

## Manually trigger dynamic partition management

Call `DBMS_PARTITION.MANAGE_DYNAMIC_PARTITION()` directly to trigger a one-time dynamic partition management task:

```sql
CALL DBMS_PARTITION.MANAGE_DYNAMIC_PARTITION();
```

`MANAGE_DYNAMIC_PARTITION` has two parameters: `precreate_time` and `time_unit`. For more information, see [MANAGE_DYNAMIC_PARTITION](../../../600.pl-reference/1000.pl-system-package-mysql/13200.dbms_partition-mysql/200.manage_dynamic_partition-of-mysql-mode.md).

* When specifying `precreate_time`, the larger value between the specified value and the `precreate_time` on the table is used for pre-creating partitions. Example:

    ```sql
    CALL DBMS_PARTITION.MANAGE_DYNAMIC_PARTITION('3DAY');
    ```

* When specifying `time_unit`, dynamic partition management is performed only when the table's `time_unit` matches the specified `time_unit`. Example:

    ```sql
    CALL DBMS_PARTITION.MANAGE_DYNAMIC_PARTITION(NULL, 'day, week');
    ```

## Query historical execution records of dynamic partition management tasks

The view [oceanbase.DBA_OB_TENANT_EVENT_HISTORY](../../../700.system-views/400.system-view-of-mysql-mode/200.dictionary-view-of-mysql-mode/12200.o-dba_ob_tenant_event_history-of-mysql-mode.md) records the historical execution status of dynamic partition management tasks under the current tenant, including the table IDs of successful and failed executions:

```sql
SELECT * FROM oceanbase.DBA_OB_TENANT_EVENT_HISTORY
WHERE EVENT = 'MANAGE_DYNAMIC_PARTITION';
```
