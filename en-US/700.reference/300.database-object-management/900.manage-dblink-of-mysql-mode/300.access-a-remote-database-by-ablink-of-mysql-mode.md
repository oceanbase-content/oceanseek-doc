# Access data in a remote database through DBLink

After creating a DBLink, you can use it to access objects in a remote database, including tables and views.

## Limitations

* Currently, OceanBase AI Database user tenants cannot read data from a MySQL database through DBLink, nor can a MySQL database read data from a user tenant of OceanBase AI Database through DBLink.
* Data types supported for access via DBLink include:

  * Numeric types: TINYINT, SMALLINT, MEDIUMINT, INT, BIGINT, FLOAT, DOUBLE, DECIMAL
  * Time types: DATE, TIME, YEAR, DATETIME, TIMESTAMP
  * Character types: CHAR, VARCHAR, TINYBLOB, TINYTEXT, BLOB, TEXT, MEDIUMBLOB, LONGBLOB, LONGTEXT
  * Other types: ENUM, SET

    <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>Due to limitations of OBClient, when reading table data through DBLink, columns of the <code>ENUM</code> or <code>SET</code> type in the remote table are treated as <code>VARCHAR</code> type columns.</p>
    </main>

  For detailed information and descriptions of each data type, see [Overview of data types](../../500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/100.basic-elements-of-mysql-mode/100.data-type-of-mysql-mode/100.data-type-overview-of-mysql-mode.md).

## Prerequisites

You have created a DBLink. For detailed steps, see [Create a DBLink](../900.manage-dblink-of-mysql-mode/100.create-a-dblink-of-mysql-mode.md).

## Access data in a remote database table

Use the `SELECT... FROM table_name@DBLink name` syntax to access data in a table of a remote database. The SQL statement is as follows:

```sql
SELECT select_expr_list 
      FROM table_name@dblink_name 
      WHERE where_conditions;
 
select_expr_list:
    table_name.*
    | table_alias_name.*
    | expr [[AS] column_alias_name]
```

Instructions for using the statement:

* `select_expr_list`: Specifies the expressions or column names to query. Separate different columns with commas (,). An asterisk (*) indicates all columns.

  * `table_name.*`: Specifies to select all columns from the specified table or view.

  * `table_alias_name.*`: Specifies an alias for the table or view.

  * `expr [[AS] column_alias_name]`: Specifies an alias for the queried column or expression. `AS` is optional.

* `table_name@dblink_name`: Specifies the table in the remote database to query. Separate multiple tables with commas (,). By default, it accesses tables in the database specified when creating the DBLink. To access tables in other databases, specify them in the SQL statement in the format `database_name.table_name@dblink_name`.

* `where_conditions`: Specifies filter conditions. The query result only contains data that meets the conditions. This is optional.

For more DBLink-related query statements, see [SELECT](../../500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/8100.select-of-mysql-mode/100.select-of-mysql-mode.md).

Example:

* Query data from the `tbl1` table in the remote database through a DBLink named `ob_dblink`.

  ```sql
  SELECT * FROM tbl1@ob_dblink;
  ```

* Read the `tbl1` table from the remote database `test` through a DBLink, and perform a join operation with the `tbl1` table in the local database.

  ```sql
  SELECT a.c_decimal, b.c_double FROM tbl1 a, tbl1@ob_dblink b WHERE a.c_int = b.c_int;
  ```

* Read the `tbl2` table from the remote database `mysql` (the database specified when creating the DBLink is `test`) through a DBLink.

  ```sql
  SELECT * FROM mysql.tbl2@ob_dblink;
  ```
