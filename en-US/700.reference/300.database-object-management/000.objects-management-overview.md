# Overview of database object management

Database objects are essential components of a database, including tables, indexes, views, triggers, sequences, and more. OceanBase AI Database provides database object management capabilities based on its MySQL-compatible mode.

This chapter describes the operations of the following database objects:

| Database object type | Database object management description |
| ---------------------- | -------------------------- |
| Database | This topic describes how to create, view, modify, and drop databases. For more information, see [Create a database](100.manage-databases-of-mysql-mode/100.to-create-a-database-of-mysql-mode.md). |
| Table | This topic describes how to create, modify, drop, lock, and truncate tables, as well as define column attributes and set constraint types. For more information, see [About tables](200.manage-tables-of-mysql-mode/100.about-tables-of-mysql-mode.md). |
| External Table | This topic describes how to create external tables, create partitions of external tables, manage external files, and perform data type mappings. For more information, see [External tables and external files](200.manage-tables-of-mysql-mode/1000.manage-external-tables-of-mysql-mode/100.about-external-tables-of-mysql-mode.md). |
| Partition | This topic describes how to create, split, and manage dynamic partitions of a partitioned table, as well as adjust partitioning rules and add or drop partitions. For more information, see [Partitioning overview](300.manage-partitions-of-mysql-mode/100.partition-overview-of-mysql-mode.md). |
| TableGroup | This topic describes how to create, view, add tables to, modify the SHARDING attribute of, and delete a table group. For more information, see [About table groups](400.manage-table-groups-of-mysql-mode/100.about-table-groups-of-mysql-mode.md). |
| Index | This topic describes how to create, view, monitor, and drop indexes, as well as the support for function-based indexes. For more information, see [About indexes](500.manage-indexes-of-mysql-mode/100.about-indexes-of-mysql-mode.md). |
| View | This topic describes how to create, modify, and drop normal views. For more information, see [Manage regular views](600.manage-views-of-mysql-mode/100.manage-normal-views-of-mysql-mode.md). |
| Materialized view | This topic describes how to create, refresh, query rewrite, modify the properties of, and perform resource isolation on materialized views. For more information, see [Overview of materialized views](600.manage-views-of-mysql-mode/200.manage-materialized-views-of-mysql-mode/100.materialized-views-overview-of-mysql-mode.md). |
| Sequence | This topic describes how to create, view, modify, and drop sequences. For more information, see [Create a sequence](700.manage-sequence-of-mysql-mode/100.create-a-sequence-of-mysql-mode.md). |
| Trigger | This topic describes how to create, view, and drop triggers. For more information, see [Overview](800.manage-triggers-of-mysql-mode/100.trigger-overview-of-mysql-mode.md). |
| DBLink | This topic describes how to create, view, and delete DBLinks. For more information, see [Create a DBLink](900.manage-dblink-of-mysql-mode/100.create-a-dblink-of-mysql-mode.md). |
| Catalog | This topic describes how to create, view, and delete a catalog. For more information, see [Overview of Catalog](1000.manage-catalog-of-mysql-mode/100.catalog-overview-of-mysql-mode.md). |
| Hot Cache Policy (storage_cache_policy) | This topic describes how to create, modify, and maintain a hotspot cache policy. For more information, see Overview of custom hotspot cache policies. |
