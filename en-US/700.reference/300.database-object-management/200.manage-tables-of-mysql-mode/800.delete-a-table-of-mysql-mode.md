# Drop a table

When a table is no longer needed, you can use the `DROP TABLE` statement to delete it.

The following example shows how to drop a table:

```sql
obclient> DROP TABLE test;
```

or

```sql
obclient> DROP TABLE IF EXISTS test;
```

When dropping a table, if `IF EXISTS` is specified, no error is returned even if the table does not exist. If `IF EXISTS` is not specified, an error is returned.

For the `DROP TABLE` operation:

* When the tenant has the recycle bin feature disabled, a `DROP TABLE` operation drops the table.

* When the tenant has the recycle bin feature enabled, a `DROP TABLE` operation moves the table to the recycle bin. You can later delete or restore the table from the recycle bin. For more information, see [Restore objects from the recycle bin](../../../600.manage/400.high-availability/500.recyclebin-management/400.restore-the-recyclebin-objects.md).

* The recycle bin feature is controlled by the system variable `recyclebin` and is disabled by default.
