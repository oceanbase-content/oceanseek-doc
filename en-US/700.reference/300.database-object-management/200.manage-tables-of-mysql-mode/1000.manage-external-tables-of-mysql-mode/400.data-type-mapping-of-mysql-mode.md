# Data type mappings

Data type mappings ensure that when data is exported from OceanBase AI Database to formats such as Parquet, ORC, MaxCompute (ODPS), and CSV, the original data types are accurately mapped to the corresponding target format data types. OceanBase AI Database uses a clear mapping table to associate various data types with the data types supported by Parquet, ORC, and MaxCompute (ODPS), thereby ensuring that data is not lost or overloaded during export and retains its semantics.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For CSV files, the exported data is of the string type.</p>
</main>

## Export to MaxCompute (ODPS) format

| MaxCompute (ODPS) data types | Data types in user tenants | Remarks |
| -------------- | ----- | -------------------- |
| BOOLEAN | TINYINT (0 indicates false and 1 indicates true) | - |
| TINYINT | TINYINT | - |
| SMALLINT | SMALLINT | - |
| INT | INT | - |
| BIGINT | BIGINT | - |
| FLOAT | FLOAT | Users are not allowed to specify the precision; otherwise, an error will be reported. |
| DOUBLE | DOUBLE | Users are not allowed to specify the precision; otherwise, an error will be reported. |
| DECIMAL | DECIMAL(M,D) | You must explicitly make M and D consistent with P and S on MaxCompute (ODPS). Otherwise, an error is reported at execution time. |
| CHAR (up to 255 bytes, with trailing spaces) | CHAR (0 to 255) | The user-specified length must be greater than or equal to the length of the corresponding column on MaxCompute (ODPS). Otherwise, an error will be reported during execution. |
| VARCHAR (up to 65,535) | VARCHAR (length can be specified as 0 to 262144) | The user-specified length must be greater than or equal to the length of the corresponding column on MaxCompute (ODPS). Otherwise, an error will be reported during execution. |
| STRING (up to 8 MB) | VARCHAR/TINYTEXT/TEXT/MEDIUMTEXT/LONGTEXT (MEDIUMTEXT is a TEXT type with a maximum length of 16,777,215 bytes, including the character set.) | You need to know the maximum length of a STRING data type in MaxCompute (ODPS) and determine the corresponding data type for mapping based on this information. | BINARY (up to 8 MB) | VARBINARY/TINYBLOB/BLOB/MEDIUMBLOB/LONGBLOB (BLOB values are treated as binary strings (byte strings), with a binary character set and collation. | TIMESTAMP_NTZ (stores UTC time with 9 decimal places in nanoseconds, completely independent of time zone) | DATETIME | Only DATETIME(6) is supported; others are not. TIMESTAMP is time zone-dependent, so it is not supported. |

### Mapping between the ARRAY type in OceanBase AI Database and the type in ODPS

| ----------------- | ------------------- |

| ARRAY(tinyint) | ARRAY\<boolean\> |
| ARRAY(smallint) | ARRAY\<smallint\> |
| ARRAY(int) | ARRAY\<int\> |
| ARRAY(bigint) | ARRAY\<bigint\> |
| ARRAY(float) | ARRAY\<float\> |
| ARRAY(double) | ARRAY\<double\> |
| ARRAY(varchar) | ARRAY\<varchar\> |
| ARRAY(varchar) | ARRAY\<string\> |
| ARRAY(array()) | ARRAY\<array\<\>\> |
