# About tables

Tables are the most basic data storage units in OceanSeek. A table contains specific data that a user can access. A table consists of rows, and a row consists of columns.

Before you create and use tables, administrators can plan tables based on business requirements by following these principles:

* Use tables based on the standard procedure and use reasonable table schemas to minimize data redundancy.

* Select a suitable SQL data type for each column.

   For more information about SQL data types, see [Overview of data types](../../500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/100.basic-elements-of-mysql-mode/100.data-type-of-mysql-mode/100.data-type-overview-of-mysql-mode.md).
  
* Choose a suitable table type based on your needs. OceanSeek currently supports non-partitioned tables and partitioned tables.
