# List of system functions supported for function-based indexes

This topic lists the system functions that can be directly or conditionally used for function-based indexes.

## System functions with parameter type requirements

The following system functions are prohibited from being used in function-based indexes when their parameters are of the TIME type. For example, for the `DATE` function, it is prohibited to use it in a function-based index when the first parameter is TIME; for the `DATEDIFF` function, it is prohibited to use it in a function-based index when any parameter is of the TIME type.

|------------|------------------|------------|---------------|
| DATE       | TIMESTAMP        | MONTHNAME  |  ADDDATE      |
| DATE_SUB   | DAY              | MONTH      | TIMESTAMP_NVL |
| DAYNAME    | YEAR             | TIMESTAMPDIFF | QUARTER    |
| DAYOFMONTH | WEEKOFYEAR       | TO_DAYS    | DAYOFWEEK     |
| WEEKDAY    | DATEDIFF         | DAYOFYEAR  | YEARWEEK      |
| TIMESTAMPADD  |  LAST_DAY     | WEEK       |    -          |

## JSON-related system functions

The expressions of the following JSON functions are allowed to be used in function-based indexes.

|-----------------|------------------|----------------|---------------------|
| JSON_EXTRACT    |  JSON_TYPE       | JSON_CONTAINS  | JSON_LENGTH         |
| JSON_CONTAINS_PATH  | JSON_INSERT  | JSON_DEPTH     | JSON_STORAGE_SIZE   |
| JSON_KEYS       | JSON_STORAGE_FREE|  JSON_ARRAY    | JSON_MERGE_PRESERVE |
| JSON_QUOTE      | JSON_MERGE       |  JSON_UNQUOTE  | JSON_MERGE_PATCH    |
| JSON_OVERLAPS   | JSON_PRETTY      |  JSON_REMOVE   | JSON_SET            |
| JSON_SEARCH     | 1 MEMBER OF      |  JSON_VALID    | JSON_VALUE          |
| JSON_ARRAY_APPEND | JSON_OBJECT    |  JSON_ARRAY_INSERT | JSON_QUERY      |
| JSON_REPLACE      | - | - | - |

In addition, the following functions are currently only allowed to be used in predicates.

|----------------------|-----------------------|
| JSON_EQUAL           | JSON_EXISTS           |

## CAST expressions

CAST expressions are special. When their target type or source type is a time type, they are prohibited from being used as part of a function-based index. The specific scenarios are shown in the following table.

| Source Type | Target Type | Description |
| ---------------------------------------- | -------------------------------- | ---------------- |
| TIME | DATETIME / TIMESTAMP / DATE | Not allowed as a function index |
| datetime/TIMESTAMP/DATE | TIMESTAMP WITH TIME ZONE / TIMESTAMP WITH LOCAL TIME ZONE | Not allowed as a function index |
