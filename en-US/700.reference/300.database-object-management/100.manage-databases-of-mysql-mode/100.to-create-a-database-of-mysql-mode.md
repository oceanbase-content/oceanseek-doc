# Create a database

This topic describes the `CREATE DATABASE` statement and how to use it.

## Prerequisites

Ensure that the current user has the `CREATE` privilege. For information about how to view your privileges, see [View user privileges](../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/400.view-user-permissions-of-mysql-mode.md). If you do not have the `CREATE` privilege, contact the administrator to grant it. For information about how to grant privileges, see [Grant privileges directly](../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/200.authority-of-mysql-mode.md).

## Procedure

1. Log in to a user tenant of the cluster.

2. Use the `CREATE DATABASE` statement to create a database.

   Examples:

   * Create a database named `test2` and set its character set to `UTF8`.

     ```shell
     obclient> CREATE DATABASE test2 DEFAULT CHARACTER SET UTF8;
     ```

   * Create a database named `test3` with read/write attributes.

     ```shell
     obclient> CREATE DATABASE test3 READ WRITE;
     ```

   * Create a database named `test4` with read-only attributes.

     ```shell
     obclient> CREATE DATABASE test4 READ ONLY;
     ```
