# View databases

This topic describes how to view databases by using the `SHOW DATABASES` statement.

## Procedure

1. Log in to a user tenant of the cluster.

2. Use the `SHOW DATABASES` statement to view the database information of the tenant.

   Here is an example:

   ```shell
   obclient> SHOW DATABASES;
   ```

   The query result is as follows:

   ```shell
   +--------------------+
   | Database           |
   +--------------------+
   | oceanbase          |
   | information_schema |
   | mysql              |
   | test               |
   +--------------------+
   3 rows in set
   ```

   * `information_schema` allows you to access the database metadata. This is a built-in database of the tenant.
   * `oceanbase` stores the system tables of OceanSeek.
   * `mysql` stores database users, privilege settings, and keywords.
   * `test` is a custom database created by the user.
