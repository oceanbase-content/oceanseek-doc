# Drop a database

This topic describes the `DROP DATABASE` statement and how to use it.

## Prerequisites

Ensure the current user has the `DROP` privilege. For information about how to view your privileges, see [View user privileges](../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/400.view-user-permissions-of-mysql-mode.md). If you do not have the `DROP` privilege, contact the administrator to grant it. For information about how to grant privileges, see [Grant privileges directly](../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/200.authority-of-mysql-mode.md).

## Procedure

1. Log in to a user tenant of the cluster.

2. Use the `DROP DATABASE` statement to drop a database.

   **Example:**

   ```shell
   obclient> DROP DATABASE my_db;
   ```

## What to do next

If you accidentally drop a database, you can restore it using the recycle bin feature, provided that the recycle bin feature is enabled. For related operations, see [Restore objects from the recycle bin](../../../600.manage/400.high-availability/500.recyclebin-management/400.restore-the-recyclebin-objects.md).
