# OceanBase Developer Center (ODC)

OceanBase Developer Center (ODC) is a GUI-based database development tool. It is also a collaborative management platform for data development and production change control. ODC comes in two forms: desktop ODC and web ODC. Desktop ODC focuses on database development capabilities, supports the Windows, macOS, and Linux operating systems, and is lightweight and easy to deploy. Web ODC provides both tool capabilities and management and collaboration capabilities, with a focus on the security, compliance, and efficiency of database changes.

ODC Web provides two workspace modes: Individual Workspace and Team Workspace. Individual Workspace is suitable for individual developers and provides a desktop-like experience in a browser. You can freely access and create data sources and use various windows and tools provided by the platform for database development. Team Workspace is designed for collaboration between developers and DBAs and serves as both a development tool and a management and collaboration platform. Through features such as project collaboration, stable change management, data security, and hot/cold data separation, ODC provides one-stop database development and management services.

## Features

### Efficient development

To help you develop databases efficiently, ODC provides a rich set of easy-to-use tools, including database object management, data import and export, SQL editing and execution, PL compilation and debugging, data and schema processing, execution analysis, and database O&M. To improve the user experience, ODC also supports the following features: generating SQL statements by dragging objects, Excel-like result set editing, syntax highlighting and SQL auto-completion during editing, code snippet definition and reference, and rapid test data generation.

### Change risk management

ODC provides a comprehensive solution for production security scenarios. Database addresses and credentials are entered by the DBA and then authorized for developer access, preventing credential leakage. ODC provides well-defined database development specifications, allowing you to flexibly define SQL check rules and SQL window blocking rules for different environments. Depending on the risk level, your operations may receive suggestions, require escalation to a DBA for approval, or be blocked, thereby controlling change risks and ensuring the stable operation of production systems.

![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/422/200.odc-overview/200.odc-overview/200.features/2.png)

### Security and compliance

ODC provides data desensitization and fine-grained auditing capabilities to ensure data security and compliance. With built-in advanced desensitization algorithms and flexible identification rules, ODC protects sensitive data in scenarios such as SQL window access and data export, meeting privacy and security compliance requirements. ODC also supports operation auditing and SQL auditing. All functional operations performed in ODC are synchronized to the Operation Records Center, and all SQL requests initiated in ODC are recorded.

![3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/422/200.odc-overview/200.odc-overview/200.features/3.png)

### Data lifecycle management

ODC provides data lifecycle management capabilities to deliver data processing solutions. These capabilities include data cleanup, data archiving, and partitioning plans. Through data cleanup, you can regularly purge expired data from business tables to reduce the size of online databases. Through data archiving, you can configure flexible archiving conditions to separate hot and cold data. Through partitioning plans, you can regularly add and delete partitions as needed to automatically maintain RANGE partitions.

![4](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/422/200.odc-overview/200.odc-overview/200.features/4.png)

### Integration with open platforms

ODC supports single sign-on (SSO) and integration with ticket approval, SQL review, and database bastion host systems. SSO supports the OAuth2 and OIDC protocols. Ticket approval supports integration with BPMS and custom approval systems. SQL review integration allows you to audit SQL statements on your enterprise's existing SQL review platform. Database bastion host integration supports capabilities such as authentication based on one-time tokens and automatic filling of database credentials.

![5](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/422/200.odc-overview/200.odc-overview/200.features/5.png)

### Efficient collaboration

ODC provides a series of features and design concepts to improve your efficiency. The batch import capability eliminates the need for tedious manual entry of individual records. The project OWNER manages all databases and members of the project, the project DBA manages all databases, and the project DEVELOPER focuses on accessing all project databases. To enable team collaboration, you only need to add collaborators to the specified project without configuring complex permissions. By configuring automatic authorization rules, visitors are automatically granted permissions when they meet the specified authorization conditions.
