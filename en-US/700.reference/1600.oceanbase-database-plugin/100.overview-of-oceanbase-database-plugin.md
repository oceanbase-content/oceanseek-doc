# Overview of OceanSeek plugins

The plugin mechanism provides a lightweight, flexible, and efficient way to extend database features. With this mechanism, you can customize and enhance OceanSeek to suit your specific needs.

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>The plugin mechanism is currently an experimental feature and is not recommended for use in production environments.</p>
</main>

## How to develop and use plugins

OceanSeek allows you to develop plugins using C/C++ and provides a complete plugin development kit (PDK). If your development environment includes the C/C++ development toolchain and the OceanSeek PDK is configured, you can quickly get started with plugin development.

## Supported scenarios

The plugin mechanism of OceanSeek currently supports the following scenarios:

* Tokenizer plugins: These plugins expand the full-text search capabilities of the database, allowing you to customize tokenization logic to meet diverse text processing requirements.
* External table JDBC plugins: These plugins allow you to access data sources supported by JDBC. The current version supports only the MySQL mode.


  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>OceanSeek supports the external table JDBC plugin service. In addition, it has released a MySQL external table plugin based on the JDBC plugin service.</p>
  </main>
