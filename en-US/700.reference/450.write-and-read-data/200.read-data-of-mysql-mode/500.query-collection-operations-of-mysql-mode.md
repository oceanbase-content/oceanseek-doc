# Set operations

In OceanSeek, you can use the set operators `UNION`, `UNION ALL`, `INTERSECT`, and `MINUS | EXCEPT` to combine multiple queries. These set operators have the same precedence. If an SQL statement contains multiple set operators, OceanSeek evaluates them from left to right, unless parentheses are used to explicitly specify the evaluation order.

This topic describes how to use the set operators `UNION`, `UNION ALL`, `INTERSECT`, and `MINUS`.

## Syntax

```sql
select_clause_set_left 
{ UNION | UNION ALL | MINUS | INTERSECT}
select_clause_set_right
```

For more information about set query syntax, see [UNION clause](../../../700.reference/500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/8100.select-of-mysql-mode/400.union-clause-of-mysql-mode.md).

**The parameters are described as follows:**

* `select_clause_set_left`: A `SELECT` statement that returns the left set for the set operation.
* `select_clause_set_right`: A `SELECT` statement that returns the right set for the set operation.
* `UNION`: Combines the result sets of two or more `SELECT` statements into one set and removes duplicate rows.
* `UNION ALL`: Combines the result sets of two or more `SELECT` statements into one set without removing duplicate rows.
* `INTERSECT`: Returns the intersection of the result sets of two `SELECT` statements.
* `MINUS | EXCEPT`: Returns the rows in the result set of the first `SELECT` statement that are not included in the result set of the second `SELECT` statement. `MINUS` is a synonym for `EXCEPT`.

<main id="notice" type='notice'>
<h4>Notice</h4>
<p>Each set operator can only operate on the result sets of <code>SELECT</code> statements, and the number of columns and data types in each result set must be the same.</p>
</main>

## Examples

Suppose there are two test tables, `test_tbl1` and `test_tbl2`, with the following data:

```shell
obclient [test]> SELECT * FROM test_tbl1;
+------+------+
| id   | name |
+------+------+
|    1 | A1   |
|    2 | A2   |
|    3 | A3   |
|    4 | A4   |
|    5 | A5   |
|    6 | A6   |
+------+------+
6 rows in set

obclient [test]> SELECT * FROM test_tbl2;
+------+------+
| id   | name |
+------+------+
|    1 | A1   |
|    2 | A2   |
|    3 | A3   |
|    7 | A7   |
|    8 | A8   |
|    9 | A9   |
+------+------+
6 rows in set
```

### UNION example

In the following SQL statement, `UNION` combines the result sets of two `SELECT` statements into one set, removing duplicate rows.

```sql
SELECT id, name FROM test_tbl1
UNION
SELECT id, name FROM test_tbl2;
```

The query result is as follows:

```shell
+------+------+
| id   | name |
+------+------+
|    1 | A1   |
|    2 | A2   |
|    3 | A3   |
|    4 | A4   |
|    5 | A5   |
|    6 | A6   |
|    7 | A7   |
|    8 | A8   |
|    9 | A9   |
+------+------+
9 rows in set
```

### UNION ALL example

In the following SQL statement, `UNION ALL` combines the result sets of two `SELECT` statements into one set, without removing duplicate rows.

```sql
SELECT id, name FROM test_tbl1
UNION ALL
SELECT id, name FROM test_tbl2;
```

The query result is as follows:

```shell
+------+------+
| id   | name |
+------+------+
|    1 | A1   |
|    2 | A2   |
|    3 | A3   |
|    4 | A4   |
|    5 | A5   |
|    6 | A6   |
|    1 | A1   |
|    2 | A2   |
|    3 | A3   |
|    7 | A7   |
|    8 | A8   |
|    9 | A9   |
+------+------+
12 rows in set
```

### INTERSECT example

In the following SQL statement, `INTERSECT` is used to return the intersection of the result sets from the two `SELECT` statements.

```sql
SELECT id, name FROM test_tbl1
INTERSECT
SELECT id, name FROM test_tbl2;
```

The query result is as follows:

```shell
+------+------+
| id   | name |
+------+------+
|    1 | A1   |
|    2 | A2   |
|    3 | A3   |
+------+------+
3 rows in set
```

### MINUS example

In the following SQL statement, `MINUS` or `EXCEPT` is used to return the rows in the result set of the first `SELECT` statement that are not included in the result set of the second `SELECT` statement.

```sql
SELECT id, name FROM test_tbl1
MINUS
SELECT id, name FROM test_tbl2;
```

or

```sql
SELECT id, name FROM test_tbl1
EXCEPT
SELECT id, name FROM test_tbl2;
```

The query result is as follows:

```shell
+------+------+
| id   | name |
+------+------+
|    4 | A4   |
|    5 | A5   |
|    6 | A6   |
+------+------+
3 rows in set
```
