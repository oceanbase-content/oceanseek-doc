# LEFT JOIN

A left join (LEFT JOIN) is a left outer join, which returns all records from the left table and the matching records from the right table whose join fields are equal.

## Background information

An outer join (OUTER JOIN) compares data in two tables using comparison operators. The join result includes not only rows that meet the join conditions but also rows that do not.

Outer joins include full joins (FULL JOIN), left joins (LEFT JOIN), and right joins (RIGHT JOIN). An outer join returns all rows that meet the join conditions, and returns unmatched rows from one table with `NULL` filled in the corresponding positions of the other table.

This topic provides examples of left joins. For examples of full joins, see [FULL JOIN](200.full-join-of-mysql-mode.md), and for examples related to right joins, see [RIGHT JOIN](400.right-join-of-mysql-mode.md).

## LEFT JOIN syntax

An outer join statement generally includes a left table and a right table. The table farthest to the left in the `JOIN` clause is the left table, and the table farthest to the right is the right table.

The syntax of LEFT JOIN is as follows:

```sql
SELECT select_list FROM table_name1 LEFT JOIN table_name2 ON join_condition
[ WHERE query_condition ]
[ ORDER BY column_list ];
```

Here, `table_name1` is the left table, and `table_name2` is the right table.

### Simple left join query

If you want the data returned by `JOIN` to include not only the data that meets the join and filter conditions but also the data in the left table that meets its own filter conditions but does not meet the join conditions, use a left outer join (`LEFT OUTER JOIN`), which can also be abbreviated as a left join (`LEFT JOIN`).

In a left join query, if a row in the left table cannot be found in the right table, `NULL` is automatically filled in for that row in the right table.

Example 1: Perform a left join query on tables `tbl_a` and `tbl_b` and obtain the result.

```sql
obclient> SELECT * FROM tbl_a;
+------+------+
| id   | name |
+------+------+
|    1 | ab   |
|    2 | cd   |
|    3 | ef   |
|    4 | gh   |
+------+------+
4 rows in set

obclient> SELECT * FROM tbl_b;
+--------+-------+
| number | value |
+--------+-------+
|      1 |  1001 |
|      3 |  1003 |
|      5 |  1005 |
+--------+-------+
3 rows in set

obclient> SELECT * FROM tbl_a LEFT JOIN tbl_b ON tbl_a.id=tbl_b.number;
+------+------+--------+-------+
| id   | name | number | value |
+------+------+--------+-------+
|    1 | ab   |      1 |  1001 |
|    2 | cd   |   NULL |  NULL |
|    3 | ef   |      3 |  1003 |
|    4 | gh   |   NULL |  NULL |
+------+------+--------+-------+
4 rows in set
```

### Combined use of left join and WHERE clause

You can use a left join to obtain the join result, and then use the `WHERE` clause to filter the join result.

Example 2: Perform a left join query on tables `tbl_a` and `tbl_b`, and return the data where `name='ab'` in table `tbl_a`.

```sql
obclient> SELECT * FROM tbl_a;
+------+------+
| id   | name |
+------+------+
|    1 | ab   |
|    2 | cd   |
|    3 | ef   |
|    4 | gh   |
+------+------+
4 rows in set

obclient> SELECT * FROM tbl_b;
+--------+-------+
| number | value |
+--------+-------+
|      1 |  1001 |
|      3 |  1003 |
|      5 |  1005 |
+--------+-------+
3 rows in set

obclient> SELECT * FROM tbl_a LEFT JOIN tbl_b ON tbl_a.id=tbl_b.number WHERE tbl_a.name='ab';
+------+------+--------+-------+
| id   | name | number | value |
+------+------+--------+-------+
|    1 | ab   |      1 |  1001 |
+------+------+--------+-------+
1 row in set
```
