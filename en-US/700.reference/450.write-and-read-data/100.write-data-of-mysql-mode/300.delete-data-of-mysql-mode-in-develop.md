# Delete data

After inserting data into a table, you can use the `DELETE` statement or other statements to delete records from the table. This topic describes how to use these statements and provides examples.

## Preparations for data deletion

Before deleting table data, confirm the following:

* Ensure you are connected to the database as a user tenant. For more information about connecting to a database, see [Overview of connection methods](../../../200.connect/100.connection-methods-overview.md).
  
  <main id="notice" type='explain'>
     <h4>Note</h4>
     <p>You can query the <code>oceanbase.DBA_OB_TENANTS</code> view in the <code>sys</code> tenant to confirm the tenant mode of the currently logged-in tenant.</p>
  </main>

* Ensure you have the `DELETE` privilege on the target table. If you use the `TRUNCATE TABLE` statement to clear table data, you must also have the `CREATE` privilege on that table. For more information about checking current user privileges, see [View user privileges](../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/400.view-user-permissions-of-mysql-mode.md). If you do not have this privilege, contact the administrator to grant the privilege. For more information about granting privileges to users, see [Grant privileges directly](../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/200.authority-of-mysql-mode.md).

## Delete data using the DELETE statement

The [DELETE](../../../700.reference/500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/3200.delete-of-mysql-mode.md) statement is typically used to delete partial or all data from a table.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>In addition to the <code>DELETE</code> statement, you can also use the <code>REPLACE INTO</code> statement to delete data. For related operations and examples of the <code>REPLACE INTO</code> statement, see <a href="400.replace-data-of-mysql-mode-in-develop.md">Replace data</a>.</p>
  </main>

The syntax for a simple `DELETE` statement is as follows:

```sql
DELETE FROM table_name [ WHERE condition ] ;
```

| Parameter | Required | Description |
| ------------------------- | --------- | -------------------------------------------------------- |
| table_name | Yes | The table from which data is to be deleted. |
| [ WHERE condition ] | No | The condition for deleting data. If no condition is specified, all data in the table is deleted. |

### Delete partial data

By adding a `WHERE` condition to the `DELETE` statement, you can delete partial data in a table that meets the specified conditions.

Delete all rows in the `t_insert` table where `value = 10004`. Example:

```sql
obclient [test]> DELETE FROM t_insert WHERE value = 10004;
Query OK, 1 row affected
```

### Delete all data

When the amount of data in a table is small, you can directly use the `DELETE` statement to delete all rows.

Example:

* Delete all row data from the `t_insert` table.

  ```sql
  obclient [test]> DELETE FROM t_insert;
  Query OK, 3 row affected
  ```

  When a table contains millions of records, a one-time DELETE operation may encounter performance issues. It is recommended to use the `WHERE` condition to delete data in batches based on the information in the table, or directly **use the TRUNCATE TABLE statement to clear the table data**.

* Filter the data in the `value` column of table `t_insert` and execute multiple statements to delete data in batches where `value < 10000`, `value < 20000`, and `value < 30000`.

  ```sql
  obclient [test]> DELETE FROM t_insert WHERE value < 100000;

  obclient [test]> DELETE FROM t_insert WHERE value < 200000;

  obclient [test]> DELETE FROM t_insert WHERE value < 300000;
  ```

## Use the TRUNCATE TABLE statement to clear table data

The `TRUNCATE TABLE` statement is used to completely clear a specified table while retaining the table structure, including the partition information defined in the table. Logically, this statement is equivalent to a `DELETE FROM` statement that deletes all rows.

The syntax for the `TRUNCATE TABLE` statement is as follows:

```sql
TRUNCATE [TABLE] table_name;
```

Use the `TRUNCATE TABLE` statement to clear all data from table `t_insert`, as shown in the following example:

```sql
obclient [test]> TRUNCATE TABLE t_insert;
```

For more information about the `TRUNCATE TABLE` statement, see [TRUNCATE TABLE](../../../700.reference/500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/8900.truncate-table-of-mysql-mode.md).
