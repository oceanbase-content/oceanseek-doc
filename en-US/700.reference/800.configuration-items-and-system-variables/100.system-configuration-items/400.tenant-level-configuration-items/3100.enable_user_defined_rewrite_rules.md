# enable_user_defined_rewrite_rules

## Overview

`enable_user_defined_rewrite_rules` specifies whether to enable the rewrite binding feature.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Both the `sys` tenant and user tenants can modify this parameter.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Parameter type | Bool |
| Default Value | False |
| Value range | <ul><li> True: enabled. </li><li>False: disabled. </li></ul> |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Usage instructions

The [Overview of DBMS_UDR](../../../600.pl-reference/1000.pl-system-package-mysql/17800.dbms-udr-mysql/100.dbms-udr-overview-mysql.md) system package provides the rewrite binding feature:

* Create a custom rewrite rule: [CREATE_RULE](../../../600.pl-reference/1000.pl-system-package-mysql/17800.dbms-udr-mysql/200.create-rule-mysql.md)
* Disable a custom rewrite rule: [DISABLE_RULE](../../../600.pl-reference/1000.pl-system-package-mysql/17800.dbms-udr-mysql/300.disable-rule-mysql.md)
* Enable a custom rewrite rule: [ENABLE_RULE](../../../600.pl-reference/1000.pl-system-package-mysql/17800.dbms-udr-mysql/400.enable-rule-mysql.md)
* Remove a custom rewrite rule: [REMOVE_RULE](../../../600.pl-reference/1000.pl-system-package-mysql/17800.dbms-udr-mysql/500.remove-rule-mysql.md)

## Configuration example

Sets the rewrite binding feature to off.

```shell
obclient> ALTER SYSTEM SET enable_user_defined_rewrite_rules = False;
```
