# audit_log_compression

## Overview

`audit_log_compression` specifies the compression algorithm used for audit logs.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Both the `sys` tenant and user tenants can use the `ALTER SYSTEM SET` statement to modify this parameter.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Parameter type | String |
| Default Value | NONE: Compression is not enabled. |
| Value range | <ul><li>NONE</li> <li>ZSTD</li></ul> |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Usage instructions

Archiving is triggered when a file exceeds the size specified by `audit_log_rotate_on_size`. This parameter controls whether archived files need to be compressed.

## Configuration example

Set the compression algorithm for audit logs to ZSTD.

```shell
obclient> ALTER SYSTEM SET audit_log_compression='ZSTD';
```
