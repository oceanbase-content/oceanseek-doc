# writing_throttling_trigger_percentage

## Overview

`writing_throttling_trigger_percentage` specifies the percentage of the MemStore memory upper limit that triggers write throttling. When the MemStore memory usage reaches this threshold, write throttling is triggered.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Both the `sys` tenant and user tenants can modify this parameter.

## Attributes

| **Attribute** | **Description** |
| -------------------- | -------------- |
| Parameter type | Int |
| Default Value | 60 |
| Value range | [1, 100] |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Usage instructions

* OceanBase AI Database uses the MemStore to store recently written data. To prevent memory overflow, the system provides two important protection mechanisms:

  * Minor compaction: Persist data in memory to disk to free up memory space.

  * Throttling mechanism: When memory pressure is high, write speed is reduced to gain time for memory release.

  These two mechanisms are controlled by two tenant-level parameters to determine the trigger timing: [freeze_trigger_percentage](3300.freeze_trigger_percentage.md) (freezing threshold) and `writing_throttling_trigger_percentage` (throttling threshold).

  To avoid performance degradation caused by premature throttling, the value of `writing_throttling_trigger_percentage` must be greater than the value of [freeze_trigger_percentage](3300.freeze_trigger_percentage.md).

* When the memory used by the MemStore reaches this threshold, write throttling is triggered. A value of 100 for this parameter disables the write throttling mechanism.

## Configuration example

Set the write throttling threshold when the used memory of the MemStore reaches 60% of its upper limit.

```shell
obclient> ALTER SYSTEM SET writing_throttling_trigger_percentage = 60;
```
