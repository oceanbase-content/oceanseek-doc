# default_delta_format

## Overview

`default_delta_format` specifies the default incremental data storage format when a table is created.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Both the `sys` tenant and user tenants can modify this parameter.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Parameter type | String |
| Default Value | flat |
| Value range | <ul><li>`flat`: flat data format. </li><li>`encoding`: the encoding data format. </li></ul> |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Usage instructions

You can modify the `default_delta_format` parameter to adjust the default incremental data format of a table, eliminating the need to specify it repeatedly during table creation:

* `flat`: Fast write speed and low compression ratio, suitable for OLTP scenarios.
* `encoding`: The write speed is relatively slow, but the compression ratio is high. This mode can improve query performance in OLAP scenarios and reduce the storage space required for incremental data. It yields better query results when the table's `MERGE_ENGINE` is set to `delete_insert`. For information about setting the table's `MERGE_ENGINE`, see the **Specify the table's update model** section in [Create a table](../../../300.database-object-management/200.manage-tables-of-mysql-mode/200.create-a-table-for-mysql-tenant-of-mysql-mode.md).

## Configuration example

* Sets `encoding` as the default incremental data format for tables created subsequently in the user tenant.

    ```shell
    obclient> ALTER SYSTEM SET default_delta_format = "encoding";
    ```

* Sets `flat` as the default incremental data format for tables created subsequently in the user tenant.

    ```shell
    obclient> ALTER SYSTEM SET default_delta_format = "flat";
    ```
