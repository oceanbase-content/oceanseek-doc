# load_vector_index_on_follower

## Overview

`load_vector_index_on_follower` specifies whether the `follower` role automatically loads memory-based vector indexes. This includes `follower` nodes in the primary cluster, as well as `leader` and `follower` nodes in the standby cluster. When this parameter is set to `false`, the aforementioned nodes will not automatically load vector indexes into memory. Note that this parameter setting is not synchronized to the standby cluster; therefore, in a primary-standby cluster scenario, both clusters must be configured separately.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Both the `sys` tenant and user tenants can modify this parameter.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Parameter type | Bool |
| Default Value | true |
| Value range | true/false |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Configuration example

Set this parameter to `true` to enable automatic synchronization of in-memory vector indexes by the follower.

```sql
ALTER SYSTEM SET load_vector_index_on_follower = true;
```
