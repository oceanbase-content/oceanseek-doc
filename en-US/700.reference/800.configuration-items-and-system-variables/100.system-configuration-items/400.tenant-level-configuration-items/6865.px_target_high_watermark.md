# px_target_high_watermark

## Overview

`px_target_high_watermark` specifies the high-watermark percentage threshold for controlling the number of parallel threads. The closer the real-time load is to this threshold, the greater the degree of parallelism is reduced. When the load exceeds this threshold, the degree of parallelism drops to 1.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Both the `sys` tenant and user tenants can modify this parameter.

## Attributes

| **Attribute** | **Description** |
| ----------- | ---------- |
| Parameter type | Int |
| Default Value | 80 |
| Value range | [0, 100] |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Usage instructions

The value of the `px_target_high_watermark` parameter must satisfy the following relationship:

[px_target_low_watermark](6870.px_target_low_watermark.md) <= `px_target_high_watermark` <= [px_target_workers_per_cpu](6880.px_target_workers_per_cpu.md)

## Configuration example

Set the high-watermark percentage threshold for the number of parallel threads to 7.

```shell
obclient> ALTER SYSTEM SET px_target_high_watermark = 7;
```
