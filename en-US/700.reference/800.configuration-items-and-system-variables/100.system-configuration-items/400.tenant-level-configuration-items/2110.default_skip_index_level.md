# default_skip_index_level

## Overview

`default_skip_index_level` specifies the default value of `skip_index_level` for creating tables in a tenant.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Both the `sys` tenant and user tenants can modify this parameter.

## Attributes

| **Attribute** | **Description** |
| ---------- | ---------- |
| Parameter type | INT |
| Default Value | 0 |
| Value range | <ul><li>0: Indicates that the columnar baseline of a table generates skip-index aggregation information. The row-based baseline generates skip-index aggregation information based on the schema, while incremental SSTables do not generate skip-index aggregation information.</li><li>1: Indicates that, in addition to what is specified for 0, the incremental SSTables of a table also generate skip-index aggregation information based on the baseline behavior.</li></ul> |
| Modifiable | Yes, you can use the following methods:`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Usage instructions

The `default_skip_index_level` parameter only affects the default format for creating primary tables in user tenants. It does not affect the `meta` or `sys` tenant. Additionally, it only takes effect when the `skip_index_level` clause is not explicitly specified in the table creation statement. If the user explicitly specifies the table's `skip_index_level`, the final table's `skip_index_level` will be parsed according to the user-specified format.

This parameter can be set to the following values:

* 1: If skip_index_level is not specified in the table creation statement, the skip_index_level for creating a table by a user tenant is set to 1.
* 0: If skip_index_level is not specified in the table creation statement, the skip_index_level for creating a table by a user tenant is 0.

Modifying the value of this parameter does not affect tables that have already been created.

## Configuration example

The default value of `skip_index_level` for creating tables in a user tenant is set to 1.

```shell
obclient> ALTER SYSTEM SET default_skip_index_level = 1;
```
