# audit_log_buffer_size

## Overview

`audit_log_buffer_size` specifies the buffer size for asynchronous log writing.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Both the `sys` tenant and user tenants can use the `ALTER SYSTEM SET` statement to modify this parameter.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Parameter type | Capacity |
| Default Value | 16M |
| Value range | [16M, 256M] |
| Modifiable | Yes, you can use the following methods:`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Usage instructions

When audit logs are written asynchronously, worker threads request memory from a buffer and place it into the I/O queue. This parameter controls the size of the buffer.

## Configuration example

Set the buffer size for asynchronous log writing to 16 MB.

```shell
obclient> ALTER SYSTEM SET audit_log_buffer_size='16M';
```
