# rpc_memory_limit_percentage

## Overview

`rpc_memory_limit_percentage` specifies the maximum percentage of memory for RPCs in a tenant relative to the total memory of the tenant.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Both the `sys` tenant and user tenants can modify this parameter.

## Attributes

| Attribute | Description |
| ------------------ | ------- |
| Parameter type | Int |
| Default Value | 0 indicates that there is no limit on RPC memory. |
| Value range | [0,100] |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Configuration example

Set the maximum memory for RPCs in a tenant as 10% of the total tenant memory.

```shell
obclient> ALTER SYSTEM SET rpc_memory_limit_percentage=10;
```
