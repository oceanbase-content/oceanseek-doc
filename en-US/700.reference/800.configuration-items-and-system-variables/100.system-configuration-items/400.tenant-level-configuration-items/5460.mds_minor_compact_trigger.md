# mds_minor_compact_trigger

## Overview

`mds_minor_compact_trigger` specifies the number of SSTables that trigger a minor compaction for MDS. When the total number of MDS SSTables reaches or exceeds this threshold, a minor compaction is triggered to merge all MDS SSTables into a new MDS Minor SSTable.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  This parameter can be modified for both the `sys` and user tenants.

## Attributes

| **Attribute** | **Description** |
| ------------------ | -------------- |
| Parameter type | Int |
| Default Value | 2 |
| Value range | [2,16] |
| Modifiable | Yes, you can use the following methods:`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Configuration example

* The user tenant sets the number of SSTables that trigger a minor compaction for the MDS to 2.

  ```shell
  obclient> ALTER SYSTEM SET mds_minor_compact_trigger = 2;
  ```

* The system tenant (`sys`) sets the number of SSTables that trigger a minor compaction for tenant `mysql` to 2.

  ```shell
  obclient> ALTER SYSTEM SET mds_minor_compact_trigger = 2 TENANT = 'mysql';
  ```
