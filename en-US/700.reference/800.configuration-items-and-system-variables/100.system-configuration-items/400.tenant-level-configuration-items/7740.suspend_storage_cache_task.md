# suspend_storage_cache_task

## Overview

`suspend_storage_cache_task` is used to set whether to suspend background cache tasks.

## Privilege requirements

* Query parameters

  The `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view can be used by the `sys` tenant and all user tenants to query this parameter.

* Modify parameters

  Both the `sys` tenant and user tenants can modify this parameter.

## Attributes

| **Attribute** | **Description** |
| ---------- | ---------- |
| Parameter type | Bool |
| Default Value | False |
| Value range | <ul><li>`True`: Pause all current and new cache tasks.</li> <li>`False`: Do not pause the background caching task; continue the caching task normally. </li></ul> |
| Modifiable | Yes, you can use the following methods:`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Configuration example

* User tenant

  1. Stop the cache task for this tenant.

     ```shell
     obclient> ALTER SYSTEM SET suspend_storage_cache_task = True;
     ```

  2. Set to normally proceed with cache tasks under this tenant.

     ```shell
     obclient> ALTER SYSTEM SET suspend_storage_cache_task = False;
     ```

* System tenant

  1. Stop the cache task under the paused tenant `mysqltenant`.

     ```shell
     obclient> ALTER SYSTEM SET suspend_storage_cache_task = True TENANT = mysqltenant;
     ```

  2. Set up the cache task for normal progression under tenant `mysqltenant`.

     ```shell
     obclient> ALTER SYSTEM SET suspend_storage_cache_task = False TENANT = mysqltenant;
     ```
