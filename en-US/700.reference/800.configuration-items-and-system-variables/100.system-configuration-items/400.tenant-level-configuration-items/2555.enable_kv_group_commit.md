# enable_kv_group_commit

## Overview

`enable_kv_group_commit` specifies whether to enable group commit.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Both the `sys` tenant and user tenants can modify this parameter.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Parameter type | Bool |
| Default Value | False |
| Value range | <ul><li>True: When enabled, the server groups operations by execution plan and executes them in groups.</li><li>False: When disabled, the server executes operations one by one according to the original process.</li></ul> |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Configuration example

Enable group commit.

```shell
obclient> ALTER SYSTEM SET enable_kv_group_commit=True;
```
