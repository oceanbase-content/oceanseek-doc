# freeze_trigger_percentage

## Overview

`freeze_trigger_percentage` specifies the threshold percentage of memory used by a tenant's MemStore that triggers a freeze.

## Attributes

| **Attribute** | **Description** |
| ------------------ | ----------- |
| Parameter type | Int |
| Default Value | 20 |
| Value range | (0, 100) |
| Modifiable | Yes, you can use the following methods:`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Usage instructions

* OceanSeek uses the MemStore to store recently written data. To prevent memory overflow, the system provides two important protection mechanisms:

  * Freezing mechanism: Persist data in memory to disk to free up memory space.

  * Throttling mechanism: When memory pressure is high, the write speed is reduced to gain time for memory release.

  These two mechanisms use two tenant-level parameters to control the trigger timing: `freeze_trigger_percentage` (freezing threshold) and [writing_throttling_trigger_percentage](8500.writing_throttling_trigger_percentage.md) (throttling threshold).

  To avoid performance degradation caused by premature throttling, the value of [writing_throttling_trigger_percentage](8500.writing_throttling_trigger_percentage.md) must be greater than the value of `freeze_trigger_percentage`.

* You can adjust the proportion of MemStore in tenant memory using the following parameter:

  * When the memory usage of a tenant's active MemStore reaches `freeze_trigger_percentage * memstore_limit` (where `memstore_limit = tenant_memory * memstore_limit_percentage`), the system automatically triggers the precursor action to [minor compaction](../../../200.system-management/500.manage-data-storage/100.dump-management/100.dump-management-overview.md), and then schedules a minor compaction. After the minor compaction, the system releases the occupied MemStore memory.

  * When memory is insufficient, you can increase the value of `memstore_limit_percentage` and decrease the value of `freeze_trigger_percentage` to achieve temporary memory expansion and prompt minor compaction for memory release. The parameter `memstore_limit_percentage` specifies the proportion of tenant memory available for MemStore writes. Its default value is 0, indicating that the system adaptively adjusts this proportion based on tenant memory availability.

## Configuration example

Set the threshold percentage of MemStore memory used by a tenant that triggers a freeze to 20.

```shell
obclient> ALTER SYSTEM SET freeze_trigger_percentage=20;
```
