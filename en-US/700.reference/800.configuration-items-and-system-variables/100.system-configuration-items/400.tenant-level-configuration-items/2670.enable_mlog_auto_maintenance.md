# enable_mlog_auto_maintenance

## Overview

`enable_mlog_auto_maintenance` specifies whether to enable automatic management of materialized view logs (mlogs).

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Both the `sys` tenant and user tenants can modify this parameter.

## Attributes

| **Attribute** | **Description** |
| ---------- | ---------- |
| Parameter type | Bool |
| Default Value | True |
| Value range | <ul><li>True: Indicates that the automatic management feature for Mlogs is enabled.</li><li>False: Indicates that the automatic management feature for Mlogs is disabled.</li></ul> |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Configuration example

* Disable automatic management of mlogs.

    ```shell
    obclient> ALTER SYSTEM SET enable_mlog_auto_maintenance = False;
    ```

* Enable automated management of Mlogs.

    ```shell
    obclient> ALTER SYSTEM SET enable_mlog_auto_maintenance = True;
    ```
