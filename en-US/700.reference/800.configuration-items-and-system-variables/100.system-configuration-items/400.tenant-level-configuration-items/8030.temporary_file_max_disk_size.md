# temporary_file_max_disk_size

## Overview

The `temporary_file_max_disk_size` parameter specifies the maximum disk space that a temporary file can occupy on a single node of a tenant.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Both the `sys` tenant and user tenants can modify this parameter.

## Attributes

| **Attribute** | **Description** |
| -------------------- | -------------- |
| Parameter type | Capacity |
| Default Value | 0M indicates that there is no limit on the maximum disk space that temporary files can occupy. |
| Value range | \[0M, +∞) |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Sample query

Set the maximum disk space for temporary files on a single node of a tenant to 100 GB.

```shell
obclient> ALTER SYSTEM SET temporary_file_max_disk_size = '100GB';
```
