# ob_result_cache_evict_percentage

## Overview

`ob_result_cache_evict_percentage` specifies the memory eviction threshold for the `result cache`.

## Privilege requirements

* Query parameters

  The `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Both the `sys` tenant and user tenants can modify this parameter.

## Attributes

| **Attribute** | **Description** |
| ----------- | --------------- |
| Parameter type | Int |
| Default Value | 90 |
| Value range | [0,100] |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Configuration example

Run the following command to set the `result cache` memory eviction threshold to 80.

```shell
obclient> ALTER SYSTEM SET ob_result_cache_evict_percentage= 80;
```
