# balancer_idle_time

## Overview

`balancer_idle_time` specifies the interval at which idle threads of background tasks such as load balancing are awakened.

* In the sys tenant: controls the time interval for disaster recovery threads and balancing threads.
* In a user tenant: controls the time interval for balancing log stream threads within the tenant.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Both the `sys` tenant and user tenants can modify this parameter.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Parameter type | Time |
| Default Value | 10s, which indicates 10 seconds. |
| Value range | [10s, +∞) |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Configuration example

* Set the time interval for all tenants under the `sys` tenant to control disaster recovery threads and balance threads to 10 seconds.

  ```shell
  obclient(root@sys)[oceanbase]> ALTER SYSTEM SET balancer_idle_time = '10s' tenant = ALL;
  ```

* Set the time interval for tenant1 to 10 minutes in the `sys` tenant.

  ```shell
  obclient(root@sys)[oceanbase]> ALTER SYSTEM SET balancer_idle_time = '10m' tenant = 'tenant1';
  ```

* Set the interval to 10 minutes in the user tenant.

  ```shell
  obclient> ALTER SYSTEM SET balancer_idle_time = '10m';
  ```
