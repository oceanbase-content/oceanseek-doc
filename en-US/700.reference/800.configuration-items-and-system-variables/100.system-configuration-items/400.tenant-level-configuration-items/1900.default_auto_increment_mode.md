# default_auto_increment_mode

## Overview

`default_auto_increment_mode` specifies the default auto-increment mode for auto-increment columns.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Both the `sys` tenant and user tenants can modify this parameter.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Parameter type | String |
| Default Value | order |
| Value range | <ul><li>order: The data in the auto-increment column remains incremental.</li> <li>noorder: The auto-increment column only guarantees that the auto-increment value is unique.</li></ul> |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Configuration example

Set the default auto-increment mode for auto-increment columns to order.

```shell
obclient> ALTER SYSTEM SET default_auto_increment_mode = 'order';
```
