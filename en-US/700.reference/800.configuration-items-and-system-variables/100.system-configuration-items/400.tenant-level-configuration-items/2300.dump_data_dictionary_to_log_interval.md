# dump_data_dictionary_to_log_interval

## Overview

`dump_data_dictionary_to_log_interval` specifies the interval for persisting tenant data dictionaries.

## Privilege requirements

* Query parameters

  The `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Both the `sys` tenant and user tenants can modify this parameter.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Parameter type | Time |
| Default Value | 0. The default unit is seconds. <main id="notice" type='explain'><h4>Note</h4><p>When the value is 0, the data dictionary will not be generated through scheduling based on this parameter. To stop generating the data dictionary, you need to use it together with`DBMS_DATA_DICT.DISABLE_DUMP()`command.</p></main> |
| Value range | [0s, +∞) |
| Modifiable | Yes, you can use the following methods:`ALTER SYSTEM SET`Statement modification. |
| Whether to Restart the OBServer Node for the Change to Take Effect | No, the setting takes effect immediately. |

## Usage instructions

The data dictionary serves only user tenants and is persisted in the system log stream (SYS_LS) of a regular tenant via PALF. After a user tenant is created, the data dictionary service is automatically enabled and runs on the LEADER replica of the tenant's SYS_LS.

When the log archiving service is enabled, an asynchronous data dictionary generation task is automatically triggered. OceanSeek supports scheduled data dictionary generation through the tenant-level parameter `dump_data_dictionary_to_log_interval` and the DBMS_DATA_DICT system package. It is recommended to schedule data dictionary generation using the [DBMS_DATA_DICT](../../../600.pl-reference/1000.pl-system-package-mysql/23000.dbms-data-dict-mysql/100.dbms-data-dict-mysql.md) system package.

OceanSeek supports recording data dictionary generation records through DBA/CDB views. You can query the [CDB_OB_DATA_DICTIONARY_IN_LOG](../../../700.system-views/300.system-view-of-sys-tenant/200.dictionary-view-of-sys-tenant/8200.o-cdb_ob_data_dictionary_in_log-of-sys-tenant.md) view in the sys tenant, or the [DBA_OB_DATA_DICTIONARY_IN_LOG](../../../700.system-views/400.system-view-of-mysql-mode/200.dictionary-view-of-mysql-mode/8300.o-dba_ob_data_dictionary_in_log-of-mysql-mode.md) view in a user tenant to obtain dictionary location information.

## Configuration example

Set the tenant data dictionary persistence cycle to 24H.

```shell
obclient> ALTER SYSTEM SET dump_data_dictionary_to_log_interval = '24H';
```
