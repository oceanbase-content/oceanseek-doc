# kv_transport_compress_func

## Overview

`kv_transport_compress_func` specifies the compression algorithm used for transmitting query results in OBKV-Table.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Only the `sys` tenant can modify this parameter. User tenants cannot modify it.

## Attributes

| **Attribute** | **Description** |
| ------------------ | -------------- |
| Parameter type | Capacity |
| Default Value | none |
| Value range | <ul><li> none</li><li> lz4_1.0</li><li> snappy_1.0</li><li> zlib_1.0, view-only</li><li> zstd_1.0</li><li> zstd 1.3.8</li><li> zstd 1.5.7</li></ul> |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Configuration example

Set the compression algorithm used for transmitting query results in OBKV-Table to lz4_1.0.

```shell
obclient> ALTER SYSTEM SET kv_transport_compress_func = 'lz4_1.0';
```
