# load_data_diagnosis_log_max_size

## Overview

`load_data_diagnosis_log_max_size` specifies the maximum size of a single diagnostic log file.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Both the `sys` tenant and user tenants can modify this parameter.

## Attributes

| **Attribute** | **Description** |
| ---------- | ---------- |
| Parameter type | Capacity |
| Default Value | 256M |
| Value range | [0M, +∞) |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Usage instructions

Audit records are continuously appended to the `diagnosis.log` file. When the size of `diagnosis.log` reaches `load_data_diagnosis_log_max_size`, a new file is automatically generated and writing continues there.

## Configuration example

Set the size of a single diagnostic log file to 128 MB.

```shell
obclient> ALTER SYSTEM SET load_data_diagnosis_log_max_size = '128M';
```
