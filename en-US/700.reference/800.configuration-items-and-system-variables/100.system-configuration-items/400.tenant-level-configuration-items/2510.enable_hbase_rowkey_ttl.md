# enable_hbase_rowkey_ttl

## Overview

`enable_hbase_rowkey_ttl` controls the enablement and disablement of the Rowkey TTL feature in OBKV-HBase. When enabled, Rowkeys will support expiration-based deletion. The system marks expired Rowkeys during queries, and background tasks periodically clean up the expired columns or multi-version data corresponding to these Rowkeys. When disabled, even if `enable_kv_ttl` is enabled, only the normal TTL will take effect, and Rowkeys will no longer support expiration-based deletion.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  This parameter can be modified by both the `sys` tenant and user tenants.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Parameter type | Boolean |
| Default Value | False |
| Value range | <ul><li>True: enabled. </li><li>False: disabled. </li></ul> |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Configuration example

Enable the Rowkey TTL feature:

```shell
obclient> ALTER SYSTEM SET enable_hbase_rowkey_ttl = true;
```
