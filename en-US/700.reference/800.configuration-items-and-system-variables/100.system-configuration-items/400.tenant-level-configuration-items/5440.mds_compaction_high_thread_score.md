# mds_compaction_high_thread_score

## Overview

`mds_compaction_high_thread_score` specifies the number of threads for the DAG (direct acyclic graph) of high-priority MDS compaction. The high-priority queue of MDS compaction is used by MDS Mini Dump.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Both the `sys` tenant and user tenants can modify this parameter.

## Attributes

| **Attribute** | **Description** |
| ------------------ | -------------- |
| Parameter type | Int |
| Default Value | 0: Use the default value 2. |
| Value range | [0,100] |
| Modifiable | Yes, you can use the following methods:`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Configuration example

* The user tenant sets the number of DAG threads for high-priority MDS compaction in the current tenant to 4.

  ```shell
  obclient> ALTER SYSTEM SET mds_compaction_high_thread_score = 4;
  ```

* The system tenant (`sys`) sets the number of DAG threads for high-priority MDS compaction in tenant `mysql` to 4.

  ```shell
  obclient> ALTER SYSTEM SET mds_compaction_high_thread_score = 4 TENANT = 'mysql';
  ```
