# kv_group_commit_rw_mode

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter takes effect only when the operation is performed in the OBKV-Table model.</p>
</main>

## Overview

`kv_group_commit_rw_mode` is used to control the scenarios where group commit is performed.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Both the `sys` tenant and user tenants can modify this parameter.

## Attributes

| **Attribute** | **Description** |
| ------------------ | -------------- |
| Parameter type | STRING |
| Default Value | ALL |
| Value range | <ul><li>ALL: Both read and write operations use group commit. </li><li>WRITE: Write operations use group commit. </li><li>READ: Read operations use group commit. </li></ul> |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Configuration example

It is set to allow only read operations to use group commits.

```shell
obclient> ALTER SYSTEM SET kv_group_commit_rw_mode = 'READ' tenant=<tenant_name>;
```
