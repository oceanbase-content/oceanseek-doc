# writing_throttling_maximum_duration

## Overview

`writing_throttling_maximum_duration` controls the write speed by regulating the memory allocation progress. Specifically, it specifies the time required to allocate all remaining MemStore memory after write throttling is triggered.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  This parameter can be modified by both the `sys` tenant and user tenants.

## Attributes

| **Attribute** | **Description** |
| ------------------ | -------------- |
| Parameter type | Time |
| Default Value | 2h |
| Value range | [1s, 3d] |
| Modifiable | Yes, you can use the following methods:`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Configuration example

The time required to allocate the remaining MemStore memory after triggering write throttling is set to 2 hours.

```shell
obclient> ALTER SYSTEM SET writing_throttling_maximum_duration = '2h';
```
