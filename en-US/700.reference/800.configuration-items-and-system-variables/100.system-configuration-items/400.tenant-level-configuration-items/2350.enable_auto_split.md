# enable_auto_split

## Overview

`enable_auto_split` specifies whether to enable automatic partitioning for a tenant.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Both the `sys` tenant and user tenants can use the `ALTER SYSTEM SET` statement to modify this parameter.

## Attributes

| **Attribute** | **Description** |
| ----------- | ---------- |
| Parameter type | BOOL |
| Default Value | FALSE |
| Value range | <ul><li>TRUE: Indicates that the auto-partitioning feature is enabled.</li><li>FALSE (default): Indicates that the auto-partitioning feature is disabled.</li></ul> |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Usage instructions

You can execute the `ALTER SYSTEM SET` statement to modify the value of a parameter.

The `enable_auto_split` parameter determines whether to create an auto-partitioned table when the table creation statement does not explicitly specify automatic partitioning using the AUTOPARTITION clause. If the table is explicitly set to use automatic partitioning, this parameter does not take effect.

* If `enable_auto_split` is set to `true`, a table will be automatically partitioned only if it meets the requirements for automatic partitioning upon creation.
* If `enable_auto_split` is `false` and later changed to `true`, this change does not take effect on existing tables that meet the auto-partitioning criteria; it only takes effect on newly created tables.

For more information about automatic partitioning, see [Automatic partition splitting](../../../300.database-object-management/300.manage-partitions-of-mysql-mode/250.partition-splitting-of-mysql-mode/300.automatic-partition-splitting-of-mysql-mode.md).

## Configuration example

Enable automatic partitioning.

```sql
ALTER SYSTEM SET enable_auto_split = TRUE;
```
