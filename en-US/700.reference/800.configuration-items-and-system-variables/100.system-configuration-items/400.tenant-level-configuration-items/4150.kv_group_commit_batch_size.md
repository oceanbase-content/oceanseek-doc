# kv_group_commit_batch_size

## Overview

`kv_group_commit_batch_size` specifies the size of the batch operations executed during group commits in OBKV. A value of 1 disables group commit. A value greater than 1 enables group commit and specifies the size of each batch for group commit.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  This parameter can be modified by both the `sys` tenant and user tenants.

## Attributes

| **Attribute** | **Description** |
| ------------------ | -------------- |
| Parameter type | Int |
| Default Value | 1 |
| Value range | (0, +∞) |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Configuration example

Set the batch_size for group commits to 10.

```shell
obclient> ALTER SYSTEM SET kv_group_commit_batch_size = 10;
```
