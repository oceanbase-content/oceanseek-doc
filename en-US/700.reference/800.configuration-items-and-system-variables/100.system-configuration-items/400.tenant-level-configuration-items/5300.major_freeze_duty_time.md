# major_freeze_duty_time

## Overview

`major_freeze_duty_time` specifies the trigger time for daily scheduled freezes and major compactions.

## Privilege requirements

* Query parameters

  The `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view can be used by both the sys tenant and all user tenants to query this parameter.

* Modify parameters

  Both the sys tenant and user tenants can modify this parameter.

## Attributes

| **Attribute** | **Description** |
| ------------------ | ------------------ |
| Parameter type | Moment |
| Default Value | 02:00 |
| Value range | \[00:00, 23:59\] or disable |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Usage instructions

When the value of `major_freeze_duty_time` is set to `disable`, the daily major compaction feature is disabled.

## Configuration example

Set the daily major compaction trigger time to `02:00`.

```shell
obclient> ALTER SYSTEM SET major_freeze_duty_time = '02:00';
```
