# enable_manual_storage_cache_policy

## Overview

`enable_manual_storage_cache_policy` is used to enable a user-specified hotspot caching policy.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Both the `sys` tenant and user tenants can modify this parameter.

  <main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>The manual hot data caching strategy setting takes effect only in user tenants. When you modify this parameter in non-user tenants (<code>sys</code> tenant and Meta tenant), the parameter value is updated, but the feature does not take effect.</p>
  </main>

## Configuration example

* Enable user-specified hotspot caching policies for user tenants.

  ```shell
  obclient> ALTER SYSTEM SET enable_manual_storage_cache_policy= True;
  ```

* In the sys tenant, enable a user-specified hotspot caching strategy for the `mysqltenant` tenant.

  ```shell
  obclient> ALTER SYSTEM SET enable_manual_storage_cache_policy= True TENANT = mysqltenant;
  ```
