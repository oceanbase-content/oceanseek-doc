# px_target_low_watermark

## Overview

`px_target_low_watermark` specifies the percentage threshold for the low-watermark of the number of parallel threads. When the number of parallel threads exceeds this threshold, downgrading control is initiated for the degree of parallelism of newly scheduled DFO tasks to prevent CPU resource exhaustion.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  This parameter can be modified by both the `sys` tenant and user tenants.

## Attributes

| **Attribute** | **Description** |
| ---------- | ---------- |
| Parameter type | Int |
| Default Value | 60 |
| Value range | [0, 100] |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Usage instructions

The value of the `px_target_low_watermark` parameter must satisfy the following relationship:

`px_target_low_watermark` <= [px_target_high_watermark](6865.px_target_high_watermark.md) <= [px_target_workers_per_cpu](6880.px_target_workers_per_cpu.md)

## Configuration example

Set the low-watermark percentage threshold for the number of parallel threads to 5.

```shell
obclient> ALTER SYSTEM SET px_target_low_watermark = 5;
```
