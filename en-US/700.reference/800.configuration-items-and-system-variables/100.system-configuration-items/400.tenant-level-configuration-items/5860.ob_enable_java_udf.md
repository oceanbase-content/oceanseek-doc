# ob_enable_java_udf

## Overview

`ob_enable_java_udf` is used to enable or disable the Java UDF feature.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  This parameter can be modified for both the `sys` and user tenants.

## Attributes

| **Attribute** | **Description** |
| ----------- | --------------- |
| Parameter type | Bool |
| Default Value | FALSE |
| Value range | TRUE/FALSE |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Usage instructions

OceanBase Cloud Database does not currently support the Java UDF feature. Moreover, since Java UDF relies on the JVM within OceanBase, in addition to enabling the `ob_enable_java_udf` parameter, you must also enable the [ob_enable_java_env](../300.cluster-level-configuration-items/16630.ob_enable_java_env.md) parameter and configure the JVM environment accordingly.

After enabling the Java UDF feature, you can enable the [ob_enable_java_udf_sandbox](../300.cluster-level-configuration-items/16655.ob_enable_java_udf_sandbox.md) parameter as needed to isolate the JVM of Java UDF from the main Observer process for enhanced execution security and stability.

## Configuration example

* Enable Java UDF feature

  ```sql
  obclient> ALTER SYSTEM SET ob_enable_java_udf = TRUE;
  ```

* Disable Java UDF feature

  ```sql
  obclient> ALTER SYSTEM SET ob_enable_java_udf = FALSE;
  ```
