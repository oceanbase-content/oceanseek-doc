# spill_compression_codec

## Overview

`spill_compression_codec` specifies the compression algorithm type to implement data spill compression during SQL execution.

## Privilege requirements

* Query parameters

  The `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Both the `sys` tenant and user tenants can use the `ALTER SYSTEM SET` statement to modify this parameter.

## Attributes

| **Attribute** | **Description** |
| ------------------ | ----------- |
| Parameter type | String |
| Default Value | NONE: no compression. |
| Value range | <ul><li>NONE</li><li>ZSTD</li><li>LZ4</li><li>SNAPPY</li></ul> |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Usage instructions

By specifying different compression algorithms in the configuration parameters, you can reduce the amount of space required for persisting temporary data during operator execution.

## Configuration example

Specifies the data compression algorithm for disk I/O during SQL execution as `LZ4`.

```shell
obclient> ALTER SYSTEM SET spill_compression_codec='LZ4';
```
