# kv_ttl_history_recycle_interval

## Overview

`kv_ttl_history_recycle_interval` specifies the retention period for historical records of the TTL task. The historical record table of the TTL task only retains records within the most recent period of length `kv_ttl_history_recycle_interval`.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Both the `sys` tenant and user tenants can modify this parameter.

## Attributes

| Attribute | Description |
| --- | --- |
| Parameter type | Time |
| Default Value | 7d |
| Value range | [1d, 180d] |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to Restart OBServer for the Change to Take Effect | No, the setting takes effect immediately. |

## Configuration example

Set the retention period for task history records with a TTL to 7 days.

```shell
obclient> ALTER SYSTEM SET kv_ttl_history_recycle_interval= '7d';
```
