# enable_gts_standalone

## Overview

`enable_gts_standalone` specifies whether to enable the feature that allows the tenant GTS service to exclusively use a set of units. After GTS exclusive use is enabled, the performance and stability of the GTS service can be improved.

## Privilege requirements

* Query parameters

  The `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Both the `sys` tenant and user tenants can modify this parameter.

## Attributes

| Attribute | Description |
| --------------------- | ----------- |
| Parameter type | Bool |
| Default Value | False |
| Value range | <ul><li>`True`: Enable exclusive GTS access. </li><li>`False`: Disable exclusive GTS. </li></ul> |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No |

## Usage instructions

The GTS service of a tenant is hosted by the unit where the system log stream resides. When the GTS service and the user log stream are in the same unit, there is a risk that they may be affected by the access traffic and maintenance operations of the user log stream. To prevent the GTS service from impacting the overall availability of the tenant, OceanBase AI Database provides the feature for the GTS service to exclusively use a dedicated set of units.

After the GTS exclusive mode is enabled, load balancing automatically selects a set of units to allocate to the system log stream (preferably the unit_list specified in the log stream O&M command or the current unit_list). Subsequently, user log streams are automatically distributed across other units.

After enabling the GTS exclusive mode, you must ensure that the `UNIT_NUM` value in all zones of the tenant is greater than or equal to 2, and the [enable_rebalance](2800.enable_rebalance.md) parameter is enabled for GTS exclusive mode to take effect.

## Configuration example

Enable the GTS exclusive mode feature.

```shell
obclient> ALTER SYSTEM SET enable_gts_standalone = 'True';
```
