# enable_window_compaction

## Overview

`enable_window_compaction` specifies whether [window-based compaction](../../../200.system-management/500.manage-data-storage/200.merge-management/310.window-compaction.md) is used for the current tenant.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Both the `sys` tenant and user tenants can modify this parameter.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Parameter type | Bool |
| Default Value | False |
| Value range | <ul><li>`True`: Daily major compactions are performed as window-based major compactions, and the start time of the major compaction is determined by the system variable [time_zone](../../200.system-variable/300.global-system-variable/13300.time_zone-global.md) to ensure the time is consistent across all regions. </li><li>`False`: The daily major compaction is performed for tenants, and the start time of the major compaction is consistent with the local time of the server where the Root Service resides. </li></ul> |
| Modifiable | Yes, you can use the following methods:`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Usage instructions

Window compaction is jointly controlled by the parameter `enable_window_compaction` and the window compaction task `DAILY_MAINTENANCE_WINDOW`. The relationship between their values and daily major compaction behavior is as follows:

| enable_window_compaction | DAILY_MAINTENANCE_WINDOW | Daily major compaction behavior |
| --------------------------- | -------------------------------------------------------------------- | --------------- |
| False | False(`CALL DBMS_SCHEDULER.DISABLE('DAILY_MAINTENANCE_WINDOW');`) | Trigger daily tenant major compaction |
| False | True(`CALL DBMS_SCHEDULER.ENABLE('DAILY_MAINTENANCE_WINDOW');`) | Trigger daily tenant major compaction |
| True | False (`CALL DBMS_SCHEDULER.DISABLE('DAILY_MAINTENANCE_WINDOW');`) | No major compaction is performed, meaning neither window-based major compaction nor daily tenant major compaction is triggered. |
| True | True(`CALL DBMS_SCHEDULER.ENABLE('DAILY_MAINTENANCE_WINDOW');`) | Trigger a major compaction |

## Configuration example

You have enabled the window merging feature for the current tenant.

```shell
obclient> ALTER SYSTEM SET enable_window_compaction = True;
```
