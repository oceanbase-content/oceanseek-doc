# default_enable_extended_rowid

## Overview

`default_enable_extended_rowid` specifies whether to create tables in extended ROWID mode.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Both the `sys` tenant and user tenants can modify this parameter.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Parameter type | Bool |
| Default Value | False |
| Value range | <ul><li>True: When creating a new table, the Extended ROWID format is used. The allocation range for tablet IDs is (2<sup>60</sup>, 2<sup>61</sup> - 1).</li> <li>False: When creating a new table, the 10-byte compatible ROWID format is used. The allocation range for tablet IDs is (200000, 2<sup>37</sup> - 1).</li></ul> |
| Modifiable | Yes, you can use the following methods:`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Configuration example

Specifies not to use the extended ROWID mode when creating a table.

```shell
obclient> ALTER SYSTEM SET default_enable_extended_rowid= false;
```
