# shared_log_retention

## Overview

`shared_log_retention` specifies the retention period for shared log files.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Both the `sys` tenant and user tenants can modify this parameter.

## Attributes

| **Attribute** | **Description** |
| ----------- | --------------- |
| Parameter type | Time |
| Default Value | 1d |
| Value range | [0s,7d] |
| Modifiable | Yes, you can use the following methods:`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Usage instructions

**When a tenant is deleted, the transaction log files of that tenant on shared storage are immediately deleted.**

## Configuration example

* Set the retention period for shared storage log files to 7 days for all tenants.

  ```shell
  obclient> ALTER SYSTEM SET shared_log_retention= '7d' TENANT='ALL';
  ```

* Set the retention period for shared storage log files of user tenants to 24 hours.

  ```shell
  obclient> ALTER SYSTEM SET shared_log_retention= '24h' TENANT='MySQL';
  ```
