# mlog_trim_interval

## Overview

`mlog_trim_interval` specifies the scheduling interval for the automatic mlog trimming task.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Both the `sys` tenant and user tenants can modify this parameter.

## Attributes

| **Attribute** | **Description** |
| ---------- | ---------- |
| Parameter type | Time |
| Default Value | 1d |
| Value range | [5s, 30d] |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Configuration example

* Set the time interval for the background mlog trimming task to `5s`.

    ```shell
    obclient> ALTER SYSTEM SET mlog_trim_interval = '5s';
    ```

* Set the time interval for the background MLog truncation task to `1d`.

    ```shell
    obclient> ALTER SYSTEM SET mlog_trim_interval = '1d';
    ```
