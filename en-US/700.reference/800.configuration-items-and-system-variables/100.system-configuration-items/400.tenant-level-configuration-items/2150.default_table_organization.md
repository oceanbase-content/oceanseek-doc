# default_table_organization

## Overview

The `default_table_organization` parameter allows you to set the default table organization mode for creating new tables.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>The current version of the <code>default_table_organization</code> parameter applies only to user tenants of OceanBase AI Database. The sys (system) tenant does not support it.</p>
</main>

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Both the `sys` tenant and user tenants can modify this parameter.

## Attributes

| **Attribute** | **Description** |
| ---------- | ---------- |
| Parameter type | String |
| Default Value | `INDEX` |
| Value range | <ul><li>`HEAP`</li><li>`INDEX`</li></ul> |
| Modifiable | Yes, you can use the following methods:`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Usage instructions

You can use the `default_table_organization` parameter to flexibly control the default table organization mode for newly created tables. This parameter can be set to one of the following two values:

* `HEAP`:

  * When you create a table with a primary key in this mode, the data is not sorted according to the order of the primary key columns.
  * This mode is suitable for scenarios that require processing large volumes of data and performing complex query analysis.

* `INDEX`:

  * When a table with a primary key is created in this mode, data is stored and sorted in the order of the primary key columns.
  * This mode is suitable for transaction processing scenarios that require fast queries and frequent updates.

By setting `default_table_organization`, you can select an appropriate table organization mode based on your specific requirements, thereby optimizing system performance and improving data management efficiency.
