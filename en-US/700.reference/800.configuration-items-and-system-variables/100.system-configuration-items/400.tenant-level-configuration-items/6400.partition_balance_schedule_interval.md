# partition_balance_schedule_interval

## Overview

`partition_balance_schedule_interval` specifies the scheduling interval for partition balancing.

## Privilege requirements

* Query parameters

  The `sys` tenant and all user tenants can use the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view to query this parameter.

* Modify parameters

  Both the `sys` tenant and user tenants can modify this parameter.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Parameter type | Time |
| Default Value | 0s: Disable automatic background partition balancing. |
| Value range | [0s,+∞) |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Usage instructions

Partition balancing can be enabled only when the value of the `partition_balance_schedule_interval` parameter is greater than the value of the [balancer_idle_time](600.balancer_idle_time.md) parameter. The current version supports scheduled partition balancing tasks, so it is no longer recommended to control partition balancing using the `partition_balance_schedule_interval` parameter.

## Configuration example

* The partition balancing scheduling cycle for any tenant under the sys tenant is modified to 1 hour.

  ```shell
  obclient(root@sys)[oceanbase]> ALTER SYSTEM SET partition_balance_schedule_interval = '1h' tenant = all;
  obclient(root@sys)[oceanbase]> ALTER SYSTEM SET partition_balance_schedule_interval = '1h' tenant = 'tenant_name';
  ```

* The partition balancing scheduling cycle for the current tenant is modified to 1 hour under the user tenant.

  ```shell
  obclient [test]> ALTER SYSTEM SET partition_balance_schedule_interval = '1h';
  ```
