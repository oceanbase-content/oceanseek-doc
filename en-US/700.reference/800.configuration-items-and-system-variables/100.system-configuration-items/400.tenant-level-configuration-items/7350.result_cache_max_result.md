# result_cache_max_result

## Overview

`result_cache_max_result` specifies the maximum proportion of memory that a single cached object can occupy in the result cache. The maximum value is specified by `result_cache_max_size`.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Both the `sys` tenant and user tenants can modify this parameter.

## Attributes

| **Attribute** | **Description** |
| ----------- | --------------- |
| Parameter type | Int |
| Default Value | 5 |
| Value range | [0,100] |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Configuration example

Run the following command to set the maximum memory usage for `result cache` of a single cached object to 10%.

```shell
obclient> ALTER SYSTEM SET result_cache_max_result=10;
```
