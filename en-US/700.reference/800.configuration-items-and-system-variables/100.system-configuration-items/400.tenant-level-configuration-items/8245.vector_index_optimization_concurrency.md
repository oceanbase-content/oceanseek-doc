# vector_index_optimization_concurrency

## Overview

The `vector_index_optimization_concurrency` parameter specifies the number of threads used for automatic partition rebuilding tasks when a vector index is executed.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Both the `sys` tenant and user tenants can modify this parameter.

## Attributes

| **Attribute** | **Description** |
| --- | --- |
| Parameter type | string |
| Default Value | 2 |
| Value range | [1, 256] |
| Modifiable | Yes, you can use the following methods:`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No |

## Sample query

Set the number of threads for rebuilding a single automatic partition by using vector indexes to 8.

```shell
obclient> ALTER SYSTEM SET vector_index_optimization_concurrency = 8;
```
