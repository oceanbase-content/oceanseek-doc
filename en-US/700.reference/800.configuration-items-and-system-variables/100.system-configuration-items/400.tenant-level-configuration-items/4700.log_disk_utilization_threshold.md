# log_disk_utilization_threshold

## Overview

`log_disk_utilization_threshold` specifies the threshold for tenant log disk utilization. When a tenant's log disk usage exceeds the total log disk space of the tenant multiplied by this value, log file reuse is performed.

## Privilege requirements

* Query parameters

  The `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Both the `sys` tenant and user tenants can modify this parameter.

## Attributes

| **Attribute** | **Description** |
| ------------------ | -------------- |
| Parameter type | Int |
| Default Value | 80 |
| Value range | [10, 99] |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Usage instructions

The value of `log_disk_utilization_threshold` should be less than the value of [log_disk_utilization_limit_threshold](4600.log_disk_utilization_limit_threshold.md).

## Configuration example

Set the tenant log disk utilization threshold to 80.

```shell
obclient> ALTER SYSTEM SET log_disk_utilization_threshold=80;
```
