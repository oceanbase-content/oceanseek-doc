# kv_ttl_duty_duration

## Overview

`kv_ttl_duty_duration` specifies the daily scheduled time period for triggering a TTL task. The TTL task is triggered once within this period.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Both the `sys` tenant and user tenants can modify this parameter.

## Attributes

| Attribute | Description |
| --- | --- |
| Parameter type | String |
| Default Value | [00:00:00, 24:00:00] |
| Value range | [00:00:00, 24:00:00] |
| Modifiable | Yes, you can use the following methods:`ALTER SYSTEM SET`Statement modification. |
| Whether to Restart OBServer for the Change to Take Effect | No, the setting takes effect immediately. |

## Configuration example

Set the daily scheduled TTL trigger period to [00:00:00, 24:00:00].

```shell
obclient> ALTER SYSTEM SET kv_ttl_duty_duration = '[00:00:00, 24:00:00]';
```
