# tenant_sql_login_thread_count

## Overview

`tenant_sql_login_thread_count` specifies the number of threads for user tenant login, which is also the number of `mysql_queue` threads.

## Privilege requirements

* Query parameters

  The `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view can be used by the `sys` tenant and all user tenants to query this parameter.

* Modify parameters

  Both the `sys` tenant and user tenants can modify this parameter.

## Attributes

| Attribute | Description |
| ------------------ | ------- |
| Parameter type | Int |
| Default Value | 0 indicates to take from the tenant unit.`min_cpu`The value of . |
| Value range | [0, 32] |
| Modifiable | Yes, you can use the following methods:`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Configuration example

Set the number of threads for user tenant login to 2.

```shell
obclient> ALTER SYSTEM SET tenant_sql_login_thread_count= 2;
```
