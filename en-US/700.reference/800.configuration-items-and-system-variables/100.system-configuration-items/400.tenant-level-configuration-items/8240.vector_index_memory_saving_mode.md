# vector_index_memory_saving_mode

## Overview

`vector_index_memory_saving_mode` specifies whether to enable memory-saving mode for vector indexes. Enabling this mode can significantly reduce memory consumption during the rebuild of vector indexes in partitioned tables. In environments with limited memory resources, this mode allows index rebuilding to be completed successfully with less memory, preventing rebuild failures caused by insufficient memory.

Based on the principle of vector indexes, rebuilding typically involves processing data for both incremental and baseline segments. When this mode is enabled, the system releases temporary memory as early as possible during partition-level construction to reduce peak memory usage.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Both the `sys` tenant and user tenants can modify this parameter.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Parameter type | Bool |
| Default Value | true |
| Value range | true/false |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Configuration example

Set this parameter to `true` to reduce the memory required during the rebuilding of a vector index for a partitioned table.

```sql
ALTER SYSTEM SET vector_index_memory_saving_mode = true;
```
