# default_micro_block_format_version

## Overview

`default_micro_block_format_version` specifies the default microblock storage format version number when creating a table.

## Privilege requirements

* Query parameters

    The `SHOW PARAMETERS` statement can be executed by the `sys` tenant and all user tenants to query this parameter.

* Modify parameters

    The `ALTER SYSTEM SET` statement can be used by the `sys` tenant and all user tenants to modify this parameter.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Parameter type | Int |
| Default Value | 2 |
| Value range | [1,+∞) <ul>Where:<ul><li> 1: Indicates consistency with the existing microblock storage format.</li><li>2: Indicates enabling the new flat-row storage format.</li><li>Other values: An invalid value error is returned.</li></ul> |
| Modifiable | Yes, you can use the following methods:`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Usage instructions

You can modify this parameter to adjust the default microblock storage format version number of a table, thereby controlling whether to enable the new flat-row storage format.

## Configuration example

Execute the following command in the user tenant to set the microblock storage format version number 2 as the default value for newly created tables:

```shell
obclient> ALTER SYSTEM SET default_micro_block_format_version = 2;
```
