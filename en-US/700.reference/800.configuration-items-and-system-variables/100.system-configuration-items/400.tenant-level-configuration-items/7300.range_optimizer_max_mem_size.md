# range_optimizer_max_mem_size

## Overview

`range_optimizer_max_mem_size` specifies the maximum memory size allowed for the query range module.

## Privilege requirements

* Query parameters

  The `sys` tenant and all user tenants can use the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view to query this parameter.

* Modify parameters

  Both the `sys` tenant and user tenants can modify this parameter.

## Attributes

| **Attribute** | **Description** |
| --- | --- |
| Parameter type | Capacity |
| Default Value | 128M |
| Value range | [0M,+∞) |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Usage instructions

This parameter is used to limit the memory usage of the Query Range module. When the memory used by the Query Range module reaches the upper limit, the system will not perform any range extraction. For example, if a complex predicate hits an index and the memory used for extracting the query range for that complex predicate reaches the upper limit, the system will not choose that index and will instead attempt to use the primary table.

## Configuration example

Set the memory available for the Query Range module to 128 MB.

```shell
obclient> ALTER SYSTEM SET range_optimizer_max_mem_size = '128M';
```
