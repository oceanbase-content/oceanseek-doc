# tablet_meta_table_check_interval

## Overview

The `tablet_meta_table_check_interval` parameter specifies the check interval for the background inspection thread of the `DBA_OB_TABLET_REPLICAS` and `CDB_OB_TABLET_REPLICAS` views.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Only the `sys` tenant can modify this parameter. User tenants cannot modify it.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Parameter type | Time |
| Default Value | 30m |
| Value range | [1m, +∞) |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to Restart the OBServer Node for the Change to Take Effect | No, the setting takes effect immediately. |

## Configuration example

Set the inspection interval for the background inspection thread of the `DBA_OB_TABLET_REPLICAS`/`CDB_OB_TABLET_REPLICAS` view to 30 minutes.

```shell
obclient> ALTER SYSTEM SET tablet_meta_table_check_interval = '30m';
```
