# cluster

<main id="notice" type='notice'>
<h4>Notice</h4>
<p>This startup parameter is recommended to be set only when creating an OceanBase AI database. After the cluster takes effect, it cannot be modified. For detailed information on creating an OceanBase AI database, see <a href="../../../../150.deploy/600.deploy-oceanbase-cluster-use-ocp/400.deploy-oceanbase-ai-cluster-using-ocp.md">Create an OceanBase AI database</a>.</p>
</main>

## Overview

`cluster` specifies the name of the current OceanBase AI database.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  This parameter is set only during cluster deployment and cannot be modified after the cluster starts.

## Attributes

| **Attribute** | **Description** |
| ------------------ | ----------- |
| Parameter type | String |
| Default Value | obcluster |
| Modifiable | No, it is not supported to pass through`ALTER SYSTEM SET`Statement modification. |
| Whether a restart of the OBServer node is required for the change to take effect | No. Read-only access is supported only.         |
