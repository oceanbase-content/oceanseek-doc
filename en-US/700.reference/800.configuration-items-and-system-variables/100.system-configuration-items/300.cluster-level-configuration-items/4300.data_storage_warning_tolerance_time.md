# data_storage_warning_tolerance_time

## Overview

The `data_storage_warning_tolerance_time` parameter specifies the tolerance period for setting the data disk status to `WARNING`.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Only the `sys` tenant can modify this parameter. User tenants cannot modify it.

## Attributes

| Attribute | Description |
| ------------------ | --------------- |
| Parameter type | Time |
| Default Value | 5s |
| Value range | [1s, 300s] |
| Modifiable | Yes, you can use the following methods:`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Usage instructions

When an unexpected I/O failure occurs, the IO Manager of OceanBase AI Database attempts to detect the status of the data disk through a probe thread. If, after the duration specified by this parameter, the probe determines that the data disk status of the machine has not returned to normal, the probe thread sets the data disk status to `WARNING`. This status triggers events such as a leader switchover to ensure normal service delivery to business requests.

## Configuration example

The tolerance time when the data disk status is set to `WARNING` is 20 seconds.

```shell
obclient> ALTER SYSTEM SET data_storage_warning_tolerance_time = 20s;
```
