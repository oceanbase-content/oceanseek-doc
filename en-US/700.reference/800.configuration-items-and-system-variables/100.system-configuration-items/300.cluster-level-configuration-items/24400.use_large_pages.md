# use_large_pages

## Overview

The `use_large_pages` clause is used to manage the use of huge pages in the database.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Only the `sys` tenant can modify this parameter. User tenants cannot modify it.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Parameter type | String |
| Default Value | false |
| Value range | <ul><li>false: Large pages are disabled.</li> <li>true: Mixed use of large and normal pages is allowed.</li> <li>only: The system is forced to use only large pages.</li></ul> |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to Restart the OBServer Node for the Change to Take Effect | Yes, the node restart is required for the changes to take effect. |

## Configuration example

Set the database to disable large-page memory usage.

```shell
obclient> ALTER SYSTEM SET use_large_pages = 'false';
```
