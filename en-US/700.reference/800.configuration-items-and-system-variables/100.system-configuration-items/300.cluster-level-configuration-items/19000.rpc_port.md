# rpc_port

## Overview

`rpc_port` specifies the port number for remote access.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  **This parameter can only be set during cluster deployment. It cannot be modified after the cluster comes into effect.**

## Attributes

| **Attribute** | **Description** |
| ------------------ | ----------------- |
| Parameter type | Int |
| Default Value | 2882 |
| Value range | [1025, 65535] |
| Modifiable | No, it is not supported to use the`ALTER SYSTEM SET`Statement modification. |
| Whether a restart of the OBServer node is required for the change to take effect | No, read-only mode only.               |
