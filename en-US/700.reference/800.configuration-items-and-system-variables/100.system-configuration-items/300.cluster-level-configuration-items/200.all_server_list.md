# all_server_list

## Overview

`all_server_list` is used to display all server addresses in the cluster.

## Privilege requirements

* Query parameters

  The `SHOW PARAMETERS` statement can be executed by the `sys` tenant and all user tenants to query this parameter.

* Modify parameters

  Only the `sys` tenant can modify this parameter. User tenants cannot modify it.

## Attributes

| **Attribute** | **Description** |
| -------------------- | ---------- |
| Parameter type | String |
| Default Value | "" indicates an empty string. |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Configuration example

Set the server addresses in the cluster to `xx.xx.xx.01:2882;xx.xx.xx.02:2882;xx.xx.xx.03:2882`.

```shell
obclient> ALTER SYSTEM SET all_server_list='xx.xx.xx.01:2882;xx.xx.xx.02:2882;xx.xx.xx.03:2882';
```
