# net_thread_count

## Overview

`net_thread_count` specifies the number of threads for network I/O.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Only the `sys` tenant can modify this parameter. User tenants cannot modify it.

## Attributes

| **Attribute** | **Description** |
| ------------------ | -------------- |
| Parameter type | Int |
| Default Value | 0 |
| Value range | [0, 128] |
| Modifiable | Yes, you can use the following methods:`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Usage instructions

* By default, the number of I/O threads for RPC and MySQL LibEasy is 1/8 of the CPU core count.

* When the value of the `net_thread_count` parameter is set to N (where N > 0), RPC and MySQL LibEasy use N I/O threads each.

## Configuration example

Set the number of network I/O threads to 6.

```shell
obclient> ALTER SYSTEM SET net_thread_count = 6;
```
