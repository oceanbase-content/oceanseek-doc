# storage_meta_cache_priority

## Overview

`storage_meta_cache_priority` specifies the priority of storing Meta Cache in KVCache.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Only the `sys` tenant can modify this parameter. User tenants cannot modify it.

## Attributes

| **Attribute** | **Description** |
| ----------- | ------------ |
| Parameter type | Int |
| Default Value | 10 |
| Value range | [1,+∞) |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Usage instructions

OceanSeek abstracts metadata such as table stores and SSTables into a unified concept called storage Meta, which is then managed within the KVCache memory. When KVCache utilization is low or there are frequent misses, users can adjust the priorities based on workload characteristics to optimize and flexibly allocate the limited KVCache memory resources.

In KVCache, a higher cache priority value indicates a higher priority and makes the cache less likely to be evicted. The priority parameters for the existing cache types are as follows:

* [tablet_ls_cache_priority](22700.tablet_ls_cache_priority.md), whose default value is 1000 and range is [1,+∞).

* [opt_tab_stat_cache_priority](16800.opt_tab_stat_cache_priority.md) The default value is 1. Value range: [1,+∞).

* [index_block_cache_priority](10600.index_block_cache_priority.md), whose default value is 10 and range is [1,+∞).

* [user_block_cache_priority](24500.user_block_cache_priority.md) The default value is 1. Value range: [1, +∞).

* [user_row_cache_priority](24700.user_row_cache_priority.md) The default value is 1. Value range: [1,+∞).

* [bf_cache_priority](2500.bf_cache_priority.md) The default value is 1. Value range: [1,+∞).

* [fuse_row_cache_priority](9600.fuse_row_cache_priority.md) The default value is 1. Value range: [1,+∞).

Note that the default value for storing Meta priority is consistent with `index_block_cache_priority`, second only to `tablet_ls_cache_priority`.

## Configuration example

Set the priority of storing Meta Cache in KVCache to 10.

```shell
obclient> ALTER SYSTEM SET storage_meta_cache_priority='10';
```
