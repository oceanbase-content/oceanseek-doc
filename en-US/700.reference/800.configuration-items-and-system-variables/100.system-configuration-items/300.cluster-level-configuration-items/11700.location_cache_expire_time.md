# location_cache_expire_time

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This parameter has not been used in practice and will not take effect after being set. It can be ignored.</p>
</main>

## Overview

`location_cache_expire_time` specifies the expiration duration for partition location information in the partition location cache. Modifying this parameter is not recommended.

## Attributes

| **Attribute** | **Description** |
| ------------------ | ----------- |
| Parameter type | Time |
| Default Value | 600s |
| Value range | \[1s, +∞) |
| Whether a restart of the OBServer node is required for the change to take effect | No        |
