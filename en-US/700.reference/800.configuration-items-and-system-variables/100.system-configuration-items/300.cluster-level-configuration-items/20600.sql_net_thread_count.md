# sql_net_thread_count

## Overview

`sql_net_thread_count` specifies the number of I/O threads in a MySQL cluster, that is, the number of `global_sql_nio_server` threads.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Only the `sys` tenant can modify this parameter. User tenants cannot modify it.

## Attributes

| **Attribute** | **Description** |
| ------------------ | -------------- |
| Parameter type | Int |
| Default Value | 0 |
| Value range | [0, 64] |
| Modifiable | Yes, you can use the following methods:`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Usage instructions

When the value of this parameter is 0, it is set to the same value as the [net_thread_count](15500.net_thread_count.md) parameter.

## Configuration example

Set the number of `global_sql_nio_server` threads to 2.

```shell
obclient> ALTER SYSTEM SET sql_net_thread_count = 2;
```
