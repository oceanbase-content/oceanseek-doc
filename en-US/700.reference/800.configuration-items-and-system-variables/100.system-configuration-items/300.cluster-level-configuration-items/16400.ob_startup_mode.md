# ob_startup_mode

## Overview

`ob_startup_mode` specifies the startup mode of an OBServer node. It can be modified only during the first startup.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Can only be modified during the first startup of the cluster.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Parameter type | String |
| Default Value | NORMAL |
| Value range | `SHARED_STORAGE`: Indicates starting in Shared-Storage (SS) mode. |
| Modifiable | No, it is not supported to pass through`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, read-only is the only supported mode. |
