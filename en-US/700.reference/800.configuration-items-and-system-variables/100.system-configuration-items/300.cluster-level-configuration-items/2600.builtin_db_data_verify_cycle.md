# builtin_db_data_verify_cycle

## Overview

`builtin_db_data_verify_cycle` specifies the cycle for data bad block self-check.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can execute the `SHOW PARAMETERS` statement to query this parameter.

* Modify parameters

  Only the `sys` tenant can modify this parameter. User tenants cannot modify it.

## Attributes

| **Attribute** | **Description** |
| -------------------- | -------------- |
| Parameter type | Int |
| Default Value | 20, in days. |
| Value range | [0, 360]<br>A value of 0 indicates that no check is performed. |
| Modifiable | Yes, you can use the following methods:`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Configuration example

Set the data bad block self-check cycle to 20 days.

```shell
obclient> ALTER SYSTEM SET builtin_db_data_verify_cycle=20;
```
