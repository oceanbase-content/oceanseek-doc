# unit_gc_wait_time

## Overview

`unit_gc_wait_time` specifies the maximum wait duration for a unit GC. If the wait duration exceeds this limit, a forced GC is triggered.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Only the `sys` tenant can modify this parameter. User tenants cannot modify it.

## Attributes

| **Attribute** | **Description** |
| ---------- | ---------------------------------- |
| Parameter type | Time |
| Default Value | 1m, which stands for 1 minute |
| Value range | [0, 30d] |
| Modifiable | Yes, you can use the following methods:`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Usage instructions

When modifying a parameter value, you can specify the unit as us (microseconds), ms (milliseconds), s (seconds), m (minutes), h (hours), or d (days).

## Configuration example

Set the maximum wait time for a minor GC to 1 minute. After 1 minute, the system will perform a forced minor GC.

```shell
obclient> ALTER SYSTEM SET unit_gc_wait_time = '1m';
```
