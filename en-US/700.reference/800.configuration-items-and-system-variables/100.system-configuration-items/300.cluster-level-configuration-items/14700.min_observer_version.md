# min_observer_version

## Overview

`min_observer_version` specifies the minimum application version of OBServer nodes in the cluster.

## Privilege requirements

* Query parameters

  The `sys` tenant and all user tenants can use the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view to query this parameter.

* Modify parameters

  Only the `sys` tenant can modify this parameter. User tenants cannot modify it.

## Attributes

| **Attribute** | **Description** |
| ------------------ | --------- |
| Parameter type | Int |
| Default Value | 4.6.2.0 |
| Modifiable | Yes, you can use the following methods:`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Configuration example

Set the minimum OBServer node application version for this cluster to 4.6.2.0.

```shell
obclient> ALTER SYSTEM SET min_observer_version='4.6.2.0';
```
