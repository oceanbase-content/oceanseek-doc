# rest_oauth2_credential_evict_time

## Overview

`rest.oauth2_credential_evict_time` specifies the eviction duration for the OAuth2 credential cache of REST Catalog.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Both the `sys` tenant and user tenants can modify this parameter.

## Attributes

| **Attribute** | **Description** |
| ----------- | --------------- |
| Parameter type | Time |
| Default Value | 10 Minutes |
| Value range | [1s, 1d] |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | Yes, it takes effect after a restart. |

## Usage instructions

Sets the eviction time for Oauth2 cache. Credentials that have not been used for more than the eviction time will be cleaned up during regular refresh tasks. You can increase `evict_time` when catalog access is very frequent to avoid frequent re-obtaining. When memory resources are tight, you can decrease `evict_time` to reduce resource usage. Supported units include microseconds (us), milliseconds (ms), seconds (s), minutes (m), hours (h), and days (d). The default unit is seconds.

## Usage examples

Set the eviction duration for the REST Catalog OAuth2 credential cache to 30 minutes.

```shell
obclient> ALTER SYSTEM SET rest_oauth2_credential_evict_time = "30m";
```
