# log_storage_warning_tolerance_time

## Overview

`log_storage_warning_tolerance_time` specifies the time before a leader switchover is triggered when the disk marked as bad occurs after an I/O failure from the log disk.

## Privilege requirements

* Query parameters

  Both the sys tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Only the sys tenant can modify this parameter. User tenants cannot modify it.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Parameter type | Time |
| Default Value | 5s |
| Value range | [1s,300s] |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Configuration example

The time before a leader switchover is triggered when the disk marked as bad is detected after I/O failures from the log disk have occurred is set to 5 seconds.

```shell
obclient> ALTER SYSTEM SET log_storage_warning_tolerance_time = '5s';
```
