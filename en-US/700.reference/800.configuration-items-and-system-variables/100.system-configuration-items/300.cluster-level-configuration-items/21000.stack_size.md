# stack_size

## Overview

`stack_size` specifies the size of the function call stack for the program.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Only the `sys` tenant can modify this parameter. User tenants cannot modify it.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Parameter type | Capacity |
| Default Value | 512 KB. The default unit is MB. You must specify the unit when configuring it. |
| Value range | [512K, 20M] |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | Yes, a restart is required for the changes to take effect. |

## Configuration example

Set the program function call stack size to 512K.

```shell
obclient> ALTER SYSTEM SET stack_size = '512K';
```
