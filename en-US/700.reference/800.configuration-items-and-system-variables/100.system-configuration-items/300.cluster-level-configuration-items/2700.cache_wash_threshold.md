# cache_wash_threshold

## Overview

`cache_wash_threshold` specifies the memory usage threshold for triggering cache cleanup. When the memory usage falls below this threshold, the system will clean up the cache.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can execute the `SHOW PARAMETERS` statement to query this parameter.

* Modify parameters

  Only the `sys` tenant can modify this parameter. User tenants cannot modify it.

## Attributes

| **Attribute** | **Description** |
| ------------------ | ---------- |
| Parameter type | Capacity |
| Default Value | 4 GB. The default unit is MB. You must specify the unit when configuring it. |
| Value range | [0, +∞) |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Configuration example

Set the capacity threshold for triggering cache cleanup to 4 GB.

```shell
obclient> ALTER SYSTEM SET cache_wash_threshold='4GB';
```
