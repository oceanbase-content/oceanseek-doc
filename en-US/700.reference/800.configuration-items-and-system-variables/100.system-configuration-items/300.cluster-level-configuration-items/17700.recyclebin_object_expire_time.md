# recyclebin_object_expire_time

## Overview

`recyclebin_object_expire_time` is used to automatically clean up expired schema objects in the recycle bin.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Only the `sys` tenant can modify this parameter. User tenants cannot modify it.

## Attributes

| **Attribute** | **Description** |
| ------------------ | -------------- |
| Parameter type | Time |
| Default Value | 0s: Disable automatic purge of the recycle bin. |
| Value range | 0s, +∞) |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Usage instructions

When the value is not 0s, it indicates that the schema objects were moved to the recycle bin a while ago.

## Configuration example

* Disable the automatic cleanup of the recycle bin.

  ```shell
  obclient> ALTER SYSTEM SET recyclebin_object_expire_time = "0s";
  ```

* Enable automatic cleanup of the recycle bin and reclaim schema objects that have been in the recycle bin for more than 7 days.

  ```shell
  obclient> ALTER SYSTEM SET recyclebin_object_expire_time = "7d";
  ```
