# diag_syslog_per_error_limit

## Overview

`diag_syslog_per_error_limit` specifies the threshold for the number of DIAG system logs printed per second for each error code. When the number of logs exceeds this threshold, log printing stops.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Only the `sys` tenant can modify this parameter. User tenants cannot modify it.

## Attributes

| **Attribute** | **Description** |
| -------- | ------- |
| Parameter type | Int |
| Default Value | 200 |
| Value range | 0, +∞) |
| Modifiable | Yes, you can use the following methods:`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Configuration example

Set the threshold for the number of DIAG system logs per second for each error code to 200.

```shell
obclient> ALTER SYSTEM SET diag_syslog_per_error_limit= 200;
```
