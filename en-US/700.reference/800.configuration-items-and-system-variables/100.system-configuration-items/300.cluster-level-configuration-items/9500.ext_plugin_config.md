# ext_plugin_config

`ext_plugin_config` is used to declare the external table C++ plugins that need to be loaded for the cluster and their dynamic library locations.

## Overview

The configuration value is a JSON array. Each element is an object that contains the required `name` field and the optional `path` field. `name` specifies the plugin name (for example, `paimon`). `path` specifies the absolute path of the plugin's dynamic library `.so` file. If `path` is not specified, the system searches for the file in `LD_LIBRARY_PATH` according to the naming convention `lib_ob_<name>.so` (the system first merges `_ob_additional_lib_path` into the search path). The corresponding `.so` file must be accessible to each OBServer node.

This configuration adopts a lazy loading mechanism and is read only once during the process lifecycle. When external tables are first identified, the system parses the JSON and loads all entries using `dlopen`. Modifying the configuration at runtime only updates the persisted values; the loaded plugin set remains unchanged. Changes take effect only after restarting the OBServer.

## Usage instructions

1. The default configuration declares the loading of the Paimon plugin. Place `lib_ob_paimon.so` and its dependency libraries under the `LD_LIBRARY_PATH` of each OBServer node. If the `.so` file is not in the default search path, use the `path` field to specify the absolute path.
2. After modifying the configuration, you must restart all OBServer nodes. The configuration and `.so` layout on each node must be consistent; otherwise, some nodes may report "plugin not loaded".

## Configuration example

```sql
-- View Current Value
SHOW PARAMETERS LIKE 'ext_plugin_config';

-- Default configuration: searches for lib_ob_paimon.so according to LD_LIBRARY_PATH.
ALTER SYSTEM SET ext_plugin_config = '[{"name":"paimon"}]';

-- Explicitly specify the absolute path of the dynamic library.
ALTER SYSTEM SET ext_plugin_config = '[{"name":"paimon","path":"/home/admin/oceanbase/lib/lib_ob_paimon.so"}]';

-- Declare Multiple Plugins at Once
ALTER SYSTEM SET ext_plugin_config = '[{"name":"paimon"},{"name":"odps","path":"/abs/lib_ob_odps.so"}]';

-- Disable all external table plugins
ALTER SYSTEM SET ext_plugin_config = '[]';
```
