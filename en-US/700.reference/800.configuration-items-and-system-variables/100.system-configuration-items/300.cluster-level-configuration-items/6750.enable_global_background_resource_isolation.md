# enable_global_background_resource_isolation

## Overview

`enable_global_background_resource_isolation` is used to enable global background and foreground resource isolation.

## Privilege requirements

* Query parameters

  The `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view can be used by the `sys` tenant and all user tenants to query this parameter. The `sys` tenant can also query this parameter through the `information_schemaарамЕТРЫ` view.

* Modify parameters

  Only the `sys` tenant can modify this parameter. User tenants cannot modify it.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Parameter type | Bool |
| Default Value | false |
| Value range | [true, false]<ul><li>true: Background tasks are isolated separately from foreground tasks within a tenant.</li><li>false: Background and foreground tasks are isolated within a tenant.</li></ul> |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | Yes, if the modification involves multiple OBServer nodes, all OBServer nodes need to be restarted. |

## Configuration example

Isolate backend and frontend tasks within a tenant.

```shell
obclient> ALTER SYSTEM SET enable_global_background_resource_isolation=false;
```
