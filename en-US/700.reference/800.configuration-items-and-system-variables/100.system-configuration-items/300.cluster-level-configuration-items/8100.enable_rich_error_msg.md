# enable_rich_error_msg

## Overview

`enable_rich_error_msg` specifies whether to include server address, time, trace ID, and other debugging information in client error messages.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Only the `sys` tenant can modify this parameter. User tenants cannot modify it.

## Attributes

| **Attribute** | **Description** |
| ------------------ | -------------- |
| Parameter type | Bool |
| Default Value | False |
| Value range | <ul><li>True: Indicates that the OBServer node name will be prepended to the error message.`ip:port`, error time, and log trace ID. </li> <li>False: Indicates that the text error message content remains unchanged. </li></ul> |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Configuration example

Configure the client to not include debug information such as the server address, time, and trace ID in the message.

```shell
obclient> ALTER SYSTEM SET enable_rich_error_msg = False;
```
