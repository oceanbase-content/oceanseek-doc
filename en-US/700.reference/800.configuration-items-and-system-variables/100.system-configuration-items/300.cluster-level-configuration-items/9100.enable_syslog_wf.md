# enable_syslog_wf

## Overview

`enable_syslog_wf` specifies whether to print system logs of WARN level and above (../../../../600.manage/800.logging/100.logging-overview.md) to a separate log file.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Only the `sys` tenant can modify this parameter. User tenants cannot modify it.

## Attributes

| **Attribute** | **Description** |
| ------------------ | -------------- |
| Parameter type | Bool |
| Default Value | True |
| Value range | <ul><li>True: enabled</li> <li>False: disabled</li></ul> |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Usage instructions

This feature takes effect only when the value of the [max_syslog_file_count](13300.max_syslog_file_count.md) parameter is set to a non-zero positive number.

## Configuration example

Configure to log system logs above WARN level to a separate log file.

```shell
obclient> ALTER SYSTEM SET enable_syslog_wf = True;
```
