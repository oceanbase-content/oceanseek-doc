# syslog_io_bandwidth_limit

## Overview

`syslog_io_bandwidth_limit` specifies the upper limit of disk I/O bandwidth that system [logs](../../../../600.manage/800.logging/100.logging-overview.md) can occupy. System logs exceeding this bandwidth limit will be discarded.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Only the `sys` tenant can modify this parameter. User tenants cannot modify it.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Parameter type | Capacity |
| Default Value | 30 MB. The default unit is MB. You must specify the unit when configuring it. |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to Restart the OBServer Node for the Change to Take Effect | No, the setting takes effect immediately. |

## Configuration example

Set the disk I/O bandwidth for system logs to 30 MB.

```shell
obclient> ALTER SYSTEM SET syslog_io_bandwidth_limit = '30MB';
```
