# memory_limit_percentage

## Overview

`memory_limit_percentage` specifies the percentage of total memory that is available for OBServer nodes.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Only the `sys` tenant can modify this parameter. User tenants cannot modify it.

## Attributes

| **Attribute** | **Description** |
| ------------------ | ------------ |
| Parameter type | Int |
| Default Value | 80 |
| Value range | [10, 95] |
| Modifiable | Yes, you can use the following methods:`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Usage instructions

If the value of `memory_limit` is not `0`, the system ignores the setting of `memory_limit_percentage` and prioritizes the value configured by `memory_limit`. For more information about `memory_limit`, see [memory_limit](13500.memory_limit.md).

## Configuration example

Set the total available memory of the OBServer node to 80% of its total memory.

```shell
obclient> ALTER SYSTEM SET memory_limit_percentage='80';
```
