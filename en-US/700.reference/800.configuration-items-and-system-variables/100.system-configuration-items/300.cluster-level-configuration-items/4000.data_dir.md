# data_dir

## Overview

`data_dir` specifies the directory for storing data such as SSTables.

## Privilege requirements

The `sys` tenant and all user tenants can use the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view to query this parameter.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Parameter type | String |
| Default Value | store |
| Modifiable | No, it is not supported to pass through`ALTER SYSTEM SET`Statement modification. |
| Whether a restart of the OBServer node is required for the change to take effect | No. Read-only access only.  |
