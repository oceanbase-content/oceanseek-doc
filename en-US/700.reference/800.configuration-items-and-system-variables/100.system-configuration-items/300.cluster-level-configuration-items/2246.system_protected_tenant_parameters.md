# system_protected_tenant_parameters

## Overview

The `system_protected_tenant_parameters` parameter is used to configure the list of tenant-level parameters that are locked. Parameters in this list cannot be modified by regular users.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Only the `sys` tenant can modify this parameter. User tenants cannot modify it.

## Attributes

| **Attribute** | **Description** |
| ---------- | ---------- |
| Parameter type | String |
| Default Value | Empty string (""), which indicates not to lock any parameters. |
| Value range | Up to 4 KB |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Usage instructions

* For tenant-level parameters that you do not want ordinary users to modify, you can add the parameter name to the parameter. After adding it, ordinary users (including those with Super privileges) will not be able to modify these parameters; only the ROOT user can do so.

* Parameter value description:

  Configuration parameters are separated by commas. The names of configuration parameters are case-insensitive. No spaces are allowed before or after a comma, and a parameter name must not start or end with a comma. The format is `"param1"` or `"param1,...,paran"`.

  **Example:**

  * `"param1"`
  * `"param1,param2"`
  * `"param1,param2,param3"`

  **Example of invalid configuration:**

  * `","`
  * `"param1,"`
  * `"param1, param2"` (a space follows the comma)
  * `"param1,param2,"`

## Configuration example

Add the `backup_dest` parameter to the protection list:

```shell
obclient> ALTER SYSTEM SET system_protected_tenant_parameters = "backup_dest";
```

Protect multiple tenant-level parameters simultaneously:

```shell
obclient> ALTER SYSTEM SET system_protected_tenant_parameters = "backup_dest,sts_credential";
```

Clear the protection list (allow all regular users to modify tenant-level parameters):

```shell
obclient> ALTER SYSTEM SET system_protected_tenant_parameters = "";
```
