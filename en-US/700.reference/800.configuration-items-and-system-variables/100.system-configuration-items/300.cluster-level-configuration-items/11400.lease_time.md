# lease_time

## Overview

`lease_time` specifies the duration of a heartbeat lease.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Only the `sys` tenant can modify this parameter. User tenants cannot modify it.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Parameter type | Time |
| Default Value | 10s |
| Value range | [1s, 5min] |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. <main id="notice" type='explain'><h4>Note</h4><p>Modifying this parameter is generally not recommended.</p></main> |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Usage instructions

If the Root Service does not receive a heartbeat from an OBServer node within the heartbeat lease duration, the OBServer node is considered offline.

## Configuration example

Set the heartbeat lease duration to 10 seconds.

```shell
obclient> ALTER SYSTEM SET lease_time ='10s';
```
