# memory_reserved

## Overview

`memory_reserved` specifies the memory size reserved for system underlying modules.

## Privilege requirements

* Query parameters

  The `sys` tenant and all user tenants can use the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view to query this parameter.

* Modify parameters

  Only the `sys` tenant can modify this parameter. User tenants cannot modify it.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Parameter type | Capacity |
| Default Value | 500 MB. The default unit is MB. You must specify the unit when configuring it. |
| Value range | 10M, +∞) |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Usage instructions

To ensure the normal operation of the base module, it is recommended to reserve sufficient `memory_reserved` as a safeguarding memory.

## Configuration example

Set the memory reserved for system underlying modules to 500 MB.

```shell
obclient> ALTER SYSTEM SET memory_reserved = '500M';
```
