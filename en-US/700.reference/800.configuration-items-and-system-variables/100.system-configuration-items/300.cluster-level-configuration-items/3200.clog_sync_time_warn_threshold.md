# clog_sync_time_warn_threshold

## Overview

`clog_sync_time_warn_threshold` specifies the threshold for generating a WARN log when the transaction log synchronization duration exceeds this value.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can execute the `SHOW PARAMETERS` statement to query this parameter.

* Modify parameters

  Only the `sys` tenant can modify this parameter. User tenants cannot modify it.

## Attributes

| **Attribute** | **Description** |
| ------------------ | ------------------ |
| Parameter type | Time |
| Default Value | 100ms |
| Value range | [1ms, 10000ms] |
| Modifiable | Yes, you can use the following methods:`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Configuration example

Set the alert threshold for transaction log synchronization time to 100 ms.

```shell
obclient> ALTER SYSTEM SET clog_sync_time_warn_threshold='100ms';
```
