# ob_enable_utl_http

## Overview

`ob_enable_utl_http` specifies whether to enable the UTL_HTTP package.

## Privilege requirements

* Query parameters

  The `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view can be used by both the sys tenant and all user tenants to query this parameter.

* Modify parameters

  Only the sys tenant can modify this parameter. User tenants cannot modify it.

## Attributes

| Attribute | Description |
| --- | --- |
| Parameter type | BOOL |
| Default Value | FALSE |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Configuration example

Run the following command to set `ob_enable_utl_http` to `true`.

```shell
ALTER SYSTEM SET ob_enable_utl_http=true;
```
