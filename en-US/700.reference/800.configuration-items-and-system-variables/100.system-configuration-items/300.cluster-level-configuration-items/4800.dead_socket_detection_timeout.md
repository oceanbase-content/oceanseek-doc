# dead_socket_detection_timeout

## Overview

`dead_socket_detection_timeout` specifies the interval for detecting invalid sockets.

## Privilege requirements

* Query parameters

  The `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Only the `sys` tenant can modify this parameter. User tenants cannot modify it.

## Attributes

| **Attribute** | **Description** |
| ------------------ | ------------- |
| Parameter type | Time |
| Default Value | 3s |
| Value range | [0s, 2h] |
| Modifiable | Yes, you can use the following methods:`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Usage instructions

* When the value of `dead_socket_detection_timeout` is 0, socket-level fault detection is disabled.

* When the value of `dead_socket_detection_timeout` is greater than 0, socket-level fault detection is enabled. If the sender fails to receive a response from the receiver within the set time for sending data, the current socket is considered unavailable.

## Configuration example

Set the time interval for detecting invalid sockets to 3 seconds.

```shell
obclient> ALTER SYSTEM SET dead_socket_detection_timeout= 3s;
```
