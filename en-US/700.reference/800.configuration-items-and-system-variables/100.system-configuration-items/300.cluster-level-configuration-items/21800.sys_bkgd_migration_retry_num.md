# sys_bkgd_migration_retry_num

## Overview

`sys_bkgd_migration_retry_num` specifies the maximum number of retries for a [replica migration](../../../../600.manage/300.replica-management/200.replica-distribution/200.locality-common-operations/700.unit-migration.md) failure.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Only the `sys` tenant can modify this parameter. User tenants cannot modify it.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Parameter type | Int |
| Default Value | 3 |
| Value range | [3, 100] |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Configuration example

Set the maximum number of retries for replica migration failures to 3.

```shell
obclient> ALTER SYSTEM SET sys_bkgd_migration_retry_num = 3;
```
