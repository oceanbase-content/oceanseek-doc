# memstore_limit_percentage

## Overview

`memstore_limit_percentage` specifies the percentage of a tenant's total available memory that can be used by the MemStore.

## Attributes

| **Attribute** | **Description** |
| ------------------ | ----------- |
| Parameter type | INT |
| Default Value | 0 indicates adaptive adjustment. |
| Value range | 0, 100) |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Usage instructions

* The `memstore_limit_percentage` parameter is used to calculate the value of `memstore_limit`. The calculation formula is as follows:

  `memstore_limit_percentage` = `memstore_limit` / `memory_size`

  Here, `memory_size` is the value specified when creating the tenant, representing the memory available for the tenant.

* You can also configure the percentage of memory occupied by a tenant's MemStore from the total memory of the tenant by using the tenant-level hidden parameter <code>_memstore_limit_percentage</code>. Except for the scope of application, its functionality and default value are the same as those of the cluster-level parameter <code>memstore_limit_percentage</code>. When configuring these two parameters, note the following:

  <ul><li>If only one of the parameters <code>_memstore_limit_percentage</code> or <code>memstore_limit_percentage</code> is configured with a value other than the default, that value will be used.</li> <li>If both the tenant-level hidden parameter <code>_memstore_limit_percentage</code> (with a value other than the default) and the cluster-level parameter <code>memstore_limit_percentage</code> (with a value other than the default) are configured, the value of <code>_memstore_limit_percentage</code> will be used.</li> <li>If neither is configured, or if both are configured with the default values, the system will use the following adaptive policy:<ul><li>Tenants with 8 GB or less of memory (real memory) will have their tenant MemStore configured at 40%.</li><li>Tenants with more than 8 GB of memory will have their tenant MemStore configured at 50%.</li></ul></li></ul>

## Configuration example

Set the memory for the tenant's MemStore to 60% of its total available memory.

```shell
obclient> ALTER SYSTEM SET memstore_limit_percentage = 60;
```
