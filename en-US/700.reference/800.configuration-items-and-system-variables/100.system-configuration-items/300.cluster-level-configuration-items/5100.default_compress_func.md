# default_compress_func

## Overview

`default_compress_func` is used to set the default compression algorithm for table data. Other compression algorithms can also be specified when creating a table.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Only the `sys` tenant can modify this parameter. User tenants cannot modify it.

## Attributes

| **Attribute** | **Description** |
| ---------------- | -------------- |
| Parameter type | String |
| Default Value | zstd_1.3.8 |
| Value range | <ul><li>none </li><li>lz4_1.0 </li><li>snappy_1.0 </li><li>zstd_1.0 </li><li>zstd_1.3.8 </li><li>zlib_lite_1.0 </li></ul> |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Usage instructions

Different minor versions of the zlib library may produce inconsistent compressed results for the same data. To avoid issues where replica data cannot be restored during an upgrade to OceanBase AI Database, the <code>zlib_1.0</code> compression algorithm is no longer supported.

## Configuration example

Set the default compression algorithm for table data to lz4_1.0.

```shell
obclient> ALTER SYSTEM SET default_compress_func = 'lz4_1.0';
```
