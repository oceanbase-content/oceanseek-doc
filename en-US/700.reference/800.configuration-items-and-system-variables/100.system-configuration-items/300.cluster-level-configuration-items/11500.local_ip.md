# local_ip

## Overview

`local_ip` specifies the IP address of the server where the OBServer node is to be installed.

## Privilege requirements

The `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

## Attributes

| **Attribute** | **Description** |
| --- | --- |
| Parameter type | String |
| Default Value | Empty string |
| Value range | Valid IP Address of the Target Server |
| Modifiable | No. This parameter can only be set during cluster deployment and cannot be modified after the cluster takes effect. |
| Whether to restart the OBServer node for the change to take effect | No, read-only only |

## Usage instructions

1. Modifying it using the `alter system set` statement is not supported.
2. When starting the OBServer, specify the IP address on the command line using the `-I` or `--local_ip` parameter.
3. It is not recommended to specify both `local_ip` and `devname`. If both are specified, `local_ip` takes precedence.
4. You can use the `-o` parameter to specify the IP address in the `local_ip=xxx.xxx.xxx.xxx` format. However, it is recommended to use the `-I` or `--local_ip` parameter to specify the IP address. If the IP address is specified using both the `-I/--local_ip` and `-o` parameters, the IP address specified by the `-o` parameter will prevail.

## Configuration example

Start OBServer on a specified IP address.

```shell
./observer -I xxx.xxx.xxx.xxx -P 2882 -p 2881 -z zone1 -n demo1 -c 1 -d /home/user_name/path_to_store/store -l INFO -r 'xxx.xxx.xxx.xxx:2882:2881;xxx.xxx.xxx.xxx:2884:2883' -o "memory_limit=64G,system_memory=16G"
```
