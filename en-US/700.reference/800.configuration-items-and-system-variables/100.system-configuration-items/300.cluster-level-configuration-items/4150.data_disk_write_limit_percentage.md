# data_disk_write_limit_percentage

## Overview

`data_disk_write_limit_percentage` specifies the percentage of data disk usage at which write operations are limited. When the data disk usage reaches this threshold, the system restricts write operations for business requests to prevent data disk space exhaustion.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Only the `sys` tenant can modify this parameter. User tenants cannot modify it.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Parameter type | Int |
| Default Value | 0: disabled. |
| Value range | [0, 100) |
| Modifiable | Yes, you can use the following methods:`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Usage instructions

* This parameter is used to stop writing when the data disk is full, so that issues can be detected early. After an issue is identified, you can urgently release space by dropping tables; otherwise, cluster recovery may become difficult.

* **The value must be greater than or equal to [data_disk_usage_limit_percentage](4100.data_disk_usage_limit_percentage.md).**

* **The recommended value for this parameter is (1 - memstore_limit_size/data_disk_size) * 100%**, where

  * memstore_limit_size: The maximum size of the memstore. It is calculated as `tenant memory_size * memstore_limit_percentage`.
  * data_disk_size: the size of the data disk configured by the user.

## Configuration example

Set the write limit percentage for the data disk to 90.

```shell
obclient> ALTER SYSTEM SET data_disk_write_limit_percentage=90;
```
