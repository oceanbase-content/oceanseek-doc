# global_background_cpu_quota

## Overview

`global_background_cpu_quota` specifies the number of CPU cores for background tasks when global foreground/background resource isolation is enabled. This parameter takes effect only when `enable_global_background_resource_isolation` is set to True.

## Privilege requirements

* Query parameters

  The `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view can be used by the `sys` tenant and all user tenants to query this parameter. The `sys` tenant can also query this parameter through the `information_schemaарамЕТРЫ` view.

* Modify parameters

  Only the `sys` tenant can modify this parameter. User tenants cannot modify it.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Parameter type | Int |
| Default Value | -1 |
| Value range | [-1, +∞)<main id="notice" type='explain'><h4>Note</h4><p>A value of -1 or 0 indicates that the number of CPU cores used is not limited by Cgroup.</p></main> |
| Modifiable | Yes, you can use the following methods:`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Configuration example

Sets the number of CPU cores for background tasks to 50 when global foreground/background resource isolation is enabled.

```shell
obclient> ALTER SYSTEM SET global_background_cpu_quota=50;
```
