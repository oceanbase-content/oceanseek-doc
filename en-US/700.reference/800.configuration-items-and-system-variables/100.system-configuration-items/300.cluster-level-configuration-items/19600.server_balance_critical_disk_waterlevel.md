# server_balance_critical_disk_waterlevel

## Overview

`server_balance_critical_disk_waterlevel` specifies the water level for the disk space load balancing feature. When the disk usage exceeds this threshold, the load balancing strategy will prioritize disk balancing.

## Privilege requirements

* Query parameters

  The `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Only the `sys` tenant can modify this parameter. User tenants cannot modify it.

## Attributes

| **Attribute** | **Description** |
| ------------------ | ----------- |
| Parameter type | Int |
| Default Value | 80 |
| Value range | [0, 100] |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Configuration example

Set the water level threshold for the disk space load balancing feature to 80. When disk usage is greater than or equal to 80%, the load balancing policy will prioritize disk balancing.

```shell
obclient> ALTER SYSTEM SET server_balance_critical_disk_waterlevel = 80;
```
