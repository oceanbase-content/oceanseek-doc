# mysql_port

## Overview

`mysql_port` specifies the port number for the SQL service protocol.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  This parameter is set only during cluster deployment and cannot be modified after the cluster starts.

## Attributes

| **Attribute** | **Description** |
| ------------------ | ----------------- |
| Parameter type | Int |
| Default Value | 2881 |
| Value range | [1025, 65535] |
| Modifiable | No, it is not supported to pass through`ALTER SYSTEM SET`Statement modification. |
| Whether a restart of the OBServer node is required for the change to take effect | No, read-only mode only.               |
