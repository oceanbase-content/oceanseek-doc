# all_cluster_list

## Overview

`all_cluster_list` is used to display the list of servers accessing the same `config_url`.

## Attributes

| **Attribute** | **Description** |
| ------------------ | -------- |
| Parameter type | String |
| Default Value | NULL value |
| Value range | NULL |
