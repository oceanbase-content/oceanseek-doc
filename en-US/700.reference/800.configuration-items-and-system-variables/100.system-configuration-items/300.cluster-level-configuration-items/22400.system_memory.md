# system_memory

## Overview

`system_memory` specifies the memory capacity reserved for the tenant with ID `500`.

  <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>The system-reserved memory cannot be allocated to regular tenants.</p>
  </main>

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Only the `sys` tenant can modify this parameter. User tenants cannot modify it.

## Attributes

| **Attribute** | **Description** |
| -------- | -------- |
| Parameter type | Capacity |
| Default Value | 0M indicates that the system automatically adjusts the memory usage strategy based on the current memory situation. |
| Value range | [0M, +∞) |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to Restart the OBServer Node for the Change to Take Effect | No, the setting takes effect immediately. |

## Configuration example

Set the memory capacity reserved for tenant ID `500` to 0 MB.

```shell
obclient> ALTER SYSTEM SET system_memory = '0M';
```
