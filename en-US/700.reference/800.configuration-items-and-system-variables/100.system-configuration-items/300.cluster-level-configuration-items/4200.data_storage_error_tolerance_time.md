# data_storage_error_tolerance_time

## Overview

The `data_storage_error_tolerance_time` parameter specifies the tolerance period for setting the data disk status to `ERROR`.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Only the `sys` tenant can modify this parameter. User tenants cannot modify it.

## Attributes

| Attribute | Description |
| ------------------ | ---------------- |
| Parameter type | Time |
| Default Value | 300s |
| Value range | [10s, 7200s] |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Usage instructions

When an unexpected I/O failure occurs, the IO Manager of OceanBase AI Database attempts to detect the data disk status via a probe thread. If, after the duration specified by this parameter, the probe determines that the data disk status of the server has not returned to normal, the probe thread sets the data disk status to `ERROR`. This status triggers events such as a server shutdown to prevent requests from failing when sent to that node.

## Configuration example

Set the tolerance time to 300 seconds when the data disk status is set to `ERROR`.

```shell
obclient> ALTER SYSTEM SET data_storage_error_tolerance_time = 300s;
```
