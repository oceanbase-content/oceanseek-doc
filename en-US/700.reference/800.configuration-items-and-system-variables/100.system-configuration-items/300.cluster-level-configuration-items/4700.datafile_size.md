# datafile_size

## Overview

The `datafile_size` parameter is used to set the size of the local cache.

## Privilege requirements

* Query parameters

  Both the `sys` tenant and all user tenants can query this parameter using the `SHOW PARAMETERS` statement or the `GV$OB_PARAMETERS` view.

* Modify parameters

  Only the `sys` tenant can modify this parameter. User tenants cannot modify it.

## Attributes

| **Attribute** | **Description** |
| ------------------ | ----------- |
| Parameter type | Capacity |
| Default Value | 0 MB. The default unit is MB. You must specify the unit when configuring it. |
| Value range | [0M, +∞) |
| Modifiable | Yes, you can use the`ALTER SYSTEM SET`Statement modification. |
| Whether to restart the OBServer node for the change to take effect | No, the setting takes effect immediately. |

## Usage instructions

* After this parameter is set, the storage capacity cannot be reduced when modified again; only expansion is supported.
* If this parameter is configured together with <code>datafile_disk_percentage</code>, the value set in this parameter takes effect. For more information about <code>datafile_disk_percentage</code>, see <a href="4400.datafile_disk_percentage.md">datafile_disk_percentage</a>.

## Configuration example

Set the local cache size to 80 GB.

```shell
obclient> ALTER SYSTEM SET datafile_size='80G';
```
