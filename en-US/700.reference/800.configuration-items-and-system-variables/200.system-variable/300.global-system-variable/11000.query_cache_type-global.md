# query_cache_type

## Overview

The `query_cache_type` parameter specifies the type of query cache.

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This variable is not effective at present.</p>
</main>

## Attributes

| **Attribute** | **Description** |
| ----------- | ---------------------------------------------------------------- |
| Parameter type | Varchar |
| Default Value | OFF |
| Value range | <ul><li>OFF: Do not cache or retrieve results.  </li><li>ON: Cache all fields except for`SELECT SQL_NO_CACHE ...`All query results. </li><li>DEMAND: Cache only`SELECT SQL_CACHE ...`Query results. </li></ul> |
| Effective Scope | Global |
| Modifiable? | No. This variable can only be specified when creating a tenant and cannot be modified via SQL statements after the tenant is created. |
