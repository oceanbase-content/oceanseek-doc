# ob_log_level

## Overview

`ob_log_level` specifies the log level for the current session. If this parameter is not specified, the system log level is used.

## Privilege requirements

* Query variables

  * Global level

    Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.GLOBAL_VARIABLES` view to view the values of global system variables.

  * Session level

    Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.SESSION_VARIABLES` view to view the values of session system variables.

* Modify variables

  * Global effective

    * The `sys` tenant can directly modify the values of global system variables.

    * The user tenant must have the `SUPER` or `ALTER SYSTEM` privilege to modify the value of a global system variable.

  * Session expiration

    The `sys` tenant and all user tenants can directly modify the values of session system variables for their own tenants.

## Attributes

| **Attribute** | **Description** |
| ---------- | ---------------------------- |
| Parameter type | Varchar |
| Default Value | disabled: Session-level logging is disabled. |
| Value range | <ul><li>trace: The most detailed log level, which records event details. This level is typically used for development and debugging. </li> <li>info: The normal information level, which records routine operational status. This level is typically used in production environments. </li><li>warn: The warning level, which records exceptions that may affect system stability, such as configuration issues. </li><li>error: The error level, which records only severe failures, such as service unavailability. </li></ul> |
| Effective Scope | <ul><li>Global</li> <li>Session </li></ul> |
| Modifiable | Yes, you can use the`SET`Statement modification. |

## Usage instructions

When `ob_log_level` is set to `disabled`, the system's global log level is used, which is controlled by the parameter [syslog_level](../../100.system-configuration-items/300.cluster-level-configuration-items/22200.syslog_level.md).

## Configuration example

Set the session-level log level to INFO.

* Session Validity Period

  ```shell
  obclient> SET ob_log_level ='INFO';
  ```

* Effective globally

  ```shell
  obclient> SET GLOBAL ob_log_level ='INFO';
  ```
