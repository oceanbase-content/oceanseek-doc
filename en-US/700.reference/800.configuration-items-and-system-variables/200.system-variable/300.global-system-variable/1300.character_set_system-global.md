# character_set_system

## Overview

`character_set_system` is used to view the character set used by the server.

## Privilege requirements

* Query variables

  * Global level

    The `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.GLOBAL_VARIABLES` view to view the values of global system variables.

  * Session level

    Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.SESSION_VARIABLES` view to view the values of session system variables.

* Modify variables

  The current variable cannot be modified.

## Attributes

| **Attribute** | **Description** |
| ----------- | --------------- |
| Parameter type | String |
| Default Value | utf8mb4 |
| Effective Scope | <ul><li>Global</li><li>Session</li></ul> |
| Modifiable | No, read-only is the only supported mode. |

## Sample query

Check the character set used by the server.

```shell
obclient> SHOW GLOBAL VARIABLES LIKE 'character_set_system';
```

The query result is as follows:

```shell
+----------------------+---------+
| Variable_name        | Value   |
+----------------------+---------+
| character_set_system | utf8mb4 |
+----------------------+---------+
```
