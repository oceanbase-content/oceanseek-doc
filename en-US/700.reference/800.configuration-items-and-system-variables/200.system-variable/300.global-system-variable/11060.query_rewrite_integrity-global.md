# query_rewrite_integrity

## Overview

`query_rewrite_integrity` specifies the data consistency check level for materialized view rewrite.

## Privilege requirements

* Query variables

  * Global level

    Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.GLOBAL_VARIABLES` view to view the values of global system variables.

  * Session level

    Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.SESSION_VARIABLES` view to view the values of session system variables.

* Modify variables

  * Global effective

    * The `sys` tenant can directly modify the values of global system variables.

    * The user tenant must have the `SUPER` or `ALTER SYSTEM` privilege to modify the value of a global system variable.

  * Session expiration

    The `sys` tenant and all user tenants can directly modify the values of session system variables for their own tenants.

## Attributes

| **Attribute** | **Description** |
| ---------- | -------------- |
| Parameter type | Enum |
| Default Value | enforced |
| Value range | [enforced, stale_tolerated]  <ul><li> enforced: Only real-time materialized views are used for query rewrite. The data in the rewritten materialized view is computed online as the current real-time data to ensure that the rewritten query result matches the original query.</li><li>stale_tolerated: Non-real-time materialized views are allowed for query rewrite. This may cause the rewritten query result to differ from the original query. In this case, even if a real-time materialized view that can be computed online is used for the rewrite, it will not be computed as the current real-time data.</li></ul> |
| Effective Scope | <ul><li>Global  </li><li>Session </li></ul> |
| Modifiable | Yes, you can use the`SET`Statement modification. |

## Usage instructions

The variable [query_rewrite_enabled](11050.query_rewrite_enabled-global.md) is meaningful only when its value is not `false`.

## Configuration example

Set to use only real-time materialized views for query rewrite.

* Session expiration

  ```shell
  obclient> SET  query_rewrite_integrity= enforced;
  ```

* Effective globally

  ```shell
  obclient> SET GLOBAL  query_rewrite_integrity= enforced;
  ```
