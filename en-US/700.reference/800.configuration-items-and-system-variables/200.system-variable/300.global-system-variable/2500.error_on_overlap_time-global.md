# error_on_overlap_time

## Overview

`error_on_overlap_time` specifies whether to report an error when the time in a daylight-saving time overlap zone is ambiguous.

## Privilege requirements

* Query variables

  * Global level

    The `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.GLOBAL_VARIABLES` view to view the values of global system variables.

  * Session level

    Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.SESSION_VARIABLES` view to view the values of session system variables.

* Modify variables

  * Global effective

    * The `sys` tenant can directly modify the values of global system variables.

    * The user tenant must have the `SUPER` or `ALTER SYSTEM` privilege to modify the value of a global system variable.

  * Session expiration

    The `sys` tenant and all user tenants can directly modify the values of session system variables for their own tenants.

## Attributes

| **Attribute** | **Description** |
| ----------- | --------------- |
| Parameter type | Bool |
| Default Value | OFF |
| Value range | <ul><li>ON: Perform error handling.</li><li>OFF: Do not perform error handling.</li></ul> |
| Effective Scope | <ul><li>Global</li><li>SESSION</li></ul> |
| Modifiable | Yes, you can use the`SET`Statement modification. |

## Configuration example

Specify not to report an error when ambiguity occurs during daylight saving time overlap zone time conversion.

* Effective globally

  ```shell
  obclient> SET GLOBAL error_on_overlap_time =OFF;
  ```

* Session expiration

  ```shell
  obclient> SET error_on_overlap_time =OFF;
  ```
