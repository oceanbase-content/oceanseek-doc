# ob_security_version

## Overview

`ob_security_version` specifies the version of OceanBase AI Database that is compatible with security features.

## Privilege requirements

* Query variables

  Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.GLOBAL_VARIABLES` view to view the values of global system variables.

* Modify variables

  * The `sys` tenant can directly modify the values of global system variables.

  * The user tenant must have the `SUPER` or `ALTER SYSTEM` privilege to modify the value of a global system variable.

## Attributes

| **Attribute** | **Description** |
| ----------- | --------------- |
| Parameter type | Varchar |
| Default Value | 4.6.2.0 |
| Value range | 4.2.3.0 and later versions |
| Effective Scope | Global |
| Modifiable | Yes, you can use the`SET`or`ALTER SESSION SET`The statement can be modified later. |

## Usage instructions

* If the value of this variable is not explicitly specified when creating a tenant, its default value is the current `cluster_version`.

* For users with security concerns, after upgrading to the new version, you must first ensure that your business operations are not exploiting any related security vulnerabilities or that the appropriate permissions have been granted to your business accounts. Only then can you set the value of this variable to the higher version.

* This variable is used only to control future security behavior changes.

* Unlike the `ob_compatibility_version` variable, this version can only be increased, not rolled back.

## Configuration example

* The OceanBase AI database version compatible with the specified security feature is V4.6.2.0 when creating the tenant.

  ```shell
  obclient> create tenant tenant_m57 zone_list=('z1'),primary_zone='z1',resource_pool_list=('pool1') set ob_compatibility_mode='MYSQL',ob_security_version='4.6.2.0',ob_tcp_invited_nodes='%';
  ```

* Set the OceanBase AI database version compatible with the specified security feature to V4.6.2.0.

  ```shell
  set global ob_security_version ='4.6.2.0';
  ```
