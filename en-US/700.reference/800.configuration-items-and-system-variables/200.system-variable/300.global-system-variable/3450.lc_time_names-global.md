# lc_time_names

## Overview

`lc_time_names` specifies the language for displaying date and month names and their abbreviations.

## Privilege requirements

* Query variables

  * Global level

    The `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement or the `information_schema.GLOBAL_VARIABLES` view to view the values of global system variables.

  * Session level

    The `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement or the `information_schema.SESSION_VARIABLES` view to view the values of session system variables.

* Modify variables

  * Global effective

    * The `sys` tenant can directly modify the values of global system variables.

    * The user tenant must have the `SUPER` or `ALTER SYSTEM` privilege to modify the value of a global system variable.

  * Session expiration

    The `sys` tenant and all user tenants can directly modify the values of session system variables for their own tenants.

## Attributes

| **Attribute** | **Description** |
| --------- | --------------- |
| Parameter type | Varchar |
| Default Value | en_US |
| Value range | <ul><li>en_US: English</li><li>ja_JP: Japanese</li><li>ko_KR: Korean</li><li>zh_CN: Chinese</li><li>zh_TW: Chinese (Taiwan)</li></ul> |
| Effective Scope | <ul><li>Global  </li><li>SESSION </li></ul> |
| Modifiable | Yes, you can use the`SET`Statement modification. |

## Usage instructions

This variable affects the output of the `DATE_FORMAT()`, `DAYNAME()`, and `MONTHNAME()` functions, but does not affect the results of the `STR_TO_DATE()` or `GET_FORMAT()` functions.

## Configuration example

Take the display of the result of a date function in Chinese as an example:

1. Set the language to Chinese for displaying date, month names, and their abbreviations.

   * Session expiration

     ```shell
     obclient> SET lc_time_names='zh_CN';
     ```

   * Global effective

     ```shell
     obclient> SET GLOBAL lc_time_names='zh_CN';
     ```

2. Check the current value of `lc_time_names`.

   ```sehll
   obclient> show variables like "lc_time_names";
   ```

   The return result is as follows:

   ```sehll
   +---------------+-------+
   | Variable_name | Value |
   +---------------+-------+
   | lc_time_names | zh_CN |
   +---------------+-------+
   1 row in set (0.015 sec)
   ```

3. Use the `DAYNAME()` function to query the weekday corresponding to the input date.

   ```sehll
   obclient> select DAYNAME('2023-01-06');
   ```

   The return result is as follows:

   ```sehll
   +-----------------------+
   | DAYNAME('2023-01-06') |
   +-----------------------+
   | Friday                |
   +-----------------------+
   1 row in set (0.000 sec)
   ```
