# ob_route_policy

## Overview

The `ob_route_policy` parameter specifies the routing policy for selecting data replicas within an OBServer node.

## Privilege requirements

* Query variables

  * Global level

    The `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.GLOBAL_VARIABLES` view to view the values of global system variables.

  * Session level

    Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.SESSION_VARIABLES` view to view the values of session system variables.

* Modify variables

  * Global effective

    * The `sys` tenant can directly modify the values of global system variables.

    * The user tenant must have the `SUPER` or `ALTER SYSTEM` privilege to modify the value of a global system variable.

  * Session expiration

    The `sys` tenant and all user tenants can directly modify the values of session system variables for their own tenants.

## Attributes

| **Attribute** | **Description** |
| ------------ | ---------------------------- |
| Parameter type | Enum |
| Default Value | 1 |
| Value range | <ul><li> 1(`READONLY_ZONE_FIRST`): Zone of the read-only replica takes priority. </li>  <li> 2 (`ONLY_READONLY_ZONE`): Send only to the zone where the read-only replica is located.  </li>  <li> 3 (`UNMERGE_ZONE_FIRST`): The zone where the replica not in a major compaction state is located takes priority.  </li> <li> 4 (`UNMERGE_FOLLOWER_FIRST`): Prioritize Follower replicas that are not in a major compaction state. </li> <li> 5 (`COLUMN_STORE_ONLY`): Send only to columnstore replicas.</li><li>6 (`FORCE_READONLY_ZONE`): All read-only requests are not forwarded to non-read-only replicas.</li></ul> |
| Effective Scope | <ul><li>Global </li><li>Session </li></ul> |
| Modifiable | Yes, you can use the`SET`Statement modification. |

## Configuration example

Set the routing strategy for selecting data replicas within an OBServer node to prioritize zones where read-only replicas reside.

* Session Validity Period

  ```shell
  obclient> SET ob_route_policy = 'READONLY_ZONE_FIRST';
  ```

  or

  ```shell
  obclient> SET ob_route_policy = 1;
  ```

* Effective globally

  ```shell
  obclient> SET GLOBAL ob_route_policy = 'READONLY_ZONE_FIRST';
  ```

  or

  ```shell
  obclient> SET GLOBAL ob_route_policy = 1;
  ```
