# event_scheduler

## Overview

`event_scheduler` specifies whether the event scheduler is enabled and running on the server.

## Privileges

* Query variables

  Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.GLOBAL_VARIABLES` view to view the values of global system variables.

* Modify variables

  * The `sys` tenant can directly modify the values of global system variables.

  * The user tenant must have the `SUPER` or `ALTER SYSTEM` privilege to modify the value of a global system variable.

## Attributes

| **Attribute** | **Description** |
| --- | --- |
| Parameter type | Bool |
| Default Value | OFF |
| Value range | <ul><li> OFF: The event scheduler has stopped. </li><li> ON: The event scheduler has started; its threads are running and executing all scheduled events. </li></ul> |
| Effective Scope | Global |
| Modifiable | Yes, you can use the following methods:`SET`Statement modification. |

## Configuration example

Run the following command to start the event scheduler:

```sql
obclient> SET GLOBAL event_scheduler=ON;
```
