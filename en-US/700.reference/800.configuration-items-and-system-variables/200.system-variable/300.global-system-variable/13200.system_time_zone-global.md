# system_time_zone

## Overview

`system_time_zone` is used to set the system time zone of the server.

## Privilege requirements

* Query variables

  Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.GLOBAL_VARIABLES` view to view the values of global system variables.

* Modify variables

  After a tenant is created, the value of this variable cannot be modified using SQL statements.

## Attributes

| **Attribute** | **Description** |
| ------------ | ----------------------------------------------------------------------------------- |
| Parameter type | Varchar |
| Default Value | CST |
| Value range | <ul><li> Value range: \[-12:59,+13:00\]. </li> <li> Time zones such as CDT (Central Daylight Time) and CST (China Standard Time). </li> </ul> |
| Effective Scope | Global |
| Modifiable? | No. This variable can only be specified when creating a tenant and cannot be modified via SQL statements after the tenant is created.   |
