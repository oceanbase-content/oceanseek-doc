# performance_schema

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This variable is for compatibility with MySQL 8.0 only. The related feature is not supported; you can query and set it, but the setting will not take effect without an error being reported.</p>
</main>

## Overview

The `performance_schema` clause is used to indicate to the client whether performance information queries are supported.

## Attributes

| Attribute | Description |
| -------------- | ------------------------------------------------------- |
| Parameter type | Bool |
| Default Value | OFF |
| Value range | <ul><li>ON: supported</li><li>OFF: not supported</li></ul> |
| Effective Scope | Global |
| Modifiable?   | Yes. You can use the `SET` statement to modify it. |
