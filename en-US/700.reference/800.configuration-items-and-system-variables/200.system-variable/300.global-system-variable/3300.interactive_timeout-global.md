# interactive_timeout

## Overview

`interactive_timeout` specifies the number of seconds the server waits for activity before closing an interactive connection.

## Privilege requirements

* Query variables

  * Global level

    Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.GLOBAL_VARIABLES` view to view the values of global system variables.

  * Session level

    Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.SESSION_VARIABLES` view to view the values of session system variables.

* Modify variables

  * Global effective

    * The `sys` tenant can directly modify the values of global system variables.

    * The user tenant must have the `SUPER` or `ALTER SYSTEM` privilege to modify the value of a global system variable.

  * Session expiration

    The `sys` tenant and all user tenants can directly modify the values of session system variables for their own tenants.

## Attributes

| **Attribute** | **Description** |
| ---------- | ----------------------------- |
| Parameter type | Int |
| Default Value | 28800 |
| Value range | [1, 31536000] |
| Effective Scope | <ul><li>Global</li><li>Session</li></ul> |
| Modifiable | Yes, you can use the`SET`Statement modification. |

## Usage instructions

When a session is started, its `wait_timeout` value is initialized based on either the global `wait_timeout` or the global `interactive_timeout` value. Which value is used depends on the client type. The client type is defined by the `CLIENT_INTERACTIVE` connection option in `mysql_real_connect`. For more information about the `wait_timeout` variable, see [wait_timeout](14600.wait_timeout-global.md).

## Configuration example

Set the number of seconds to wait for active connections before closing interactive connections on the server to 28800.

* Session Validity Period

  ```shell
  obclient> SET interactive_timeout = 28800;
  ```

* Effective globally

  ```shell
  obclient> SET GLOBAL interactive_timeout = 28800;
  ```
