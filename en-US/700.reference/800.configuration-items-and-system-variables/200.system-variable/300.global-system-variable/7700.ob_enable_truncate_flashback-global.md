# ob_enable_truncate_flashback

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This variable is no longer used. It can still be queried and set, but the related features will not take effect.</p>
</main>

## Overview

`ob_enable_truncate_flashback` specifies whether to enable truncation-based flashback for tables.

## Attributes

| **Attribute** | **Description** |
| ---------- | ------------------ |
| Parameter type | Bool |
| Default Value | OFF |
| Value range | <ul><li>OFF (0): disabled</li><li>ON (1): enabled</li></ul> |
| Effective Scope | <ul><li>Global</li><li>Session</li></ul> |
| Modifiable? | Yes. You can use the `SET` statement to modify it. |
