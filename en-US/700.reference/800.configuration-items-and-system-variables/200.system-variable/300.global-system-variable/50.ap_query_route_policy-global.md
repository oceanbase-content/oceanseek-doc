# ap_query_route_policy

## Overview

The `ap_query_route_policy` parameter specifies the adaptive selection policy for AP queries to replica.

## Privilege requirements

* Query variables

  * Global level

    Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.GLOBAL_VARIABLES` view to view the values of global system variables.

  * Session level

    Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.SESSION_VARIABLES` view to view the values of session system variables.

* Modify variables

  * Global effective

    * The `sys` tenant can directly modify the values of global system variables.

    * The user tenant must have the `SUPER` or `ALTER SYSTEM` privilege to modify the value of a global system variable.

  * Session expiration

    The `sys` tenant and all user tenants can directly modify the values of session system variables for their own tenants.

## Attributes

| **Attribute** | **Description** |
| ---------- | ---------- |
| Parameter type | Enum |
| Default Value | AUTO |
| Value range | <ul><li>OFF: Disable.</li><li>AUTO: Adaptable selection of columnstore replicas based on query characteristics and cost.</li><li>FORCE: Always select columnstore replicas for execution.</li></ul> |
| Effective Scope | <ul><li>Global</li><li>Session</li></ul> |
| Modifiable | Yes, you can use the`SET`Statement modification. |

## Usage instructions

The `ap_query_route_policy` variable is a switch that controls the adaptive selection of columnstore replicas. For clusters without columnstore replicas, the value of the `ap_query_route_policy` variable has no effect.

This variable can also be controlled at the query level using the `opt_param` hint.

## Configuration example

Set the value of `ap_query_route_policy` to `AUTO`.

* Session expiration

  ```shell
  obclient> SET ap_query_route_policy = 'AUTO';
  ```

* Effective globally

  ```shell
  obclient> SET GLOBAL ap_query_route_policy = 'AUTO';
  ```
