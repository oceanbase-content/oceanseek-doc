# ob_reserved_meta_memory_percentage

## Overview

`ob_reserved_meta_memory_percentage` specifies the percentage of memory reserved for the tenant, which is primarily used to store metadata-related structural information.

## Privilege requirements

* Query variables

  Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.GLOBAL_VARIABLES` view to view the values of global system variables.

* Modify variables

  * The `sys` tenant can directly modify the values of global system variables.

  * The user tenant must have the `SUPER` or `ALTER SYSTEM` privilege to modify the value of a global system variable.

## Attributes

| **Attribute** | **Description** |
| ---------- | ---------------------------- |
| Parameter type | Int |
| Default Value | 10 |
| Value range | [1,100) |
| Effective Scope | Global |
| Modifiable | Yes, you can use the following methods:`SET`Statement modification. |

## Configuration example

Set the tenant reserved memory ratio to 10.

```shell
obclient> SET GLOBAL ob_reserved_meta_memory_percentage= 10;
```
