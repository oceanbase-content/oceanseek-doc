# socket

## Overview

`socket` is used to query the name of the local client connection `Socket` file.

## Privilege requirements

* Query variables

  Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement or the `information_schema.GLOBAL_VARIABLES` view to view the values of global system variables.

* Modify variables

  This variable cannot be modified.

## Attributes

| **Attribute** | **Description** |
| ----------- | --------------- |
| Parameter type | Varchar |
| Default Value | /run/sql.sock |
| Effective Scope | Global |
| Modifiable | No, read-only is the only supported mode. |
| Read-only | Yes |

## Sample query

Query the name of the local client connection `socket` file.

```shell
obclient> SHOW VARIABLES LIKE 'socket';
```

The query result is as follows:

```shell
+---------------+------------------------------------+
| Variable_name | Value                              |
+---------------+------------------------------------+
| socket        | /home/admin/oceanbase/run/sql.sock |
+---------------+------------------------------------+
1 row in set (0.003 sec)
```
