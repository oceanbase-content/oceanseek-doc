# max_allowed_packet

## Overview

`max_allowed_packet` specifies the maximum size of a network packet.

## Privilege requirements

* Query variables

  Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.GLOBAL_VARIABLES` view to view the values of global system variables.

* Modify variables

  * The `sys` tenant can directly modify the values of global system variables.

  * The user tenant must have the `SUPER` or `ALTER SYSTEM` privilege to modify the value of a global system variable.

## Attributes

| **Attribute** | **Description** |
| ----------- | ----------------------- |
| Parameter type | Int |
| Default Value | 16,777,216 bytes. |
| Value range | [1024,1073741824] |
| Effective Scope | Global |
| Modifiable | Yes, only supports through`SET GLOBAL`Statement modification. |

## Usage instructions

* You can modify the value of this variable by using the `SET GLOBAL` statement in global scope, but you cannot use the `SET SESSION` statement to modify it in session scope.

* When using this feature, both the client and server sides generally need to be adjusted. If the values on the two sides do not match, an error `ERROR 1153 (08S01) : Got a packet bigger than \'max_allowed_packet\' bytes` is returned.

## Configuration example

Set the maximum packet size to 16,777,216 bytes.

```shell
obclient> SET GLOBAL max_allowed_packet=16777216;
```
