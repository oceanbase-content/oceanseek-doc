# port

## Overview

`port` specifies the port number on which the server listens for TCP/IP connections during the deployment of an OBServer node.

## Privilege requirements

* Query variables

  Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement or the `information_schema.GLOBAL_VARIABLES` view to view the values of global system variables.

* Modify variables

  This variable cannot be modified.

## Attributes

| **Attribute** | **Description** |
| ----------- | --------------- |
| Parameter type | Int |
| Default Value | 3306 |
| Effective Scope | Global |
| Modifiable | No. This variable can only be specified when deploying an OBServer node and cannot be set through the`SET`Statement modification. |
| Read-only | Yes |

## Sample query

Query the port number on which the server listens for TCP/IP connections.

```shell
obclient> SHOW VARIABLES LIKE 'port';
```

The query result is as follows:

```shell
+---------------+-------+
| Variable_name | Value |
+---------------+-------+
| port          | 2881  |
+---------------+-------+
1 row in set (0.003 sec)
```
