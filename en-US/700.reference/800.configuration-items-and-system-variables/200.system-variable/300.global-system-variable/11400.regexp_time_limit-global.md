# regexp_time_limit

## Overview

`regexp_time_limit` specifies the maximum execution time for a regular expression match, in milliseconds by default.

## Privilege requirements

* Query variables

  Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.GLOBAL_VARIABLES` view to view the values of global system variables.

* Modify variables

  * The `sys` tenant can directly modify the values of global system variables.

  * You must have the `SUPER` or `ALTER SYSTEM` privilege to modify the value of a global system variable.

## Attributes

| **Attribute** | **Description** |
| --------------- | ------------------------------------------ |
| Parameter type | Int |
| Default Value | 32 |
| Value range | \[0, 2147483647] |
| Effective Scope | Global |
| Modifiable | Yes, you can use the following methods:`SET`Statement modification. |

## Configuration example

Set the maximum execution time for regular expression matching operations to 32 ms.

```shell
obclient> SET GLOBAL regexp_time_limit = 32;
```
