# runtime_filter_type

## Overview

`runtime_filter_type` is used to set the tenant-level Runtime Filter type.

## Privilege requirements

* Query variables

  * Global level

    Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.GLOBAL_VARIABLES` view to view the values of global system variables.

  * Session level

    Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.SESSION_VARIABLES` view to view the values of session system variables.

* Modify variables

  * Global effective

    * The `sys` tenant can directly modify the values of global system variables.

    * The user tenant must have the `SUPER` or `ALTER SYSTEM` privilege to modify the value of a global system variable.

  * Session expiration

    The `sys` tenant and all user tenants can directly modify the values of session system variables for their own tenants.

## Attributes

| Attribute | Description |
| --- | --- |
| Parameter type | Varchar |
| Default Value | BLOOM_FILTER,RANGE,IN |
| Value range | <ul><li>BLOOM_FILTER: Indicates that the data is filtered using a Bloom filter-type runtime filter, which determines whether the data is within the Bloom filter.  </li><li>RANGE: Indicates that the data is filtered using a RANGE-type runtime filter, which internally stores the maximum and minimum values of the build table, and filters the data by determining whether it is within this interval. </li><li>IN: Indicates that the data is filtered using an IN-type runtime filter, whose internal data structure is a hash table. The data is filtered by determining whether it is present in the hash table. </li><li>Empty string: Indicates that the runtime filter feature is disabled. </li></ul><main id="notice" type='explain'><h4>Note</h4><p>If the value is BLOOM_FILTER, RANGE, or IN, at least one of these must be selected.</p></main> |
| Effective Scope | <ul><li>Global  </li><li>Session </li></ul> |
| Modifiable | Yes, you can use the`SET`Statement modification. |

## Configuration example

* Session Validity Period

  Set the Runtime Filter type to `range`, `bloom_filter`, or `in`.

  ```shell
  obclient> SET runtime_filter_type = 'range,in,bloom_filter';
  ```

  Disable the Runtime Filter feature with the following statement:

  ```shell
  obclient> SET runtime_filter_type = '';
  ```

* Effective globally

  Set the tenant-level Runtime Filter type to `range`.

  ```shell
  obclient> SET GLOBAL runtime_filter_type = 'range';
  ```
