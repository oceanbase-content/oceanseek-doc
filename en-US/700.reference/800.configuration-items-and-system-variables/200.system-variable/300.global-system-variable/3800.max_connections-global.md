# max_connections

## Overview

`max_connections` specifies the maximum number of connections for the entire tenant.

## Privilege requirements

* Query variables

  Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement or the `information_schema.GLOBAL_VARIABLES` view (in MySQL-compatible mode) to view the values of global system variables.

* Modify variables

  * The `sys` tenant can directly modify the values of global system variables.

  * The user tenant must have the `SUPER` or `ALTER SYSTEM` privilege to modify the value of a global system variable.

## Attributes

| **Attribute** | **Description** |
| ------------ | ------------------- |
| Parameter type | Uint |
| Default Value | 2147483647 |
| Value range | [1,2147483647] |
| Effective Scope | Global |
| Modifiable | Yes, you can use the following methods:`SET`Statement modification. |

## Configuration example

Set the maximum number of connections for the entire tenant to 2,147,483,647.

```shell
obclient> SET GLOBAL max_connections=2147483647;
```
