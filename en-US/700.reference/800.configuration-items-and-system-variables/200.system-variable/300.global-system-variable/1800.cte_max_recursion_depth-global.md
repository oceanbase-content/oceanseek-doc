# cte_max_recursion_depth

## Overview

The `cte_max_recursion_depth` parameter specifies the maximum recursion depth for a common table expression (CTE). The server terminates operations that exceed this CTE value.

## Privilege requirements

* Query variables

  * Global level

    Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement or the `information_schema.GLOBAL_VARIABLES` view to view the values of global system variables.

  * Session level

    Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement or the `information_schema.SESSION_VARIABLES` view to view the values of session system variables.

* Modify variables

  * Global effective

    * The `sys` tenant can directly modify the values of global system variables.

    * The user tenant must have the `SUPER` or `ALTER SYSTEM` privilege to modify the value of a global system variable.

  * Session takes effect

    The `sys` tenant and all user tenants can directly modify the values of session system variables for their own tenants.

## Attributes

| **Attribute** | **Description** |
| ----------- | --------------- |
| Parameter type | Uint |
| Default Value | 1000 |
| Value range | [0, 4294967295] |
| Effective Scope | <ul><li>Global</li><li>Session</li></ul> |
| Modifiable | Yes, you can use the`SET`Statement modification. |
| Whether it can be empty | Yes |

## Configuration example

Set the maximum recursion depth of a common table expression (CTE) to 1,000.

* Effective globally

  ```shell
  obclient> SET GLOBAL cte_max_recursion_depth = 1000;
  ```

* Session expiration

  ```shell
  obclient> SET cte_max_recursion_depth =1000;
  ```
