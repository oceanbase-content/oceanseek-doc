# max_user_connections

## Overview

`max_user_connections` specifies the maximum number of connections a single user can establish to an OBServer node.

## Privilege requirements

* Query variables

  * Global level

    Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.GLOBAL_VARIABLES` view to view the values of global system variables.

  * Session level

    The `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.SESSION_VARIABLES` view to view the values of session system variables.

* Modify variables

  * The `sys` tenant can directly modify the values of global system variables.

  * The user tenant must have the `SUPER` or `ALTER SYSTEM` privilege to modify the value of a global system variable.

## Attributes

| **Attribute** | **Description** |
| ---------- | ----------------- |
| Parameter type | Uint |
| Default Value | 0 indicates that the number of connections is not limited. |
| Value range | [0, 4294967295] |
| Effective Scope | <ul><li>Global</li> <li>Session </li></ul> |
| Modifiable | This variable can be obtained through the`SET GLOBAL`The value obtained by modifying the global effective method cannot be obtained through`ALTER SESSION SET`statement modifies the value under the session effective mode. |

## Configuration example

Set the number of connections that a single user can establish to an OBServer node to unlimited.

```shell
obclient> SET GLOBAL max_user_connections =0;
```
