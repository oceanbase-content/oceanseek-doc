# ob_plan_cache_evict_high_percentage

## Overview

`ob_plan_cache_evict_high_percentage` specifies the percentage of the maximum memory that triggers plan cache eviction.

## Privilege requirements

* Query variables

  Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.GLOBAL_VARIABLES` view to view the values of global system variables.

* Modify variables

  * The `sys` tenant can directly modify the values of global system variables.

  * The user tenant must have the `SUPER` or `ALTER SYSTEM` privilege to modify the value of a global system variable.

## Attributes

| **Attribute** | **Description** |
| ---------- | ---------------------------- |
| Parameter type | Int |
| Default Value | 90 |
| Value range | [0, 100] |
| Effective Scope | Global |
| Modifiable | Yes, you can use the`SET`Statement modification. |

## Usage instructions

The memory size that triggers plan cache eviction (the high watermark for eviction) is calculated as follows: Absolute upper limit of plan cache memory × ob_plan_cache_evict_high_percentage / 100. For information about the absolute upper limit of plan cache memory, see [ob_plan_cache_percentage](../300.global-system-variable/8400.ob_plan_cache_percentage-global.md).

## Configuration example

Set the percentage of the maximum memory to be 90.

```shell
obclient> SET GLOBAL ob_plan_cache_evict_high_percentage =90;
```
