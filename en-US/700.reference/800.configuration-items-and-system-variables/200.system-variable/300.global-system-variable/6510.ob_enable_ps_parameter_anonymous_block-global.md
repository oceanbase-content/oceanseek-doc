# ob_enable_ps_parameter_anonymous_block

## Overview

`ob_enable_ps_parameter_anonymous_block` specifies whether to enable or disable parameterization for anonymous blocks and `CALL` statements during parsing in PS mode.

## Privilege requirements

* Query variables

  * Global level

    Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.GLOBAL_VARIABLES` view to view the values of global system variables.

  * Session level

    The `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.SESSION_VARIABLES` view to view the values of session system variables.

* Modify variables

  * Global effective

    * The `sys` tenant can directly modify the values of global system variables.

    * The user tenant must have the `SUPER` or `ALTER SYSTEM` privilege to modify the value of a global system variable.

  * Session Validity Period

    The `sys` tenant and all user tenants can directly modify the values of session system variables for their own tenants.

## Attributes

| **Attribute** | **Description** |
| ----------- | --------------- |
| Parameter type | Bool |
| Default Value | ON |
| Value range | <ul><li>ON</li><li>OFF</li> |
| Effective Scope | <ul><li>Global</li><li>Session</li></ul> |
| Modifiable | Yes, you can use the following methods:`SET`or`ALTER SESSION SET`Statement modification. |

## Configuration example

Enable parameterization for anonymous blocks and `call` statements during parsing in PS mode.

* Effective globally

```shell
obclient> SET GLOBAL aob_enable_ps_parameter_anonymous_block=ON;
```

* Session expiration

```shell
obclient> SET ob_enable_ps_parameter_anonymous_block=ON;
```
