# ob_enable_jit

## Overview

`ob_enable_jit` is used to set the JIT execution engine mode.

## Privilege requirements

* Query variables

  * Global level

    The `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.GLOBAL_VARIABLES` view to view the values of global system variables.

  * Session level

    The `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.SESSION_VARIABLES` view to view the values of session system variables.

* Modify variables

  * Global effective

    * The `sys` tenant can directly modify the values of global system variables.

    * The user tenant must have the `SUPER` or `ALTER SYSTEM` privilege to modify the value of a global system variable.

  * Session Validity Period

    The `sys` tenant and all user tenants can directly modify the values of session system variables for their own tenants.

## Attributes

| **Attribute** | **Description** |
| ---------- | ---------------------------- |
| Parameter type | Enum |
| Default Value | OFF |
| Value range | <ul><li>OFF: Disable expression compilation and execution for the current session. </li> <li>AUTO: Enable expression compilation and execution for the current session only when the average SQL execution RT exceeds 1 second. </li><li>FORCE: Force enable expression compilation and execution for the current session. </li></ul> |
| Effective Scope | <ul><li>Global</li> <li>Session </li></ul> |
| Modifiable | Yes, you can use the`SET`Statement modification. |

## Configuration example

Set the JIT execution engine mode to OFF.

* Session Validity Period

  ```shell
  obclient> SET ob_enable_jit =OFF;
  ```

* Effective globally

  ```shell
  obclient> SET GLOBAL ob_enable_jit =OFF;
  ```
