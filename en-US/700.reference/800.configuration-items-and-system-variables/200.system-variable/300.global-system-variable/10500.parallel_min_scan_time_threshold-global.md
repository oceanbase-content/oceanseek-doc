# parallel_min_scan_time_threshold

## Overview

`parallel_min_scan_time_threshold` is a parameter used to calculate the degree of parallelism in the auto-DOP strategy. It sets the minimum estimated execution time for parallel processing of base table scans. When the estimated execution time for a base table scan exceeds this threshold, parallelism is enabled, and an appropriate degree of parallelism is calculated based on this value.

## Privilege requirements

* Query variables

  * Global level

    The `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.GLOBAL_VARIABLES` view to view the values of global system variables.

  * Session level

    The `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.SESSION_VARIABLES` view to view the values of session system variables.

* Modify variables

  * Global effective

    * The `sys` tenant can directly modify the values of global system variables.

    * The user tenant must have the `SUPER` or `ALTER SYSTEM` privilege to modify the value of a global system variable.

  * Session expiration

    The `sys` tenant and all user tenants can directly modify the values of session system variables for their own tenants.

## Configuration example

Set the minimum estimated execution time for parallel processing of base table scans to 100 ms.

* Session expiration

  ```shell
  obclient> SET parallel_min_scan_time_threshold = 100;
  ```

* Effective globally

  ```shell
  obclient> SET GLOBAL parallel_min_scan_time_threshold = 100;
  ```
