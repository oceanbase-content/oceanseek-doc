# init_connect

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This variable is for compatibility with MySQL 5.7 only. The related feature is not supported. You can query and set it, but the setting will not take effect without an error message.</p>
</main>

## Overview

`init_connect` specifies the string that the server executes for each client connection. The string consists of one or more SQL statements separated by semicolons.

## Attributes

| **Attribute** | **Description** |
| ----------- | --------------- |
| Parameter type | Varchar |
| Effective Scope | Global |
| Modifiable? | Yes. You can use the `SET` statement to modify it. |
