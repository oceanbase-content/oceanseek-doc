# sql_throttle_rt

## Overview

`sql_throttle_rt` specifies the RT value in microseconds. If the RT value of a query is not less than this value, the query is not allowed to be executed.

## Privilege requirements

* Query variables

  Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.GLOBAL_VARIABLES` view to view the values of global system variables.

* Modify variables

  * The `sys` tenant can directly modify the values of global system variables.

  * You must have the `SUPER` or `ALTER SYSTEM` privilege to modify the value of a global system variable.

## Attributes

| **Attribute** | **Description** |
| -------- | ----------------- |
| Parameter type | Numeric |
| Default Value | -1 |
| Value range | No specific value range. It depends on the actual business load. |
| Effective Scope | Global |
| Modifiable | Yes, you can use the`SET`Statement modification. |

## Configuration example

Specify the query's RT value as 100 μs.

```shell
obclient> SET GLOBAL sql_throttle_rt = 100;
```
