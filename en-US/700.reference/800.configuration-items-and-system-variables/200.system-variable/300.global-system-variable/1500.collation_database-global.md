# collation_database

## Overview

`collation_database` specifies the default character set and collation for creating a database.

## Privilege requirements

* Query variables

  * Global level

    Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement or the `information_schema.GLOBAL_VARIABLES` view to view the values of global system variables.

  * Session level

    The `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement or the `information_schema.SESSION_VARIABLES` view to view the values of session system variables.

* Modify variables

  * Global effective

    * The `sys` tenant can directly modify the values of global system variables.

    * The user tenant must have the `SUPER` or `ALTER SYSTEM` privilege to modify the value of a global system variable.

  * Session expiration

    The `sys` tenant and all user tenants can directly modify the values of session system variables for their own tenants.

## Configuration example

Specify the default character set and collation for database creation as `utf8mb4_general_ci`.

* Effective globally

  ```shell
  obclient> SET GLOBAL collation_database='utf8mb4_general_ci';
  ```

* Session expiration

  ```shell
  obclient> SET collation_database='utf8mb4_general_ci';
  ```
