# validate_password_check_user_name

## Overview

`validate_password_check_user_name` specifies whether the user password can be the same as the username.

## Privilege requirements

* Query variables

  Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.GLOBAL_VARIABLES` view to view the values of global system variables.

* Modify variables

  * The `sys` tenant can directly modify the values of global system variables.

  * The user tenant must have the `SUPER` or `ALTER SYSTEM` privilege to modify the value of a global system variable.

## Attributes

| **Attribute** | **Description** |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| Parameter type | Enum |
| Default Value | on |
| Value range | <ul><li>on: the user password cannot be the same as the username. </li><li>off: the user password can be the same as the username. </li></ul> |
| Effective Scope | Global |
| Modifiable | Yes, you can use the`SET`Statement modification. |

## Usage instructions

This variable must be used together with the [validate_password_policy](14200.validate_password_policy-global.md) variable. It takes effect only when the value of [validate_password_policy](14200.validate_password_policy-global.md) is `MEDIUM`.

## Configuration example

The user password cannot be the same as the username.

```shell
obclient> SET GLOBAL validate_password_check_user_name = on;
```
