# ob_early_lock_release

<main id="notice" type='explain'>
 <h4>Note</h4>
 <p>This variable is deprecated. The behavior of the ELR product is now controlled by the tenant-level parameter <a href="../../../../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/2500.enable_early_lock_release.md">enable_early_lock_release</a>.</p>
</main>

## Overview

`ob_early_lock_release` specifies whether to enable early lock release (ELR) for transactions.

## Attributes

| **Attribute** | **Description** |
| ----------- | ---------------------- |
| Parameter type | Bool |
| Default Value | 0 |
| Value range | <ul><li>0: disabled</li><li>1: enabled</li></ul> |
| Scope of Application | Global              |
