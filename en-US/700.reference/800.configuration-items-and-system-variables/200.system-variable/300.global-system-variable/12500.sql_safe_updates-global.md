# sql_safe_updates

## Overview

`sql_safe_updates` specifies whether to enable the SQL safe mode of MySQL. The default value is off.

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This variable is for compatibility only. OceanSeek does not currently implement the functionality of this variable.</p>
</main>

## Attributes

| **Attribute** | **Description** |
| --------- | ------------------------------------------ |
| Parameter type | Bool |
| Default Value | 0 |
| Value range | <ul><li>0: FALSE, which means disabled. </li><li>1: TRUE, which means enabled. </li></ul> |
| Scope    | <ul><li>Global   </li><li>Session </li></ul>   |
