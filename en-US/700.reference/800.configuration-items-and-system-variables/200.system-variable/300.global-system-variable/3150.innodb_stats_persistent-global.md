# innodb_stats_persistent

## Overview

`innodb_stats_persistent` specifies whether to persist InnoDB index statistics on disk.

<main id="notice">
  <h4>Applicability</h4>
  <p>This variable is only used to ensure compatibility with ecosystem tools and will not affect the functionality of OceanBase AI Database.</p>
</main>

## Privilege requirements

* Query variables

  Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement or the `information_schema.GLOBAL_VARIABLES` view to view the values of global system variables.

* Modify variables

  This variable is for compatibility only. The parameter configuration has no practical effect and does not take effect.
