# div_precision_increment

## Overview

`div_precision_increment` specifies the increment of the division result precision based on the dividend precision.

## Privilege requirements

* Query variables

  * Global level

    Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement or the `information_schema.GLOBAL_VARIABLES` view to view the values of global system variables.

  * Session level

    The `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement or the `information_schema.SESSION_VARIABLES` view to view the values of session system variables.

* Modify variables

  * Global effective

    * The `sys` tenant can directly modify the values of global system variables.

    * The user tenant must have the `SUPER` or `ALTER SYSTEM` privilege to modify the value of a global system variable.

  * Session expiration

    The `sys` tenant and all user tenants can directly modify the values of session system variables for their own tenants.

## Attributes

| **Attribute** | **Description** |
| ----------- | --------------- |
| Parameter type | Int |
| Default Value | 4 |
| Value range | [0, 30] |
| Effective Scope | <ul><li>Global</li><li>Session</li></ul> |
| Modifiable | Yes, you can use the`SET`Statement modification. |

## Configuration example

Set the increment of the division result precision based on the dividend precision to 4.

* Effective globally

  ```shell
  obclient> SET GLOBAL div_precision_increment =4;
  ```

* Session expiration

  ```shell
  obclient> SET div_precision_increment =4;
  ```
