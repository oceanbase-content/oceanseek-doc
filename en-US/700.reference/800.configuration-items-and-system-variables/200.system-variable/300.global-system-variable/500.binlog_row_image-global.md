# binlog_row_image

## Overview

`binlog_row_image` specifies whether to record full-column logs.

## Privilege requirements

* Query variables

  * Global level

    Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.GLOBAL_VARIABLES` view to view the values of global system variables.

  * Session level

    The `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.SESSION_VARIABLES` view to view the values of session system variables.

* Modify variables

  * Global effective

    * The `sys` tenant can directly modify the values of global system variables.

    * The user tenant must have the `SUPER` or `ALTER SYSTEM` privilege to modify the value of a global system variable.

  * Session expiration

    The `sys` tenant and all user tenants can directly modify the values of session system variables for their own tenants.

## Attributes

| **Attribute** | **Description** |
| ----------- | --------------- |
| Parameter type | Enum |
| Default Value | FULL |
| Value range | <ul><li>FULL: Indicates that all columns are recorded.</li><li>MINIMAL: Indicates that only the columns modified in DML operations are recorded. This improves primary/secondary replication throughput and reduces binlog size, network resource consumption, and server memory usage.</li><li>NOBLOB: Currently not supported.</li></ul> |
| Effective Scope | <ul><li>GLOBAL</li><li>Session</li></ul> |
| Modifiable | Yes, you can use the following methods:`SET`Statement modification. |

## Usage instructions

* Full-column logs record **both the old and new values of all columns** for UPDATE and DELETE statements on an OBServer node. Non-full-column logs record only the **new value**.

* After you modify a variable by using the <code>SET GLOBAL binlog_row_image= 'xxx'</code> command, the change does not take effect on **any existing sessions** (including the session that initiated the modification).

## Configuration example

Sets all columns to record full-column logs.

* Effective globally

  ```shell
  obclient> SET GLOBAL binlog_row_image=FULL;
  ```

* Session Validity Period

  ```shell
  obclient> SET binlog_row_image=FULL;
  ```
