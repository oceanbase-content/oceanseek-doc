# ob_temp_tablespace_size_percentage

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This variable is no longer used. The percentage of disk usage is controlled by the <a href="../../../../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/300.cluster-level-configuration-items/4100.data_disk_usage_limit_percentage.md">data_disk_usage_limit_percentage</a> parameter.</p>
</main>,

## Overview

`ob_temp_tablespace_size_percentage` specifies the percentage of temporary tablespaces allowed on a tenant's data disk.

## Attributes

| **Attribute** | **Description** |
| ----------- | --------------- |
| Parameter type | Int |
| Default Value | 0 |
| Value range | [0, 100] |
| Scope    |  <ul><li>Global</li><li>Session</li></ul>  |
