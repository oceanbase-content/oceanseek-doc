# mview_refresh_dop

## Overview

`mview_refresh_dop` controls the default refresh parallelism for materialized views.

## Privilege requirements

* Query variables

  * Global level

    The `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement or the `information_schema.GLOBAL_VARIABLES` view to view the values of global system variables.

  * Session level

    The `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement or the `information_schema.SESSION_VARIABLES` view to view the values of session system variables.

* Modify variables

  * Global effective

    * The `sys` tenant can directly modify the values of global system variables.

    * The user tenant must have the `SUPER` or `ALTER SYSTEM` privilege to modify the value of a global system variable.

  * Session expiration

    The `sys` tenant and all user tenants can directly modify the values of session system variables for their own tenants.

## Attributes

| **Attribute** | **Description** |

| Parameter type | Int |

| Modifiable | Yes, you can use the`SET`Statement modification |

## Usage instructions

1. Session-level settings:

   Sets `mview_refresh_dop` for the current session to control the default refresh parallelism for materialized views in that session. For manual refreshes of materialized views initiated in this session later on, this value will be used if no parallelism is explicitly specified.

2. Global settings:

   Sets the global `mview_refresh_dop`, which affects all sessions, including both manual and automatic materialized view refreshes. For all subsequent sessions initiating a materialized view refresh, if the degree of parallelism is not explicitly specified, this value will be used.

3. When `mview_refresh_dop` is set to 0 or 1, parallel refresh is not enabled.

## Configuration example

* Sets the default parallelism for session-level refreshes.

  ```shell
  obclient> SET mview_refresh_dop = 5;
  ```

* Sets the global default refresh parallelism.

  ```shell
  obclient> SET GLOBAL mview_refresh_dop = 5;
  ```
