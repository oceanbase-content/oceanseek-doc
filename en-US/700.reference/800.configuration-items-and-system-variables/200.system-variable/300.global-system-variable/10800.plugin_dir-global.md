# plugin_dir

## Overview

`plugin_dir` is used to view the path where plugin DLLs are stored.

## Privilege requirements

* Query variables

  Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.GLOBAL_VARIABLES` view to view the values of global system variables.

* Modify variables

  This variable cannot be modified.

## Attributes

| **Attribute** | **Description** |
| -------- | --------------- |
| Parameter type | Varchar |
| Default Value | ./plugin_dir/ |
| Effective Scope | Global |
| Modifiable | No, it is not supported to pass through`SET`Statement modification. |
| Read-only    | Yes |
