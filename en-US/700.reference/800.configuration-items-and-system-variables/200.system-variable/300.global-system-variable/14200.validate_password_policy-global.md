# validate_password_policy

## Overview

`validate_password_policy` is used to set the password check policy.

## Privilege requirements

* Query variables

  Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.GLOBAL_VARIABLES` view to view the values of global system variables.

* Modify variables

  * The `sys` tenant can directly modify the values of global system variables.

  * The user tenant must have the `SUPER` or `ALTER SYSTEM` privilege to modify the value of a global system variable.

## Attributes

| **Attribute** | **Description** |
| --------- | ------------------------------- |
| Parameter type | Enum |
| Default Value | LOW |
| Value range | <ul><li>LOW: Indicates that only common password checks are performed. </li><li>>MEDIUM: Indicates that checks include password length, number of uppercase letters, number of lowercase letters, number of digits, number of special characters, and duplicate username/password. </li></ul> |
| Effective Scope | Global |
| Modifiable | Yes, you can use the`SET`Statement modification. |

## Configuration example

Set the password check policy to `LOW`, which only includes password length detection.

```shell
obclient> SET GLOBAL validate_password_policy = 'LOW';
```
