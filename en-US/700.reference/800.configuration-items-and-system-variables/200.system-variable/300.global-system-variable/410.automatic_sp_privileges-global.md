# automatic_sp_privileges

## Overview

`automatic_sp_privileges` specifies whether to automatically grant the ALTER and EXECUTE privileges on stored procedures.

## Privilege requirements

* Query variables

  Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement or the `information_schema.GLOBAL_VARIABLES` view to view the values of global system variables.

* Modify variables

  * The `sys` tenant can directly modify the values of global system variables.

  * The user tenant must have the `SUPER` or `ALTER SYSTEM` privilege to modify the value of a global system variable.

## Attributes

| **Attribute** | **Description** |
| --------- | --------------- |
| Parameter type | int |
| Default Value | 1 |
| Value range | [0,1] |
| Effective Scope | Global |
| Modifiable | Yes, you can use the`SET`Statement modification. |

## Usage instructions

When a stored procedure is created, if the value of this variable is 1, the creator is automatically granted the ALTER and EXECUTE privileges on the stored procedure. If the variable value is 0, these privileges are not automatically granted.

## Configuration example

Privileges to automatically grant ALTER and EXECUTE on stored procedures.

```shell
obclient> SET GLOBAL automatic_sp_privileges = true;
```
