# ob_plan_cache_percentage

## Overview

`ob_plan_cache_percentage` specifies the percentage of memory available for the plan cache from the tenant's total memory.

## Privilege requirements

* Query variables

  Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.GLOBAL_VARIABLES` view to view the values of global system variables.

* Modify variables

  * The `sys` tenant can directly modify the values of global system variables.

  * The user tenant must have the `SUPER` or `ALTER SYSTEM` privilege to modify the value of a global system variable.

## Attributes

| **Attribute** | **Description** |
| ---------- | ---------------------------- |
| Parameter type | Int |
| Default Value | 5 |
| Value range | [0, 100] |
| Effective Scope | Global |
| Modifiable | Yes, you can use the following methods:`SET`Statement modification. |

## Usage instructions

The maximum memory that can be used for plan caching (absolute memory limit) = Tenant memory limit × ob_plan_cache_percentage/100.

## Configuration example

Set the memory usage for plan caching to 5%.

```shell
obclient> SET GLOBAL ob_plan_cache_percentage =5;
```
