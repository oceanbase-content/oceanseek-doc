# collation_connection

## Overview

`collation_connection` specifies the character set and collation for a connection.

## Privilege requirements

* Query variables

  * Global level

    The `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.GLOBAL_VARIABLES` view to view the values of global system variables.

  * Session level

    Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.SESSION_VARIABLES` view to view the values of session system variables.

* Modify variables

  * Global effective

    * The `sys` tenant can directly modify the values of global system variables.

    * The user tenant must have the `SUPER` or `ALTER SYSTEM` privilege to modify the value of a global system variable.

  * Session Validity Period

    The `sys` tenant and all user tenants can directly modify the values of session system variables for their own tenants.

## Attributes

| **Attribute** | **Description** |

## Configuration example

Set the character set of the default database to `utf8mb4_general_ci`.

* Effective globally

  ```shell
  obclient> SET GLOBAL character_set_database ='utf8mb4_general_ci';
  ```

* Session effective

  ```shell
  obclient> SET character_set_database ='utf8mb4';
  ```
