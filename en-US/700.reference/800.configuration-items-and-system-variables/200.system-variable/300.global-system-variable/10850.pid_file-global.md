# pid_file

## Overview

`pid_file` specifies the path of the file to which the server writes its process ID.

## Privilege requirements

* Query variables

  Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement or the `information_schema.GLOBAL_VARIABLES` view to view the values of global system variables.

* Modify variables

  This variable cannot be modified.

## Attributes

| **Attribute** | **Description** |
| ----------- | --------------- |
| Parameter type | Varchar |
| Default Value | /run/observer.pid |
| Effective Scope | Global |
| Modifiable | No, it is not supported to pass through`SET`Statement modification. |
| Read-only | Yes |

## Sample query

Query the path of the file on the server that contains its process ID.

```shell
obclient> SHOW VARIABLES LIKE 'pid_file';
```

The query result is as follows:

```shell
+---------------+----------------------------------------+
| Variable_name | Value                                  |
+---------------+----------------------------------------+
| pid_file      | /home/admin/oceanbase/run/observer.pid |
+---------------+----------------------------------------+
1 row in set (0.004 sec)
```
