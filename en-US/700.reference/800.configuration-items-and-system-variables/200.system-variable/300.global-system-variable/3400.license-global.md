# license

## Overview

`license` is used to view the type of the license.

## Privilege requirements

The `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.GLOBAL_VARIABLES` view to view the values of global system variables.

## Attributes

| **Attribute** | **Description** |
| ---------- | ---------- |
| Parameter type | Varchar |
| Default Value | "" indicates an empty string. |
| Effective Scope | Global |
| Modifiable | No, read-only only |

## Sample query

Check the type of the license.

```shell
obclient(root@mysql001)[(none)]> SHOW VARIABLES LIKE '%license%';
```

The result is as follows:

```shell
+---------------+-------+
| Variable_name | Value |
+---------------+-------+
| license       |       |
+---------------+-------+
1 row in set
```
