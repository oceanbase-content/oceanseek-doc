# server_uuid

## Overview

`server_uuid` is used to view the UUID of the OBServer node.

When an OBServer node starts, it automatically generates a UUID. For example: `182d0ebb-1209-11ed-b01e-a237b1d47168`.

## Privilege requirements

* Query variables

  Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement or the `information_schema.GLOBAL_VARIABLES` view (in MySQL-compatible mode) to view the values of global system variables.

* Modify variables

  This variable cannot be modified.
