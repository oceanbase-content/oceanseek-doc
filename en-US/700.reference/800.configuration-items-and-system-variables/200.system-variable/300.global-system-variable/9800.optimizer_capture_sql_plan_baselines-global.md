# optimizer_capture_sql_plan_baselines

## Overview

The `optimizer_capture_sql_plan_baselines` parameter specifies whether to automatically capture new execution plans into the plan baseline.

## Privilege requirements

* Query variables

  * Global level

    Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.GLOBAL_VARIABLES` view to view the values of global system variables.

  * Session level

    Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.SESSION_VARIABLES` view to view the values of session system variables.

* Modify variables

  * Global effective

    * The `sys` tenant can directly modify the values of global system variables.

    * The user tenant must have the `SUPER` or `ALTER SYSTEM` privilege to modify the value of a global system variable.

  * Session expiration

    The `sys` tenant and all user tenants can directly modify the values of session system variables for their own tenants.

## Attributes

| **Attribute** | **Description** |
| ----------- | --------------- |
| Parameter type | Bool |
| Default Value | 0 |
| Value range | <ul><li> 0: Indicates that new plans are not automatically captured to the plan baseline.</li><li>1: Indicates that for newly generated plans, if the SQL does not have a corresponding plan baseline, the plan is added to the SQL Plan Baseline. If an existing plan baseline exists and the new plan is different, plan evolution is triggered for verification to determine whether the new plan should replace the old plan baseline.</li></ul> |
| Effective Scope | <ul><li>Global</li><li>Session</li></ul> |
| Modifiable | Yes, you can use the following methods:`SET`Statement modification. |

## Configuration example

Controls whether to automatically capture new execution plans into the plan baseline.

* Effective globally

  ```shell
  obclient> SET GLOBAL optimizer_capture_sql_plan_baselines=0;
  ```

* Session Validity Period

  ```shell
  obclient> SET optimizer_capture_sql_plan_baselines=0;
  ```
