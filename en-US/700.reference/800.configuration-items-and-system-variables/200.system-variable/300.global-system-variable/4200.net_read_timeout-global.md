# net_read_timeout

## Overview

`net_read_timeout` specifies the number of seconds to wait for other data from the connection before interrupting the read.

## Privilege requirements

* Query variables

  * Global level

    Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.GLOBAL_VARIABLES` view to view the values of global system variables.

  * Session level

    The `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.SESSION_VARIABLES` view to view the values of session system variables.

* Modify variables

  * Global effective

    * The `sys` tenant can directly modify the values of global system variables.

    * The user tenant must have the `SUPER` or `ALTER SYSTEM` privilege to modify the value of a global system variable.

  * Session expiration

    The `sys` tenant and all user tenants can directly modify the values of session system variables for their own tenants.

## Attributes

| **Attribute** | **Description** |
| ---------- | -------------------------- |
| Parameter type | Int |
| Default Value | 30 |
| Value range | [1, 31536000] |
| Effective Scope | <ul><li>Global</li> <li>Session </li></ul> |
| Modifiable | Yes, you can use the`SET`Statement modification. |

## Usage instructions

When the server reads data from the client, `net_read_timeout` specifies the timeout value that controls when to interrupt the read.

## Configuration example

Set the number of seconds to wait for other data on the connection before interrupting data reading to 30.

* Session expiration

  ```shell
  obclient> SET net_read_timeout =30;
  ```

* Effective globally

  ```shell
  obclient> SET GLOBAL net_read_timeout =30;
  ```
