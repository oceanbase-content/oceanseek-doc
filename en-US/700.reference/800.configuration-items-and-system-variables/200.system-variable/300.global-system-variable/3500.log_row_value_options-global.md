# log_row_value_options

## Overview

`log_row_value_options` specifies whether to use partial updates for LOB data.

## Privilege requirements

* Query variables

  * Global level

    Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement or the `information_schema.GLOBAL_VARIABLES` view to view the values of global system variables.

  * Session level

    Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement or the `information_schema.SESSION_VARIABLES` view to view the values of session system variables.

* Modify variables

  * Global effective

    * The `sys` tenant can directly modify the values of global system variables.

    * The user tenant must have the `SUPER` or `ALTER SYSTEM` privilege to modify the value of a global system variable.

  * Session Validity Period

    The `sys` tenant and all user tenants can directly modify the values of session system variables for their own tenants.

## Attributes

| **Attribute** | **Description** |
| -------- | --------- |
| Parameter type | Varchar |
| Default Value | Empty string |
| Value range | ['', 'partial_json']<ul><li><code>''</code>: an empty string, which indicates to disable partial update capability.</li><li>Specifies to enable partial JSON update capability.</li></ul> |
| Effective Scope | <ul><li>Global</li><li>Session</li></ul> |
| Modifiable | Yes, you can modify it using the SET statement. |

## Usage instructions

When set to `partial_json`, the partial update capability for JSON data is enabled. When updating JSON data using `json_set/json_remove/json_replace` expressions, partial updates are used instead of incremental updates, which can improve the performance of updating large JSON objects.

## Configuration example

Set the Lob to use partial update and enable the JSON partial update capability.

* Session expiration

  ```shell
  obclient> SET log_row_value_options="partial_json";
  ```

* Effective globally

  ```shell
  obclient> SET GLOBAL log_row_value_options="partial_json";
  ```
