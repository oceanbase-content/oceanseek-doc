# ob_capability_flag

## Overview

`ob_capability_flag` is used to set the capabilities that an OBServer node can provide. It is used for capability negotiation when connecting to OBProxy, informing OBProxy which features the current OBServer node supports and which it does not support.

## Attributes

| **Attribute** | **Description** |
| -------- | ---------------------------------- |
| Parameter type | uint |
| Default Value | 0 |
| Value range | \[0,18446744073709551615\] |
| Effective Scope | Session |
| Modifiable | No. This variable can be specified when creating a tenant, but cannot be modified via SQL statements after the tenant is created. |
| Visible | No, invisible to all tenants |

## Usage instructions

You cannot query the value of this variable by using the `SHOW VARIABLES` statement or the `information_schema.SESSION_VARIABLES` view. You can query the value of this variable by using the `oceanbase.DBA_OB_SYS_VARIABLES` view.
