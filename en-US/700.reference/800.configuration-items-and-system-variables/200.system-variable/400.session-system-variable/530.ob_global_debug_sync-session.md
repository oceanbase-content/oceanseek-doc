# ob_global_debug_sync

## Overview

`ob_global_debug_sync` is used to set the synchronization point during debugging. Setting this variable affects all sessions.

## Attributes

| **Attribute** | **Description** |
| -------- | ------------ |
| Parameter type | Varchar |
| Default Value | Empty string |
| Effective Scope | Session |
| Visible | No, invisible to all tenants |

## Usage instructions

You cannot query the value of this variable by using the `SHOW VARIABLES` statement or the `information_schema.SESSION_VARIABLES` view. You can query the value of this variable by using the `oceanbase.DBA_OB_SYS_VARIABLES` view.

This setting takes effect only if the value of the [debug_sync_timeout](../../100.system-configuration-items/300.cluster-level-configuration-items/4900.debug_sync_timeout.md) parameter is not 0.
