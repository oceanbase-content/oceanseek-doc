# ob_sparse_drop_ratio_search

## Overview

`obsparse_drop_ratio_search` is used to set a minimal fraction of dimension values in the query vector to `0` during sparse vector queries, thereby reducing the dimensionality and accelerating the query.

## Privilege requirements

* Query variables

  * The `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement or the `information_schema.SESSION_VARIABLES` view to view the values of session system variables.

* Modify variables

  * The sys tenant and all user tenants can directly modify the values of session system variables for their own tenants.

## Attributes

| **Attribute** | **Description** |
| --------- | --------- |
| Parameter type | Uint |
| Default Value | 0 |
| Value range | [0,100] |
| Effective Scope | Session |
| Modifiable | Yes, you can use the`SET`Statement modification. |

## Configuration example

When setting up a sparse vector query, the smallest 30% of dimension values in the query vector are set to `0`.

```shell
obclient> SET ob_sparse_drop_ratio_search = 30;
```
