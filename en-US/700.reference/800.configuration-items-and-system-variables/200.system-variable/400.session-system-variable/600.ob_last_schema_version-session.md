# ob_last_schema_version

## Overview

`ob_last_schema_version` is used to set the version number of the most recently used schema in the current session.

When the same connection of the proxy corresponds to multiple servers, this system variable is required for schema synchronization. Therefore, this variable takes effect only at the session level.

## Privilege requirements

* Query variables

  Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement and the `information_schema.SESSION_VARIABLES` view to view the values of session system variables.

* Modify variables

  The `sys` tenant and all user tenants can directly modify the values of session system variables for their own tenants.

## Attributes

| **Attribute** | **Description** |
| -------- | ---------------------------- |
| Parameter type | Int |
| Default Value | 0 |
| Value range | \[0, 9223372036854775807\] |
| Effective Scope | Session |
| Modifiable | Yes, you can use the`SET`Statement modification. |

## Configuration example

Set the latest schema version number used in the current session to `1749025079596944`.

```shell
obclient> SET ob_last_schema_version = 1749025079596944;
```
