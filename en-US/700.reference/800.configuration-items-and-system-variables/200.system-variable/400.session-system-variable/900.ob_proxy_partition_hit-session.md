# ob_proxy_partition_hit

## Overview

`ob_proxy_partition_hit` specifies whether OBProxy sends the data requested by the SQL statement to the OBServer node where the data resides in the primary partition.

## Attributes

| **Attribute** | **Description** |
| -------- | ----------------------------------------------------------------------------------------------------- |
| Parameter type | Bool |
| Default Value | 1 |
| Value range | <ul><li> 1: Yes   </li><li> 0: No </li></ul> |
| Effective Scope | Session |
| Modifiable | No. This variable can only be specified when creating a tenant and cannot be modified via SQL statements after the tenant is created. |

## Usage instructions

You cannot query the value of this variable by using the `SHOW VARIABLES` statement or the `information_schema.SESSION_VARIABLES` view. You can query the value of this variable by using the `oceanbase.DBA_OB_SYS_VARIABLES` view.

Alternatively, you can use the `SELECT` statement to retrieve the value of this variable:

```shell
obclient> SELECT @@ob_proxy_partition_hit;
```

The return result is as follows:

```shell
+--------------------------+
| @@ob_proxy_partition_hit |
+--------------------------+
|                        1 |
+--------------------------+
1 row in set
```
