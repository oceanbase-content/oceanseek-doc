# ob_proxy_global_variables_version

## Overview

`ob_proxy_global_variables_version` is used for internal communication between OBProxy and OBServer nodes. It specifies the latest version of global variables that an OBServer node should return to OBProxy.

## Attributes

| **Attribute** | **Description** |
| -------- | --------------------------------------------------------------------------------------------------------- |
| Parameter type | Int |
| Default Value | 0 |
| Value range | \[0, INT64_MAX) |
| Effective Scope | Session |
| Modifiable | No. This variable can only be specified when creating a tenant and cannot be modified via SQL statements after the tenant is created. |

## Usage instructions

You cannot query the value of this variable by using the `SHOW VARIABLES` statement or the `information_schema.SESSION_VARIABLES` view. You can query the value of this variable by using the `oceanbase.DBA_OB_SYS_VARIABLES` view.

Alternatively, you can use the `SELECT` statement to retrieve the latest version number of the current global variable:

```shell
obclient> SELECT @@ob_proxy_global_variables_version;
```

The return result is as follows:

```shell
+-------------------------------------+
| @@ob_proxy_global_variables_version |
+-------------------------------------+
|                                   0 |
+-------------------------------------+
1 row in set
```
