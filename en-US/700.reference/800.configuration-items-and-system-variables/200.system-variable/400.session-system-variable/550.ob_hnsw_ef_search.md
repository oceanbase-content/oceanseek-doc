# ob_hnsw_ef_search

## Overview

`ob_hnsw_ef_search` specifies the number of neighbor points searched by the HNSW algorithm in each graph layer during vector index queries. A larger value increases the number of neighbor points explored, enhancing the likelihood of finding the true nearest neighbor and improving search accuracy. However, it also prolongs the search time.

## Privilege requirements

* Query variables

  Both the `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement or the `information_schema.SESSION_VARIABLES` view to view the values of session system variables.

* Modify variables

  The `sys` tenant and all user tenants can directly modify the values of session system variables for their own tenants.

## Attributes

| **Attribute** | **Description** |
| --------- | --------- |
| Parameter type | Uint |
| Default Value | 64 |
| Value range | [1,1000] |
| Effective Scope | Session |
| Modifiable | Yes, you can use the following methods:`SET`Statement modification. |

## Sample query

Set the number of neighbor points searched by the HNSW algorithm in each layer of the graph during vector index queries to 50.

```shell
obclient> SET ob_hnsw_ef_search = 50;
```
