# ob_ivf_nprobes

## Overview

`ob_ivf_nprobes` specifies the number of nearest cluster centers to search for in a vector index query. This variable affects the performance and recall of IVF queries: a larger value results in higher recall but also longer search time.

## Privilege requirements

* Query variables

  * The `sys` tenant and all user tenants can use the `SHOW VARIABLES` statement or the `information_schema.SESSION_VARIABLES` view to view the values of session system variables.

* Modify variables

  * The sys tenant and all user tenants can directly modify the values of session system variables for their own tenants.

## Attributes

| **Attribute** | **Description** |
| --------- | --------- |
| Parameter type | Int |
| Default Value | 8 |
| Value range | [1,65536] |
| Effective Scope | Session |
| Modifiable | Yes, you can use the`SET`Statement modification. |

## Configuration example

Set this query to search for the 10 nearest cluster centers.

```shell
obclient> SET ob_ivf_nprobes = 10;
```
