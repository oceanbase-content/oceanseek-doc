# Usage guidelines for cache

This topic describes the guidelines for using caches in OceanBase AI Database.

* For fields that require frequent write operations in business scenarios, it is recommended to use write caching mechanisms, such as for counter writes.

* Use hints to control plan caching

  * `/*+ USE_PLAN_CACHE(NONE)*/` specifies not to use the plan cache.

  * `/*+USE_PLAN_CACHE(DEFAULT)*/` indicates to use the plan cache.

* SQL statements are prohibited from using hints, such as `force index`, `ignore index`, `straight_join`, and `SQL_no_cache`.
