# DDL statement writing guidelines

This topic describes the writing specifications for database DDL statements in OceanSeek.

- We recommend that you use the `TRUNCATE TABLE` statement for full table deletion.

- We recommend that you perform online DDL operations during off-peak hours to minimize the impact on the system.
