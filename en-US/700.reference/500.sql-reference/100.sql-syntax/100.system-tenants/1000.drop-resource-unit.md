# DROP RESOURCE UNIT

## Description

This statement is used to drop a resource unit.

  <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>Before deleting a resource unit, ensure it is not currently in use. If the resource unit is being used, you must remove it from the resource pool before deleting it.</p>
  </main>

## Syntax

```sql
DROP RESOURCE UNIT unit_name;
```

## Parameters

| **Parameters** | **Description** |
| ----------- | ---------------- |
| unit_name | The name of the resource unit to be deleted. |

## Examples

* When a resource unit is not assigned to a resource pool, you can directly delete the resource unit `unit1`.

  ```shell
  obclient> DROP RESOURCE UNIT unit1;
  Query OK, 0 rows affected
  ```

* If a resource unit has been assigned to a resource pool and you only want to delete the resource unit, you cannot delete it directly. You must first remove it from the resource pool before deleting it.

  For example, in the following example, resource unit `unit1` has been assigned to resource pool `pool1`.

  ```shell
  obclient> CREATE RESOURCE POOL pool1 UNIT='unit1', UNIT_NUM=1, ZONE_LIST=('zone2');
  ```

  An error is reported when directly deleting the resource unit `unit1`.

  ```shell
  obclient> DROP RESOURCE UNIT unit1;
  ERROR 4634 (HY000): resource unit 'UNIT1' is referenced by some resource pool
  ```

  In this case, if you still need to remove `unit1` from resource pool `pool1`, you can first create a new resource unit `unit2` and assign `unit2` to `pool1`, and then delete `unit1`. Example:

  1. Create a new resource unit named `unit2`.

     ```shell
     obclient> CREATE RESOURCE UNIT unit2 MAX_CPU 4, MEMORY_SIZE '5G', MAX_IOPS 1280,LOG_DISK_SIZE '10G', MIN_CPU=4, MIN_IOPS=1024;
     ```

  2. Remove `unit1` from resource pool `pool1`.

     ```shell
     obclient> ALTER RESOURCE POOL pool1 UNIT='';
     ```

     <main id="notice" type='notice'>
     <h4>Notice</h4>
     <p>Because each execution of the <code>ALTER RESOURCE POOL</code> statement can only add or remove one resource unit to a resource pool, you must first remove <code>unit1</code> and then add <code>unit2</code>.</p>
     </main>

  3. Assign `unit2` to the resource pool `pool1`.

     ```shell
     obclient> ALTER RESOURCE POOL pool1 UNIT='unit2';
     ```

  4. Delete the resource unit `unit1` again. The deletion succeeds.

     ```shell
     obclient> DROP RESOURCE UNIT unit1;
     Query OK, 0 rows affected
     ```

* If a resource unit has already been assigned to a resource pool and you want to clean up both the resource pool and the resource unit, you must delete the resource pool first, and then delete the resource unit.

  For example, in the following example, resource unit `unit1` has been assigned to resource pool `pool1`.

  ```shell
  obclient> CREATE RESOURCE POOL pool1 UNIT='unit1', UNIT_NUM=1, ZONE_LIST=('zone2');
  ```

  An error is reported when directly deleting the resource unit `unit1`.

  ```shell
  obclient> DROP RESOURCE UNIT unit1;
  ERROR 4634 (HY000): resource unit 'UNIT1' is referenced by some resource pool
  ```

  First, delete the resource pool `pool1`, then delete the resource unit `unit1`. The deletion is successful.

  ```shell
  obclient> DROP RESOURCE POOL pool1;
  Query OK, 0 rows affected
  ```

  ```shell
  obclient> DROP RESOURCE UNIT unit1;
  Query OK, 0 rows affected
  ```
