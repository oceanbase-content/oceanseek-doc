# DROP RESOURCE POOL

## Purpose

This statement is used to drop a resource pool.

  <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>A resource pool that has been allocated to a tenant cannot be deleted. </p>
  </main>

## Syntax

```sql
DROP RESOURCE POOL pool_name;
```

## Parameters

| **Parameters** | **Description** |
| ----------- | ------------ |
| pool_name | The name of the resource pool to be deleted. |

## Examples

Delete the resource pool named `pool1`.

```sql
obclient> DROP RESOURCE POOL pool1;
Query OK, 0 rows affected
```
