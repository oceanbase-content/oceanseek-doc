# BOOTSTRAP

## Description

This statement is used to start an OceanBase AI database cluster.

This command only needs to be executed when OceanBase AI Database is started for the first time. Each cluster can execute this command only once. If the command fails, it cannot be re-executed; you must rebuild the OceanBase AI database cluster.

Before running this command, ensure that all specified OBServer nodes have been started normally.

## Syntax

```sql
ALTER SYSTEM BOOTSTRAP
    server_info_list [shared_storage_info]

server_info_list:
    server_info [, server_info]...

server_info:
    [REGION=region] ZONE=zone SERVER=ip:port

shared_storage_info:
    , SHARED_STORAGE_INFO = 'string_value'
```

## Parameters

| Parameter | Description |
| --------- | ------ |
| REGION | Specifies the geographic region where the database server is located. This parameter is optional. |
| ZONE | Specifies the availability zone where the database server is located. This parameter is required. |
| SERVER | Specify the IP address and port number of the database server. This parameter is required. The format is 'IP:PORT'. |
| shared_storage_info | Describes the initial object storage information specified for each zone during cluster startup. Character type. The string includes the bucket name for object storage, along with several sub-parameters for object storage, separated by `?` intervals. Separate sub-parameters with `&` Optional. Separate multiple server_info entries with commas. |

## Examples

Specify the list of Root Service machines and start the cluster. If the list contains multiple OBServer nodes, separate them with commas (,).

```sql
obclient> ALTER SYSTEM BOOTSTRAP ZONE 'zone1' SERVER 'xxx.xxx.xx.xx1:xxxx', ZONE 'zone2' SERVER 'xxx.xxx.xx.xx2:xxxx', ZONE 'zone3' SERVER 'xxx.xxx.xx.xx3:xxxx';
```

```sql
obclient> ALTER SYSTEM BOOTSTRAP
    REGION='hangzhou' ZONE='zone1' SERVER='xxx.xxx.xxx.10:2882';
```

```sql
obclient> ALTER SYSTEM BOOTSTRAP
    ZONE 'z1' SERVER 'xxx.xxx.xxx.xxx:26603',
    ZONE 'z2' SERVER 'xxx.xxx.xxx.xxx:26605',
    ZONE 'z3' SERVER 'xxx.xxx.xxx.xxx:26607',
    SHARED_STORAGE_INFO "s3://cn-hangzhou-bucket-1?host=***&access_id=xxx&access_key=xxx&max_iops=10000&max_bandwidth=1GB"
```

The preceding examples show how to initialize OceanBase AI database clusters with single or multiple nodes. When running the commands, replace the parameter values with your actual configuration information.
