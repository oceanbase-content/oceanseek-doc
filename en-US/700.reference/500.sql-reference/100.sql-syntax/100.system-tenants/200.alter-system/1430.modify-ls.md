# MODIFY LS

## Purpose

This statement is used to [change the log stream](../../../../../600.manage/230.logstream-management/200.modify-a-logstream.md), including modifying the log stream's `UNIT_GROUP` (in homogeneous zone mode) or `UNIT_LIST` (in heterogeneous zone mode), and the log stream's `PRIMARY_ZONE`.

## Limitations and considerations

* The current version of OceanBase AI Database supports both homogeneous zone mode and heterogeneous zone mode for tenants. Specifically:

  * In homogeneous zone mode, you can modify the `UNIT_GROUP` for log stream distribution and the `PRIMARY_ZONE` for log streams.

  * In heterogeneous zone mode, you can modify the `UNIT_LIST` for log stream distribution and the `PRIMARY_ZONE` of a log stream.

* When changing the log stream, the log stream to be changed must exist and its status must be `NORMAL`.

* When changing the log stream, the tenant status of the tenant whose log stream is to be changed must be `NORMAL`.

* When modifying the log stream distribution's `UNIT_GROUP` (in homogeneous zone mode) or `UNIT_LIST` (in heterogeneous zone mode) for a primary tenant, all current log streams of the tenant must have no load balancing tasks.

* We recommend that you do not modify the `UNIT_GROUP` (in homogeneous zone mode) or `UNIT_LIST` (in heterogeneous zone mode) attribute of a log stream distribution on a standby tenant. This is because the standby tenant automatically adjusts the `UNIT_GROUP`/`UNIT_LIST` attributes of log streams, and manual modifications may not take effect.

* When modifying the log stream distribution for `UNIT_GROUP` (in homogeneous zone mode) or `UNIT_LIST` (in heterogeneous zone mode), the target `UNIT_GROUP`/`UNIT_LIST` must be in the `ACTIVE` state.

* When modifying the `PRIMARY_ZONE` of a log stream, ensure that the modified zone is included in the tenant's `ZONE_LIST`. For a log stream, setting the `PRIMARY_ZONE` is slightly different from setting it for a tenant. A log stream can only be assigned one zone, such as `z1` or `z2`, and cannot be set to `z1,z2`, `z1; z2`, or `RANDOM` as a tenant can.

* When changing the log stream, ensure that the tenant-level parameter `enable_rebalance` is disabled, meaning its value is `False`. When `enable_rebalance` is enabled, the tenant's load balancing module may automatically adjust the `PRIMARY_ZONE` and `UNIT_GROUP`/`UNIT_LIST` attributes of the log stream.

* In homogeneous zone mode, only the broadcast electron stream and system log stream (log stream 1) support specifying `UNIT_GROUP` as 0.

* In heterogeneous zone mode, the `UNIT_LIST` specified for the user log stream must not be empty.

## Privilege requirements

The user executing this statement must have the `ALTER SYSTEM` privilege. For more information about OceanBase AI database privileges, see [Permission classification](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md).

## Syntax

```sql
ALTER SYSTEM MODIFY LS
    LS [=] ls_id
    [UNIT_GROUP [=] unit_group_id] | [UNIT_LIST [=] (unit_id_list)]
    [,PRIMARY_ZONE [=] 'zone_name'] 
    [TENANT [=] 'tenant_name'];
```

## Parameters

| **Parameters** | **Description** |
| ------------------- | ------------------------------------ |
| ls_id | Specifies the ID of the log stream to be changed. |
| unit_group_id | Specifies the target unit group ID of the log stream to be changed. This parameter is applicable only in homogeneous zone mode. When executing this statement, you must modify at least one attribute of the log stream. `UNIT_GROUP` or `PRIMARY_ZONE`. |
| unit_id_list | Specify the list of units for the log stream distribution to be changed. Separate multiple unit_ids with commas (,). This applies only in heterogeneous zone mode. |
| zone_name | Specifies the target primary zone for the log stream to be changed. When executing this statement, you must modify at least one attribute of the log stream. `UNIT_GROUP` or `PRIMARY_ZONE`. |
| tenant_name | Optional. The system tenant specifies the target tenant. <main id="notice" type='notice'><h4>Note</h4><p>Only the system tenant can specify other tenants. This statement does not support using <code>ALL</code>, <code>ALL_USER</code>, or <code>ALL_META</code> to specify all tenants, user tenants, or all Meta tenants.</p></main> |

## Examples

:::tab
tab Homogeneous Zone Mode

* System tenant

  * Only modify the `UNIT_GROUP` of the log stream.

    The system tenant modifies the log stream location of tenant `obtenant` from 1002 to `UNIT_GROUP` 1002.

    ```shell
    obclient> ALTER SYSTEM MODIFY LS 1002 UNIT_GROUP 1002 TENANT = obtenant;
    ```

  * Only modify the `PRIMARY_ZONE` of the log stream.

    The system tenant changes the first priority of the leader of log stream 1002 for tenant `obtenant` to `z1`.

    ```shell
    obclient> ALTER SYSTEM MODIFY LS 1002 PRIMARY_ZONE 'z1' TENANT = obtenant;
    ```

  * Simultaneously modify the `UNIT_GROUP` and `PRIMARY_ZONE` of a log stream.

    The system tenant modifies the log stream location of tenant `obtenant` from 1002 to `UNIT_GROUP` of 1002, and changes the first priority of the log stream leader to `z1`.

    ```shell
    obclient> ALTER SYSTEM MODIFY LS 1002 UNIT_GROUP 1002, PRIMARY_ZONE 'z1' TENANT = obtenant;
    ```

* User tenant

  * Only modify the `UNIT_GROUP` of the log stream.

    The user tenant moves the position of log stream 1002 within this tenant to `UNIT_GROUP` 1002.

    ```shell
    obclient> ALTER SYSTEM MODIFY LS 1002 UNIT_GROUP 1002;
    ```

  * Only modify the `PRIMARY_ZONE` of the log stream.

    The user tenant changes the first priority of the leader of log stream 1002 in this tenant to `z1`.

    ```shell
    obclient> ALTER SYSTEM MODIFY LS 1002 PRIMARY_ZONE 'z1';
    ```

  * Simultaneously modify the `UNIT_GROUP` and `PRIMARY_ZONE` of a log stream.

    The user tenant modifies the location of log stream 1002 within the tenant to `UNIT_GROUP` and changes the first priority of the log stream leader to `z1`.

    ```shell
    obclient> ALTER SYSTEM MODIFY LS 1002 UNIT_GROUP 1002, PRIMARY_ZONE 'z1';
    ```

tab Heterogeneous Zone Mode

* System tenant

  * Only modify the `UNIT_LIST` for log stream distribution.

    The system tenant modifies the log stream location of tenant `obtenant` to the `UNIT_LIST` with `unit_id` 1001, 1002, and 1003.

    ```shell
    obclient> ALTER SYSTEM MODIFY LS 1002 UNIT_LIST (1001, 1002, 1003) TENANT = obtenant;
    ```

  * Only modify the `PRIMARY_ZONE` of the log stream.

    The system tenant changes the first priority of the leader of log stream 1002 for tenant `obtenant` to `z1`.

    ```shell
    obclient> ALTER SYSTEM MODIFY LS 1002 PRIMARY_ZONE 'z1' TENANT = obtenant;
    ```

  * Simultaneously modify the `UNIT_LIST` and `PRIMARY_ZONE` of a log stream.

    The system tenant modifies the log stream location of tenant `obtenant` to the `UNIT_LIST` with `unit_id` 1001, 1002, and 1003, and changes the first priority of the log stream leader to `z1`.

    ```shell
    obclient> ALTER SYSTEM MODIFY LS 1002 UNIT_LIST (1001, 1002, 1003), PRIMARY_ZONE 'z1' TENANT = obtenant;
    ```

* User tenant

  * Only modify the `UNIT_LIST` for log stream distribution.

    The user tenant modifies the location of log stream 1002 within itself to the `UNIT_LIST` where `unit_id` is 1001, 1002, and 1003.

    ```shell
    obclient> ALTER SYSTEM MODIFY LS 1002 UNIT_LIST (1001, 1002, 1003);
    ```

  * Only modify the `PRIMARY_ZONE` of the log stream.

    The user tenant changes the first priority of the leader of log stream 1002 in this tenant to `z1`.

    ```shell
    obclient> ALTER SYSTEM MODIFY LS 1002 PRIMARY_ZONE 'z1';
    ```

  * Simultaneously modify the `UNIT_LIST` and `PRIMARY_ZONE` of a log stream.

    The user tenant modifies the location of its own log stream 1002 to the `UNIT_LIST` where `unit_id` is 1001, 1002, and 1003, and changes the first priority of the log stream leader to `z1`.

    ```shell
    obclient> ALTER SYSTEM MODIFY LS 1002 UNIT_LIST (1001, 1002, 1003), PRIMARY_ZONE 'z1';
    ```

:::
