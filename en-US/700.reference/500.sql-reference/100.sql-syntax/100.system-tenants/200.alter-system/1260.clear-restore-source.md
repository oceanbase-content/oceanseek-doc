# CLEAR RESTORE SOURCE

## Purpose

This statement is used to revoke the path loaded by the `ADD RESTORE SOURCE` statement.

## Privilege requirements

The current user must have the `ALTER SYSTEM` privilege to execute this statement.

## Syntax

```sql
ALTER SYSTEM CLEAR RESTORE SOURCE;
```
