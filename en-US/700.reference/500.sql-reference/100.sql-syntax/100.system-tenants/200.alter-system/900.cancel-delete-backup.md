# CANCEL DELETE BACKUP

## Description

The `CANCEL DELETE BACKUP` statement is used to cancel a running cleanup task.

The `CANCEL DELETE BACKUP` statement is used only to cancel a currently running cleanup task. If you want to prevent a cleanup task from being scheduled again, you must first execute the `DROP DELETE BACKUP POLICY` statement to remove the automatic cleanup policy, and then execute the `CANCEL DELETE BACKUP` statement. For more information about the `DROP DELETE BACKUP POLICY` statement, see [DELETE BACKUP POLICY](1270.delete-backup.md).

## Privilege requirements

This statement must be executed by the `root` user of the `sys` tenant (`root@sys`) or the administrator user of a user tenant (`root` user).

## Syntax

```sql
ALTER SYSTEM CANCEL DELETE BACKUP [TENANT [=] {tenant_name[, tenant_name]...} ];
```

## Parameters

| Parameter | Description |
| ----------------- | -------------------------------------------------------------------------------------------------------------------- |
| tenant_name | The system tenant specifies the [clean-up task to be canceled](../../../../../600.manage/600.backup-and-recovery/500.clear-backup-data/200.cancel-cleaning-backup-data.md) of the tenant. Multiple tenant names can be specified, separated by commas (,). If not specified under the sys tenant, `TENANT = tenant_name` clause indicates that all ongoing cleanup tasks under all user tenants are canceled simultaneously. <main id="notice" type='notice'> <h4>Notice</h4><p>Only the system tenant can specify the target tenant via the <code>TENANT = tenant_name</code> clause when executing this command. User tenants can only execute this command for themselves and cannot specify the <code>TENANT = tenant_name</code> clause.</p></main> |

## Examples

* The system tenant cancels the cleanup policy `default` for tenant `mysql_tenant`.

  ```shell
  obclient [oceanbase]> ALTER SYSTEM DROP DELETE BACKUP POLICY 'default' TENANT = mysql_tenant;
  ```

* The system tenant cancels a cleanup task in progress for the `mysql_tenant` tenant.

  ```shell
  obclient [oceanbase]> ALTER SYSTEM CANCEL DELETE BACKUP TENANT mysql_tenant;
  ```

* The tenant `mysql_tenant` cancels the ongoing cleanup task for itself.

  ```sql
  obclient [SYS]> ALTER SYSTEM CANCEL DELETE BACKUP;
  ```
