# JOB

## Purpose

This statement triggers a background task specified by the parameter.

This statement can only be executed in the sys tenant.

## Syntax

```sql
alter_system_job_stmt:
ALTER SYSTEM RUN JOB job_name
[ZONE [=] 'zone' | SERVER [=] 'server'];
```

## Parameters

| **Parameters** | **Description** |
| ----------------------- | ------------- |
| job_name | Specify the task name. If the name contains special characters, single quotes are required; otherwise, single quotes are optional. Supported job names include: <ul><li>`check_partition_table`: The OBServer node executes the partition table verification and deletion task. </li>   <li>`root_inspection`: Trigger a root service inspection.</li></ul> |
| SERVER \[=\] 'server' | This task is executed on the specified server. Only the `check_partition_table` task supports this parameter. |
| ZONE \[=\] 'zone' | This task is executed in the specified zone. Only the `check_partition_table` task supports this parameter. |

## Examples

Trigger a Root Service inspection task.

```sql
obclient> ALTER SYSTEM RUN JOB "root_inspection";
```
