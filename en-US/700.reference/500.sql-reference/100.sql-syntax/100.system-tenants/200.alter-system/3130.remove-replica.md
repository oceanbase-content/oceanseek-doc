# REMOVE REPLICA

## Purpose

This statement is used to delete a replica of a log stream.

## Limitations and considerations

* Ensure that a majority of log streams still exist after deleting the replica; otherwise, the O&M command will report an error.

* This statement can delete only one replica at a time.

* For the same log stream of a tenant, except that multiple replica migration tasks can be executed in parallel, only one disaster recovery task (including adding replicas, deleting replicas, converting replica types, and modifying the quorum size of a log stream) can be executed at a time.

    <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>You can query the <code>CDB_OB_LS_REPLICA_TASKS</code> view in the sys tenant or the <code>DBA_OB_LS_REPLICA_TASKS</code> view in a user tenant to check whether any disaster recovery tasks are running.</p>
    </main>

## Privilege requirements

The user executing this statement must have the `ALTER SYSTEM` privilege. For more information about OceanBase AI database privileges, see [Permission classification](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md).

## Syntax

```sql
ALTER SYSTEM REMOVE REPLICA
    LS [=] ls_id
    SERVER [=] 'svr_ip:svr_port'
    [PAXOS_REPLICA_NUM [=] paxos_replica_num]
    [TENANT [=] 'tenant_name'];
```

## Parameters

| **Parameters** | **Description** |
| ------------------- | ------------------------------------ |
| ls_id | Specifies the log stream ID of the replica to be deleted. |
| svr_ip:svr_port | Specify the IP address and port number of the server where the replica to be deleted is located. For example, `xxx.xx.xxx.001:2882`. |
| paxos_replica_num | Optional. Specifies the required number of quorum members for the log stream leader. If this value is not explicitly specified, the system will use the current default value of `paxos_replica_num`. At the same time, the number of F replicas for a log stream cannot exceed 7.<main id="notice" type='notice'><h4>Notice</h4><p>To specify a value for this parameter, the following conditions must be met:<ol><li>After modification, <code>paxos_replica_num</code> must form a majority.</li><li>The value of <code>paxos_replica_num</code> must be greater than or equal to the number of members in <code>MEMBER_LIST</code> of the current leader replica. You can confirm this by querying the <code>CDB_OB_LS_LOCATIONS</code> view for the sys tenant, or the <code>DBA_OB_LS_LOCATIONS</code> view for user tenants.</li><li>The absolute change in the value of <code>paxos_replica_num</code> cannot exceed 1. For example, if the current <code>paxos_replica_num</code> is 3, you can only modify it to 2.</li></ul>If any of the above conditions are not met for the specified value, the system will report an error.</p></main> |
| tenant_name | Optional. Specifies the tenant to operate on. If not explicitly specified, the default tenant is the current tenant.<main id="notice" type='notice'><h4>Notice</h4><p><ul><li>The system tenant can specify other tenants, while a user tenant can only specify itself.</li><li>This statement does not support using <code>ALL</code>, <code>ALL_USER</code>, or <code>ALL_META</code> to specify all tenants, user tenants, or all Meta tenants.</li></ul></p></main> |

## Examples

Execute the following command in the sys tenant to delete a log stream replica for the `mysql001` tenant.

```sql
ALTER SYSTEM REMOVE REPLICA
    LS = 1001
    SERVER = 'xxx.xxx.xxx.001:2882'
    PAXOS_REPLICA_NUM = 2
    TENANT = 'mysql001';
```

For more examples of deleting log stream replicas, see [Reduce replicas](../../../../../600.manage/300.replica-management/200.replica-distribution/200.locality-common-operations/400.reduce-replica.md).
