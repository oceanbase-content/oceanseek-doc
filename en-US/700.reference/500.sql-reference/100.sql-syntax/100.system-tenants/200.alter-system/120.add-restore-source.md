# ADD RESTORE SOURCE

## Purpose

This statement is used to load the path to be restored.

## Privilege requirements

The current user must have the `ALTER SYSTEM` privilege to execute this statement.

## Syntax

```sql
ALTER SYSTEM ADD RESTORE SOURCE 'restore_path';
```

## Parameters

| **Parameters** | **Description** |
| ----------------------------- | ---------------------------------------------------- |
| restore_path | Enter the data backup set to be loaded (`backup_set`) or log archiving (`archivelog_piece`). It can be one or multiple paths. <main id="notice" type='notice'><h4>Notice</h4><p><ul><li>If the <code>backup_set</code> or <code>archivelog_piece</code> to be loaded is stored on object storage, the parameters such as <code>host</code>, <code>access_id</code>, and <code>access_key</code> must be the same for each <code>backup_set</code> or <code>archivelog_piece</code> path.</li><li>This statement can be executed multiple times consecutively within the same session. When executed multiple times in the same session, the system will incrementally add them to the restore source list.</li></ul></p></main> |

## Examples

1. Load the backup_set to be restored.

   ```shell
   obclient [oceanbase]> ALTER SYSTEM ADD RESTORE SOURCE 'file:///ob_backup/data/backup_set_1_full';
   ```

2. Load the archive log piece to be restored.

   ```shell
   obclient [oceanbase]> ALTER SYSTEM ADD RESTORE SOURCE 'file:///ob_backup/archive/piece_d1002r1p1,file:///ob_backup/archive/piece_d1002r1p2';
   ```

   ```shell
   obclient [oceanbase]> ALTER SYSTEM ADD RESTORE SOURCE 's3://test_bucket/archive/piece_1?host=***&access_id=x****&access_key=****';
   ```
