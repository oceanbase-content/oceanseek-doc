# SWITCHOVER

## Purpose

This statement is used for tenant primary/standby role switchover commands, enabling a lossless switchover from the primary tenant to the standby tenant, and from the standby tenant back to the primary tenant.

## Syntax

```sql
ALTER SYSTEM SWITCHOVER TO {STANDBY | PRIMARY}
    [TENANT tenant_name]
    [VERIFY];
```

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p><ul><li>The <code>TENANT tenant_name</code> parameter is required when the system tenant executes this command.</li><li>A user tenant can only execute this command for itself.</li></ul></p>
</main>

## Syntax

| **Field** | **Note** |
| ----------- | -------- |
| STANDBY | Perform a lossless switchover from the primary tenant to the standby tenant. |
| PRIMARY | Switch the standby tenant to the primary tenant. |
| tenant_name | Specify the primary/standby tenant name. |
| VERIFY | Optional. When this parameter is used, it performs a pre-check to confirm the execution of `SWITCHOVER` Whether the prerequisites for the command are met.  <main id="notice" type='notice'><h4>Notice</h4><p><ul><li>There is some risk of failure during primary-standby tenant role conversion. The <code>VERIFY</code> command only performs a preliminary verification to assess whether the prerequisites for role conversion are met, helping to reduce the likelihood of operation failure, but it does not actually perform the <code>SWITCHOVER</code> operation.</li><li>Even if the <code>VERIFY</code> command runs successfully, it does not guarantee that the subsequent <code>SWITCHOVER</code> operation will succeed.</li></ul></p></main> |

## Examples

Execute the primary-to-standby switchover command for the primary tenant to change it to a standby tenant named `tenant1`, and verify that the primary tenant has been switched to a standby tenant, with `TENANT_ROLE` changed to `STANDBY` and `SWITCHOVER_STATUS` changed to `NORMAL`.

```shell
obclient> ALTER SYSTEM SWITCHOVER TO STANDBY TENANT tenant1;
Query OK, 0 rows affected

obclient> SELECT TENANT_NAME,TENANT_TYPE,TENANT_ROLE,SWITCHOVER_STATUS FROM DBA_OB_TENANTS
    WHERE TENANT_NAME='tenant1';
+---------------------+-------------+-------------+-------------------+
| TENANT_NAME         | TENANT_TYPE | TENANT_ROLE | SWITCHOVER_STATUS |
+---------------------+-------------+-------------+-------------------+
| t1                  | USER        | STANDBY     | NORMAL            |
+---------------------+-------------+-------------+-------------------+
1 row in set
```
