# CREATE LS

## Purpose

This statement is used to create a user log stream.

## Limitations and considerations

* Currently, only normal user log streams can be created; broadcast log streams are not supported.

* The current version supports both homogeneous zone mode and heterogeneous zone mode for tenants:

  * In homogeneous zone mode, you must specify a unit group to [create a log stream](../../../../../600.manage/230.logstream-management/100.create-a-logstream.md).

  * In heterogeneous zone mode, you must specify UNIT_LIST to create a log stream.

  For more information about the differences between homogeneous zone mode and heterogeneous zone mode, see [Data distribution](../../../../../250.database-schema-design/300.data-distribution.md).

* Log stream creation can only be performed on the primary tenant. The `STATUS` and `SWITCHOVER_STATUS` of the tenant for which you want to create a log stream must be `NORMAL`.

* When creating a log stream:

  * In homogeneous zone mode, the status of the target `UNIT_GROUP` must be `ACTIVE`, and the value of the target `UNIT_GROUP_ID` in the `DBA_OB_UNITS` view must not be 0.

  * In heterogeneous zone mode, the status of the target `UNIT_LIST` must be `ACTIVE`, and the specified target `UNIT_LIST` cannot be empty.

* When specifying `PRIMARY_ZONE` for a log stream to be created, ensure that the specified zone is included in the tenant's `ZONE_LIST`. Setting the `PRIMARY_ZONE` for a log stream differs slightly from setting it for a tenant. A log stream can only be assigned one zone, such as `z1` or `z2`, and cannot be set to `z1,z2`, `z1; z2`, or `RANDOM` as a tenant can.

* It is recommended to disable load balancing-related parameters, that is, set their values to `False`. Otherwise:

  * When the tenant-level parameter [enable_rebalance](../../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/2800.enable_rebalance.md) is enabled, that is, its value is `True`, the created log streams will be migrated by the system from the target `UNIT_GROUP` to other `UNIT_GROUPS`.

  * If the tenant-level parameter [enable_transfer](../../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/3000.enable_transfer.md) is enabled, that is, its value is `True`, the created log streams may be deleted.

## Privilege requirements

The user executing this statement must have the `ALTER SYSTEM` privilege. For more information about OceanBase AI database privileges, see [Permission classification](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md).

## Syntax

```sql
ALTER SYSTEM CREATE LS
    {UNIT_GROUP [=] unit_group_id} | {UNIT_LIST [=] (unit_id_list)}
    [,PRIMARY_ZONE [=] 'zone_name'] 
    [TENANT [=] 'tenant_name'];
```

## Parameters

| **Parameters** | **Description** |
| ------------------- | ------------------------------------ |
| unit_group_id | Specifies the ID of the target `UNIT_GROUP` for the log stream to be created. This parameter takes effect only in homogeneous zone mode. |
| unit_id_list | Specify the list of units for distributing the log streams to be created. Separate multiple unit IDs with commas (,). This parameter takes effect only in heterogeneous zone mode. |
| zone_name         | Specifies the target primary zone for the log stream to be created. If `PRIMARY_ZONE` is not specified, the system automatically selects a zone for allocation. |
| tenant_name       | Optional. Specifies the target tenant.<main id="notice" type='notice'><h4>Notice</h4><p>Only the system tenant can specify other tenants. User tenants can only specify themselves. This statement does not support using <code>ALL</code>, <code>ALL_USER</code>, or <code>ALL_META</code> to specify all tenants, user tenants, or all Meta tenants.</p></main>|

## Examples

:::tab
tab Homogeneous Zone Mode

* System tenant

  The system tenant creates a log stream for the `obtenant` tenant on the `UNIT_GROUP` with ID 1001.

  ```shell
  obclient> ALTER SYSTEM CREATE LS UNIT_GROUP 1001 TENANT = obtenant;
  ```

  The system tenant creates a log stream for the `obtenant` tenant on the `UNIT_GROUP` with ID 1001, and sets the log stream's `PRIMARY_ZONE` to `z1`.

  ```shell
  obclient> ALTER SYSTEM CREATE LS UNIT_GROUP 1001, PRIMARY_ZONE 'z1' TENANT = obtenant;
  ```

* User tenant

  The user tenant creates a log stream for itself on the `UNIT_GROUP` with ID 1001.

  ```shell
  obclient> ALTER SYSTEM CREATE LS UNIT_GROUP 1001;
  ```

  The user tenant creates a log stream on the `UNIT_GROUP` with ID 1001 for this tenant and sets the `PRIMARY_ZONE` of this log stream to `z1`.

  ```shell
  obclient> ALTER SYSTEM CREATE LS UNIT_GROUP 1001, PRIMARY_ZONE 'z1';
  ```

tab Heterogeneous Zone Mode

* System tenant

  The system tenant creates a log stream for the `obtenant` tenant on the `UNIT_LIST` with IDs 1001, 1002, and 1003.

  ```shell
  obclient> ALTER SYSTEM CREATE LS UNIT_LIST = (1001,1002,1003) TENANT = obtenant;
  ```

  The system tenant creates a log stream on the `UNIT_LIST` of tenants `obtenant` at IDs 1001, 1002, and 1003, and sets the `PRIMARY_ZONE` of this log stream to `z1`.

  ```shell
  obclient> ALTER SYSTEM CREATE LS UNIT_LIST = (1001,1002,1003), PRIMARY_ZONE 'z1' TENANT = obtenant;
  ```

* User tenant

  The user tenant creates a log stream for itself on the `UNIT_LIST` with IDs 1001, 1002, and 1003.

  ```shell
  obclient> ALTER SYSTEM CREATE LS UNIT_LIST = (1001,1002,1003);
  ```

  The user tenant creates a log stream on the `UNIT_LIST` with IDs 1001, 1002, and 1003 for this tenant, and sets the log stream's `PRIMARY_ZONE` to `z1`.

  ```shell
  obclient> ALTER SYSTEM CREATE LS UNIT_LIST = (1001,1002,1003), PRIMARY_ZONE 'z1';
  ```

:::
