# FLUSH PLAN CACHE

## Purpose

This statement is used to clear the plan cache for a specified database and SQL ID.

## Syntax

```sql
ALTER SYSTEM FLUSH PLAN CACHE
     [
      [SQL_identifier] [database_list] tenant_list
      ] [GLOBAL]

database_list:
     databases ='database_name, database_name...'

tenant_list:
     TENANT = 'tenant_name, tenant_name....'
```

## Parameters

| Parameter | Description |
| ---------------- | ---------------------- |
| tenant_list | Used to specify the tenant scope. When you specify the `SQL_identifier` and `database_list` parameters, you must specify `tenant_list` to limit the operation to the tenant scope. <main id="notice" type='explain'><h4>Note</h4><p> Only the system tenant <code>sys</code> can specify <code>tenant_list</code>. Other tenants cannot specify this parameter; they can only clear their own plan cache. If the system tenant does not specify <code>tenant_list</code>, it means clearing the plan cache for all tenants.</p></main> |
| SQL_identifier | Used to specify the SQL statement in the format of `sql_id = 'xxx'`. If this parameter is not specified, the plan cache for all SQL statements is cleared.<main id="notice" type='explain'><h4>Note</h4><p>Used under the system tenant sys `SQL_identifier` Parameter must be specified `tenant_list`. If used under a regular tenant, it cannot be specified. `tenant_list` parameter. </p></main> |
| database_list | Specifies the database. If this parameter is not specified, all plan caches are cleared.<main id="notice" type='explain'><h4>Note</h4><p>Used under the sys tenant `database_list` Parameter must be specified `tenant_list`. If used under a regular tenant, it cannot be specified. `tenant_list` parameter. </p></main> |
| GLOBAL | Optional. If this parameter is not specified, only the plan cache on the local server is cleared. If it is specified, the plan caches on all servers of the tenant are cleared. |

## Examples

* Clear all plan caches.

  ```sql
  obclient> ALTER SYSTEM FLUSH PLAN CACHE;
  Query OK, 0 rows affected
  ```

* Clear the plan cache of the user tenant.

  ```sql
  obclient> ALTER SYSTEM FLUSH PLAN CACHE TENANT = 'MySQL';
  Query OK, 0 rows affected
  ```

* Delete a specified plan cache under the sys tenant.

  ```sql
  obclient> ALTER SYSTEM FLUSH PLAN CACHE sql_id='B601070DFC14CB85FDA3766A69A9E1B3'
        databases='myob1' tenant='tenant1' GLOBAL;
  Query OK, 0 rows affected
  ```

* A regular tenant logs in to the database as a DBA to clear its own plan cache.

  ```sql
  obclient> ALTER SYSTEM FLUSH PLAN CACHE sql_id='B601070DFC14CB85FDA3766A69A9E1B3'
         databases='myob1' GLOBAL;
  Query OK, 0 rows affected
  ```
