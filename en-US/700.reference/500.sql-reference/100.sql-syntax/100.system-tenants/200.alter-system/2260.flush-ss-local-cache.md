# FLUSH LOCAL_CACHE

## Purpose

The `ALTER SYSTEM FLUSH LOCAL_CACHE` statement is used to flush local cache data of a specified type for a specified tenant.

## Privilege requirements

This statement must be executed by the `root` user of the `sys` tenant. User tenants do not support this statement.

## Syntax

```sql
ALTER SYSTEM FLUSH LOCAL_CACHE TENANT [=] tenant_name [CACHE [=] cache_type];

cache_type:
    macro_cache
  | mem_macro_cache
  | hot_macro_cache
```

## Parameters

| Parameter | Description |
| ------------------- | ------------------------------------------------------ |
| tenant_name | Specifies the user tenant whose local cache is to be cleaned. Only one tenant can be specified per statement. |
| cache_type | Specifies the type of local cache to be cleaned. Only one type can be specified per statement. Supported types: <ul><li>`macro_cache`: Local persistent macroblock cache</li> <li>`mem_macro_cache`: Local memory macroblock cache</li> <li>`hot_macro_cache`: Cache hot data of local persistent users.</li></ul><p>If not used, `CACHE [=] cache_type`<p>If you specify the type of local cache to be cleaned, all types of local cache data will be cleaned by default.</p> |

## Examples

* In the `sys` tenant, clean up all types of data cached locally by the `mysql_tenant` tenant.

  ```shell
  obclient(root@sys)[(none)]> ALTER SYSTEM FLUSH LOCAL_CACHE TENANT = 'mysql_tenant';
  ```

* In the `sys` tenant, clean up the memory macroblock cache data in the local cache of the `mysql_tenant` tenant.

  ```shell
  obclient(root@sys)[(none)]> ALTER SYSTEM FLUSH LOCAL_CACHE TENANT = 'mysql_tenant' CACHE = 'mem_macro_cache';
  ```
