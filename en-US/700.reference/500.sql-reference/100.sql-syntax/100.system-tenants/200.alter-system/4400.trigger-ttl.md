# TTL

## Description

The `ALTER SYSTEM TRIGGER/SUSPEND/RESUME/CANCEL TTL` statement is used to manually trigger, suspend, resume, or cancel a tenant-level Time-To-Live (TTL) task.

## Privilege requirements

To execute the `ALTER SYSTEM TRIGGER/SUSPEND/RESUME/CANCEL TTL` statement, the current user must have the `ALTER SYSTEM` privilege. For more information about OceanBase AI database privileges, see [Permission classification](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md).

## Syntax

```sql
ALTER SYSTEM {TRIGGER | SUSPEND | RESUME | CANCEL} TTL [TENANT [=] all | all_user | tenant_list];

tenant_list:
  tenant_name[,tenant_name ...]
```

## Parameters

| Parameter | Description |
| --------------- | ------------------------ |
| TENANT | Specifies the user tenant whose TTL task is to be triggered, paused, resumed, or canceled. When executed by the system tenant, you must specify a user tenant. Multiple tenant names can be specified, separated by commas (,).<main id="notice" type='notice'> <h4>Notice</h4><p>Only the system tenant needs to specify the target tenant via the <code>TENANT</code> clause when executing this command. User tenants can only execute this command for themselves and cannot specify the <code>TENANT</code> clause.</p></main> |

## Examples

* The system tenant triggers a TTL task for user tenant `tenant1`.

  1. Enable the TTL feature for tenant `tenant1`.

     ```shell
     obclient(root@sys)[(none)]> ALTER SYSTEM SET enable_ttl = True TENANT = tenant1;
     ```

  2. Manually trigger a TTL task for the user tenant `tenant1`.

     ```shell
     obclient(root@sys)[(none)]> ALTER SYSTEM TRIGGER TTL TENANT = tenant1;
     ```

* A user tenant triggers a TTL task for itself.

  1. Enable the TTL feature.

     ```shell
     obclient(root@mysql001)[(none)]> ALTER SYSTEM SET enable_ttl = True;
     ```

  2. Manually trigger a TTL task.

     ```shell
     obclient(root@mysql001)[(none)]> ALTER SYSTEM TRIGGER TTL;
     ```
