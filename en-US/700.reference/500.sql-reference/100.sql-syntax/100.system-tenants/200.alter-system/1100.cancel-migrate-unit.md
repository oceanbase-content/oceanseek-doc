# CANCEL MIGRATE UNIT

## Description

This statement is used to cancel the migration of a unit.

  <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>This statement can only be executed in the sys tenant.</p>
  </main>

## Syntax

```sql
ALTER SYSTEM CANCEL MIGRATE UNIT unit_id;
```

## Parameters

| **Parameters** | **Description** |
| --------- | ------------------ |
| unit_id | Specifies the ID of the unit to be migrated. |

## Examples

Cancel the migration of the resource unit with `unit_id` `1001`.

```sql
obclient> ALTER SYSTEM CANCEL MIGRATE UNIT 1001;
```
