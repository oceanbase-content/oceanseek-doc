# MODIFY PAXOS_REPLICA_NUM

## Description

This statement is used to modify the `paxos_replica_num` of a log stream, that is, to change the quorum size of the log stream's leader.

## Limitations and considerations

* This statement can modify the `paxos_replica_num` of only one log stream at a time.

* For the same log stream of a tenant, except that multiple replica migration tasks can be executed in parallel, only one disaster recovery task (including adding replicas, deleting replicas, converting replica types, and [modifying the quorum size of a log stream](../../../../../600.manage/300.replica-management/200.replica-distribution/200.locality-common-operations/800.modify-paxos-replica-number.md) at a time is allowed.

    <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>You can query the <code>CDB_OB_LS_REPLICA_TASKS</code> view in the sys tenant or the <code>DBA_OB_LS_REPLICA_TASKS</code> view in a user tenant to check whether any disaster recovery tasks are running.</p>
    </main>

## Privilege requirements

The user executing this statement must have the `ALTER SYSTEM` privilege. For more information about OceanBase AI database privileges, see [Permission classification](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md).

## Syntax

```sql
ALTER SYSTEM MODIFY
    LS [=] ls_id
    PAXOS_REPLICA_NUM [=] paxos_replica_num
    [TENANT [=] 'tenant_name'];
```

## Parameters

| **Parameters** | **Description** |
| ------------------- | ------------------------------------ |
| ls_id | Specifies the ID of the log stream to be modified. |
| paxos_replica_num | Specifies the number of quorum members for the modified leader.<main id="notice" type='notice'><h4>Notice</h4><p>When specifying the value of this parameter, note the following:<ol><li>After the adjustment, ensure that both the adjusted <code>paxos_replica_num</code> and the number of members in <code>MEMBER_LIST</code> of the leader replica satisfy the majority requirement.</li><li>The value of <code>paxos_replica_num</code> must be greater than or equal to the current number of members in <code>MEMBER_LIST</code> of the leader replica. You can confirm this by querying the <code>CDB_OB_LS_LOCATIONS</code> view for the sys tenant, or the <code>DBA_OB_LS_LOCATIONS</code> view for user tenants.</li><li><code>paxos_replica_num</code> can only be decreased, not increased, and the absolute change must not exceed 1.</li></ol>If any of the above conditions are not met for the specified value, the system will report an error.</p></main> |
| tenant_name | Optional. Specifies the tenant to operate on. If you do not explicitly specify the tenant, the default tenant is the current tenant. <main id="notice" type='notice'><h4>Notice</h4><p>The system tenant can specify other tenants, while a user tenant can only specify itself. This statement does not support using <code>ALL</code>, <code>ALL_USER</code>, or <code>ALL_META</code> to specify all tenants, user tenants, or all Meta tenants.</p></main> |

## Examples

Execute the following command in the sys tenant to change the `PAXOS_REPLICA_NUM` value for log stream (1002) in tenant `mysql001` to 2.

```sql
ALTER SYSTEM MODIFY
    LS = 1002
    PAXOS_REPLICA_NUM = 2
    TENANT = 'mysql001';
```

For more examples of modifying the log stream `paxos_replica_num`, see Modify the quorum size of a log stream.
