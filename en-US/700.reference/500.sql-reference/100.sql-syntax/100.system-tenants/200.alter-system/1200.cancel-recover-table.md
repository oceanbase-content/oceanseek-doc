# CANCEL RECOVER TABLE

## Description

The `ALTER SYSTEM CANCEL RECOVER TABLE` statement is used to cancel an ongoing table-level recovery task for a target tenant.

## Limitations and considerations

* Executing this statement will cancel all table-level restore tasks under the corresponding tenant, but will not release the resource pool created for the auxiliary tenant.

* If some tables have already been restored before executing this statement, the restore of those tables cannot be canceled.

## Privilege requirements

Only the `root` user of the `sys` tenant (`root@sys`) can execute the `ALTER SYSTEM RECOVER TABLE` statement.

## Syntax

```sql
ALTER SYSTEM CANCEL RECOVER TABLE dest_tenant_name;
```

## Parameters

| **Parameters** | **Description** |
| ---------------------- | ------------------------------ |
| dest_tenant_name | Specifies the target tenant for which table-level restore is being performed. |

## Examples

Cancel the table-level restore task for tenant `obt` under tenant `sys`.

```sql
obclient [oceanbase]> ALTER SYSTEM CANCEL RECOVER TABLE obt;
```
