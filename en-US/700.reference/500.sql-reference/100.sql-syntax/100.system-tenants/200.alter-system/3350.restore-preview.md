# RESTORE PREVIEW

## Description

This statement is used to specify the original tenant-level archive and backup paths and the desired restore time, thereby previewing the data backup set (`backup_set`) and log archive (`archivelog_piece`) required to restore to the desired time.

## Privilege requirements

The current user must have the `ALTER SYSTEM` privilege to execute this statement.

## Syntax

```sql
ALTER SYSTEM RESTORE FROM 'uri' UNTIL { TIME='timestamp' | SCN=scn } PREVIEW;
```

## Parameters

| **Parameters** | **Description** |
| ----------------------------- | ---------------------------------------------------- |
| uri | Specify the original data backup path and log archive path, separated by commas. |
| TIME='timestamp' \ \| SCN=scn | Specifies the timestamp or SCN at which you want to restore. When executing this statement, you must explicitly specify a time. |

## Examples

* NFS

  * Specify the original data backup path and log archive path, and expect to restore to the specified SCN `1712650554000909004`.

    ```shell
    ALTER SYSTEM RESTORE FROM 'file:///ob_backup/data, file:///ob_backup/archive' UNTIL SCN = 1712650554000909004 PREVIEW;
    ```

  * Specify the original data backup path and log archive path, and aim to restore to the specified timestamp `2024-04-09 16:15:54`.

    ```shell
    ALTER SYSTEM RESTORE FROM 'file:///ob_backup/data, file:///ob_backup/archive' UNTIL TIME = '2024-04-09 16:15:54' PREVIEW;
    ```
