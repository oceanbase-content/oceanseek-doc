# SET LOG_ARCHIVE_DEST_STATE

## Description

The `SET LOG_ARCHIVE_DEST_STATE` statement is used to set the state of the archive destination.

## Privilege requirements

This statement must be executed by the `root` user of the `sys` tenant (`root@sys`) or the administrator user of a user tenant (`root` user).

## Syntax

```sql
ALTER SYSTEM SET LOG_ARCHIVE_DEST_STATE={'ENABLE' | 'DEFER'} [TENANT = tenant_name];
```

## Parameters

| Parameter | Description |
| ------------------------- | -------------------------------------------------------------------------------------------------------- |
| 'ENABLE' \ \| 'DEFER' | Specifies the status of the destination archive: <ul><li>`ENABLE`: The enabled state. When the system is in this state and archiving mode is enabled, but archiving has not yet started, the system will begin the archiving task. After the archive destination is successfully configured, the system is in this state by default.</li> <li>`DEFER`: The archiving task is paused. When the system is in this state, archiving is paused if archive mode is enabled and there are archive tasks.</li></ul> |
| tenant_name | The system tenant specifies the tenant name for which the archive destination status is to be set. Each statement only supports setting the archive destination for one tenant.<main id="notice" type='notice'><h4>Notice</h4><p>Only the system tenant needs to specify the target tenant via the <code>TENANT tenant_name</code> clause when executing this command. User tenants can only execute this command for themselves, so this clause is not required.</p></main> |

## Examples

Assume the tenant `mysql_tenant` has completed the configuration of the archiving destination. Example:

* The system tenant suspends log archiving for the `mysql_tenant` on the destination.

  ```sql
  obclient [oceanbase]> ALTER SYSTEM SET LOG_ARCHIVE_DEST_STATE = 'DEFER' TENANT = mysql_tenant;
  ```

* The tenant `mysql_tenant` initiates log archiving for itself at the destination.

  ```sql
  obclient [oceanbase]> ALTER SYSTEM SET LOG_ARCHIVE_DEST_STATE = 'ENABLE';
  ```
