# MODIFY REPLICA

## Purpose

This statement is used to convert the type of a log stream replica.

## Limitations and considerations

* Ensure that the log streams can still form a majority after modifying the replica type; otherwise, the O&M command will report an error.

* This statement can only modify the type of one replica at a time.

* For the same log stream of a tenant, except that multiple replica migration tasks can be executed in parallel, only one disaster recovery task (including adding replicas, deleting replicas, changing replica types, and modifying the quorum size of the log stream) can be executed at a time.

    <main id="notice" type='explain'>
      <h4>Note</h4>
      <p>You can query the <code>CDB_OB_LS_REPLICA_TASKS</code> view in the sys tenant to check whether any disaster recovery tasks are running. You can also query the <code>DBA_OB_LS_REPLICA_TASKS</code> view in a user tenant to check whether any disaster recovery tasks are running.</p>
    </main>

## Privilege requirements

The user executing this statement must have the `ALTER SYSTEM` privilege. For more information about OceanBase AI database privileges, see [Permission classification](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md).

## Syntax

```sql
ALTER SYSTEM MODIFY REPLICA
    LS [=] ls_id
    SERVER [=] 'svr_ip:svr_port'
    REPLICA_TYPE [=] 'replica_type'
    [PAXOS_REPLICA_NUM [=] paxos_replica_num]
    [TENANT [=] 'tenant_name'];
```

## Parameters

| **Parameters** | **Description** |
| ------------------- | ------------------------------------ |
| ls_id | Specifies the log stream ID whose replica type needs to be converted. |
| svr_ip:svr_port | Specify the IP address and port of the destination server for the replica type to be converted. For example, `xxx.xx.xxx.001:2882`. |
| replica_type | Specifies the target replica type after conversion. The following two replica types are currently supported for conversion (case-insensitive):<ul><li>Full-featured replica: represented by <code>FULL</code> or <code>F</code>.</li><li>Read-only replica: represented by <code>READONLY</code> or <code>R</code>.</li></ul>  <main id="notice" type='explain'><h4>Note</h4><p><code>F</code> replicas can be elected as Leaders (primary replicas), while <code>R</code> replicas cannot be elected as Leaders.</p></main> |
| paxos_replica_num | Optional. Specifies the quorum size for the leader of a log stream. If this value is not explicitly specified, the system will use the current default value of `paxos_replica_num`. The maximum number of F replicas for a log stream is 7.<main id="notice" type='notice'><h4>Notice</h4><p>When specifying the value of this parameter, note the following:<ol><li>If converting an <code>F</code> replica to an <code>R</code> replica, it is equivalent to deleting a leader replica. Therefore, the value of <code>paxos_replica_num</code> must be decreased by 1.</li><li>If converting an <code>R</code> replica to an <code>F</code> replica, it is equivalent to adding a leader replica. Therefore, the value of <code>paxos_replica_num</code> must be increased by 1.</li><li>After modification, <code>paxos_replica_num</code> must still represent a majority.</li><li>The value of <code>paxos_replica_num</code> must be greater than or equal to the number of members in the <code>MEMBER_LIST</code> of the current leader replica. You can confirm this by querying the <code>CDB_OB_LS_LOCATIONS</code> view for the sys tenant, or the <code>DBA_OB_LS_LOCATIONS</code> view for user tenants.</li><li>The absolute change in the <code>paxos_replica_num</code> value cannot exceed 1. For example, if the current <code>paxos_replica_num</code> is 3, it can only be changed to 2 or 4.</li></ol>If any of the above conditions are not met for the specified value, the system will report an error.</p></main> |
| tenant_name | Optional. Specifies the tenant to operate on. If you do not explicitly specify the tenant, the default tenant is the current tenant. <main id="notice" type='notice'><h4>Notice</h4><p>The system tenant can specify other tenants, while a user tenant can only specify itself. This statement does not support using <code>ALL</code>, <code>ALL_USER</code>, or <code>ALL_META</code> to specify all tenants, user tenants, or all Meta tenants.</p></main> |

## Examples

Execute the following command in the sys tenant to convert a unidirectional log stream replica of type `F` to a bidirectional log stream replica of type `R` for tenant `mysql001`.

```sql
ALTER SYSTEM MODIFY REPLICA
    LS = 1001
    SERVER = 'xxx.xxx.xxx.001:2882'
    REPLICA_TYPE = 'R'
    PAXOS_REPLICA_NUM = 2
    TENANT = 'mysql001';
```
