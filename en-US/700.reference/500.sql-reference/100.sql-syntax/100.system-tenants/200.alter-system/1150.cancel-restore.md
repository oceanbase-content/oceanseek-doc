# CANCEL RESTORE

## Purpose

The `ALTER SYSTEM CANCEL RESTORE` statement is used to cancel a ongoing tenant restore and delete the tenant that is being restored.

## Privilege requirements

Only the `root` user of the `sys` tenant (`root@sys`) can execute the `ALTER SYSTEM CANCEL RESTORE` statement.

## Syntax

```sql
ALTER SYSTEM CANCEL RESTORE dest_tenant_name;
```

## Parameters

| **Parameters** | **Description** |
| ---------------------- | ----------------------------------------------------------------------------------------- |
| dest_tenant_name | Specifies the name of the tenant whose restore operation is to be canceled. |

## Examples

Aborts the ongoing restore operation for the `mysql` tenant.

```shell
obclient [oceanbase]> ALTER SYSTEM CANCEL RESTORE mysql;
```
