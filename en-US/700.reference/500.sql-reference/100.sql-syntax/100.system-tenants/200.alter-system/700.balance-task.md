# BALANCE TASK

## Purpose

This statement is used to clear unscheduled load balancing tasks.

This statement can only be executed in the sys tenant.

## Syntax

```sql
ALTER SYSTEM REMOVE BALANCE TASK opt_tenant_list opt_zone_list opt_balance_task_type;

opt_tenant_list
    TENANT [=] tenant_name[,tenant_name, ...]

opt_zone_list
    ZONE [=] zone_name, zone_list

opt_balance_task_type
    ALL
    | MANUAL
    | AUTO
```

## Parameters

| **Parameters** | **Description** |
| ----------------------- | ---------------------------- |
| opt_tenant_list | Tenant list. If not specified, the task will clear all tenants. |
| opt_zone_list | List of zones. Optional. |
| opt_balance_task_type | Type of task to be cleared: <ul><li>`ALL`: All tasks. </li>   <li>`AUTO`: automatically generated tasks. </li>   <li>`MANUAL`: A task manually initiated by the user.</li></ul> |

## Examples

Clears all unscheduled tasks for all tenants.

```sql
obclient> ALTER SYSTEM REMOVE BALANCE TASK;
```
