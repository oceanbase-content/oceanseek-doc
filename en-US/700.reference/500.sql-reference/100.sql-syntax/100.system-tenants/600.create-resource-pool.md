# CREATE RESOURCE POOL

## Purpose

The `CREATE RESOURCE POOL` statement is used to create a resource pool, which describes a collection of resource units that can be allocated to tenants.

After a resource pool is created, it can be allocated to a tenant. Each resource pool can only be bound to one tenant. The total amount of resources allocated to a tenant within each zone is calculated as: Unit specification × Number of units.

## Limitations and considerations

If the resources reserved for the corresponding node are insufficient when creating a resource pool, the resource pool creation will fail. You can query the [GV$OB_SERVERS](../../../700.system-views/300.system-view-of-sys-tenant/300.performance-view-of-sys-tenant/3200.gv-ob_servers-of-sys-tenant.md) view to confirm the resource allocation information of each node.

## Privilege requirements

Only the `root` user of the `sys` tenant (`root@sys`) can create a resource pool. Other tenants do not support creating resource pools.

## Syntax

```sql
CREATE RESOURCE POOL pool_name
UNIT [=] unit_name,
UNIT_NUM [=] unit_num,
ZONE_LIST [=] ('zone_name' [, 'zone_name' ...]);
```

## Parameters

| **Parameters** | **Description** |
| ------------------------------------------- | --------------------------------------------------------------- |
| pool_name | Specifies the name of the resource pool to be created. |
| UNIT \[=\] unit_name | Specifies the name of the unit config for the resource pool to be created. |
| UNIT_NUM \[=\] unitnum | Specifies the number of units for the resource pool to be created in a single zone. The value must be less than the number of nodes in the target zone, and a tenant can have at most one unit distributed across each node. |
| ZONE_LIST \[=\] ('zone' \[, 'zone' ...\]) | Specifies the zone distribution for the resource pool to be created. |

## Examples

Create a resource pool named `pool1` with the unit specification `unit1`, one unit, and resources distributed in `zone1`.

```sql
obclient [oceanbase]> CREATE RESOURCE POOL pool1 UNIT='unit1', UNIT_NUM=1, ZONE_LIST=('zone1');
```

After the resource pool is created, query its information.

```sql
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_RESOURCE_POOLS WHERE NAME='pool1';
```

The query result is as follows:

