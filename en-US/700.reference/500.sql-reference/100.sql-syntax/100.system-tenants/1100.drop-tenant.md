# DROP TENANT

## Purpose

This statement is used to delete an OceanBase AI database tenant.

  <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>To execute the <code>DROP TENANT</code> statement, you must log in to the sys tenant as the root user. </p>
  </main>

## Syntax

```sql
drop_tenant_stmt:
DROP TENANT [IF EXISTS] tenant_name [PURGE|FORCE];
```

## Parameters

| **Parameters** | **Description** |
| ------------- | -------------------------------------- |
| tenant_name | Specifies the name of the tenant to be dropped. |
| PURGE | Indicates that the tenant will be deleted and will not be moved to the recycle bin. When the recycle bin feature of the `sys` tenant is disabled, `DROP TENANT` statements and `DROP TENANT... PURGE` statements have the same effect. |
| FORCE | This operation forcibly deletes the tenant, and the integrity of physical backup data cannot be guaranteed. The deleted tenant will not be moved to the recycle bin. |

## Examples

Delete the tenant named `test_tenant1`.

```sql
obclient> DROP TENANT test_tenant1;
```
