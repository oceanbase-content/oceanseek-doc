# SET DECRYPTION

## Purpose

This statement is used to set the password for restoration. You only need to set a password if one was added during backup.

This statement can only be executed in the sys tenant.

## Syntax

```sql
SET DECRYPTION IDENTIFIED BY  ('password'[, 'password' ...]);
```

## Parameters

| Parameter | Description |
| ---------- | --------------------------------------------------------------------------------------------- |
| password | The password added during backup. <main id="notice" type='explain'><h4>Note</h4><p> If the passwords set for full backup and incremental backup are different, you need to enter multiple passwords, separated by commas.</p></main>. |

## Examples

* Set the same password for both full and incremental backups.

  ```sql
  obclient> SET DECRYPTION IDENTIFIED BY '***1***';
  ```

* Set different passwords for full and incremental backups. The first is for the full backup, and the second is for the incremental backup.

  ```sql
  obclient> SET DECRYPTION IDENTIFIED BY '***1***','***2***';
  ```
