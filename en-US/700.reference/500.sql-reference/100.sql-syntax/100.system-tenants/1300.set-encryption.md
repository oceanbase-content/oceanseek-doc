# SET ENCRYPTION

## Purpose

This statement is used to set the backup password.

This statement only takes effect for the current session. The password will be cleared after the backup is initiated. Therefore, if you need to configure a backup password, you must set it again before each backup.

## Syntax

```sql
SET ENCRYPTION ON IDENTIFIED BY 'password' ONLY;
```

## Parameters

| Parameter | Description |
| ---------- | ---------- |
| password | The encryption password for the backup. |

## Examples

Set the backup password.

```sql
obclient> SET ENCRYPTION ON IDENTIFIED BY  '***1***' ONLY;
```
