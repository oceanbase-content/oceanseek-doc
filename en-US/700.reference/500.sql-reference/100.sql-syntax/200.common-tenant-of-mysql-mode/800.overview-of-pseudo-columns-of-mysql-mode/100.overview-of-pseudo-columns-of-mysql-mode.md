# Overview of PseudoColumns

A pseudocolumn behaves like a column in a table but does not store specific values. Therefore, a pseudocolumn is read-only and cannot be used for insert, update, or delete operations. This topic describes the pseudocolumns supported by the current version of OceanSeek and their usage instructions.

OceanSeek supports the following pseudo-column types:

* [PARTITIONID Pseudo Column](200.partititionid-pseudo-column-of-mysql-mode.md)
* [Sequence Pseudocolumns](300.sequence-pseudo-column-of-mysql-mode.md)
