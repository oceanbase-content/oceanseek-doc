# DROP USER

## Purpose

This statement is used to drop one or more database users.

  <main id="notice" type='notice'>
    <h4>Notice</h4>
    <ul>
    <li>You must have the global <code>CREATE USER</code> privilege to use the <code>DROP USER</code> command.</li>
    <li>You cannot delete the <code>mysql.user</code> table using the <code>DELETE</code> statement. You must use the <code>DROP</code> statement instead.</li>
    <li>After a user is successfully deleted, all permissions associated with that user are also deleted.</li>
    </ul>
  </main>

## Syntax

```sql
DROP USER [IF EXISTS] user_name [, user_name...]
```

## Parameters

| **Parameters** | **Description** |
| ----------- | ----------------------- |
| IF EXISTS | Optional. When this clause is used, attempting to delete a non-existent user will generate a warning rather than an error. If this clause is not used, deleting a non-existent user will cause an error. |
| user_name | Username. Separate multiple usernames with commas when deleting them simultaneously. |

## Examples

* Drop the user `sales_user`.

```sql
obclient> DROP USER sales_user;
```

* When you use `IF EXISTS` to delete a user, no error is returned if the user does not exist.

```sql
obclient> DROP USER IF EXISTS finance_user;
```

* Delete multiple users simultaneously.

```sql
obclient> DROP USER user1, user2, user3;
```
