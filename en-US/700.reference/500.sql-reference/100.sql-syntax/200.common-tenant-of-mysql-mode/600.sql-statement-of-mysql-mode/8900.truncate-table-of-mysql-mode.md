# TRUNCATE TABLE

## Purpose

This statement is used to completely clear a specified table while retaining its structure, including the partition information defined in the table. Logically, this statement is equivalent to a `DELETE FROM` statement that deletes all rows.

## Limitations and considerations

* The `TRUNCATE TABLE` statement efficiently clears a table by deleting all its data and resetting the table's metadata. This method offers significant performance advantages over row-by-row deletion using the `DELETE FROM` statement, especially for large data tables, as it eliminates the need for row-level locking and logging.

* The number of rows affected by a `TRUNCATE TABLE` statement is always displayed as `0` rows.

* When you use the `TRUNCATE TABLE` statement, the table manager does not remember the last used `AUTO_INCREMENT` value but restarts the count from zero.

* The `TRUNCATE` statement cannot be executed during transaction processing or when a table is locked. Using it in such situations will result in an error.

* As long as the table definition file is valid, you can use `TRUNCATE TABLE` to recreate a table as an empty table, even if the data or index files are corrupted.

## Privilege requirements

To execute the `TRUNCATE TABLE` statement, the current user must have the `DROP` privilege on the table. For more information about OceanBase AI database privileges, see [Permission classification](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md).

## Syntax

```sql
TRUNCATE [TABLE] table_name;
```

## Parameters

| **Parameters** | **Description** |
| ------------ | ---------- |
| table_name | Specify the table name. |

## Examples

1. Create the table `test_tbl1`.

   ```sql
   CREATE TABLE test_tbl1(col1 INT AUTO_INCREMENT PRIMARY KEY, col2 VARCHAR(20))
       PARTITION BY HASH(col1) PARTITIONS 5;
   ```

2. Insert test data into the `test_tbl1` table.

   ```sql
   INSERT INTO test_tbl1(col2) VALUES('A1'),('A2'),('A3');
   ```

   The return result is as follows:

   ```shell
   Query OK, 3 rows affected
   Records: 3  Duplicates: 0  Warnings: 0
   ```

3. Completely truncate the `test_tbl1` table.

   ```sql
   TRUNCATE TABLE test_tbl1;
   ```

4. Query the data in the `test_tbl1` table.

   ```sql
   SELECT * FROM test_tbl1;
   ```

   The result is as follows:

   ```shell
   Empty set
   ```

5. Query the definition of the `test_tbl1` table.

   ```sql
   SHOW CREATE TABLE test_tbl1;
   ```

   The result is as follows:

   ```shell
   +-----------+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
   | Table     | Create Table                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
   +-----------+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
   | test_tbl1 | CREATE TABLE `test_tbl1` (
   `col1` int(11) NOT NULL AUTO_INCREMENT,
   `col2` varchar(20) DEFAULT NULL,
   PRIMARY KEY (`col1`)
   ) AUTO_INCREMENT = 1 AUTO_INCREMENT_MODE = 'ORDER' DEFAULT CHARSET = utf8mb4 ROW_FORMAT = DYNAMIC COMPRESSION = 'zstd_1.3.8' REPLICA_NUM = 1 BLOCK_SIZE = 16384 USE_BLOOM_FILTER = FALSE TABLET_SIZE = 134217728 PCTFREE = 0
   partition by hash(col1)
   (partition `p0`,
   partition `p1`,

   partition `p4`) |

   1 row in set
   ```
