# SET NAMES

## Purpose

Set the character sets and collations for the client, connection, and results.

## Syntax

```sql
SET NAMES charset_name [COLLATE collation_name]
```

## Parameters

| Parameter | Description |
| ---------------- | ----------------------------- |
| charset_name | Specify the default character set for columns in a table. The following character sets are supported: <ul><li>`binary`   </li><li> `utf8mb4`   </li><li> `gbk`   </li><li> `utf16`   </li><li> `gb18030` </li></ul> |
| collation_name | To specify the default collation for columns in a table, you can use the following collations: <ul><li>`binary`   </li><li> `gbk_bin`   </li><li> `gbk_chinese_ci`   </li><li> `utf8mb4_general_ci`   </li><li> `utf8mb4__general_cs`   </li><li> `utf8mb4_bin`   </li><li> `utf8mb4_unicode_ci`   </li><li> `utf16_general_ci`   </li><li> `utf16_bin`   </li><li> `utf16_unicode_ci`   </li><li> `gb18030_chinese_ci`   </li><li> `gb18030_bin`  </li></ul> |

## Examples

Specify the client, connection, and result character sets as `gbk`, and the collation as `gbk_bin`.

```sql
obclient> SET NAMES gbk COLLATE gbk_bin;
```
