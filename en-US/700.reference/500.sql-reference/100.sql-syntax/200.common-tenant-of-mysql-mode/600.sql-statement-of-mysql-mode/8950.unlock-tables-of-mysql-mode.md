# UNLOCK TABLES

## Purpose

This statement is used to release all table locks held by the current session.

## Limitations and considerations

`UNLOCK TABLES` does not actively commit the transaction.

## Syntax

```sql
UNLOCK {TABLE | TABLES};
```

## Syntax

| **Field** | **Description** |
| -------------------------- | ---------- |
| UNLOCK {TABLE \ \| TABLES} | Releases all table locks held by the current session. `UNLOCK TABLE` is a synonym for `UNLOCK TABLES`. |

## Examples

Releases all table locks held by the current session.

```sql
UNLOCK TABLES;
```
