# REPLACE

## Purpose

This statement is used to replace one or more records in a table. If there is no primary key or unique key conflict, the record is inserted. If a conflict exists, the conflicting record is deleted first, and then the new record is inserted.

## Syntax

```sql
REPLACE [INTO] table_factor [PARTITION (partition_name_list)] [(column_name_list)]
    {VALUES | VALUE} column_value_lists

partition_name_list:
    partition_name [, partition_name ...]

column_name_list:
    column_name [, column_name ...]

column_value_lists:
    (column_value_list) [, (column_value_list) ...]

column_value_list:
    column_value [, column_value ...]

column_value:
    {expression | DEFAULT}
```

## Parameters

| **Parameters** | **Description** |
| --------------------- | ------------ |
| table_factor | The name of the table to be replaced. |
| column_name_list | Specifies the column whose data is to be replaced. |
| partition_name_list | Replace the partition name specified for the table. |

## Examples

This example is based on the following table definition.

```sql
obclient> CREATE TABLE product_info (product_id INT PRIMARY KEY, product_name VARCHAR(40));
```

1. Replace two records in the `product_info` table.

   ```sql
   obclient> REPLACE INTO product_info VALUES (1, 'Product A'),(2, 'Product B');
   ```

2. View the contents of the `product_info` table.

   ```sql
   obclient> SELECT * FROM product_info;
   ```

   The query result is as follows:

   ```sql
   +------------+-------------+
   | product_id | product_name|
   +------------+-------------+
   |          1 | Product A   |
   |          2 | Product B   |
   +------------+-------------+
   2 rows in set
   ```

3. Replace the record in the `product_info` table where `product_id=2`. The existing record will be replaced.

   ```sql
   obclient> REPLACE INTO product_info VALUES (3, 'Product C'),(2, 'Product B Updated');
   ```

4. View the contents of the `product_info` table.

   ```sql
   obclient> SELECT * FROM product_info;
   ```

   The query result is as follows:

   ```sql
   +------------+------------------+
   | product_id | product_name     |
   +------------+------------------+
   |          1 | Product A        |
   |          2 | Product B Updated|
   |          3 | Product C        |
   +------------+------------------+
   3 rows in set
   ```
