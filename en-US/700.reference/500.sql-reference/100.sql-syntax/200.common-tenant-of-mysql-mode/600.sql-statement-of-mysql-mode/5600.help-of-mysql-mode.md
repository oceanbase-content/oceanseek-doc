# HELP

## Purpose

Returns the search results from the help table. The search string can contain the wildcard percent sign (`%`) and underscore (`_`).

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>The <code>HELP</code> feature requires loading the <code>help tables</code> for proper use. The procedure is as follows:</p>
    <ol>
    <li>Copy the <code>fill_help_tables-ob.sql</code> file to the <code>tmp</code> directory on the client machine. The <code>fill_help_tables-ob.sql</code> file is located in the <code>etc</code> directory of the OceanSeek installation directory.</li>
    <li>Log in to the sys tenant and execute the statement <code>source /tmp/fill_help_tables-ob.sql</code>.</li>
    </ol>
  </main>

A search string can match one category, multiple topics, or a single topic:

* View the list of top-level help categories:

  ```sql
  HELP 'contents';
  ```

* View topics in each help category. For example, to search for data types, enter `data types`:

  ```sql
  HELP 'data_types';
  ```

* For a specific help topic, you can use one or more associated keywords:

  ```sql
  HELP 'create table'
  ```

  The returned topic contains the following information:

  * `name`: The name of the topic.

  * `description`: The descriptive help text for this topic.

## Syntax

```sql
HELP 'search_string';

search_string:
   contents | data_types | theme
```

## Parameters

| Parameter | Description |
| ------------ | ------------------------------- |
| contents | You can view the directory of all help topics and search for more information by topic name. |
| data_types | View help information for a specified data type. |
| theme | View the help information for a specified topic. |

## Examples

* View the table of contents for all help topics.

  ```sql
  obclient> HELP 'contents';
  ```

  The execution result is as follows:

  ```sql
  You asked for help about help category: "Contents"
  For more information, type 'help <item>', where <item> is one of the following
  categories:
     Data Types
     Functions
     Operator
     Escape character
     Data Definition
     Data Manipulation
     Transaction Statements
     Prepared Statements
     Compound Statements
     Administration
     Utility
  ```

* View the data types included in the numeric type.

  ```sql
  obclient> HELP 'Numeric Types';
  ```

  The execution result is as follows:

  ```sql
  You asked for help about help category: "Numeric Types"
  For more information, type 'help <item>', where <item> is one of the following
  topics:
     TINYINT
     BOOL,BOOLEAN
     SMALLINT
     MEDIUMINT
     INT
     INTEGER
     BIGINT
     FLOAT
     DOUBLE
     DOUBLE PRECISION
     FLOAT(p)
     DECIMAL
     NUMERIC
  ```

* View the usage of the `KILL` statement.

  ```sql
  obclient> HELP 'KILL';
  ```

  The execution result is as follows:

  ```sql
  Name: 'KILL'
  Description:

    Syntax:

    KILL [GLOBAL | LOCAL] [CONNECTION | QUERY] 'sessionid'

    Each connection to OceanSeek runs in its own thread. You can use the SHOW PROCESSLIST; statement to view which threads are running, and use the KILL thread_id statement to terminate a thread.

  • KILL CONNECTION is the same as KILL without a modifier: it terminates the connection with the given thread_id.

  • KILL QUERY terminates the statement currently being executed by the connection, but preserves the connection.
  If you have the PROCESS privilege, you can view all threads. If you have the SUPER privilege, you can terminate all threads and statements. Otherwise, you can only view and terminate your own threads and statements.
  ```

* View the syntax of the `SELECT` statement.

  ```sql
  obclient> HELP SELECT;
  ```

  The execution result is as follows:

  ```sql
  Name: 'SELECT'
  Description:

    This statement is used to query the contents of a table.

    Basic queries

    Syntax:

    SELECT
      [ALL | DISTINCT]
        selectexpr [AS othername] [, selectexpr ...]
        [FROM table_references]
          [WHERE where_conditions]
      [GROUP BY group_by_list]
      [HAVING search_confitions]
      [ORDER BY order_list]
      [LIMIT {[offset,] rowcount | rowcount OFFSET offset}]
          [FOR UPDATE];
  ```
