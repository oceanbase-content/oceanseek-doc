# REPAIR TABLE

This statement is used to repair potentially damaged tables.

## Syntax

```sql
REPAIR [NO_WRITE_TO_BINLOG | LOCAL]
    TABLE tbl_name [, tbl_name] ...
    [QUICK] [EXTENDED] [USE_FRM]
```
