# RENAME USER

## Purpose

This statement is used to modify the username of a user logging in to OceanBase AI Database.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>You must have the global <code>CREATE USER</code> privilege to rename a user using this command.</p>
  </main>

## Syntax

```sql
RENAME USER
    'old_user_name' TO 'new_user_name'
  [,'old_user_name' TO 'new_user_name'...]
```

## Parameters

| **Parameters** | **Description** |
| ------------------------------------ | ------------------------------------------------------------- |
| old_user_name | Old username. |
| new_user_name | New username. The username must be 16 bytes or less. |
| 'old_user_name' TO 'new_user_name' | Modify the username. When modifying multiple usernames, separate them with commas (,). The permissions of the new and old users remain the same before and after the modification. |

## Examples

1. Before modification, execute the following command to view users.

   ```sql
   obclient> SELECT user FROM mysql.user;
   ```

   The query result is as follows:

   ```sql
   +-----------+
   | user      |
   +-----------+
   | root      |
   | admin     |
   | sqluser01 |
   | sqluser02 |
   +-----------+
   4 rows in set
   ```

2. Run the following command to change the username of the `sqluser01` user to `obsqluser01`.

   ```sql
   obclient> RENAME USER 'sqluser01' TO 'obsqluser01';
   ```

3. After modification, execute the following command to view the user.

   ```sql
   obclient> SELECT user FROM mysql.user;
   ```

   The query result is as follows:

   ```sql
   +-------------+
   | user        |
   +-------------+
   | root        |
   | admin       |
   | obsqluser01 |
   | sqluser02   |
   +-------------+
   4 rows in set
   ```

   The username of the `sqluser01` user has been changed to `obsqluser01`.
