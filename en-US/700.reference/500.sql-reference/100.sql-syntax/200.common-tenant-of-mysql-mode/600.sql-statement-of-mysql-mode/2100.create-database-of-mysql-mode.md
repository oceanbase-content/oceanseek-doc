# CREATE DATABASE

## Description

This statement is used to create a database and can specify the database's default attributes (such as the default character set and collation).

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p><code>CREATE DATABASE</code> is equivalent to <code>CREATE SCHEMA</code>.</p>
</main>

## Privilege requirements

To execute the `CREATE DATABASE` statement, the current user must have the global `CREATE` privilege. For more information about OceanBase AI database privileges, see [Permission classification](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md).

## Syntax

```sql
CREATE {DATABASE | SCHEMA} [IF NOT EXISTS] database_name [database_option...]

database_option:
      [DEFAULT] {CHARACTER SET | CHARSET} charset_name
    | [DEFAULT] COLLATE collate_name
    | {READ ONLY | READ WRITE}
    | [DEFAULT] TABLEGROUP {table_group_name | NULL}
```

## Parameters

| Parameter | Description |
| ------- | ----------- |
| IF NOT EXISTS | It indicates that if the database already exists, it will not be created. When creating a database, if the database exists and this option is not specified, `IF NOT EXISTS`, an error will be reported. |
| database_name | Specifies the name of the database to be created. |
| [DEFAULT] {CHARACTER SET \ \| CHARSET} charset_name | Sets the character set (charset) of the database. |
| [DEFAULT] COLLATE collate_name | Set the database collation. |
| {READ ONLY \ \| READ WRITE} | Specifies the read and write properties of the database. <ul><li>`READ ONLY`: Sets the database to read-only mode, prohibiting write operations on the database.</li><li>`READ WRITE`: Sets the database to read/write mode, allowing both read and write operations on the database. </li></ul> |
| [DEFAULT] TABLEGROUP {table_group_name \ \| NULL} | Specifies the default table group for a database. You can set it to a specified table group name or disable the default table group for the database. |

## Examples

* Create a database named `test1` and set its character set to `UTF-8`.

  ```shell
  obclient> CREATE DATABASE IF NOT EXISTS test1 DEFAULT CHARACTER SET utf8;
  ```

* Create a database named `test2` with read and write attributes.

  ```shell
  obclient> CREATE DATABASE test2 READ WRITE;
  ```
