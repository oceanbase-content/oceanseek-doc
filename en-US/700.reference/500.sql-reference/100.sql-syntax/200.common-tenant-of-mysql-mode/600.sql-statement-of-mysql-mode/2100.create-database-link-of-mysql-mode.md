# CREATE DATABASE LINK

## Description

This statement is used to create a `dblink` for accessing a specified remote database. It requires specifying the `dblink` name and providing the remote database's username, tenant name, database name, password, IP address, port number, and cluster name.

In OceanSeek, currently only user tenants of a local OceanSeek cluster can read data from user tenants of a remote OceanSeek cluster. You can also create a `dblink` between different user tenants within the same cluster. Reading data from native MySQL databases or reading data from user tenants of an OceanSeek cluster by native MySQL databases is not supported.

The `dblink` of OceanSeek supports reading the following data types.

* Numeric data types: `TINYINT`, `SMALLINT`, `MEDIUMINT`, `INT`, `BIGINT`, `FLOAT`, `DOUBLE`, and `DECIMAL`.

* Time types: `DATE`, `TIME`, `YEAR`, `DATETIME`, and `TIMESTAMP`.

* Character types: `CHAR`, `VARCHAR`, `TINYBLOB`, `TINYTEXT`, `BLOB`, `TEXT`, `MEDIUMTEXT`, `LONGBLOB`, and `LONGTEXT`.

* Other types: `ENUM` and `SET`.

## Syntax

```sql
CREATE DATABASE LINK [IF NOT EXISTS] dblink_name CONNECT TO user_name@tenant_name DATABASE database_name IDENTIFIED BY password HOST 'ip:port' [CLUSTER cluster_name]
```

## Description

| field | Description |
| --- | --- |
| dblink_name | Specifies the name of the database link to access. |
| IF NOT EXISTS | If specified `IF NOT EXISTS`, even if the dblink to be created already exists, no error will be reported. If it is not specified and the dblink to be created already exists, the system will report an error. |
| user_name | Specifies the username of the remote database user. |
| tenant_name | Specifies the tenant name of the remote database. |
| password | Specifies the login password for the username of the remote database. If the password contains special characters other than digits and letters (~!@#%^&*_-+=&#124;(){}[]:;,.?/), you must enclose the password in single quotes or double quotes to avoid syntax errors. |
| database_name | The database name of the remote user tenant. When reading data via dblink, this database is accessed by default. To access another database, you can specify the target database for a table in the SQL statement. |
| ip | Specify the IP address of the remote database. You can specify the IP address of the cluster's proxy or the IP address of an OBServer node in the cluster. If you specify the IP address of an OBServer node, the network between the local database and the specified OBServer node must be accessible.  <main id="notice" type='explain'><h4>Note</h4><p>In addition to IP addresses, OceanSeek also supports domain names. For example, <code>example.com:port</code>. You can use the appropriate domain name to connect to the remote database based on your actual environment.</p></main> |
| port | Specifies the port number of the remote database. You can specify the port number of the cluster's proxy or the port number of an OBServer node in the cluster. If you specify the port number of an OBServer node, the network between the local database and the specified OBServer node must be accessible. |
| cluster_name | Specifies the name of the remote OceanBase AI database cluster. The cluster name is required only if the IP address and port number belong to the proxy and the proxy is deployed using the ConfigUrl method. The cluster name is case-sensitive and must be enclosed in double quotation marks. |

## Examples

* Create a dblink named `ob_dblink` to connect to an OBServer node in a remote OceanBase AI database cluster. The tenant of the remote database is `mysql` (you can specify any user tenant), the user is `user1`, and the database is `test`. Specify the password, IP address, and port number according to your actual environment.

  ```shell
  obclient> CREATE DATABASE LINK IF NOT EXISTS ob_dblink  CONNECT TO user1@mysql DATABASE test IDENTIFIED BY '******' HOST 'xx.xx.xx.xx:xx';
  ```

* Create a dblink named `ob_dblink_proxy` to connect to the remote OceanBase AI database cluster. The tenant of the remote database is the default `mysql` (you can specify any user tenant), the user is `user1`, and the database is `test`. Specify the password, IP address, and port number according to your actual environment.

  ```shell
  obclient> CREATE DATABASE LINK IF NOT EXISTS  ob_dblink_proxy CONNECT TO user1@mysql DATABASE test IDENTIFIED BY '******' HOST 'xx.xx.xx.xx:xx' CLUSTER "obcluster";
  ```

After creating a Dblink, you can query and delete it. For more information, see [SELECT](8100.select-of-mysql-mode/100.select-of-mysql-mode.md).

You can query the `oceanbase.DBA_DB_LINKS` view for information about the created DBLINKs. For more information, see [DBA_DB_LINKS](../../../../700.system-views/300.system-view-of-sys-tenant/200.dictionary-view-of-sys-tenant/14300.o-dba_db_links-of-sys-tenant.md);
