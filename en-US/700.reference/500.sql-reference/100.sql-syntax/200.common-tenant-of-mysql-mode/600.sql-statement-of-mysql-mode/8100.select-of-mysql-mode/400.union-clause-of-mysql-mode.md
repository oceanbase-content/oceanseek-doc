# UNION clause

## Description

This statement is used to perform set operations on the results of multiple `SELECT` queries.

## Limitations and considerations

* The set operators have the same precedence. If an SQL statement contains multiple set operators, OceanSeek evaluates them from left to right, unless parentheses are used to explicitly specify the order of operation.

* Each set operator can only operate on the result sets of `SELECT` statements, and the number of columns and data types in each result set must be the same.

## Syntax

```sql
select_stmt
    {UNION | UNION ALL | MINUS | EXCEPT | INTERSECT} select_stmt
    [, {UNION | UNION ALL | MINUS | EXCEPT | INTERSECT} select_stmt ...]
    [ORDER BY order_by_condition_list]
    [LIMIT limit_clause];
```

## Parameters

| Parameter | Description |
| ---------------------------------- | -------------------------------------------------- |
| select_stmt | The `SELECT` statement used for set computation. For more information about the `SELECT` statement, see [SELECT](100.select-of-mysql-mode.md). |
| UNION | Used to concatenate the result sets of two `SELECT` statements into a single set and remove duplicate rows. |
| UNION ALL | Used to concatenate the result sets of two `SELECT` statements into one set without removing duplicate rows. |
| MINUS \ \| EXCEPT | Used to return the rows in the result set of the first `SELECT` statement that are not contained in the result set of the second `SELECT` statement. `MINUS` is a synonym for `EXCEPT`. |
| INTERSECT | Used to return the intersection of the result sets of two `SELECT` statements and remove duplicates. |
| ORDER BY order_by_condition_list | Specifies to sort the result set after collection. |
| LIMIT limit_clause | Specifies the number of rows returned after the set operation. |

## Examples

1. Create tables `test_tbl1` and `test_tbl2`.

   ```sql
   CREATE TABLE test_tbl1 (col1 INT, col2 INT);
   CREATE TABLE test_tbl2 (col1 INT, col2 INT);
   ```

2. Insert test data into tables `test_tbl1` and `test_tbl2`.

   ```sql
   INSERT INTO test_tbl1 VALUES (1, 1), (2, 2), (4, 4);
   INSERT INTO test_tbl2 VALUES (2, 2), (3, 3), (5, 5);
   ```

* Select the data in columns `col1` and `col2` from tables `test_tbl1` and `test_tbl2`, and use the `UNION ALL` operator to merge them into a single result set, retaining duplicate rows.

  ```sql
  SELECT col1, col2 FROM test_tbl1
  UNION ALL
  SELECT col1, col2 FROM test_tbl2;
  ```

  The return result is as follows:

  ```shell
  +------+------+
  | col1 | col2 |
  +------+------+
  |    1 |    1 |
  |    2 |    2 |
  |    4 |    4 |
  |    2 |    2 |
  |    3 |    3 |
  |    5 |    5 |
  +------+------+
  6 rows in set
  ```

* Select the data from columns `col1` and `col2` in the `test_tbl1` and `test_tbl2` tables, and use the `UNION` operator to combine them into a single result set, removing duplicate rows.

  ```sql
  SELECT col1, col2 FROM test_tbl1
  UNION
  SELECT col1, col2 FROM test_tbl2;
  ```

  The return result is as follows:

  ```shell
  +------+------+
  | col1 | col2 |
  +------+------+
  |    1 |    1 |
  |    2 |    2 |
  |    4 |    4 |
  |    3 |    3 |
  |    5 |    5 |
  +------+------+
  5 rows in set
  ```

* Select the data in columns `col1` and `col2` from tables `test_tbl1` and `test_tbl2`, and return their intersection. That is, return the duplicate parts of the data in columns `col1` and `col2` between `test_tbl1` and `test_tbl2`.

  ```sql
  SELECT col1, col2 FROM test_tbl1
  INTERSECT
  SELECT col1, col2 FROM test_tbl2;
  ```

  The return result is as follows:

  ```shell
  +------+------+
  | col1 | col2 |
  +------+------+
  |    2 |    2 |
  +------+------+
  1 row in set
  ```

* Select the data from columns `col1` and `col2` in the `test_tbl1` table, and exclude the identical data in columns `col1` and `col2` from the `test_tbl2` table. In other words, return the data rows that are present in `test_tbl1` but absent from `test_tbl2`.

  ```sql
  SELECT col1, col2 FROM test_tbl1
  EXCEPT
  SELECT col1, col2 FROM test_tbl2;
  ```

  The return result is as follows:

  ```shell
  +------+------+
  | col1 | col2 |
  +------+------+
  |    1 |    1 |
  |    4 |    4 |
  +------+------+
  2 rows in set
  ```

* Retrieve the data from columns `col1` and `col2` in tables `test_tbl1` and `test_tbl2`, respectively, and merge them. Then sort the merged result in descending order by `col1` and return only the first three rows.

  ```sql
  SELECT col1, col2 FROM test_tbl1
  UNION
  SELECT col1, col2 FROM test_tbl2
  ORDER BY col1 DESC
  LIMIT 3;
  ```

  The return result is as follows:

  ```shell
  +------+------+
  | col1 | col2 |
  +------+------+
  |    5 |    5 |
  |    4 |    4 |
  |    3 |    3 |
  +------+------+
  3 rows in set
  ```
