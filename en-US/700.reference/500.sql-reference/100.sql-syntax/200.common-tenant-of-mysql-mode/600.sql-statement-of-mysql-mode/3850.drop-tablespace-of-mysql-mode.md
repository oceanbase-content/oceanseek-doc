# DROP TABLESPACE

## Description

This statement is used to drop a logical TableSpace object. It can be successfully executed only when no tables exist in the TableSpace.

## Syntax

```sql
DROP TABLESPACE tablespace_name
[ENGINE [=] engine_name];
```

## Parameters

| Parameter | Description |
| ----------------- | ----------------------- |
| tablespace_name | Specifies the name of the tablespaces to be dropped. |
| ENGINE | Specifies the storage engine that uses tablespaces. This keyword syntax is supported only in the current version, but the feature is not yet available. |

## Examples

Delete the tablespaces object `tablespace001`.

```shell
DROP TABLESPACE tablespace001;
```
