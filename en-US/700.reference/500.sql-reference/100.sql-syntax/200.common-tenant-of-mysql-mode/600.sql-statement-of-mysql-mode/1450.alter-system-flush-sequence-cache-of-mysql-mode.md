# ALTER SYSTEM FLUSH SEQUENCE CACHE

## Description

This statement is used to clear the sequence cache.

## Privilege requirements

The current user must have the `ALTER SYSTEM` privilege to execute this statement. For more information about OceanBase AI database privileges, see [Permission classification](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md).

## Syntax

```sql
ALTER SYSTEM FLUSH SEQUENCE CACHE
    SEQUENCE_NAME = sequence_name
    [DATABASES = 'database_name']
    [GLOBAL];
```

## Parameters

| Parameter | Description |
| --------------------------------- | ------------------ |
| SEQUENCE_NAME = 'sequence_name' | Specifies the name of the sequence whose local cache needs to be cleared. |
| DATABASES = 'database_name' | Optional. Specifies in which database to perform this operation. If this parameter is not specified, the operation is performed in the current database. |
| GLOBAL | Optional. Clears the cache on all nodes. If this parameter is not specified, only the cache on the current node is cleared. |

## Examples

* Purge the cache on this node for the sequence named `test_seq1` under the current tenant and database.

    ```shell
    obclient> ALTER SYSTEM FLUSH SEQUENCE CACHE
        SEQUENCE_NAME = test_seq1;
    ```

* Purge the cache with the sequence name `test_seq1` from all nodes in the current tenant and database.

    ```shell
    obclient> ALTER SYSTEM FLUSH SEQUENCE CACHE
        SEQUENCE_NAME = test_seq1
        GLOBAL;
    ```

* Purge the cache named `test_seq1` from all nodes in the current tenant and the database named `test`.

    ```shell
    obclient> ALTER SYSTEM FLUSH SEQUENCE CACHE
        SEQUENCE_NAME = test_seq1
        DATABASES = 'test'
        GLOBAL;
    ```
