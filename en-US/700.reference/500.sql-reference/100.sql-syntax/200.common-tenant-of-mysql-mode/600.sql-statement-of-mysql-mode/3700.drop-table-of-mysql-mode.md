# DROP TABLE

## Description

This statement is used to drop a table from OceanSeek.

## Syntax

```sql
DROP {TABLE | TABLES} [TEMPORARY] [IF EXISTS]
table_name [,table_name]...
[RESTRICT | CASCADE]
```

## Parameters

| **Parameters** | **Description** |
| --------------------- | ------------------------------------------------------------------------------------------------ |
| table_name | Specify the table name to be dropped. When dropping multiple tables, separate them with commas (,). |
| TEMPORARY | Indicates that a temporary table is dropped. |
| IF EXISTS | If specified `IF EXISTS`. If this parameter is not specified, an error will be returned. |
| RESTRICT \ \| CASCADE | Used for scenarios where data is migrated from other databases to OceanSeek.  <br>**Note**  This parameter is not supported in the current version. If provided, it will be parsed but ignored.  <br> |

## Examples

* Specify `IF EXISTS` to drop the table `test1`.

  ```sql
  obclient> DROP TABLE IF EXISTS test1;
  Query OK, 0 rows affected
  ```

* Specify `IF EXISTS` to delete both tables `test1` and `test2`.

  ```sql
  obclient> DROP TABLES IF EXISTS test1,test2;
  Query OK, 0 rows affected
  ```

* If `IF EXISTS` is not specified, deleting multiple tables will fail if any one of the tables does not exist.

  ```sql
  obclient> DROP TABLES test1,test2;
  ERROR 1051 (42S02): Unknown table 'test.test2'
  ```

* Drop the temporary table `tset3`.

  ```sql
  obclient> DROP TEMPORARY TABLE test3;
  Query OK, 0 rows affected
  ```
