# USE

## Purpose

This statement is used to switch the current database.

## Syntax

```sql
USE database_name
```

## Parameters

| Parameter | Description |
| --------------- | ----------- |
| database_name | The name of the database to be used. |

## Examples

Switches the current database.

```sql
obclient> USE test
```

The query result is as follows:

```sql
Database changed
```
