# DROP DATABASE

## Purpose

This statement is used to drop a database.

## Syntax

```sql
DROP DATABASE [IF EXISTS] database_name
```

## Parameters

| **Parameters** | **Description** |
| --------------- | ------------------- |
| IF EXISTS | This is used to prevent errors when the database does not exist. |
| database_name | Specifies the name of the database to be dropped. |

## Examples

* Drop the database `test2`.

  ```sql
  obclient> DROP DATABASE test2;
  ```

* Delete the non-existent database `notest`.

  ```sql
  obclient> DROP DATABASE notest;
  ```

  Expected return value:

  ```sql
  ERROR 1008 (HY000): Can't drop database 'notest'; database doesn't exist
  ```

  ```sql
  obclient> DROP DATABASE IF EXISTS notest;
  ```

  Expected return result:

  ```sql
  Query OK, 0 rows affected, 1 warning
  ```

  ```sql
  obclient> SHOW WARNINGS;
  ```

  Expected return value:

  ```sql
  
  +-------+------+------------------------------------------------------+
  | Level | Code | Message                                              |
  +-------+------+------------------------------------------------------+
  | Note  | 1008 | Can't drop database 'notest'; database doesn't exist |
  +-------+------+------------------------------------------------------+
  1 row in set
  ```
