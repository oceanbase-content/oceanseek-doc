# ALTER VIEW

## Purpose

This statement is used to modify the definition of a view.

## Privilege requirements

To execute the `ALTER VIEW` statement, the current user must have the `DROP` and `CREATE VIEW` privileges. For more information about OceanBase AI database privileges, see [Permission classification](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md).

## Syntax

```sql
ALTER VIEW view_name [(column_name_list)]
    AS select_stmt;

column_name_list:
    column_name [, column_name ...]
```

## Parameters

| Parameter | Description |
| ------------------ | ------------------------------------------------------------ |
| view_name | Specifies the view name. |
| column_name_list | Optional. Specifies the list of column names for the view. If the column name list is not specified, the column names retrieved by the `SELECT` statement will be used as the view column names. The columns retrieved by the `SELECT` statement can be simple references to table columns or expressions that use functions, constant values, operators, and so on. View column names have the following limitations:<ul><li>They must be unique and cannot duplicate.</li><li>The number of names in `column_name_list` must be equal to the number of columns retrieved by the `SELECT` statement.</li></ul> |
| column_name | The column name of the view. |
| select_stmt | The query used to define the view (`SELECT`) statement. It defines the view, which can select data from base tables or other views. For details about the structure and options of the query statement, see [SELECT](8100.select-of-mysql-mode/100.select-of-mysql-mode.md). |

## Examples

Modify the definition of view `v1` to select data from `test_tbl2`.

1. Create the table `test_tbl1`.

   ```sql
   CREATE TABLE test_tbl1 (col1 INT, col2 INT);
   ```

2. Create a view named `v1` based on the table `test_tbl1`.

   ```sql
   CREATE VIEW v1
       AS SELECT * FROM test_tbl1;
   ```

3. Create the table `test_tbl2`.

   ```sql
   CREATE TABLE test_tbl2 (col1 INT, col2 INT, col3 INT);
   ```

4. Modify the definition of view `v1` to select data from `test_tbl2`.

   ```sql
   ALTER VIEW v1 AS SELECT * FROM test_tbl2;
   ```

5. View the definition of view `v1` again.

   ```sql
   SHOW CREATE VIEW v1;
   ```

   The return result is as follows:

   ```shell
   +------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------+----------------------+----------------------+
   | View | Create View                                                                                                                                                                | character_set_client | collation_connection |
   +------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------+----------------------+----------------------+
   | v1   | CREATE VIEW `v1` AS select `db_test`.`test_tbl2`.`col1` AS `col1`,`db_test`.`test_tbl2`.`col2` AS `col2`,`db_test`.`test_tbl2`.`col3` AS `col3` from `db_test`.`test_tbl2` | utf8mb4              | utf8mb4_general_ci   |
   +------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------+----------------------+----------------------+
   1 row in set
   ```
