# ALTER USER

## Description

This statement is mainly used to perform the following operations:

* Change the password of an OceanBase AI database user.

* Lock or unlock users. Locked users are not allowed to log in to the database.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>To execute this command, you must have the <code>CREATE USER</code> privilege, in addition to being able to change the current user's password.</p>
  </main>

* Sets the default role activated for users upon login.

* Modify user resource options.

## Privilege requirements

To execute the `ALTER USER` statement, the current user must have the `CREATE USER` privilege. For more information about OceanBase AI database privileges, see [Permission classification](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md).

## Syntax

* Change the password of a user:

  ```sql
  ALTER USER 'user_name'
  IDENTIFIED [WITH auth_plugin]  BY 'password' | IDENTIFIED [WITH auth_plugin] AS 'auth_string'
  ```

* Locked users:

  ```sql
  ALTER USER 'user_name' [ACCOUNT LOCK | ACCOUNT UNLOCK]
  ```

* Set the default role activated for users upon login:

  ```sql
  ALTER USER user_name DEFAULT ROLE {NONE | ALL | role_name [, role_name ...]}
  ```

* Modify user resource options:

  ```sql
  ALTER USER user_name WITH  resource_option [resource_option]

  resource_option:
      MAX_CONNECTIONS_PER_HOUR integer
      | MAX_USER_CONNECTIONS integer
  ```

## Parameters

| **Parameters** | **Description** |
| ---------------- | ---------- |
| user_name | Specify the username. |
| password | Specify the new password. |
| IDENTIFIED WITH auth_plugin AS 'auth_string' | Set the account authentication plugin to `auth_plugin`, and set the `auth_string` value stored in the `mysql.user` table. If a plugin requires a hash string, it is assumed that the string is already in the hash format required by the plugin. |
| ACCOUNT LOCK | Specifies the locking user. |
| ACCOUNT UNLOCK | Specifies the user to unlock. |
| NONE | Specify all roles granted to the disabled user. |
| ALL | Specify to activate all roles under the user. |
| role_name | Specifies the role name. When activating multiple roles, separate the role names with commas (`,`) separated. |
| resource_option | Resource options for the specified user. Separate multiple resource options with spaces.<ul><li>`MAX_CONNECTIONS_PER_HOUR`: Specifies the maximum number of connections allowed per hour. `integer` is an integer that specifies the maximum number of connections allowed. </li><li>`MAX_USER_CONNECTIONS`: Specifies the maximum number of connections allowed for each user. `integer` is an integer that specifies the maximum number of connections allowed. </li></ul> |

## Examples

* Run the following command to change the password of user `sqluser01` to `******`.

  ```sql
  obclient> CREATE USER 'sqluser01' IDENTIFIED BY '******';
  obclient> ALTER USER 'sqluser01' IDENTIFIED BY '******';
  ```

* Run the following command to specify the authentication plugin.

  ```sql
  obclient> ALTER USER 'sqluser01'
  IDENTIFIED WITH mysql_native_password
             AS '*6C8989366EAF75BB670AD8EA7A7FC1176A95CEF4';
  ```

* Lock the user `obsqluser01`.

  ```sql
  obclient> CREATE USER 'obsqluser01'
  IDENTIFIED BY '******';
  obclient> ALTER USER 'obsqluser01' ACCOUNT LOCK;
  ```

* Unlock the user `obsqluser01`.

  ```sql
  obclient> ALTER USER 'obsqluser01' ACCOUNT UNLOCK;
  ```

* Specify that when user `user001` logs in, the `role001` and `role002` roles granted to the user are activated by default.

  ```sql
  obclient> CREATE USER user001 IDENTIFIED BY '******';
  -- Ensure that the roles `role001` and `role002` already exist.
  obclient> ALTER USER user001 DEFAULT ROLE role001, role002;
  ```

* Modify user resource options. First, create the user `user001`, then modify its maximum number of connections.

  ```sql
  obclient> ALTER USER user001 WITH MAX_USER_CONNECTIONS 30;
  ```

* Modify the maximum number of connections per hour for user `user001`.

  ```sql
  obclient> ALTER USER user001 WITH MAX_CONNECTIONS_PER_HOUR 50;
  ```

* Modify the maximum number of connections and the maximum number of connections per hour for user `user001`.

  ```sql
  obclient> ALTER USER user001 WITH MAX_USER_CONNECTIONS 300 MAX_CONNECTIONS_PER_HOUR 500;
  ```
