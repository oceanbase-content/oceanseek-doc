# PURGE RECYCLEBIN

## Purpose

This statement is used to empty the recycle bin.

  <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p><code>PURGE RECYCLEBIN</code> clears all database objects from the recycle bin. Only the root user can execute this statement. Exercise caution when using it.</p>
  </main>

## Syntax

```sql
PURGE RECYCLEBIN
```

## Examples

Empty Recycle Bin:

```sql
obclient> PURGE RECYCLEBIN;
```
