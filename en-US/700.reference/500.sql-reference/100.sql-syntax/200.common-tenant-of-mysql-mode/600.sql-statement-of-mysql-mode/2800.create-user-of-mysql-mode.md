# CREATE USER

## Description

The `CREATE USER` statement is used to create a new OceanBase AI database user. After creating a new user, you can use the new user to connect to OceanSeek.

## Privilege requirements

To execute the `CREATE USER` statement, you must have the global CREATE USER privilege. For more information about OceanBase AI database privileges, see [Permission classification](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md).

## Syntax

```sql
CREATE USER [IF NOT EXISTS] {user [, user...]}
    [REQUIRE {NONE | SSL | X509 | tls_option}]
    [WITH resource_option [resource_option...]];

user:
      user_name
    | user_name IDENTIFIED [WITH auth_plugin] BY password
    | user_name IDENTIFIED [WITH auth_plugin] BY PASSWORD password
    | user_name IDENTIFIED [WITH auth_plugin] AS PASSWORD 'auth_string'

tls_option:
      CIPHER cipher_name
    | ISSUER issuer_name
    | SUBJECT subject_name

resource_option:
      MAX_CONNECTIONS_PER_HOUR integer
    | MAX_USER_CONNECTIONS integer
```

## Parameters

| Parameter | Description |
| ------- | ----------- |
| IF NOT EXISTS | It indicates that if the username already exists, the user will not be created. When creating a user, if the specified username already exists and the `IF NOT EXISTS`, an error will be reported. |
| user_name | Username. After the user is created, a new row for the user is added to the `mysql.user` table. When creating multiple users at the same time, separate the names with commas (`,`). |
| auth_plugin | Specifies the user authentication method. Currently, only `mysql_native_password` Authentication plugins. |
| IDENTIFIED BY password | Create a password for the user to be created. The password is stored in plaintext here. `mysql.user` After the table, the password is stored as ciphertext on the server side. If the password contains special characters <code>~!@#%^&*_-+=&#96;\| (){}[]:;',.?/</code> must be enclosed in English quotation marks (<code>'</code> or <code>"</code>). |
| IDENTIFIED BY PASSWORD password | Create a password for the user to be created. The password is stored in ciphertext format and will be directly stored in the database. `mysql.user` Table. |
| IDENTIFIED AS PASSWORD | Set the account authentication plugin to `auth_plugin` and store the `auth_string` value in the `mysql.user` table. If the plugin requires a hash string, it is assumed that the string is already in the hash format required by the plugin. |
| REQUIRE | Specifies the password verification requirements for a user. Valid values: <ul><li>NONE: No password verification is required. The user can use any password or no password at all.</li><li>SSL: The user must use an SSL connection for authentication.</li><li>X509: The user must use an X509 certificate for authentication.</li><li>tls_option: The user must meet specified Transport Layer Security (TLS) requirements.</li></ul> |
| tls_option | Specifies the specific options for TLS requirements. <ul><li>CIPHER: Specifies the encryption algorithm or cipher suite used for the TLS connection.</li><li>ISSUER: Specifies the issuer of the TLS certificate.</li><li>SUBJECT: Specifies the subject of the TLS certificate.</li></ul> |
| resource_option | Resource options for a specified user. Separate multiple resource options with spaces.<ul><li>MAX_CONNECTIONS_PER_HOUR: the maximum number of connections allowed per hour. integer specifies the maximum number of connections allowed.</li><li>MAX_USER_CONNECTIONS: the maximum number of connections allowed per user. integer specifies the maximum number of connections allowed.</li></ul> |

## Examples

* Create users test1 and test2, specify their plaintext passwords, and set the maximum number of connections allowed per user.

  ```sql
  obclient> CREATE USER IF NOT EXISTS test1 IDENTIFIED BY '********', test2 IDENTIFIED BY '********' WITH MAX_USER_CONNECTIONS 10;
  ```

* Create a user named test3, specify a ciphertext password, and require SSL connection authentication.

  ```sql
  obclient> CREATE USER IF NOT EXISTS test3 IDENTIFIED BY PASSWORD '********' REQUIRE SSL;
  ```

* Create a user named test4 and specify to use the mysql_native_password authentication plugin.

  ```sql
  obclient> CREATE USER IF NOT EXISTS test4 IDENTIFIED WITH mysql_native_password BY PASSWORD '********';
  ```
