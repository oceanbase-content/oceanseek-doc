# LOAD INDEX INTO CACHE

## Purpose

This statement is used to load indexes into the cache to improve query performance. It can load multiple indexes into the cache at once, rather than loading each index individually. This reduces system overhead during index loading and improves overall performance.

## Syntax

```sql
LOAD INDEX INTO CACHE tbl_index_list [, tbl_index_list ...];

tbl_index_list:
    tbl_name [PARTITION (partition_list)] [{INDEX|KEY} (index_name[, index_name ...])] [IGNORE LEAVES]

partition_list:
    partition_name [, partition_name ...]
    | ALL
```
