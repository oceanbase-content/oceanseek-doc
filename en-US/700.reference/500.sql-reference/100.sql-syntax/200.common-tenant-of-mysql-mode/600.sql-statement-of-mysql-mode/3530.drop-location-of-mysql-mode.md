# DROP LOCATION

## Purpose

This statement is used to drop a location object.

## Privilege requirements

To execute the `DROP LOCATION` statement, the current user must have the `CREATE LOCATION` privilege. For more information about OceanBase AI database privileges, see [Permission classification](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md).

## Syntax

```sql
DROP LOCATION location_name;
```

## Parameters

| **Parameters** | **Description** |
| --------------- | ---------- |
| location_name | The name of the Location object to be deleted. |

## Examples

Delete the `test_location_local` Location object.

```shell
obclient> DROP LOCATION test_location_local;
```
