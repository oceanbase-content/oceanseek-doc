# DROP EVENT

This statement is used to drop an event.

## Syntax

```sql
DROP EVENT [IF EXISTS] event_name
```

## Parameters

| Parameter | Description |
| ------- | ----------- |
| event_name | Specifies the name of the event to be deleted. |

## Examples

```shell
obclient> DROP EVENT myevent;
```
