# FLUSH TABLE

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>The current version only supports this keyword syntax; the feature does not take effect.</p>
</main>

## Purpose

This statement is used to clean up or refresh specific internal caches, logs, and tables.

## Syntax

```sql
FLUSH [NO_WRITE_TO_BINLOG | LOCAL] { tables_option }

tables_option: {
    table_synonym
  | table_synonym tbl_name [, tbl_name] ...
  | table_synonym WITH READ LOCK
  | table_synonym tbl_name [, tbl_name] ... WITH READ LOCK
  | table_synonym tbl_name [, tbl_name] ... FOR EXPORT
}

table_synonym: {
    TABLE
  | TABLES
}
```

## Usage instructions

When the tenant-level hidden parameter `_enable_mock_stmt_flush_table` is enabled, the `FLUSH TABLE` statement executes without returning an error. When this parameter is disabled, the statement returns an `NOT SUPPORT` error.

You can run the following command to open this parameter:

```sql
ALTER SYSTEM SET _enable_mock_stmt_flush_table = true;
```
