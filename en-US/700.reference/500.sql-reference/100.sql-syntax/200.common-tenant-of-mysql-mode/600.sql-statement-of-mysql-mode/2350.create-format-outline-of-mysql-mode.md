# CREATE FORMAT OUTLINE

## Purpose

This statement is used to create a fuzzy outline. You can create a fuzzy outline in two ways: one is by using `FORMAT_SQL_TEXT` (the original parameterized statement executed by the user), and the other is by using `FORMAT_SQL_ID`.

## Limitations and considerations

* Outlines must be created under the corresponding user.

* When `FORMAT_SQL_ID` is the same, an outline created by using the `FORMAT_SQL_TEXT` method will overwrite an outline created by using the `FORMAT_SQL_ID` method. The `FORMAT_SQL_TEXT` method has a higher priority. Furthermore, OceanBase AI Database uses `FORMAT_SQL_ID` to distinguish different SQL statements, and `FORMAT_SQL_ID` is obtained by applying `MD5` encryption to `FORMAT_SQL_TEXT`. In a production system, it is recommended to bind outlines using `FORMAT_SQL_ID`.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p><ul><li>The matching rules of <code>FORMAT_SQL_TEXT</code> ignore the parameter content, case, and non-syntactic symbols such as spaces and line breaks. It only compares the text content after these preprocessing steps.</li><li><code>FORMAT_SQL_ID</code> is generated by formatting <code>FORMAT_SQL_TEXT</code> (removing extra spaces and line breaks, and converting all characters to uppercase or lowercase uniformly), and then applying <code>MD5</code> hash encryption to the formatted result.</li></ul></p>
  </main>

## Syntax

```sql
/*Use FORMAT_SQL_TEXT to create an outline*/
CREATE [OR REPLACE] FORMAT OUTLINE outline_name ON format_stmt [ TO format_target_stmt ]

/*Use FORMAT_SQL_ID to create an outline.*/
CREATE [OR REPLACE] FORMAT OUTLINE outline_name ON format_sql_id USING HINT hint;
```

## Parameters

| Parameter | Description |
| ---------------------- | ---------------------------- |
| outline_name | Specify the name of the fuzzy outline to be created. |
| OR REPLACE | If specified, `OR REPLACE`, and the Outline to be created already exists, the existing Outline will be replaced. |
| format_stmt | Specifies the original SQL text, which is the SQL statement or operation for which you want to apply an outline. <main id="notice" type='explain'><h4>Note</h4><p>OceanBase AI Database automatically processes unformatted SQL text into formatted SQL text.</p></main> |
| TO format_target_stmt | Optional. Optional. Specifies the target SQL statements to which `format_stmt` is converted or applied. That is, to make the outline applicable to other SQL statements, you can use the TO format_target_stmt option to declare these SQL statements. <main id="notice" type='notice'><h4>Notice</h4><p><ul><li>To fix the plan for statements containing hints, use <code>format_target_stmt</code> to specify the original SQL.</li><li>When using the <code>TO format_target_stmt</code> clause, the original SQL <code>format_stmt</code> and <code>format_target_stmt</code> must match after removing hints and applying formatting.</li></ul></p></main> |
| format_sql_id | The SQL statement to be bound, which has been rewritten according to a series of rules `format_stmt`, and then based on `format_stmt` Calculate `MD5` Obtained from the value of `format_sql_id`. |

## Examples

* Use `FORMAT_SQL_TEXT` to create an outline.

  ```sql
  CREATE FORMAT OUTLINE my_outline ON SELECT * FROM employees WHERE department_id = ?;
  ```

* Use `FORMAT_SQL_ID` to create an outline.

  ```sql
  CREATE FORMAT OUTLINE my_sql_id_outline ON 'ED570339F2C856BA96008A29EDF04C74' USING HINT /*+ index(t1 idx_c2)*/;

  ```
