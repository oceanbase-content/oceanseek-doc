# SET TRANSACTION

## Purpose

Sets the transaction isolation level.

OceanBase AI Database supports two isolation levels: Read Committed and Repeatable Read. The default isolation level is Read Committed.

* The isolation level cannot be set during transaction execution; otherwise, an error will be reported.

  `ERROR:OBE-01453: SET TRANSACTION must be first statement of transaction`

* When the serializable isolation level is enabled, you must ensure that the Global Timestamp Service (GTS) is enabled.

* The session maintains a session-level transaction isolation level. This isolation level is obtained when a transaction starts and can be overridden by a transaction-level isolation level.

## Syntax

```sql
SET [GLOBAL | SESSION | LOCAL] TRANSACTION trans_opt

trans_opt:
   transaction_access_mode
 | isolation_level
 | transaction_access_mode, isolation_level
 | isolation_level, transaction_access_mode

transaction_access_mode:
    [READ ONLY | READ WRITE]

isolation_level:
    ISOLATION LEVEL {
      READ UNCOMMITTED
    | READ COMMITTED
    | REPEATABLE READ
    | SERIALIZABLE
  }
```

## Parameters

| Parameter | Description |
| ---------------- | -------------- |
| GLOBAL \ \| SESSION \ \| LOCAL | Specifies the scope of the transaction isolation level. The default value is empty. <ul><li>`GLOBAL`: Applies to all subsequent sessions. The current session is not affected.   </li><li> `SESSION \| LOCAL`: Applies to all subsequent transactions in the current session, without affecting ongoing transactions. If executed between transactions, this statement will override any previously set transaction-specific values for the named feature.   </li><li> No declaration: Applies to the next individual transaction executed in the session, after which subsequent transactions will revert to using the session-level values for the named feature.</li></ul> |
| READ ONLY \ \| READ WRITE | Specifies the read and write modes of a transaction. |
| READ UNCOMMITTED | Specifies the transaction isolation level as Read Uncommitted.<br> **Note**  The current version does not support setting the transaction isolation level to Read Uncommitted. |
| READ COMMITTED | Specify the transaction isolation level as Read Committed. |
| REPEATABLE READ | Specify the transaction isolation level as Repeatable Read. |
| SERIALIZABLE | Specifies the transaction isolation level as serializable.  <br>**Note**  OceanBase AI Database does not support setting the transaction isolation level for the sys tenant to serializable, because it is not possible to create a user tenant in the sys |

## Examples

* Sets the transaction isolation level for the next transaction in the current session to Read Committed.

  ```sql
  obclient> SET TRANSACTION ISOLATION LEVEL READ COMMITTED;
  ```

* Set the transaction isolation level of the current session to repeatable read.

  ```sql
  obclient> SET SESSION TRANSACTION ISOLATION LEVEL REPEATABLE READ;
  ```
