# SET CHARSET

## Purpose

This statement is used to set the client and result character sets.

## Syntax

```sql
SET {CHARSET | CHARACTER SET} {DEFAULT | charset_name}
```

## Parameters

| Parameter | Explanation |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| charset_name | Specify the client and result character sets. The following character sets are supported: <ul><li>`utf8`  </li> <li> `utf8mb4`   </li> <li> `gbk`   </li> <li> `utf16`   </li> <li> `gb18030`  </li></ul> |
| DEFAULT | Use the system default character set. |

## Examples

Set the client character set to `gbk`:

```sql
obclient> SET CHARSET 'gbk';
```

View character set-related variables:

```sql
obclient> SHOW VARIABLES LIKE '%char%';
```

The query result is as follows:

```sql
+--------------------------------------+---------+
| Variable_name                        | Value   |
+--------------------------------------+---------+
| character_set_client                 | gbk     |
| character_set_connection             | utf8mb4 |
| character_set_database               | utf8mb4 |
| character_set_filesystem             | binary  |
| character_set_results                | gbk     |
| character_set_server                 | utf8mb4 |
| character_set_system                 | utf8mb4 |
| validate_password_special_char_count | 0       |
+--------------------------------------+---------+
8 rows in set
```

Set the character set to the system default:

```sql
obclient> SET CHARSET DEFAULT;
```
