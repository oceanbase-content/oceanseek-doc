# CREATE ROLE

## Purpose

This statement is used to create a role. You can use roles to manage permissions.

## Privilege requirements

* The current user must have the `CREATE USER` or `CREATE ROLE` privilege to create a role. For more information about OceanBase AI database privileges, see [Permission classification](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md).

* If the value of the system variable `read_only` for the current tenant is `1`, meaning the tenant is in read-only mode, the current user must also have the `SUPER` privilege to execute the `CREATE ROLE` statement.

  The system variable `read_only` is used to set whether a tenant is in read-only mode. The default value is `0`, which indicates that the tenant is in read-write mode. For more information about the system variable `read_only`, see [read_only](../../../../800.configuration-items-and-system-variables/200.system-variable/300.global-system-variable/11100.read_only-global.md).

## Syntax

```sql
CREATE ROLE [IF NOT EXISTS] role_name [, role_name ...];
```

## Parameters

| **Parameters** | **Description** |
| ---------- | ---------- |
| IF NOT EXISTS | Optional. If this clause is specified, the system will issue a warning if the role to be created already exists in the current tenant, but no error will be returned. If this clause is not specified, an error will be returned. |
| role_name | Specifies the name of the role to be created. When creating multiple roles, separate the role names with commas (`,`). |

## Examples

* Create the role `role001`.

  ```sql
  obclient [test]> CREATE ROLE role001;
  ```

* Create the roles `role001` and `role002` simultaneously.

  ```sql
  obclient [test]> CREATE ROLE IF NOT EXISTS role001, role002;
  ```

  The return result is as follows:

  ```shell
  Query OK, 0 rows affected, 1 warning
  ```

  Use the `SHOW WARNINGS;` statement to query warning information. The return result is as follows:

  ```shell
  +-------+------+-----------------------------------------------+
  | Level | Code | Message                                       |
  +-------+------+-----------------------------------------------+
  | Note  | 3163 | Authorization ID 'role001'@'%' already exists |
  +-------+------+-----------------------------------------------+
  1 row in set
  ```
