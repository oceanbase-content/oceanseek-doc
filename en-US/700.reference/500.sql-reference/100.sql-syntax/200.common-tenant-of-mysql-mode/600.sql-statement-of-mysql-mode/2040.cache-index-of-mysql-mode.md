# CACHE INDEX

## Purpose

This statement is used to load the index of a specific database table into the cache to improve query performance. Once the index is loaded into the cache, queries can access the indexed data more quickly, thereby speeding up the query.

## Syntax

```sql
CACHE INDEX {
    tbl_index_list [, tbl_index_list ...]
    | tbl_name PARTITION (partition_list)
    }
    IN key_cache_name;

tbl_index_list:
    tbl_name [{INDEX|KEY} (index_name[, index_name ...])]

partition_list:
    partition_name [, partition_name ...]
    | ALL
```
