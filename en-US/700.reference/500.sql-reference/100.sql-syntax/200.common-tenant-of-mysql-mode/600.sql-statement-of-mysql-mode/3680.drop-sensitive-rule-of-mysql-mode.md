# DROP SENSITIVE RULE

## Description

This statement is used to drop a sensitive data protection rule.

## Privilege requirements

To execute the `DROP SENSITIVE RULE` statement, the current user must have the `CREATE SENSITIVE RULE` privilege. For more information about OceanBase AI database privileges, see [Permission classification](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md).

## Syntax

```sql
DROP SENSITIVE RULE rule_name
```

## Parameters

The specific parameters are described as follows:

| Parameter | Data type | Default Value | Description |
| -- | -- | -- | -- |
| rule_name | Character |  | The name of the sensitive rule, which must be unique within the tenant. |

The description is as follows:

* Rules take effect immediately after they are deleted.

The limitations are as follows:

* You can delete only one rule at a time.

## Examples

For example:

```sql
-- Delete sensitive rule r1
DROP SENSITIVE RULE r1;
```
