# ALTER EXTERNAL TABLE

## Purpose

This statement is used to manually update the files of an external table. Table data in a single file can be updated automatically, but if the external table data comes from a file list, automatic update is not possible and manual refresh is required.

## Syntax

```sql
ALTER EXTERNAL TABLE table_name REFRESH
```

## Parameters

`table_name` specifies the name of the external table to be flushed.

## Examples

```sql
-- To successfully execute this statement, you must ensure that the corresponding external table exists.
obclient> ALTER EXTERNAL TABLE lineitem REFRESH;
```
