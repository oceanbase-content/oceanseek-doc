# CANCEL JOB

Cancel an asynchronous task.

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p><ul><li>You must specify the <code>job_id</code> when executing <code>CANCEL JOB</code>.</li><li>Running tasks will be terminated, and tasks that have not started will not run.</li><li>For a task that has already finished running, executing <code>cancel job</code> will report the <code>ERROR 4018 (HY000): Entry not exist</code> error.</li><li>You can still view the job status after canceling it.</li></ul></p>
</main>

## Syntax

```sql
CANCEL JOB 'job_id';
```

## Examples

```shel
obclient> CANCEL JOB '2010011125899906847397';
3 rows in set (0.00 sec)
```
