# DROP CONCURRENT_LIMITING_RULE

## Purpose

This statement is used to drop a rate limiting rule.

## Privilege requirements

To execute the `DROP CONCURRENT_LIMITING_RULE` statement, the current user must have the DROP privilege. For more information about OceanBase AI database privileges, see [Permission classification](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md).

## Syntax

```sql
DROP CONCURRENT_LIMITING_RULE [ IF EXISTS ] `ccl_rule_name1` [, `ccl_rule_name2`, ...]
```

Here, `ccl_rule_name` indicates the name of the throttling rule.

## Examples

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>The deleted rate-limiting rule will immediately become invalid. All SQL statements in the queue waiting for execution under this rule will then be executed normally.</p>
</main>

Run the following command to drop the rate-limiting rules `sql1_keywords_ccl_rule` and `sql2_keywords_ccl_rule`:

```shell
obclient> DROP ONCURRENT_LIMITING_RULE `sql1_keywords_ccl_rule`,`sql2_keywords_ccl_rule`;
```
