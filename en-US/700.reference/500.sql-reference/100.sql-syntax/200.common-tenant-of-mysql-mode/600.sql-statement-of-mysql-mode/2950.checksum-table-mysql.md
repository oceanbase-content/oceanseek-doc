# CHECKSUM TABLE

This statement is used to obtain the checksum of a table. It calculates a unique numeric value based on the table's contents, which can be used to verify the consistency of the table data. Specifically, it can be used to check whether the same table is consistent across two databases, or to verify whether the table has changed over time.

## Syntax

```sql
CHECKSUM TABLE tbl_name [, tbl_name] ... [QUICK | EXTENDED]
```
