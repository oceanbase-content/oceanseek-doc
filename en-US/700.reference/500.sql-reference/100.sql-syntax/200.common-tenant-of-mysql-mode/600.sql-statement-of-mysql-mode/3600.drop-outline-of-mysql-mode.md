# DROP OUTLINE

## Purpose

This statement is used to drop an outline in OceanSeek.

## Syntax

```sql
DROP OUTLINE outline_name
DROP OUTLINE database_name.outline_name
```

## Parameters

| **Parameters** | **Description** |
| ------------------ | ---------------------------- |
| outline_name | Specifies the name of the outline to be deleted. |
| database_name | Optional. Specifies the name of the database to which the outline belongs. |

## Examples

* Drop the outline `olt_1` from the current database.

```sql
obclient> DROP OUTLINE olt_1;
```

* Drop an outline from a specified database.

```sql
obclient> DROP OUTLINE ol_db.olt_2;
```
