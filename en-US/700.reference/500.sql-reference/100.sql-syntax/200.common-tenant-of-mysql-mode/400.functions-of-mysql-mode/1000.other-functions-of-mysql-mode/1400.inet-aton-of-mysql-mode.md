# INET_ATON

## Declaration

```sql
INET_ATON(expr)
```

## Description

Converts an IPv4 network address into a string and returns an integer representing the address value in network byte order (big-endian). If the parameter is invalid, `NULL` is returned.

  <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>Use the <code>INT UNSIGNED</code> type to store values generated by <code>INET_ATON()</code>; do not use the signed <code>INT</code> type. If you use a signed column, the value cannot be stored correctly when the first octet of the IP address is greater than 127.</p>
  </main>

## Examples

```sql
obclient> SELECT INET_ATON('1.1.1.1');
+----------------------+
|  INET_ATON('1.1.1.1') |
+----------------------+
|             16843009 |
+----------------------+
1 row in set
```
