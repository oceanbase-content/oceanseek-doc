# INET6_NTOA

## Declaration

```sql
INET6_NTOA(expr)
```

## Description

Converts an IPv6 or IPv4 network address represented as a numeric value into a binary string that can be used as a character in a connection. If the parameter is not a valid address, `NULL` is returned.

The `INET6_NTOA()` function has the following properties:

* No system functions are used for conversion, so the output string is platform-independent.

* The maximum length of the returned string is 39 (4 x 8 + 7).

* The returned string uses lowercase letters to represent the IPv6 address.

## Examples

```sql
obclient> SELECT INET6_NTOA(INET6_ATON('fdfe::5a55:caff:fefa:9089'));
+------------------------------------------------------------+
|  INET6_NTOA(INET6_ATON('fdfe::5a55:caff:fefa:9089')) |
+------------------------------------------------------------+
|                            fdfe::5a55:caff:fefa:9089 |
+------------------------------------------------------------+
1 row in set
```
