# INET_NTOA

## Declaration

```sql
INET_NTOA(expr)
```

## Description

Converts a numeric representation of an IPv4 network address in network byte order into a string of dots-separated IP addresses, as a character in the connection character set. If the parameter is invalid, `NULL` is returned.

## Examples

```sql
obclient> SELECT INET_NTOA(16843009);
+---------------------+
| INET_NTOA(16843009) |
+---------------------+
| 1.1.1.1             |
+---------------------+
1 row in set
```
