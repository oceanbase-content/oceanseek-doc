# SLEEP

## Declaration

```sql
SLEEP(duration)
```

## Description

The `SLEEP` function pauses for the duration specified by `duration` seconds and returns `0` after the pause ends.

* If `SLEEP` is executed alone and not interrupted, the return result is `0`.

* If the `SLEEP` statement is interrupted while it is being executed alone, the result code `1` is returned, but no error code is returned.

* If `SLEEP` is part of a query and the query is interrupted during the pause, error code `ERROR 1317` is returned.

## Examples

```sql
obclient> SELECT SLEEP(1000);
+------------------+
| SLEEP(1000) |
+------------------+
|          0 |
+------------------+

obclient> SELECT SLEEP(1000);
+------------------+
| SLEEP(1000) |
+------------------+
|          1 |
+------------------+

obclient> SELECT 1 FROM t1 WHERE SLEEP(1000);
ERROR 1317 (70100): Query execution was interrupted
```
