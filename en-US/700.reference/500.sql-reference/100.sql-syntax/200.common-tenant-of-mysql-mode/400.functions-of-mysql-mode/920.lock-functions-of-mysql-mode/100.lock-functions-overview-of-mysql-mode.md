# Overview of Lock Functions

OceanSeek supports the following functions for lock operations, as shown in the table below.

| **Function Name** | **Description** |
| -------------- | ---------- |
| [GET_LOCK](200.get-lock-of-mysql-mode.md) | Acquires a named lock. |
| [IS_FREE_LOCK](300.is-free-lock-of-mysql-mode.md) | Whether the specified lock is idle. |
| [IS_USED_LOCK](400.is-used-lock-of-mysql-mode.md) | Specifies whether the lock is in use. |
| [RELEASE_ALL_LOCKS()](500.release-all-locks-of-mysql-mode.md) | Releases all locks held by the current session. |
| [RELEASE_LOCK](600.release-lock-of-mysql-mode.md) | Releases the specified lock. |

## Prerequisites

If you use a proxy to connect to the cluster, you must also enable the following proxy configuration:

```sql
ALTER PROXYCONFIG SET proxy_id = 1;
ALTER PROXYCONFIG SET client_session_id_version = 2;
ALTER PROXYCONFIG SET enable_single_leader_node_routing = false;
```

For more information about the proxy configuration, see [proxy_id](https://docs.oceanbase.com/odp/proxy_id), [client_session_id_version](https://docs.oceanbase.com/odp/client_session_id_version) and [enable_single_leader_node_routing](https://docs.oceanbase.com/odp/enable_single_leader_node_routing).
