# VALIDATE_PASSWORD_STRENGTH

## Declaration

```sql
VALIDATE_PASSWORD_STRENGTH(str)
```

## Description

Returns an integer indicating the strength of a specified password string. The return value ranges from 0 (weak) to 100 (strong). You can run the `SHOW VARIABLES LIKE 'validate_password%';` statement to view the system variables involved in password evaluation.

## Examples

```sql
obclient [test]> SELECT VALIDATE_PASSWORD_STRENGTH('ob$_@123');
+----------------------------------------------+
| VALIDATE_PASSWORD_STRENGTH('ob$_@123') |
+----------------------------------------------+
|                                          100 |
+----------------------------------------------+
1 row in set
```
