# RANDOM_BYTES

## Declaration

```sql
RANDOM_BYTES(len)
```

## Description

Returns a random binary string of length `len` bytes. The valid values for `len` are [1, 1024].

## Examples

```sql
obclient [test]> select RANDOM_BYTES(2);
+-----------------+
| RANDOM_BYTES(2) |
+-----------------+
| H              |
+-----------------+
1 row in set
```
