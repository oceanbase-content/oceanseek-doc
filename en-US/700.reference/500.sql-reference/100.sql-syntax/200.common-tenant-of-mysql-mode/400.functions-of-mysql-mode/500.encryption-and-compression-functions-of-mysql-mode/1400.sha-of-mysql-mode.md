# SHA

## Declaration

```sql
SHA(str)
```

## Description

Computes and returns the SHA-1 160-bit checksum of a given string, which is returned as a string of 40 hexadecimal digits. Equivalent to the `SHA1()` function.

## Examples

```sql
obclient [test]> SELECT SHA('OB');
+------------------------------------------+
| SHA('OB')                                |
+------------------------------------------+
| 29a6de2fd8618f31afb281a608c57995b7eb105d |
+------------------------------------------+
1 row in set
```
