# DECODE

## Declaration

```sql
DECODE(crypt_str,pass_str)
```

## Description

`DECODE()` uses `pass_str` as a password to decrypt the encrypted string `crypt_str` and returns the decrypted string.

## Examples

```sql
obclient> SELECT DECODE(ENCODE('secret','cry'), 'cry');
+---------------------------------------+
| DECODE(ENCODE('secret','cry'), 'cry') |
+---------------------------------------+
| secret                                |
+---------------------------------------+
1 row in set
```
