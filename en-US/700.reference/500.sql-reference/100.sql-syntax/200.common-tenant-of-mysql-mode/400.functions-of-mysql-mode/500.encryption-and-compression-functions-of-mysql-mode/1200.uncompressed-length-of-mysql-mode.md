# UNCOMPRESSED_LENGTH

## Declaration

```sql
UNCOMPRESSED_LENGTH(str)
```

## Description

Returns the length of a compressed string before it is compressed by using the [COMPRESS](../500.encryption-and-compression-functions-of-mysql-mode/300.compress-of-mysql-mode.md) function.

## Examples

```sql
obclient [test]> SELECT UNCOMPRESSED_LENGTH(COMPRESS('abc'));
+--------------------------------------+
| UNCOMPRESSED_LENGTH(COMPRESS('abc')) |
+--------------------------------------+
|                                    3 |
+--------------------------------------+
1 row in set
```
