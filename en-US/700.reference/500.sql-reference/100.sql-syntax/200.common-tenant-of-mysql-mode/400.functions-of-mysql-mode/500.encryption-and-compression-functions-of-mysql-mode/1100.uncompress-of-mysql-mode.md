# UNCOMPRESS

## Declaration

```sql
UNCOMPRESS(str)
```

## Description

Decompress a string compressed by the [COMPRESS](../500.encryption-and-compression-functions-of-mysql-mode/300.compress-of-mysql-mode.md) function.

## Examples

```sql
obclient [test]> SELECT UNCOMPRESS(COMPRESS('abc'));
+-----------------------------+
| UNCOMPRESS(COMPRESS('abc')) |
+-----------------------------+
| abc                         |
+-----------------------------+
1 row in set
```
