# ENHANCED_AES_DECRYPT

## Declaration

```sql
ENHANCED_AES_DECRYPT(cipher_text[, iv])
```

## Description

* This function is primarily used for column encryption, which is controlled by the `tde_method` parameter. For more information, see [tde_method](../../../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/7800.tde_method.md).

* The function requires the `DECRYPT` privilege.

* `cipher_text`: The ciphertext to be decrypted by AES.

* `[, iv]` is an optional parameter that specifies the initialization vector.

* The input parameter `cipher_text` of the decryption function `ENHANCED_AES_DECRYPT` must be a result generated by the `ENHANCED_AES_DECRYPT` function. Otherwise, a 4334 `OB_ERR_AES_DECRYPT` error is raised.

## Examples

The `SELECT` statement uses the decryption function to return the plaintext column.

```sql
-- Return Plaintext
SELECT ENHANCED_AES_DECRYPT(cipher_col) FROM tbl;
```

The ciphertext is directly compared with its corresponding plaintext, which is expected to return false. The ciphertext needs to be decrypted, or the plaintext needs to be encrypted, before comparison.

```sql
-- After decrypting cipher_col, the expected plaintext data '12345' cannot be matched. The index cannot be used.
SELECT ... FROM tbl WHERE ENHANCED_AES_DECRYPT(cipher_col) = '12345';
```
