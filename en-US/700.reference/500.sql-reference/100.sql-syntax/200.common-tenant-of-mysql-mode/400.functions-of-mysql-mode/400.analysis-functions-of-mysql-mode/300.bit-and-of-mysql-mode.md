# BIT_AND

## Declaration

```sql
BIT_AND(expr) OVER (analytic_clause)
```

## Description

Returns the bitwise AND of all bits in `expr`.

The result type depends on whether the function parameters are evaluated as binary strings or numbers. Binary string evaluation occurs when a parameter is of the binary string type and is not a hexadecimal literal, a bit literal, or a `NULL` literal. Otherwise, numerical computation occurs, converting the parameter value to an unsigned 64-bit integer if necessary.

If no matching rows are found, `BIT_AND()` returns a neutral value of the same length as the parameter values (with all bits set to 1). A `NULL` value does not affect the result unless all values are `NULL`. In that case, the result is a neutral value of the same length as the parameter values.

## Examples

```sql

INSERT INTO PRODUCT_INFORMATION VALUES ('102050', '2380', '750', '731');
```
