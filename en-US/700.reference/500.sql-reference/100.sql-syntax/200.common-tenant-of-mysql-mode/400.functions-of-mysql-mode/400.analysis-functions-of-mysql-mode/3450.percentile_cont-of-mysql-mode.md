# PERCENTILE_CONT

## Purpose

This function calculates the exact percentile of a specified column. It sorts the input column in ascending order and returns the corresponding interpolated value based on the given percentile (`percentile`).

## Limitations

The current version of `PERCENTILE_CONT` does not support the `DATETIME` data type.

## Syntax statement

```sql
PERCENTILE_CONT(expr, percentile)
```

## Parameters

* `expr`: The target column for which the percentile needs to be calculated. It must be a numeric type. For specific supported types, see [Supported types](#Supported%20types).

    <main id="notice" type='explain'>
      <h4>Note</h4>
      <p><code>PERCENTILE_CONT</code> automatically ignores <code>NULL</code> values in the input column.</p>
    </main>

* `percentile`: the specified percentile value, indicating the position of the target value in the data distribution. The value must be a floating-point constant in the range [0, 1].

### Supported types

* Integer types: `TINYINT`, `SMALLINT`, `MEDIUMINT`, `INT`/`INTEGER`, and `BIGINT`.
* Fixed-point types: `DECIMAL` and `NUMERIC`.
* Floating-point types: `FLOAT` and `DOUBLE`.
* Bit-Value type: `BIT`.

## Return type

The return type is the same as that of `expr`.

Returns a value that is at the specified percentile. If no input value lies exactly at the desired percentile, the result is calculated using linear interpolation between the two nearest input values.

## Examples

1. Create a test table named `test_tbl1` containing columns `col1` and `col2`.

   ```sql
   CREATE TABLE test_tbl1(col1 VARCHAR(10), col2 INT);
   ```

2. Insert test data into the `test_tbl1` table.

   ```sql
   INSERT INTO test_tbl1 VALUES
       ('A1', 80), ('A1', 100), ('A1', NULL),
       ('B1', 60), ('B1', 70), ('B1', 85),
       ('C1', 75), ('C1', 80), ('C1', 85), ('C1', 99);
   ```

3. Use `PERCENTILE_CONT` to calculate the median (i.e., the 50th percentile) for each category in column `col1`.

   ```sql
   SELECT col1, PERCENTILE_CONT(col2, 0.5)
   FROM test_tbl1
   GROUP BY col1;
   ```

   The return result is as follows:

   ```shell
   +------+----------------------------+
   | col1 | PERCENTILE_CONT(col2, 0.5) |
   +------+----------------------------+
   | A1   |                         90 |
   | B1   |                         70 |
   | C1   |                       82.5 |
   +------+----------------------------+
   3 rows in set
   ```
