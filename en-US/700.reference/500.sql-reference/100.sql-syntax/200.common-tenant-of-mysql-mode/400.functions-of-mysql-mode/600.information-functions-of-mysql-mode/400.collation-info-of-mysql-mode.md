# COLLATION

## Declaration

```sql
COLLATION(str)
```

## Description

Returns the lexicographical order of the string `str`.

You can execute the `SHOW COLLATION` statement to view the collations supported by OceanBase AI Database.

## Examples

```sql
obclient> SELECT COLLATION("oceanbase");
+------------------------+
| COLLATION("oceanbase") |
+------------------------+
| utf8mb4_general_ci     |
+------------------------+
1 row in set

obclient> SELECT COLLATION("oceanbase" COLLATE utf8mb4_bin);
+--------------------------------------------+
| COLLATION("oceanbase" COLLATE utf8mb4_bin) |
+--------------------------------------------+
| utf8mb4_bin                                |
+--------------------------------------------+
1 row in set
```
