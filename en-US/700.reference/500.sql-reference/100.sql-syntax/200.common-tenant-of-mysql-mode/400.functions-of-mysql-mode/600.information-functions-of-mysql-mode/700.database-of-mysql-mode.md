# DATABASE

## Declaration

```sql
DATABASE()
```

## Description

Returns the current database name in the utf8mb4 character set.

If the database is not specified by the `USE` statement, `NULL` is returned.

## Examples

Returns the current database name.

```sql
obclient> SELECT DATABASE();
+------------+
| DATABASE() |
+------------+
| oceanbase  |
+------------+
1 row in set
```
