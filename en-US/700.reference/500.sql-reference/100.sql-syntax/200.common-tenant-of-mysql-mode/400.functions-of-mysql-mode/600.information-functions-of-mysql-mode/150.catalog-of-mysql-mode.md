# CATALOG

## Declaration

```sql
CATALOG()
```

## Description

This function is used to view the current catalog environment. Its functionality is identical to that of the `CURRENT_CATALOG()` function.

## Examples

```shell
obclient> SELECT CATALOG();
```

The return result is as follows:

```shell
+-----------+
| CATALOG() |
+-----------+
| internal  |
+-----------+
1 row in set
```
