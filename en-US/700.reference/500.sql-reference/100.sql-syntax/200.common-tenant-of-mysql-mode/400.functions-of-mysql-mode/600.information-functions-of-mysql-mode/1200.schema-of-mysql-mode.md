# SCHEMA

## Declaration

```sql
SCHEMA()
```

## Description

Returns the name of the current schema. This function is a synonym for `DATABASE()`.

## Examples

The following example queries the current schema name.

```sql
obclient> SELECT SCHEMA();
+----------+
| SCHEMA() |
+----------+
| test     |
+----------+
1 row in set
```
