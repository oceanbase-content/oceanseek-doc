# VERSION

## Declaration

```sql
VERSION()
```

## Description

Returns the version number of the current OceanBase AI database that is compatible with MySQL, with the character set set to utf8mb4.

## Examples

```sql
obclient> SELECT VERSION();
+---------------------------+
| VERSION()                 |
+---------------------------+
| 5.7.25-OceanBase-v4.1.0.0 |
+---------------------------+
1 row in set
```
