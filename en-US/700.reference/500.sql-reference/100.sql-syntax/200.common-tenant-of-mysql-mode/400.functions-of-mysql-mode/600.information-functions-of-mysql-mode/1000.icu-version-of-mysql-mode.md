# ICU_VERSION

## Declaration

```sql
ICU_VERSION()
```

## Description

This function returns the version of the ICU library that supports regular expression operations.
OceanSeek uses International Components for Unicode (ICU) to support regular expressions. ICU provides full Unicode support and is multibyte-safe.

## Examples

```sql
obclient> SELECT ICU_VERSION();
+---------------+
| ICU_VERSION() |
+---------------+
| 69.1          |
+---------------+
1 row in set
```
