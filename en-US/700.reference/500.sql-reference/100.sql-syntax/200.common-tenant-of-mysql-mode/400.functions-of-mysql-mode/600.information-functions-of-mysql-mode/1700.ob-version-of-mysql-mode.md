# OB_VERSION

## Declaration

```sql
OB_VERSION()
```

## Description

Returns the version information of the current OceanBase AI database, with the character set being utf8mb4.

## Examples

```sql
obclient> SELECT OB_VERSION();
+--------------+
| OB_VERSION() |
+--------------+
| 4.1.0.0      |
+--------------+
1 row in set
```
