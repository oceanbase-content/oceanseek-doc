# Overview of Spatial Functions

Spatial functions are a set of functions provided in the OceanSeek system for specifically processing geospatial data. These functions enable users to perform complex spatial queries and analyses at the database level, allowing Geographic Information Systems (GIS) and other applications that rely on spatial data to store, query, and manipulate spatial data efficiently.

The following table describes the types of spatial functions supported by OceanSeek and their uses:

## Spatial function types

| Spatial Function Types | Description |
| ------------------------------------------ | -------------------------------------------------------------------- |
| [Create a geometric value function](150.create-a-geometry-function-of-mysql-mode.md) | Generates instances of geometric data types, such as points, lines, and polygons. |
| [Spatial operators](200.spatial-operation-functions-of-mysql-mode.md) | Provides functions for basic operations on geometric objects, such as addition, subtraction, and multiplication. |
| [Spatial relationship functions](300.spatial-relation-functions-of-mysql-mode.md) | Functions that determine the spatial relationship between two geometric objects, such as intersection, containment, and adjacency. |
| [Geometric property functions](400.geometry-attribute-functions-of-mysql-mode.md) | Functions for obtaining attributes of geometric objects, such as area, length, and boundary. |
| [Geometric format conversion functions](500.geometry-conversion-function-of-mysql-mode.md) | Functions for converting between geometric data formats, such as converting from WKB to WKT. |
| [Spatial analysis functions](600.spatial-analysis-function-of-mysql-mode.md) | Functions for performing complex spatial processing and analysis, such as buffer analysis, merging, and clipping. |
| [Spatial Constructors](700.spatial-constructor-function-of-mysql-mode.md) | Functions for creating new spatial data types and geometric shapes. |
| [Spatial accessor functions](800.spatial-accessor-function-of-mysql-mode.md) | Provides functions for accessing components of spatial data, such as the vertices of a polygon or the start point of a line. |
| [Spatial format conversion functions](900.spatial-format-conversion-function-of-mysql-mode.md) | It is used to convert between different spatial data representation formats, such as converting geometric objects to text or binary formats. |
|[Geometric Processing Functions](1000.spatial-processing-function-of-mysql-mode.md)|Performs various operations and transformations on spatial geometric objects, including shape modification, geometric relationship calculation, spatial query, and other types of spatial analysis.|
