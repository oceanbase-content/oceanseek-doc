# AUDIT_LOG_FILTER_REMOVE_USER

## Purpose

This function (expression) is used to remove the filter from the user.

## Syntax

```sql
AUDIT_LOG_FILTER_REMOVE_USER('user_name');
```

## Description

### Parameters

`user_name`: the username.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p><code>AUDIT_LOG_FILTER_REMOVE_USER</code> has the semantics of <code>DROP IF EXISTS</code>. Dropping non-existent objects will not cause an error.</p>
</main>

### Return value

The input expression must be a string constant, and the output is of the string type.

* When the DDL statement is executed successfully, the expression returns `OK`.
* When the DDL statement fails, the `SELECT` statement is still executed successfully, and the expression outputs an error message.

## Examples

Remove the filter from user `user001`.

```sql
SELECT AUDIT_LOG_FILTER_REMOVE_USER('user001');
```

The return result is as follows:

```shell
+-----------------------------------------+
| AUDIT_LOG_FILTER_REMOVE_USER('user001') |
+-----------------------------------------+
| OK                                      |
+-----------------------------------------+
1 row in set
```
