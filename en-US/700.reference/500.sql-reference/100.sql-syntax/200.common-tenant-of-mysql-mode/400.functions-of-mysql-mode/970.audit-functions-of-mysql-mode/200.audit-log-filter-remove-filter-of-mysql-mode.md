# AUDIT_LOG_FILTER_REMOVE_FILTER

## Purpose

This function (expression) is used to delete a filter.

## Syntax

```sql
AUDIT_LOG_FILTER_REMOVE_FILTER('filter_name');
```

## Description

### Parameters

`filter_name`: the name of the filter.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p><code>AUDIT_LOG_FILTER_REMOVE_FILTER</code> has the semantics of <code>DROP IF EXISTS</code>. Dropping non-existent objects will not cause an error.</p>
</main>

### Return value

The expression input must be a string constant, and the output is of the string type.

* When DDL is executed successfully, the expression returns `OK`.
* When DDL execution fails, the `SELECT` statement is still executed successfully, and the expression outputs an error message.

## Examples

Delete the `log_all` filter.

```sql
SELECT AUDIT_LOG_FILTER_REMOVE_FILTER('log_all');
```

The return result is as follows:

```shell
+-------------------------------------------+
| AUDIT_LOG_FILTER_REMOVE_FILTER('log_all') |
+-------------------------------------------+
| OK                                        |
+-------------------------------------------+
1 row in set
```
