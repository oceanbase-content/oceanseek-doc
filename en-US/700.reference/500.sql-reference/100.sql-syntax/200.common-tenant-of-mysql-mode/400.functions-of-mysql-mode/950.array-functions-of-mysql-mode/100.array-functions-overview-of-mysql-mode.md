# Overview of array functions

Array functions are a set of specialized functions provided in the OceanBase AI database system for processing array data. These functions enable users to perform complex array queries and analyses.

The following table describes the array functions supported by OceanBase Database and their purposes:

## Array functions

| Array Function Types | Description |
| ------------------------------------------ | -------------------------------------------------------------------- |
| [Array constructor](200.array-constructor-functions-of-mysql-mode.md) | A function for constructing a new array data type. |
| [Array comparison functions](300.array-decision-functions-of-mysql-mode.md) | A function that performs a logical operation on the input array data and returns a boolean value. |
| [Array output functions](500.array-output-functions-of-mysql-mode.md) | Output the input array data and return the output array data. |
| [Array functions](600.array-manipulation-functions-of-mysql-mode.md) | Performs basic operations on the input array data, such as adding elements, deleting elements, and searching for elements, and returns the array data after the operation. |
