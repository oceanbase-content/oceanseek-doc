## Aggregate functions

Aggregate functions perform calculations on a set of values and return a single value. Aggregate functions ignore null values. They are often used together with the `GROUP BY` clause in a `SELECT` statement.

All aggregate functions are deterministic. Whenever they are called with a given set of input values, they return the same value.

In aggregate functions of OceanSeek, only one value expression is allowed. For example, `COUNT(c1, c2)` is not supported; only `COUNT(c1)` is supported.

## Analytical functions

Analysis functions (also called window functions in some databases) are similar to aggregate functions in that they always operate on a set of rows. The difference is that an aggregate function can return only one row for a group, while an analysis function can return multiple rows for each group, with each row within the group being the result of a window-based calculation. Analysis functions can significantly optimize queries that require self-joins.

A "window", also known as a frame, in OceanSeek supports both `ROWS` and `RANGE` frame semantics. The former is based on physical row offsets, while the latter is based on logical value offsets.
