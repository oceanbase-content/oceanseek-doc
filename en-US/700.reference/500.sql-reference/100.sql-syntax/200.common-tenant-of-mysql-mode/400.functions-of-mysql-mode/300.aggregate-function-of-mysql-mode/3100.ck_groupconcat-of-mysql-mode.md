# GROUPCONCAT

## Declaration

```sql
GROUPCONCAT([DISTINCT] expr)
```

## Description

This function concatenates the values of multiple `expr` rows within a group into a single string. You can use `DISTINCT` to remove duplicates.

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>This is a ClickHouse-compatible function. It is disabled by default and must be enabled by setting the <code>sql_func_extension_mode</code> parameter. For more information, see <a href="../../../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/7470.sql_func_extension_mode.md">sql_func_extension_mode</a>.</p>
</main>

## Examples

1. Enable the ClickHouse extension function mode.

    ```shell
    obclient> ALTER SYSTEM SET sql_func_extension_mode = "ClickHouse";
    ```

2. Create the test table `test_tbl1`.

    ```shell
    obclient> CREATE TABLE test_tbl1 (col1 INT PRIMARY KEY, col2 INT, col3 VARCHAR(50));
    ```

3. Insert data into the `test_tbl1` table.

    ```shell
    obclient> INSERT INTO test_tbl1 VALUES
        (1, 1, 'X'),
        (2, 1, 'Y'),
        (3, 1, 'X'),
        (4, 2, 'M'),
        (5, 2, 'N');
    ```

4. Group by `col2` and use `GROUPCONCAT` to concatenate all distinct `col3` values into a single string.

    ```shell
    obclient> SELECT col2, GROUPCONCAT(DISTINCT col3)
        FROM test_tbl1
        GROUP BY col2;
    ```

    The return result is as follows:

    ```shell
    +------+----------------------------+
    | col2 | GROUPCONCAT(DISTINCT col3) |
    +------+----------------------------+
    |    2 | MN                         |
    |    1 | XY                         |
    +------+----------------------------+
    2 rows in set
    ```
