# UNIQ

## Declaration

```sql
UNIQ(expr)
```

## Description

This function is used to approximately count the number of distinct values in a column.

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>This is a ClickHouse-compatible function. It is disabled by default and must be enabled by setting the <code>sql_func_extension_mode</code> parameter. For more information, see <a href="../../../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/7470.sql_func_extension_mode.md">sql_func_extension_mode</a>.</p>
</main>

## Examples

1. Enable the ClickHouse extension function mode.

    ```shell
    obclient> ALTER SYSTEM SET sql_func_extension_mode = "ClickHouse";
    ```

2. Create a test table named `test_tbl1`.

    ```shell
    obclient> CREATE TABLE test_tbl1 (col1 INT PRIMARY KEY, col2 VARCHAR(50), col3 INT);
    ```

3. Insert data into the `test_tbl1` table.

    ```shell
    obclient> INSERT INTO test_tbl1 VALUES(1, 'a1', 6), (2, 'a2', 8), (3, 'a2', 8);
    ```

4. Use `UNIQ` to count the number of distinct values in column `col3`.

    ```shell
    obclient> SELECT UNIQ(col3) FROM test_tbl1;
    ```

    The return result is as follows:

    ```shell
    +------------+
    | UNIQ(col3) |
    +------------+
    |          2 |
    +------------+
    1 row in set
    ```
