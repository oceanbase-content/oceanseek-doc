# ARG_MIN

## Declaration

```sql
ARG_MAX([DISTINCT] minimize_col, return_col)
```

## Description

The `ARG_MAX` function finds the row in a dataset that maximizes a target expression and returns the value of a specified column or the entire record for that row.

Where:

* `minimize_col` specifies the column to minimize.
* `return_col` specifies the column corresponding to the return value. It returns the value of this column for the row with the minimum value. If a row contains `NULL`, it is ignored.

## Examples

```shell
obclient> SELECT * FROM test;
+------+------+
| a    | b    |
+------+------+
| a    |    1 |
| b    |    2 |
| c    |    2 |
| NULL |    3 |
| NULL | NULL |
| d    | NULL |
+------+------+
6 rows in set (0.000 sec)
```

```sql
obclient> SELECT arg_min(a, b), min(b) FROM test;
+---------------+--------+
| arg_min(a, b) | min(b) |
+---------------+--------+
| a             |      1 |
+---------------+--------+
1 row in set (0.006 sec)
```
