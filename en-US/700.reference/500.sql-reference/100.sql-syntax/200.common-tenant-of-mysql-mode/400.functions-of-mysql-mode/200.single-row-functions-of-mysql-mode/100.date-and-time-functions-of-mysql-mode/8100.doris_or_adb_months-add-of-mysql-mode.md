# MONTHS_ADD

## Declaration

```sql
MONTHS_ADD(date, months)
```

## Description

This function adds a specified number of months `months` to the date `date`.

## Supported data types

The `months_add` function in OceanSeek supports multiple time-related data types as inputs and determines the return type based on the input type. The specific correspondence is as follows:

* Input `DATE` to return a `DATE` type.
* Input `DATETIME` returns `DATETIME` type.
* Input `TIMESTAMP` returns `DATETIME` type.
* Input `VARCHAR` (a string that can be parsed as a date) returns `DATETIME` type.
* When `TIME` is input, the function returns a `DATETIME` value. For a `TIME` value, the function takes its year, month, and day parts as the current date and performs the calculation with the given number of months.

## Behavior description

* In OceanSeek, the `month_add` function returns `NULL` for invalid inputs instead of throwing an error.
* Supports the `TIME` data type, where the year, month, and day are set to the current time.
* Determines whether to allow calculations involving invalid dates based on the `ALLOW_INVALID_DATES` setting.
* When a single `SELECT` statement parameter is a string, it is uniformly converted to the `DATETIME` type before output.

Add 1 month to `2026-01-31`.

obclient> SELECT MONTHS_ADD('2026-01-31', 1);
