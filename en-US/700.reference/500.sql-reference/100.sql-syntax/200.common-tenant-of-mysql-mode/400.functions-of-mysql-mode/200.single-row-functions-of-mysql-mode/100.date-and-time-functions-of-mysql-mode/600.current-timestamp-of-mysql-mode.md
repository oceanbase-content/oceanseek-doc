# CURRENT_TIMESTAMP

## Declaration

```javascript
CURRENT_TIMESTAMP([scale])
```

## Description

Returns the date and time in the current timezone.

`scale` indicates the precision of the microsecond part. The valid values are integers from `0` to `6`, and the default value is `0`.

## Examples

```javascript
obclient> SELECT CURRENT_TIMESTAMP(6);
+----------------------------+
| CURRENT_TIMESTAMP(6)       |
+----------------------------+
| 2018-05-05 11:35:39.177764 |
+----------------------------+
1 row in set
```
