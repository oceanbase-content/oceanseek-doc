# TIME_TO_SEC

## Declaration

```sql
TIME_TO_SEC(time)
```

## Description

Converts the time type parameter `time` to seconds.

## Examples

```sql
obclient> SELECT TIME_TO_SEC('22:23:00');
+-------------------------+
| TIME_TO_SEC('22:23:00') |
+-------------------------+
|                   80580 |
+-------------------------+
1 row in set

obclient> SELECT TIME_TO_SEC('00:39:38');
+-------------------------+
| TIME_TO_SEC('00:39:38') |
+-------------------------+
|                    2378 |
+-------------------------+
1 row in set
```
