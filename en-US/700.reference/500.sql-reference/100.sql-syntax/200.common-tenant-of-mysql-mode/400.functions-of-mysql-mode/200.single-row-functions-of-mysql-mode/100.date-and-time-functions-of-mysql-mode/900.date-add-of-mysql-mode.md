# DATE_ADD

## Declaration

```sql
DATE_ADD(date, INTERVAL expr unit)
```

## Description

The DATE_ADD function adds a period of time to a specified date and returns the result.

The parameters are described as follows:

* `date`: the date and time base, which can be a date type, time type, or datetime type.

* `expr` indicates the time interval, which can be negative.

* `unit` indicates the time interval unit.

The following table lists all time interval units:

| unit | Type | Meaning | Format |
| ---------------------- | ---- | ------- | ----------------- |
| `MICROSECOND` | standalone | microsecond | `MICROSECONDS` |
| `SECOND` | standalone | Seconds | `SECONDS` |
| `MINUTE` | standalone | minutes | `MINUTES` |
| `HOUR` | standalone | Hour | `HOURS` |
| `DAY` | standalone | day | `DAYS` |
| `WEEK` | standalone | Week | `WEEKS` |
| `MONTH` | standalone | Month | `MONTHS` |
| `QUARTER` | standalone | Quarter | `QUARTERS` |
| `YEAR` | standalone | year | `YEARS` |
| `SECOND_MICROSECOND` | combination | Seconds to microseconds | `'SECONDS.MICROSECONDS'` |
| `MINUTE_MICROSECOND` | combination | minutes to microseconds | `'MINUTES:SECONDS.MICROSECONDS'` |
| `MINUTE_SECOND` | combination | Minutes to Seconds | `'MINUTES:SECONDS'` |
| `HOUR_MICROSECOND` | combination | hours to microseconds | `'HOURS:MINUTES:SECONDS.MICROSECONDS'` |
| `HOUR_SECOND` | combination | hours to seconds | `'HOURS:MINUTES:SECONDS'` |
| `HOUR_MINUTE` | combination | Hour to Minute | `'HOURS:MINUTES'` |
| `DAY_SECOND` | combination | Days to Seconds | `'DAYS HOURS:MINUTES:SECONDS'` |
| `DAY_MINUTE` | combination | Days to Minutes | `'DDAYSD HOURS:MINUTES'` |
| `DAY_HOUR` | combination | Day to Hour | `'DAYS HOURS'` |
| `YEAR_MONTH` | combination | Year to Month | `'YEARS-MONTHS'` |
