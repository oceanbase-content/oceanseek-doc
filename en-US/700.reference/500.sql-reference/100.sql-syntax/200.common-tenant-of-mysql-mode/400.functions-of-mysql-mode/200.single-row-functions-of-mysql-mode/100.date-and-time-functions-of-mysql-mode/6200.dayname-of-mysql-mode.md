# DAYNAME

## Declaration

```sql
DAYNAME(date)
```

## Description

Return the name of the weekday corresponding to the specified date.

## Examples

```sql
obclient> SELECT DAYNAME('2022-09-08');
+-----------------------+
| DAYNAME('2022-09-08') |
+-----------------------+
| Thursday              |
+-----------------------+
1 row in set
```
