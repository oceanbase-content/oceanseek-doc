# CURRENT_TIME

## Declaration

```javascript
CURRENT_TIME([scale])
```

## Description

Returns the current time without the date.

`scale` indicates the precision of the microsecond part. The valid values are integers from `0` to `6`, and the default value is `0`.

## Examples

```javascript
obclient> SELECT CURRENT_TIME(6);
+-----------------+
| CURRENT_TIME(6) |
+-----------------+
| 11:11:45.215311 |
+-----------------+
1 row in set
```
