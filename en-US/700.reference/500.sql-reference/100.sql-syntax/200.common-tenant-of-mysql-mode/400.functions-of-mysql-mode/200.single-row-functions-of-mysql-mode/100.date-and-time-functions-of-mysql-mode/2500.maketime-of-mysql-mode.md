# MAKETIME

## Declaration

```sql
MAKETIME(hour,minute,second)
```

## Description

Returns a time value specified in the `hour:minute:second` format, where `second` can include a decimal part.

## Examples

```sql
obclient> SELECT MAKETIME(12,15,30);
+--------------------+
| MAKETIME(12,15,30) |
+--------------------+
| 12:15:30.000000    |
+--------------------+
1 row in set
```
