# LOCALTIMESTAMP

## Declaration

```sql
LOCALTIMESTAMP([scale])
```

## Description

Returns the current date and time. The `scale` parameter specifies the precision of the microsecond part, with valid integer values from `0` to `6`. `LOCALTIMESTAMP` and `LOCALTIMESTAMP()` are synonyms for `NOW()`.

## Examples

```sql
obclient> SELECT LOCALTIMESTAMP,LOCALTIMESTAMP(0),LOCALTIMESTAMP(6);
+---------------------+---------------------+----------------------------+
| LOCALTIMESTAMP      | LOCALTIMESTAMP(0)   | LOCALTIMESTAMP(6)          |
+---------------------+---------------------+----------------------------+
| 2021-08-25 17:17:08 | 2021-08-25 17:17:08 | 2021-08-25 17:17:08.952508 |
+---------------------+---------------------+----------------------------+
1 row in set
```
