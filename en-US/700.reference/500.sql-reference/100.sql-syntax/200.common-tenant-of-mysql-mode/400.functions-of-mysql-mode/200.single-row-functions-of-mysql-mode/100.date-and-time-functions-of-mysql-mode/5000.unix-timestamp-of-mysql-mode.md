# UNIX_TIMESTAMP

## Declaration

```sql
UNIX_TIMESTAMP()
UNIX_TIMESTAMP(date)
```

## Description

* If the `date` parameter is not specified, the number of seconds elapsed from the current time to `'1970-01-01 00:00:00'` is returned. Time zone information must be taken into account.

* When the `date` parameter is specified, it returns the number of seconds elapsed from `'1970-01-01 00:00:00'` up to the specified time. Time zone information must be taken into account.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>The parameters of this function can be dates or times of the <code>DATE</code>, <code>DATETIME</code>, or <code>TIMESTAMP</code> type.</p>
</main>
