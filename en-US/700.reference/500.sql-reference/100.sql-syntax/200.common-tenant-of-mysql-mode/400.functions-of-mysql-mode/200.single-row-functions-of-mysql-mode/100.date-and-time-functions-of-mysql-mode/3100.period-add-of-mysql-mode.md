# PERIOD_ADD

## Declaration

```sql
PERIOD_ADD(P,N)
```

## Description

Add `N` months to the time period `P`, where `P` is in the format `YYMM` or `YYYYMM`.

The return value is in the format of `YYYYMM`.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>The <code>P</code> parameter cannot be of the <code>DATE</code> type, that is, it must not be a date value.</p>
  </main>

## Examples

```sql
obclient> SELECT PERIOD_ADD(200801,2);
+----------------------+
| PERIOD_ADD(200801,2) |
+----------------------+
|               200803 |
+----------------------+
1 row in set
```
