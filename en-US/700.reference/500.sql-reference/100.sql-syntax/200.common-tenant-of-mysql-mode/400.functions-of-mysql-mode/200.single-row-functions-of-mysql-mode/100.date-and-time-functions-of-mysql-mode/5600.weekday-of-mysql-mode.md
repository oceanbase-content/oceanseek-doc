# WEEKDAY

## Declaration

```sql
WEEKDAY(date)
```

## Description

Returns the day of the week for a date or datetime value.

## Examples

```sql
obclient> SELECT WEEKDAY('2021-07-16 00:00:00');
+--------------------------------+
| WEEKDAY('2020-07-16 00:00:00') |
+--------------------------------+
|                              5 |
+--------------------------------+
1 row in set
```
