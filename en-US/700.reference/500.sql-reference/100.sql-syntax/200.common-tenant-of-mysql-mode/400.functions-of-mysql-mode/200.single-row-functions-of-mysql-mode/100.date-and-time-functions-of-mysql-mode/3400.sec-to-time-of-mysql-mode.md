# SEC_TO_TIME

## Declaration

```sql
SEC_TO_TIME(seconds)
```

## Description

Returns the time type converted from `seconds`. The result is limited to the range of the `TIME` data type.

## Examples

```sql
obclient> SELECT SEC_TO_TIME(2378);
+-------------------+
| SEC_TO_TIME(2378) |
+-------------------+
| 00:39:38          |
+-------------------+
1 row in set

obclient> SELECT SEC_TO_TIME(2378) + 0;
+-----------------------+
| SEC_TO_TIME(2378) + 0 |
+-----------------------+
|                  3938 |
+-----------------------+
1 row in set
```
