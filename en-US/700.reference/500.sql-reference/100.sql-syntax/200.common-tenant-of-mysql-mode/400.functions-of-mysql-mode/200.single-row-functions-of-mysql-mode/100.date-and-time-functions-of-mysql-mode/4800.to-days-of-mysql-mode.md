# TO_DAYS

## Declaration

```javascript
TO_DAYS(date)
```

## Description

Returns the number of days corresponding to the specified `date`. The number of days refers to the number of days since `0000-01-01`.

## Examples

```javascript
obclient> SELECT TO_DAYS('2015-11-04'), TO_DAYS('20151104');
+-----------------------+---------------------+
| TO_DAYS('2015-11-04') | TO_DAYS('20151104') |
+-----------------------+---------------------+
|                736271 |              736271 |
+-----------------------+---------------------+
1 row in set
```
