# NOW

## Declaration

```javascript
NOW([scale])
```

## Description

Returns the current date and time, taking into account the time zone settings. This function is an alias for `CURRENT_TIMESTAMP()`.

`scale` indicates the precision of the microsecond part. The valid values are integers from `0` to `6`, and the default value is `0`.

## Examples

```sql
obclient> SELECT NOW(6);
+----------------------------+
| NOW(6)                     |
+----------------------------+
| 2021-07-20 16:30:54.816317 |
+----------------------------+
1 row in set
```
