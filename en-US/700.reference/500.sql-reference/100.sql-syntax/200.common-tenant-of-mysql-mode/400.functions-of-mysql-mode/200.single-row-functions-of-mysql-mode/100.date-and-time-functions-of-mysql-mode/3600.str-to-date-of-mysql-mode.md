# STR_TO_DATE

## Declaration

```javascript
STR_TO_DATE(str, format)
```

## Description

Use `format` to convert `str` to a `DATETIME`, `DATE`, or `TIME` value. The return type depends on which date and time parts `format` includes.

* If `str` or `format` is `NULL`, the function returns `NULL`.

* If `str` is not in a valid date format, the return value varies depending on the `sql_mode` setting:

  * `sql_mode` includes `NO_ZERO_IN_DATE`: Returns `NULL`.

  * `sql_mode` does not contain `NO_ZERO_IN_DATE`:

    * If `str` is of the INT type and `str` \< 0, return `0000-00-00 00:00:00` and issue a warning.

      ```sql
      obclient> SELECT STR_TO_DATE(-100,'%Y-%b-%D %r');
      +---------------------------------+
      | STR_TO_DATE(-100,'%Y-%b-%D %r') |
      +---------------------------------+
      | 0000-00-00 00:00:00             |
      +---------------------------------+
      1 row in set, 1 warning
      ```

    * If `str` is of the INT type and 0 ≤ `str` ≤ 69, then return `1999-11-30 00:00:00` plus the year of `str`;

      ```sql
      obclient> SELECT STR_TO_DATE(0,'%Y-%b-%D %r');
      +------------------------------+
      | STR_TO_DATE(0,'%Y-%b-%D %r') |
      +------------------------------+
      | 1999-11-30 00:00:00          |
      +------------------------------+
      1 row in set
      ```

    * If `str` is of the INT type and 69 \< `str` ≤ 99, return `1969-11-30 00:00:00` plus the year of `str` minus 70.

      ```sql
      obclient> SELECT STR_TO_DATE(88,'%Y-%b-%D %r');
      +-------------------------------+
      | STR_TO_DATE(88,'%Y-%b-%D %r') |
      +-------------------------------+
      | 1987-11-30 00:00:00           |
      +-------------------------------+
      1 row in set
      ```

    * If `str` is of the INT type and 100 \< `str` ≤ 9999, return `0099-11-30 00:00:00` plus the year of `str` minus 100.

      ```sql
      obclient> SELECT STR_TO_DATE(2088,'%Y-%b-%D %r');
      +---------------------------------+
      | STR_TO_DATE(2088,'%Y-%b-%D %r') |
      +---------------------------------+
      | 2087-11-30 00:00:00             |
      +---------------------------------+
      1 row in set
      ```

    * If `str` is of the INT type and `str` > 10,000, return `NULL` and issue a warning.

      ```sql
      obclient> SELECT STR_TO_DATE(10001,'%Y-%b-%D %r');
      +----------------------------------+
      | STR_TO_DATE(10001,'%Y-%b-%D %r') |
      +----------------------------------+
      | NULL                             |
      +----------------------------------+
      1 row in set, 1 warning
      ```

    * If `str` is a string, it will be converted to a date and time as much as possible. The result is a date and time of the type `1999-11-30 00:00:00` plus `str`. If conversion to a date and time is not possible, `NULL` is returned.

      ```sql
      obclient> SELECT STR_TO_DATE('a2014-Jan-1st 5:5:5 pm', '%Y-%b-%D %r');
      +------------------------------------------------------+
      | STR_TO_DATE('a2014-Jan-1st 5:5:5 pm', '%Y-%b-%D %r') |
      +------------------------------------------------------+
      | NULL                                                 |
      +------------------------------------------------------+
      1 row in set, 1 warning

      obclient> SELECT STR_TO_DATE('a2014-Jan-1st 5:5:5 pm', 'a%Y-%b-%D %r');
      +-------------------------------------------------------+
      | STR_TO_DATE('a2014-Jan-1st 5:5:5 pm', 'a%Y-%b-%D %r') |
      +-------------------------------------------------------+
      | 2014-01-01 05:05:05                                   |
      +-------------------------------------------------------+
      1 row in set
      ```

    * If `str` is of another type, return `NULL` and issue a warning.

      ```sql
      obclient> SELECT STR_TO_DATE(1.6,'%Y-%b-%D %r');
      +--------------------------------+
      | STR_TO_DATE(1.6,'%Y-%b-%D %r') |
      +--------------------------------+
      | NULL                           |
      +--------------------------------+
      1 row in set, 1 warning

      obclient> SELECT STR_TO_DATE(pi(),'%Y-%b-%D %r');
      +---------------------------------+
      | STR_TO_DATE(pi(),'%Y-%b-%D %r') |
      +---------------------------------+
      | NULL                            |
      +---------------------------------+
      1 row in set, 1 warning
      ```

For more information about the formats supported by `FORMAT`, see [DATE_FORMAT](../100.date-and-time-functions-of-mysql-mode/1000.date-format-of-mysql-mode.md).

## Examples

```javascript
obclient> SELECT STR_TO_DATE('2014-Jan-1st 5:5:5 pm', '%Y-%b-%D %r');
+-----------------------------------------------------+
| STR_TO_DATE('2014-Jan-1st 5:5:5 pm', '%Y-%b-%D %r') |
+-----------------------------------------------------+
| 2014-01-01 05:05:05                                 |
+-----------------------------------------------------+
1 row in set
```
