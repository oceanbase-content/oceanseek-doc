# WEEKOFYEAR

## Declaration

```sql
WEEKOFYEAR(date)
```

## Description

Returns the position of the week specified by the date type `date` within a year.

## Examples

```sql
obclient> SELECT WEEKOFYEAR('2020-07-16');
+--------------------------+
| WEEKOFYEAR('2020-07-16') |
+--------------------------+
|                       29 |
+--------------------------+
1 row in set
```
