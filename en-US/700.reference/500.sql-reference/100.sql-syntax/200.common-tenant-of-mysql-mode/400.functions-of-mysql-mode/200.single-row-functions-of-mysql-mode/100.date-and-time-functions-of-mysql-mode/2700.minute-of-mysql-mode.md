# MINUTE

## Declaration

```sql
MINUTE(time)
```

## Description

Returns the number of minutes in the `time` field.

## Examples

```sql
obclient> SELECT MINUTE('18:20:17');
+--------------------+
| MINUTE('18:20:17') |
+--------------------+
|                 20 |
+--------------------+
1 row in set
```
