# SYSDATE

## Declaration

```sql
SYSDATE(fsp)
```

## Description

Returns the current date and time in the format `%Y-%m-%d %H.%i.%s`.

`fsp` indicates the second-precision, which specifies the number of digits in the fractional part of the return value. The valid values are integers from 0 to 6, and the default value is 0.

## Examples

```sql
obclient> SELECT SYSDATE();
+---------------------+
| SYSDATE()           |
+---------------------+
| 2021-07-15 14:10:06 |
+---------------------+
1 row in set
```
