# LOCALTIME

## Declaration

```sql
LOCALTIME
LOCALTIME([scale])
```

## Description

Returns the current date and time. `LOCALTIME` and `LOCALTIME()` are synonyms for `NOW()`.

`scale` indicates the precision of the microsecond part. The valid values are integers from `0` to `6`, and the default value is `0`.

## Examples

```sql
obclient> SELECT LOCALTIME(0);
+---------------------+
| LOCALTIME(0)        |
+---------------------+
| 2021-08-25 17:20:31 |
+---------------------+
1 row in set

obclient> SELECT LOCALTIME(6);
+----------------------------+
| LOCALTIME(6)               |
+----------------------------+
| 2021-08-25 17:20:41.358574 |
+----------------------------+
1 row in set
```
