# CURDATE

## Declaration

```javascript
CURDATE()
```

## Description

Returns the current date without the time part.

## Examples

```javascript
obclient> SELECT CURDATE();
+------------+
| CURDATE()  |
+------------+
| 2018-05-05 |
+------------+
1 row in set
```
