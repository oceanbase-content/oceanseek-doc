# DAYOFYEAR

## Declaration

```sql
DAYOFYEAR(date)
```

## Description

Returns the position of a given date `date` in a year.

## Examples

```sql
obclient> SELECT DAYOFYEAR('2021-07-15');
+-------------------------+
| DAYOFYEAR('2021-07-15') |
+-------------------------+
|                     196 |
+-------------------------+
1 row in set
```
