# DAYOFWEEK

## Declaration

```sql
DAYOFWEEK(date)
```

## Description

Returns the weekday of the date `date`, calculated from Sunday.

## Examples

```sql
obclient> SELECT DAYOFWEEK('2021-07-15');
+-------------------------+
| DAYOFWEEK('2021-07-15') |
+-------------------------+
|                       5 |
+-------------------------+
1 row in set
```
