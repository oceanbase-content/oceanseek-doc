# TO_SECONDS

## Declaration

```sql
TO_SECONDS(expr)
```

## Description

Returns the number of seconds elapsed since the year 0 AD for a time or datetime expression `expr`. If `expr` is `NULL`, `NULL` is returned.

## Examples

```sql
obclient> SELECT TO_SECONDS(950501);
+--------------------+
| TO_SECONDS(950501) |
+--------------------+
|        62966505600 |
+--------------------+
1 row in set

obclient> SELECT TO_SECONDS('2021-07-15');
+--------------------------+
| TO_SECONDS('2021-07-15') |
+--------------------------+
|              63793526400 |
+--------------------------+
1 row in set
```
