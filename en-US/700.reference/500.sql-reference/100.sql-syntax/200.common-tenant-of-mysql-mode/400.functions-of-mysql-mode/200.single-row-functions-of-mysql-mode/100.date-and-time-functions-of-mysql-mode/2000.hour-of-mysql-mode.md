# HOUR

## Declaration

```sql
HOUR(time)
```

## Description

Returns the hour value of the `time` type.

## Examples

```sql
obclient> SELECT HOUR('10:05:03');
+------------------+
| HOUR('10:05:03') |
+------------------+
|               10 |
+------------------+
1 row in set

obclient> SELECT HOUR('272:59:59');
+-------------------+
| HOUR('272:59:59') |
+-------------------+
|               272 |
+-------------------+
1 row in set
```
