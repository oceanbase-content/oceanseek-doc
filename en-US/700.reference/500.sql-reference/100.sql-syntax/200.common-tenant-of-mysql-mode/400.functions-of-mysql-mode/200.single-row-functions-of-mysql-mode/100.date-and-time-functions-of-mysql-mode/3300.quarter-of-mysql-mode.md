# QUARTER

## Declaration

```sql
QUARTER(date)
```

## Description

Returns the quarter value for a specified date, with a range of \[1,4\].

## Examples

```sql
obclient> SELECT QUARTER(NOW()), NOW();
+----------------+---------------------+
| QUARTER(NOW()) | NOW()               |
+----------------+---------------------+
|              3 | 2021-07-12 19:45:01 |
+----------------+---------------------+
1 row in set
```
