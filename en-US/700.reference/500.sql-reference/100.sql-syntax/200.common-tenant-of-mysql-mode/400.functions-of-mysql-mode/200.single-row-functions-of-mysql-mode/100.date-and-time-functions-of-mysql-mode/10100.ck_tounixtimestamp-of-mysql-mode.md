# TOUNIXTIMESTAMP

## Declaration

```sql
TOUNIXTIMESTAMP(datetime)
```

## Description

This function converts a datetime expression `datetime` to a Unix timestamp (the number of seconds since '1970-01-01 00:00:00' UTC). If the parameter is of type `DATE`, the time part defaults to midnight (00:00:00).

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>This is a ClickHouse-compatible function. It is disabled by default and must be enabled by setting the <code>sql_func_extension_mode</code> parameter. For more information, see <a href="../../../../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/7470.sql_func_extension_mode.md">sql_func_extension_mode</a>.</p>
</main>

## Examples

1. Enable the ClickHouse extension function mode.

    ```shell
    obclient> ALTER SYSTEM SET sql_func_extension_mode = "ClickHouse";
    ```

2. Returns an integer timestamp.

    ```shell
    obclient> SELECT TOUNIXTIMESTAMP('2026-03-30 12:00:00');
    ```

    The return result is as follows:

    ```shell
    +----------------------------------------+
    | TOUNIXTIMESTAMP('2026-03-30 12:00:00') |
    +----------------------------------------+
    |                             1774843200 |
    +----------------------------------------+
    1 row in set
    ```

3. Returns the Unix timestamp for 0:00 on the current day.

    ```shell
    obclient> SELECT TOUNIXTIMESTAMP(DATE '2026-03-30');
    ```

    The return result is as follows:

    ```shell
    +------------------------------------+
    | TOUNIXTIMESTAMP(DATE '2026-03-30') |
    +------------------------------------+
    |                         1774800000 |
    +------------------------------------+
    1 row in set
    ```
