# SECOND

## Declaration

```sql
SECOND(time)
```

## Description

Return the number of seconds in the `time` field.

## Examples

```sql
obclient> SELECT SECOND('18:20:17');
+--------------------+
| SECOND('18:20:17') |
+--------------------+
|                 17 |
+--------------------+
1 row in set
```
