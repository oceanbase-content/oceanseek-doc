# CURTIME

## Declaration

```javascript
CURTIME(scale)
```

## Description

Returns the current time without the date. This function is an alias for `CURRENT_TIME()`.

`scale` indicates the precision of the microsecond part. The valid values are integers from `0` to `6`, and the default value is `0`.

## Examples

```sql
obclient> SELECT CURTIME(0);
+------------+
| CURTIME(0) |
+------------+
| 16:17:11   |
+------------+
1 row in set
```
