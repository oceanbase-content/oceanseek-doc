# DAY

## Declaration

```sql
DAY(date)
```

## Description

Return the day of the month in `date`, ranging from 1 to 31. `DAY()` is a synonym for `DAYOFMONTH()`.

## Examples

```sql
obclient> SELECT DAY('2008-12-31');
+--------------------------+
| DAY('2008-12-31') |
+--------------------------+
|                       31 |
+--------------------------+
```
