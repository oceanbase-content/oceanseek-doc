# DAYOFMONTH

## Declaration

```sql
DAYOFMONTH(date)
```

## Description

Returns the position of a given date `date` within a month.

## Examples

```sql
obclient> SELECT DAYOFMONTH('2008-12-31');
+--------------------------+
| DAYOFMONTH('2008-12-31') |
+--------------------------+
|                       31 |
+--------------------------+
```
