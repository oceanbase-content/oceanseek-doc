# CEIL

## Declaration

```sql
CEIL(expr)
```

## Description

Returns the smallest integer greater than or equal to `expr`.

Comparison operations are supported, with the result being a BOOL value. This value is converted to a numeric type, resulting in `1` (`TRUE`) or `0` (`FALSE`).

If `NULL` is input, the return value is `NULL`.

If a string of digits is entered, it can be automatically converted to a numeric type.

The return value is converted to a BIGINT.

## Examples

```sql
obclient> SELECT CEIL(1.2), CEIL(-1.2), CEIL(1+1.5), CEIL(1=1),CEIL(1<1),CEIL(null);
+-----------+------------+-------------+-----------+-----------+------------+
| CEIL(1.2) | CEIL(-1.2) | CEIL(1+1.5) | CEIL(1=1) | CEIL(1<1) | CEIL(null) |
+-----------+------------+-------------+-----------+-----------+------------+
|         2 |         -1 |           3 |         1 |         0 |       NULL |
+-----------+------------+-------------+-----------+-----------+------------+
1 row in set

obclient> SELECT CEIL(name);
ERROR 1054 (42S22): Unknown column 'name' in 'field list'

obclient> SELECT CEIL('2');
+-----------+
| CEIL('2') |
+-----------+
|         2 |
+-----------+
1 row in set
```
