# UNIFORM

## Declaration

```sql
UNIFORM(<min> , <max> , <gen>)
```

## Description

This function returns an integer or floating-point number that follows a uniform distribution.

* The values of `min` and `max` must be scalar values that do not change during row iteration. For example, they can be constants or scalar functions. In PL, they can also be expressions such as `@v1` or `1+@v3`.
* If both `min` and `max` are integers, the output of the `UNIFORM()` function is an integer. Otherwise, the output is a floating-point number.
* `gen` is a numeric generation function, typically generated using the `RANDOM()` function. If the input value is a constant, the `UNIFORM()` function also returns a constant value.

## Examples

The following example evenly generates integers between 1 and 10.

```shell
obclient> SELECT v, COUNT(*) FROM (SELECT UNIFORM(1, 10, RANDOM()) v FROM TABLE(GENERATOR(1000000))) x GROUP BY v ORDER BY v;
+------+----------+
| v    | count(*) |
+------+----------+
|    1 |   100738 |
|    2 |   100119 |
|    3 |   100223 |
|    4 |    99537 |
|    5 |   100125 |
|    6 |   100001 |
|    7 |   100275 |
|    8 |    99235 |
|    9 |    99837 |
|   10 |    99910 |
+------+----------+
10 rows in set
```
