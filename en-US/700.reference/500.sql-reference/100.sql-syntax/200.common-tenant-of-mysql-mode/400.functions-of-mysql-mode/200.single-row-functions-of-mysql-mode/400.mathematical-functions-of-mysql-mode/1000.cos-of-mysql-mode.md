# COS

## Declaration

```sql
COS(X)
```

## Description

Returns the cosine value of the given radian `X`.

## Examples

```sql
obclient> SELECT COS(PI());
+-----------+
| COS(PI()) |
+-----------+
|        -1 |
+-----------+
1 row in set
```
