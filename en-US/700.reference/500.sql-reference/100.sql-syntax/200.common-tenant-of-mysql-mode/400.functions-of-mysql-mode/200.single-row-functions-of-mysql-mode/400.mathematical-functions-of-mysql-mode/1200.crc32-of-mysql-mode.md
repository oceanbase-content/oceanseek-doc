# CRC32

## Declaration

```sql
CRC32(expr)
```

## Description

Calculates a cyclic redundancy check value and returns a 32-bit unsigned value.

The `expr` parameter must be a string. If it is not, it may be treated as one.

If the parameter is `NULL`, the result is `NULL`.

## Examples

```sql
obclient>SELECT CRC32('hello-world');
+-----------------------+
| COS32('hello-world') |
+-----------------------+
|               2983461467|
+-----------------------+
1 row in set
```
