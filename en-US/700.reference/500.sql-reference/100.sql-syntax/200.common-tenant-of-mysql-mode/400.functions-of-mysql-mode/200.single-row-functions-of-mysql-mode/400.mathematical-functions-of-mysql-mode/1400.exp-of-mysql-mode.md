# EXP

## Declaration

```sql
EXP(X)
```

## Description

Returns `X` raised to the power of the natural logarithm base `e`.

## Examples

```sql
obclient> SELECT EXP(2);
+------------------+
| EXP(2)           |
+------------------+
| 7.38905609893065 |
+------------------+
1 row in set

obclient> SELECT EXP(0);
+--------+
| EXP(0) |
+--------+
|      1 |
+--------+
1 row in set

obclient> SELECT EXP(-2);
+--------------------+
| EXP(-2)            |
+--------------------+
| 0.1353352832366127 |
+--------------------+
1 row in set
```
