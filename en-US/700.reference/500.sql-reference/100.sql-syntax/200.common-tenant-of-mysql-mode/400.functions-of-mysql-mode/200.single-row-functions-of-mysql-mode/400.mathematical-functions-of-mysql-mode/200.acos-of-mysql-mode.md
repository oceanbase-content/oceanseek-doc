# ACOS

## Declaration

```sql
ACOS(X)
```

## Description

Returns the arc cosine of `X`, that is, the value whose cosine is `X`. If `X` is not in the interval `[-1,1]`, the function returns `NULL`.

## Examples

```sql
obclient> SELECT ACOS(-10), ACOS(0), ACOS(10), ACOS(-0.5), ACOS(0.5);
+-----------+--------------------+----------+--------------------+--------------------+
| ACOS(-10) | ACOS(0)            | ACOS(10) | ACOS(-0.5)         | ACOS(0.5)          |
+-----------+--------------------+----------+--------------------+--------------------+
|      NULL | 1.5707963267948966 |     NULL | 2.0943951023931957 | 1.0471975511965979 |
+-----------+--------------------+----------+--------------------+--------------------+
1 row in set
```
