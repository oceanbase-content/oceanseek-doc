# LOG2

## Declaration

```sql
LOG2(X)
```

## Description

Returns the exponent of `X` in base 2.

## Examples

```sql
obclient> SELECT LOG2(65536);
+-------------+
| LOG2(65536) |
+-------------+
|          16 |
+-------------+
1 row in set

obclient> SELECT LOG2(-65536);
+--------------+
| LOG2(-65536) |
+--------------+
|         NULL |
+--------------+
1 row in set, 1 warning
```
