# ATAN2

## Declaration

```sql
ATAN2(X,Y)
```

## Description

Returns the arctangent of `X` divided by `Y`. It is similar to calculating the arctangent of `Y/X`, but the signs of the two parameters determine which quadrant the result lies in.

This function can also be written as `ATAN(X,Y)`. For more information, see [ATAN](../400.mathematical-functions-of-mysql-mode/400.atan-of-mysql-mode.md).

## Examples

```sql
obclient> SELECT ATAN(PI(),0);
+--------------------+
| ATAN(PI(),0)       |
+--------------------+
| 1.5707963267948966 |
+--------------------+
1 row in set
```
