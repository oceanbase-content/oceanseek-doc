# TAN

## Declaration

```sql
TAN(X)
```

## Description

Returns the tangent value of the given angle X in radians.

## Examples

```sql
obclient> SELECT TAN(PI());
+-------------------------+
| TAN(PI())               |
+-------------------------+
| -1.2246467991473532e-16 |
+-------------------------+
1 row in set
```
