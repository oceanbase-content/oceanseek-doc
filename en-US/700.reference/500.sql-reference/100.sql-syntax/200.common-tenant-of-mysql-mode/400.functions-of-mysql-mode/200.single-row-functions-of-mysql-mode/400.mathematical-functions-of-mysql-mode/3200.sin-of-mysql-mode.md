# SIN

## Declaration

```sql
SIN(X)
```

## Description

Returns the sine value of the given radian `X`.

## Examples

```sql
obclient> SELECT SIN(PI());
+------------------------+
| SIN(PI())              |
+------------------------+
| 1.2246467991473532e-16 |
+------------------------+
1 row in set
```
