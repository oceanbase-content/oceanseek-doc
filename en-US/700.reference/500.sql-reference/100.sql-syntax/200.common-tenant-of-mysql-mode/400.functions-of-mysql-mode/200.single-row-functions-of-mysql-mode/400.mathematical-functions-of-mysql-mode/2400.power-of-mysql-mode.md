# POWER

## Declaration

```sql
POWER(X,Y)
```

## Description

Returns `Y` raised to the power of `X`. This function is an alias for `POW()`.

If either `X` or `Y` is `NULL`, the return value is `NULL`.

## Examples

```sql
obclient> SELECT POWER(2,8);
+------------+
| POWER(2,8) |
+------------+
|        256 |
+------------+
1 row in set
```
