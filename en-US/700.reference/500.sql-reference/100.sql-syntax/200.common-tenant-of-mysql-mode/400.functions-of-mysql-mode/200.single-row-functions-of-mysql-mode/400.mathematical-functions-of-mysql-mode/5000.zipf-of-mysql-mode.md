# ZIPF

## Declaration

```sql
ZIPF(<s> , <N> , <gen>)
```

## Description

This function returns an integer that follows a Zipf distribution, with values in the range [0, N), where `s` is the characteristic exponent of the partition.

* `s` is the skewness parameter. A larger `s` value results in a more skewed sequence, which produces a steeper curve when plotted.
* Requirements for `s` and `N`: They must be scalar values that do not change during row iteration. For example, integer or floating-point constants, scalar functions, etc. In PL, they can also be `@v1`, `1+@v3`, etc. The value range of `s` is [1, +∞), and the value range of `N` is [1, 16777215].
* The storage and computational resources consumed by the `zipf` algorithm implementation are related to the value of `N`. The algorithm has a space complexity of `O(N)` and a time complexity of `O(logN)` for generating each integer. Therefore, the range of `N` is limited to [1, 16777215].
* `gen` is a numerical generation function, typically using the `RANDOM()` function. If the input value is a constant, the `zipf()` function also returns a fixed value.

