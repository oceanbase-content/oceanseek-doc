# TRUNCATE

## Declaration

```sql
TRUNCATE(X,D)
```

## Description

Returns `X` rounded to `D` decimal places. If `D` is `0`, the function returns the integer part of `X`. If `D` is negative, the function sets the `D` digits to the left of the decimal point in `X` to `0`.

## Examples

```sql
obclient> SELECT TRUNCATE(3.27,1);
+------------------+
| TRUNCATE(3.27,1) |
+------------------+
|              3.2 |
+------------------+
1 row in set

obclient> SELECT TRUNCATE(3.27,0);
+------------------+
| TRUNCATE(3.27,0) |
+------------------+
|                3 |
+------------------+
1 row in set

obclient> SELECT TRUNCATE(3.27,-1);
+-------------------+
| TRUNCATE(3.27,-1) |
+-------------------+
|                 0 |
+-------------------+
1 row in set
```
