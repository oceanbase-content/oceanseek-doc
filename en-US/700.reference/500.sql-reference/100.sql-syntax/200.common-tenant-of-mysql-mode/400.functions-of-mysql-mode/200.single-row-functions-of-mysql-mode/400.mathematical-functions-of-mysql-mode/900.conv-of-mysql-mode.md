# CONV

## Declaration

```sql
CONV(N, from_base, to_base)
```

## Description

Converts a number between different bases. The return value is a string representing the number converted from the `from_base` to the `to_base`.

* The input parameter `N` can be an integer or a string. The minimum base is `2`, and the maximum base is `36`. If `to_base` is negative, `N` is treated as a signed number. Otherwise, `N` is treated as an unsigned number.

* If `from_base` is negative, it is treated as an integer and its sign is ignored.

* The `N` parameter only supports input of integer and string types.

* The `from_base` and `to_base` parameters only support decimal integer input, with a value range of \[-36, -2\] U \[2, 36\].

Invalid input will cause an error. Invalid inputs include the following:

* `from_base` or `to_base` is not a valid decimal integer input;

* The value of `from_base` or `to_base` is outside the range \[-36,-2\] ∪ \[2,36\].

* `N` is not a valid numeric representation, for example, the value exceeds the character range of `0` to `9`, `a` to `z`, and `A` to `Z`;

* `N` is out of the valid range for `from_base`. For example, if `from_base` is 2, `N` cannot be 3.

* The value of `N` exceeds the maximum representable range of `BIGINT`, which is \[-9223372036854775807, 9223372036854775807\].
