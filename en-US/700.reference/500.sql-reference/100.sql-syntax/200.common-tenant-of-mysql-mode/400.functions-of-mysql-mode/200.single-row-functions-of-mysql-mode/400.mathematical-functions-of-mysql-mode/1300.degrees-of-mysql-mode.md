# DEGREES

## Syntax statement

```sql
DEGREES(x)
```

## Description

The `DEGREES()` function converts the parameter `x` from radians to degrees and returns the result.

## Examples

The following examples convert the values of `PI()` and `PI()/2` to their corresponding degrees.

```sql
obclient> SELECT DEGREES(PI());
+---------------+
| DEGREES(PI()) |
+---------------+
|           180 |
+---------------+
1 row in set

obclient> SELECT DEGREES(PI()/2);
+-------------------+
| DEGREES(PI()/2) |
+-------------------+
|                90 |
+-------------------+
1 row in set
```
