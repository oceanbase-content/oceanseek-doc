# REGEXP

## Declaration

```sql
str [NOT] REGEXP | RLIKE pat
```

## Description

Regular expression match. If the parameter contains `NULL`, return `NULL`.

## Examples

```sql
obclient> SELECT
     1234 REGEXP 1,
     'hello' RLIKE 'h%'
     \G
*************************** 1. row ***************************
     1234 REGEXP 1: 1
'hello' RLIKE 'h%': 0
1 row in set
```
