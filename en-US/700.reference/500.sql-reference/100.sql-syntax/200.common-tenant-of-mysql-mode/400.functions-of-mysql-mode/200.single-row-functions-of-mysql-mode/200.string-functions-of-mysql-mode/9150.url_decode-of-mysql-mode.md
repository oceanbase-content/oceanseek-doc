# URL_DECODE

## Description

This function decodes a URL-encoded string into its original form. It restores the characters corresponding to the two-digit hexadecimal numbers following the `%` symbol in `expr`. `URL_ENCODE` and `URL_DECODE` are inverse operations.

## Considerations

* This function currently only supports the `utf8` collation.
* If the input is of the `string` type, the output collation remains consistent with the input. If the input is not of the `string` type, the output collation is the default collation of the current session.

## Syntax statement

```sql
URL_DECODE(expr)
```

## Parameters

`expr`: The string that requires URL decoding.

## Return type

* Returns a URL-encoded string (`VARCHAR` type).
* Returns `NULL` if the value of `expr` is `NULL`.

## Examples

```sql
SELECT URL_DECODE('https%3A%2F%2Fexample.com%2Fpath%3Fname%3DJohn+Doe%26age%3D25'), URL_DECODE(NULL);
```

The return result is as follows:

```shell
+-----------------------------------------------------------------------------+------------------+
| URL_DECODE('https%3A%2F%2Fexample.com%2Fpath%3Fname%3DJohn+Doe%26age%3D25') | URL_DECODE(NULL) |
+-----------------------------------------------------------------------------+------------------+
| https://example.com/path?name=John+Doe&age=25                               | NULL             |
+-----------------------------------------------------------------------------+------------------+
1 row in set
```
