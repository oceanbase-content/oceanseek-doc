# MD5_CONCAT_WS

## Purpose

This function concatenates multiple strings into a single string, separating adjacent strings with `separator`. If any parameter contains `NULL`, `replace_null_value` is used to replace `NULL` during concatenation. The MD5 hash of the resulting concatenated string is then calculated and returned as the result.

## Considerations

* At least **three** parameters are required (`separator`, `replace_null_value`, and at least one string to concatenate). Otherwise, an `Incorrect parameter count` error is returned.
* LOB data types, such as `TEXT`, `MEDIUMTEXT`, `LONGTEXT`, `BLOB`, `MEDIUMBLOB`, and `LONGBLOB` (except for `TINYTEXT`), cannot be used as input parameters. Otherwise, an error `Not supported feature or function` is returned.
* This function may encounter hash collisions, which means different inputs could result in the same output.
* You must specify a value that does not duplicate any values in the input column as the replacement for `NULL` values, to ensure that the result after replacing `NULL` values with this replacement value does not duplicate any values in the input column. The following usage is incorrect:

    ```sql
    MD5_CONCAT_WS('_', '@', 'a', NULL, 'b') = MD5('a_@_b')

    MD5_CONCAT_WS('_', '@', 'a', '@', 'b')  = MD5('a_@_b')
    ```

## Syntax

```sql
MD5_CONCAT_WS(separator, replace_null_value, str1, ... , strN)
```

## Parameters

* `separator`: A string that is used as the delimiter when concatenating the input values.
* `replace_null_value`: A string to replace input values that are `NULL`.
* `str1, ... , strN`: A list of strings to be concatenated as input values (variable number of parameters).

## Return value

Returns the MD5 value (32-bit hexadecimal) of the concatenated string.

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>If both <code>separator</code> and <code>replace_null_value</code> are specified and one of them is <code>NULL</code>, the function returns <code>NULL</code>.</p>
</main>

## Examples

1. Create the table `test_tbl1`.

    ```shell
    obclient> CREATE TABLE test_tbl1 (
        col1 INT PRIMARY KEY,
        col2 VARCHAR(20) NOT NULL,
        col3 VARCHAR(50)
        );
    ```

2. Insert test data

    ```shell
    obclient> INSERT INTO test_tbl1 VALUES
        (1, 'A1', NULL),
        (2, 'A2', 'OceanBase'),
        (3, 'A3', 'DATABASE'),
        (4, 'A4', NULL),
        (5, 'A5', 'TABLEGROUP');
    ```

    The return result is as follows:

    ```shell
    Query OK, 5 rows affected
    Records: 5  Duplicates: 0  Warnings: 0
    ```

3. Concatenate the columns `col1`, `col2`, and `col3` of table `test_tbl1` with an underscore `_` to form a string, replacing `NULL` values with `@`. Then generate an MD5 hash value.

    ```shell
    obclient> SELECT MD5_CONCAT_WS('_', '@', t1.col1, t1.col2, t1.col3)
        FROM test_tbl1 t1;
    ```

    The return result is as follows:

    ```shell
    +----------------------------------------------------+
    | MD5_CONCAT_WS('_', '@', t1.col1, t1.col2, t1.col3) |
    +----------------------------------------------------+
    | 7df704a058d6e9293f01ae16c5c01fef                   |
    | a7518a709f593d475604511ab528351d                   |
    | fcd7a30f8897edfaf2f725aafc6af30c                   |
    | 1ad84ebb99c253544f2341f9c2b5dd57                   |
    | 26bb87a94aad329bae3d9cfb10b5614c                   |
    +----------------------------------------------------+
    5 rows in set
    ```
