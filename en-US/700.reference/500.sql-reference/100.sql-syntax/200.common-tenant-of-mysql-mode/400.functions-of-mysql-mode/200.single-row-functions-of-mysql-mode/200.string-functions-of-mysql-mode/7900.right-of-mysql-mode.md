# RIGHT

## Declaration

```sql
RIGHT(str,len)
```

## Description

Returns the last `len` characters of the string `str`. If `str` or `len` is `NULL`, returns `NULL`.

This function is multibyte-safe.

## Examples

```sql
obclient> SELECT RIGHT('oceanbase',4);
+----------------------+
| RIGHT('oceanbase',4) |
+----------------------+
| base                 |
+----------------------+
1 row in set
```
