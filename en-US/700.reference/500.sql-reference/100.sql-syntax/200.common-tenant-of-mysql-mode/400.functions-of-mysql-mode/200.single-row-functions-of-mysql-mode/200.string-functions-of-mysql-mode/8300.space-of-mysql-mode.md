# SPACE

## Declaration

```sql
SPACE(N)
```

## Description

Returns a string containing `N` spaces.

## Examples

Returns a string containing five spaces.

```sql
obclient> SELECT SPACE(5);
+----------+
| SPACE(5) |
+----------+
|          |
+----------+
1 row in set
```
