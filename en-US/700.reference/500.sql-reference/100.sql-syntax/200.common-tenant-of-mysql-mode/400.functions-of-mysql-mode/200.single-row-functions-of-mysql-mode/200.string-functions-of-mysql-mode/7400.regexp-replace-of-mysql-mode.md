# REGEXP_REPLACE

## Declaration

```sql
REGEXP_REPLACE(expr, pat, repl[, pos[, occurrence[, match_type]]])
```

## Description

Replaces all substrings in the string `expr` that match the pattern `pat` with the string specified by `repl`, and returns the resulting string. If `expr`, `pat`, or `repl` is `NULL`, the function returns `NULL`.

* `pos`: The position in the expression `expr` from which to start the search. The default value is `1`.

* `occurrence`: specifies the number of times to perform the replacement. The default value is `0`, which means all matching substrings will be replaced.

* `match_type` specifies the matching rule. For more information about matching rules, see [REGEXP_LIKE](../200.string-functions-of-mysql-mode/7300.regexp-like-of-mysql-mode.md).

```sql
obclient> SELECT REGEXP_REPLACE('OceanBase', 'a', '2');

+---------------------------------------+
| Oce2nB2se                             |
+---------------------------------------+
1 row in set
```
