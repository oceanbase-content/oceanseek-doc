# LOWER

## Declaration

```sql
LOWER(str)
```

## Description

Converts uppercase letters in a string to lowercase letters.

This function is a synonym for `LCASE()`.

## Examples

```sql
obclient> SELECT LOWER('OBCLIENT Hello!');
+-----------------------------+
| LOWER('OBCLIENT Hello!) |
+-----------------------------+
| Hello, obclient!          |
+-----------------------------+
1 row in set
```
