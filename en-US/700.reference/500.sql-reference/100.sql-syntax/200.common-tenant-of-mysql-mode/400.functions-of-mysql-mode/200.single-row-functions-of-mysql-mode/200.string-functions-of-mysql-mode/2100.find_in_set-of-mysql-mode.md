# FIND_IN_SET

## Declaration

```sql
FIND_IN_SET(str,strlist)
```

## Description

Returns the position of the specified string `str` in the string array `strlist`, starting from `1`. If `str` does not exist in `strlist`, returns `0`. If `str` or `strlist` is `NULL`, returns `NULL`.

The `str` string must not contain commas (,).

## Examples

```sql
obclient> SELECT FIND_IN_SET('b','a,b,c,d');
+----------------------------+
| FIND_IN_SET('b','a,b,c,d') |
+----------------------------+
|                          2 |
+----------------------------+
1 row in set
```
