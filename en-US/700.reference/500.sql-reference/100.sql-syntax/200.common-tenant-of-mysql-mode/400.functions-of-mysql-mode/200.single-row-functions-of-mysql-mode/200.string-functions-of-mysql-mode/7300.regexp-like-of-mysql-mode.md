# REGEXP_LIKE

## Declaration

```sql
REGEXP_LIKE(expr, pat[, match_type])
```

## Description

If the string `expr` matches a value specified in the regular expression `pat`, `1` is returned; otherwise, `0` is returned. If either `expr` or `pat` is `NULL`, `NULL` is returned.

`match_type` can be set to the following values, which indicate the matching modes:

* `c` indicates case sensitivity.

* `i` indicates case-insensitivity.

* `m` matches line breaks in the string. By default, it only matches line breaks at the start and end of the string expression.

* `n` specifies that the period `.` matches only line breaks (`\n`). By default, `.` matches any single character other than a line break (`\n`).

* `u` matches only the Unix line break. Only the line break character (`\n`) can be recognized as a line end by the characters `.`, `^`, and `$`.
