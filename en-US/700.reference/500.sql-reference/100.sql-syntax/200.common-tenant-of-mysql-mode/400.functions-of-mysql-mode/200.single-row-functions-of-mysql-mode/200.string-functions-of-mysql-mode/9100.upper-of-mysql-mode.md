# UPPER

## Declaration

```sql
UPPER(str)
```

## Description

Converts lowercase letters in the string `str` to uppercase letters.

## Examples

```sql
obclient> obclient> SELECT UPPER('Hello, obclient!');
+----------------------------+
| UPPER('obclient Hello!)    |
+----------------------------+
| Hello, OBCLIENT!             |
+----------------------------+
1 row in set
```
