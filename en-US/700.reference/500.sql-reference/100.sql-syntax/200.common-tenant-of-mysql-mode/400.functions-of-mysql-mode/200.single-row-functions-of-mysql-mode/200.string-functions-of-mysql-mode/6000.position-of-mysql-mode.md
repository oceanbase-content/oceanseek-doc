# POSITION

## Declaration

```sql
POSITION(substr IN str)
```

## Description

Returns the first occurrence of the substring `substr` within the string `str`.

## Examples

```sql
obclient> SELECT POSITION('bar' IN 'foobarbar');
+--------------------------------+
| POSITION('bar' IN 'foobarbar') |
+--------------------------------+
|                              4 |
+--------------------------------+
1 row in set
```
