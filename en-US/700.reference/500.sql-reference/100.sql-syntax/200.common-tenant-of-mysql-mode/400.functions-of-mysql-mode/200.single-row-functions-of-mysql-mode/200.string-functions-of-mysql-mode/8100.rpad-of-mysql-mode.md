# RPAD

## Declaration

```sql
RPAD(str,len,padstr)
```

## Description

The `padstr` function pads the right side of the string `str` with the character string `filler` until the length of `str` is `len`.

* If the length of `str` is greater than `len`, return the first `len` characters of `str`.

* If the length of `str` is less than `len`, and the concatenated length of `str` and `padstr` is greater than `len`, then the first `len` characters of the concatenated string are returned.

* If the length of `str` is less than `len`, or the concatenated length of `str` and `padstr` is less than `len`, then return the first `len` characters of the concatenation of `str` and multiple repetitions of `padstr` (with a total length greater than or equal to `len`).

## Examples

```sql
obclient> SELECT RPAD('hi',5,'?');
+------------------+
| RPAD('hi',5,'?') |
+------------------+
| hi???            |
+------------------+
1 row in set

obclient> SELECT RPAD('hi',1,'?');
+------------------+
| RPAD('hi',1,'?') |
+------------------+
| h                |
+------------------+
1 row in set
```
