# REPEAT

## Declaration

```sql
REPEAT(str, count)
```

## Description

Returns a string consisting of the repeated character `str` for `count` times. If `count` is less than or equal to 0, an empty string is returned. If the parameter contains `NULL`, `NULL` is returned.

## Examples

```javascript
obclient> SELECT
     REPEAT('1', -1),
     REPEAT(null, null),
     REPEAT('Abc', 4)
     \G
*************************** 1. row ***************************
   REPEAT('1', -1):
REPEAT(null, null): NULL
  REPEAT('Abc', 4): AbcAbcAbcAbc
1 row in set
```
