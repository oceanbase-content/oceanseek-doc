# SUBSTRING

## Declaration

```sql
SUBSTRING(str, pos)
SUBSTRING(str, pos, len)
SUBSTRING(str FROM pos)
SUBSTRING(str FROM pos FOR len)
```

## Description

Returns a substring of `str` starting at position `pos` and with a length of `len`. If any parameter is `NULL`, `NULL` is returned. This function is an alias for `SUBSTR()`.

* If `len` is not specified, the returned substring starts at position `pos` and ends at the end of `str`.

* If the `pos` value is negative, the starting position is determined by counting backward from the end to the beginning of `str`.

* An empty string is returned if `len` is less than or equal to 0, or if the starting position specified by `pos` is invalid.

## Examples

```javascript
obclient> SELECT
    SUBSTRING('abcdefg', 3),
    SUBSTRING('abcdefg', 3, 2),
    SUBSTRING('abcdefg', -3),
    SUBSTRING('abcdefg', 3, -2),
    SUBSTRING('abcdefg' from -4 for 2)
    \G

          SUBSTRING('abcdefg', -3): efg
       SUBSTRING('abcdefg', 3, -2):
SUBSTRING('abcdefg' from -4 for 2): de
```
