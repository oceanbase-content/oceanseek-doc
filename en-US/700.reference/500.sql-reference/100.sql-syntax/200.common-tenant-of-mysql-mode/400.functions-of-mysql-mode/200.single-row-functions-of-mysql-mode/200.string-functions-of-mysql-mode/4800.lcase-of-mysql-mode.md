# LCASE

## Declaration

```sql
LCASE(str)
```

## Description

Converts uppercase letters in a string to lowercase letters.

This function is a synonym for `LOWER()`.

## Examples

```sql
obclient> SELECT LCASE('Hello, OBCLIENT!');
+----------------------------+
| LCASE('OBCLIENT Hello!)    |
+----------------------------+
| Hello, obclient!             |
+----------------------------+
1 row in set
```
