# CONCAT

## Declaration

```sql
CONCAT(str1, str2, ...)
```

## Description

Concatenates multiple strings into a single string. If all parameters are non-binary strings, the result is a non-binary string. If any parameter contains a binary string, the result is a binary string. Numerical parameters are converted to their equivalent non-binary string forms.

If the parameter contains `NULL`, return `NULL`.

## Examples

```sql
obclient> SELECT
     CONCAT('test','obclient', '1.0'),
     CONCAT('test','obclient', NULL)
     \G
*************************** 1. row ***************************
CONCAT('test','obclient', '1.0'): testobclient1.0
 CONCAT('test','obclient', NULL): NULL
1 row in set
```
