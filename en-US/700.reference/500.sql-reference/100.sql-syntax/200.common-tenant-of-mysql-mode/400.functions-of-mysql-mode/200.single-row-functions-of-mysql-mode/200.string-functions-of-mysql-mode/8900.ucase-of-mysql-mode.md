# UCASE

## Declaration

```sql
UCASE(str)
```

## Description

Converts lowercase letters in the string `str` to uppercase letters. This function is a synonym for `UPPER()`.

## Examples

```sql
obclient> SELECT UCASE('obclient Hello!');
+----------------------------+
| UCASE('obclient Hello!')    |
+----------------------------+
| Hello, OBCLIENT!             |
+----------------------------+
1 row in set
```
