# SPLIT_PART

## Purpose

This function splits an input string into multiple substrings based on the delimiter and returns the substring at the specified position.

## Limitations

The signs of the `start_part` and `end_part` parameters must be the same. When `start_part` is a negative value, you cannot specify `end_part`; otherwise, an error is returned.

## Syntax statement

```sql
SPLIT_PART(str, delimiter, start_part[, end_part])
```

## Parameters

* `str`: The string to be split. Supported data types: `VARCHAR`, `TINYTEXT`, `TEXT`, `LONGTEXT`, and `NULL`. The `JSON` data type is not supported.
* `delimiter`: The delimiter used to split the string. Valid types: `VARCHAR` and `NULL`.
* `start_part`: Specifies which part of the split `str` to return. Supported types: `INT` and `NULL`.
* `end_part`: Optional. When specified, the expression returns the string from `start_part` to `end_part`. Supported types: `INT`, `NULL`.

## Return type

* In most scenarios, the return value type is consistent with `str`. However, when `str` is `TINYTEXT`, the return value type is `VARCHAR`.
* If any parameter in the expression is `NULL`, the return value is `NULL`.
* If `delimiter` is not present in `str` and `start_part` is `1`, return the original string of `str`.
* When `start_part = 0`, treat `0` as `1`.
* When `start_part < 0`, the data is processed in reverse order.
* Negative numbers are processed in reverse order.

## Examples

```sql
SELECT
    SPLIT_PART('a,b,c,d', ',', 1),
    SPLIT_PART('a,b,c,d', ',', 1, 2),
    SPLIT_PART('a,b,c,d', ',', 0),
    SPLIT_PART('a,b,c,d', ',', -2),
    SPLIT_PART('a,b,c,d', ',', 5),
    SPLIT_PART('a,b,c,d', ',', -5);
```

The return result is as follows:

```shell
+-------------------------------+----------------------------------+-------------------------------+--------------------------------+-------------------------------+--------------------------------+
| SPLIT_PART('a,b,c,d', ',', 1) | SPLIT_PART('a,b,c,d', ',', 1, 2) | SPLIT_PART('a,b,c,d', ',', 0) | SPLIT_PART('a,b,c,d', ',', -2) | SPLIT_PART('a,b,c,d', ',', 5) | SPLIT_PART('a,b,c,d', ',', -5) |
+-------------------------------+----------------------------------+-------------------------------+--------------------------------+-------------------------------+--------------------------------+
| a                             | a,b                              | a                             | c                              |                               |                                |
+-------------------------------+----------------------------------+-------------------------------+--------------------------------+-------------------------------+--------------------------------+
1 row in set
```
