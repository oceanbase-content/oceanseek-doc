# MID

## Declaration

```sql
MID(str,pos,len)
```

## Description

Returns a substring of `str` starting at position `pos` and with length `len`. If any parameter is `NULL`, the function returns `NULL`.

* If `len` is not specified, the returned substring starts at position `pos` and ends at the end of `str`.

* When the `pos` value is negative, the starting position is determined by counting backward from the end to the beginning of `str`.

* An empty string is returned if `len` is less than or equal to 0, or if the starting position specified by `pos` is invalid.

This function is an alias for `SUBSTRING(str,pos,len)`.

## Examples

```sql
obclient> SELECT MID('OceanBase',6);
+--------------------+
| MID('OceanBase',6) |
+--------------------+
| Base               |
+--------------------+
1 row in set
```
