# REPLACE

## Purpose

The `REPLACE()` function is used to replace substrings within a string. It searches for all occurrences of `from_str` in `str` and replaces them with `to_str`. If no `from_str` is found in `str`, the original string remains unchanged.

- If any parameter in `REPLACE()` is `NULL`, the result is `NULL`.

- The `REPLACE()` function is case-sensitive, which means it considers the case of the strings. If you want to perform a case-insensitive replacement, you can use `REPLACE(UPPER(str), UPPER(from_str), to_str)` or `REPLACE(LOWER(str), LOWER(from_str), to_str)` to ensure the replacement is performed without considering case.

- The `REPLACE()` function is multibyte-safe.

## Syntax

```sql
REPLACE(str, from_str)

REPLACE(str, from_str, to_str)
```

## Parameters

| Parameter | Required/Optional | Description |
| ---------- | ----------- | -------------------------------- |
| `str` | Required | Original string to be replaced. |
| `from_str` | Required | The substring to be replaced. |
| `to_str` | Optional | The new string after replacement. If omitted, it is equivalent to an empty string, meaning the original string is deleted. `from_str`. |

## Examples

- Example 1: The following query example uses the `REPLACE` function to replace all substrings `abc.` with `www` in the original string.

```sql
obclient> SELECT REPLACE('abc.efg.gpg.nowdew.abc.dabc.e', 'abc.', 'www');
```

The return result is as follows:

```sql
+---------------------------------------------------------+
| REPLACE('abc.efg.gpg.nowdew.abc.dabc.e', 'abc.', 'www') |
+---------------------------------------------------------+
| wwwefg.gpg.nowdew.wwwdwwwe                              |
+---------------------------------------------------------+
1 row in set
```

- Example 2: The following query example uses the `REPLACE` function to replace `NULL` with `www` in the original string. Since the substring to be replaced is `NULL`, the entire expression will return `NULL`.

```sql
obclient> SELECT REPLACE('abc.efg.gpg.nowdew.abc.dabc.e', NULL, 'www');
```

The return result is as follows:

```sql
+-------------------------------------------------------+
| REPLACE('abc.efg.gpg.nowdew.abc.dabc.e', NULL, 'www') |
+-------------------------------------------------------+
| NULL                                                  |
+-------------------------------------------------------+
1 row in set
```

- Example 3: The following query example uses the `REPLACE` function to replace `abc.` with `WWW` in the original string. Since the `REPLACE()` function is case-sensitive, the result of the entire expression will be `WWWefg.gpg.nowdew.WWWdWWWe`.

```sql
obclient> SELECT REPLACE('abc.efg.gpg.nowdew.abc.dabc.e', 'abc.', 'WWW');
```

The return result is as follows:

```sql
+---------------------------------------------------------+
| REPLACE('abc.efg.gpg.nowdew.abc.dabc.e', 'abc.', 'WWW') |
+---------------------------------------------------------+
| WWWefg.gpg.nowdew.WWWdWWWe                              |
+---------------------------------------------------------+
1 row in set
```

- Example 4: In the following query example, `Hello World` is converted to uppercase `HELLO WORLD`, and `world` is also converted to uppercase. Therefore, this query returns the result `HELLO Universe` because it replaces the uppercase `WORLD` with `Universe`.

```sql
obclient> SELECT REPLACE(UPPER('Hello World'), UPPER('world'), 'Universe');
```

The return result is as follows:

```sql
+-----------------------------------------------------------+
| REPLACE(UPPER('Hello World'), UPPER('world'), 'Universe') |
+-----------------------------------------------------------+
| HELLO Universe                                            |
+-----------------------------------------------------------+
1 row in set
```

## MySQL compatibility

The behavior of the `REPLACE()` function varies across different versions: in MySQL 5.7, when the second parameter is an empty string (`''`) and the third parameter is `NULL`, the result is the first parameter; whereas in MySQL 8.0, the result is `NULL`.
