# REGEXP_INSTR

## Declaration

```sql
REGEXP_INSTR(expr, pat [, pos [, occurrence [, return_option [, match_type ]]]])
```

## Description

Returns the starting position of the first substring that matches the pattern `pat` in the expression `expr`. If no matching substring is found, returns `0`. If either `expr` or `pat` is `NULL`, the function returns `NULL`. The returned position is 1-based.

* `pos`: The position in the string to start the search. The default value is `1`.

* `occurrence`: the position in `expr` where `pat` occurs for the first time. The default value is `1`.

* `return_option` indicates the type of the return value. The default value is `0`.

  * When the value is `0`, it indicates that REGEXP_INSTR() returns the position of the first matched character.

  * When the value is `1`, it indicates that REGEXP_INSTR() returns the position of the last matched character.

* `match_type` specifies the matching rule. For more information, see [REGEXP_LIKE](../200.string-functions-of-mysql-mode/7300.regexp-like-of-mysql-mode.md).
