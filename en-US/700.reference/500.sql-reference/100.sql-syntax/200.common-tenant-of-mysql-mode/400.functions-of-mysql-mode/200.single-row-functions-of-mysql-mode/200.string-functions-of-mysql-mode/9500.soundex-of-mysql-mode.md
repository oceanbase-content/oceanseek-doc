# SOUNDEX

## Declaration

```sql
SOUNDEX(str)
```

## Description

Converts the input string into an encoding that represents its pronunciation. This function is commonly used for fuzzy queries or matching strings with similar pronunciations in databases.

## Examples

```sql
obclient> SELECT SOUNDEX('a');
+--------------+
| SOUNDEX('a') |
+--------------+
| A000         |
+--------------+
1 row in set
```
