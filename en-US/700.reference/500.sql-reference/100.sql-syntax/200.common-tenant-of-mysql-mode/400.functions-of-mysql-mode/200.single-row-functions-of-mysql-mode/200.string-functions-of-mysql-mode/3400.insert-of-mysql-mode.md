# INSERT

## Declaration

```sql
INSERT (str1,pos,len,str2)
```

## Description

Returns the string `str1`, replacing the substring starting at position `pos` and having length `len` with `str2`. If `pos` exceeds the length of the string, the original string is returned. If `len` is longer than either of the other strings, the replacement starts from position `pos`. If any parameter is `NULL`, the return value is `NULL`. This function supports multibyte characters.

* `str1` and `str2` must be strings, and `pos` and `len` must be integers. If any parameter is `NULL`, the result is always `NULL`.

* The Chinese characters in `str1` and `str2` are treated as a byte stream.

* If the value of `pos` is negative or greater than the length of `str1`, `str1` is returned.

* If `len` is less than 0 or greater than the length of `str1`, the result is a concatenation of `str1` from the beginning to position `pos` and `str2`.
