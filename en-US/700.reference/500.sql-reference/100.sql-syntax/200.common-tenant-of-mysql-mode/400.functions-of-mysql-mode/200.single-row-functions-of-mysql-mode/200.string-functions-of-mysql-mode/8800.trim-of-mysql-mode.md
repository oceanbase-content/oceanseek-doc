# TRIM

## Declaration

```sql
TRIM([[{BOTH | LEADING | TRAILING}] [remstr] FROM] str
```

## Description

Specifies whether to delete all prefixes and/or suffixes from the string. The default value is `BOTH`. If the parameter contains `NULL`, `NULL` is returned.

## Examples

```sql
obclient> SELECT
     TRIM(' bar '),
     TRIM(LEADING 'x' FROM 'xxxbarxxx'),
     TRIM(BOTH 'x' FROM 'xxxbarxxx'),
     TRIM(TRAILING 'x' FROM 'xxxbarxxx')
     \G
*************************** 1. row ***************************
                      TRIM(' bar '): bar
 TRIM(LEADING 'x' FROM 'xxxbarxxx'): barxxx
    TRIM(BOTH 'x' FROM 'xxxbarxxx'): bar
TRIM(TRAILING 'x' FROM 'xxxbarxxx'): xxxbar
1 row in set
```
