# LEFT

## Declaration

```sql
LEFT(str,len)
```

## Description

Returns the first `len` characters of the string `str`. If `str` or `len` is `NULL`, returns `NULL`.

This function is multibyte-safe.

## Examples

```sql
obclient> SELECT LEFT('oceanbase', 5);
+----------------------+
| LEFT('oceanbase', 5) |
+----------------------+
| ocean                |
+----------------------+
1 row in set
```
