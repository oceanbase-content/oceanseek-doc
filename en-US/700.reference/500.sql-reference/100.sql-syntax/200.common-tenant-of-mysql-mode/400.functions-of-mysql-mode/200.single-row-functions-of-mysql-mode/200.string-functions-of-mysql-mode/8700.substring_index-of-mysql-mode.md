# SUBSTRING_INDEX

## Declaration

```sql
SUBSTRING_INDEX(str, delim, count)
```

## Description

Return the substring from `str` up to, but not including, the first occurrence of the delimiter `delim`. The function also returns the number of characters matched.

* If `count` is positive, return all content to the left of the final delimiter (starting from the left).

* If `count` is negative, return all characters to the right of the delimiter (starting from the right).

* If any parameter is `NULL`, return `NULL`;

* If `str` or `delim` is an empty string, an empty string is returned.

* If `count=0`, an empty string is also returned.

* The `str`, `delim`, and `count` parameters support implicit conversion between numeric and string values.
