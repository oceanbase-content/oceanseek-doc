# TO_CHAR(character)

## Purpose

This function is used to convert character data into a `VARCHAR` type string.

## Syntax statement

```sql
TO_CHAR(character)
```

## Parameters

`character`: the character data to be converted.

## Return type

* Returns data of the `VARCHAR` type.
* If the `character` value is `NULL`, return `NULL`.

## Examples

```sql
SELECT TO_CHAR('Hello, World!'), TO_CHAR(NULL);
```

The return result is as follows:

```shell
+--------------------------+---------------+
| TO_CHAR('Hello, World!') | TO_CHAR(NULL) |
+--------------------------+---------------+
| Hello, World!            |          NULL |
+--------------------------+---------------+
1 row in set
```
