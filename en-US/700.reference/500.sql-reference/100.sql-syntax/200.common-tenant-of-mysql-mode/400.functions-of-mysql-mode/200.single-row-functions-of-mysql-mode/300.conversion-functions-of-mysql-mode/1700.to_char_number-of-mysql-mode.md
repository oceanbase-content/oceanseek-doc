# TO_CHAR(number)

## Purpose

This function is used to convert numeric data into `VARCHAR` type data.

## Syntax

```sql
TO_CHAR(number [, fmt])
```

## Parameters

* `number`: The numeric data to be converted.
* `fmt`: Optional. Specifies the format for the output value. If omitted, `number` is converted to a `VARCHAR` value. For more information, see [fmt](#fmt).

### fmt

The `fmt` parameter can be set to the following values:

* [Numeric](#Numeric): `0` and `9`.
* [Grouping classes](#Grouping): `.`, `,`, `D`, and `G`.
* [Currency types](#Currency types): `$`, `C`, `L`, and `U`.
* [Arithmetic conversion categories](#Arithmetic conversion categories): `EEEE`, `RN`, `V`, and `X`.
* [Signs](#Positive%20and%20negative%20signs): `MI`, `PR`, and `S`.
* [Orthodox](#Orthodox): `TM`.
* [Other classes](#Other classes): `B` and `FM`.

#### Numeric

* `0`: A placeholder indicating a numeric position. Returns the corresponding character at that position; if no character exists, fills with `0`.

    <main id="notice" type='notice'>
      <h4>Notice</h4>
      <p><code>0</code> is a mandatory symbol. If the corresponding bit is absent, it is filled with <code>0</code>. This is a feature that differs from <code>9</code>.</p>
    </main>

  **Example:**

  ```sql
  SELECT TO_CHAR(123, '00000'), TO_CHAR(123.456, '0000.0000');
  ```

  The return result is as follows:

  ```shell
  +-----------------------+-------------------------------+
  | TO_CHAR(123, '00000') | TO_CHAR(123.456, '0000.0000') |
  +-----------------------+-------------------------------+
  |  00123                |  0123.4560                    |
  +-----------------------+-------------------------------+
  1 row in set
  ```

* `9`: A placeholder indicating a digit position. Specifically:

  * For decimal places, it indicates converting to the corresponding character. If there is no such character, `0` is used for padding.

  * For integer digits, no character is padded if there is no corresponding value.

    **Example:**

    ```sql
    SELECT TO_CHAR(123, '999999'), TO_CHAR(123.456, '9999.9999');
    ```

    The return result is as follows:

    ```shell
    +------------------------+-------------------------------+
    | TO_CHAR(123, '999999') | TO_CHAR(123.456, '9999.9999') |
    +------------------------+-------------------------------+
    |     123                |   123.4560                    |
    +------------------------+-------------------------------+
    1 row in set
    ```

#### Grouping

* `.` (period): Indicates a decimal point, located at the specified position. If the fractional part is insufficient, zeros are padded; if the fractional part exceeds the number of digits specified in `fmt`, rounding is performed.

    <main id="notice" type='notice'>
      <h4>Notice</h4>
      <p><code>fmt</code> can specify only one decimal point.</p>
    </main>

  **Example:**

  ```sql
  SELECT TO_CHAR(123.555, '999.99'), TO_CHAR(123.5, '999.99');
  ```

  The return result is as follows:

  ```shell
  +----------------------------+--------------------------+
  | TO_CHAR(123.555, '999.99') | TO_CHAR(123.5, '999.99') |
  +----------------------------+--------------------------+
  |  123.56                    |  123.50                  |
  +----------------------------+--------------------------+
  1 row in set
  ```

* `,` (English comma): Typically appears in the thousandth place as a grouping symbol. If necessary, it can also represent the tenth or hundredth place and may appear up to N times, depending on the size of the number.

    <main id="notice" type='notice'>
      <h4>Notice</h4>
      <p><code>,</code> cannot be at the beginning of <code>fmt</code> and can only appear in the integer part.</p>
    </main>

  **Example:**

  ```sql
  SELECT TO_CHAR(123456, '99,99,99'), TO_CHAR(123456789, '999,999,999');
  ```

  The return result is as follows:

  ```shell
  +-----------------------------+-----------------------------------+
  | TO_CHAR(123456, '99,99,99') | TO_CHAR(123456789, '999,999,999') |
  +-----------------------------+-----------------------------------+
  |  12,34,56                   |  123,456,789                      |
  +-----------------------------+-----------------------------------+
  1 row in set
  ```

* `D` (ISO decimal character): The international version (ISO) of the "decimal point" character. It has the same function as `.` and can appear only once. The difference is that this character uses the default value of the `NLS_NUMERIC_CHARACTER` parameter.

    <main id="notice" type='notice'>
      <h4>Notice</h4>
      <p>Generally, do not use this format symbol unless necessary, and do not modify the parameter value (<code>NLS_NUMERIC_CHARACTER</code>) lightly.</p>
    </main>

  **Example:**

  ```sql
  SELECT TO_CHAR(123.555, '999D99'), TO_CHAR(123.5, '999D99');
  ```

  The return result is as follows:

  ```shell
  +----------------------------+--------------------------+
  | TO_CHAR(123.555, '999D99') | TO_CHAR(123.5, '999D99') |
  +----------------------------+--------------------------+
  |  123.56                    |  123.50                  |
  +----------------------------+--------------------------+
  1 row in set
  ```

* `G`: The ISO standard for a "comma", used as a grouping symbol and can be applied in multiple locations.

    <main id="notice" type='notice'>
      <h4>Notice</h4>
      <p>If you want to convert a number into a decimal point, you must use it with <code>D</code>, not with the period (<code>.</code>).</p>
    </main>

  **Example:**

  ```sql
  SELECT TO_CHAR(123456, '99G99G99'), TO_CHAR(123456789, '999G999G999');
  ```

  The return result is as follows:

  ```shell
  +-----------------------------+-----------------------------------+
  | TO_CHAR(123456, '99G99G99') | TO_CHAR(123456789, '999G999G999') |
  +-----------------------------+-----------------------------------+
  |  12,34,56                   |  123,456,789                      |
  +-----------------------------+-----------------------------------+
  1 row in set
  ```

#### Currency

* `$` (dollar sign): Returns the value with a leading dollar sign.

    <main id="notice" type='notice'>
      <h4>Notice</h4>
      <p><code>$</code> can be placed anywhere in the <code>fmt</code> string, but it must appear only once.</p>
    </main>

  **Example:**

  ```sql
  SELECT TO_CHAR(123.45, '$999.99'), TO_CHAR(123.45, '9,9,9,9.$99');
  ```

  The return result is as follows:

  ```shell
  +----------------------------+--------------------------------+
  | TO_CHAR(123.45, '$999.99') | TO_CHAR(123.45, '9,9,9,9.$99') |
  +----------------------------+--------------------------------+
  |  $123.45                   |    $1,2,3.45                   |
  +----------------------------+--------------------------------+
  1 row in set
  ```

* `C` (International Currency Symbol): Returns the ISO currency symbol (the value represented by the current `NLS_ISO_CURRENCY` parameter) at the specified position.

    <main id="notice" type='notice'>
      <h4>Notice</h4>
      <p><code>C</code> can only appear as the first character in the integer part of <code>fmt</code>.</p>
    </main>

  **Example:**

  ```sql
  SELECT TO_CHAR(123.45, 'C999.99');
  ```

  The return result is as follows:

  ```shell
  +----------------------------+
  | TO_CHAR(123.45, 'C999.99') |
  +----------------------------+
  |      USD123.45             |
  +----------------------------+
  1 row in set
  ```

* `L` (local currency symbol): the local version of `C`, which returns the local currency symbol at the specified position. It can be placed at the very beginning or end of the entire format.

  **Example:**

  ```sql
  SELECT TO_CHAR(123.45, 'L999.99'), TO_CHAR(123.45, '999.99L');
  ```

  The return result is as follows:

  ```shell
  +----------------------------+----------------------------+
  | TO_CHAR(123.45, 'L999.99') | TO_CHAR(123.45, '999.99L') |
  +----------------------------+----------------------------+
  |           $123.45          |           123.45$          |
  +----------------------------+----------------------------+
  1 row in set
  ```

* `U`: Returns the euro (or other) currency symbol determined by the current value represented by the `NLS_DUAL_CURRENCY` parameter at the specified position.

  **Example:**

  ```sql
  SELECT TO_CHAR(123.45, 'U999.99'), TO_CHAR(123.45, '999.99U'), TO_CHAR(123.45, '999U999');
  ```

  The return result is as follows:

  ```shell
  +----------------------------+----------------------------+----------------------------+
  | TO_CHAR(123.45, 'U999.99') | TO_CHAR(123.45, '999.99U') | TO_CHAR(123.45, '999U999') |
  +----------------------------+----------------------------+----------------------------+
  |           $123.45          |           123.45$          |           123$450          |
  +----------------------------+----------------------------+----------------------------+
  1 row in set
  ```

#### Compute conversion classes

* `EEEE` (scientific notation): Returns the value in scientific notation. Since this is a scientific calculation method, adding one or more leading 9s or 0s is sufficient; more than one leading digit is meaningless.

  **Example:**

  ```sql
  SELECT TO_CHAR(10000, '9EEEE'), TO_CHAR(10000, '9.9EEEE'), TO_CHAR(10000, '999.9EEEE');
  ```

  The return result is as follows:

  ```shell
  +-------------------------+---------------------------+-----------------------------+
  | TO_CHAR(10000, '9EEEE') | TO_CHAR(10000, '9.9EEEE') | TO_CHAR(10000, '999.9EEEE') |
  +-------------------------+---------------------------+-----------------------------+
  |   1E+04                 |   1.0E+04                 |   1.0E+04                   |
  +-------------------------+---------------------------+-----------------------------+
  1 row in set
  ```

* `RN` (`rn`): Converts an integer (between 1 and 3,999) to Roman numerals. `RN` indicates uppercase conversion, while `rn` indicates lowercase conversion.

    <main id="notice" type='notice'>
      <h4>Notice</h4>
      <p><code>RN</code> (<code>rn</code>) cannot be combined with other symbols.</p>
    </main>

  **Example:**

  ```sql
  SELECT TO_CHAR(99, 'RN'), TO_CHAR(99, 'rn');
  ```

  The return result is as follows:

  ```shell
  +-------------------+-------------------+
  | TO_CHAR(99, 'RN') | TO_CHAR(99, 'rn') |
  +-------------------+-------------------+
  |            XCIX   |            xcix   |
  +-------------------+-------------------+
  1 row in set
  ```

* `V`: Returns a value multiplied by `10^n` (rounded if necessary), where `n` is the number of 9s following `V`.

    <main id="notice" type='notice'>
      <h4>Notice</h4>
      <p><code>V</code> cannot be used together with decimal expressions in the <code>fmt</code> format, but can be mixed with symbols such as currency.</p>
    </main>

  **Example:**

  ```sql
  SELECT TO_CHAR(123.456, '999V99'), TO_CHAR(123.4, '999V999'), TO_CHAR(5, '9V');
  ```

  The return result is as follows:

  ```shell
  +----------------------------+---------------------------+------------------+
  | TO_CHAR(123.456, '999V99') | TO_CHAR(123.4, '999V999') | TO_CHAR(5, '9V') |
  +----------------------------+---------------------------+------------------+
  |  12346                     |  123400                   |  5               |
  +----------------------------+---------------------------+------------------+
  1 row in set
  ```

* `X`: Returns a hexadecimal value of the specified length. If the specified number is not an integer, it is rounded to an integer. The following restrictions apply:

  * This element accepts only positive values or 0. Negative values return an error.

  * You can only add 0 (leading zeros) or FM in front of this element. Any other element will return an error. If you use X without specifying 0 or FM, the return value always has a leading space.

    **Example:**

    ```sql
    SELECT TO_CHAR(10, 'X'), TO_CHAR(10, 'XXXX');
    ```

    The result is as follows:

    ```shell
    +------------------+---------------------+
    | TO_CHAR(10, 'X') | TO_CHAR(10, 'XXXX') |
    +------------------+---------------------+
    |  A               |     A               |
    +------------------+---------------------+
    1 row in set
    ```

#### Positive and negative signs

* `MI` (`mi`): Returns a negative value with a trailing minus sign (`-`). If the number is positive, a space is appended to the end.

    <main id="notice" type='notice'>
      <h4>Notice</h4>
      <p><code>MI</code>-formatted elements can only appear at the end of a numeric format model.</p>
    </main>

  **Example:**

  ```sql
  SELECT TO_CHAR(-123, '999MI'), TO_CHAR(-123, '999mi');
  ```

  The return result is as follows:

  ```shell
  +------------------------+------------------------+
  | TO_CHAR(-123, '999MI') | TO_CHAR(-123, '999mi') |
  +------------------------+------------------------+
  | 123-                   | 123-                   |
  +------------------------+------------------------+
  1 row in set
  ```

* `PR`: Another way to represent negative numbers:

  * If it is a positive number, add a space at the beginning.

  * If it is a negative number, enclose the number in angle brackets `<>`.

    <main id="notice" type='notice'>
      <h4>Notice</h4>
      <p><code>PR</code>-formatted elements can only appear at the very end of a numeric format model.</p>
    </main>

    **Example:**

    ```sql
    SELECT TO_CHAR(-1234.89,'9G999D00PR'), TO_CHAR(1234.89,'9G999D00PR');
    ```

    The return result is as follows:

    ```shell
    +--------------------------------+-------------------------------+
    | TO_CHAR(-1234.89,'9G999D00PR') | TO_CHAR(1234.89,'9G999D00PR') |
    +--------------------------------+-------------------------------+
    | <1,234.89>                     |  1,234.89                     |
    +--------------------------------+-------------------------------+
    1 row in set
    ```

* `S`: A positive number is prefixed with a plus sign (`+`), and a negative number is prefixed with a minus sign (`-`).

    <main id="notice" type='notice'>
      <h4>Notice</h4>
      <p><code>S</code>-formatted elements can only appear at the beginning or end of a numeric format model.</p>
    </main>

  **Example:**

  ```sql
  SELECT TO_CHAR(-123.45,'S999.99'), TO_CHAR(123.45,'S999.99');
  ```

  The return result is as follows:

  ```shell
  +----------------------------+---------------------------+
  | TO_CHAR(-123.45,'S999.99') | TO_CHAR(123.45,'S999.99') |
  +----------------------------+---------------------------+
  | -123.45                    | +123.45                   |
  +----------------------------+---------------------------+
  1 row in set
  ```

#### Orthodox

`TM`: The default value is `TM9`. Unless the output exceeds 64 characters, it returns the number with fixed symbols. If the output exceeds 64 characters, the number is automatically returned in scientific notation. When a number exceeds 64 bits, the output of `TM9` is equivalent to that of `TME`.

**Example:**

```sql
SELECT TO_CHAR(1234, 'TM9'), TO_CHAR(1234, 'TME');
```

The returned result is as follows:

```shell
+----------------------+----------------------+
| TO_CHAR(1234, 'TM9') | TO_CHAR(1234, 'TME') |
+----------------------+----------------------+
| 1234                 | 1.234E+03            |
+----------------------+----------------------+
1 row in set
```

#### Other classes

* `B` (space): A space character can be added before the integer part. It can appear anywhere.

    <main id="notice" type='notice'>
      <h4>Notice</h4>
      <p><code>B</code> can only appear in the integer part.</p>
    </main>

  **Example:**

  ```sql
  SELECT TO_CHAR(1234, '99B99'), TO_CHAR(1234, '9999B'), TO_CHAR(1234, 'B9999');
  ```

  The return result is as follows:

  ```shell
  +------------------------+------------------------+------------------------+
  | TO_CHAR(1234, '99B99') | TO_CHAR(1234, '9999B') | TO_CHAR(1234, 'B9999') |
  +------------------------+------------------------+------------------------+
  |  1234                  |  1234                  |  1234                  |
  +------------------------+------------------------+------------------------+
  1 row in set
  ```

* `FM` (`fm`): Remove leading spaces.

    <main id="notice" type='notice'>
      <h4>Notice</h4>
      <p><code>FM</code> can only appear as the first digit of the integer part of <code>fmt</code>.</p>
    </main>

  **Example:**

  ```sql
  SELECT TO_CHAR('  123.456', 'fm999.999'), TO_CHAR('  123.456', 'FM999.999');
  ```

  The return result is as follows:

  ```shell
  +-----------------------------------+-----------------------------------+
  | TO_CHAR('  123.456', 'fm999.999') | TO_CHAR('  123.456', 'FM999.999') |
  +-----------------------------------+-----------------------------------+
  | 123.456                           | 123.456                           |
  +-----------------------------------+-----------------------------------+
  1 row in set
  ```

## Return type

* Returns data of the `VARCHAR` type.
* Returns `NULL` when the `number` value is `NULL`.

## Examples

```sql
SELECT
    TO_CHAR(11111.111, '999,999.9999'),
    TO_CHAR(11111.111, '000,000.0000'),
    TO_CHAR(55555.555, '99,999.99'),
    TO_CHAR(55555.555, '99,999V99'),
    TO_CHAR(NULL, '999.999');
```

The return result is as follows:

```shell
+------------------------------------+------------------------------------+---------------------------------+---------------------------------+--------------------------+
| TO_CHAR(11111.111, '999,999.9999') | TO_CHAR(11111.111, '000,000.0000') | TO_CHAR(55555.555, '99,999.99') | TO_CHAR(55555.555, '99,999V99') | TO_CHAR(NULL, '999.999') |
+------------------------------------+------------------------------------+---------------------------------+---------------------------------+--------------------------+
|   11,111.1110                      |  011,111.1110                      |  55,555.56                      |  55,55556                       |                     NULL |
+------------------------------------+------------------------------------+---------------------------------+---------------------------------+--------------------------+
1 row in set
```
