# CONVERT

## Declaration

```sql
CONVERT(expr USING transcoding_name)
CONVERT(expr,type)
```

## Description

The two declarations of the `CONVERT()` function correspond to two different applications:

* `CONVERT(expr USING transcoding_name)` is used to convert the expression `expr` to the character set specified by `transcoding_name`.

* `CONVERT(expr,type)` is used to convert the expression `expr` to the data type specified by `type`.

  In this usage, `CONVERT(expr,type)` is identical to `CAST(expr AS type)`. For more information about the `CAST` function, see [CAST](../300.conversion-functions-of-mysql-mode/100.cast-of-mysql-mode.md).

## Examples

* Changed the character set used by the string to `BINARY`.

  ```sql
  obclient> SELECT CHARSET(CONVERT('abc' USING binary));
  +--------------------------------------+
  | charset(CONVERT('abc' USING binary)) |
  +--------------------------------------+
  | binary                               |
  +--------------------------------------+
  1 row in set
  ```

* Specify the string type as `CHAR`.

  ```sql
  obclient> SELECT CONVERT('test', CHAR);
  +-----------------------+
  | CONVERT('test', CHAR) |
  +-----------------------+
  | test                  |
  +-----------------------+
  1 row in set
  ```
