# DECODE_TRACE_ID

## Declaration

```sql
DECODE_TRACE_ID()
```

## Description

The `DECODE_TRACE_ID()` function is used to parse a trace ID and return the IP address and port number of the server that initiated the SQL request. You can also view related information through the [GV$OB_SQL_AUDIT](../../../../../../../700.reference/700.system-views/400.system-view-of-mysql-mode/300.performance-view-of-mysql-mode/3500.gv-ob_sql_audit-of-mysql-mode.md) view.

## Examples

```sql
obclient [(none)]> SELECT DECODE_TRACE_ID(LAST_TRACE_ID());
```

The return result is as follows:

```shell
+----------------------------------+
| DECODE_TRACE_ID(LAST_TRACE_ID()) |
+----------------------------------+
| xxx.xx.xxx.xx1:2882              |
+----------------------------------+
1 row in set
```
