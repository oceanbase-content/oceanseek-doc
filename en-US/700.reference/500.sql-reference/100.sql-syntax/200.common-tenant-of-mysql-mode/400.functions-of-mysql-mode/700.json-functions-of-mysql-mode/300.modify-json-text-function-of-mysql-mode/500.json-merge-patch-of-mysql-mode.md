# JSON_MERGE_PATCH

## Purpose

This function merges two or more JSON documents according to the RFC 7396 standard and returns the merged result. The result does not retain members with duplicate keys. If a document passed as a parameter is invalid, an error is thrown.

## Syntax

```sql
JSON_MERGE_PATCH(json_doc, json_doc[, json_doc] ...)
```

## Description

The `json_doc` parameter specifies the JSON document to be merged.

The rules for executing a merge using JSON_MERGEPatch() are as follows:

1. If the first parameter is not an object, it is treated as an empty object and merged with the second parameter to produce the result.

2. If the second parameter is not an object, the result of the merge is the second parameter.

3. If both parameters are objects, the result of the merge is an object with the following members:

   * No member of the first object has a corresponding member with the same key in the second object.

   * All members of the second object do not have corresponding keys in the first object, and their values are not the JSON null literal.

   * The keys of all members exist in both the first and second objects, and the values in the second object are not JSON null literals. The values of these members are the results of recursively merging the values in the first object with those in the second object.
