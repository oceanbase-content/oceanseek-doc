# JSON_APPEND

## Purpose

This function appends a specified value to the end of an array in a JSON document and returns the result. It is an alias for the `JSON_ARRAY_APPEND()` function.

## Syntax

```sql
JSON_APPEND(json_doc, path, val[, path, val] ...)
```

## Description

The `json_doc` parameter specifies the JSON document, and `path` is a path parameter. If either parameter is `NULL`, `NULL` is returned.

An error will be returned in the following scenarios:

* The `json_doc` parameter is not a valid JSON document.

* The `path` parameter is not a valid path expression.

* The `path` parameter contains the \* or \*\* wildcard.

Path-value pairs are evaluated from left to right. The document generated by evaluating the current path-value pair becomes the new value for evaluating the next pair.

If the value corresponding to a path is a scalar or an object value, that value is automatically wrapped in an array and added to the array. Path-value pairs in the JSON document that are not identified by a path and belong to no array are ignored.

## Examples

* In the following example, a user variable `@jn` is defined to contain a JSON string that represents a JSON array.

  ```sql
  obclient> SET @jn = '["a", ["b", "c"], "d","e"]';
  ```

  Append the value `1` to the end of the array whose path is `$[1]` and whose variable is `@jn`.

  ```sql
  obclient> SELECT JSON_APPEND(@jn, '$[1]', 1);
  ```

  Here, `$[1]` corresponds to the second element in the JSON array. The return result is as follows:

  ```shell
  +--------------------------------+
  | JSON_APPEND(@jn, '$[1]', 1)    |
  +--------------------------------+
  | ["a", ["b", "c", 1], "d", "e"] |
  +--------------------------------+
  1 row in set
  ```

  Append the value `2` to the end of the array whose path is `$[0]` and whose variable is `@jn`.

  ```sql
  obclient> SELECT JSON_APPEND(@jn, '$[0]', 2);
  ```

  Here, `$[0]` corresponds to the first element in the JSON array. The return result is as follows:

  ```shell
  +----------------------------------+
  | JSON_APPEND(@jn, '$[0]', 2)      |
  +----------------------------------+
  | [["a", 2], ["b", "c"], "d", "e"] |
  +----------------------------------+
  1 row in set
  ```

  Since `["b", "c"]` is an array, we can append the value `3` to the end of the array at path `$[1][0]` in variable `@jn`.

  ```sql
  obclient> SELECT JSON_APPEND(@jn, '$[1][0]', 3);
  ```

  The return result is as follows:

  ```shell
  +----------------------------------+
  | JSON_APPEND(@jn, '$[1][0]', 3)   |
  +----------------------------------+
  | ["a", [["b", 3], "c"], "d", "e"] |
  +----------------------------------+
  1 row in set
  ```

* In the following example, a user variable `@jemp` is defined, containing a JSON string that represents an object. The object contains three key-value pairs: the value of `"a"` is the number `1`; the value of `"b"` is an array containing the numbers `2` and `3`; the value of `"c"` is the number `4`.

  ```sql
  obclient> SET @jemp = '{"a": 1, "b": [2, 3], "c": 4}';
  ```

  Appends the string `x` to the end of the array whose path is `$.b` and whose variable is `@jemp`.

  ```sql
  obclient> SELECT JSON_APPEND(@jemp, '$.b', 'x');
  ```

  Here, `$.b` represents the array corresponding to the `"b"` key. The return result is as follows:

  ```shell
  +------------------------------------+
  | JSON_APPEND(@jemp, '$.b', 'x')     |
  +------------------------------------+
  | {"a": 1, "b": [2, 3, "x"], "c": 4} |
  +------------------------------------+
  1 row in set
  ```

  Similarly, append the string `y` to the end of the array with path `$.c` in the variable `@jemp`.

  ```sql
  obclient> SELECT JSON_APPEND(@jemp, '$.c', 'y');
  ```

  Here, `$.c` represents the array corresponding to the `"c"` key. The return result is as follows:

  ```shell
  +--------------------------------------+
  | JSON_APPEND(@jemp, '$.c', 'y')       |
  +--------------------------------------+
  | {"a": 1, "b": [2, 3], "c": [4, "y"]} |
  +--------------------------------------+
  1 row in set
  ```

* In the following example, a user variable `@temp` is defined, containing a simple JSON object. In this object, the key is `"a"` and the value is the number `5`.

  ```sql
  obclient> SET @temp = '{"a": 5}';
  ```

  Appends the string `z` to the end of the array with path `$` in the variable `@temp`.

  ```sql
  obclient> SELECT JSON_APPEND(@temp, '$', 'z');
  ```

  Note that specifying the path as `$` refers to the root level of the JSON document, which is the entire JSON object, rather than adding key-value pairs to the JSON object. The return result is as follows:

  ```shell
  +------------------------------+
  | JSON_APPEND(@temp, '$', 'z') |
  +------------------------------+
  | [{"a": 5}, "z"]              |
  +------------------------------+
  1 row in set
  ```
