# JSON_UNQUOTE

## Purpose

This function is used to dereference a JSON value and return the result as a utf8mb4 string.

## Syntax

```sql
JSON_UNQUOTE(json_val)
```

## Description

The `json_val` parameter is the referenced JSON value. If the parameter is `NULL`, `NULL` is returned.

An error occurs if a value starts and ends with double quotes but is not a valid JSON string literal.

## Examples

```sql
obclient> SET @jn = '"abcd"';
Query OK, 0 rows affected

obclient> SELECT @jn, JSON_UNQUOTE(@jn);
+--------+-------------------+
| @jn    | JSON_UNQUOTE(@jn) |
+--------+-------------------+
| "abcd" | abcd              |
+--------+-------------------+
1 row in set

obclient> SET @jn = '[1, 2, 3, 4]';
Query OK, 0 rows affected

obclient> SELECT @jn, JSON_UNQUOTE(@jn);
+--------------+-------------------+
| @jn          | JSON_UNQUOTE(@jn) |
+--------------+-------------------+
| [1, 2, 3, 4] | [1, 2, 3, 4]      |
+--------------+-------------------+
1 row in set
```
