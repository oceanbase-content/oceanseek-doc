# JSON_CONTAINS_PATH

## Purpose

This function checks whether one or more specified paths are contained in the target JSON document. If they are, the function returns 1; otherwise, it returns 0.

## Syntax

```sql
JSON_CONTAINS_PATH(json_doc, one_or_all, path[, path] ...)
```

## Description

The `json_doc` parameter specifies the JSON document, and `path` is a path parameter. If either parameter is `NULL`, `NULL` is returned.

The valid values of the `one_or_all` parameter are as follows:

* `'one'`: Returns 1 if the document contains at least one path; otherwise, returns 0.

* `'all'`: Returns 1 if all paths exist in the document, otherwise returns 0.

An error will be returned in the following scenarios:

* The `json_doc` parameter is not a valid JSON document.

* Any `path` parameter is not a valid path expression.

* The value of the `one_or_all` parameter is not `'one'` or `'all'`.
