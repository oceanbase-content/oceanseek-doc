# JSON_OVERLAPS

## Description

This function compares two JSON documents. If the two documents have common key-value pairs or array elements, it returns 1; otherwise, it returns 0.

## Syntax

```sql
JSON_OVERLAPS(json_doc1, json_doc2)
```

## Description

The parameters `json_doc1` and `json_doc2` specify the two JSON documents to be compared. If both parameters are scalars, the function performs a simple equality test.

This function corresponds to JSON_CONTAINS(). It requires that all elements of the search array are present in the target array. Therefore, JSON_CONTAINS() performs an `AND` operation on the search keys, whereas JSON_OVERLAPS() performs an `OR` operation.

When comparing two arrays, if they share one or more array elements, JSON_OVERLAPS() returns `1`; otherwise, it returns `0`.

Queries that use JSON_OVERLAPS() on a JSON column of an InnoDB table in the `WHERE` clause can be optimized using a multi-valued index.
