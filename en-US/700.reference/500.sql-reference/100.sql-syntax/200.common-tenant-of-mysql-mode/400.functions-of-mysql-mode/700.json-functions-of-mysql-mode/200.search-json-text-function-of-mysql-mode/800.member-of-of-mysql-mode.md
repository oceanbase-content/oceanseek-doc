# MEMBER OF

## Purpose

If the element being searched for is equal to any element in the JSON array, the function returns 1; otherwise, it returns 0.

## Syntax

```sql
value MEMBER OF(json_array)
```

## Description

If `value` is an element of `json_array`, return 1; otherwise, return 0.

`value` must be a scalar or a JSON document. If it is a scalar, the operator treats it as an element of a JSON array.

## Examples

```sql
obclient> SELECT 45 MEMBER OF('[123, "abc", 45, "ab", 10]');
+--------------------------------------------+
| 45 MEMBER OF('[123, "abc", 45, "ab", 10]') |
+--------------------------------------------+
|                                          1 |
+--------------------------------------------+
1 row in set

obclient> SELECT 'cd' MEMBER OF('[23, "abc", 17, "cd", 10]');
+---------------------------------------------+
| 'cd' MEMBER OF('[23, "abc", 17, "cd", 10]') |
+---------------------------------------------+
|                                           1 |
+---------------------------------------------+
1 row in set

obclient> SELECT 5 MEMBER OF('[123, "abc", 45, "ab", 10]');
+-------------------------------------------+
| 5 MEMBER OF('[123, "abc", 45, "ab", 10]') |
+-------------------------------------------+
|                                         0 |
+-------------------------------------------+
1 row in set

obclient> SELECT
       45 MEMBER OF('[23, "abc", "45", "ab", 10]'),
      "45" MEMBER OF('[23, "abc", 45, "ab", 10]')\G
```
