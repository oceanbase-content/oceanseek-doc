# JSON_CONTAINS

## Purpose

This function checks whether the specified JSON document is contained within the target JSON document, or whether the specified element is found at the specified path within the target document (if the `path` parameter is provided). If the specified JSON document is contained within the target JSON document, the function returns 1; otherwise, it returns 0.

If you only need to check whether data exists in a specified path, use JSON_CONTAINS_PATH() instead.

## Syntax

```sql
JSON_CONTAINS(target, candidate[, path])
```

## Description

The `candidate` parameter specifies the source JSON document, and the `target` parameter specifies the target JSON document.

If any parameter is `NULL`, or if the `path` parameter is not identified as part of the target document, `NULL` is returned.

An error occurs in any of the following scenarios:

* The `candidate` or `target` parameter is not a valid JSON document.

* The `path` parameter is not a valid path expression.

* The `path` parameter contains the \* or \*\* wildcard character.

This function follows these rules:

* For two single elements to be equal, their JSON_TYPE() must be the same and they must be comparable. For numeric types, this means they can be directly compared.

* For arrays, the `candidate` array is contained in the `target` array if and only if all elements of `candidate` are present in `target`.

* For objects, the `candidate` object is contained in the `target` object if and only if all keys of `candidate` are present in `target`, and the value corresponding to each key in `candidate` is equal to the value corresponding to that key in `target`.
