# JSON_SEARCH

## Purpose

This function returns the path of a specified string in a JSON document.

## Syntax

```sql
JSON_SEARCH(json_doc, one_or_all, search_str[, escape_char[, path] ...])
```

## Description

The `json_doc` parameter specifies the JSON document, `search_str` is the search string parameter, `escape_char` specifies a constant expression, and `path` is the path parameter.

If any parameter is `NULL`, the function returns `NULL`. It also returns `NULL` if the specified path does not exist in the document or if the specified string is not found.

The valid values of the `one_or_all` parameter are as follows:

* `'one'`: The search terminates after the first match and returns a path string.

* `'all'`: Searches for all matching path strings and returns them without duplicates. If multiple strings are found, they are automatically wrapped into an array. The order of the array elements is not guaranteed.

For the `search_str` parameter, the `%` and `_` characters have the same meaning as the `LIKE` operator, as follows:

* `%` matches any number of characters, including zero characters.

* `_` matches exactly one character.

To specify the `%` or `_` character in the search string, precede it with an escape character. If the `escape_char` parameter is missing or set to `NULL`, the default escape character is `\`. Otherwise, `escape_char` must be a null constant or character.

Regardless of the database's encoding value, `search_str` and `path` are always treated as UTF-8MB4 strings.

An error occurs in the following situations:

* The `json_doc` parameter does not specify a valid JSON document.

* The `path` parameter is not a valid path expression.

* The value of the `one_or_all` parameter is not `'one'` or `'all'`.

* `escape_char` is not a constant expression.
