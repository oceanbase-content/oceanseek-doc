# Overview of bitmap functions

Bitmap functions are a set of specialized functions provided in the OceanSeek system for efficiently compressing and processing bitmap data. These functions enable users to perform complex bitmap queries and analyses at the database level, allowing applications such as user behavior analysis, user profiling, and audience segmentation to store, query, and manipulate bitmap data efficiently.

The following table describes the bitmap functions in OceanSeek and their purposes:

## Bitmap function types

| Bitmap Function Types | Description |
| ------------------------------------------ | -------------------------------------------------------------------- |
| [Bitmap Constructor](200.roaring-bitmap-constructor-functions-of-mysql-mode.md) | A function for creating a new bitmap data type. |
| [Bitmap cardinality functions](300.roaring-bitmap-cardinality-calculation-functions-of-mysql-mode.md) | Used to calculate the cardinality of bitmap data. |
| [Bitmap arithmetic functions](400.roaring-bitmap-operation-functions-of-mysql-mode.md) | Provides functions for basic operations on bitmap data, such as intersection, union, XOR, and NAND. |
| [Bitmap predicate functions](500.roaring-bitmap-decision-functions-of-mysql-mode.md) | A function that performs some judgment on the input bitmap data and returns a boolean value. |
| [Bitmap output functions](600.roaring-bitmap-output-functions-of-mysql-mode.md) | A function used to select the output format for bitmap data. For example, it can output each element of the bitmap data as a string in sequence, separated by commas. |
| [Bitmap aggregate functions](700.roaring-bitmap-aggregate-functions-of-mysql-mode.md) | Provides functions for aggregating numeric types into a bitmap type, that is, performing aggregate operations on bitmap data. |
