# Overview of mapping functions

Mapping functions are a set of specialized functions provided in the OceanSeek system for processing mapped data. These functions enable users to perform complex mapping queries and analyses.

The following table describes some of the mapping functions provided by OceanSeek and their uses:

## Types of mapping functions

| Mapping Function Type | Description |
| ------------------------------------------ | -------------------------------------------------------------------- |
| [Constructor of Map](200.map-constructor-functions-of-mysql-mode.md) | A function for creating a new mapped data type. |
| [Mapping judgment function](300.map-decision-functions-of-mysql-mode.md) | A function that performs logical judgment on the input mapped data and returns a boolean value. |
| [Mapping functions](600.map-manipulation-functions-of-mysql-mode.md) | It is used to perform basic operations on the input map data, such as extracting keys and values, and returns the mapped data after the operation. |

## Overview of Mapping Functions

The following table describes all the mapping functions supported by OceanSeek:

| [Constructor of Map](200.map-constructor-functions-of-mysql-mode.md) | {} | Used to construct a mapped data. |
