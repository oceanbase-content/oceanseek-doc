# Operator overview

An operator is typically used to combine individual data items such as operands or parameters and return a result. Syntactically, an operator can appear before an operand, after an operand, or between two operands.

Common operators can also be classified as unary and binary operators:

* Unary operators

  A unary operator operates on a single operand. The general format of a unary operator is as follows:

  ```sql
  Operator Operand
  ```

* Binary operators

  A binary operator performs an operation on two operands. The general format of a binary operator is as follows:

  ```sql
  Operand 1 Operator Operand 2
  ```

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <ul>
    <li>Other operators with special formats can accept more than two operands.</li>
    <li>If an operator is provided with a null operand <code>NULL</code>, the result is always null. The only exception to this rule is the character concatenation operator (||).</li>
    </ul>
  </main>
