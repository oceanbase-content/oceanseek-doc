# Character concatenation operators

OceanSeek supports character concatenation operators.

The following table describes the character concatenation operators supported by the current version of OceanBase Database.

| operator | operand | Meaning |
| ------ | ----- | ------- |
| `\|\|` | binary | String concatenation |

The `||` operator can be used as a logical OR operator, which is controlled by the `sql_mode` setting:

* When `sql_mode` includes `PIPES_AS_CONCAT`, `||` is a character concatenation operator.

* If `sql_mode` does not contain `PIPES_AS_CONCAT`, `||` is a logical OR operator.
