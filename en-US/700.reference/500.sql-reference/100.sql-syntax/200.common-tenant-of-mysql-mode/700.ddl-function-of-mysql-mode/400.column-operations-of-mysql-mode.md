# Column operations

Column operations include appending a column, adding a non-terminating column, dropping a column, renaming a column, reordering columns, modifying column types, managing column defaults, managing constraints, and modifying auto-increment column values.

## Add a column

Adding a column can be done as either an **append-only operation** or a non-**append-only operation**, which are described below.

### Append-only operation

The syntax for appending a column to the end of a table is as follows:

```sql
ALTER TABLE table_name ADD COLUMN column_name data_type;
```

The related parameters are described as follows:

* `table_name`: Specifies the name of the table to which a column is to be added.

* `column_name`: Specifies the name of the column to be added.

* `data_type`: Specifies the data type of the column to be added.

Assume that a table named `tbl1` exists in the database. This example shows how to execute the statement to add a column `c1` to the end of the `tbl1` table.

1. View the schema of the `tbl1` table.

   ```shell
   obclient> DESCRIBE tbl1;
   ```

   The output is as follows, showing that the table contains three columns: `id`, `name`, and `age`.

   ```shell
   +-------+-------------+------+-----+---------+-------+
   | Field | Type        | Null | Key | Default | Extra |
   +-------+-------------+------+-----+---------+-------+
   | id    | int(11)     | NO   | PRI | NULL    |       |
   | name  | varchar(50) | NO   |     | NULL    |       |
   | age   | int(11)     | YES  |     | NULL    |       |
   +-------+-------------+------+-----+---------+-------+
   ```

2. Add a column `c1` to the end of the table and specify its data type as INT.

   ```shell
   obclient> ALTER TABLE tbl1 ADD COLUMN c1 INT;
   ```

3. View the schema of the `tbl1` table again.

   ```shell
   obclient> DESCRIBE tbl1;
   ```

   The output is as follows, showing that the `c1` column has been added to the end of the table.

   ```shell
   +-------+-------------+------+-----+---------+-------+
   | Field | Type        | Null | Key | Default | Extra |
   +-------+-------------+------+-----+---------+-------+
   | id    | int(11)     | NO   | PRI | NULL    |       |
   | name  | varchar(50) | NO   |     | NULL    |       |
   | age   | int(11)     | YES  |     | NULL    |       |
   | c1    | int(11)     | YES  |     | NULL    |       |
   +-------+-------------+------+-----+---------+-------+
   ```

### Non-append-only operation

The syntax for adding a column to a position other than the end of a table is as follows:

```sql
ALTER TABLE table_name
    ADD COLUMN new_column_name data_type
    {FIRST | BEFORE | AFTER} column_name;
```

The related parameters are described as follows:

* `table_name`: Specifies the name of the table to which a column is to be added.

* `new_column_name`: the name of the column to be added.

* `data_type`: the data type of the column to be added.

* `FIRST | BEFORE | AFTER`: Specifies the position where the column to be added is placed. It can be added at the beginning of the table (`FIRST`), before `column_name` (`BEFORE`), or after `column_name` (`AFTER`).

  <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>When using <code>FIRST</code> to add a column to the beginning of a table, you do not need to set <code>column_name</code>; otherwise, an error will occur. </p>
  </main>

* `column_name`: the name of the column corresponding to the position of the column to be added.

Assume a table named tbl1 exists in the database. The structure of the tbl1 table is as follows:

```shell
+-------+-------------+------+-----+---------+-------+
| Field | Type        | Null | Key | Default | Extra |
+-------+-------------+------+-----+---------+-------+
| id    | int(11)     | NO   | PRI | NULL    |       |
| name  | varchar(50) | NO   |     | NULL    |       |
| age   | int(11)     | YES  |     | NULL    |       |
+-------+-------------+------+-----+---------+-------+
```

This example shows how to execute the statement for adding columns by adding a `c1` column at the beginning of the `tbl1` table, a `c2` column before the `name` column, and a `c3` column after the `name` column.

1. Add a `c1` column to the header of table tbl1 and specify its data type as INT.

   ```shell
   obclient> ALTER TABLE tbl1 ADD COLUMN c1 INT FIRST;
   ```

2. Add a `c2` column before the `name` column in table `tbl1`, and specify its data type as VARCHAR.

   ```shell
   obclient> ALTER TABLE tbl1 ADD COLUMN c2 VARCHAR(50) BEFORE name;
   ```

3. Add a `c3` column after the `name` column in table `tbl1`. Specify the data type of this column as VARCHAR and add a NOT NULL constraint.

   ```shell
   obclient> ALTER TABLE tbl1 ADD COLUMN c3 VARCHAR(25) NOT NULL AFTER name;
   ```

4. View the table structure information of tbl1 again

   ```shell
   obclient> DESCRIBE tbl1;
   ```

   The output is as follows,

   ```shell
   +-------+-------------+------+-----+---------+-------+
   | Field | Type        | Null | Key | Default | Extra |
   +-------+-------------+------+-----+---------+-------+
   | c1    | int(11)     | YES  |     | NULL    |       |
   | id    | int(11)     | NO   | PRI | NULL    |       |
   | c2    | varchar(50) | YES  |     | NULL    |       |
   | name  | varchar(50) | NO   |     | NULL    |       |
   | c3    | varchar(25) | NO   |     | NULL    |       |
   | age   | int(11)     | YES  |     | NULL    |       |
   +-------+-------------+------+-----+---------+-------+
   ```

## Drop columns

The syntax for dropping a column is as follows:

```sql
ALTER TABLE table_name DROP COLUMN column_name
```

Here, `table_name` specifies the name of the table containing the column to be dropped; `column_name` specifies the name of the column to be dropped.

Assume a table named tbl1 exists in the database. The structure of tbl1 is as follows:

```shell
+-------+-------------+------+-----+---------+-------+
| Field | Type        | Null | Key | Default | Extra |
+-------+-------------+------+-----+---------+-------+
| id    | int(11)     | NO   | PRI | NULL    |       |
| name  | varchar(50) | NO   |     | NULL    |       |
| age   | int(11)     | YES  |     | NULL    |       |
+-------+-------------+------+-----+---------+-------+
```

This example shows you how to execute a statement for dropping a column by dropping the `name` column.

```shell
obclient> ALTER TABLE tbl1 DROP COLUMN name;
```

After the column is dropped, execute the `DESCRIBE tbl1;` command again to view the table structure of tbl1. The output is as follows. The `name` column no longer exists in table tbl1.

```shell
+-------+-------------+------+-----+---------+-------+
| Field | Type        | Null | Key | Default | Extra |
+-------+-------------+------+-----+---------+-------+
| id    | int(11)     | NO   | PRI | NULL    |       |
| age   | int(11)     | YES  |     | NULL    |       |
+-------+-------------+------+-----+---------+-------+
```

### Delete multiple columns

**Syntax:**

```sql
ALTER TABLE table_name DROP COLUMN column_name1, DROP COLUMN column_name2, ...;
```

Similar to dropping a single column, `table_name` specifies the name of the table containing the column to be dropped, and `column_name` specifies the name of the column to be dropped.
Assume a table named tbl1 exists in the database. The structure of tbl1 is as follows:

```shell
obclient> ALTER TABLE tbl1 DROP COLUMN C4, DROP COLUMN C5;
```


## Rename a column

You can rename a column by using either of the following syntaxes:

* Rename a column and modify its data type at the same time.

  ```sql
  ALTER TABLE table_name CHANGE old_col_name new_col_name data_type;
  ```

  The related parameters are described as follows:

  * `table_name`: The name of the table that contains the column to be renamed.

  * `old_col_name`: the name of the column to be renamed.

  * `new_col_name`: the name of the column after renaming.

  * `data_type`: Specifies the data type of the column to be renamed. You can specify the current data type or another data type to which the column will be modified. For information about the supported data types, see [Modify column type](#Modify column type).

* Rename columns only

  ```sql
  ALTER TABLE table_name RENAME COLUMN old_col_name TO new_col_name
  ```

  The related parameters are described as follows:

  * `table_name`: The name of the table that contains the column to be renamed.

  * `old_col_name`: the name of the column to be renamed.

  * `new_col_name`: the name of the column after renaming.

Assume a table named tbl1 exists in the database. The structure of table tbl1 is as follows:

```shell
+-------+-------------+------+-----+---------+-------+
| Field | Type        | Null | Key | Default | Extra |
+-------+-------------+------+-----+---------+-------+
| id    | int(11)     | NO   | PRI | NULL    |       |
| name  | varchar(50) | NO   |     | NULL    |       |
| age   | int(11)     | YES  |     | NULL    |       |
+-------+-------------+------+-----+---------+-------+
```

This topic uses the following examples to illustrate how to execute a statement for renaming columns: changing the column name `name` to `c2`, changing the column name `age` to `c3`, and changing the data type of the `age` column to VARCHAR.

1. Change the column name `name` to `c2`.

   ```shell
   obclient> ALTER TABLE tbl1 RENAME COLUMN name TO c2;
   ```

2. Rename the `age` column to `c3` and modify its data type to VARCHAR.

   ```shell
   obclient> ALTER TABLE tbl1 CHANGE age c3 VARCHAR(50);
   ```

3. Execute the `DESCRIBE tbl1;` command again to view the table structure of tbl1.

   The output is as follows. Table tbl1 has only three columns: `id`, `c2`, and `c3`, and the data type of column `c3` is VARCHAR.

   ```shell
   +-------+-------------+------+-----+---------+-------+
   | Field | Type        | Null | Key | Default | Extra |
   +-------+-------------+------+-----+---------+-------+
   | id    | int(11)     | NO   | PRI | NULL    |       |
   | c2    | varchar(50) | YES  |     | NULL    |       |
   | c3    | varchar(50) | YES  |     | NULL    |       |
   +-------+-------------+------+-----+---------+-------+
   ```

## Rearrange

The syntax for rearrangement is as follows:

```sql
ALTER TABLE table_name
    MODIFY [COLUMN] column_name data_type
    {FIRST | BEFORE | AFTER} column_name;
```

The related parameters are described as follows:

* `table_name`: The name of the table to be rearranged.

* `column_name`: The name of the column to be rearranged.

* `data_type`: Specifies the data type of the column to be rearranged. You can specify the current data type or a different data type to which the column will be modified. For information about the supported data types, see [Modify column type](#Modify column type).

* `FIRST | BEFORE | AFTER`: Specifies the position where the column to be added is placed. It can be added at the beginning of the table (`FIRST`), before `column_name` (`BEFORE`), or after `column_name` (`AFTER`).

  <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>When using <code>FIRST</code> to add a column to the beginning of a table, you do not need to set <code>column_name</code>; otherwise, an error will occur. </p>
  </main>

* `column_name`: the name of the column related to the position to be rearranged.

Assume that a table named tbl1 exists in the database. The table structure of tbl1 is as follows:

```shell
+-------+-------------+------+-----+---------+-------+
| Field | Type        | Null | Key | Default | Extra |
+-------+-------------+------+-----+---------+-------+
```

This example shows you how to use the rearrange statement by reordering the `age` column before the `name` column and changing the data type of the `age` column to VARCHAR.

## Manage column defaults

You can modify or delete the default value of a column in OceanBase AI Database. This section describes how to perform these operations.

### Modify the default value of a column

```sql
ALTER TABLE table_name ALTER COLUMN column_name SET DEFAULT const_value;
```

The related parameters are described as follows:

## Manage constraints

OceanBase AI Database allows you to add column constraints to tables, such as changing an existing column to an auto-increment column, setting whether a column can be null, and specifying column uniqueness. This section describes how to perform these operations.

The syntax for managing constraints is as follows:

```sql
ALTER TABLE table_name
    MODIFY [COLUMN] column_name data_type
    [AUTO_INCREMENT]
    [NULL | NOT NULL]
    [[PRIMARY] KEY]
    [UNIQUE [KEY]];
```

The related parameters are described as follows:

* `table_name`: the name of the table that contains the column to which you want to add a constraint.

* `column_name`: The name of the column to which the constraint is added.

* `data_type`: Specifies the data type of the column to be modified. You can specify the current data type or another data type to which the column is to be modified. For information about the supported data types, see [Modify column type](#Modify column type).

* `AUTO_INCREMENT`: specifies that the selected column is an auto-increment column.

* `NULL | NOT NULL`: specifies whether the selected column can be null (`NULL`) or cannot be null (`NOT NULL`).

* `[PRIMARY] KEY`: specifies to set the selected column as the primary key.

* `UNIQUE [KEY]`: specifies to set uniqueness for the selected column.

Assume that a table named tbl1 exists in the database. The structure of table tbl1 is as follows:

```shell
+-------+-------------+------+-----+---------+-------+
| Field | Type        | Null | Key | Default | Extra |
+-------+-------------+------+-----+---------+-------+
| id    | int(11)     | YES  |     | NULL    |       |
| name  | varchar(50) | YES  |     | NULL    |       |
| age   | int(11)     | YES  |     | NULL    |       |
+-------+-------------+------+-----+---------+-------+
```

1. Set the `id` column as the primary key.

   ```shell
   obclient> ALTER TABLE tbl1 MODIFY COLUMN id INT PRIMARY KEY;
   ```

2. Set the `id` column as an auto-increment column.

   ```shell
   obclient> ALTER TABLE tbl1 MODIFY COLUMN id INT AUTO_INCREMENT;
   ```

3. Set the `name` column to NOT NULL

   ```shell
   obclient> ALTER TABLE tbl1 MODIFY COLUMN name VARCHAR(50) NOT NULL;
   ```

4. Set the `age` column to be unique

   ```shell
   obclient> ALTER TABLE tbl1 MODIFY COLUMN age INT UNIQUE;
   ```

5. Execute the `DESCRIBE tbl1;` command again to view the table structure of tbl1.

   ```shell
   +-------+-------------+------+-----+---------+----------------+
   | Field | Type        | Null | Key | Default | Extra          |
   +-------+-------------+------+-----+---------+----------------+
   | id    | int(11)     | NO   | PRI | NULL    | auto_increment |
   | name  | varchar(50) | NO   |     | NULL    |                |
   | age   | int(11)     | YES  | UNI | NULL    |                |
   +-------+-------------+------+-----+---------+----------------+
   ```

## Modify the value of an auto-increment column

The syntax for modifying the value of an auto-increment column is as follows:

```sql
ALTER TABLE table_name [SET] AUTO_INCREMENT = next_value;
```

This example assumes a table named tbl1 exists in the database. It demonstrates how to modify the value of an auto-increment column by setting it to 12.

```shell
obclient> ALTER TABLE tbl1 AUTO_INCREMENT = 12;
```

After the modification, the next auto-increment value for the tbl1 table will be set to 12. When inserting new records, the auto-increment column (for example, `c1`) will start incrementing from 12.
