# Overview

A character set is a set of symbols and their encoding. A collation is a set of rules for comparing characters within a character set.

Regarding character sets and collations, OceanBase AI Database supports the following features:

* Store strings using various character sets.

* Compare strings using various collations.

* Mixing strings with different character sets or collations within the same server, database, or table.

* You can enable character set and collation specifications at the database, table, or column level.
