# Overview of the JSON data type

OceanBase AI Database supports the JSON (JavaScript Object Notation) data type that complies with the RFC 7159 standard. Users can store semi-structured JSON data and access and modify data within JSON documents.

The JSON data type has the following advantages:

* Automatically validates JSON documents stored in JSON columns. Invalid documents will report an error.

* JSON documents stored in JSON columns can be converted into a format that facilitates fast reading and access. When the server needs to read a JSON value stored in binary format, it does not need to parse the value from text.

* Supports semi-structured encoding for user tenants to further reduce storage costs. It can split a JSON data into multiple subcolumns for storage, with each subcolumn encoded separately to improve encoding compression ratio and reduce the storage space required for the JSON data. For usage and examples, see [Create a JSON value](200.create-a-json-value-of-mysql-mode.md) and [Semi-structured encoding](600.json-semi-struct-of-mysql-mode.md).
