# Overview of Array Element Types

OceanBase AI Database supports the array data type (ARRAY). The array type can be used to store and process multiple elements of the same type.

The current version of OceanBase AI Database supports the following data types for array elements:

* Integer types: `TINYINT`, `SMALLINT`, `INT`/`INTEGER`, and `BIGINT`.

* Floating-point types: `FLOAT` and `DOUBLE`.

* String type: `VARCHAR`.

The description is as follows:

* Array type is a commonly used data type in OLAP scenarios, primarily for storing and processing multiple pieces of data of the same type.

* When describing a multi-valued attribute of an entity (for example, a product belonging to multiple categories, multiple tags for a user, or multiple measurement values from a sensor), using an array type can more naturally represent this relationship.

* In data analysis, it is often used to determine whether a specific value is present in an array.

The limitations are as follows:

* The array data type does not support setting a default value.

In addition to the array data type, functions are also provided for array data. For more information, see [Overview of array functions](../../../400.functions-of-mysql-mode/950.array-functions-of-mysql-mode/100.array-functions-overview-of-mysql-mode.md).
