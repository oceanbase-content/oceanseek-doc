# BIT-Value type

The `BIT` data type is used to store bit values.

Bit values are specified in the form of `b'value'`, where `value` is represented by 0s and 1s. For example, `b'111'` represents 7, and `b'10000000'` represents 128.

The syntax is as follows:

```sql
BIT[(M)]
```

`M` indicates the number of bits for each value, with a range of \[1, 64\]. If `M` is omitted, the default value of 1 is used.

When inserting a value into a `BIT(M)` column, if the length of the inserted value is less than `M`, zeros are padded on the left. For example, inserting `b'101'` into a `BIT(6)` column is equivalent to inserting `b'000101'`.
