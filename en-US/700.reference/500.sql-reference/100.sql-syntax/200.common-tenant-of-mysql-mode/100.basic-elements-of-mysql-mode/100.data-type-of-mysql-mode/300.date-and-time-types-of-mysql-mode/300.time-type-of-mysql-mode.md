# TIME type

The `TIME` data type can represent a specific time of day, elapsed time, or the time interval between two events (which may be much longer than 24 hours).

OceanBase AI Database allows you to assign values to a `TIME` column by using either strings or numbers.

The retrieval and display format for `TIME` values is `'hh:mm:ss'`, with a range from '-838:59:59' to '838:59:59'.

The display format for `TIME` values can also include a fractional second part, in the format `'hh:mm:ss[.fraction]'`. The precision can reach up to microseconds (6 digits), with a range from '-838:59:59.000000' to '838:59:59.000000'. The fractional part must always be separated from other time fields by a decimal point; other separators are not recognized.

The syntax for `TIME` is as follows:

```sql
TIME[(fsp)]
```

The optional `fsp` value specifies the precision of the fractional seconds, with a range of \[0,6\]. A value of 0 indicates no fractional part. If omitted, the default precision is 0.
