# Overview of spatial data types

The Geographic Information System (GIS) feature of OceanSeek supports the following spatial data types:

* `GEOMETRY`

* `POINT`

* `LINESTRING`

* `POLYGON`

* `MULTIPOINT`

* `MULTILINESTRING`

* `MULTIPOLYGON`

* `GEOMETRYCOLLECTION`

Among these, `POINT`, `LINESTRING`, and `POLYGON` are the three most fundamental types for storing individual spatial data. They respectively extend the collection types `MULTIPOINT`, `MULTILINESTRING`, and `MULTIPOLYGON` for storing collections of spatial data, but can only represent collections of their specified base types. `GEOMETRY` is a virtual type that can represent any base type, and `GEOMETRYCOLLECTION` can be a collection of any `GEOMETRY` type.
