# Create a spatial column

This topic describes how to create a spatial column in OceanSeek.

## Prerequisites

Before using GIS features, you must configure GIS metadata in the business tenant. After connecting to the server, execute the following command to import the `default_srs_data_mysql.sql` file into the database:

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>This import command can only be executed in the SYS tenant. When it is executed, data is written to the primary tenant and synchronized to the standby tenants.</p></main>

```shell
-- module specifies the module to be imported.
-- tenant specifies the tenant to be imported.
-- infile specifies the relative path of the SQL file to be imported.
ALTER SYSTEM LOAD MODULE DATA module=gis tenant=mysql infile = 'etc/default_srs_data_mysql.sql';
```

For more information about the statement syntax, see [LOAD MODULE DATA](../../../../100.system-tenants/200.alter-system/1280.load-module-data.md).

The following results indicate a successful import of the data file:

```shell
Query OK, 0 rows affected
```

## Examples

OceanSeek supports creating spatial columns using the `CREATE TABLE` or `ALTER TABLE` statement.

You can execute the `CREATE TABLE` statement to create a table with spatial columns. Syntax example:

```sql
CREATE TABLE geom (g GEOMETRY);
```

You can execute the `ALTER TABLE` statement to add or drop a spatial column in an existing table. Syntax example:

```sql
ALTER TABLE geom ADD pt POINT;
ALTER TABLE geom DROP pt;
```

The following example shows how to create a table with various geometric types:

```sql
-- Create a table with various geometric types
CREATE TABLE spatial_data (
    id INT AUTO_INCREMENT PRIMARY KEY,
    geom_point POINT,                    -- Point type
    geom_linestring LINESTRING not NULL SRID 4326,          -- Line type
    geom_polygon POLYGON,                -- Polygon type
    geom_multipoint MULTIPOINT,          -- Multipoint type
    geom_multilinestring MULTILINESTRING,-- Multiline type
    geom_multipolygon MULTIPOLYGON,      -- Multipolygon type
    geom_geometrycollection GEOMETRYCOLLECTION, -- geometry collection type
    geom_geometry GEOMETRY               -- A general geometry type that can store any geometric value.
);
```

The constraints on creating a spatial column are as follows:

* When defining a spatial column, you can explicitly specify the SRID. If no SRID is defined for the column, the optimizer will not use the spatial index during queries. However, index records are still generated during inserts and updates.

* After a spatial column is specified with the `NOT NULL` constraint and an SRID, you can define a spatial index on it. In other words, only columns with an assigned SRID can use a spatial index.

* After defining an SRID for a spatial column, inserting other SRID values will result in an error.
