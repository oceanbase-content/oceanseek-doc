# Enumeration types

The `ENUM` data type is a string object that can have only one value, which must be a quoted string literal from the list `'value1', 'value2', ...`.

`ENUM` values are internally represented as integers. An `ENUM` column can contain up to 65,535 different elements (the actual limit is less than 3,000). `ENUM` is a variable-length type that supports the `UTF8MB4` character set.

The syntax for `ENUM` is as follows:

```sql
ENUM('value1','value2',...) [CHARACTER SET charset_name] [COLLATE collation_name]
```

`CHARACTER SET` specifies the character set. If necessary, you can use the `COLLATE` attribute and other attributes to specify the collation for the character set.

The `ENUM` type has the following advantages:

* The input string is automatically encoded as a number for compressed data storage.

* Readable queries and outputs. Numbers are converted back into the corresponding strings in the query results.
