# Character type overview

OceanSeek supports the character data types `CHAR`, `VARCHAR`, `BINARY`, and `VARBINARY`.

The following table describes the regular character types supported by the current version of OceanSeek and their related information.

| Type | Length type | Maximum Length | Character set |
| ------------- | ------ | ---------- | ----------- |
| `CHAR` | Fixed Length | 256 characters | `UTF8MB4` |
| `VARCHAR` | variable | 262,144 characters | `UTF8MB4` |
| `BINARY` | Fixed Length | 256 bytes | `BINARY` |
| `VARBINARY` | variable | 10,485,760 bytes | `BINARY` |

The `CHAR` type uses characters as the length unit. The `VARCHAR` type and the binary string types `BINARY` and `VARBINARY` use bytes as the length unit.
