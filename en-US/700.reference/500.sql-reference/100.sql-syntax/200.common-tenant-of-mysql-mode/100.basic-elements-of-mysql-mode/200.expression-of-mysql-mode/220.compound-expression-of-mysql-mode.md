# Compound Expressions

A compound expression is an expression formed by combining various types of expressions using arithmetic operations, bitwise operations, or grouping with parentheses.

The syntax for a compound expression is as follows:

```sql
{ simple_expr
| bit_expr { + | - | * | / | % | MOD | DIV } bit_expr
| bit_expr { & | | | ^ } bit_expr
| bit_expr { << | >> } bit_expr
| bit_expr { + | - } INTERVAL expr date_unit
}
```

Where:

* The arithmetic operators `+`, `-`, `*`, `/`, `%` (or `MOD`), and `DIV` are used to calculate the result between two `bit_expr` expressions.
* Bitwise operators `&` (AND), `|` (OR), `^` (XOR), `<<` (left shift), and `>>` (right shift) are used for integer expressions.
* `bit_expr + INTERVAL expr date_unit` and `bit_expr - INTERVAL expr date_unit` are used for date and time operations. For more information, see [Date and time expressions](250.date-and-time-expressions-of-mysql-mode.md).

You can use any built-in function as a simple expression to construct compound expressions.

The following are some examples of valid compound expressions:

* `(1 + 2) * 3`

* `LENGTH('OCEANBASE') * 2`

* `(salary + bonus) * 1.1`

* `NOW() + INTERVAL 7 DAY`
