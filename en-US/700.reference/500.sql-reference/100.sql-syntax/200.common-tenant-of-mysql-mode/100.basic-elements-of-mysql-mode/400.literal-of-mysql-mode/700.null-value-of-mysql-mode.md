# NULL values

A `NULL` value indicates "no data".

`NULL` is case-insensitive. Its synonym is `\N` (case-sensitive). Note that a `NULL` value is different from the number 0 and the empty string `''`.

When sorting using `ORDER BY`, for ascending order, `NULL` values are placed before other values; for descending order, `NULL` values are placed after other values.

In `LOAD DATA` or `SELECT ... INTO OUTFILE`, you can use \N to represent NULL.

**Example:**

```sql
obclient [test]> SELECT 1, NULL, \N FROM dual;
```

The return result is as follows:

```shell
+------+------+------+
| 1    | NULL | NULL |
+------+------+------+
|    1 | NULL | NULL |
+------+------+------+
1 row in set
```
