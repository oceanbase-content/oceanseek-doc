# Overview of Literals

A literal is used to express a fixed value.

Many functions and SQL statements require specifying literals, which can also be part of expressions and conditions.

OceanBase AI Database supports the following literals:

* [String text](../400.literal-of-mysql-mode/200.string-literal-of-mysql-mode.md)

* [Numbers](../400.literal-of-mysql-mode/300.numeric-value-of-mysql-mode.md)

* [Date and time values](../400.literal-of-mysql-mode/400.date-and-time-of-mysql-mode.md)

* [Bit value](../400.literal-of-mysql-mode/500.hexadecimal-numeric-of-mysql-mode.md)

* [Boolean values](../400.literal-of-mysql-mode/600.boolean-of-mysql-mode.md)

* [NULL values](../400.literal-of-mysql-mode/700.null-value-of-mysql-mode.md)
