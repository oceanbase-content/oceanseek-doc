# Bit value

Bit values start with the prefix `b` /`B` and `0b` /`0B`, followed by binary digits consisting of `0` and `1`.
The following are valid bit values:

```sql
b'11'
B'11'
0b11
0B11
```

The following are invalid bit values:

```sql
b'3' (3 is not a binary digit)
```

By default, a bit value is a binary string:

```sql
obclient> SELECT b'1000001', CHARSET(b'1000001');
+------------+---------------------+
| b'1000001' | CHARSET(b'1000001') |
+------------+---------------------+
| A          | binary              |
+------------+---------------------+
1 row in set

obclient> SELECT 0b1100001, CHARSET(0b1100001);
+-----------+--------------------+
| 0b1100001 | CHARSET(0b1100001) |
+-----------+--------------------+
| a         | binary             |
+-----------+--------------------+
1 row in set
```

OceanSeek treats bit values as integers. To ensure that a bit value is not processed as a number, you can add a leading `0` or use `CAST(... AS UNSIGNED)`. By default, a bit value assigned to a user-defined variable is a binary string.

```sql
obclient>  SET @v1 = b'1100001';
Query OK, 0 rows affected

obclient> SET @v2 = b'1100001'+0;
Query OK, 0 rows affected

obclient> SET @v3 = CAST(b'1100001' AS UNSIGNED);
Query OK, 0 rows affected

obclient> SELECT @v1, @v2, @v3;
+------+------+------+
| @v1  | @v2  | @v3  |
+------+------+------+
| a    |   97 |   97 |
+------+------+------+
1 row in set
```
