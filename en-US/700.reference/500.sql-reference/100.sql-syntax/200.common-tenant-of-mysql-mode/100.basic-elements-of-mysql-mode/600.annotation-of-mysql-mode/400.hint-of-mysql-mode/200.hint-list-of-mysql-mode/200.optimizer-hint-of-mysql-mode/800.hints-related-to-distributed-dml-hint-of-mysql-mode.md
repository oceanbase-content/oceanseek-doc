# Distributed DML Hints under Optimized Hint Type

In OceanSeek, distributed DML hints are used to control whether DML operations are performed in a distributed manner. Note the following two important concepts:

- Distributed DML: Specifically refers to DML operations executed across multiple nodes, which are fundamentally different from non-distributed DML operations that are executed locally or partition-wise on a single node.
- Parallel DML: Refers to the situation where a single DML operation is executed in parallel by multiple threads within a single node.

Furthermore, although such hints can be used to fix execution plans, they are not recommended for general use and are typically enabled only in OUTLINE DATA.

| Hint name | Explanation |
| --------------------------------------- | ------------ |
| `USE_DISTRIBUTED_DML` | Enables distributed DML operations. Its reverse operation is `NO_USE_DISTRIBUTED_DML`. |
| `NO_USE_DISTRIBUTED_DML` | Disables distributed DML operations. Its reverse operation is `USE_DISTRIBUTED_DML`. |

## `USE_DISTRIBUTED_DML` Hint

The `USE_DISTRIBUTED_DML` hint enables distributed DML operations. After this hint is enabled, DML operations will be executed in a distributed manner. Its counterpart is the `NO_USE_DISTRIBUTED_DML` hint.

### Syntax

```sql
/*+ USE_DISTRIBUTED_DML [ ( [ @ qb_name ] ) ] */
```

### Examples

```sql
-- Create a table named tp1 with 10 partitions in hash partitioning.
CREATE TABLE tp1(c1 INT, c2 INT, c3 INT) PARTITION BY HASH(c1) PARTITIONS 10;

-- Use the USE_DISTRIBUTED_DML hint to update column c2 of table tp1 to 4, where the condition is that the value in column c1 is less than 4.
-- This update operation will be executed in a distributed manner.
EXPLAIN BASIC UPDATE /*+ USE_DISTRIBUTED_DML */ tp1 SET c2 = 4 WHERE c1 < 4;
```

## `NO_USE_DISTRIBUTED_DML` Hint

The `NO_USE_DISTRIBUTED_DML` hint prohibits distributed execution for DML operations. Its counterpart is the `USE_DISTRIBUTED_DML` hint.

### Syntax

```sql
/*+ NO_USE_DISTRIBUTED_DML [ ( [ @ qb_name ] ) ] */
```

### Examples

```sql
-- Create a table named tp1 with 10 partitions in hash partitioning.
CREATE TABLE tp1(c1 INT, c2 INT, c3 INT) PARTITION BY HASH(c1) PARTITIONS 10;

-- Use the NO_USE_DISTRIBUTED_DML hint to restrict update operations from being executed locally on a single node instead of distributed.
-- This update operation will be non-distributed execution.
```
