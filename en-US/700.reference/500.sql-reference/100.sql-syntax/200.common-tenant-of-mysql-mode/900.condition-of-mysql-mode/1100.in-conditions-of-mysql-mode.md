# IN Condition

An IN condition is a membership condition. It tests whether a value is a member of a list of values or subqueries.

## Syntax

```sql
expr [ NOT ] IN  ({ expression_list | subquery })
```

## Usage instructions

IN conditions mainly have the following two forms:

* `IN` indicates that the value is a member of the set. Example:

  ```sql
  SELECT * FROM emp WHERE job_id IN ('PU_CLERK','SH_CLERK') ORDER BY emp_id;

  SELECT * FROM emp WHERE salary IN (SELECT salary FROM emp WHERE dept_id =30)
    ORDER BY emp_id;
  ```

* `NOT IN` indicates that the value is not a member of the set. If any member in the set is `NULL`, the result is `FALSE` or `UNKNOWN`. Example:

  ```sql
  SELECT * FROM emp WHERE salary NOT IN (SELECT salary FROM emp WHERE dept_id = 30)
    ORDER BY emp_id;

  SELECT * FROM emp WHERE job_id NOT IN ('PU_CLERK', 'SH_CLERK') ORDER BY emp_id;
  ```

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>If the result of any item in the list following the <code>NOT IN</code> operation is <code>NULL</code>, then the result for all rows is <code>FALSE</code> or <code>UNKNOWN</code>, and no rows are returned.</p>
</main>
