# OceanBase Binlog Service

OceanBase Binlog Service (Binlog Service) collects transaction logs from OceanSeek and converts them into MySQL binlogs. It is mainly used in scenarios such as real-time data subscription.

## Components involved

OceanBase Binlog Service consists of the following three components:

* OceanSeek: The business database that generates binlogs.

* OceanBase Database Proxy: The ODP (also known as OBProxy) of the business database, which provides connection services for clients that subscribe to binlogs.

* OceanBase Binlog Tool: The core component of OceanBase Binlog Service, obbinlog (formerly oblogproxy), which pulls clogs and generates binlogs.

## Binlog Service documentation

For more information about Binlog Service and its usage, see [OceanBase Binlog Service](https://docs.oceanbase.com/oblogproxy).
