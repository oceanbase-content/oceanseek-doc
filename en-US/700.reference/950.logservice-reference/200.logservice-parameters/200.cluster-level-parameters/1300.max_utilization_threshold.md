# max_utilization_threshold

## Purpose

The upper limit (in percentage) of disk or resource utilization of a node in log stream load balancing. Migration is triggered when this limit is exceeded.

## Attributes

| **Attribute** | **Description** |
| --- | --- |
| Parameter type | u8 |
| Default value | 60 |
| Value range | 0–100 |
| Effective mode | dynamic |
