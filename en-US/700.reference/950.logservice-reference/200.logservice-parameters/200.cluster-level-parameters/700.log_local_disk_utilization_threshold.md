# log_local_disk_utilization_threshold

## Purpose

The local disk usage threshold (in percentage). When this threshold is exceeded, the disk pressure handling logic is triggered.

## Attributes

| **Attribute** | **Description** |
| --- | --- |
| Parameter type | u16 |
| Default value | 80 |
| Value range | 0–100 |
| Effective mode | dynamic |
