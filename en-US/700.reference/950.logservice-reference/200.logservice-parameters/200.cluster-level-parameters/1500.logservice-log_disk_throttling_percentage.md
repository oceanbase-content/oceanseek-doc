# log_disk_throttling_percentage

## Purpose

The threshold at which progressive throttling of the log disk starts, expressed as a percentage of the total log disk capacity. Throttling starts when the space occupied by unreclaimable logs exceeds this threshold.

## Attributes

| **Attribute** | **Description** |
| --- | --- |
| Parameter type | u16 |
| Default value | 70 |
| Value range | 1–100. No progressive throttling range is generated when the write stop threshold is reached or exceeded. |
| Effective mode | dynamic |
