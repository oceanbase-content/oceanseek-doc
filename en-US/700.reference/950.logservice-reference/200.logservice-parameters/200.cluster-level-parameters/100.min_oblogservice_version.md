# min_oblogservice_version

## Purpose

Specifies the minimum oblogservice version that the cluster is allowed to run. This version can be increased only during an upgrade and must not be manually rolled back.

## Attributes

| **Attribute** | **Description** |
| --- | --- |
| Parameter type | String |
| Default value | Current build version |
| Value range | A valid x.y.z version string |
| Effective mode | dynamic |
