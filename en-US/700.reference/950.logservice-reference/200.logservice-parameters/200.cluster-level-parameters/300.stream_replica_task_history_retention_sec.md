# stream_replica_task_history_retention_sec

## Purpose

Specifies the retention period (in seconds) of the history of log stream replica migration or replication tasks.

## Attributes

| **Attribute** | **Description** |
| --- | --- |
| Parameter type | u64 |
| Default value | 604800 (7 days) |
| Value range | Unlimited |
| Effective mode | dynamic |
