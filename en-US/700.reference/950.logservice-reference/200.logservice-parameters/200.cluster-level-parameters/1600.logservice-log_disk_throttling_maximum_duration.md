# log_disk_throttling_maximum_duration

## Purpose

Specifies the maximum latency duration (in milliseconds) for progressive throttling of the log disk. If this parameter is set to 0, progressive throttling is disabled.

## Attributes

| **Attribute** | **Description** |
| --- | --- |
| Parameter type | u64 |
| Default value | 600000 (10 minutes) |
| Value range | 0–7200000 (0 indicates disabled; the maximum duration is 2 hours) |
| Effective mode | dynamic |
