# min_utilization_threshold

## Purpose

The lower limit (in percentage) of disk or resource utilization of a node in log stream load balancing. When the utilization falls below this limit, only `UnderUtilized` resource events are recorded for observation, and migration is not triggered.

## Attributes

| **Attribute** | **Description** |
| --- | --- |
| Parameter type | u8 |
| Default value | 30 |
| Value range | 0–100 |
| Effective mode | dynamic |
