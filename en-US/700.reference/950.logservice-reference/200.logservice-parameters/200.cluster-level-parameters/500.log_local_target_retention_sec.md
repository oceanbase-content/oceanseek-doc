# log_local_target_retention_sec

## Purpose

Specifies the target retention period (in seconds) of the local logs of each stream. This period is guaranteed as much as possible, but may be shortened under disk pressure.

## Attributes

| **Attribute** | **Description** |
| --- | --- |
| Parameter type | u64 |
| Default value | 30 |
| Value range | Unlimited |
| Effective mode | dynamic |
