# node_permanent_offline_time_sec

## Purpose

A node is marked as permanently offline after it remains offline continuously for longer than the configured duration.

## Attributes

| **Attribute** | **Description** |
| --- | --- |
| Parameter type | u64 |
| Default value | 1800 (30 minutes) |
| Value range | Unlimited |
| Effective mode | dynamic |
