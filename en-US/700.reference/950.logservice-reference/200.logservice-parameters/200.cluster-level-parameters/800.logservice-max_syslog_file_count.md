# max_syslog_file_count

## Purpose

Specifies the maximum number of log files (`oblogservice.log`) retained after rolling. A value of 0 indicates no limit.

## Attributes

| **Attribute** | **Description** |
| --- | --- |
| Parameter type | u64 |
| Default value | 200 |
| Value range | Unrestricted (0 indicates no restriction) |
| Effective mode | dynamic |
