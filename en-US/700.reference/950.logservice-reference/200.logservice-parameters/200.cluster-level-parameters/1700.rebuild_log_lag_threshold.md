# rebuild_log_lag_threshold

## Purpose

Controls the replica log lag threshold that triggers automatic Rebuild in LogService. When the difference between the uploaded anchor LSN broadcast by the Log Manager (LM) and the local `max_flushed_lsn` of the lagging log node (LN) reaches this threshold, the lagging LN replica can trigger a Rebuild to resume synchronization from after the uploaded anchor. A value of 0 disables automatic Rebuild triggering.

## Attributes

| **Attribute** | **Description** |
| --- | --- |
| Parameter type | ReadableSize |
| Default value | 1048512 KB (16 * (64 MB - 4 KB), 16 logical log blocks, nearly 1 GB) |
| Value range | A capacity value of 0 or a positive number, in units such as B, KB, MB, GB, TB, and PB. |
| Effective mode | dynamic |
