# object_store_url

## Purpose

The access address of the object storage service. Only the `s3://` protocol (for AWS S3 and S3-compatible object storage) and the `azblob://` protocol (for Azure Blob) are supported. Other protocols are not supported.

## Attributes

| **Attribute** | **Description** |
| --- | --- |
| Parameter type | String |
| Default value | "" (empty) |
| Value range | Only URL strings starting with `s3://` or `azblob://` are supported. |
| Effective mode | readonly |
