# memory_limit

## Purpose

Specifies the maximum memory that the process can use. If this parameter is set to 0, the process uses 70% of the physical memory of the system by default. The total memory used by the process must not exceed the total physical memory of the system.

## Attributes

| **Attribute** | **Description** |
| --- | --- |
| Parameter type | ReadableSize |
| Default value | 0MB |
| Value range | 0 or a positive integer. Supported units include MB and GB. |
| Effective mode | dynamic |
