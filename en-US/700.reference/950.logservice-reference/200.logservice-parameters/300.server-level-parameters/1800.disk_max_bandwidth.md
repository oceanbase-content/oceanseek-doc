# disk_max_bandwidth

## Purpose

The estimated maximum disk bandwidth, used for I/O rate limiting. The default value is `0`, indicating that bandwidth is not configured. If the `load_based` balancing policy is configured, this parameter must be greater than 0.

## Attributes

| **Attribute** | **Description** |
| --- | --- |
| Parameter type | ReadableSize |
| Default value | 0 (not configured) |
| Value range | A non-negative integer greater than or equal to 0. Supported units include KB, MB, and GB. |
| Effective mode | dynamic |
