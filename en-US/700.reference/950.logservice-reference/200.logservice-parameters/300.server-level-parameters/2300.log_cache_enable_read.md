# log_cache_enable_read

## Purpose

This parameter is the read switch for LogCache. It is enabled by default. If it is set to `false`, both log upload and read operations access the disk directly without using the cache, which effectively disables the cache. This is suitable for emergency rollbacks or for comparing performance before and after enabling the cache (baseline comparison).

## Attributes

| **Attribute** | **Description** |
| --- | --- |
| Parameter type | bool |
| Default value | true |
| Value range | true / false |
| Effective mode | dynamic |
