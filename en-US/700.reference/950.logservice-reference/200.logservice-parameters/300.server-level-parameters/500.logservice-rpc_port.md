# rpc_port

## Purpose

The port on which the node's gRPC service listens. It forms the listening address together with `local_ip`.

## Attributes

| **Attribute** | **Description** |
| --- | --- |
| Parameter type | u16 |
| Default value | 50051 |
| Value range | 1–65535 |
| Effective mode | readonly |
