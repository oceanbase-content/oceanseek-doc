# log_cache_memory_percentage

## Purpose

The percentage of `memory_limit` that LogCache capacity can use (if `memory_limit` is set to 0, 70% of the total system memory is used). The actual capacity has a lower limit of 256 MB. If this parameter is set to 0, the cache is completely disabled.

## Attributes

| **Attribute** | **Description** |
| --- | --- |
| Parameter type | u8 |
| Default value | 20 |
| Value range | 0–100 |
| Effective mode | static |
