# disk_max_iops

## Purpose

The estimated maximum disk IOPS, used for I/O rate limiting. The default value is `0`, indicating that IOPS is not configured. If the `load_based` balancing policy is configured, this parameter must be greater than 0.

## Attributes

| **Attribute** | **Description** |
| --- | --- |
| Parameter type | u64 |
| Default value | 0 (not configured) |
| Value range | An integer greater than or equal to 0. |
| Effective mode | dynamic |
