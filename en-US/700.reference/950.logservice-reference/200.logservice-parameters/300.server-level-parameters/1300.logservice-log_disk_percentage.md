# log_disk_percentage

## Purpose

The percentage of the total file system space allocated to logs. This parameter takes effect only when `log_disk_size` is set to 0. The value must be in the range [1, 99]. A value of 0 or greater than or equal to 100 causes disk quota parsing to fail.

## Attributes

| **Attribute** | **Description** |
| --- | --- |
| Parameter type | u8 |
| Default value | 90 |
| Value range | 1–99 (0 and ≥100 are invalid) |
| Effective mode | dynamic |
