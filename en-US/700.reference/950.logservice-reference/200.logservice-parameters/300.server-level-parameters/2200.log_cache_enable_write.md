# log_cache_enable_write

## Purpose

This parameter specifies whether to enable write caching for LogCache. It is enabled by default. If you set this parameter to `false`, the cache stops accepting new write data (while retaining existing cached data). When used together with `log_cache_enable_read` set to `false`, it can downgrade the cache to a completely cold state without restarting the node. This is useful for emergency rollbacks or for comparing performance before and after enabling the cache (baseline comparison).
