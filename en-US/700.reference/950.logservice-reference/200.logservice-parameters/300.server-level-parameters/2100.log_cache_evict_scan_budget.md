# log_cache_evict_scan_budget

## Purpose

This LogCache tuning parameter limits the maximum budget for scanning reusable space in the cache during a single log publish operation, thereby constraining the tail latency of the publishing process. When the cache space is insufficient and the scan budget is exhausted, the current publish operation is abandoned without blocking the main log write process. This parameter generally does not require adjustment, and you can keep the default value.
