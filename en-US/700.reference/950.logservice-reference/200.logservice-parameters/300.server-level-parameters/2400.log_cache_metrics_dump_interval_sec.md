# log_cache_metrics_dump_interval_sec

## Purpose

The interval (in seconds) at which each node outputs `log_cache_metrics` monitoring logs. A value of 0 disables this feature (the default, which causes no behavior change during an upgrade). If you set it to a value such as 10, time series data such as `hit_rate`, `hit_bytes`, and `miss_bytes` can be obtained during the verification period.

## Attributes

| **Attribute** | **Description** |
| --- | --- |
| Parameter type | u64 |
| Default value | 0 (disabled) |
| Value range | Unrestricted (0 indicates disabled) |
| Effective mode | dynamic |
