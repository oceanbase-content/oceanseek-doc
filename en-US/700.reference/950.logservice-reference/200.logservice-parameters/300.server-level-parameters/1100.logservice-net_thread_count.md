# net_thread_count

## Purpose

The number of network I/O threads. If this parameter is set to 0, the runtime automatically determines the number.

## Attributes

| **Attribute** | **Description** |
| --- | --- |
| Parameter type | usize |
| Default value | 0 |
| Value range | Unlimited |
| Effective mode | readonly |
