# http_port

## Purpose

The listening port of the HTTP status management service. It forms the listening address together with `local_ip`. **The port must be valid. Otherwise, an error is reported when the node starts, and the node fails to start.**

## Attributes

| **Attribute** | **Description** |
| --- | --- |
| Parameter type | u16 |
| Default value | 50052 |
| Value range | 1–65535 |
| Effective mode | static |
