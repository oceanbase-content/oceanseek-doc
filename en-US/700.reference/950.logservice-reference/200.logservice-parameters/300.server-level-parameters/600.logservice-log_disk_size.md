# log_disk_size

## Purpose

Specifies the maximum disk space that can be occupied by log data. If this parameter is set to 0, the quota is determined by `log_disk_percentage`.

## Attributes

| **Attribute** | **Description** |
| --- | --- |
| Parameter type | ReadableSize |
| Default value | 0GB |
| Value range | 0 or a positive integer. Supported units include KB, MB, and GB. |
| Effective mode | dynamic |
