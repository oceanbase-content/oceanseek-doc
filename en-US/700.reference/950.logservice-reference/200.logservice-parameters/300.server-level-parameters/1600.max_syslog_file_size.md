# max_syslog_file_size

## Purpose

The size threshold for rolling over a single log file (`oblogservice.log`). A new file is created when the file size exceeds this threshold.

## Attributes

| **Attribute** | **Description** |
| --- | --- |
| Parameter type | ReadableSize |
| Default value | 256MB |
| Value range | A positive integer. Supported units include KB, MB, and GB. |
| Effective mode | readonly |
