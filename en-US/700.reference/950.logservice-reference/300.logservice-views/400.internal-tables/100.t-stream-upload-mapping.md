# t_stream_upload_mapping

This internal table is available starting with oblogservice 1.1.1.

## Purpose

Records the mapping between log streams and upload nodes. LogService assigns a new upload node to a log stream that does not have a valid upload node based on the I/O load of its replicas, and persists this mapping to this internal table.

## Columns

| **Field name** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| `stream_id` | u64 | NO | The log stream ID, which is the unique identifier of the stream (primary key). |
| `create_time` | i64 | NO | The creation time (in microseconds). |
| `modify_time` | i64 | NO | The modification time (in microseconds). |
| `ln_id` | u64 | NO | The ID of the log node (LN) responsible for the upload task of this stream. |
| `generator_module` | u32 | NO | The generation module. Valid values: 0 = UploadService (upload service), 1 = LoadBalancer (load balancer), and 2 = DisasterRecovery (disaster recovery service). |

## Sample query

Query the mapping between log streams and upload nodes:

```shell
ls_ctrl -H <HOST_ADDRESS> show meta --table-name t_stream_upload_mapping
```
