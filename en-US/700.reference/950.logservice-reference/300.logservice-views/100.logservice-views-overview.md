# Overview of LogService views

LogService provides two types of views for querying the operational status and metadata of a cluster: **virtual views** and **internal tables**.

## Virtual views

Virtual views are virtual tables built on the in-memory structures of LogService nodes. They display real-time performance statistics and monitoring information for the cluster, including node load, AZ load, and log stream replica I/O statistics. Virtual views are read-only and cannot be modified or deleted.

Query virtual views using the `show v-table` command:

```shell
ls_ctrl -H <HOST_ADDRESS> show v-table <VTABLE_TYPE>
```

Here, `<VTABLE_TYPE>` specifies the type of the virtual view. Valid values: `node_load`, `az_load`, and `stream_replica_io`.

## Internal tables

Internal tables are persistent data tables in the LogService MetaDB, used to store metadata and system status information of the LogService cluster, including node information, log stream replica information, and migration task records. Internal tables are read-only.

Query internal tables using the `show meta` command:

```shell
ls_ctrl -H <HOST_ADDRESS> show meta --table-name <TABLE_NAME>
```

The `--table-name` option specifies the name of the internal table to query. If `--table-name` is not specified, all queryable internal tables are listed.
