# stream_replica_io

This virtual view is available starting with oblogservice 1.1.1.

## Purpose

This view displays the I/O statistics for each log stream replica, including I/O type, replica type, bandwidth, and IOPS.

## Columns

| **Field name** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| `stream_id` | u64 | NO | The log stream ID, which is the unique identifier of the stream (primary key). |
| `ln_id` | u64 | NO | The log node (LN) ID, which is the unique identifier of the node (primary key). |
| `io_type` | DiskIOType | NO | The I/O type (primary key). Valid values: `Pread`, `ReceiveLog`, `ReceiveAcceptorLog`, `WriteBlockHeader`, `FetchedLog`, `UploadLog`, `WriteMeta`, `ReadMeta`, and `Other`. |
| `replica_type` | String | NO | The replica type. Valid values: `normal` (normal replica), `creating` (being created), `migrating_out` (migrating out), and `migrating_in` (migrating in). |
| `bps` | f64 | NO | The bandwidth (bytes per second). |
| `iops` | f64 | NO | The number of IOPS. |

## Sample query

Query the I/O statistics for all log stream replicas:

```shell
ls_ctrl -H <HOST_ADDRESS> show v-table stream_replica_io
```
