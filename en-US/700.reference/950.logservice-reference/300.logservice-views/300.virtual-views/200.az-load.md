# az_load

This virtual view is available starting with oblogservice 1.1.1.

## Purpose

Displays the IOPS and bandwidth usage for each availability zone (AZ).

## Columns

| **Field name** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| `az` | String | NO | The name of the availability zone (AZ), which is the unique identifier of the AZ (primary key). |
| `bps_used` | f64 | NO | The total bandwidth used (bytes per second) by all nodes in the AZ. |
| `iops_used` | f64 | NO | The total number of IOPS used by all nodes in the AZ. |
| `bps_capacity` | f64 | NO | The bandwidth capacity (bytes per second), which is the total bandwidth capacity of all nodes in the AZ. |
| `iops_capacity` | f64 | NO | The IOPS capacity, which is the total IOPS capacity of all nodes in the AZ. |
| `bps_utilization` | f64 | NO | Bandwidth utilization (0.0-1.0). |
| `iops_utilization` | f64 | NO | IOPS utilization (0.0-1.0). |

## Sample query

Query the load information of all availability zones:

```shell
ls_ctrl -H <HOST_ADDRESS> show v-table az_load
```
