# node_load

This virtual view is available starting with oblogservice 1.1.1.

## Purpose

Displays the IOPS and bandwidth usage of each log service node (LN).

## Columns

| **Field name** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| `ln_id` | u64 | NO | The log node (LN) ID, which is the unique identifier of the node (primary key). |
| `az` | String | NO | The name of the availability zone (AZ). |
| `bps_used` | f64 | NO | The amount of bandwidth used (bytes per second). |
| `iops_used` | f64 | NO | The number of IOPS used. |
| `bps_capacity` | f64 | NO | The bandwidth capacity (bytes per second). |
| `iops_capacity` | f64 | NO | The IOPS capacity. |
| `bps_utilization` | f64 | NO | Bandwidth utilization (0.0-1.0). |
| `iops_utilization` | f64 | NO | IOPS utilization (0.0-1.0). |

## Sample query

Query the load information of all log service nodes:

```shell
ls_ctrl -H <HOST_ADDRESS> show v-table node_load
```
