# check

## Purpose

This command is used to check the health status of a specified AZ, a specified stream, or the entire cluster.

## Syntax

```shell
ls_ctrl -H <HOST_ADDRESS> check az <NAME>
ls_ctrl -H <HOST_ADDRESS> check stream --stream-id-list <ID,...> [--need-check-stream-locality]
ls_ctrl -H <HOST_ADDRESS> check cluster
```

## Parameters

| **Parameter** | **Description** |
| --- | --- |
| `az <NAME>` | Performs a health check on a specified AZ. `<NAME>` specifies the name of the AZ. |
| `stream --stream-id-list <ID,...>` | Performs a health check on a specified stream. `<ID,...>` specifies a comma-separated list of stream IDs. |
| `--need-check-stream-locality` | Optional. If this parameter is specified, the locality of the stream is checked. The default value is `false`. |
| `cluster` | Performs a health check on the entire cluster. |

## Examples

### Check the health status of an AZ

```shell
./ls_ctrl -H 127.0.0.1:7891 check az beijing-1
```

### Check the health status of a cluster

```shell
./ls_ctrl -H 127.0.0.1:7891 check cluster
```

### Check the health status of a stream

```shell
./ls_ctrl -H 127.0.0.1:7891 check stream --stream-id-list 1,2,3
```

```shell
./ls_ctrl -H 127.0.0.1:7891 check stream --stream-id-list 1 --need-check-stream-locality
```
