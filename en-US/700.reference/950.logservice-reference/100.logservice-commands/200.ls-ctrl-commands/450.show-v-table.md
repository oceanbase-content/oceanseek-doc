# show v-table

## Purpose

This command is used to view data in a virtual table.

## Syntax

```shell
ls_ctrl -H <HOST_ADDRESS> show v-table <VTABLE_TYPE>
```

## Parameters

| **Parameter** | **Description** |
| --- | --- |
| `<VTABLE_TYPE>` | Required. The type name of the virtual table. Valid values: `node_load`, `az_load`, and `stream_replica_io`. |

## Examples

### View node load information

```shell
ls_ctrl -H 127.0.0.1:8080 show v-table node_load
```

### View AZ load information

```shell
ls_ctrl -H 127.0.0.1:8080 show v-table az_load
```

### View stream replica I/O statistics

```shell
ls_ctrl -H 127.0.0.1:8080 show v-table stream_replica_io
```
