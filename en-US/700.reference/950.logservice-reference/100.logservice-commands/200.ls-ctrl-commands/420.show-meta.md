# show meta

## Purpose

This command is used to view the data in internal tables of the MetaDB.

## Syntax

```shell
ls_ctrl -H <HOST_ADDRESS> show meta [--table-name <TABLE_NAME>] [--force <FORCE>]
```

## Parameters

| **Parameter** | **Description** |
| --- | --- |
| `--table-name <TABLE_NAME>` | Optional. The name of the internal table to query. |
| `--force <FORCE>` | Optional. If this parameter is specified, the proposal ID consistency check is skipped, and the MetaDB replica on the local node is read directly. This feature is for diagnostic purposes only. When it is enabled, non-leader nodes can also respond. Default: `false`. Only the leader node can respond. |

## Examples

### Query the primary directory

```shell
./ls_ctrl -H 127.0.0.1:7891 show meta --table-name t_primary_dir
```

### Force query of the primary directory

```shell
./ls_ctrl -H 127.0.0.1:7891 show meta --table-name t_primary_dir --force true
```

In a forced query, the host is the node on which the query is executed, and the request is not automatically forwarded to the LM leader.

### Query the secondary directory

```shell
./ls_ctrl -H 127.0.0.1:7891 show meta --table-name t_secondary_dir
```

### Query streams

```shell
./ls_ctrl -H 127.0.0.1:7891 show meta --table-name t_stream
```

### Query all table information

```shell
./ls_ctrl -H 127.0.0.1:7891 show meta
```
