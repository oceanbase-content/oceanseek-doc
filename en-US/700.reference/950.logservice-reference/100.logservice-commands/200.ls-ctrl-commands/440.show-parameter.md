# show parameter

## Purpose

This command is used to query the value of a specified cluster-level parameter or node-level parameter.

## Syntax

```shell
ls_ctrl -H <HOST_ADDRESS> show parameter [--server-only] <NAME>
```

## Parameters

| **Parameter** | **Description** |
| --- | --- |
| `--server-only` | Optional. If this parameter is specified, the local configuration of the node specified by `-H` is read instead of the cluster parameters from the LM leader. Default value: `false`. |
| `<NAME>` | Required. The name of the parameter. |

## Examples

### Query a cluster-level parameter

```shell
ls_ctrl -H <HOST_ADDRESS> show parameter node_permanent_offline_time_sec
```

### Query a node-local parameter

```shell
ls_ctrl -H <HOST_ADDRESS> show parameter log_level --server-only
```
