# delete ln

## Purpose

This command is used to delete a specified LN.

## Syntax

```shell
ls_ctrl -H <HOST_ADDRESS> delete ln <LN>
```

## Parameters

| **Parameter** | **Description** |
| --- | --- |
| `<LN>` | Required. The ID or address of the LN. The address must be in the format `host:port`. |

## Examples

### Delete by LN address

```shell
./ls_ctrl -H 127.0.0.1:7891 delete ln "127.0.0.1:7892"
```

### Delete by LN ID

```shell
./ls_ctrl -H 127.0.0.1:7891 delete ln 3
```
