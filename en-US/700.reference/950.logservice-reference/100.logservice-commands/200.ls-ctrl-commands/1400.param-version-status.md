# param-version-status

## Purpose

This command is used to query the current `param_version` of a cluster and the synchronization (propagation) status of each LN for that version. It is commonly used after parameter changes such as `rotate-ak` to confirm whether all LNs have obtained the latest version.

## Syntax

```shell
ls_ctrl -H <HOST_ADDRESS> param-version-status
```

## Parameters

None.

## Output

The output includes the current `param_version` of the cluster, as well as information about each LN, such as its ID, the latest reported `param_version`, the last heartbeat time, address, status, and online/offline time.

## Examples

```shell
ls_ctrl -H 127.0.0.1:8080 param-version-status
```
