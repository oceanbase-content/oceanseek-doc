# rotate-ak

## Purpose

This command is used to rotate the access key (AK) and secret key (SK) used for object storage.

## Syntax

```shell
ls_ctrl -H <HOST_ADDRESS> rotate-ak -i <ACCESS_KEY_ID> -k <ACCESS_KEY_SECRET>
```

## Parameters

| **Parameter** | **Description** |
| --- | --- |
| `-i, --new-access-key-id <ID>` | Required. The new AccessKey ID. |
| `-k, --new-access-key-secret <SECRET>` | Required. The new AccessKey secret. |

## Usage notes

Before the rotation, the LM uses the new key to perform a probe verification on object storage. If the verification fails, the rotation is rejected and the existing configuration remains unchanged.

## Examples

```shell
ls_ctrl -H 127.0.0.1:8080 rotate-ak \
    -i LTAItestNewAccessKeyId \
    -k testNewAccessKeySecret
```
