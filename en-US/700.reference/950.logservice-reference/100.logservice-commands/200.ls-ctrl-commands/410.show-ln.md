# show ln

## Purpose

This command is used to view information about a specified LN or all LNs.

## Syntax

```shell
ls_ctrl -H <HOST_ADDRESS> show ln [<NAME>]
```

## Parameters

| **Parameter** | **Description** |
| --- | --- |
| `<NAME>` | Optional. The name of an LN. If this parameter is not specified, information about all LNs is retrieved. If the name of an LN (its IP address or LN ID) is specified, detailed information about that LN is retrieved. |

## Examples

### Query information about all LNs

```shell
./ls_ctrl -H 127.0.0.1:7891 show ln
```

### Query by specifying an IP address

```shell
./ls_ctrl -H 127.0.0.1:7891 show ln "127.0.0.1:7892"
```

### Query by specifying an LN ID

```shell
./ls_ctrl -H 127.0.0.1:7891 show ln 2
```
