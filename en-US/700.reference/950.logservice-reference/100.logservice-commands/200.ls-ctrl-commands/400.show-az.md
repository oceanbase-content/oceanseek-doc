# show az

## Purpose

This command is used to view information about a specified AZ or all AZs.

## Syntax

```shell
ls_ctrl -H <HOST_ADDRESS> show az [<NAME>]
```

## Parameters

| **Parameter** | **Description** |
| --- | --- |
| `<NAME>` | Optional. The name of the availability zone (AZ). If this parameter is not specified, information about all AZs is retrieved. If an AZ name is specified, information about that AZ is retrieved. |

## Examples

### Query information about all AZs

```shell
./ls_ctrl -H 127.0.0.1:7891 show az
```

### Query information about a specified AZ

```shell
./ls_ctrl -H 127.0.0.1:7891 show az AZ-1
```
