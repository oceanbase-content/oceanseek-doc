# add ln

## Purpose

This command is used to add an LN to a specified AZ.

## Syntax

```shell
ls_ctrl -H <HOST_ADDRESS> add ln <LN> <AZ>
```

## Parameters

| **Parameter** | **Description** |
| --- | --- |
| `<LN>` | Required. The address of the new LN, in the format `host:port`. |
| `<AZ>` | Required. The name of the target AZ. |

## Examples

### Add a node to a specified AZ

```shell
./ls_ctrl -H 127.0.0.1:7891 add ln "127.0.0.1:7896" AZ-1
```
