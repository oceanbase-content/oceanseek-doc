# set param

## Purpose

This command is used to set cluster-level parameters (default) or node-level parameters of the current node (`--server-only`).

## Syntax

```shell
ls_ctrl -H <HOST_ADDRESS> set param [--server-only] <NAME> <VALUE>
```

## Parameters

| **Parameter** | **Description** |
| --- | --- |
| `--server-only` | Optional. If this parameter is specified, the change takes effect only on the node specified by `-H` (server level). Otherwise, the change takes effect on the entire cluster (cluster level). Default value: `false`. |
| `<NAME>` | Required. The name of the parameter. |
| `<VALUE>` | Required. The value of the parameter. |

## Examples

### Set cluster-level parameters

```shell
ls_ctrl -H <HOST_ADDRESS> set param <NAME> <VALUE>
```

### Set node-level parameters

```shell
ls_ctrl -H <HOST_ADDRESS> set param --server-only <NAME> <VALUE>
```
