# fetch

## Purpose

This command is used to pull the clog data of a specified stream from object storage to the local node.

## Syntax

```shell
ls_ctrl -H <HOST_ADDRESS> fetch --work-dir <WORK_DIR> --cluster-id <CLUSTER_ID> --tenant-id <TENANT_ID> --ls-id <LS_ID> [--point-type <POINT_TYPE>] --start-point <START_POINT> [--end-point <END_POINT>]
```

## Parameters

| **Parameter** | **Description** |
| --- | --- |
| `--work-dir <WORK_DIR>` | Required. The working directory for storing pulled logs. The directory must be empty. |
| `--cluster-id <CLUSTER_ID>` | Required. The ID of the cluster to which the stream belongs. |
| `--tenant-id <TENANT_ID>` | Required. The ID of the tenant to which the stream belongs. |
| `--ls-id <LS_ID>` | Required. The ID of the target log stream. |
| `--point-type <POINT_TYPE>` | Optional. The type of the start and end points of logs. Valid values: `lsn` and `scn`. The default value is `scn`. |
| `--start-point <START_POINT>` | Required. The start point for pulling logs. |
| `--end-point <END_POINT>` | Optional. The end point for pulling logs. |

## Examples

### Pull logs

```shell
ls_ctrl -H 127.0.0.1:7891 fetch --work-dir ./clog --cluster-id 1 --tenant-id 1 --ls-id 1 --point-type lsn --start-point 100 --end-point 16384
```
