# upgrade

## Purpose

This command is used to perform the cluster upgrade process.

## Syntax

```shell
ls_ctrl -H <HOST_ADDRESS> upgrade begin
ls_ctrl -H <HOST_ADDRESS> upgrade finish <TARGET_VERSION>
```

## Parameters

| **Parameter** | **Description** |
| --- | --- |
| `begin` | Starts the upgrade process. |
| `finish <TARGET_VERSION>` | Completes the upgrade process. `<TARGET_VERSION>` specifies the target version number. |

## Examples

### Preparations before upgrade

```shell
./ls_ctrl -H 127.0.0.1:7891 upgrade begin
```

### Post-upgrade procedures

```shell
./ls_ctrl -H 127.0.0.1:7891 upgrade finish 1.0.0
```
