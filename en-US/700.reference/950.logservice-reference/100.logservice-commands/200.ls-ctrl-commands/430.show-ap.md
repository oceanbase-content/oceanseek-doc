# show ap

## Purpose

This command is used to view information about all access points.

## Syntax

```shell
ls_ctrl -H <HOST_ADDRESS> show ap
```

## Parameters

None.

## Examples

### Query access point information

```shell
./ls_ctrl -H 127.0.0.1:7891 show ap
```
