# migrate replica

## Purpose

This command is used to migrate a replica of a specified stream from the source LN to the target LN.

## Syntax

```shell
ls_ctrl -H <HOST_ADDRESS> migrate replica <STREAM_ID> <SRC_LN> <DEST_LN>
```

## Parameters

| **Parameter** | **Description** |
| --- | --- |
| `<STREAM_ID>` | Required. The ID of the target stream (u64). |
| `<SRC_LN>` | Required. The ID (u64) or address (`host:port`) of the source LN. |
| `<DEST_LN>` | Required. The ID (u64) or address (`host:port`) of the target LN. |

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p><code>&lt;SRC_LN&gt;</code> and <code>&lt;DEST_LN&gt;</code> must be in the same format (either both IDs or both addresses). Mixing them causes an error.</p>
</main>

## Examples

### Use an LN ID

```shell
ls_ctrl -H 127.0.0.1:7891 migrate replica 4360635369 1 4
```

### Use an LN address

```shell
ls_ctrl -H 127.0.0.1:7891 migrate replica 4360635369 127.0.0.1:7890 127.0.0.1:7898
```
