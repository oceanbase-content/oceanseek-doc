# bootstrap

## Purpose

This command is used to initialize a LogService cluster, specifying the region, zone name, and address for each node, as well as the object storage URL.

## Syntax

```shell
ls_ctrl -H <HOST_ADDRESS> bootstrap --object-store-url <OBJECT_STORE_URL> <NODES>...
```

## Parameters

| **Parameter** | **Description** |
| --- | --- |
| `--object-store-url <OBJECT_STORE_URL>` | Required. The object storage address used by the cluster, for example, `s3://bucket-name`. |
| `<NODES>...` | Required. Specifies the list of servers (at least three nodes), including the region and zone information, in the format `REGION <REGION_NAME> AZ <AZ_NAME> SERVER <IP_ADDRESS>`. Separate multiple nodes with commas (,). The REGION parameter does not take effect in the current version. |

## Examples

### Specify three nodes to initiate bootstrap

```shell
./ls_ctrl -H 127.0.0.1:7891 bootstrap REGION beijing AZ az1 SERVER 127.0.0.1:7890, REGION beijing AZ az2 SERVER 127.0.0.1:7892, REGION beijing AZ az3 SERVER 127.0.0.1:7894 --object-store-url 's3://logservice01?host=http://100.88.99.199:9000&access_id=XXX&access_key=XXX&s3_region=cn-north-1'
```

In the preceding command, each node is deployed in a different zone but within the same region.
