# Automatic minor compaction

This topic describes how automatic minor compaction is triggered.

When the memory usage of a tenant's active MemTable reaches `freeze_trigger_percentage * memstore_limit` (where `memstore_limit = tenant_memory * memstore_limit_percentage`), the system automatically triggers a minor freeze (the precursor action to minor compaction) and then schedules a minor compaction. When the number of minor freezes reaches a certain threshold, automatic minor compaction is triggered.

For more information about the parameters `memstore_limit_percentage` and `freeze_trigger_percentage`, see [Modify minor compaction settings](../100.dump-management/500.modify-dump-configuration.md).
