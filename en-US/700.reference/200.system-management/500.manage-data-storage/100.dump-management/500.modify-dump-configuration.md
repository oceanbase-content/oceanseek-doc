# Modify minor compaction settings

This topic describes the minor compaction parameters and how to set them.

## Minor compaction parameters

| Parameter | Description | Default value | Value range |
| ----------------------------- | ------------------------------------------------------- | ----- | -------------- |
| minor_compact_trigger | A tenant-level parameter that specifies the threshold for the number of SSTables that triggers a minor compaction. | 2 | \[0, 16\] |
| freeze_trigger_percentage | A tenant-level parameter that specifies the threshold for the percentage of memory occupied by the tenant's MemStore. When this value is reached, a freeze is triggered. | 20 | (0, 100) |
| memstore_limit_percentage | A cluster-level parameter that specifies the percentage of a tenant's total memory allocated to its MemStore. | 0 | [0, 100) |

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>You can configure the percentage of total memory that the tenant's MemStore occupies by using the tenant-level hidden parameter <code>_memstore_limit_percentage</code>. Except for the scope of application, its functionality and default value are the same as those of the cluster-level parameter <code>memstore_limit_percentage</code>. When configuring these two parameters, note the following:</p>
  <ul><li>If only one of the values (non-default) of <code>_memstore_limit_percentage</code> or <code>memstore_limit_percentage</code> is configured, the configured value (non-default) takes effect.</li>
  <li>If both the tenant-level hidden parameter <code>_memstore_limit_percentage</code> (non-default) and the cluster-level parameter <code>memstore_limit_percentage</code> (non-default) are configured, the value configured in <code>_memstore_limit_percentage</code> takes effect.</li>
  <li>If neither is configured, or both are configured with their default values, the system adopts the following adaptive policy:
    <ul><li>Tenants with 8 GB (actual memory) or less have a configured MemStore ratio of 40%.</li>
    <li>Tenants with more than 8 GB of memory have a configured MemStore ratio of 50%.</li></ul>
   </li></ul>
</main>

## Modify minor compaction settings by using SQL statements

1. Log in to the database as a tenant administrator.

2. Execute the following statements respectively to modify the minor compaction settings.

   Example:

   ```sql
   obclient> ALTER SYSTEM SET minor_compact_trigger=2;
   
   obclient> ALTER SYSTEM SET freeze_trigger_percentage=20;
   
   obclient> ALTER SYSTEM SET memstore_limit_percentage=50;
   ```

3. After the modification, you can execute the `SHOW PARAMETERS` statement to check whether the modification is successful.

   Example:

   ```sql
   obclient> SHOW PARAMETERS LIKE 'minor_compact_trigger';
   
   obclient> SHOW PARAMETERS LIKE 'freeze_trigger_percentage';
   
   obclient> SHOW PARAMETERS LIKE 'memstore_limit_percentage';
   ```
