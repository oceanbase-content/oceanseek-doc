# Modify major compaction configuration

This topic describes the parameters related to major compaction and how to modify them.

## Major compaction parameters

The following table describes the parameters related to major compaction.

| Parameter | Description | Default value | Value range |
| ------------------------------- | ---------------------------------------------------------------------------------------------------------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| enable_major_freeze | A cluster-level parameter that specifies whether to enable major compaction. | True | <ul><li>True </li><li>False  </li></ul> |
| major_freeze_duty_time | A tenant-level parameter that specifies the daily scheduled major compaction time. | 02:00 | \[00:00,24:00\] |
| major_compact_trigger | A tenant-level parameter that specifies how many freezes trigger a major compaction. | 0 | \[0,65535\] |
| default_progressive_merge_num | A tenant-level parameter that specifies the default major compaction behavior during table creation. | 0 | \[0, +∞)  </br>where: <ul><li>`0`: Indicates that 100 progressive compactions are performed by default. </li><li>`1`: Indicates that a full compaction is forcibly executed without performing a progressive compaction. </li>   <li>A value greater than 1: Indicates that the specified number of progressive compactions is performed when a schema change occurs. </li></ul> <main id="notice" type='explain'><h4>Note</h4><p>You can also modify the compaction behavior of a table after it is created by executing the <code>ALTER TABLE table_name SET PROGRESSIVE_MERGE_NUM=0;</code> statement.</p></main> |
| merger_check_interval | A tenant-level parameter that specifies the interval for checking the major compaction progress in each zone. | 10m | \[10s, 60m\] |
| enable_window_compaction | A tenant-level parameter that controls whether to enable window compaction. | False | <ul><li>True </li><li>False  </li></ul> |

## Modify major compaction configuration by using SQL statements

1. Log in to the database as a tenant administrator.

2. Use the following SQL statements to modify the major compaction configuration.

   Example:

   ```sql
   obclient> ALTER SYSTEM SET major_freeze_duty_time='03:00';
   ```

   <main id="notice" type='notice'>
   <h4>Notice</h4>
   <p>Cluster-level parameters must be set under the <code>sys</code> tenant.</p>
   </main>

3. After the parameters are modified, you can execute the `SHOW PARAMETERS` statement to check whether the modification is successful.

   Example:

   ```sql
   obclient>SHOW PARAMETERS LIKE 'major_freeze_duty_time';
   ```
