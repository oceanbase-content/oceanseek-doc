# Schedule daily tenant major compactions

You can also schedule tenant major compactions by specifying the daily trigger time.

## Prerequisites

* Before triggering a major compaction, ensure the global major freeze switch is enabled. This switch is controlled by the cluster-level parameter [enable_major_freeze](../../../800.configuration-items-and-system-variables/100.system-configuration-items/300.cluster-level-configuration-items/7000.enable_major_freeze.md), with a default value of `True`, indicating the compaction switch is on.

  If the global major freeze switch is not enabled for the current cluster, refer to the following steps to enable it.

  1. Log in to the `sys` tenant of the cluster as the `root` user.

  2. Check whether the global major freeze switch is enabled.

     ```shell
     obclient(root@sys)[(none)]> SHOW PARAMETERS LIKE 'enable_major_freeze';
     ```

  3. If it is not enabled, execute the following statement to turn on the compaction switch.

     ```shell
     obclient(root@sys)[(none)]> ALTER SYSTEM SET enable_major_freeze='True';
     ```

* To trigger daily tenant major compactions, ensure the tenant-level parameter [enable_window_compaction](../../../800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/3150.enable_window_compaction.md) is set to `False`, which disables window-based compaction.

   Procedure:

   1. Log in to the user tenant of the cluster as the tenant administrator.

   2. Check the value of the tenant-level parameter `enable_window_compaction`.

      ```shell
      obclient> SHOW PARAMETERS LIKE 'enable_window_compaction';
      ```

   3. If the value is `True`, execute the following statement to disable window-based compaction.

      ```shell
      obclient> ALTER SYSTEM SET enable_window_compaction = False;
      ```

      In the sys tenant, you can set this by specifying the tenant name, for example: `ALTER SYSTEM SET enable_window_compaction = False TENANT = tenant_name;`.

## Trigger conditions for daily tenant major compactions

After the global major freeze switch is enabled and window-based compaction is disabled, daily tenant major compactions are triggered automatically at the specified time. The trigger time is controlled by the `major_freeze_duty_time` parameter. You can also modify this time in OCP. By default, the compaction is triggered at `02:00` every day.

For descriptions and settings of `major_freeze_duty_time` and other major compaction-related parameters, see [Modify major compaction configuration](../200.merge-management/700.modify-a-merge-configuration.md).

## Specify the daily tenant major compaction trigger time

1. Log in to the `sys` tenant of the cluster as the `root` user.

2. Execute the following statement to modify the daily compaction trigger time.

   * Modify the daily major compaction trigger time for this tenant.

      ```sql
      obclient> ALTER SYSTEM SET major_freeze_duty_time='01:00';
      ```

   * Modify the daily major compaction trigger time for all user tenants.

      In scenarios with many tenants, when the trigger time for each major compaction is the same across all user tenants, a sudden spike in CPU utilization may occur. If such a spike happens, it is recommended to set different daily major compaction times for each user tenant.

      ```sql
      obclient> ALTER SYSTEM SET major_freeze_duty_time='01:00' TENANT = all_user;
      ```

      or

      ```sql
      obclient> ALTER SYSTEM SET major_freeze_duty_time='01:00' TENANT = all;
      ```

     <main id="notice" type='explain'>
     <h4>Note</h4>
     <p><code>TENANT = all_user</code> and <code>TENANT = all</code> have the same semantics. When you need to specify all user tenants, we recommend that you use <code>TENANT = all_user</code>. The <code>TENANT = all</code> option will be deprecated in the future.</p>

   * Modify the daily major compaction trigger time for all Meta tenants.

      In scenarios with many tenants, when the trigger time for each major compaction is the same across all Meta tenants, a sudden spike in CPU utilization may occur. If such a spike happens, it is recommended to set different daily major compaction times for each Meta tenant.

      ```sql
      obclient> ALTER SYSTEM SET major_freeze_duty_time='01:00' TENANT = all_meta;
      ```

   * Modify the daily major compaction trigger time for a specified tenant.

      The following statement only supports specifying one tenant at a time. To modify multiple tenants, you need to repeat the statement.

      ```sql
      obclient> ALTER SYSTEM SET major_freeze_duty_time='01:00' TENANT = tenant1;
      ```
