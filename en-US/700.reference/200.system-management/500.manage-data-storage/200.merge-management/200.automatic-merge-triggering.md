# Automatically trigger a major compaction

A major compaction can be automatically triggered.

## Prerequisites

Before triggering a major compaction, ensure that the global major compaction switch is enabled. This switch is controlled by the cluster-level parameter `enable_major_freeze`, with a default value of `True`, indicating the switch is on.

If the global major compaction switch is not enabled for the current cluster, refer to the following steps to enable it.

1. Log in to the `sys` tenant of the cluster as the `root` user.

2. Check whether the global major compaction switch is enabled.

   ```sql
   obclient> SHOW PARAMETERS LIKE 'enable_major_freeze';
   ```

3. If it is not enabled, execute the following statement to enable the switch.

   ```sql
   obclient> ALTER SYSTEM SET enable_major_freeze='True';
   ```

   For more information about the `enable_major_freeze` parameter, see [enable_major_freeze](../../../800.configuration-items-and-system-variables/100.system-configuration-items/300.cluster-level-configuration-items/7000.enable_major_freeze.md).

## Trigger conditions for automatic major compaction

A major compaction is automatically triggered when the number of minor freezes reaches a certain threshold.
