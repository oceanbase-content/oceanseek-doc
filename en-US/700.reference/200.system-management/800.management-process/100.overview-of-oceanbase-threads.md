# Overview of OceanSeek threads

OceanSeek runs as a single process. Some threads are system threads that maintain the distributed database service, and others are worker threads that handle database workload.

## Thread types in OceanSeek

Overall, threads in OceanSeek can be classified into the following categories:

* Tenant threads: These threads handle tenant requests, such as SQL and transaction requests. They are named in the `TNT_L<n>_<tenant id>` format.

* System threads:

  * net io: Handles network I/O.

  * disk io: Handles disk I/O.

  * dag thread: Executes tasks such as minor compactions, major compactions, and partition migration.

  * clog writer: Writes clogs.

  * election worker: Performs leader election.

  * misc timer: Consists of multiple background timer threads and is mainly responsible for resource cleanup.

  * Additionally, there are a set of Root Server-specific threads, which are not further subdivided here.

  * Finally, there are some background threads for specific purposes, which you can ignore until you have a deeper understanding of OceanSeek.

Tenant threads are unique to each tenant and execute the requests of that tenant. System threads ensure the proper running of the observer process and request processing on the node, and are shared by all tenants.
