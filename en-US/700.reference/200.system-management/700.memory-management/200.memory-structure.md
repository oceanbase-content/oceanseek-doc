# Memory structure

![Memory](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.2.1/700.reference/200.system-management/memory-struc.jpg)

As shown in the preceding figure, the total memory of an OBServer node in OceanSeek is a proportion of the server memory, and it can also be configured to an absolute value. Some of the memory is used for system running, and the rest is allocated to tenants. Each tenant is equivalent to an instance in a conventional database. Except for the sys tenant, all other tenants have the same memory module composition. The sys tenant does not have a corresponding Meta tenant, and its memory consists of a MemStore for storing incremental data and a KVCache. Each user tenant has a corresponding Meta tenant. Therefore, the memory of a user tenant consists of the memory of the user tenant itself and the memory of the corresponding Meta tenant. Both consist of a MemStore for storing incremental data and a KVCache.
