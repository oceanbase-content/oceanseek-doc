# Set the maximum memory for a database

This topic describes how to set the maximum memory for a database and provides configuration examples.

## Parameters for setting the maximum memory

OceanBase AI Database provides the following parameters for setting the maximum memory for a database:

* `memory_limit_percentage`: specifies the percentage of the maximum server memory that can be occupied by OceanBase AI Database.

* `memory_limit`: specifies the maximum memory for OceanBase AI Database. If `memory_limit` is set to `0M`, the value of `memory_limit_percentage` prevails. If `memory_limit` is set to another value, the specified absolute value is used.

## Examples

The following examples show how the values of the `memory_limit_percentage` and `memory_limit` parameters affect the actual maximum memory available to OceanBase AI Database, with the total server memory being 100 GB.

| Example | **memory_limit_percentage** | **memory_limit** | **Maximum memory of OceanBase AI Database** |
|---|---|---|---|
| **Example 1** | 80 | 0M | 80 GB |
| **Example 2** | 80 | 90 GB | 90 GB |

* In Example 1, `memory_limit` is set to `0M`. Therefore, the `memory_limit_percentage` parameter determines the maximum memory of OceanBase AI Database, which is 100 GB × 80% = 80 GB.

* In Example 2, `memory_limit` is set to 90 GB. Therefore, the `memory_limit` parameter determines the maximum memory of OceanBase AI Database, which is 90 GB.

  <main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>Mainstream OceanBase AI Database servers are usually configured with 384 GB or 512 GB of memory. We recommend that you allocate 80% of the 384 GB server memory or 90% of the 512 GB server memory to OceanBase AI Database.</p>
  </main>
