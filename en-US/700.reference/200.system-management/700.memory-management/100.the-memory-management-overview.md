# Memory management overview

OceanSeek is a quasi-in-memory distributed database that supports the multi-tenant architecture, which places high demands on the management and utilization of large-capacity memory. OceanSeek occupies most of the server memory and manages the memory in a unified manner.

When you create a tenant for a new service, the tenant can occupy part of the allocatable memory. The number of allocated CPU cores and the size of allocated memory depend on the scale of the new service. If the allocatable CPU and memory are insufficient, you can scale out the OceanBase cluster to meet the growing business requirements.
