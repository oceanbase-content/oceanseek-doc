# Internal system memory management

OceanSeek supports the multi-tenant architecture. However, not all the memory configured for OceanSeek can be allocated to tenants, because tenants share specific resources and features on each OBServer node. As the memory occupied by these shared resources and features does not belong to any user tenant, this type of memory is managed as internal system memory.

The `system_memory` parameter specifies the maximum amount of internal system memory. This parameter is an estimate of the memory used internally by the system, and it limits the maximum memory that can be used by tenants, which is calculated by subtracting `system_memory` from `memory_limit`.

For example, if the maximum memory of OceanSeek is 80 GB and `system_memory` is 20 GB, the memory that can be allocated to tenants is 60 GB.
