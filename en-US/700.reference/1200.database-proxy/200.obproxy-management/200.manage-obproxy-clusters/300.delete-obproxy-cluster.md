# Delete an OBProxy cluster

You can delete an OBProxy cluster that is no longer required. After an OBProxy cluster is deleted, all OBProxy services are uninstalled from the hosts in the cluster, and the resources occupied by the OBProxy services on those hosts are released.

## Prerequisites

* The user logged in to OCP has the `OBPROXY_MANAGER` role.

* The OBProxy cluster to be deleted no longer provides the proxy service.

## Procedure

1. Log in to OCP.

2. In the left-side navigation pane, click **OBProxy**.

3. In the cluster list, select the target OBProxy cluster to go to its **Overview** page.

4. In the upper-right corner of the page, click the **...** icon and select **Delete Cluster**.

   ![delete-cluster](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/user-guide/odp-management/delete-odp-cluster.png)

5. In the dialog box that appears, click **Delete** to complete the deletion of the OBProxy cluster.

   You can view the progress via the **View Task** button in the dialog box.

   The deletion is successful when the task status is **Completed** and the OBProxy cluster no longer appears in the **Cluster List** on the OBProxy page.
