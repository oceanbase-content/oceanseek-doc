# Upgrade all OBProxies in an OBProxy cluster

When a new OBProxy version becomes available, you can upgrade all OBProxies in an OBProxy cluster in the OCP console.

## Procedure

1. Log in to OCP.

2. In the left-side navigation pane, click **OBProxy**.

3. In the cluster list, select the target OBProxy cluster to go to its **Overview** page.

4. In the upper-right corner of the page, click the **...** icon and select **Upgrade All**.

5. In the dialog box that appears, select a software package version to upgrade to.

   <main id="notice" type='explain'>
    <h4>Note</h4>
    <ul>
    <li>
    <p>You can only select a software package that is higher than the current highest version.</p>
    </li>
    <li>
    <p>When upgrading an OBProxy cluster with multiple CPU architectures, if the selected installation package version is missing for a particular <b>CPU architecture</b>, the upgrade cannot proceed.</p>
    </li>
    </ul>
   </main>

6. Click **OK**.

   You can view the upgrade progress by clicking the **View Task** button in the dialog box.

   The upgrade is successful when the task status is **Completed** and the status of each OBProxy in the **OBProxy List** on the cluster **Overview** page is **Running**.
