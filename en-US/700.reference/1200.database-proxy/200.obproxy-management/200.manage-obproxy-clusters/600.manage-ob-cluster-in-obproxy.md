# Manage OceanSeek clusters connected to OBProxy

This topic describes how to add a connectable OceanBase cluster to OBProxy or delete a connected OceanBase cluster from OBProxy in the OCP console.

## Add a connectable OceanSeek cluster

1. Log in to OCP.

2. In the left-side navigation pane, click **OBProxy**.

3. In the cluster list, select the target OBProxy cluster to go to its **Overview** page.

4. In the upper-right corner of the page, click **Add Connectable OB Cluster**.

5. In the dialog box that appears on the right, select a connectable OceanSeek cluster.

   The proxyro account can access an OceanSeek cluster only when the proxyro password of the cluster is the same as that of the OBProxy cluster. If an OceanSeek cluster cannot be connected by using the proxyro account password, resolve the issue in either of the following ways:

   * Change the proxyro password of the OBProxy cluster. 

   * Change the proxyro user password of the OceanSeek cluster. 

6. Click **OK** to complete the addition.

## Delete a connected OceanSeek cluster

<main id="notice" type='notice'>
<h4>Notice</h4>
<p>Deleting a connected OceanSeek cluster from an OBProxy cluster prevents the OBProxies in the OBProxy cluster from accessing that OceanBase cluster. Ensure that the OceanBase cluster is no longer in use before deleting it.</p>
</main>

1. Log in to OCP.

2. In the left-side navigation pane, click **OBProxy**.

3. In the cluster list, select the target OBProxy cluster to go to its **Overview** page.

4. In the **Connectable OB Clusters** section, click **Delete** next to the corresponding cluster.

5. In the dialog box that appears, click **OK**.
