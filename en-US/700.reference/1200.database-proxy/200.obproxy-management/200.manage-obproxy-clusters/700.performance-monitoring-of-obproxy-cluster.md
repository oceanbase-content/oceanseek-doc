# Monitor the performance of an OBProxy cluster

This topic describes how to view the performance monitoring information of an OBProxy cluster, including service monitoring information and system monitoring information, in the OCP console.

## Service monitoring

1. Log in to OCP.

2. In the left-side navigation pane, click **OBProxy**.

3. In the cluster list, select the target OBProxy cluster to go to the **Service Monitoring** tab of its **Performance Monitoring** page.

   * On the **Service Monitoring** tab, you can view the monitoring data for the last **5 minutes**, **10 minutes**, **20 minutes**, **30 minutes**, **1 hour**, **3 hours**, **6 hours**, **12 hours**, or a **custom time period**.

   * Click **Auto Refresh** to update the data every 10 seconds.

4. In the **Overview** section, view the performance monitoring status of the current OBProxy cluster. Click **View All** in the upper-right corner to view information about the **TPS**, **QPS**, **Client Connections**, **Server Connections**, **Average SQL Response Time**, **Average Route Table Queries per Second**, and **Average Network Request/Response Bytes**.

5. In the **Data of the Connected OceanBase Cluster** section, view the interaction performance between the current OBProxy cluster and the OceanSeek cluster it proxies.

   You can view the maximum, minimum, and average values of each metric. Click **Column Management** to select the metric information to display.

6. In the **OBProxy IP Data** section, view the performance of each OBProxy node in the current OBProxy cluster.

   You can view the maximum, minimum, and average values of each metric. Click **Column Management** to select the metric information to display.

## System monitoring

1. Log in to OCP.

2. In the left-side navigation pane, click **OBProxy**.

3. In the cluster list, select the target OBProxy cluster to go to the **System Monitoring** tab of its **Performance Monitoring** page.

   On the **System Monitoring** tab, you can view the monitoring data for the last **5 minutes**, **10 minutes**, **20 minutes**, **30 minutes**, **1 hour**, **3 hours**, **6 hours**, **12 hours**, or a **custom time period**.

   You can also click **Auto Refresh** to view real-time data updates.

4. In the **Overview** section, click **View All** in the upper-right corner to view information about the **Linux System Load**, **CPU Usage**, **IO Usage**, **IO Queue Length**, **Average IOPS**, **Average IO Latency**, **Average IODATA**, **Network Throughput**, **Memory**, and **Disk Usage**.

5. In the **OBProxy IP Data** section, you can view the performance metrics of each OBProxy node in the current OBProxy cluster. Click **Column Management** to select the metric information you want to display.
