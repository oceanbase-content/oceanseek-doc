# Manage parameters of an OBProxy cluster

This topic describes how to view the **Parameter List** and **Modification History** on the parameter management page of an OBProxy cluster by using OCP.

## View or modify parameters

1. Log in to OCP.

2. In the left-side navigation pane, click **OBProxy**.

3. In the cluster list, select the target OBProxy cluster to go to its **Overview** page.

4. Click **Parameter Management** in the left-side navigation pane. The **Parameter List** tab opens by default.

   On this page, you can perform the following operations:

   * View parameters

     Enter a parameter name in the search box and click Search to view information about the specified parameter. Fuzzy search is supported.

   * Modify parameters

     1. In the **Actions** column of the target parameter, click the **Change Value** button.
     2. Enter a value and then click **OK**.
     3. After modifying the value of the target parameter, click **Submit Modification**.
     4. In the dialog box that appears, confirm the modification information and click **Confirm Modification**. Wait for the modification task to complete for the change to take effect.

        After the parameter is modified, you can view the **Whether Restart Required** information to determine how the parameter takes effect:

        * Parameters that do not require a restart: The parameter takes effect approximately 3 minutes after the modification.
        * Parameters that require a restart: The parameter takes effect only after you restart the OBProxy.

## View the modification history

1. Log in to OCP.

2. In the left-side navigation pane, click **OBProxy**.

3. In the cluster list, select the target OBProxy cluster to go to its **Overview** page.

4. Click **Parameter Management** in the left-side navigation pane. The **Parameter List** tab opens by default.

5. Select the **Modification History** tab.

   On the **Modification History** tab, you can enter corresponding information in the **Modification Date** and **Parameter Name** fields and click **Query** to filter the parameters. In the parameter list, you can view information such as **Parameter Name**, **Value - Before Change** (the parameter value before the change), **Value - After Change** (the parameter value after the change), **Modification Time**, and **Operator**.
