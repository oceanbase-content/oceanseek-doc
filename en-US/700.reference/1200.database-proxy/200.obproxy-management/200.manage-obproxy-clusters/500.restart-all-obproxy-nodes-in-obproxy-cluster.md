# Restart all OBProxies in an OBProxy cluster

This topic describes how to restart all OBProxies in an OBProxy cluster in the OCP console.

## Prerequisites

The user logged in to OCP has the `OBPROXY_MANAGER` role.

## Considerations

Restarting OBProxies interrupts connections. Proceed with caution.

## Procedure

1. Log in to OCP.

2. In the left-side navigation pane, click **OBProxy**.

3. In the cluster list, select the target OBProxy cluster to go to its **Overview** page.

4. In the upper-right corner of the page, click the **...** icon and select **Restart All**.

   <main id="notice" type='notice'>
   <h4>Notice</h4>
   <p>Restarting OBProxies will cause connection interruptions. Proceed with caution.</p>
   </main>

   ![restart-cluster](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/user-guide/odp-management/delete-odp-cluster.png)

5. In the dialog box that appears, click **Restart**.

   You can view the restart progress by clicking **View Task** in the dialog box.

   The restart is successful when the task status is **Completed** and the status of all OBProxies is **Running** in the **OBProxy List** on the cluster **Overview** page.
