# Upgrade OBProxy

When a new OBProxy version is available, you can upgrade one or more OBProxies in the OCP console.

## Prerequisites

The current OCP user has permissions to manage the target OBProxy.

## Procedure

1. Log in to OCP.

2. In the left-side navigation pane, click **OBProxy**.

3. In the cluster list, select the target OBProxy cluster to go to its **Overview** page.

4. Perform the following operations:

   * In the **OBProxy List**, find the OBProxy that you want to upgrade, click **Upgrade** in the corresponding **Actions** column, select or upload the upgrade package, and then click **OK**.

   * To upgrade multiple OBProxies at a time, select them in the **OBProxy List**, click **Batch Upgrade** in the upper-right corner of the list, select or upload the upgrade package, and then click **OK**.

5. In the dialog box that appears, select the version to upgrade to in the **Upgrade Version** field.

   <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>You can upgrade to only a higher version. The hardware architecture of the target version must match that of the current host.</p>
   </main>

6. Click **OK** to complete the upgrade.

   You can view the progress by clicking **View Task** in the dialog box.

   The upgrade is successful when the task status is **Completed** and the status of the OBProxy is **Running** in the **OBProxy List** on the cluster **Overview** page.

## References
