# Refresh OBProxy configuration

This topic describes how to refresh the configuration of an OBProxy.

## Refresh OBProxy configuration by using SQL statements

You can use the `ALTER PROXYCONFIG` statement to refresh the configuration of a single OBProxy.

1. Connect to OBProxy as the `root@proxysys` user.

2. Execute the following statement to view the value of the parameter to be refreshed.

   Here is an example:

   ```sql
   obclient> SHOW PROXYCONFIG LIKE 'fetch_proxy_bin_random_time';
   ```

   You can also use the `SHOW PROXYCONFIG` statement to view all parameters of the current OBProxy.

3. Execute the following statement to modify the parameter value:

   ```sql
   obclient> ALTER PROXYCONFIG SET fetch_proxy_bin_random_time='300s';
   ```
