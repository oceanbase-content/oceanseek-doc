# Delete an OBProxy

This topic describes how to delete an OBProxy that is no longer needed in the OCP console. You can delete one or more OBProxies based on your business requirements.

## Prerequisites

Ensure that no business connections exist on the OBProxy.

## Procedure

1. Log in to OCP.

2. In the left-side navigation pane, click **OBProxy**.

3. In the cluster list, select the target OBProxy cluster to go to its **Overview** page.

4. Perform the following operations:

   <main id="notice" type='notice'>
   <h4>Notice</h4>
   <p><ul>
   <li>If the OBProxy to be deleted is the last one in the OBProxy cluster, the deletion will prevent applications from connecting to the corresponding database. Proceed with caution.</li>
   <li>After an OBProxy is deleted, it is removed from the load balancing policy configuration, which affects the applications hosted by it.</li>
   </ul></p>
   </main>

   * In the **OBProxy List**, find the OBProxy that you want to delete, click the ... icon in the corresponding **Actions** column, select **Delete**, and then click **Delete** again in the dialog box that appears.

      ![Delete OBProxy](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/user-guide/odp-management/delete-an-odp.png)

   * To delete multiple OBProxies at a time, select the OBProxies that you want to delete in the **OBProxy List**, click the **...** icon in the upper-right corner of the list, select **Batch Delete**, and then click **Delete** again in the dialog box that appears.
  
      ![Batch delete](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/user-guide/odp-management/delete-odps.png)

5. In the dialog box that appears, select **Delete**.

   You can view the deletion progress by clicking **View Task** in the dialog box.

   When the task status is **Completed** and the OBProxy is no longer listed in the **OBProxy List** on the cluster **Overview** page, the deletion is successful.
