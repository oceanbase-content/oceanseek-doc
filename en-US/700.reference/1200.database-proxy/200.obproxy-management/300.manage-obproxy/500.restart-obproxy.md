# Restart OBProxy

This topic describes how to restart OBProxy.

## Restart a single OBProxy by using commands

When an abnormality occurs in an OBProxy instance, you can run commands to restart the corresponding obproxy process.

To do so, perform the following steps:

1. Log in as the admin user to the server that hosts the OBProxy instance.

2. Stop the obproxy process.

   For more information, see [Stop OBProxy](../300.manage-obproxy/400.stop-obproxy.md).

3. Start the obproxy process.

   For more information, see [Start OBProxy](../300.manage-obproxy/200.start-obproxy.md).
