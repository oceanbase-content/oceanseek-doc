# Add an OBProxy

This topic describes how to add a new OBProxy to an existing OBProxy cluster by using OCP.

## Prerequisites

You have created an OBProxy cluster. For more information about how to create an OBProxy cluster, see [Create an OBProxy cluster](../200.manage-obproxy-clusters/100.create-an-obproxy-cluster.md).

## Procedure

1. Log in to OCP.

2. In the left-side navigation pane, click **OBProxy**.

3. In the cluster list, select the target OBProxy cluster to go to its **Overview** page.

4. Click **Add OBProxy**.

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/user-guide/odp-management/add-an-odp.png)

5. In the dialog box that appears, specify the **Software Version**, **SQL Port**, **Exporter Port**, **Data Center**, **Host Type**, and **Host**.

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.1.0/user-guide/odp-management/add-an-odp2.png)

   Refer to the following table to specify the parameters:

   | Parameter | Description |
   |---------------|----------------------------------------------------|
   | SQL Port | The default value is 2883. |
   | Exporter Port | The default value is 2884. |
   | Software Version | Select the version of OBProxy to install. |
   | Data Center, Host Type (Optional), Host | Configure the host where OBProxy is to be deployed by setting **Data Center**, **Host Type (Optional)**, and **Host**. |

6. Click **OK**.

   <main id="notice" type='explain'>
   <h4>Note</h4>
   <p><ul>
   <li>If the OBProxy cluster is V4.0 or later, you can only select software packages of V4.0.0 or later.</li><li>If the OBProxy cluster is V3.x or earlier, you can select software packages of V1.8.0 or later but earlier than V4.0.0.</li>
   <li>If no OBProxy has been created or taken over in the OBProxy cluster, you can customize the SQL port and Exporter port when adding an OBProxy. If an OBProxy already exists in the OBProxy cluster, the SQL port and Exporter port inherit the ports configured when OBProxy was deployed in the cluster and cannot be customized.</li>
   </ul></p>
   </main>
