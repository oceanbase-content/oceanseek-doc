# Query the statistics of a session

This topic describes how to query the internal statistics of a specified client session on ODP, including the number of SQL request responses and the size of SQL request responses.

## Procedure

You can query the internal statistics of a specified client session on ODP by executing the `SHOW PROXYSESSION STAT` statement in the `sys` tenant or a user tenant.

1. Connect to OceanBase AI Database by using ODP.

    Here is an example:

    ```shell
    obclient -h10.xx.xx.xx -uusername@obtenant#obdemo -P2883 -p****** -c -A oceanbase
    ```

    For more information about how to connect to a database by using ODP, see [Connect to OceanBase AI Database by using OBClient](../../../200.connect/200.client/300.connect-to-an-oceanbase-tenant-by-using-obclient.md).

2. Query the internal statistics of the specified client session on ODP.

    ```sql
    SHOW PROXYSESSION STAT id LIKE 'xx';
    ```

    The parameters are described as follows:

    * In the statement, `id` can be replaced with `cs_id` or `connection_id`, and the query results are the same.

      `cs_id` indicates the ID of a client session in ODP. `connection_id` indicates the ID of a client session in OceanBase AI Database.

      You can obtain the `connection_id` value by using the `SELECT CONNECTION_ID();` statement.

    * The `LIKE` option supports fuzzy matches. Percent signs (%) and underscores (_) are supported.

    Here is an example:

    1. Query `cs_id` or `connection_id`.

       Execute the following statement to query `cs_id`:

       ```sql
       SHOW PROXYSESSION;
       ```

       In the following query result, `Id` is equivalent to `cs_id`.

       ```shell
       +----------------------+-------+----------+----------+------+----------------------+------+-------------+-------------------+-------------------+-------+-------+-----------+
       | proxy_sessid         | Id    | Cluster  | Tenant   | User | Host                 | db   | trans_count | svr_session_count | state             | tid   | pid   | using_ssl |
       +----------------------+-------+----------+----------+------+----------------------+------+-------------+-------------------+-------------------+-------+-------+-----------+
       | 12402504630519660562 | 11    | test420  | mysql001 | root | 100.xx.xx.xx:48056   | NULL |           0 |                 1 | MCS_ACTIVE_READER | 76286 | 76286 |         0 |
       +----------------------+-------+----------+----------+------+----------------------+------+-------------+-------------------+-------------------+-------+-------+-----------+
       1 row in set
       ```

       Execute the following statement to query `connection_id`:

       ```sql
       SELECT CONNECTION_ID();
       ```

       The query result is as follows:

       ```shell
       +-----------------+
       | CONNECTION_ID() |
       +-----------------+
       |      3221597019 |
       +-----------------+
       1 row in set
       ```

    2. Query the internal statistics.

       ```sql
       SHOW PROXYSESSION STAT 11 LIKE '%time%';
       ```

       Alternatively, use the following syntax:

       ```sql
       SHOW PROXYSESSION STAT 3221597019 LIKE '%time%';
       ```

       The return result is as follows:

