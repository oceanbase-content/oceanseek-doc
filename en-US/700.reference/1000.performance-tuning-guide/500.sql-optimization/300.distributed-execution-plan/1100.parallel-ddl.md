# Parallel DDL

OceanSeek supports parallel DDL operations to improve the execution efficiency of DDL statements.

## Configure parallel DDL

In OceanSeek, you can flexibly control the parallel DDL feature by configuring the following parameters:

* `_enable_parallel_table_creation`: controls parallel `CREATE TABLE` operations.
* `_parallel_ddl_control`: controls the following parallel operations:

  * `TRUNCATE TABLE`
  * `DROP TABLE`
  * `CREATE INDEX`
  * `CREATE VIEW`
  * `COMMENT`

### _enable_parallel_table_creation

`_enable_parallel_table_creation` specifies whether to enable concurrent table creation (`CREATE TABLE`) at the tenant level.

| **Attribute** | **Description** |
| ----------- | ---------------- |
| Parameter type | Boolean |
| Default value | True, indicating that concurrent table creation is enabled. |
| Value range | <ul><li> False   </li><li> True  </li></ul> |
| Effective mode | Effective immediately |

#### Examples

* Execute the following statement in the `sys` tenant to disable concurrent table creation for the user tenant `mysql001`.

    ```sql
    ALTER SYSTEM SET _enable_parallel_table_creation = false tenant=mysql001;
    ```

* Execute the following statement in a user tenant to disable concurrent table creation.

    ```sql
    ALTER SYSTEM SET _enable_parallel_table_creation = false;
    ```

    ```sql
    ALTER SYSTEM SET "_enable_parallel_table_creation" = false;
    ```

### _parallel_ddl_control

`_parallel_ddl_control` specifies whether to enable various parallel DDL features at the tenant level. In the current version of OceanSeek, this parameter controls the switches for the parallel features of `TRUNCATE TABLE`, `CREATE INDEX`, `CREATE VIEW`, `DROP TABLE`, and `COMMENT`.

| **Attribute** | **Description** |
| ----------- | ---------------- |
| Parameter type | STRING |
| Default value | Empty string. The semantics are as follows: <ul><li>`TRUNCATE TABLE` defaults to `ON`, indicating that parallel execution is enabled by default. </li><li>For other types of DDL statements (other than `TRUNCATE TABLE`), the default value is `OFF`, indicating that parallel execution is disabled by default. </li></ul> <main id="notice" type='explain'><h4>Note</h4><p>For individual parallel DDL operations, DDL types other than <code>TRUNCATE TABLE</code> (which defaults to <code>ON</code>) default to <code>OFF</code>.</p></main> |
| Value range | An empty string, or <code>DDL:{ON \| OFF} [, DDL:{ON \| OFF}] [, ...]</code>. For details about DDL type information, see the table below. |
| Effective mode | Effective immediately |

DDL type information:

| **DDL type** | **Valid values** |
| ------------- | ---------- |
| TRUNCATE_TABLE | TRUNCATE_TABLE:{ON \| OFF} |
| SET_COMMENT | SET_COMMENT:{ON \| OFF} |
| CREATE_INDEX | CREATE_INDEX:{ON \| OFF} |
| CREATE_VIEW | CREATE_VIEW:{ON \| OFF} |
| DROP_TABLE | DROP_TABLE:{ON \| OFF} |

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>The current version of OceanSeek does not support concurrent execution of full-text indexes, multi-valued indexes, and vector indexes.</p>
</main>

#### Examples

* Execute the following statement in the `sys` tenant to enable parallel `TRUNCATE TABLE` and disable parallel `CREATE INDEX` for the user tenant `mysql001`.

    ```sql
    ALTER SYSTEM SET _parallel_ddl_control = 'CREATE_INDEX:ON, TRUNCATE_TABLE:OFF' tenant = 'mysql001';
    ```

* Execute the following statement in a user tenant to disable parallel `TRUNCATE TABLE` and enable parallel `CREATE INDEX`.

    ```sql
    ALTER SYSTEM SET _parallel_ddl_control = 'CREATE_INDEX:ON, TRUNCATE_TABLE:OFF';
    ```

    ```sql
    ALTER SYSTEM SET "_parallel_ddl_control" = 'CREATE_INDEX:ON, TRUNCATE_TABLE:OFF';
    ```

## Default DDL parallelism

In OceanSeek, you can use the session-level parameter `_force_parallel_ddl_dop` to specify the default parallelism for DDL operations.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>If the parallelism is not explicitly specified using the <code>PARALLEL</code> hint, DDL will use the value set by <code>_force_parallel_ddl_dop</code>.</p>
</main>

When using the parallel DDL feature, you can pre-set the parallelism for DDL execution via `_force_parallel_ddl_dop`.

### Example

Execute the following statement in a user tenant to set the default parallelism for session-level DDL operations to 16.

```sql
SET _FORCE_PARALLEL_DDL_DOP = 16;
```

```sql
SET "_FORCE_PARALLEL_DDL_DOP" = 16;
```
