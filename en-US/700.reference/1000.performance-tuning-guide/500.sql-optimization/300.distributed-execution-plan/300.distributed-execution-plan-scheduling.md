# Distributed execution plan scheduling

OceanBase AI Database schedules query plans based on a simple scheduling model.

In the final stage of execution plan generation, the plan is split into multiple subplans with `EXCHANGE` nodes as the boundaries. Each subplan is encapsulated as a DFO. In a scenario where the degree of parallelism is greater than 1, two DFOs are scheduled at a time to traverse and execute the DFO tree in sequence. In a scenario where the degree of parallelism is equal to 1, each DFO stores the generated data in the intermediate result manager, and the entire DFO tree is traversed and executed in post-order traversal.
