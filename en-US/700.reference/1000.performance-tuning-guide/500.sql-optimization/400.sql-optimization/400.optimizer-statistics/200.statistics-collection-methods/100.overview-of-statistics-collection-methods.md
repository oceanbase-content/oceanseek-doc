# Overview of statistics collection methods

The optimizer of OceanBase AI Database supports both manual and automatic statistics collection. It also provides corresponding views for querying the collected statistics.

The following table lists the views in OceanBase AI Database for querying relevant statistics.

| **View** | **Description** |
| -------------------------------------- | --------------------------------------------------- |
| oceanbase.DBA_TAB_STATISTICS | Used to query table-level statistics. |
| oceanbase.DBA_TAB_COL_STATISTICS | Used to query column-level statistics at the `GLOBAL` granularity. |
| oceanbase.DBA_PART_COL_STATISTICS | Used to query column-level statistics at the `PARTITION` granularity. |
| oceanbase.DBA_SUBPART_COL_STATISTICS | Used to query column-level statistics at the `SUBPARTITION` granularity. |
| oceanbase.DBA_TAB_HISTOGRAMS | Used to query column-level histogram statistics at the `GLOBAL` granularity. |
| oceanbase.DBA_PART_HISTOGRAMS | Used to query column-level histogram statistics at the `PARTITION` granularity. |
| oceanbase.DBA_SUBPART_HISTOGRAMS | Used to query column-level histogram statistics at the `SUBPARTITION` granularity. |
| oceanbase.DBA_IND_STATISTICS | Used to query index statistics. |
