# FOR UPDATE

The `FOR UPDATE` operator is used to lock data in a table.

OceanBase AI Database supports the `FOR UPDATE` and `MULTI FOR UPDATE` operators.

The general process for executing a query with the `FOR UPDATE` operator is as follows:

1. First, execute the `SELECT` statement part to obtain the query result set.

2. Lock the records related to the query result set.

## FOR UPDATE

`FOR UPDATE` is used to lock a single table (or a single partition).

In the following example, query Q1 locks the rows in table `t1` that satisfy `c1 = 1`. Table `t1` is a single-partition table, so operator 1 generates a `FOR UPDATE` operator.

```sql
obclient> CREATE TABLE t1(c1 INT, c2 INT);
Query OK, 0 rows affected 

obclient> CREATE TABLE t2(c1 INT, c2 INT);
Query OK, 0 rows affected 

obclient> INSERT INTO t1 VALUES(1, 1);
Query OK, 0 rows affected

obclient> INSERT INTO t1 VALUES(2, 2);
Query OK, 1 rows affected 

obclient> INSERT INTO t1 VALUES(3, 3);
Query OK, 1 rows affected 

obclient> INSERT INTO t2 VALUES(1, 1);
Query OK, 1 rows affected 

obclient> INSERT INTO t2 VALUES(2, 2);
Query OK, 1 rows affected 

obclient> INSERT INTO t2 VALUES(3, 3);
Query OK, 1 rows affected 

Q1: 
obclient> EXPLAIN SELECT * FROM t1 WHERE c1 = 1 FOR UPDATE;
```

| lock tables | The tables that need to be locked. |

## MULTI FOR UPDATE

`MULTI FOR UPDATE` is used to lock multiple tables (or multiple partitions).

In the following example, query Q2 locks the data in tables `t1` and `t2`, targeting the rows that satisfy `c1 = 1 AND c1 = d1`. Since rows from multiple tables need to be locked, operator 1 is a `MULTI FOR UPDATE`.

```sql
obclient> CREATE TABLE t1 (c1 INT, c2 INT);
Query OK, 0 rows affected 

obclient> CREATE TABLE t2 (d1 INT, d2 INT);
Query OK, 0 rows affected 

obclient> EXPLAIN SELECT * FROM t1, t2 WHERE c1 = 1 AND c1 = d1 FOR UPDATE;
```
