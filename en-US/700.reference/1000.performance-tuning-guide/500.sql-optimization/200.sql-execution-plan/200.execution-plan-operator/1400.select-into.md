# SELECT INTO

The `SELECT INTO` operator is used to assign the query result to a list of variables. The query returns only one row of data.

In the following example query, the output columns of `SELECT` are `COUNT(*)` and `MAX(c1)`. Their query results are assigned to variables `@a` and `@b` respectively.

```sql
obclient> CREATE TABLE t1(c1 INT, c2 INT);
Query OK, 0 rows affected 

obclient> INSERT INTO t1 VALUES(1,1);
Query OK, 1 rows affected 

obclient> INSERT INTO t1 VALUES(2,2);
Query OK, 1 rows affected 

obclient> EXPLAIN SELECT COUNT(*), MAX(c1) INTO @a, @b FROM t1;
```
