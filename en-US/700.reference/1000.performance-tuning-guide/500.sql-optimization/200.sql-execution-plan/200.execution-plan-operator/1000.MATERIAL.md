# MATERIAL

The `MATERIAL` operator is used to materialize the data output by a lower-level operator.

OceanSeek uses streaming execution plans. However, sometimes an operator must wait until all data from a lower-level operator is output before it can start executing. Therefore, a `MATERIAL` operator is added below it to materialize all the data. In addition, when a subplan needs to be executed repeatedly, a `MATERIAL` operator can avoid repeated execution.

In the following example, when performing a `NESTED LOOP JOIN` operation between table `t1` and table `t2`, the right table requires repeated scanning. A `MATERIAL` operator on the right table can be used to save all the data of table `t2`.

```sql
obclient> CREATE TABLE t1(c1 INT, c2 INT, c3 INT);
Query OK, 0 rows affected 

obclient> CREATE TABLE t2(c1 INT ,c2 INT ,c3 INT);
Query OK, 0 rows affected 

obclient> EXPLAIN SELECT  /*+ORDERED USE_NL(T2)*/* FROM t1,t2 WHERE t1.c1=t2.c1;

Query Plan: 
===========================================
|ID|OPERATOR        |NAME|EST. ROWS|COST  |
-------------------------------------------
|0 |NESTED-LOOP JOIN|    |2970     |277377|
|1 | TABLE SCAN     |t1  |3        |37    |
|2 | MATERIAL       |    |100000   |176342|
|3 |  TABLE SCAN    |t2  |100000   |70683 |
===========================================
Outputs & filters: 
-------------------------------------
  0 - output([t1.c1], [t1.c2], [t1.c3], [t2.c1], [t2.c2], [t2.c3]), filter(nil), 
      conds([t1.c1 = t2.c1]), nl_params_(nil)
  1 - output([t1.c1], [t1.c2], [t1.c3]), filter(nil), 
      access([t1.c1], [t1.c2], [t1.c3]), partitions(p0)
  2 - output([t2.c1], [t2.c2], [t2.c3]), filter(nil)
  3 - output([t2.c1], [t2.c2], [t2.c3]), filter(nil), 
      access([t2.c1], [t2.c2], [t2.c3]), partitions(p0)
```

In the preceding example, the purpose of Operator 2 (`MATERIAL`) in the execution plan is to save the data of table `t2`, thereby avoiding scanning the data of table `t2` from disk on each join. The `outputs & filters` section of the execution plan shows the output information of the `MATERIAL` operator as follows:

| **Information name** | **Description** |
| ---------- | ------------------------------------------------------------------------ |
| output | The output columns of this operator. |
| filter | The filter predicate of this operator. In the example, no `filter` is set for the `MATERIAL` operator, so the value is `nil`. |
