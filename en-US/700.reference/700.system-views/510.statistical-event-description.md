# Overview of Metrics

Covers key monitoring metrics for all core components of OceanBase AI Database, including its clusters, tenants, and hosts.

## Query metric items

You can query the definition information of all monitoring items by executing an SQL statement in the sys tenant. Example:

```shell
obclient> SELECT STAT_ID, CLASS, NAME FROM V$STATNAME;
```

Many monitoring items are related to the internal implementation and may be changed or deleted. The actual situation shall prevail. For details about specific monitoring item categories, see Monitoring Items.

## Metric categories

OceanBase AI Database supports monitoring over 600 metrics across 15 major categories, covering all critical execution aspects such as network, request queue, transactions, SQL, caching, storage, resource quotas, and logs. The specific categories are as follows:
