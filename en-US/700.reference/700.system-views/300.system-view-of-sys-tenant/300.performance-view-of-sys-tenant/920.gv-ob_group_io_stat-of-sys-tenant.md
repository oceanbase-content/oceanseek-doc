# GV$OB_GROUP_IO_STAT

## Overview

This view displays the real-time status of each resource group on all OBServer nodes of all tenants.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ------------------------------ | -------------- | ---------------- | ------------------------------------------------------------ |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| SVR_IP | varchar(46) | NO | Server IP Address |
| SVR_PORT | bigint(20) | NO | Server Port Number |
| GROUP_ID | bigint(20) | NO | Corresponding resource group ID |
| GROUP_NAME | varchar(128) | NO | Corresponding resource group name |
| MODE | varchar(128) | NO | Read/write mode. Valid values:<ul><li>`READ`: read-only mode</li> <li>`WRITE`: Write mode</li></ul> |
| MIN_IOPS | bigint(20) | NO | Minimum IOPS in the resource group |
| MAX_IOPS | bigint(20) | NO | Maximum IOPS in the Resource Group |
| NORM_IOPS | bigint(20) | NO | Current IOPS (converted to the value corresponding to a 16 KB read for display) |
| REAL_IOPS | bigint(20) | NO | Current IOPS |
| MAX_NET_BANDWIDTH | bigint(20) | NO | Maximum network bandwidth in the resource group, in bytes |
| MAX_NET_BANDWIDTH_DISPLAY | varchar(128) | NO | The maximum network bandwidth of the resource group after conversion, displayed in a format such as 10 GB/s or 10 MB/s. |
| REAL_NET_BANDWIDTH | bigint(20) | NO | Current network bandwidth, in bytes |
| REAL_NET_BANDWIDTH_DISPLAY | varchar(128) | NO | The current network bandwidth displayed after conversion, in a format such as 10 GB/s or 10 MB/s. |

## Sample query

Query the real-time status of all resource groups on all OBServer nodes across all tenants in the sys tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_GROUP_IO_STAT LIMIT 1\G
```
