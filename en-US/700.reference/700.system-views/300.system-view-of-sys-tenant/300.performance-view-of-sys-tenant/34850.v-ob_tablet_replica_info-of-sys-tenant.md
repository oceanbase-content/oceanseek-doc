# V$OB_TABLET_REPLICA_INFO

## Overview

The `V$OB_TABLET_REPLICA_INFO` view displays basic information about all tablet replicas of all tenants on the current node, including the tenant to which they belong, log stream, table, database, and disk usage.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ---------------------- | --------------- | ---------------- | --------------------------------- |
| SVR_IP | varchar(46) | NO | Node IP Address |
| SVR_PORT | bigint(20) | NO | Node Port Number |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| LS_ID | bigint(20) | NO | Log Stream ID |
| TABLET_ID | bigint(20) | NO | Tablet replica ID |
| ROLE | varchar(8) | NO | Log stream roles:<ul><li>`LEADER`: Primary replica</li> <li>`FOLLOWER`: From replica</li></ul> |
| ZONE | varchar(128) | NO | Zone of Tablet Replica |
| TABLE_ID | bigint(20) | NO | ID of the table to which the tablet replica belongs |
| TABLE_NAME | varchar(256) | NO | Table name of the tablet replica |
| DATABASE_ID | bigint(20) | NO | ID of the database to which the table belongs |
| DATABASE_NAME | varchar(128) | NO | The name of the database to which the table belongs. |
| TABLE_TYPE | varchar(21) | NO | Table type:<ul><li>`SYSTEM_TABLE`: system tables</li> <li>`USER_TABLE`: User table</li> <li>`INDEX`: index table</li> <li>`LOB AUX TABLE`: LOB auxiliary table, a system-built table used to assist in implementing LOB columns.</li> <li>`MATERIALIZED VIEW LOG`: Materialized View Logs</li></ul> |
| TABLEGROUP_ID | bigint(20) | NO | Table group ID |
| TABLEGROUP_NAME | varchar(128) | NO | Table group name |
| DATA_TABLE_ID | bigint(20) | NO | Data table ID of the table. |
| OCCUPY_SIZE | bigint(20) | NO | The actual data size occupied by the tablet replica, in bytes. |
| REQUIRED_SIZE | bigint(20) | NO | The size of space required for tablet replica data, in bytes. |
| OBJECT_ID | bigint(20) | NO | The ID of the partition or subpartition object. For a non-partitioned table, it displays as the table's `table_id`. |
| PARTITION_NAME | varchar(64) | NO | The name of the partition. For a non-partitioned table, this field is empty. |
| SUBPARTITION_NAME | varchar(64) | NO | Subpartition name. If the table is not a partitioned table, this field displays empty. |

## Sample query

The system tenant queries the basic information of all tablet replicas of the tenant with ID 1002 on the current node and displays the first two records.

```shell
obclient(root@sys)[oceanbase]> SELECT * FROM oceanbase.V$OB_TABLET_REPLICA_INFO WHERE TENANT_ID = 1002 LIMIT 2\G
```
