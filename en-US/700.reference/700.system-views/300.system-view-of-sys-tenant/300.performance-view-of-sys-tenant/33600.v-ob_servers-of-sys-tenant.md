# V$OB_SERVERS

## Overview

Displays information about the current OBServer node.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ------------------------- | -------------- | ------------ | -------------------------------------------------------------- |
| SVR_IP | varchar(46) | NO | Server IP Address |
| SVR_PORT | bigint(20) | NO | Server Port Number |
| ZONE | varchar(128) | NO | Zone Name |
| SQL_PORT | bigint(20) | NO | SQL Port |
| CPU_CAPACITY | bigint(20) | NO | Total Node CPU Capacity |
| CPU_CAPACITY_MAX | double | NO | The overprovisioning value of the total CPU capacity of the node. It is calculated by `resource_hard_limit` Parameter control: `CPU_CAPACITY_MAX =  CPU_CAPACITY * resource_hard_limit` |
| CPU_ASSIGNED | double | NO | The number of CPU cores allocated to the OBServer node, which is the total number of CPU cores for all units on the OBServer node. `MIN_CPU` The total size of the specifications. Constraints: `CPU_ASSIGNED <= CPU_CAPACITY` |
| CPU_ASSIGNED_MAX | double | NO | The upper limit of CPU cores allocated to the OBServer node, which is the total number of CPU cores for all units on the OBServer node. `MAX_CPU` The total size of the specifications. Constraints: `CPU_ASSIGNED_MAX <= CPU_CAPACITY_MAX` |
| MEM_CAPACITY | bigint(20) | NO | Total memory size available for tenants on the OBServer node. Value: `memory_limit - system_memory`, in bytes |
| MEM_ASSIGNED | bigint(20) | NO | The allocated memory size of the OBServer node, which is the total memory for all units on the OBServer node. `MEMORY_SIZE` The total size, in bytes. Constraints: `MEM_ASSIGNED <= MEM_CAPACITY` |
| LOG_DISK_CAPACITY | bigint(20) | NO | Total log disk space, in bytes |
| LOG_DISK_ASSIGNED | bigint(20) | NO | The allocated size of the log disk, which is the total size of all units on the OBServer node. `LOG_DISK_SIZE` Total size, in bytes |
| LOG_DISK_IN_USE | bigint(20) | NO | Used log disk space, in bytes |
| DATA_DISK_CAPACITY | bigint(20) | NO | Indicates the total size of the local cache space on the OBServer node. It is the sum of the cache sizes of all units on the OBServer node. `DATA_DISK_SIZE` The upper limit of the sum of the sizes, in bytes. |
| DATA_DISK_ASSIGNED | bigint(20) | YES | Indicates the local cache size allocated to the unit on the OBServer node. It is the total of all units on the OBServer node. `DATA_DISK_SIZE` The total size of the specifications, in bytes. |
| DATA_DISK_IN_USE | bigint(20) | NO | Indicates the size of the local cache used by the OBServer node. It is the sum of the sizes of all units on the OBServer node. `DATA_DISK_IN_USE` sum, in bytes. |
| DATA_DISK_HEALTH_STATUS | varchar(20) | NO | Data disk health status: <ul><li>`NORMAL`: Normal </li><li>`WARNING`: An exception occurred.  </li><li>`ERROR`: An error occurred. </li></ul> |
| MEMORY_LIMIT | bigint(20) | NO | Total memory size available for the OBServer node, in bytes |
| DATA_DISK_ALLOCATED | bigint(20) | NO | This value equals `DATA_DISK_CAPACITY` indicates that the entire space is available. |
| DATA_DISK_ABNORMAL_TIME | timestamp(6) | NO | Last Data Disk Exception (`WARNING` and `ERROR` (Status) Time |
| SSL_CERT_EXPIRED_TIME | timestamp(6) | NO | Records the expiration time and UTC time of the SSL certificate used by the current OBServer node when SSL is enabled. Unit: microseconds. |
| SS_DATA_DISK_OPERATION_SUGGESTED | varchar(32) | YES | Recommendations for scaling local cache disks in shared storage:<ul><li>`NONE`: No operation. </li> <li>`EXPAND`: scale-out</li> <li>`SHRINK`: Scale down</li> </ul> |
| SS_DATA_DISK_SIZE_SUGGESTED | bigint(20) | YES | The recommended value for local disk capacity, in bytes. If the value is `0`, which allows you to decide the size of each expansion. If the value is not `0` After the scale-out, ensure that the capacity of the local disk is greater than or equal to the current recommended value. |
