# V$OB_PL_CACHE_OBJECT

## Overview

The `V$OB_PL_CACHE_OBJECT` view displays basic information about PL-related cache objects in the local server for all tenants.

## Columns

| **Column** | **Type** | **Is NULL** | **Description** |
| ---- | ---- | ---- | ---- |
| TENANT_ID | bigint(20) | NO | Tenant ID: <ul><li>1: system tenant ID</li><li>Other values: user tenant or Meta tenant ID</li></ul> |
| SVR_IP | varchar(46) | NO | Node address where the cached object is located |
| SVR_PORT | bigint(20) | NO | Port of the node where the cache object resides |
| CACHE_OBJECT_ID | bigint(20) | NO | Cache object ID allocated by libcache |
| PARAMETERIZE_TEXT | longtext | NO | <ul><li>Anonymous blocks and CALL statements in package storage mode: Indicates a parameterized SQL text.  </li><li>Procedure/Fuction/Package, etc.: Indicates the name of a stored procedure object. </li></ul> |
| OBJECT_TEXT | longtext | NO | Query statement text. This field is valid only in anonymous blocks and CALL statements in PS mode. |
| FIRST_LOAD_TIME | timestamp(6) | NO | Time taken for the first load, in microseconds |
| LAST_ACTIVE_TIME | timestamp(6) | NO | Last Cache Hit Time, in microseconds |
| AVG_EXE_USEC | bigint(20) | NO | Average execution time, in microseconds |
| SLOWEST_EXE_TIME | timestamp(6) | NO | Slowest execution timestamp, in microseconds |
| SLOWEST_EXE_USEC | bigint(20) | NO | Time consumed in the most recent slow execution, in microseconds |
| HIT_COUNT | bigint(20) | NO | Cache Hits |
| CACHE_OBJ_SIZE | bigint(20) | NO | Memory Size Occupied by Cache Objects |
| EXECUTIONS | bigint(20) | NO | Number of Successful Stored Procedure Executions |
| ELAPSED_TIME | bigint(20) unsigned | NO | Time taken by the last stored procedure execution, in microseconds |
| OBJECT_TYPE | longtext | NO | Cache object type (for example, Procedure, Function, Trigger, etc.) |
| OBJECT_ID | bigint(20) unsigned | NO | Storage Procedure Object ID (`routine_id`/`package_id`) |
| COMPILE_TIME | bigint(20) unsigned | NO | Stored procedure compilation time, in microseconds |
| SCHEMA_VERSION | bigint(20) | NO | Schema version number |
| PS_STMT_ID | bigint(20) | NO | The corresponding prepare ID of the request: <ul><li>`-1`: Indicates that the SQL statement does not use the PS protocol.  </li><li>Non-`-1`: Indicates that the SQL statement uses the PS protocol, which is the unique identifier returned by the PS protocol for this statement.</li></ul> |
| DB_ID | bigint(20) unsigned | NO | The database ID used during the compilation of the stored procedure. |
| PL_CG_MEM_HOLD | bigint(20) | NO | Memory Held During PLCG Phase |
| SYS_VARS | varchar(4096) | NO | Displays system variables that affect plan generation in the current session. |
| PARAM_INFOS | longtext | NO | Displays the parameterized type information for anonymous blocks and call proc info |
| SQL_ID | varchar(32) | NO | Unique ID generated by the MD5 hash of db_name+routine_name |
| OUTLINE_VERSION | bigint(20) | NO | The version of the throttling outline. Default value: `0` |
| OUTLINE_ID | bigint(20) | NO | The ID of the throttling outline, which is  by default. `-1` |
| CONCURRENT_DATA | longtext | NO | Throttling content, default is `/*+max_concurrent(-1)*/`, `-1` Indicates that throttling is not performed. |
| CG_TIME | bigint(20) unsigned | NO | Time Spent on Code Generation During PL Compilation |
