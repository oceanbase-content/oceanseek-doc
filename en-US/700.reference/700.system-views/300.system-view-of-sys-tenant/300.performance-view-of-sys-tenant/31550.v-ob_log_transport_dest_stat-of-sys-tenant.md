# V$OB_LOG_TRANSPORT_DEST_STAT

## Overview

The `V$OB_LOG_TRANSPORT_DEST_STAT` view displays information about all downstream log synchronization links (OBCDC/network standby databases) under the current OBServer for all tenants.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| -------- | -------- | ------------------ | -------- |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| SVR_IP | varchar(46) | NO | Server IP |
| SVR_PORT | bigint(20) | NO | Server RPC_PORT |
| LS_ID | bigint(20) | NO | Log stream ID of the request |
| CLIENT_IP | varchar(46) | NO | IP Address of the Server Where the Client Process Resides |
| CLIENT_PID | bigint(20) | NO | Process ID of the requester |
| CLIENT_TENANT_ID | bigint(20) | NO | Tenant ID of the requester |
| CLIENT_TYPE | varchar(7) | NO | Client type. Valid values: <ul><li>STANDBY: standby database client</li><li>CDC: OBCDC client</li><li>UNKNOWN: unknown client type</li></ul> |
| START_SERVE_TIME | timestamp(6) | NO | Record creation time |
| LAST_SERVE_TIME | timestamp(6) | NO | Record Modification Time |
| LAST_READ_SOURCE | varchar(7) | NO | Source of logs read during the last request processing:<ul><li>ONLINE: Online logs</li><li>ARCHIVE: Archived logs</li><li>UNKNOWN: Unknown source</li></ul> |
| LAST_REQUEST_TYPE | varchar(24) | NO | RPC type of the last request:<ul><li>0: SEQUENTIAL_READ_SERIAL, indicating that the serial log transfer protocol is used to read logs sequentially. </li><li>1: SEQUENTIAL_READ_PARALLEL, indicating that the parallel log transfer protocol is used to read logs sequentially. </li><li>2: SCATTERED_READ, indicating that the last request was to read discrete logs. </li><li>Other values: indicate an unknown RPC type. </li></ul> |
| LAST_REQUEST_LOG_LSN | bigint(20) unsigned | NO | LSN of the last requested log |
| LAST_REQUEST_LOG_SCN | bigint(20) unsigned | NO | SCN of the Last Requested Log |
| LAST_FAILED_REQUEST | longtext | NO | Information about the last failed RPC, including the send time, trace ID, and error code |
| AVG_REQUEST_PROCESS_TIME | bigint(20) | NO | Average RPC Processing Time |
| AVG_REQUEST_QUEUE_TIME | bigint(20) | NO | Average RPC Queue Time |
| AVG_REQUEST_READ_LOG_TIME | bigint(20) | NO | Average RPC Read Log Time |
| AVG_REQUEST_READ_LOG_SIZE | bigint(20) | NO | Average RPC Read Log Size |
| AVG_LOG_TRANSPORT_BANDWIDTH | varchar(29) | NO | Average Log Transfer Bandwidth |

## Sample query

Query the information about all downstream log synchronization links (OBCDC/network standby databases) under this OBServer for all tenants.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_LOG_TRANSPORT_DEST_STAT;
```
