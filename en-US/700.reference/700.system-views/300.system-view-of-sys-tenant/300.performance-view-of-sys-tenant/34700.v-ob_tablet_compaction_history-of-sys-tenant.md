# V$OB_TABLET_COMPACTION_HISTORY

## Overview

The `V$OB_TABLET_COMPACTION_HISTORY` view displays historical information on tablet-level compaction.

## Columns

| Field Name | Type | **Nullable** | Description |
| -------------------------------------- | -------------- | ---------------- | -------- |
| SVR_IP | varchar(46) | NO | Server IP |
| SVR_PORT | bigint(20) | NO | Server Port Number |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| LS_ID | bigint(20) | NO | Log Stream ID |
| TABLET_ID | bigint(20) | NO | Data Shard ID |
| TYPE | varchar(64) | NO | Compaction type:<ul><li>`MDS_TABLE_MERGE`: Persist system metadata to disk in SSTable format.</li> <li>`MAJOR_MERGE`: Tenant-level major compaction</li> <li>`MEDIUM_MERGE`: Partition-level major compaction</li> <li>`MINI_MERGE`: Performs a minor compaction, converting the MemTable into a Mini SSTable.</li> <li>`MINOR_MERGE`: Minor compaction, where multiple Mini SSTables are merged into a new Mini SSTable, or multiple Mini SSTables and a Minor SSTable are merged into a new Minor SSTable.</li> <li>`META_MAJOR_MERGE`: A special type of compaction that synthesizes data from a specified point in time into a Meta Major SSTable. Its data format is the same as that of a Major SSTable, excluding multi-version data and uncommitted transaction data.</li></ul> |
| COMPACTION_SCN | bigint(20) unsigned | NO | Major compaction version information |
| START_TIME | timestamp(6) | NO | Start Time |
| FINISH_TIME | timestamp(6) | NO | End Time |
| TASK_ID | varchar(64) | NO | Task Execution Trace |
| OCCUPY_SIZE | bigint(20) | NO | Data volume |
| MACRO_BLOCK_COUNT | bigint(20) | NO | Number of Macroblocks |
| MULTIPLEXED_MACRO_BLOCK_COUNT | bigint(20) | NO | Number of Macroblocks Reused |
| NEW_MICRO_COUNT_IN_NEW_MACRO | bigint(20) | NO | Number of New Microblocks in the Newly Generated Macroblock |
| MULTIPLEXED_MICRO_COUNT_IN_NEW_MACRO | bigint(20) | NO | Number of Reusable Microblocks in the Newly Generated Macroblock |
| TOTAL_ROW_COUNT | bigint(20) | NO | Total Rows |
| INCREMENTAL_ROW_COUNT | bigint(20) | NO | New Output Row |
| COMPRESSION_RATIO | double | NO | Compression ratio of new data = Ratio of compressed data to uncompressed data of newly added macroblocks |
| NEW_FLUSH_DATA_RATE | bigint(20) | NO | Output speed of new data, in KB/s |
| PROGRESSIVE_COMPACTION_ROUND | bigint(20) | NO | Asymptotic Major Compaction Current Round (This column is -1 for a full compaction.) |
| PROGRESSIVE_COMPACTION_NUM | bigint(20) | NO | Total Number of Asymptotic Major Compactions |
| PARALLEL_DEGREE | bigint(20) | NO | Degree of Parallelism |
| PARALLEL_INFO | varchar(512) | NO | Parallel task information, displaying statistics on the data scanned, running time, and output data volume (minimum/maximum/average) of the parallel task. |
| PARTICIPANT_TABLE | varchar(512) | NO | Information about tables participating in this compaction |
| MACRO_ID_LIST | varchar(256) | NO | The output macroblock list. If the macroblock list is too long, it will not be displayed. |
| COMMENTS | varchar(256) | NO | Records the history of failed compactions and collects information on the duration of the current compaction. |
| START_CG_ID | bigint(20) | NO | Start ID of Column Group |
| END_CG_ID | bigint(20) | NO | End ID of Column Group |
| KEPT_SNAPSHOT | varchar(128) | NO | Displays the multi-version timestamp retained for this compaction. |
| MERGE_LEVEL | varchar(64) | NO | Displays whether major compaction or microblock reuse was used during this execution. |
| EXEC_MODE | varchar(64) | NO | The mode that displays the major compaction trace: <ul><li>`EXEC_MODE_LOCAL`: local mode, outputs macroblocks to the local disk.</li> <li>`EXEC_MODE_VALIDATE`: Shared mode. Only computes the checksum and does not output macroblocks. This mode is not supported in the current version.</li> <li>`EXEC_MODE_OUTPUT`: Shared mode, which outputs macroblocks to shared storage. This mode is not supported in the current version.</li></ul> |
| IS_FULL_MERGE | varchar(5) | NO | Whether it is a full compaction. |
| IO_COST_TIME_PERCENTAGE | bigint(20) | NO | The ratio of I/O time to major compaction time. |
| MERGE_REASON | varchar(32) | NO | Reasons for concurrent initiation. Valid values: <ul><li>`LOAD_DATA_SCENE`: Derived scenarios</li> <li>`TOMBSTONE_SCENE`: Tombstone scenario</li> <li>`INEFFICIENT_QUERY`: Slow query scenarios</li> <li>`FREQUENT_WRITE`: Frequent write scenarios</li> <li>`TENANT_MAJOR`: Tenant-level major compaction</li> <li>`WINDOW_COMPACTION`: Window Consolidation</li>  <li>`USER_REQUEST`: User-initiated major compaction</li> <li>`REBUILD_COLUMN_GROUP`: Row-to-column scenarios</li></ul> |
| BASE_MAJOR_STATUS | varchar(64) | NO | Type of the major SSTable before major compaction: <ul><li>`COL_WITH_ALL`: defined as a hybrid row-column table, with baseline data in hybrid row-column format</li> <li>`COL_ONLY_ALL`: Defines the table as a hybrid row-column table during creation, and adaptive optimization of baseline data is performed only on row-based storage.</li> <li>`PURE_COL`: The table is defined as a pure columnar storage table, and the baseline data is stored in pure columnar format.</li> <li>`PURE_COL_ONLY_ALL`: The table is defined as a pure columnar storage table, but the baseline data adaptive optimization only stores row data.</li> <li>`ROW_STORE_MAJOR`:Row-store tables</li></ul> |
| CO_MERGE_TYPE | varchar(64) | NO | Columnar storage major compaction type:<ul><li>`BUILD_COLUMN_STORE_MERGE`: Major compaction to columnar storage</li> <li>`BUILD_ROW_STORE_MERGE`: Consolidate to rowstore</li> <li>`USE_RS_BUILD_SCHEMA_MATCH_MERGE`: Merged into the storage type that matches the schema.</li></ul> |
| MDS_FILTER_INFO | varchar(1024) | NO | Displays the MDS filter information used for major compaction. |
| EXECUTE_TIME | bigint(20) | NO | CPU Time Consumed by Major Compaction Tasks, in Microseconds |
| FILTER_ROW_COUNT | bigint(20) | NO | Number of rows reclaimed through compaction |
