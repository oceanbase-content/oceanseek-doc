# GV$OB_KVCACHE

## Overview

Displays the KVcache information of all tenants on each OBServer node.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ---------------- | --------------- | ------------ | ----------- |
| SVR_IP | varchar(46) | NO | Server IP Address |
| SVR_PORT | bigint(20) | NO | Server Port Number |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| CACHE_NAME | varchar(128) | NO | CACHE Item Name |
| PRIORITY | bigint(20) | NO | Priority |
| CACHE_SIZE | bigint(20) | NO | CACHE Size |
| HIT_RATIO | decimal(38,3) | NO | Hit Rate |
| TOTAL_PUT_CNT | bigint(20) | NO | Number of PUT Operations |
| TOTAL_HIT_CNT | bigint(20) | NO | Hit Count |
| TOTAL_MISS_CNT | bigint(20) | NO | Misses |

## Sample query

In the sys tenant, query the KVcache information of the tenant with ID 1002 on each OBServer node.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_KVCACHE WHERE TENANT_ID=1002;
```
