# GV$OB_IO_CALIBRATION_STATUS

## Overview

Displays the execution status of I/O calibration tasks on all nodes.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | Server IP Address |
| SVR_PORT | bigint(20) | NO | Server Port Number |
| STORAGE_NAME | varchar(1024) | NO | Storage name, for example, DATA or REDO. |
| STATUS | varchar(256) | NO | I/O calibration status. Valid values: <ul><li>NOT AVAILABLE</li><li>IN PROGRESS</li><li>READY</li></ul> |
| START_TIME | timestamp(6) | NO | Last I/O Calibration Start Time |
| FINISH_TIME | timestamp(6) | NO | End time of the last I/O calibration |

## Sample query

Query the execution status of I/O calibration tasks on all nodes.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_IO_CALIBRATION_STATUS;
```
