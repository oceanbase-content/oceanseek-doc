# V$OB_HMS_CLIENT_POOL_STAT

## Overview

This view displays the usage of the HMS Catalog client for all tenants.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ---------------- | ------------- | ---------------- | ---------------- |
| SVR_IP | varchar(46) | NO | Represents the node address where the replica is located. |
| SVR_PORT | bigint(20) | NO | Represents the node port where the replica is located. |
| TENANT_ID | bigint(20) | NO | Represents the tenant ID. Valid values: <ul><li>1: the system tenant ID. </li><li>Other values: the user tenant or Meta tenant ID.</li></ul> |
| CLIENT_TYPE | varchar(128) | NO | Indicates the client type. |
| CATALOG_ID | bigint(20) | NO | Represents the ID of a catalog under a tenant. |
| URI | varchar(4096) | NO | Indicates the IP address of the server to which the client is connected. |
| TOTAL_CLIENTS | bigint(20) | NO | Indicates the total number of clients created for the corresponding catalog under the current tenant. |
| IN_USE_CLIENTS | bigint(20) | NO | Indicates the number of clients currently using the corresponding catalog under the current tenant. |
| IDLE_CLIENTS | bigint(20) | NO | Indicates the number of clients whose corresponding catalog under the current tenant is not in use (idle). |

## Sample query

Query the usage of HMS Catalog clients for all tenants under the sys tenant.

obclient> SELECT * FROM oceanbase.V$OB_HMS_CLIENT_POOL_STAT;
