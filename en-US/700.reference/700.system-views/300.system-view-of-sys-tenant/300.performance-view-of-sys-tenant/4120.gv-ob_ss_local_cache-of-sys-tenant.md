# GV$OB_LOCAL_CACHE

## Overview

This API is used to query the metrics of various cache data in the local cache of each tenant on each OBServer node.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ----------------- | ----------------------- | ---------------- | --------------------------------- |
| SVR_IP | varchar(46) | NO | IP Address of OBServer Node |
| SVR_PORT | bigint(20) | NO | Port number of the OBServer node |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| CACHE_NAME | varchar(128) | NO | The names of the caches for certain types of data in the local cache, mainly including the following categories:<ul><li>`ss_local_cache_shared_macro`: Shared Macro Block Cache, indicating the cache metrics for shared macro blocks in the local cache.</li> <li>`ss_local_cache_private_macro`: Private Macro Block Cache, which indicates the cache metrics of private macro blocks in the local cache. </li> <li>`ss_mem_macro_cache`: Memory Macroblock Cache, indicating the hit rate, miss rate, and memory usage of macroblocks in the memory cache layer.</li> <li>`ss_macro_block_kvcache`: Macroblock KVCache, indicating the overall metrics of macroblocks in the KVCache layer, including hit rate, miss rate, and memory usage.<main id="notice" type='explain'><h4>Note</h4><p>This metric is available starting with V4.6.2.1.</p></main></li> <li>`ss_local_cache`: Total number of items in the local cache, representing the overall metric for the local cache. The statistical scope includes both in-memory macroblock cache and disk macroblock cache.</li></ul> |
| PRIORITY | bigint(20) | NO | Cache priority. A larger value indicates a higher priority. This field is currently unused, and the default value is `0` |
| HIT_RATIO | decimal(38,3) | NO | Cache Hit Rate |
| TOTAL_HIT_CNT | bigint(20) | NO | Total Cache Hits |
| TOTAL_MISS_CNT | bigint(20) | NO | Total Number of Cache Misses |
| HOLD_SIZE | bigint(20) | NO | Total size of objects stored in the cache, in bytes |
| ALLOC_DISK_SIZE | bigint(20) | NO | Allocated Disk Space, in Bytes |
| USED_DISK_SIZE | bigint(20) | NO | Used disk space, in bytes |
| USED_MEM_SIZE | bigint(20) | NO | Memory space used, in bytes |
