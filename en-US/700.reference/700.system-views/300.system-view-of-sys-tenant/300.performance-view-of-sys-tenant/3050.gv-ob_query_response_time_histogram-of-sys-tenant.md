# GV$OB_QUERY_RESPONSE_TIME_HISTOGRAM

## Overview

The `GV$OB_QUERY_RESPONSE_TIME_HISTOGRAM` view is used to collect histogram statistics on query execution times for all nodes in all tenants.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| ------------ | -------- | ------------------ | -------- |
| SVR_IP | varchar(46) | NO | Node IP |
| SVR_PORT | bigint(20) | NO | Node Port Number |
| TENANT_ID | bigint(20) | NO | tenant |
| SQL_TYPE | varchar(128) | NO | Statement types of QUERY:<ul><li>SELECT</li><li>INSERT</li><li>UPDATE</li><li>DELETE</li><li>REPLACE</li><li>COMMIT</li><li>OTHER</li><li>INNER SQL</li><li>TABLEAPI SELECT</li><li>TABLEAPI INSERT</li><li>TABLEAPI DELETE</li><li>TABLEAPI UPDATE</li><li>TABLEAPI REPLACE</li><li>TABLEAPI QUERY AND MUTATE</li><li>TABLEAPI OTHER</li><li>HBASE SCAN</li><li>HBASE PUT</li><li>HBASE DELETE</li><li>HBASE APPEND</li><li>HBASE INCREMENT</li><li>HBASE CHECK AND PUT</li><li>HBASE CHECK AND DELETE</li><li>HBASE HYBRID BATCH</li></ul> |
| RESPONSE_TIME | decimal(24,6) | NO | Response time interval, in seconds |
| COUNT | bigint(20) | NO | Count of Records within the Range |
| TOTAL | decimal(24,6) | NO | The total duration of the corresponding interval, in seconds. |

## Sample query

Query the histogram information of query execution time for all nodes in all tenants.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_QUERY_RESPONSE_TIME_HISTOGRAM LIMIT 2\G
```
