# V$OB_HNSW_INDEX_SEGMENT_INFO

## Overview

This view displays the basic information and real-time status of each data segment in a single partition of HNSW series index tables for all tenants on the current OBServer node.

## Columns

| Field Name | Data type | Whether can be NULL | Description | Information Type |
| ------------------------------ | -------------- | ---------------- | ------------------------------------------------------------ | ------------ |
| SVR_IP | varchar(46) | NO | Node address of the replica | Basic Information |
| SVR_PORT | bigint(20) | NO | RPC_PORT of the replica node | Basic Information |
| TENANT_ID | bigint(20) | NO | Tenant ID<ul><li>1: System tenant ID</li> <li>Other values: User tenant or Meta tenant ID</li></ul> | Basic Information |
| DATA_TABLE_ID | bigint(20) | NO | Data Table ID | Basic Information |
| DATA_TABLET_ID | bigint(20) | NO | Partition ID | Basic Information |
| VBITMAP_TABLET_ID | bigint(20) | NO | The storage auxiliary table (index_id) corresponds to the partition ID. | Basic Information |
| INC_INDEX_TABLET_ID | bigint(20) | NO | The partition ID of the delta_buffer table that stores incremental data. | Basic Information |
| SNAPSHOT_INDEX_TABLET_ID | bigint(20) | NO | Partition ID of the index_snapshot_data table that stores data snapshots. | Basic Information |
| BLOCK_COUNT | bigint(20) | NO | The number of data blocks contained in the snapshot segment in the index_snapshot_data table. | Basic Information |
| SEGMENT_TYPE | varchar(20) | NO | Segment type. Valid values:<ul><li>INVALID: The default value or an uninitialized segment.</li> <li>IN_MEMORY: An unreduced segment that resides only in memory and has not been flushed to disk.</li> <li>PERSISTED_INCR: A reduced segment that has been flushed to disk.</li> <li>MERGED_INCR: A major compaction incremental segment.</li> <li>PERSISTED_BASE: A persistent baseline segment.</li></ul> | Basic Information |
| INDEX_TYPE | varchar(20) | NO | Vector index types:<ul><li>HNSW</li> <li>HNSW_SQ</li> <li>HNSW_BQ</li> <li>HGRAPH</li></ul> | Basic Information |
| MEM_USED | bigint(20) | NO | The memory size occupied by the current segment (in bytes). | Basic Information |
| MIN_VID | bigint(20) | NO | The smallest vector ID (vid) contained in the segment. | Basic Information |
| MAX_VID | bigint(20) | NO | The maximum vector ID (vid) contained in the segment. | Basic Information |
| VECTOR_CNT | bigint(20) | NO | The number of vectors (data) in a segment. | Basic Information |
| REF_CNT | bigint(20) | NO | The reference count of a segment, which typically indicates the number of times it is referenced by indexes or queries. | Basic Information |
| SEGMENT_STATE | varchar(20) | NO | Status of the current segment:<ul><li>DEFAULT: Not initialized or in the default state.</li> <li>ACTIVE: An active segment that is being written to.</li> <li>FROZEN: The writing has stopped and the segment has entered the frozen state.</li> <li>FLUSHING: Being persisted to disk.</li> <li>PERSISTED: Persistence completed and available for queries.</li></ul> | Basic Information |
| PERSISTENCE_TIMESTAMP | timestamp | NO | Timestamp when segment persistence is completed (obtained by converting the segment's SCN). | Basic Information |
| SEGMENT_PARAMS | varchar(256) | NO | The vector index parameters actually used by the current segment. Each parameter is represented as `KEY=VALUE` The format is as follows: multiple parameters are separated by commas (,), for example, `m=32`, `ef_construction=300`. | Basic Information |

## Sample query

Query the real-time status of HNSW vector indexes for all tenants on the current OBServer node in the SYS tenant.

```sql
SELECT * FROM oceanbase.V$OB_HNSW_INDEX_SEGMENT_INFO ORDER BY PERSISTENCE_TIME DESC\G;
```

After modifying HNSW series index parameters using `DBMS_VECTOR.ALTER_INDEX_PARAMS`, you can check the `SEGMENT_PARAMS` column to understand the actual parameters used by each segment. In the following example, `500001` is the data table ID; please replace it with the actual value you need to query.

```sql
SELECT SVR_IP, SVR_PORT, DATA_TABLE_ID, DATA_TABLET_ID,
       SEGMENT_TYPE, SEGMENT_STATE, SEGMENT_PARAMS
FROM oceanbase.V$OB_HNSW_INDEX_SEGMENT_INFO
WHERE DATA_TABLE_ID = 500001
ORDER BY DATA_TABLET_ID DESC\G;
```
