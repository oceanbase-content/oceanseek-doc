# V$OB_PARAMETERS

## Overview

The `V$OB_PARAMETERS` view displays the parameter information on the current OBServer node, including hidden parameters that start with an underscore (_).

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ------------ | ---------------- | ------------ | --------------------------------------------------------------------------------------------------- |
| SVR_IP | varchar(46) | NO | Server IP Address |
| SVR_PORT | bigint(20) | NO | Server Port Number |
| ZONE | varchar(128) | NO | Zone Name |
| SCOPE | varchar(64) | NO | <ul><li>`CLUSTER`: Cluster-level parameters</li><li>`TENANT`: Tenant-level parameters</li></ul> |
| TENANT_ID | bigint(20) | YES | Tenant ID: <ul><li>`NULL` Not belonging to any tenant.  </li><li>Valid value: tenant ID.  </li></ul> |
| NAME | varchar(128) | NO | Parameter name |
| DATA_TYPE | varchar(128) | YES | Parameter value type |
| VALUE | varchar(65536) | NO | Parameter Value |
| INFO | varchar(4096) | NO | Parameter Description |
| SECTION | varchar(128) | NO | Module to Which the Parameter Belongs |
| EDIT_LEVEL | varchar(128) | NO | The following table describes the effective time of parameter modifications. <ul><li>`READONLY`: read-only, cannot be modified. </li><li>`STATIC_EFFECTIVE`: Restart is required for the changes to take effect. </li><li>`DYNAMIC_EFFECTIVE`: Modified settings take effect dynamically.</li></ul> |
| DEFAULT_VALUE | varchar(65536) | NO | Default value of the parameter |
| ISDEFAULT | varchar(3) | NO | Whether the current value is the default value:<ul><li>NO: The current value is not the default value.</li><li>YES: The current value is the default value.</li></ul> |

The possible values of the `DATA_TYPE` field in the view are as follows:

| Field value | Description | Example (NAME=VALUE) |
| -------- | ------ | ------------------ |
| BOOL | Boolean | enable_ddl=True |
| INT | Integer types | log_disk_percentage=1 |
| DOUBLE | Floating-point number types | server_cpu_quota_min=1.0 |
| STRING | String | leak_mod_to_check='NONE' |
| STR_LIST | A list of strings separated by semicolons. | config_additional_dir='etc2;etc3' |
| TIME | Time period | merger_check_interval='10m' |
| MOMENT | Point in Time | major_freeze_duty_time='02:00' |
| CAPACITY | Capacity, for example, 3 MB or 5 GB | log_disk_size='0M' |
| VERSION | Version | compatible='4.3.0.0' |
| MODE | Specify to enable/disable the corresponding OBKV feature. | _obkv_feature_mode = 'ttl=off, rerouting=on' |

## Sample query

Query the information related to the `large_query_threshold` parameter on this OBServer node.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_PARAMETERS WHERE NAME LIKE '%large_query_threshold%'\G
```
