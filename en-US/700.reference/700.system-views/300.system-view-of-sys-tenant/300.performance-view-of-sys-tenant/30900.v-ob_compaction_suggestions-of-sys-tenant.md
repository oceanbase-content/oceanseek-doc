# V$OB_COMPACTION_SUGGESTIONS

## Overview

Displays the recommended information for compaction on the current node.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ------------- | --------------- | ------------ | -------- |
| SVR_IP | varchar(46) | NO | Server IP Address |
| SVR_PORT | bigint(20) | NO | Server Port Number |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| TYPE | varchar(64) | NO | Type of compaction: <ul><li>`MDS_TABLE_MERGE`: Persist the system's metadata to disk in SSTable format.</li> <li>`MAJOR_MERGE`: Tenant-level major compaction</li> <li>`MEDIUM_MERGE`: Partition-level major compaction</li> <li>`MINI_MERGE`: Performs a minor compaction, converting the MemTable into a Mini SSTable.</li> <li>`MINOR_MERGE`: Minor compaction, where multiple Mini SSTables are merged into a new Mini SSTable, or multiple Mini SSTables and one Minor SSTable are merged into a new Minor SSTable. </li> <li>`META_MAJOR_MERGE`: A special type of compaction that synthesizes data from a specified point in time into a Meta Major SSTable. Its data format is the same as that of a Major SSTable, excluding multi-version data and uncommitted transaction data.</li></ul> |
| LS_ID | bigint(20) | NO | Log Stream ID |
| TABLET_ID | bigint(20) | NO | Data Shard ID |
| START_TIME | timestamp(6) | NO | Start Time |
| FINISH_TIME | timestamp(6) | NO | End Time |
| SUGGESTION  | varchar(1024) | NO         | Suggestion information.  |
