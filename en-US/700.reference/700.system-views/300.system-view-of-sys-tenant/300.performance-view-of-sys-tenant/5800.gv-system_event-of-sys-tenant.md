# GV$SYSTEM_EVENT

## Overview

Displays the wait events of each tenant across all OBServer nodes in the cluster, and provides statistics such as the number of occurrences, total wait time, and timeout count for each type of wait event.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| CON_ID | bigint(20) | NO | Tenant ID |
| SVR_IP | varchar(46) | NO | IP Address of the Server Where Information is Located |
| SVR_PORT | bigint(20) | NO | Port number of the server where the information is located |
| EVENT_ID | bigint(20) | NO | ID of the event to wait for |
| EVENT | varchar(64) | NO | Description of the Waiting Event |
| WAIT_CLASS_ID | bigint(20) | NO | Class ID of the Waiting Event |
| WAIT_CLASS# | bigint(20) | NO | Index of the class to which the event belongs |
| WAIT_CLASS | varchar(64) | NO | Class of the waiting event |
| TOTAL_WAITS | bigint(20) | NO | Total Wait Count for This Event |
| TOTAL_TIMEOUTS | bigint(20) | NO | Total Number of Timeout Events for This Wait Event |
| TIME_WAITED | double | NO | Total wait time for this event, in 10 milliseconds. |
| AVERAGE_WAIT | double | NO | The average wait time for this event, in 10 milliseconds. |
| TIME_WAITED_MICRO | bigint(20) | NO | Total wait time for this event, in microseconds. |

## Sample query

In the sys tenant, view all wait events for all tenants across all nodes, displaying the first 10 records.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$SYSTEM_EVENT LIMIT 10;
```
