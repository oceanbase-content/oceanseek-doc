# V$OB_PLAN_CACHE_PLAN_STAT

## Overview

The `V$OB_PLAN_CACHE_PLAN_STAT` view displays the status of each cached object in the plan cache for all tenants on the current OBServer node.

  <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>This view caches not only SQL plan objects but also PL objects (such as anonymous blocks, PL packages, and PL functions). Some fields are valid only for specific objects.</p>
  </main>

## Columns

| SVR_PORT | bigint(20) | NO | Server Port Number |
| PLAN_ID | bigint(20) | NO | ID of the cached object |
| SQL_ID | varchar(32) | NO | SQL ID corresponding to the cached object. This field is NULL for PL objects. |
| TYPE | bigint(20) | NO | For SQL plan caching, this field indicates the plan type:  <ul><li> 1: Local Plan  </li><li> 2: Remote Plan </li><li>3: Distribute Plan  </li></ul>For PL object caching, this field indicates the PL object type:<ul><li> 1: Procedure    </li><li> 2: Function </li><li>3: Package  </li><li> 4: Anonymous Block   </li></ul> |
| IS_BIND_SENSITIVE | bigint(20) | NO | Whether to enable ACS for this plan |

| DB_ID | bigint(20) unsigned | NO | Database ID |

| QUERY_SQL | longtext | NO | For SQL plans, the field contains the original SQL statement queried when the plan was first loaded. For anonymous blocks, this field contains the parameterized anonymous block statement. |

| PARAM_INFOS | longtext | NO | Represents parameterized information. |

| SLOWEST_EXE_TIME | timestamp(6) | NO | Slowest Execution Timestamp |

| SLOW_COUNT | bigint(20) | NO | Number of Times the Current SQL Plan Became a Slow Query |

| OUTLINE_VERSION | bigint(20) | NO | Outline Version |
| OUTLINE_ID | bigint(20) | NO | The ID of the outline. If the value is -1, the plan was not generated by binding an outline. |
| OUTLINE_DATA | longtext | NO | Outline information of the plan |

| EVOLUTION | tinyint(4) | NO | Indicates whether the execution plan is evolving. |
| EVO_EXECUTIONS | bigint(20) | NO | Evolution Count |

| OBJECT_TYPE | longtext | NO | Type of the cached object:<ul><li>SQL_PLAN</li><li> PROCEDURE   </li><li>FUNCTION</li><li> PACKAGE   </li><li> ANONYMOUS </li></ul> |
| HINTS_INFO | longtext | NO | Hint information of SQL plan |
| HINTS_ALL_WORKED | tinyint(4) | NO | Whether all hints in the SQL plan have taken effect |
| PL_SCHEMA_ID | bigint(20) unsigned | NO | For PL objects other than anonymous blocks, this field is the schema ID of the cached object. For anonymous blocks, this field is the same as ps_stmt_id. For SQL plans, this field is meaningless. |
| IS_BATCHED_MULTI_STMT | tinyint(4) | NO | Indicates whether the plan is optimized for batched multistatement execution. |
| RULE_NAME | varchar(256) | NO | Represents the rule name. |

| ADAPTIVE_FEEDBACK_TIMES | bigint(20) | NO | Represents the number of consecutive positive or negative feedbacks. |
| FIRST_GET_PLAN_TIME | bigint(20) | NO | The time taken for the query to be parsed. |
| FIRST_EXE_USEC | bigint(20) | NO | The time when the query was executed for the first time. |
| FORMAT_SQL_ID | varchar(32) | NO | Indicates the format SQL ID of the current plan. |
| CACHE_NODE_ID | bigint(20) | NO | The ID of the cache node to which the object belongs. |
| PCV_ID | bigint(20) | NO | Indicates the ID of the plan cache value node to which the object belongs. |
| PLAN_SET_ID | bigint(20) | NO | The ID of the plan set node to which the object belongs. |
| CREATE_REASON | varchar(4096) | NO | Indicates the reason for joining the current plan. |
