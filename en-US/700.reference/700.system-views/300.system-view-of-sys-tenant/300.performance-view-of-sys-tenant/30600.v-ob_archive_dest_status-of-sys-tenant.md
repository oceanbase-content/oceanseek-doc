# V$OB_ARCHIVE_DEST_STATUS

## Overview

Displays the status of each log archive destination at the tenant level.

## Columns

| field | Type | Whether can be NULL | Description |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| DEST_ID | bigint(20) | NO | Archive Target ID |
| PATH | varchar(4096) | NO | Archive Path |
| STATUS | varchar(64) | NO | Archive Status |
| CHECKPOINT_SCN | bigint(20) unsigned | NO | Latest Archived Log Offset |
| SYNCHRONIZED | varchar(32) | NO | Whether archiving is synchronized with tenant logs: <ul><li>`YES`: Archiving is synchronized with tenant logs.  </li><li>`NO`: Log files are not synchronized with tenant logs. </li></ul> |
| COMMENT | varchar(262144) | NO | Error message |

## Sample query

The system tenant queries the status of each log archive destination in the user tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_ARCHIVE_DEST_STATUS;
```

The query result is as follows:

```shell
+-----------+---------+-------------------------------------+--------+---------------------+--------------+---------+
| TENANT_ID | DEST_ID | PATH                                | STATUS | CHECKPOINT_SCN      | SYNCHRONIZED | COMMENT |
+-----------+---------+-------------------------------------+--------+---------------------+--------------+---------+
|      1002 |    1001 | file:///home/admin/oceanbase/arglog | DOING  | 1736321349494697000 | NO           |         |
+-----------+---------+-------------------------------------+--------+---------------------+--------------+---------+
1 row in set
```
