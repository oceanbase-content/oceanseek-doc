# V$SESSION_WAIT

## Overview

The `V$SESSION_WAIT` view displays the details of all current session waits on the current node. By convention, each wait event is associated with three parameters, each recording a corresponding value.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| ---- | ---- | ---- | ---- |
| SID | bigint(20) | NO | <ul><li>In direct connection mode:<br>This field indicates the server session ID.</li> <li>In ODP mode:</li><ul><li>When the ODP parameter <code>client_session_id_version = 2</code> is set, this field indicates the client session ID. </li> <li>When <code>client_session_id_version = 1</code> is set, this field indicates the server session ID.</li></ul></ul> |
| CON_ID | bigint(20) | NO | Tenant ID |
| SVR_IP | varchar(46) | NO | Server IP |
| SVR_PORT | bigint(20) | NO | Server Port |
| EVENT | varchar(64) | NO | Event Name |
| P1TEXT | varchar(64) | NO | Description of the first parameter for waiting for an event |
| P1 | bigint(20) unsigned | NO | Value of the first parameter for the wait event |
| P2TEXT | varchar(64) | NO | Description of the second parameter for waiting on an event |
| P2 | bigint(20) unsigned | NO | Value of the Second Parameter for Waiting for an Event |
| P3TEXT | varchar(64) | NO | Description of the third parameter for waiting on an event |
| P3 | bigint(20) unsigned | NO | Value of the third parameter for the wait event |
| WAIT_CLASS_ID | bigint(20) | NO | Category ID of the waiting event |
| WAIT_CLASS# | bigint(20) | NO | Category number of the waiting event |
| WAIT_CLASS | varchar(64) | NO | Category name of the event to be waited for |
| STATE | varchar(19) | NO | The current status of the event wait, which includes four states:<ul><li>Waiting: The session is waiting for this event.</li><li>Waited unknown time: Timed_statistics is set to false, so the time information cannot be obtained. This indicates a wait occurred, but the duration was very short.</li><li>Wait short time: A wait occurred, but because it was extremely brief, not exceeding one time unit, it was not recorded.</li><li>Waited known time: If the session waits and then obtains the required resource, it will transition from the waiting state to this state.</li></ul> |
| WAIT_TIME_MICRO | bigint(20) | NO | Wait time, in microseconds. If currently waiting, indicates the duration already spent waiting; if not currently waiting, indicates the total wait time from the last wait. |
| TIME_REMAINING_MICRO | bigint(20) | NO | <ul><li>> 0: The last wait time (in microseconds). The session is not in a waiting state. </li><li>0: The session is waiting for the current event. </li><li>-1: The last wait time is less than 1 statistical unit. The session is not in a waiting state. </li><li>-2: The time statistics status is not available. The session is not in a waiting state. </li></ul> |
| TIME_SINCE_LAST_WAIT_MICRO | bigint(20) | NO | Time elapsed since the last wait ended, in microseconds. If currently waiting, the value is 0. |

## Sample query

Query the details of all events currently being waited on by sessions on the current node.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$SESSION_WAIT LIMIT 1\G
```
