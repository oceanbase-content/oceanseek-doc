# V$OB_OPT_STAT_GATHER_MONITOR

## Overview

Displays the real-time status of statistical information collection tasks for all tenants on the current OBServer node.

## Columns

| **Column** | **Type** | **Is NULL** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | Tenant ID of the collection task |
| SVR_IP | varchar(46) | NO | Node address where the collection task is located |
| SVR_PORT | bigint(20) | NO | Port of the node where the collection task is located |
| SESSION_ID | bigint(20) | NO | The session ID of the task collector. <ul><li>In direct connection mode:<br>This field indicates the server session ID.</li> <li>In ODP mode:</li><ul><li>When the ODP parameter <code>client_session_id_version = 2</code> is set, this field indicates the client session ID. </li> <li>When <code>client_session_id_version = 1</code> is set, this field indicates the server session ID.</li></ul></ul> |
| TRACE_ID | varchar(64) | NO | The trace ID of the collection task. |
| TASK_ID | varchar(36) | NO | Collection Task ID (UUID generated, globally unique) |
| TYPE | varchar(16) | NO | Collection Task Type |
| TASK_START_TIME | datetime(6) | NO | Collection Task Start Time |
| TASK_DURATION_TIME | bigint(20) | NO | Duration of the collection task, in microseconds. |
| TASK_TABLE_COUNT | bigint(20) | NO | Number of tables to be collected in the task |
| COMPLETED_TABLE_COUNT | bigint(20) | NO | Number of Tables for Which Collection Tasks Are Completed |
| RUNNING_TABLE_OWNER | varchar(128) | NO | Username of the user who is collecting data from the table |
| RUNNING_TABLE_NAME | varchar(256) | NO | The name of the table being collected by the collection task |
| RUNNING_TABLE_DURATION_TIME | bigint(20) | NO | Duration for which the collection task is collecting data from the table |
| RUNNING_TABLE_PROGRESS | varchar(256) | NO | Collection Progress of the Collection Task |

## Sample query

In the sys tenant, view the real-time status of the statistical information collection task for the tenant with ID 1006 on the current node.

```shell
obclient> SELECT * FROM oceanbase.V$OB_OPT_STAT_GATHER_MONITOR WHERE TENANT_ID = 1006;
```
