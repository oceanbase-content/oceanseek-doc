# V$SQL_WORKAREA_HISTOGRAM

## Overview

Displays statistics from all previous workareas, such as the number of times operations were processed entirely in-memory within the 1 MB to 2 MB range and the number of one-pass executions.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| ------------------------ | ------------ | ---------------- | ------------------------------------------ |
| LOW_OPTIMAL_SIZE | bigint(20) | NO | Minimum Memory for Workarea in Optimal Mode |
| HIGH_OPTIMAL_SIZE | bigint(20) | NO | Maximum Memory for Workarea in Optimal Mode |
| OPTIMAL_EXECUTIONS | bigint(20) | NO | Number of executions in the optimal mode for workarea within the lowest and highest ranges |
| ONEPASS_EXECUTIONS | bigint(20) | NO | Number of Times Workarea Executes in One-Pass Mode Within the Minimum and Maximum Ranges |
| MULTIPASSES_EXECUTIONS | bigint(20) | NO | Number of Executions in Multi-Pass Mode for Workarea Within the Minimum and Maximum Ranges |
| TOTAL_EXECUTIONS | bigint(20) | NO | Total Number of Workarea Executions |
| CON_ID | bigint(20) | NO | Tenant ID |
| SVR_IP | varchar(46) | NO | Server IP Address |
| SVR_PORT | bigint(20) | NO | Server Port Number |

## Sample query

The system tenant queries the statistics of all workareas executed by the tenant with ID `1002` on the current node and displays the first 10 records.

```shell
obclient[oceanbase]> SELECT * FROM oceanbase.V$SQL_WORKAREA_HISTOGRAM WHERE CON_ID=1002 LIMIT 10;
```
