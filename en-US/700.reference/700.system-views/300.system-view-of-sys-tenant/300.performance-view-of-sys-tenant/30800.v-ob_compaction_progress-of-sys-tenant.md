# V$OB_COMPACTION_PROGRESS

## Overview

Displays the major compaction progress information of all tenants on the current node.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ------------------------- | -------------- | ------------ | -------- |
| SVR_IP | varchar(46) | NO | Server IP |
| SVR_PORT | bigint(20) | NO | Server Port Number |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| TYPE | varchar(64) | NO | Types of compaction. <ul><li> MINI: Minor compaction or minor compaction, where the MemTable is converted into an SSTable through minor compaction. </li><li>MAJOR: Major compaction. </li><li>MINOR: L1 compaction, where multiple Mini SSTables are merged into one. </li></ul> |
| ZONE | varchar(128) | NO | Zone Information |
| COMPACTION_SCN | bigint(20) unsigned | NO | Major compaction version information |
| STATUS | varchar(10) | NO | Status Information |
| TOTAL_TABLET_CNT | bigint(20) | NO | Total Tablets |
| UNFINISHED_TABLET_CNT | bigint(20) | NO | Number of Tablets Not Completed |
| DATA_SIZE | bigint(20) | NO | Total data volume requiring compaction, in bytes |
| UNFINISHED_DATA_SIZE | bigint(20) | NO | Data volume of unfinished major compaction, in bytes |
| COMPRESSION_RATIO | bigint(20) | NO | Compression Ratio of New Data (Records only the compression ratio of newly written data after the last major version point.) |
| START_TIME | timestamp(6) | NO | Start Time |
| ESTIMATED_FINISH_TIME | timestamp(6) | NO | Estimated completion time (if |
|  |  | NO | If compaction_progress is 100, the end time is displayed.) |
| COMMENTS | varchar(1024) | NO | Comment information. During a major compaction, it records the latest compaction events. After the major compaction is complete, it records the overall duration. |

## Sample query

The system tenant queries the major compaction progress information of all tenants on the current node and displays the first 5 records.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_COMPACTION_PROGRESS LIMIT 5;
```
