# V$ACTIVE_SESSION_HISTORY

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This view has been renamed to <a href="30500.v-ob_active_session_history-of-sys-tenant.md">V$OB_ACTIVE_SESSION_HISTORY</a></p>
</main>

## Overview

The `V$ACTIVE_SESSION_HISTORY` view displays the history of active sessions on the current OBServer node for all tenants.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | IP Address of the Server Where the Sample Belongs |
| SVR_PORT | bigint(20) | NO | Port number of the server to which the sample belongs |
| SAMPLE_ID | bigint(20) | NO | Unique ID of the sample host |
| SAMPLE_TIME | timestamp(6) | NO | Sampling Time |
| CON_ID | bigint(20) | NO | Tenant ID |
| USER_ID | bigint(20) | NO | User ID of the sampled session |
| SESSION_ID | bigint(20) | NO | ID of the sampled session. <ul><li>In direct connection mode:<br>This field indicates the server session ID.</li> <li>In ODP mode:</li><ul><li>When the ODP parameter <code>client_session_id_version = 2</code> is set, this field indicates the client session ID. </li> <li>When <code>client_session_id_version = 1</code> is set, this field indicates the server session ID.</li></ul></ul> |
| SESSION_TYPE | varchar(10) | NO | Session type: <ul><li>FOREGROUND: foreground session, that is, a user session.</li><li>BACKGROUND: background session.</li></ul> |
| SESSION_STATE | varchar(7) | NO | Session status:<ul><li>ON CPU: The session is not waiting and is currently executing SQL logic.</li><li>WAITING: The session is waiting. For details, see the `EVENT` field.</li></ul> |
| SQL_ID | varchar(32) | NO | SQL ID |
| PLAN_ID | bigint(20) | NO | The plan ID of the sampled SQL statement in the PLAN CACHE, used to associate the sampling point with the plan. |
| TRACE_ID | varchar(64) | NO | Trace ID of the operator |
| EVENT | varchar(64) | NO | Description of the Waiting Event |
| EVENT_NO | bigint(20) | NO | Internal event ID, used to associate queries with other tables |
| EVENT_ID | bigint(20) | NO | Indicates the ID of the event currently being waited for. |
| P1TEXT | varchar(64) | NO | The name of parameter 1 for the WAIT FOR event. This name varies depending on the event. |
| P1 | bigint(20) | NO | Value of Parameter 1 for the Wait Event |
| P2TEXT | varchar(64) | NO | The name of parameter 2 for the WAIT FOR event. This name varies depending on the event. |
| P2 | bigint(20) | NO | Value of Parameter 2 for the Wait Event |
| P3TEXT | varchar(64) | NO | The name of parameter 3 for the wait event. This name varies depending on the event. |
| P3 | bigint(20) | NO | Value of Parameter 3 for Waiting for Events |
| WAIT_CLASS | varchar(64) | NO | Type of the event to be waited for |
| WAIT_CLASS_ID | bigint(20) | NO | ID of the event type to wait for, used to associate queries with other tables |
| TIME_WAITED | bigint(20) | NO | Total wait time for this event, in microseconds (μs). |
| SQL_PLAN_LINE_ID | bigint(20) | NO | The number of the SQL operator in the SQL plan during sampling. |
| GROUP_ID | bigint(20) | NO | The ID of the resource group to which the instance belongs. |
| PLAN_HASH | bigint(20) unsigned | NO | The current execution SQL command's plan hash. |
| THREAD_ID | bigint(20) | NO | Thread ID of the current active session. |
| STMT_TYPE | bigint(20) | NO | SQL type of the current active session. |
| TIME_MODEL | bigint(20) | NO | Time model information is a collection of data from all IN_XXX fields, such as IN_PARSE and IN_PL_PARSE. |
| IN_PARSE | varchar(1) | NO | Whether the session is performing SQL parse during sampling |
| IN_PL_PARSE | varchar(1) | NO | Whether SQL PL parse is in progress during session sampling |
| IN_PLAN_CACHE | varchar(1) | NO | Whether the session is performing plan cache matching during sampling |
| IN_SQL_OPTIMIZE | varchar(1) | NO | Whether the session is performing SQL parsing optimization during sampling |
| IN_SQL_EXECUTION | varchar(1) | NO | Whether the session is performing SQL execution during sampling |
| IN_PX_EXECUTION | varchar(1) | NO | Whether the session is performing SQL parallel execution during sampling. When a session is in this state, it must also be in the IN_SQL_EXECUTION state. |
| IN_SEQUENCE_LOAD | varchar(1) | NO | Whether the session is fetching values from an auto-increment column or a sequence during sampling. |
| IN_COMMITTING | varchar(1) | NO | Whether the current sampling point is in the transaction commit phase |
| IN_STORAGE_READ | varchar(1) | NO | Whether the current sampling point is in the storage read phase |
| IN_STORAGE_WRITE | varchar(1) | NO | Whether the current sampling point is in the storage write phase |
| IN_REMOTE_DAS_EXECUTION | varchar(1) | NO | Whether the current sampling point is in the DAS remote execution phase |
| IN_FILTER_ROWS | varchar(1) | NO | Indicates whether the current sampling point is in the store pushdown execution phase. |
| IN_RPC_ENCODE | varchar(1) | NO | The serialization operation currently in progress for the SQL statement |
| IN_RPC_DECODE | varchar(1) | NO | Deserialization Operation in Progress for the Current SQL |
| IN_CONNECTION_MGR | varchar(1) | NO | The current SQL statement is performing a link establishment operation. |
| PROGRAM | varchar(64) | NO | Program name being executed at the current sampling point: <ul><li>Background thread: refers to the thread name, for example, `observer`, `WrTimer`</li><li>Frontend threads: <ul><li>For regular requests, it is `user@client_ip (thread_name)`  </li><li>`inner_sql` Remote execution is `INNER SQL REMOTE EXEC (thread_name)`</li><li>For DAS remote execution, set it to `DAS REMOTE EXEC (thread_name)` </li></ul> </li></ul> |
| MODULE | varchar(64) | NO | The MODULE value recorded during session sampling. `DBMS_APPLICATION_INFO.SET_MODULE` Package settings. |
| ACTION | varchar(64) | NO | The ACTION value recorded during sampling for a session, through `DBMS_APPLICATION_INFO.SET_ACTION` Package settings. |
| CLIENT_ID | varchar(64) | NO | The CLIENT_ID value recorded during session sampling. It is obtained through the `DBMS_SESSION.set_identifier` Package settings. |
| BACKTRACE | varchar(512) | NO | Auxiliary debugging field, used to record the code call stack at the time the event occurred. The value of this field is always NULL. |
| TM_DELTA_TIME | bigint(20) | NO | Calculate the time interval of the time model, in microseconds. |
| TM_DELTA_CPU_TIME | bigint(20) | NO | Past `TM_DELTA_TIME` The amount of time spent on the CPU during the period |
| TM_DELTA_DB_TIME | bigint(20) | NO | Past `TM_DELTA_TIME` The amount of time spent on database calls within the time period. |
| TOP_LEVEL_SQL_ID | CHAR(32) | NO | Top-level SQL ID |
| IN_PLSQL_COMPILATION | varchar(1) | NO | Current PL Compilation Status: Y/N |
| IN_PLSQL_EXECUTION | varchar(1) | NO | Current PL Execution Status: Y/N |
| PLSQL_ENTRY_OBJECT_ID | bigint(20) | NO | OBJECT ID of the Top-Level PL |
| PLSQL_ENTRY_SUBPROGRAM_ID | bigint(20) | NO | Sub-project ID of the top-level PL |
| PLSQL_ENTRY_SUBPROGRAM_NAME | varchar(32) | NO | Sub project name of the top-level PL |
| PLSQL_OBJECT_ID | bigint(20) | NO | ID of the PL object currently being executed |
| PLSQL_SUBPROGRAM_ID | bigint(20) | NO | ID of the PL subprogram currently being executed |
| PLSQL_SUBPROGRAM_NAME | varchar(32) | NO | Name of the currently executing PL subprogram |
| TX_ID | bigint(20) | NO | Current Transaction ID |
| BLOCKING_SESSION_ID | bigint(20) | NO | If the current session is blocked, displays the session ID that blocked it. This feature currently takes effect only in lock conflict scenarios, showing the session IDs of the holding locks. |
| TABLET_ID | bigint(20) | NO | ID of the tablet being processed by the current SQL statement |
| PROXY_SID | bigint(20) | NO | Proxy Session ID |
| TX_ID | bigint(20) | NO | Current Transaction ID |
| DELTA_READ_IO_REQUESTS | bigint(20) | NO | Number of Reads Between Two Samples |
| DELTA_READ_IO_BYTES | bigint(20) | NO | Cumulative File Size Read Between Two Samples |
| DELTA_WRITE_IO_REQUESTS | bigint(20) | NO | Number of Writes Between Two Samples |
| DELTA_WRITE_IO_BYTES | bigint(20) | NO | Cumulative File Size Written Between Two Samples |
