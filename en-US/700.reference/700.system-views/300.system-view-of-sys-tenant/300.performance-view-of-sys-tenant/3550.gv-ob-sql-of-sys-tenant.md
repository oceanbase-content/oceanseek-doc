# GV$OB_SQL_CCL_STATUS

## Overview

Records the number of SQL statements that hit the throttling rules on all nodes of all tenants at the current moment, helping you observe the impact of the throttling rules set in the system.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --------- | ------- | ------------- | -------- |
| CON_ID | bigint(20) | NO | Tenant ID |
| SVR_IP | varchar(46) | NO | IP Address of OBServer Node |
| SVR_PORT | bigint(20) | NO | Port number of the BServer node |
| CCL_RULE_ID | bigint(20) | NO | Effective Throttling Rule ID |
| FORMAT_SQLID | varchar(32) | NO | Throttling granularity:<ul><li>Rule level: 0 </li><li>Format SQLID level:1</li></ul> |
| CURRENT_CONCURRENCY | bigint(20) | NO | Number of SQL Statements Currently Executing That Hit This Throttling Rule |
| MAX_CONCURRENCY | bigint(20) | NO | The maximum concurrency of this throttling rule. |

## Sample query

```shell
obclient> SELECT * FROM oceanbase.GV$OB_SQL_CCL_STATUS;
```
