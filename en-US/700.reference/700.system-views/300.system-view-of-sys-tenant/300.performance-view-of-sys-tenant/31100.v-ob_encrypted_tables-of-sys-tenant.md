# V$OB_ENCRYPTED_TABLES

## Overview

Displays the encryption status of tables with encryption enabled under the current tenant. The system tenant cannot enable encryption.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| ------------------ | --------------------- | ------------ | ------------------------------------------------------------------------------------ |
| CON_ID | bigint(20) | NO | Tenant ID |
| TABLE_ID | bigint(20) | NO | Table ID |
| TABLE_NAME | varchar(256) | NO | Table name |
| TABLESPACE_ID | bigint(20) | NO | Tablespace ID |
| ENCRYPTIONALG | varchar(30) | NO | Encryption algorithm name: <ul><li>AES-128   </li><li> AES-192   </li><li> AES-256   </li><li> SM4</li></ul> |
| ENCRYPTED | varchar(3) | NO | Encryption completed: <ul><li>YES</li><li>NO</li></ul> |
| ENCRYPTEDKEY | varchar(33) | NO | Encrypted Key Encrypted by Primary Key |
| MASTERKEYID | bigint(20) unsigned | NO | Primary Key Version |
| BLOCKS_ENCRYPTED | decimal(20,0) | NO | Number of Encryption Macroblocks |
| BLOCKS_DECRYPTED | decimal(21,0) | NO | Number of Uncrypted Macroblocks |
| STATUS | varchar(10) | NO | Encryption Status: <ul><li>NORMAL: normal state   </li><li> ENCRYPTING: encrypting   </li><li> DECRYPTING: decrypting</li></ul> |
| CON_ID | bigint(20) | NO | Tenant ID |
