# GV$OB_MERGE_INFO

## Overview

This API is used to query the statistics of completed compactions in an OceanBase AI database cluster.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ------------------- | --------------- | ------------ | ----------------------------------------------------------------------------------------------------- |
| SVR_IP | varchar(46) | NO | Server IP Address |
| SVR_PORT | bigint(20) | NO | Server Port Number |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| LS_ID | bigint(20) | NO | Log Stream ID |
| TABLET_ID | bigint(20) | NO | Data Shard ID |
| ACTION | varchar(64) | NO | Compaction actions:<ul><li>`MDS_TABLE_MERGE`: Persist the system's metadata to disk in SSTable format.</li> <li>`MAJOR_MERGE`: Tenant-level major compaction</li> <li>`MEDIUM_MERGE`: Partition-level compaction</li> <li>`MINI_MERGE`: Performs a minor compaction, converting the MemTable into a Mini SSTable.</li> <li>`MINOR_MERGE`: Minor compaction, where multiple Mini SSTables are merged into a new Mini SSTable, or multiple Mini SSTables and a Minor SSTable are merged into a new Minor SSTable. </li> <li>`META_MAJOR_MERGE`: A special type of compaction that synthesizes data from a specified point in time into a Meta Major SSTable. Its data format is the same as that of a Major SSTable, excluding multi-version data and uncommitted transaction data.</li></ul> |
| COMPACTION_SCN | bigint(20) unsigned | NO | Compaction Version |
| START_TIME | timestamp(6) | NO | Compaction Start Time |
| END_TIME | timestamp(6) | NO | Compaction End Time |
| MACRO_BLOCK_COUNT | bigint(20) | NO | Total Number of Compaction Macroblocks |
| REUSE_PCT | decimal(26,2) | NO | Compaction Macroblock Reuse Rate |
| PARALLEL_DEGREE | bigint(20) | NO | Compaction Parallelism |

## Sample query

The sys tenant queries the statistics on completed minor compactions (`MINI_MERGE`) in the cluster and returns the first five records.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_MERGE_INFO WHERE ACTION='MINI_MERGE' LIMIT 5;
```
