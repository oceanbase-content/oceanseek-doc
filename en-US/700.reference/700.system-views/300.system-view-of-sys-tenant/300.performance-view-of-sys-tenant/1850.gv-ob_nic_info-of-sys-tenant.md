# GV$OB_NIC_INFO

## Overview

The `GV$OB_NIC_INFO` view displays the NIC information on all OBServer nodes of a tenant, primarily the NIC speed.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| ------------ | ------- | ------------------- | -------- |
| SVR_IP | varchar(46) | NO | IP Address of OBSerber |
| SVR_PORT | bigint(20) | NO | RPC Port of OBServer |
| DEVNAME | varchar(128) | NO | NIC Name of the Server Where OBServer resides |
| SPEED_MBPS | bigint(20) | NO | Network interface card speed, in Mbps |

## Sample query

Query the NIC information of all OBServer nodes where a tenant resides.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_NIC_INFO;
```

The query result is as follows:

```shell
+----------------+----------+---------+------------+
| SVR_IP         | SVR_PORT | DEVNAME | SPEED_MBPS |
+----------------+----------+---------+------------+
| xx.xx.xx.xx    |     2882 | eth0    |      10000 |
| xx.xx.xx.xx    |     2884 | bond0   |      10000 |
| xx.xx.xx.xx    |     2886 | bond0   |      10000 |
+----------------+----------+---------+------------+
```
