# GV$OB_SERVER_STORAGE

## Overview

Displays the object storage configuration information of the cluster on all OBServer nodes.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ---------------------- | --------------- | ---------------- | ------------------------------- |
| SVR_IP | varchar(46) | NO | IP Address of OBServer Node |
| SVR_PORT | bigint(20) | NO | Port number of the OBServer node |
| PATH | varchar(1024) | NO | The root path used by object storage. Common types include: `s3://`, `azblob://` etc. |
| ENDPOINT | varchar(1024) | NO | The endpoint of the object storage service. |
| USED_FOR | varchar(256) | NO | The user of the object storage. Currently, only `ALL`, indicating that it is for use by clogs and data. |
| ZONE | varchar(128) | NO | Zone Name |
| STORAGE_ID | bigint(20) | NO | The number of the object storage path. Paths with the same name have the same STORAGE_ID. |
| MAX_IOPS | bigint(20) | NO | Maximum IOPS for Object Storage |
| MAX_BANDWIDTH | bigint(20) | NO | Maximum bandwidth for object storage, in bytes |
| CREATE_TIME | timestamp(6) | NO | Creation Time of Object Storage |
| AUTHORIZATION | varchar(1024) | NO | Object Storage Authorization Information |
| STATE | varchar(256) | NO | Object storage status: <ul><li>`ADDING`: Adding status</li> <li>`ADDED`: Added successfully.</li> <li>`DROPPING`: Deleting</li> <li>`CHANGING`: Rotating AK/SK</li> <li>`CHANGED`: AK/SK rotation completed.</li></ul> |
| STATE_INFO | varchar(1024) | NO | Object Storage Status Information |
| LAST_CHECK_TIMESTAMP | timestamp(6) | NO | Last Check Time |
| EXTENSION | varchar(4096) | NO | Other information about object storage |
