# GV$OB_COMPACTION_PROGRESS

## Overview

Displays the minor compaction progress of all tenant OBServer nodes.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ------------------------- | -------------- | ------------ | -------- |
| SVR_IP | varchar(46) | NO | Server IP Address |
| SVR_PORT | bigint(20) | NO | Server Port Number |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| TYPE | varchar(64) | NO | Type of Compaction: <ul><li>`MDS_TABLE_MERGE`: Persist the system's metadata to disk in SSTable format.</li> <li>`MAJOR_MERGE`: Tenant-level major compaction</li> <li>`MEDIUM_MERGE`: Partition-level compaction</li> <li>`MINI_MERGE`: Performs a minor compaction, converting the MemTable into a Mini SSTable.</li> <li>`MINOR_MERGE`: Minor compaction, where multiple mini-SSTables are merged into a new mini-SSTable, or multiple mini-SSTables and a minor-SSTable are merged into a new minor-SSTable. </li> <li>`META_MAJOR_MERGE`: A special type of compaction that synthesizes data from a specified point in time into a Meta Major SSTable. Its data format is the same as that of a Major SSTable, excluding multi-version data and uncommitted transaction data.</li></ul> |
| ZONE | varchar(128) | NO | Zone Information |
| COMPACTION_SCN | bigint(20) unsigned | NO | Major compaction version information |
| STATUS | varchar(15) | NO | Status Information |
| TOTAL_TABLET_COUNT | bigint(20) | NO | Total Tablets |
| UNFINISHED_TABLET_COUNT | bigint(20) | NO | Number of Tablets Not Completed |
| DATA_SIZE | bigint(20) | NO | Total data volume requiring compaction, in bytes |
| UNFINISHED_DATA_SIZE | bigint(20) | NO | Data volume of unfinished major compaction, in bytes |
| COMPRESSION_RATIO | double | NO | Compression ratio of new data: Records only the compression ratio of newly written data after the last major version. |
| START_TIME | timestamp(6) | NO | Start Time |
| ESTIMATED_FINISH_TIME | timestamp(6) | NO | Estimated completion time: If compaction_progress is 100, the end time is displayed. |
| COMMENTS | varchar(1024) | NO | Comment information. During a major compaction, it records the latest compaction events. After the major compaction is complete, it records the overall duration. |

## Sample query

The system tenant queries the OBServer node-level major compaction progress information of all tenants and displays the first 10 records.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_COMPACTION_PROGRESS LIMIT 10;
```
