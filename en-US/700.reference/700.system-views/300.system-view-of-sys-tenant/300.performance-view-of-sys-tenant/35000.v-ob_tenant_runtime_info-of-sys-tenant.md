# V$OB_TENANT_RUNTIME_INFO

## Overview

Displays information related to thread queues and thread quotas for tenants on the current OBServer node.

## Columns

| **Column** | **Type** | **Is NULL** | **Description** |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | Server IP Address |
| SVR_PORT | bigint(20) | NO | Server Port Number |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| COMPAT_MODE | bigint(20) | NO | Tenant Compatibility Mode |
| UNIT_MIN_CPU | double | NO | Minimum CPU Cores |
| UNIT_MAX_CPU | double | NO | Maximum CPU Cores |
| SLICE | double | NO | Slice Size of Tenant Units |
| REMAIN_SLICE | double | NO | Remaining Slice Size |
| TOKEN_CNT | bigint(20) | NO | The number of tokens allocated by the scheduler. One token is converted into one worker thread. |
| ASS_TOKEN_CNT | bigint(20) | NO | The number of tokens currently confirmed by the tenant (determined based on token_cnt; generally equal to the latter). |
| LQ_TOKENS | bigint(20) | NO | Large Query Tokens |
| USED_LQ_TOKENS | bigint(20) | NO | Number of Workers Currently Holding LQ Tokens |
| STOPPED | bigint(20) | NO | Whether the tenant unit is being deleted |
| IDLE_US | bigint(20) | NO | Total idle time of worker threads in one round (10 seconds). Idle time actually only counts the time spent in the wait queue. |
| RECV_HP_RPC_CNT | bigint(20) | NO | Cumulative Number of High-Priority RPC Requests Received by Tenant |
| RECV_NP_RPC_CNT | bigint(20) | NO | Cumulative Number of RPC Requests at the Normal Level Received by Tenant |
| RECV_LP_RPC_CNT | bigint(20) | NO | Cumulative Number of RPC Requests at Low Level Received by Tenant |
| RECV_MYSQL_CNT | bigint(20) | NO | Cumulative Number of MySQL Requests Received by Tenant |
| RECV_TASK_CNT | bigint(20) | NO | Cumulative Number of Internal Tasks Received by Tenant |
| RECV_LARGE_REQ_CNT | bigint(20) | NO | The cumulative predicted large request count for a tenant only increments and does not reset. It actually increases during retries. |
| RECV_LARGE_QUERIES | bigint(20) | NO | Cumulative Number of Large Queries Received by Tenant |
| ACTIVES | bigint(20) | NO | The number of active worker threads, which is generally equal to the number of workers. The difference between them includes: tenant worker thread cache + large request cache with worker threads. |
| WORKERS | bigint(20) | NO | The number of worker threads held by the tenant. In fact, it is `workers_ list` The size of the file. |
| LQ_WAITING_WORKERS | bigint(20) | NO | Number of Worker Threads Waiting for Large Queries |
| REQ_QUEUE_TOTAL_SIZE | bigint(20) | NO | Total Request Queue Size |
| QUEUE_0 | bigint(20) | NO | Size of Queue 0 |
| QUEUE_1 | bigint(20) | NO | Size of Queue 1 |
| QUEUE_2 | bigint(20) | NO | Size of Queue 2 |
| QUEUE_3 | bigint(20) | NO | Size of Queue 3 |
| QUEUE_4 | bigint(20) | NO | Size of Queue 4 |
| QUEUE_5 | bigint(20) | NO | Queue 5 Size |
| LARGE_QUEUED | bigint(20) | NO | Number of Large Requests in Queue |

The system tenant displays information about the queue and thread quota of tenant threads on the current node.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_TENANT_RUNTIME_INFO;
```
