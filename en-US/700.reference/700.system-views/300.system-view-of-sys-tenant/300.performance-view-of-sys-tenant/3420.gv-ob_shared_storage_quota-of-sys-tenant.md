# GV$OB_SHARED_STORAGE_QUOTA

## Overview

Displays the I/O access resource information on all OBServer nodes.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ------------- | --------------- | ---------------- | ------------------------------------------------------------- |
| SVR_IP | varchar(46) | NO | IP Address of OBServer Node |
| SVR_PORT | bigint(20) | NO | Port number of the OBServer node |
| ENDPOINT | varchar(256) | NO | Endpoint for shared storage. |
| PATH | varchar(1024) | NO | The path of the object storage.</br>The commonly used types are: `local://`, `file://`, `s3://` etc. |
| CLASS_ID | bigint(20) | NO | The ID used for labeling. Its meaning varies depending on the purpose of the object storage bucket:<ul><li>When the bucket is used for clog storage or data storage, this field is meaningless and its value is `0`</li> <li>When the bucket is used for backup and restore, data import, export, or other tasks, this field indicates the tenant ID.</li></ul> |
| TYPE | varchar(32) | NO | Metric types, mainly including the following: <ul><li>`IPS`: Number of instructions per second.</li> <li>`OPS`: The number of operations performed per second.</li> <li>`IOPS`: The number of operations input or output per second.</li> <li>`IBW`: Input bandwidth</li> <li>`OBW`: Output bandwidth</li> <li>`IOBW`: Input or output bandwidth</li> <li>`TAG`: User-defined tag information.</li></ul> |
| REQUIREMENT | bigint(20) | NO | Resources required by the server |
| ASSIGN | bigint(20) | NO | The upper limits of various resources specified by the server throttling algorithm |

## Sample query

In the sys tenant, query the requested and limited quotas for various object storage metrics across all OBServer nodes in scenarios such as clog storage and data storage. For scenarios like backup and recovery, data import, and export, query the requested and limited quotas for various object storage metrics across all tenants on all OBServer nodes.

```shell
obclient> SELECT * FROM oceanbase.GV$OB_SHARED_STORAGE_QUOTA;
```
