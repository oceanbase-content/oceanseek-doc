# GV$SQL_WORKAREA_HISTOGRAM

## Overview

Displays the statistics of all previous workareas executed on the current node of the tenant, including the number of times processed entirely in-memory within the 1 MB to 2 MB range and the number of one-pass executions.

## **Column description**

| **Field** | **Type** | **Nullable** | **Description** |
| ------------------------ | ------------ | ---------------- | ------------------------------------------ |
| LOW_OPTIMAL_SIZE | NUMBER | NO | Minimum Memory for Workarea in Optimal Mode |
| HIGH_OPTIMAL_SIZE | NUMBER | NO | Maximum Memory for Workarea in Optimal Mode |
| OPTIMAL_EXECUTIONS | NUMBER | NO | Number of executions in the optimal mode for workarea within the lowest and highest ranges |
| ONEPASS_EXECUTIONS | NUMBER | NO | Number of Times Workarea Executes in One-Pass Mode Within the Minimum and Maximum Ranges |
| MULTIPASSES_EXECUTIONS | NUMBER | NO | Number of Executions in Multi-Pass Mode for Workarea Within the Minimum and Maximum Ranges |
| TOTAL_EXECUTIONS | NUMBER | NO | Total Number of Workarea Executions |
| CON_ID | NUMBER | NO | Tenant ID |
| SVR_IP | VARCHAR2(46) | NO | Server IP Address |
| SVR_PORT | NUMBER | NO | Server Port Number |

## Sample query

View the execution statistics of all previous workareas on the current node of this tenant, displaying the first 10 records.

```shell
obclient[SYS]> SELECT * FROM SYS.V$SQL_WORKAREA_HISTOGRAM WHERE ROWNUM<= 10;
```
