# V$OB_PX_WORKER_STAT

## Overview

In parallel execution scenarios, it displays the execution information of each thread for all tenants on the current OBServer node.

## Columns

| **Field** | Type | **Nullable** | Description |
| ------------ | -------------- | ---------------- | ---------------- |
| SESSION_ID | bigint(20) | NO | <ul><li>In direct connection mode:<br>This field indicates the server session ID.</li> <li>In ODP mode:</li><ul><li>When the ODP parameter <code>client_session_id_version = 2</code> is set, this field indicates the client session ID. </li> <li>When <code>client_session_id_version = 1</code> is set, this field indicates the server session ID.</li></ul></ul> |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| SVR_IP | varchar(46) | NO | Server IP Address |
| SVR_PORT | bigint(20) | NO | Server Port |
| TRACE_ID | varchar(128) | NO | SQL trace_id |
| QC_ID | bigint(20) | NO | qc_id in px |
| SQC_ID | bigint(20) | NO | sqc_id in px |
| WORKER_ID | bigint(20) | NO | Thread ID |
| DFO_ID | bigint(20) | NO | dfo_id in px |
| START_TIME | timestamp(6) | NO | Time when the thread starts running |

## Sample query

In the sys tenant, view the execution information of all threads of all tenants on the current OBServer node in parallel execution scenarios.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_PX_WORKER_STAT\G
```
