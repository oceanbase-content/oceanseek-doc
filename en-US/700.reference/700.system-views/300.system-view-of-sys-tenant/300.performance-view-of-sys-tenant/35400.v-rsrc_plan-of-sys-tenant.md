# V$RSRC_PLAN

## Overview

Displays the resource management plan of the current active tenant.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ---------------------------- | --------------- | ------------ | -------------------------------------------------------------------------------- |
| ID | decimal(10,0) | NO | Resource plan ID, globally unique. |
| NAME | varchar(128) | NO | Resource Plan Name |
| IS_TOP_PLAN | varchar(5) | NO | Whether the current resource plan is the top-level plan set currently: <ul><li>`TRUE`: Indicates that the current resource plan is the top-level plan set currently.    </li><li>`FALSE`: Indicates that the current resource plan is a subplan of the current top-level plan.</li></ul>  <br>  Currently, this value is fixed as `TRUE` in OceanSeek. |
| CPU_MANAGED | varchar(3) | NO | Whether the current resource plan has parameters set to manage CPU usage: <ul><li>`ON`: Set    </li><li>`OFF`: Not set.</li></ul>  <br>  Currently, this value is fixed to `ON` in OceanSeek. |
| INSTANCE_CAGING | varchar(3) | NO | For compatibility only. Currently, this value is fixed to `NULL` |
| PARALLEL_SERVERS_ACTIVE | decimal(10,0) | NO | This value is fixed for compatibility only and currently stands at `NULL` |
| PARALLEL_SERVERS_TOTAL | decimal(10,0) | NO | For compatibility only. Currently, this value is fixed to `NULL` |
| PARALLEL_EXECUTION_MANAGED | varchar(32) | NO | This value is fixed to  for compatibility only. `NULL` |

## Sample query

Query the resource management plan of the current active tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$RSRC_PLAN;
```

The query result is as follows:

```shell
+------+---------+-------------+-------------+-----------------+-------------------------+------------------------+----------------------------+
| ID   | NAME    | IS_TOP_PLAN | CPU_MANAGED | INSTANCE_CAGING | PARALLEL_SERVERS_ACTIVE | PARALLEL_SERVERS_TOTAL | PARALLEL_EXECUTION_MANAGED |
+------+---------+-------------+-------------+-----------------+-------------------------+------------------------+----------------------------+
| NULL | daytime | TRUE        | ON          | NULL            |                    NULL |                   NULL | NULL                       |
+------+---------+-------------+-------------+-----------------+-------------------------+------------------------+----------------------------+
1 row in set
```
