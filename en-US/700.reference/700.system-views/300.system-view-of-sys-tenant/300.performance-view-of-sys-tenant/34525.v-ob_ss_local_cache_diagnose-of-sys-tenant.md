# V$OB_LOCAL_CACHE_DIAGNOSE

## Overview

The `V$OB_LOCAL_CACHE_DIAGNOSE` view is used to diagnose the operational status of the local cache submodules for all tenants on the current OBServer node.

## Columns

| Field Name | Type | Whether to allow | Description |
| ----------------- | ----------- | ---------------- | -------- |
| SVR_IP | varchar(46) | NO | Node address of the replica |
| SVR_PORT | bigint(20) | NO | Node Port of Replica |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| MOD_NAME | varchar(64) | NO | Module Name in Local Cache |
| SUB_MOD_NAME | varchar(64) | NO | Sub-module name in local cache |
| STATUS | varchar(7) | NO | Corresponding sub-module running status: <ul><li>NORMAL/1: normal</li><li>WARN/2: minor exception</li><li>ERROR/3: severe exception</li></ul> |
| MODIFY_TIME | timestamp(6) | NO | Timestamp of the most recent status change for the corresponding sub-module |
| DIAGNOSE_INFO | varchar(1024) | NO | Diagnostic information of the corresponding sub-module |
| EXTRA_INFO | varchar(1024) | NO | Supplementary information on the status of the corresponding sub-module |

## Sample query

Query the running status and diagnostic information of each sub-module in the local cache for tenant ID 1004:

```shell
obclient(root@sys)[(none)]> SELECT * FROM oceanbase.V$OB_LOCAL_CACHE_DIAGNOSE WHERE tenant_id=1004;
```

The query result is as follows:

```shell
+--------------+----------+-----------+----------------+--------------+--------+----------------------------+-------------------------------------------------+------------+
| SVR_IP       | SVR_PORT | TENANT_ID | MOD_NAME       | SUB_MOD_NAME | STATUS | MODIFY_TIME                | DIAGNOSE_INFO                                   | EXTRA_INFO |
+--------------+----------+-----------+----------------+--------------+--------+----------------------------+-------------------------------------------------+------------+
```
