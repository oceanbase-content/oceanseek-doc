# GV$OB_SESSION

## Overview

The `GV$OB_SESSION` view is used to record session information created on all servers.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| ID | bigint(20) unsigned | NO | <ul><li>In direct connection mode:<br>This field indicates the server session ID.</li> <li>In ODP mode:</li><ul><li>When the ODP parameter <code>client_session_id_version = 2</code> is set, this field indicates the client session ID. </li> <li>When <code>client_session_id_version = 1</code> is set, this field indicates the server session ID.</li></ul></ul> |
| USER | varchar(32) | NO | Represents the user to whom the session belongs. |
| TENANT | varchar(128) | NO | Tenant Name |
| HOST | varchar(128) | NO | Indicates the client IP address and port number that initiated the session. If connecting to the database via ODP, it indicates the host IP address and port number of ODP. |
| DB | varchar(128) | YES | Indicates the name of the database to which the session is currently connected. |
| COMMAND | varchar(4096) | NO | Indicates the command being executed by the session. |
| SQL_ID | varchar(32) | NO | SQL ID Information |
| TIME | bigint(21) | NO | Indicates the time taken to execute the current command, in seconds. If the command is retried, this value will be reset and recalculated. |
| STATE | varchar(128) | YES | Indicates the current state of the session. |
| INFO | varchar(262143) | YES | Represents the statement being executed by the session. |
| SVR_IP | varchar(46) | NO | Server IP Address |
| SVR_PORT | bigint(20) | NO | Server RPC Port Number |
| SQL_PORT | bigint(20) | NO | SQL port number of the server |
| PROXY_SESSID | bigint(20) unsigned | YES | If the current client is ODP, this column displays the ODP session ID. |
| USER_CLIENT_IP | varchar(46) | YES | User Client IP |
| USER_HOST | varchar(128) | YES | User Client Host Name |
| TRANS_ID | bigint(20) unsigned | NO | Transaction ID |
| THREAD_ID | bigint(20) unsigned | NO | Thread ID |
| TRACE_ID | varchar(64) | YES | Trace ID |
| REF_COUNT | bigint(20) | NO | Connection Reference Count |
| BACKTRACE | varchar(16384) | YES | Connection Reference Call Stack |
| TRANS_STATE | varchar(32) | YES | Transaction status. If no transaction is active in the session, this field is empty. Valid values: <ul><li>`IDLE`: Idle, indicating the transaction has not started. </li> <li>`ACTIVE`: The transaction is explicitly started. Use `START TRANSACTION`, `BEGIN` and other statements are explicitly enabled. </li> <li>`IMPLICIT_ACTIVE`: The transaction is implicitly started. `autocommit = on` In  transaction mode, a transaction is started after executing data-modifying statements such as DML.</li> <li>`ROLLBACK_SAVEPOINT`: The transaction is rolling back to a savepoint. </li> <li>`IN_TERMINATE`: The transaction is being terminated, including termination due to internal reasons and user-initiated transaction termination (for example, executing the `COMMIT`, `ROLLBACK` statements). </li> <li>`ABORTED`: The transaction is internally terminated or rolled back due to an exception. </li> <li>`ROLLED_BACK`: The transaction has been rolled back. </li> <li>`COMMIT_TIMEOUT`: Transaction commit timeout.</li> <li>`COMMIT_UNKNOWN`: The transaction commit result is unknown.</li> <li>`COMMITTED`: The transaction has been successfully committed. </li></ul> |
| USER_CLIENT_PORT | bigint(20) | NO | User Client Port Number |
| TOTAL_CPU_TIME | bigint(21) | NO | The CPU time consumed by the current command, in seconds. |

## Sample query

Query the session information created by all tenants on all servers.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_SESSION limit 1\G
```
