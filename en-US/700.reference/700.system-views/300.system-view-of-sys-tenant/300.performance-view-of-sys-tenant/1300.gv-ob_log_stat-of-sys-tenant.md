# GV$OB_LOG_STAT

## Overview

Displays the status of the log stream Palf. Common usage scenarios include:

* Query whether the log stream has a leader (the replica where the leader resides).
* Query the member list of a log stream (number of Paxos replicas).
* Query the replica synchronization status.
* Query the recyclable timestamp of a log stream.
* Query the scope of log streams that are allowed to provide log consumption services (including LSN and SCN).
* Query the access mode of Palf.

The results obtained by querying this view vary depending on the tenant. Specifically:

* When queried through the sys tenant, this view displays the status of all tenant log stream Palfs.
* When querying this view from a user tenant, only the status of the Palf for the current tenant's log stream is displayed.

## Columns

| **Column** | **Type** | **Nullable** | Description |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| LS_ID | bigint(20) | NO | Log Stream ID |
| SVR_IP | varchar(46) | NO | OBServer IP |
| SVR_PORT | bigint(20) | NO | OBServer Port Number |
| ROLE | varchar(32) | NO | Replica role: <ul><li>`LEADER`: The replica role is LEADER.  </li><li>`FOLLOWER`: The replica role is FOLLOWER. </li></ul> |
| PROPOSAL_ID | bigint(20) | NO | Paxos Proposal ID |
| CONFIG_VERSION | varchar(128) | NO | Version number corresponding to the configuration change |
| ACCESS_MODE | varchar(32) | NO | Access mode:<ul><li>`APPEND`: The log stream replica is writable by the primary tenant.  </li><li>`RAW_WRITE`: The log stream replica is in read-only state for the standby tenant. </li></ul> |
| PAXOS_MEMBER_LIST | varchar(1024) | NO | Paxos Member List |
| PAXOS_REPLICA_NUM | bigint(20) | NO | Number of Paxos Replicas |
| IN_SYNC | varchar(3) | NO | Whether the replicas are fully synchronized with the leader |
| BASE_LSN | bigint(20) | NO | Maximum Recyclable Timestamp |
| BEGIN_LSN | bigint(20) | NO | Least Recently Consumed Timestamp (LSN) |
| BEGIN_SCN | bigint(20) | NO | Smallest Consumable SCN |
| END_LSN | bigint(20) | NO | Maximum Consecutive Majority LSN |
| END_SCN | bigint(20) | NO | Maximum Consecutive Majority Timestamp/Scannable Consumer Timestamp (SCN) |
| MAX_LSN | bigint(20) | NO | Maximum Write Point (LSN) |
| MAX_SCN | bigint(20) | NO | Maximum Write Point (SCN) |
| ARBITRATION_MEMBER | varchar(128) | NO | The server address of the arbitration member. This parameter is not required at the moment. |
| DEGRADED_LIST | varchar(1024) | NO | List of Full-featured Replicas Degraded in Arbitration Scenarios |
| LEARNER_LIST | longtext | NO | List of Read-only Replicas for the Current Log Stream |

## Sample query

The system tenant can view the log stream replica status for all tenants.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_LOG_STAT\G
```
