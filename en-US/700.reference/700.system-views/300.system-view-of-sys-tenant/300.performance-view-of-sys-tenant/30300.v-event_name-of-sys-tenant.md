# V$EVENT_NAME

## Overview

Displays the definitions of all wait events.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| --------------- | ------------- | ---------------- | -------------- |
| CON_ID | bigint(20) | NO | Tenant ID |
| EVENT_ID | bigint(20) | NO | ID of the event to wait for |
| EVENT# | bigint(20) | NO | Index of the Waiting Event |
| NAME | varchar(64) | NO | Name of the event to wait for |
| DISPLAY_NAME | varchar(64) | NO | Alias for the wait event |
| PARAMETER1 | varchar(64) | NO | Parameter 1 of waitevent |
| PARAMETER2 | varchar(64) | NO | Parameter 2 of the WAIT FOR EVENT statement |
| PARAMETER3 | varchar(64) | NO | Parameter 3 of WAIT FOR EVENTS |
| WAIT_CLASS_ID | bigint(20) | NO | ID of the event type to wait for |
| WAIT_CALSS# | bigint(20) | NO | Index of the event type |
| WAIT_CLASS | varchar(64) | NO | Name of the event type being waited for |

## Sample query

In the sys tenant, view the definitions of all pending events and display the first 10 records.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$EVENT_NAME limit 10;
```
