# GV$OB_FLT_TRACE_CONFIG

## Overview

Displays diagnostic information for end-to-end tracing.

## Columns

| **Column** | **Type** | **Is NULL** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | Tenant ID. <ul><li>1: System tenant ID.</li><li>Other values: User tenant or Meta tenant ID.</li></ul> |
| TYPE | varchar(16) | NO | The monitoring level of diagnostic information. <ul><li>Tenant level: monitors diagnostic information at the tenant level.  </li><li>Module/action level: monitors diagnostic information at the module and action levels. </li><li>Client_identifier level: monitors diagnostic information at the client identifier level. </li></ul> |
| TENANT_NAME | varchar(128) | NO | Tenant Name |
| MODULE_NAME | varchar(4096) | NO | Module Name |
| ACTION_NAME | varchar(4096) | NO | Action |
| CLIENT_IDENTIFIER | varchar(65) | NO | Client Identifier |
| LEVEL | bigint(20) | NO | Indicates the end-to-end tracing monitoring level for the session. For example, 1 indicates diagnostic information at level 1. |
| SAMPLE_PERCENTAGE | bigint(20) | NO | Indicates the sampling frequency for end-to-end tracing of the session. For example, 50 indicates that diagnostic information is sampled with a probability of 50%. |
| RECORD_POLICY | varchar(32) | NO | Specifies the trace recording strategy for the entire session. The following three strategies are supported:<ul><li>ALL: All trace information collected during sampling is printed to the log file. This happens at the end of each span. </li><li>ONLY_SLOW_QUERY: Only traces of slow queries are printed to the log file. Other traces are discarded. In this mode, traces are printed after the request is identified as a slow query. For root spans (that is, transaction-level spans) in the proxy, they are printed only when a slow query is detected. </li><li>SAMPLE_AND_SLOW_QUERY: Traces that meet the following conditions are printed to the log file:<ol><li>The hidden parameter <code>_print_sample_ppm</code> is used to enable probability sampling at a rate of one in ten thousand. A trace is printed only if it is selected in the sampling.</li><li>The trace meets the printing conditions in ONLY_SLOW_QUERY mode.</li></ol>In this mode, traces are not printed at the end of each span. If condition 1 is met, the trace is marked for forced printing on the client, and this information is passed to downstream components. If condition 2 is met, the printing timing is the same as in ONLY_SLOW_QUERY mode.</li></ul> |
