# GV$OB_TENANT_RESOURCE_LIMIT_DETAIL

## Overview

The `GV$OB_TENANT_RESOURCE_LIMIT.Detail` view displays the logical resource limits for all tenants across all OBServer nodes, along with the upper limits for each type of resource.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ---------- | -------- | ----------------- | ------------- |
| SVR_IP | varchar(46) | NO | IP Address of OBServer |
| SVR_PORT | bigint(20) | NO | RPC Port of OBServer |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| RESOURCE_NAME | varchar(128) | NO | Resource Name |
| LIMIT_TYPE | varchar(128) | NO | Limit Name |
| LIMIT_VALUE | bigint(20) | NO | Limit value |

## Sample query

Query the logical resource limits for all tenants across all OBServer nodes, including the upper limits for each constraint. Display the first five records.

```shell
obclient[oceanbase]> SELECT * FROM oceanbase.GV$OB_TENANT_RESOURCE_LIMIT_DETAIL LIMIT 5;
```
