# GV$OB_DTL_INTERM_RESULT_MONITOR

## Overview

Displays the monitoring information of the DTL intermediate result manager.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | Server IP Address |
| SVR_PORT | bigint(20) | NO | Server Port Number |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| TRACE_ID | varchar(64) | NO | TRACE ID of the statement |
| OWNER | varchar(64) | NO | Intermediate result user |
| START_TIME | timestamp(6) | NO | Time for Writing Intermediate Results |
| EXPIRE_TIME | timestamp(6) | NO | Intermediate Result Timeout Period |
| HOLD_MEMORY | bigint(20) | NO | Memory size occupied, in bytes |
| DUMP_SIZE | bigint(20) | NO | Dump size, in bytes |
| DUMP_COST | bigint(20) | NO | Dump Time |
| DUMP_TIME | timestamp(6) | YES | Dump Time Point |
| DUMP_FD | bigint(20) | NO | FD of the Dump File |
| DUMP_DIR_ID | bigint(20) | NO | Directory ID of Dump File |
| CHANNEL_ID | bigint(20) | NO | DTL's channel ID |
| QC_ID | bigint(20) | NO | QC ID of the sender |
| DFO_ID | bigint(20) | NO | DFO ID of the sender |
| SQC_ID | bigint(20) | NO | SQC ID of the sender |
| BATCH_ID | bigint(20) | NO | The number of the batch in the PX batch rescan scenario |
| MAX_HOLD_MEMORY | bigint(20) | NO | The maximum size of memory that can be occupied, in bytes. |
