# V$OB_TENANT_RESOURCE_LIMIT_DETAIL

## Overview

The `V$OB_TENANT_RESOURCE_LIMIT.Detail` view displays the logical resource limits imposed on all tenants on the current OBServer, along with the upper limits for each constraint.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ---------- | -------- | ----------------- | ------------- |
| SVR_IP | varchar(46) | NO | IP Address of OBServer |
| SVR_PORT | bigint(20) | NO | RPC Port of OBServer |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| RESOURCE_NAME | varchar(128) | NO | Resource Name |
| LIMIT_TYPE | varchar(128) | NO | Limit Name |
| LIMIT_VALUE | bigint(20) | NO | Limit value |

## Sample query

Query the limitations on the logical resources of all tenants on this OBServer node, and the upper limits for each limitation.

```shell
obclient[oceanbase]> SELECT * FROM oceanbase.V$OB_TENANT_RESOURCE_LIMIT_DETAIL LIMIT 5;
```

The query result is as follows:

```shell
+----------------+----------+-----------+---------------+---------------+---------------------+

|   xx.xx.xx.xx  |     2882 |         1 | ls            | memory        |                  70 |
```
