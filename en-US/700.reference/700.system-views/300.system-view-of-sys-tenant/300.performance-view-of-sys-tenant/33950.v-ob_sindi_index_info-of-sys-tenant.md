# V$OB_SINDI_INDEX_INFO

## Overview

Displays the basic information and real-time status of SINDI and SINDI_SQ vector indexes on the current OBServer node.

## Columns

| Field Name | Data type | Whether can be NULL | Description | Information Type |
| ------------------------------ | -------------- | ---------------- | ------------------------------------------------------------ | ------------ |
| SVR_IP | varchar(46) | NO | Node address of the replica | Basic Information |
| SVR_PORT | bigint(20) | NO | RPC_PORT of the replica node | Basic Information |
| TENANT_ID | bigint(20) | NO | Tenant ID<ul><li>1: System tenant ID</li> <li>Other values: User tenant or Meta tenant ID</li></ul> | Basic Information |
| DATA_TABLE_ID | bigint(20) | NO | Data Table ID | Basic Information |
| DATA_TABLET_ID | bigint(20) | NO | Partition ID | Basic Information |
| TABLE_NAME | varchar(256) | NO | Table name | Basic Information |
| INDEX_NAME | varchar(256) | NO | Index name | Index Information |
| ROLE | varchar(8) | NO | Role. Valid values: *:<ul><li>leader: primary replica.</li> <li>follower: follower replica.</li></ul> | Basic Information |
| INDEX_PARAM | varchar(512) | NO | Index parameters | Index Information |
| MEMORY_USED | bigint(20) | NO | Memory Usage | Index Information |
| MEMORY_HOLD | bigint(20) | NO | Memory Usage | Index Information |
| INCR_MEM_HOLD | bigint(20) | NO | Incremental Memory Usage | Index Information |
| SNAP_MEM_HOLD | bigint(20) | NO | Snapshot Memory Usage | Index Information |
| INCR_VECTOR_CNT | bigint(20) | NO | Number of Incremental Vectors | Index Information |
| SNAP_VECTOR_CNT | bigint(20) | NO | Number of Snapshot Vectors | Index Information |
| INCR_DATA_SCN | bigint(20) unsigned | NO | Incremental data version | Index Information |
| SNAP_DATA_SCN | bigint(20) unsigned | NO | Snapshot Data Version | Index Information |
| LAST_SUCC_SYNC_TIME | datetime | NO | Last Successful Time | Synchronization Information |
| LAST_FAILED_SYNC_TIME | datetime | NO | Last Failure Time | Synchronization Information |
| LAST_FAILED_CODE | bigint(20) | NO | Error Code of the Most Recent Failure | Synchronization Information |

## Sample query

Users can query the real-time status of SINDI and SINDI_SQ vector indexes on the current OBServer node.

```sql
SELECT * FROM oceanbase.V$OB_SINDI_INDEX_INFO\G;
```
