# V$OB_IO_BENCHMARK

## Overview

Displays the disk calibration data used by the I/O module on the current node.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | Server IP Address |
| SVR_PORT | bigint(20) | NO | Server Port Number |
| STORAGE_NAME | varchar(1024) | NO | Storage name, for example, DATA or REDO. |
| MODE | varchar(256) | NO | I/O mode, for example, READ and WRITE |
| SIZE | bigint(20) | NO | I/O size, in bytes |
| IOPS | bigint(20) | NO | Number of I/O Requests Completed per Second |
| MBPS | bigint(20) | NO | Disk bandwidth, in MB/s |
| LATENCY | bigint(20) | NO | Response time, in μs |

## Sample query

View the disk calibration data used by the I/O module on the current node, displaying the first 10 records.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_IO_BENCHMARK LIMIT 10;
```
