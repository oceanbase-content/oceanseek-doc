# V$OB_TABLET_COMPACTION_PROGRESS

## Overview

Displays the progress information of tablet-level compaction for all tenants on the current node.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ------------------------------ | -------------- | ------------ | -------- |
| SVR_IP | varchar(46) | NO | Server IP Address |
| SVR_PORT | bigint(20) | NO | Server Port Number |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| TYPE | varchar(64) | NO | Compaction type:<ul><li>`MDS_TABLE_MERGE`: Persist the system's metadata to disk in SSTable format.</li> <li>`MAJOR_MERGE`: Tenant-level major compaction</li> <li>`MEDIUM_MERGE`: Partition-level compaction</li> <li>`MINI_MERGE`: Performs a minor compaction, converting the MemTable into a Mini SSTable.</li> <li>`MINOR_MERGE`: Minor compaction, where multiple mini-SSTables are merged into a new mini-SSTable, or multiple mini-SSTables and a minor-SSTable are merged into a new minor-SSTable. </li> <li>`META_MAJOR_MERGE`: A special type of compaction that synthesizes data from a specified point in time into a Meta Major SSTable. Its data format is the same as that of a Major SSTable, excluding multi-version data and uncommitted transaction data.</li></ul> |
| TABLE_ID | bigint(20) | NO | Primary Table ID |
| LS_ID | bigint(20) | NO | Log Stream ID |
| TABLET_ID | bigint(20) | NO | Data Shard ID |
| COMPACTION_SCN | bigint(20) unsigned | NO | Major compaction version information |
| TASK_ID | varchar(64) | NO | Executed Trace |
| STATUS | varchar(15) | NO | Task Status |
| DATA_SIZE | bigint(20) | NO | Total data volume requiring compaction, in bytes |
| UNFINISHED_DATA_SIZE | bigint(20) | NO | Data volume of unfinished major compaction, in bytes |
| PROGRESSIVE_COMPACTION_ROUND | bigint(20) | NO | Asymptotic Major Compaction Round |
| CREATE_TIME | timestamp(6) | NO | Task Creation Time |
| START_TIME | timestamp(6) | NO | Start Time |
| ESTIMATED_FINISH_TIME | timestamp(6) | NO | Estimated Completion Time |
| START_CG_ID | bigint(20) | NO | Start ID of Column Group |
| END_CG_ID | bigint(20) | NO | End ID of Column Group |

## Sample query

Query the progress information of the tenant with ID 1002 in the current node for the `MAJOR_MERGE` compaction type in the sys tenant.

```shell
obclient [oceanbase]> SELECT * FROM ocenbase.V$OB_TABLET_COMPACTION_PROGRESS WHERE TENANT_ID=1002 AND TYPE='MAJOR_MERGE'\G
```
