# GV$OB_IVF_INDEX_INFO

## Overview

This view displays the basic information and real-time status of IVF vector indexes for all tenants across all OBServer nodes.

## Columns

| Field Name | Data type | Whether can be NULL | Description | Information Type |
| ------------------------------ | -------------- | ---------------- | ------------------------------------------------------------ | ------------ |
| SVR_IP | varchar(46) | NO | Node address of the replica | Basic Information |
| SVR_PORT | bigint(20) | NO | RPC_PORT of the replica node | Basic Information |
| TENANT_ID | bigint(20) | NO | Tenant ID: <ul><li>1: System tenant ID</li> <li>Other values: User tenant or Meta tenant ID</li></ul> | Basic Information |
| DATA_TABLE_ID | bigint(20) | NO | Data Table ID | Basic Information |
| TABLE_NAME | varchar(256) | NO | Table name | Basic Information |
| INDEX_NAME | varchar(256) | NO | Index name | Index Information |
| INDEX_TABLE_ID | bigint(20) | NO | Index Table ID | Index Information |
| INDEX_TABLET_ID | bigint(20) | NO | Index Table Partition ID | Index Information |
| INDEX_PARAM | varchar(1024) | NO | Index parameters | Index Information |
| CACHE_TYPE | varchar(29) | NO | IVF index cache type:<ul><li>IVF_CENTROID_CACHE: The center point cache for IVF indexes.</li> <li>IVF_PQ_CENTROID_CACHE: The center point cache for IVF_PQ indexes.</li> <li>IVF_PQ_PRECOMPUTE_TABLE_CACHE: The precomputed table cache for IVF_PQ indexes.</li></ul> | Cache information |
| IS_INIT | varchar(5) | NO | Whether initialized: <ul><li>TRUE: Initialized</li> <li>FALSE: Not initialized</li></ul> | Cache information |
| MEMORY_USED | bigint(20) | NO | Memory Usage | Index Information |
| MEMORY_HOLD | bigint(20) | NO | Memory Usage | Index Information |
| CACHE_INFO | varchar(512) | NO | Cache attribute information in JSON format | Cache information |

## Sample query

Query the real-time status of IVF vector indexes for all tenants across all OBServer nodes in the SYS tenant.

SELECT * FROM oceanbase.GV$OB_IVF_INDEX_INFO;
