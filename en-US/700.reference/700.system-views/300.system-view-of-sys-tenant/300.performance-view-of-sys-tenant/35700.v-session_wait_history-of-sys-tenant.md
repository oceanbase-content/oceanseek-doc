# V$SESSION_WAIT_HISTORY

## Overview

The `V$SESSION_WAIT_HISTORY` view displays the details of all current session wait events on the current node, including the last 10 such events.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| ---- | ---- | ---- | ---- |
| SID | bigint(20) | NO | <ul><li>In direct connection mode:<br>This field indicates the server session ID.</li> <li>In ODP mode:</li><ul><li>When the ODP parameter <code>client_session_id_version = 2</code> is set, this field indicates the client session ID. </li> <li>When <code>client_session_id_version = 1</code> is set, this field indicates the server session ID.</li></ul></ul> |
| CON_ID | bigint(20) | NO | Tenant ID |
| SVR_IP | varchar(46) | NO | Server IP Address |
| SVR_PORT | bigint(20) | NO | Server Port |
| SEQ# | bigint(20) | NO | Wait Event Sequence Number |
| EVENT# | bigint(20) | NO | Event Number |
| EVENT | varchar(64) | NO | Event Name |
| P1TEXT | varchar(64) | NO | Description of Parameter 1 for the WAIT FOR EVENT Statement |
| P1 | bigint(20) unsigned | NO | Value of Parameter 1 for the Wait Event |
| P2TEXT | varchar(64) | NO | Description of Parameter 2 for the WAIT FOR EVENT Statement |
| P2 | bigint(20) unsigned | NO | Value of Parameter 2 for the Wait Event |
| P3TEXT | varchar(64) | NO | Description of Parameter 3 for the WAIT FOR EVENT Statement |
| P3 | bigint(20) unsigned | NO | Value of Parameter 3 for the Wait Event |
| WAIT_TIME | double | NO | Wait time for the event, in milliseconds |
| WAIT_TIME_MICRO | bigint(20) | NO | Wait time for the event, in microseconds |
| TIME_SINCE_LAST_WAIT_MICRO | bigint(20) | NO | Time elapsed from the end of the previous wait to the current wait, in microseconds. |

## Sample query

Query the details of all current wait events for all sessions on the current node, including the most recent 10 wait events.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$SESSION_WAIT_HISTORY LIMIT 1\G
```
