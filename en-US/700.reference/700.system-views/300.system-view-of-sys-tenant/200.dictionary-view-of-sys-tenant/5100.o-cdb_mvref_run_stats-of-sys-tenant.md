# CDB_MVREF_RUN_STATS

## Overview

The `CDB_MVREF_RUN_STATS` view displays information about each refresh operation of a materialized view, with each operation identified by a REFRESH_ID. This information includes timing statistics related to the operation and the parameters specified in that operation.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| RUN_OWNER | varchar(128) | NO | Owner of the refresh operation (the user who initiated the operation). |
| REFRESH_ID | bigint(20) | NO | Refresh ID |
| NUM_MVS | bigint(20) | NO | Number of Materialized Views Refreshed |
| MVIEWS | text | NO | Parameter for the materialized view name specified by the API |
| BASE_TABLES | text | YES | For Internal Use Only |
| METHOD | text | YES | METHOD parameter specified in the API |
| ROLLBACK_SEG | text | YES | ROLLBACK_SEG parameter specified by the API |
| PUSH_DEFERRED_RPC | varchar(1) | NO | PUSH_DEFERRED_RPC parameter specified by the API |
| REFRESH_AFTER_ERRORS | varchar(1) | NO | The REFRESH_AFTER_ERRORS parameter specified in the API |
| PURGE_OPTION | bigint(20) | NO | PURGE_OPTION parameter specified by the API |
| PARALLELISM | bigint(20) | NO | PARALLELISM parameter specified by the API |
| HEAP_SIZE | bigint(20) | NO | The HEAP_SIZE parameter specified by the API |
| ATOMIC_REFRESH | varchar(1) | NO | The ATOMIC_REFRESH parameter specified in the API |
| NESTED | varchar(1) | NO | NESTED parameter specified by the API |
| OUT_OF_PLACE | varchar(1) | NO | OUT_OF_PLACE parameter specified by API |
| NUMBER_OF_FAILURES | bigint(20) | NO | Number of Failures in Processing APIs |
| RESULT | bigint(20) | YES | Refresh result (error code). |
| START_TIME | datetime | NO | Start time of the refresh run |
| END_TIME | datetime | NO | End Time of Refresh |
| ELAPSED_TIME | bigint(20) | NO | The duration for which the refresh is running. |
| LOG_SETUP_TIME | bigint(1) | NO | Log retention period for the materialized view, in seconds<main id="notice" type='explain'> <h4>Note</h4><p>This field is only compatible with and its default value is 0.</p></main> |
| LOG_PURGE_TIME | bigint(20) | NO | Log purge time for the materialized view. |
| COMPLETE_STATS_AVAILABLE | varchar(1) | NO | Indicates whether all completely refreshed statistics are available for this run.<ul><li> Y </li><li>N </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>This field is only compatible with and its default value is Y.</p></main> |
| MVIEW_ID | bigint(20) | YES | The materialized view ID. |
| MVIEW_NAME | varchar(128) | NO | The name of the materialized view. |
| DATA_TARGET_SCN | bigint(20) unsigned | YES | Represents the target data synchronization SCN. |
| TRACE_ID | varchar(64) | YES | Represents the trace ID of the refresh task. |

## Sample query

Query the information about each refresh of a materialized view. Each refresh is identified by a REFRESH_ID.

```shell
obclient [test_db]> SELECT * FROM oceanbase.CDB_MVREF_RUN_STATS;
```
