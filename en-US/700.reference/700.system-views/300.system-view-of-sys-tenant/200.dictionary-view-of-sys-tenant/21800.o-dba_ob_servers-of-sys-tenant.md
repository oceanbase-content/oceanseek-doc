# oceanbase.DBA_OB_SERVERS

## Overview

Displays information about all OBServer nodes.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ----------------------- | -------------- | ------------ | ---------------------------------------------------------------------------- |
| SVR_IP | varchar(46) | NO | Server IP Address |
| SVR_PORT | bigint(20) | NO | Server Port Number |
| ID | bigint(20) | NO | The unique ID assigned to the cluster. |
| ZONE | varchar(128) | NO | Zone to which the OBServer node belongs |
| SQL_PORT | bigint(20) | NO | Port for serving SQL requests on the OBServer node |
| WITH_ROOTSERVER | varchar(3) | NO | <ul><li>`YES`: Root service exists. </li><li>`NO`: No Root Service</li></ul> |
| STATUS | varchar(64) | NO | <ul><li>`ACTIVE`: OBServer node and RS heartbeat normal. </li><li>`INACTIVE`: OBServer node loses heartbeat contact with RS. </li><li>`DELETING`: The OBServer node is being deleted.</li></ul> |
| START_SERVICE_TIME | timestamp(6) | NO | The point in time after the node process starts when it can provide services: <ul><li>`NULL`: The node process has not been started or the node status is unavailable.   </li><li> Valid values: the point in time after the node process is started when it can provide services to external requests.</li></ul> |
| STOP_TIME | timestamp(6) | NO | Time point when the user actively stopped the node service:<ul><li>`NULL`: The node has not been stopped.   </li><li> Valid values: OBServer node is stopped, indicating the stop time.</li></ul> |
| BLOCK_MIGRATE_IN_TIME | timestamp(6) | NO | The time when data migration to an OBServer node is prohibited:<ul><li>`NULL`: No data migration is prohibited.   </li><li> Valid values: the time when data migration is prohibited.</li></ul> |
| CREATE_TIME | timestamp(6) | YES | Table creation time |
| MODIFY_TIME | timestamp(6) | YES | Last Modified Time |
| BUILD_VERSION | varchar(256) | NO | OBServer Binaries Build Version |
| LAST_OFFLINE_TIME | timestamp(6) | NO | Last Offline Time of OBServer Node: <ul><li>`NULL`: The OBServer node has never gone offline.   </li><li> Valid value: the last offline time of the OBServer node.</li></ul> |

## Sample query

The sys tenant is used to view information about all OBServer nodes in the cluster.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_SERVERS\G
```
