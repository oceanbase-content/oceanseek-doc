# oceanbase.DBA_OB_BACKUP_PARAMETER

## Overview

Displays the backup parameters configured for the current tenant. The system tenant does not contain user data and is used for cluster management. Therefore, it does not support backup and recovery, and the `sys` tenant has no backup parameters configured. In the `sys` tenant, the query result of this view is always empty.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --- | --- | --- | --- |
| NAME | varchar(1024) | NO | Parameter name |
| VALUE | longtext | NO | The parameter value. |
