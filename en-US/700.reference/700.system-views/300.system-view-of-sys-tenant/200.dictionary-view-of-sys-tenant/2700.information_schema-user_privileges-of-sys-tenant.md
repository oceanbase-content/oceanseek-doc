# information_schema.USER_PRIVILEGES

## Overview

Records user permission information.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| ---------------- | --------------- | ---------------- | -------- |
| GRANTEE | varchar(81) | NO | Account Name Granted Permission |
| TABLE_CATALOG | varchar(512) | NO | Table directory, fixed as `def` |
| PRIVILEGE_TYPE | varchar(64) | NO | Granted Privilege |
| IS_GRANTABLE | varchar(3) | NO | Sublicensable |

## Sample query

Query user privileges.

```shell
obclient [infotest]> SELECT * FROM information_schema.USER_PRIVILEGES;
```

A sample query is as follows:

```shell
+-------------+---------------+----------------+--------------+
| GRANTEE     | TABLE_CATALOG | PRIVILEGE_TYPE | IS_GRANTABLE |
+-------------+---------------+----------------+--------------+
| 'test1'@'%' | def           | USAGE          | NO           |
+-------------+---------------+----------------+--------------+
1 row in set
```
