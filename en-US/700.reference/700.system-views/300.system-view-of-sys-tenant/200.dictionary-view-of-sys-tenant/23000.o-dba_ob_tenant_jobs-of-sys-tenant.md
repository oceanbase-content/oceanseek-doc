# oceanbase.DBA_OB_TENANT_JOBS

## Overview

Displays task information at the tenant level.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ------------- | -------------- | ------------ | ------------- |
| JOB_ID | bigint(20) | NO | Task ID |
| JOB_TYPE | varchar(128) | NO | Task type: <ul><li>`ALTER_TENANT_LOCALITY`: Modify Tenant Locality</li> <li>`ROLLBACK_ALTER_TENANT_LOCALITY`: Roll back the tenant's locality.</li> <li>`SHRINK_RESOURCE_TENANT_UNIT_NUM`: The number of units to scale down for the tenant.</li> <li>`ALTER_TENANT_PRIMARY_ZONE`: Modify tenant's `PRIMARY_ZONE`</li>  <li>`ALTER_RESOURCE_TENANT_UNIT_NUM`: Modify the tenant resource pool's `UNIT_NUM`</li> <li>`UPGRADE_POST_ACTION`: Prerequisites for upgrade</li> <li>`UPGRADE_SYSTEM_VARIABLE`: Upgrade system variables</li> <li>`UPGRADE_SYSTEM_TABLE`: Upgrade system tables</li> <li>`UPGRADE_BEGIN`: Upgrade started</li> <li>`UPGRADE_VIRTUAL_SCHEMA`: Upgrade Schema</li> <li>`UPGRADE_SYSTEM_PACKAGE`: Upgrade system packages</li> <li>`UPGRADE_ALL_POST_ACTION`: Post-upgrade operations</li> <li>`UPGRADE_INSPECTION`: Upgrade check</li> <li>`UPGRADE_END`: Upgrade completed.</li> <li>`UPGRADE_ALL`: Upgrade all tenants</li></ul> |
| JOB_STATUS | varchar(128) | NO | Task status: <ul><li>`INPROGRESS`: In progress </li><li>`SUCCESS`: successful</li><li>`FAILED`: Failed. </li></ul> |
| RESULT_CODE | bigint(20) | YES | Task End Code |
| PROGRESS | bigint(20) | NO | Task progress percentage, which ranges from 0 to 100. |
| START_TIME | timestamp(6) | YES | Task Start Time |
| MODIFY_TIME | timestamp(6) | YES | Last Modified Time |
| TENANT_ID | bigint(20) | YES | Tenant ID |
| SQL_TEXT | longtext | YES | Related SQL strings |
| EXTRA_INFO | varchar(512) | YES | Additional information |
| RS_SVR_IP | varchar(46) | NO | Root Service Server IP Address |
| RS_SVR_PORT | bigint(20) | NO | Root Service Server Port Number |

## Sample query

The system tenant queries the tenant task information of all tenants.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_TENANT_JOBS\G
```
