# oceanbase.CDB_OB_AI_MODEL_PROVIDERS

<main id="notice" type='explain'>
    <h4>Note</h4>
    <p>This view is available starting with V4.6.2.1. </p>
</main>

## Overview

Displays the AI vendor (Provider) configuration information for all tenants. It is commonly used to view the vendor connection information and access credential configurations registered by each tenant through the `REGISTER_PROVIDER` statement under the sys tenant.

## Columns

| field | Type | Is NULL | Description |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | YES | Tenant ID. |
| PROVIDER_NAME | varchar(256) | NO | Vendor name. In `provider/model` In the formula, `/` The name is displayed on the left. |
| PROTOCOL | varchar(256) | NO | Communication protocol, for example, `openai`, `dashscope`, `cohere` etc. |
| BASE_URL | varchar(2048) | NO | The currently effective base URL of the model service. |
| ACCESS_KEY | varchar(2048) | NO | Access credentials. The query results are not returned in plaintext. |
| CREATE_TIME | timestamp(6) | NO | Creation time. |
| UPDATE_TIME | timestamp(6) | NO | Last modified at. |

## Sample query

Query the AI vendor configuration information of all tenants from the system tenant.

1. Register the vendor configuration in user tenant `1004` (replace `access_key` with the actual value):

    ```shell
    CALL DBMS_AI_SERVICE.REGISTER_PROVIDER('deepseek', '{
    "access_key": "sk-xxx"
    }');
    ```

2. Query in the sys tenant:

    ```shell
    SELECT TENANT_ID, PROVIDER_NAME, PROTOCOL, BASE_URL
    FROM oceanbase.CDB_OB_AI_MODEL_PROVIDERS
    WHERE PROVIDER_NAME = 'deepseek';
    ```

    The sample result is as follows:

    ```shell
    TENANT_ID	PROVIDER_NAME	PROTOCOL	BASE_URL
    1004	deepseek	openai	https://api.deepseek.com
    1 row in set
    ```
