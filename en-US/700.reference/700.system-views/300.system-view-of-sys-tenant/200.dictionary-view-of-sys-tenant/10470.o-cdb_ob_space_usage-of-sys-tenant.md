# oceanbase.CDB_OB_SPACE_USAGE

## Overview

The `CDB_OB_SPACE_usage` view records the space usage of different data types for each tenant at various endpoints and paths.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| ------------ | ------------- | --------------------- | ---------------------------------------- |
| TENANT_ID | varchar(128) | NO | Tenant ID. |
| TENANT_NAME | varchar(128) | NO | Tenant name. |
| ENDPOINT | varchar(1024) | NO | Endpoint for shared storage. |
| PATH | varchar(1024) | NO | The path of the shared storage. |
| SPACE_TYPE | varchar(11) | NO | <ul><li>Local Data: All macroblocks in local deployment mode, including the private data, all metadata, and all temporary files of all replica nodes in the tenant. </li><li>clog Data: Clogs in local deployment mode, including the private clogs of all replica nodes in the tenant. </li><li>PRIVATE: Sum of multi-replica multi-versions and temporary files</li><li>Shared Data: The multi-version baseline shared by tenants. </li></ul> |
| USAGE_BYTES | decimal(42,0) | NO | The actual size of disk space occupied by the data, in bytes. |
