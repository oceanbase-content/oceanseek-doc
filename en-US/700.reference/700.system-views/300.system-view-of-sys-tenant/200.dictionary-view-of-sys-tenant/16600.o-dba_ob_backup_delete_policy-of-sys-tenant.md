# oceanbase.DBA_OB_BACKUP_DELETE_POLICY

## Overview

Displays the cleanup policies set for expiration cleanup and automatic cleanup under the tenant. The `sys` tenant and Meta tenant do not support physical backup.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --- | --- | --- | --- |
| POLICY_NAME | varchar(256) | NO | Cleanup Policy Name: <ul><li>`default`: Indicates that the current tenant will be automatically cleaned up. `DATA_BACKUP_DEST` and `LOG_ARCHIVE_DEST` of the backup. </li> <li>`log_only`: Indicates that the logs in the archive path specified by the `LOG_ARCHIVE_DEST` parameter are automatically cleaned up.</li></ul> |
| RECOVERY_WINDOW | varchar(64) | NO | The recoverable time window. Default value: 0. |
