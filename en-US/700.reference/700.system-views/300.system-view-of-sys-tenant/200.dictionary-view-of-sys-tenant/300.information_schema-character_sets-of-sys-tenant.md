# information_schema.CHARACTER_SETS

## Overview

Displays the character set information of OceanBase AI Database.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| ---------------------- | -------------- | ---------------- | --------- |
| CHARACTER_SET_NAME | varchar(128) | NO | Character set name |
| DEFAULT_COLLATE_NAME | varchar(128) | NO | Character set comparison method |
| DESCRIPTION | varchar(64) | NO | Character set description |
| MAXLEN | bigint(20) | NO | Maximum Length of Character Set |

## Sample query

View the character set information of OceanBase AI Database.

```shell
obclient [oceanbase]> SELECT * FROM information_schema.CHARACTER_SETS;
```
