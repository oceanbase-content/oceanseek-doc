# oceanbase.DBA_RSRC_PLAN_DIRECTIVES

<main id="notice" type='explain'>
<h4>Note</h4>
<p>In the current version, it is recommended to use the view <a href="21420.o-dba_ob_rsrc_directives-of-sys-tenant.md">DBA_OB_RSRC_DIRECTIVES</a> to view the resource configuration parameters of a tenant in the Resource Manager.</p>
</main>

## Overview

Displays the details of each set of resource plan directives in the database.
