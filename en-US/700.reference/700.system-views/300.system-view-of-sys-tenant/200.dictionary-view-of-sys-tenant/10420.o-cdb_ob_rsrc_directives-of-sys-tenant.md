# oceanbase.CDB_OB_RSRC_DIRECTIVES

## Overview

Displays the resource configuration parameters of all tenants in the Resource Manager.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ------------------------------ | ----------------- | ---------------- | ----------------------- |
| TENANT_ID | bigint(20) | NO | Tenant ID of the resource plan |
| PLAN | varchar(128) | NO | Resource Plan Name |
| GROUP_OR_SUBPLAN | varchar(128) | NO | Resource group name controlled by the resource plan |
| COMMENTS | varchar(2000) | YES | Comments Corresponding to Resource Plan Items |
| MGMT_P1 | bigint(20) | NO | The maximum relative CPU utilization under full system load. Default value: `100` |
| UTILIZATION_LIMIT | bigint(20) | NO | The maximum percentage of the tenant's total CPU resources that can be used by the resource group. Default value: `100`, indicating that the tenant can use all available CPU resources. |
| MIN_IOPS | bigint(20) | NO | In the event of I/O contention, the reserved IOPS resources for the resource group, specified by all resource groups `MIN_IOPS` The sum of these values must not exceed 100. Default value: `0` |
| MAX_IOPS | bigint(20) | NO | The maximum IOPS resources that a resource group can use, specified for all resource groups. `MAX_IOPS` The sum of these values can exceed 100. The default value is `100` |
| WEIGHT_IOPS | bigint(20) | NO | The weight value of IOPS in case of I/O resource contention, specified for all resource groups. `WEIGHT_IOPS` The sum of these values can exceed 100. To meet the requirement, `MIN_IOPS`, `MAX_IOPS` If this parameter is set, I/O resources will be allocated according to the normalized weight values. The default value is `0` |
| MAX_NET_BANDWIDTH | bigint(20) | NO | The upper limit of network bandwidth for resource groups. It is specified for all resource groups. `MAX_NET_BANDWIDTH` The sum of these values can exceed 100. The default value is `100` |
| NET_BANDWIDTH_WEIGHT | bigint(20) | NO | The bandwidth weight in case of network resource contention, specified for all resource groups. `NET_BANDWIDTH_WEIGHT` The sum of these values can exceed 100. To meet the requirement, `MAX_NET_BANDWIDTH` With this setting enabled, network bandwidth resources will be allocated according to the normalized weight values. The default value is `0` |

## Sample query

In the Shared-Nothing (SN) mode, the sys tenant can view the resource configuration parameters of all tenants in the Resource Manager.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_RSRC_DIRECTIVES;
```

The query result is as follows:

```shell
+-----------+---------+-------------------+-----------+---------+-------------------+----------+----------+-------------+-------------------+----------------------+
| TENANT_ID | PLAN    | GROUP_OR_SUBPLAN  | COMMENTS  | MGMT_P1 | UTILIZATION_LIMIT | MIN_IOPS | MAX_IOPS | WEIGHT_IOPS | MAX_NET_BANDWIDTH | NET_BANDWIDTH_WEIGHT |
+-----------+---------+-------------------+-----------+---------+-------------------+----------+----------+-------------+-------------------+----------------------+
| 1002 | daytime | batch_group |  | 100 | 40 | 40 | 80 | 70 | 100 | 0 |
| 1002 | daytime | interactive_group | new | 40 | 60 | 40 | 80 | 70 | 30 | 30 |
| 1004 | PLAN_A | BIG_GROUP | new | 40 | 60 | 20 | 100 | 10 | 60 | 60 |
| 1004 | PLAN_A | SMALL_GROUP | AP Priority | 100 | 100 | 10 | 90 | 30 | 100 | 0 |
+-----------+---------+-------------------+-----------+---------+-------------------+----------+----------+-------------+-------------------+----------------------+
4 rows in set
```
