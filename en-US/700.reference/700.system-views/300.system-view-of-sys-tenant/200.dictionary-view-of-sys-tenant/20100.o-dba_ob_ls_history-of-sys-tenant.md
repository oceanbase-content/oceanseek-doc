# oceanbase.DBA_OB_LS_HISTORY

## Overview

Displays the log streams that have existed in this tenant's history.

## Columns

| field | Type | Is NULL | Description |
| ------------- | --------------- | ------------- | ------------------------------------------- |
| LS_ID | bigint(20) | NO | Log Stream ID |
| LS_GROUP_ID | bigint(20) | NO | Log Stream Group ID |
| STATUS | varchar(100) | NO | Current status of the log stream: <ul><li>`CREATING`: Creating log stream.</li><li>`NORMAL`: The status of the normal log stream.</li><li>`DROPPING`: Log stream is being deleted.</li><li>`PRE_TENANT_DROPPING`: The system log stream is in a special state, indicating that deletion of all log streams under the tenant has started.</li><li>`TENANT_DROPPING`: The tenant is being deleted and its log streams are being deleted.</li><li>`DROPPED`: The log stream has been reclaimed or is in the process of being reclaimed. </li><li>`WAIT_OFFLINE`: Log stream waiting to be recycled</li><li>`CREATE_ABORT`: Stop creating log streams</li></ul> |
| FLAG | varchar(2048) | NO | Log stream tag:<ul><li>Empty: normal log stream.</li><li>`DUPLICATE`: The broadcast log stream of the user tenant. The replication table is created on this log stream. </li> <li>`BLOCK_TABLET_IN`: Indicates that a tablet cannot be created on this log stream.</li> <li>`DUPLICATE \| BLOCK_TABLET_IN`: The current broadcast log stream does not allow creating tablets.</li></ul> |
| CREATE_SCN | decimal(20,0) | NO | GTS at Log Stream Creation, in Nanoseconds |

## Sample query

Query the system tenant for log streams that have existed in this tenant's history.

```sshell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_LS_HISTORY;
```
