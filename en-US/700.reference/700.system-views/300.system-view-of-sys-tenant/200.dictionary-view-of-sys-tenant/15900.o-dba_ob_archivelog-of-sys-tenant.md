# oceanbase.DBA_OB_ARCHIVELOG

## Overview

Displays the [Log Archiving](../../../../600.manage/600.backup-and-recovery/300.log-archive/100.overview-of-log-archive.md) status for each path in the tenant. The `sys` and Meta tenants do not support physical backup.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --- | --- | --- | --- |
| DEST_ID | bigint(20) | NO | Path Identifier |
| ROUND_ID | bigint(20) | NO | Indicates the round of backup. |
| INCARNATION | bigint(20) | NO | Indicates the number of forks after a flashback database operation. |
| DEST_NO | bigint(20) | NO | Identifier log_archive_dest_n |
| STATUS | varchar(64) | NO | Archive Status: <ul><li>`PREPARE`: The starting point for archiving. `START_SCN`</li> <li>`BEGINNING`: Starting log archiving  </li> <li>`DOING`: Archiving logs in progress. </li><li>`INTERRUPTED`: Log archiving is interrupted and requires manual intervention. </li><li>`STOP`: Log archiving has stopped.  </li><li>`STOPPING`: Stopping log archiving  </li><li>`SUSPENDING`: Pausing log archiving  </li><li>`SUSPEND`: Log archiving has been paused.  </li></ul> |
| START_SCN | bigint(20) unsigned | NO | Start Backup Timestamp |
| START_SCN_DISPLAY | datetime(6) | NO | Display of START_SCN after conversion to time unit |
| CHECKPOINT_SCN | bigint(20) unsigned | NO | Current Archive Point |
| CHECKPOINT_SCN_DISPLAY | datetime(6) | NO | Display after converting CHECKPOINT_SCN to time units |
| COMPATIBLE | bigint(20) | NO | Compatibility Version |
| BASE_PIECE_ID | bigint(20) | NO | The first PIECE ID of this round |
| USED_PIECE_ID | bigint(20) | NO | PIECE ID Used in This Round |
| PIECE_SWITCH_INTERVAL | bigint(20) | NO | Piece Switching Cycle |
| UNIT_SIZE | bigint(20) | NO | The size of a log block that is compressed or encrypted during log archiving. This field is not supported at present. |
| COMPRESSION | varchar(128) | NO | Compression algorithm:<ul><li> none: no compression</li><li> lz4_1.0: the lz4_1.0 algorithm</li><li>zstd_1.3.8: the zstd_1.3.8 algorithm</li></ul>This field is not supported. |
| INPUT_BYTES | bigint(21) | NO | The amount of data read, in bytes |
| INPUT_BYTES_DISPLAY | varchar(28) | NO | Displays the converted value of INPUT_BYTES in one of the following units: MB, GB, TB, or PB. |
| OUTPUT_BYTES | bigint(21) | NO | Output data volume, in bytes |
| OUTPUT_BYTES_DISPLAY | varchar(28) | NO | Displays the converted value of OUTPUT_BYTES in one of the following units: MB, GB, TB, or PB. |
| COMPRESSION_RATIO | decimal(24,2) | NO | Compression ratio. This field is not currently supported. |
| DELETED_INPUT_BYTES | bigint(20) | NO | The amount of original data deleted, in bytes. |
| DELETED_INPUT_BYTES_DISPLAY | varchar(27) | NO | The value of DELETED_INPUT_BYTES is displayed in one of the following units: MB, GB, TB, or PB. |
| DELETED_OUTPUT_BYTES | bigint(20) | NO | The amount of valid data deleted, in bytes |
| DELETED_OUTPUT_BYTES_DISPLAY | varchar(27) | NO | The display unit after conversion for DELETED_OUTPUT_BYTES. Valid values: MB, GB, TB, and PB. |
| COMMENT | varchar(262144) | NO | Display error messages |
| PATH | varchar(2048) | NO | Archive Path |
