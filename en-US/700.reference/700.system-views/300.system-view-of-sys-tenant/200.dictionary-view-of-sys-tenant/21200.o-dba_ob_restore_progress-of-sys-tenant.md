# oceanbase.DBA_OB_RESTORE_PROGRESS

## Overview

Displays the ongoing restore tasks for the current tenant.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ------ | ------ | ------ | ------ |
| JOB_ID | bigint(20) | NO | Recovery Job ID, Corresponding to a Recovery Task |
| RESTORE_TENANT_NAME | longtext | NO | Tenant name to be restored |
| RESTORE_TENANT_ID | longtext | NO | Tenant ID to be Restored |
| BACKUP_TENANT_NAME | longtext | NO | Name of the source tenant for backup |
| BACKUP_TENANT_ID | longtext | NO | Source Tenant ID for Backup |
| BACKUP_CLUSTER_NAME | longtext | NO | Source cluster name for backup |
| BACKUP_DEST | longtext | NO | Backup set path, which refers to the data backup path and log archive path entered by the user. |
| RESTORE_OPTION | longtext | NO | Recovery options, specified by the user when initiating recovery. `restore_option` |
| RESTORE_TYPE | varchar(4096) | NO | The recovery type. <ul> <li>`FULL`: indicates full restore. </li> <li>`QUICK`: Indicates quick restore.</li></ul> |
| RESTORE_SCN | bigint(20) unsigned | NO | User-specified restore point |
| RESTORE_SCN_DISPLAY | datetime(6) | NO | The timestamp of the user-specified restore point is represented as |
| STATUS | longtext | NO | Recovery status: The recovery task status of the system tenant is inconsistent with that of the tenant being recovered. <br>System tenant:<ul><li>`CREATE_TENANT`: Create a tenant. In this phase, the system tenant creates the restored tenant. </li> <li>`WAIT_TENANT_RESTORE_FINISH`: Waiting for tenant restore to complete. </li> <li>`RESTORE_SUCCESS`: Tenant restored successfully. </li> <li>`RESTORE_FAIL`: Restore tenant failed. </li></ul> <br>Restored tenant: <ul><li>`RESTORE_PRE`: Preparation before recovery. Set the encryption information if encryption is enabled. </li> <li>`RESTORE_CREATE_INIT_LS`: Create log stream</li> <li>`RESTORE_WAIT_LS`: Waiting for log stream recovery to complete. </li> <li>`POST_CHECK`: Check tenant roles and restore to standby database. </li> <li>`UPGRADE`: Upgrade. If it is a restore across versions, the tenant will go through the upgrade process. </li> <li>`RESTORE_SUCCESS`: Recovery successful. </li> <li>`RESTORE_FAIL`: Restore failed. </li></ul> |
| START_TIMESTAMP | datetime(6) | NO | Restored Task Start Timestamp |
| BACKUP_SET_LIST | longtext | NO | List of data backup set paths to restore. Separate backup sets with commas (,). `,` Separate them with commas, for example: `file:///data/nfs/backup/data/backup_set_1_full,file:///data/nfs/backup/data/backup_set_2_inc` |
| BACKUP_PIECE_LIST | longtext | NO | List of log archive paths for dependent shards. Separate shards with commas. `,` Separate them with commas. Example: `file:///data/nfs/backup/data/backup_set_1_full,file:///data/nfs/backup/data/backup_set_2_inc` |
| RECOVER_SCN | bigint(20) unsigned | NO | The log restore point. For the sys tenant, the value of this field is `NULL` |
| RECOVER_SCN_DISPLAY | datetime(6) | NO | The timestamp of the point in time to which logs are restored. For the sys tenant, the value of this field is `NULL` |
| RECOVER_PROGRESS | decimal(6,2) | NO | The progress of log restore, with results rounded to two decimal places. For example: displays as `87.65` Indicates that the current progress is 87.65%. For the sys tenant, the value of this field is `NULL` |
| TABLET_COUNT | bigint(20) | NO | Total number of tablets to be restored. For the sys tenant, the value of this field is `NULL` |
| FINISH_TABLET_COUNT | bigint(20) | NO | Total number of restored tablets. For the sys tenant, the value of this field is `NULL` |
| RESTORE_PROGRESS | decimal(6,2) | NO | Data restore progress, rounded to two decimal places. For example: `87.65` Indicates that the current progress is 87.65%. For the sys tenant, the value of this field is `NULL` |
| TOTAL_BYTES | bigint(20) | NO | Total Bytes Restored |
| TOTAL_BYTES_DISPLAY | varchar(27) | NO | Total bytes restored, displayed in storage capacity units |
| FINISH_BYTES | bigint(20) | NO | Number of bytes restored |
| FINISH_BYTES_DISPLAY | varchar(27) | NO | Number of bytes restored, in storage capacity units |
| DESCRIPTION | longtext | NO | Specified in the restore command `DESCRIPTION` Information |
