# oceanbase.CDB_OB_SYS_VARIABLES

## Overview

The `CDB_OB_SYS_VARIABLES` view displays information about system variables for all tenants, including hidden variables that start with an underscore (_).

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ------- | ---- | -------------- | ---- |
| CREATE_TIME | timestamp(6) | NO | System Variable Creation Time |
| MODIFY_TIME | timestamp(6) | NO | System Variable Modification Time |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| NAME | varchar(128) | NO | System variable name |
| VALUE | varchar(65536) | YES | System variable value |
| MIN_VALUE | varchar(65536) | NO | Minimum Value |
| MAX_VALUE | varchar(65536) | NO | Maximum Value |
| SCOPE | varchar(16) | NO | Scope. Valid values: <ul><li>GLOBAL_ONLY: tenant-level variable.</li><li>SESSION_ONLY: session-level variable.</li><li>GLOBAL &#124; SESSION: both tenant-level and session-level variables.</li></ul> |
| INFO | varchar(4096) | NO | Description |
| DEFAULT_VALUE | varchar(65536) | YES | Default value of system variables |
| ISDEFAULT | varchar(3) | NO | Whether it is the default value. |

## Sample query

Query the system variable `ob_query_timeout` for all tenants.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_SYS_VARIABLES WHERE NAME='ob_query_timeout';
```
