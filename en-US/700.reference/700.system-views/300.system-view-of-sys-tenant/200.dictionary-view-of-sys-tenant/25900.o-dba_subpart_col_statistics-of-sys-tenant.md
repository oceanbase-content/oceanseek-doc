# oceanbase.DBA_SUBPART_COL_STATISTICS

## Overview

Displays the column statistics and histogram information for all subpartitioned tables of the current tenant.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --- | --- | --- | --- |
| OWNER | varchar(128) | NO | Owner of partitioned tables |
| TABLE_NAME | varchar(128) | NO | Table name |
| SUBPARTITION_NAME | varchar(128) | NO | Subpartitioned Table Name |
| COLUMN_NAME | varchar(128) | NO | Column name |
| NUM_DISTINCT | decimal(10,0) | NO | Number of distinct values in the column |
| LOW_VALUE | varchar(128) | NO | Minimum value of the column |
| HIGH_VALUE | varchar(128) | NO | Maximum Value of Column |
| DENSITY | decimal(10,0) | NO | Column density. If a histogram is available for COLUMN_NAME, this column shows the selectivity of values that span fewer than two endpoints in the histogram. It does not represent the selectivity of values that span two or more endpoints. If no histogram is available for COLUMN_NAME, the value in this column is 1/NUM_DISTINCT. |
| NUM_NULLS | decimal(10,0) | NO | Number of NULLs in Column |
| NUM_BUCKETS | decimal(10,0) | NO | Number of Buckets in Column Histogram |
| LAST_ANALYZED | datetime(6) | NO | Date of Last Chromatographic Column Analysis |
| SAMPLE_SIZE | decimal(10,0) | NO | Sample volume used for chromatographic column analysis |
| GLOBAL_STATS | varchar(3) | NO | Indicates whether statistics have been collected:<ul><li>YES</li><li>NO</li></ul> |
| USER_STATS | varchar(3) | NO | Indicates whether the statistics were directly entered by the user. Valid values:<ul><li>YES</li><li>NO</li></ul> |
| NOTES | varchar(80) | NO | Describes some additional attributes of statistics. For example, if the value is INCREMENTAL, global statistics are derived from summaries, meaning they are maintained incrementally. |
| AVG_COL_LEN | decimal(10,0) | NO | Average Column Length (Bytes) |
| HISTOGRAM | varchar(15) | NO | Specifies the type of histogram:<ul><li>NONE</li><li>FREQUENCY</li><li>HEIGHT BALANCED</li><li>HYBRID</li><li>TOP-FREQUENCY</li></ul> |

## Sample query

Query the column statistics of subpartitions in the partitioned table `t_subpart` of the current tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_SUBPART_COL_STATISTICS WHERE TABLE_NAME='t_subpart';
```
