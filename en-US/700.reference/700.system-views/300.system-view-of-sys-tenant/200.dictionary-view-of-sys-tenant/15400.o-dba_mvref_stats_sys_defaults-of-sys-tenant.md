# oceanbase.DBA_MVREF_STATS_SYS_DEFAULTS

## Features

The `DBA_MVREF_STATS_SYS_DEFAULTS` view displays the system-wide default values for various statistics attributes related to materialized view refresh history.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| PARAMETER_NAME | varchar(16) | NO | Parameter name<ul><li>COLLECTION_LEVEL: the level or detail of data collection.</li><li>RETENTION_PERIOD: the duration for which data is retained.</li></ul> |
| VALUE | varchar(40) | NO | System Default Value of Parameter |

## Sample query

Query the system-wide default value for refreshing historical statistics attributes of materialized views.

```shell
obclient [test_db]> SELECT * FROM oceanbase.DBA_MVREF_STATS_SYS_DEFAULTS;
```

The query result is as follows:

```shell
+------------------+---------+
| PARAMETER_NAME   | VALUE   |
+------------------+---------+
| COLLECTION_LEVEL | TYPICAL |
| RETENTION_PERIOD | 31      |
+------------------+---------+
2 rows in set (0.007 sec)
```
