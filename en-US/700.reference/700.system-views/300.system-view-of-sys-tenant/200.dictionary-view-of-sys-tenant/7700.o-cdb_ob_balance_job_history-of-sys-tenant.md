# oceanbase.CDB_OB_BALANCE_JOB_HISTORY

## Overview

Displays the load balancing operation history for all tenants.

## Columns

| **Column** | **Type** | **Is NULL** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | Tenant ID. <ul><li>1: the ID of the system tenant.  </li><li>Other values: the ID of a user tenant or meta tenant. </li></ul> |
| JOB_ID | bigint(20) | NO | CLB Work ID |
| CREATE_TIME | timestamp(6) | NO | Job Creation Time |
| FINISH_TIME | timestamp(6) | NO | Job completion time, including successful and canceled times |
| BALANCE_STRATEGY | varchar(64) | NO | Load balancing strategy name. Valid values:  <ul><li>`LS balance by migrate`: Migration balancing  </li><li>`LS balance by alter`: Modify log stream attributes for balancing.</li><li>`LS balance by expand`: Scale-out balancing </li><li>`LS balance by shrink`: Scale-down balancing </li><li>`partition balance`: Partition balancing. </li></ul> |
| JOB_TYPE | varchar(64) | NO | Task type  <ul><li>`LS_BALANCE`: Log stream balancing  </li><li>`PARTITION_BALANCE`: Partition balancing</li></ul> |
| TARGET_UNIT_NUM | bigint(20) | NO | Number of Units in Each Zone Affected by the Change |
| TARGET_PRIMARY_ZONE_NUM | bigint(20) | NO | Number of Target Changed Primary Zones |
| STATUS | varchar(64) | NO | Task status: <ul><li>`COMPLETED`: Task executed successfully. </li><li>`CANCELED`: Task canceled </li></ul> |
| COMMENT | longtext | YES | Comments |
| MAX_END_TIME | timestamp(6) | YES | Maximum End Time of Load Balancing Task |
| ZONE_UNIT_NUM_LIST | varchar(4096) | NO | Number of Units in Each Zone of the Tenant |
| PARAMETER_LIST | longtext | NO | Balancing-related parameters |

## Sample query

View the load balancing work history executed by all tenants.

```shell
obclient(root@sys)[oceanbase]> SELECT * FROM oceanbase.CDB_OB_BALANCE_JOB_HISTORY;
```
