# information_schema.GLOBAL_STATUS

## Overview

Records global server status variables for OceanSeek, including the current number of active connections and database uptime.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| ---------------- | --------------- | ---------------- | ------------- |
| VARIABLE_NAME | varchar(128) | NO | Variable name corresponding to global status |
| VARIABLE_VALUE | varchar(1024) | YES | Variable content corresponding to global status |

## Sample query

View the global server status variables and their corresponding values in OceanSeek.

```shell
obclient [oceanbase]> SELECT * FROM information_schema.GLOBAL_STATUS;
```

The query result is as follows:

```shell
+-------------------+----------------+
| VARIABLE_NAME     | VARIABLE_VALUE |
+-------------------+----------------+
| Threads_connected | 1              |
| Uptime            | 254110         |
+-------------------+----------------+
2 rows in set
```
