# oceanbase.DBA_OB_TABLET_TO_LS

## Overview

Displays a list of all tablets for the current tenant and the log stream information to which each tablet belongs.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ----------- | ------------ | ------------ | ------------------ |
| TABLET_ID | bigint(20) | NO | TABLET ID |
| LS_ID | bigint(1) | NO | Log stream ID of the tablet |

## Sample query

The system tenant queries the tablet list information of its own tenant and displays the first 5 entries.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_TABLET_TO_LS LIMIT 5;
```

The query result is as follows:

```shell
+-----------+-------+
| TABLET_ID | LS_ID |
+-----------+-------+
|         1 |     1 |
|    100001 |     1 |
|    100002 |     1 |
|    100003 |     1 |
|     50003 |     1 |
+-----------+-------+
5 rows in set
```
