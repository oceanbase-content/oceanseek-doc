# oceanbase.CDB_OB_ARCHIVELOG_SUMMARY

## Overview

Displays the historical and current log archiving status for all tenants.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| DEST_ID | bigint(20) | NO | Path number. The system assigns a unique ID to each configured path. |
| ROUND_ID | bigint(20) | NO | Identifies the round of complete clog backup data streams |
| INCARNATION | bigint(20) | NO | Indicates the number of forks after a flashback database operation. |
| DEST_NO | bigint(20) | NO | Identifies the log_archive_dest_n, for example, log_archive_dest_0 indicates that dest_no is 0, and log_archive_dest_1 indicates that dest_no is 1. |
| STATUS | varchar(64) | NO | Archiving status: <ul><li>`PREPARE`: The starting point for archiving. `START_SCN`</li> <li>`BEGINNING`: Starting log archiving  </li> <li>`DOING`: Log archiving in progress. </li><li>`INTERRUPTED`: Log archiving is interrupted and requires manual intervention. </li><li>`STOP`: Log archiving has stopped.  </li><li>`STOPPING`: Stopping log archiving  </li><li>`SUSPENDING`: Pausing log archiving  </li><li>`SUSPEND`: Log archiving has been paused.  </li></ul> |
| START_SCN | bigint(20) unsigned | NO | Start Backup Timestamp |
| START_SCN_DISPLAY | datetime(6) | NO | Display of START_SCN after conversion to time unit |
| CHECKPOINT_SCN | bigint(20) unsigned | NO | Current Archive Point |
| CHECKPOINT_SCN_DISPLAY | datetime(6) | NO | Display after converting CHECKPOINT_SCN to time units |
| COMPATIBLE | bigint(20) | NO | Compatibility Version |
| BASE_PIECE_ID | bigint(20) | NO | The first PIECE ID of this round |
| USED_PIECE_ID | bigint(20) | NO | PIECE ID Used in This Round |
| PIECE_SWITCH_INTERVAL | bigint(20) | NO | Piece Switching Cycle |
| UNIT_SIZE | bigint(20) | NO | The size of a log block that is compressed or encrypted during log archiving. This field is not supported at present. |
| COMPRESSION | varchar(128) | NO | Compression algorithm:<ul><li> none: no compression</li><li> lz4_1.0: the lz4_1.0 algorithm</li><li>zstd_1.3.8: the zstd_1.3.8 algorithm</li></ul>This field is not supported. |
| INPUT_BYTES | bigint(20) | NO | The amount of data read, in bytes |
| INPUT_BYTES_DISPLAY | varchar(27) | NO | The amount of data read, including units, for example: 798.01 MB or 5.25 GB. |
| OUTPUT_BYTES | bigint(20) | NO | Output data volume, in bytes |
| OUTPUT_BYTES_DISPLAY | varchar(27) | NO | Output data volume with units, for example: 798.01 MB or 5.25 GB |
| COMPRESSION_RATIO | decimal(23,2) | NO | Compression ratio. This field is not currently supported. |
| DELETED_INPUT_BYTES | bigint(20) | NO | The amount of original data deleted, in bytes. |
| DELETED_INPUT_BYTES_DISPLAY | varchar(27) | NO | The value of DELETED_INPUT_BYTES is displayed in one of the following units: MB, GB, TB, or PB. |
| DELETED_OUTPUT_BYTES | bigint(20) | NO | The amount of valid data deleted, in bytes |
| DELETED_OUTPUT_BYTES_DISPLAY | varchar(27) | NO | The display unit of the converted value of DELETED_OUTPUT_BYTES. Valid values: MB, GB, TB, and PB. |
| PATH | varchar(2048) | NO | Archive Path |
| COMMENT | varchar(262144) | NO | Display error prompts |
