# oceanbase.DBA_OB_ARCHIVE_DEST

## Overview

Displays the archive path configuration of the current tenant. The system tenant does not contain user data and is used for cluster management. It does not support backup and recovery, so the `sys` tenant has no archive path configured. In the `sys` tenant, the query result of this view is always empty.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --- | --- | --- | --- |
| DEST_NO | bigint(20) | NO | Identifier log_archive_dest_n |
| NAME | varchar(1024) | NO | Field name, which includes the following fields:<ul><li>`binding`: Priority mode for archiving and business operations</li> <li>`dest_id`: The ID of the destination archive.</li> <li>`path`: archive path information</li> <li>`piece_switch_interval`: The switching cycle of the Piece.</li> <li>`state`: The status of the destination archive.</li></ul> |
| VALUE | varchar(4096) | NO | `name` Field Value |
