# mysql.help_relation

## Overview

It works together with the other three tables, `mysql.help_category`, `mysql.help_topic`, and `mysql.help_keyword`, to generate help commands.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| ----------------- | ------------ | ---------------- | -------- |
| help_topic_id | bigint(20) | NO | Topic ID |
| help_keyword_id | bigint(20) | NO | Keyword ID |
