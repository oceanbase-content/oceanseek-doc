# oceanbase.CDB_OB_KV_TTL_TASK_HISTORY

## Overview

This API is used to query the historical TTL tasks of all tenants under the system tenant.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| TABLE_NAME | varchar(256) | NO | Table name |
| TABLE_ID | bigint(20) | NO | Table ID |
| TABLET_ID | bigint(20) | NO | Tablet ID |
| TASK_ID | bigint(20) | NO | Task ID, starting from 1. |
| START_TIME | timestamp(6) | NO | Task Start Time |
| END_TIME | timestamp(6) | NO | End Time |
| TRIGGER_TYPE | varchar(8) | NO | Task trigger type. Valid values: PERIODIC and USER. |
| STATUS | varchar(13) | NO | Task status. For more information, see Task status. |
| TTL_DEL_CNT | bigint(20) | NO | Based on `time_to_live` Number of Records Deleted |
| MAX_VERSION_DEL_CNT | bigint(20) | NO | Based on `MAX_VERSION` Number of Records Deleted |
| SCAN_CNT | bigint(20) | NO | Records Scanned by Task |
| RET_CODE | varchar(512) | NO | The return code of the task. |
