# oceanbase.DBA_OB_BALANCE_JOBS

## Overview

Displays the current load balancing job being executed by a tenant. A tenant can only have one load balancing job running at a time. Each load balancing job generates multiple load balancing tasks to perform specific load balancing operations.

## Columns

| **Column** | **Type** | **Is NULL** | **Description** |
| --- | --- | --- | --- |
| JOB_ID | bigint(20) | NO | CLB Work ID |
| CREATE_TIME | timestamp(6) | YES | Creation Time |
| MODIFY_TIME | timestamp(6) | YES | Information Update Time |
| BALANCE_STRATEGY | varchar(64) | NO | Load balancing strategy name. Valid values: <ul><li>`LS balance by migrate`: Migration balancing  </li><li>`LS balance by alter`: Modify log stream attributes for balancing </li><li>`LS balance by expand`: Expansion balancing </li><li>`LS balance by shrink`: Scale-down balancing </li><li>`partition balance`: Partition balancing</li></ul> |
| JOB_TYPE | varchar(64) | NO | Task type. Valid values: <ul><li>`LS_BALANCE`: Log stream balancing  </li><li>`PARTITION_BALANCE`: Partition balancing </li></ul> |
| TARGET_UNIT_NUM | bigint(20) | NO | The number of units in each zone where the target changes. The value of this field is always <code>NULL</code>. |
| TARGET_PRIMARY_ZONE_NUM | bigint(20) | NO | Number of Target Changed Primary Zones |
| STATUS | varchar(64) | NO | Task status. Valid values: <ul><li>`DOING`: The job is being executed.  </li><li>`COMPLETED`: Task executed successfully. </li><li>`CANCELING`: Canceled </li><li>`CANCELED`: Task canceled</li> <li>`SUSPEND`: Task paused</li></ul> |
| COMMENT | longtext | YES | Comments |
| MAX_END_TIME | timestamp(6) | YES | Maximum End Time of Load Balancing Task |
| ZONE_UNIT_NUM_LIST | varchar(4096) | NO | Number of Units in Each Zone of the Tenant |
| PARAMETER_LIST | longtext | NO | Balancing-related parameters |
