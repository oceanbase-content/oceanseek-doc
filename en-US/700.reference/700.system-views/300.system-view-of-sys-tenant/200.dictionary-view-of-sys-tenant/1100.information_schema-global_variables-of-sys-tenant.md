# information_schema.GLOBAL_VARIABLES

## Overview

Records information about all global variables (including hidden variables that start with an underscore (_)).

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| ---------------- | ---------------- | ---------------- | -------- |
| VARIABLE_NAME | varchar(128) | NO | Variable name |
| VARIABLE_VALUE | varchar(65536) | YES | Variable Value |

## Sample query

Check the value of the global variable `ob_trx_timeout`.

```shell
obclient [oceanbase]> SELECT * FROM information_schema.GLOBAL_VARIABLES WHERE VARIABLE_NAME='ob_trx_timeout';
```

The query result is as follows:

```shell
+----------------+----------------+
| VARIABLE_NAME  | VARIABLE_VALUE |
+----------------+----------------+
| ob_trx_timeout | 86400000000    |
+----------------+----------------+
1 row in set
```
