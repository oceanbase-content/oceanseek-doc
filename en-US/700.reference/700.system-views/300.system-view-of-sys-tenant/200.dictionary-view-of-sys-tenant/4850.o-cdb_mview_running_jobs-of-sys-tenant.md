# oceanbase.CDB_MVIEW_RUNNING_JOBS

## Overview

This view is accessible only to the system tenant and displays all current materialized view-related tasks for all tenants, including refresh tasks and MLOG cleanup tasks.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| ---------------- | ---------- | --------------------- | --------- |
| SVR_IP | varchar(46) | NO | The IP address of the node where the leader of log stream 1 resides. |
| SVR_PORT | bigint(20) | NO | Port of the node where the leader of log stream 1 resides. |
| TENANT_ID | bigint(20) | NO | Tenant ID. |
| TABLE_NAME | varchar(256) | NO | The name of the table associated with the task. <ul><li>For a refresh task: the name of the table containing the materialized view.</li><li>For an MLOG cleanup task: the name of the MLOG table.</li></ul> |
| JOB_TYPE | varchar(64) | NO | Task type. Valid values: <ul><li>INVALID</li><li>COMPLETE REFRESH</li><li>FAST REFRESH</li><li>PURGE MLOG</li></ul> |
| SESSION_ID | bigint(20) unsigned | NO | The session ID of the task initiator. |
| READ_SNAPSHOT | bigint(20) | NO | The snapshot point used by the task. |
| PARALLEL | bigint(20) | NO | The degree of parallelism of the task. |
| JOB_START_TIME | timestamp(6) | NO | The start time of the task. |
| REFRESH_ID     | bigint(20) unsigned | NO   | The ID of the current refresh task. |
