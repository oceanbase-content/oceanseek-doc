# oceanbase.CDB_OB_TABLEGROUP_SUBPARTITIONS

<main id="notice" type='explain'>
<h4>Note</h4>
<ul>
<li>The concept of partitions no longer exists for table groups. This view is no longer used. Users can query it, but the result will be empty.</li>
<li>You can query table group information through the <a href="11000.o-cdb_ob_tablegroups-of-sys-tenant.md">CDB_OB_TABLEGROUPS</a> view. For more details about table groups, see <a href="../../../300.database-object-management/400.manage-table-groups-of-mysql-mode/100.about-table-groups-of-mysql-mode.md">About table groups</a>.</li>
</ul>
</main>

## Overview

The system tenant displays the subpartition information for all tenant's partitioned table groups.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ----------------------- | --------------- | ------------ | ---------------------------------------------------------------------- |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| TABLEGROUP_NAME | varchar(128) | NO | TABLEGROUP Name |
| PARTITION_NAME | varchar(64) | NO | The name of the partition to which the subpartition belongs. |
| SUBPARTITION_NAME | varchar(64) | NO | Subpartition name of the table group |
| HIGH_VALUE | varchar(4096) | NO | The value is `NULL` |
| HIGH_VALUE_LENGTH | bigint(20) | NO | The value is `NULL` |
| PARTITION_POSITION | bigint(20) | NO | The value is `NULL` |
| SUBPARTITION_POSITION | bigint(20)    | NO         | This value is `NULL`.            |
