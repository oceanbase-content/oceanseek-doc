# CDB_MVREF_STATS_SYS_DEFAULTS

## ## Description

The `CDB_MVREF_STATS_SYS_DEFAULTS` view displays the system-wide default values for statistics attributes of materialized view refresh history.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| PARAMETER_NAME | varchar(16) | NO | Parameter name<ul><li>COLLECTION_LEVEL: the level or detail of data collection.</li><li>RETENTION_PERIOD: the duration for which data is retained.</li></ul> |
| VALUE | varchar(40) | NO | System Default Value of Parameter |

## Sample query

Query the system-wide default value for refreshing historical statistics attributes of materialized views.

```shell
obclient [test_db]> SELECT * FROM oceanbase.CDB_MVREF_STATS_SYS_DEFAULTS;
```
