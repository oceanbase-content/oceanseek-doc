# oceanbase.DBA_OB_RESOURCE_POOLS

## Overview

Displays the resource pool information for all tenants.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| -------------- | ---------------- | ------------ | ------------------------------------- |
| RESOURCE_POOL_ID | bigint(20) | NO | Unique ID of the resource pool. |
| NAME | varchar(128) | NO | Resource Pool Name |
| TENANT_ID | bigint(20) | NO | Tenant ID: <ul><li>`NULL`: Indicates that the instance does not belong to any tenant. </li><li>Valid value: The ID of the tenant to which the instance belongs. </li></ul> |
| CREATE_TIME | timestamp(6) | YES | Creation Time |
| MODIFY_TIME | timestamp(6) | YES | Last Modified At |
| UNIT_COUNT | bigint(20) | NO | Number of Units |
| UNIT_CONFIG_ID | bigint(20) | NO | Resource Specification ID of the Resource Pool |
| ZONE_LIST | varchar(8192) | NO | Zone list of the resource pool |
| REPLICA_TYPE | varchar(7) | NO | Replica types supported by the resource pool: <ul><li>`FULL`: Supports all replica types, not just full-featured replicas.</li> <li>`READONLY`: Read-only replicas only. </li> <li>`COLUMNSTORE`: Only columnstore replicas are supported.</li></ul> |

## Sample query

The system tenant can view the resource pool information of all tenants in the cluster.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_RESOURCE_POOLS;
```
