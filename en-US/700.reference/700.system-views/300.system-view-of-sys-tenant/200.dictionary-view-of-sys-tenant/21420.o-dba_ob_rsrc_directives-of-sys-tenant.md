# oceanbase.DBA_OB_RSRC_DIRECTIVES

## Overview

Displays the resource configuration parameters of the current tenant in the Resource Manager.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ------------------------------ | ----------------- | ---------------- | ----------------------- |
| PLAN | varchar(128) | NO | Resource Plan Name |
| GROUP_OR_SUBPLAN | varchar(128) | NO | Resource group name controlled by the resource plan |
| COMMENTS | varchar(2000) | YES | Comments Corresponding to Resource Plan Items |
| MGMT_P1 | bigint(20) | NO | The maximum relative CPU utilization under full system load. Default value: `100` |
| UTILIZATION_LIMIT | bigint(20) | NO | The maximum percentage of the tenant's total CPU resources that can be used by the resource group. Default value: `100`, indicating that the tenant can use all CPU resources. |
| MIN_IOPS | bigint(20) | NO | In the event of I/O contention, the reserved IOPS resources for all resource groups specified by the `MIN_IOPS` The sum of these values must not exceed 100. The default value is `0` |
| MAX_IOPS | bigint(20) | NO | The maximum IOPS resources that a resource group can use, specified for all resource groups. `MAX_IOPS` The sum of these values can exceed 100. The default value is `100` |
| WEIGHT_IOPS | bigint(20) | NO | The weight value of IOPS in case of I/O resource contention, specified for all resource groups. `WEIGHT_IOPS` The sum of these values can exceed 100. To meet the requirement, `MIN_IOPS`, `MAX_IOPS` With this setting enabled, I/O resources are allocated according to the normalized weight values. The default value is `0` |
| MAX_NET_BANDWIDTH | bigint(20) | NO | The upper limit of the network bandwidth used by the resource group. This parameter is specified for all resource groups. `MAX_NET_BANDWIDTH` The sum of these values can exceed 100. The default value is `100` |
| NET_BANDWIDTH_WEIGHT | bigint(20) | NO | The bandwidth weight in case of network resource contention, specified for all resource groups. `NET_BANDWIDTH_WEIGHT` The sum of these values can exceed 100. To meet the requirement, `MAX_NET_BANDWIDTH` If this parameter is not specified, the network bandwidth resources will be allocated according to the normalized weight. The default value is `0` |
