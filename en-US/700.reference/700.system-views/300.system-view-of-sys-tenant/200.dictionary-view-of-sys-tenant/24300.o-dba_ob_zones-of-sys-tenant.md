# oceanbase.DBA_OB_ZONES

## Overview

Displays information for all zones.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| -------- | --------------- | ------------ | ----------------------------- |
| ZONE | varchar(128) | NO | Zone Name |
| CREATE_TIME | timestamp(6) | NO | Creation Time of Zone |
| MODIFY_TIME | timestamp(6) | NO | Modified At Time of Zone |
| STATUS | varchar(4096) | NO | Status of the zone: <ul><li>`ACTIVE`: Currently active, providing services normally.</li><li>`INACTIVE`: The zone is in the STOP state.</li></ul> |
| IDC | varchar(4096) | NO | IDC Information of the Zone |
| REGION | varchar(4096) | NO | Region Information of the Zone |
| TYPE | varchar(4096) | NO | Type of zone: <ul><li>`ReadWrite`: Read/Write Zone </li><li>`Encryption`: Encrypted Zone </li></ul> |

## Sample query

The system tenant queries information about all zones in the cluster.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_ZONES;
```

The query result is as follows:

```shell
+-------+----------------------------+----------------------------+--------+------+---------+-----------+
| ZONE  | CREATE_TIME                | MODIFY_TIME                | STATUS | IDC  | REGION  | TYPE      |
+-------+----------------------------+----------------------------+--------+------+---------+-----------+
| zone1 | 2025-01-06 16:31:31.733840 | 2025-01-07 13:53:45.645465 | ACTIVE |      | region1 | ReadWrite |
+-------+----------------------------+----------------------------+--------+------+---------+-----------+
1 row in set
```
