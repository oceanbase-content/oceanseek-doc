# CDB_MVREF_CHANGE_STATS

## Description

The `CDB_MVREF_CHANGE_STATS` view displays statistics related to materialized view refreshes. These statistics show how much data changes occur on the base tables associated with each materialized view refresh, and the amount of information required to load these changed data.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| TBL_OWNER | varchar(128) | NO | Base Table Owner Name |
| TBL_NAME | varchar(128) | NO | Base Table Name |
| MV_OWNER | varchar(128) | NO | Materialized View Owner |
| MV_NAME | varchar(128) | NO | Materialized View Name |
| REFRESH_ID | bigint(20) | NO | Refresh ID |
| RETRY_ID | bigint(20) | NO | The ID of the retry batch to which this change record belongs. |
| NUM_ROWS_INS | bigint(20) | YES | Number of inserted rows |
| NUM_ROWS_UPD | bigint(20) | YES | Number of updated rows |
| NUM_ROWS_DEL | bigint(20) | YES | Number of rows deleted |
| NUM_ROWS_DL_INS | bigint(1) | NO | direct load insert rows<main id="notice" type='explain'> <h4>Note</h4><p>This field is only compatible and its default value is 0.</p></main> |
| PMOPS_OCCURRED | varchar(1) | NO | Indicates whether a partition maintenance operation (PMOP) has occurred.<ul><li>Y  </li><li>N </li><li>NULL </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>This field is only compatible with the value N by default.</p></main> |
| PMOP_DETAILS | text | NO | The details of PMOP are represented in the following format:<ul><li>TRUNCATE (low_bound, high_bound)  </li><li>EXECHANGE (low_bound, high_bound) </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>This field is only compatible and its default value is NULL.</p></main> |
| NUM_ROWS | bigint(20) | YES | Number of rows in the base table at the start of the refresh operation |

```shell
obclient [test_db]> SELECT * FROM oceanbase.CDB_MVREF_CHANGE_STATS;
```
