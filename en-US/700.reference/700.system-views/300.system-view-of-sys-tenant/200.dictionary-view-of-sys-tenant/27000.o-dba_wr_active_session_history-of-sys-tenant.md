# oceanbase.DBA_WR_ACTIVE_SESSION_HISTORY

## Overview

The `DBA_WR_ACTIVE_SESSION_HISTORY` view displays the persisted ASH data for the current tenant.

## Columns

| SESSION_TYPE | tinyint(4) | YES | SESSION type. <ul><li>N: FOREGROUND indicates a foreground session, that is, a user session.  </li><li>Y: BACKGROUND indicates a background session. </li></ul> |
| SESSION_STATE | varchar(7) | NO | Status at the time of session sampling <ul><li>`EVENT_NO == 0`: "ON CPU" indicates that the statement is currently being executed without any waits.  </li><li>`EVENT_NO ≠ 0`: "WAITING" indicates that the operation is currently waiting.
