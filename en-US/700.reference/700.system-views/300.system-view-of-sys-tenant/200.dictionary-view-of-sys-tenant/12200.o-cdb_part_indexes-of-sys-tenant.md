# oceanbase.CDB_PART_INDEXES

## Overview

Displays the partition information of all tenant's partitioned indexes.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --------------------------- | --------------- | ------------ | -------------------------------- |
| CON_ID | decimal(10,0) | NO | Tenant ID |
| OWNER | varchar(128) | NO | Partition Index Owner |
| INDEX_NAME | varchar(128) | NO | Name of partitioned index |
| TABLE_NAME | varchar(128) | NO | Name of the table associated with the index |
| PARTITIONING_TYPE | varchar(13) | NO | Partitioning method: <ul><li>HASH</li><li>RANGE</li><li>LIST</li></ul> |
| SUBPARTITIONING_TYPE | varchar(13) | NO | Subpartitioning method:<ul><li> HASH</li><li>RANGE</li><li>LIST</li></ul> |
| PARTITION_COUNT | bigint(20) | NO | Number of Partitions in Index |
| DEF_SUBPARTITION_COUNT | bigint(20) | NO | For composite partitioned indexes, the default is the number of partitions for the subpartition (if specified). |
| PARTITIONING_KEY_COUNT | bigint(21) | NO | Number of columns in the partitioning key |
| SUBPARTITIONING_KEY_COUNT | bigint(21) | NO | Number of Partitioning Keys for Subpartitions in a Composite Partition Index |
| LOCALITY | varchar(6) | NO | Is the partitioned index local or global? |
| ALIGNMENT | varchar(12) | NO | Whether the partitioned index is a prefixed or non-preixed index |
| DEF_TABLESPACE_NAME | varchar(30) | NO | For local indexes, the default tablespace when adding or splitting a table partition. |
| DEF_PCT_FREE | bigint(1) | NO | This field is not currently supported. The default value of this field is 0. |
| DEF_INI_TRANS | bigint(1) | NO | This field is not currently supported. The default value of this field is 0. |
| DEF_MAX_TRANS | bigint(1) | NO | This field is not currently supported. The default value of this field is 0. |
| DEF_INITIAL_EXTENT | varchar(40) | NO | This field is not supported. Currently, the default value of this field is NULL. |
| DEF_NEXT_EXTENT | varchar(40) | NO | This field is not supported. Currently, the default value of this field is NULL. |
| DEF_MIN_EXTENTS | varchar(40) | NO | This field is not supported. Currently, the default value of this field is NULL. |
| DEF_MAX_EXTENTS | varchar(40) | NO | This field is not supported. Currently, the default value of this field is NULL. |
| DEF_MAX_SIZE | varchar(40) | NO | This field is not supported. Currently, the default value of this field is NULL. |
| DEF_PCT_INCREASE | varchar(40) | NO | This field is not supported. Currently, the default value of this field is NULL. |
| DEF_FREELISTS | bigint(1) | NO | This field is not currently supported. The default value of this field is 0. |
| DEF_FREELIST_GROUPS | bigint(1) | NO | This field is not currently supported. The default value of this field is 0. |

| DEF_BUFFER_POOL | varchar(7) | NO | This field is not supported. Currently, the default value of this field is NULL. |

| DEF_PARAMETERS | text | NO | This field is not supported. Currently, the default value of this field is NULL. |
| INTERVAL | text | NO | This field is not currently supported. The default value of this field is `NO` |
| AUTOLIST | varchar(3) | NO | Indicates whether the local index uses automatic list partitioning:<ul><li>YES</li><li>NO</li></ul> |
| INTERVAL_SUBPARTITION | text | NO | This field is not supported. Currently, the default value of this field is NULL. |
| AUTOLIST_SUBPARTITION | text | NO | This field is not supported. Currently, the default value of this field is NULL. |

## Sample query

In the sys tenant, query the partition information of the internal partition index `tbl1_h_idx1` with tenant ID 1002.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_PART_INDEXES WHERE CON_ID=1002 AND INDEX_NAME='tbl1_h_idx1'\G
```
