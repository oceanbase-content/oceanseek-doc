# oceanbase.CDB_OB_AI_GATEWAYS

<main id="notice" type='explain'>
    <h4>Note</h4>
    <p>This view is available starting with V4.6.2.1. </p>
</main>

## Overview

Displays the AI gateway (Gateway) configuration information for all tenants. It is commonly used to view the multi-endpoint routing and weight configurations created by each tenant using the `CREATE_AI_GATEWAY` PL procedure under the sys tenant.

## Columns

| field | Type | Is NULL | Description |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | YES | Tenant ID. |
| GATEWAY_NAME | varchar(256) | NO | Gateway name. |
| ENDPOINTS | varchar(32767) | NO | JSON list of endpoint routes. Each item contains `name`, `model`, `weight` fields, `model` is `provider/model` format. |
| CIRCUIT_BREAKER | varchar(4096) | YES | JSON configuration for gateway-level circuit breaking. |
| CREATE_TIME | timestamp(6) | NO | Creation time. |
| UPDATE_TIME | timestamp(6) | NO | Last modified at. |

## Sample query

Query the AI gateway configuration information of all tenants in the system tenant.

1. Register the vendor configuration and create a gateway in the user tenant (replace `access_key` and `base_url` with actual values):

    ```shell
    CALL DBMS_AI_SERVICE.REGISTER_PROVIDER('test-provider', '{
    "protocol": "openai",
    "base_url": "https://xxx",
    "access_key": "sk-xxx"
    }');
    CALL DBMS_AI_SERVICE.CREATE_AI_GATEWAY('test', '{
    "endpoints": [
        {"name":"ep1","model":"test-provider/test-model","weight":70},
        {"name":"ep2","model":"test-provider/test-model2","weight":30}
    ]
    }');
    ```

2. Query in the sys tenant:

    ```sql
    SELECT TENANT_ID, GATEWAY_NAME, ENDPOINTS, CIRCUIT_BREAKER
    FROM oceanbase.CDB_OB_AI_GATEWAYS
    WHERE GATEWAY_NAME = 'test';
    ```

    The sample result is as follows:

    ```shell
    TENANT_ID	GATEWAY_NAME	ENDPOINTS	CIRCUIT_BREAKER
    1004	    test	[{"name": "ep1", "model": "test-provider/test-model", "weight": 70}, {"name": "ep2", "model": "test-provider/test-model2", "weight": 30}]	NULL
    1 row in set
    ```

<main id="notice" type='explain'>
    <h4>Note</h4>
    <p>To troubleshoot routing configurations by endpoint, query the <code>CDB_OB.AI_GATEWAY_ENDPOINTS</code> view.</p>
</main>
