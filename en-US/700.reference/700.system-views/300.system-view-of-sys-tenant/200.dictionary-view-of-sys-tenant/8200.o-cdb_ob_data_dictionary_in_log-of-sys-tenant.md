# oceanbase.CDB_OB_DATA_DICTIONARY_IN_LOG

## Overview

Records the position range of the data dictionary in the system log stream to facilitate CDC consumption of the data dictionary.

## Columns

| **Column** | **Type** | **Is NULL** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | Tenant ID.<ul><li> 1: system tenant ID.  </li><li> Other values: user tenant ID. </li></ul> |
| SNAPSHOT_SCN | bigint(20) unsigned | NO | SNAPSHOT SCN of the corresponding tenant during data dictionary generation |
| REPORT_TIME | timestamp(6) | NO | Time taken to report the generated data dictionary to the internal table (in microseconds) |
| START_LSN | bigint(20) unsigned | NO | LSN of the first log persisted in tenant log stream 1 |
| END_LSN | bigint(20) unsigned | NO | LSN of the last log persisted in tenant log stream 1 |

## Sample query

The system tenant queries the data dictionary of all user tenants for the location range in the system log stream.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_DATA_DICTIONARY_IN_LOG;
```

The query result is as follows:

```shell
+-----------+---------------------+----------------------------+-----------+----------+
| TENANT_ID | SNAPSHOT_SCN        | REPORT_TIME                | START_LSN | END_LSN  |
+-----------+---------------------+----------------------------+-----------+----------+
|      1002 | 1722408567371559602 | 2024-07-31 14:49:27.420098 |   9118467 |  9118467 |
|      1004 | 1722408697334096435 | 2024-07-31 14:51:37.373029 |  13706567 | 13706567 |
+-----------+---------------------+----------------------------+-----------+----------+
2 rows in set
```
