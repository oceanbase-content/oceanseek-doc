# oceanbase.CDB_OB_SERVICES

## Overview

The `CDB_OB_SERVICES` view displays information about all `SERVICE_NAME` entries under all tenants.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --------------------------- | --------------- | ---------------- | -------- |
| TENANT_ID | bigint(20) | NO | Tenant ID, including the user tenant ID. |
| CREATE_TIME | timestamp(6) | NO | The time when the service was created. |
| MODIFIED_TIME | timestamp(6) | NO | The update time of service-related information. |
| SERVICE_NAME_ID | bigint(20) | NO | Service name ID, which uniquely identifies the service name. |
| SERVICE_NAME | varchar(64) | NO | Service name. |
| SERVICE_STATUS | varchar(64) | NO | Service status. Valid values: <ul><li>STARTED: The service is started.</li><li>STOPPING: The service is being stopped.</li><li>STOPPED: The service is stopped.</li></ul> |

## Sample query

Query information about all `SERVICE_NAME` instances under all tenants.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_SERVICES;
```

The query result is as follows:

```shell
+-----------+----------------------------+----------------------------+-----------------+------------------+----------------+
| TENANT_ID | CREATE_TIME                | MODIFIED_TIME              | SERVICE_NAME_ID | SERVICE_NAME     | SERVICE_STATUS |
+-----------+----------------------------+----------------------------+-----------------+------------------+----------------+
|      1002 | 2024-06-18 14:18:36.405999 | 2024-06-18 14:18:36.405999 |               3 | service_mysql001 | STARTED        |
+-----------+----------------------------+----------------------------+-----------------+------------------+----------------+
1 row in set
```
