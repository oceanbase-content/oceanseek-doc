# oceanbase.DBA_OB_CONCURRENT_LIMIT_SQL

## Overview

Displays the throttling rule outline information of the current tenant.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --- | --- | --- | --- |
| CREATE_TIME | timestamp(6) | YES | Creation Timestamp |
| MODIFY_TIME | timestamp(6) | YES | Modified Timestamp |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| DATABASE_ID | bigint(20) | NO | Database ID |
| OUTLINE_ID | bigint(20) | NO | Throttling Rule Outline ID |
| DATABASE_NAME | varchar(128) | NO | Database Name |
| OUTLINE_NAME | varchar(128) | NO | Throttling Rule Outline Name |
| OUTLINE_CONTENT | longtext | NO | The content of the outline corresponding to the throttling rule. It can be empty. |
| VISIBLE_SIGNATURE | longtext | NO | Deserialized Signature Result |
| SQL_TEXT | longtext | NO | SQL statement specified in the ON clause when creating a rate-limiting rule outline |
| CONCURRENT_NUM | bigint(20) | NO | Current SQL Concurrency Limit |
| LIMIT_TARGET | longtext | NO | SQL Statements Subject to Throttling |

Query the throttling rule outline information of the current tenant.

```shell
obclient[oceanbase]>  SELECT * FROM oceanbase.DBA_OB_CONCURRENT_LIMIT_SQL\G
```
