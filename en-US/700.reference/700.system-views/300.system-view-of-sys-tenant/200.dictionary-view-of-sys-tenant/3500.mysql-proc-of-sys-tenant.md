# mysql.proc

## Overview

Displays information about stored procedures.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| ---------------------- | ------------------ | ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| db | varchar(128) | NO | Database Name |
| name | varchar(128) | NO | The name of the stored procedure. |
| type | varchar(10) | NO | Types of stored procedures:<ul><li>PROCEDURE: stored procedure.</li><li>FUNCTION: stored function.</li></ul> |
| specific_name | varchar(128) | NO | Same as the name field. |
| language | varchar(4) | NO | Not used. The current value is a fixed SQL statement. |
| sql_data_access | varchar(32) | NO | Not used. The current value is CONTAINS_SQL. |
| is_deterministic | varchar(4) | NO | Not used. Indicates whether the stored procedure enables `DETERMINISTIC` Feature definition: <ul><li>YES</li><li>NO</li></ul> |
| security_type | varchar(10) | NO | Not used. Identifies the access attributes of the SQL statement:<ul><li> DEFINER   </li><li> INVOKER   </li></ul> |
| param_list | longblob | NO | Parameter list information of the stored procedure |
| returns | longblob | NO | Return value information of stored procedures |
| body | longblob | NO | Text information defining the stored procedure |
| definer | varchar(77) | NO | User who created the stored procedure |
| created | timestamp(6) | NO | Date and Time of Stored Procedure Creation |
| modified | timestamp(6) | NO | Last modified date and time of the stored procedure |
| sql_mode | text | NO | The SQL mode that is valid when creating or altering the stored procedure, and in which the stored procedure is executed. |
| comment | varchar(4096) | NO | Comment text |
| character_set_client | varchar(128) | NO | Session value of the character_set_client system variable when creating or altering a stored procedure |
| collation_connection | varchar(128) | NO | Session value of the collation_connection system variable when creating or altering a stored procedure |
| collation_database | varchar(128) | NO | Session value of collation_database system variable when creating or altering a stored procedure |
| body_utf8 | longblob | NO | Procedure definition, which is the same as the body field. |

## Sample query

View the details of the stored procedure `my_proc`.

```shell
obclient [infotest]> SELECT * FROM mysql.proc WHERE NAME='my_proc'\G
```
