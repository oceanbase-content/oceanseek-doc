# oceanbase.DBA_OB_TENANT_FLASHBACK_LOG_SCN

## Overview

The `DBA_OB_TENANT_flashBACK_LOG_SCN` view displays information about each log truncation for the current tenant.

## Columns

| field | Type | Is NULL | Description |
| ------------------- | -------------- | ------------- | ------------------------------------------ |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| TIMESTAMP | timestamp(6) | NO | Creation time, in microseconds |
| SWITCHOVER_EPOCH | bigint(20) | NO | Tenant role switched to `NORMAL` When the status is `SWITCHOVER_EPOCH`. `SWITCHOVER_EPOCH` is a flag used to identify tenant role switchover/Failover is the unique identifier of the operation. |
| OP_TYPE | varchar(64) | NO | Operation type. Valid values: <ul><li>`FAILOVER_TO_PRIMARY`: The type of failover operation. It specifies the operation to switch the standby tenant to the primary tenant when the primary tenant is unavailable.</li><li>`FLASHBACK_STANDBY_LOG`: The type of log trimming operation for the standby tenant, used to trim the standby tenant's logs to a specified SCN position.</li></ul> |
| FLASHBACK_LOG_SCN | bigint(20) unsigned | NO | End Point for Trimming Tenant Logs from Back to Front |

## Sample query

Query information about each log trimming operation in the current tenant.

```shell
obclient(root@sys)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_TENANT_FLASHBACK_LOG_SCN;
```
