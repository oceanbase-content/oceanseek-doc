# oceanbase.CDB_OB_CS_REPLICA_STATS

## Overview

Displays the progress of converting tablets to columnar storage in the log streams of C replicas on each OBServer node for all tenants.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --------------------------- | --------------- | --------------------- | ------------------------------------- |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| SVR_IP | varchar(46) | NO | IP address of the server where the leader replica resides |
| SVR_PORT | bigint(20) | NO | Port number of the server where the follower replica resides |
| LS_ID | bigint(20) | NO | Log Stream ID |
| TOTAL_TABLET_CNT | bigint(20) | NO | Number of Partitions to Convert to Columnar Storage |
| AVAILABLE_TABLET_CNT | decimal(42,0) | NO | Number of Available Partitions |
| TOTAL_MACRO_BLOCK_CNT | decimal(42,0) | NO | Total Baseline Macroblocks (without Multi-Versioning) |
| AVAILABLE_MACRO_BLOCK_CNT | decimal(42,0) | NO | Number of Available Baseline Macroblocks (Excluding Multi-Version) |
| AVAILABLE | varchar(5) | NO | Whether the log stream is fully available: <ul><li>`TRUE`: Available. A log stream is fully available only when all tablets on it are available.</li> <li>`FALSE`: Not available</li></ul> |

## Sample query

The system tenant queries the progress of converting tablets to columnar storage in the log streams of replica C on each OBServer node for the tenant with ID 1004.

```shell
obclient[oceanbase]> SELECT * FROM oceanbase.CDB_OB_CS_REPLICA_STATS WHERE TENANT_ID=1004;
```

The query result is as follows:

```shell
+-----------+----------------+----------+-------+------------------+----------------------+-----------------------+---------------------------+-----------+
| TENANT_ID | SVR_IP         | SVR_PORT | LS_ID | TOTAL_TABLET_CNT | AVAILABLE_TABLET_CNT | TOTAL_MACRO_BLOCK_CNT | AVAILABLE_MACRO_BLOCK_CNT | AVAILABLE |
+-----------+----------------+----------+-------+------------------+----------------------+-----------------------+---------------------------+-----------+
|      1004 | xx.xxx.xxx.212 |    63000 |  1001 |             1019 |                 1019 |                 10706 |                     10706 | TRUE      |
+-----------+----------------+----------+-------+------------------+----------------------+-----------------------+---------------------------+-----------+
1 row in set
```

Based on the query results, you can calculate the value of `AVAILABLE_TABLET_CNT / TOTAL_TABLET_CNT` or `AVAILABLE_MACRO_BLOCK_CNT / TOTAL_MACRO_BLOCK_CNT` to roughly estimate the progress of converting row-based storage to columnar storage.
