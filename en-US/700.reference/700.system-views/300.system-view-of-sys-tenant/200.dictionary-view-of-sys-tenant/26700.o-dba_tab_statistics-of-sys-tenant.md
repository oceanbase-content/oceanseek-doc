# oceanbase.DBA_TAB_STATISTICS

## Overview

Displays the optimizer statistics for all tables in the current tenant.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --- | --- | --- | --- |
| OWNER | varchar(128) | NO | User to Which Entity Belongs |
| TABLE_NAME | varchar(128) | NO | Table name |
| PARTITION_NAME | varchar(128) | NO | Partition name |
| PARTITION_POSITION | decimal(10,0) | NO | Location of partitions in the table |
| SUBPARTITION_NAME | varchar(128) | NO | Subpartition name |
| SUBPARTITION_POSITION | decimal(10,0) | NO | Location of Subpartition within Partition |
| OBJECT_TYPE | varchar(12) | NO | Entity type |
| NUM_ROWS | decimal(10,0) | NO | Number of rows in the entity |
| BLOCKS | decimal(10,0) | NO | This field is not supported. Currently, the default value of this field is NULL. |
| EMPTY_BLOCKS | decimal(10,0) | NO | This field is not supported. Currently, the default value of this field is NULL. |
| AVG_SPACE | decimal(10,0) | NO | This field is not supported. Currently, the default value of this field is NULL. |
| CHAIN_CNT | decimal(10,0) | NO | This field is not supported. Currently, the default value of this field is NULL. |
| AVG_ROW_LEN | decimal(10,0) | NO | Average Row Length of Entities |
| AVG_SPACE_FREELIST_BLOCKS | decimal(10,0) | NO | This field is not supported. Currently, the default value of this field is NULL. |
| NUM_FREELIST_BLOCKS | decimal(10,0) | NO | This field is not supported. Currently, the default value of this field is NULL. |
| AVG_CACHED_BLOCKS | decimal(10,0) | NO | This field is not supported. Currently, the default value of this field is NULL. |

| IM_IMCU_COUNT | decimal(10,0) | NO | This field is not supported. Currently, the default value of this field is NULL. |
| IM_BLOCK_COUNT | decimal(10,0) | NO | This field is not supported. Currently, the default value of this field is NULL. |
| IM_STAT_UPDATE_TIME | datetime | NO | This field is not supported. Currently, the default value of this field is NULL. |
| SCAN_RATE | decimal(10,0) | NO | This field is not supported. Currently, the default value of this field is NULL. |
| SAMPLE_SIZE | decimal(10,0) | YES | Sampling Size for Statistics Collection |
| LAST_ANALYZED | datetime(6) | NO | Last Analysis Time |
| GLOBAL_STATS | varchar(3) | NO | <ul><li>`YES`: Indicates that statistics are directly collected or incrementally maintained.   </li><li>`NO`: Other cases</li></ul> |

| STATTYPE_LOCKED | varchar(5) | NO | Statistics Lock Type |

| SCOPE | varchar(7) | NO | Effective Range of Statistics |

