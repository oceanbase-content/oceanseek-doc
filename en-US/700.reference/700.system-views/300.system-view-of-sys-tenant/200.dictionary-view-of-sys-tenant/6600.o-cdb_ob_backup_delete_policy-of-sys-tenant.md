# oceanbase.CDB_OB_BACKUP_DELETE_POLICY

## Overview

Displays the cleanup strategies set for expiration cleanup and automatic cleanup under each tenant.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| POLICY_NAME | varchar(256) | NO | Cleanup Policy Name: <ul><li>`default`: Indicates that the current tenant will be automatically cleaned up. `DATA_BACKUP_DEST` and `LOG_ARCHIVE_DEST` The backup in the parameter. </li> <li>`log_only`: Indicates that the logs in the archive path specified by the `LOG_ARCHIVE_DEST` parameter are automatically cleaned up.</li></ul> |
| RECOVERY_WINDOW | varchar(64) | NO | Restorable Time Window. Default value: 0. |

## Sample query

The sys tenant can view the cleanup strategies of all tenants.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_BACKUP_DELETE_POLICY;
```

The query result is as follows:

```shell
+-----------+-------------+-----------------+
| TENANT_ID | POLICY_NAME | RECOVERY_WINDOW |
+-----------+-------------+-----------------+
|      1002 | default     | 7d              |
+-----------+-------------+-----------------+
1 row in set
```
