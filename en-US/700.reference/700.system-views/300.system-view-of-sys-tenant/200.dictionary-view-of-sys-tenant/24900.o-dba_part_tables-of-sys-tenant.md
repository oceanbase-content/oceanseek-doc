# oceanbase.DBA_PART_TABLES

## Overview

Displays the partition information of the partitioned tables for the current tenant.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --------------------------- | --------------- | ------------ | -------------------------------- |
| OWNER | varchar(128) | NO | Owner of partitioned tables |
| TABLE_NAME | varchar(128) | NO | Name of the partitioned table |
| PARTITIONING_TYPE | varchar(13) | NO | Partitioning method: <ul><li> HASH </li><li> RANGE  </li><li> LIST</li></ul> |
| SUBPARTITIONING_TYPE | varchar(13) | NO | Subpartitioning method:<ul><li> HASH </li><li> RANGE </li><li> LIST </li></ul> |
| PARTITION_COUNT | bigint(20) | NO | Number of Partitions in Partitioned Tables |
| DEF_SUBPARTITION_COUNT | bigint(20) | NO | For a composite partitioned table, indicates the number of subpartitions. |
| PARTITIONING_KEY_COUNT | bigint(21) | NO | Number of Partitioning Keys |
| SUBPARTITIONING_KEY_COUNT | bigint(21) | NO | For a composite partitioned table, indicates the number of subpartitioning keys. |
| STATUS | varchar(8) | NO | This field is not currently supported. The default value of this field is NULL. |
| DEF_TABLESPACE_NAME | varchar(30) | NO | Tablespace name of the partitioned table |
| DEF_PCT_FREE | bigint(0) | NO | This field is not currently supported. The default value of this field is NULL. |
| DEF_PCT_USED | bigint(0) | NO | This field is not currently supported. The default value of this field is NULL. |

| REF_PTN_CONSTRAINT_NAME | varchar(30) | NO | This field is not currently supported. The default value of this field is NULL. |

| AUTOLIST | varchar(3) | NO | Indicates whether the table uses automatic list partitioning:<ul><li>YES</li><li>NO</li></ul> |
| INTERVAL_SUBPARTITION | text | NO | String of Subinterval Boundaries |
