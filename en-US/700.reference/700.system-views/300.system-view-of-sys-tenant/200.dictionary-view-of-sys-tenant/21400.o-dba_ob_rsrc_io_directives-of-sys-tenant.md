# oceanbase.DBA_OB_RSRC_IO_DIRECTIVES

<main id="notice" type='explain'>
<h4>Note</h4>
<p>In the current version, we recommend that you use the <a href="21420.o-dba_ob_rsrc_directives-of-sys-tenant.md">DBA_OB_RSRC_DIRECTIVES</a> view to view the resource configuration parameters of a tenant in the Resource Manager.</p>
</main>

## Overview

Displays the I/O resource configuration in the resource manager.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| PLAN | varchar(128) | NO | Resource Plan Name of the Statement |
| GROUP_OR_SUBPLAN | varchar(128) | NO | Resource group name controlled by directives |
| COMMENTS | varchar(2000) | YES | Resource Plan Remarks |
| MIN_IOPS | bigint(20) | NO | When an I/O contention occurs, the reserved IOPS resources of the resource group, all resource groups specified `MIN_IOPS` The sum of the values in the  column must not exceed 100. The default value is `0` |
| MAX_IOPS | bigint(20) | NO | The maximum IOPS resources that a resource group can use, specified for all resource groups. `MAX_IOPS` The sum of these values can exceed 100. The default value is `100` |
| WEIGHT_IOPS | bigint(20) | NO | The weight value of IOPS in case of I/O resource contention, specified for all resource groups. `WEIGHT_IOPS` The sum of these values can exceed 100. To meet the requirement of `MIN_IOPS`, `MAX_IOPS` With this setting enabled, I/O resources will be allocated according to the normalized weight values. The default value is `0` |

## Sample query

Query the I/O resource configuration in the resource manager of the current tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_RSRC_IO_DIRECTIVES;
```

The query result is as follows:

```shell
+---------+------------------+----------+----------+----------+-------------+
| PLAN    | GROUP_OR_SUBPLAN | COMMENTS | MIN_IOPS | MAX_IOPS | WEIGHT_IOPS |
+---------+------------------+----------+----------+----------+-------------+
| daytime | batch_group      |          |       40 |       80 |          70 |
+---------+------------------+----------+----------+----------+-------------+
1 row in set
```
