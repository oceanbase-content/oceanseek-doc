# information_schema.VIEWS

## Overview

Records view information.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| ---------------------- | ---------------- | ------------ | --------------------------------------------- |
| TABLE_CATALOG | varchar(64) | NO | Table of Contents |
| TABLE_SCHEMA | varchar(128) | NO | Database Name |
| TABLE_NAME | varchar(256) | NO | View name |
| VIEW_DEFINITION | longtext | NO | View definition |
| CHECK_OPTION | varchar(8) | NO | Check Options |
| IS_UPDATABLE | varchar(3) | NO | Updatable |
| DEFINER | varchar(288) | NO | Username for creating the view |
| SECURITY_TYPE | varchar(7) | NO | Security Type |
| CHARACTER_SET_CLIENT | varchar(64) | NO | The value of the character_set_client session variable at the time the view was created. |
| COLLATION_CONNECTION | varchar(64) | NO | The value of the collation_connection session variable at the time the view was created. |
