# oceanbase.CDB_OB_BALANCE_TASKS

## Overview

Displays all current load balancing tasks being executed by tenants.

## Columns

| **Column** | **Type** | **Is NULL** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | Tenant ID<ul><li>1: System tenant ID.  </li><li>Other values: User tenant or Meta tenant ID. </li></ul> |
| TASK_ID | bigint(20) | NO | Load balancing task ID |
| CREATE_TIME | timestamp(6) | YES | Creation Time |
| MODIFY_TIME | timestamp(6) | YES | Information Update Time |
| TASK_TYPE | varchar(64) | NO | Task type. Valid values: <ul><li>`LS_SPLIT`: Log stream split  </li><li>`LS_ALTER`: Modify log stream attributes</li><li>`LS_MERGE`: Log stream major compaction </li><li>`LS_TRANSFER`: Log Stream Transfer </li></ul> |
| SRC_LS | bigint(20) | NO | Source log stream (the log data stream generated from the data source) |
| DEST_LS | bigint(20) | NO | Destination log stream |
| PART_LIST | longtext | YES | Partition list, including: user table partitions and global index partitions |
| FINISHED_PART_LIST | longtext | YES | List of Partitions That Have Completed Load Balancing |
| PART_COUNT | bigint(20) | YES | Number of Partitions in the Partition List |
| FINISHED_PART_COUNT | bigint(20) | YES | Number of Partitions with Load Balancing Completed |
| LS_GROUP_ID | bigint(20) | NO | Log Stream Group ID |
| STATUS | varchar(64) | NO | Task status <ul><li>`INIT`: Task creation  </li><li>`CREATE_LS`: Create log stream</li><li>`ALTER_LS`: Modify log stream attributes</li> <li>`TRANSFER`: Transfer between log streams</li> <li>`SET_LS_MERGING`: Log stream major compaction</li><li>`DROP_LS`: Delete log stream</li><li>`COMPLETED`: Task executed successfully. </li><li>`CANCELED`: Task canceled </li></ul> |
| PARENT_LIST | varchar(1024) | YES | Parent Task List |
| CHILD_LIST | varchar(1024) | YES | Subtask List |
| CURRENT_TRANSFER_TASK_ID | bigint(20) | NO | The ID of the transfer task triggered by the current load balancing task. |
| JOB_ID | bigint(20) | NO | Job ID of the current task |
| COMMENT | longtext | YES | Comments |
| BALANCE_STRATEGY | varchar(64) | YES | The balancing strategy corresponding to the balance task:<ul><li>`LS balance by migrate`: Migration balancing  </li><li>`LS balance by alter`: Modify log stream attributes for balancing.</li><li>`LS balance by expand`: Expansion balancing </li><li>`LS balance by shrink`: Scale-down balancing </li><li>`partition balance`: Partition balancing. </li></ul> |

View all current load balancing tasks being executed by tenants.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_BALANCE_TASKS\G
```
