# oceanbase.DBA_SQL_PLAN_BASELINES

## Overview

Displays the plan baseline for SQL statements in the SPM of the current tenant.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --- | --- | --- | --- |
| SIGNATURE | bigint(20) unsigned | NO | SQL Unique Identifier Generated by Normalized SQL |
| SQL_HANDLE | varchar(32) | NO | Unique SQL Text |
| SQL_TEXT | longtext | NO | Unnormalized SQL text |
| PLAN_NAME | varchar(128) | NO | Unique text-based plan identifier |
| CREATOR | varchar(128) | NO | User who created this plan baseline |
| ORIGIN | varchar(29) | NO | Methods for creating a plan baseline: <ul><li>MANUAL-LOAD</li><li>AUTO-CAPTURE</li><li>MANUAL-SQLTUNE</li><li>AUTO-SQLTUNE</li></ul> |
| PARSING_SCHEMA_NAME | varchar(128) | NO | This field is not currently supported and defaults to NULL. |
| DESCRIPTION | varchar(500) | YES | Description of the plan baseline |
| VERSION | varchar(256) | NO | Database version at the time of baseline creation |
| CREATED | timestamp(6) | YES | Creation Time of Plan Baseline |
| LAST_MODIFIED | timestamp(6) | YES | Last modification time of the plan baseline |
| LAST_EXECUTED | bigint(20) | NO | Last execution time of the plan baseline |
| LAST_VERIFIED | bigint(20) | NO | Last verification time on the baseline plan |
| ENABLED | varchar(3) | NO | Indicates whether the plan baseline is enabled. Valid values: <ul><li>YES</li><li>NO</li></ul> |
| ACCEPTED | varchar(3) | NO | Indicates whether the plan baseline is adopted. Valid values:<ul><li>YES</li><li>NO</li></ul> |
| FIXED | varchar(3) | NO | Specifies whether the plan baseline is fixed. Valid values: <ul><li>YES</li><li>NO</li></ul> |
| REPRODUCED | varchar(3) | NO | Indicates whether the plan baseline can be reproduced:<ul><li>YES</li><li>NO</li></ul> |
| AUTOPURGE | varchar(3) | NO | Specifies whether to automatically clean up the plan baseline. Valid values: <ul><li>YES</li><li>NO</li></ul> |
| ADAPTIVE | varchar(3) | NO | Indicates whether the plan baseline automatically captured by SPM has been adapted:<ul><li>YES</li><li>NO</li></ul> |
| OPTIMIZER_COST | bigint(20) | NO | Planned Cost Estimated by the Optimizer During Baseline Creation |
| MODULE | varchar(64) | NO | This field is not currently supported and defaults to NULL. |
| ACTION | varchar(64) | NO | This field is not currently supported and defaults to NULL. |
| EXECUTIONS | bigint(20) | NO | Number of Plan Executions at the Time of Baseline Creation |
| ELAPSED_TIME | bigint(20) | NO | Total Time Spent on the Plan at Baseline Creation |
| CPU_TIME | bigint(20) | NO | Total CPU Time of Plans at the Time of Baseline Creation |
| BUFFER_GETS | bigint(0) | NO | This field is not currently supported and defaults to NULL. |
| DISK_READS | bigint(0) | NO | This field is not currently supported and defaults to NULL. |
| DIRECT_WRITES | bigint(0) | NO | This field is not currently supported and defaults to NULL. |
| ROWS_PROCESSED | bigint(0) | NO | This field is not currently supported and defaults to NULL. |
| FETCHES | bigint(0) | NO | This field is not currently supported and defaults to NULL. |
| END_OF_FETCH_COUNT | bigint(0) | NO | This field is not currently supported and defaults to NULL. |
