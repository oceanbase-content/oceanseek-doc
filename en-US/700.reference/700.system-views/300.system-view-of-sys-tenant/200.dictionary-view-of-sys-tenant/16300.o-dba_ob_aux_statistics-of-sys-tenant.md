# DBA_OB_AUX_STATISTICS

## Overview

The `DBA_OB_AUX_STATISTICS` view displays auxiliary statistics for each tenant.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| --------------------------- | -------------- | ---------------------- | ----------- |
| LAST_ANALYZED | timestamp(6) | NO | Timestamp of the last statistics collection |
| CPU_SPEED(MHZ) | bigint(20) | YES | The current CPU frequency of the environment, in MHz. |
| DISK_SEQ_READ_SPEED(MB/S) | bigint(20) | YES | Sequential read rate of the hard disk, in MB/s |
| DISK_RND_READ_SPEED(MB/S) | bigint(20) | YES | The random read rate of the disk, in MB/s. |
| NETWORK_SPEED(MB/S) | bigint(20) | YES | Network transfer rate, in MB/s |

## Sample query

1. Manually enable auxiliary statistics collection:

   ```shell
   obclient [oceanbase]> CALL dbms_stats.gather_system_stats();
   ```

2. Query auxiliary statistics of a tenant:

   ```shell
   obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_AUX_STATISTICS;
   ```

3. The query result is as follows:

   ```shell
   ------------------------+----------------+---------------------------+---------------------------+---------------------+
   | LAST_ANALYZED              | CPU_SPEED(MHZ) | DISK_SEQ_READ_SPEED(MB/S) | DISK_RND_READ_SPEED(MB/S) | NETWORK_SPEED(MB/S) |
   +----------------------------+----------------+---------------------------+---------------------------+---------------------+
   | 2024-03-14 11:36:55.196214 |           2500 |                      3257 |                       407 |                1250 |
   +----------------------------+----------------+---------------------------+---------------------------+---------------------+
   1 row in set (0.002 sec)
   ```
