# oceanbase.CDB_OB_BACKUP_SET_FILES

## Overview

Displays the file status of backup sets for each tenant.

## Columns

| Field Name | Field Name | Whether can be NULL | Field Name |
| ------------------------------- | ---------------- | ----------------- | ---------------------------------- |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| BACKUP_SET_ID | bigint(20) | NO | Backup Set ID |
| DEST_ID | bigint(20) | NO | Backup Path ID |
| INCARNATION | bigint(20) | NO | Indicates the number of forks after a flashback database operation. |
| BACKUP_TYPE | varchar(1) | NO | Backup type: <ul><li>`FULL`: Indicates a full backup. </li> <li>`INC`: Incremental backup</li></ul> |
| PREV_FULL_BACKUP_SET_ID | bigint(20) | NO | BACKUP_SET_ID of the last full backup that the current backup set depends on |
| PREV_INC_BACKUP_SET_ID | bigint(20) | NO | BACKUP_SET_ID of the Previous Incremental Backup on Which the Current Backup Set Depends |
| START_TIMESTAMP | timestamp(6) | NO | Backup Set Backup Start Timestamp |
| END_TIMESTAMP | varchar(26) | NO | Backup Set End Time |
| STATUS | varchar(64) | NO | Backup Set Status: <ul><li>`SUCCESS`: Indicates the backup was successful.  </li><li>`FAILED`: Indicates backup failed.</li></ul> |
| FILE_STATUS | varchar(64) | NO | File status of the backup set:<ul><li>COPYING: The file is being backed up.</li><li>AVAILABLE: The backup is valid.</li><li>DELETING: The file is being deleted.</li><li>EXPIRED: The backup file has expired.</li><li>INCOMPLETE: The backup file is incomplete.</li><li>BROKEN: The backup file is incomplete and cannot be used.</li><li>DELETED: The backup file has been deleted.</li></ul> |
| ELAPSED_SECONDES | decimal(22,0) | NO | Backup Duration |
| PLUS_ARCHIVELOG | varchar(4096) | NO | Whether to append logs |
| START_REPLAY_SCN | bigint(20) unsigned | NO | Backup Set Dependent on Log Replay SCN |
| START_REPLAY_SCN_DISPLAY | varchar(26) | NO | Backup Set Dependency Log Playback Timestamp Offset |
| MIN_RESTORE_SCN | bigint(20) unsigned | NO | Latest Restorable SCN of Backup Set |
| MIN_RESTORE_SCN_DISPLAY | varchar(26) | NO | Minimum Restorable Timestamp for Backup Set |
| INPUT_BYTES | bigint(20) | YES | Input Bytes |
| OUTPUT_BYTES | bigint(20) | YES | Output Bytes |
| OUTPUT_RATE_BYTES | decimal(28,4) | NO | Output Bytes Per Second |
| EXTRA_META_BYTES | bigint(20) | YES | Extra Bytes |
| TABLET_COUNT | bigint(20) | YES | Total Number of Backed-up Tablets |
| FINISH_TABLET_COUNT | bigint(20) | YES | Total Backed-Up Tablets |
| MACRO_BLOCK_COUNT | bigint(20) | YES | Total Backup Macroblocks |
| FINISH_MACRO_BLOCK_COUNT | bigint(20) | YES | Total Number of Backup Macroblocks Completed |
| FILE_COUNT | bigint(20) | YES | Number of Backup Files |
| META_TURN_ID | bigint(20) | YES | Backup Meta Cycle |
| DATA_TURN_ID | bigint(20) | YES | Backup Cycle |
| RESULT | bigint(20) | NO | Backup Error Code Result |
| COMMENT | varchar(4096) | YES | Backup Error Code Description |
| ENCRYPTION_MODE | varchar(64) | YES | Encryption mode:<ul><li>None: no encryption.</li><li>Password: password protection only.</li><li>Password Encryption: encryption and password protection.</li><li>Transparent Encryption: transparent data encryption (TDE).</li><li>Dual mode Encryption: TDE and password protection.</li></ul> </br>The following modes are supported: None and Password. |
| PASSWD | varchar(128) | YES | password |
| TENANT_COMPATIBLE | varchar(4096) | NO | Tenant version number |
| BACKUP_COMPATIBLE | bigint(20) | NO | Backup Set Version |
| PATH | varchar(4096) | YES | Backup Path |
| CLUSTER_VERSION | varchar(4096) | NO | Cluster Version |
| CONSISTENT_SCN | bigint(20) unsigned | NO | Consistent Backup Timestamp |
| MINOR_TURN_ID | bigint(20) | NO | Round of Minor Compaction Data Backup Completion |
| MAJOR_TURN_ID | bigint(20) | NO | Round of Baseline Data Backup Completion |

## Sample query
