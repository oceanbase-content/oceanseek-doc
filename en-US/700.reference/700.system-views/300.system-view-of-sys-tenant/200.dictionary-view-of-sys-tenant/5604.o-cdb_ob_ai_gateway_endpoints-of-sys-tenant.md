# oceanbase.CDB_OB_AI_GATEWAY_ENDPOINTS

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.6.2.1. </p>
</main>

## Overview

This view displays the details of all tenant AI gateway endpoints, which is commonly used to troubleshoot routing configurations of each tenant by endpoint under the sys tenant. This view is derived from the `endpoints` JSON field in the `CDB_OB_AI_GATEWAYS` table.

## Columns

| field | Type | Is NULL | Description |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | YES | Tenant ID. |
| GATEWAY_NAME | varchar(256) | NO | Gateway name. |
| ENDPOINT_NAME | varchar(256) | NO | Endpoint name. |
| MODEL | varchar(512) | NO | The full model name is `provider/model` format. |
| WEIGHT | int(11) | YES | Routing weight. When this parameter is set to NULL, the routing is based on the `0` Display. |
| CREATE_TIME | timestamp(6) | NO | The time when the gateway was created. |
| UPDATE_TIME | timestamp(6) | NO | The last modification time of the gateway. |

## Sample query

Query endpoint routing information under a specified gateway for all tenants in the sys tenant:

```sql
SELECT TENANT_ID, GATEWAY_NAME, ENDPOINT_NAME, MODEL, WEIGHT
FROM oceanbase.CDB_OB_AI_GATEWAY_ENDPOINTS
WHERE GATEWAY_NAME = 'test'
ORDER BY TENANT_ID, ENDPOINT_NAME;
```

The sample result is as follows:

```shell
TENANT_ID	GATEWAY_NAME	ENDPOINT_NAME	MODEL	WEIGHT
1004	    test	ep1	test-provider/test-model	70
1004	    test	ep2	test-provider/test-model2	30
2 rows in set
```
