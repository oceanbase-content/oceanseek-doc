# oceanbase.CDB_OB_LS_LOG_ARCHIVE_PROGRESS

## Overview

Displays the log stream archiving progress for all tenants.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| DEST_ID | bigint(20) | NO | Archive Destination ID |
| LS_ID | bigint(20) | NO | Log Stream ID |
| ROUND_ID | bigint(20) | NO | Log Stream Round ID |
| PIECE_ID | bigint(20) | NO | Latest Piece ID |
| INCARNATION | bigint(20) | NO | Avatar ID |
| START_SCN | bigint(20) unsigned | NO | Archive Start SCN |
| MIN_LSN | bigint(20) unsigned | NO | Minimum LSN of Current Piece Log Stream |
| MAX_LSN | bigint(20) unsigned | NO | Maximum LSN of Current Piece Log Stream |
| CHECKPOINT_SCN | bigint(20) unsigned | NO | Maximum Archiving Progress of Current Piece Log Stream |
| STATUS | varchar(64) | NO | Tenant archiving status:<ul><li> PREPARE: The initial state after archiving is enabled. </li><li>BEGINNING: Entered this state after the basic check for enabling archiving is completed. </li><li> DOING: The normal archiving state. </li><li> INTERRUPTED: Archiving is interrupted and cannot continue. </li><li> STOPPING: Entered this state when stopping archiving is initiated. </li><li>STOP: The archiving is stopped. </li><li> SUSPENDING: Archiving has entered the suspended state. </li><li> SUSPEND: Archiving is in the suspended state. </li></ul> |
| FILE_ID | bigint(20) | NO | Maximum Archived File ID of Current Piece |
| FILE_OFFSET | bigint(20) | NO | Maximum Archived File Offset for the Current Piece |
| INPUT_BYTES | bigint(20) | NO | Volume of Log Data Read |
| OUTPUT_BYTES | bigint(20) | NO | Volume of Archived Log Data |
