# mysql.time_zone_transition_type

## Overview

Displays the time zone conversion type (SYSTEM_VIEW).

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| -------------------- | ------------ | ---------------- | ----------- |
| Time_zone_id | bigint(20) | NO | Time zone ID |
| Transition_type_id | bigint(20) | NO | Time zone conversion type ID |
| Offset | bigint(20) | NO | Time zone offset |
| Is_DST | bigint(20) | NO | Whether Daylight Saving Time is in Effect |
| Abbreviation       | varchar(8) | NO             | Abbreviation    |
