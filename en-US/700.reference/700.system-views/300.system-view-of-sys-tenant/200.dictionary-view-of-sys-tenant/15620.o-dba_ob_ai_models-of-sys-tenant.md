# oceanbase.DBA_OB_AI_MODELS

## Overview

Displays the AI model information for the current tenant.

## Columns

| field | Type | Is NULL | Description |
| --- | --- | --- | --- |
| MODEL_ID | int(20) | NO | Unique identifier of the large model. |
| NAME | varchar(128) | NO | The unique name of the user-defined large language model. This name is used when invoking AI functions or interacting with the model. `DBMS_AI_SERVICE` To include the system package, use this name. |
| TYPE | varchar(128) | NO | The type of the large language model. The value must be one of the following:<ul><li><code>dense_embedding</code>: Dense vector model</li><li><code>sparse_embedding</code>: Sparse vector model</li><li><code>completion</code>: Text completion model</li><li><code>rerank</code>: Re-ranking model</li></ul><main id="notice" type='notice'><h4>Note</h4><p>The sparse vector model is not currently supported.</p></main> |
| MODEL_NAME | varchar(128) | NO | Larger model name, for example, `text-embedding-v2`. |

## Sample query

Query the AI model information of the current tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_AI_MODELS;
```

The query result is as follows:

```shell
+----------+---------------+-----------------+-------------------+
| MODEL_ID | NAME          | TYPE            | MODEL_NAME        |
+----------+---------------+-----------------+-------------------+
|   500005 | my_ai_model_1 | DENSE_EMBEDDING | text-embedding-v1 |
+----------+---------------+-----------------+-------------------+
1 row in set
```
