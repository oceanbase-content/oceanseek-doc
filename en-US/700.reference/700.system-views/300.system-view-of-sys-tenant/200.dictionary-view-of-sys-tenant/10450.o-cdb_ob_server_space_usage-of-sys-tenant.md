# oceanbase.CDB_OB_SERVER_SPACE_USAGE

## Overview

The `CDB_OB_SERVER_SPACE_USAGE` view is used to monitor the detailed storage space usage of each tenant on each node.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| ------------ | ------------- | --------------------- | ---------------------------------------- |
| TENANT_ID | varchar(128) | NO | Tenant ID |
| TENANT_NAME | varchar(128) | NO | Tenant name |
| SERVER_IP | varchar(46) | NO | Node IP Address Containing Tenant Uint |
| SERVER_PORT | bigint(20) | NO | Port of the Node Containing Tenant Uint |
| SPACE_TYPE | varchar(9) | NO | Types include:<ul><li>Table Data: data of all partitions in all primary tables, including LOB partitions.</li><li>Index Data: data of all partitions in all index tables.</li><li>Meta Data: all metadata.</li><li>Tmp Data: temporary files.</li><li>clog Data: total size of clogs on the node.</li></ul><main id="notice" type='explain'><h4>Note</h4><p>Only private data of the node is counted. </p></main> |
| DATA_BYTES | decimal(42,0) | NO | Data content size, in bytes |
| USAGE_BYTES | decimal(42,0) | NO | Actual disk space usage, in bytes |
