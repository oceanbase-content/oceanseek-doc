# oceanbase.DBA_OB_TRANSFER_TASK_HISTORY

## Overview

Displays the history of all transfer tasks executed under this tenant.

## Columns

| **Column** | **Type** | **Is NULL** | **Description** |
| --- | --- | --- | --- |
| TASK_ID | bigint(20) | NO | Transfer Task ID |
| CREATE_TIME | timestamp(6) | YES | Task Start Time |
| MODIFY_TIME | timestamp(6) | YES | Task completion time, including success and cancellation times |
| SRC_LS | bigint(20) | NO | Source log stream (the log data stream generated from the data source) |
| DEST_LS | bigint(20) | NO | Destination log stream |
| PART_LIST | longtext | YES | Partition list, including: user table partitions and global index partitions |
| PART_COUNT | bigint(20) | YES | Number of Partitions in the Partition List |
| NOT_EXIST_PART_LIST | longtext | YES | List of partitions that exist during lock acquisition but will be executed in this task |
| LOCK_CONFLICT_PART_LIST | longtext | YES | List of partitions that were planned for this task but encountered lock conflicts during locking |
| TABLE_LOCK_TABLET_LIST | longtext | YES | A list of tablets that successfully acquired partition-level table locks when entering the START state, used for table lock migration. This list contains only the tablets corresponding to the partitions in the PART_LIST. |
| TABLET_LIST | longtext | YES | The complete list of tablets involved in this transfer operation includes not only the tablets listed in the PART_LIST but also the tablets associated with local index tables and LOB auxiliary tables. |
| TABLET_COUNT | bigint(20) | YES | Number of Tablets in the Tablet List |
| START_SCN | bigint(20) unsigned | YES | SCN at Which the Transfer Was Initiated |
| FINISH_SCN | bigint(20) unsigned | YES | SCN at the End of Transfer |
| STATUS | varchar(64) | NO | Task status: <ul><li>`COMPLETED`: Task executed successfully. </li><li>`FAILED`: Task execution failed. </li><li>`CANCELED`: Cancel the task. </li></ul> |
| TRACE_ID | varchar(64) | NO | Task Full Process Trace ID |
| RESULT | bigint(20) | YES | Task Result |
| BALANCE_TASK_ID | bigint(20) | NO | The ID of the associated load balancing task. This transfer task is a subtask generated by the corresponding load balancing task. |
| TABLE_LOCK_OWNER_ID | bigint(20) | YES | When acquiring a table lock, the system generates an owner_id for each lock to identify its owner. When releasing the lock, the corresponding owner_id must be provided so that the system can correctly recognize and release it. |
| COMMENT | longtext | YES | Comment information. Records the cause of the current deadlock, diagnostic information, and task failure details. |
