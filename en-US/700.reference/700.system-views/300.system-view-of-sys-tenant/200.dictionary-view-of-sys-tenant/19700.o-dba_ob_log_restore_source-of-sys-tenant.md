# oceanbase.DBA_OB_LOG_RESTORE_SOURCE

## Overview

Displays the log restore source for the current tenant.

## Columns

| **Column** | **Type** | **Is NULL** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| ID | bigint(20) | NO | Log Restore Source Number |
| TYPE | varchar(32) | NO | Log restore source type. Valid values: <ul><li>`SERVICE`: Restore logs directly from the source over the network.  </li><li>`LOCATION`: Restore Source from Archived Logs</li><li>`RAWPATH`: User management log restore source </li></ul> |
| VALUE | longtext | NO | Log restore source entry address <ul><li>SERVICE type: the access entry for primary tenants, for example, "IP_LIST=xxx.xxx.xxx.xxx:44803,USER=user@mysql,PASSWORD=******,TENANT_ID=1002,CLUSTER_ID=1,IS_ENCRYPTED=true"  </li><li>LOCATION: the log archive directory, for example, "file:///data/1/archive/" </li><li>RAWPATH: the user-defined directory </li></ul> |
| RECOVERY_UNTIL_SCN | bigint(20) unsigned | NO | The maximum number of logs to obtain. The value can be INT64_MAX or a positive finite number. |
