# oceanbase.DBA_OB_TABLEGROUPS

## Overview

Displays the meta information of a table group, mainly its partition information.

<main id="notice" type='explain'>
<h4>Note</h4>
<p>The partition attribute fields in this view are uniformly displayed as <code>NONE</code> or <code>NULL</code>.</p>
</main>

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --------------------------- | -------------- | ------------ | -------------------------------------------------------------------------------------------------------- |
| TABLEGROUP_NAME | varchar(128) | NO | Table group name |
| PARTITIONING_TYPE | varchar(13) | NO | Partition type of a partitioned table group's partition:<ul><li>`NONE`: Non-partitioned table group   </li><li>`HASH`: HASH partitioning (single partitioning key)   </li><li>`KEY`: KEY partitioning   </li><li>`RANGE`: RANGE partitioning (single partitioning key)   </li><li>`RANGE COLUMNS`: RANGE COLUMNS partitioning   </li><li>`LIST`: LIST partitioning (single partitioning key)   </li><li>`LIST COLUMNS`: LIST COLUMNS partition   </li><li>`UNKNOWN`: Exception type. </li></ul> <main id="notice" type='explain'><h4>Note</h4><p>The value of this field is <code>NULL</code>. </p></main> |
| SUBPARTITIONING_TYPE | varchar(13) | NO | Partition types of subpartitions in a partitioned table group:<ul><li>`NONE`: Non-partitioned table groups, partitioned table groups   </li><li>`HASH`: HASH partitioning (single partitioning key)   </li><li>`KEY`: KEY partition   </li><li>`RANGE`: RANGE partitioning (single partitioning key)   </li><li>`RANGE COLUMNS`: RANGE COLUMNS partitioning   </li><li>`LIST`: LIST partitioning (single partitioning key)   </li><li>`LIST COLUMNS`: LIST COLUMNS partition   </li><li>`UNKNOWN`: Exception type. </li></ul><main id="notice" type='explain'><h4>Note</h4><p>The value of this field is <code>NULL</code>. </p></main> |
| PARTITION_COUNT | bigint(20) | NO | The value is `NULL` |
| DEF_SUBPARTITION_COUNT | bigint(0) | NO | This value is `NULL` |
| PARTITIONING_KEY_COUNT | bigint(20) | NO | The value is `NULL` |
| SUBPARTITIONING_KEY_COUNT | bigint(20) | NO | The value is `NULL` |
| SHARDING | varchar(20) | NO | The SHARDING attribute of the table group. Valid values: <ul><li>`NONE`: For tables in this table group, all partitions of all tables within the table group are stored on the same server. No restrictions are placed on tables that can be added to the table group.</li> <li>`PARTITION`: For tables in the table group with this attribute, the data of each table is scattered into partitions. For a subpartitioned table, all subpartitions under a partition are aggregated together.</li> <li>`ADAPTIVE`: For tables in the table group with this attribute, the data of each table is scattered in an adaptive manner. That is, if a table in the table group is a partitioned table, its data is scattered by partitions; if a table in the table group is a subpartitioned table, its data is scattered by subpartitions within each partition.</li></ul> |

## Sample query

1. Create a table group named `tblgroup1`.

   ```shell
   obclient [test]> CREATE TABLEGROUP tblgroup1 SHARDING = 'PARTITION';
   ```

2. View the SHARDING attribute of the table group `tblgroup1`.

   ```shell
   obclient [test]> SELECT TABLEGROUP_NAME, SHARDING FROM oceanbase.DBA_OB_TABLEGROUPS WHERE tablegroup_name = 'tblgroup1';
   ```

   The query result is as follows:

   ```shell
   +-----------------+-----------+
   | TABLEGROUP_NAME | SHARDING  |
   +-----------------+-----------+
   | tblgroup1       | PARTITION |
   +-----------------+-----------+
   1 row in set
   ```
