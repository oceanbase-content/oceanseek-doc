# oceanbase.CDB_OB_TRANSFER_PARTITION_TASK_HISTORY

## Overview

The `CDB_OB_TRANSFER_PARTITION_TASK_HISTORY` view displays the history of all [Transfer Partition](../../../500.sql-reference/100.sql-syntax/100.system-tenants/200.alter-system/4300.Transfer-partition.md) tasks executed by tenants.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | User Tenant ID |
| TASK_ID | bigint(20) | NO | Unique identifier of the partition transfer task. |
| CREATE_TIME | timestamp(6) | NO | Creation Time |
| FINISH_TIME | timestamp(6) | NO | Task completion time, including success and cancellation |
| TABLE_ID | bigint(20) | NO | Table ID of the partition for which data is being transferred |
| OBJECT_ID | bigint(20) | NO | Partition of Transfer `OBJECT_ID` |
| DEST_LS | bigint(20) | NO | Destination log stream |
| BALANCE_JOB_ID | bigint(20) | NO | CLB Work ID Associated with Task Execution |
| TRANSFER_TASK_ID | bigint(20) | NO | Transfer task ID associated with the task during execution |
| STATUS | varchar(64) | NO | Task status:<ul><li>COMPLETED: The task is completed successfully.</li><li>FAILED: The task failed.</li></ul> |
| COMMENT | longtext | YES | Comments |

## Sample query

View the history of transfer partition tasks executed by the tenant with ID 1006.

```shell
obclient> SELECT * FROM oceanbase.CDB_OB_TRANSFER_PARTITION_TASK_HISTORY  WHERE TENANT_ID = 1006;
```
