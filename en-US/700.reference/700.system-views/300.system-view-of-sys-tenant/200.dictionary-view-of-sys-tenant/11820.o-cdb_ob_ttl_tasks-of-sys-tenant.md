# oceanbase.CDB_OB_TTL_TASKS

## Overview

The `oceanbase.CDB_OB_TTL_TASKS` view displays the execution status of all user tenant TTL tasks in SQL mode.

## Columns

| field | Type | Is NULL | Description |
| --------------- | -------------- | ------------- | ------------------------------------------- |
| TENANT_ID | bigint(20) | NO | Tenant name |
| TABLE_NAME | varchar(256) | NO | Table name |
| TABLE_ID | bigint(20) | NO | Table ID |
| TASK_ID | bigint(20) | NO | The ID of the current batch task. |
| START_TIME | timestamp(6) | NO | Task Start Time |
| MODIFIED_TIME | timestamp(6) | NO | Row Update Time |
| TRIGGER_TYPE | varchar(8) | NO | Task trigger type: <ul><li>`PERIODIC`: Triggered periodically by the system.</li> <li>`USER`: Manually triggered by the user.</li></ul> |
| STATUS | varchar(10) | NO | Task status: <ul><li>`PENDING`: Waiting to reach the executable state.</li> <li>`CANCELED`: The task is canceled. </li> <li>`FINISHED`: The task has ended.</li> <li>`SKIP`: Not reached the executable state, skipping this execution cycle.</li> <li>`FAILED`: Task execution failed.</li> <li>`TRIGGERING`: RS-side task is in progress.</li> <li>`SUSPENDING`: The task on the RS side is paused.</li> <li>`CANCELING`: The RS-side task is canceled.</li> <li>`MOVING`: The RS side transfers the task information to the task history table.</li></ul> |
| RET_CODE | varchar(512) | NO | Error code returned at the end of the task |
| TASK_TYPE | varchar(10) | NO | TTL Task Type: <ul><li>`NORMAL`: Tenant-level information display</li> <li>`COMPACTION`: Table-level task type, which performs deleted data cleanup through compaction.</li></ul> |

## Sample query

Query the execution status of all user tenant TTL tasks for the system tenant.

```shell
obclient(root@sys)[oceanbase]> SELECT * FROM oceanbase.CDB_OB_TTL_TASKS;
```
