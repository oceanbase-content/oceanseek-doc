# oceanbase.DBA_SCHEDULER_JOB_RUN_DETAILS

## Overview

The `DBA_SCHEDULER_JOB_RUN_DETAILS` view displays information about all scheduler jobs in the current tenant.

## Columns

| **Column** | **Type** | **Is NULL** | **Description** |
| -------- | -------- | --------------- | -------- |
| LOG_ID | decimal(20,0) | NO | This field is not supported. The default value is 0. |
| LOG_DATE | datetime | NO | Log entry. |
| OWNER | varchar(128) | NO | Owner of the job. |
| JOB_NAME | varchar(128) | NO | The name of the job. |
| JOB_SUBNAME | varchar(128) | NO | This field is not supported and its default value is NULL. |
| STATUS | varchar(128) | NO | Job status. |
| CODE | bigint(20) | YES | Error number when an error occurs during job execution. |
| REQ_START_DATE | datetime | NO | The expected start time of the job. |
| ACTUAL_START_DATE | datetime | NO | The actual start time of the job. |
| RUN_DURATION | decimal(20,0) | NO | Duration of job execution. |
| INSTANCE_ID | varchar(128) | NO | This field is not supported and its default value is NULL. |
| SESSION_ID | decimal(20,0) | NO | This field is not supported and its default value is NULL. |
| SLAVE_PID | varchar(128) | NO | This field is not supported and its default value is NULL. |
| CPU_USED | decimal(20,0) | NO | This field is not supported and its default value is NULL. |
| CREDENTIAL_OWNER | varchar(128) | NO | This field is not supported and its default value is NULL. |
| CREDENTIAL_NAME | varchar(128) | NO | This field is not supported and its default value is NULL. |
| DESTINATION_OWNER | varchar(128) | NO | Cross-database jobs are not currently supported. This field is set to NULL by default. |
| DESTINATION | varchar(128) | NO | Cross-database jobs are not currently supported. This field is set to NULL by default. |
| MESSAGE | varchar(4000) | NO | Error message returned by the job. |
| JOB | bigint(20) | NO | The name of the program job. |
| TIME | timestamp(6) | NO | The time when the job log was recorded, in seconds. |
| JOB_CLASS | varchar(30) | YES | The category of the program job. |
| GMT_CREATE | timestamp(6) | YES | The time when the job was created, in seconds. |
| GMT_MODIFIED | timestamp(6) | YES | The time when the job was modified, in seconds. |

## Sample query

Query information about all scheduler jobs in the current tenant and display the first record.

```shell
obclient(root@sys)[oceanbase]> SELECT * FROM oceanbase.DBA_SCHEDULER_JOB_RUN_DETAILS limit  1\G
```
