# oceanbase.DBA_OB_TTL_TASK_HISTORY

## Overview

The `oceanbase.DBA_OB_TTL_TASK_HISTORY` view displays the execution history of current tenant's TTL tasks in SQL mode.

## Columns

| field | Type | Is NULL | Description |
| --------------- | -------------- | ------------- | ------------------------------------------- |
| TABLE_NAME | varchar(256) | NO | Table name |
| TABLE_ID | bigint(20) | NO | Table ID |
| TASK_ID | bigint(20) | NO | The ID of the current batch task. |
| START_TIME | timestamp(6) | NO | Task Start Time |
| MODIFIED_TIME | timestamp(6) | NO | Row Update Time |
| TRIGGER_TYPE | varchar(8) | NO | Task trigger type: <ul><li>`PERIODIC`: Triggered periodically by the system.</li> <li>`USER`: Manually triggered by the user.</li></ul> |
| STATUS | varchar(10) | NO | Task status: <ul><li>`CANCELED`: The task is canceled. </li> <li>`FINISHED`: Task has ended.</li> <li>`SKIP`: Not ready for execution. Skip this execution.</li> <li>`FAILED`: Task execution failed.</li></ul> |
| RET_CODE | varchar(512) | NO | Error code returned at the end of the task |
| TASK_TYPE | varchar(10) | NO | TTL task type:<ul><li>`NORMAL`: Tenant-level information display</li> <li>`COMPACTION`: Table-level task type, which uses compaction to delete expired data.</li></ul> |
