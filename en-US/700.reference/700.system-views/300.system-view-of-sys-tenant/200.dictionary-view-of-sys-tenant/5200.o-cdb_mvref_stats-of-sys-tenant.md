# CDB_MVREF_STATS

## Description

The `CDB_MVREF_STATS` view displays basic timing statistics for materialized view refreshes.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| MV_OWNER | varchar(128) | NO | Owner of the materialized view |
| MV_NAME | varchar(128) | NO | Materialized View Name |
| REFRESH_ID | bigint(20) | NO | Refresh ID |
| REFRESH_METHOD | varchar(30) | NO | The method used to refresh the materialized view. Valid values:<ul><li>FAST: incremental refresh.</li><li>COMPLETE: complete refresh.</li></ul> |
| REFRESH_OPTIMIZATIONS | text | NO | The primary key or foreign key of the application during an optimization refresh, such as an empty refresh or a materialized view refresh. <main id="notice" type='explain'> <h4>Note</h4><p>This field is only compatible and its default value is NULL.</p></main> |
| ADDITIONAL_EXECUTIONS | text | NO | Additional operations. For example, log operations involved during index rebuilding or materialized view refresh.<main id="notice" type='explain'> <h4>Note</h4><p>This field is only compatible with and its default value is NULL.</p></main> |
| START_TIME | datetime | NO | Refresh Start Time |
| END_TIME | datetime | NO | Refresh End Time |
| ELAPSED_TIME | bigint(20) | NO | The duration for which the refresh is running. |
| LOG_SETUP_TIME | bigint(1) | NO | Log retention period for the materialized view, in seconds<main id="notice" type='explain'> <h4>Note</h4><p>This field is only compatible with and its default value is 0.</p></main> |
| LOG_PURGE_TIME | bigint(20) | NO | Log purge time for the materialized view. |
| INITIAL_NUM_ROWS | bigint(20) | NO | Initial row count in the materialized view (at the start of the refresh) |
| FINAL_NUM_ROWS | bigint(20) | NO | Final row count in the materialized view (at the end of refresh) |
| NUM_STEPS | bigint(20) | NO | Indicates the total number of steps in this refresh. |
| RESULT | bigint(20) | NO | The execution result code of the refresh task. 0 indicates success. |
| REFRESH_SCN | bigint(20) unsigned | YES | The SCN at which the refresh starts. |
| SVR_IP | varchar(64) | YES | The IP address of the OBServer node that performs the refresh. |
| SVR_PORT | bigint(20) | YES | The port of the OBServer node on which the refresh is performed. |
