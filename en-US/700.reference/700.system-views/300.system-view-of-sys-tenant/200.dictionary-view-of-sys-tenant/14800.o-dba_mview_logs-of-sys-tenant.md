# oceanbase.DBA_MVIEW_LOGS

## Overview

The `DBA_MVIEW_LOGS` view is used to display materialized view log information.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| LOG_OWNER | varchar(128) | NO | Owner name of the materialized view log |
| MASTER | varchar(128) | NO | The name of the primary table to which the materialized view log belongs. |
| LOG_TABLE | varchar(128) | NO | Materialized View Log Table Name |
| LOG_TRIGGER | varchar(128) | YES | A trigger that fires after a row is inserted into the primary table, used to insert the row into the materialized view log. <main id="notice" type='explain'> <h4>Note</h4><p>This field is only compatible with and its default value is NULL.</p></main> |
| ROWIDS | varchar(3) | NO | Specifies whether to record the rowid information.<ul><li>YES</li><li>NO</li></ul> |
| PRIMARY_KEY | varchar(3) | NO | Whether to record the primary key information.<ul><li>YES</li><li>NO</li></ul> |
| OBJECT_ID | varchar(3) | NO | Indicates whether object identification information is recorded in the object table.<ul><li>YES</li><li>NO</li></ul><main id="notice" type='explain'> <h4>Note</h4><p>This field is only compatible with the value NO by default.</p></main> |
| FILTER_COLUMNS | varchar(3) | NO | Whether to record filtered column information.<ul><li> YES </li><li>NO </li></ul> |
| SEQUENCE | varchar(3) | NO | Specifies whether to record the sequence value that provides additional sorting information.<ul><li>YES</li><li>NO</li></ul><main id="notice" type='explain'> <h4>Note</h4><p>The value of this field is always YES.</p></main> |
| INCLUDE_NEW_VALUES | varchar(3) | NO | Specifies whether to record both the old and new values.<ul><li>YES: Records both the old and new values. </li><li>NO: Records only the old value, not the new value. </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>The value of this field is always YES.</p></main> |
| PURGE_ASYNCHRONOUS | varchar(3) | NO | Whether the materialized view log is cleared asynchronously.<ul><li>YES</li><li>NO</li></ul> |
| PURGE_DEFERRED | varchar(3) | NO | Specifies whether to purge materialized view logs in a delayed manner.<ul><li>YES</li><li>NO</li></ul> |
| PURGE_START | datetime | YES | Delayed cleanup start date |
| PURGE_INTERVAL | varchar(200) | YES | Indicates the clearance time interval for delayed clearance. |
| LAST_PURGE_DATE | datetime | YES | Date of the last purge of materialized view logs |
| LAST_PURGE_STATUS | bigint(1) | NO | Indicates the status of the last materialized view log purge.<ul><li>Error code</li><li>0: successful</li></ul><main id="notice" type='explain'> <h4>Note</h4><p>The value of this field is always 0.</p></main> |
| NUM_ROWS_PURGED | bigint(20) | YES | Indicates the number of rows cleared in the last materialized view log cleanup. |
| COMMIT_SCN_BASED | varchar(3) | NO | Whether the materialized view log is based on the commit SCN.<ul><li> YES </li><li>NO </li></ul><main id="notice" type='explain'> <h4>Note</h4><p>The value of this field is always YES.</p></main> |
| STAGING_LOG | varchar(3) | NO | Whether the materialized view log is a temporary log for synchronous refresh.<ul><li>YES</li><li>NO</li></ul><main id="notice" type='explain'> <h4>Note</h4><p>This field is only compatible with and its default value is NO.</p></main> |
| PURGE_DOP | bigint(20) | NO | The degree of parallelism for cleaning up materialized view logs. |
| LAST_PURGE_TIME | bigint(20) | YES | The time consumed by the last materialized view log cleanup task, in seconds. |
| LAST_PURGE_METHOD | varchar(16) | NO | The method used in the last materialized view log cleanup task. Valid values: <ul><li>SQL </li><li>COMPACTION</li></ul> If no cleanup task has been performed, NULL is displayed. |
