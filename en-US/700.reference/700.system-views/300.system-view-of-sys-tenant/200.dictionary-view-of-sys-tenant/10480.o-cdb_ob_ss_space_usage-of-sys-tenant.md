# oceanbase.CDB_OB_STORAGE_SPACE_USAGE

## Overview

The `CDB_OB_STORAGE_SPACE_USAGE` view is used to record the storage space usage of object storage for each tenant.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --------------- | --------------- | --------------------- | ---------------------------------------- |
| TENANT_ID | bigint(20) | NO | Tenant ID. |
| TENANT_NAME | varchar(128) | NO | Tenant name. |
| ENDPOINT | varchar(128) | NO | Endpoint for shared storage. |
| PATH | varchar(128) | NO | The path of the shared storage. |
| STORAGE_TYPE | varchar(32) | NO | Storage type: <ul><li>`Local All Bytes`: all data in the local directory on object storage.</li> <li>`Shared Data Bytes`: data in the public directory of object storage.</li> <li>`Shared Meta Bytes`: all metadata on object storage.</li></ul> |
| VALUE | bigint(20) | NO | `STORAGE_TYPE` The corresponding space usage, in bytes. |

## Sample query

View the storage space usage on the object storage of each tenant.

```shell
obclient(root@sys)[oceanbase]> SELECT * FROM oceanbase.CDB_OB_STORAGE_SPACE_USAGE;
```
