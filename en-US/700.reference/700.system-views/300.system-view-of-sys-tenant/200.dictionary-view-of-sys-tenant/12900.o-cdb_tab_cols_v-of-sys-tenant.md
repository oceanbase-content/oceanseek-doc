# oceanbase.CDB_TAB_COLS_V$

## Overview

This view displays the column information for tables and views of all tenants. It is consistent with `CDB_TAB_COLS`, but includes an additional `NOTES` column, which is currently unused.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ---------------------- | ----------------- | ------------ | --------------- |
| CON_ID | bigint(20) | NO | Tenant ID |
| OWNER | varchar(128) | NO | Owner of a table, view, or cluster |
| TABLE_NAME | varchar(128) | NO | The name of the table, view, or cluster. |
| COLUMN_NAME | varchar(128) | NO | Column name |
| DATA_TYPE | varchar(128) | NO | Data type of the column |
| DATA_TYPE_MOD | varchar(3) | NO | The default value is `NULL` |
| DATA_TYPE_OWNER | varchar(128) | NO | Default value: `NULL` |
| DATA_LENGTH | bigint(21) | NO | Column Length (in bytes) |
| DATA_PRECISION | bigint(20) | NO | `NUMBER` The decimal precision of the data type. `FLOAT` Binary precision of the data type; NULL for all other data types. |
| DATA_SCALE | bigint(20) | NO | The digits to the right of the decimal point in a number |
| NULLABLE | varchar(1) | NO | Indicates whether the column allows NULL values. This value is the column's `N` Whether it exists. `NOT NULL` Whether the constraint or column belongs to `PRIMARY KEY` |
| COLUMN_ID | bigint(20) | NO | Sequence Number of the Created Column |
| DEFAULT_LENGTH | bigint(20) | NO | Length of the column's default value |

| LOW_VALUE | varchar(128) | NO | Minimum value of the column |

| DENSITY | bigint(21) | NO | Column Density |

| NUM_BUCKETS | bigint(20) | NO | Number of Buckets in Column Histogram |
| LAST_ANALYZED | date | NO | Date of Last Analysis for This Column |
| SAMPLE_SIZE | bigint(20) | NO | The number of samples used to analyze this column. |

| CHAR_COL_DECL_LENGTH | bigint(0) | NO | Default value: `NULL` |
| GLOBAL_STATS | varchar(3) | NO | `GLOBAL_STATS` If statistics are collected or incrementally maintained, they will `YES` Yes, otherwise it would be `NO` |
| USER_STATS | varchar(3) | NO | Indicates whether the statistics were directly entered by the user. `YES`) or not (`NO`) |
| NOTES | varchar(80) | NO | Record some additional attributes |
| AVG_COL_LEN | bigint(21) | NO | Average Column Length (Bytes) |
| CHAR_LENGTH | bigint(20) | NO | Displays the length of a column in characters. This value applies only to the following data types:<ul><li>`CHAR`   </li><li> `VARCHAR2`   </li><li> `NCHAR`   </li><li> `NVARCHAR2`  </li></ul> |
| CHAR_USED | varchar(1) | NO | Indicates that the column uses `BYTE` Length semantics (`B`) or `CHAR` Length semantics (`C`), or whether the data type is not any of the following (NULL): <ul><li>`CHAR`   </li><li> `VARCHAR2`   </li><li> `NCHAR`   </li><li> `NVARCHAR2` </li></ul> |
| V80_FMT_IMAGE | varchar(3) | NO | The default value is `NULL` |
| DATA_UPGRADED | varchar(3) | NO | Default value: `NULL` |
| HIDDEN_COLUMN | varchar(3) | NO | Indicates whether the column is hidden. `YES`) or not (`NO`) |
| VIRTUAL_COLUMN | varchar(3) | NO | Indicates whether the column is a virtual column. `YES`) or not (`NO`) |
| SEGMENT_COLUMN_ID | bigint(0) | NO | The default value is `NULL` |
| INTERNAL_COLUMN_ID | bigint(0) | NO | Default value: `NULL` |
| HISTOGRAM | varchar(15) | NO | Indicates the presence or type of a histogram:<ul><li>`NONE`   </li><li> `FREQUENCY`   </li><li> `TOP-FREQUENCY`   </li><li> `HEIGHT BALANCED`   </li><li> `HYBRID` </li></ul> |
| QUALIFIED_COL_NAME | text | NO | Limited Column Name |
| USER_GENERATED | varchar(3) | NO | Specifies the column generation attribute. Valid values: <ul><li>`YES`: Indicates that the column is user-generated. </li><li>`NO`: Indicates that the column is system-generated, meaning it has been logically deleted (not physically removed from storage).</li></ul> |
| DEFAULT_ON_NULL | varchar(3) | NO | The default value is `NULL` |

| UNUSABLE_BEFORE | varchar(128) | NO | The default value is `NULL` |
| UNUSABLE_BEGINNING | varchar(128) | NO | Default value: `NULL` |
| COLLATION | varchar(100) | NO | Default value: `NULL` |
| COLLATED_COLUMN_ID | bigint(0) | NO | Default value: `NULL` |
