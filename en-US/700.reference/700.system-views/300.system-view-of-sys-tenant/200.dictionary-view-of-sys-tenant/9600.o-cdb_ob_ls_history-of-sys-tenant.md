# oceanbase.CDB_OB_LS_HISTORY

## Overview

Accessible only to the system tenant, this view displays all log streams that have existed in the history of all tenants.

## Columns

| field | Type | Is NULL | Description |
| ------------- | --------------- | ------------- | ------------------------------------------- |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| LS_ID | bigint(20) | NO | Log Stream ID |
| LS_GROUP_ID | bigint(20) | NO | Log Stream Group ID |
| STATUS | varchar(100) | NO | Current status of the log stream:<ul><li>CREATING: The log stream is being created.</li><li>NORMAL: The normal status of a log stream.</li><li>DROPPING: The log stream is being dropped.</li><li>PRE_TENANT_DROPPING: A special status of the system log stream, indicating that the deletion of all log streams under the tenant has started.</li><li>TENANT_DROPPING: The tenant is being dropped and the log streams are being deleted.</li><li>DROPPED: The log stream has been reclaimed or is in the process of being reclaimed.</li><li>WAIT_OFFLINE: The log stream is waiting to be reclaimed.</li><li>CREATE_ABORT: The creation of the log stream has stopped.</li></ul> |
| FLAG | varchar(2048) | NO | Log stream tag:<ul><li>NULL: normal log stream</li><li>DUPLICATE: broadcast log stream of a user tenant. A replicated table is created on this log stream.</li><li>BLOCK_TABLET_IN: indicates that a tablet cannot be created on this log stream.</li><li>DUPLICATE \| BLOCK_TABLET_IN: Broadcast log streams currently do not allow creating tablets.</li></ul> |
| CREATE_SCN | decimal(20,0) | NO | GTS at Log Stream Creation, in Nanoseconds |

obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_LS_HISTORY;
