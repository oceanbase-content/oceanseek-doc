# oceanbase.CDB_OB_BACKUP_JOBS

## Overview

Displays the backup job tasks for all tenants in the cluster. Each time a user initiates a backup task, a corresponding job record is created.

## Columns

| Field Name | Field Name | Whether can be NULL | Field Name |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| JOB_ID | bigint(20) | NO | Backup Job Task ID. Each backup operation corresponds to a job task record. |
| INCARNATION | bigint(20) | NO | Indicates the number of forks after a flashback database operation. |
| BACKUP_SET_ID | bigint(20) | YES | Backup set ID. The default value for the sys tenant is 0, and for user tenants, it starts from 1 and increments sequentially. |
| INITIATOR_TENANT_ID | bigint(20) | NO | The tenant ID of the task initiator, indicating the tenant that initiated the task and executed the backup SQL command. |
| INITIATOR_JOB_ID | bigint(20) | NO | JOB ID of the task initiator |
| EXECUTOR_TENANT_ID | varchar(65536) | NO | The tenant ID for which backup is to be performed, associated with this job-level backup task. |
| PLUS_ARCHIVELOG | varchar(4096) | NO | Whether to enable log completion: <ul><li>ON: Enable log completion.</li><li>OFF: Disable log completion.</li></ul> |
| BACKUP_TYPE | varchar(4096) | NO | Backup type: <ul><li>`FULL`: Indicates a full backup. </li> <li>`INC`: Incremental backup.</li></ul> |
| JOB_LEVEL | varchar(4096) | NO | JOB Level:<ul><li>CLUSTER: The sys tenant initiates backup tasks for all tenants.</li><li>SYS_TENANT: The sys tenant initiates a backup task for a specified tenant.</li><li>USER_TENANT: A user tenant initiates its own backup.</li></ul> |
| ENCRYPTION_MODE | varchar(4096) | YES | Encryption mode:<ul><li>None: no encryption.</li><li>Password: password protection only.</li><li>Password Encryption: encryption and password protection.</li><li>Transparent Encryption: transparent data encryption (TDE).</li><li>Dual mode Encryption: TDE and password protection.</li></ul> </br>The following modes are supported: None and Password. |
| PASSWD | varchar(4096) | YES | password |
| START_TIMESTAMP | timestamp(6) | NO | Start Time of JOB-Level Backup Task |
| END_TIMESTAMP | timestamp(6) | NO | End Time of Job-Level Backup Task |
| STATUS | varchar(4096) | NO | Backup Status |
| RESULT | bigint(20) | NO | Backup Error Code Result |
| COMMENT | varchar(4096) | YES | Error Code Description |
| DESCRIPTION | varchar(4096) | YES | User-specified backup description |
| PATH | varchar(4096) | YES | Backup Path |

## Sample query

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_BACKUP_JOBS WHERE TENANT_ID = 1002\G
```
