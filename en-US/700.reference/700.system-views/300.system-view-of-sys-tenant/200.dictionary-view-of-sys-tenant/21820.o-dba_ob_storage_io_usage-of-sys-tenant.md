# oceanbase.DBA_OB_STORAGE_IO_USAGE

## Overview

Displays the I/O operation statistics of the current tenant's object storage and cloud disks.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ----------- | --------------- | ---------------- | ------------------------------- |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| PATH | varchar(1024) | NO | The path format is similar to `s3://`, `file://`, `azblob://` etc. |
| ENDPOINT | varchar(256) | NO | Endpoint of the object storage device for storing logs (clogs) or data, and for backup and recovery, data import, and data export |
| TYPE | varchar(128) | NO | Operation type:<ul><li>`READ`: Read type</li> <li>`WRITE`: Write type</li> <li>`READ_BYTES`: Object storage network ingress traffic</li> <li>`WRITE_BYTES`: Object storage network egress traffic</li> <li>`TAG`: The tag type in object storage. This type is not displayed for local disks and cloud disks.</li></ul> |
| TOTAL | bigint(20) | NO | Each type (`TYPE`) the cumulative value: <ul><li>`READ`: Cumulative count of operations related to read types</li> <li>`WRITE`: Number of operations related to write types.</li> <li>`READ_BYTES`: Total network inbound traffic of object storage, in bytes.</li> <li>`WRITE_BYTES`: Total outbound traffic of the object storage network, in bytes.</li> <li>`TAG`: The cumulative value of the tag type in object storage. This statistic is not displayed for local disks or cloud disks.</li></ul> |
