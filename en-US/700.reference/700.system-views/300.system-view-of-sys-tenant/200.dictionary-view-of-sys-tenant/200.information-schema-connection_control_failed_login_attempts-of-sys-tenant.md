# information_schema.CONNECTION_CONTROL_FAILED_LOGIN_ATTEMPTS

## Overview

The `information_schema.CONNECTION_CONTROL_FAILED_LOGIN_ATTEMPTS` view displays the number of failed login attempts by different users.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| ----------------- | -------------- | ---------------- | ---------------------------------------------------------------- |
| USERHOST | varchar(261) | NO | Represents the combination of username and host information for a failed login attempt, in the format of `<user_name>@<hostname or ip address>` |
| FAILED_ATTEMPTS | bigint(20) | NO | Number of Failed Login Attempts |

## Sample query

Views the number of failed login attempts by a user.

```shell
obclient> SELECT * FROM information_schema.CONNECTION_CONTROL_FAILED_LOGIN_ATTEMPTS;
```

The query result is as follows:

```shell
+-------------+-----------------+
| USERHOST    | FAILED_ATTEMPTS |
+-------------+-----------------+
| 'test'@'%'  |               5 |
+-------------+-----------------+
1 row in set
```
