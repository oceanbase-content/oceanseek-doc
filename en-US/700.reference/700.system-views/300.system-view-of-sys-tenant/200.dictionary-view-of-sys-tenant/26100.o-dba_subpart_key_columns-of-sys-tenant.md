# oceanbase.DBA_SUBPART_KEY_COLUMNS

## Overview

Displays the columns contained in the subpartitioning key for all partition objects of the current tenant.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| -------------------- | --------------- | ---------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| OWNER | varchar(128) | NO | Owner of a partitioned table or partitioned index |
| NAME | varchar(128) | NO | The name of the partitioned table or partitioned index. |
| OBJECT_TYPE | varchar(5) | NO | Type of the partition object:<ul><li>TABLE</li><li>INDEX</li></ul> |
| COLUMN_NAME | text | NO | Column name |
| COLUMN_POSITION | bigint(21) | NO | Position in the Partitioning Key |
| COLLATED_COLUMN_ID | bigint(0) | NO | This field is not currently supported and defaults to NULL. |

## Sample query

The system tenant queries the columns contained in subpartitions of the partitioned table `tbl2_f_rl` within its own tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_SUBPART_KEY_COLUMNS WHERE NAME='tbl2_f_rl';
```

The query result is as follows:

```shell
+-------+-----------+-------------+-------------+-----------------+--------------------+
| OWNER | NAME      | OBJECT_TYPE | COLUMN_NAME | COLUMN_POSITION | COLLATED_COLUMN_ID |
+-------+-----------+-------------+-------------+-----------------+--------------------+
| test  | tbl2_f_rl | TABLE       | col2        |               1 |               NULL |
+-------+-----------+-------------+-------------+-----------------+--------------------+
1 row in set
```
