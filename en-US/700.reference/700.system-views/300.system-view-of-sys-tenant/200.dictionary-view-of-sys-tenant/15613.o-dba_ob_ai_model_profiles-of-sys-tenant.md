# oceanbase.DBA_OB_AI_MODEL_PROFILES

<main id="notice" type='explain'>
    <h4>Note</h4>
    <p>This view is available starting with V4.6.2.1. </p>
</main>

## Overview

Displays the AI model profile configuration information for the current tenant. You can view the `provider/model` level parameters created or updated by using the `ALTER_MODEL_PROFILE` PL procedure.

## Columns

| field | Type | Is NULL | Description |
| --- | --- | --- | --- |
| MODEL | varchar(513) | NO | The full model name is `provider_name` and `model_name` with `/` Concatenated results, for example, `aliyun/qwen-plus`. |
| MODEL_CONFIG | varchar(4096) | YES | Model API call parameters JSON, corresponding to `ALTER_MODEL_PROFILE` in the `model_config`. |
| RUN_CONFIG | varchar(4096) | YES | JSON for model runtime options on the OceanBase side, corresponding to `ALTER_MODEL_PROFILE` in the `run_config`. |
| CREATE_TIME | timestamp(6) | NO | Creation time. |
| UPDATE_TIME | timestamp(6) | NO | Last modified at. |

## Sample query

This example shows how to query the parameter configuration information of AI models in the current tenant.

1. If vendor configuration has not been registered, execute `REGISTER_PROVIDER` first, and replace `access_key` and `base_url` with the actual values:

    ```shell
    CALL DBMS_AI_SERVICE.REGISTER_PROVIDER('test-provider', '{
    "protocol": "openai",
    "base_url": "https://xxx",
    "access_key": "sk-xxx"
    }');
    ```

2. Use `ALTER_MODEL_PROFILE` to set parameters for the model:

    ```shell
    CALL DBMS_AI_SERVICE.ALTER_MODEL_PROFILE('test-provider/test-model', '{
    "model_config": {
        "max_tokens": 4096,
        "temperature": 0
    },
    "run_config": {
        "batch_size": 16,
        "max_image_size": 4194304,
        "min_concurrency": 10,
        "max_concurrency": 100
    }
    }');
    ```

3. Query model parameter configuration information:

    ```sql
    SELECT MODEL, MODEL_CONFIG, RUN_CONFIG
    FROM oceanbase.DBA_OB_AI_MODEL_PROFILES
    WHERE MODEL = 'test-provider/test-model';
    ```

    The sample result is as follows:

    ```shell
    MODEL	MODEL_CONFIG	RUN_CONFIG
    test-provider/test-model	{"max_tokens": 4096, "temperature": 0}	{"batch_size": 16, "max_image_size": 4194304, "max_concurrency": 100, "min_concurrency": 10}
    1 row in set
    ```
