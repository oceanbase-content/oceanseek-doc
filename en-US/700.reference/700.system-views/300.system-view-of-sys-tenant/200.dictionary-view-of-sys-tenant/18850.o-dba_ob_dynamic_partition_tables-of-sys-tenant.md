# oceanbase.DBA_OB_DYNAMIC_PARTITION_TABLES

## Overview

Displays the dynamic partitioned table information of the current tenant.

## Columns

| field | Type | Is NULL | Description |
| -------------------- | --------------- | ------------- | ------ |
| DATABASE_NAME | varchar(128) | NO | The name of the database where the dynamic partitioned table is located. |
| TABLE_NAME | varchar(256) | NO | The name of the dynamic partitioned table. |
| TABLE_ID | bigint(20) | NO | The ID of the dynamic partitioned table. |
| MAX_HIGH_BOUND_VAL | varchar(4096) | NO | The upper bound of the maximum RANGE partition. |
| ENABLE | varchar(4096) | NO | Specifies whether to enable dynamic partition management. |
| TIME_UNIT | varchar(4096) | NO | Dynamically partitioned management `time_unit`. |
| PRECREATE_TIME | varchar(4096) | NO | Dynamically partitioned management `precreate_time`. |
| EXPIRE_TIME | varchar(4096) | NO | Dynamically partitioned management `expire_time`. |
| TIME_ZONE | varchar(4096) | NO | Dynamically partitioned management `time_zone`. |
| BIGINT_PRECISION | varchar(4096) | NO | Dynamic partition management `bigint_precision`. |
