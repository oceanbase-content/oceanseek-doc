# mysql.default_roles

## Overview

The `mysql.default_roles` view displays the roles that are enabled by default for users.

## Columns

| **Column** | **Type** | **Is NULL** | **Description** |
| -------- | -------- | --------------- | -------- |
| HOST | varchar(255) | NO | Account Host Name |
| USER | varchar(128) | NO | Account Name |
| DEFAULT_ROLE_HOST | varchar(255) | NO | Host Name of the Default Enabled Role |
| DEFAULT_ROLE_USER | varchar(128) | NO | Account name of the role enabled by default |

## Sample query

Query the default enabled roles for user `user001`.

1. Create a role named `role1`.

   ```shell
   obclient [oceanbase]> CREATE ROLE IF NOT EXISTS role1;
   Query OK, 0 rows affected, 1 warning
   ```

2. Grant the `ALTER SYSTEM` privilege to the role `role1`.

   ```shell
   obclient [oceanbase]> GRANT ALTER SYSTEM ON *.* TO role1;
   ```

3. Create a new user named `user001`.

   ```shell
   obclient [oceanbase]> CREATE USER 'user001'@'%' IDENTIFIED BY '******';
   ```

4. Grant the role `role1` to the newly created user `user001`.

   ```shell
   obclient [oceanbase]>GRANT role001 TO user001 WITH ADMIN OPTION;;
   ```

5. Specify that the user `user001` is granted all roles by default upon login.

   ```shell
   obclient > SET DEFAULT ROLE ALL TO user001;
   ```

6. Query the roles that are enabled by default for user `user001`.

   ```shell
   obclient > SELECT * FROM mysql.default_roles;
   ```

   The query result is as follows:

   ```shell
   +------+---------+-------------------+-------------------+
   | HOST | USER    | DEFAULT_ROLE_HOST | DEFAULT_ROLE_USER |
   +------+---------+-------------------+-------------------+
   | %    | user001 | %                 | role001           |
   +------+---------+-------------------+-------------------+
   1 row in set (0.001 sec)
   ```
