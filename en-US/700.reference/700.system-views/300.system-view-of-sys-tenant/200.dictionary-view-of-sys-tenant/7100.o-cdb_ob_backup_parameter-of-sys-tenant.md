# oceanbase.CDB_OB_BACKUP_PARAMETER

## Overview

Displays the backup parameter information configured for all tenants.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| NAME | varchar(1024) | NO | Parameter name |
| VALUE | longtext | NO | Parameter Value |

## Sample query

In the sys tenant, view the backup parameter configurations of all tenants.

```shell
obclient[oceanbase]> SELECT * FROM oceanbase.CDB_OB_BACKUP_PARAMETER;
```

The query result is as follows:

```shell
+-----------+------------------+------------------------------------------------------------------------------------------------------------------------------+
| TENANT_ID | NAME             | VALUE                                                                                                                        |
+-----------+------------------+------------------------------------------------------------------------------------------------------------------------------+
|      1002 | data_backup_dest | s3://example_path/data?host=***&access_id=******&access_key=******&checksum_type=md5    |
+-----------+------------------+------------------------------------------------------------------------------------------------------------------------------+
1 row in set
```

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>The sensitive information in the example, such as <code>host</code>, <code>access_id</code>, and <code>access_key</code>, has been masked.</p>
</main>
