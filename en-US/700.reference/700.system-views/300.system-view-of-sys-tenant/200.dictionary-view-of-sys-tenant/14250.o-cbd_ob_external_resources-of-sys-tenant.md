# oceanbase.CDB_OB_EXTERNAL_RESOURCES

## Overview

The `oceanbase.CDB_OB_EXTERNAL_resources` view is used to display all uploaded resource files under the sys tenant.

| **Field** | **Type** | **Nullable** | **Description** |
| ------------ | ------------- | --------------------- | ---------------------------------------- |
| TENANT_ID | bigint(20) | NO | The ID of the tenant to which the resource belongs. |
| RESOURCE_ID | bigint(20) | NO | Resource ID, which is the unique identifier of a resource. |
| DATABASE_ID | bigint(20) | NO | The ID of the database to which the resource belongs. |
| NAME | varchar(256) | NO | Resource name. |
| TYPE | varchar | NO | Resource type, used to distinguish between resources such as Java JAR files or Python source code. The current valid values are {'JAVA_JAR', 'PYTHON_PY'. |
| CONTENT | longblob | NO | The binary content of the resource. |
| COMMENT | varchar(4096) | NO | A comment added when uploading the resource. |

## Sample query

```shell
obclient > SELECT * FROM oceanbase.CDB_OB_EXTERNAL_RESOURCES;
```
