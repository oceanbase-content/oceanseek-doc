# oceanbase.DBA_TAB_HISTOGRAMS

## Overview

Displays histograms for all columns in the current tenant.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --- | --- | --- | --- |
| OWNER | varchar(128) | NO | User to Which the Histogram Belongs |
| TABLE_NAME | varchar(128) | NO | Table Name of the Histogram |
| COLUMN_NAME | varchar(128) | NO | Column Name of the Histogram |
| ENDPOINT_NUMBER | decimal(10,0) | NO | Cumulative Frequency of Buckets |
| ENDPOINT_VALUE | decimal(10,0) | NO | Normalized Bucket Endpoint Value |
| ENDPOINT_ACTUAL_VALUE | text | NO | Bucket Endpoint Value |
| ENDPOINT_ACTUAL_VALUE_RAW | text | NO | Binary value of the bucket endpoint |
| ENDPOINT_REPEAT_COUNT | decimal(10,0) | NO | Frequency of Bucket Endpoint Values |
| SCOPE | varchar(7) | NO | Range of the histogram |

## Sample query

In the sys tenant, view the table-level histogram information of the `t_subpart` table in the current tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_TAB_HISTOGRAMS WHERE TABLE_NAME='t_subpart';
```
