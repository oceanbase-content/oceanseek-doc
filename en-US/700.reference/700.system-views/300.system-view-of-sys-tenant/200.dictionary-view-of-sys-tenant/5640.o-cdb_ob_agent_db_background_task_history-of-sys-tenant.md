# oceanbase.CDB_OB_AGENT_DB_BACKGROUND_TASK_HISTORY

## Overview

The `CDB_OB_AGENT_DB_BACKGROUND_TASK_HISTORY` view displays the history of all completed background deletion tasks for logical tables in all tenants.

## Columns

| field | Type | Is NULL | Description |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | Tenant ID. |
| DATABASE_NAME | varchar(128) | NO | The name of the database. |
| COLLECTION_NAME | varchar(256) | NO | The name of the collection. |
| NAMESPACE_NAME | varchar(256) | NO | Namespace name. |
| LTABLE_NAME | varchar(256) | NO | The name of the logical table.<ul><li>`NAMESPACE_DELETE` The scenario value is an empty string (`''`).</li><li>`HOT_NAMESPACE_EXPIRE` The scenario value is an empty string (`''`).</li></ul> |
| OPERATION_TYPE | varchar(32) | NO | Operation type. Valid values:<ul><li>`LTABLE_DELETE`</li><li>`NAMESPACE_DELETE`</li><li>`HOT_NAMESPACE_EXPIRE`</li></ul> |
| OPERATION_STATUS | varchar(32) | NO | Operation status. Valid values: <ul><li>`COMPLETED`</li><li>`FAILED`</li></ul> |
| START_TIME | timestamp | NO | The task start time. |
| FINISH_TIME | timestamp | NO | End time of the task. |
| ELAPSED_TIME | bigint | NO | Time consumed in deleting tasks, in microseconds. |
| TOTAL_DELETED_ROWS | bigint | NO | <ul><li>`LTABLE_DELETE` / `NAMESPACE_DELETE` Scenario: Indicates that the logical table has been deleted. `<collection_id>_kv_data_table` The number of rows in the physical table. </li><li>`HOT_NAMESPACE_EXPIRE` Scenario: The value is `0`.</li></ul> |
| ORIGINAL_NAME | varchar(256) | NO | Original name of the deleted object. |
| RET_CODE | varchar(512) | NO | Error code name. |

## Sample query

Query the history of background deletion tasks for logical tables completed by all tenants in the sys tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.CDB_OB_AGENT_DB_BACKGROUND_TASK_HISTORY;
```
