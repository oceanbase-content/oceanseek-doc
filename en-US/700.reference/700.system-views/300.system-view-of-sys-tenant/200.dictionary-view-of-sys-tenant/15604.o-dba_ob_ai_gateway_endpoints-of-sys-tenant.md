# oceanbase.DBA_OB_AI_GATEWAY_ENDPOINTS

<main id="notice" type='explain'>
    <h4>Note</h4>
    <p>This view is available starting with V4.6.2.1. </p>
</main>

## Overview

This view displays the details of the AI gateway endpoints for the current tenant. It is derived from the `endpoints` JSON field in the `DBA_OB_AI_GATEWAYS` view, making it convenient for troubleshooting routing configurations at the endpoint level.

## Columns

| field | Type | Is NULL | Description |
| --- | --- | --- | --- |
| GATEWAY_NAME | varchar(256) | NO | Gateway name. |
| ENDPOINT_NAME | varchar(256) | NO | Endpoint name. |
| MODEL | varchar(512) | NO | The full model name is `provider/model` format. |
| WEIGHT | int(11) | YES | Routing weight. When this parameter is set to NULL, the routing is based on the `0` Display. |
| CREATE_TIME | timestamp(6) | NO | The time when the gateway was created. |
| UPDATE_TIME | timestamp(6) | NO | The last modification time of the gateway. |

## Sample query

Query endpoint routing information under a specified gateway.

```sql
SELECT GATEWAY_NAME, ENDPOINT_NAME, MODEL, WEIGHT
FROM oceanbase.DBA_OB_AI_GATEWAY_ENDPOINTS
WHERE GATEWAY_NAME = 'test'
ORDER BY ENDPOINT_NAME;
```

The sample result is as follows:

```shell
GATEWAY_NAME	ENDPOINT_NAME	MODEL	WEIGHT
test	ep1	test-provider/test-model	70
test	ep2	test-provider/test-model2	30
2 rows in set
```
