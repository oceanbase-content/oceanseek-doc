# DBA_OB_TRUSTED_ROOT_CERTIFICATE

## Overview

The `DBA_OB_TRUSTED_ROOT_CERTIFICATE` view displays information such as the list of root certificates trusted by the OBServer cluster and their expiration dates.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| ------------ | -------- | ------------------ | -------- |
| COMMON_NAME | varchar(256) | NO | Common Name of the Certificate |
| DESCRIPTION | varchar(256) | NO | Certificate Source and Purpose Description |
| CERT_EXPIRED_TIME | timestamp(6) | NO | Certificate Expiration Time |

## Sample query

Query the list of root CA certificates trusted by the OBServer cluster and information such as their expiration dates.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_TRUSTED_ROOT_CERTIFICATE;
```
