# oceanbase.DBA_OB_ARCHIVELOG_PIECE_FILES

## Overview

Displays the status of pieces in the backup set of the current tenant. The `sys` tenant and the Meta tenant do not support physical backup.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --- | --- | --- | --- |
| DEST_ID | bigint(20) | NO | Path number. The system assigns a unique ID to each configured path. |
| ROUND_ID | bigint(20) | NO | Identifies the round of complete clog backup data streams |
| PIECE_ID | bigint(20) | NO | Backup Log Shard ID |
| INCARNATION | bigint(20) | NO | Indicates the number of forks after a flashback database operation. |
| DEST_NO | bigint(20) | NO | Identifies the log_archive_dest_n, for example, log_archive_dest_0 indicates that dest_no is 0, and log_archive_dest_1 indicates that dest_no is 1. |
| STATUS | varchar(64) | NO | Status of the piece:<ul><li>ACTIVE: The current active piece.</li><li>FREEZING: The piece is being frozen.</li><li>FROZEN: The piece has been frozen. After this state, the piece's status will not change.</li></ul> |
| START_SCN | bigint(20) unsigned | NO | Actual Start Offset of Piece |
| START_SCN_DISPLAY | datetime(6) | NO | Display of START_SCN after conversion to time unit |
| CHECKPOINT_SCN | bigint(20) unsigned | NO | Current Archive Point |
| CHECKPOINT_SCN_DISPLAY | datetime(6) | NO | Display after converting CHECKPOINT_SCN to time units |
| MAX_SCN | bigint(20) unsigned | NO | Maximum Archive Timestamp |
| END_SCN | bigint(20) unsigned | NO | Theoretically final piece offset |
| END_SCN_DISPLAY | datetime(6) | NO | End time of the piece |
| COMPATIBLE | bigint(20) | NO | Compatible version number for log archiving |
| UNIT_SIZE | bigint(20) | NO | The size of a log block that is compressed or encrypted during log archiving. This field is not supported at present. |
| COMPRESSION | varchar(128) | NO | Compression algorithm:<ul><li> none: no compression</li><li> lz4_1.0: the lz4_1.0 algorithm</li><li>zstd_1.3.8: the zstd_1.3.8 algorithm</li></ul>This field is not supported. |
| INPUT_BYTES | bigint(20) | NO | Original data volume, in bytes |
| INPUT_BYTES_DISPLAY | varchar(27) | NO | Display after converting the unit of INPUT_BYTES |
| OUTPUT_BYTES | bigint(20) | NO | Effective data volume after encryption and compression |
| OUTPUT_BYTES_DISPLAY | varchar(27) | NO | Display of OUTPUT_BYTES after unit conversion |
| COMPRESSION_RATIO | decimal(23,2) | NO | Compression ratio. This field is not supported. |
| FILE_STATUS | varchar(64) | NO | File status of backup log shards:<ul><li>AVAILABLE: The backup is valid and can be used for restore.</li><li>COPYING: The log file is being backed up.</li><li>INCOMPLETE: The logs under the piece are incomplete, missing some log streams.</li><li>DELETING: The log file is being deleted.</li><li>EXPIRED: The backup file has expired.</li><li>BROKEN: The backup file is incomplete and unusable.</li><li>DELETED: The log file has been deleted.</li></ul> |
| PATH | varchar(2048) | NO | Archive Path |
