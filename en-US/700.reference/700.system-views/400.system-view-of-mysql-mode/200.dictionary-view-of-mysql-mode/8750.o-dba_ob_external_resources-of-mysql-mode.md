# oceanbase.DBA_OB_EXTERNAL_RESOURCES

## Overview

The `oceanbase.DBA_OB_EXTERNAL_resources` view displays the uploaded resource files.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| ------------ | ------------- | --------------------- | ---------------------------------------- |
| RESOURCE_ID | bigint(20) | NO | Resource ID, which is the unique identifier of a resource. |
| DATABASE_ID | bigint(20) | NO | The ID of the database to which the resource belongs. |
| NAME | varchar(256) | NO | Resource name. |
| TYPE | varchar(12) | NO | Resource type, used to distinguish resources such as Java JAR files or Python source code. Currently, the valid values are {'JAVA_JAR', 'PYTHON_PY'. |
| CONTENT | longblob | NO | The binary content of the resource. |
| COMMENT | varchar(4096) | NO | A comment added when uploading the resource. |

## Sample query

Execute the following SQL statement to query the resource files uploaded by the current tenant.

```shell
obclient > SELECT * FROM oceanbase.DBA_OB_EXTERNAL_RESOURCES;
```
