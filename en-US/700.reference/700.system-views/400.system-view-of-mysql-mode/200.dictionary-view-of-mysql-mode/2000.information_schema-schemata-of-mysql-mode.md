# information_schema.SCHEMATA

## Overview

Displays database metadata.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| ---------------------------- | -------------- | ---------------- | --------- |
| CATALOG_NAME | varchar(3) | NO | Fixed value def |
| SCHEMA_NAME | varchar(128) | NO | Database Name |
| DEFAULT_CHARACTER_SET_NAME | varchar(7) | NO | Default Character Set |
| DEFAULT_COLLATION_NAME | varchar(18) | NO | Default comparison rule |
| SQL_PATH | null | NO | NULL |
| DEFAULT_ENCRYPTION | varchar(2) | NO | Whether to encrypt by default |

## Sample query

Query the metadata of all databases in the current tenant.

```shell
obclient [oceanbase]> SELECT * FROM information_schema.SCHEMATA;
```
