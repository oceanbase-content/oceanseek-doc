# mysql.user


## Overview

Displays the user's global privileges (VIRTUAL_TABLE).

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| ------------------------ | --------------- | ---------------- | --------------------------------------------------- |
| host | varchar(128) | NO | Host name |
| user | varchar(128) | NO | Username |
| password | varchar(128) | NO | User Password |
| select_priv | varchar(1) | NO | Whether the SELECT statement is executable |
| insert_priv | varchar(1) | NO | Whether the INSERT statement can be executed |
| update_priv | varchar(1) | NO | Whether the UPDATE statement is executable. |
| delete_priv | varchar(1) | NO | Whether the DELETE statement is executable |
| create_priv | varchar(1) | NO | Whether the CREATE statement can be executed |
| drop_priv | varchar(1) | NO | Whether the DROP statement is executable |
| reload_priv | varchar(1) | NO | Whether the flush statement is executable. This field is not currently used. |
| shutdown_priv | varchar(1) | NO | Whether the shutdown command can be executed. This field is currently not used. |
| process_priv | varchar(1) | NO | Whether to query active thread information |
| file_priv | varchar(1) | NO | Whether the file read/write permission is granted. This field is not currently used. |
| grant_priv | varchar(1) | NO | Whether the authorization statement can be executed |
| reference_priv | varchar(1) | NO | Not Used |
| index_priv | varchar(1) | NO | Whether an index can be created |
| alter_priv | varchar(1) | NO | Whether ALTER statements are allowed |
| show_db_priv | varchar(1) | NO | executable `show database` statement |
| super_priv | varchar(1) | NO | Whether to Execute Superuser Statements |
| create_tmp_table_priv | varchar(1) | NO | Whether temporary tables can be created. (Not used.) |
| lock_tables_priv | varchar(1) | NO | executable `lock tables` Statement. This field is not currently used. |
| execute_priv | varchar(1) | NO | Whether the stored procedure is executable. This field is not currently used. |
| repl_slave_priv | varchar(1) | NO | Not Used |
| repl_client_priv | varchar(1) | NO | Not Used |
| create_view_priv | varchar(1) | NO | Whether the view can be created |
| show_view_priv | varchar(1) | NO | executable `show create view` statement |
| create_routine_priv | varchar(1) | NO | Whether a stored procedure can be created. This field is not currently used. |
| alter_routine_priv | varchar(1) | NO | Whether the stored procedure can be modified. This field is currently not used. |
| create_user_priv | varchar(1) | NO | executable `create user` statement |
| event_priv | varchar(1) | NO | Whether to allow creating, changing, or deleting events. This field is not currently used. |
| trigger_priv | varchar(1) | NO | Whether the user has the privilege to operate on triggers. This field is not currently used. |
| create_tablespace_priv | varchar(1) | NO | Whether a tablespace can be created. This field is not currently used. |
| ssl_type | varchar(10) | NO | This field is not currently used. |
| ssl_cipher | varchar(1024) | NO | This field is not currently used. |
| x509_issuer | varchar(1024) | NO | This field is not currently used. |
| x509_subject | varchar(1024) | NO | This field is not currently used. |
| max_questions | bigint(20) | NO | Maximum Queries Per Hour (Unused) |
| max_updates | bigint(20) | NO | Maximum number of updates a user can perform per hour. This field is currently not used. |
| max_connections | bigint(20) | NO | Maximum number of connections a user can receive per hour. This field is not currently used. |
| max_user_connections | bigint(20) | NO | Maximum number of concurrent connections. This field is not currently used. |
| plugin | varchar(1024) | NO | This field is not currently used. |
| authentication_string | varchar(1024) | NO | This field is not currently used. |
| password_expired | varchar(1) | NO | Whether the user password has expired. This field is not currently used. |
| account_locked | varchar(1) | NO | Whether the user is locked |
| drop_database_link_priv | varchar(1) | NO | Whether to delete the database link |
| create_database_link_priv | varchar(1) | NO | Whether to create a database link |
| create_role_priv | varchar(1) | NO | Whether to create a role |
| drop_role_priv | varchar(1) | NO | Whether the role can be deleted. |

obclient [oceanbase]> SELECT * FROM mysql.user WHERE user=''test3'\G
