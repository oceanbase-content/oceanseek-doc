# oceanbase.DBA_OB_TABLET_REPLICAS

## Overview

Displays information for all tablet replicas of the current tenant. Each tablet replica is uniquely identified by a composite key: `<TABLET_ID, SVR_IP, SVR_PORT, LS_ID>`.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --------------- | ------------- | ------------ | ------------------------------------------------------------ |
| CREATE_TIME | timestamp(6) | NO | Creation Time |
| MODIFY_TIME | timestamp(6) | NO | Modified At |
| TABLET_ID | bigint(20) | NO | TABLET ID |
| SVR_IP | varchar(46) | NO | Server IP Address |
| SVR_PORT | bigint(20) | NO | Server Port Number |
| LS_ID | bigint(20) | NO | Log stream ID of the tablet |
| COMPACTION_SCN | bigint(20) unsigned | NO | Data Snapshot Version Number |
| DATA_SIZE | bigint(20) | NO | Actual data size, in bytes |
| REQUIRED_SIZE | bigint(20) | NO | The size of the data allocation space, in bytes. Data storage is based on macroblocks (2 MB) as the minimum unit, so `REQUIRED_SIZE >= DATA_SIZE` |

## Sample query

View the tablet replica information of the current tenant and display the first 10 records.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_TABLET_REPLICAS LIMIT 10;
```
