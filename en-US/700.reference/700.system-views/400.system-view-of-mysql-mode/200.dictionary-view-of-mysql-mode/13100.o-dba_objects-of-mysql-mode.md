# oceanbase.DBA_OBJECTS

## Overview

The `oceanbase.DBA_OBJECTS` view displays all database objects. Its definition is the same as that of the `ALL_OBJECTS` view.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ------------------- | -------------- | ------------ | ------------------------------- |
| OWNER | varchar(128) | NO | Owner of the object |
| OBJECT_NAME | varchar(128) | NO | Object Name |
| SUBOBJECT_NAME | varchar(128) | NO | Subobject name (for example, partition) |
| OBJECT_ID | bigint(20) | NO | Dictionary ID of the object |
| DATA_OBJECT_ID | bigint(20) | NO | Dictionary ID of the segment containing this object |
| OBJECT_TYPE | varchar(23) | NO | Object types, including tables, indexes, partitions, packages, stored procedures, synonyms, sequences, etc. |
| CREATED | datetime | NO | Object creation time |
| LAST_DDL_TIME | datetime | NO | Last DDL Time of Object |
| TIMESTAMP | datetime | NO | Object specified timestamp, output as a character |
| STATUS | varchar(7) | NO | Object status: <ul><li>>VALID: valid.</li><li>INVALID: invalid. </li></ul> |
| TEMPORARY | varchar(1) | NO | Indicates that the object is a temporary object. |
| GENERATED | varchar(1) | NO | Indicates whether the object name was generated by the system. |
| SECONDARY | varchar(1) | NO | This field is not currently used. |
| NAMESPACE | bigint(1) | NO | Object Namespace |
| EDITION_NAME | varchar(128) | NO | Reserved Fields |
| SHARING | varchar(18) | NO | The default value is `NULL` |
| EDITIONABLE | varchar(1) | NO | Default value: `NULL` |
| ORACLE_MAINTAINED | varchar(1) | NO | Default value: `NULL` |
| APPLICATION | varchar(1) | NO | Default value: `NULL` |
| DEFAULT_COLLATION | varchar(1) | NO | Default value: `NULL` |
| DUPLICATED | varchar(1) | NO | The default value is `NULL` |
| SHARDED | varchar(1) | NO | The default value is `NULL` |
| IMPORTED_OBJECT | varchar(1) | NO | Default value: `NULL` |
| CREATED_APPID | bigint(0) | NO | The default value is `NULL` |
| CREATED_VSNID | bigint(0) | NO | Default value: `NULL` |
| MODIFIED_APPID | bigint(0) | NO | Default value: `NULL` |
| MODIFIED_VSNID | bigint(0) | NO | Default value: `NULL` |

## Sample query

Query the object information of all databases in the database.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OBJECTS limit 1 \G
```
