# information_schema.PROCESSLIST


## Overview

Provides information about running threads.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| ---------- | --------------------- | ---------------- | -------------- |
| ID | bigint(20) unsigned | NO | Connection Identifier<ul><li>In direct connection mode:<br>This field indicates the server session ID.</li> <li>In ODP mode:</li><ul><li>When the ODP parameter <code>client_session_id_version = 2</code> is set, this field indicates the client session ID. </li> <li>When <code>client_session_id_version = 1</code> is set, this field indicates the server session ID.</li></ul></ul> |
| USER | varchar(32) | NO | Username |
| HOST | varchar(128) | NO | Client Host Name |
| DB | varchar(128) | YES | Database Name |
| COMMAND | varchar(4096) | NO | Types of Commands Executed by Threads |
| TIME | bigint(20) | NO | Duration of the thread in the current state, in seconds. |
| STATE | varchar(128) | YES | Indicates the task identifier that the thread is currently working on. |
| INFO | varchar(262143) | YES | Statement Being Executed by the Current Thread |

## Sample query

Query all running thread information for the current user tenant.

```shell
obclient [oceanbase]> SELECT * FROM information_schema.PROCESSLIST;
```
