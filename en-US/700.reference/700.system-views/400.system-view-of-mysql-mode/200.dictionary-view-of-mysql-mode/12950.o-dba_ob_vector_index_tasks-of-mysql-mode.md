# oceanbase.DBA_OB_VECTOR_INDEX_TASKS

## Overview

The `DBA_OB_VECTOR_INDEX_TASKS` view displays information about all background tasks related to vector indexes for the current tenant, including partition rebuilding, segment minor compaction and major compaction, IVF cluster center loading and cleanup, semantic index refresh, and memory synchronization. You can distinguish task types by using the `TASK_TYPE` column in the view.

## Sample query

### Complete example

In the sys tenant, view the performance optimization task information for vector indexes of all tenants.

```sql
SELECT * FROM oceanbase.DBA_OB_VECTOR_INDEX_TASKS ORDER BY MODIFY_TIME DESC\G;
```


The following table describes the fields of the TASK_INFO string.

| **Field** | **JSON field types** | **Meaning** |
| --- | --- | --- |
| merge_segments_cnt | string | Number of Segments to Be Merged |
| merge_segments | array | Segment information before major compaction. The number of segments is equal to merge_segments_cnt. |
| result_segments | array | Information on the Merged Segment |
| scn | string | Internal Timestamp |
| start_key | string | Upper Bound of Segment Storage Range |
| end_key | string | Lower bound of segment storage range |
| index_type | string | The index type for processing vectors. Valid values: <ul><li>HNSW</li><li>HNSW_SQ</li><li>HNSW_BQ</li><li>HGRAPH</li><li>SINDI</li></ul> |
| mem_used | string | Memory Used by Segments |
| mem_limit_info | object | Memory Throttling Information, Including `task_memory_limited`, `vector_mem_hold`, `vector_mem_limit`, `task_estimate_memory`, `tasks_total_reserved_memory` and other fields. This only occurs in memory-intensive tasks such as partition-level index rebuilding or incremental segment merging. |
| min_vid | string | Minimum Vector ID of a Segment |
| max_vid | string | Maximum Vector ID of a Segment |

### View memory throttling information

For memory-intensive tasks such as partition-level index rebuilding or incremental segment merging, the task information may include a `mem_limit_info` section that records memory throttling details. You can query the following SQL statement to obtain memory estimation and throttling information:

```sql
SELECT
  TABLET_ID,
  TASK_TYPE,
  JSON_EXTRACT(TASK_INFO, '$.mem_limit_info.task_estimate_memory') AS estimate_mem,
  JSON_EXTRACT(TASK_INFO, '$.mem_limit_info.vector_mem_hold') AS mem_hold,
  JSON_EXTRACT(TASK_INFO, '$.mem_limit_info.vector_mem_limit') AS mem_limit,
  JSON_EXTRACT(TASK_INFO, '$.mem_limit_info.task_memory_limited') AS was_throttled
FROM OCEANBASE.DBA_OB_VECTOR_INDEX_TASKS
WHERE TASK_TYPE = 'PARTITION_REBUILD';
```

The subfields of the `mem_limit_info` field are described in detail as follows:

| **Subfield** | **Unit** | **Note** |
| --- | --- | ---- |
| `task_memory_limited` |  | Whether memory throttling has been triggered (true/false) |
| `vector_mem_hold` | byte | Tenant Vector Memory Usage During Task Scheduling |
| `vector_mem_limit` | byte | Total Tenant Vector Memory Limit |
| `task_estimate_memory` | byte | Estimated Memory Requirement for the Current Task |
| `tasks_total_reserved_memory` | byte | Total Reserved Memory for Other Running Tasks |
