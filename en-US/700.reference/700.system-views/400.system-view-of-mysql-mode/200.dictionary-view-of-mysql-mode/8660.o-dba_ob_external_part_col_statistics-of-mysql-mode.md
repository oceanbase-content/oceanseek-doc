# oceanbase.DBA_OB_EXTERNAL_PART_COL_STATISTICS

## Overview

This view is used to query partition-level statistics for external catalog external tables.

## Columns

| **Column** | **Type** | **Is NULL** | **Description** |
| ---------------- | ---------------- | ----------------- | ---------- |
| CATALOG_NAME | varchar(128) | NO | The name of the catalog. |
| DATABASE_NAME | varchar(128) | NO | The name of the database. |
| TABLE_NAME | varchar(128) | NO | The table name. |
| PARTITION_NAME | text | NO | Represents the value of the partitioning column. |
| COLUMN_NAME | varchar(128) | NO | Represents the partition column name. |
| NUM_DISTINCT | decimal(20,0) | NO | Represents the deduplication count. |
| LOW_VALUE | varchar(128) | NO | Represents the minimum value. |
| HIGH_VALUE | varchar(128) | NO | Represents the maximum value. |
| DENSITY | decimal(30,10) | NO | Indicates the data distribution density. |
| NUM_NULLS | decimal(20,0) | NO | Represents the number of NULL values. |
| NUM_BUCKETS | decimal(20,0) | NO | This field currently has no practical meaning. |
| LAST_ANALYZED | datetime(6) | NO | Indicates the latest sampling time for analysis. |
| LAST_MODIFIED | datetime(6) | NO | Indicates the last time statistics were written. |
| SAMPLE_SIZE | decimal(10,0) | NO | Represents the sample size. |
| AVG_COL_LEN | decimal(10,0) | NO | The average column length. |
| HISTOGRAM      | varchar(15)    | NO              | This field has no practical meaning at present. |
