# oceanbase.DBA_OB_CCL_RULES

## Overview

Records all current throttling rules for a user tenant.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| CCL_RULE_ID | bigint(20) | NO | Throttling Rule ID |
| CCL_RULE_NAME | varchar(128) | NO | Throttling Rule Name |
| AFFECT_USER_NAME | varchar(128) | NO | Number of users affected by rate limiting |
| AFFECT_HOST | varchar(128) | NO | IP Address for Throttling |
| AFFECT_FOR_ALL_DATABASES | tinyint(4) | NO | Whether it takes effect on all databases |
| AFFECT_FOR_ALL_TABLES | tinyint(4) | NO | Whether to apply to all tables |
| AFFECT_DML | bigint(20) | NO | DML Statements Subject to Rate Limiting |
| AFFECT_DATABASE | bigint(20) | YES | Databases where throttling takes effect |
| AFFECT_TABLE | bigint(20) | YES | Tables with Throttling in Effect |
| AFFECT_SCOPE | bigint(10) | NO | Throttling granularity:<ul><li>Rule level: 0 </li><li>Format SQLID level:1</li></ul> |
| CCL_KEYWORDS | varchar(1048576) | NO | Throttling keywords |
| MAX_CONCURRENCY | bigint(20) | NO | Maximum concurrency for rate limiting |

## Sample query

You can query the throttling rules of the current tenant.

```shell
obclient[oceanbase]> SELECT * FROM DBA_OB_CCL_RULES;
```
