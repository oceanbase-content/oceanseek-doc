# oceanbase.DBA_OB_SYS_VARIABLES

## Overview

The `DBA_OB_SYS_VARIABLES` view displays the configurations of system variables for the current tenant, including hidden variables that start with an underscore (_).

## Columns

| **Column** | **Type** | **Is NULL** | **Description** |
| -------- | -------- | --------------- | -------- |
| CREATE_TIME | timestamp(6) | YES | Creation Time |
| MODIFY_TIME | timestamp(6) | YES | Modified At |
| NAME | varchar(128) | NO | System Variable Name |
| VALUE | varchar(65536) | YES | Current value of system variable |
| MIN_VALUE | varchar(65536) | NO | Minimum Value |
| MAX_VALUE | varchar(65536) | NO | Maximum Value |
| SCOPE | varchar(16) | NO | System Variable Level |
| INFO | varchar(4096) | NO | Information |
| DEFAULT_VALUE | varchar(65536) | YES | Default value of system variables |
| ISDEFAULT | varchar(3) | NO | Whether it is the default value. |

## Sample query

View information about the system variable `ob_query_timeout` for this tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_SYS_VARIABLES WHERE NAME='ob_query_timeout';
```

The query result is as follows:

```shell
+----------------------------+----------------------------+------------------+----------+-----------+-----------+------------------+----------------------------------+---------------+-----------+
| CREATE_TIME                | MODIFY_TIME                | NAME             | VALUE    | MIN_VALUE | MAX_VALUE | SCOPE            | INFO                             | DEFAULT_VALUE | ISDEFAULT |
+----------------------------+----------------------------+------------------+----------+-----------+-----------+------------------+----------------------------------+---------------+-----------+
| 2024-07-23 15:19:59.763474 | 2024-07-23 15:19:59.763474 | ob_query_timeout | 10000000 |           |           | GLOBAL | SESSION | Query timeout in microsecond(us) | 10000000      | YES       |
+----------------------------+----------------------------+------------------+----------+-----------+-----------+------------------+----------------------------------+---------------+-----------+
1 row in set
```
