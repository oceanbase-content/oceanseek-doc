# oceanbase.DBA_OB_TABLEGROUP_PARTITIONS

<main id="notice" type='explain'>
<h4>Note</h4>
<ul>
<li>Since partitions are no longer a concept in table groups, this view is no longer used. Users can query it, but the result will be empty.</li>
<li>You can query table group information through the <a href="11800.o-dba_ob_tablegroups-of-mysql-mode.md">DBA_OB_TABLEGROUPS</a> view. For more details about table groups, see <a href="../../../300.database-object-management/400.manage-table-groups-of-mysql-mode/100.about-table-groups-of-mysql-mode.md">About table groups</a>.</li>
</ul>
</main>

## Overview

Displays the partition information of a table group.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| -------------------- | --------------- | ------------ | --------------------------- |
| TABLEGROUP_NAME | varchar(128) | NO | TABLEGROUP Name |
| COMPOSITE | varchar(3) | NO | Whether the partitioned table group is a subpartition. Valid values: `YES` or `NO` |
| PARTITION_NAME | varchar(64) | NO | The name of the partition in a partitioned table group. |
| SUBPARTITION_COUNT | bigint(20) | NO | The value is `NULL` |
| HIGH_VALUE | varchar(4096) | NO | The value is `NULL` |
| HIGH_VALUE_LENGTH | bigint(20) | NO | The value is `NULL` |
| PARTITION_POSITION | bigint(20) unsigned | NO   | This value is `NULL`.    |
