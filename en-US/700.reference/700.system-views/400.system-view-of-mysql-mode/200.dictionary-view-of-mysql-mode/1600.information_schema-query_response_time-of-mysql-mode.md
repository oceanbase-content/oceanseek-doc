# information_schema.QUERY_RESPONSE_TIME

## Overview

Displays data types such as RESPONSE TIME histograms for monitoring by Prometheus.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --- | --- | --- | --- |
| RESPONSE_TIME | bigint(14) | NO | Response Time |
| COUNT | bigint(14) | NO | Number of Requests Within the Response Time |
| TOTAL | bigint(14) | NO | Total Request Response Time |

## Sample query

View the RESPONSE TIME histogram for the current tenant.

```shell
obclient[test]> SELECT * FROM information_schema.information_schema.QUERY_RESPONSE_TIME;
```
