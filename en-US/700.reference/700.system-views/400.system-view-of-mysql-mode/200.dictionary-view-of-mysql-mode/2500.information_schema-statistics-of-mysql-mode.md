# information_schema.STATISTICS

## Overview

The `information_schema.STATISTICS` view is used to record table and index information.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ------- | ---- | -------------- | ---- |
| TABLE_CATALOG | varchar(512) | NO | Fixed value (def) |
| TABLE_SCHEMA | varchar(128) | NO | Database Name |
| TABLE_NAME | varchar(256) | NO | Table name |
| NON_UNIQUE | bigint(20) | NO | Whether it is a unique index |
| INDEX_SCHEMA | varchar(128) | NO | Database Name |
| INDEX_NAME | varchar(256) | NO | Index type |
| SEQ_IN_INDEX | bigint(20) unsigned | NO | Index Number |
| COLUMN_NAME | varchar(128) | NO | Column name |
| COLLATION | varchar(1) | NO | Comparison Method |
| CARDINALITY | bigint(0) | NO | Default value: `NULL` |
| SUB_PART | bigint(20) | NO | If a column is only partially indexed, the length is the number of characters that are indexed. If the entire column is indexed, the value is NULL. |
| PACKED | varchar(10) | NO | The default value is `NULL` |
| NULLABLE | varchar(3) | NO | Whether can be NULL |
| INDEX_TYPE | varchar(16) | NO | Data structure type used by index |
| COMMENT | varchar(16) | NO | Add comments or descriptions to indexes |
| INDEX_COMMENT | text | NO | Index Comment |
| IS_VISIBLE | varchar(3) | NO | Index visibility |
| EXPRESSION | varbinary(262144) | NO | For compatibility with MySQL only. Value: `NULL` |

## Sample query

Query the index information of a table.

```shell
obclient [none]> SELECT * FROM information_schema.STATISTICS limit 1 \G
```
