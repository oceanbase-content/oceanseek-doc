# oceanbase.DBA_WR_STATNAME

## Overview

Displays the name of the system statistic item for this tenant.

## Columns

| **Column** | **Type** | **Is NULL** | **Description** |
| --- | --- | --- | --- |
| CLUSTER_ID | bigint(20) | NO | Cluster ID |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| STAT_ID | bigint(20) | NO | Statistical Item ID |
| STAT_NAME | varchar(64) | NO | Statistical Item Name |

## Sample query

View the names of system statistics for the current tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_WR_STATNAME limit 1;
```

The return result is as follows:

```shell
    +------------+-----------+---------+---------------+
    | CLUSTER_ID | TENANT_ID | STAT_ID | STAT_NAME     |
    +------------+-----------+---------+---------------+
    |       4000 |         1 |   10000 | rpc packet in |
    +------------+-----------+---------+---------------+
    1 row in set (0.004 sec)
```
