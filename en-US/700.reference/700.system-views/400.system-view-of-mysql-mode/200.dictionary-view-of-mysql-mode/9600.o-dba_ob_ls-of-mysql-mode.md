# oceanbase.DBA_OB_LS

## Overview

Displays the status and recovery progress of log streams under the current tenant.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --------------- | --------------------- | ----------------------- | -------------------- |
| LS_ID | bigint(20) | NO | Log Stream ID |
| STATUS | varchar(100) | NO | The status of the log stream, including: <ul><li>`CREATING`: Log stream is being created.</li><li>`CREATED`: Log stream created.</li><li>`NORMAL`: Log streams can provide services.</li><li>`DROPPING`: The log stream is about to be deleted. You need to migrate the tablets on the log stream away.</li><li>`TENANT DROPPING`: The tenant where the log stream is located is being deleted, and the log stream needs to be deleted.</li><li>`WAIT OFFLINE`: Log stream data has been deleted and is waiting for GC.</li><li>`CREATE ABORT`: Log stream creation failed or not required, about to be deleted.</li></ul> |
| PRIMARY_ZONE | longtext | YES | Election Priority of Log Streams |
| UNIT_GROUP_ID | bigint(20) | NO | Unit Group ID <main id="notice" type='explain'><h4>Note</h4><p>The value of this field is always 0.</p></main> |
| LS_GROUP_ID | bigint(20) | NO | Log stream group ID. For system log streams (log stream 1) and broadcast log streams, this field displays as 0, indicating that the log stream does not belong to any log stream group. |
| CREATE_SCN | bigint(20) unsigned | NO | The timestamp when the log stream starts writing logs. |
| DROP_SCN | bigint(20) unsigned | NO | The log stream deletion timestamp, which is also the end timestamp of all user data. If the log stream is deleted, this field records the SCN at the time of deletion; if it is not deleted, this field is empty. |
| SYNC_SCN | bigint(20) unsigned | NO | The synchronization timestamp of the log stream, indicating the SCN of the last successfully synchronized transaction. |
| READABLE_SCN | bigint(20) unsigned | NO | The readable point of a log stream, indicating the minimum SCN at which the log stream can be read. |
| FLAG | varchar(2048) | NO | Log stream tag:<ul><li>NULL: normal log stream</li><li>DUPLICATE: broadcast log stream of a user tenant. A replicated table is created on this log stream.</li><li>BLOCK_TABLET_IN: indicates that a tablet cannot be created on this log stream.</li><li>DUPLICATE \| BLOCK_TABLET_IN: Broadcast log streams currently do not allow creating tablets.</li></ul> |
| UNIT_LIST     | varchar(1216)       | NO   | The list of units for distributing user log streams. This column is empty for system and broadcast log streams if no specific location is specified.  |

## Sample query

Users can view the status and recovery progress of log streams within their own tenant.

```shell
obclient(root@mysql001)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_LS;
```

The query result is as follows:

