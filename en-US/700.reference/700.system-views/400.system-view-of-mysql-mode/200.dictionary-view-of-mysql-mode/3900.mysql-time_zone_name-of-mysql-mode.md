# mysql.time_zone_name

## Overview

Displays the timezone name information (SYSTEM_VIEW).

## Columns

| Field Name | Type | Whether can be NULL | Description |
| -------------- | ------------- | ------------ | ------- |
| Name | varchar(64) | NO | Time Zone Name |
| Time_zone_id | bigint(20)  | NO         | The ID of the time zone. |
