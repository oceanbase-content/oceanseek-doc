# oceanbase.DBA_OB_DEADLOCK_EVENT_HISTORY

## Overview

The `DBA_OB_deadLOCK_EVENT_HISTORY` view displays the historical records of deadlock events for the current tenant.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ------- | ------ | ------ | ------ |
| EVENT_ID | bigint(20) unsigned | NO | ID of the deadlock event |
| SVR_IP | varchar(46) | NO | IP addresses of nodes involved in the deadlock |
| SVR_PORT | bigint(20) unsigned | NO | Port number of the node involved in the deadlock |
| DETECTOR_ID | bigint(20) unsigned | NO | Node ID of the participant in the deadlock (unique within the process). |
| REPORT_TIME | timestamp(6) | NO | The time when the deadlock event was reported (based on the timestamp of the reporting server). |
| CYCLE_IDX | bigint(20) | NO | The node number in the ring. |
| CYCLE_SIZE | bigint(20) | NO | Number of Nodes Involved in the Deadlock |
| ROLE | longtext | NO | Role of this node in the deadlock event: <ul><li>witness</li><li>victim</li></ul> |
| PRIORITY_LEVEL | longtext | NO | Priority levels of this node:<ul><li>extreme-low</li><li>low</li><li>normal</li><li>high</li><li>extreme-high</li></ul> |
| PRIORITY | bigint(20) unsigned | NO | The priority value of this node. Priority values are comparable only when the priorities are equal. The node with the lowest priority value in the ring is evicted. |
| CREATE_TIME | timestamp(6) | NO | Time when the node was created |
| START_DELAY_US | bigint(20) unsigned | NO | The interval from the time a node is created until it is allowed to start detecting deadlocks, in microseconds. |
| MODULE | longtext | NO | The module where the node is located. The value is fixed as transaction. |
| VISITOR | longtext | NO | The resource visitor represented by this node, in the format of `{session_id:$1}:{txid:$2}`, `$1` and `$2` All digits |
| OBJECT | longtext | NO | The primary key content of the row for the resource that this node wants to obtain, in the format of `{addr:"$1:$2"}:{ls:$3}:{tablet:$4}:{row_key:{$5}}`, where <ul><li><code>\$1</code> is the IP address. </li><li><code>\$2</code> is the port number. Together with <code>\$1</code>, they form the process address of the machine where the conflict occurred. </li><li><code>\$3</code> is the log stream where the conflict occurred. </li><li><code>\$4</code> is the tablet where the conflict occurred. </li><li><code>\$5</code> is the serialized value of the row lock primary key. </li></ul> |
| EXTRA_NAME1 | longtext | YES | The name of the additional information that the upper layer wants to add to the deadlock report event. The format is as follows: `wait_sql` |
| EXTRA_VALUE1 | longtext | YES | The current executing SQL content when a transaction deadlock occurs |
| EXTRA_NAME2 | longtext | YES | The name of the additional information 2 that the upper layer wishes to add to the deadlock report event, in the format of `hold_sql_request_time` |
| EXTRA_VALUE2 | longtext | YES | Request Time of Lock-Holding Statements |
| EXTRA_NAME3 | longtext | YES | The name of the additional information that the upper layer wishes to add to the deadlock report event, in the format of `hold_sql` |
| EXTRA_VALUE3 | longtext | YES | Hold `cycle_idx - 1` SQL statement for the object corresponding to the row record |

## Sample query

Query the history of deadlock events for this tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_DEADLOCK_EVENT_HISTORY LIMIT 10;
```
