# information_schema.SESSION_STATUS

## Overview

Records server status variables of a session, including the current number of active connections and database uptime.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| ---------------- | --------------- | ---------------- | ------------- |
| VARIABLE_NAME | varchar(128) | NO | Session Status |
| VARIABLE_VALUE | varchar(1024) | YES | Session Status Values |

## Sample query

View the server status variables of a session and their corresponding values.

```shell
obclient [oceanbase]> SELECT * FROM information_schema.SESSION_STATUS;
```

The query result is as follows:

```shell
+-------------------+----------------+
| VARIABLE_NAME     | VARIABLE_VALUE |
+-------------------+----------------+
| Threads_connected | 2              |
| Uptime            | 255239         |
+-------------------+----------------+
2 rows in set
```
