# oceanbase.DBA_OB_DYNAMIC_PARTITION_TABLES

## Overview

Displays the dynamic partitioned table information for the current tenant.

## Columns

| field | Type | Is NULL | Description |
| -------------------- | --------------- | ------------- | ------ |
| DATABASE_NAME | varchar(128) | NO | The name of the database where the dynamic partitioned table is located. |
| TABLE_NAME | varchar(256) | NO | The name of the dynamic partitioned table. |
| TABLE_ID | bigint(20) | NO | The ID of the dynamic partitioned table. |
| MAX_HIGH_BOUND_VAL | varchar(4096) | NO | The upper bound of the maximum RANGE partition. |
| ENABLE | varchar(4096) | NO | Specifies whether to enable dynamic partition management. |
| TIME_UNIT | varchar(4096) | NO | Dynamic partition management `time_unit`. |
| PRECREATE_TIME | varchar(4096) | NO | Dynamically partitioned management `precreate_time`. |
| EXPIRE_TIME | varchar(4096) | NO | Dynamic partition management `expire_time`. |
| TIME_ZONE | varchar(4096) | NO | Dynamically partitioned management `time_zone`. |
| BIGINT_PRECISION | varchar(4096) | NO | Dynamically partitioned management `bigint_precision`. |

## Sample query

Query information about a dynamic partitioned table in the current tenant.

```shell
obclient> SELECT * FROM oceanbase.DBA_OB_DYNAMIC_PARTITION_TABLES LIMIT 1\G
```

The query result is as follows:

```shell
*************************** 1. row ***************************
     DATABASE_NAME: db_test
        TABLE_NAME: tbl2
          TABLE_ID: 502062
MAX_HIGH_BOUND_VAL: '2025-04-15 14:00:00'
            ENABLE: TRUE
         TIME_UNIT: HOUR
    PRECREATE_TIME: 3HOUR
       EXPIRE_TIME: 1DAY
         TIME_ZONE: +8:00
  BIGINT_PRECISION: NONE
1 row in set
```
