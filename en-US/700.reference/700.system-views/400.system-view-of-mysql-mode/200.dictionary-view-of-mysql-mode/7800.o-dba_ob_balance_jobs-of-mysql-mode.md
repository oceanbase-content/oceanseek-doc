# oceanbase.DBA_OB_BALANCE_JOBS

## Overview

Displays the current load balancing job being executed by a tenant. Each tenant can only run one load balancing job at a time. Each load balancing job generates multiple load balancing tasks to perform specific load balancing operations.

## Columns

| **Column** | **Type** | **Is NULL** | **Description** |
| --- | --- | --- | --- |
| JOB_ID | bigint(20) | NO | CLB Work ID |
| CREATE_TIME | timestamp(6) | YES | Creation Time |
| MODIFY_TIME | timestamp(6) | YES | Information Update Time |
| BALANCE_STRATEGY | varchar(64) | NO | Balancing Strategy Name: <ul><li>`LS balance by migrate`: Migration balancing  </li><li>`LS balance by alter`: Modify log stream attributes for balancing. </li><li>`LS balance by expand`: Scale-out balancing</li><li>`LS balance by shrink`: Scale-in load balancing</li><li>`partition balance`: Partition balancing</li></ul> |
| JOB_TYPE | varchar(64) | NO | Task type. Valid values: <ul><li>`LS_BALANCE`: Log stream balancing  </li><li>`PARTITION_BALANCE`: Partition balancing. </li></ul> |
| TARGET_UNIT_NUM | bigint(20) | NO | Number of Units in Each Zone Where Target Changes Occur <main id="notice" type='explain'><h4>Note</h4><p>The value of this field is always <code>NULL</code>.</p></main> |
| TARGET_PRIMARY_ZONE_NUM | bigint(20) | NO | Number of Target Changed Primary Zones |
| STATUS | varchar(64) | NO | Task status: <ul><li>`DOING`: The job is being executed.  </li><li>`COMPLETED`: Task executed successfully. </li><li>`CANCELING`: Cancellation in progress. </li><li>`CANCELED`: Task canceled</li> <li>`SUSPEND`: Task paused </li></ul> |
| COMMENT | longtext | YES | Comments |
| MAX_END_TIME | timestamp(6) | YES | Maximum End Time of Load Balancing Task |
| ZONE_UNIT_NUM_LIST | varchar(4096) | NO | Number of Units in Each Zone of the Tenant |
| PARAMETER_LIST | longtext | NO | Balancing-related parameters |

## Sample query

View the current load balancing tasks being executed for this tenant.

```shell
obclient(root@mysql001)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_BALANCE_JOBS;
```

