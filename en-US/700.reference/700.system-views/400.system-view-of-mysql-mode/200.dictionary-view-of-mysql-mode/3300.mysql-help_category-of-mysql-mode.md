# mysql.help_category

## Overview

It works together with the other three tables, `mysql.help_relation`, `mysql.help_topic`, and `mysql.help_keyword`, to generate help commands.

## **Column description**

| **Field** | **Type** | **Nullable** | **Description** |
| -------------------- | ---------------- | ---------------- | -------- |
| help_category_id | bigint(20) | NO | Category ID |
| name | varchar(64) | NO | Category |
| parent_category_id | bigint(20) | YES | Parent Category ID |
| url | varchar(65535) | NO | URL |
