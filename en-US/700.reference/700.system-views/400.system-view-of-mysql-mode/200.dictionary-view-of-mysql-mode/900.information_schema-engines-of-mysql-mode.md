# information_schema.ENGINES

## Overview

Records information related to the storage engine.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| -------------- | --------------- | ---------------- | ----------------- |
| ENGINE | varchar(64) | NO | Engine type |
| SUPPORT | varchar(8) | NO | Whether the current storage engine is supported |
| COMMENT | varchar(80) | NO | Comment |
| TRANSACTIONS | varchar(3) | NO | Transaction-related content |
| XA | varchar(3) | NO | Distributed Transaction XA |
| SAVEPOINTS | varchar(3) | NO | Savepoints |

## Sample query

View information about the storage engine.

```shell
obclient [oceanbase]> SELECT * FROM information_schema.ENGINES;
```

The query result is as follows:

```shell
+--------+---------+-----------------------+--------------+------+------------+
| ENGINE | SUPPORT | COMMENT               | TRANSACTIONS | XA   | SAVEPOINTS |
+--------+---------+-----------------------+--------------+------+------------+
| InnoDB | YES     | Supports transactions | YES          | NO   | YES        |
+--------+---------+-----------------------+--------------+------+------------+
1 row in set
```
