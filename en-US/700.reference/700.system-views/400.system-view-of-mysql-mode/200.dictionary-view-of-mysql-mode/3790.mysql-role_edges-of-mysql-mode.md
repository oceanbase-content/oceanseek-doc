# mysql.role_edges

## Overview

The `mysql.role_edges` view displays the grant relationships between roles and users.

## Columns

| **Column** | **Type** | **Is NULL** | **Description** |
| -------- | -------- | --------------- | -------- |
| FROM_HOST | varchar(255) | NO | Host Name of the Role Account |
| FROM_USER | varchar(128) | NO | Grantee role account name |
| TO_HOST | varchar(255) | NO | Recipient Account Host Name |
| TO_USER | varchar(128) | NO | Recipient Account Name |
| WITH_ADMIN_OPTION | varchar(1) | NO | Whether the role has the ADMIN privilege option |

## Sample query

Query the grant relationship between role `role1` and user `user001`.

1. Create a role named `role1`.

   ```shell
   obclient [oceanbase]> CREATE ROLE IF NOT EXISTS role1;
   Query OK, 0 rows affected, 1 warning
   ```

2. Grant the `ALTER SYSTEM` privilege to the role `role1`.

   ```shell
   obclient [oceanbase]> GRANT ALTER SYSTEM ON *.* TO role1;
   ```

3. Create a new user named `user001`.

   ```shell
   obclient [oceanbase]> CREATE USER 'user001'@'%' IDENTIFIED BY '******';
   ```

4. Grant the role `role1` to the newly created user `user001`.

   ```shell
   obclient [oceanbase]>GRANT role001 TO user001 WITH ADMIN OPTION;;
   ```

5. Query the grant relationships between role `role1` and user `user001`.

   ```shell
   obclient > SELECT * FROM mysql.role_edges;
   ```

   The query result is as follows:

   ```shell
   +-----------+-----------+---------+---------+-------------------+
   | FROM_HOST | FROM_USER | TO_HOST | TO_USER | WITH_ADMIN_OPTION |
   +-----------+-----------+---------+---------+-------------------+
   | %         | role001   | %       | user001 | Y                 |
   +-----------+-----------+---------+---------+-------------------+
   1 row in set
   ```
