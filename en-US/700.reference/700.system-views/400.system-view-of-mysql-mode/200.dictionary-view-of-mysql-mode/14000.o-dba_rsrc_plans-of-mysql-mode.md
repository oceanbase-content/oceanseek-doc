# oceanbase.DBA_RSRC_PLANS

## Overview

Displays all system-defined resource management plans.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --------------------------- | ---------------- | ------------ | ---------------------------------------------------- |
| PLAN_ID | decimal(10,0) | NO | Resource Plan ID |
| PLAN | varchar(128) | NO | Resource Plan Name |
| NUM_PLAN_DIRECTIVES | decimal(10,0) | NO | The number of directives defined in the current resource plan. This field is for compatibility only and its value is fixed as `NULL` |
| CPU_METHOD | varchar(128) | NO | For compatibility only. The current value is fixed to `NULL` |
| MGMT_METHOD | varchar(128) | NO | For compatibility only. The current value is fixed as `NULL` |
| ACTIVE_SESS_POOL_MTH | varchar(128) | NO | For compatibility only. The current value is fixed as `NULL` |
| PARALLEL_DEGREE_LIMIT_MTH | varchar(128) | NO | For compatibility only. The current value is fixed as `NULL` |
| QUEUING_MTH | varchar(128) | NO | For compatibility only. The current value is fixed to `NULL` |
| SUB_PLAN | varchar(3) | NO | For compatibility only. The current value is fixed as `NULL` |
| COMMENTS | varchar(2000) | YES | Remarks of the resource plan |
| STATUS | varchar(128) | NO | For compatibility only. The current value is fixed to `NULL` |
| MANDATORY | varchar(3) | NO | For compatibility only. The current value is fixed as `NULL` |

## Sample query

Users and tenants can query all system-defined resource management plans.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_RSRC_PLANS;
```
