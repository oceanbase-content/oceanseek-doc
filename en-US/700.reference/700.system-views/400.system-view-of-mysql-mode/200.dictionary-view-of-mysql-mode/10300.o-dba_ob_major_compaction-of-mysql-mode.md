# oceanbase.DBA_OB_MAJOR_COMPACTION

## Overview

Displays the global major compaction information for the tenant.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| -------------------------- | ------------- | ------------ | --------------------------------------------- |
| FROZEN_SCN | bigint(20) unsigned | NO | Version number of the most recent major compaction |
| FROZEN_TIME | timestamp(6) | NO | Time when the last major compaction was initiated (displayed in a readable format). |
| GLOBAL_BROADCAST_SCN | bigint(20) unsigned | NO | Global Broadcast Major Compaction Version |
| LAST_SCN | bigint(20) unsigned | NO | The last version for which major compaction is completed |
| LAST_FINISH_TIME | timestamp(6) | NO | Last Major Compaction End Time |
| START_TIME | timestamp(6) | NO | Start Time of Major Compaction |
| STATUS | varchar(10) | NO | <ul><li>`IDLE`: Not involved in any major compactions. </li><li>`COMPACTING`: major compaction in progress </li><li>`CHECKSUM`: Verify checksum </li></ul> |
| IS_ERROR | varchar(3) | NO | <ul><li>`YES`: An error occurred during the major compaction. </li><li>`NO`: No errors were reported during the major compaction. </li></ul> |
| IS_SUSPENDED | varchar(3) | NO | <ul><li>`YES`: Suspension status of major compaction. </li><li>`NO`: No major compaction is paused.   </li></ul> |
| INFO | varchar(14) | NO | Displays the major compaction information. For example, the cause of the major compaction failure. |
| MODE | varchar(7) | NO | Type of daily major compaction:<ul><li>`TENANT`: Tenant major compaction</li> <li>`WINDOW`: [Window merging](../../../200.system-management/500.manage-data-storage/200.merge-management/310.window-compaction.md)</li></ul> |

## Sample query

You can view the global major compaction information of the current tenant.

```shell
obclient(root@mysql001)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_MAJOR_COMPACTION;
```

The query result is as follows:

```shell
+---------------------+----------------------------+----------------------+---------------------+----------------------------+----------------------------+--------+----------+--------------+------+--------+
| FROZEN_SCN          | FROZEN_TIME                | GLOBAL_BROADCAST_SCN | LAST_SCN            | LAST_FINISH_TIME           | START_TIME                 | STATUS | IS_ERROR | IS_SUSPENDED | INFO | MODE   |
+---------------------+----------------------------+----------------------+---------------------+----------------------------+----------------------------+--------+----------+--------------+------+--------+
| 1772992801519693000 | 2026-03-09 02:00:01.519693 |  1772992801519693000 | 1772992801519693000 | 2026-03-09 02:05:42.538179 | 2026-03-09 16:15:11.214954 | IDLE   | NO       | NO           |      | WINDOW |
+---------------------+----------------------------+----------------------+---------------------+----------------------------+----------------------------+--------+----------+--------------+------+--------+
1 row in set
```
