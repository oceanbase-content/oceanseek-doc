# oceanbase.DBA_OB_LS_REPLICA_TASK_HISTORY

## Overview

The `DBA_OB_LS_REPLICA_TASK_HISTORY` view displays the execution history of disaster recovery tasks for the current tenant.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| LS_ID | bigint(20) | NO | Log Stream ID |
| TASK_TYPE | varchar(64) | NO | Task type. Valid values: <ul><li>`MIGRATE REPLICA`: migrate replicas</li><li>`ADD REPLICA`: Add replicas</li><li>`TYPE TRANSFORM`: Replica type conversion</li><li>`REMOVE PAXOS REPLICA`: Delete a Paxos member replica.</li><li>`REMOVE NON PAXOS REPLICA`: Delete non-Paxos member replicas.</li><li>`MODIFY PAXOS REPLICA NUMBER`: Modify the number of quorum replicas</li></ul> |
| TASK_ID | varchar(200) | NO | Task ID |
| TASK_STATUS | varchar(2048) | YES | Task status. Valid values: <ul><li>`COMPLETED`: Task completed</li><li>`CANCELED`: Cancel Task</li></ul> |
| PRIORITY | varchar(5) | NO | Task priority. Valid values: <ul><li>`LOW`: low-priority tasks</li><li>`HIGH`: high-priority tasks</li></ul> |
| TARGET_REPLICA_SVR_IP | varchar(46) | YES | IP Address of the Server Where the Target Replica Resides |
| TARGET_REPLICA_SVR_PORT | bigint(20) | YES | Port of the server where the destination replica resides |
| TARGET_PAXOS_REPLICA_NUMBER | bigint(20) | YES | Quorum Paxos Replicas for Log Stream Targets |
| TARGET_REPLICA_TYPE | varchar(16) | YES | Target Replica Type |
| SOURCE_REPLICA_SVR_IP | varchar(46) | YES | IP Address of the Source Replica Host |
| SOURCE_REPLICA_SVR_PORT | bigint(20) | YES | Port of the Source Replica Host |
| SOURCE_PAXOS_REPLICA_NUMBER | bigint(20) | YES | Number of Paxos Followers in Log Stream Primary State |
| SOURCE_REPLICA_TYPE | varchar(16) | YES | Source Replica Type |
| DATA_SOURCE_SVR_IP | varchar(46) | YES | Data Source IP |
| DATA_SOURCE_SVR_PORT | bigint(20) | YES | Data Source Port |
| IS_MANUAL | varchar(6) | NO | The source of the disaster recovery task. Valid values: <ul><li>`TRUE`: Indicates a disaster recovery task triggered by manual O&M commands.</li><li>`FALSE`: Default value. It indicates a disaster recovery task automatically generated by the RS layer for disaster recovery.</li></ul> |
| TASK_EXEC_SVR_IP | varchar(46) | YES | Task Execution Machine IP |
| TASK_EXEC_SVR_PORT | bigint(20) | YES | Task Execution Machine PORT |
| CREATE_TIME | datetime | NO | Task Generation Time |
| START_TIME | datetime | NO | Task Scheduling Time |
| MODIFY_TIME | datetime | NO | Last Updated |
| FINISH_TIME | datetime | NO | End Time |
| EXECUTE_RESULT | varchar(2048) | YES | Task Execution Result |
| COMMENT | varchar(2048) | YES | Reason for Task Generation Remarks |
| CONFIG_VERSION | varchar(128) | YES | Record the config_version information of the clog layer during disaster recovery task execution. |
