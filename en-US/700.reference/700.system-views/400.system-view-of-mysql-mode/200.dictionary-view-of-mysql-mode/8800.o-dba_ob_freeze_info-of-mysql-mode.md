# oceanbase.DBA_OB_FREEZE_INFO

## Overview

Displays the version information generated by major freeze for this tenant.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --- | --- | --- | --- |
| FROZEN_SCN | bigint(20) unsigned | NO | Major Freeze Generated Major Compaction Version Number |
| CLUSTER_VERSION | bigint(20) | NO | Current cluster version number during major_freeze |
| SCHEMA_VERSION | bigint(20) | NO | Current Schema Version Number During Major Freeze |
| GMT_CREATE | timestamp(6) | NO | Record creation time |
| GMT_MODIFIED | timestamp(6) | NO | Record Last Modified At |

## Sample query

Users can query the version information generated by major compactions in their own tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_FREEZE_INFO;
```
