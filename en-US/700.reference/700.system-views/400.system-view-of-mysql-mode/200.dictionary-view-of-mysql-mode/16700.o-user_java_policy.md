# oceanbase.USER_JAVA_POLICY

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.6.3. </p>
</main>

## Overview

The `USER_JAVA_POLICY` view displays the Java privilege policy of the currently logged-in user, including the privilege granting and restriction rules for Java UDFs.

Difference from the `DBA_JAVA_POLICY` view: The `DBA_JAVA_POLICY` view displays the Java permission policy for all users in the current tenant, while the `USER_JAVA_POLICY` view displays only the permission policy records related to the currently logged-in user.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --- | --- | --- | --- |
| KIND | varchar(8) | NO | Policy type: <ul><li>`GRANT`: Grants privileges. </li><li>`RESTRICT`: Restricts privileges. </li></ul> |
| GRANTEE | varchar(128) | NO | The authorized username. |
| TYPE_SCHEMA | varchar(128) | NO | The name of the database to which the type belongs. |
| TYPE_NAME | varchar(4096) | YES | Type name. |
| NAME | varchar(4096) | YES | The name of the permission target. |
| ACTION | varchar(4096) | YES | Permission action. |
| ENABLED | varchar(8) | NO | Whether the policy is enabled: <ul><li>`ENABLED`: Enable.</li><li>`DISABLED`: Disabled.</li></ul> |
| SEQ | bigint(20) | NO | Policy ID. |

## Sample query

Query the Java permission policy of the currently logged-in user.

```sql
SELECT * FROM oceanbase.USER_JAVA_POLICY;
```

The query result is as follows:

```shell
+------+---------+--------------+------------------------+--------+--------+---------+------+
| KIND | GRANTEE | TYPE_SCHEMA  | TYPE_NAME              | NAME   | ACTION | ENABLED | SEQ  |
+------+---------+--------------+------------------------+--------+--------+---------+------+
| GRANT| SYS     | java.io      | FilePermission         | /tmp/- | read   | ENABLED | 1    |
+------+---------+--------------+------------------------+--------+--------+---------+------+
1 row in set
```
