# information_schema.COLLATION_CHARACTER_SET_APPLICABILITY

## Overview

Records the correspondence between characters and collations.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| -------------------- | -------------- | ---------------- | -------- |
| COLLATION_NAME | varchar(128) | NO | Comparison Method Name |
| CHARACTER_SET_NAME | varchar(128) | NO | Character set name |
