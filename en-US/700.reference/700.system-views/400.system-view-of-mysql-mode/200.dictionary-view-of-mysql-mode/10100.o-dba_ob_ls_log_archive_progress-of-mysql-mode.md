# oceanbase.DBA_OB_LS_LOG_ARCHIVE_PROGRESS

## Overview

Displays the log stream archiving progress for the current tenant.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| DEST_ID | bigint(20) | NO | Archive Destination ID |
| LS_ID | bigint(20) | NO | Log Stream ID |
| ROUND_ID | bigint(20) | NO | Log Stream Round ID |
| PIECE_ID | bigint(20) | NO | Latest Piece ID |
| INCARNATION | bigint(20) | NO | Avatar ID |
| START_SCN | bigint(20) unsigned | NO | Archive Start SCN |
| MIN_LSN | bigint(20) unsigned | NO | Minimum LSN of Current Piece Log Stream |
| MAX_LSN | bigint(20) unsigned | NO | Maximum LSN of Current Piece Log Stream |
| CHECKPOINT_SCN | bigint(20) unsigned | NO | Maximum Archiving Progress of Current Piece Log Stream |
| STATUS | varchar(64) | NO | Archive Status |
| FILE_ID | bigint(20) | NO | Maximum Archived File ID of Current Piece |
| FILE_OFFSET | bigint(20) | NO | Maximum Archived File Offset for the Current Piece |
| INPUT_BYTES | bigint(20) | NO | Volume of log data read, in bytes |
| OUTPUT_BYTES | bigint(20) | NO | Volume of Archived Log Data, in Bytes |

You can view the log stream archiving progress of the current tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_LS_LOG_ARCHIVE_PROGRESS\G
```
