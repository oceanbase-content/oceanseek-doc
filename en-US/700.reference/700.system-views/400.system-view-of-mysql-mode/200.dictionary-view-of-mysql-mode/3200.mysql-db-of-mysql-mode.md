# mysql.db

## Overview

Displays database-level privilege information.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| ----------------------- | -------------- | ---------------- | ---------------------------------- |
| host | varchar(128) | NO | Host name |
| db | varchar(128) | NO | Database Name |
| user | varchar(128) | NO | Username |
| select_priv | varchar(1) | NO | Whether the SELECT statement is executable |
| insert_priv | varchar(1) | NO | Whether the INSERT statement can be executed |
| update_priv | varchar(1) | NO | Whether the UPDATE statement is executable. |
| delete_priv | varchar(1) | NO | Yes, the delete statement can be executed. |
| create_priv | varchar(1) | NO | Whether the CREATE statement can be executed |
| drop_priv | varchar(1) | NO | Whether the DROP statement is executable |
| grant_priv | varchar(1) | NO | Whether authorization is allowed |
| reference_priv | varchar(1) | NO | Not Used |
| index_priv | varchar(1) | NO | Whether an index can be created |
| alter_priv | varchar(1) | NO | executable `alter table` statement |
| create_tmp_table_priv | varchar(1) | NO | Whether temporary tables can be created. This field is currently not used. |
| lock_tables_priv | varchar(1) | NO | Whether the `LOCK TABLES` statement can be executed. The user must also have the SELECT privilege on the table. This field is not currently used. |
| create_view_priv | varchar(1) | NO | executable `create view` statement |
| show_view_priv | varchar(1) | NO | executable `show create view` statement |
| create_routine_priv | varchar(1) | NO | Whether to allow the creation of stored procedures (not currently used) |
| alter_routine_priv | varchar(1) | NO | executable `alter function` Statement (not used yet) |
| execute_priv | varchar(1) | NO | Whether the stored procedure is executable. (Not used.) |
| event_priv | varchar(1) | NO | Whether an event can be created, deleted, or modified. (Not used.) |
| trigger_priv | varchar(1) | NO | executable `create trigger` or `drop trigger` Statement. This field is not currently used. |

## Sample query

Query the database-level privileges of user `test2`.

```shell
obclient [oceanbase]> SELECT * FROM mysql.db WHERE user='test2' \G
```
