# information_schema.TABLE_CONSTRAINTS

## Overview

Describes the table constraint information.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| -------------------- | --------------- | ---------------- | -------- |
| CONSTRAINT_CATALOG | varchar(64) | NO | Constraint Catalog |
| CONSTRAINT_SCHEMA | varchar(128) | NO | Database Name |
| CONSTRAINT_NAME | varchar(256) | NO | Constraint name |
| TABLE_SCHEMA | varchar(128) | NO | Database Name |
| TABLE_NAME | varchar(256) | NO | Table name |
| CONSTRAINT_TYPE | varchar(11) | NO | Constraint type |
| ENFORCED | varchar(3) | NO | Whether the constraint is enabled. |

## Sample query

View the constraints of table `tbl6`.

```shell
obclient [infotest]> SELECT * FROM information_schema.TABLE_CONSTRAINTS WHERE TABLE_NAME='tbl6';
```

The query result is as follows:

```shell
+--------------------+-------------------+-----------------+--------------+------------+-----------------+----------+
| CONSTRAINT_CATALOG | CONSTRAINT_SCHEMA | CONSTRAINT_NAME | TABLE_SCHEMA | TABLE_NAME | CONSTRAINT_TYPE | ENFORCED |
+--------------------+-------------------+-----------------+--------------+------------+-----------------+----------+
| def                | infotest          | col1            | infotest     | tbl6       | UNIQUE          | YES      |
+--------------------+-------------------+-----------------+--------------+------------+-----------------+----------+
1 row in set
```
