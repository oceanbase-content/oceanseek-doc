# oceanbase.DBA_OB_VECTOR_INDEX_TASK_HISTORY

## Overview

The `DBA_OB_VECTOR_INDEX_TASK_HISTORY` view displays the historical information of all vector index-related background tasks under the current tenant, including partition rebuilding, segment minor compaction and major compaction, IVF cluster center loading and cleanup, semantic index refreshing, and memory synchronization. You can distinguish task types by using the `TASK_TYPE` column in the view.


### View memory throttling information

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This feature is supported starting with V4.6.2.1.</p>
</main>

For memory-intensive tasks such as partition-level index rebuilding or incremental segment merging, the `TASK_INFO` field contains a `mem_limit_info` segment after the task completes, which records information about memory throttling. You can query the following SQL statement to obtain the estimated memory usage and throttling information:

```sql
SELECT
  TABLET_ID,
  TASK_TYPE,
  JSON_EXTRACT(TASK_INFO, '$.mem_limit_info.task_estimate_memory') AS estimate_mem,
  JSON_EXTRACT(TASK_INFO, '$.mem_limit_info.vector_mem_hold') AS mem_hold,
  JSON_EXTRACT(TASK_INFO, '$.mem_limit_info.vector_mem_limit') AS mem_limit,
  JSON_EXTRACT(TASK_INFO, '$.mem_limit_info.task_memory_limited') AS was_throttled
FROM OCEANBASE.DBA_OB_VECTOR_INDEX_TASK_HISTORY
WHERE TASK_TYPE = 'PARTITION_REBUILD';
```

The subfields of the `mem_limit_info` field are described in detail as follows:

| **Subfield** | **Unit** | **Note** |
| --- | --- | ---- |
| `task_memory_limited` |  | Whether memory throttling has been triggered (true/false) |
| `vector_mem_hold` | byte | Tenant Vector Memory Usage During Task Scheduling |
| `vector_mem_limit` | byte | Total Tenant Vector Memory Limit |
| `task_estimate_memory` | byte | Estimated Memory Requirement for the Current Task |
| `tasks_total_reserved_memory` | byte | Total Reserved Memory for Other Running Tasks |
