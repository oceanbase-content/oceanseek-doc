# oceanbase.DBA_WR_CONTROL

## Overview

Displays the configuration information related to write requests.

## Columns

| **Column** | **Type** | **Is NULL** | **Description** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | Tenant ID. <ul><li>1: the ID of the system tenant.  </li><li>Other values: the ID of a user tenant or meta tenant. </li></ul> |
| SNAP_INTERVAL | varchar(64) | NO | The interval between each snapshot, in the format of `DD HH:mm:SS` Easy to read |
| RETENTION | varchar(64) | NO | The retention period between snapshots, in the format of `DD HH:mm:SS` Easy to read |
| TOPNSQL | bigint(20) | NO | Stored top N SQL statements |
