# oceanbase.DBA_OB_TENANT_FLASHBACK_LOG_SCN

## Overview

The `oceanbase.DBA_OB_TENANT_FLASHBACK_LOG_SCN` view displays information about each log trim operation in the current tenant.

## Columns

| field | Type | Is NULL | Description |
| ------------------- | --------------------- | ------------- | ------------------------------------------ |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| TIMESTAMP | timestamp(6) | NO | Creation time, in microseconds |
| SWITCHOVER_EPOCH | bigint(20) | NO | Tenant role switched to `NORMAL` When the status is `SWITCHOVER_EPOCH`. `SWITCHOVER_EPOCH` is a flag used to indicate a tenant role switchover/Failover the unique identifier of the operation. |
| OP_TYPE | varchar(64) | NO | Operation type. Valid values: <ul><li>`FAILOVER_TO_PRIMARY`: The type of failover operation. This operation switches the standby tenant to the primary tenant when the primary tenant is unavailable.</li><li>`FLASHBACK_STANDBY_LOG`: The type of log trimming operation for the standby tenant, used to trim the standby tenant's logs to a specified SCN position.</li></ul> |
| FLASHBACK_LOG_SCN | bigint(20) unsigned | NO | End Point for Trimming Tenant Logs from Back to Front |

## Sample query

Query information about each log trimming operation in the current tenant.

```shell
obclient(root@mysql001)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_TENANT_FLASHBACK_LOG_SCN;
```

The return result is as follows:

```shell
+-----------+----------------------------+------------------+---------------------+---------------------+
| TENANT_ID | TIMESTAMP                  | SWITCHOVER_EPOCH | OP_TYPE             | FLASHBACK_LOG_SCN   |
+-----------+----------------------------+------------------+---------------------+---------------------+
|      1002 | 2025-05-21 16:48:53.583749 | 1747817333380437 | FAILOVER TO PRIMARY | 1747817331313513000 |
+-----------+----------------------------+------------------+---------------------+---------------------+
1 row in set
```
