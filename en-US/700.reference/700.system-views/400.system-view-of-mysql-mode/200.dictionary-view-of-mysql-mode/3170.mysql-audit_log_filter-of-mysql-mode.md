# mysql.audit_log_filter

## Overview

The `mysql.audit_log_filter` view is used to display the definition of audit filters.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| ------------ | ------------- | --------------------- | ---------------------------------------- |
| NAME | varchar(64) | NO | Filter Name |
| FILTER | longtext | NO | Filter definition |

## Sample query

View the definition of an audit filter.

```shell
obclient [mysql]> select * from mysql.audit_log_filter;
```

The query result is as follows:

```shell
+---------+-------------------------------+
| NAME    | FILTER                        |
+---------+-------------------------------+
| log_all | { "filter": { "log": true } } |
+---------+-------------------------------+
1 row in set (0.003 sec)
```
