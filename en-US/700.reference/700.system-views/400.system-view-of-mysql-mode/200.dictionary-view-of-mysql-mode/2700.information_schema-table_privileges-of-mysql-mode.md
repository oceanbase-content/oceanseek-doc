# information_schema.TABLE_PRIVILEGES

## Overview

Displays table privilege information.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| ---------------- | --------------- | ---------------- | -------- |
| GRANTEE | varchar(81) | NO | Account Name Granted Permission |
| TABLE_CATALOG | varchar(512) | NO | Table directory, fixed as `def` |
| TABLE_SCHEMA | varchar(128) | NO | Database Name |
| TABLE_NAME | varchar(64) | NO | Table name |
| PRIVILEGE_TYPE | varchar(64) | NO | Granted Privilege |
| IS_GRANTABLE | varchar(3) | NO | Sublicensable |

## Sample query

Query table-level privileges granted to a user.

```shell
obclient [infotest]> SELECT * FROM information_schema.TABLE_PRIVILEGES;
```

A sample query is as follows:

```shell
+-------------+---------------+--------------+------------+----------------+--------------+
| GRANTEE     | TABLE_CATALOG | TABLE_SCHEMA | TABLE_NAME | PRIVILEGE_TYPE | IS_GRANTABLE |
+-------------+---------------+--------------+------------+----------------+--------------+
| 'test2'@'%' | def           | infotest     | tbl1       | INSERT         | NO           |
| 'test2'@'%' | def           | infotest     | tbl1       | SELECT         | NO           |
+-------------+---------------+--------------+------------+----------------+--------------+
2 rows in set
```
