# oceanbase.DBA_RSRC_CONSUMER_GROUPS

## Overview

Displays information about all resource groups in the current tenant.

## Columns

| Field type | Type | Whether can be NULL | Description |
| ------------------- | ---------------- | ------------ | -------------------------------------- |
| CONSUMER_GROUP_ID | bigint(20) | NO | Resource group ID. |
| CONSUMER_GROUP | varchar(128) | NO | The name of the resource group to which the user is bound. |
| CPU_METHOD | varchar(128) | NO | For compatibility only. The current value is fixed as `NULL`. |
| MGMT_METHOD | varchar(128) | NO | For compatibility only. The current value is fixed as `NULL`. |
| INTERNAL_USE | varchar(3) | NO | Indicates whether the resource group is for internal use only or for compatibility purposes only. The current value is fixed as `NULL`. |
| COMMENTS | varchar(2000) | YES | The remarks for the resource group. |
| CATEGORY | varchar(128) | NO | The category of the resource group, which is only used for compatibility. The current value is fixed as `NULL`. |
| STATUS | varchar(128) | NO | Resource group status, used only for compatibility. The current value is fixed as `NULL`. |
| MANDATORY | varchar(3) | NO | Indicates whether this resource group is required. This parameter is for compatibility only and its value is fixed as `NULL`. |

## Sample query

You can query all resource groups in the current tenant.

```shell
obclient [oceanbase]> SELECT CONSUMER_GROUP_ID, CONSUMER_GROUP FROM oceanbase.DBA_RSRC_CONSUMER_GROUPS;
```

The query result is as follows:

```shell
+-------------------+-------------------+
| CONSUMER_GROUP_ID | CONSUMER_GROUP    |
+-------------------+-------------------+
|             10001 | batch_group       |
|             10000 | interactive_group |
+-------------------+-------------------+
2 rows in set
```
