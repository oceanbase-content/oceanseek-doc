# oceanbase.DBA_OB_BACKUP_DELETE_JOBS

## Overview

Displays the execution progress of the backup cleanup job for the current tenant.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| JOB_ID | bigint(20) | NO | Task ID, which is monotonically increasing. |
| INCARNATION | bigint(20) | NO | Avatar ID |
| INITIATOR_TENANT_ID | bigint(20) | NO | Tenant ID that initiated the job |
| INITIATOR_JOB_ID | bigint(20) | NO | JOB ID of the tenant that initiated this job |
| EXECUTOR_TENANT_ID | varchar(65536) | NO | List of Tenants for Which the Cleanup Task Is to Be Performed |
| TYPE | varchar(64) | NO | Cleanup type: <ul><li>`DELETE OBSOLETE BACKUP`: Purge expired data</li> <li>`DELETE BACKUP ALL`: Clear all backup or archive data in the path.</li> <li>`DELETE BACKUPSET`: Clean up the specified data backup set.</li> <li>`DELETE ARCHIVELOG_PIECE`: Clean up the specified log archive piece. </li></ul> |
| PARAMETER | timestamp(6) | NO | Cleanup parameters, describing the specific parameter information for different cleanup types |
| JOB_LEVEL | varchar(64) | NO | Task Initiation Level: <ul><li>`USER_TENANT`: User tenant initiated task</li><li>`SYS_TENANT`: tasks initiated by the sys tenant</li></ul> |
| START_TIMESTAMP | timestamp(6) | NO | Current Tenant Time at Task Start |
| END_TIMESTAMP | timestamp(6) | NO | Current Tenant Time at Task End |
| STATUS | varchar(64) | NO | Task status: <ul><li>`INIT`: Task initialization phase </li><li>`DOING`: Task execution phase </li><li>`CANCELING`: The task is canceled. </li><li>`COMPLETED`: The task was executed successfully. </li><li>`FAILED`: Task execution failed. </li><li>`CANCELED`: The task was successfully canceled. </li></ul> |
| TASK_COUNT | bigint(20) | YES | Number of backup_set/piece Tasks |
| SUCCESS_TASK_COUNT | bigint(20) | YES | Number of Successfully Executed Tasks for backup_set/piece |
| RESULT | bigint(20) | NO | Error Code |
| COMMENT | varchar(4096) | YES | Task Execution Instructions |

## Sample query

Users can query the execution progress of backup cleanup jobs for their own tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_BACKUP_DELETE_JOBS\G
```

