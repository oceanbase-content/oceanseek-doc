# oceanbase.DBA_OB_TRANSFER_PARTITION_TASKS

## Overview

The `DBA_OB_TRANSFER_PARTITION_TASKS` view displays the current [Transfer Partition](../../../500.sql-reference/100.sql-syntax/100.system-tenants/200.alter-system/4300.Transfer-partition.md) tasks being processed under the current tenant.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| TASK_ID | bigint(20) | NO | Unique identifier of the partition transfer task. |
| CREATE_TIME | timestamp(6) | YES | Creation Time |
| MODIFY_TIME | timestamp(6) | YES | Information Update Time |
| TABLE_ID | bigint(20) | NO | Table ID of the partition for which data is being transferred |
| OBJECT_ID | bigint(20) | NO | Partition of Transfer `OBJECT_ID` |
| DEST_LS | bigint(20) | NO | Destination log stream |
| BALANCE_JOB_ID | bigint(20) | NO | CLB Work ID Associated with Task Execution |
| TRANSFER_TASK_ID | bigint(20) | NO | Transfer task ID associated with the task during execution |
| STATUS | varchar(64) | NO | Task status: <ul><li>WAITING: The task is waiting and has not started execution.</li><li>INIT: The task has started scheduling.</li><li>DOING: The task has started executing the transfer.</li></ul> |
| COMMENT | longtext | YES | Comments |

## Sample query

Query the current transfer partition tasks being processed under this tenant.

```shell
obclient> SELECT * FROM oceanbase.DBA_OB_TRANSFER_PARTITION_TASKS;
```

The query result is as follows:

```shell
+---------+----------------------------+----------------------------+----------+-----------+---------+----------------+------------------+--------+---------+
| TASK_ID | CREATE_TIME                | MODIFY_TIME                | TABLE_ID | OBJECT_ID | DEST_LS | BALANCE_JOB_ID | TRANSFER_TASK_ID | STATUS | COMMENT |
+---------+----------------------------+----------------------------+----------+-----------+---------+----------------+------------------+--------+---------+
|       4 | 2023-12-01 11:21:11.357272 | 2023-12-01 11:21:17.904857 |   500012 |    500014 |    1003 |         737367 |                9 | DOING  | NULL    |
+---------+----------------------------+----------------------------+----------+-----------+---------+----------------+------------------+--------+---------+
1 row in set (0.002 sec)
```
