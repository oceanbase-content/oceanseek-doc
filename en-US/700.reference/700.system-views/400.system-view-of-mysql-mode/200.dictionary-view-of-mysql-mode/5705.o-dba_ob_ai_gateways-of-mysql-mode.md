# oceanbase.DBA_OB_AI_GATEWAYS

<main id="notice" type='explain'>
    <h4>Note</h4>
    <p>This view is available starting with V4.6.2.1. </p>
</main>

## Overview

Displays the AI gateway configuration information of the current tenant, allowing you to view the multi-endpoint routing and weight configurations created by using the `CREATE_AI_GATEWAY` PL procedure.

## Columns

| field | Type | Is NULL | Description |
| --- | --- | --- | --- |
| GATEWAY_NAME | varchar(256) | NO | Gateway name. |
| ENDPOINTS | varchar(32767) | NO | JSON list of endpoint routes. Each item contains `name`, `model`, `weight` fields, `model` is `provider/model` format. |
| CIRCUIT_BREAKER | varchar(4096) | YES | JSON configuration for gateway-level circuit breaking. |
| CREATE_TIME | timestamp(6) | NO | Creation time. |
| UPDATE_TIME | timestamp(6) | NO | Last modified at. |

## Sample query

This example shows how a user tenant queries the AI gateway configuration information of its own tenant.

1. If the vendor configuration has not been registered, execute `REGISTER_PROVIDER` first and replace `access_key` and `base_url` with the actual values:

    ```shell
    CALL DBMS_AI_SERVICE.REGISTER_PROVIDER('test-provider', '{
    "protocol": "openai",
    "base_url": "https://xxx",
    "access_key": "sk-xxx"
    }');
    CALL DBMS_AI_SERVICE.CREATE_AI_GATEWAY('test', '{
    "endpoints": [
        {"name":"ep1","model":"test-provider/test-model","weight":70},
        {"name":"ep2","model":"test-provider/test-model2","weight":30}
    ]
    }');
    ```

2. Query gateway configuration information:

    ```sql
    SELECT GATEWAY_NAME, ENDPOINTS, CIRCUIT_BREAKER
    FROM oceanbase.DBA_OB_AI_GATEWAYS
    WHERE GATEWAY_NAME = 'test';
    ```

    The example result is as follows:

    ```shell
    GATEWAY_NAME	ENDPOINTS	CIRCUIT_BREAKER
    test	[{"name": "ep1", "model": "test-provider/test-model", "weight": 70}, {"name": "ep2", "model": "test-provider/test-model2", "weight": 30}]	NULL
    ```

<h4>Note</h4>
<p>To troubleshoot routing configurations by endpoint, query the <code>DBA_OB_AI_GATEWAY_ENDPOINTS</code> view.</p>
</main>
