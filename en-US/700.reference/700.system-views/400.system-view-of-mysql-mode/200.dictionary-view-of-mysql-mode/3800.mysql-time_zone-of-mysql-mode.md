# mysql.time_zone

## Overview

Displays time zone-related information.

## Columns

| **Field** | **Type** | **Whether it can be NULL** | **Description** |
| ------------------ | ------------ | ----------------- | -------- |
| Time_zone_id | bigint(20) | NO | Time zone ID |
| Use_leap_seconds | varchar(8) | NO              | Whether to use leap seconds. |
