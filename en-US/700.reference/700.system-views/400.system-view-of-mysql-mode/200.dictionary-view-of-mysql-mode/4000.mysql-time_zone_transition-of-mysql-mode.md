# mysql.time_zone_transition

## Overview

A system view that displays time zone conversion information.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| -------------------- | ------------ | ---------------- | ----------- |
| Time_zone_id | bigint(20) | NO | Time zone ID |
| Transition_time | bigint(20) | NO | Time zone conversion time |
| Transition_type_id | bigint(20) | NO             | The ID of the time zone conversion type. |
