# oceanbase.DBA_OB_ZONE_MAJOR_COMPACTION

## Overview

Displays the major compaction information for each zone in the tenant.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ------------------- | -------------- | ------------ | ------------------ |
| ZONE | varchar(128) | NO | Zone Name |
| BROADCAST_SCN | bigint(20) unsigned | NO | Broadcast Major Compaction Version Number |
| LAST_SCN | bigint(20) unsigned | NO | The version number of the last major compaction |
| LAST_FINISH_TIME | timestamp(6) | NO | Last Major Compaction End Time |
| START_TIME | timestamp(6) | NO | Start Time of Major Compaction |
| STATUS | varchar(10) | NO | <ul><li> `IDLE`: Not involved in any major compaction.  </li><li>`COMPACTING`: In progress. </li></ul> |

## Sample query

You can view the major compaction information of each zone in the current tenant.

```shell
obclient> SELECT * FROM oceanbase.DBA_OB_ZONE_MAJOR_COMPACTION;
```

The query result is as follows:

```shell
+-------+---------------------+---------------------+----------------------------+----------------------------+--------+
| ZONE  | BROADCAST_SCN       | LAST_SCN            | LAST_FINISH_TIME           | START_TIME                 | STATUS |
+-------+---------------------+---------------------+----------------------------+----------------------------+--------+
| zone1 | 1748455203748142000 | 1748455203748142000 | 2025-05-29 02:05:55.879349 | 2025-05-29 02:00:03.782431 | IDLE   |
+-------+---------------------+---------------------+----------------------------+----------------------------+--------+
1 row in set
```
