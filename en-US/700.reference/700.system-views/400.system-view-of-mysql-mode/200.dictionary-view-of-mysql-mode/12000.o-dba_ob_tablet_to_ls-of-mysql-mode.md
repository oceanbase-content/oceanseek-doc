# oceanbase.DBA_OB_TABLET_TO_LS

## Overview

Displays a list of all tablets for the current tenant and the log stream information to which each tablet belongs.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ----------- | ------------ | ------------ | ------------------ |
| TABLET_ID | bigint(20) | NO | TABLET ID |
| LS_ID | bigint(1) | NO | Log stream ID of the tablet |

## Sample query

The user tenant queries the tablet list information of log stream 1001 for the current tenant and displays the first 5 entries.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_TABLET_TO_LS WHERE LS_ID=1001 LIMIT 5;
```

The query result is as follows:

```shell
+-----------+-------+
| TABLET_ID | LS_ID |
+-----------+-------+
|    200004 |  1001 |
|    200005 |  1001 |
|    200007 |  1001 |
|    200008 |  1001 |
|    200009 |  1001 |
+-----------+-------+
5 rows in set
```
