# oceanbase.DBA_PART_COL_STATISTICS

## Overview

Displays the column statistics and histogram information for all partitioned tables in the tenant.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --- | --- | --- | --- |
| OWNER | varchar(128) | NO | Owner of partitioned tables |
| TABLE_NAME | varchar(128) | NO | Table name |
| PARTITION_NAME | varchar(128) | NO | Table Partition Name |
| COLUMN_NAME | varchar(128) | NO | Column name |
| NUM_DISTINCT | decimal(10,0) | NO | Number of distinct values in the column |
| LOW_VALUE | varchar(128) | NO | Minimum value of the column |
| HIGH_VALUE | varchar(128) | NO | Maximum Value of Column |
| DENSITY | decimal(10,0) | NO | Column density. If a histogram is available for COLUMN_NAME, this column shows the selectivity of values that span fewer than two endpoints in the histogram. It does not represent the selectivity of values that span two or more endpoints. If no histogram is available for COLUMN_NAME, the value in this column is 1/NUM_DISTINCT. |
| NUM_NULLS | decimal(10,0) | NO | Number of NULLs in Column |
| NUM_BUCKETS | decimal(10,0) | NO | Number of Buckets in Column Histogram |
| LAST_ANALYZED | datetime(6) | NO | Date of Last Chromatographic Column Analysis |
| SAMPLE_SIZE | decimal(10,0) | NO | Sample volume used for chromatographic column analysis |
| GLOBAL_STATS | varchar(3) | NO | Indicates whether statistics have been collected:<ul><li>YES: Collected.</li><li>NO: Not collected or aggregated from subpartitions.</li></ul> |
| NOTES | varchar(80) | NO | Describes some additional attributes of statistics:<ul><li>INCREMENTAL: Indicates that the column has a summary.</li><li>INCREMENTAL(HLL): Indicates that the column has a summary and the summary is in hyperloglog format.</li><li>INCREMENTAL(SAMPLING): Indicates that the column has a summary and the summary is in adaptive sampling format.</li></ul> <br>This column can be used to determine whether the summary in adaptive sampling format has been completely phased out and cleared correctly. |
| AVG_COL_LEN | decimal(10,0) | NO | Average Column Length (Bytes) |
| HISTOGRAM | varchar(15) | NO | Specifies the type of histogram:<ul><li>NONE</li><li>FREQUENCY</li><li>HEIGHT BALANCED</li><li>HYBRID</li><li>TOP-FREQUENCY</li></ul> |

## Sample query

View the column statistics and histogram information of the partitions in the partitioned table `t_subpart` within the current tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_PART_COL_STATISTICS WHERE TABLE_NAME='t_subpart';
```
