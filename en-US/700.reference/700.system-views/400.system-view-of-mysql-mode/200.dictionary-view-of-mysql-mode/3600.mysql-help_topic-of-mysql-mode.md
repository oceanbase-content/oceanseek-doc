# mysql.help_topic

## Overview

It works together with the other three tables, `mysql.help_category`, `mysql.help_relation`, and `mysql.help_keyword`, to generate help commands.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| ------------------ | ---------------- | ---------------- | -------- |
| help_topic_id | bigint(20) | NO | Topic ID |
| name | varchar(64) | NO | Topic |
| help_category_id | bigint(20) | NO | Category ID |
| description | varchar(65535) | NO | Description |
| example | varchar(65535) | NO | Example |
| url | varchar(65535) | NO | URL |
