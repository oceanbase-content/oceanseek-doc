# oceanbase.DBA_OB_LS_LOCATIONS

## Overview

Displays the replica distribution information of log stream (LS) for the current tenant.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| -------------- | ---------------- | ------------ | ---------------------------------------------------------------------- |
| CREATE_TIME | datetime(6) | NO | Creation Time |
| MODIFY_TIME | datetime(6) | NO | Modified At |
| LS_ID | bigint(20) | NO | Log Stream ID |
| SVR_IP | varchar(46) | NO | Server IP Address |
| SVR_PORT | bigint(20) | NO | Server Port Number |
| SQL_PORT | bigint(20) | NO | SQL Port Number |
| ZONE | varchar(128) | NO | Zone Name |
| ROLE | varchar(8) | NO | Replica role: <ul><li>`LEADER` </li><li> `FOLLOWER`</li></ul> |
| MEMBER_LIST | varchar(4480) | NO | List of replica members, separated by commas for multiple replicas: <ul><li>When the role is `LEADER` This field is valid when. The display format for a single replica is `svr_ip:svr_port:timestamp`. Where: <ul><li>`svr_ip`: The IP address of the server where the replica is located.</li> <li>`svr_port`: the port number of the server where the replica resides.</li> <li>`timestamp`: The time when the replica was added to the member list. Default value: `1`, this value will change if replica supplementation or migration operations are performed.</li></ul></br> Display example: 172.xx.xxx.xxx:2882:1</li> <li>When the role is not `LEADER` When the time is displayed as `NULL`.</li></ul> |
| PAXOS_REPLICA_NUMBER | bigint(20) | NO | Quorum of Paxos replicas: When the role is `LEADER` This field is valid when the parameter is specified; otherwise, it is set to `NULL` |
| REPLICA_TYPE | varchar(18) | NO | Replica type: <ul><li>`FULL`: Full-featured replica</li> <li>`READONLY`: read-only replica</li> <li>`COLUMNSTORE`: Columnstore replica</li></ul> |
| LEARNER_LIST | longtext | YES | The list of read-only replicas for the current log stream, with multiple replicas separated by commas. The display format for a single replica is `svr_ip:svr_port:timestamp:flag`. Where: <ul><li>`svr_ip`: The IP address of the server where the replica resides.</li> <li>`svr_port`: The port number of the server where the replica resides. </li> <li>`timestamp`: The time when the replica joined. Default value: `1`. This value changes if you perform replica replenishment or migration.</li> <li>`flag`: Indicates whether the replica is in migration. `0` indicates that the replica is not involved in migration; `2` Indicates that the replica is in the process of migration.</li></ul></br> Display example: 172.xx.xxx.xxx:2882:1:0 |
| REBUILD | varchar(5) | NO | Whether the replica is undergoing rebuild |
