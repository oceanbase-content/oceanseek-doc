# oceanbase.DBA_OB_TEMP_FILES

## Overview

The `DBA_OB_TEMP_FILES` view displays information about temporary files.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| -------- | -------- | ------------------ | -------- |
| SVR_IP | varchar(46) | NO | IP Address of OBServer |
| SVR_PORT | bigint(20) | NO | Port of OBServer |
| FILE_ID | bigint(20) | NO | File ID of Temporary File |
| TRACE_ID | varchar(64) | NO | TRACE ID of the Current Environment When the Temporary File Was Opened |
| DIR_ID | bigint(20) | NO | Directory ID of Temporary Files |
| BYTES | bigint(20) | NO | Data size of temporary files, in bytes |
| START_OFFSET | bigint(20) | NO | The byte offset of the temporary file where the data starts. This is the starting position of the current valid data. |
| TOTAL_WRITES | bigint(20) | NO | Total Number of Temporary File Write Requests |
| UNALIGNED_WRITES | bigint(20) | NO | Total Number of Asynchronous Write Requests for Temporary Files |
| TOTAL_READS | bigint(20) | NO | Total Number of Temporary File Read Requests |
| UNALIGNED_READS | bigint(20) | NO | Total Number of Asynchronous Read Requests for Temporary Files |
| TOTAL_READ_BYTES | bigint(20) | NO | Total size of read requests for temporary files, in bytes |
| LAST_ACCESS_TIME | timestamp(6) | NO | Last Access Time of Temporary File |
| LAST_MODIFY_TIME | timestamp(6) | NO | Last Modified Time of Temporary File |
| BIRTH_TIME | timestamp(6) | NO | Temporary File Creation Time |

## Sample query

Query temporary file information.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_TEMP_FILES LIMIT=1 \G
```
