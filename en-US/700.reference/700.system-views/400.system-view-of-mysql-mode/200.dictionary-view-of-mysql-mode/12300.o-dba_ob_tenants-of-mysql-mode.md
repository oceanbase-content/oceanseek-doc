# oceanbase.DBA_OB_TENANTS

## Overview

Displays the basic information of a tenant.

* When querying this view from the sys tenant, it displays information for all tenants, including the sys tenant, user-created tenants (user tenants), and the meta tenant. You can distinguish between [tenant types](../../../../600.manage/200.tenant-management/300.tenant-type.md) based on the `TENANT_TYPE` column.
* When querying this view from a user tenant, only information of the current tenant is displayed.

## Columns

| STATUS | varchar(64) | NO | Current tenant status: <ul><li>`NORMAL`: Normal tenant status. </li><li>`RESTORE`: Tenant in physical restore  </li><li>`CREATING`: Tenant is being created. </li><li>`DROPPING`: Tenant being deleted </li></ul> |
| IN_RECYCLEBIN | varchar(3) | NO | Whether it is in the recycle bin: <ul><li>`YES`: In the recycle bin </li><li>`NO`: Not in Recycle Bin </li></ul> |

| TENANT_ROLE | varchar(100) | NO | Cluster roles: <ul><li>`PRIMARY`: Primary Tenant   </li><li>`STANDBY`: Standby Tenant  </li><li>`RESTORE`: The tenant is being restored. </li></ul> |
| SWITCHOVER_STATUS | varchar(100) | NO | SWITCHOVER Status: <ul><li>`NORMAL`: Normal, not in the process of switching.   </li><li>`PREPARE SWITCHING TO PRIMARY`: Prepare for standby-to-primary switchover state. </li><li>`SWITCHING TO PRIMARY`: Standby Switchover Status</li><li>`PREPARE FLASHBACK`: Prepare for flashback state. </li><li>`FLASHBACK`: Flashback status. </li><li>`PREPARE SWITCHING TO STANDBY`: Prepare for primary-to-standby switchover. </li><li>`SWITCHING TO STANDBY`: Primary to standby status</li></ul> |

| READABLE_SCN | bigint(20) unsigned | NO | The readable snapshot version of the current tenant. This parameter is meaningless for the sys tenant and meta tenant, and its value is NULL. |
| RECOVERY_UNTIL_SCN | bigint(20) unsigned | NO | Maximum restore point of the current tenant. This parameter is meaningless for the sys tenant and meta tenant, and its value is NULL. |
| LOG_MODE | varchar(100) | NO | Archive mode:<ul><li>`ARCHIVELOG`: Archiving mode is enabling. </li><li>`NOARCHIVELOG`: Archiving mode is not enabled. </li></ul> |
| ARBITRATION_SERVICE_STATUS | varchar(64) | NO | The status of the tenant's arbitration service. Valid values: <ul><li>`ENABLING`: Enabling</li><li>`ENABLED`: Completed </li><li>`DISABLING`: Shutting down</li><li>`DISABLED`: Close the window. </li></ul> |
| UNIT_NUM | bigint(20) | NO | Each zone of the tenant `UNIT_NUM` Minimum value of |
| ZONE_UNIT_NUM_LIST | varchar(65536) | NO | Displays the number of units in each zone under a tenant. |
| COMPATIBLE | varchar(65536) | NO | Compatibility Version |
| MAX_LS_ID | bigint(20) | NO | The largest log stream ID that the tenant has ever had. For the system tenant and Meta tenant, this value is 1; for user tenants, it is the actual size. |
| RESTORE_DATA_MODE | varchar(128) | NO | The mode for restoring tenant data. Valid values: <ul><li>`NORMAL`: Indicates that the tenant was created normally or restored through full data recovery.</li><li>`REMOTE` indicates that the tenant has been quickly restored and the data is in a remotely referenced state.</li></ul> |
| FLASHBACK_LOG_SCN | bigint(20) | NO | The point in time when log trimming was last performed for the tenant. After a failover, you can use an O&M command to trim the standby tenant's logs to this point in time, thereby connecting the original standby tenant of the primary tenant to the new primary tenant. |
| COMMENT | varchar(4096) | NO | Comments |
| PROTECTION_MODE | varchar(128) | NO | The protection mode of the current tenant. Currently, only `MAXIMUM PERFORMANCE` (Maximum performance) Protection mode. |
| PROTECTION_LEVEL | varchar(128) | NO | The protection level of the current tenant. Currently, only `MAXIMUM PERFORMANCE` (Maximum Performance) Protection Level. |
