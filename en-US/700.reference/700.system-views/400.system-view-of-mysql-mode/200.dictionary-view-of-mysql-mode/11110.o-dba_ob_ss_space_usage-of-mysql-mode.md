# oceanbase.DBA_OB_STORAGE_SPACE_USAGE

## Overview

The `DBA_OB_STORAGE_SPACE_USAGE` view is used to record the storage space usage on object storage for the current tenant.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --------------- | --------------- | --------------------- | ---------------------------------------- |
| ENDPOINT | varchar(128) | NO | Endpoint for shared storage. |
| PATH | varchar(128) | NO | The path of the shared storage. |
| STORAGE_TYPE | varchar(32) | NO | Storage type:<ul><li>`Local All Bytes`: all data in the local directory on object storage.</li> <li>`Shared Data Bytes`: data in public directories of object storage.</li> <li>`Shared Meta Bytes`: all metadata on object storage.</li></ul> |
| VALUE | bigint(20) | NO | `STORAGE_TYPE` The corresponding space usage, in bytes. |

## Sample query

View the storage space usage of the object storage for this tenant.

```shell
obclient(root@mysql001)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_STORAGE_SPACE_USAGE;
```

The query result is as follows:

```shell
+----------+-------+-------------------+----------+
| ENDPOINT | PATH  | STORAGE_TYPE      | VALUE    |
+----------+-------+-------------------+----------+
| UNUSE    | UNUSE | Local All Bytes   |        0 |
| UNUSE    | UNUSE | Shared Data Bytes | 22203985 |
| UNUSE    | UNUSE | Shared Meta Bytes |  6508544 |
+----------+-------+-------------------+----------+
3 rows in set
```
