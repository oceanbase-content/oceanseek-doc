# oceanbase.DBA_OB_RSRC_IO_DIRECTIVES

<main id="notice" type='explain'>
<h4>Note</h4>
<p>In the current version, it is recommended to use the view <a href="11020.o-dba_ob_rsrc_directives-of-mysql-mode.md">DBA_OB_RSRC_DIRECTIVES</a> to view various resource configuration parameters of a tenant in the Resource Manager.</p>
</main>

## Overview

Displays the I/O resource configuration in the resource manager.

## Columns

| **Column** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| PLAN | varchar(128) | NO | Resource Plan Name of the Statement |
| GROUP_OR_SUBPLAN | varchar(128) | NO | Resource group name controlled by directives |
| COMMENTS | varchar(2000) | YES | Resource Plan Remarks |
| MIN_IOPS | bigint(20) | NO | In the event of I/O contention, the reserved IOPS resources for the resource group, specified by all resource groups `MIN_IOPS` The sum of these values must not exceed 100. Default value: `0` |
| MAX_IOPS | bigint(20) | NO | The maximum IOPS resources that a resource group can use, specified for all resource groups. `MAX_IOPS` The sum of these values can exceed 100. The default value is `100` |
| WEIGHT_IOPS | bigint(20) | NO | The weight value of IOPS in case of I/O resource contention, specified for all resource groups. `WEIGHT_IOPS` The sum of these values can exceed 100. To meet the requirement, `MIN_IOPS`, `MAX_IOPS` If this parameter is not set, I/O resources will be allocated according to the normalized weight values. The default value is `0` |

## Sample query

You can query the IO resource configuration in the resource manager of the current tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_RSRC_IO_DIRECTIVES;
```

The query result is as follows:

```shell
+---------+------------------+----------+----------+----------+-------------+
| PLAN    | GROUP_OR_SUBPLAN | COMMENTS | MIN_IOPS | MAX_IOPS | WEIGHT_IOPS |
+---------+------------------+----------+----------+----------+-------------+
| daytime | batch_group      |          |       40 |       80 |          70 |
+---------+------------------+----------+----------+----------+-------------+
1 row in set
```
