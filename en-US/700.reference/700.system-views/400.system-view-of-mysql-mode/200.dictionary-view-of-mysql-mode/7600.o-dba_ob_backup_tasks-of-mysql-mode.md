# oceanbase.DBA_OB_BACKUP_TASKS

## Overview

Displays the tenant's own task-level backup tasks.

## Columns

| Field Name | Field Name | Whether can be NULL | Field Name |
| ------------------------------- | ---------------- | ----------------- | ---------------------------------- |
| TASK_ID | bigint(20) | NO | Task-level backup task ID, corresponding to the task of a backup set. |
| JOB_ID | bigint(20) | NO | The Job ID to which this task belongs. |
| INCARNATION | bigint(20) | NO | Indicates the number of forks after a flashback database operation. |
| BACKUP_SET_ID | bigint(20) | NO | The ID of the backup set corresponding to this task. |
| START_TIMESTAMP | timestamp(6) | NO | The start time of the task. |
| END_TIMESTAMP | timestamp(6) | NO | End time of the task. |
| STATUS | varchar(4096) | NO | Backup Status |
| START_SCN | bigint(20) unsigned | NO | SCN at the Start of Backup |
| END_SCN | bigint(20) unsigned | NO | SCN at the End of Backup |
| USER_LS_START_SCN | bigint(20) unsigned | NO | SCN of Backup Log Stream META |
| ENCRYPTION_MODE | varchar(4096) | YES | Encryption mode:<ul><li>None: no encryption.</li><li>Password: password protection only.</li><li>Password Encryption: encryption and password protection.</li><li>Transparent Encryption: transparent data encryption (TDE).</li><li>Dual mode Encryption: TDE and password protection.</li></ul> </br>The following modes are supported: None and Password. |
| PASSWD | varchar(4096) | YES | password |
| INPUT_BYTES | bigint(20) | YES | Input Bytes |
| OUTPUT_BYTES | bigint(20) | YES | Output Bytes |
| OUTPUT_RATE_BYTES | decimal(28,4) | NO | Output Bytes Per Second |
| EXTRA_META_BYTES | bigint(20) | YES | Extra Metadata Bytes |
| TABLET_COUNT | bigint(20) | YES | Total Number of Backed-up Tablets |
| FINISH_TABLET_COUNT | bigint(20) | YES | Total Backed-Up Tablets |
| MACRO_BLOCK_COUNT | bigint(20) | YES | Number of Macroblocks |
| FINISH_MACRO_BLOCK_COUNT | bigint(20) | YES | Number of Macroblocks Backed Up |
| FILE_COUNT | bigint(20) | YES | Number of Backup Files |
| META_TURN_ID | bigint(20) | YES | Backup Meta Cycle |
| DATA_TURN_ID | bigint(20) | YES | Backup Cycle of DATA |
| RESULT | bigint(20) | YES | Backup Error Code Result |
| COMMENT | varchar(4096) | YES | Error Code Description |
| PATH | varchar(4096) | YES | Backup Path |
| MINOR_TURN_ID | bigint(20) | NO | Round of Minor Compaction Data Backup Completion |
| MAJOR_TURN_ID | bigint(20) | NO | Round of Baseline Data Backup Completion |
| DATA_PROGRESS | decimal(26,2) | NO | The backup progress of data backup. The calculation method is `Number of completed macroblocks / Total number of macroblocks`, and the result is rounded to two decimal places. For example, 87.65 indicates that the current progress is 87.65%. |
| LOG_FILE_COUNT | bigint(20) | NO | Total Number of Archived Clog Files |
| FINISH_LOG_FILE_COUNT | bigint(20) | NO | Number of Archived Clog Files Backed Up |
| LOG_PROGRESS | decimal(26,2) | NO | The backup progress of archived clog files. The calculation method is `Number of Archived Clog Files Backed Up / Total Number of Archived Clog Files`, with the result rounded to two decimal places. For example, 87.65 indicates that the current progress is 87.65%. |

## Sample query

Users can query backup tasks at the task level within their own tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_BACKUP_TASKS\G
```
