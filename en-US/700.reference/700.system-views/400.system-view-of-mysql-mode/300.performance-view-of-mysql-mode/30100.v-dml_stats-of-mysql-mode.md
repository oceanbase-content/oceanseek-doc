# V$DML_STATS

## Overview

Displays the DML information of user tables for the current tenant on the current OBServer node.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | Server IP Address |
| SVR_PORT | bigint(20) | NO | Server Port Number |
| INST_ID | bigint(20) | NO | Tenant ID |
| OBJN | bigint(20) | NO | Object ID |
| INS | bigint(20) | NO | Approximate Number of Inserts Since the Last Statistics Collection |
| UPD | bigint(20) | NO | Approximate Number of Updates Since the Last Statistics Collection |
| DEL | bigint(20) | NO | Approximate Number of Deletions Since the Last Statistics Collection |
| DROPSEG | bigint(0) | NO | This field is not currently supported and defaults to NULL. |
| CURROWS | bigint(0) | NO | This field is not currently supported and defaults to NULL. |
| PAROBJN | bigint(20) | NO | This field is not currently supported and defaults to NULL. |
| LASTUSED | bigint(0) | NO | This field is not currently supported and defaults to NULL. |
| FLAGS | bigint(0) | NO | This field is not currently supported and defaults to NULL. |
| CON_ID | bigint(0) | NO | This field is not currently supported and defaults to NULL. |

## Sample query

View the DML information of user tables for the current tenant on the current OBServer node.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$DML_STATS;
```
