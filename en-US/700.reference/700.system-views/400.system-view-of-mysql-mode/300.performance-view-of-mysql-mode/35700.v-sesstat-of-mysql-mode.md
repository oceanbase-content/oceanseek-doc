# V$SESSTAT

## Overview

The `V$SESSTAT` view displays statistics for each session.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| ---- | ---- | ---- | ---- |
| SID | bigint(20) | NO | <ul><li>In direct connection mode:<br>This field indicates the server session ID.</li> <li>In ODP mode:</li><ul><li>When the ODP parameter <code>client_session_id_version = 2</code> is set, this field indicates the client session ID. </li> <li>When <code>client_session_id_version = 1</code> is set, this field indicates the server session ID.</li></ul></ul> |
| CON_ID | bigint(20) | NO | Tenant ID |
| SVR_IP | varchar(46) | NO | IP Address of the Server Where Information is Located |
| SVR_PORT | bigint(20) | NO | Port number of the server where the information is located |
| STATISTICS# | bigint(20) | NO | Index of the statistical event |
| VALUE | bigint(20) | NO | Count of Occurrences |

## Sample query

Query the overview of statistics events at the session level.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$SESSTAT LIMIT 1\G
```

The query result is as follows:

```shell
*************************** 1. row ***************************
       SID: 1152921504606863376
    CON_ID: 1002
    SVR_IP: xx.xx.xx.xx
  SVR_PORT: 2882
STATISTIC#: 0
     VALUE: 0
```
