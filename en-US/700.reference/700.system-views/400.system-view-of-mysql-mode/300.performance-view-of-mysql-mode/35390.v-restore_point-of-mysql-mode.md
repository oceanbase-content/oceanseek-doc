# V$RESTORE_POINT

## Overview

The `V$RESTORE_POINT` view displays information about restore points.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| ----------- | -------------- | ---------------- | ---------------- |
| TENANT_ID | bigint(20) | YES | Tenant ID |
| SNAPSHOT | bigint(20) | NO | Database SCN at the time the restore point was created |
| TIME | timestamp(6) | NO | Time when the restore point was created |
| NAME | varchar(512) | YES | Restore Point Name |

## Sample query

View all restore point information for the current tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$RESTORE_POINT;
```

The query result is as follows:

```shell
+-----------+------------------+----------------------------+----------+
| TENANT_ID | SNAPSHOT         | TIME                       | NAME     |

|      1001 | 1710987516261317 | 2024-03-21 10:18:36.263262 | rt1      |
|      1001 | 1710987957553230 | 2024-03-21 10:25:57.554246 | rt_mysql |
+-----------+------------------+----------------------------+----------+
2 rows in set
```
