# GV$OB_TABLET_LOCAL_CACHE

## Overview

Displays the overall cache status of the current tenant across all OBServer nodes.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ---------------------- | --------------- | ---------------- | --------------------------------- |
| SVR_IP | varchar(46) | NO | IP Address of OBServer Node |
| SVR_PORT | bigint(20) | NO | Port number of the OBServer node |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| TABLET_ID | bigint(20) | NO | Tablet ID |
| STORAGE_CACHE_POLICY | varchar(64) | NO | The current cache status of this tablet:<ul><li>`AUTO`: Automatic identification of hot and cold data</li> <li>`HOT`: Hot data</li></ul> |
| CACHED_DATA_SIZE | bigint(20) | NO | The amount of data cached locally in this tablet, in bytes |
| CACHE_HIT_COUNT | bigint(20) | NO | The number of times the tablet cache hit. This field is not currently enabled, and its value is `-1` |
| CACHE_MISS_COUNT | bigint(20) | NO | The number of times the tablet cache has experienced misses. This field is not currently enabled and its value is `-1` |
| CACHE_HIT_SIZE | bigint(20) | NO | The amount of data cached in the tablet, in bytes. This field is not currently enabled and the value is `-1` |
| CACHE_MISS_SIZE | bigint(20) | NO | The amount of data in bytes that is cached in the tablet for missed requests. This field is not currently enabled and the value is `-1` |
| INFO | varchar(4096) | NO | Other information |

## Sample query

In SS mode, you can view the overall cache status of your tenant across all OBServer nodes.

```shell
obclient> SELECT SVR_IP, SVR_PORT, TENANT_ID, TABLET_ID, STORAGE_CACHE_POLICY, INFO FROM oceanbase.GV$OB_TABLET_LOCAL_CACHE;
```
