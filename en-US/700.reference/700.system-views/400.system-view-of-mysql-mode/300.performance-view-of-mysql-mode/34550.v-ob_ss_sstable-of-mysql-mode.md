# V$OB_SHARED_SSTABLES

## Overview

Displays the SSTable information of the current tenant.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ------------------------- | ------------- | ---------------- | --------------------------------- |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| LS_ID | bigint(20) | NO | Log Stream ID |
| TABLET_ID | bigint(20) | NO | Partition ID |
| TRANSFER_SCN | bigint(20) | NO | Transfer version number |
| TABLE_TYPE | varchar(20) | NO | SSTable types, including MAJOR, MINOR, MINI, META, DDL_DUMP, CO_MAJOR, NORMAL_CG, ROWKEY_CG, COL_ORIENTED_META, DDL_MERGE_CO, DDL_MERGE_CG, DDL_MEM_CO, DDL_MEM_CG, DDL_MEM_MINI_SSTABLE, MDS_MINI, MDS_MINOR, and INVALID. |
| CG_IDX | bigint(20) | NO | SSTable corresponding to which column of the columnar data |
| START_LOG_SCN | bigint(20) | NO | Left Boundary of SSTable |
| END_LOG_SCN | bigint(20) | NO | Right Boundary of SSTable |
| DATA_CHECKSUM | bigint(20) | NO | Data checksum |
| SIZE | bigint(20) | NO | The actual disk space occupied by the SSTable, in bytes. |
| REC_SCN | bigint(20) | NO | Log replay position required after the SSTable is uploaded |
| UPPER_TRANS_VERSION | bigint(20) | NO | Maximum Transaction Commit Version Number in SSTable |
| CONTAIN_UNCOMMITTED_ROW | varchar(3) | NO | Whether Uncommitted Data is Included |

## Sample query

In a user tenant, view the SSTable information of a specified `TABLET_ID` under a specified log stream in that tenant.

```shell
obclient> SELECT * FROM oceanbase.V$OB_SHARED_SSTABLES WHERE LS_ID=1 AND TABLET_ID=60263;
```
