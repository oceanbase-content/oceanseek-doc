# V$OB_COMPATIBILITY_CONTROL

## Overview

The `V$OB_COMPATIBILITY_CONTROL` view displays all features that can be controlled for compatibility with the product behavior of the OceanBase AI database release version.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| ------------ | -------- | ------------------- | -------- |
| NAME | varchar(128) | NO | Feature name |
| DESCRIPTION | varchar(4096) | NO | Feature description |
| IS_ENABLE | varchar(5) | NO | Effective |
| ENABLE_VERSIONS | longtext | NO | The effective version range, represented by a series of intervals |

## Sample query

View all features whose product behavior can be controlled for compatibility with the OceanBase AI database release version.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_COMPATIBILITY_CONTROL;
```
