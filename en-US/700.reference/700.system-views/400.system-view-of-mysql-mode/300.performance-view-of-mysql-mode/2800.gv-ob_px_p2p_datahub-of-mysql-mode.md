# GV$OB_PX_P2P_DATAHUB

## Overview

Displays information related to data transfer operations during parallel execution.

## Columns

| **Column** | **Type** | **Is NULL** | **Description** |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | Server IP Address |
| SVR_PORT | bigint(20) | NO | Server Port Number |
| TRACE_ID | varchar(64) | NO | The trace ID of the SQL statement involved in this data. |
| DATAHUB_ID | bigint(20) | NO | Datahub ID of the data |
| MESSAGE_TYPE | varchar(256) | NO | Message type of the data |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| HOLD_SIZE | bigint(20) | NO | Materialized data size |
| TIMEOUT_TS | datetime | NO | The expected timeout period for this data |
| START_TIME | datetime | NO | The start time of the write operation. |
