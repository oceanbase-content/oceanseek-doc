# V$SQL_JOIN_FILTER

## Overview

Dynamically displays information related to Join Filter execution for the current tenant on the current OBServer node.

## Columns

| **Column** | **Type** | **Is NULL** | **Description** |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | Server IP Address |
| SVR_PORT | bigint(20) | NO | Server Port Number |
| QC_SESSION_ID | bigint(0) | NO | The QC (Query Coordinator) session ID of the cursor for a parallel query. <ul><li>In direct connection mode:<br>This field indicates the server session ID.</li> <li>In ODP mode:</li><ul><li>When the ODP parameter <code>client_session_id_version = 2</code> is set, this field indicates the client session ID. </li> <li>When <code>client_session_id_version = 1</code> is set, this field indicates the server session ID.</li></ul></ul> |
| QC_INSTANCE_ID | bigint(0) | NO | QC instance ID of the cursor for the parallel query |
| SQL_PLAN_HASH_VALUE | bigint(0) | NO | Hash value of the SQL plan for the cursor in a parallel query |
| FILTER_ID | bigint(20) | NO | The ID of the connection filter in the given cursor, which corresponds to the filter ID in the execution plan. |
| BITS_SET | bigint(0) | NO | The size of the bitmap used in BLOOM_FILTER. In the current version, this parameter is only for compatibility. |
| FILTERED | bigint(20) | NO | Number of rows processed by the connection filter |
| PROBED | bigint(20) | NO | The number of rows in the right table that have passed the bitmap filter test. This refers to the total number of filtered and unfiltered rows. |
| ACTIVE | bigint(0) | NO | Whether the filter is active (Yes) or inactive (No). |
| CON_ID | bigint(20) | NO | The ID of the container to which the data belongs. |
| TRACE_ID | varchar(64) | NO | Trace ID Corresponding to SQL Statement |

## Sample query

In a user tenant, view information related to the execution of join filters on the current node of that tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$SQL_JOIN_FILTER;
```
