# V$SYSSTAT

## Overview

Displays the statistical event information of the current tenant on the current OBServer node.

Where:

* `STATISTIC#`: the number of the statistic. The number for the same statistic may vary across different OBServer node versions.

* `STAT_ID`: The ID of the statistic. The ID of the same statistic is guaranteed to be the same across different OBServer node versions.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>To use this view, you must enable monitoring by setting the value of the <code>enable_perf_event</code> parameter to True.</p>
</main>

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| CON_ID | bigint(20) | NO | Tenant ID |
| SVR_IP | varchar(46) | NO | IP Address of the Server Where Information is Located |
| SVR_PORT | bigint(20) | NO | Port number of the server where the information is located |
| STATISTIC# | bigint(20) | NO | Index of the statistical event |
| NAME | varchar(64) | NO | Name of the statistical event |
| CLASS | bigint(20) | NO | Type of the statistical event |
| VALUE | bigint(20) | NO | Result value corresponding to the statistical event |
| VALUE_TYPE | varchar(16) | NO | Statistic value type:<ul><li>ADD: cumulative</li><li>SET: updated</li></ul> |
| STAT_ID | bigint(20) | NO | Statistics Event ID |

## Sample query

In the user tenant, view the statistical event information of the current tenant on the current node, displaying the first 10 records.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$SYSSTAT LIMIT 10;
```
