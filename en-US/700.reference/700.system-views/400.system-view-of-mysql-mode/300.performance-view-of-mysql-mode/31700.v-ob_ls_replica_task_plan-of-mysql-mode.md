# V$OB_LS_REPLICA_TASK_PLAN

## Overview

Displays all tasks that should be generated currently, including those that have been generated and those that have not been generated.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ------------------------- | ---------------- | ----------------- | ------------------------------------ |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| LS_ID | bigint(20) | NO | Log Stream ID |
| TASK_TYPE | varchar(64) | NO | Task type. Valid values: <ul><li>MIGRATE REPLICA: migrate a replica.</li><li>ADD REPLICA: add a replica.</li><li>REMOVE PAXOS REPLICA: remove a replica.</li><li>MODIFY PAXOS REPLICA NUMBER: modify the quorum replica count.</li></ul> |
| PRIORITY | varchar(5) | NO | Task priority. Valid values:<ul><li>LOW: low-priority task. Only migration tasks can be low-priority.</li><li>HIGH: high-priority task.</li></ul> |
| TARGET_REPLICA_SVR_IP | varchar(46) | YES | IP Address of the Server Where the Target Replica Resides |
| TARGET_REPLICA_SVR_PORT | bigint(20) | YES | Port number of the server where the target replica resides |
| TARGET_PAXOS_REPLICA_NUMBER | bigint(20) | YES | Quorum Paxos Replicas for Target Replica |
| TARGET_REPLICA_TYPE | varchar(16) | YES | Target Replica Type |
| SOURCE_REPLICA_SVR_IP | varchar(46) | YES | IP address of the server where the source replica resides.</br>This field is invalid for operations such as deleting a replica or modifying the quorum count, and is displayed as NULL. |
| SOURCE_REPLICA_SVR_PORT | bigint(20) | YES | Port number of the server where the source replica resides.</br>This field is invalid and displays as 0 for tasks such as deleting a replica or modifying the quorum count. |
| SOURCE_PAXOS_REPLICA_NUMBER | bigint(20) | YES | Quorum Paxos Replicas at Source |
| SOURCE_REPLICA_TYPE | varchar(16) | YES | Source Replica Type</br>This field is invalid for tasks such as deleting a replica or modifying the quorum count, and is displayed as NULL. |
| TASK_EXEC_SVR_IP | varchar(46) | YES | IP Address of the Task Execution Machine |
| TASK_EXEC_SVR_PORT | bigint(20) | YES | Port number of the task execution machine |
| COMMENT | varchar(2048) | YES | Reason for Task Generation Remarks |
| CONFIG_VERSION | varchar(128) | YES | Record the config_version information of the clog layer during disaster recovery task execution. |
