# V$OB_TRANSACTION_SCHEDULERS

## Overview

The `V$OB_TRANSACTION_SCHEDULERS` view is used to query the transaction scheduler information for all servers.

## Columns

| **Column** | **Type** | **Nullable** | **Note** |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| SVR_IP | varchar(46) | NO | IP Address of the Server Where the Replica Resides |
| SVR_PORT | bigint(20) | NO | Server Port of the Replica |
| SESSION_ID | bigint(20) | NO | <ul><li>In direct connection mode:<br>This field indicates the server session ID.</li> <li>In ODP mode:</li><ul><li>When the ODP parameter <code>client_session_id_version = 2</code> is set, this field indicates the client session ID. </li> <li>When <code>client_session_id_version = 1</code> is set, this field indicates the server session ID.</li></ul></ul> |
| TX_ID | bigint(20) | NO | Transaction ID |
| STATE | varchar(18) | NO | Transaction Status |
| CLUSTER_ID | bigint(20) | NO | Unique cluster ID |
| COORDINATOR | bigint(20) | NO | Log Stream ID of the Coordinator |
| PARTICIPANTS | varchar(1024) | NO | Transaction participant information |
| ISOLATION_LEVEL | varchar(16) | NO | Isolation Level |
| SNAPSHOT_VERSION | bigint(20) unsigned | NO | Snapshot version for the RR or SERIAL isolation level. If not enabled, the value is -1. |
| ACCESS_MODE | varchar(10) | NO | Access mode (read-only or read/write) |
| TX_OP_SN | bigint(20) | NO | Transaction-level operation sequence number |
| ACTIVE_TIME | timestamp(6) | NO | Explicitly or Implicitly Enable Transaction Timestamping |
| EXPIRE_TIME | timestamp(6) | NO | Transaction Expiration Timestamp |
| CAN_EARLY_LOCK_RELEASE | varchar(7) | NO | Whether row locks can be released in advance |
| FORMATID | bigint(20) | NO | Format Identifier for Global Transactions |
| GLOBALID | varchar(257) | NO | Global Transaction Unique Identifier |
| BRANCHID | varchar(257) | NO | Unique identifier of a branch transaction |

## Sample query

```sql
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_TRANSACTION_SCHEDULERS;
```
