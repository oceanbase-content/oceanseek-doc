# V$OB_LOCKS

## Overview

Displays the lock holding or lock requesting status of each table for the current user.

## Columns

| **Column** | **Type** | **Is NULL** | **Description** |
| ---- | ---- | ---- | ---- |
| SVR_IP | varchar(46) | NO | IP address of the OBServer node that holds or requests the lock |
| SVR_PORT | bigint(20) | NO | Port number of the OBServer node holding or requesting the lock |
| TENANT_ID | bigint(20) | NO | ID of the tenant that holds or requests the lock |
| TRANS_ID | bigint(20) | NO | Transaction ID of the transaction holding or requesting the lock |
| SESSION_ID | bigint(20) | NO | The session ID that holds or requests the lock.<ul><li>In direct connection mode:<br>This field indicates the server session ID.</li> <li>In ODP mode:</li><ul><li>When the ODP parameter <code>client_session_id_version = 2</code> is set, this field indicates the client session ID. </li> <li>When <code>client_session_id_version = 1</code> is set, this field indicates the server session ID.</li></ul></ul> |
| TYPE | varchar(9) | NO | Lock type:<ul><li>TM: table lock</li><li>TX: transaction lock</li><li>TR: row lock</li></ul> |
| ID1 | bigint(20) | NO | Lock identifier. 1:<ul><li>Table lock: TABLE_ID or TABLET_ID</li><li>Transaction lock: TX_ID</li><li>Row lock: TABLET_ID</li></ul> |
| ID2 | varchar(533) | NO | Lock identifier. 2:<ul><li>Table lock: NULL</li><li>Transaction lock: NULL</li><li>Row lock: TX_ID + row key</li></ul> |
| ID3 | varchar(512) | NO | Lock identifier. 3:<ul><li>TM: TABLE_ID / TABLET_ID</li><li>TX: NULL</li><li>TR: TABLET_ID + row key of the current row</li></ul> |
| LMODE | varchar(8) | NO | Current lock mode: <ul><li>NONE: No locks are held.</li><li>RS: ROW SHARE</li><li>RX: ROW EXCLUSIVE</li><li>S: SHARE</li><li>SRX: SHARE ROW EXCLUSIVE</li><li>X: EXCLUSIVE</li></ul> |
| REQUEST | varchar(8) | NO | The lock mode requested for the current request. Valid values: <ul><li>NONE: no lock is requested. </li><li>RS: row share lock.  </li><li>RX: row exclusive lock.  </li><li>S: share lock.  </li><li>SRX: share row exclusive lock.  </li><li>X: exclusive lock.  </li></ul> |
| CTIME | bigint(20) | NO | Time held or waiting for a lock, in microseconds |
| BLOCK | bigint(1) | NO | Indicates whether the lock requested by the current transaction is held by another transaction:<ul><li>0: The lock requested is not held by another transaction. That is, this transaction holds the lock.  </li><li>1: The lock requested is held by another transaction. That is, this transaction is blocked. </li></ul> |

## Sample query

Query the lock holding or request lock status of each table for the current user.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_LOCKS LIMIT 1\G
```

The query result is as follows:

```shell
*************************** 1. row ***************************
    SVR_IP: xx.xx.xx.xx
  SVR_PORT: 2882
 TENANT_ID: 1003
  TRANS_ID: 7414198
SESSION_ID: 3221619563
      TYPE: TX
       ID1: 7414198
       ID2: 3221619563
       ID3: NULL
     LMODE: X
   REQUEST: NONE
     CTIME: 11162
     BLOCK: 0
```
