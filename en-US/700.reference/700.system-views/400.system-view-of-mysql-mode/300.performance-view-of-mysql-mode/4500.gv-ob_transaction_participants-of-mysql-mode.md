# GV$OB_TRANSACTION_PARTICIPANTS

## Overview

The `GV$OB_TRANSACTION_PARTICIPANTS` view displays information about the participants in active transactions on all OBServer nodes.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ------------------ | --------------- | ------------ | ----------- |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| SVR_IP | varchar(46) | NO | Server IP Address |
| SVR_PORT | bigint(20) | NO | Server Port Number |
| SESSION_ID | bigint(20) | NO | <ul><li>In direct connection mode:<br>This field indicates the server session ID.</li> <li>In ODP mode:</li><ul><li>When the ODP parameter <code>client_session_id_version = 2</code> is set, this field indicates the client session ID. </li> <li>When <code>client_session_id_version = 1</code> is set, this field indicates the server session ID.</li></ul></ul> |
| SCHEDULER_ADDR | varchar(64) | NO | Node Address of the Scheduler |
| TX_TYPE | varchar(11) | NO | Transaction type |
| TX_ID | bigint(20) | NO | Transaction ID |
| LS_ID | bigint(20) | NO | Log Stream ID |
| PARTICIPANTS | varchar(1024) | NO | Participants |
| CTX_CREATE_TIME | timestamp(6) | YES | Context Creation Time |
| TX_EXPIRED_TIME | timestamp(6) | YES | Transaction Timeout Point |
| STATE | varchar(9) | NO | Context Commit Status |
| ACTION | varchar(10) | NO | Previous Action |
| PENDING_LOG_SIZE | bigint(20) | NO | Size of Data to be Persisted |
| FLUSHED_LOG_SIZE | bigint(20) | NO | Size of Persisted Data |
| ROLE | varchar(8) | NO | Context role |
| COORD | bigint(20) | NO | Corresponding coordinator IS ID (effective only after entering the commit phase) |
| LAST_REQUEST_TIME | timestamp(6) | YES | Last Time External Request Received |
| FORMATID | bigint(20) | NO | XID Format |
| GLOBALID | varchar(257) | NO | Global XA Transaction Identifier |
| BRANCHID | varchar(257) | NO | XA Transaction Branch Identifier |

## Sample query

Query the participant information of active transactions on all OBServer nodes.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_TRANSACTION_PARTICIPANTS LIMIT 1\G
```
