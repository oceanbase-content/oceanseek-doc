# V$OB_DYNAMIC_PARTITION_TABLES

## Overview

This view displays information about dynamic partitioned tables for the current tenant. It reads attributes related to dynamic partitioned tables from memory, which provides good read performance.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>Because the dynamic performance view (<code>V$OB_DYNAMIC_PARTITION_TABLES</code>) retrieves information from the memory of the connection node, its data may not be up to date compared to the data dictionary view (<code>DBA/CDB_OB_DYNAMIC_PARTITION_TABLES</code>). You must use <code>TENANT_SCHEMA_VERSION</code> to verify the version.</p>
</main>

## Columns

| field | Type | Is NULL | Description |
| ----------------------- | --------------- | ------------- | ------ |
| TENANT_ID | bigint(20) | NO | The tenant ID of the dynamic partitioned table. |
| TENANT_SCHEMA_VERSION | bigint(20) | NO | The value on which the current attribute is based when retrieved from memory. `schema_version`. |
| DATABASE_NAME | varchar(128) | NO | The name of the database where the dynamic partitioned table is located. |
| TABLE_NAME | varchar(256) | NO | The name of the dynamic partitioned table. |
| TABLE_ID | bigint(20) | NO | The ID of the dynamic partitioned table. |
| MAX_HIGH_BOUND_VAL | varchar(4096) | NO | The upper bound of the maximum RANGE partition. |
| ENABLE | varchar(1024) | NO | Specifies whether to enable dynamic partition management. |
| TIME_UNIT | varchar(1024) | NO | Dynamically partitioned management `time_unit`. |
| PRECREATE_TIME | varchar(1024) | NO | Dynamically partitioned management `precreate_time`. |
| EXPIRE_TIME | varchar(1024) | NO | Dynamic partition management `expire_time`. |
| TIME_ZONE | varchar(1024) | NO | Dynamically partitioned management `time_zone`. |
| BIGINT_PRECISION | varchar(1024) | NO | Dynamically partitioned management `bigint_precision`. |

```sql
SELECT * FROM oceanbase.V$OB_DYNAMIC_PARTITION_TABLES LIMIT 1\G
```
