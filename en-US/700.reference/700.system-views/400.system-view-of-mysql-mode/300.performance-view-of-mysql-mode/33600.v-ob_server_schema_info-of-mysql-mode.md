# V$OB_SERVER_SCHEMA_INFO

## Overview

Displays the schema information of the current server.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| ---------------------------- | ------------- | ---------------- | ---------------------------------- |
| SVR_IP | varchar(46) | NO | Server IP Address |
| SVR_PORT | bigint(20) | NO | Server Port Number |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| REFRESHED_SCHEMA_VERSION | bigint(20) | NO | Schema Versions Refreshed by Tenant |
| RECEIVED_SCHEMA_VERSION | bigint(20) | NO | Schema versions to be refreshed for the tenant |
| SCHEMA_COUNT | bigint(20) | NO | The total number of schema objects in the corresponding schema version. |
| SCHEMA_SIZE | bigint(20) | NO | The total memory size occupied by each schema object under the corresponding schema version, in bytes. |
| MIN_SSTABLE_SCHEMA_VERSION | bigint(20) | NO | Minimum schema version recorded in the tenant's SSTable |

## Sample query

Users can query the schema information on the current OBServer node.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_SERVER_SCHEMA_INFO;
```

The query result is as follows:
