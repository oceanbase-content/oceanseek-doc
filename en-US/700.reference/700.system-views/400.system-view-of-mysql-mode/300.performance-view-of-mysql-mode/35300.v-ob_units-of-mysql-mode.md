# V$OB_UNITS

## Overview

Displays the unit information of the current OBServer node.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ------------------ | -------------- | ------------ | ------------------------------------------------------------------------- |
| SVR_IP | varchar(46) | NO | Server IP Address |
| SVR_PORT | bigint(20) | NO | Server Port Number |
| UNIT_ID | bigint(20) | NO | Unit ID |
| TENANT_ID | bigint(20) | NO | Tenant ID of the unit |
| ZONE | varchar(128) | NO | Zone Name |
| ZONE_TYPE | varchar(128) | NO | The zone type of the unit's zone. Valid values: <ul><li>`NULL`: Indicates that the column value is invalid. Invalid values may briefly appear after an OBServer node restarts.</li> <li>`ReadWrite`: Read/Write Zone</li> <li>`Encryption`: Encrypted Zone</li></ul> |
| REGION | varchar(128) | NO | The name of the region to which the zone where the unit is located belongs. If not set, the default value is `default_region`. Valid values: `NULL` indicates that the column value is invalid. This invalid value may appear briefly after an OBServer node restarts. |
| MAX_CPU | double | NO | Maximum CPU Specification |
| MIN_CPU | double | NO | Minimum CPU Specification |
| MEMORY_SIZE | bigint(20) | NO | Memory size, in bytes |
| MAX_IOPS | bigint(20) | NO | Maximum Disk IOPS Specification |
| MIN_IOPS | bigint(20) | NO | Minimum Disk IOPS Specification |
| IOPS_WEIGHT | bigint(20) | NO | IOPS Weight |
| MAX_NET_BANDWIDTH | bigint(20) | YES | Maximum network bandwidth of the unit, in bytes |
| NET_BANDWIDTH_WEIGHT | bigint(20) | YES | Weight value of unit's network bandwidth |
| LOG_DISK_SIZE | bigint(20) | NO | Log disk size, in bytes |
| LOG_DISK_IN_USE | bigint(20) | NO | Used log disk space, in bytes |
| DATA_DISK_SIZE | bigint(20) | YES | Indicates the size of the local cache available to the unit, in bytes. |
| DATA_DISK_IN_USE | bigint(20) | NO | Indicates the size of the local cache used by the unit, in bytes. |
| STATUS | varchar(64) | NO | Status of the unit: <ul><li>`NORMAL`: Normal state.   </li><li>`MIGRATING IN`: Migrating In   </li><li>`MIGRATING OUT`: Moving Out   </li><li>`MARK DELETING`: Mark for Deletion</li><li>`WAIT GC`: Waiting for GC data </li><li>`DELETING`: GC completed, deleting now. </li><li>`ERROR`: Error status. </li></ul> |
| CREATE_TIME | timestamp(6) | NO | Creation Time of Unit on OBServer Node |
| REPLICA_TYPE | varchar(7) | NO | Replica type. Default value: `FULL` |

## Sample query

You can view the unit information of the current OBServer node in the user tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_UNITS\G
```
