# V$OB_MEMSTORE

## Overview

Displays the MemStore statistics of the current tenant on the current OBServer node.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| ---------------- | ------------- | ---------------- | ---------------------------------- |
| SVR_IP | varchar(46) | NO | Server IP |
| SVR_PORT | bigint(20) | NO | Server Port |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| ACTIVE_SPAN | bigint(20) | NO | Estimated memory usage of the active MemTable (may be higher), in bytes |
| FREEZE_TRIGGER | bigint(20) | NO | Memory size that triggers MemTable freezing, in bytes |
| FREEZE_CNT | bigint(20) | NO | Number of Freezes of MemTable |
| MEMSTORE_USED | bigint(20) | NO | Total memory size currently used by the MemTable, in bytes |
| MEMSTORE_LIMIT | bigint(20) | NO | Memory size limit for MemTable, in bytes |

## Sample query

You can query the memory usage of the MemTable on the current node of the current tenant.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.V$OB_MEMSTORE;
```

The query result is as follows:

```shell
+----------------+----------+-----------+-------------+----------------+------------+---------------+----------------+
| SVR_IP         | SVR_PORT | TENANT_ID | ACTIVE_SPAN | FREEZE_TRIGGER | FREEZE_CNT | MEMSTORE_USED | MEMSTORE_LIMIT |
+----------------+----------+-----------+-------------+----------------+------------+---------------+----------------+
| 172.xx.xxx.xxx |     2882 |      1002 |    62914560 |      603982068 |          0 |      62914560 |     2684354550 |
+----------------+----------+-----------+-------------+----------------+------------+---------------+----------------+
1 row in set
```
