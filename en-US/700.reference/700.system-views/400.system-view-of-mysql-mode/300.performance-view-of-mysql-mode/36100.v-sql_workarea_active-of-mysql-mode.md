# V$SQL_WORKAREA_ACTIVE

## Overview

Displays the workspace information of the currently active operator on the current node.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| ------------------ | -------------- | ---------------- | ------------------------------------------------------------------------------------ |
| SQL_HASH_VALUE | bigint(0) | NO | Hash value of the executed statement. Currently, this value is NULL. |
| SQL_ID | varchar(32) | NO | The unique identifier of an SQL statement. |
| SQL_EXEC_START | date | NO | The time when the SQL statement starts to be executed. |
| SQL_EXEC_ID | bigint(20) | NO | Unique identifier for SQL execution. |
| WORKAREA_ADDRESS | varbinary(8) | NO | The URL of the workspace. |
| OPERATION_TYPE | varchar(40) | NO | Operator types of the workarea, such as Sort, Hash Join, and Group by. |
| OPERATION_ID | bigint(20) | NO | A unique identifier for an operator in the plan tree. |
| POLICY | varchar(6) | NO | Workarea policy:<ul><li>MANUAL</li><li> AUTO </li></ul> |
| SID | bigint(20) | NO | Unique identifier of the session. |
| QCINST_ID | bigint(0) | NO | Query the instance ID of the coordinator. |
| QCSID | bigint(0) | NO | Query coordinator session identifier. |
| ACTIVE_TIME | bigint(20) | NO | Average time of workarea being active, in ms. |
| WORK_AREA_SIZE | bigint(20) | NO | Maximum size of the work area that an operator can use, in bytes. |
| EXPECT_SIZE | bigint(20) | NO | The expected size of the workspace, in bytes. |
| ACTUAL_MEM_USED | bigint(20) | NO | The memory size requested for the workspace, in bytes. |
| MAX_MEM_USED | bigint(20) | NO | The maximum memory usage for the workspace, in bytes. |
| NUMBER_PASSES | bigint(20) | NO | The mode in which the workspace runs. Valid values:<ul><li>0: optimal mode</li><li>1: one-pass mode</li><li>≥2: multi-pass mode</li></ul> |
| TEMPSEG_SIZE | bigint(20) | NO | The size of temporary space used by the workspace, in bytes. If this parameter is NULL, no temporary file was written. |
| TABLESPACE | varchar(20) | NO | The table namespace for writing temporary files. If NULL, no temporary file was written. |
| SEGRFNO# | bigint(0) | NO | The number of files related to writing temporary files. NULL indicates no temporary files were written. |
| SEGBLK# | bigint(0) | NO | The number of blocks used to create temporary files in the workspace. NULL indicates no temporary file writes occurred. |
| CON_ID | bigint(20) | NO | Tenant ID |
| SVR_IP | varchar(46) | NO | Server IP Address |
| SVR_PORT                 | bigint(20)   | NO             | The port number of the server.                   |
