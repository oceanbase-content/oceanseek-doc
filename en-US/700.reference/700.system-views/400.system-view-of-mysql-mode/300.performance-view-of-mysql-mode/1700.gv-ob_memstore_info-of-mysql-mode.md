# GV$OB_MEMSTORE_INFO

## Overview

Displays the details of the MemTable for all partitions of the current tenant on all servers.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | Server IP Address |
| SVR_PORT | bigint(20) | NO | Server Port |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| LS_ID | bigint(20) | NO | Log Stream |
| TABLE_ID | bigint(20) | NO | Data Shard ID |
| IS_ACTIVE | varchar(3) | NO | Active |
| START_SCN | bigint(20) unsigned | NO | Storage Start Offset |
| END_SCN | bigint(20) unsigned | NO | Storage End Offset |
| FREEZE_TS | bigint(20) | NO | Frozen Timestamp |

## Sample query

You can query the details of the MemTable of all partitions in the current tenant on all servers.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_MEMSTORE_INFO;
```
