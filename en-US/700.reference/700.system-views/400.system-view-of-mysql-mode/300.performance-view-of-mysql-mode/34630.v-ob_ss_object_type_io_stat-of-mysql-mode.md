# V$OB_OBJECT_TYPE_IO_STAT

## Overview

The `V$OB_OBJECT_TYPE_IO_STAT` view displays the read, write, and delete operation statistics for different types of objects in a tenant on the current node.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ----------------- | ----------------------- | ---------------- | --------------------------------- |
| SVR_IP | varchar(46) | NO | IP Address of OBServer Node |
| SVR_PORT | bigint(20) | NO | Port number of the OBServer node |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| OBJECT_TYPE | varchar(128) | NO | Object type |
| MODE            | varchar(32)  | NO   | The data source type.
:<ul><li>`local`: local storage.</li><li>`remote`: object storage.</li></ul>     |
| READ_CNT | bigint(20) | NO | Total Number of I/O Reads |
| READ_SIZE | bigint(20) | NO | Total size of I/O reads, in bytes |
| READ_FAIL_CNT | bigint(20) | NO | Total Number of I/O Read Failures |
| READ_IOPS | bigint(20) | NO | Average IOPS for Read Operations |
| WRITE_CNT | bigint(20) | NO | Total Number of I/O Writes |
| WRITE_SIZE | bigint(20) | NO | Total size of I/O writes, in bytes |
| WRITE_FAIL_CNT | bigint(20) | NO | Total Number of I/O Write Failures |
| WRITE_IOPS | bigint(20) | NO | Average IOPS for Write Operations |
| DELETE_CNT | bigint(20) | NO | Total Number of Object Deletions |
| DELETE_FAIL_CNT | bigint(20) | NO | Total Number of Object Deletion Failures |
| DELETE_IOPS | bigint(20) | NO | IOPS for Object Deletion |
| READ_BANDWIDTH | bigint(20) | NO | Average I/O Read Bandwidth, in MB/s |
| READ_BANDWIDTH_DISPLAY | varchar(29) | NO | Display in human-readable format, for example, converted to a format like 10 GB/s or 10 MB/s. |
| READ_DELAY_US | bigint(20) | NO | Average I/O Read Latency, in μs |
| WRITE_BANDWIDTH | bigint(20) | NO | Average I/O write bandwidth, in MB/s |
| WRITE_BANDWIDTH_DISPLAY | varchar(29) | NO | Display in human-readable format, for example, converted to a format like 10 GB/s or 10 MB/s. |
| WRITE_DELAY_US | bigint(20) | NO | Average IO write latency, in μs |

## Sample query

You can view the read, write, and delete usage of different object types for the current tenant on the current node.

```shell
obclient(root@mysql001)[oceanbase]> SELECT * FROM oceanbase.V$OB_OBJECT_TYPE_IO_STAT WHERE tenant_id = 1002 LIMIT 10; 
```
