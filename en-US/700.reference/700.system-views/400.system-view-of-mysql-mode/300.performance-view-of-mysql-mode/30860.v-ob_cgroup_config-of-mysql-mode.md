# V$OB_CGROUP_CONFIG

## Overview

The `V$OB_CGROUP_CONFIG` view is used to quickly query the cgroup configuration of the current OBServer node. The view fields are derived from the cgroup directory in the OBServer node's installation directory (for example, `/home/admin/oceanbase/cgroup`).

## Columns

| **Column** | **Type** | **Is NULL** | **Description** |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | IP Address of OBServer |
| SVR_PORT | bigint(20) | NO | OBServer Port Number |
| CFS_QUOTA_US | bigint(20) | NO | The CPU time slice of the thread, in microseconds. This field is obtained from the file under the path directory. `cpu.cfs_quota_us` |
| CFS_PERIOD_US | bigint(20) | NO | The control cycle time of cgroup, in microseconds. Used together with Quota. This field's information comes from the file under the path directory. `cpu.cfs_period_us` |
| SHARES | bigint(20) | NO | CPU Usage of Thread (only effective when CPU is at full load). This field is derived from the file in the path directory. `cpu.shares` |
| CGROUP_PATH | varchar(256) | NO | Configure a path in the cgroup directory of the OBServer node. |

## Sample query

Query the cgroup configuration of the current OBServer node in a user tenant.

```shell
obclient(root@mysql001)[oceanbase]> SELECT * FROM oceanbase.GV$OB_CGROUP_CONFIG;
```
