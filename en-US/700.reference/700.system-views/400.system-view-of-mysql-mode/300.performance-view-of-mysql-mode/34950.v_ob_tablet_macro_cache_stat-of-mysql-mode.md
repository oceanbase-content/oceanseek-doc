# V$OB_TABLET_MACRO_CACHE_STAT

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view is available starting with V4.6.3.</p>
</main>

## Overview

This view displays the macroblock cache statistics for tablets of the current tenant on the current OBServer node. Each row corresponds to a tablet on the current node, showing the total number of macroblocks in the current version, the number of cached macroblocks, the actual data size of the macroblocks, the data size of the cached macroblocks, and the cache ratio for that tablet. It can be used to check whether all data of a specified table or tablet has been cached.

<main id="notice" type='notice'>
<h4>Notice</h4>
<p>When querying this view, you must specify <code>TABLE_ID</code> or <code>TABLET_ID</code>. A full-table scan without a range is not supported when neither parameter is specified.</p>
</main>

## Columns

| Field Name | Type | Whether can be NULL | Description |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | The IP address of the OBServer node. |
| SVR_PORT | bigint(20) | NO | The port number of the OBServer node. |
| TENANT_ID | bigint(20) | NO | Tenant ID. |
| LS_ID | bigint(20) | NO | The ID of the log stream to which the tablet currently belongs. |
| TABLET_ID | bigint(20) | NO | Tablet ID. |
| TRANSFER_SCN | bigint(20) | NO | The transfer SCN (transfer version number) of the tablet. |
| TABLE_ID | bigint(20) | NO | The table ID to which the tablet belongs. |
| STORAGE_CACHE_POLICY | varchar(64) | NO | The current hot/cold status of the tablet. Valid values are the same as those in [V$OB_TABLET_LOCAL_CACHE](34920.v-ob_tablet_local_cache-of-mysql-mode.md) in the `STORAGE_CACHE_POLICY` Consistent, including `AUTO` (Automatic identification of hot and cold data) and `HOT` (Hot data). |
| MACRO_BLOCK_COUNT | bigint(20) | NO | Total number of macroblocks in the current version of the tablet. |
| CACHED_MACRO_BLOCK_COUNT | bigint(20) | NO | The number of macroblocks cached in the current version of the tablet. |
| MACRO_BLOCK_REQUIRED_SIZE | bigint(20) | NO | The actual data size of the macroblock corresponding to the current tablet version, in bytes. |
| CACHED_MACRO_BLOCK_REQUIRED_SIZE | bigint(20) | NO | The actual data size of the macroblock cached in the current version's macroblock, in bytes. |
| CACHE_RATIO_PERCENT | bigint(20) | NO | The percentage of cached macroblocks in the total number of macroblocks in the current version of the Tablet. |
| INFO | varchar(1024) | NO | Other diagnostic information. |

## Usage instructions

* The statistics scope of this view is the current OBServer node. When a user tenant queries, only data of the current tenant is displayed.

* When generating statistics for each row, the system must retrieve the current tablet, load and traverse its macroblock information, deduplicate by `MacroBlockId`, and query the macroblock cache metadata of this node one by one. Therefore, during queries, you should try to narrow down the scope using `TABLE_ID` or `TABLET_ID` to avoid querying a large number of tablets at once.

* In the case of a fork table, a macroblock may be shared by multiple tablets. When troubleshooting cache issues, you should consider the values of `TABLET_ID`, `TABLE_ID`, and `STORAGE_CACHE_POLICY` together.

## Sample query

1. Query the macroblock cache status of each tablet for a specified table on the current node.

    ```sql
    SELECT SVR_IP, SVR_PORT, TENANT_ID, TABLE_ID, TABLET_ID,
           STORAGE_CACHE_POLICY, MACRO_BLOCK_COUNT,
           CACHED_MACRO_BLOCK_COUNT, CACHE_RATIO_PERCENT
    FROM oceanbase.V$OB_TABLET_MACRO_CACHE_STAT
    WHERE TABLE_ID = 500001;
    ```

2. Query the macroblock cache status of a specified tablet on the current node.

    ```sql
    SELECT *
    FROM oceanbase.V$OB_TABLET_MACRO_CACHE_STAT
    WHERE TABLET_ID = 200001;
    ```
