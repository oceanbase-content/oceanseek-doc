# GV$OB_TENANT_MEMORY

## Overview

Displays the memory usage of the current tenant across all nodes.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ----------- | ------------- | ------------ | --------- |
| TENANT_ID | bigint(20) | NO | Tenant ID |
| SVR_IP | varchar(46) | NO | IP Address of the Server |
| SVR_PORT | bigint(20) | NO | Server Port Number |
| HOLD | bigint(20) | NO | Tenant Used Memory, in bytes |
| FREE | bigint(21) | NO | Remaining memory of the tenant, in bytes |

## Sample query

You can query the memory usage of the current tenant across all nodes.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_TENANT_MEMORY;
```

The query result is as follows:

