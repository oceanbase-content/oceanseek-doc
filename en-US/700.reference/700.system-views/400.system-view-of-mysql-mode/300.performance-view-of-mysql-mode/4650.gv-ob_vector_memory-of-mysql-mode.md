# GV$OB_VECTOR_MEMORY

## Overview

Displays detailed statistics on the memory usage of vector index data for the current tenant across all OBServer nodes.

## Columns

| **Column** | **Type** | **Is NULL** | **Description** |
| ---- | ---- | ---- | ---- |
| TENANT_ID | bigint(20) | NO | Tenant ID: <ul><li>1: system tenant ID</li><li>Other values: user tenant or Meta tenant ID</li></ul> |
| SVR_IP | varchar(46) | NO | Node Address |
| SVR_PORT | bigint(20) | NO | Node Port |
| VECTOR_MEM_HOLD | bigint(20) | NO | Memory usage of vector index data, in bytes |
| VECTOR_MEM_LIMIT | bigint(20) | NO | Maximum data memory for vector indexes, in bytes |
| VECTOR_MEM_USED | bigint(20) | NO | Actual memory used by vector index data, in bytes |

## Sample query

Query detailed memory usage statistics of vector index data for the current tenant across all OBServer nodes.

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.GV$OB_VECTOR_MEMORY  \G
```

The query result is as follows:

```shell
*************************** 1. row ***************************
                svr_ip: 11.xxx.xx.xx
              svr_port: 46002
             tenant_id: 1004
       vector_mem_hold: 82231296
       vector_mem_used: 77876328
      vector_mem_limit: 429496720
1 row in set
```
