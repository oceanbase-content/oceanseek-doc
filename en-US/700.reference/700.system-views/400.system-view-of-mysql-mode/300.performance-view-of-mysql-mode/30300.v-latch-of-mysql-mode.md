# V$LATCH

<main id="notice" type='explain'>
<h4>Note</h4>
<p>This view no longer records data due to feature adjustments. Lock diagnostic-related data can be viewed through the <a href="../../../../700.reference/700.system-views/400.system-view-of-mysql-mode/300.performance-view-of-mysql-mode/36500.v-system_event-of-mysql-mode.md">V$SYSTEM_EVENT</a> view and the <a href="../../../../700.reference/700.system-views/400.system-view-of-mysql-mode/300.performance-view-of-mysql-mode/30400.v-ob_active_session_history-of-mysql-mode.md">V$OB_ACTIVE_SESSION_HISTORY</a> view.</p>
</main>

## Overview

This view displays the latch information of all OBServer nodes in the cluster.

## Columns

| **Field** | **Type** | **Nullable** | **Description** |
| --- | --- | --- | --- |
| CON_ID | bigint(20) | NO | Tenant ID |
| SVR_IP | varchar(46) | NO | IP Address |
| SVR_PORT | bigint(20) | NO | Port number |
| ADDR | varchar(256) | NO | Currently NULL |
| LATCH# | bigint(20) | NO | Index of the class to which the latch belongs |
| LEVEL# | bigint(20) | NO | Index of the level to which the latch belongs |
| NAME | varchar(256) | NO | Name of the latch |
| HASH | bigint(20) | NO | This value is currently 0. |
| GETS | bigint(20) | NO | Number of Successful Locks |
| MISSES | bigint(20) | NO | Number of Lock Wait Entries |
| SLEEPS | bigint(20) | NO | Total Number of Yields |
| IMMEDIATE_GETS | bigint(20) | NO | Number of Successful try_lock Operations |
| IMMEDIATE_MISSES | bigint(20) | NO | Number of Failed try_lock Operations |
| SPIN_GETS | bigint(20) | NO | Total Spins |
| WAIT_TIME | bigint(20) | NO | The amount of time to wait in sleep mode. |
