# V$OB_STORAGE_CACHE_TASKS

## Overview

Displays the cache task information of the current tenant on the current OBServer node.

## Columns

| Field Name | Type | Whether can be NULL | Description |
| ----------------- | ----------------------- | ---------------- | --------------------------------- |
| SVR_IP | varchar(46) | NO | IP Address of OBServer Node |
| SVR_PORT | bigint(20) | NO | Port number of the OBServer node |
| TENANT_ID | bigint(20) | NO | Tenant ID of the tablet |
| TABLET_ID | bigint(20) | NO | Tablet ID |
| STATUS | varchar(64) | NO | The status of the cache task. Valid values:<ul><li>`WAITING`: The task is being initialized.</li> <li>`DONIG`: The task is in progress.</li> <li>`FINISHED`: The task has been completed.</li> <li>`SUSPENDED`: Task paused</li> <li>`CANCELED`: The task is canceled.</li> <li>`FAILED`: Task execution failed.</li></ul> |
| SPEED | varchar(29) | NO | Pull speed of tablets |
| START_TIME | timestamp(6) | NO | Cache Task Start Time |
| COMPLETE_TIME | timestamp(6) | NO | Cache Task End Time |
| RESULT | bigint(20) | NO | Displays the corresponding error code if the task fails. |
| COMMENT | varchar(4096) | NO | Detailed error description after the task failed, including `trace_id` Information |

## Sample query

In SS mode, you can view the cache task information of the current tenant on the current OBServer node.

```shell
obclient> SELECT * FROM oceanbase.V$OB_STORAGE_CACHE_TASKS;
```
