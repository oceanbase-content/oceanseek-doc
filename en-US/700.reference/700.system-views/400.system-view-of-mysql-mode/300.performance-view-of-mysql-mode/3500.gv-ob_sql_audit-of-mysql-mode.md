# GV$OB_SQL_AUDIT

## Overview

The `GV$OB_SQL_AUDIT` view displays statistics such as the source and execution status of each SQL request on all OBServer nodes. This view is partitioned by tenant. Except for the system tenant, other tenants cannot perform cross-tenant queries.
