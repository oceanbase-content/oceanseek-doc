# Get started with OceanBase AI Database

This topic explains how to work with an already deployed OceanBase AI Database cluster to create and log in to a user tenant, create a business database, and run basic queries, helping you complete your first use of OceanBase AI Database quickly.

## Prerequisites

* An OceanBase AI Database cluster has been deployed. For the deployment process, see [Deployment process](../150.deploy/200.deployment-process.md).
* You have obtained the root user password of the cluster's sys tenant, which is the **root@sys password** set during cluster creation.
* The OBClient client has been installed. For more connection methods, see [Overview of connection methods](../200.connect/100.connection-methods-overview.md).

## Step 1: Create a user tenant

OceanBase AI Database is a natively distributed database. Multiple database instances can run in the same database at the same time. The first step is usually to create a tenant (database instance), and then use it like a traditional standalone database instance.

OceanBase AI Database supports creating only user tenants. The system tenant is created automatically when the cluster is created. The procedure for creating a user tenant is as follows:

1. Create a resource unit.

   1. Log in to the `sys` tenant of the cluster as the `root` user.

      ```shell
      obclient -h172.30.xx.xx -P2883 -uroot@sys#cluster -p**** -A
      ```

   2. Enter the `oceanbase` database.

      ```shell
      obclient(root@sys)[(none)]> USE oceanbase;
      ```

   3. Query the `DBA_OB_UNIT_CONFIGS` view for existing resource unit information.

      ```shell
      obclient(root@sys)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_UNIT_CONFIGS;
      ```

      The query result is as follows:

      ```shell
      +----------------+-----------------+----------------------------+----------------------------+---------+---------+-------------+---------------+----------------+---------------------+---------------------+-------------+---------------------+----------------------+
      | UNIT_CONFIG_ID | NAME            | CREATE_TIME                | MODIFY_TIME                | MAX_CPU | MIN_CPU | MEMORY_SIZE | LOG_DISK_SIZE | DATA_DISK_SIZE | MAX_IOPS            | MIN_IOPS            | IOPS_WEIGHT | MAX_NET_BANDWIDTH   | NET_BANDWIDTH_WEIGHT |
      +----------------+-----------------+----------------------------+----------------------------+---------+---------+-------------+---------------+----------------+---------------------+---------------------+-------------+---------------------+----------------------+
      |              1 | sys_unit_config | 2026-09-01 16:31:19.277829 | 2026-09-01 16:31:19.277829 |       1 |       1 |  5368709120 |    7516192768 |    10737418240 | 9223372036854775807 | 9223372036854775807 |           1 | 9223372036854775807 |                    1 |
      +----------------+-----------------+----------------------------+----------------------------+---------+---------+-------------+---------------+----------------+---------------------+---------------------+-------------+---------------------+----------------------+
      1 row in set (0.002 sec)
      ```

      For detailed information about the `DBA_OB_UNIT_CONFIGS` view, see [DBA_OB_UNIT_CONFIGS](../700.reference/700.system-views/300.system-view-of-sys-tenant/200.dictionary-view-of-sys-tenant/23700.o-dba_ob_unit_configs-of-sys-tenant.md).

   4. Create a resource unit using the `CREATE RESOURCE UNIT` statement.

      Example: Create a resource unit named `S1_unit_config` with 1 CPU core and 5 GB of memory.

      ```shell
      obclient(root@sys)[oceanbase]> CREATE RESOURCE UNIT S1_unit_config
                     MEMORY_SIZE = '5G',
                     MAX_CPU = 1, MIN_CPU = 1;
      ```

      For detailed information about this statement, see the **Create a resource unit** section in [Create a tenant](../600.manage/200.tenant-management/600.common-tenant-operations/200.manage-create-tenant.md).

   5. Query the `DBA_OB_UNIT_CONFIGS` view to confirm that the resource unit `S1_unit_config` has been created successfully.

      ```shell
      obclient(root@sys)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_UNIT_CONFIGS WHERE NAME = 'S1_unit_config';
      ```

      The query result is as follows:

      ```shell
      +----------------+----------------+----------------------------+----------------------------+---------+---------+-------------+---------------+----------------+---------------------+---------------------+-------------+---------------------+----------------------+
      | UNIT_CONFIG_ID | NAME           | CREATE_TIME                | MODIFY_TIME                | MAX_CPU | MIN_CPU | MEMORY_SIZE | LOG_DISK_SIZE | DATA_DISK_SIZE | MAX_IOPS            | MIN_IOPS            | IOPS_WEIGHT | MAX_NET_BANDWIDTH   | NET_BANDWIDTH_WEIGHT |

      +----------------+----------------+----------------------------+----------------------------+---------+---------+-------------+---------------+----------------+---------------------+---------------------+-------------+---------------------+----------------------+
      1 row in set (0.001 sec)
      ```

2. Create a resource pool.

   1. Query the `DBA_OB_RESOURCE_POOLS` view for the configuration information of the resource pool.

      ```shell
      obclient(root@sys)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_RESOURCE_POOLS;
      ```

      The query result is as follows:

      ```shell
      +------------------+----------+-----------+----------------------------+----------------------------+------------+----------------+-----------+--------------+
      | RESOURCE_POOL_ID | NAME     | TENANT_ID | CREATE_TIME                | MODIFY_TIME                | UNIT_COUNT | UNIT_CONFIG_ID | ZONE_LIST | REPLICA_TYPE |
      +------------------+----------+-----------+----------------------------+----------------------------+------------+----------------+-----------+--------------+
      |                1 | sys_pool |         1 | 2026-09-01 16:31:19.281405 | 2026-09-01 16:31:19.281405 |          1 |              1 | zone1     | FULL         |
      +------------------+----------+-----------+----------------------------+----------------------------+------------+----------------+-----------+--------------+
      1 row in set (0.002 sec)
      ```

      For more information about the `DBA_OB_RESOURCE_POOLS` view, see [DBA_OB_RESOURCE_POOLS](../700.reference/700.system-views/300.system-view-of-sys-tenant/200.dictionary-view-of-sys-tenant/21000.o-dba_ob_resource_pools-of-sys-tenant.md).

   2. Use the `CREATE RESOURCE POOL` statement to create a resource pool.

      Example: Create a resource pool named `mq_pool_01`, allocate one unit in zone1, and set the unit's resource specification to `S1_unit_config`.

      ```shell
      obclient(root@sys)[oceanbase]> CREATE RESOURCE POOL mq_pool_01
                        UNIT='S1_unit_config',
                        UNIT_NUM=1,
                        ZONE_LIST=('zone1');
      ```

      For more information about this statement, see the **Create a resource pool** section in [Create a tenant](../600.manage/200.tenant-management/600.common-tenant-operations/200.manage-create-tenant.md).

   3. Query the `DBA_OB_RESOURCE_POOLS` view to confirm that the `mq_pool_01` resource pool has been created successfully.

      ```shell
      obclient(root@sys)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_RESOURCE_POOLS WHERE NAME = 'mq_pool_01';
      ```

      The query result is as follows:

      ```shell
      +------------------+------------+-----------+----------------------------+----------------------------+------------+----------------+-----------+--------------+
      | RESOURCE_POOL_ID | NAME       | TENANT_ID | CREATE_TIME                | MODIFY_TIME                | UNIT_COUNT | UNIT_CONFIG_ID | ZONE_LIST | REPLICA_TYPE |
      +------------------+------------+-----------+----------------------------+----------------------------+------------+----------------+-----------+--------------+
      |             1001 | mq_pool_01 |      NULL | 2026-09-01 19:57:25.969501 | 2026-09-01 19:57:25.969501 |          1 |           1003 | zone1     | FULL         |
      +------------------+------------+-----------+----------------------------+----------------------------+------------+----------------+-----------+--------------+
      1 row in set (0.002 sec)
      ```

3. Create a tenant.

   1. Query the `DBA_OB_TENANTS` view for all tenant information.

      ```shell
      obclient(root@sys)[oceanbase]> SELECT TENANT_ID, TENANT_NAME, TENANT_TYPE, CREATE_TIME, MODIFY_TIME, PRIMARY_ZONE, LOCALITY, COMPATIBILITY_MODE, STATUS, TENANT_ROLE FROM oceanbase.DBA_OB_TENANTS;
      ```

      The query result is as follows:

      ```shell
      +-----------+-------------+-------------+----------------------------+----------------------------+--------------+---------------+--------------------+--------+-------------+
      | TENANT_ID | TENANT_NAME | TENANT_TYPE | CREATE_TIME                | MODIFY_TIME                | PRIMARY_ZONE | LOCALITY      | COMPATIBILITY_MODE | STATUS | TENANT_ROLE |
      +-----------+-------------+-------------+----------------------------+----------------------------+--------------+---------------+--------------------+--------+-------------+
      |         1 | sys         | SYS         | 2026-09-01 16:31:19.292987 | 2026-09-01 16:31:19.292987 | RANDOM       | FULL{1}@zone1 | MYSQL              | NORMAL | PRIMARY     |
      +-----------+-------------+-------------+----------------------------+----------------------------+--------------+---------------+--------------------+--------+-------------+
      1 row in set (0.008 sec)
      ```

      For more information about the `DBA_OB_TENANTS` view, see [DBA_OB_TENANTS](../700.reference/700.system-views/300.system-view-of-sys-tenant/200.dictionary-view-of-sys-tenant/23100.o-dba_ob_tenants-of-sys-tenant.md).

   2. Use the `CREATE TENANT` statement to create a tenant.

      Example: Create a tenant named `mq_t1`, specify the resource pool as `mq_pool_01`, set the primary zone to zone1, and allow connections from all IPs to the database.

      ```shell
      obclient(root@sys)[oceanbase]> CREATE TENANT IF NOT EXISTS mq_t1
                     PRIMARY_ZONE='zone1',
                     RESOURCE_POOL_LIST=('mq_pool_01')
                     SET OB_TCP_INVITED_NODES='%';
      ```

      For more information about this statement, see the **Create a tenant** section in [Create a tenant](../600.manage/200.tenant-management/600.common-tenant-operations/200.manage-create-tenant.md).

   3. Query the `DBA_OB_TENANTS` view to confirm that the `mq_t1` tenant has been created successfully.

      ```shell
      obclient(root@sys)[oceanbase]> SELECT TENANT_ID, TENANT_NAME, TENANT_TYPE, CREATE_TIME, MODIFY_TIME, PRIMARY_ZONE, LOCALITY, COMPATIBILITY_MODE, STATUS, TENANT_ROLE FROM oceanbase.DBA_OB_TENANTS WHERE TENANT_NAME = 'mq_t1';
      ```

      The query result is as follows:

      ```shell
      +-----------+-------------+-------------+----------------------------+----------------------------+--------------+---------------+--------------------+--------+-------------+
      | TENANT_ID | TENANT_NAME | TENANT_TYPE | CREATE_TIME                | MODIFY_TIME                | PRIMARY_ZONE | LOCALITY      | COMPATIBILITY_MODE | STATUS | TENANT_ROLE |

      +-----------+-------------+-------------+----------------------------+----------------------------+--------------+---------------+--------------------+--------+-------------+
      1 row in set (0.011 sec)
      ```

## Step 2: Log in to the user tenant

After the tenant is created, you can log in to it. The default administrator user `root` of the `mq_t1` user tenant has an empty password. You must first change the administrator user's password.

1. Log in as the root user of the `mq_t1` tenant.

   ```shell
   obclient -h172.30.xx.xx -P2883 -uroot@mq_t1#cluster -A
   ```

2. Execute the following statement to change the root user's password.

   ```shell
   obclient(root@mq_t1)[(none)]> ALTER USER root IDENTIFIED BY '****';
   Query OK, 0 rows affected
   ```

3. After the administrator user's password is changed successfully, log in to the tenant again.

   ```shell
   obclient -h172.30.xx.xx -P2883 -uroot@mq_t1#cluster -p**** -A
   ```

## Step 3: Create a business database

1. Use the `CREATE DATABASE` statement to create a business database.

   Example: Create a database named `db1`, specify the character set as `utf8mb4`, and set the read/write attribute.

   ```shell
   obclient(root@mq_t1)[(none)]> CREATE DATABASE db1 DEFAULT CHARACTER SET utf8mb4 READ WRITE;
   ```

2. After the database is ceated, you can use the `SHOW DATABASES` command to view all databases in the current tenant.

   ```shell
   obclient(root@mq_t1)[(none)]> SHOW DATABASES;
   ```

   The query result is as follows:

   ```shell
   +--------------------+
   | Database           |
   +--------------------+
   | db1                |
   | information_schema |
   | mysql              |
   | oceanbase          |
   | test               |
   +--------------------+
   5 rows in set (0.003 sec)
   ```

   For more information about the `CREATE DATABASE` statement, see [CREATE DATABASE](../700.reference/500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/2100.create-database-of-mysql-mode.md).

## Step 4: Perform basic queries

After the business database is created, you can start using OceanBase AI Database for data writing and querying.

1. Switch to the `db1` database.

   ```shell
   obclient(root@mq_t1)[(none)]> USE db1;
   ```

2. Create a table named `t1` to store sample data.

   ```shell
   obclient(root@mq_t1)[db1]> CREATE TABLE t1 (id INT, name VARCHAR(50), num INT);
   ```

3. Insert multiple rows of data into the table `t1`.

   ```shell
   obclient(root@mq_t1)[db1]> INSERT INTO t1 VALUES(1,'a',100),(2,'b',200),(3,'a',50);
   ```

4. Query the data in the table `t1`.

   ```shell
   obclient(root@mq_t1)[db1]> SELECT * FROM t1;
   ```

   The query result is as follows:

   ```shell
   +------+------+------+
   | id   | name | num  |
   +------+------+------+
   |    1 | a    |  100 |
   |    2 | b    |  200 |
   |    3 | a    |   50 |
   +------+------+------+
   3 rows in set (0.002 sec)
   ```

5. Query data by condition. In this example, query records where `name = 'a'`.

   ```shell
   obclient(root@mq_t1)[db1]> SELECT id, name, num FROM t1 WHERE name = 'a';
   ```

   The query result is as follows:

   ```shell
   +------+------+------+
   | id   | name | num  |
   +------+------+------+
   |    1 | a    |  100 |
   |    3 | a    |   50 |
   +------+------+------+
   2 rows in set (0.002 sec)
   ```

You have now completed your first use of OceanBase AI Database.
