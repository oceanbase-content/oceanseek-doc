# 通过驱动或 ORM 框架连接

OceanSeek 支持通过驱动或 ORM 框架连接，这些方式为不同编程语言和开发场景提供了灵活的接入方案。

## C

* C 驱动（OceanBase Connector/C）

  OceanBase Connector/C 是一个基于 C/C++ 的 OceanBase 客户端开发组件，支持 C API Lib 库。

  OceanBase Connector/C 允许 C/C++ 程序以一种较为底层的方式访问 OceanSeek，以进行数据库连接、数据访问、错误处理和 Prepared Statement 处理等操作。

  OceanBase Connector/C 也称为 LibOBClient，用于应用程序作为独立的服务器进程通过网络连接与数据库服务器 OBServer 节点进行通信。客户端程序在编译时会引用 C API 头文件，同时可以连接到 C API 库文件。

  <main id="notice" type='explain'>
    <h4>说明</h4>
    <p>LibOBClient 生成的 so 文件为 <code>libobclient.so</code>（对应 MySQL 的 <code>libmysqlclient.so</code>），OceanSeek 安装后的命令行工具是 OBClient（对应 MySQL 的命令行工具）。 </p>
  </main>

  使用 C 应用程序连接 OceanSeek 的具体操作示例请参见 [创建 C 示例应用程序](../400.driver-or-orm/20.orms-frameworks/10.c-sharp/100.connect-to-the-oceanbase-database-through-mysql-connector-c-of-mysql-mode.md)。

* Golang 驱动

  * Go-SQL-Driver/MySQL

* Golang ORM

  * GORM

    GORM 是一个用于 Go 语言的优秀 ORM（对象关系映射）库，它提供了丰富的功能，帮助开发者更轻松地与数据库进行交互。使用 GORM 连接 OceanSeek 的具体操作示例请参见 [GORM 连接示例程序](../400.driver-or-orm/20.orms-frameworks/20.go/100.gorm-connection-oceanbase-database-program.md)。

## PHP

* PHP 驱动

  * EXT

    EXT（PHP Extension）是 PHP 的一个扩展，用于与不同的数据库进行连接和交互。它提供了多种功能，以便开发人员可以更好地操作数据库和处理数据。使用 EXT 连接 OceanSeek 的具体操作示例请参见 [EXT 驱动连接示例程序](../400.driver-or-orm/20.orms-frameworks/50.php/100.ext-driver-connects-to-oceanbase-database.md)。

  * MySQLi

    MySQLi（MySQL Improved）是 PHP 官方提供的一个扩展，用于与 MySQL 数据库进行交互。它支持面向对象和过程化编程，提供了准备好的语句、事务支持和多查询等功能，旨在提高性能和安全性。使用 MySQLi 连接 OceanSeek 的具体操作示例请参见 [使用 MySQLi 驱动连接](../400.driver-or-orm/20.orms-frameworks/50.php/200.use-mysqli-driver-to-connect-to-oceanbase.md)。

  * PDO

    PDO（PHP Data Objects）是一个数据库访问抽象层，允许开发者以统一的方式与多种数据库进行交互。PDO 支持预处理语句，有助于提高安全性，并使得代码在不同数据库之间的迁移变得更加简便。使用 PDO 连接 OceanSeek 的具体操作示例请参见 [使用 PDO 驱动连接](../400.driver-or-orm/20.orms-frameworks/50.php/300.use-pdo-driver-to-connect-to-oceanbase.md)。

## Python

* Python 驱动（PyMySQL）

  * PyMySQL

    PyMySQL是在 Python3.x 版本中用于连接 MySQL 服务器的一个库。遵循 Python 数据库 API v2.0 规范，并包含了 pure-Python MySQL 客户端库。用户可以使用 PyMySQL 驱动为 Python 应用程序提供与 OceanSeek 的连接。使用 Python 应用程序连接 OceanSeek 的具体操作示例请参见 [PyMySQL 连接](../400.driver-or-orm/20.orms-frameworks/60.python/50.pymysql-connection-to-oceanbase-database-sample-program.md)。

  * mysqlclient

    mysqlclient 是一个 MySQL 数据库的 Python 客户端库，它是对 MySQL 官方 C API 的一个封装。使用 mysqlclient 应用程序连接 OceanSeek 的具体操作示例请参见 [mysqlclient 连接示例程序](../400.driver-or-orm/20.orms-frameworks/60.python/100.mysqlclient-connection-to-oceanbase-database-sample-program.md)。

  * MySQL-connector-python

    MySQL-connector-python 是由 Oracle 官方提供的 MySQL 数据库驱动程序，专门为 Python 设计。它遵循 Python 数据库 API v2.0 规范，提供了一组完整的功能，可以方便地通过 Python 代码与 MySQL 数据库交互。该库是跨平台的，支持 Python 2 和 3，并且是纯 Python 实现，无需依赖任何外部库。MySQL-connector-python 也可用于建立与 OceanSeek 的连接，执行查询和管理数据。使用 MySQL-connector-python 应用程序连接 OceanSeek 的具体操作示例请参见 [创建 MySQL-connector-python 连接示例程序](../400.driver-or-orm/20.orms-frameworks/60.python/150.mysql-connector-py-connection-to-oceanbase-database-sample-program.md)。

  * SQLAlchemy

    SQLAlchemy 是一个用于 Python 语言的优秀 ORM（对象关系映射）库，它提供了丰富的功能，帮助开发者更轻松地与数据库进行交互。使用 SQLAlchemy 连接 OceanSeek 的具体操作示例请参见 [SQLAlchemy 连接](../400.driver-or-orm/20.orms-frameworks/60.python/200.sqlalchemy-connection-oceanbase-database-program.md)。
