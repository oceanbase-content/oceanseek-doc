# 通过 SDK 连接 OceanBase AI 数据库

pyseekdb 是 OceanBase 提供的 Python 客户端。实现了基于一套 API 接口，支持连接到远程服务器。

pyseekdb 通过 `Client` 和 `AdminClient` 接口，连接 OceanBase AI 数据库。`Client` 和 `AdminClient` 的接口区别如下：

* `AdminClient`：仅支持数据库管理相关操作。例如创建数据库，获取数据库，删除数据库等。
* `Client`：用于执行数据库操作，例如查询数据、插入数据、创建表、删除表等。

## 前提条件

* 已部署 OceanBase AI 数据库，有关 OceanBase AI 数据库的部署方法，参见 [部署 OceanBase AI 数据库](../150.deploy/100.deploy-overview.md)。
* 已部署 pyseekdb，有关 pyseekdb 的部署方法，参见 [部署概述](https://docs.seekdb.ai/seekdb/zh-CN/pyseekdb-sdk-get-started)。

## 连接远程服务器

### 通过 `AdminClient` 连接到远程服务器

通过 AdminClient 连接到  OceanBase AI 数据库。

```python
import pyseekdb

# Remote server mode - Database management
admin = pyseekdb.AdminClient(
    host="127.0.0.1",
    port=2881,
    tenant="test",
    user="root",
    password=""  # Can be retrieved from SEEKDB_PASSWORD environment variable
)
```

参数说明：

|参数|取值类型|是否必选|描述|取值示例|
|---|---|---|---|---|
|`host`|string|必选|数据库所在服务器 IP。|`127.0.0.1`|
|`prot`|string|必选|OceanBase AI 数据库端口。默认为 2881。|`2881`|
|`tenant`|string|可选|租户名。默认是 sys。|`test`|
|`user`|string|必选|租户对应的用户名。默认为 root。|`root`|
|`password`|string|必选|用户所对应的密码。如果未提供 `password` 或者填写了空字符串，系统会通过 `SEEKDB_PASSWORD` 环境变量获取。||

关于 `AdminClient` 的详细介绍，参见  [pyseekdb-AdminClient](https://docs.seekdb.ai/seekdb/zh-CN/admin-client)。

### 通过 `Client` 连接到远程服务器

通过 Client 连接到 OceanBase AI 数据库。

```python
import pyseekdb

# Create remote server client (OceanBase Server)
client = pyseekdb.Client(
    host="127.0.0.1",      # Server host
    port=2881,              # Server port (default: 2881)
    tenant="test",         # Tenant name
    database="test",       # Database name
    user="root",           # Username (default: "root")
    password=""             # Password (can be retrieved from SEEKDB_PASSWORD environment variable)
)
```

参数说明：

|参数|取值类型|是否必选|描述|取值示例|
|---|---|---|---|---|
|`host`|string|必选|数据库所在服务器 IP。|`127.0.0.1`|
|`prot`|string|必选|OceanBase AI 数据库端口。默认为 2881。|`2881`|
|`tenant`|string|可选|租户名。默认是 sys。|`test`|
|`database`|string|必选|数据库名。|`test`|
|`user`|string|必选|租户对应的用户名。默认为 root。|`root`|
|`password`|string|必选|用户所对应的密码。如果未提供 `password` 或者填写了空字符串，系统会通过 `SEEKDB_PASSWORD` 环境变量获取。||

关于 Client 的详细介绍，参见 [pyseekdb-Clien](https://docs.seekdb.ai/seekdb/zh-CN/client)。
