# 连接方式概述

本章节主要介绍连接和访问 OceanSeek 的方法，当前主要支持通过客户端、GUI、驱动、ORM 框架或连接池连接 OceanSeek。

## 选择客户端连接

支持通过以下客户端连接 OceanSeek：

* MySQL 客户端（mysql）

  mysql 是 MySQL 数据库的命令行客户端，需要单独安装。

  连接 OceanSeek 后，在 mysql 的命令行环境里，可以运行 mysql 运维命令和 SQL 语句来执行以下任务：

  * 计算、存储和打印查询结果。

  * 创建数据库对象、检查和修改对象定义。

  * 执行数据库管理和修改参数等。

  使用 MySQL 客户端连接 OceanSeek 的具体操作示例请参见  [通过 MySQL 客户端连接 OceanSeek](200.client/200.connect-to-an-oceanbase-tenant-by-using-a-mysql-client.md)。

* OceanBase 客户端（OBClient）

  OBClient 是一个交互式和批处理查询工具，需要单独安装。它是一个命令行用户界面，在连接到数据库时充当客户端，支持 OceanSeek。

  OBClient 在运行时需要指定 OceanSeek 租户的连接信息。连接上 OceanSeek 后，通过 OBClient 可以运行一些数据库命令（包含常用的 MySQL 命令）、SQL 语句和 PL 语句，可以实现以下任务：

  * 计算、存储和打印查询结果。

  * 创建数据库对象、检查和修改对象定义。

  * 开发和运行批处理脚本。

  * 执行数据库管理和修改参数等。

  使用 OceanBase 客户端连接 OceanSeek 租户的具体操作示例请参见 [通过 OBClient 连接 OceanSeek](200.client/300.connect-to-an-oceanbase-tenant-by-using-obclient.md)。

* OceanBase 开发者中心（ODC）

  OceanBase 开发者中心（OceanBase Developer Center，ODC）是为 OceanSeek 产品量身打造的企业级数据库开发平台。

  ODC 支持连接 OceanSeek，同时为数据库开发者提供了数据库日常开发操作、WebSQL、SQL 诊断、会话管理和数据导入导出等功能。

  使用 OceanBase 开发者中心连接 OceanSeek 租户的具体操作示例请参见 [通过 ODC 连接 OceanSeek](200.client/400.connect-to-the-oceanbase-database-through-odc.md)。

## 选择 GUI 连接

* DBeaver

  DBeaver 是通用的数据库客户端工具，其原理是使用各个数据库提供的 JDBC 驱动连接数据库，支持常见的关系型数据库、非关系型数据库、分布式数据库等等。

  更多内容参见[通过 DBeaver 连接数据库](300.gui/100.connect-to-oceanbase-database-through-dbeaver.md)。

* Navicat

  同 DBeaver 一样，Navicat 也是一款通用的数据库客户端工具，其原理是使用各个数据库提供的 JDBC 驱动连接数据库，支持常见的关系型数据库、非关系型数据库、分布式数据库等等。

  更多内容参见[通过 Navicat 连接数据库](300.gui/200.connect-to-oceanbase-database-through-navicat.md)。

## 选择驱动或 ORM 框架连接

OceanSeek 支持通过驱动或 ORM 框架连接，这些方式为不同编程语言和开发场景提供了灵活的接入方案。更多内容参见 [通过驱动或 ORM 框架连接](400.driver-or-orm/10.driver-or-orm.md)。
