# 开始使用 OceanBase AI 数据库

本文介绍如何基于已部署的 OceanBase AI 数据库集群，依次完成用户租户的创建与登录、业务数据库的创建和查询，帮助您快速完成 OceanBase AI 数据库的首次使用。

## 前提条件

* 已完成 OceanBase AI 数据库集群的部署。部署流程请参见 [部署流程](../150.deploy/200.deployment-process.md)。
* 已获取集群 sys 租户的 root 用户密码，即在创建集群时设置的 **root@sys 密码**。
* 已安装 obclient 客户端。更多连接方式请参见 [连接方式概览](../200.connect/100.connection-methods-overview.md)。

## 步骤一：创建用户租户

OceanBase AI 数据库是原生分布式数据库，在同一个数据库中可以同时运行多个数据库实例，第一步往往需要创建一个租户（数据库实例），然后像使用传统单机数据库那样使用数据库实例。

OceanBase AI 数据库仅支持创建用户租户，系统租户由集群创建时自动创建。创建用户租户的步骤为：

1. 创建资源规格。

   1. 使用 `root` 用户登录到集群的 `sys` 租户。

      ```shell
      obclient -h172.30.xx.xx -P2883 -uroot@sys#cluster -p**** -A
      ```

   2. 进入 `oceanbase` 数据库。

      ```shell
      obclient(root@sys)[(none)]> USE oceanbase;
      ```

   3. 通过 `DBA_OB_UNIT_CONFIGS` 视图，获取已有的资源规格信息。

      ```shell
      obclient(root@sys)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_UNIT_CONFIGS;
      ```

      返回结果如下：

      ```shell
      +----------------+-----------------+----------------------------+----------------------------+---------+---------+-------------+---------------+----------------+---------------------+---------------------+-------------+---------------------+----------------------+
      | UNIT_CONFIG_ID | NAME            | CREATE_TIME                | MODIFY_TIME                | MAX_CPU | MIN_CPU | MEMORY_SIZE | LOG_DISK_SIZE | DATA_DISK_SIZE | MAX_IOPS            | MIN_IOPS            | IOPS_WEIGHT | MAX_NET_BANDWIDTH   | NET_BANDWIDTH_WEIGHT |
      +----------------+-----------------+----------------------------+----------------------------+---------+---------+-------------+---------------+----------------+---------------------+---------------------+-------------+---------------------+----------------------+
      |              1 | sys_unit_config | 2026-09-01 16:31:19.277829 | 2026-09-01 16:31:19.277829 |       1 |       1 |  5368709120 |    7516192768 |    10737418240 | 9223372036854775807 | 9223372036854775807 |           1 | 9223372036854775807 |                    1 |
      +----------------+-----------------+----------------------------+----------------------------+---------+---------+-------------+---------------+----------------+---------------------+---------------------+-------------+---------------------+----------------------+
      1 row in set (0.002 sec)
      ```

      关于 `DBA_OB_UNIT_CONFIGS` 视图的详细说明，参见 [DBA_OB_UNIT_CONFIGS](../700.reference/700.system-views/300.system-view-of-sys-tenant/200.dictionary-view-of-sys-tenant/23700.o-dba_ob_unit_configs-of-sys-tenant.md)。

   4. 通过 `CREATE RESOURCE UNIT` 语句，创建资源规格。

      示例：创建一个名称为 `S1_unit_config` 的资源规格，其资源配置为 1 核 CPU、5G 内存。

      ```shell
      obclient(root@sys)[oceanbase]> CREATE RESOURCE UNIT S1_unit_config
                     MEMORY_SIZE = '5G',
                     MAX_CPU = 1, MIN_CPU = 1;
      ```

      关于该语句的详细说明，参见 [创建租户](../600.manage/200.tenant-management/600.common-tenant-operations/200.manage-create-tenant.md) 中的 **创建资源规格** 章节。

   5. 查询 `DBA_OB_UNIT_CONFIGS` 视图，确认资源规格 `S1_unit_config` 创建成功。

      ```shell
      obclient(root@sys)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_UNIT_CONFIGS WHERE NAME = 'S1_unit_config';
      ```

      返回结果如下：

      ```shell
      +----------------+----------------+----------------------------+----------------------------+---------+---------+-------------+---------------+----------------+---------------------+---------------------+-------------+---------------------+----------------------+
      | UNIT_CONFIG_ID | NAME           | CREATE_TIME                | MODIFY_TIME                | MAX_CPU | MIN_CPU | MEMORY_SIZE | LOG_DISK_SIZE | DATA_DISK_SIZE | MAX_IOPS            | MIN_IOPS            | IOPS_WEIGHT | MAX_NET_BANDWIDTH   | NET_BANDWIDTH_WEIGHT |
      +----------------+----------------+----------------------------+----------------------------+---------+---------+-------------+---------------+----------------+---------------------+---------------------+-------------+---------------------+----------------------+
      |           1003 | S1_unit_config | 2026-09-01 19:56:21.723061 | 2026-09-01 19:56:21.723061 |       1 |       1 |  5368709120 |    5368709120 |    10737418240 | 9223372036854775807 | 9223372036854775807 |           1 | 9223372036854775807 |                    1 |
      +----------------+----------------+----------------------------+----------------------------+---------+---------+-------------+---------------+----------------+---------------------+---------------------+-------------+---------------------+----------------------+
      1 row in set (0.001 sec)
      ```

2. 创建资源池。

   1. 通过 `DBA_OB_RESOURCE_POOLS` 视图，获取资源池的配置信息。

      ```shell
      obclient(root@sys)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_RESOURCE_POOLS;
      ```

      返回结果如下：

      ```shell
      +------------------+----------+-----------+----------------------------+----------------------------+------------+----------------+-----------+--------------+
      | RESOURCE_POOL_ID | NAME     | TENANT_ID | CREATE_TIME                | MODIFY_TIME                | UNIT_COUNT | UNIT_CONFIG_ID | ZONE_LIST | REPLICA_TYPE |
      +------------------+----------+-----------+----------------------------+----------------------------+------------+----------------+-----------+--------------+
      |                1 | sys_pool |         1 | 2026-09-01 16:31:19.281405 | 2026-09-01 16:31:19.281405 |          1 |              1 | zone1     | FULL         |
      +------------------+----------+-----------+----------------------------+----------------------------+------------+----------------+-----------+--------------+
      1 row in set (0.002 sec)
      ```

      关于 `DBA_OB_RESOURCE_POOLS` 视图的详细说明，参见 [DBA_OB_RESOURCE_POOLS](../700.reference/700.system-views/300.system-view-of-sys-tenant/200.dictionary-view-of-sys-tenant/21000.o-dba_ob_resource_pools-of-sys-tenant.md)。

   2. 通过 `CREATE RESOURCE POOL` 语句，创建资源池。

      示例：创建一个名为 `mq_pool_01` 的资源池，在 zone1 创建 1 个 Unit，且 Unit 的资源规格为 `S1_unit_config`。

      ```shell
      obclient(root@sys)[oceanbase]> CREATE RESOURCE POOL mq_pool_01
                        UNIT='S1_unit_config',
                        UNIT_NUM=1,
                        ZONE_LIST=('zone1');
      ```

      关于该语句的详细说明，参见 [创建租户](../600.manage/200.tenant-management/600.common-tenant-operations/200.manage-create-tenant.md) 中的 **创建资源池** 章节。

   3. 查询 `DBA_OB_RESOURCE_POOLS` 视图，确认资源池 `mq_pool_01` 创建成功。

      ```shell
      obclient(root@sys)[oceanbase]> SELECT * FROM oceanbase.DBA_OB_RESOURCE_POOLS WHERE NAME = 'mq_pool_01';
      ```

      返回结果如下：

      ```shell
      +------------------+------------+-----------+----------------------------+----------------------------+------------+----------------+-----------+--------------+
      | RESOURCE_POOL_ID | NAME       | TENANT_ID | CREATE_TIME                | MODIFY_TIME                | UNIT_COUNT | UNIT_CONFIG_ID | ZONE_LIST | REPLICA_TYPE |
      +------------------+------------+-----------+----------------------------+----------------------------+------------+----------------+-----------+--------------+
      |             1001 | mq_pool_01 |      NULL | 2026-09-01 19:57:25.969501 | 2026-09-01 19:57:25.969501 |          1 |           1003 | zone1     | FULL         |
      +------------------+------------+-----------+----------------------------+----------------------------+------------+----------------+-----------+--------------+
      1 row in set (0.002 sec)
      ```

3. 创建租户。

   1. 通过 `DBA_OB_TENANTS` 视图，查看所有的租户信息。

      ```shell
      obclient(root@sys)[oceanbase]> SELECT TENANT_ID, TENANT_NAME, TENANT_TYPE, CREATE_TIME, MODIFY_TIME, PRIMARY_ZONE, LOCALITY, COMPATIBILITY_MODE, STATUS, TENANT_ROLE FROM oceanbase.DBA_OB_TENANTS;
      ```

      返回结果如下：

      ```shell
      +-----------+-------------+-------------+----------------------------+----------------------------+--------------+---------------+--------------------+--------+-------------+
      | TENANT_ID | TENANT_NAME | TENANT_TYPE | CREATE_TIME                | MODIFY_TIME                | PRIMARY_ZONE | LOCALITY      | COMPATIBILITY_MODE | STATUS | TENANT_ROLE |
      +-----------+-------------+-------------+----------------------------+----------------------------+--------------+---------------+--------------------+--------+-------------+
      |         1 | sys         | SYS         | 2026-09-01 16:31:19.292987 | 2026-09-01 16:31:19.292987 | RANDOM       | FULL{1}@zone1 | MYSQL              | NORMAL | PRIMARY     |
      +-----------+-------------+-------------+----------------------------+----------------------------+--------------+---------------+--------------------+--------+-------------+
      1 row in set (0.008 sec)
      ```

      关于 `DBA_OB_TENANTS` 视图的详细说明，请参见 [DBA_OB_TENANTS](../700.reference/700.system-views/300.system-view-of-sys-tenant/200.dictionary-view-of-sys-tenant/23100.o-dba_ob_tenants-of-sys-tenant.md)。

   2. 通过 `CREATE TENANT` 语句，创建租户。

      示例：创建一个名为 `mq_t1` 的租户，资源池指定为 `mq_pool_01`，Primary Zone 为 zone1，允许所有 IP 连接数据库。

      ```shell
      obclient(root@sys)[oceanbase]> CREATE TENANT IF NOT EXISTS mq_t1
                     PRIMARY_ZONE='zone1',
                     RESOURCE_POOL_LIST=('mq_pool_01')
                     SET OB_TCP_INVITED_NODES='%';
      ```

      关于该语句的详细说明，参见 [创建租户](../600.manage/200.tenant-management/600.common-tenant-operations/200.manage-create-tenant.md) 中的 **创建租户** 章节。

   3. 查询 `DBA_OB_TENANTS` 视图，确认租户 `mq_t1` 创建成功。

      ```shell
      obclient(root@sys)[oceanbase]> SELECT TENANT_ID, TENANT_NAME, TENANT_TYPE, CREATE_TIME, MODIFY_TIME, PRIMARY_ZONE, LOCALITY, COMPATIBILITY_MODE, STATUS, TENANT_ROLE FROM oceanbase.DBA_OB_TENANTS WHERE TENANT_NAME = 'mq_t1';
      ```

      返回结果如下：

      ```shell
      +-----------+-------------+-------------+----------------------------+----------------------------+--------------+---------------+--------------------+--------+-------------+
      | TENANT_ID | TENANT_NAME | TENANT_TYPE | CREATE_TIME                | MODIFY_TIME                | PRIMARY_ZONE | LOCALITY      | COMPATIBILITY_MODE | STATUS | TENANT_ROLE |
      +-----------+-------------+-------------+----------------------------+----------------------------+--------------+---------------+--------------------+--------+-------------+
      |      1002 | mq_t1       | USER        | 2026-09-01 20:02:24.186055 | 2026-09-01 20:03:03.737490 | zone1        | FULL{1}@zone1 | MYSQL              | NORMAL | PRIMARY     |
      +-----------+-------------+-------------+----------------------------+----------------------------+--------------+---------------+--------------------+--------+-------------+
      1 row in set (0.011 sec)
      ```

## 步骤二：登录用户租户

租户创建成功后，即可登录租户。用户租户 `mq_t1` 的默认管理员用户 root 密码为空，您需要先修改管理员用户的密码。

1. 登录 `mq_t1` 租户的 root 用户。

   ```shell
   obclient -h172.30.xx.xx -P2883 -uroot@mq_t1#cluster -A
   ```

2. 执行以下语句修改 root 用户的密码。

   ```shell
   obclient(root@mq_t1)[(none)]> ALTER USER root IDENTIFIED BY '****';
   Query OK, 0 rows affected
   ```

3. 管理员用户密码修改成功后，重新登录租户。

   ```shell
   obclient -h172.30.xx.xx -P2883 -uroot@mq_t1#cluster -p**** -A
   ```

## 步骤三：创建业务数据库

1. 使用 `CREATE DATABASE` 语句创建业务数据库。

   示例：创建数据库 `db1`，指定字符集为 `utf8mb4`，并创建读写属性。

   ```shell
   obclient(root@mq_t1)[(none)]> CREATE DATABASE db1 DEFAULT CHARACTER SET utf8mb4 READ WRITE;
   ```

2. 创建完成后，可以通过 `SHOW DATABASES` 命令查看当前租户中的所有数据库。

   ```shell
   obclient(root@mq_t1)[(none)]> SHOW DATABASES;
   ```

   返回结果如下：

   ```shell
   +--------------------+
   | Database           |
   +--------------------+
   | db1                |
   | information_schema |
   | mysql              |
   | oceanbase          |
   | test               |
   +--------------------+
   5 rows in set (0.003 sec)
   ```

   关于 `CREATE DATABASE` 语句的详细说明，参见 [CREATE DATABASE](../700.reference/500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/2100.create-database-of-mysql-mode.md)。

## 步骤四：执行基础查询

业务数据库创建完成后，即可开始使用 OceanBase AI 数据库进行数据的写入与查询。

1. 切换到数据库 `db1`。

   ```shell
   obclient(root@mq_t1)[(none)]> USE db1;
   ```

2. 创建表 `t1`，用于存放示例数据。

   ```shell
   obclient(root@mq_t1)[db1]> CREATE TABLE t1 (id INT, name VARCHAR(50), num INT);
   ```

3. 向表 `t1` 中插入多行数据。

   ```shell
   obclient(root@mq_t1)[db1]> INSERT INTO t1 VALUES(1,'a',100),(2,'b',200),(3,'a',50);
   ```

4. 查询表 `t1` 中的数据。

   ```shell
   obclient(root@mq_t1)[db1]> SELECT * FROM t1;
   ```

   返回结果如下：

   ```shell
   +------+------+------+
   | id   | name | num  |
   +------+------+------+
   |    1 | a    |  100 |
   |    2 | b    |  200 |
   |    3 | a    |   50 |
   +------+------+------+
   3 rows in set (0.002 sec)
   ```

5. 按条件查询数据。示例中查询 `name = 'a'` 的记录。

   ```shell
   obclient(root@mq_t1)[db1]> SELECT id, name, num FROM t1 WHERE name = 'a';
   ```

   返回结果如下：

   ```shell
   +------+------+------+
   | id   | name | num  |
   +------+------+------+
   |    1 | a    |  100 |
   |    3 | a    |   50 |
   +------+------+------+
   2 rows in set (0.002 sec)
   ```

至此，您已经完成了 OceanBase AI 数据库的首次使用。
