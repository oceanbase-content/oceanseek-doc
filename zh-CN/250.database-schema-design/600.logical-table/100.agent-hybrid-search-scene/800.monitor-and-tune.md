# 监控与维护

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>本功能在当前版本为实验特性。</p>
</main>

本文档介绍了 Agent 混合搜索场景的运维与调优。删除 Collection / Namespace 等操作为异步后台任务。可通过系统视图查看进度，并通过租户级配置项调节删除并发与热 Namespace 缓存 TTL。

## 监控

可通过 SQL 查询相关视图来查看后台任务进度。

## 维护

| **配置项** | **类型** | **默认值** | **说明** |
| --- | --- | --- | --- |
| [enable_agent_db_background_task](../../../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/2320.enable_agent_db_background_task.md) | bool | True | 是否开启逻辑表后台删除任务。 |
| [agent_db_background_delete_thread_score](../../../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/50.agent_db_background_delete_thread_score.md) | int | 0（表示使用默认值 2） | 后台删除线程数，范围 `[0, 100]`；值越大删得越快，占用资源也更多。 |
| [agent_db_hot_namespace_ttl](../../../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/400.tenant-level-configuration-items/55.agent_db_hot_namespace_ttl.md) | 时间 | `1h` | 热 Namespace 缓存（向量索引聚类中心）存活时间，超时未访问自动淘汰；范围 `[1s, 180d]`。淘汰后首次访问需重新加载，可用 `ns.prewarm()` 预热。 |
