# 索引与嵌入函数

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>本功能在当前版本为实验特性。</p>
</main>

本文档介绍 Agent 混合搜索场景下的索引与嵌入函数配置，并说明如何组合这两者。

## Schema 与向量索引

创建 Collection 时可通过 `schema` 参数自定义索引配置。默认配置因模式而异：

* `use_namespace=False`：默认启用 HNSW 索引（384 维、cosine 距离）与 ik 分词器。
* `use_namespace=True`（本场景）：需显式配置 `IVFConfiguration`，当前仅支持 `type="ivf_flat"`。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p><li><code>use_namespace=True</code> 时仅支持稠密向量索引与全文索引，不支持稀疏向量索引。</li><li>全文索引可选，一个 Collection 最多创建一个。</li></p>
</main>

### Schema 结构

`Schema` 用于定义 Collection 的索引配置，包含三个配置域：

* `vector_index`：稠密向量索引
* `fulltext_index`：全文索引
* `sparse_vector_index`：稀疏向量索引

```shell
from pyseekdb import Schema, VectorIndexConfig, IVFConfiguration, FulltextIndexConfig

collection = client.create_collection(
    name="my_col",
    schema=Schema(
        # 向量索引
        vector_index=VectorIndexConfig(
            ivf=IVFConfiguration(
                dimension=1024,
                distance="cosine",
                type="ivf_flat",
            ),
        ),
        # 全文索引
        fulltext_index=FulltextIndexConfig(analyzer="ik"),
    ),
    use_namespace=True,
)
```

### 链式 API

`Schema` 支持方法链，可以一段接一段地调用方法，逐步添加各类索引配置。例如先 `Schema()` 创建空对象，再连续 `.create_index(...)` 分别加入向量索引和全文索引；每一步返回的仍是 Schema 对象：

```shell
schema = (
    Schema()
    .create_index(IVFConfiguration(dimension=384, distance="cosine"))
    .create_index(FulltextIndexConfig(analyzer="ik"))
)
```

`create_index` 会按传入对象类型自动挂载对应索引（`IVFConfiguration` / `VectorIndexConfig` / `FulltextIndexConfig`），链式写法与直接构造 `Schema(...)` 等价。

### IVF 向量索引

```shell
IVFConfiguration(
    dimension=384,          
    distance="cosine",      
    type="ivf_flat",        
    lib="ob",               
    centroids_fresh_mode="spfresh",  
    properties={"nprobes": 32},  
)
```

| **参数** | **默认值** | **说明** |
| --- | --- | --- |
| dimension | 384 | 向量维度，需与嵌入模型输出一致，取值范围 [1, 4096] |
| distance | "cosine" | 距离度量方式，当前仅支持 "l2" / "cosine" / "inner_product" |
| type | "ivf_flat" | 索引子类型，当前仅支持 "ivf_flat" |
| lib | "ob" | 底层索引实现库，当前仅支持 "ob" |
| centroids_fresh_mode | None | SPFresh 模式，可选，当前仅支持传入 "spfresh" |
| properties | None | 索引属性字典，支持 nprobes 等参数 | // TODO: 补充 properties 参数说明

## 全文索引

全文索引通过 `FulltextIndexConfig` 配置，用于 `hybrid_search` 的全文搜索端，以及 `where_document` 中的 `$contains` 条件过滤。

### 基础配置

```shell
FulltextIndexConfig(
    analyzer="ik",           
    properties=None,         
)
```

### 分词器选择与属性

支持的分词器包含：ik、space、ngram、ngram2、beng。具体说明和支持的属性（properties）请参见：[全文索引 - 字段说明](https://docs.seekdb.ai/seekdb/zh-CN/fulltext-index-of-pyseekdb#字段说明)。

## 嵌入函数

嵌入函数（Embedding Function）将文本转为向量。**本功能接口与 [seekdb 的 EF](https://docs.seekdb.ai/seekdb/zh-CN/ef-overview-py) 一致（默认模型、内置实现、自定义协议、自动向量化规则均相同）；唯一写法差异是：本场景（`use_namespace=True`）须把 EF 配在 `VectorIndexConfig(embedding_function=...)` 中，不要作为 `create_collection` 的顶层参数（传入 `schema` 时顶层会被忽略）**。

通用说明、平台鉴权与自定义细节见 seekdb：[嵌入函数概览](https://docs.seekdb.ai/seekdb/zh-CN/ef-overview-py)。

### 工作方式

配置嵌入函数后，写入和查询时会自动进行向量化：

* 写入：`add` / `update` / `upsert` 传入 `documents` 且未传 `embeddings` 时，由嵌入函数生成向量。
* 查询：`query` / `hybrid_search` 传入 `query_texts` 且未传 `query_embeddings` 时，由嵌入函数生成查询向量。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>索引配置中的 <code>IVFConfiguration.dimension</code> 须与嵌入函数输出维度一致。</p>
</main>

### 配置示例

```shell
from pyseekdb import Schema, VectorIndexConfig, IVFConfiguration
from pyseekdb.utils.embedding_functions import OpenAIEmbeddingFunction

ef = OpenAIEmbeddingFunction(
    api_key="sk-xxx",  # 或环境变量 OPENAI_API_KEY
    model_name="text-embedding-3-small",
)
collection = client.create_collection(
    name="my_collection",
    schema=Schema(
        vector_index=VectorIndexConfig(
            ivf=IVFConfiguration(dimension=1536, distance="cosine"),
            embedding_function=ef,  # 配置嵌入函数，须写在 VectorIndexConfig 中
        ),
    ),
    use_namespace=True,
)
```

不传 `embedding_function` 时，使用默认 `DefaultEmbeddingFunction`（`all-MiniLM-L6-v2`，维度 384；本地运行，首次可能下载模型）。详细说明请参见 [默认嵌入式函数](https://docs.seekdb.ai/seekdb/zh-CN/default-embedding-function-of-api)。

完全手动传向量时，可显式关闭自动向量化：

```shell
collection = client.create_collection(
    name="manual_vectors",
    schema=Schema(
        vector_index=VectorIndexConfig(
            ivf=IVFConfiguration(dimension=384, distance="cosine"),
            # 显式关闭
            embedding_function=None,
        ),
    ),
    use_namespace=True,
)
```

### 内置与平台实现

OpenAI、通义千问、Ollama、Cohere、Bedrock 等内置实现的依赖与参数，与 seekdb 相同，请按平台查阅 [嵌入函数概览 - 支持的平台](https://docs.seekdb.ai/seekdb/zh-CN/ef-overview-py#支持的平台)；配置时仍须放入本场景的 `VectorIndexConfig`。

### 自定义嵌入函数

完整约束与示例见：

* [创建自定义嵌入函数](https://docs.seekdb.ai/seekdb/zh-CN/create-custim-embedding-functions-of-api)
* [使用自定义嵌入函数](https://docs.seekdb.ai/seekdb/zh-CN/using-custom-embedding-functions-of-api)

本场景配置示例如下（索引用 IVF，维度与 `ef.dimension` 对齐）：

```shell
from pyseekdb import (
    EmbeddingFunction,
    IVFConfiguration,
    Schema,
    VectorIndexConfig,
    register_embedding_function,
)

@register_embedding_function
class MyEmbedding(EmbeddingFunction):
    @staticmethod
    def name() -> str:
        return "my_embedding"

    def __call__(self, documents):
        # 返回 list[list[float]]
        return [[0.1, 0.2, 0.3] for _ in documents]

    def get_config(self) -> dict:
        return {"model": "custom-v1"}

    @staticmethod
    def build_from_config(config: dict):
        return MyEmbedding()

    @staticmethod
    def support_persistence(embedding_function) -> bool:
        return False

# 使用
collection = client.create_collection(
    "my_col",
    schema=Schema(
        vector_index=VectorIndexConfig(
            ivf=IVFConfiguration(dimension=3),
            embedding_function=MyEmbedding(),
        ),
    ),
    use_namespace=True,
)
```

自定义时需继承 `EmbeddingFunction`，至少实现把文本转成向量的 `__call__`，并建议声明 `dimension`。若希望创建 Collection 后，下次 `get_collection` 时仍能自动还原同一套实例，再实现 `name`、`get_config`、`build_from_config`，并用 `@register_embedding_function` 注册：SDK 会把 `name` 与 `get_config()` 的返回值存进 Collection 元数据，之后用 `build_from_config` 重建实例。
