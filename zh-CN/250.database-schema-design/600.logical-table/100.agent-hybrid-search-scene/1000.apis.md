# API 速查

<main id="notice" type='explain'>

本文汇总本场景常用 pyseekdb 接口签名，便于查阅。

## Client API

```shell
import pyseekdb

# 创建客户端（连接 OceanSeek）
# host/tenant/database/user/password: str；port: int
client = pyseekdb.Client(
    host="localhost", port=2881,
    tenant="test", database="test",
    user="root", password="",
)

# 创建 Collection；本场景须 use_namespace=True
# name: str，仅字母/数字/下划线，最长 512 字符
# schema: Schema | None，本场景须显式配置 IVF；构造见下文 Schema / Configuration API
# 返回 Collection 实例
client.create_collection(name="tech_docs", use_namespace=True, schema=schema)

# 获取已有 Collection；不存在则抛异常
# name: str 
client.get_collection("tech_docs")

# 存在则返回，不存在则创建；参数同 create_collection
# 已存在时后续传入的 schema / use_namespace 不会修改已有配置
client.get_or_create_collection(name="tech_docs", use_namespace=True, schema=schema)

# 删除 Collection；调用会阻塞直到删除完成再返回，无返回值
client.delete_collection("tech_docs")

# 列举全部 Collection ；返回 list[Collection]
client.list_collections()

# 是否存在；返回 bool
client.has_collection("tech_docs")
```

## Collection API

```shell
# 创建 Namespace；name: str，仅字母/数字/下划线，最长 256 字符；返回 Namespace 实例
# 须在 use_namespace=True 的 Collection 上调用
collection.create_namespace("my_knowledge")

# 获取 Namespace；不存在则抛异常
collection.get_namespace("my_knowledge")

# 存在则返回，不存在则创建
collection.get_or_create_namespace("my_knowledge")

# 删除 Namespace；异步，调用后立即返回，后台逐步删数据
collection.delete_namespace("my_knowledge")

# 列举全部 Namespace ；返回 list[Namespace]
collection.list_namespaces()

# 是否存在；返回 bool
collection.has_namespace("my_knowledge")

# 属性
collection.name                 # str，Collection 名称
collection.id                   # str，Collection ID
collection.dimension            # int，向量维度
collection.distance             # str，距离算法（如 cosine / l2）
collection.use_namespace        # bool，是否启用 Namespace 模式
collection.metadata             # dict | None，元数据
collection.embedding_function   # EmbeddingFunction | None，当前嵌入函数
```

本场景下数据读写在 Namespace 上执行，Collection 本身不直接承载 DML / DQL。

## Namespace API

```shell
# ---------- DML ----------
# 插入；ids 在 Namespace 内须唯一，重复会报错；需要可重复执行时用 upsert
# ids: str | list[str]
# embeddings: list[float] | list[list[float]] | None（一条或多条向量，维数须与 Collection 一致）
# metadatas: dict | list[dict] | None
# documents: str | list[str] | None
# embeddings / documents / metadatas 至少传一个；未传 embeddings、只传 documents 时须已配置嵌入函数
# 批量时 documents / embeddings / metadatas 长度须与 ids 一致；单次最多 100 条
ns.add(ids=["doc1"], documents=["OceanSeek"])

# 按 id 更新指定字段；不传的字段不改；id 不存在时不报错也不更新
ns.update(ids=["doc1"], documents=["OceanSeek（已更新）"])

# 存在则更新，不存在则插入；参数类型同 add
ns.upsert(ids=["doc1"], documents=["OceanSeek"])

# 删除，可按 id 或过滤条件；ids / where / where_document 至少传一个
ns.delete(ids=["doc1", "doc2"])
ns.delete(where={"category": "database"})

# ---------- DQL ----------
# 向量搜索 -> dict（含 ids / documents / metadatas / distances 等）
# query_embeddings: list[float] | list[list[float]] | None
#   list[float] 为一条查询向量；list[list[float]] 为多条查询向量（批量查询，各向量独立搜索并返回二维结果，不会合并为混合搜索）
# query_texts: str | list[str] | None
#   str 为一条查询文本；list[str] 为多条查询文本（一次批量查询）
# query_embeddings 与 query_texts 至少传一个，两个都不传时报错
# n_results: int，默认 10
# where / where_document: dict | None
# include: list[str] | None（如 ["documents", "metadatas", "distances"]）
# 返回二维 dict，外层对应每条查询
ns.query(query_texts=["aaa"], n_results=10,
         where=None, where_document=None, include=None)
ns.query(query_embeddings=[[0.12, 0.34, ...]], n_results=10,
         where=None, where_document=None, include=None)

# 混合搜索（向量 + 全文）；query 为全文路，knn 为向量路，rank 为融合；返回二维 dict
# query: dict | None
#   where_document: dict | None（如 {"$contains": "aaa"}）
#   where: dict | None（本路 metadata 过滤）
#   n_results: int（本路召回条数，默认 10）
# knn: dict | None
#   query_texts 或 query_embeddings 至少一个（语义同 ns.query）
#   where / n_results（本路 metadata 过滤与召回条数）
# rank: dict | None，如 {"rrf": {"rank_window_size": 60, "rank_constant": 60}}
# n_results: int，融合后返回条数，默认 10
# include: list[str] | None；distances 始终返回
# query_hint: QueryHint | None，仅本接口生效（parallel / query_timeout / vector_index）
ns.hybrid_search(
    query={
        "where_document": {"$contains": "aaa"},
        "where": {"category": {"$eq": "database"}},
        "n_results": 6,
    },
    knn={
        "query_texts": ["aaaaa"],
        "n_results": 6,
    },
    rank={"rrf": {"rank_window_size": 60, "rank_constant": 60}},
    n_results=3,
    include=["documents", "metadatas"],
)

# 精确获取（非相似度搜索）；返回一维 dict
# 可按 ids 或 where / where_document；limit / offset 用于分页
ns.get(ids=["doc1", "doc2"])
ns.get(where={"category": "database"}, limit=2, offset=0,
       include=["documents", "metadatas"])

# ---------- 统计与运维 ----------
# 记录条数 ；返回 int
ns.count()

# 预览前 limit 条；返回一维 dict（结构同 get）
ns.peek(limit=10)

# 预热当前 Namespace（远程共享存储部署可用）；无返回值
ns.prewarm()

# 属性
ns.name            # str，Namespace 名称
ns.namespace_id    # str，Namespace ID
ns.collection      # Collection，所属 Collection
```

## Schema / Configuration API

```shell
from pyseekdb import (
    Schema, VectorIndexConfig, IVFConfiguration,
    FulltextIndexConfig,
)

# Schema：Collection 索引总配置
Schema(
    # vector_index: VectorIndexConfig | None，向量索引
    vector_index=VectorIndexConfig(
        # ivf: IVFConfiguration；dimension 须与嵌入模型输出一致，取值 [1, 4096]
        #   distance: cosine / l2 / inner_product；本场景 type 仅支持 ivf_flat
        ivf=IVFConfiguration(dimension=384, distance="cosine", type="ivf_flat"),
        # embedding_function: EmbeddingFunction | None，文本自动向量化
        embedding_function=ef,
    ),
    # fulltext_index: FulltextIndexConfig | None，全文索引
    #   analyzer: str（ik / space / ngram / ngram2 / beng）
    fulltext_index=FulltextIndexConfig(analyzer="ik"),
)
```

本场景向量索引使用 IVF。`SparseVectorIndexConfig` 仅适用于非 Namespace Collection，本场景不要配置。

## Embedding Function API

```shell
from pyseekdb import EmbeddingFunction, register_embedding_function

# 注册自定义嵌入函数，便于按 name 识别与重建
@register_embedding_function
class MyEF(EmbeddingFunction):
    @staticmethod
    def name() -> str: ...
    # 嵌入函数标识名 ；返回 str

    def __call__(self, documents) -> list[list[float]]: ...
    # 文本转向量；documents: str | list[str] ；返回 list[list[float]]

    def get_config(self) -> dict: ...
    # 写入 Collection 元数据的配置 ；返回 dict

    @staticmethod
    def build_from_config(config) -> EmbeddingFunction: ...
    # 按元数据还原实例；config: dict ；返回 EmbeddingFunction
```

绑定方式见 [索引与嵌入函数](700.index-and-embedding.md)。
