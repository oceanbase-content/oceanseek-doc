# Agent 混合搜索场景快速上手

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>本功能在当前版本为实验特性。</p>
</main>

本文档通过一个完整示例，带你走通从连接到搜索的全流程。示例场景：创建一个"技术文档"知识库，写入几条文档，执行向量搜索和精确查询。

## 前提条件

* 已部署 OceanBase AI 数据库，有关 OceanBase AI 数据库的部署方法，请参见 [部署概述](../../../150.deploy/100.deploy-overview.md)。
* 已安装 pyseekdb SDK，有关 pyseekdb SDK 的安装方法，请参见 [部署概述](https://docs.seekdb.ai/seekdb/zh-CN/pyseekdb-sdk-get-started)。
* 已创建 pyseekdb SDK 连接，连接方法请参见 [通过 SDK 连接 OceanBase AI 数据库](../../../200.connect/600.connect-oceanbase-tenant-using-pyseekdb.md)。

## 创建 Collection

```shell
# 导入 pyseekdb 模块
from pyseekdb import Schema, VectorIndexConfig, IVFConfiguration, FulltextIndexConfig

# 创建带 IVF 向量索引与全文索引的 Collection
collection = client.create_collection(
    # 集合名称
    name="tech_docs",
    # 集合 schema
    schema=Schema(
        vector_index=VectorIndexConfig(
            ivf=IVFConfiguration(dimension=384, distance="cosine", centroids_fresh_mode="spfresh"),
        ),
        fulltext_index=FulltextIndexConfig(analyzer="ik"),
    ),
    # 是否使用 Namespace
    use_namespace=True,
)
```

`use_namespace=True` 模式下。如需自定义索引参数，请参见 [索引与嵌入](700.index-and-embedding.md)。

## 创建 Namespace

```shell
# 创建 Namespace，系统自动分配 namespace_id
ns = collection.create_namespace("my_knowledge")
print(f"namespace_id: {ns.namespace_id}")
```

## 写入数据

```shell
# 批量写入文档（本示例只传文本，由 SDK 自动生成向量）
ns.add(
    # 业务 ID，用于关联业务数据
    ids=["doc1", "doc2", "doc3"],
    # 文档文本
    documents=[
        "OceanBase AI 数据库是蚂蚁集团自研的分布式数据库，支持 HTAP 混合负载",
        "Agent 混合搜索场景是 OceanBase AI 数据库面向 AI Agent 的多租户向量搜索方案",
        "pyseekdb 是 OceanBase AI 数据库的 Python SDK，提供向量存储与混合搜索能力",
    ],
    # 元数据，用于关联业务数据
    metadatas=[
        {"category": "database", "version": "4.0"},
        {"category": "ai", "version": "4.6"},
        {"category": "sdk", "version": "1.2"},
    ],
)
```

本节第一个示例没有传 `embeddings` 参数，这种情况 SDK 会自动将 `documents` 参数的文本向量化。如不希望使用自动向量化，传入 `embeddings` 参数指定向量即可，例如：

```shell
ns.add(
    ids=["doc1"],
    documents=["OceanBase AI 数据库是蚂蚁集团自研的分布式数据库，支持 HTAP 混合负载"],
    # 向量，用于搜索
    embeddings=[[0.12, 0.34, ...]],  # 384 维向量
)
```
## 查询数据

本节示例中，已写入三条数据，以下为查询数据的示例，包含向量搜索、精确查询和统计。

### 向量搜索

```shell
# 用自然语言做向量搜索，返回最相似的 2 条并打印结果
results = ns.query(
    query_texts=["分布式数据库"],
    n_results=2,
    include=["documents", "metadatas", "distances"],
)

for i, id_ in enumerate(results["ids"][0]):
    print(f"id: {id_}")
    print(f"  document: {results['documents'][0][i]}")
    print(f"  distance: {results['distances'][0][i]:.4f}")
```

输出示例：

```shell
id: doc1
  document: OceanBase AI 数据库是蚂蚁集团自研的分布式数据库，支持 HTAP 混合负载
  distance: 0.2310
id: doc3
  document: pyseekdb 是 OceanBase AI 数据库的 Python SDK，提供向量存储与混合搜索能力
  distance: 0.4512
```

`query_texts` 会自动调用嵌入函数将文本转换为向量。详见 [数据搜索](600.data-search.md)。

### 精确查询

```shell
# 根据业务 ID 精确查询，返回第一条并打印结果
result = ns.get(ids=["doc1"])
print(result["documents"][0])
```

### 统计

```shell
print(ns.count()) 
# 输出: 3
```

### 预热

生产环境中，Namespace 长时间未访问会变为"冷"状态（索引缓存被淘汰），变冷后下一次查询延迟较高。写入数据后调用 `prewarm` 接口可主动加载缓存：

```shell
ns.prewarm()
```

本示例中数据量极小且刚写入，预热效果不明显，但大规模数据场景下建议写入后立即预热。详见 [Collection 与 Namespace 管理](400.collection-and-namespace.md)。

## 清理资源

```shell
# 删除 Namespace 和 Collection
collection.delete_namespace("my_knowledge")
client.delete_collection("tech_docs")
```

`delete_namespace` 为异步操作，调用后立即返回，数据由后台任务逐步清理；`delete_collection` 为同步操作，调用会直接完成删除并返回，无需等待后台异步任务。可通过 `DBA_OB_AGENT_DB_BACKGROUND_TASKS` 视图查看删除进度，详见 [监控与维护](800.monitor-and-tune.md)。
