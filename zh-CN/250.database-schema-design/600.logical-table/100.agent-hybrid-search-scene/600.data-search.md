## 创建示例数据

假定已完成 pyseekdb 连接（变量 `client` 可用）。若同名对象已存在，可先删除再创建，或改用 `get_or_create_*`。

:::collapse
```shell
from pyseekdb import Schema, VectorIndexConfig, IVFConfiguration, FulltextIndexConfig
from pyseekdb.utils.embedding_functions import DefaultEmbeddingFunction

collection = client.create_collection(
    name="tech_docs1",
    schema=Schema(
        vector_index=VectorIndexConfig(
            ivf=IVFConfiguration(dimension=384, distance="cosine"),
            embedding_function=DefaultEmbeddingFunction(),
        ),
        fulltext_index=FulltextIndexConfig(analyzer="ik"),
    ),
    use_namespace=True,
)

ns = collection.create_namespace("my_knowledge1")
```
:::

写入 6 条样例数据，含相近文本与不同 `category`，便于观察过滤后召回变化：

:::collapse
```shell
ns.add(
```

## 向量搜索（query）

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p><code>query_embeddings</code> 与 <code>query_texts</code> 至少指定一个，两个都不传会直接报错。</p>
</main>

### 按文本查询（推荐）

以下示例通过 `where={"category": "database"}` 过滤，六条样例中仅 `doc1`、`doc4` 命中该类别，便于观察过滤效果。`query_texts` 支持同时搜索多个查询文本：

```shell
results = ns.query(
    query_texts=["分布式数据库"],
    n_results=5,
    where={"category": "database"},
    include=["documents", "metadatas", "distances"],
)
```

结果示例如下（示意距离与排序，实际数值随模型与数据略有差异）：

```shell
#1: doc1 (distance=0.2310)
    OceanSeek 是蚂蚁集团自研的分布式数据库，支持 HTAP 混合负载
    {'category': 'database', 'version': '4.0'}
#2: doc4 (distance=0.2780)
    OceanSeek 通过多副本与日志复制提供分布式数据库高可用能力
    {'category': 'database', 'version': '4.2'}
```

`query` 返回二维结果，外层对应每个查询向量/文本，内层对应结果列表。

### 按向量查询

```shell
results = ns.query(
    query_embeddings=[[0.12, 0.34, ...]],
    n_results=10,
)
```

## 混合搜索（hybrid_search）

同时走全文搜索和向量搜索两路，融合排序后返回：

```shell
# 全文路（query）：搜索含”数据库“的文档，过滤 category=database
# 向量路（knn）：用”分布式数据库高可用“做近邻搜索
# 两路结果用 RRF 融合，取 Top-3
results = ns.hybrid_search(
    query={
        "where_document": {"$contains": "数据库"},
        "where": {"category": {"$eq": "database"}},
        "n_results": 6,
    },
    knn={
        "query_texts": ["分布式数据库高可用"],
        "n_results": 6,
    },
    rank={"rrf": {"rank_window_size": 60, "rank_constant": 60}},
    n_results=3,
    include=["documents", "metadatas", "distances"],
)

for i, id_ in enumerate(results["ids"][0]):
    print(f"#{i+1}: {id_} (distance={results['distances'][0][i]:.4f})")
```

参数说明请参见 [hybrid_search](https://docs.seekdb.ai/seekdb/zh-CN/hybrid-search-of-api)。

## 精确查询（get）

```shell
# 按 id 查询
result = ns.get(ids=["doc1", "doc2"])

# 条件查询 + 分页
result = ns.get(
    where={"category": "database"},
    limit=2,
    offset=0,
    include=["documents", "metadatas"],
)
```

## 通用参数与返回值

| **参数** | **适用方法** | **说明** |
| --- | --- | --- |
| n_results | query / hybrid_search | 返回数量，默认 10 |
| include | query / hybrid_search / get | 返回字段：`"documents"` / `"metadatas"` / `"embeddings"`。`distances` 在 query / hybrid_search 中始终返回 |
| where | 全部 | metadata 过滤，详见下文 |
| where_document | 全部 | document 过滤，详见下文 |

返回值结构：

* `query` / `hybrid_search`：二维。外层对应每个查询文本/向量，内层为结果列表，例如 `{"ids": [["doc1", "doc4"]], "distances": [[0.12, 0.18]], ...}`。
* `get`：一维，例如 `{"ids": ["doc1", "doc4"], "documents": [...], "metadatas": [...]}`。

`hybrid_search` 返回的 `distances` 通常是融合后的相关性分数，不一定等于向量距离。在 Namespace 模式下，可以直接用 `query()` 做向量搜索，效果与仅使用 `hybrid_search` 的 knn 路径一致。

## 过滤条件

过滤条件适用于 `query`、`hybrid_search`、`get`、`delete` 方法。

### metadata 过滤（where）

比较运算符（下表为语法示意；本场景示例数据字段为 `category` / `version`）：

| **运算符** | **含义** | **示例** |
| --- | --- | --- |
| $eq | 等于 | {"category": {"$eq": "database"}} |
| $ne | 不等于 | {"category": {"$ne": "sdk"}} |
| $lt / $lte | 小于 / 小于等于 | {"version": {"$lt": "4.6"}} |
| $gt / $gte | 大于 / 大于等于 | {"version": {"$gte": "4.0"}} |
| $in | 在列表中 | {"category": {"$in": ["database", "ai"]}} |
| $nin | 不在列表中 | {"category": {"$nin": ["sdk"]}} |

逻辑组合：

```shell
# AND + NOT
{"$and": [{"category": {"$eq": "database"}}, {"$not": {"version": {"$eq": "1.2"}}}]}
```

### document 过滤（where_document）

```shell
# 全文搜索
{"$contains": "分布式数据库"}

# 正则匹配
{"$regex": "^OceanBase.*"}

# 不包含
{"$not_contains": "过时内容"}

# 逻辑组合
{"$or": [{"$contains": "OceanBase"}, {"$contains": "数据库"}]}
```

`$not_contains` 和 `$regex` 在部分 hybrid/knn 场景下无法下推到向量过滤，会由 SDK 做后置过滤。

### 组合使用

```shell
results = ns.query(
    query_texts=["分布式技术"],
    n_results=10,
    # 多个条件并列
    where={
        "$and": [
            {"category": {"$in": ["database", "ai"]}},
            {"version": {"$in": ["4.0", "4.2", "4.6", "4.7"]}},
        ]
    },
    # 全文搜索
    where_document={"$contains": "OceanBase"},
)
```

## QueryHint 查询优化

`QueryHint` 用于控制查询的并行度和超时。在本场景下，`query_hint` 适用于混合搜索：

```shell
from pyseekdb import QueryHint

results = ns.hybrid_search(
    query={"where_document": {"$contains": "数据库"}, "n_results": 10},
    knn={"query_texts": ["分布式技术"], "n_results": 10},
    n_results=5,
    query_hint=QueryHint(
        parallel=8,           # 查询并行度，需 > 0
        query_timeout=10.0,   # 超时时间（秒），需 > 0
        vector_index=True,    # 是否使用向量索引 hint
    ),
)
```

| **参数** | **类型** | **说明** |
| --- | --- | --- |
| parallel | int | 查询并行度，需 > 0 |
| query_timeout | float | 查询超时秒数，需 > 0 |
| vector_index | bool | 是否添加向量索引 hint |

限制如下：

* `query_hint` 仅对 `hybrid_search` 生效，`ns.query()` 和 `ns.get()` 暂不支持。
