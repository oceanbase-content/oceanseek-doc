# Collection 与 Namespace 管理

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>本功能在当前版本为实验特性。</p>
</main>

本文档介绍 Collection 与 Namespace 的创建、删除、预热与命名规则。示例中的 Collection 名称 `tech_docs`、Namespace 名称 `my_knowledge` 与 [快速上手](300.quick-start.md) 保持一致。

## Collection 管理

Collection 是本场景的顶层容器。在 Collection 层面配置向量索引、全文索引等参数，这些参数会固化在 Collection 的 Schema 中，Collection 下的所有 Namespace 共享 Collection 定义的索引配置。

<main id="notice" type='notice'>
    <h4>注意</h4>
    <p><code>use_namespace=True</code> 模式下，Collection 本身不承载数据操作（DML 和 DQL），必须通过 Namespace 执行。直接在 Collection 上调用 <code>add</code> / <code>query</code> 等方法会抛异常。</p>
</main>

### 创建 Collection

#### create_collection 接口

示例代码如下：

```shell
# 导入 pyseekdb 模块
from pyseekdb import Schema, VectorIndexConfig, IVFConfiguration, FulltextIndexConfig

# 创建 Collection
collection = client.create_collection(
    # Collection 名称
    name="tech_docs",
    # Collection schema
    schema=Schema(
        # 创建向量索引
        vector_index=VectorIndexConfig(
            # IVF 索引配置
            ivf=IVFConfiguration(dimension=384, distance="cosine"),
            # 文本嵌入函数
            embedding_function=DefaultEmbeddingFunction(),
        ),
        # 全文索引配置
        fulltext_index=FulltextIndexConfig(analyzer="ik"),
    ),
    # 是否使用 Namespace
    use_namespace=True,
)
```

| **参数** | **类型** | **默认值** | **说明** |
| --- | --- | --- | --- |
| name | string | — | Collection 名称（必填），仅允许字母、数字、下划线，最长 512 字符 |
| schema |  | None | 索引配置。本场景仅支持 IVF 向量索引和全文索引。详见 [索引与嵌入](700.index-and-embedding.md) |
| embedding_function |  | DefaultEmbeddingFunction() | 文本自动向量化函数。不要作为 `create_collection` 顶层参数，否则会被忽略。设为 `None` 表示完全手动传向量。详见 [索引与嵌入](700.index-and-embedding.md) |
| use_namespace | boolean | False | 是否启用 Namespace 模式。本场景请设为 `True`。值为 `False` 时，数据操作直接在 Collection 级别进行，不走 Namespace 隔离路径。 |

索引相关参数说明具体请参见 [索引与嵌入](700.index-and-embedding.md)。

#### get_or_create_collection 接口

还可使用 `get_or_create_collection` 接口，该接口可重复调用，效果为存在则返回已有 Collection，不存在则创建新的 Collection。示例代码如下：

```shell
from pyseekdb.utils.embedding_functions import DefaultEmbeddingFunction

collection = client.get_or_create_collection(
    "tech_docs",
    schema=Schema(
        vector_index=VectorIndexConfig(
            ivf=IVFConfiguration(dimension=384, distance="cosine"),
            embedding_function=DefaultEmbeddingFunction(),
        ),
        fulltext_index=FulltextIndexConfig(analyzer="ik"),
    ),
    use_namespace=True,
)
```

如果存在同名 Collection，后续传入的 `schema`、`use_namespace` 等创建参数不会修改已有 Collection 配置；需要变更索引或 Namespace 模式时，请删除重建或使用新名称。

### 获取、列举与判断

```shell
# 获取指定 Collection（不存在时抛异常）
collection = client.get_collection("tech_docs")

# 列举所有 Collection
collections = client.list_collections()
for c in collections:
    print(c.name)

# 判断是否存在
if client.has_collection("tech_docs"):
    print("已存在")
```

### 删除 Collection

```shell
client.delete_collection("tech_docs")
```

`delete_collection` 是同步操作：调用会直接完成删除并返回，无需等待后台异步任务。

## Namespace 管理

Namespace 是数据隔离的基本单元。在 `use_namespace=True` 模式下，所有 DML 和 DQL 操作都在 Namespace 上执行。不同的 Namespace 之间数据完全隔离。

### 命名规则与限制

| **约束** | **说明** |
| --- | --- |
| 类型 | string |
| 字符集 | 仅允许字母（a-z、A-Z）、数字（0-9）、下划线（_） |
| 长度 | 不超过 256 字符 |
| 非空 | 不允许空字符串 |
| 唯一性 | 在同一 Collection 内唯一 |

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>在 `use_namespace=False` 的 Collection 上调用 `create_namespace` 等方法会抛出 `ValueError: Namespace is not enabled for this collection`。</p>
</main>

### 创建与获取

```shell
# 创建 Namespace
ns = collection.create_namespace("my_knowledge")
print(ns.namespace_id)  # 系统自动分配的 namespace_id

# 获取已有 Namespace（不存在时抛异常）
ns = collection.get_namespace("my_knowledge")

# 获取或创建（不存在则自动创建，幂等）
ns = collection.get_or_create_namespace("my_knowledge")
```

### 列举、判断与删除

```shell
# 列举当前 Collection 下所有 Namespace
namespaces = collection.list_namespaces()
for ns in namespaces:
    print(f"{ns.name} -> {ns.namespace_id}")

# 判断是否存在
if collection.has_namespace("my_knowledge"):
    print("已存在")

# 删除 Namespace（异步操作）
collection.delete_namespace("my_knowledge")
```

`delete_namespace` 是异步操作，调用后立即返回，数据删除任务由后台逐步执行。

### 数据预览与统计

```shell
# 统计数据量
print(ns.count())  # 3

# 快速预览前 N 条数据
preview = ns.peek(limit=5)
for i in range(len(preview["ids"])):
    print(f"{preview['ids'][i]}: {preview['documents'][i]}")
```

### 预热

Namespace 长时间未访问会变为"冷"状态（向量索引的聚类中心缓存被淘汰），再次查询时首次请求延迟较高。调用 `prewarm` 可主动加载缓存：

```shell
ns.prewarm()
```

建议在大规模数据写入后、或 Namespace 长时间闲置后重新使用前调用。预热是 Namespace 级别的操作，不同 Namespace 需要分别预热。
