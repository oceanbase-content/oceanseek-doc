# 闪应用场景快速上手

本文档通过一个最简洁的示例，带你走通从连接、创建 Collection、建虚拟表到读写与清理的全流程。

## 前提条件

* 已部署 OceanSeek V4.6.2.1 及以上版本，有关 OceanSeek 的部署方法，请参见 [部署概述](../../../150.deploy/100.deploy-overview.md)。
* 已安装 json-table-sdk（1.5.0 及以上，Namespace 模式），有关安装说明请参见 [通过 json-table-sdk 连接数据库](200.flash-app-connect.md) 中的“安装 json-table-sdk”章节。
* 已准备可连接的数据库账号与目标库。通过 json-table-sdk 初始化客户端的完整参数说明，请参见 [通过 json-table-sdk 连接数据库](200.flash-app-connect.md)。

## 初始化客户端并创建 Collection

须启用 `use_namespace=True`，并先创建或绑定 Collection，再执行业务读写。

```shell
# 导入 json-table-sdk 模块的 VirtualTableClient 与 RequestContext 类
from antob_json_table import VirtualTableClient, RequestContext

# 创建客户端
client = VirtualTableClient(
    host="127.0.0.1",      # 数据库地址
    port=2881,             # 数据库端口
    user="root@mysql",     # 用户名
    password="",           # 密码
    database="test",       # 数据库名称
    use_namespace=True,    # 是否使用 Namespace（逻辑表模式必须为 True）
)

# 创建 Collection（partition_count 可选，范围 [1, 8192]，默认 64）
coll = client.create_collection("my_flash_app", partition_count=64)
```

## 指定 App

每次建表或读写都要传入 `RequestContext`，用来说明在哪个 App 下操作。`app_prefix` 对应 Namespace 名。参数说明见 [数据操作](#相关文档)，隔离规则见 [Collection 与 App 管理](#相关文档)。

```shell
# app_prefix 表示应用前缀，系统自动映射为 Namespace 名
# created_by 表示操作人，可选，默认 "admin"
ctx = RequestContext(coll, app_prefix="app001", created_by="admin")
```

## 创建虚拟表并写入数据

```shell
client.create_table(ctx, """
    CREATE TABLE users (
        id BIGINT NOT NULL,
        name VARCHAR(64) NOT NULL,
        age TINYINT DEFAULT 0
    )
""")

client.insert(ctx, """
    INSERT INTO users (id, name, age) VALUES
    (1, '张三', 25),
    (2, '李四', 30)
""")
```

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>用户 SQL 中直接使用业务表名（如 <code>users</code>），SDK 通过 <code>namespace_id</code> 与表名定位数据。</p>
</main>

## 查询与更新

```shell
rows = client.select(
    ctx,
    "SELECT * FROM users WHERE age > 25 ORDER BY age DESC LIMIT 100",
)

client.update(ctx, "UPDATE users SET age = 26 WHERE id = 1 LIMIT 10")
```

## 预热与清理

```shell
# 预热当前 App（须至少执行过一次业务操作以注册 Namespace）
coll.prewarm("app001")

# 查看表结构
schema = client.get_table_schema(ctx, "users")

# 删除虚拟表
client.drop_table(ctx, "users")

# 删除 App / Collection
coll.drop_app("app001")
client.delete_collection("my_flash_app")
client.close()
```

## 多应用隔离

同一 Collection 下使用不同 `app_prefix` 即可隔离数据；相同表名在不同 App 下互不影响。完整规则与示例见 [Collection 与 App 管理](#相关文档)。
