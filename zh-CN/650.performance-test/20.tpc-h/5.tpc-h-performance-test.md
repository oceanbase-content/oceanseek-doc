# OceanBase AI 数据库 TPC-H 测试

本文介绍使用 TPC-H 工具在 OceanBase AI 数据库的租户中手动执行 TPC-H 测试的方法。示例数据规模为 SF1000（约 1 TB）。

## 什么是 TPC-H

TPC-H（商业智能计算测试）是由国际组织 TPC（Transaction Processing Performance Council）制定的决策支持类基准测试集，用于模拟商业智能场景下的复杂查询负载。TPC-H 用 3NF 实现了一个数据仓库，共包含 8 个基本关系，主要评价指标是各个查询的响应时间，即从提交查询到结果返回所需的时间。

TPC-H 基准测试由 TPC-D 发展而来，其度量单位是每小时执行的查询数（QphH@size），其中 H 表示每小时系统执行复杂查询的平均次数，size 表示数据库规模的大小。TPC-H 可广泛用于银行信贷分析、信用卡分析、电信运营分析、税收分析等场景的性能评估。

## 环境准备

准备 OceanBase AI 数据库测试集群、测试租户和 OBClient。本文在存放数据的 OBServer 主机上安装工具、生成数据和执行脚本；主机需要具备 gcc、make、unzip、dos2unix、Bash 和 awk。

以支持 yum 的 Linux 系统为例，安装依赖：

```bash
sudo yum install -y gcc make unzip dos2unix
```

以下连接信息请按实际环境替换：`$host_ip` 为 OBServer 地址，`$host_port` 为 SQL 端口（默认 2881），`$user` 使用 root，`$tenant` 为测试租户名。

以下以数据盘挂载在 `/data/1` 为例，实际路径不同时请同步替换数据目录。

设置数据规模和目录。SF1000 约为 1 TB；测试 100G 时将 SF 改为 100：

```bash
export SF=1000
export WORK="$HOME/ob-tpch-sf$SF"
export DATA_DIR="/data/1/tpch-sf$SF"
umask 077
mkdir -p "$WORK"
cd "$WORK"
```

## 执行 TPC-H 测试

测试流程如下：

* 步骤一：进行环境调优
* 步骤二：安装 TPC-H Tool
* 步骤三：生成数据
* 步骤四：生成查询 SQL
* 步骤五：新建表
* 步骤六：加载数据
* 步骤七：发起合并
* 步骤八：等待合并完成
* 步骤九：收集统计信息
* 步骤十：执行测试

### 步骤二：安装 TPC-H Tool

1. 下载 TPC-H Tool。

    详细信息请参考 [TPC-H Tool 下载页面](https://www.tpc.org/tpc_documents_current_versions/download_programs/tools-download-request5.asp?bm_type=TPC-H&bm_vers=3.0.0&mode=CURRENT-ONLY)。

2. 下载完成后解压文件，进入 TPC-H 解压后的目录。将压缩包名称替换为实际下载的文件名。

    ```bash
    cd "$WORK"
    unzip 7e965ead-8844-4efa-a275-34e35f8ab89b-tpc-h-tool.zip
    cd TPC-H_Tools_v3.0.0/dbgen
    cp Makefile.suite Makefile
    ```

3. 修改 `Makefile` 文件中的 `CC`、`DATABASE`、`MACHINE`、`WORKLOAD` 等参数定义。

    ```makefile
    CC       = gcc
    DATABASE = MYSQL
    MACHINE  = LINUX
    WORKLOAD = TPCH
    ```

4. 修改 `tpcd.h` 文件，添加以下宏定义。

    ```c
    #ifdef MYSQL
    #define GEN_QUERY_PLAN ""
    #define START_TRAN "START TRANSACTION"
    #define END_TRAN "COMMIT"
    #define SET_OUTPUT ""
    #define SET_ROWCOUNT "limit %d;\n"
    #define SET_DBASE "use %s;\n"
    #endif
    ```

5. 编译文件。

    ```bash
    make
    ```

### 步骤三：生成数据

使用官方 dbgen 并行生成 20 份数据，nation 和 region 单独生成。数据规模使用环境准备中设置的 SF。使用新的空数据目录。

```bash
(
    set -e
    SCALE_FACTOR="$SF"
    CHUNK_COUNT=20
    DATA_DIR="$DATA_DIR"
    mkdir "$DATA_DIR"
    cd "$DATA_DIR"
    pids=()
    for ((child=1; child<=CHUNK_COUNT; child++)); do
        DSS_CONFIG="$WORK/TPC-H_Tools_v3.0.0/dbgen" \
            "$WORK/TPC-H_Tools_v3.0.0/dbgen/dbgen" \
            -s "$SCALE_FACTOR" -C "$CHUNK_COUNT" -S "$child" -vf \
            > "$WORK/dbgen-${child}.log" 2>&1 &
        pids+=("$!")
    done
    failed=0
    for pid in "${pids[@]}"; do wait "$pid" || failed=1; done
    [[ "$failed" == 0 ]] || { echo "造数失败，请检查 dbgen 日志"; exit 1; }
    DSS_CONFIG="$WORK/TPC-H_Tools_v3.0.0/dbgen" \
        "$WORK/TPC-H_Tools_v3.0.0/dbgen/dbgen" -s "$SCALE_FACTOR" -T l -vf
    chmod 755 "$DATA_DIR"
    chmod 644 "$DATA_DIR/"*.tbl*
)
```

### 步骤四：生成查询 SQL

1. 复制 `qgen` 和 `dists.dss` 文件至查询目录。

    ```bash
    mkdir -p "$WORK/queries"
    cp "$WORK/TPC-H_Tools_v3.0.0/dbgen/qgen" "$WORK/queries/"
    cp "$WORK/TPC-H_Tools_v3.0.0/dbgen/dists.dss" "$WORK/queries/"
    cd "$WORK/queries"
    ```

2. 创建 `gen.sh` 脚本生成查询 SQL。数据规模与生成数据时保持一致。

    ```bash
    #!/bin/bash
    set -e
    export DSS_QUERY="$WORK/TPC-H_Tools_v3.0.0/dbgen/queries"
    for i in {1..22}
    do
        ./qgen -d "$i" -s "$SF" > db"$i".sql
    done
    ```

3. 执行 `gen.sh` 脚本。

    ```bash
    chmod +x gen.sh
    ./gen.sh
    dos2unix db*.sql
    ```

4. 调整查询 SQL。

    在查询中添加 `/*+ PARALLEL(96) */`。检查正数 LIMIT 是否位于 SELECT 的结束分号之前，并保留原值；若生成了表示不限行数的 LIMIT -1，则删除该条 LIMIT 语句。将 Q1 中的 `DAY(3)`（或 `DAY (3)`）改为 `DAY`，保留原有日期和天数。

    查询写法可参考 [官网提供的 TPC-H 查询 SQL](https://github.com/oceanbase/obdeploy/tree/master/plugins/tpch/3.1.0/queries)，其中的 cpu_num 替换为本例查询并行度 96。

### 步骤六：加载数据

1. 将以下脚本保存为 `$WORK/load_data.sh`。连接信息和数据目录在执行时传入。

    ```bash
    #!/bin/bash
    set -euo pipefail
    set +x
    umask 077
    WORK="$(cd "$(dirname "$0")" && pwd)"
    host=
    port=2881
    user=
    database=
    data_path=
    while (($#)); do
        case "$1" in
            -h) host="${2:?请填写主机地址}"; shift 2 ;;
            -P) port="${2:?请填写端口}"; shift 2 ;;
            -u) user="${2:?请填写用户@租户}"; shift 2 ;;
            -D) database="${2:?请填写数据库名}"; shift 2 ;;
            --data-dir) data_path="${2:?请填写数据目录}"; shift 2 ;;
            *) echo "用法：bash load_data.sh -h 主机 [-P 2881] -u 用户@租户 -D 数据库 --data-dir 数据目录"; exit 2 ;;
        esac
    done
    [[ -n "$host" && -n "$user" && -n "$database" && -n "$data_path" ]] || {
        echo "请填写 -h、-u、-D 和 --data-dir"
        exit 2
    }
    [[ "$port" =~ ^[0-9]+$ ]] && ((10#$port >= 1 && 10#$port <= 65535)) || {
        echo "端口必须为 1 到 65535"
        exit 2
    }
    [[ "$data_path" == /* ]] || { echo "--data-dir 请填写绝对路径"; exit 2; }

    # 运行时输入密码，不将密码写入脚本或命令行。
    read -r -s -p "测试租户 root 密码: " password
    printf '\n'
    password="${password//\\/\\\\}"
    password="${password//\"/\\\"}"
    auth="$(printf '[client]\npassword="%s"\n' "$password")"
    unset password
    DB=(obclient --defaults-file=/dev/fd/3 -h "$host" -P "$port"
        -u "$user" -D "$database" -c --skip-reconnect)

    [[ "$data_path" != *"'"* && "$data_path" != *$'\n'* && "$data_path" != *$'\r'* ]] || {
        echo "数据路径不能包含单引号或换行"
        exit 2
    }
    shopt -s nullglob
    printf 'table\tparallel\tpattern\tload_sql_seconds\tstatus\n' > "$WORK/load_times.tsv"
    import_start=$(date +%s%N)

    function load_data
    {
        local table_name=$1 table=$1 pattern encoding_clause="" found=false
        local file output status load_start load_end seconds sql
        pattern="${table}[.]tbl([.][0-9]+)?"
        for file in "$data_path/"*; do
            if [[ -f "$file" && "${file##*/}" =~ ^${pattern}$ ]]; then found=true; break; fi
        done
        [[ "$found" == true ]] || { echo "缺少 $table_name 的数据文件"; exit 1; }
        sql="LOAD DATA /*+ parallel(32) direct(false,0) enable_parallel_dml */ FROM FILES(LOCATION='${data_path%/}/', FORMAT=(TYPE='CSV', FIELD_DELIMITER='|'${encoding_clause}, NULL_IF=('', 'NULL'), SKIP_BLANK_LINES=TRUE, IGNORE_LAST_EMPTY_COLUMN=TRUE), PATTERN='${pattern}') INTO TABLE ${table_name};"
        echo "正在导入 $table_name"
        load_start=$(date +%s%N)
        if output=$(printf '%s\n' "$sql" | "${DB[@]}" 3<<< "$auth" 2>&1); then status=0; else status=$?; fi
        load_end=$(date +%s%N)
        seconds=$(awk -v a="$load_start" -v b="$load_end" 'BEGIN {printf "%.6f",(b-a)/1000000000}')
        if [[ "$status" != 0 || "$output" == *"ERROR "* ]]; then
            printf '%s\t32\t%s\t%s\tfailed\n' "$table_name" "$pattern" "$seconds" >> "$WORK/load_times.tsv"
            printf '%s\n' "$output"
            exit 1
        fi
        printf '%s\t32\t%s\t%s\tsuccess\n' "$table_name" "$pattern" "$seconds" >> "$WORK/load_times.tsv"
    }

    for table in region nation supplier customer part partsupp orders lineitem; do
        load_data "$table"
    done
    import_end=$(date +%s%N)
    total=$(awk -F '\t' 'NR>1 && $5=="success"{s+=$4} END{printf "%.6f",s}' "$WORK/load_times.tsv")
    wall=$(awk -v a="$import_start" -v b="$import_end" 'BEGIN{printf "%.6f",(b-a)/1000000000}')
    printf 'metric\tseconds\nsuccessful_load_calls\t%s\nimport_wall\t%s\n' "$total" "$wall" > "$WORK/load_summary.tsv"
    printf '成功 LOAD 调用累计：%s 秒\n导入流程总耗时：%s 秒\n' "$total" "$wall"

    ```

4. 执行加载脚本，按提示输入密码；空密码直接回车。

    ```bash
    bash "$WORK/load_data.sh" \
        -h "$host_ip" -P "$host_port" -u "$user@$tenant" \
        -D tpch_bench --data-dir "$DATA_DIR"
    ```

脚本通过本机 CSV 文件导入，NULL_IF 将空字段解析为 NULL，IGNORE_LAST_EMPTY_COLUMN 处理末尾分隔符，不需要改写原始数据。`load_times.tsv` 保存逐表耗时和状态；`load_summary.tsv` 分别记录成功 LOAD 调用累计耗时及导入流程总耗时，不包含造数、合并和统计信息收集。失败调用单独记录，导入失败时停止。

### 步骤七：发起合并

使用测试租户的 root 账号连接测试库，准备发起合并。

```bash
obclient -h$host_ip -P$host_port -u$user@$tenant -p -D tpch_bench
```

先记录合并前的 FROZEN_SCN：

```sql
SELECT FROZEN_SCN, LAST_SCN FROM oceanbase.DBA_OB_MAJOR_COMPACTION;
```

然后发起本轮合并：

```sql
ALTER SYSTEM MAJOR FREEZE;
```

### 步骤八：等待合并完成

切换到 sys 租户查看合并进度，将下面 SQL 中的 `bench_tenant` 替换为实际测试租户名。

```bash
obclient -h$host_ip -P$host_port -uroot@sys -p -D oceanbase
```

```sql
SELECT t.TENANT_NAME, c.FROZEN_SCN, c.LAST_SCN
FROM oceanbase.DBA_OB_TENANTS t
JOIN oceanbase.CDB_OB_MAJOR_COMPACTION c
  ON t.TENANT_ID=c.TENANT_ID
WHERE t.TENANT_NAME='bench_tenant';
```

重复查询，直到 FROZEN_SCN 大于合并前记录的值，且 FROZEN_SCN 与 LAST_SCN 相等，再继续收集统计信息。若未返回测试租户的记录，需先检查租户名和合并状态。字段含义参见 [合并全局信息视图](../../700.reference/700.system-views/300.system-view-of-sys-tenant/200.dictionary-view-of-sys-tenant/20500.o-dba_ob_major_compaction-of-sys-tenant.md)。

### 步骤十：执行测试

Hot 和 Cold 共用以下脚本，使用前面生成并完成兼容修改的查询文件，按 Q1～Q22 的顺序执行。

将脚本保存为 `$WORK/run_test.sh`。连接信息在执行时传入；测试租户和 sys 租户的密码分别交互输入，空密码直接回车。

```bash
#!/usr/bin/env bash
# run_test.sh：使用 hot 或 cold 选择测试方式。
set -euo pipefail
set +x
umask 077
WORK="$(cd "$(dirname "$0")" && pwd)"

MODE="${1:-}"
case "$MODE" in
    hot|cold) shift ;;
    *) echo "用法：bash run_test.sh hot|cold -h 主机 [-P 2881] -u 用户@租户 -D 数据库 --allow-cache-reset"; exit 2 ;;
esac
DB_HOST=
DB_PORT=2881
DB_USER=
DB_NAME=
ALLOW_CACHE_RESET=false
while (($#)); do
    case "$1" in
        -h) DB_HOST="${2:?请填写主机地址}"; shift 2 ;;
        -P) DB_PORT="${2:?请填写端口}"; shift 2 ;;
        -u) DB_USER="${2:?请填写用户@租户}"; shift 2 ;;
        -D) DB_NAME="${2:?请填写数据库名}"; shift 2 ;;
        --allow-cache-reset) ALLOW_CACHE_RESET=true; shift ;;
        *) echo "支持的参数：-h、-P、-u、-D、--allow-cache-reset"; exit 2 ;;
    esac
done
[[ -n "$DB_HOST" && -n "$DB_USER" && -n "$DB_NAME" ]] || {
    echo "请填写 -h、-u 和 -D"
    exit 2
}
[[ "$DB_PORT" =~ ^[0-9]+$ ]] && ((10#$DB_PORT >= 1 && 10#$DB_PORT <= 65535)) || {
    echo "端口必须为 1 到 65535"
    exit 2
}
[[ "$ALLOW_CACHE_RESET" == true ]] || {
    echo "请添加 --allow-cache-reset 允许清理测试租户缓存"
    exit 1
}
QUERY_COUNT=22
SAVE_RESULTS=true
# 密码只经内存管道传给 OBClient，不写入文件或命令行。
read -r -s -p "测试租户 root 密码: " DB_PASSWORD
printf '\n'
DB_PASSWORD="${DB_PASSWORD//\\/\\\\}"
DB_PASSWORD="${DB_PASSWORD//\"/\\\"}"
DB_AUTH="$(printf '[client]\npassword="%s"\n' "$DB_PASSWORD")"
unset DB_PASSWORD

DB=(obclient --defaults-file=/dev/fd/3 -h "$DB_HOST" -P "$DB_PORT"
    -u "$DB_USER" -D "$DB_NAME" -c --default-character-set=utf8mb4
    -B -N -r --skip-reconnect)

for ((i = 1; i <= QUERY_COUNT; i++)); do
    printf -v name 'db%d.sql' "$i"
    [[ -s "$WORK/queries/$name" && ! -L "$WORK/queries/$name" ]] || {
        echo "缺少审核后的查询文件 $name"
        exit 1
    }
done
shopt -s nullglob
SQL_FILES=("$WORK/queries/"*.sql)
((${#SQL_FILES[@]} == QUERY_COUNT)) || {
    echo "查询文件数不正确"
    exit 1
}
# 文件数校验后重建数值顺序，避免 glob 把 Q10 放到 Q2 前面。
SQL_FILES=()
for ((i=1; i<=QUERY_COUNT; i++)); do
    printf -v name 'db%d.sql' "$i"
    SQL_FILES+=("$WORK/queries/$name")
done

read -r -s -p "sys 租户密码: " SYS_PASSWORD
printf '\n'
SYS_PASSWORD="${SYS_PASSWORD//\\/\\\\}"
SYS_PASSWORD="${SYS_PASSWORD//\"/\\\"}"
SYS_AUTH="$(printf '[client]\npassword="%s"\n' "$SYS_PASSWORD")"
unset SYS_PASSWORD

SYS=(obclient --defaults-file=/dev/fd/3 -h "$DB_HOST" -P "$DB_PORT"
    -u root@sys -D oceanbase --skip-reconnect)

# 从 DB_USER 提取测试租户名，缓存清理仅作用于该租户。
login="$DB_USER"
[[ "$login" =~ ^[A-Za-z0-9_]+@([A-Za-z0-9_]+)$ ]] || {
    echo "DB_USER 应为 user@tenant"
    exit 1
}
TENANT="${BASH_REMATCH[1]}"
[[ "${TENANT,,}" != sys ]] || {
    echo "不能清理 sys 业务缓存"
    exit 1
}
RESULT_DIR="$WORK/results/$MODE-$(date +%Y%m%d-%H%M%S)-$$"
mkdir -p "$RESULT_DIR/logs" "$RESULT_DIR/$MODE"
sha256sum "${SQL_FILES[@]}" > "$RESULT_DIR/query-sha256.txt"
CACHE_ACTIVE=0

sys_sql() {
    local statement="$1" current_err="$RESULT_DIR/logs/cache-current.err"
    if ! printf '%s\n' "$statement" | "${SYS[@]}" 3<<< "$SYS_AUTH" > /dev/null 2> "$current_err"; then
        cat "$current_err" >> "$RESULT_DIR/logs/cache.err"
        return 1
    fi
    cat "$current_err" >> "$RESULT_DIR/logs/cache.err"
    if grep -Eq '^ERROR([[:space:]]|:)' "$current_err"; then
        return 1
    fi
}

time_query() {
    local file="$1" phase="$2" sample="$3" name begin end output
    local begin_file end_file begin_command end_command
    name="${file##*/}"
    output=/dev/null
    [[ "$SAVE_RESULTS" != true ]] || output="$RESULT_DIR/$phase/$name.$sample.out"
    begin_file="$RESULT_DIR/logs/$phase-$name.$sample.begin"
    end_file="$RESULT_DIR/logs/$phase-$name.$sample.end"
    rm -f -- "$begin_file" "$end_file"
    printf -v begin_command 'date +%%s%%N > %q' "$begin_file"
    printf -v end_command 'date +%%s%%N > %q' "$end_file"
    # system 是 OBClient 的本地命令：连接后开始计时，查询返回后结束。
    {
        printf 'system %s\n' "$begin_command"
        cat "$file"
        printf '\nsystem %s\n' "$end_command"
    } | "${DB[@]}" --unbuffered 3<<< "$DB_AUTH" \
        > "$output" 2> "$RESULT_DIR/logs/$phase-$name.$sample.err"
    if grep -Eq '^ERROR([[:space:]]|:)' "$RESULT_DIR/logs/$phase-$name.$sample.err"; then
        return 1
    fi
    [[ -s "$begin_file" && -s "$end_file" ]] || {
        echo "查询计时未完成：$name"
        return 1
    }
    begin="$(cat "$begin_file")"
    end="$(cat "$end_file")"
    [[ "$begin" =~ ^[0-9]+$ && "$end" =~ ^[0-9]+$ ]] && ((end >= begin)) || {
        echo "查询时间戳无效：$name"
        return 1
    }
    QUERY_SECONDS="$(awk -v a="$begin" -v b="$end" 'BEGIN {printf "%.6f",(b-a)/1000000000}')"
}

clear_hot_caches() {
    # 仅清理指定测试租户；清理和等待不计入查询耗时。
    sys_sql "ALTER SYSTEM FLUSH PLAN CACHE TENANT='$TENANT' GLOBAL;"
    sleep 3
    sys_sql "ALTER SYSTEM FLUSH KVCACHE TENANT='$TENANT';
ALTER SYSTEM FLUSH KVCACHE TENANT='$TENANT' CACHE 'user_row_cache';"
    sleep 3
}

restore_cache() {
    local status="$?"
    trap - EXIT
    if ((CACHE_ACTIVE)); then
        if ! sys_sql "ALTER SYSTEM SET _local_cache_expiration_time='0s' TENANT='$TENANT';"; then
            echo "缓存参数恢复失败，请管理员手动核对。" >&2
            status=1
        fi
    fi
    exit "$status"
}
trap restore_cache EXIT
trap 'exit 130' INT
trap 'exit 143' TERM

if [[ "$MODE" == hot ]]; then
    mkdir -p "$RESULT_DIR/warmup"
    printf 'phase\tquery_file\tsample\tseconds\tused_in_hot_mean\n' > "$RESULT_DIR/hot-samples.tsv"
    printf 'query_file\tseconds\n' > "$RESULT_DIR/hot.tsv"
    sys_sql "ALTER SYSTEM SET _local_cache_expiration_time='0s' TENANT='$TENANT';"
    # 先完整预热一遍；预热不计入 Hot 成绩。
    clear_hot_caches
    for file in "${SQL_FILES[@]}"; do
        time_query "$file" warmup 1
        printf 'warmup\t%s\t1\t%s\tfalse\n' "${file##*/}" "$QUERY_SECONDS" >> "$RESULT_DIR/hot-samples.tsv"
    done
    # 正式 Hot 前只清 plan/KV/user_row cache，不清 Local Cache。
    clear_hot_caches
    for file in "${SQL_FILES[@]}"; do
        second=0
        third=0
        for sample in 1 2 3; do
            time_query "$file" hot "$sample"
            used=true
            [[ "$sample" != 1 ]] || used=false
            printf 'hot\t%s\t%s\t%s\t%s\n' "${file##*/}" "$sample" "$QUERY_SECONDS" "$used" >> "$RESULT_DIR/hot-samples.tsv"
            [[ "$sample" != 2 ]] || second="$QUERY_SECONDS"
            [[ "$sample" != 3 ]] || third="$QUERY_SECONDS"
        done
        average="$(awk -v a="$second" -v b="$third" 'BEGIN {printf "%.6f",(a+b)/2}')"
        printf '%s\t%s\n' "${file##*/}" "$average" >> "$RESULT_DIR/hot.tsv"
    done
else
    # Cold：每题清缓存并等待后执行查询。
    printf 'query_file\tseconds\n' > "$RESULT_DIR/cold.tsv"
    for file in "${SQL_FILES[@]}"; do
        name="${file##*/}"
        CACHE_ACTIVE=1
        # 所有清理命令均显式指定测试租户；清理和等待在计时前完成。
        sys_sql "ALTER SYSTEM SET _local_cache_expiration_time='1s' TENANT='$TENANT';
    ALTER SYSTEM FLUSH PLAN CACHE TENANT='$TENANT' GLOBAL;
    ALTER SYSTEM FLUSH KVCACHE TENANT='$TENANT';
    ALTER SYSTEM FLUSH KVCACHE TENANT='$TENANT' CACHE 'user_row_cache';"
        sleep 3
        flushed=false
        for attempt in 1 2 3; do
            if sys_sql "ALTER SYSTEM FLUSH LOCAL CACHE TENANT='$TENANT';"; then
                flushed=true
                break
            fi
            [[ "$attempt" == 3 ]] || sleep 5
        done
        [[ "$flushed" == true ]] || {
            echo "清缓存失败，停止测试"
            exit 1
        }
        sleep 5
        sys_sql "ALTER SYSTEM SET _local_cache_expiration_time='0s' TENANT='$TENANT';"
        CACHE_ACTIVE=0
        time_query "$file" cold 1
        seconds="$QUERY_SECONDS"
        printf '%s\t%s\n' "$name" "$seconds" >> "$RESULT_DIR/cold.tsv"
    done
fi

printf 'phase\ttotal_seconds\n' > "$RESULT_DIR/summary.tsv"
awk -F '\t' -v phase="$MODE" 'NR>1{s+=$2} END{printf "%s\t%.6f\n",phase,s}' \
    "$RESULT_DIR/$MODE.tsv" >> "$RESULT_DIR/summary.tsv"
printf 'complete\ttrue\nquery_files\t%s\n' "$QUERY_COUNT" > "$RESULT_DIR/status.tsv"
printf '%s 完成，结果目录：%s\n' "$MODE" "$RESULT_DIR"
cat "$RESULT_DIR/summary.tsv"
```

查询计时从连接建立后开始，包含 SQL 执行和结果接收，不包含清缓存和等待；多语句文件按完整文件计时。

#### Hot 测试

脚本先预热全部查询，再逐个查询连续执行 3 次，取第 2、3 次耗时的平均值。预热前和正式测试前清理 plan、KV 和 user row cache，保留 Local Cache。

```bash
set -o pipefail
bash "$WORK/run_test.sh" hot \
    -h "$host_ip" -P "$host_port" -u "$user@$tenant" \
    -D tpch_bench --allow-cache-reset | tee "$WORK/hot.log"
```

脚本结束后打印本次结果目录。其中，`hot.tsv` 为每个查询的平均耗时，`hot-samples.tsv` 为各次执行耗时，`summary.tsv` 为 Hot 总耗时，单位均为秒。查询返回值保存在该目录的 `warmup` 和 `hot` 子目录中。

#### Cold 测试

每个查询执行前清理 plan、KV、user row 和 Local Cache，然后执行一次查询。清理 Local Cache 时将过期时间设为 1s，清理后恢复为 0s；清缓存和等待时间不计入查询耗时。

```bash
set -o pipefail
bash "$WORK/run_test.sh" cold \
    -h "$host_ip" -P "$host_port" -u "$user@$tenant" \
    -D tpch_bench --allow-cache-reset | tee "$WORK/cold.log"
```

脚本结束后打印本次结果目录。其中，`cold.tsv` 为每个查询的耗时，`summary.tsv` 为 Cold 总耗时，单位均为秒。查询返回值保存在该目录的 `cold` 子目录中。
