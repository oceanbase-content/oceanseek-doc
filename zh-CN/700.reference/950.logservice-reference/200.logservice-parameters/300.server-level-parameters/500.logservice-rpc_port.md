# rpc_port

## 功能描述

节点 gRPC（RPC）服务监听端口，配合 local_ip 组成监听地址。

## 属性说明

| 属性 | 描述 |
| --- | --- |
| 参数类型 | u16 |
| 默认值 | 50051 |
| 取值范围 | 1–65535 |
| 生效模式 | readonly |
