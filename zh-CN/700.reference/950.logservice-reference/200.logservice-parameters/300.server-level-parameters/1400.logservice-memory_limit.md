# memory_limit

## 功能描述

进程内存使用上限；设为 0 时默认占用系统物理内存的 70%；不得超过系统物理内存总量。

## 属性说明

| 属性 | 描述 |
| --- | --- |
| 参数类型 | ReadableSize |
| 默认值 | 0MB |
| 取值范围 | 0 或正整数，支持 MB/GB 等单位 |
| 生效模式 | dynamic |
