# log_cache_evict_scan_budget

## 功能描述

LogCache 调优项，用于限制单次日志发布（publish）在缓存中扫描可复用空间的预算上限，以约束发布流程的尾延迟。当缓存空间不足且扫描预算耗尽时，本次发布直接放弃，不阻塞日志写入主流程。该配置项一般无需调整，保持默认值即可。

## 属性说明

| 属性 | 描述 |
| --- | --- |
| 参数类型 | u64 |
| 默认值 | 64 |
| 取值范围 | 正整数 |
| 生效模式 | static |
