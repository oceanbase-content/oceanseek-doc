# log_disk_size

## 功能描述

日志数据占用磁盘空间上限；设为 0 时改用 log_disk_percentage 决定配额。

## 属性说明

| 属性 | 描述 |
| --- | --- |
| 参数类型 | ReadableSize |
| 默认值 | 0GB |
| 取值范围 | 0 或正整数，支持 KB/MB/GB 等单位 |
| 生效模式 | dynamic |
