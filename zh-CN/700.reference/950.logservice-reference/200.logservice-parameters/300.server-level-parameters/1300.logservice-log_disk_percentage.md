# log_disk_percentage

## 功能描述

文件系统总空间中分配给日志的百分比；仅在 log_disk_size 为 0 时生效；取值必须在 1–99 之间，0 或 ≥100 会导致磁盘配额解析失败。

## 属性说明

| 属性 | 描述 |
| --- | --- |
| 参数类型 | u8 |
| 默认值 | 90 |
| 取值范围 | 1–99（0 及 ≥100 非法） |
| 生效模式 | dynamic |
