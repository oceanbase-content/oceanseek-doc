# log_cache_enable_write

## 功能描述

LogCache 写入开关，默认开启。设置为 `false` 后，缓存停止接收新的写入数据（已有缓存内容保留）；配合 `log_cache_enable_read=false` 使用，可在不重启节点的情况下将缓存退化为完全冷状态。适用于应急回滚或对比缓存开启前后的性能（baseline 对比）场景。

## 属性说明

| 属性 | 描述 |
| --- | --- |
| 参数类型 | bool |
| 默认值 | true |
| 取值范围 | true / false |
| 生效模式 | dynamic |
