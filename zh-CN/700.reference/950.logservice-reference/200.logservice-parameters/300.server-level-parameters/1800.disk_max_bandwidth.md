# disk_max_bandwidth

## 功能描述

磁盘最大带宽估计值，用于 I/O 限速计算。默认值为 `0`，表示未配置；配置为 `load_based` 均衡策略时，该配置项必须大于 0。

## 属性说明

| 属性 | 描述 |
| --- | --- |
| 参数类型 | ReadableSize |
| 默认值 | 0（表示未配置） |
| 取值范围 | 0 或正整数且大于 0，支持 KB/MB/GB 等单位 |
| 生效模式 | dynamic |
