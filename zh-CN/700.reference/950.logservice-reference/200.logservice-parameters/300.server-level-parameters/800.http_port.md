# http_port

## 功能描述

HTTP 状态/管理服务监听端口，配合 local_ip 组成监听地址；**必须为合法端口，非法时节点启动阶段即报错无法启动**。

## 属性说明

| 属性 | 描述 |
| --- | --- |
| 参数类型 | u16 |
| 默认值 | 50052 |
| 取值范围 | 1–65535 |
| 生效模式 | static |
