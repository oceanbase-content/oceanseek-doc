# log_cache_memory_percentage

## 功能描述

LogCache 容量占 memory_limit（为 0 时取系统总内存的 70%）的百分比；实际容量有 256 MB 下限；设为 0 时完全关闭 cache。

## 属性说明

| 属性 | 描述 |
| --- | --- |
| 参数类型 | u8 |
| 默认值 | 20 |
| 取值范围 | 0–100 |
| 生效模式 | static |
