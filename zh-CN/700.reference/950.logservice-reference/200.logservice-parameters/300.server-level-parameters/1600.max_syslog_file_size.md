# max_syslog_file_size

## 功能描述

单个日志文件（oblogservice.log）滚动的大小阈值，超过后切换到新文件。

## 属性说明

| 属性 | 描述 |
| --- | --- |
| 参数类型 | ReadableSize |
| 默认值 | 256MB |
| 取值范围 | 正整数，支持 KB/MB/GB 等单位 |
| 生效模式 | readonly |
