# log_cache_enable_read

## 功能描述

LogCache 读取开关，默认开启。设置为 `false` 后，日志上传与读取均直接访问磁盘，不再命中缓存，效果等同于未启用缓存。适用于应急回滚或对比缓存开启前后的性能（baseline 对比）场景。

## 属性说明

| 属性 | 描述 |
| --- | --- |
| 参数类型 | bool |
| 默认值 | true |
| 取值范围 | true / false |
| 生效模式 | dynamic |
