# log_cache_metrics_dump_interval_sec

## 功能描述

每节点输出 log_cache_metrics 监控日志的周期（秒）；0 关闭（默认，升级零行为变化）；设为如 10 可在验证期得到 hit_rate/hit_bytes/miss_bytes 等时间序列。

## 属性说明

| 属性 | 描述 |
| --- | --- |
| 参数类型 | u64 |
| 默认值 | 0（关闭） |
| 取值范围 | 无限制（0 表示关闭） |
| 生效模式 | dynamic |
