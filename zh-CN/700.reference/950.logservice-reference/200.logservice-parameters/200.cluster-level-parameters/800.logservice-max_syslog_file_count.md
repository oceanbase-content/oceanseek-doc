# max_syslog_file_count

## 功能描述

日志文件（oblogservice.log）滚动后保留的最大文件数；0 表示不限制。

## 属性说明

| 属性 | 描述 |
| --- | --- |
| 参数类型 | u64 |
| 默认值 | 200 |
| 取值范围 | 无限制（0 表示不限制） |
| 生效模式 | dynamic |
