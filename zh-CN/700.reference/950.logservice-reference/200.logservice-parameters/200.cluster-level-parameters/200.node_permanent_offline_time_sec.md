# node_permanent_offline_time_sec

## 功能描述

节点连续离线超过配置时长后被标记为永久下线。

## 属性说明

| 属性 | 描述 |
| --- | --- |
| 参数类型 | u64 |
| 默认值 | 1800（30 分钟） |
| 取值范围 | 无限制 |
| 生效模式 | dynamic |
