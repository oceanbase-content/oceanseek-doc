# log_disk_throttling_percentage

## 功能描述

日志盘渐进限速起始阈值，占日志盘总容量的百分比；当不可回收日志占用超过该阈值后进入限速。

## 属性说明

| 属性 | 描述 |
| --- | --- |
| 参数类型 | u16 |
| 默认值 | 70 |
| 取值范围 | 1–100；大于等于停写阈值时不产生渐进限速区间 |
| 生效模式 | dynamic |
