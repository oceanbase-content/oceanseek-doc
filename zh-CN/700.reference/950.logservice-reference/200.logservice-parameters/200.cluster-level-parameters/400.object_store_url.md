# object_store_url

## 功能描述

对象存储服务访问地址。仅支持 `s3://`（AWS S3 及兼容 S3 协议的对象存储）和 `azblob://`（Azure Blob）两种协议头，其它协议不支持。

## 属性说明

| 属性 | 描述 |
| --- | --- |
| 参数类型 | String |
| 默认值 | ""（空） |
| 取值范围 | 仅支持以 `s3://` 或 `azblob://` 开头的 URL 字符串 |
| 生效模式 | readonly |
