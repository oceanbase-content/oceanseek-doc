# rebuild_log_lag_threshold

## 功能描述

控制日志服务 Rebuild 自动触发的副本日志落后阈值。当 LM 广播的已上传 anchor LSN 与 LN 本地 `max_flushed_lsn` 的差值达到该阈值时，落后 LN 副本可以触发 Rebuild，从已上传 anchor 之后继续同步。配置值为 0 时关闭自动 Rebuild 触发。

## 属性说明

| 属性 | 描述 |
| --- | --- |
| 参数类型 | ReadableSize |
| 默认值 | 1048512KB（16 * (64MB-4KB)，16 个逻辑日志块，接近 1GB） |
| 取值范围 | 0 或正容量值，支持 B、KB、MB、GB、TB、PB 等单位 |
| 生效模式 | dynamic |
