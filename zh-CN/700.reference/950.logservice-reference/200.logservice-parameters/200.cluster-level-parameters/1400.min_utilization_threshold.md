# min_utilization_threshold

## 功能描述

日志流负载均衡中节点磁盘/资源利用率下限（百分比），低于时仅记录 UnderUtilized 资源事件用于观测，不触发迁移。

## 属性说明

| 属性 | 描述 |
| --- | --- |
| 参数类型 | u8 |
| 默认值 | 30 |
| 取值范围 | 0–100 |
| 生效模式 | dynamic |
