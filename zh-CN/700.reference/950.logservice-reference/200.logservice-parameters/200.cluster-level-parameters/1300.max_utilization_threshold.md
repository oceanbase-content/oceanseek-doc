# max_utilization_threshold

## 功能描述

日志流负载均衡中节点磁盘/资源利用率上限（百分比），超过时触发迁移。

## 属性说明

| 属性 | 描述 |
| --- | --- |
| 参数类型 | u8 |
| 默认值 | 60 |
| 取值范围 | 0–100 |
| 生效模式 | dynamic |
