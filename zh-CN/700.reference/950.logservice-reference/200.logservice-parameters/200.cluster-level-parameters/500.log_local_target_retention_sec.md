# log_local_target_retention_sec

## 功能描述

每个 stream 本地日志的目标保留时长（秒），尽力保证，高写入压力下可能缩短。

## 属性说明

| 属性 | 描述 |
| --- | --- |
| 参数类型 | u64 |
| 默认值 | 30 |
| 取值范围 | 无限制 |
| 生效模式 | dynamic |
