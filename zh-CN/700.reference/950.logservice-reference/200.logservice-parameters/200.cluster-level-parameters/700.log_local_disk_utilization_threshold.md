# log_local_disk_utilization_threshold

## 功能描述

本地磁盘使用率（百分比）阈值，超过时触发磁盘压力处理逻辑。

## 属性说明

| 属性 | 描述 |
| --- | --- |
| 参数类型 | u16 |
| 默认值 | 80 |
| 取值范围 | 0–100 |
| 生效模式 | dynamic |
