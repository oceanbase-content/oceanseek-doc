# load_balance_policy

## 功能描述

负载均衡策略。`load_based` 表示基于节点负载（磁盘使用率等）均衡，`replica_count_based` 表示基于副本数量均衡。

## 属性说明

| 属性 | 描述 |
| --- | --- |
| 参数类型 | String |
| 默认值 | "replica_count_based" |
| 取值范围 | load_based / replica_count_based |
| 生效模式 | dynamic |

## 使用说明

* `load_based`：使用基于集群负载的均衡策略。要求集群中所有节点的 `disk_max_bandwidth` 与 `disk_max_iops` 均已正确设置（非 0）。

  * 运行时尝试设置 `load_based` 时，若存在节点上述配置为 0，本次修改被拒绝，配置项值保持不变。
  * 运行期间节点配置缺失（如新接入节点未配置、配置被改成 0）时，集群自动按 `replica_count_based` 执行调度，并周期性以 ERROR 日志告警，提示补全节点配置；配置项展示值不变，仍为 `load_based`。缺失的配置被补全后，集群自动检测并切回 `load_based`，无需人工干预。
  * 当前版本不提供当前实际生效策略的查询接口或监控指标，可通过周期性 ERROR 日志告警感知降级状态。

* `replica_count_based`：使用基于日志流副本数量的均衡策略，不依赖节点 IO 容量配置。

* 配置变更立即生效，当前正在执行的均衡/调度任务按旧策略跑完，不中断；策略切换会触发一次常规调度评估，是否实际发起再均衡由调度器按新策略判断，不强制做全量再均衡。
