# min_oblogservice_version

## 功能描述

集群允许运行的最低 oblogservice 版本号；仅应由升级流程推高，不应手动回退。

## 属性说明

| 属性 | 描述 |
| --- | --- |
| 参数类型 | String |
| 默认值 | 当前构建版本 |
| 取值范围 | 合法的 x.y.z 版本字符串 |
| 生效模式 | dynamic |
