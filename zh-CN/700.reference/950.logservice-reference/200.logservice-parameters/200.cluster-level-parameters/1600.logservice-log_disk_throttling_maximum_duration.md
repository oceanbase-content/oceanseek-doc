# log_disk_throttling_maximum_duration

## 功能描述

日志盘渐进限速的最大延迟时长（毫秒）；设为 0 表示关闭渐进限速。

## 属性说明

| 属性 | 描述 |
| --- | --- |
| 参数类型 | u64 |
| 默认值 | 600000（10 分钟） |
| 取值范围 | 0–7200000（0 表示关闭，最大 2 小时） |
| 生效模式 | dynamic |
