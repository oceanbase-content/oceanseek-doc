# 日志服务配置项总览

本文根据日志服务（LogService）配置项的作用域，详细地罗列了 LogService 的集群级配置项和节点级配置项。

## 集群级配置项

| 配置项名称 | 功能描述 |
| --- | --- |
| [min_oblogservice_version](./200.cluster-level-parameters/100.min_oblogservice_version.md) | 集群允许运行的最低 oblogservice 版本号；仅应由升级流程推高，不应手动回退。 |
| [node_permanent_offline_time_sec](./200.cluster-level-parameters/200.node_permanent_offline_time_sec.md) | 节点连续离线超过设置时长后被标记为永久下线。 |
| [stream_replica_task_history_retention_sec](./200.cluster-level-parameters/300.stream_replica_task_history_retention_sec.md) | 日志流副本迁移/复制任务历史记录保留时长（秒）。 |
| [object_store_url](./200.cluster-level-parameters/400.object_store_url.md) | 对象存储服务访问地址。 |
| [log_local_target_retention_sec](./200.cluster-level-parameters/500.log_local_target_retention_sec.md) | 每个 stream 本地日志的目标保留时长（秒），尽力保证，磁盘压力下可能缩短。 |
| [retained_remote_log_blocks](./200.cluster-level-parameters/600.retained_remote_log_blocks.md) | 远端对象存储上保留的日志块数量。 |
| [log_local_disk_utilization_threshold](./200.cluster-level-parameters/700.log_local_disk_utilization_threshold.md) | 本地磁盘使用率（百分比）阈值，超过时触发磁盘压力处理逻辑。 |
| [max_syslog_file_count](./200.cluster-level-parameters/800.logservice-max_syslog_file_count.md) | 日志文件（oblogservice.log）滚动后保留的最大文件数；0 表示不限制。 |
| [enable_rebalance](./200.cluster-level-parameters/900.logservice-enable_rebalance.md) | 是否开启日志流负载均衡。 |
| [load_balance_policy](./200.cluster-level-parameters/1000.load_balance_policy.md) | 负载均衡策略；`load_based` 基于节点负载（磁盘使用率等）均衡，`replica_count_based` 基于副本数量均衡。 |
| [rebalance_interval_sec](./200.cluster-level-parameters/1100.rebalance_interval_sec.md) | 负载均衡触发间隔（秒）。 |
| [metric_sample_save_interval_sec](./200.cluster-level-parameters/1200.metric_sample_save_interval_sec.md) | 监控指标采样保存间隔（秒）。 |
| [max_utilization_threshold](./200.cluster-level-parameters/1300.max_utilization_threshold.md) | 日志流负载均衡中节点磁盘/资源利用率上限（百分比），超过时触发迁移。 |
| [min_utilization_threshold](./200.cluster-level-parameters/1400.min_utilization_threshold.md) | 日志流负载均衡中节点磁盘/资源利用率下限（百分比），低于时仅记录 UnderUtilized 资源事件用于观测，不触发迁移。 |
| [log_disk_throttling_percentage](./200.cluster-level-parameters/1500.logservice-log_disk_throttling_percentage.md) | 日志盘渐进限速起始阈值，占日志盘总容量的百分比；当不可回收日志占用超过该阈值后进入限速。 |
| [log_disk_throttling_maximum_duration](./200.cluster-level-parameters/1600.logservice-log_disk_throttling_maximum_duration.md) | 日志盘渐进限速的最大延迟时长（毫秒）；设为 0 表示关闭渐进限速。 |
| [rebuild_log_lag_threshold](./200.cluster-level-parameters/1700.rebuild_log_lag_threshold.md) | 控制日志服务 Rebuild 自动触发的副本日志落后阈值。 |

## 节点级配置项

| 配置项名 | 功能描述 |
| --- | --- |
| [cluster_id](./300.server-level-parameters/100.logservice-cluster_id.md) | 集群唯一标识。 |
| [region](./300.server-level-parameters/200.region.md) | 节点所在地域标识。 |
| [az](./300.server-level-parameters/300.az.md) | 节点所在可用区标识。 |
| [local_ip](./300.server-level-parameters/400.logservice-local_ip.md) | 节点对外监听的 IP 地址。 |
| [rpc_port](./300.server-level-parameters/500.logservice-rpc_port.md) | 节点 gRPC（RPC）服务监听端口，配合 local_ip 组成监听地址。 |
| [log_disk_size](./300.server-level-parameters/600.logservice-log_disk_size.md) | 日志数据占用磁盘空间上限；设为 0 时改用 log_disk_percentage 决定配额。 |
| [io_worker_count](./300.server-level-parameters/700.io_worker_count.md) | I/O 工作线程数量。 |
| [http_port](./300.server-level-parameters/800.http_port.md) | HTTP 状态/管理服务监听端口，配合 local_ip 组成监听地址；**必须为合法端口，非法时节点启动阶段即报错无法启动**。 |
| [status_thread_pool_size](./300.server-level-parameters/900.status_thread_pool_size.md) | HTTP 状态服务线程池大小。 |
| [stack_size](./300.server-level-parameters/1000.logservice-stack_size.md) | 工作线程栈大小。 |
| [net_thread_count](./300.server-level-parameters/1100.logservice-net_thread_count.md) | 网络 I/O 线程数；设为 0 时由运行时自动决定。 |
| [enable_heap_profile](./300.server-level-parameters/1200.enable_heap_profile.md) | 是否开启堆内存 profiling。 |
| [log_disk_percentage](./300.server-level-parameters/1300.logservice-log_disk_percentage.md) | 文件系统总空间中分配给日志的百分比；仅在 log_disk_size 为 0 时生效；取值必须在 1–99 之间，0 或 ≥100 会导致磁盘配额解析失败。 |
| [memory_limit](./300.server-level-parameters/1400.logservice-memory_limit.md) | 进程内存使用上限；设为 0 时默认占用系统物理内存的 70%；不得超过系统物理内存总量。 |
| [log_level](./300.server-level-parameters/1500.log_level.md) | 日志输出级别。 |
| [max_syslog_file_size](./300.server-level-parameters/1600.max_syslog_file_size.md) | 单个日志文件（oblogservice.log）滚动的大小阈值，超过后切换到新文件。 |
| [disk_max_iops](./300.server-level-parameters/1700.disk_max_iops.md) | 磁盘最大 IOPS 估计值，用于 I/O 限速计算；必须大于 0。 |
| [disk_max_bandwidth](./300.server-level-parameters/1800.disk_max_bandwidth.md) | 磁盘最大带宽估计值，用于 I/O 限速计算；必须大于 0。 |
| [upload_block_concurrency](./300.server-level-parameters/1900.upload_block_concurrency.md) | 上传日志块到对象存储的并发数。 |
| [log_cache_memory_percentage](./300.server-level-parameters/2000.log_cache_memory_percentage.md) | LogCache 容量占 memory_limit（为 0 时取系统总内存的 70%）的百分比；实际容量有 256 MB 下限；设为 0 时完全关闭 cache。 |
| [log_cache_evict_scan_budget](./300.server-level-parameters/2100.log_cache_evict_scan_budget.md) | 单次日志发布（publish）在缓存中扫描可复用空间的预算上限。 |
| [log_cache_enable_write](./300.server-level-parameters/2200.log_cache_enable_write.md) | LogCache 写入开关，默认开启。 |
| [log_cache_enable_read](./300.server-level-parameters/2300.log_cache_enable_read.md) | LogCache 读取开关，默认开启。 |
| [log_cache_metrics_dump_interval_sec](./300.server-level-parameters/2400.log_cache_metrics_dump_interval_sec.md) | 每节点输出 log_cache_metrics 监控日志的周期（秒）；0 关闭（默认，升级零行为变化）；设为如 10 可在验证期得到 hit_rate/hit_bytes/miss_bytes 等时间序列。 |
| [ln_id](./300.server-level-parameters/2500.ln_id.md) | 当前节点（LN）在集群中的数字编号，由部署系统写入。 |
| [local_storage_dir](./300.server-level-parameters/2600.local_storage_dir.md) | 节点本地数据目录路径。 |
