# LS-CTRL 概述

LS-CTRL（LogService Control）是日志服务（LogService）的命令行运维工具，通过 HTTP 与 LM/LN 节点通信，提供集群初始化、节点管理、状态查询、参数变更等能力。

## 命令列表

公开稳定命令如下：

| 命令 | 描述 |
| --- | --- |
| bootstrap | 初始化日志服务集群。 |
| show | 查询集群中的可用区（AZ）、日志节点（LN）、内部表、服务入口（AccessPoint）、参数及虚拟表等信息。 |
| add ln | 向指定 AZ 添加一个 LN 节点。 |
| delete ln | 从日志服务集群中删除指定 LN 节点。 |
| set param | 设置集群级或节点级参数。 |
| check | 对集群、指定 AZ 或指定 Stream 做健康检查。 |
| upgrade | 执行集群升级流程。 |
| fetch | 从对象存储拉取指定 Stream 的 clog 日志数据到本地。 |
| migrate replica | 将指定 Stream 的副本从源 LN 迁移到目标 LN。 |
| rotate-ak | 轮转对象存储的访问密钥（AK/SK）。 |
| param-version-status | 查询集群当前参数版本及各 LN 对该版本的同步状态。 |

各命令的详细语法、参数及示例，请参见对应命令文档。

## 工作方式

LS-CTRL 整体包含客户端和服务端两部分，交互方式如下：

- **客户端**：LS-CTRL 是客户端工具，通过 HTTP 与 LM/LN 节点通信。命令执行时，LS-CTRL 会自动将请求路由到 LM Leader 节点，由 Leader 节点完成实际操作。
- **服务端**：每个 LN 节点自身均启动一个 HTTP 服务端，响应 LS-CTRL 的管理请求。

## 命令结构

```shell
ls_ctrl -H <HOST_ADDRESS> <COMMAND>
```

其中：

- `-H, --host <HOST_ADDRESS>`：必选参数，用于指定日志服务任意节点的 HTTP 地址（带端口号的形式），例如 `127.0.0.1:8080`。该工具自动将请求转发至集群 Leader 节点，所以只需提供一个节点的 HTTP 地址即可。
- `<COMMAND>`：必选参数，用于指定具体的操作命令（例如 `add`、`delete`、`show` 等）。每个命令都可能有对应的子命令和选项，详见各命令文档。

## 通用参数

适用于所有子命令的通用参数如下：

| 参数 | 描述 | 默认值 |
| --- | --- | --- |
| `-H, --host <HOST_ADDRESS>` | 目标节点地址（host:port）。 | 无（必需） |
| `-p, --pretty` | JSON 输出 pretty-print。 | false |
| `-d, --debug` | 开启 debug 模式（更详细日志）。 | false |

## 输出格式

为方便外部工具消费，**无论成功还是失败**，命令的 stdout 恒为两部分：

1. 第一行：状态行（如 `200 OK`、`500 Internal Server Error`）。
2. 第二行：一个 JSON 对象或数组。

## 退出码

- `0`：成功。
- 非 0：失败（具体含义参考 stderr 输出）。
