# migrate replica

## 描述

该命令用于将指定 Stream 的副本从源 LN 迁移到目标 LN。

## 命令语法

```shell
ls_ctrl -H <HOST_ADDRESS> migrate replica <STREAM_ID> <SRC_LN> <DEST_LN>
```

## 参数解释

| 参数 | 描述 |
| --- | --- |
| `<STREAM_ID>` | 必填参数，目标 Stream 的 ID（u64）。 |
| `<SRC_LN>` | 必填参数，源 LN 的 id（u64）或地址（`host:port`）。 |
| `<DEST_LN>` | 必填参数，目标 LN 的 id（u64）或地址（`host:port`）。 |

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p><code>&lt;SRC_LN&gt;</code> 与 <code>&lt;DEST_LN&gt;</code> 须为同一种形式（均为 id 或均为地址），混用将报错。</p>
</main>

## 示例

### 使用 LN id

```shell
ls_ctrl -H 127.0.0.1:7891 migrate replica 4360635369 1 4
```

### 使用 LN 地址

```shell
ls_ctrl -H 127.0.0.1:7891 migrate replica 4360635369 127.0.0.1:7890 127.0.0.1:7898
```
