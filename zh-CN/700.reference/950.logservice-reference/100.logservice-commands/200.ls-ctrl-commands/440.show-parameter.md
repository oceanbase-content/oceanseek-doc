# show parameter

## 描述

该命令用于查询指定集群参数或节点本地参数值。

## 命令语法

```shell
ls_ctrl -H <HOST_ADDRESS> show parameter [--server-only] <NAME>
```

## 参数解释

| 参数 | 描述 |
| --- | --- |
| `--server-only` | 可选参数，若指定，则从 `-H` 所指向节点的本地配置读取，而非从 LM leader 读取集群参数。默认 false。 |
| `<NAME>` | 必填参数，参数名称。 |

## 示例

### 查询集群级参数

```shell
ls_ctrl -H <HOST_ADDRESS> show parameter node_permanent_offline_time_sec
```

### 查询节点本地参数

```shell
ls_ctrl -H <HOST_ADDRESS> show parameter log_level --server-only
```
