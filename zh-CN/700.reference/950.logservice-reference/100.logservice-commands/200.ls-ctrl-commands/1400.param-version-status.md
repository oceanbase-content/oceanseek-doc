# param-version-status

## 描述

该命令用于查询集群当前 `param_version`，以及各 LN 对该版本的同步（传播）状态。常用于 `rotate-ak` 等参数变更后，确认所有 LN 是否已拉取到最新版本。

## 命令语法

```shell
ls_ctrl -H <HOST_ADDRESS> param-version-status
```

## 参数解释

无。

## 输出

输出包含集群当前 `param_version`，以及每个 LN 的 id、最近上报的 `param_version`、最近一次心跳时间、地址、状态、上线/下线时间等信息。

## 示例

```shell
ls_ctrl -H 127.0.0.1:8080 param-version-status
```
