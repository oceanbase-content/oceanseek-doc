# show az

## 描述

该命令用于查看指定 AZ 或所有 AZ 的信息。

## 命令语法

```shell
ls_ctrl -H <HOST_ADDRESS> show az [<NAME>]
```

## 参数解释

| 参数 | 描述 |
| --- | --- |
| `<NAME>` | 可选参数，可用区的名称。未指定时获取所有可用区的信息；指定 AZ 名称时获取该指定可用区的信息。 |

## 示例

### 查询所有 AZ 的信息

```shell
./ls_ctrl -H 127.0.0.1:7891 show az
```

### 查询指定 AZ 的信息

```shell
./ls_ctrl -H 127.0.0.1:7891 show az AZ-1
```
