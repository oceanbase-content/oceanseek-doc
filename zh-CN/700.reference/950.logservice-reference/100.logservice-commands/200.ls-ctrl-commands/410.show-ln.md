# show ln

## 描述

该命令用于查看指定 LN 或所有 LN 的信息。

## 命令语法

```shell
ls_ctrl -H <HOST_ADDRESS> show ln [<NAME>]
```

## 参数解释

| 参数 | 描述 |
| --- | --- |
| `<NAME>` | 可选参数，LN 节点的名称。未指定时获取所有 LN 的信息；指定 LN 的名称（IP 地址或 LN_ID）时获取指定 LN 的详细信息。 |

## 示例

### 查询所有 LN 的信息

```shell
./ls_ctrl -H 127.0.0.1:7891 show ln
```

### 指定 IP 地址查询

```shell
./ls_ctrl -H 127.0.0.1:7891 show ln "127.0.0.1:7892"
```

### 指定 LN_ID 查询

```shell
./ls_ctrl -H 127.0.0.1:7891 show ln 2
```
