# delete ln

## 描述

该命令用于删除指定 LN 节点。

## 命令语法

```shell
ls_ctrl -H <HOST_ADDRESS> delete ln <LN>
```

## 参数解释

| 参数 | 描述 |
| --- | --- |
| `<LN>` | 必填参数，LN 的 id 或地址（`host:port`）。 |

## 示例

### 使用 LN 地址删除

```shell
./ls_ctrl -H 127.0.0.1:7891 delete ln "127.0.0.1:7892"
```

### 使用 LN_ID 删除

```shell
./ls_ctrl -H 127.0.0.1:7891 delete ln 3
```
