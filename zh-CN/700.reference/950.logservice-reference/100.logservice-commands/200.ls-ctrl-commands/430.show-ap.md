# show ap

## 描述

该命令用于查看所有 AccessPoint 信息。

## 命令语法

```shell
ls_ctrl -H <HOST_ADDRESS> show ap
```

## 参数解释

无。

## 示例

### 查询 AccessPoint 信息

```shell
./ls_ctrl -H 127.0.0.1:7891 show ap
```
