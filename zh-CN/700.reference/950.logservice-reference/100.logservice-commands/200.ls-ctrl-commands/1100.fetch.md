# fetch

## 描述

该命令用于从对象存储拉取指定 Stream 的 clog 日志数据到本地。

## 命令语法

```shell
ls_ctrl -H <HOST_ADDRESS> fetch --work-dir <WORK_DIR> --cluster-id <CLUSTER_ID> --tenant-id <TENANT_ID> --ls-id <LS_ID> [--point-type <POINT_TYPE>] --start-point <START_POINT> [--end-point <END_POINT>]
```

## 参数解释

| 参数 | 描述 |
| --- | --- |
| `--work-dir <WORK_DIR>` | 必填参数，存放拉取日志的工作目录，目录必须为空。 |
| `--cluster-id <CLUSTER_ID>` | 必填参数，Stream 所属的集群 ID。 |
| `--tenant-id <TENANT_ID>` | 必填参数，Stream 所属的租户 ID。 |
| `--ls-id <LS_ID>` | 必填参数，目标 Log Stream 的 ID。 |
| `--point-type <POINT_TYPE>` | 可选参数，日志起止点的类型，可选值为 `lsn` 或 `scn`。默认 `scn`。 |
| `--start-point <START_POINT>` | 必填参数，拉取日志的起始点。 |
| `--end-point <END_POINT>` | 可选参数，拉取日志的结束点。 |

## 示例

### 拉取日志

```shell
ls_ctrl -H 127.0.0.1:7891 fetch --work-dir ./clog --cluster-id 1 --tenant-id 1 --ls-id 1 --point-type lsn --start-point 100 --end-point 16384
```
