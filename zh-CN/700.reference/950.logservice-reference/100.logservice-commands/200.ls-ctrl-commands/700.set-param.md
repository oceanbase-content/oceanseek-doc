# set param

## 描述

该命令用于设置集群参数（默认）或当前节点本地参数（`--server-only`）。

## 命令语法

```shell
ls_ctrl -H <HOST_ADDRESS> set param [--server-only] <NAME> <VALUE>
```

## 参数解释

| 参数 | 描述 |
| --- | --- |
| `--server-only` | 可选参数，若指定，则仅对 `-H` 所指向的节点生效（server 级别）；否则对整个集群生效（cluster 级别）。默认 false。 |
| `<NAME>` | 必填参数，参数名称。 |
| `<VALUE>` | 必填参数，参数值。 |

## 示例

### 设置集群级参数

```shell
ls_ctrl -H <HOST_ADDRESS> set param <NAME> <VALUE>
```

### 设置节点本地参数

```shell
ls_ctrl -H <HOST_ADDRESS> set param --server-only <NAME> <VALUE>
```
