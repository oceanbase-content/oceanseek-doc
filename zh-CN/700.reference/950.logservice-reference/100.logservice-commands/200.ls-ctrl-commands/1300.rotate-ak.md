# rotate-ak

## 描述

该命令用于轮转对象存储的访问密钥（AK/SK）。

## 命令语法

```shell
ls_ctrl -H <HOST_ADDRESS> rotate-ak -i <ACCESS_KEY_ID> -k <ACCESS_KEY_SECRET>
```

## 参数解释

| 参数 | 描述 |
| --- | --- |
| `-i, --new-access-key-id <ID>` | 必填参数，新的 Access Key Id。 |
| `-k, --new-access-key-secret <SECRET>` | 必填参数，新的 Access Key Secret。 |

## 说明

轮转前 LM 会用新密钥对对象存储做一次探测校验，校验失败则拒绝轮转、不影响现有配置。

## 示例

```shell
ls_ctrl -H 127.0.0.1:8080 rotate-ak \
    -i LTAItestNewAccessKeyId \
    -k testNewAccessKeySecret
```
