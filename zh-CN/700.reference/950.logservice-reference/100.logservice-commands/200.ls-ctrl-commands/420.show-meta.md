# show meta

## 描述

该命令用于查看 MetaDB 内部表数据。

## 命令语法

```shell
ls_ctrl -H <HOST_ADDRESS> show meta [--table-name <TABLE_NAME>] [--force <FORCE>]
```

## 参数解释

| 参数 | 描述 |
| --- | --- |
| `--table-name <TABLE_NAME>` | 可选参数，指定要查询的内部表名。 |
| `--force <FORCE>` | 可选参数，跳过 proposal-id 一致性校验，直接读取本节点 MetaDB 副本（仅供诊断；开启后非 leader 节点也可响应）。默认 `false`，仅 leader 节点可响应。 |

## 示例

### 查询一级目录

```shell
./ls_ctrl -H 127.0.0.1:7891 show meta --table-name t_primary_dir
```

### 强制查询一级目录

```shell
./ls_ctrl -H 127.0.0.1:7891 show meta --table-name t_primary_dir --force true
```

当执行强制查询时，host 就是查询所在的节点，不会自动转发到 LM 的 Leader 上。

### 查询二级目录

```shell
./ls_ctrl -H 127.0.0.1:7891 show meta --table-name t_secondary_dir
```

### 查询 stream

```shell
./ls_ctrl -H 127.0.0.1:7891 show meta --table-name t_stream
```

### 查询所有表信息

```shell
./ls_ctrl -H 127.0.0.1:7891 show meta
```
