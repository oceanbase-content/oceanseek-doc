# add ln

## 描述

该命令用于向指定 AZ 添加一个 LN 节点。

## 命令语法

```shell
ls_ctrl -H <HOST_ADDRESS> add ln <LN> <AZ>
```

## 参数解释

| 参数 | 描述 |
| --- | --- |
| `<LN>` | 必填参数，新 LN 的地址（`host:port`）。 |
| `<AZ>` | 必填参数，目标 AZ 名称。 |

## 示例

### 新增节点到指定可用区

```shell
./ls_ctrl -H 127.0.0.1:7891 add ln "127.0.0.1:7896" AZ-1
```
