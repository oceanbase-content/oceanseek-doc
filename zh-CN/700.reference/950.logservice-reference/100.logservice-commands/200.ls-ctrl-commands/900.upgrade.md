# upgrade

## 描述

该命令用于执行集群升级流程。

## 命令语法

```shell
ls_ctrl -H <HOST_ADDRESS> upgrade begin
ls_ctrl -H <HOST_ADDRESS> upgrade finish <TARGET_VERSION>
```

## 参数解释

| 参数 | 描述 |
| --- | --- |
| `begin` | 开始升级流程。 |
| `finish <TARGET_VERSION>` | 完成升级流程，`<TARGET_VERSION>` 为目标版本号。 |

## 示例

### 升级前准备

```shell
./ls_ctrl -H 127.0.0.1:7891 upgrade begin
```

### 升级后处理

```shell
./ls_ctrl -H 127.0.0.1:7891 upgrade finish 1.0.0
```
