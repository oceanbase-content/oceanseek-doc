# 日志服务视图概述

日志服务（LogService）提供两类视图用于查询集群的运行状态和元数据信息：**虚拟视图**和**内部表**。

## 虚拟视图

虚拟视图是基于日志服务节点内存结构构建的虚拟表，用于显示集群的实时性能统计信息和监控信息，包括节点负载、可用区负载和日志流副本 IO 统计。虚拟视图是只读的，不能对其进行修改或删除。

通过 `show v-table` 命令查询虚拟视图：

```shell
ls_ctrl -H <HOST_ADDRESS> show v-table <VTABLE_TYPE>
```

其中 `<VTABLE_TYPE>` 为虚拟视图类型，支持 `node_load`、`az_load`、`stream_replica_io` 三种。

## 内部表

内部表是日志服务 MetaDB 中持久化的数据表，用于存储日志服务集群的元数据信息和系统状态信息，包括节点信息、日志流副本信息、迁移任务记录等。内部表通过 `show meta` 命令查询，是只读的。

通过 `show meta` 命令查询内部表：

```shell
ls_ctrl -H <HOST_ADDRESS> show meta --table-name <TABLE_NAME>
```

其中 `--table-name` 指定要查询的内部表名称。不指定 `--table-name` 时，列出所有可查询的内部表。
