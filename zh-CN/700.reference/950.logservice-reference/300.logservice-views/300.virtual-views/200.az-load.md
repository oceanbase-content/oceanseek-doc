# az_load

该虚拟视图从 oblogservice 1.1.1 版本开始提供。

## 功能描述

展示每个可用区（AZ）的 IOPS 和带宽使用情况。

## 字段说明

| **字段名称** | **类型** | **是否可以为 NULL** | **描述** |
| --- | --- | --- | --- |
| az | String | NO | 可用区名称，可用区的唯一标识（主键）。 |
| bps_used | f64 | NO | 已使用的带宽（字节/秒），该 AZ 下所有节点的带宽使用总和。 |
| iops_used | f64 | NO | 已使用的 IOPS，该 AZ 下所有节点的 IOPS 使用总和。 |
| bps_capacity | f64 | NO | 带宽容量（字节/秒），该 AZ 下所有节点的带宽容量总和。 |
| iops_capacity | f64 | NO | IOPS 容量，该 AZ 下所有节点的 IOPS 容量总和。 |
| bps_utilization | f64 | NO | 带宽利用率（0.0-1.0）。 |
| iops_utilization | f64 | NO | IOPS 利用率（0.0-1.0）。 |

## 查询示例

查询所有可用区的负载信息：

```shell
ls_ctrl -H <HOST_ADDRESS> show v-table az_load
