# stream_replica_io

该虚拟视图从 oblogservice 1.1.1 版本开始提供。

## 功能描述

展示每个日志流副本的 IO 统计信息，包括 IO 类型、副本类型、带宽和 IOPS。

## 字段说明

| **字段名称** | **类型** | **是否可以为 NULL** | **描述** |
| --- | --- | --- | --- |
| stream_id | u64 | NO | 日志流 ID，流的唯一标识（主键）。 |
| ln_id | u64 | NO | 日志节点 ID，节点的唯一标识（主键）。 |
| io_type | DiskIOType | NO | IO 类型（主键），枚举值：Pread、ReceiveLog、ReceiveAcceptorLog、WriteBlockHeader、FetchedLog、UploadLog、WriteMeta、ReadMeta、Other。 |
| replica_type | String | NO | 副本类型，枚举值：normal（正常副本）、creating（创建中）、migrating_out（迁出中）、migrating_in（迁入中）。 |
| bps | f64 | NO | 带宽（字节/秒）。 |
| iops | f64 | NO | IOPS。 |

## 查询示例

查询所有日志流副本的 IO 统计信息：

```shell
ls_ctrl -H <HOST_ADDRESS> show v-table stream_replica_io
