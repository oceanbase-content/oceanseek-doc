# node_load

该虚拟视图从 oblogservice 1.1.1 版本开始提供。

## 功能描述

展示每个日志服务节点（LN）的 IOPS 和带宽使用情况。

## 字段说明

| **字段名称** | **类型** | **是否可以为 NULL** | **描述** |
| --- | --- | --- | --- |
| ln_id | u64 | NO | 日志节点 ID，节点的唯一标识（主键）。 |
| az | String | NO | 可用区名称。 |
| bps_used | f64 | NO | 已使用的带宽（字节/秒）。 |
| iops_used | f64 | NO | 已使用的 IOPS。 |
| bps_capacity | f64 | NO | 带宽容量（字节/秒）。 |
| iops_capacity | f64 | NO | IOPS 容量。 |
| bps_utilization | f64 | NO | 带宽利用率（0.0-1.0）。 |
| iops_utilization | f64 | NO | IOPS 利用率（0.0-1.0）。 |

## 查询示例

查询所有日志服务节点的负载信息：

```shell
ls_ctrl -H <HOST_ADDRESS> show v-table node_load
