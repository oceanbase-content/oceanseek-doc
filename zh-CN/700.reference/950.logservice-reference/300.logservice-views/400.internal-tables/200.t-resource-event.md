# t_resource_event

该内部表从 oblogservice 1.1.1 版本开始提供。

## 功能描述

记录集群的资源事件告警。当集群的资源使用率大于或小于特定阈值时，日志服务产生资源事件告警，表示某些资源负载过高或过低。集群管理员可以通过轮询该内部表来订阅资源事件告警，辅助判断集群是否需要扩容或缩容。

## 字段说明

| **字段名称** | **类型** | **是否可以为 NULL** | **描述** |
| --- | --- | --- | --- |
| resource_type | u32 | NO | 资源类型（主键），枚举值：0=IOPS、1=BPS（带宽）。 |
| az | String | NO | 可用区名称（主键），如 `az1`、`az2` 或 `ALL_AZ`（表示所有 AZ）。 |
| ln | u64 | NO | 日志节点 ID（主键），0 表示 AZ 级别的事件（非节点级别）。 |
| event | u32 | NO | 事件类型，枚举值：0=OverUtilized（资源过载）、1=UnderUtilized（资源低载）。 |
| utilization_rate | u32 | NO | 资源利用率（百分比，0-100），例如 80 表示 80%。 |
| comment | String | NO | 事件说明，描述事件的原因或详细信息。 |
| start_time | i64 | NO | 事件开始时间（微秒时间戳）。 |

ls_ctrl -H <HOST_ADDRESS> show meta --table-name t_resource_event
