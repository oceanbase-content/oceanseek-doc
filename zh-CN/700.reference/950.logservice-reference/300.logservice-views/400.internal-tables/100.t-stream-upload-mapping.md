# t_stream_upload_mapping

该内部表从 oblogservice 1.1.1 版本开始提供。

## 功能描述

记录日志流与上传节点的映射关系。日志服务根据日志流副本的 IO 负载，为没有有效上传节点的日志流分配新的上传节点，并将映射关系持久化到该内部表。

## 字段说明

| **字段名称** | **类型** | **是否可以为 NULL** | **描述** |
| --- | --- | --- | --- |
| stream_id | u64 | NO | 日志流 ID，流的唯一标识（主键）。 |
| create_time | i64 | NO | 创建时间（微秒时间戳）。 |
| modify_time | i64 | NO | 修改时间（微秒时间戳）。 |
| ln_id | u64 | NO | 上传节点 ID，负责该流上传任务的日志节点 ID。 |
| generator_module | u32 | NO | 生成模块，枚举值：0=UploadService（上传服务）、1=LoadBalancer（负载均衡器）、2=DisasterRecovery（容灾服务）。 |

## 查询示例

查询日志流与上传节点的映射关系：

```shell
ls_ctrl -H <HOST_ADDRESS> show meta --table-name t_stream_upload_mapping
