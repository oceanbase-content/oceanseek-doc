# DDL 功能概述

OceanBase AI 数据库的 DDL 功能用于数据库对象的变更。

OceanBase AI 数据库所支持的 DDL 功能如下：

* 索引操作
* 主键操作
* 列操作
* 生成列操作
* 外键操作
* 表操作
* 分区操作
