# 伪列概述

伪列（Pseudocolumn）的行为与表中的列相同，但并未存储具体数值。因此，伪列只具备读属性，您不可以对伪列进行插入、更新、删除的等行为。本章节主要介绍 OceanSeek 当前版本所支持的伪列及使用说明。

OceanSeek 支持如下伪列类型：

* [PARTITIONID 伪列](200.partititionid-pseudo-column-of-mysql-mode.md)
* [序列伪列](300.sequence-pseudo-column-of-mysql-mode.md)
