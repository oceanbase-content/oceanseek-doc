# ALTER POLICY

## 描述

该语句用于修改已存在的行级权限（Row-Level Security，RLS）策略，包括角色列表、`USING` / `WITH CHECK` 表达式，以及策略重命名。

## 权限要求

执行 `ALTER POLICY` 语句，需要当前用户对目标表拥有对象级 `ALTER` 权限。库级或全局 `ALTER` 若已覆盖该表，同样满足要求。更多说明请参见 [权限分类](../../../../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/100.permission-classification-of-mysql.md)。

## 使用限制及注意事项

* 不能通过 `ALTER POLICY` 修改 `AS PERMISSIVE/RESTRICTIVE` 或 `FOR` 类型。需要改变这些属性时，应删除并重建策略。
* 一次 `ALTER POLICY` 可以同时修改角色列表、`USING` 和 `WITH CHECK`。未指定的属性保持不变。
* 策略修改后，已连接的业务会话无需重连，后续 SQL 会使用新策略。

## 语法

```sql
-- 修改策略属性
ALTER POLICY policy_name ON [schema_name.]table_name
    [TO role_name [, role_name ...]]
    [USING (using_expression)]
    [WITH CHECK (check_expression)];

-- 重命名策略
ALTER POLICY policy_name ON [schema_name.]table_name
    RENAME TO new_policy_name;
```

## 参数说明

| **参数** | **说明** |
| --- | --- |
| policy_name | 待修改的策略名。 |
| table_name | 策略所属对象名。可使用 `database_name.table_name` 显式指定数据库。 |
| TO | 修改适用角色列表。省略或 `PUBLIC` 表示所有用户。 |
| USING | 行可见性过滤表达式（读、更新旧行、删除）。 |
| WITH CHECK | 写操作新行校验表达式（插入、更新后的新行）。 |
| RENAME TO | 将策略重命名为 `new_policy_name`。 |

说明及限制如下：

* 修改属性时，`TO`、`USING`、`WITH CHECK` 三个子句均为可选，但至少需指定其中一项。
* `TO` 指定的角色列表会替换现有绑定（覆盖而非追加）。使用 `TO PUBLIC` 可将角色策略改为对所有用户生效。
* `TO` 指定角色列表时，当前会话须激活列表中任意一个角色；只能填写已存在的角色名。
* 修改 `USING` / `WITH CHECK` 时，遵循与 [CREATE POLICY](2320.create-policy-of-mysql-mode.md) 相同的子句合法性规则（例如 `FOR SELECT` 策略不允许 `WITH CHECK`）。
* `USING` / `WITH CHECK` 结果须为布尔类型；列引用、函数与表达式限制与 [CREATE POLICY](2320.create-policy-of-mysql-mode.md) 相同。
* 若省略 `WITH CHECK` 且已有 `USING`，则写入校验等于 `USING`。
* 若新行不满足 `WITH CHECK`，写操作报错 `OB_ERR_POLICY_WITH_CHECK_OPTION_VIOLATION`。
* 重命名后的策略名在同一表内须唯一；不同表可使用相同策略名。

## 示例

以下示例仅供参考，实际使用时请根据实际情况进行调整：

```sql
-- 将策略改为对所有用户生效
ALTER POLICY emp_dept_policy ON hr.employees TO PUBLIC;

-- 同时修改角色与表达式
ALTER POLICY emp_dept_policy ON hr.employees
    TO manager
    USING (dept_id = GET_MY_DEPT())
    WITH CHECK (dept_id = GET_MY_DEPT());

-- 重命名策略
ALTER POLICY emp_dept_policy ON hr.employees RENAME TO emp_dept_rls;
```
