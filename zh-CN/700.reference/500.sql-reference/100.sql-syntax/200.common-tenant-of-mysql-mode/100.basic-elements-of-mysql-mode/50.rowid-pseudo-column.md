# ROWID 伪列

ROWID 伪列提供了快速定位表中某一行的能力，ROWID 值不会进行实际的存储。本文主要介绍 ROWID 伪列的使用说明。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>OceanSeek 从 V4.6.3 版本开始支持查询 ROWID 伪列，并通过 ROWID 定位更新、删除数据。该能力为 OceanSeek 的扩展能力。</p>
</main>

## 概述

对于数据库中的每一行，ROWID 伪列返回标识该行的编码值，ROWID 值通过 Base64 编码转换而成，数据类型为 `VARCHAR`。ROWID 值的编码来源由表形态决定：

* 有主键的表：ROWID 值由表的主键（分区表包含分区键）编码得到，只要主键不变，ROWID 值就不会改变。
* 无主键的堆表：ROWID 值由行所在 Tablet 的编号和隐藏自增列值编码得到。

ROWID 值有如下重要用途：

* 是访问单行的最快方式，可以在 `UPDATE`/`DELETE` 语句的 `WHERE` 子句中通过 `ROWID = ?` 定位单行。
* 作为表中行的唯一标识符。

使用 ROWID 值需要特别注意以下事项：

* 通常，ROWID 值唯一标识数据库中的一行。但是，存储在同一集群中的不同表中的行可以具有相同的 ROWID。
* 不能使用 ROWID 作为表的主键。
* 虽然可以在查询的 `SELECT` 和 `WHERE` 子句中使用 ROWID 伪列，但是因为这些伪列值实际上并未存储在数据库中，所以不能插入、更新或删除 ROWID 值。

ROWID 值以 Base64 编码的 `VARCHAR` 字符串形式返回：有主键的表返回的 ROWID 值以 `*` 开头；无主键的堆表返回的 ROWID 值不带 `*` 前缀。应用程序可以通过 `ResultSet.getString()` 读取 ROWID 值并保存，后续将 ROWID 字符串作为参数原样回传，用于定位更新或删除对应的行。

## 支持场景

### 查询表

在 `SELECT` 语句中查询 ROWID 伪列，支持为 ROWID 指定列别名：

```sql
SELECT ROWID AS __ds_rowid, c1, c2
FROM t
WHERE ...;
```

也允许使用表别名限定 ROWID，此时 ROWID 绑定到对应的基础表：

```sql
SELECT t.ROWID AS __ds_rowid, t.c1, t.c2
FROM t;
```

多表查询中，使用表别名限定的 ROWID 分别绑定对应基础表：

```sql
SELECT t1.ROWID, t2.ROWID, t1.c1, t2.c2
FROM t1
JOIN t2 ON t1.id = t2.id;
```

### 查询视图

对于视图，可以查询基础表为单表查询的视图的 ROWID，视图的 ROWID 即其基础表的 ROWID：

```sql
CREATE VIEW v AS
SELECT c1, c2
FROM t
WHERE c1 > 10;

SELECT v.ROWID, v.c1
FROM v;
```

### 通过 ROWID 定位更新、删除数据

在 `UPDATE`/`DELETE` 语句的 `WHERE` 子句中，通过 ROWID 值定位单行进行更新或删除：

```sql
UPDATE t
SET c2 = ?
WHERE ROWID = ?;
```

```sql
DELETE FROM t
WHERE ROWID = ?;
```

## 名称解析规则

`rowid` 不是保留字，用户可以为表定义名为 `rowid` 的真实列。因此，ROWID 的名称解析会遵循“真实列优先、伪列兜底”的规则：

* 若语句中引用的标识符（`rowid`、`ROWID`、`RowId` 等任意大小写形式）对应表中已存在同名的真实列，则解析为该普通列。
* 仅当表中不存在同名真实列时，该标识符才解析为对应基础表的 ROWID 伪列。

## 使用限制

* 多目标表 `UPDATE`（一条语句同时更新多张表）中使用 ROWID 暂不支持。
* 外表不支持通过 ROWID 进行查询。

## 使用示例

1. 从表 `t1` 中查询 ROWID 值。

   ```sql
   obclient> CREATE TABLE t1 (c1 INT PRIMARY KEY, c2 VARCHAR(20));
   Query OK, 0 rows affected

   obclient> INSERT INTO t1 VALUES (1, 'a'), (2, 'b');
   Query OK, 2 rows affected

   obclient> SELECT ROWID, c1, c2 FROM t1 WHERE c1 = 1;
   +--------------+----+------+
   | ROWID        | c1 | c2   |
   +--------------+----+------+
   | *AAEEAQAAAA== |  1 | a    |
   +--------------+----+------+
   1 row in set
   ```

2. 从无主键堆表 `t2` 中查询 ROWID 值。

   ```sql
   obclient> CREATE TABLE t2 (c1 INT, c2 VARCHAR(20)) ORGANIZATION = HEAP;
   Query OK, 0 rows affected

   obclient> INSERT INTO t2 VALUES (1, 'x');
   Query OK, 1 row affected

   obclient> SELECT ROWID, c1, c2 FROM t2 WHERE c1 = 1;
   +--------------------------+----+------+
   | ROWID                    | c1 | c2   |
   +--------------------------+----+------+
   | sAAAAAAABAEAAAAAAAAAAQ== |  1 | x    |
   +--------------------------+----+------+
   1 row in set
   ```

3. 使用 ROWID 值进行 `UPDATE` 操作。将之前查询得到的 ROWID 字符串作为条件回传即可。

   ```sql
   obclient> UPDATE t1 SET c2 = 'c' WHERE ROWID = '*AAEEAQAAAA==';
   Query OK, 1 row affected
   ```

4. 使用 ROWID 值进行 `DELETE` 操作。

   ```sql
   obclient> DELETE FROM t2 WHERE ROWID = 'sAAAAAAABAEAAAAAAAAAAQ==';
   Query OK, 1 row affected
   ```
