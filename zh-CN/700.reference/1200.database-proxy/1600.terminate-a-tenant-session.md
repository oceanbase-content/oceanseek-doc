# 终止租户会话

OceanSeek 支持通过 `KILL` 语句终止会话。

终止会话的 SQL 语句如下：

```sql
KILL [CONNECTION] 'session_id';
```

语句使用说明：

* `KILL` 语句每次只能终止一个会话。

* 普通用户如果拥有 `PROCESS` 权限，则可以查看所有会话。如果拥有 `SUPER` 权限，则可以逐一终止所有会话和语句。否则，普通用户只能查看和终止您自己的会话和语句。租户管理员可以逐一终止所有会话和语句。

  查看权限的相关操作，参见 [查看用户权限](../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/400.view-user-permissions-of-mysql-mode.md)。如果您没有所需的权限，请联系管理员为您添加，为用户添加权限的相关操作，参见 [直接授予权限](../../600.manage/500.security-and-permissions/300.access-control/200.user-and-permission/200.permission-of-mysql-mode/200.authority-of-mysql-mode.md)。

终止指定的会话的示例如下：

```sql
KILL session_id;
```

或者

```sql
KILL CONNECTION session_id;
```

其中，`session_id` 即会话 ID，可通过 `SHOW PROCESSLIST` 语句或 `SHOW FULL PROCESSLIST` 语句获取。获取会话 ID 的详细操作及说明，请参见 [查看租户会话](1500.view-tenant-sessions.md)。

更多 `KILL` 语句的使用和说明，请参见 [KILL](../500.sql-reference/100.sql-syntax/200.common-tenant-of-mysql-mode/600.sql-statement-of-mysql-mode/5800.kill-of-mysql-mode.md)。
