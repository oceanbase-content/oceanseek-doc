# 查看 AI 模型信息

本文档介绍如何通过视图查看 AI 模型的相关信息。

## 查看厂商/模型参数/网关信息（新接口）

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>本节所有视图从 V4.6.2.1 开始支持。</p>
</main>

OceanBase AI 数据库支持通过视图查看已注册的厂商配置、模型参数和网关信息，具体请参见：

| 视图 | 描述 |
| --- | --- |
| [CDB/DBA_OB_AI_MODEL_PROVIDERS](../700.system-views/400.system-view-of-mysql-mode/200.dictionary-view-of-mysql-mode/5714.o-dba_ob_ai_model_providers-of-mysql-mode.md) | 查看已注册的厂商配置信息。 |
| [CDB/DBA_OB_AI_MODEL_PROFILES](../700.system-views/400.system-view-of-mysql-mode/200.dictionary-view-of-mysql-mode/5713.o-dba_ob_ai_model_profiles-of-mysql-mode.md) | 查看已注册的模型参数信息。 |
| [CDB/DBA_OB_AI_GATEWAYS](../700.system-views/400.system-view-of-mysql-mode/200.dictionary-view-of-mysql-mode/5705.o-dba_ob_ai_gateways-of-mysql-mode.md) | 查看已注册的网关信息。 |
| [CDB/DBA_OB_AI_GATEWAY_ENDPOINTS](../700.system-views/400.system-view-of-mysql-mode/200.dictionary-view-of-mysql-mode/5704.o-dba_ob_ai_gateway_endpoint-of-mysql-mode.md) | 查看已注册的网关端点信息。 |
