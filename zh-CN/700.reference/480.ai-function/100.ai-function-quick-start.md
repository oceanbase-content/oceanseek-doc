# AI 函数服务快速上手

本文面向首次使用 AI 函数服务的用户，通过最少步骤完成模型注册并运行第一个示例，帮助您快速跑通流程。

本文仅使用 `AI_COMPLETE` 函数介绍快速上手流程，其他函数请参考 [AI 函数服务语法及示例](300.ai-function.md)。

<main id="notice" type='explain'>
<h4>说明</h4>
<p>本文档使用新接口 <code>REGISTER_PROVIDER</code> 进行模型注册，从 V4.6.2.1 版本开始支持。旧接口 <code>CREATE_AI_MODEL</code> 等 PL 系统包子程序完整保留，存量用法可继续工作。</p>
</main>

## 前提条件

* 已部署 OceanBase AI 数据库并创建用户租户，且已连接到数据库。
* 已具备 AI 函数相关权限。详见 [AI 函数服务权限](150.ai-function-permission.md)。
* 已获取第三方模型服务的 API Key。

## 快速上手

### 步骤一：注册厂商配置

在首次使用前，需先注册厂商配置。本示例使用内置厂商 `aliyun`，只需填写 `access_key`，`protocol` 与 `base_url` 可省略，系统会自动填充默认值。请将 `access_key` 替换为实际的 API Key：

```sql
-- 本示例使用的是文本生成模型的 API Key
CALL DBMS_AI_SERVICE.REGISTER_PROVIDER('aliyun', '{
  "access_key": "sk-xxxx"
}');
```

更多厂商配置方式请参见文末相关文档。

### 步骤二：（可选）配置模型参数

如需为特定模型设置调用参数，可使用 `ALTER_MODEL_PROFILE`：

```sql
CALL DBMS_AI_SERVICE.ALTER_MODEL_PROFILE('aliyun/qwen-plus', '{
  "model_config": {
    "max_tokens": 4096,
    "temperature": 0
  }
}');
```

### 步骤三：运行示例

使用 `provider/model` 格式调用 `AI_COMPLETE`，对一段文本做情感判断：

```sql
SELECT AI_COMPLETE('aliyun/qwen-plus', AI_PROMPT('你的任务是对提供的文本进行情感分析，判断其情感倾向为正面还是负面。
    以下是需要分析的文本：
    <text>
    {0}
    </text>
    判断标准如下：
    如果文本表达的是正面情感，输出 1；如果文本表达的是负面情感，输出 -1。不要输出其他东西。', '天气真好啊')) AS sentiment;
```

预期返回结果中 `sentiment` 为 `1`，表示正面情感。

### 步骤四：（可选）使用网关（Gateway）路由

如需在多个模型端点间做加权路由与容灾，可创建 AI 网关，同时配置端点权重与熔断参数：

```sql
CALL DBMS_AI_SERVICE.CREATE_AI_GATEWAY('prod_gateway', '{
  "endpoints": [
    {"name":"ep1","model":"aliyun/qwen-plus","weight":70},
    {"name":"ep2","model":"deepseek/deepseek-chat","weight":30}
  ],
  "circuit_breaker": {
    "failure_rate_threshold": 50,
    "window_size_seconds": 60,
    "minimum_requests": 10,
    "break_duration_seconds": 60,
    "probe_requests": 3
  }
}');
```

创建后，可通过 Gateway 名称调用 AI 函数。Gateway 语法说明请参见 [CREATE_AI_GATEWAY](../600.pl-reference/1000.pl-system-package-mysql/1000.dbms-ai-service-mysql/1200.create-ai-gateway-mysql.md)。

### 步骤五：综合应用（可选）

将多个 AI 函数组合使用，构建一个简单的智能问答系统。

1. 注册所需厂商配置（可跳过）

    本示例需要嵌入模型、文本生成模型和重排序模型。若步骤一已注册 `aliyun` 厂商配置，且对应模型均通过该厂商访问，可跳过本步；否则请注册其他厂商配置：

    ```sql
    CALL DBMS_AI_SERVICE.REGISTER_PROVIDER('deepseek', '{
      "access_key": "sk-xxxx"
    }');
    ```

2. 准备数据并生成向量

    ```sql
    CREATE TABLE knowledge_base (
        id INT AUTO_INCREMENT PRIMARY KEY,
        title VARCHAR(255),
        content TEXT,
        embedding TEXT
    );

    INSERT INTO knowledge_base (title, content) VALUES
        ('OceanBase 简介', 'OceanBase 是一个强大的数据库系统，支持向量搜索和 AI 函数。'),
        ('向量搜索', '向量搜索可以用于语义搜索，找到相似的内容。'),
        ('AI 函数', 'AI 函数可以在 SQL 中直接调用 AI 模型。');

    UPDATE knowledge_base
    SET embedding = AI_EMBED('aliyun/text-embedding-v3', content);
    ```

3. 向量搜索并重排序

    ```sql
    SET @query = "什么是向量搜索？";
    SET @query_vector = AI_EMBED('aliyun/text-embedding-v3', @query);

    -- 直接构建字符串数组格式的文档列表
    SET @candidate_docs = '["OceanBase 是一个强大的数据库系统，支持向量搜索和 AI 函数。", "向量搜索可以用于语义搜索，找到相似的内容。"]';

    SELECT AI_RERANK('aliyun/gte-rerank-v2', @query, @candidate_docs) AS ranked_results;
    ```

    返回结果如下，`index` 为文档索引，`relevance_score` 为相关性分数：

    ```sql
    +-------------------------------------------------------------------------------------------------------------+
    | ranked_results                                                                                              |
    +-------------------------------------------------------------------------------------------------------------+
    | [{"index": 1, "relevance_score": 0.9904329776763916}, {"index": 0, "relevance_score": 0.16993996500968933}] |
    +-------------------------------------------------------------------------------------------------------------+
    1 row in set
    ```

4. 生成答案

    基于检索与重排序结果，生成答案：

    ```sql
    SELECT AI_COMPLETE('aliyun/qwen-plus',
        AI_PROMPT('基于以下文档内容，回答用户的问题。
        用户问题：{0}

        相关文档：{1}

        请基于以上文档内容，简洁准确地回答用户的问题。', @query, CAST(JSON_EXTRACT(@candidate_docs, '$[1]') AS CHAR))) AS answer;
    ```

    返回结果如下：

    ```sql
    +--------------------------------------------------------------------------------------------------------------------------------------------+
    | answer                                                                                                                                     |
    +--------------------------------------------------------------------------------------------------------------------------------------------+
    | 根据提供的文档内容，向量搜索是一种用于语义搜索的技术，旨在通过比对向量数据来找到相似的内容。                                               |
    +--------------------------------------------------------------------------------------------------------------------------------------------+
    1 row in set
    ```

    通过上述步骤，您可以在 OceanBase AI 数据库内快速完成完整的 AI 应用流程：向量化、搜索、重排序、生成答案。
