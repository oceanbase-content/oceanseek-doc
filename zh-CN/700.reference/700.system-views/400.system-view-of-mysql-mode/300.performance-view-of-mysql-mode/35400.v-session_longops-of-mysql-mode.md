# V$SESSION_LONGOPS

## 功能描述

<main id="notice" type='explain'>
<h4>说明</h4>
<p>查看向量索引 Segment 合并任务从 V4.6.2.1 版本开始支持。</p>
</main>

展示当前 OBServer 节点上长时间运行操作的执行状态和进度，包括 DDL 操作和向量索引增量段（Segment）合并任务等。

## 字段说明

|     **字段名称**     |    **类型**     | **是否可以为 NULL** |  **描述**   |
|------------------|---------------|----------------|-----------|
| SID              | bigint(20)    | NO             | 会话 ID     |
| TRACE_ID         | varchar(64)  | NO   | 该语句的 trace_id    |
| OPNAME           | varchar(64)  | NO             | 操作名称      |
| TARGET           | varchar(64)  | NO             | 操作对象      |
| SVR_IP           | varchar(46)   | NO             | 操作所在机器 IP |
| SVR_PORT         | bigint(20)    | NO             | 操作所在机器端口号 |
| START_TIME       | date   | NO             | 开始时间      |
| ELAPSED_SECONDS  | bigint(21) | NO             | 已经消耗时间    |
| TIME_REMAINING   | bigint(20)    | NO             | 预估剩余需要时间  |
| LAST_UPDATE_TIME | date   | NO             | 统计信息更新时间  |
| MESSAGE          | varchar(512)  | NO             | 备注信息      |
## 查询示例

查看正在执行的向量索引 Segment 合并任务进度：

```sql
SELECT SID, OPNAME, TARGET, ELAPSED_SECONDS, TIME_REMAINING, MESSAGE
FROM V$SESSION_LONGOPS
WHERE OPNAME = 'VEC MERGE TASK';
```

也可通过任务视图与本视图联合查询，获取完整的 MERGE 任务执行状态：

```sql
SELECT
  t.TABLET_ID,
  t.TASK_TYPE,
  t.STATUS,
  t.TRACE_ID,
  l.ELAPSED_SECONDS,
  l.TIME_REMAINING,
  l.MESSAGE
FROM OCEANBASE.DBA_OB_VECTOR_INDEX_TASKS t
LEFT JOIN V$SESSION_LONGOPS l ON l.TARGET = CONCAT('task_id=', t.TASK_ID)
WHERE t.TASK_TYPE = 'INCREMENTAL_INDEX_MERGE'
  AND t.STATUS = 'RUNNING';
```

当 Plan Monitor 数据尚未就绪时（如 SQL 刚开始执行），`MESSAGE` 字段可能显示等待信息，进度百分比为 0。任务完成后对应的 longops 记录会自动清理。
