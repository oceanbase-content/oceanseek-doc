# GV$OB_TABLET_MACRO_CACHE_STAT

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该视图从 V4.6.3 版本开始引入。</p>
</main>

## 功能描述

展示所有 OBServer 节点上各租户的 Tablet 宏块缓存统计信息。每一行对应一个 OBServer 节点上的一个 Tablet，展示该 Tablet 当前版本的宏块总数、已缓存宏块数、宏块实际数据大小、已缓存宏块的数据大小以及缓存比例，可用于巡检指定表或 Tablet 的数据是否已全部缓存。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>查询该视图时必须指定 <code>TABLE_ID</code> 或 <code>TABLET_ID</code>，不支持在两者均未指定时执行无范围全表扫描。</p>
</main>

## 字段说明

| 字段名称 | 类型 | 是否可以为 NULL | 描述 |
| --- | --- | --- | --- |
| SVR_IP | varchar(46) | NO | OBServer 节点的 IP 地址。 |
| SVR_PORT | bigint(20) | NO | OBServer 节点的端口号。 |
| TENANT_ID | bigint(20) | NO | 租户 ID。 |
| LS_ID | bigint(20) | NO | Tablet 当前所属的日志流 ID。 |
| TABLET_ID | bigint(20) | NO | Tablet ID。 |
| TRANSFER_SCN | bigint(20) | NO | Tablet 的 Transfer SCN（Transfer 版本号）。 |
| TABLE_ID | bigint(20) | NO | Tablet 所属的表 ID。 |
| STORAGE_CACHE_POLICY | varchar(64) | NO | Tablet 当前冷热状态。取值与 [GV$OB_TABLET_LOCAL_CACHE](4320.gv-ob_tablet_local_cache-of-mysql-mode.md) 中的 `STORAGE_CACHE_POLICY` 一致，包括 `AUTO`（自动冷热数据识别）和 `HOT`（热数据）。 |
| MACRO_BLOCK_COUNT | bigint(20) | NO | Tablet 当前版本的宏块总数。 |
| CACHED_MACRO_BLOCK_COUNT | bigint(20) | NO | Tablet 当前版本的宏块中已被缓存的宏块数。 |
| MACRO_BLOCK_REQUIRED_SIZE | bigint(20) | NO | Tablet 当前版本宏块对应的实际数据大小，单位为字节。 |
| CACHED_MACRO_BLOCK_REQUIRED_SIZE | bigint(20) | NO | Tablet 当前版本宏块中被缓存的宏块所对应的实际数据大小，单位为字节。 |
| CACHE_RATIO_PERCENT | bigint(20) | NO | Tablet 当前版本宏块中，被缓存的宏块数占总宏块数的百分比。 |
| INFO | varchar(1024) | NO | 其他诊断信息。 |

## 使用说明

* 该视图的统计范围为所有 OBServer 节点。用户租户查询时，仅展示当前租户的数据。

* 生成每一行统计时，系统需要获取当前 Tablet、加载并遍历 Tablet 的宏块信息、按 `MacroBlockId` 去重，并逐个查询本节点的宏块缓存元数据。因此，查询时应尽量通过 `TABLE_ID` 或 `TABLET_ID` 缩小范围，避免一次性查询大量 Tablet。

* 对于 fork table 场景，一个宏块可能被多个 Tablet 共享。排查缓存情况时，应结合 `TABLET_ID`、`TABLE_ID` 和 `STORAGE_CACHE_POLICY` 共同判断。

## 查询示例

1. 查询指定表的各 Tablet 宏块缓存情况。

    ```sql
    SELECT SVR_IP, SVR_PORT, TENANT_ID, TABLE_ID, TABLET_ID,
           STORAGE_CACHE_POLICY, MACRO_BLOCK_COUNT,
           CACHED_MACRO_BLOCK_COUNT, CACHE_RATIO_PERCENT
    FROM oceanbase.GV$OB_TABLET_MACRO_CACHE_STAT
    WHERE TABLE_ID = 500001;
    ```

2. 查询指定 Tablet 的宏块缓存情况。

    ```sql
    SELECT *
    FROM oceanbase.GV$OB_TABLET_MACRO_CACHE_STAT
    WHERE TABLET_ID = 200001;
    ```
