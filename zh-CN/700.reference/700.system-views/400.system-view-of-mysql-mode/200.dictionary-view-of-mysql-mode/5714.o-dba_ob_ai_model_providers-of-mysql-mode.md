# oceanbase.DBA_OB_AI_MODEL_PROVIDERS

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该视图从 V4.6.2.1 版本开始引入。</p>
</main>

## 功能描述

展示本租户的 AI 厂商（Provider）配置信息，用于查看通过 `REGISTER_PROVIDER` 注册的厂商连接信息与访问凭证配置。

## 字段说明

| 字段 | 类型 | 是否为 NULL | 描述 |
| --- | --- | --- | --- |
| PROVIDER_NAME | varchar(256) | NO | 厂商名称。在 `provider/model` 格式中，`/` 左侧即为该名称。 |
| PROTOCOL | varchar(256) | NO | 通信协议，例如 `openai`、`dashscope`、`cohere` 等。 |
| BASE_URL | varchar(2048) | NO | 当前生效的模型服务 Base URL。 |
| ACCESS_KEY | varchar(2048) | NO | 访问凭证。查询结果不返回明文。 |
| CREATE_TIME | timestamp(6) | NO | 创建时间。 |
| UPDATE_TIME | timestamp(6) | NO | 最近修改时间。 |

## 查询示例

用户租户查询本租户的 AI 厂商配置信息。如尚未注册厂商配置，请先执行 `REGISTER_PROVIDER`，并替换 `access_key` 为实际值。

```shell
CALL DBMS_AI_SERVICE.REGISTER_PROVIDER('deepseek', '{
  "access_key": "sk-xxx"
}');

SELECT PROVIDER_NAME, PROTOCOL, BASE_URL
FROM oceanbase.DBA_OB_AI_MODEL_PROVIDERS
WHERE PROVIDER_NAME = 'deepseek';
```

示例结果如下：

```shell
PROVIDER_NAME	PROTOCOL	BASE_URL
deepseek	openai	https://api.deepseek.com
1 row in set
```
