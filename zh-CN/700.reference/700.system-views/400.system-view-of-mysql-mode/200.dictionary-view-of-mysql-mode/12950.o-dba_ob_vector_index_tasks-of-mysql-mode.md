# oceanbase.DBA_OB_VECTOR_INDEX_TASKS

## 功能描述

视图 `DBA_OB_VECTOR_INDEX_TASKS` 展示了当前租户下所有向量索引相关后台任务的信息，包括分区重建、Segment 转储与合并、IVF 聚类中心加载与清理、语义索引刷新、内存同步等，可通过视图中的 `TASK_TYPE` 字段区分任务类型。

## 查询示例

### 完整示例

系统租户下，查看所有租户的向量索引性能优化任务信息。

```sql
SELECT * FROM oceanbase.DBA_OB_VECTOR_INDEX_TASKS ORDER BY MODIFY_TIME DESC\G;
```


TASK_INFO 字段 JSON 字符串说明：

| **字段名** | **JSON 字段类型** | **含义** |
|---|---|---|
| merge_segments_cnt | string | 需要被合并的 Segment 数量 |
| merge_segments | array | 合并前的 Segment 信息，数量和 merge_segments_cnt 相等 |
| result_segments | array | 合并后的 Segment 结果信息 |
| scn | string | 内部时间戳 |
| start_key | string | Segment 存储范围的上界 |
| end_key | string | Segment 存储范围的下界 |
| index_type | string | Segment 处理向量的索引类型，包含值有：<ul><li>HNSW</li><li>HNSW_SQ</li><li>HNSW_BQ</li><li>HGRAPH</li><li>SINDI</li></ul> |
| mem_used | string | Segment 使用的内存 |
| mem_limit_info | object | 内存限流相关信息，包含 `task_memory_limited`、`vector_mem_hold`、`vector_mem_limit`、`task_estimate_memory`、`tasks_total_reserved_memory` 等字段。仅在分区级索引重建、增量 Segment 合并等内存消耗较大的任务中可能出现。 |
| min_vid | string | Segment 最小的向量 ID |
| max_vid | string | Segment 最大的向量 ID |

### 查看内存限流信息

对于分区级索引重建、增量 Segment 合并等内存消耗较大的任务，任务信息中可能包含 `mem_limit_info` 段，记录内存限流相关信息。可通过以下 SQL 查询内存预估与限流信息：

```sql
SELECT
  TABLET_ID,
  TASK_TYPE,
  JSON_EXTRACT(TASK_INFO, '$.mem_limit_info.task_estimate_memory') AS estimate_mem,
  JSON_EXTRACT(TASK_INFO, '$.mem_limit_info.vector_mem_hold') AS mem_hold,
  JSON_EXTRACT(TASK_INFO, '$.mem_limit_info.vector_mem_limit') AS mem_limit,
  JSON_EXTRACT(TASK_INFO, '$.mem_limit_info.task_memory_limited') AS was_throttled
FROM OCEANBASE.DBA_OB_VECTOR_INDEX_TASKS
WHERE TASK_TYPE = 'PARTITION_REBUILD';
```

`mem_limit_info` 字段的子字段详细说明如下：

| **子字段** | **单位** | **说明** |
| --- | --- | ---- |
| `task_memory_limited` |  | 是否触发过内存限流（true/false） |
| `vector_mem_hold` | 字节 | 任务调度时租户向量内存已使用量 |
| `vector_mem_limit` | 字节 | 租户向量内存总限额 |
| `task_estimate_memory` | 字节 | 当前任务的预估内存需求 |
| `tasks_total_reserved_memory` | 字节 | 其他运行中任务的总预留内存 |
