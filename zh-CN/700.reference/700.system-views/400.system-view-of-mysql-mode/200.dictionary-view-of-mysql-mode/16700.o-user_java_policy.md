# oceanbase.USER_JAVA_POLICY

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该视图从 V4.6.3 版本开始引入。</p>
</main>

## 功能描述

视图 `USER_JAVA_POLICY` 用于展示当前登录用户拥有的 Java 权限策略，包括 Java UDF 的权限授予和限制规则。

与 `DBA_JAVA_POLICY` 视图的差异：`DBA_JAVA_POLICY` 展示当前租户下所有用户的 Java 权限策略，`USER_JAVA_POLICY` 仅展示当前登录用户相关的权限策略记录。

## 字段说明

| 字段名称 | 类型 | 是否可以为 NULL | 描述 |
| --- | --- | --- | --- |
| KIND | varchar(8) | NO | 策略类型：<ul><li>`GRANT`：授予权限。</li><li>`RESTRICT`：限制权限。</li></ul> |
| GRANTEE | varchar(128) | NO | 被授权的用户名。 |
| TYPE_SCHEMA | varchar(128) | NO | 类型所属的数据库名。 |
| TYPE_NAME | varchar(4096) | YES | 类型名称。 |
| NAME | varchar(4096) | YES | 权限目标名称。 |
| ACTION | varchar(4096) | YES | 权限动作。 |
| ENABLED | varchar(8) | NO | 策略是否启用：<ul><li>`ENABLED`：启用。</li><li>`DISABLED`：禁用。</li></ul> |
| SEQ | bigint(20) | NO | 策略序号。 |

## 查询示例

查询当前登录用户拥有的 Java 权限策略。

```sql
SELECT * FROM oceanbase.USER_JAVA_POLICY;
```

查询结果如下：

```shell
+------+---------+--------------+------------------------+--------+--------+---------+------+
| KIND | GRANTEE | TYPE_SCHEMA  | TYPE_NAME              | NAME   | ACTION | ENABLED | SEQ  |
+------+---------+--------------+------------------------+--------+--------+---------+------+
| GRANT| SYS     | java.io      | FilePermission         | /tmp/- | read   | ENABLED | 1    |
+------+---------+--------------+------------------------+--------+--------+---------+------+
1 row in set
```
