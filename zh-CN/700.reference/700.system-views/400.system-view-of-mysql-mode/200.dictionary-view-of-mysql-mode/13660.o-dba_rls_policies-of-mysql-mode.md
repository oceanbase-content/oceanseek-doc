# oceanbase.DBA_RLS_POLICIES

## 功能描述

视图 `DBA_RLS_POLICIES` 为租户级视图，展示当前用户租户下所有表上定义的行级权限（RLS）策略信息，包括策略名称、关联表、策略类型、适用命令类型、绑定角色、`USING` / `WITH CHECK` 表达式等。

说明如下：

* 该视图仅展示通过 `CREATE POLICY` 直接创建在表上的策略。
* 该视图不按策略所有者过滤行。普通用户须先获得该视图的 `SELECT` 权限才能查询；授权后可查看其他数据库的策略表达式。

## 字段说明

| **字段** | **类型** | **是否可以为 NULL** | **描述** |
| --- | --- | --- | --- |
| POLICY_NAME | char(128) | NO | 策略名称。 |
| TABLE_SCHEMA | char(128) | NO | 策略关联表所属的数据库名。 |
| TABLE_NAME | char(128) | NO | 策略关联的表名。 |
| POLICY_TYPE | char(16) | NO | 策略类型：`PERMISSIVE` 或 `RESTRICTIVE`。 |
| COMMAND_TYPE | char(64) | NO | 策略适用的 DML 类型：`ALL`、`SELECT`、`INSERT`、`UPDATE`、`DELETE`，或其组合（逗号分隔）。 |
| ROLES | char(4096) | YES | 策略绑定的角色/用户名列表（逗号分隔）。`PUBLIC` 表示对所有用户生效。被引用角色已删除时可能为 `NULL`，此时不等于 `PUBLIC`。 |
| USING_EXPRESSION | char(65535) | YES | 策略的 `USING` 行过滤表达式文本；未配置时为 `NULL`。 |
| WITH_CHECK_EXPRESSION | char(65535) | YES | 策略的 `WITH CHECK` 写操作校验表达式文本；未配置时为 `NULL`。 |

说明如下：

* `WITH_CHECK_EXPRESSION IS NULL` 不一定表示没有写入检查。对只有 `USING` 的 `ALL` / `UPDATE` 策略，执行期会把 `USING` 作为隐式写入检查。
* 表级 RLS 开关请结合 `information_schema.TABLES` 的 `ROW_SECURITY`、`ROW_SECURITY_FORCED` 字段查看。策略是否存在不影响这两个字段。

## 查询示例

查询 `hr.employees` 表上的策略：

```sql
SELECT * FROM oceanbase.DBA_RLS_POLICIES WHERE TABLE_SCHEMA = 'hr' AND TABLE_NAME = 'employees';
```

结果样例如下：

```shell
+------------------+--------------+------------+-------------+---------------+----------+------------------------------------------+------------------------------------------+
| POLICY_NAME      | TABLE_SCHEMA | TABLE_NAME | POLICY_TYPE | COMMAND_TYPE  | ROLES    | USING_EXPRESSION                         | WITH_CHECK_EXPRESSION                    |
+------------------+--------------+------------+-------------+---------------+----------+------------------------------------------+------------------------------------------+
| emp_dept_policy  | hr           | employees  | PERMISSIVE  | SELECT        | PUBLIC   | dept_id = current_setting('app.dept_id') | NULL                                     |
| mgr_write_policy | hr           | employees  | RESTRICTIVE | INSERT,UPDATE | manager  | dept_id = current_setting('app.dept_id') | dept_id = current_setting('app.dept_id') |
| hr_admin_policy  | hr           | employees  | PERMISSIVE  | ALL           | hr_admin | 1=1                                      | NULL                                     |
+------------------+--------------+------------+-------------+---------------+----------+------------------------------------------+------------------------------------------+
```
