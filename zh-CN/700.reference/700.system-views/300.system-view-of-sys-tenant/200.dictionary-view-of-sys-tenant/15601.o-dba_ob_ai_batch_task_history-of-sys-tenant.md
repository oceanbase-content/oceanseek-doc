# oceanbase.DBA_OB_AI_BATCH_TASK_HISTORY

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该视图从 V4.6.2.1 版本开始引入。</p>
</main>

## 功能描述

展示本租户已结束的 AI Batch 任务历史信息，常用于追溯 Batch File 模式建索引任务的结果、token 消耗及任务耗时。

任务完成或失败后约 10 分钟会从当前任务视图归档至本历史视图。视图中将内部数值状态转换为字符串，并按已处理请求数与总请求数计算进度百分比。

与任务视图相比，本视图额外提供 token 用量统计（`TOKEN_USAGE`）及 Batch 任务耗时信息（`PROVIDER_TIMELINE`）。

## 字段说明

| **字段** | **类型** | **是否为 NULL** | **描述** |
| --- | --- | --- | --- |
| TASK_ID | varchar(256) | NO | AI Batch 任务唯一标识。 |
| DDL_TASK_ID | bigint(20) | YES | 关联的 DDL 任务 ID。Batch File 建索引时，对应 `CREATE VECTOR INDEX` 触发的 DDL 任务。 |
| MODEL_NAME | varchar(256) | NO | 使用的 AI 模型名称，对应 `DBMS_AI_SERVICE` 中注册的模型名。 |
| COMMAND_TYPE | varchar(256) | NO | AI 调用类型，例如 `EMBED`。 |
| STATUS | varchar(256) | NO | 任务终态，取值为 `INVALID`、`PENDING`、`RUNNING`、`FINISHED`、`FAILED`、`CANCELLED`、`UNKNOWN`。 |
| REQUESTS_HANDLED | bigint(20) | NO | 已处理请求数。 |
| TOTAL_REQUESTS | bigint(20) | NO | 总请求数。 |
| PROGRESS_PERCENT | decimal | YES | 任务进度百分比，按 `REQUESTS_HANDLED / TOTAL_REQUESTS` 计算。 |
| TASK_CREATE_TIME | timestamp | NO | 任务创建时间。 |
| TASK_UPDATE_TIME | timestamp | NO | 任务最近状态更新时间。 |
| BATCH_ID | varchar(256) | YES | AI 服务商侧 Batch 任务 ID。 |
| REMOTE_FILE_IDS | varchar(2048) | YES | AI 服务商侧文件 ID，JSON 字符串。OpenAI 风格示例：`{"input_file_id":"file-in-xxx","output_file_id":"file-out-xxx","error_file_id":"file-err-xxx"}`；Anthropic 风格示例：`{"output_file_id":"msgbatch_yyy_result"}`。 |
| ERROR_DETAIL | varchar(4096) | YES | OceanSeek 及模型侧错误信息，JSON 字符串。示例：`{"ob_error_code":0,"model_http_code":429,"message":"Rate limit exceeded for requests"}`。 |
| TOKEN_USAGE | varchar(1024) | YES | Batch 任务在 AI 服务商侧实际消耗的 token 统计，JSON 字符串。示例：`{"completion_tokens":0,"prompt_tokens":6,"total_tokens":6}`。 |
| PROVIDER_TIMELINE | varchar(1024) | YES | Batch 任务耗时信息，JSON 字符串。可包含服务商侧各阶段时间戳（Unix 秒）或等待耗时等字段，例如 `{"model_wait_time_us":61193090}`。 |

## 查询示例

```shell
obclient [oceanbase]> SELECT * FROM oceanbase.DBA_OB_AI_BATCH_TASK_HISTORY;
```
