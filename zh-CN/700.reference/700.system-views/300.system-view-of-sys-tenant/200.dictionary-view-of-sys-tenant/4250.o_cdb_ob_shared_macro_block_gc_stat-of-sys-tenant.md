# oceanbase.CDB_OB_SHARED_MACRO_BLOCK_GC_STAT

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该视图从 V4.6.3 版本开始引入。</p>
</main>

## 功能描述

展示所有租户每天按存储类型统计的共享数据 GC 删除宏块数量。视图按统计记录 `GMT_CREATE` 所属的 GMT 自然日和存储类型，仅系统租户可以查询。

该视图仅查询 `MARK_SWEEP_GC_IN_TABLE_STAT` 和 `MARK_SWEEP_GC_OBJECT_STORAGE_STAT` 两类统计记录，不会读取或反序列化 `MARK_SWEEP_GC` 记录中的原始 MacroBlockID 列表，从而避免全租户查询时因展开大量 MacroBlockID 导致查询超时。

## 字段说明

| 字段名称 | 类型 | 是否可以为 NULL | 描述 |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | 租户 ID。 |
| STAT_DATE | date | NO | 统计记录 `GMT_CREATE` 所属的 GMT 自然日。 |
| GC_TYPE | varchar(128) | NO | GC 类型，本期固定返回 `MARK_SWEEP_GC`。 |
| STORAGE_TYPE | varchar(32) | NO | 存储类型：<ul><li>`IN_TABLE`：表内宏块。</li><li>`OBJECT_STORAGE`：对象存储宏块。</li></ul> |
| DELETED_MACRO_BLOCK_COUNT | bigint(20) | NO | 当天该存储类型完成删除流程的 MacroBlockID 数量。 |
| DELETED_MACRO_BLOCK_SIZE | bigint(20) | YES | 删除宏块的总大小，单位为 Byte。本期为预留字段，固定返回 `NULL`。 |

## 使用说明

* `DELETED_MACRO_BLOCK_COUNT` 的取值为统计记录中 `VALUE` 字段的累加和，即 `SUM(CAST(VALUE AS UNSIGNED))`，不是统计记录的数量 `COUNT(*)`。

* `STORAGE_TYPE` 与内部统计类型的映射关系如下：

  | 内部统计类型 | 视图 `STORAGE_TYPE` |
  | --- | --- |
  | `MARK_SWEEP_GC_IN_TABLE_STAT` | `IN_TABLE` |
  | `MARK_SWEEP_GC_OBJECT_STORAGE_STAT` | `OBJECT_STORAGE` |

* `DELETED_MACRO_BLOCK_SIZE` 在本版本固定返回 `NULL` 而不是 `0`，避免使用方误认为删除大小为 0。

* `STAT_DATE` 按 GMT 自然日统计。

## 查询示例

系统租户查询租户 ID 为 `1002` 的租户每天按存储类型统计的共享数据 GC 删除宏块数量。

```sql
SELECT *
FROM oceanbase.CDB_OB_SHARED_MACRO_BLOCK_GC_STAT
WHERE TENANT_ID = 1002
ORDER BY STAT_DATE, STORAGE_TYPE;
```

查询结果如下：

```shell
+-----------+------------+---------------+----------------+---------------------------+--------------------------+
| TENANT_ID | STAT_DATE  | GC_TYPE       | STORAGE_TYPE   | DELETED_MACRO_BLOCK_COUNT | DELETED_MACRO_BLOCK_SIZE |
+-----------+------------+---------------+----------------+---------------------------+--------------------------+
|      1002 | 2026-08-18 | MARK_SWEEP_GC | IN_TABLE       |                       120 |                     NULL |
|      1002 | 2026-08-18 | MARK_SWEEP_GC | OBJECT_STORAGE |                       380 |                     NULL |
+-----------+------------+---------------+----------------+---------------------------+--------------------------+
2 rows in set
```
