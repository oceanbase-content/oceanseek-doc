# oceanbase.DBA_OB_AI_GATEWAYS

<main id="notice" type='explain'>
    <h4>说明</h4>
    <p>该视图从 V4.6.2.1 版本开始引入。</p>
</main>

## 功能描述

展示本租户的 AI 网关（Gateway）配置信息，用于查看通过 `CREATE_AI_GATEWAY` PL 子程序创建的多端点路由与权重配置。

## 字段说明

| 字段 | 类型 | 是否为 NULL | 描述 |
| --- | --- | --- | --- |
| GATEWAY_NAME | varchar(256) | NO | 网关名称。 |
| ENDPOINTS | varchar(32767) | NO | 端点（Endpoint）路由列表 JSON。每项包含 `name`、`model`、`weight` 等字段，`model` 为 `provider/model` 格式。 |
| CIRCUIT_BREAKER | varchar(4096) | YES | 网关级熔断配置 JSON。 |
| CREATE_TIME | timestamp(6) | NO | 创建时间。 |
| UPDATE_TIME | timestamp(6) | NO | 最近修改时间。 |

## 查询示例

查询本租户的 AI 网关配置信息。

1. 如尚未注册厂商配置，请先执行 `REGISTER_PROVIDER`，并替换 `access_key` 与 `base_url` 为实际值：

    ```shell
    CALL DBMS_AI_SERVICE.REGISTER_PROVIDER('test-provider', '{
    "protocol": "openai",
    "base_url": "https://xxx",
    "access_key": "sk-xxx"
    }');
    CALL DBMS_AI_SERVICE.CREATE_AI_GATEWAY('test', '{
    "endpoints": [
        {"name":"ep1","model":"test-provider/test-model","weight":70},
        {"name":"ep2","model":"test-provider/test-model2","weight":30}
    ]
    }');
    ```

2. 查询网关配置信息：

    ```sql
    SELECT GATEWAY_NAME, ENDPOINTS, CIRCUIT_BREAKER
    FROM oceanbase.DBA_OB_AI_GATEWAYS
    WHERE GATEWAY_NAME = 'test';
    ```

    示例结果如下：

    ```shell
    GATEWAY_NAME	ENDPOINTS	CIRCUIT_BREAKER
    test	[{"name": "ep1", "model": "test-provider/test-model", "weight": 70}, {"name": "ep2", "model": "test-provider/test-model2", "weight": 30}]	NULL
    ```
