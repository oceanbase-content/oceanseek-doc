# oceanbase.CDB_OB_AGENT_DB_BACKGROUND_TASK_HISTORY

## 功能描述

视图 `CDB_OB_AGENT_DB_BACKGROUND_TASK_HISTORY` 展示所有租户已完成的逻辑表（Logical Table）后台删除任务历史。

## 字段说明

| 字段 | 类型 | 是否为 NULL | 描述 |
| --- | --- | --- | --- |
| TENANT_ID | bigint(20) | NO | 租户 ID。 |
| DATABASE_NAME | varchar(128) | NO | 数据库名字。 |
| COLLECTION_NAME | varchar(256) | NO | Collection 名字。 |
| NAMESPACE_NAME | varchar(256) | NO | Namespace 名字。 |
| LTABLE_NAME | varchar(256) | NO | 逻辑表名字。<ul><li>`NAMESPACE_DELETE` 场景值为空字符串（`''`）。</li><li>`HOT_NAMESPACE_EXPIRE` 场景值为空字符串（`''`）。</li></ul> |
| OPERATION_TYPE | varchar(32) | NO | 操作类型，取值如下：<ul><li>`LTABLE_DELETE`</li><li>`NAMESPACE_DELETE`</li><li>`HOT_NAMESPACE_EXPIRE`</li></ul> |
| OPERATION_STATUS | varchar(32) | NO | 操作状态，取值如下：<ul><li>`COMPLETED`</li><li>`FAILED`</li></ul> |
| START_TIME | timestamp | NO | 任务开始时间。 |
| FINISH_TIME | timestamp | NO | 任务结束时间。 |
| ELAPSED_TIME | bigint | NO | 删除任务耗时，单位为微秒。 |
| TOTAL_DELETED_ROWS | bigint | NO | <ul><li>`LTABLE_DELETE` / `NAMESPACE_DELETE` 场景：表示当前该逻辑表已删除的 `<collection_id>_kv_data_table` 物理表的行数。</li><li>`HOT_NAMESPACE_EXPIRE` 场景：值为 `0`。</li></ul> |
| ORIGINAL_NAME | varchar(256) | NO | 被删除对象的原始名称。 |
| RET_CODE | varchar(512) | NO | 错误码名字。 |

## 查询示例

系统租户查询所有租户已完成的逻辑表后台删除任务历史。
