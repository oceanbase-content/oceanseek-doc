# oceanbase.DBA_OB_AI_GATEWAY_ENDPOINTS

<main id="notice" type='explain'>
    <h4>说明</h4>
    <p>该视图从 V4.6.2.1 版本开始引入。</p>
</main>

## 功能描述

展示本租户的 AI 网关端点（Gateway Endpoint）展开信息。该视图由 `DBA_OB_AI_GATEWAYS` 中的 `endpoints` JSON 展开而来，便于按端点维度排查路由配置。

## 字段说明

| 字段 | 类型 | 是否为 NULL | 描述 |
| --- | --- | --- | --- |
| GATEWAY_NAME | varchar(256) | NO | 网关名称。 |
| ENDPOINT_NAME | varchar(256) | NO | 端点名称。 |
| MODEL | varchar(512) | NO | 完整模型名，为 `provider/model` 格式。 |
| WEIGHT | int(11) | YES | 路由权重。为 NULL 时按 `0` 展示。 |
| CREATE_TIME | timestamp(6) | NO | 网关创建时间。 |
| UPDATE_TIME | timestamp(6) | NO | 网关最近修改时间。 |

## 查询示例

查询指定网关下的端点路由信息。

```sql
SELECT GATEWAY_NAME, ENDPOINT_NAME, MODEL, WEIGHT
FROM oceanbase.DBA_OB_AI_GATEWAY_ENDPOINTS
WHERE GATEWAY_NAME = 'test'
ORDER BY ENDPOINT_NAME;
```

示例结果如下：

```shell
GATEWAY_NAME	ENDPOINT_NAME	MODEL	WEIGHT
test	ep1	test-provider/test-model	70
test	ep2	test-provider/test-model2	30
2 rows in set
```
