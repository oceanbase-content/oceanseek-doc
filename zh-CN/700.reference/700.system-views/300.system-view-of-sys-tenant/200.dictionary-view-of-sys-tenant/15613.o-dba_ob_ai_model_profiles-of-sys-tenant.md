# oceanbase.DBA_OB_AI_MODEL_PROFILES

<main id="notice" type='explain'>
    <h4>说明</h4>
    <p>该视图从 V4.6.2.1 版本开始引入。</p>
</main>

## 功能描述

展示本租户的 AI 模型参数（Model Profile）配置信息，用于查看通过 `ALTER_MODEL_PROFILE` PL 子程序创建或更新的 `provider/model` 级参数。

## 字段说明

| 字段 | 类型 | 是否为 NULL | 描述 |
| --- | --- | --- | --- |
| MODEL | varchar(513) | NO | 完整模型名，为 `provider_name` 与 `model_name` 以 `/` 拼接的结果，例如 `aliyun/qwen-plus`。 |
| MODEL_CONFIG | varchar(4096) | YES | 模型 API 调用参数 JSON，对应 `ALTER_MODEL_PROFILE` 中的 `model_config`。 |
| RUN_CONFIG | varchar(4096) | YES | OceanBase 侧模型运行选项 JSON，对应 `ALTER_MODEL_PROFILE` 中的 `run_config`。 |
| CREATE_TIME | timestamp(6) | NO | 创建时间。 |
| UPDATE_TIME | timestamp(6) | NO | 最近修改时间。 |

## 查询示例

本示例展示了查询本租户的 AI 模型参数配置信息。

1. 如尚未注册厂商配置，请先执行 `REGISTER_PROVIDER`，并替换 `access_key` 与 `base_url` 为实际值：

    ```shell
    CALL DBMS_AI_SERVICE.REGISTER_PROVIDER('test-provider', '{
    "protocol": "openai",
    "base_url": "https://xxx",
    "access_key": "sk-xxx"
    }');
    ```

2. 使用 `ALTER_MODEL_PROFILE` 为模型设置参数：

    ```shell
    CALL DBMS_AI_SERVICE.ALTER_MODEL_PROFILE('test-provider/test-model', '{
    "model_config": {
        "max_tokens": 4096,
        "temperature": 0
    },
    "run_config": {
        "batch_size": 16,
        "max_image_size": 4194304,
        "min_concurrency": 10,
        "max_concurrency": 100
    }
    }');
    ```

3. 查询模型参数配置信息：

    ```sql
    SELECT MODEL, MODEL_CONFIG, RUN_CONFIG
    FROM oceanbase.DBA_OB_AI_MODEL_PROFILES
    WHERE MODEL = 'test-provider/test-model';
    ```

    示例结果如下：

    ```shell
    MODEL	MODEL_CONFIG	RUN_CONFIG
    test-provider/test-model	{"max_tokens": 4096, "temperature": 0}	{"batch_size": 16, "max_image_size": 4194304, "max_concurrency": 100, "min_concurrency": 10}
    1 row in set
    ```
