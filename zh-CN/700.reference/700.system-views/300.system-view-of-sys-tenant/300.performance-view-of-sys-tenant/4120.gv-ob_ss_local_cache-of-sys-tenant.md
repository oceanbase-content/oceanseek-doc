# GV$OB_LOCAL_CACHE

## 功能描述

展示所有租户在每个 OBServer 节点的本地缓存中各类缓存数据的相关指标。

## 字段说明

|      字段名称    |         类型          | 是否可以为 NULL |                       描述      |
|-----------------|-----------------------|----------------|---------------------------------|
| SVR_IP          | varchar(46)           | NO             |  OBServer 节点的 IP 地址    |
| SVR_PORT        | bigint(20)            | NO             |  OBServer 节点的端口号      |
| TENANT_ID       | bigint(20)            | NO             |  租户 ID                   |
| CACHE_NAME      | varchar(128)          | NO             |  本地缓存中某类数据缓存的名称，主要包括以下几类：<ul><li>`ss_local_cache_shared_macro`：共享宏块缓存，表示本地缓存中 shared macro 类型宏块的缓存指标。</li> <li>`ss_local_cache_private_macro`：私有宏块缓存，表示本地缓存中 private macro 类型宏块的缓存指标。</li> <li>`ss_mem_macro_cache`：内存宏块缓存，表示宏块在内存缓存层的命中、未命中及内存占用指标。</li> <li>`ss_macro_block_kvcache`：宏块 KVCache，表示宏块在 KVCache 缓存层整体指标，包括命中、未命中及内存占用等指标。<main id="notice" type='explain'><h4>说明</h4><p>该类型从 V4.6.2.1 版本开始引入。</p></main></li> <li>`ss_local_cache`：本地缓存总项，表示本地缓存整体指标，统计范围包含内存宏块缓存和磁盘宏块缓存。</li></ul>    |
| PRIORITY        | bigint(20)            | NO             |  缓存优先级，值越大优先级越高。当前该字段暂未使用，值默认为 `0`     |
| HIT_RATIO       | decimal(38,3)         | NO             |  缓存命中率                    |
| TOTAL_HIT_CNT   | bigint(20)            | NO             |  缓存命中的总次数               |
| TOTAL_MISS_CNT  | bigint(20)            | NO             |  缓存未命中的总次数             |
| HOLD_SIZE       | bigint(20)            | NO             |  缓存中所存放的对象的总量，单位为字节    |
| ALLOC_DISK_SIZE | bigint(20)            | NO             |  已分配的磁盘空间，单位为字节    |
| USED_DISK_SIZE  | bigint(20)            | NO             |  已使用的磁盘空间（可能存在磁盘空间分配后暂未使用的情况），单位为字节    |
| USED_MEM_SIZE   | bigint(20)            | NO             |  已使用的内存空间，单位为字节                 |
