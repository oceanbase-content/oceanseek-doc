# OBKV-Table 查询数据

本文档介绍了 OBKV-Table 的查询能力。OBKV-Table 支持单点查询（基于主键查询）和范围查询。在范围查询中，支持指定过滤条件、扫描顺序、limit 条件等。此外 OBKV-Table 还支持简单的汇聚能力，在汇聚查询中，也可以指定过滤条件、扫描顺序、limit 条件等。

OBKV-Table 不支持类似 SQL 的 Order By 功能，但是可以利用存储有序的特性，获取基于主表/索引表主键的顺序以及逆序。因此在指定 ScanOrder 的时候，不需要提供排序的列信息，目前限制只能基于主键列。

## 单点查询

### 接口

ObTableClient 有单点查询能力的接口如下：

| **接口** | **描述** |
| --- | --- |
| `Get get(String tableName)` | 基于主键查询一行数据 |

### 示例

#### 准备条件

查询前需要做如下准备:

* 你的 ObTableClient 已经初始化完成。
* 在你的数据库中已经创建了关系表，为方便说明，后续示例以下面的关系表进行说明：
    ```sql
    CREATE TABLE IF NOT EXISTS `employees` (
    `employeeId` int NOT NULL, 
    `name` varchar(100) NOT NULL,
    `department` varchar(50),
    `position` varchar(50),
    `workYear` int,
    `comment` varchar(100),
    PRIMARY KEY (`employeeId`)
    ) PARTITION BY KEY(`employeeId`) PARTITIONS 97;
    ```
    
其他说明如下：

* 已支持 JSON 类型，具体说明及写入示例请参见 [OBKV-Table 数据类型](../../700.obkv-table-reference/230.obkv-table-data-type.md)。

#### 单行查询

示例代码查询了一行数据，指定主键 `employeeId` 为 `1001` 进行了查询，查询时指定了查询 `name` 列。

```java
// 假设数据库中已经存在下面的数据
/*
+------------+----------+------------+----------+----------+---------+
| employeeId | name     | department | position | workYear | comment |
+------------+----------+------------+----------+----------+---------+
|       1001 | zhangsan | R&D        | dev      |       10 | NULL    |
+------------+----------+------------+----------+----------+---------+
*/
private static void getRow(ObTableClient obkvHandle) throws Exception {
    Row rowKey = row().add(colVal("employeeId", 1001));
    Map<String, Object> res = obkvHandle.get("employees")
            .setRowKey(rowKey)
            .select("name")
            .execute();
    System.out.println(res.get("name"));
}
```

#### 批量查询

示例代码查询了 2 行数据，指定主键 `employeeId` 分别为 `1001` 和 `1002` 进行了查询，查询时指定了查询 `name` 列。

```java
// 假设数据库中已经存在下面的数据
/*
+------------+----------+------------+----------+----------+---------+
| employeeId | name     | department | position | workYear | comment |
+------------+----------+------------+----------+----------+---------+
|       1001 | zhangsan | R&D        | dev      |       10 | NULL    |
|       1002 | lisi     | R&D        | dev      |       10 | NULL    |
+------------+----------+------------+----------+----------+---------+
*/
private static void batchGetRow(ObTableClient obkvHandle) throws Exception {
    Row rowKey1 = row().add(colVal("employeeId", 1001));
    Row rowKey2 = row().add(colVal("employeeId", 1002));
    Get getOp1 = get().setRowKey(rowKey1).select("name");
    Get getOp2 = get().setRowKey(rowKey2).select("name");
    BatchOperationResult res = obkvHandle.batchOperation("employees")
            .addOperation(getOp1,getOp2)
            .execute();
    System.out.println(res.size());
    System.out.println(res.get(0).getOperationRow().get("name"));
    System.out.println(res.get(1).getOperationRow().get("name"));
}
```

## 范围查询

### 接口

ObTableClient 有范围查询能力的接口如下：

| **接口** | **描述** |
| --- | --- |
| `TableQuery query(String tableName)` | 基于范围查询数据 |

### TableQuery 常用方法

| **方法** | **描述** | **是否可选** |
| --- | --- | --- |
| `TableQuery select(String... columns)` | 设置需要返回给客户端的列，不填返回所有列。<ul><li>建议填写，返回过多不需要的列，会带来额外开销。</li></ul> | 是 |
| `TableQuery indexName(String indexName)` | 本次查询需要使用的索引。 | 是 |
| `TableQuery addScanRange(Object[] starts, boolean startEquals, Object[] ends, boolean endEquals)` | 设置查询的主键范围。<ul><li>start/end：主键的开始以及结束值</li><li>startEquals/endEquals：查询范围是否包含 start/end 值。</li><li>建议使用主键的 scanRange 进行过滤，主键的 scan Range 过滤效率最高。</li></ul>  | 是 |
| `TableQuery setFilter(ObTableFilter filter)` | 设置查询的 filter。<ul><li>filter 可以是单个 filter 或者 filterlist。</li></ul> | 是 |
| `TableQuery scanOrder(boolean forward)` | 设置扫描顺序。<ul><li>forward：默认 true，表示正向扫描，false 表示反向扫描。</li></ul> | 是 |
| `TableQuery limit(int offset, int limit)` | 设置查询结果集中, 返回给客户端记录的范围。<ul><li>offset：偏移量。从结果集的第 offset 个记录开始返回，默认是第 1 条记录。</li><li>limit：返回给客户端的记录数量。</li></ul> | 是 |
| `QueryResultSet execute()` | 提交操作到数据库。 | 否 |

### Filter

OBKV-Table 支持的 Filter 包括:

* ObTableValueFilter
* ObTableFilterList
* ObTableInFilter

#### ObTableValueFilter

TableValueFilter 是最常用的 Filter，用于基于数据表中的列值和用户指定值之间的关系，来过滤数据。OBKV-Table 支持的运算关系, 定义在 ObCompareOp 枚举中。

```java
enum ObCompareOp {
    LT,     // 小于
    GT,     // 大于
    LE,     // 小于等于
    GE,     // 大于等于
    NE,     // 不等于
    EQ,     // 等于
    IS,     // 为空
    IS_NOT  //不为空
}
```

#### ObTableFilterList

ObTableFilterList 通过 AND / OR 将多个 Filter 串接在一起，共同组成一个复合的 Filter。如下为枚举ObTableFilterList.operator的定义：

```java
enum ObTableFilterListOperator {
    AND, // 逻辑与
    OR   // 逻辑或
}
```

#### ObTableInFilter

ObTableInFilter 是OBKV-Table提供的语法糖, 提供类似 SQL 中 `IN` 的语义：

* ObTableInFilter 本质上是一个 ObTableFilterList。
* 其中的每个 Filter 都是 ObCompareOp::EQ 关系的 ObTableValueFilter。


### 索引组织表示例

#### 准备条件

查询前需要做如下准备：

* 你的 ObTableClient 已经初始化完成。
* 在你的数据库中已经创建了索引组织表，示例如下：
    ```sql
    CREATE TABLE IF NOT EXISTS `employees` (
    `employeeId` int NOT NULL, 
    `name` varchar(100) NOT NULL,
    `department` varchar(50),
    `position` varchar(50),
    `workYear` int,
    `comment` varchar(100),
    PRIMARY KEY (`employeeId`)
    ) PARTITION BY KEY(`employeeId`) PARTITIONS 97;
    ```

#### 使用查询范围进行过滤

示例进行了一个范围查询，查询指定了范围列为主键 `employeeId`、`departmentId`，指定扫描范围为 `[{1000, 1},{1010, 1}]`，指定查询的列为 `name`。

```java
private static void queryWithScanRange(ObTableClient obkvHandle) throws Exception {
    TableQuery query = obkvHandle.query("employees");
    QueryResultSet res = query.setScanRangeColumns("employeeId","departmentId")
    .addScanRange(new Object[] { 1000, 1 }, new Object[] { 1010, 1 })
    .select("name")
    .execute();
    while (res.next()) {
        System.out.println(res.getRow().get("name"));
    }
}
```

#### 使用 filter 进行过滤

示例进行了一个范围查询，查询指定了范围列为主键 `employeeId`、`departmentId`，指定扫描范围为 `[{1000, 1},{1010, 1}]`，指定查询的列为 `name`。查询额外指定了 ObTableValueFilter 过滤条件，只有 `workYear` 大于等于 `3` 的记录会被返回。

```java
private static void queryWithFilter(ObTableClient obkvHandle) throws Exception {
    TableQuery query = obkvHandle.query("employees");
    ObTableValueFilter filter = compareVal(ObCompareOp.GE, "workYear", 3);
    QueryResultSet res = query.setScanRangeColumns("employeeId","departmentId")
            .addScanRange(new Object[] { 1000, 1 }, new Object[] { 1010, 1 })
            .setFilter(filter)
            .select("name")
            .execute();
    while (res.next()) {
        System.out.println(res.getRow().get("name"));
    }
}
```

#### 使用索引进行过滤

示例进行了一个范围查询，查询指定了范围列为索引键 `departmentId`，指定扫描范围为 `[1， 10]`，指定查询的列为 `name`。查询额外指定了使用索引 `idx_departmentId` 进行查询。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>在 OBKV-Table 中，二级索引需要包含分区键，以在指定二级索引范围时，确定分区键的范围。</p>
</main>

```java
private static void queryWithIndex(ObTableClient obkvHandle) throws Exception {
    TableQuery query = obkvHandle.query("employees");
    QueryResultSet res = query.setScanRangeColumns("departmentId")
            .addScanRange(new Object[] { 1 }, new Object[] { 10 })
            .indexName("idx_departmentId")
            .select("name")
            .execute();
    while (res.next()) {
        System.out.println(res.getRow().get("name"));
    }
}
```

### 堆组织表示例

#### 准备条件

查询前需要做如下准备：

* 你的 ObTableClient 已经初始化完成。
* 在你的数据库中已经创建了堆组织表，示例如下：
    ```sql
    CREATE TABLE test (
        c1 bigint, 
        c2 varchar(20), 
        c3 bigint,
        UNIQUE INDEX idx_unique_c1 (c1) -- 创建唯一索引可以加速查询
      ) ORGANIZATION = HEAP PARTITION BY KEY(c1) PARTITIONS 97; -- 通过 ORGANIZATION 参数指定堆表
    ```

#### 使用索引进行查询

示例进行了一个范围查询，查询指定了范围列为主键 `c1`，指定扫描范围为 `[1000, 1003]`，指定查询的列为 `c1`、`c2`、`c3`。查询额外指定了使用索引 `idx_unique_c1` 进行查询。

```java
private static void queryWithIndex(ObTableClient obkvHandle) throws Exception {
    try {
        // 使用BatchOperation进行批量插入
        BatchOperation batch = client.batchOperation(tableName);
        // 添加多个插入操作
        // 注意需要通过 setPartitionKey 设定分区键 c1 的值
        // 也需要通过 addMutateColVal 设定 c1 的值
        for (int i = 1; i <= 3; i++) {
            Insert insert = new Insert();
            insert.setPartitionKey(row(colVal("c1", (long)(1000 + i))))
                .addMutateColVal(colVal("c1", (long)(1000 + i)), colVal("c2", "batch_test"), colVal("c3", (long)(3000 + i)));
            batch.addOperation(insert);
        }
        batch.execute();
        System.out.println("Batch insert successful: 3 operations executed");

        // 指定索引扫描范围 [1000, 1003]
        // 指定索引 idx_unique_c1
        TableQuery query = client.query(tableName)
            .addScanRange(1000L, 1003L)
            .setScanRangeColumns("c1")
            .indexName("idx_unique_c1")
            .select("c1", "c2", "c3");
        QueryResultSet res = query.execute();
        int count = 0;
        while (res.next()) {
            count++;
            Map<String, Object> valueMap = res.getRow();
            long c1 = (long)valueMap.get("c1");
            String c2 = (String)valueMap.get("c2");
            long c3 = (long)valueMap.get("c3");
            assertEquals("c1 should match", c1 >= 1000 && c1 <= 1003, true);
            assertEquals("c2 should match", c2.equals("batch_test"), true);
            assertEquals("c3 should match", c3 >= 3000 && c3 <= 3003, true);
        }
        assertEquals("Should have 3 records", 3, count);
    } finally {
        truncateTable();
    }
}
```
