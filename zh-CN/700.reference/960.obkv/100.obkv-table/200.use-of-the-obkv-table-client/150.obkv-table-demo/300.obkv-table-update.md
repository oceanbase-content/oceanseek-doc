# OBKV-Table 更新数据

OBKV-Table Java 客户端支持单行数据更新和批量数据更新。业务可以根据需求选择对应的接口进行数据更新。

## 支持更新的接口

ObTableClient 有更新能力的接口如下：

| **接口** | **描述** | **注意事项** |
| --- | --- | --- |
| `update(String tableName)` | 更新一行数据，可以设置更新条件。 |  |
| `insertOrUpdate(String tableName)` | 插入或更新一行数据。 |  |
| `replace(String tableName)` | 替换一行数据（以先删后写的逻辑）。 |  |
| `put(String tableName)` | 覆盖写一行数据。 | <ul><li>必须更新每一列。</li><li>表中无索引。</li><li>表中无 LOB 类型。</li><li>租户的 `binlog_row_image` 值必须为 `minimal`。</li></ul> |
| `increment(String tableName)` | 原子对某一整型列增加值。 | 当旧行不存在时，将更新新行，值为指定的 delta 值。 |
| `append(String tableName)` | 原子对某一字符串追加字符串。 | 当旧行不存在时，将新增一行，值为指定 delta 值。
| `checkAndInsUp(String tableName, ObTableFilter filter, InsertOrUpdate insUp, boolean checkExists, boolean rollbackWhenCheckFailed)` | 满足条件后更新 | <ul><li>这个接口的 check 有两层语义</li><ul><li>这个行不存在（基于主键判断不存在，不是因为不满足 filter 条件）。</li><li>这个行存在，但是不满足 filter 的条件。</li></ul><li>当行数据存在的时候，接口行为:<ul><li>满足 filter 条件，做更新操作。</li><li>不满足 filter 条件，不做任何操作。</li></ul><li>当行数据不存在的时候，接口行为:<ul><li>`checkExists = true`，不做任何操作。</li><li>`checkExists = false`，做插入操作。</li></ul><li>当 check 不通过时，接口行为:<ul><li>`rollbackWhenCheckFailed = false`，不报错。</li><li>`rollbackWhenCheckFailed = true`，抛 `ObTableException` 异常，错误信息为 `[-10518][OB_KV_CHECK_FAILED][Check failed in CheckAndInsUp]`。</li></ul> |

## 更新示例

### 准备条件

1. 你的 ObTableClient 已经初始化完成。
2. 在你的数据库中已经创建了关系表，为方便说明，后续示例以下面的关系表进行说明：
    ```sql
    CREATE TABLE IF NOT EXISTS `employees` (
    `employeeId` int NOT NULL, 
    `name` varchar(100) NOT NULL,
    `department` varchar(50),
    `position` varchar(50),
    `workYear` int,
    `comment` varchar(100),
    PRIMARY KEY (`employeeId`)
    ) PARTITION BY KEY(`employeeId`) PARTITIONS 97;
    ```

### 单行更新

#### update

示例代码更新了一行数据，将主键 `employeeId` 为 `1001` 的 `workYear` 更新为 `11`。

```java
// 假设数据库中已经存在下面的数据
/*
+------------+----------+------------+----------+----------+---------+
| employeeId | name     | department | position | workYear | comment |
+------------+----------+------------+----------+----------+---------+
|       1001 | zhangsan | R&D        | dev      |       10 | NULL    |
+------------+----------+------------+----------+----------+---------+
*/
private static void updateRow(ObTableClient obkvHandle) throws Exception {
    Row rowKey = row().add(colVal("employeeId", 1001));
    Row properties = row().add(colVal("workYear", 11));
    obkvHandle.update("employees")
            .setRowKey(rowKey)
            .addMutateRow(properties)
            .execute();
}
```

示例代码更新了一行数据，如果主键 `employeeId` 为 `1001` 的 workYear 大于等于 `3`， 则将 workYear 更新为 `11`。

```java
// 假设数据库中已经存在下面的数据
/*
+------------+----------+------------+----------+----------+---------+
| employeeId | name     | department | position | workYear | comment |
+------------+----------+------------+----------+----------+---------+
|       1001 | zhangsan | R&D        | dev      |       10 | NULL    |
+------------+----------+------------+----------+----------+---------+
*/
private static void updateRowWithFilter(ObTableClient obkvHandle) throws Exception {
    Row rowKey = row().add(colVal("employeeId", 1001));
    Row properties = row().add(colVal("workYear", 11));
    ObTableValueFilter filter = compareVal(ObCompareOp.GE, "workYear", 3);

            .execute();
}
```

#### checkAndInsUp

示例代码检查了主键 `employeeId` 为 `1001` 的 `workYear` 是否大于等于 `3`，如果大于等于 `3`，则执行 insertUpOp，更新 `comment` 为 `good`。

```java
// 假设数据库中已经存在下面的数据
/*
+------------+----------+------------+----------+----------+---------+
| employeeId | name     | department | position | workYear | comment |
+------------+----------+------------+----------+----------+---------+
|       1001 | zhangsan | R&D        | dev      |       10 | NULL    |
+------------+----------+------------+----------+----------+---------+
*/
private static void checkAndInsUpRow(ObTableClient obkvHandle) throws Exception {
    Row rowKey = row().add(colVal("employeeId", 1001));
    Row properties = row().add(colVal("name", "zhangsan"))
            .add(colVal("department", "R&D"))
            .add(colVal("position", "dev"))
            .add(colVal("workYear", 10))
            .add(colVal("comment", "good"));
    InsertOrUpdate insertUpOp = insertOrUpdate().setRowKey(rowKey).addMutateRow(properties);
    ObTableValueFilter filter = compareVal(ObCompareOp.GE, "workYear", 3);
    MutationResult result = obkvHandle.checkAndInsUp("employees", filter, insertUpOp, true)
            .execute();
    System.out.println(result.getAffectedRows());
}
```

### 批量更新

#### batchUpdate

示例代码在一批里面更新了 2 行数据，将主键 `employeeId` 为 `1001` 和 `1002` 的 `workYear` 都更新成了 `11`。

```java

|       1002 | lisi     | R&D        | dev      |       10 | NULL    |
+------------+----------+------------+----------+----------+---------+
*/
private static void batchUpdateRow(ObTableClient obkvHandle) throws Exception {
    Row rowKey1 = row().add(colVal("employeeId", 1001));
    Row rowKey2 = row().add(colVal("employeeId", 1002));
    Row properties1 = row().add(colVal("workYear", 11));
    Row properties2 = row().add(colVal("workYear", 11));
    Update updateOp1 = update().setRowKey(rowKey1).addMutateRow(properties1);
    Update updateOp2 = update().setRowKey(rowKey2).addMutateRow(properties2);
    BatchOperationResult res = obkvHandle.batchOperation("employees")
            .addOperation(updateOp1,updateOp2)
            .execute();
    System.out.println(res.hasError());
}
```
