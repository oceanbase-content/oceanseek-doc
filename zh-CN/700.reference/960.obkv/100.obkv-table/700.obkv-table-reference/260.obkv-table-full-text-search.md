# OBKV-Table 全文索引

OBKV-Table 提供了全文索引 DML 和查询的能力，你可以为表创建全文索引，然后在表中插入、更新、删除数据时，数据会自动被索引，从而支持全文搜索。

## 支持范围

当前 OBKV-Table 客户端支持的功能范围如下：

* 支持字符串类型和 LOB 类型。
* 支持一个表上多个全文索引和同一列上支持多个全文索引。
* 支持分区表。
* 查询模式为 `NATURAL LANGUAGE MODE`。
* 支持 OBKV-Table 客户端的如下操作：
  * 单操作：不支持 PUT。
  * 批操作：不支持 PUT。
  * 支持 OBKV-Table 的组提交、TTL 等。

## 使用示例

为表 `tbl1` 创建全文索引 `full_idx1_tbl1`：

```sql
CREATE TABLE IF NOT EXISTS tbl1(
    id INT, 
    c2 INT, 
    txt text, 
    PRIMARY KEY (id), 
    FULLTEXT INDEX full_idx1_tbl1(txt)
);
```

向表 `tbl1` 插入数据：

```sql
MutationResult res = client.insert("tbl1").setRowKey(colVal("id", id))
                    .addMutateRow(row(colVal("txt", "OceanSeek Database is a native, " +
                            "enterprise-level distributed database developed independently by the OceanSeek team")))
                    .execute();
```

查询表 `tbl1` 的数据：

```sql
// 同步查询
QueryResultSet resultSet = client.query(noPartTableName)
                    .setSearchText("oceanbase")
                    .indexName("full_idx1_tbl1")
                    .limit(0,1)
                    .execute();
// 异步查询
QueryResultSet asyncResultSet = client.query(noPartTableName)
                    .indexName("full_idx1_tbl1")
                    .setSearchText("oceanbase")
                    .limit(0,1)
                    .asyncExecute();
```
