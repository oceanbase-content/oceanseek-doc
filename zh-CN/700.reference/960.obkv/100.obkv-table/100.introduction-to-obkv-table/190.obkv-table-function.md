# OBKV-Table 核心功能

本文档介绍了 OBKV-Table 的核心功能。

## 客户端

| **客户端** | **描述** |
| --- | --- |
| Java | 支持 Java 客户端 |

## OBKV-Table 模型功能

### 基础功能

| **功能** | **描述** |
| --- | --- |
| 单操作 | <ul><li>支持 insert / put / update / delete / get / insertOrUpdate / increment / append / checkAndInsertup 等单操作</li> |
| 查询 | <ul><li>支持带条件或范围的查询</li><li>支持 scanOrder</li><li>支持翻页查询</li></ul> |
| 批操作 | <ul><li>支持单操作的批量处理</li><li>支持查询的批量处理</li><li>支持混合操作的批量处理</li></ul> |
| 聚合 | <ul><li>支持 Min / Max / Sum / Avg / Count 等基础聚合能力</li><li>支持带条件或范围查询的聚合能力</li></ul> |
| 索引 | <ul><li>支持局部索引</li><li>支持[全局索引](../700.obkv-table-reference/280.scope-and-examples-of-using-obkv-table-global-indexes.md)</li><li>支持[全文索引](../700.obkv-table-reference/260.obkv-table-full-text-search.md)</li></ul> |

### 性能优化功能

| **功能** | **描述** |
| --- | --- |
| [TTL](../700.obkv-table-reference/290.obkv-table-ttl.md) | <ul><li>表级别 TTL（TTL 策略设置在表上，所有行基于表级策略过期）</li><li>支持过期数据自动删除</li></ul><main id="notice" type='notice'><h4>注意</h4><p>过期数据删除（TTL）功能仅限于 OceanSeek KV 场景使用，SQL 场景下禁用，否则会导致不可预期的数据误删除问题。</p></main> |
| [组提交](../700.obkv-table-reference//295.obkv-table-group-commit.md) | <ul><li>支持组提交，提高写入性能</li></ul> |
| [弱读和就近读](../700.obkv-table-reference/300.obkv-table-weak-read.md) | <ul><li>支持从 Follower 副本读取数据，降低 Leader 压力和网络延迟</li></ul> |

### 高级功能

| **功能** | **描述** |
| --- | --- |
| 事务 | <ul><li>单操作支持行级事务</li><li>批操作支持单机事务</li><li>暂不提供跨节点的分布式事务</li></ul>|
| 容灾 | 复用 OceanSeek 已有的所有容灾能力，比如多副本架构、主备库、 两地三中心、 三地五中心部署。 |
| 多租户 | 复用 OceanSeek 多租户能力 |
| 扩展性 | 复用 OceanSeek 的数据分区、弹性扩缩容能力 |
| 备份恢复 | 复用 OceanSeek 的备份恢复能力 |
| 数据压缩 | 存储数据压缩 |
| 数据加密 | 支持 TDE 透明加密 |
