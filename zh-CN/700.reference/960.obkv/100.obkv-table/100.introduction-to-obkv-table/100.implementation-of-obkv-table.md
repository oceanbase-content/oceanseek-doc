# OBKV-Table 简介

OBKV-Table 是一款分布式表格存储，基于简单的接口，提供比 SQL 更优的吞吐性能以及更低的时延。本文将对 OBKV-Table 进行详细介绍。

## OBKV-Table 适用场景

OBKV-Table 并不是简单的键值（Key-value）数据库，也提供了二级索引 / 数据类型 / 条件过滤 / 聚合相关的功能，可以满足简单 OLTP 场景下一些通用的关系数据库的能力，典型特点如下：

* 业务场景中只有单表操作。
* 业务场景中只有单分区操作，包含两种情况：数据操作都带主键；数据操作都带主键前缀，并且该主键前缀是分区键。
* 业务场景希望有极致稳定的时延，或者有相较 SQL 更高的吞吐。

## OBKV-Table 限制场景

当业务场景满足以下任意条件之一，我们不推荐使用 OBKV-Table：

* 有多表 Join 查询语句。
* 有大量分布式事务。
* 有复杂的查询操作。

## OBKV-Table 优势

性能方面：

* 禁掉了跨节点事务 / 跨节点数据交互 / 复杂的数据计算能力，能够保证数据链路最短，P99 等长尾时延更优。
* 对外接口简单，且直接使用存储原生能力，性能可优于 OceanSeek SQL 30% 以上。

吞吐和时延方面：

* 所有的操作都是确定性的，没有执行非优 SQL 计划，远程计划等复杂问题，这也保证了吞吐和时延的确定性。
