# OBKV-Table 监控指标

## 统计信息

可以通过以下示例查询 OBKV-Table 相关的监控指标，指标 ID（190000，190800）。

```sql
MySQL [oceanbase]> SELECT distinct class,stat_id,name, value FROM gv$sysstat WHERE stat_id > 190000 AND stat_id < 190800;
```

Name 中 Batch 和 Multi 语义的区别如下：

* Multi 指同一类单操作的 Batch。
* Batch Scan, 多个 Scan 的 Batch。
* Batch Hybird, 混合 batch, 比如不同类单操作的 Batch。
