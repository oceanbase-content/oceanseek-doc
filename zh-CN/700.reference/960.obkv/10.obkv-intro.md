# OBKV 简介

OBKV 是构建在 OceanBase AI 数据库分布式存储引擎之上的 NoSQL 产品系列，目前支持 OBKV-Table、OBKV-HBase 两种产品形态，原生继承了 OceanBase AI 数据库的高性能、事务、分布式、多租户、高可靠的基础能力。此外，OceanBase AI 数据库的工具体系（比如 OCP、OMS、CDC 等）也原生支持 OBKV，运维 OBKV 的各个产品形态和运维 OceanBase AI 数据库的 SQL 集群完全一样。OBKV 可以帮助企业统一技术栈，在满足业务对多模 NoSQL 数据库诉求的同时，减少企业在数据库运维上的复杂度。

## 模型介绍

### OBKV-Table

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>OBKV-Table 仅支持 Java 客户端。</p>
</main>

提供基于表格的海量存取能力，提供全局/局部二级索引，丰富的过滤查询，TTL等能力。适用于没有复杂查询诉求，但是有极高性能要求的海量数据存取业务。

有关 OBKV-Table 的详细信息，参见 [OBKV-Table 简介](100.obkv-table/100.introduction-to-obkv-table/100.implementation-of-obkv-table.md)。

### OBKV-HBase

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>OBKV-HBase 仅支持 Java 客户端。</p>
</main>

提供兼容 HBase 接口的宽表服务，读取性能是开源 HBase 的数倍，成本相较开源 HBase 更低，可参见[OBKV-HBase 适用场景](200.obkv-hbase/10.obkv-hbase-intro.md)。

有关 OBKV-HBase 的详细信息，参见 [OBKV-HBase 简介](200.obkv-hbase/10.obkv-hbase-intro.md)。
