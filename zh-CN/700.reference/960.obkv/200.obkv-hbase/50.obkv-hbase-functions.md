# OBKV-HBase 核心功能

## HBase 模型功能

### 基础功能

| **功能** | **描述** |
|---|---|
| HBase 兼容 | <ul><li>以接口的形式兼容 HBase 0.94 以及 1.1.13 大部分功能</li><li>支持[常用接口](700.obkv-hbase-reference/150.obkv-hbase-interface-compatibility.md)，比如 put、get、exists、delete、append、increment、scan 等</li></ul> |
| 行锁支持 | 支持 HBase 行锁 |
| [多列族操作](200.obkv-hbase-develop/300.obkv-hbase-demo.md) | put、delete、get、scan 接口支持多列族 |
| 二级分区 | 支持二级分区 |
| 表模型 | 除普通表模型外，也支持时序表模型 |
| Filter | <ul><li>支持 CompareFilter、SingleColumnValueFilter、PageFilter、ColumnCountGetFilter、PrefixFilter、SkipFilter、WhileMatchFilter、PageFilter、ColumnPrefixFilter、ColumnPaginationFilter、FirstKeyOnlyFilter、KeyOnlyFilter、RandomRowFilter、TimestampsFilter 等 Filter</li><li>支持基于 FilterList 的多 Filter</li></ul> |
| 生态 | <ul><li>支持 Flink 接入 OBKV-HBase</li></ul> |
| 开发工具 | <ul><li>不支持 HBase shell</li><li>支持通过 MySQL 客户端来访问 HBase 表中的数据</li></ul> |

### 性能优化功能

| **功能** | **描述** |
|---|---|
| [TTL](700.obkv-hbase-reference/500.obkv-hbase-ttl.md) | <ul><li>表级别 TTL（TTL 策略设置在表上，所有行基于表级策略过期）</li><li>支持过期数据实时不可见</li></ul><main id="notice" type='notice'><h4>注意</h4><p>过期数据删除（TTL）功能仅限于 OceanSeek KV 场景使用，SQL 场景下禁用，否则会导致不可预期的数据误删除问题。</p></main> |
| MaxVersion | <ul><li>支持设置最多维护的版本数，并且配合 TTL 后台异步删除多余的版本</li></ul> |
| [弱读和就近读](700.obkv-hbase-reference/600.obkv-hbase-weak-read.md) | <ul><li>支持弱读功能，允许客户端从非主副本（如 Follower 或 Replica）读取数据。此模式下读取数据会产生略微延迟，但能够提升读取性能和系统可用性。</li><li>支持就近读功能，客户端优先选择与自身地理位置或网络距离最近的机房副本读取数据，降低网络延迟，提高访问速度与用户体验。</li></ul> |
| [自动分区分裂](700.obkv-hbase-reference/400.obkv-hbase-auto-partition.md) | <ul><li>支持自动分区分裂功能，当表数据量达到一定阈值时，自动进行分区分裂，提高查询性能和系统可用性。</li></ul> |

## 高级功能

|**功能**|**描述**|
|---|---|
| 事务 | <ul><li>单操作支持行级事务</li><li>Batch 操作支持单机事务</li><li>暂不提供跨节点的分布式事务</li></ul>|
| 容灾 | 复用 OceanSeek 已有的所有容灾能力，比如多副本架构、主备库、 两地三中心、 三地五中心部署。 |
| 多租户 | 复用 OceanSeek 多租户能力 |
| 扩展性 | 复用 OceanSeek 的数据分区、弹性扩缩容能力 |
| 备份恢复 | 复用 OceanSeek 的备份恢复能力 |
| 监控指标 | 支持服务端和客户端监控指标，包括 QPS/RT/ROWS 相关指标、直方图性能指标等。详情请参见 [OBKV-HBase 监控指标](300.obkv-hbase-manage/200.obkv-hbase-monitor-items.md) |
| 数据压缩 | 存储数据压缩 |
| 数据加密 | 支持 TDE 透明加密 |

## OBKV-HBase 客户端兼容

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>OBKV-HBase 仅支持 Java 客户端。</p>
</main>

obkv-hbase-client-java 客户端版本规划如下：

* 1.X 的客户端版本兼容 HBase 1.X 业务场景。
* 2.X 的客户端版本兼容 HBase 2.X 业务场景。

具体功能如下：

|**obkv-hbase-client-java 1.X 客户端版本**|**版本动态**|
|---|---|
| 1.1.0 | 支持分区分裂功能和 batch get 操作。 |

|**obkv-hbase-client-java 2.X 客户端版本**|**版本动态**|
|---|---|
| 2.1.0 | 支持分区分裂功能和 batch get 操作。 |
