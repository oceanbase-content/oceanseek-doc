# OBKV-HBase 应用开发概述

OBKV-HBase 支持通过 OBKV-HBase 客户端连接 OBKV-HBase 集群使用 HBase 兼容的 API 进行数据处理。若您当前有业务使用了原生 HBase 数据操作逻辑，您可以通过部署 OceanSeek 集群，在 OBServer 服务端创建 HBase Table，并通过 OBKV-HBase 客户端进行数据操作。  

## OBKV-HBase 数据模型

您可以使用宽表模型（WideColumn）对数据建模，以便更好的兼容 HBase 的数据及后续通过 OBKV-Hbase 维护。详细信息，参见 [OBKV-HBase 数据模型](../700.obkv-hbase-reference/50.obkv-hbase-data-model.md) 和 [数据库模型设计](../700.obkv-hbase-reference/100.obkv-hbase-schema-design.md)。

如果您想了解 HBase 存储模型的详细内容，请参考 [Apache HBase 数据模型](https://hbase.apache.org/book.html#datamodel)。  

## 使用 OBKV-HBase Java 客户端进行应用开发

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>OBKV-HBase 仅支持 Java 客户端。</p>
</main>

您可以通过 OBKV-HBase Java 客户端，使用 HBase 兼容的 API 进行数据处理。具体操作，参见 [使用 OBKV-HBase Java 客户端连接集群](200.connecting-by-using-obkv-hbase-client.md)。  

## 数据操作示例

关于 OBKV-HBase 的使用示例，参见 [数据操作示例](300.obkv-hbase-demo.md)。 

如果您想对 HBase 有更深入的了解，请参考 [Apache HBase 官方网站](https://hbase.apache.org/)、[Apache HBase interface 接口](https://hbase.apache.org/1.1/apidocs/org/apache/hadoop/hbase/client/Table.html)。  

## 接口和 Filter 列表

OBKV-HBase 客户端实现了 [HTableInterface](https://svn.apache.org/repos/asf/hbase/hbase.apache.org/trunk/0.94/apidocs/org/apache/hadoop/hbase/client/HTableInterface.html) 的接口：

* 已支持的接口列表，参见 [兼容 HBase 的接口](../700.obkv-hbase-reference/150.obkv-hbase-interface-compatibility.md)。
* 已支持的 Filter 列表，参见 [兼容 HBase 的 Filter](../700.obkv-hbase-reference/200.obkv-hbase-filter-compatibility.md)。
