# 迁移 HBase 业务代码至 OBKV-HBase

OBKV-HBase 已支持兼容 HBase 1.x/2.x 版本，本文介绍如何通过只修改配置文件的方式，将业务代码从 HBase 客户端迁移到 OBKV-HBase 客户端。

## 准备工作

如果没有通过 OMS 进行结构迁移，且 OBServer 中没有建立好原客户端代码中对应的表，请参考 [使用 OBKV-HBase Java 客户端连接集群](../200.obkv-hbase-develop/200.connecting-by-using-obkv-hbase-client.md) 创建对应的 OBKV-HBase 表。

## 迁移代码

### 添加 OBKV-HBase 客户端依赖

在项目的 pom.xml 文件中添加 OBKV-Hbase 客户端依赖，如果你之前使用的是 Hbase 1.x 版本，那么对应 OBKV-HBase 1.x.x；如果之前使用的是 Hbase 2.x 版本，则对应 OBKV-HBase 2.x.x 版本。

```xml
 <dependencies>
    <dependency>
        <groupId>com.oceanbase</groupId>
        <artifactId>obkv-hbase-client</artifactId>
        <version>2.1.0</version>
    </dependency>
</dependencies>
```

<main id="notice" type='notice'>
  <h4>注意</h4>
  <ul>
  <li>尽量使用最新版本 jar 包，旧版本的 jar 包可能不支持新的服务端。</li>
  <li>这里的版本号可能不是最新的，参考<a href="https://mvnrepository.com/artifact/com.oceanbase/obkv-hbase-client">中央仓库</a>的已发布 OBKV-HBase 版本，将版本号替换为已发布的最新版本号。</li>
  </ul>
</main>

### 设置 OBKV-HBase 客户端连接参数

此步骤需要在 OBKV-HBase 客户端配置文件中设置 Connection 类型为 OHConnectionImpl，并且添加 OBKV-Hbase 连接相关参数：

* 如果当前 HBase 客户端使用的是 org.apache.hadoop.hbase.HBaseConfiguration，修改配置文件 `hbase-site.xml`。
* 如果当前 HBase 客户端使用的是 rg.apache.hadoop.conf.Configuration，修改配置文件 `core-site.xml`。

#### 修改 Connection 类型

修改 HBase Connection 的实现为 OHConnectionImpl，后续通过 ConnectionFactory 创建的连接即为 OHConnectionImpl。

```Java
<configuration>
    <property>
      <name>hbase.client.connection.impl</name>
      <value>com.alipay.oceanbase.hbase.util.OHConnectionImpl</value>
    </property>
</configuration>
```

#### 添加 OBKV-HBase 客户端连接参数

此步骤需要添加 OBKV-HBase 的连接参数，用于初始化 OHConnectionImpl，此处以 ODP 模式为例（直连模式下需要设置的参数不同）。关于参数的说明请参见 [使用 OBKV-HBase 客户端连接集群](../200.obkv-hbase-develop/200.connecting-by-using-obkv-hbase-client.md) 中 云上模式配置（公有云）和 直连模式配置 (私有化部署) 部分。

```xml
<configuration>
    <property>
        <name>hbase.oceanbase.fullUserName</name>
        <value>your user name</value>
    </property>
    <property>
        <name>hbase.oceanbase.password</name>
        <value>your user password</value>
    </property>
    <property>
        <name>hbase.oceanbase.odpAddr</name>
        <value>your odp addr</value>
    </property>
    <property>
        <name>hbase.oceanbase.odpPort</name>
        <value>3307</value>
    </property>
    <property>
        <name>hbase.oceanbase.odpMode</name>
        <value>true</value>
    </property>
    <property>
        <name>hbase.oceanbase.database</name>
        <value>your database</value>
    </property>
</configuration>
```
