# 通过 Hive 访问 OBKV-HBase

Apache Hive 是一个基于 Apache Hadoop 的数据仓库软件，它允许用户使用 SQL 进行大规模数据集的读写和管理。Hive 的主要功能包括分布式存储、容错能力，以及大规模数据分析。它简化了对存储在分布式系统中的数据的查询和分析过程，为数据分析提供了便利。

本文介绍了如何使用 Hive 直接访问 OBKV-HBase，且无需进行代码修改。

## 准备工作

在开始使用 Hive 访问 OBKV-HBase 之前，需要确保以下条件已满足：

* 使用 OBKV-HBase Java 客户端版本 2.0.0-alpha4 及更高版本，以支持原生 Hive 能力。
* 确保 Hive 版本在 3.0.0 到 3.1.3 之间。

## 建表

使用 Hive 访问 OBKV-HBase 宽表时，有两种建表方式：

* 使用 [HBase Admin createTable 接口](../700.obkv-hbase-reference/150.obkv-hbase-interface-compatibility.md) 建表。
* 通过 SQL 建表。如果通过 SQL 建表，需按照 OBKV-HBase 建表规则建表。建表规则请参考 [OBKV-HBase 数据操作示例](../200.obkv-hbase-develop/300.obkv-hbase-demo.md)。

## 设置 OBKV-HBase 客户端连接参数

OBKV-HBase 在公有云和私有化部署方式下，客户端连接参数的设置方式不同。对于私有化部署的 OceanSeek 集群，需要按照 **直连模式配置** 进行设置，而对于公有云 OBKV 服务，则需要按照 **云上模式** 进行设置。

无论是哪种部署方式，所有的配置项都可以通过以下两种方式进行设置：

* 在 Hive 客户端配置文件 `hive-site.xml` 中进行设置。
* 通过 Hive Configuration 的 `set` 方法在代码中 Connection 初始化之前进行设置。

### 直连模式配置

直连模式适用于私有化部署的 OceanSeek 集群。它通过 `Configurl` 直接连接 OceanSeek 集群，`Configurl` 用于获取 OceanSeek 底层服务器的真实地址。以下是直连模式在 Hive 中配置连接参数的方法：

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p><code>paramURL</code> 会包含 xml 特殊字符 <code>&</code>，需要将其转换成 <code>&amp;</code>，否则会解析失败。</p>
</main>

* 方式一：在 Hive 的配置文件 `hive-site.xml` 中配置以下配置项：

    ```xml
    <!-- 
    假设当前集群如下
    ClusterName：obkvcluster
    TenantName：obkv
    DataBaseName: test
    UserName：root
    UserPassWord: 
    SYS_USER_NAME : sysroot 
    SYS_USER_PASSWD:
    -->

    <configuration>
    <!-- OceanSeek HBase 实现类替换 -->
    <property>
        <name>hbase.client.connection.impl</name>
        <value>com.alipay.oceanbase.hbase.util.OHConnectionImpl</value>
    </property>
    
    <!-- OceanSeek 连接配置 -->
    <property>
        <!-- 从 obconfig server 获取 RSlist 的 URL，详见 Config URL 获取相关内容 -->
        <name>hbase.oceanbase.paramURL</name>
        <value>PARAM_URL</value>
    </property>
    <property>
        <!-- 格式为 userName@tenantName#clusterName  -->
        <name>hbase.oceanbase.fullUserName</name>
        <value>root@obkv#obkvcluster</value>
    </property>
    <property>
        <!-- fullUserName 中 userName 访问 OceanSeek 的密码 -->
        <name>hbase.oceanbase.password</name>
        <value></value>
    </property>
    <property>
        <!-- 系统租户下的用户名, 只有系统租户下的用户才有权限访问路由表 -->
        <name>hbase.oceanbase.sysUserName</name>
        <value>sysroot</value>
    </property>
    <property>
        <!-- 系统租户下的用户密码 -->
        <name>hbase.oceanbase.sysPassword</name>
        <value></value>
    </property>
    </configuration>
    ```

* 方式二：在代码中，通过 HiveConf 配置参数

    ```java
    /*
    * 假设当前集群如下
    * ClusterName：obkvcluster
    * TenantName：obkv
    * DataBaseName: test
    * UserName：root
    * UserPassWord: 
    * SYS_USER_NAME : sysroot 
    * SYS_USER_PASSWD:
    */
    HiveConf conf = new HiveConf();
    conf.set("hbase.client.connection.impl", "com.alipay.oceanbase.hbase.util.OHConnectionImpl")
    conf.set("hbase.oceanbase.fullUserName", "root@obkv#obkvcluster");
    conf.set("hbase.oceanbase.password", "");
    // 从 obconfig server 获取 RSlist 的 URL，详见下文 Config URL 获取相关内容
    conf.set("hbase.oceanbase.paramURL", "");
    conf.set("hbase.oceanbase.sysUserName", "sysroot");
    conf.set("hbase.oceanbase.sysPassword", "");
    ```

### 云上模式配置

云上模式适用于公有云部署的 OceanSeek 集群。它通过 ODP 连接 OceanSeek 集群。以下是云上模式在 Hive 中配置连接参数的方法：

* 方式一：在 Hive 的配置文件 `hive-site.xml` 中配置以下配置项：

    ```xml
    <!--
    假设当前集群如下
    DataBaseName: test
    UserName：root
    <configuration>
    -->
    <!-- OceanSeek HBase实现类替换 -->
    <property>
        <name>hbase.client.connection.impl</name>
        <value>com.alipay.oceanbase.hbase.util.OHConnectionImpl</value>
    </property>

    <!-- OceanSeek 连接配置 -->
    <configuration>
        <property>
            <name>hbase.oceanbase.fullUserName</name>
            <value>root</value>
        </property>
        <property>
            <name>hbase.oceanbase.password</name>
            <value></value>
        </property>
        <property>
            <!-- 详见 ODP Address 获取相关内容 -->
            <name>hbase.oceanbase.odpAddr</name>
            <value></value>
        </property>
        <property>
            <name>hbase.oceanbase.odpPort</name>
            <value>3307</value>
        </property>
        <property>
            <name>hbase.oceanbase.odpMode</name>
            <value>true</value>
        </property>
        <property>
            <name>hbase.oceanbase.database</name>
            <value>test</value>
        </property>
    </configuration>
    ```

* 方式二：在代码中，通过 HiveConf 配置参数：

    ```java
    /*
    * 假设当前集群如下
    * DataBaseName: test
    * UserName：root
    */
    HiveConf conf = new HiveConf();
    conf.set("hbase.client.connection.impl", "com.alipay.oceanbase.hbase.util.OHConnectionImpl")
    conf.set(HBASE_OCEANBASE_FULL_USER_NAME, "root");    
    // 用户 Password
    conf.set(HBASE_OCEANBASE_PASSWORD, "");       
    // 详见 ODP Address 备注
    conf.set(HBASE_OCEANBASE_ODP_ADDR, "");        

    // OBKV 的端口是 3307（固定）
    conf.setInt(HBASE_OCEANBASE_ODP_PORT, "3307");     

    // 云上使用 ODP 模式（固定）
    conf.setBoolean(HBASE_OCEANBASE_ODP_MODE, true);  

    // 数据库的 database 的名字
    conf.set(HBASE_OCEANBASE_DATABASE, "test");
    ```

</main>

## 使用示例

### 依赖引入

在项目 `pom.xml` 中引入 OBKV-HBase 依赖：

```xml
<dependency>
  <groupId>com.oceanbase</groupId>
  <artifactId>obkv-hbase-client</artifactId>
  <version>2.2.1</version>
</dependency>
```

引入 Hive 依赖，注意引入 `Hive-HbaseHandler` 的时候需要剔除 Hive 自带的 `hbase-common` 和 `hadoop-common` 依赖，以免和 OBKV-HBase 的依赖冲突：

```xml
<!-- Hive JDBC Driver -->
<dependency>
    <groupId>org.apache.hive</groupId>
    <artifactId>hive-jdbc</artifactId>
    <version>${hive.version}</version>
    <exclusions>
        <exclusion>
            <groupId>org.apache.hadoop</groupId>
            <artifactId>hadoop-common</artifactId>
        </exclusion>
        <exclusion>
            <groupId>org.apache.hbase</groupId>
            <artifactId>hbase-common</artifactId>
        </exclusion>
    </exclusions>
</dependency>

<!-- Hive HBase Handler -->
<dependency>
    <groupId>org.apache.hive</groupId>
    <artifactId>hive-hbase-handler</artifactId>
    <version>${hive.version}</version>
    <exclusions>
        <exclusion>
            <groupId>org.apache.hbase</groupId>
            <artifactId>hbase-common</artifactId>
        </exclusion>
    </exclusions>
</dependency>
```

### Hive 读写示例

Hive 读写 OBKV-HBase 的示例包括创建外表、查询外表、插入数据等。

#### Hive 创建外表

创建外表的语法如下：

```sql
CREATE EXTERNAL TABLE if not exists {HiveTableName}(key string, value string)
STORED BY 'org.apache.hadoop.hive.hbase.HBaseStorageHandler'
WITH SERDEPROPERTIES ("hbase.columns.mapping" = ":key,{HbaseFamilyName}:{HbaseQualifiername}")
TBLPROPERTIES ("hbase.table.name" = "{HbaseTableName}", "hbase.mapred.output.outputtable" = "{HbaseTableName}");
```

其中：

* `HiveTableName` 是 Hive 中外表的表名。
* `HbaseFamilyName` 用于指定 HBase 中的 Column Family 名。
* `HbaseQualifiername` 用于指定 HBase 中的 Qualifier 名。
* `hbase.table.name` 用于指定对应的 HBase 表名。
* `hbase.mapred.output.outputtable` 用于指定写入时的目标 HBase 表名。

#### 读写示例

为 OBKV 表创建 Hive 外表：

```sql
hive> CREATE EXTERNAL TABLE IF NOT EXISTS user_behavior_analysis(
    >   user_id string,           -- 映射到 OBKV 的 K 字段
    >   user_name string,         -- 映射到 Q='user_name' 的 V 值
    >   user_age string,          -- 映射到 Q='user_age' 的 V 值  
    >   user_city string,         -- 映射到 Q='user_city' 的 V 值
    >   total_orders string,      -- 映射到 Q='total_orders' 的 V 值
    >   total_amount string,      -- 映射到 Q='total_amount' 的 V 值
    >   last_login string         -- 映射到 Q='last_login' 的 V 值
    > )
    > STORED BY 'org.apache.hadoop.hive.hbase.HBaseStorageHandler'
    > WITH SERDEPROPERTIES (
    >   "hbase.columns.mapping" = ":key,user_behavior:user_name,
    >                               user_behavior:user_age,
    >                               user_behavior:user_city,
    >                               user_behavior:total_orders,
    >                               user_behavior:total_amount,
    >                               user_behavior:last_login"
    > )
```
