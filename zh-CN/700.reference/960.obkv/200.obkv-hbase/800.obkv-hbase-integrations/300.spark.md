# 通过 Spark 访问 OBKV-HBase

Apache Spark 是一个开源的、快速且通用的大数据处理引擎，专为大规模数据集的批处理和流处理而设计。它在 Hadoop 生态系统中扮演着核心角色，但相比传统的 MapReduce 模型，Spark 提供了更高效的数据处理能力。

本文介绍了如何使用 Spark 直接访问 OBKV-HBase，且无需进行代码修改。

## 准备工作

在开始使用 Spark 访问 OBKV-HBase 之前，需要确保以下条件已满足：

* 使用 OBKV-HBase Java 客户端版本 2.2.1/1.2.1 及更高版本，以支持原生 Spark 能力。
* 引入 Spark-HBase 依赖时需要避免引入其自带 HBase 版本，以免和 OBKV-HBase Java 客户端依赖的 HBase 版本冲突。
* 确保 Spark 版本为 3.0.1 以下。

## 建表

使用 Spark 访问 OBKV-HBase 宽表时，有两种建表方式：

* 通过 [HBase Admin createTable 接口](../700.obkv-hbase-reference/150.obkv-hbase-interface-compatibility.md) 建表。
* 通过 SQL 建表。如果通过 SQL 建表，需按照 OBKV-HBase 建表规则建表，建表规则请参考 [OBKV-HBase 数据操作示例](../200.obkv-hbase-develop/300.obkv-hbase-demo.md)。

## 设置 OBKV-HBase 客户端连接参数

OBKV-HBase 客户端连接参数用于建立和 Oceanbase 集群之间的连接。OBKV-HBase 在公有云和私有化部署方式下，客户端连接参数的设置方式不同。对于私有化部署的 OceanSeek 集群，需要按照 **直连模式配置** 进行设置，而对于公有云 OBKV 服务，则需要按照 **云上模式** 进行设置。具体 OBKV-HBase 客户端连接集群教程请参考 [使用 OBKV-HBase 客户端连接集群](../200.obkv-hbase-develop/200.connecting-by-using-obkv-hbase-client.md)。

无论是哪种部署方式，所有的配置项都可以通过以下两种方式进行设置：

* 在配置文件 `hbase-site.xml` 中进行设置。
* 通过 Hadoop Configuration 的 `set` 方法在代码中 Connection 初始化之前进行设置。

### 直连模式配置

直连模式适用于私有化部署的 OceanSeek 集群。它通过 `Configurl` 直接连接 OceanSeek 集群，`Configurl` 用于获取 OceanSeek 底层服务器的真实地址。以下是直连模式在 Spark 中配置连接参数的方法：

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>paramURL 会包含 xml 特殊字符 &，需要将其转换成 &amp;，否则会解析失败</p>
</main>

* 方式一：在 `hbase-site.xml` 配置文件中配置以下配置项：

    ```xml
    <!-- 
    假设当前集群如下
    ClusterName：obkvcluster
    TenantName：obkv
    DataBaseName: test
    UserName：root
    UserPassWord: 
    SYS_USER_NAME : sysroot 
    SYS_USER_PASSWD:
    -->
    <configuration>
    <!-- OceanSeek HBase 实现类替换 -->
    <property>
        <name>hbase.client.connection.impl</name>
        <value>com.alipay.oceanbase.hbase.util.OHConnectionImpl</value>
    </property>
    
    <!-- OceanSeek 连接配置 -->
    <property>
        <!-- 从 obconfig server 获取 RSlist 的 URL，详见下文 Config URL 获取相关内容-->
        <name>hbase.oceanbase.paramURL</name>
        <value>PARAM_URL</value>
    </property>
    <property>
        <!-- 格式为 userName@tenantName#clusterName  -->
        <name>hbase.oceanbase.fullUserName</name>
        <value>root@obkv#obkvcluster</value>
    </property>
    <property>
        <!-- fullUserName 中 userName 访问 OceanSeek 的密码 -->
        <name>hbase.oceanbase.password</name>
        <value></value>
    </property>
    <property>
        <!-- 系统租户下的用户名, 只有系统租户下的用户才有权限访问路由表 -->
        <name>hbase.oceanbase.sysUserName</name>
        <value>sysroot</value>
    </property>
    <property>
        <!-- 系统租户下的用户密码 -->
        <name>hbase.oceanbase.sysPassword</name>
        <value></value>
    </property>
    </configuration>
    ```

* 方式二：在代码中往 Hadoop Configuration 中配置参数，通过 `set` 方法在代码中 Connection 初始化之前进行设置：

    ```java
    /*
    * 假设当前集群如下
    * ClusterName：obkvcluster
    * TenantName：obkv
    * DataBaseName: test
    * UserName：root
    * UserPassWord: 
    * SYS_USER_NAME : sysroot 
    * SYS_USER_PASSWD:
    */
    Configuration conf = HBaseConfiguration.create();
    conf.set("hbase.client.connection.impl", "com.alipay.oceanbase.hbase.util.OHConnectionImpl")
    conf.set("hbase.oceanbase.fullUserName", "root@obkv#obkvcluster");
    conf.set("hbase.oceanbase.password", "");
    // 从 obconfig server 获取 RSlist 的 URL，详见下文 Config URL 获取相关内容
    conf.set("hbase.oceanbase.paramURL", "");
    conf.set("hbase.oceanbase.sysUserName", "sysroot");
    conf.set("hbase.oceanbase.sysPassword", "");
    ```

### 云上模式配置

云上模式适用于公有云部署的 OceanSeek 集群。它通过 ODP 连接 OceanSeek 集群。以下是云上模式在 Spark 中配置连接参数的方法：

* 方式一：在 `hbase-site.xml` 配置文件中配置以下配置项：

    ```xml
    <!--
    假设当前集群如下
    DataBaseName: test
    UserName：root
    <configuration>
    -->
    <!-- OceanSeek HBase 实现类替换 -->
    <property>
        <name>hbase.client.connection.impl</name>
        <value>com.alipay.oceanbase.hbase.util.OHConnectionImpl</value>
    </property>

    <!-- OceanSeek 连接配置 -->
    <configuration>
        <property>
            <name>hbase.oceanbase.fullUserName</name>
            <value>root</value>
        </property>
        <property>
            <name>hbase.oceanbase.password</name>
            <value></value>
        </property>
        <property>
            <!--详见下文获取 ODP Address-->
            <name>hbase.oceanbase.odpAddr</name>
            <value></value>
        </property>
        <property>
            <name>hbase.oceanbase.odpPort</name>
            <value>3307</value>
        </property>
        <property>
            <name>hbase.oceanbase.odpMode</name>
            <value>true</value>
        </property>
        <property>
            <name>hbase.oceanbase.database</name>
            <value>test</value>
        </property>
    </configuration>
    ```

* 方式二：在代码中往 Hadoop Configuration 中配置参数，通过 set 方法在代码中 Connection 初始化之前进行设置：

```java
/*
* 假设当前集群如下
* DataBaseName: test
* UserName：root
*/
Configuration conf = HBaseConfiguration.create();
conf.set("hbase.client.connection.impl", "com.alipay.oceanbase.hbase.util.OHConnectionImpl")
conf.set(HBASE_OCEANBASE_FULL_USER_NAME, "root");    
// 用户密码
conf.set(HBASE_OCEANBASE_PASSWORD, "");       
// 详见 ODP Address 备注
conf.set(HBASE_OCEANBASE_ODP_ADDR, "");        
// OBKV 的端口是 3307（固定）
conf.setInt(HBASE_OCEANBASE_ODP_PORT, "3307");     
// 云上使用 ODP 模式(固定)
conf.setBoolean(HBASE_OCEANBASE_ODP_MODE, true);  
// 数据库的 database 的名字
conf.set(HBASE_OCEANBASE_DATABASE, "test");
```

## 使用示例

### 依赖引入

引入 OBKV-HBase 依赖：

```xml
<!-- OBKV-HBase 依赖，内含 hbase-client hadoop-common -->
<dependency>
  <groupId>com.oceanbase</groupId>
  <artifactId>obkv-hbase-client</artifactId>
  <version>2.2.1</version>
</dependency>
```

为确保 OBKV-HBase 和 Spark 的无缝集成，我们建议使用 Spark 3.0.1 版本依赖，并与 `hbase-spark` 依赖进行集成。以下是引入 Spark 依赖时需要注意的事项：

* 在引入 `hbase-spark` 依赖时，需要排除 Spark 自带的 `hbase-client` 和 `hadoop-common` 依赖，以避免与 OBKV-HBase 的依赖冲突。
* 在引入 OBKV-HBase 依赖时，需要排除 `jackson-databind` 依赖，以避免与 Spark 使用的对应版本冲突，导致版本检测不通过。

```xml
<!-- OBKV-HBase 依赖 -->
<dependency>
  <groupId>com.oceanbase</groupId>
  <artifactId>obkv-hbase-client</artifactId>
  <version>${hbase.client.version}</version>
  <exclusions>
    <exclusion>
      <artifactId>jackson-databind</artifactId>
      <groupId>com.fasterxml.jackson.core</groupId>
    </exclusion>
  </exclusions>
</dependency>
<!-- Spark 依赖 -->
<dependency>
  <groupId>org.apache.spark</groupId>
  <artifactId>spark-core_2.12</artifactId>
  <version>${spark.version}</version>
</dependency>
<dependency>
  <groupId>org.apache.spark</groupId>
  <artifactId>spark-sql_2.12</artifactId>
  <version>${spark.version}</version>
</dependency>
<dependency>
  <groupId>org.apache.spark</groupId>
  <artifactId>spark-streaming_2.12</artifactId>
  <version>${spark.version}</version>
</dependency>
<!-- Spark 和 HBase 连接器依赖 -->
<dependency>
  <groupId>org.apache.hbase.connectors.spark</groupId>
  <artifactId>hbase-spark</artifactId>
  <version>${hbase.spark.version}</version>
  <exclusions>
    <exclusion>
      <groupId>org.apache.hbase</groupId>
      <artifactId>hbase-client</artifactId>
    </exclusion>
    <exclusion>
      <groupId>org.apache.hadoop</groupId>
      <artifactId>hadoop-common</artifactId>
    </exclusion>
  </exclusions>
</dependency>
```

### Spark 读写示例

以下是 Spark 读写 OBKV-HBase 的示例，包括表结构、读写数据和 Spark SQL 读写数据。

#### 表结构

假设当前有 OBKV-HBase 表：

```sql
-- 创建表组
CREATE TABLEGROUP `spark_demo` SHARDING = 'ADAPTIVE';

-- 创建表
CREATE TABLE `spark_demo$cf1` (
    `K` varbinary(1024) NOT NULL,
    `Q` varbinary(256) NOT NULL,
    `T` bigint(20) NOT NULL,
    `V` varbinary(1024) DEFAULT NULL,
    PRIMARY KEY (`K`, `Q`, `T`)
) TABLEGROUP = `spark_demo` partition by key(`K`) partitions 17;
CREATE TABLE `spark_demo$cf2` (
    `K` varbinary(1024) NOT NULL,
    `Q` varbinary(256) NOT NULL,
    `T` bigint(20) NOT NULL,
    `V` varbinary(1024) DEFAULT NULL,
    PRIMARY KEY (`K`, `Q`, `T`)
) TABLEGROUP = `spark_demo` partition by key(`K`) partitions 17;
```

#### 通过 Hadoop `TableInputForamt`/`TableOutputFormat` 和 Spark RDD 读写数据

通过结合使用 Hadoop 的 `TableInputFormat` 和 `TableOutputFormat`，以及 Spark 的 RDD，实现了对数据的读写操作。由于 Spark 使用 OBKV-HBase 的 Java API 进行读写，因此无需配置 `hbase.zookeeper.quorum`。这种配置方式能够充分利用 OceanSeek 的分布式集群能力。

```java
// 写入数据
public void testSparkReadAfterWriteHBase() throws Exception {
    // Initialize SparkContext
    SparkConf sparkConf = new SparkConf().setAppName("HBaseWriteExample").setMaster("local");
    JavaSparkContext jsc = new JavaSparkContext(sparkConf);
    // Configure HBase for write
    Configuration hbaseConf = HBaseConfiguration.create();
    hbaseConf.set(TableOutputFormat.OUTPUT_TABLE, "spark_demo");
    hbaseConf.set("mapreduce.job.output.key.class", ImmutableBytesWritable.class.getName());
    hbaseConf.set("mapreduce.job.output.value.class", Put.class.getName());
    hbaseConf.set("mapreduce.outputformat.class", TableOutputFormat.class.getName());
    // Create RDD data (Key: RowKey, Value: Tuple of (ColumnFamily, ColumnName, Value))
    JavaRDD<Tuple2<byte[], Tuple3<String, String, String>>> data = jsc.parallelize(Arrays.asList(
        new Tuple2<>(Bytes.toBytes(row1), new Tuple3<>(family1, "name", john_name)),
        new Tuple2<>(Bytes.toBytes(row1), new Tuple3<>(family1, "age", john_age)),
        new Tuple2<>(Bytes.toBytes(row1), new Tuple3<>(family1, "gender", john_gender)),
        new Tuple2<>(Bytes.toBytes(row2), new Tuple3<>(family1, "name", lily_name)),
        new Tuple2<>(Bytes.toBytes(row2), new Tuple3<>(family1, "age", lily_age)),
        new Tuple2<>(Bytes.toBytes(row2), new Tuple3<>(family1, "gender", lily_gender)),
        new Tuple2<>(Bytes.toBytes(row3), new Tuple3<>(family1, "name", walter_name)),
        new Tuple2<>(Bytes.toBytes(row3), new Tuple3<>(family1, "age", walter_age)),
        new Tuple2<>(Bytes.toBytes(row3), new Tuple3<>(family1, "gender", walter_gender))
    ));
    // Map RDD to HBase format (ImmutableBytesWritable, Put)
    JavaPairRDD<ImmutableBytesWritable, Put> hbaseWriteRDD = data.mapToPair(tuple -> {
        byte[] rowKey = tuple._1;
        String family = tuple._2._1();
        String qualifier = tuple._2._2();
        String value = tuple._2._3();
    
        Put put = new Put(rowKey);
        put.addColumn(Bytes.toBytes(family), Bytes.toBytes(qualifier), Bytes.toBytes(value));
        return new Tuple2<>(new ImmutableBytesWritable(rowKey), put);
    });
    // Write the data to HBase
    hbaseWriteRDD.saveAsNewAPIHadoopDataset(hbaseConf);
    // Read from HBase
    hbaseConf.set(TableInputFormat.INPUT_TABLE, "spark_demo");
    Scan scan = new Scan();
    scan.addFamily(Bytes.toBytes(family1));
    scan.addFamily(Bytes.toBytes(family2));
    scan.setCaching(100);
    String scanToString = org.apache.hadoop.hbase.mapreduce.TableMapReduceUtil.convertScanToString(scan);
    hbaseConf.set(TableInputFormat.SCAN, scanToString);
    JavaPairRDD<ImmutableBytesWritable, Result> hbaseReadRDD = jsc.newAPIHadoopRDD(
        hbaseConf,
        TableInputFormat.class,
        ImmutableBytesWritable.class,
        Result.class
    );
    // Process the data
    hbaseReadRDD.flatMapToPair(tuple -> {
        ImmutableBytesWritable key = tuple._1();
        Result result = tuple._2();
        String rowKey = Bytes.toString(key.get());
        List<Tuple2<String, String>> res = new ArrayList<>();
        for (Cell c : result.rawCells()) {
            String familyValue = Bytes.toString(CellUtil.cloneValue(c));
            String column = Bytes.toString(CellUtil.cloneQualifier(c));
                    Tuple2<String, String> value = new Tuple2<>(rowKey, String.format("Get result from cf1: K: %s, Q: %s, V: %s", Bytes.toString(result.getRow()), column, familyValue));
                    res.add(value);
        }
                return res.iterator();
    }).collect().forEach(System.out::println);
    // Stop SparkContext
    jsc.stop();
}
```

#### 通过 SparkSession SQL 读取数据

Spark SQL 仅支持从 HBase 中读取数据。OBKV-HBase 目前尚不支持 SparkSQLPushDownFilter 过滤器。禁止该过滤器需要将 SparkSession 的 `hbase.spark.pushdown.columnfilter` 参数设置成 `false`，该参数默认为 `true`。示例如下：

```java
public void testSparkSessionSQLHBase() throws Exception {
    SparkConf conf = new SparkConf().setAppName("SparkSQLHBaseExample").setMaster("local[*]");
    conf.set("spark.sql.defaultUrlStreamHandlerFactory.enabled", "false"); // avoid Connection Casting Exception
    JavaSparkContext jsc = new JavaSparkContext(conf);
    // Initialize SparkSession
    SparkSession spark = SparkSession.builder()
            .appName("SparkSQLHBaseExample")
            .config(conf)
            .getOrCreate();
    // HBase configuration
    Configuration hbaseConf = ObHTableTestUtil.newConfiguration();
    // Initialize HBaseContext
    String tmpHdfsConfigPath = "/your-hdfs-path/tmp/hbase-config";
    HBaseContext hbaseContext = new HBaseContext(jsc.sc(), hbaseConf, tmpHdfsConfigPath);
    String tableName = "spark_demo";
    String hbase_column_mapping = "id STRING :key, " +
            "name STRING cf1:name, " +
            "gender STRING cf1:gender, " +
            "age STRING cf1:age";
    Dataset<Row> hbaseDF = spark.read()
            .format("org.apache.hadoop.hbase.spark")
            .option("hbase.columns.mapping", hbase_column_mapping)
            // disable column pushdown optimization，OBKV-HBase does not support SparkSQLPushDownFilter yet
            .option("hbase.spark.pushdown.columnfilter", false)
            .option("hbase.table", tableName)
            .load();
    hbaseDF.printSchema();
    // select * from table
    hbaseDF.show();
    // Perform SQL queries on the DataFrame
    hbaseDF.createOrReplaceTempView(tableName);
    // select with condition
    Dataset<Row> result = spark.sql("SELECT * FROM spark_demo WHERE age > 30");
    result.show();
    jsc.stop();
    spark.stop();
}
```
