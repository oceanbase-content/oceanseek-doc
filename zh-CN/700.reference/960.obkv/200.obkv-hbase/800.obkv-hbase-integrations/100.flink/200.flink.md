# 通过原生 Flink 访问 OBKV-HBase

Apache Flink 是一个开源的流处理框架，专为处理实时数据流及批处理任务而设计。其高效的流处理能力补充了 Hadoop 生态系统，提供了实时数据处理能力和低延迟的数据分析。Flink 能处理来自各种数据源的实时数据，使用户能够在同一套数据架构中进行复杂的流数据和批处理任务。

本文介绍了如何使用社区版 Flink 直接访问 OBKV-HBase，且无需进行代码修改。

## 准备工作

在开始使用 Flink 访问 OBKV-HBase 之前，需要确保以下条件已满足：

* 原生 Flink 访问能力需使用 OBKV-HBase Java 客户端 2.2.1 或 1.2.1 及以上版本，推荐使用 2.2.1 版本；Flink 主流版本默认使用 HBase 2.x。
* 使用社区版 Flink 时避免引入自带的 HBase 版本。

## 建表

使用社区版 Flink 访问 OBKV-HBase 宽表时，有两种建表方式：

* 通过 [HBase Admin createTable 接口](../../700.obkv-hbase-reference/150.obkv-hbase-interface-compatibility.md) 建表。
* 通过 SQL 建表。如果通过 SQL 建表，需按照 OBKV-HBase 建表规则建表，建表规则请参考 [OBKV-HBase 数据操作示例](../../200.obkv-hbase-develop/300.obkv-hbase-demo.md)。

## 设置 OBKV-HBase 客户端连接参数

OBKV-HBase 客户端连接参数用于建立和 Oceanbase 集群之间的连接。OBKV-HBase 在公有云和私有化部署方式下，客户端连接参数的设置方式不同。对于私有化部署的 OceanBase AI 数据库集群，需要按照 **直连模式配置** 进行设置，而对于公有云 OBKV 服务，则需要按照 **云上模式** 进行设置。具体 OBKV-HBase 客户端连接集群教程请参考 [使用 OBKV-HBase 客户端连接集群](../../200.obkv-hbase-develop/200.connecting-by-using-obkv-hbase-client.md)。

无论是哪种部署方式，所有的配置项都可以通过以下两种方式进行设置：

* 在配置文件 `hbase-site.xml` 中进行设置。
* 通过 Hadoop Configuration 的 `set` 方法在代码中 Connection 初始化之前进行设置。
* 确保 Flink 版本在 1.13 到 1.20 之间。

### 直连模式配置

直连模式适用于私有化部署的 OceanBase AI 数据库集群。它通过 `Configurl` 直接连接 OceanBase AI 数据库集群，`Configurl` 用于获取 OceanBase AI 数据库底层服务器的真实地址。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>paramURL 会包含 xml 特殊字符 &，需要将其转换成 &amp;，否则会解析失败</p>
</main>

* 方式一：在 `hbase-site.xml` 配置文件中配置以下配置项：

    ```xml
    <!-- 
    假设当前集群如下
    ClusterName：obkvcluster
    TenantName：obkv
    DataBaseName: test
    UserName：root
    UserPassWord: 
    SYS_USER_NAME : sysroot 
    SYS_USER_PASSWD:
    -->
    <configuration>
    <!-- OceanBase AI 数据库HBase 实现类替换 -->
    <property>
        <name>hbase.client.connection.impl</name>
        <value>com.alipay.oceanbase.hbase.util.OHConnectionImpl</value>
    </property>
    
    <!-- OceanBase AI 数据库连接配置 -->
    <property>
        <!-- 从 obconfig server 获取 RSlist 的 URL，详见下文 Config URL 获取相关内容-->
        <name>hbase.oceanbase.paramURL</name>
        <value>PARAM_URL</value>
    </property>
    <property>
        <!-- 格式为 userName@tenantName#clusterName  -->
        <name>hbase.oceanbase.fullUserName</name>
        <value>root@obkv#obkvcluster</value>
    </property>
    <property>
        <!-- fullUserName 中 userName 访问 OceanBase AI 数据库的密码 -->
        <name>hbase.oceanbase.password</name>
        <value></value>
    </property>
    <property>
        <!-- 系统租户下的用户名, 只有系统租户下的用户才有权限访问路由表 -->
        <name>hbase.oceanbase.sysUserName</name>
        <value>sysroot</value>
    </property>
    <property>
        <!-- 系统租户下的用户密码 -->
        <name>hbase.oceanbase.sysPassword</name>
        <value></value>
    </property>
    </configuration>
    ```

* 方式二：在代码中往 Hadoop Configuration 中配置参数，通过 `set` 方法在代码中 Connection 初始化之前进行设置：


```java
/*
* 假设当前集群如下
* ClusterName：obkvcluster
* TenantName：obkv
* DataBaseName: test
* UserName：root
* UserPassWord: 
* SYS_USER_NAME : sysroot 
* SYS_USER_PASSWD:
*/
Configuration conf = HBaseConfiguration.create();
conf.set("hbase.client.connection.impl", "com.alipay.oceanbase.hbase.util.OHConnectionImpl")
conf.set("hbase.oceanbase.fullUserName", "root@obkv#obkvcluster");
conf.set("hbase.oceanbase.password", "");
// 从 obconfig server 获取 RSlist 的 URL，详见下文 Config URL 获取相关内容
conf.set("hbase.oceanbase.paramURL", "");
conf.set("hbase.oceanbase.sysUserName", "sysroot");
conf.set("hbase.oceanbase.sysPassword", "");
```

### 云上模式配置

云上模式适用于公有云部署的 OceanBase AI 数据库集群。它通过 ODP 连接 OceanBase AI 数据库集群。

* 方式一：在 `hbase-site.xml` 配置文件中配置以下配置项：

    ```xml
    <!--
    假设当前集群如下
    DataBaseName: test
    UserName：root
    <configuration>
    -->
    <!-- OceanBase AI 数据库HBase 实现类替换 -->
    <property>
        <name>hbase.client.connection.impl</name>
        <value>com.alipay.oceanbase.hbase.util.OHConnectionImpl</value>
    </property>

    <!-- OceanBase AI 数据库连接配置 -->
    <configuration>
        <property>
            <name>hbase.oceanbase.fullUserName</name>
            <value>root</value>
        </property>
        <property>
            <name>hbase.oceanbase.password</name>
            <value></value>
        </property>
        <property>
            <!--详见下文获取 ODP Address-->
            <name>hbase.oceanbase.odpAddr</name>
            <value></value>
        </property>
        <property>
            <name>hbase.oceanbase.odpPort</name>
            <value>3307</value>
        </property>
        <property>
            <name>hbase.oceanbase.odpMode</name>
            <value>true</value>
        </property>
        <property>
            <name>hbase.oceanbase.database</name>
            <value>test</value>
        </property>
    </configuration>
    ```

* 方式二：在代码中往 Hadoop Configuration 中配置参数，通过 `set` 方法在代码中 Connection 初始化之前进行设置：

```java
/*
* 假设当前集群如下
* DataBaseName: test
* UserName：root
*/
Configuration conf = HBaseConfiguration.create();
conf.set("hbase.client.connection.impl", "com.alipay.oceanbase.hbase.util.OHConnectionImpl")
conf.set(HBASE_OCEANBASE_FULL_USER_NAME, "root");    
// 用户密码
conf.set(HBASE_OCEANBASE_PASSWORD, "");       
// 详见 ODP Address 备注
conf.set(HBASE_OCEANBASE_ODP_ADDR, "");        
// OBKV 的端口是 3307（固定）
conf.setInt(HBASE_OCEANBASE_ODP_PORT, "3307");     
// 云上使用 ODP 模式(固定)
conf.setBoolean(HBASE_OCEANBASE_ODP_MODE, true);  
// 数据库的 database 的名字
conf.set(HBASE_OCEANBASE_DATABASE, "test");
```

## 使用示例

### 创建维表

维表（Dimension Table） 是数据仓库和数据分析中的一个重要概念，它用于存储不经常变化的维度信息，如日期、时间、地点、人员等，为事实表提供上下文和属性信息。

社区版 Flink 和 OBKV Flink 连接器的创建维表方式不同，具体请参考下文：

* 如果您使用社区版 Flink 访问 OBKV-HBase 宽表，可以参考[创建维表](https://nightlies.apache.org/flink/flink-docs-master/docs/connectors/table/hbase/#how-to-use-hbase-table)。
* 如果您使用 OBKV Flink 连接器访问 OBKV-HBase 宽表，可以参考[创建维表](100.ob-flink.md)。

### 创建事实表

事实表（Fact Table） 是数据仓库和数据分析中的另一个重要概念，它存储业务过程中发生的每个交易或操作的详细信息和相关的数值信息。

* 如果您使用社区版 Flink 访问 OBKV-HBase 宽表，可以参考[创建事实表](https://nightlies.apache.org/flink/flink-docs-master/docs/connectors/table/hbase/#how-to-use-hbase-table)。
* 如果您使用 OBKV Flink 连接器 访问 OBKV-HBase 宽表，可以参考[创建事实表](100.ob-flink.md)。

### 依赖引入

引入 OBKV-HBase 依赖:

```xml
<!-- OBKV-HBase 依赖，内含 hbase-client hadoop-common -->
<dependency>
  <groupId>com.oceanbase</groupId>
  <artifactId>obkv-hbase-client</artifactId>
  <version>2.2.1</version>
</dependency>
```

如果使用 Flink SQL，需要避免引入如下依赖，以免造成冲突：

```xml
<!-- Flink Connector HBase 依赖 -->
<dependency>
  <groupId>org.apache.flink</groupId>
  <artifactId>flink-connector-hbase-2.2</artifactId>
  <version>{flink.connector.hbase.version}</version>
  <exclusions>
    <exclusion>
      <groupId>org.apache.hbase</groupId>
      <artifactId>hbase-client</artifactId>
    </exclusion>
  </exclusions>
</dependency>
```

### Flink 读写示例

本部分将展示 Flink 两种不同的读写方式，DataStream 和 Flink SQL。

#### Flink DataStream 读写

创建示例表组和表：

```sql
-- 创建表组
CREATE TABLEGROUP `flink_test` SHARDING = 'ADAPTIVE';

-- 创建表
CREATE TABLE `flink_test$cf1` (
    `K` varbinary(1024) NOT NULL,
    `Q` varbinary(256) NOT NULL,
    `T` bigint(20) NOT NULL,
    `V` varbinary(1024) DEFAULT NULL,
    PRIMARY KEY (`K`, `Q`, `T`)
) TABLEGROUP = `flink_test` partition by key(`K`) partitions 17;
CREATE TABLE `flink_test$cf2` (
    `K` varbinary(1024) NOT NULL,
    `Q` varbinary(256) NOT NULL,
    `T` bigint(20) NOT NULL,
    `V` varbinary(1024) DEFAULT NULL,
    PRIMARY KEY (`K`, `Q`, `T`)
) TABLEGROUP = `flink_test` partition by key(`K`) partitions 17;
```

使用 Flink DataStream 结合 HBase Java API 进行读写。读写示例如下：

```java
StreamExecutionEnvironment env = 
        StreamExecutionEnvironment.getExecutionEnvironment();
env.fromElements("row1", "row2")
   .flatMap(new RichFlatMapFunction<String, String>() {
    private	transient Table table;
    @Override
    public void open(org.apache.flink.configuration.Configuration parameters) throws Exception {
        Connection connection = ConnectionFactory.createConnection(ObHTableTestUtil.newConfiguration());
        table = connection.getTable(org.apache.hadoop.hbase.TableName.valueOf("flink_test"));
    }
    @Override
    public void flatMap(String s, Collector<String> out) throws Exception {
        // Write to HBase
        Put put = new Put(Bytes.toBytes(s));
        put.addColumn(Bytes.toBytes(family1), Bytes.toBytes(column1), Bytes.toBytes("cf1_" + s +"_value"));
        put.addColumn(Bytes.toBytes(family2), Bytes.toBytes(column2), Bytes.toBytes("cf2_" + s + "_value"));
        table.put(put);
        // Read from HBase
        Get get = new Get(Bytes.toBytes(s));
        Result result = table.get(get);
        String family1Value = Bytes.toString(result.getValue(Bytes.toBytes(family1), Bytes.toBytes(column1)));
        String family2Value = Bytes.toString(result.getValue(Bytes.toBytes(family2), Bytes.toBytes(column2)));
        // collect get result
        out.collect(String.format("Get result from cf1: Row: %s, Qualifier: %s, Value: %s", Bytes.toString(result.getRow()), column1, family1Value));
        out.collect(String.format("Get result from cf2: Row: %s, Qualifier: %s, Value: %s", Bytes.toString(result.getRow()), column2, family2Value));
    }
    @Override
    public void close() throws Exception {
        table.close();
    }
}).print();
```

#### Flink SQL 读写

创建示例表组和表：

```sql
CREATE TABLEGROUP `student_info` SHARDING = 'ADAPTIVE';
CREATE TABLEGROUP `student_hobby` SHARDING = 'ADAPTIVE';
CREATE TABLEGROUP `all_student_info` SHARDING = 'ADAPTIVE';
CREATE TABLE `student_info$cf1` (
    `K` varbinary(1024) NOT NULL,
    `Q` varbinary(256) NOT NULL,
    `T` bigint(20) NOT NULL,
    `V` varbinary(1024) DEFAULT NULL,
    PRIMARY KEY (`K`, `Q`, `T`)
) TABLEGROUP = `student_info` partition by key(`K`) partitions 17;
CREATE TABLE `student_hobby$cf1` (
    `K` varbinary(1024) NOT NULL,
    `Q` varbinary(256) NOT NULL,
    `T` bigint(20) NOT NULL,
    `V` varbinary(1024) DEFAULT NULL,
    PRIMARY KEY (`K`, `Q`, `T`)
) TABLEGROUP = `student_hobby` partition by key(`K`) partitions 17;
CREATE TABLE `all_student_info$cf1` (
    `K` varbinary(1024) NOT NULL,
    `Q` varbinary(256) NOT NULL,
    `T` bigint(20) NOT NULL,
    `V` varbinary(1024) DEFAULT NULL,
    PRIMARY KEY (`K`, `Q`, `T`)
) TABLEGROUP = `all_student_info` partition by key(`K`) partitions 17;
```

在使用 OBKV-HBase 创建表映射时，虽然不需要设置 `zookeeper.quorum` 参数，但该参数仍需要被设置为非空字符串，且内容可以是任意字符串。Flink SQL 通过对 `student_info` 表和 `student_hobby` 表的写入操作，来模拟维表的操作。示例如下：

```sql
-- 创建 Flink 和 HBase 表 student_info 的映射
CREATE TABLE student_info (
  id INT,
  cf1 ROW<name STRING, age INT>,
  PRIMARY KEY (id) NOT ENFORCED 
) WITH (
  'connector' = 'hbase-2.2',
  'table-name' = 'student_info',
  'zookeeper.quorum' = 'any_string'
);

-- 创建 Flink 和 HBase 表 student_hobby 的映射
CREATE TABLE student_hobby (
  id INT,
  cf1 ROW<hobby STRING>,
  PRIMARY KEY (id) NOT ENFORCED 
) WITH (
  'connector' = 'hbase-2.2',
  'table-name' = 'student_hobby',
  'zookeeper.quorum' = 'any_string'
);

-- 向 student_info 和 student_hobby 中插入数据
INSERT INTO student_info VALUES 
  (1001, ROW('Lily', 13)),
  (1002, ROW('John', 12)),
  (1003, ROW('David', 13));
INSERT INTO student_hobby VALUES 
  (1001, ROW('basketball')),
  (1002, ROW('badminton')),
  (1003, ROW('jogging'));
```

使用 Flink SQL 从 `student_info` 和 `student_hobby` 表中读取数据，并将结果合并写入到 `all_student_info` 表中：

```sql
-- 创建 Flink 和 HBase 表 all_student_info 的映射
CREATE TABLE all_student_info (
  id INT,
  cf1 ROW<name STRING, age INT, hobby STRING>,
  PRIMARY KEY (id) NOT ENFORCED 
) WITH (
  'connector' = 'hbase-2.2',
  'table-name' = 'all_student_info',
  'zookeeper.quorum' = 'any_string'
);

-- 向 all_student_info 中插入数据
INSERT INTO all_student_info
  SELECT 
    si.id AS id,
    ROW(si.cf1.name, si.cf1.age, sh.cf1.hobby) AS cf1
  FROM 
    student_info AS si
  LEFT JOIN
    student_hobby AS sh ON si.id = sh.id;
```
