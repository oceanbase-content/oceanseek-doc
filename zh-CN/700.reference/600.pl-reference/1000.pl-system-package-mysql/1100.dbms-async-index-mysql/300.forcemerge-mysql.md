# FORCEMERGE

`FORCEMERGE` 用于手动触发指定表上异步索引的合并，将增量数据与基线数据整合，以优化存储并提升查询效率。

## 语法

```sql
PROCEDURE FORCEMERGE(
    IN table_name VARCHAR(65535)
);
```

## 参数说明

| **参数** | **描述** | **类型** | **是否可空** |
| --- | --- | --- | --- |
| table_name | 已创建异步索引的目标表名。 | VARCHAR(65535) | No |

## 示例

```sql
CALL DBMS_ASYNC_INDEX.FORCEMERGE('doc_async');
```
