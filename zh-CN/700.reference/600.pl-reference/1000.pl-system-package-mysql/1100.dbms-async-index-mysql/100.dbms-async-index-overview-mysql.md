# DBMS_ASYNC_INDEX 概述

`DBMS_ASYNC_INDEX` 系统包用于管理异步索引，提供手动触发合并的接口。适用于已创建异步全文索引（`ASYNC FULLTEXT`）或异步搜索索引（`ASYNC SEARCH INDEX`）的表。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>本系统包从 V4.6.2.1 版本开始支持。</p>
</main>

## DBMS_ASYNC_INDEX 子程序概览

下表列出了 OceanSeek 当前版本所支持的 `DBMS_ASYNC_INDEX` 子程序和简要描述。

| **子程序** | **描述** |
| --- | --- |
| [FORCEMERGE](300.forcemerge-mysql.md) | 手动触发指定表上异步索引的合并。 |
