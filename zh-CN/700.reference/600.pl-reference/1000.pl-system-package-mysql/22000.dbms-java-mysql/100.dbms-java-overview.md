# DBMS_JAVA 概述

`DBMS_JAVA` 用于在数据库内集成和管理 Java 程序，支持 Java 存储过程、函数及安全策略的实现。

## DBMS_JAVA 权限说明

禁止 Java UDF 访问，`DBMS_JAVA` 包现在不支持访问文件和网络。

## DBMS_JAVA 子程序概览

下表列出了 OceanSeek 所支持的 `DBMS_JAVA` 子程序以及简要描述。

|                **子程序**             |                 **描述**                       |
|-----------------------------------------|------------------------------------------------|
| [LOADJAVA](200.loadjava-mysql.md) | 用于将 Jar 包作为外部资源上传到 OBServer。 |
| [DROPJAVA](300.dropjava-mysql.md) | 用于删除上传的外部资源 Jar 包。|
| [GRANT_PERMISSION](400.grant-permission-mysql.md) | 用于为指定的用户或角色授予 Java 权限。|
| [RESTRICT_PERMISSION](500.restrict-permission-mysql.md) | 用于为指定的用户或角色设置 Java 权限限制。|
| [REVOKE_PERMISSION](600.revoke-permission-mysql.md) | 用于回收指定用户或角色的 Java 权限。|
| [DISABLE_PERMISSION](700.disable-permission-mysql.md) | 用于根据权限记录主键禁用指定的 Java 权限记录。|
| [ENABLE_PERMISSION](800.enable-permission-mysql.md) | 用于根据权限记录主键启用指定的 Java 权限记录。|
| [DELETE_PERMISSION](900.delete-permission-mysql.md) | 用于根据权限记录主键删除指定的 Java 权限记录。|
