# RESTRICT_PERMISSION

`DBMS_JAVA.RESTRICT_PERMISSION` 用于为指定的用户或角色设置 Java 权限限制。限制类权限的优先级高于授予类权限。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该子程序从 OceanSeek V4.6.3 版本开始引入。</p>
</main>

## 语法

`RESTRICT_PERMISSION` 提供两种重载形式。第二种形式通过 `key` 输出参数返回本次设置的权限记录主键。

```sql
DBMS_JAVA.RESTRICT_PERMISSION(IN grantee VARCHAR(65535), IN permission_type VARCHAR(65535), IN permission_name VARCHAR(65535), IN permission_action VARCHAR(65535));

DBMS_JAVA.RESTRICT_PERMISSION(IN grantee VARCHAR(65535), IN permission_type VARCHAR(65535), IN permission_name VARCHAR(65535), IN permission_action VARCHAR(65535), OUT key BIGINT);
```

## 参数说明

| **参数**      | **说明**         |
|-------------------|-----------|
| grantee           | 被限制权限的用户或角色名称。    |
| permission_type   | Java 权限类型，即 Java 权限类的类名，例如 `java.io.FilePermission`。     |
| permission_name   | 权限对应的目标名称，例如 `/dev/random`。     |
| permission_action | 权限对应的操作，例如 `read`。       |
| key               | 出参，返回本次设置的权限记录主键。     |

## 使用说明

- 调用 `DBMS_JAVA.RESTRICT_PERMISSION` 前，需确保租户配置项 `ob_enable_java_udf` 已开启，否则会返回不支持的错误。
- 仅 root 用户可以操作 Java 权限，其他用户调用会报权限不足的错误。
- 仅支持系统权限类型（`permission_type` 中不包含 `:` 分隔符），不支持通过 `SCHEMA:TYPE` 形式指定非系统权限类型。
- 对于未在白名单中的权限，仅 sys 租户的 root 用户（`root@sys`）可以操作。
- 该操作是幂等的：若目标权限记录已存在且处于启用状态，则不重复创建；若已存在但处于禁用状态，则将其重新启用。
