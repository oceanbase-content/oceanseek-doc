# REVOKE_PERMISSION

`DBMS_JAVA.REVOKE_PERMISSION` 用于回收指定用户或角色的 Java 权限。该子程序会将该对象下所有与入参匹配且处于启用状态的权限记录置为禁用状态。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该子程序从 OceanBase AI 数据库 V4.6.3 版本开始引入。</p>
</main>

## 语法

```sql
DBMS_JAVA.REVOKE_PERMISSION(IN permission_schema VARCHAR(65535), IN permission_type VARCHAR(65535), IN permission_name VARCHAR(65535), IN permission_action VARCHAR(65535));
```

## 参数说明

| **参数**  | **说明**     |
|-------------------|-------|
| permission_schema | 要回收权限的用户或角色名称。      |
| permission_type   | Java 权限类型，即 Java 权限类的类名，例如 `java.io.FilePermission`。     |
| permission_name   | 权限对应的目标名称，例如 `/dev/random`。 |
| permission_action | 权限对应的操作，例如 `read`。    |

## 使用说明

- 调用 `DBMS_JAVA.REVOKE_PERMISSION` 前，需确保租户配置项 `ob_enable_java_udf` 已开启，否则会返回不支持的错误。
- 仅 root 用户可以操作 Java 权限，其他用户调用会报权限不足的错误。
- 该子程序会匹配指定对象下系统权限类型中 `permission_type`、`permission_name`、`permission_action` 均一致且处于启用状态的权限记录，并将其置为禁用状态。
- 若需要彻底删除权限记录，请使用 `DBMS_JAVA.DELETE_PERMISSION`。
