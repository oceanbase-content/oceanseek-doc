# DISABLE_PERMISSION

`DBMS_JAVA.DISABLE_PERMISSION` 用于根据权限记录主键禁用指定的 Java 权限记录。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该子程序从 OceanBase AI 数据库 V4.6.3 版本开始引入。</p>
</main>

## 语法

```sql
DBMS_JAVA.DISABLE_PERMISSION(IN key BIGINT);
```

## 参数说明

| **参数** | **说明**            |
|--------|------------|
| key    | 待禁用的权限记录主键，即授予或限制权限时返回的 `key` 值。            |

## 使用说明

- 调用 `DBMS_JAVA.DISABLE_PERMISSION` 前，需确保租户配置项 `ob_enable_java_udf` 已开启，否则会返回不支持的错误。
- 仅 root 用户可以操作 Java 权限，其他用户调用会报权限不足的错误。
- 禁用后的权限记录仍保留，可通过 `DBMS_JAVA.ENABLE_PERMISSION` 重新启用。
