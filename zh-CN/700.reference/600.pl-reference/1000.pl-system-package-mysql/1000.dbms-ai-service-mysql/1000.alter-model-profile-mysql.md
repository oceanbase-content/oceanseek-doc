# ALTER_MODEL_PROFILE

`ALTER_MODEL_PROFILE` 过程用于创建或更新 `provider/model` 级模型参数。若对应记录不存在则创建，存在则更新。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>本过程从 V4.6.2.1 开始支持。</p>
</main>

## 语法

```sql
PROCEDURE alter_model_profile(
    IN model VARCHAR(512),
    IN json_params JSON);
```

## 参数说明

| 参数 | 描述 | 类型 | 取值范围 | 是否可为 NULL |
|------|------|------|----------|----------|
| model | 完整模型名，格式为 `provider/model_name`。`provider/model` 按第一个 `/` 拆分，`model_name` 部分可继续含 `/`。 | VARCHAR(512) | 最大 512 字节 | NO |
| json_params | 模型参数，必须为 JSON 对象。 | JSON | 见下表 | NO |

`json_params` 支持的顶层字段如下：

| 字段 | 类型 | 是否必填 | 说明 |
|------|------|----------|------|
| `model_config` | JSON OBJECT | 否 | 模型 API 调用参数。 |
| `run_config` | JSON OBJECT | 否 | OceanSeek 运行选项。 |

`run_config` 当前支持字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| `batch_size` | INT | 批量处理大小。 |
| `max_image_size` | INT | 图片输入最大字节数。 |
| `min_concurrency` | INT | 自适应并发下限，默认 `10`。 |
| `max_concurrency` | INT | 自适应并发上限，默认 `100`。 |

## 示例

```sql
CALL DBMS_AI_SERVICE.ALTER_MODEL_PROFILE('aliyun/qwen-plus', '{
  "model_config": {
    "max_tokens": 4096,
    "temperature": 0,
    "enable_thinking": false
  },
  "run_config": {
    "batch_size": 16,
    "max_image_size": 4194304,
    "min_concurrency": 10,
    "max_concurrency": 100
  }
}');
```
