# DROP_MODEL_PROFILE

`DROP_MODEL_PROFILE` 过程用于删除已注册的指定模型参数。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>本过程从 V4.6.2.1 开始支持。</p>
</main>

## 语法

```sql
PROCEDURE drop_model_profile(
    IN model VARCHAR(512));
```

## 参数说明

| 参数 | 描述 | 类型 | 取值范围 | 是否可空 |
|------|------|------|----------|----------|
| model | 完整模型名，格式为 `provider/model_name`。 | VARCHAR(512) |  | NO |

## 示例

```sql
CALL DBMS_AI_SERVICE.DROP_MODEL_PROFILE('aliyun/qwen-plus');
```
