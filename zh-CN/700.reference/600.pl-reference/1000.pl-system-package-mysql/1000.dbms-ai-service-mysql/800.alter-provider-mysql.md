# ALTER_PROVIDER

`ALTER_PROVIDER` 过程用于修改租户内已创建的 AI 服务厂商配置。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>本过程从 V4.6.2.1 开始支持。</p>
</main>

## 语法

```sql
PROCEDURE alter_provider(
    IN provider_name VARCHAR(256),
    IN json_params JSON);
```

## 参数说明

| 参数 | 描述 | 类型 | 取值范围 | 是否可为 NULL |
|------|------|------|----------|----------|
| provider_name | 厂商名称。 | VARCHAR(256) | 最大 256 字节 | NO |
| json_params | 厂商配置，必须为 JSON 对象。 | JSON | 见下表 | NO |

`json_params` 支持的字段如下：

| 字段 | 类型 | 说明 |
|------|------|------|
| `base_url` | VARCHAR(2048) | 当前生效的 Base URL。 |
| `access_key` | VARCHAR(2048) | 访问凭证，写入内表时加密存储。 |

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>暂不支持修改 <code>protocol</code>。如需使用不同协议，请注册新的厂商。</p>
</main>

## 示例

修改 `access_key`：

```sql
CALL DBMS_AI_SERVICE.ALTER_PROVIDER('aliyun', '{
  "access_key": "sk-1xxxx"
}');
```

将内置厂商的 `base_url` 修改为阿里云国际地址：

```sql
CALL DBMS_AI_SERVICE.ALTER_PROVIDER('aliyun', '{
  "base_url": "https://dashscope-intl.aliyuncs.com/compatible-mode/v1"
}');
```
