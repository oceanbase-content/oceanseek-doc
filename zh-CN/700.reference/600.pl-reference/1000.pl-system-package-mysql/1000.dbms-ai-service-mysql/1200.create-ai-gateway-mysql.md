# CREATE_AI_GATEWAY

`CREATE_AI_GATEWAY` 过程用于创建网关（Gateway）配置。AI 网关位于 AI 函数与真实模型服务之间，提供路由与容灾能力：将同一逻辑模型下的多个端点（可对应不同 Key、厂商或模型）统一纳管，按权重将流量分发至健康节点；若某端点连续失败，则自动熔断并切换至其它可用端点。端点不携带 `access_key`，凭证统一由厂商配置提供。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>本过程从 V4.6.2.1 开始支持。</p>
</main>

## 语法

```sql
PROCEDURE create_ai_gateway(
    IN gateway_name VARCHAR(256),
    IN json_params JSON);
```

## 参数说明

| **参数** | **描述** | **类型** | **取值范围** | **是否可为 NULL** |
| --- | --- | --- | --- | --- |
| gateway_name | 网关名称。 | VARCHAR(256) | 最大 256 字节 | NO |
| json_params | 网关配置，必须为 JSON 对象。 | JSON | 见下表 | NO |

`json_params` 支持的顶层字段如下：

| **字段** | **类型** | **是否必填** | **说明** |
| --- | --- | --- | --- |
| `endpoints` | JSON ARRAY | 是 | 路由列表。每项为 JSON 对象，须包含 `name`、`model`、`weight` 字段。`model` 为 `provider/model` 格式。 |
| `circuit_breaker` | JSON OBJECT | 否 | 熔断配置。用于在端点连续失败时自动熔断，并将流量切到其它可用端点。 |

`circuit_breaker` 支持的字段如下：

| **字段** | **类型** | **说明** |
| --- | --- | --- |
| `failure_rate_threshold` | INT | 失败率阈值（百分比）。 |
| `window_size_seconds` | INT | 统计窗口大小（秒）。 |
| `minimum_requests` | INT | 触发熔断的最小请求数。 |
| `break_duration_seconds` | INT | 熔断持续时间（秒）。 |
| `probe_requests` | INT | 探活请求数。 |

## 示例

```sql
CALL DBMS_AI_SERVICE.CREATE_AI_GATEWAY('prod_gateway', '{
  "endpoints": [
    {"name":"ep1","model":"aliyun/qwen-plus","weight":70},
    {"name":"ep2","model":"deepseek/deepseek-chat","weight":30}
  ],
  "circuit_breaker": {
    "failure_rate_threshold": 50,
    "window_size_seconds": 60,
    "minimum_requests": 10,
    "break_duration_seconds": 60,
    "probe_requests": 3
  }
}');
```
