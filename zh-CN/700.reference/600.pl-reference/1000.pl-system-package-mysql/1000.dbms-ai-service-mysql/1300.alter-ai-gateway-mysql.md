# ALTER_AI_GATEWAY

`ALTER_AI_GATEWAY` 过程用于全量替换已有网关配置。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>本过程从 V4.6.2.1 开始支持。</p>
</main>

## 语法

```sql
PROCEDURE alter_ai_gateway(
    IN gateway_name VARCHAR(256),
    IN json_params JSON);
```

## 参数说明

| 参数 | 描述 | 类型 | 取值范围 | 是否可为 NULL |
|------|------|------|----------|----------|
| gateway_name | 网关名称。 | VARCHAR(256) | 最大 256 字节 | NO |
| json_params | 网关配置，必须为 JSON 对象。 | JSON | 与 [CREATE_AI_GATEWAY](1200.create-ai-gateway-mysql.md) 中 <code>json_params</code> 字段说明一致 | NO |

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>本过程为全量替换语义，不支持局部增删端点。调用时需传入完整的 <code>endpoints</code> 配置。</p>
</main>

## 示例

```sql
CALL DBMS_AI_SERVICE.ALTER_AI_GATEWAY('prod_gateway', '{
  "endpoints": [
    {"name":"ep1","model":"aliyun/qwen-plus","weight":50},
    {"name":"ep2","model":"siliconflow/qwen-plus","weight":50}
  ]
}');
```
