# UNREGISTER_PROVIDER

`UNREGISTER_PROVIDER` 过程用于注销已注册的厂商配置。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>本过程从 V4.6.2.1 开始支持。</p>
</main>

## 语法

```sql
PROCEDURE unregister_provider(
    IN provider_name VARCHAR(256));
```

## 参数说明

| 参数 | 描述 | 类型 | 取值范围 | 是否可为 NULL |
|------|------|------|----------|----------|
| provider_name | 厂商名称。 | VARCHAR(256) | 最大 256 字节 | NO |


<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>若厂商配置仍被网关（Gateway）引用，注销会失败。请先删除引用该厂商的网关，再执行本过程。</p>
</main>

## 示例

```sql
CALL DBMS_AI_SERVICE.UNREGISTER_PROVIDER('ob-mass');
```
