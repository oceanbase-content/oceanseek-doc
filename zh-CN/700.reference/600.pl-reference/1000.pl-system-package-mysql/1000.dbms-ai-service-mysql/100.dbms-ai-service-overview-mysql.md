# DBMS_AI_SERVICE 概述

`DBMS_AI_SERVICE` 系统包用于管理 AI 服务，包括旧版接口的 AI 模型对象、AI 模型服务连接点对象，以及新版接口的厂商配置、模型参数与网关配置。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>厂商配置、模型参数与网关配置相关新子程序自 V4.6.2.1 起提供。旧接口 <code>CREATE_AI_MODEL</code> / <code>DROP_AI_MODEL</code> / <code>CREATE_AI_MODEL_ENDPOINT</code> / <code>ALTER_AI_MODEL_ENDPOINT</code> / <code>DROP_AI_MODEL_ENDPOINT</code> 完整保留，存量用法可继续工作。</p>
</main>

## 配置对象说明

| **对象** | **说明** | **管理子程序** |
| --- | --- | --- |
| AI 模型/端点（旧） | 通过模型名与端点 URL 管理远端模型访问 | `CREATE_AI_MODEL`、`DROP_AI_MODEL`、`CREATE_AI_MODEL_ENDPOINT`、`ALTER_AI_MODEL_ENDPOINT`、`DROP_AI_MODEL_ENDPOINT` |
| 厂商配置（新） | 管理厂商连接信息与访问凭证 | `REGISTER_PROVIDER`、`ALTER_PROVIDER`、`UNREGISTER_PROVIDER` |
| 模型参数（新） | 为每个模型设置和管理参数，例如最大 tokens 数、温度等，用于定制模型行为 | `ALTER_MODEL_PROFILE`（创建或变更参数）、`DROP_MODEL_PROFILE`（删除参数配置） |
| 网关配置（新） | 管理多端点的加权路由与熔断容灾 | `CREATE_AI_GATEWAY`、`ALTER_AI_GATEWAY`、`DROP_AI_GATEWAY` |
