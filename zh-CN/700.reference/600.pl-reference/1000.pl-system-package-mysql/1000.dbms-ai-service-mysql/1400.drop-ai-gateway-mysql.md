# DROP_AI_GATEWAY

`DROP_AI_GATEWAY` 过程用于删除指定网关。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>本过程从 V4.6.2.1 开始支持。</p>
</main>

## 语法

```sql
PROCEDURE drop_ai_gateway(
    IN gateway_name VARCHAR(256));
```

## 参数说明

| 参数 | 描述 | 类型 | 取值范围 | 是否可为 NULL |
|------|------|------|----------|----------|
| gateway_name | 网关名称。 | VARCHAR(256) | 最大 256 字节 | NO |

## 示例

```sql
CALL DBMS_AI_SERVICE.DROP_AI_GATEWAY('prod_gateway');
```
