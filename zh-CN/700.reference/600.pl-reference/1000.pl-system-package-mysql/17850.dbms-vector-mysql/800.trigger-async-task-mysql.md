# TRIGGER_ASYNC_TASK

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该存储过程从 V4.6.2.1 版本开始支持。</p>
</main>

`TRIGGER_ASYNC_TASK` 存储过程可用于按需手动触发指定类型的向量索引后台维护任务，并可精细到具体 tablet 进行操作，适合需要精确控制索引维护时使用。该过程支持多种任务类型，任务下发后，可通过 [DBA_OB_VECTOR_INDEX_TASKS](../../../700.system-views/400.system-view-of-mysql-mode/200.dictionary-view-of-mysql-mode/12950.o-dba_ob_vector_index_tasks-of-mysql-mode.md) 等系统视图实时监控任务执行进度与结果。

## 语法

```sql
PROCEDURE TRIGGER_ASYNC_TASK(
    IN     DATABASE_NAME           VARCHAR(65535),
    IN     TASK_TYPE               VARCHAR(65535),
    IN     TABLE_NAME              VARCHAR(65535),
    IN     INDEX_NAME              VARCHAR(65535),
    IN     TABLET_ID               BIGINT
);
```

## 参数说明

| **参数** | **类型** | **描述** |
| --- | --- | --- |
| database_name | VARCHAR | 数据库名。 |
| task_type | VARCHAR | 任务类型，取值见下表。 |
| table_name | VARCHAR | 目标表名。 |
| index_name | VARCHAR | 向量索引名。 |
| tablet_id | BIGINT | 目标 tablet ID，必须属于指定的向量索引。查询方法请参见下文。 |

task_type 取值说明：

| **值** | **说明** |
| --- | --- |
| INCREMENTAL_INDEX_FREEZE | 触发增量 Segment 冻结（转储）。 |
| INCREMENTAL_INDEX_MERGE | 触发增量 Segment 合并。 |
| FOLLOWER_IN_MEMORY_INDEX_REFRESH | 触发 Follower 内存加载。 |

查询 tablet_id 方法：

* 可通过 [DBA_OB_TABLE_LOCATIONS](../../../700.system-views/400.system-view-of-mysql-mode/200.dictionary-view-of-mysql-mode/11200.o-dba_ob_table_locations-of-mysql-mode.md) 视图，按数据库名和索引名查询向量索引对应的 `TABLET_ID`：
    ```sql
    SELECT DISTINCT TABLET_ID, TABLE_NAME, INDEX_NAME, PARTITION_NAME, SUBPARTITION_NAME
    FROM oceanbase.DBA_OB_TABLE_LOCATIONS
    WHERE DATABASE_NAME = 'test' AND INDEX_NAME = 'my_vector_idx';
    ```
* 对于已在内存中加载的向量索引，也可通过索引性能视图 [V$OB_HNSW_INDEX_INFO](../../../700.system-views/400.system-view-of-mysql-mode/300.performance-view-of-mysql-mode/31200.v-ob_hnsw_index_info-of-mysql-mode.md)、[V$OB_SINDI_INDEX_INFO](../../../700.system-views/400.system-view-of-mysql-mode/300.performance-view-of-mysql-mode/34050.v-ob_sindi_index_info-of-mysql-mode.md)、[V$OB_IVF_INDEX_INFO](../../../700.system-views/400.system-view-of-mysql-mode/300.performance-view-of-mysql-mode/31225.v-ob_ivf_index_info-of-mysql-mode.md) 的 `DATA_TABLET_ID` 字段查询。

## 全局注意事项

* 执行该存储过程前，需确保对目标表拥有 `ALTER` 权限。
* 手动触发的任务会以最高优先级调度执行，确保及时响应。
* 如传入了不支持的任务类型，系统将返回错误码 `1235` 并中止执行。

## 示例

手动触发指定 tablet 的增量 Segment 冻结：

```sql
CALL DBMS_VECTOR.TRIGGER_ASYNC_TASK('test', 'INCREMENTAL_INDEX_FREEZE', 'my_table', 'my_vector_idx', 200001);
```

手动触发指定 tablet 的增量 Segment 合并：

```sql
CALL DBMS_VECTOR.TRIGGER_ASYNC_TASK('test', 'INCREMENTAL_INDEX_MERGE', 'my_table', 'my_vector_idx', 200001);
```

手动触发指定 tablet 的 Follower 内存加载：

```sql
CALL DBMS_VECTOR.TRIGGER_ASYNC_TASK('test', 'FOLLOWER_IN_MEMORY_INDEX_REFRESH', 'my_table', 'my_vector_idx', 200001);
```
