# pid_file

## 功能描述

`pid_file` 用于查询服务器写入其进程 ID 的文件的路径名。

## 权限要求

* 查询变量

  `sys` 租户和所有用户租户均可以使用 `SHOW VARIABLES` 语句或视图 `information_schema.GLOBAL_VARIABLES` 查看 Global 系统变量的值。

* 修改变量

  该变量不支持修改。

## 属性说明

| **属性**  |    **描述**  |
|-----------|---------------|
| 参数类型    |  Varchar             |
| 默认值      |  /run/observer.pid  |
| 生效范围    |  Global  |
| 是否可修改  | 否，不支持通过 `SET` 语句修改。       |
| 是否只读    | 是       |

## 查询示例

查询服务器写入其进程 ID 的文件的路径名。

```shell
obclient> SHOW VARIABLES LIKE 'pid_file';
```

查询结果如下：

```shell
+---------------+----------------------------------------+
| Variable_name | Value                                  |
+---------------+----------------------------------------+
| pid_file      | /home/admin/oceanbase/run/observer.pid |
+---------------+----------------------------------------+
1 row in set (0.004 sec)
```
