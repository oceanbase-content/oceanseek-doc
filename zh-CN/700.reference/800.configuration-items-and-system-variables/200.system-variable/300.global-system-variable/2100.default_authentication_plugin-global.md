# default_authentication_plugin

## 功能描述

`default_authentication_plugin` 用于设置新用户默认的认证插件。

## 权限要求

* 查询变量

  `sys` 租户和所有用户租户均可以使用 `SHOW VARIABLES` 语句及视图 `information_schema.GLOBAL_VARIABLES` 查看 Global 系统变量的值。

* 修改变量

  * `sys` 租户可以直接修改 Global 系统变量的值。

  * 用户租户需要拥有 `SUPER` 或 `ALTER SYSTEM` 权限才能修改 Global 系统变量的值。

## 属性说明

| **属性**  |   **描述**    |
|---------|---------------|
| 参数类型    |  Varchar(64)    |
| 默认值      | '' （或 `DEFAULT`，同 ''）  |
| 取值范围    | 记录密码 HASH 计算使用的 plugin 名称，目前只允许四种设置：<ul><li>空串（同 <code>mysql_native_password</code>）</li><li><code>mysql_native_password</code></li><li><code>caching_sha2_password</code></li></ul>  |
| 生效范围    | Global      |
| 是否可修改  | 是，支持通过 `SET` 语句修改。|

## 配置示例

设置新用户默认的认证插件为 `caching_sha2_password` 插件。

```shell
obclient> SET default_authentication_plugin = 'caching_sha2_password';
```
