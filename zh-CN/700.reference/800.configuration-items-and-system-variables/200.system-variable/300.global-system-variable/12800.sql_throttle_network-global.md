# sql_throttle_network

## 功能描述

`sql_throttle_network` 用于指定请求排队时间，如果请求排队时间大于或等于该值，则不允许执行查询。

## 权限要求

* 查询变量

  `sys` 租户和所有用户租户均可以使用 `SHOW VARIABLES` 语句及视图 `information_schema.GLOBAL_VARIABLES` 查看 Global 系统变量的值。

* 修改变量

  * `sys` 租户可以直接修改 Global 系统变量的值。

  * 用户租户需要拥有 `SUPER` 或 `ALTER SYSTEM` 权限才能修改 Global 系统变量的值。

## 属性说明

| **属性** |    **描述**     |
|--------|---------------|
| 参数类型   | Numeric       |
| 默认值    | -1            |
| 取值范围   | 与系统负载相关，单位 us |
| 生效范围   | Global                      |
| 是否可修改  | 是，支持通过 `SET` 语句修改。|

## 配置示例

指定请求排队时间为 1000000 us。

```shell
obclient> SET GLOBAL sql_throttle_network = 1000000;
```
