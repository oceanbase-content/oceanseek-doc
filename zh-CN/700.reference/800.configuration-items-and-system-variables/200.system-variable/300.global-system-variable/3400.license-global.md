# license

## 功能描述

`license` 用于查看 license 的类型。

## 权限要求

`sys` 租户和所有用户租户均可以使用 `SHOW VARIABLES` 语句及视图 `information_schema.GLOBAL_VARIABLES` 查看 Global 系统变量的值。

## 属性说明

| **属性** | **描述**  |
|----------|----------|
| 参数类型    | Varchar |
| 默认值      | ""，表示空字符串    |
| 生效范围    | Global  |
| 是否可修改  | 否，仅支持只读       |

## 查询示例

查看 license 的类型。

```shell
obclient(root@mysql001)[(none)]> SHOW VARIABLES LIKE '%license%';
```

结果如下：

```shell
+---------------+-------+
| Variable_name | Value |
+---------------+-------+
| license       |       |
+---------------+-------+
1 row in set
```
