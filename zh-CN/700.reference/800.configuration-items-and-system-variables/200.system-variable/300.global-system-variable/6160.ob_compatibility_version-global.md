# ob_compatibility_version

## 功能描述

`ob_compatibility_version` 用于控制产品行为发生变更的功能兼容的 OceanSeek 版本。

## 权限要求

* 查询变量

  `sys` 租户和所有用户租户均可以使用 `SHOW VARIABLES` 语句及视图 `information_schema.GLOBAL_VARIABLES` 查看 Global 系统变量的值。

* 修改变量

  * `sys` 租户可以直接修改 Global 系统变量的值。

  * 用户租户需要拥有 `SUPER` 或 `ALTER SYSTEM` 权限才能修改 Global 系统变量的值。

## 属性说明

| **属性**  |    **描述**  |
|-----------|---------------|
| 参数类型    |    Varchar              |
| 默认值      |  4.6.2.0  |
| 取值范围    |  4.2.3.0 及后续版本              |
| 生效范围    |  Global |
| 是否可修改  | 是，支持通过 `SET` 或 `ALTER SESSION SET` 语句再修改。|

## 使用说明

* 创建租户时，如果没有显示明确该变量的值，则该变量默认取值为当前 `cluster_version`。

## 配置示例

* 创建租户时指定产品行为发生变更的功能兼容的 OceanSeek 版本为 V4.6.2.0。

  ```shell
  obclient> create tenant tenant_m57 zone_list=('z1'),primary_zone='z1',resource_pool_list=('pool1') set ob_compatibility_mode='MYSQL',ob_compatibility_version='4.6.2.0',ob_tcp_invited_nodes='%';
  ```

* 设置指定产品行为发生变更的功能兼容的 OceanSeek 版本为 V4.6.2.0。

  ```shell
  set global ob_compatibility_version ='4.6.2.0';
  ```
