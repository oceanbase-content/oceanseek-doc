# default_password_lifetime

## 功能描述

`default_password_lifetime` 用于设置密码的过期时间。

## 权限要求

* 查询变量

  `sys` 租户和所有用户租户均可以使用 `SHOW VARIABLES` 语句及视图 `information_schema.GLOBAL_VARIABLES` 查看 Global 系统变量的值。

* 修改变量

  * `sys` 租户可以直接修改 Global 系统变量的值。

  * 用户租户需要拥有 `SUPER` 或 `ALTER SYSTEM` 权限才能修改 Global 系统变量的值。

## 属性说明

| **属性**  |   **描述**    |
|---------|-------------|
| 参数类型    | Uint        |
| 默认值     | 0           |
| 取值范围    | \[0,65535\] |
| 生效范围    | Global      |
| 是否可修改  | 是，支持通过 `SET` 语句修改。|

## 配置示例

设置密码的过期时间为 0。

```shell
obclient> SET GLOBAL default_password_lifetime =0;
```
