# ob_enable_jit

## 功能描述

`ob_enable_jit` 用于设置 JIT 执行引擎模式。

## 权限要求

* 查询变量

  * Global 级别

    `sys` 租户和所有用户租户均可以使用 `SHOW VARIABLES` 语句及视图 `information_schema.GLOBAL_VARIABLES` 查看 Global 系统变量的值。

  * Session 级别

    `sys` 租户和所有用户租户均可以使用 `SHOW VARIABLES` 语句及视图 `information_schema.SESSION_VARIABLES` 查看 Session 系统变量的值。

* 修改变量

  * Global 生效

    * `sys` 租户可以直接修改 Global 系统变量的值。

    * 用户租户需要拥有 `SUPER` 或 `ALTER SYSTEM` 权限才能修改 Global 系统变量的值。

  * Session 生效

    `sys` 租户和所有用户租户均可以直接修改本租户的 Session 系统变量的值。

## 属性说明

| **属性** |        **描述**            |
|----------|----------------------------|
| 参数类型    | Enum                                                                     |
| 默认值      | OFF                                                                      |
| 取值范围    | <ul><li>OFF：当前 Session 不开启表达式编译执行。</li> <li>AUTO：当前 Session 表达式编译执行只有在 SQL 执行平均 RT 大于 1s 时才开启。 </li><li>FORCE：当前 Session 强制开启表达式编译执行功能。 </li></ul>   |
| 生效范围    | <ul><li>Global</li> <li>Session </li></ul>    |
| 是否可修改  | 是，支持通过 `SET` 语句修改。|

## 配置示例

设置 JIT 执行引擎模式为 OFF。

* Session 生效

  ```shell
  obclient> SET ob_enable_jit =OFF;
  ```

* Global 生效

  ```shell
  obclient> SET GLOBAL ob_enable_jit =OFF;
  ```
