# version

## 功能描述

`version` 用于查看服务器的版本号。

## 权限要求

* 查询变量

  `sys` 租户和所有用户租户均可以使用 `SHOW VARIABLES` 语句及视图 `information_schema.GLOBAL_VARIABLES` 查看 Global 系统变量的值。

* 修改变量

  * `sys` 租户可以直接修改 Global 系统变量的值。

  * 用户租户需要拥有 `SUPER` 或 `ALTER SYSTEM` 权限才能修改 Global 系统变量的值。

## 属性说明

| **属性** | **描述**  |
|--------|---------|
| 参数类型   | Varchar |
| 默认值    | 5.7.25-OceanSeek-v4.6.2.0  |
| 取值范围   | <ul><li>取值为空字符串时，返回值为默认值 </li><li>取值为非空字符串时，返回值为设定值 </li></ul>   |
| 生效范围   | Global  |
| 是否可修改  | 是，支持通过 `SET` 语句修改。        |

## 配置示例

将版本号设置成默认版本号。

```shell
obclient> SET GLOBAL version='';
```
