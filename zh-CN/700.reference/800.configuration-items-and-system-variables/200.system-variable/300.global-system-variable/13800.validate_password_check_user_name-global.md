# validate_password_check_user_name

## 功能描述

`validate_password_check_user_name` 用于设置用户密码是否可以和用户名相同。

## 权限要求

* 查询变量

  `sys` 租户和所有用户租户均可以使用 `SHOW VARIABLES` 语句及视图 `information_schema.GLOBAL_VARIABLES` 查看 Global 系统变量的值。

* 修改变量

  * `sys` 租户可以直接修改 Global 系统变量的值。

  * 用户租户需要拥有 `SUPER` 或 `ALTER SYSTEM` 权限才能修改 Global 系统变量的值。

## 属性说明

| **属性**  |                                                              **描述**                                                               |
|---------|-----------------------------------------------------------------------------------------------------------------------------------|
| 参数类型    | Enum                                           |
| 默认值     | on                                            |
| 取值范围    | <ul><li>on：表示用户密码不可以和用户名相同 </li><li>off：表示用户密码可以和用户名相同 </li></ul>    |
| 生效范围    | Global                                         |
| 是否可修改  | 是，支持通过 `SET` 语句修改。|

## 使用说明

该变量需要与 [validate_password_policy](14200.validate_password_policy-global.md) 变量配合使用，仅当 [validate_password_policy](14200.validate_password_policy-global.md) 的取值为 `MEDIUM` 时，该变量才会生效。

## 配置示例

设置用户密码不可以与用户名相同。

```shell
obclient> SET GLOBAL validate_password_check_user_name = on;
```
