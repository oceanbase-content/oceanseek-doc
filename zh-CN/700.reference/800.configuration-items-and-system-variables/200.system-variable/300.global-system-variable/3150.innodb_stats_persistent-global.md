# innodb_stats_persistent

## 功能描述

`innodb_stats_persistent` 用于控制是否将 InnoDB 索引统计信息持久化到磁盘上。

<main id="notice">
  <h4>功能适用性</h4>
  <p>该变量仅用于保障生态工具的兼容性，不会对 OceanSeek 功能产生影响。</p>
</main>

## 权限要求

* 查询变量

  `sys` 租户和所有用户租户均可以使用 `SHOW VARIABLES` 语句或视图 `information_schema.GLOBAL_VARIABLES` 查看 Global 系统变量的值。

* 修改变量

  该变量仅用于兼容，参数配置并无实际作用，不生效。

## 属性说明

| **属性**  |    **描述**  |
|---------|---------------|
| 参数类型    |    Enum              |
| 默认值     |  1  |
| 取值范围    | <ul><li>ON：开启  </li><li>OFF：不开启 </li></ul>                   |
| 生效范围    |  Global |
| 是否可修改 | 是，支持通过 `SET` 语句修改。|
