# port

## 功能描述

`port` 用于在 OBServer 节点部署时，设置服务器监听 TCP/IP 连接的端口号。

## 权限要求

* 查询变量

  `sys` 租户和所有用户租户均可以使用 `SHOW VARIABLES` 语句或视图 `information_schema.GLOBAL_VARIABLES` 查看 Global 系统变量的值。

* 修改变量

  该变量不支持修改。

## 属性说明

| **属性**  |    **描述**  |
|-----------|---------------|
| 参数类型    |  Int             |
| 默认值      |  3306  |
| 生效范围    |  Global  |
| 是否可修改  | 否，该变量仅支持在 OBServer 节点部署时指定，不支持通过 `SET` 语句修改。|
| 是否只读    | 是       |

## 查询示例

查询服务器监听 TCP/IP 连接的端口号。

```shell
obclient> SHOW VARIABLES LIKE 'port';
```

查询结果如下：

```shell
+---------------+-------+
| Variable_name | Value |
+---------------+-------+
| port          | 2881  |
+---------------+-------+
1 row in set (0.003 sec)
```
