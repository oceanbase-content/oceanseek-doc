# version_comment

## 功能描述

`version_comment` 用于查看 OBServer 节点的版本信息。

## 权限要求

* 查询变量

  `sys` 租户和所有用户租户均可以使用 `SHOW VARIABLES` 语句及视图 `information_schema.GLOBAL_VARIABLES` 查看 Global 系统变量的值。

* 修改变量

  该变量不支持修改。

## 属性说明

| **属性** |     **描述**      |
|--------|-----------------|
| 参数类型   | Varchar         |
| 默认值    | OceanBase 4.6.0.0 AI 4.6.2.0 (r20xxxxxxxx0-4a13xxxxxxxxxxxxxxxxxx72e) (Built Jul  7 2026 13:38:31) |
| 生效范围   | Global          |
| 是否可修改  | 否，该变量仅支持只读。               |
