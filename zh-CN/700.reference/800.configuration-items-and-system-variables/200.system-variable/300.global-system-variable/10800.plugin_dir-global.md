# plugin_dir

## 功能描述

`plugin_dir` 用于查看存放插件 DLL 的路径。

## 权限要求

* 查询变量

  `sys` 租户和所有用户租户均可以使用 `SHOW VARIABLES` 语句及视图 `information_schema.GLOBAL_VARIABLES` 查看 Global 系统变量的值。

* 修改变量

  该变量不支持修改。

## 属性说明

| **属性** |    **描述**     |
|--------|---------------|
| 参数类型   | Varchar       |
| 默认值    | ./plugin_dir/ |
| 生效范围   | Global        |
| 是否可修改  | 否，不支持通过 `SET` 语句修改。          |
| 是否只读    | 是 |
