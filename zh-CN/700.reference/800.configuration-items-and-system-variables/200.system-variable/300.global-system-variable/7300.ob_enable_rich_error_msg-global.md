# ob_enable_rich_error_msg

## 功能描述

`ob_enable_rich_error_msg` 用于控制 SQL 执行出错时是否显示 svr_ip、time、trace_id 等信息。

## 权限要求

* 查询变量

  * Global 级别

    `sys` 租户和所有用户租户均可以使用 `SHOW VARIABLES` 语句及视图 `information_schema.GLOBAL_VARIABLES` 查看 Global 系统变量的值。

  * Session 级别

    `sys` 租户和所有用户租户均可以使用 `SHOW VARIABLES` 语句及视图 `information_schema.SESSION_VARIABLES` 查看 Session 系统变量的值。

* 修改变量

  * Global 生效

    * `sys` 租户可以直接修改 Global 系统变量的值。

    * 用户租户需要拥有 `SUPER` 或 `ALTER SYSTEM` 权限才能修改 Global 系统变量的值。

  * Session 生效

    `sys` 租户和所有用户租户均可以直接修改本租户的 Session 系统变量的值。

## 属性说明

| **属性**  |      **描述**    |
|-----------|------------------|
| 参数类型    | Bool        |
| 默认值      | False       |
| 取值范围    | <ul><li>False：不显示 </li><li>True：显示 </li></ul>|
| 生效范围    | <ul><li>Global </li><li>Session </li></ul>        |
| 是否可修改  | 是，支持通过 `SET` 语句修改。 |

## 配置示例

设置 SQL 执行出错时不显示 svr_ip、time、trace_id 等信息。

* Global 生效

  ```shell
  obclient> SET GLOBAL ob_enable_rich_error_msg =False;
  ```

* Session 生效

  ```shell
  obclient> SET ob_enable_rich_error_msg =False;
  ```
