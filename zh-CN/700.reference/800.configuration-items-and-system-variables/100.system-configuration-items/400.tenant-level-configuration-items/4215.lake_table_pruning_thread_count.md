# lake_table_pruning_thread_count

`lake_table_pruning_thread_count` 用于设置湖表并行裁剪线程池的线程数量，为 Iceberg 和 Paimon 的并行裁剪提供线程资源。

## 功能描述

当 `enable_lake_table_parallel_resolving` 开启后，系统使用租户级线程池执行并行裁剪任务。`lake_table_pruning_thread_count` 决定该线程池中的线程数量。线程数越多，并行裁剪的并发度越高，计划生成耗时越短，但同时会占用更多的 CPU 和内存资源。

## 属性说明

| 属性 | 说明 |
| --- | --- |
| 参数类型 | INT |
| 默认值 | 4 |
| 取值范围 | [1, 64] |
| 是否可修改 | 是，支持通过 `ALTER SYSTEM SET` 语句修改。 |
| 是否重启 OBServer 节点生效 | 否，设置后立即生效。 |

## 使用说明

对于资源充裕且数据文件数量较多的租户，可适当增大线程数以缩短计划生成时间；对于资源紧张或并发查询较多的租户，可适当减小线程数，避免裁剪线程占用过多资源。

## 配置示例

```sql
-- 查看当前值
SHOW PARAMETERS LIKE 'lake_table_pruning_thread_count';

-- 将线程数调整为 8
ALTER SYSTEM SET lake_table_pruning_thread_count = 8;

-- 将线程数调整为 16
ALTER SYSTEM SET lake_table_pruning_thread_count = 16;
```
