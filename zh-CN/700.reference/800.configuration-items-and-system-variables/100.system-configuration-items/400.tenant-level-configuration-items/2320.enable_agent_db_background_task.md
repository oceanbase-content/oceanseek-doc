# enable_agent_db_background_task

## 功能描述

`enable_agent_db_background_task` 用于控制是否开启逻辑表（Logical Table）后台删除任务。

## 权限要求

* 查询配置项

  `sys` 租户和所有用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  `sys` 租户和用户租户均可修改该配置项。

## 属性说明

| **属性** | **描述** |
| -------- | -------- |
| 参数类型 | Bool |
| 默认值 | True |
| 取值范围 | <ul><li>`True`：开启逻辑表后台删除任务。</li><li>`False`：关闭逻辑表后台删除任务。</li></ul> |
| 是否可修改 | 是，支持通过 `ALTER SYSTEM SET` 语句修改。|
| 是否重启 OBServer 节点生效 | 否，设置后立即生效。 |

## 使用说明

* 开启后，系统会对用户执行的 `DROP NAMESPACE` / `DROP LTABLE` 操作进行后台物理数据删除；关闭后，不再启动新的逻辑表后台删除任务。
* 通过该配置项可避免大量删除任务导致系统抖动。
* 该配置项不会控制热点 Namespace 的 TTL 任务的清理。

## 配置示例

* 系统租户为指定用户租户关闭逻辑表后台删除任务。

  ```shell
  obclient(root@sys)[(none)]> ALTER SYSTEM SET enable_agent_db_background_task = False TENANT = tenant_name;
  ```

* 用户租户为本租户开启逻辑表后台删除任务。

  ```shell
  obclient> ALTER SYSTEM SET enable_agent_db_background_task = True;
  ```
