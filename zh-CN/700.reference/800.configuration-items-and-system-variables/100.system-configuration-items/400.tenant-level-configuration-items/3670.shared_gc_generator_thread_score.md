# shared_gc_generator_thread_score

## 功能描述

`shared_gc_generator_thread_score` 用于配置同时可用来生成共享数据 GC 任务的线程数。默认为 0，表示不显式指定，使用 priority 默认线程 score，共享数据 GC 生成任务线程数默认是 2。

## 权限要求

* 查询配置项

  `sys` 租户和所有用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  `sys` 租户和用户租户都可以使用 `ALTER SYSTEM SET` 语句修改该配置项。

## 属性说明

| **属性** | **描述** |
| -------- | -------- |
| 参数类型   | Int |
| 默认值     | 0，表示不显式指定，使用默认线程 score，共享数据 GC 生成任务的默认线程数为 2 |
| 取值范围   | [0, 100] |
| 是否可修改 | 是，支持通过 `ALTER SYSTEM SET` 语句修改。|
| 是否重启 OBServer 节点生效 | 否，设置后立即生效。   |

## 使用说明

该配置项用于动态调整共享数据 GC 生成任务的线程数。通过该配置项，系统可以根据具体业务需求灵活调整共享数据 GC 生成任务的线程数量。

## 配置示例

用户租户下，设置用于生成共享数据 GC 任务的线程数为 8。

```shell
obclient> ALTER SYSTEM SET shared_gc_generator_thread_score = 8;
```
