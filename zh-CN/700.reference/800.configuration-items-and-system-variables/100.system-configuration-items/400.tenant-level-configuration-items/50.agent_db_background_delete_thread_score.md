# agent_db_background_delete_thread_score

## 功能描述

`agent_db_background_delete_thread_score` 用于设置逻辑表（Logical Table）后台删除数据的线程数。

## 权限要求

* 查询配置项

  `sys` 租户和所有用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  `sys` 租户和用户租户均可修改该配置项。

## 属性说明

| **属性** | **描述** |
| -------- | -------- |
| 参数类型 | Int |
| 默认值 | 0，表示使用默认值 2 |
| 取值范围 | [0, 100] |
| 是否可修改 | 是，支持通过 `ALTER SYSTEM SET` 语句修改。|
| 是否重启 OBServer 节点生效 | 否，设置后立即生效。 |

## 使用说明

* 值越大，后台删除任务可使用的线程资源越多，删除速度越快，但会占用更多系统资源。
* 后台任务每隔 10 秒检查一次是否存在需要清理的逻辑表；若有，系统会提交多个分区级别的删除任务，并由该配置项控制并发删除的线程数。

## 配置示例

* 系统租户为指定用户租户设置逻辑表后台删除数据的线程数为 4。

  ```shell
  obclient(root@sys)[(none)]> ALTER SYSTEM SET agent_db_background_delete_thread_score = 4 TENANT = tenant_name;
  ```

* 用户租户为本租户设置逻辑表后台删除数据的线程数为 4。

  ```shell
  obclient> ALTER SYSTEM SET agent_db_background_delete_thread_score = 4;
  ```
