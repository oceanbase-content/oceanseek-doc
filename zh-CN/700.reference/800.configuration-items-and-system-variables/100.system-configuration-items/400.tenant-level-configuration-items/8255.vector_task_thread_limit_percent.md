# vector_task_thread_limit_percent

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该配置项从 V4.6.2.1 版本开始引入。</p>
</main>

## 功能描述

配置项 `vector_task_thread_limit_percent` 用于为不同类型的向量异步任务独立设置调度水位（百分比），可根据实际业务高峰动态调整各类向量后台任务的执行强度。当未配置该参数或设置为空字符串时，系统将采用默认调度水位。

## 使用说明

向量后台任务统一使用一个线程池。默认情况下，系统根据任务类型、优先级和预设的水位表顺序，结合当前线程池繁忙状态，动态决定各类任务的调度比例。这种机制在多数场景下能满足资源分配需求。但在实际运行中，某些任务在特定租户或特定时段内，可能需要更积极或更保守的调度策略。为此，提供本配置项，允许用户针对具体任务类型灵活调整调度水位，覆盖默认行为。

* 业务高峰期：可适当下调如转储、合并等任务的调度百分比，优先保证在线查询资源。
* 业务低峰期或维护窗口：可恢复为空字符串，或提高相关任务百分比，以加快处理和维护速度。
* 仅需设置需要调整的任务类型，未配置的类型将继续采用系统默认水位。
* 本配置项仍受最小槽位保证保护：即使将某任务类型水位设为 `0`，该类型任务仍可能被调度。

## 权限要求

* 查询配置项

  `sys` 租户和 MySQL 用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  `sys` 租户和 MySQL 用户租户均可修改该配置项。

## 属性说明

| **属性** | **描述** |
| --- | --- |
| 参数类型 | String |
| 默认值 | 空字符串 |
| 取值范围 | 见下文"取值说明"小节 |
| 是否可修改 | 是，支持通过 `ALTER SYSTEM SET` 语句修改。 |
| 是否重启 OBServer 节点生效 | 否，设置后立即生效。 |

## 取值说明

* 空字符串：不覆盖内核默认水位。
* 非空字符串：使用英文逗号 `,` 分隔多项，每项格式为 `任务类型短名:百分比`，其中冒号为英文冒号 `:`。
* 百分比：整数，取值范围为闭区间 `[0, 100]`。

支持的任务类型短名如下：

| **任务类型短名** | **说明** |
| --- | --- |
| IVF_CACHE_LOAD | IVF 聚类中心加载任务 |
| MEM_SYNC | 内存同步任务 |
| IVF_CACHE_CLEAN | IVF 聚类中心清理任务 |
| INCREMENTAL_INDEX_FREEZE | Segment 转储任务 |
| INCREMENTAL_INDEX_MERGE | Segment 合并任务 |
| SEMANTIC_INDEX_REFRESH | 语义索引刷新任务 |
| PARTITION_REBUILD | 分区重建任务 |

## 配置示例

在业务高峰期降低 Segment 转储与合并任务的调度强度，其余任务类型仍使用默认水位：

```sql
ALTER SYSTEM SET vector_task_thread_limit_percent = 'INCREMENTAL_INDEX_FREEZE:30,INCREMENTAL_INDEX_MERGE:30';
```

恢复为内核默认水位：

```sql
ALTER SYSTEM SET vector_task_thread_limit_percent = '';
```

查看当前配置：

```sql
SHOW PARAMETERS LIKE 'vector_task_thread_limit_percent';
```
