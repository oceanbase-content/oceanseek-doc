# enable_lake_table_parallel_resolving

`enable_lake_table_parallel_resolving` 用于控制是否启用 Iceberg 表的并行数据文件裁剪（pruning）。

## 功能描述

查询 Iceberg 湖表时，系统需要根据查询条件对数据文件进行裁剪，以过滤不相关的文件、减少后续读取量。当表的数据文件数量较多时，串行裁剪会成为计划生成的性能瓶颈。开启该配置后，系统将裁剪任务分配到多个线程并行执行，从而缩短计划生成时间。

## 属性说明

| 属性 | 说明 |
| --- | --- |
| 参数类型 | BOOL |
| 默认值 | True |
| 取值范围 | True / False |
| 是否可修改 | 是，支持通过 `ALTER SYSTEM SET` 语句修改。 |
| 是否重启 OBServer 节点生效 | 否，设置后立即生效。 |

## 使用说明

对于数据文件数量较多的 Iceberg 表，建议保持默认值 True。若因特殊排查需要临时关闭并行裁剪，可将其设置为 False。

## 配置示例

```sql
-- 查看当前值
SHOW PARAMETERS LIKE 'enable_lake_table_parallel_resolving';

-- 开启并行裁剪
ALTER SYSTEM SET enable_lake_table_parallel_resolving = True;

-- 关闭并行裁剪
ALTER SYSTEM SET enable_lake_table_parallel_resolving = False;
```
