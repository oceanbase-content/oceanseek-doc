# location_cache_expire_time

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该配置项目前没有实际使用，设置后不生效，可以忽略。</p>
</main>

## 功能描述

`location_cache_expire_time` 用于设置分区位置缓存中分区位置信息的过期时长。不建议修改。

## 属性说明

|      **属性**      |  **描述**   |
|------------------|-----------|
| 参数类型             | Time      |
| 默认值              | 600s      |
| 取值范围             | \[1s, +∞) |
| 是否重启 OBServer 节点生效 | 否         |
