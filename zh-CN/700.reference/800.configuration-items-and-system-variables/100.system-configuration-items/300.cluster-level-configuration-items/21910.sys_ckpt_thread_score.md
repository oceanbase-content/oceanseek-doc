# sys_ckpt_thread_score

<main id="notice" type='explain'>
<h4>说明</h4>
<p>该配置项从 V4.6.3 版本开始引入。</p>
</main>

## 功能描述

在 Shared Storage 模式下，LS checkpoint 用于将 `sys` 租户的 `SYS_LS` 元数据持久化到共享存储。

`sys_ckpt_thread_score` 用于设置集群级 LS checkpoint 工作线程分值，控制 LS checkpoint 调度队列的任务并发额度，以及首次创建集群时 Bootstrap checkpoint 的上传并发度。取值为 `0` 时使用默认分值 `16`。

## 权限要求

* 查询配置项

  `sys` 租户和所有用户租户均可以使用 `SHOW PARAMETERS` 语句或视图 `GV$OB_PARAMETERS` 查询该配置项。

* 修改配置项

  仅 `sys` 租户可以修改该配置项，用户租户不能修改该配置项。

## 属性说明

| **属性** | **描述** |
| -------- | -------- |
| 参数类型 | Int |
| 默认值 | 16 |
| 取值范围 | \[0, 100\] |
| 是否可修改 | 是，支持通过 `ALTER SYSTEM SET` 语句修改。 |
| 是否重启 OBServer 节点生效 | 否，设置后立即生效。 |

## 使用说明

* 该配置项为集群级配置项，各 OBServer 节点通过 `GCONF` 读取，不按租户分别配置。

* thread score 表示每个租户 DAG 调度器中 `PRIO_LS_CKPT` 队列的 Task 并发额度，并不是整个集群共享一个全局线程池。因此，该值并不表示整个集群所有租户合计只能运行该数量的 Task。

* 创建 Bootstrap checkpoint DAG 时，系统会按有效线程分值创建 Upload Task，并设置单个 DAG 的并发上限。默认值为 `16`，显式配置为 `0` 时使用默认分值 `16`。周期性的 NORMAL checkpoint 固定创建 1 个 Upload Task。

* Bootstrap checkpoint DAG 仅在首次创建集群期间执行。集群创建完成后，动态修改该配置项只会刷新各租户 DAG 调度器中 `PRIO_LS_CKPT` 队列的 Task 并发额度，不会再次创建 Bootstrap checkpoint DAG。

* 首次创建集群时，如果需要显式指定 Bootstrap checkpoint 的上传并发度，应在各 OBServer 节点的启动参数 `-o` 中配置相同的 `sys_ckpt_thread_score`。`-o` 只作用于当前启动的 OBServer 进程，未显式指定时使用默认值 `16`。

* 调整该配置项前，应评估各 OBServer 节点上的租户数量、CPU、内存、DAG 队列以及对象存储的压力。建议优先使用默认值 `16`，仅在首次 Bootstrap checkpoint 存在明显上传瓶颈且资源充足时逐步调高。

## 配置示例

1. 首次创建集群时，通过 OBServer 启动参数指定 `sys_ckpt_thread_score`。

    ```bash
    ./bin/observer \
      -n ob1.shuili.wh \
      -c 1 \
      -P 1424 \
      -p 1459 \
      -z z1 \
      -d /data/1/ob1.z1.obs0/store \
      -m shared_storage \
      -o "sys_ckpt_thread_score=32,enable_logservice=True" \
      -i eth0
    ```

    `-o` 后是一个以英文逗号分隔的 `key=value` 配置字符串。已有其他启动配置时，应将 `sys_ckpt_thread_score=32` 合并到同一个 `-o` 中，不能再单独追加第二个 `-o`。

2. 集群创建完成后，动态修改该配置项。

    ```sql
    ALTER SYSTEM SET sys_ckpt_thread_score = 32;
    ```

3. 查看当前配置。

    ```sql
    SHOW PARAMETERS LIKE 'sys_ckpt_thread_score';
    ```
