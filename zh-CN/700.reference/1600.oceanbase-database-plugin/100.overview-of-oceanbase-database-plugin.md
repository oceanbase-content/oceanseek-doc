# OceanSeek 插件概述

插件机制旨在为用户提供一种轻量、灵活且高效的功能扩展方式。通过插件机制，用户可以根据自身需求定制和增强 OceanSeek 的功能。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>OceanSeek 插件机制目前为实验特性，暂不建议在生产环境中使用。</p>
</main>

## 如何开发和使用插件

OceanSeek 支持使用 C/C++ 语言开发插件，并提供了一套完整的插件开发包（Plugin Development Kit, PDK）。只要您的开发环境中已安装 C/C++ 开发工具链，并配置了 OceanSeek 插件开发包，即可快速上手插件开发。

## 支持场景

当前，OceanSeek 插件机制主要支持以下场景：

* 分词器插件：用于扩展数据库的全文搜索能力，允许用户自定义分词逻辑，满足多样化的文本处理需求。
* 外表 JDBC 插件：通过外表 JDBC 插件，可以访问 JDBC 支持的数据源。当前版本仅支持 MySQL 模式。


  <main id="notice" type='explain'>
    <h4>说明</h4>
    <p>OceanSeek 支持外表 JDBC 插件服务。同时 OceanSeek 也基于 JDBC 插件服务发布了 MySQL 外表插件。</p>
  </main>
