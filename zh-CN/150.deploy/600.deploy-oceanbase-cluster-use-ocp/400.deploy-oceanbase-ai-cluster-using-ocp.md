# 使用 OCP 部署 OceanSeek 集群

OceanSeek 是存算分离架构的新一代分布式数据库，专为 AI 时代工作负载打造。AI 集群以对象存储（如 S3）作为数据持久化的主要介质，计算节点仅保留本地缓存盘，实现存算分离，具备弹性扩缩容、低成本存储等优势。

本文将为您介绍如何创建 OceanSeek 集群。

## 内存规划

OBServer 集群与 LogService 集群部署在同一台机器上时（混部场景），需提前规划两者的内存使用，避免出现内存不足的情况。建议按如下方式配置：

* Logservice 集群：在创建 Logservice 集群时，需设置 `memory_limit` 参数，限制其内存使用。建议根据日志量大小和业务需求，将 Logservice 的内存限制在合理范围内。

* OBServer 集群：在创建 OBServer 集群时，同样需设置 `memory_limit` 参数，限制其内存使用。根据业务负载和并发需求，合理分配 OBServer 集群的内存资源。

## 前提条件

* 您已部署社区版 OCP V4.5.1 BP3 版本及以上。关于社区版 OCP 的部署操作，参见 [部署 OCP](https://www.oceanbase.com/docs/common-obd-cn-1000000007052840)。
* 如果选择和 LogService 混部，可以复用 [使用 OCP 部署 Logservice 集群](300.deploy-the-logservice-use-ocp.md) 时已经添加的服务器。如果选择独立部署，需要参考 [使用 OCP 部署 Logservice 集群](300.deploy-the-logservice-use-ocp.md) 中的介绍添加 OceanSeek 集群的服务器到 OCP 资源池中。
* 当前登录 OCP 的用户有 `CREATE CLUSTER` 的权限。详细信息，请参见 [角色概述](https://www.oceanbase.com/docs/enterprise-oceanbase-ocp-cn-10000000001541995) 和 [OCP 默认角色](https://www.oceanbase.com/docs/enterprise-oceanbase-ocp-cn-10000000001541990)。
* 已获取  OceanSeek RPM 包以及同架构同版本的 oceanseek-libs 和 oceanseek-utils 安装包，并上传到 OCP。详细信息，请参见 [准备安装包](../300.preparations-before-deploy/300.prepare-installation-packages.md)。
* 已经完成配置对象存储，详情参见 [创建对象存储配置](200.create-an-object-storage.md)。已经创建了 Bucket 且 Bucket 可正常访问。

   <main id="notice" type='notice'>
   <h4>注意</h4>
   <p>建议为 OceanSeek 集群的 OBServer 和 LogService 配置不同的 Bucket。</p>
   </main>

* 完成创建 Logservice 集群，详情参见 [使用 OCP 部署 Logservice 集群](300.deploy-the-logservice-use-ocp.md)。

## 操作步骤

1. 登录 OCP。

2. 在左侧导航栏上，单击 **集群**。

3. 进入 **集群** 总览页面，根据实际业务场景，找到新建集群的入口。

   * 如果您没有可管理的集群，系统会在 **集群列表** 页签中提示您新建集群，直接在提示信息中单击 **创建集群** 。
   * 如果您已经有可管理的集群，则在 **集群列表** 页签的右上角，单击 **创建集群** 。

4. 在 **创建集群** 页面右上角，选择 **AI 集群**。

5. 在 **创建集群** 页面，设置集群的基础信息。

   **基本设置** 如下表所示。

   |    **配置**       |     **描述**    |
   |-------------------|-----------------|
   | **集群名**     | 自定义待管理的集群的名称。集群名称必须以英文字母开头，可支持大小写字母、数字和下划线，长度为 2 \~ 48 字符。|
   | **root@sys 密码** | 支持自定义或随机生成。密码需要满足以下复杂度条件：</br> <ol><li>长度：8 位 \~ 32 位。</li><li>至少包含 2 个数字、2 个大写字母、2 个小写字母和 2 个特殊字符。</li></ol>  </br>支持的特殊字符如下：<code>\~!@#%\^\&\*_-+=\`\|(){}\[\]:;',.?/</code> </br>此外，您可以单击 **复制密码**，将自定义或随机生成的密码复制到剪贴板。 |
   | **OceanBase 版本** | 可以从列表中选择已有的 OceanSeek 版本，也可以在列表下方单击 **添加版本**，上传 OceanSeek RPM 版本包。|
   | **关联 OBProxy 集群** | 该选项用于关联已有的 OBProxy 集群，本例中不开启该选项。|

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oceanbase-database-ai/deploy/deploy-oceanbase-cluster-use-ocp/1.png)

6. 在 **创建集群** 页面，设置集群的部署模式信息。

   默认添加 2 个 Zone 的信息，如果您希望部署的集群 Zone 的个数大于 2 个，您可以在下方单击 **新增 Zone** 按钮，增加 Zone 信息。如果部署的集群 Zone 的个数小于 2 个，您可以单击 Zone 后面的删除图标。

   <main id="notice" type='notice'>
   <h4>注意</h4>
   <p>OceanSeek 集群推荐使用两副本，即 2 个 zone。</p>
   </main>

   每个 Zone 需要设置的信息及其说明如下表所示。

   |       **配置**     |            **描述**               |
   |--------------------|-----------------------------------|
   | **Zone 名称**      | 一般会有一个默认名称，您可以根据需要自定义名称。Zone 名称必须以英文字母开头，可支持大小写字母、数字和下划线，长度为 2 个 \~ 48 个字符。|
   | **机房**           | Zone 所在的机房，每个 Zone 中的主机只能部署在同一个机房。|
   | **机型（可选）**   | 可选项。如果选择了机型，后面主机列表会根据机型进行过滤。 |
   | **CPU 架构**   | 在**基本信息**内选择 **OceanBase 版本** 后，会自动识别。         |
   | **主机**           | 机器的 IP。您可以选择多个 IP。|
   | **Root Server 位置** | 您需选择一个 IP 作为 Root Service 所在的机器。多副本的 OceanSeek 集群，其每个 Zone 都需指定一个 Root Service。        |
   | **Zone 优先级排序**  | 集群 sys 租户的主副本分布的优先级。可选项，如不指定，以第一个 Zone 为第一优先级。最高优先级的 Zone 会被视为 Primary Zone，且只能有一个。</br>您也可以开启该选项自定义 Zone 的优先级排序，排序方法如下：<ol><li> 勾选左侧列表框中的一个或多个 Zone。左侧列表框中显示了当前集群中所有可选的 Zone。</li><li>单击中间的 <b>></b> 按钮。此时勾选的 Zone 就会被移动到 <b>优先级排序</b> 列表中。同时勾选的多个 Zone 具有相同的优先级。</li><li>重复 a、b 动作，添加低一优先级的 Zone。</li><li>如需调整优先级，可在 <b>优先级排序</b> 列表中拖拽以调整顺序。列表中从上到下，优先级依次递减。</li></ol>|

   ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oceanbase-database-ai/deploy/deploy-oceanbase-cluster-use-ocp/2.png)

7. 在 **创建集群** 页面，配置数据存储参数。

   <main id="notice" type='notice'>
   <h4>注意</h4>
   <p>建议为 OceanSeek 集群的 OBServer 和 LogService 配置不同的 Bucket。</p>
   </main>

   OceanSeek 集群采用存算分离架构，数据主要存储在对象存储中。本模块用于配置 AI 集群的数据存储相关参数。

   |   配置   |  描述   |
   |-----|-------|
   | **对象存储配置**    | 选择已创建的对象存储配置。  |
   | **存储目录**     | 指定数据在对象存储中的存储路径，格式为 `s3://my-bucket/my-data`。   |
   | **Logservice 集群**    | 选择已创建的 Logservice 集群，为 AI 集群提供日志服务。   |

   <main id="notice" type='explain'>
   <h4>说明</h4>
   <p>在创建 OceanSeek 集群前，需提前在 OCP 中创建对象存储配置和 Logservice 集群。</p>
   </main>

   ![3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oceanbase-database-ai/deploy/deploy-oceanbase-cluster-use-ocp/3.png)

8. Cgroup 配置

   主要用于 OceanSeek 集群内租户之间以及租户内的 CPU 资源隔离。默认开启，开启 Cgroup 会造成大约 7% 的性能下降，不建议在单租户、小规格场景开启 Cgroup ，请依据您的集群业务类型按需开启。

9. 设置 CPU 超卖

   当不同业务场景的负载出现交叠，OceanSeek 集群在运行过程中可能会产生负载过载等情况，会出现不同租户间进行线程竞争 CPU 的现象，进而导致实际业务场景变慢。为保证系统不同的租户负载可以有控制地交错运行，配置 CPU 资源时可以进行超卖设置来提升资源利用率。

   在 CPU 超卖设置 模块，您可通过滑动块或输入框配置超卖比例，默认值为 120%，取值范围为 101%~200%。

10. 配置 JVM 环境依赖服务

      开启 **JVM 环境依赖服务**，OBServer 可通过 JNI（Java Native Interface）框架对接外表、Java UDF、ODPS 远程访问等功能。

      <main id="notice" type='notice'>
      <h4>注意</h4>
      <p><ul><li>OceanSeek 支持配置 JVM 环境依赖服务。</li><li>请参考 <a href='../800.deploy-the-ob-java-sdk-environment.md'>部署 JAVA SDK 环境</a>，提前通过上传软件包功能上传服务依赖的 JAR 包库，确保 OBServer 可正常加载使用。</li><li>此服务依赖 Java 环境，若集群下存在机器尚未配置 Java 环境，请自行配置：<ul><li>若主机为 arrch64 架构，需确保 OpenJDK 为 15 及以上版本；</li><li>若主机为其它架构，需确保 OpenJDK 为 11 及以上版本。</li></ul>
      </p></main>

      1. 配置服务类型。

         OCP 支持 ODPS 外表、HDFS 外表、Java UDF、ODPS Catalog 和 MySQL 外表插件 5 种服务。

         <main id="notice" type='explain'>
         <h4>说明</h4>
         <p>配置服务类型时，ODPS 外表、HDFS 外表、Java UDF、ODPS Catalog 4 种服务类型均默认开启，不支持关闭。</p></main>

      2. 配置 JVM 内存。

         合理的 JVM 内存配置对 Java 应用的稳定性和性能具有直接影响，您可通过对 JVM 内存进行设置，确保 Java 应用程序在 OceanSeek 集群中的基本运行需要。根据 OBServer 节点的不同内存规格，提供预定义的 JVM 内存配置选项如下：

         | OBServer 内存节点  | -Xmx/-Xms            | -Dio.netty.maxDirectMemory  | JVM 内存总计  |
         |--------------------|----------------------|-----------------------------|--------------|
         | 16 GiB             | 512 MiB              | 512 MiB                     | 1 GiB        |
         | 32 GiB             | 1 GiB                | 1 GiB                       | 2 GiB        |
         | 70 GiB             | 3 GiB                | 3 GiB                       | 6 GiB        |

      3. 配置 JAVA_HOME 路径。

         开启 JVM 环境依赖服务后，需手动填写 JAVA_HOME 路径，请务必确保集群内全部 OBServer 的 JAVA_HOME 路径完全一致。

11. 配置集群参数

     在 **参数设置** 模块，您可自定义配置集群参数。

     * 单击 **添加启动参数**，可逐个添加启动参数项，并为其配置参数值。

     * 配置 OBServer 的 `memory_limit` 参数，具体参数值、取值范围可参考 [memory_limit](../../700.reference/800.configuration-items-and-system-variables/100.system-configuration-items/300.cluster-level-configuration-items/13500.memory_limit.md)。

     * 单击 **选择模板自动填充**，可在下拉列表中选择一个参数模板，系统会将模板中的参数配置自动填充到此处。

     * 系统提供如下 3 种内置模板，模板中包含了常用的参数设置，您可直接应用该模板进行集群的初始化设置。关于系统内置模板，具体说明如下。

       | 模板 |  说明 |
       |------|------|
       | OLAP 参数模板   |  默认模板，对应 **OLAP** 负载类型。   |
       | EXPRESS_OLTP 参数模板   | 建议向量混搜等 AI 负载以及历史库负载选择此模版。   |
       | KV 参数模板   |  对应 **OBKV** 负载类型。   |

     * 您也可单击 **新建集群参数模板**，为集群自定义创建参数模板。

12. 自定义配置

    在 **自定义设置** 模块，支持您执行集群级别的用户配置（如操作系统属主用户）、路径设置（如软件安装路径、缓存盘路径）以及端口设置（如 SQL 端口、RPC 端口）。

    1. 配置操作系统所属主用户：

       该用户为配置安装、运行 OBServer 的操作系统用户，不支持编辑。您可通过调整 `ocp.operation.default.os.user` 参数的默认配置来修改此用户。

    2. 配置相关路径：

       |   配置   |  描述   |
       |-----|-------|
       | **软件安装路径**   | <ul><li>当 **操作系统所属主用户** 为 admin 时，**软件安装路径** 默认为 `/home/admin/oceanbase`，支持自定义。</li><li>当 **操作系统所属主用户** 为非 admin 时，**软件安装路径** 默认为 `/opt/oceanbase/oceanbase`，支持自定义。</li></ul>   |
       | **缓存盘路径**       | 默认为 `/data/1`，支持自定义。在 OceanSeek 集群中，本地磁盘作为缓存盘使用，用于缓存热点基线数据和转储数据，而非持久化存储所有数据。  |

    3. 配置相关端口：

       |   配置   |  描述   |
       |-----|-------|
       | **SQL 端口**        | 默认为 2881，支持自定义。  |
       | **RPC 端口**   | 默认为 2882，支持自定义。     |

    4. 配置完成后，单击 **测试**，校验所填路径及端口是否可用。

       * 若测试通过，单击 **新建** 。
       * 若测试不通过，可根据提示信息进行排查处理。

13. 确认集群信息

    1. 在右侧面板中确认所配置的集群信息是否无误，单击 **下一步** 。

    2. 执行创建前的预检查，系统将验证您的环境是否满足创建 AI 集群的最低要求。若检查项执行失败，可根据提示进行如下操作：

       * **上传**：仅特定检查项失败时展示。请根据提示信息，单击 **上传** 手动上传所需软件包。
       * **跳过**：此操作将跳过当前检查项（专为特殊场景设计），请务必确保相关检查项已满足产品规范要求，否则可能导致后续流程执行失败。跳过后，该检查项的状态将变更为 **警告**。
       * **重试**：根据失败原因和优化建议对问题进行排查修复，修复后单击 **重试**，重新运行失败的检查项。
       * **全部重试**：待所有问题均排查修复后，单击 **全部重试**，重新运行所有失败的检查项。

    3. 待不存在执行失败的检查项后，单击 **新建**。

       提交新建集群任务后，您可在 **任务中心** 中查看该任务的执行进度。

## 后续操作

集群创建成功后，可根据业务需要创建用户租户。

* 使用 OCP 创建用户租户的详细信息，请参见 [新建主租户](https://www.oceanbase.com/docs/common-ocp-1000000000347993)。
* 使用命令行创建用户租户的详细信息，请参见 OceanSeek 文档中的租户管理相关说明。
