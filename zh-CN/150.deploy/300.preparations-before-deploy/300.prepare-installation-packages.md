# 准备安装包

部署前，请确认已获取各产品使用的镜像和安装包，用于后续的安装部署。

## 部署 OceanSeek 

部署 OceanSeek 集群时需要部署 OBServer 和 LogService，对应的 RPM 包可以从 [OceanBase 下载中心](https://www.oceanbase.com/softwarecenter) 获取。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <ul><li>操作系统 Rocky Linux 9 和 Alibaba Cloud Linux 3 推荐使用 al8 RPM 包。</li>
  <li>如果是 Linux Kernel 的操作系统需高于等于 4.19。</li></ul>
</main>

* OceanSeek RPM 包

  * X86_64 平台：

    * el7：oceanseek-x.x.x.x-xxxxxxxxxxxxxxxxxx.el7.x86_64.rpm
    * al8：oceanseek-x.x.x.x-xxxxxxxxxxxxxxxxxx.al8.x86_64.rpm

  * ARM_64 平台：

    * el7：

      * 开启 LSE（默认）：oceanseek-x.x.x.x-xxxxxxxxxxxxxxxxxx.el7.aarch64.rpm
      * 关闭 LSE：oceanseek-x.x.x.x-xxxxxxxxxxxxxxxxxx.nonlse.el7.aarch64.rpm

    * al8：oceanseek-x.x.x.x-xxxxxxxxxxxxxxxxxx.al8.aarch64.rpm

* Logservice RPM 包

  * X86_64 平台：

    * el7：oblogservice-ce-x.x.x-xxxxxxxxxxx.el7.x86_64.rpm
    * al8：oblogservice-ce-x.x.x-xxxxxxxxxxx.al8.x86_64.rpm

  * ARM_64 平台：

    * el7：oblogservice-ce-x.x.x-xxxxxxxxxxx.el7.aarch64.rpm
    * al8：oblogservice-ce-x.x.x-xxxxxxxxxxx.al8.aarch64.rpm

## 部署 OceanBase 数据库代理（可选）

部署 OceanBase 数据库代理对应的 RPM 包如下：

<main id="notice" type='explain'>
    <h4>说明</h4>
    <ul><li>对于 Debian/Ubuntu 的系统，可直接使用 RPM 包，由 OCP 来负责安装部署，不需要转换成 .deb 包。</li>
    <li>操作系统 Rocky Linux 9 和 Alibaba Cloud Linux 3 推荐使用 al8 RPM 包。</li>
    <li> Linux Kernel 需高于等于 4.19。</li></ul>
</main>

* X86_64 平台：

  * el7：obproxy-x.x.x.x-xxxxxxxxxxxxxx.el7.x86_64.rpm
  * al8：obproxy-x.x.x.x-xxxxxxxxxxxxxx.al8.x86_64.rpm

* ARM_64 平台：

  * el7：obproxy-x.x.x.x-xxxxxxxxxxxxxx.el7.aarch64.rpm
  * al8：obproxy-x.x.x.x-xxxxxxxxxxxxxx.al8.aarch64.rpm
