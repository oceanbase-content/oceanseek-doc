# 准备安装包

部署前，请确认已获取各产品使用的镜像和安装包，用于后续的安装部署。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>安装包不提供公开下载，请联系技术支持获取。</p>
</main>

## 部署 OceanBase AI 数据库集群使用的镜像和安装包

### 部署 OceanBase 管理者工具（OAT）

部署 OAT 可以使用 OAT docker image 或者 oat-all-in-one 安装包，新环境推荐使用 oat-all-in-one 安装包安装 OAT，oat-all-in-one 安装包提供了 Docker，OAT，MetaDB、NLB 镜像及常用工具软件包。
不同平台需要下载不同的安装包：

* OAT docker image
  
  * X86_64 平台：oat_x.x.x_xxxxxxxx_x86.tgz
  * ARM_64 平台：oat_x.x.x_xxxxxxxx_arm.tgz

* oat-all-in-one 安装包

  * X86_64 平台：oat-all-in-one-x86-xxx.tar
  * ARM_64 平台：oat-all-in-one-arm-xxx.tar

### 部署 OceanBase 云平台（OCP）

部署 OceanBase 云平台（OCP）可以使用 OCP docker image 和 MetaDB docker image 安装包。部署的 OCP 版本需要 V4.5.0 版本以上。

* OCP docker image：用于部署 OCP

  * X86_64 平台：ocpxxx.tar.gz
  * ARM_64 平台：ocpxxx.arm.tar.gz

* MetaDB docker image：用于部署 OCP MetaDB、MonitorDB。

    <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>如果使用的 OAT docker image 安装 OAT，安装 OCP 时需要提供 MetaDB docker image。</p>
    </main>
  
  * X86_64 平台：meta_xxxxxx_xxxxxx_x86_xxxxxxxx.tgz
  * ARM_64 平台：meta_xxxxxx_xxxxxx_arm_xxxxxxxx.tgz
  
## 部署 OceanBase AI 数据库

部署 OceanBase AI 数据库集群时需要部署 observer 和 LogService，具体安装包如下：

<main id="notice" type='explain'>
  <h4>说明</h4>
  <ul><li>OceanBase AI 数据库RPM 包和 Logservice RPM 包官方不提供公开下载，请联系技术支持人员获取。</li>
  <li>操作系统 Rocky Linux 9 和 Alibaba Cloud Linux 3 推荐使用 al8 RPM 包。</li>
  <li>如果是 Linux Kernel 的操作系统需高于等于 4.19。</li></ul>
</main>

* OceanBase AI 数据库RPM 包

  * X86_64 平台：

    * el7：oceanbase.ai-x.x.x.x-xxxxxxxxxxxxxxxxxx.el7.x86_64.rpm
    * al8：oceanbase.ai-x.x.x.x-xxxxxxxxxxxxxxxxxx.al8.x86_64.rpm

  * ARM_64 平台：

    * el7：

      * 开启 LSE（默认）：oceanbase.ai-x.x.x.x-xxxxxxxxxxxxxxxxxx.el7.aarch64.rpm
      * 关闭 LSE：oceanbase.ai-x.x.x.x-xxxxxxxxxxxxxxxxxx.nonlse.el7.aarch64.rpm

    * al8：oceanbase.ai-x.x.x.x-xxxxxxxxxxxxxxxxxx.al8.aarch64.rpm

* Logservice RPM 包

  * X86_64 平台：

    * el7：oblogservice-x.x.x-xxxxxxxxxxx.el7.x86_64.rpm
    * al8：oblogservice-x.x.x-xxxxxxxxxxx.al8.x86_64.rpm

  * ARM_64 平台：

    * el7：oblogservice-x.x.x-xxxxxxxxxxx.el7.aarch64.rpm
    * al8：oblogservice-x.x.x-xxxxxxxxxxx.al8.aarch64.rpm

### 部署 OceanBase 数据库代理（可选）

部署 OceanBase 数据库代理对于的 RPM 包如下：

<main id="notice" type='explain'>
    <h4>说明</h4>
    <ul><li>对于 Debian/Ubuntu 的系统，可直接使用 RPM 包，由 OCP 来负责安装部署，不需要转换成 .deb 包。</li>

    <li> Linux Kernel 需高于等于 4.19。</li></ul>
</main>

* X86_64 平台：

  * el7：obproxy-x.x.x.x-xxxxxxxxxxxxxx.el7.x86_64.rpm
  * al8：obproxy-x.x.x.x-xxxxxxxxxxxxxx.al8.x86_64.rpm

* ARM_64 平台：

  * el7：obproxy-x.x.x.x-xxxxxxxxxxxxxx.el7.aarch64.rpm
  * al8：obproxy-x.x.x.x-xxxxxxxxxxxxxx.al8.aarch64.rpm
