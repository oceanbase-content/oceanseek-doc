# 准备对象存储

OceanBase AI 数据库当前版本支持 Azure Blob、AWS S3 以及兼容 S3 协议的对象存储（例如：阿里云 OSS、华为 OBS、Google GCS、腾讯云 COS）等介质，部分介质需要满足一些基本要求才能使用。

配置对象存储时，传入的 URL 仅支持以下两种协议头，其它协议均不支持：

* AWS S3 及兼容 S3 协议的对象存储：`s3://`，例如 `s3://your-bucket-name/your-path?host=your-service.com&access_id=your-access-id&access_key=your-access-key`。
* Azure Blob：`azblob://`，例如 `azblob://your-bucket-name/your-path?host=http://your-storage-account.blob.core.windows.net&access_id=your-access-id&access_key=your-access-key`。

在部署 OceanBase AI 数据库集群时，建议 OBServer 和 LogService 配置不同的对象存储桶。

## SDK 版本要求

在当前版本中，默认使用 obdal 来访问对象存储。obdal 为基于 OpenDAL 开发的对象存储统一框架。有关 OpenDAL 的详细介绍，参见 [OpenDAL](https://github.com/oceanbase/opendal)。

此外，如果需要使用对象存储的 SDK，仅支持 S3 SDK for C++，支持版本为 1.11.156 。

## 权限要求

需要保证集群 OBServer 和 LogService 所在节点能够访问到配置的对象存储。

### 接口要求

* 兼容 S3 协议的对象存储（例如：阿里云 OSS、华为 OBS、Google GCS、腾讯云 COS）：

  1. 需要兼容支持下表所示的 S3 API 行为。

     | 接口名                 |  描述                         |
     |-----------------------|-------------------------------|
     | PutObject             | 上传单个对象                   |
     | DeleteObject          | 删除单个对象                   |
     | DeleteObjects         | 批量删除对象                   |
     | GetObject             | 下载单个对象                   |
     | ListObjects           | 列举路径下的所有对象            |
     | HeadObject            | 获取某个对象的元数据            |
     | PutObjectTagging（可选项）  | 设置对象标签               |
     | GetObjectTagging（可选项）  | 获取对象标签               |  
     | CreateMultipartUpload | 初始化分片上传                 |
     | UploadPart            | 上传单个分片                   |
     | CompleteMultipartUpload | 合并已上传分片为一个对象      |
     | AbortMultipartUpload  | 中止分片上传，删除已上传分片    |
     | ListMultipartUploads  | 列出上传的分片                 |
     | ListParts             | 列出上传任务中已完成上传的分片信息|

  2. 需要支持 Virtual-hosted–style 的对象访问 URL。有关 Virtual-hosted–style 请求的详细说明，参见 [AWS S3 官网](https://docs.aws.amazon.com/AmazonS3/latest/userguide/VirtualHosting.html#virtual-hosted-style-access)。

选择介质时，可以通过 ob_admin 工具中的 `test_io_device` 命令来验证该介质所提供的 I/O 接口及当前 I/O 权限是否满足 OceanBase AI 数据库集群需要。同时，还可以使用 ob_admin 工具中的 `io_adapter_benchmark` 命令来查看 OBServer 节点到介质的读写性能。有关 `test_io_device` 和 `io_adapter_benchmark` 命令的详细说明及使用，请参见 OceanBase AI 数据库文档中的 ob_admin 工具说明。
