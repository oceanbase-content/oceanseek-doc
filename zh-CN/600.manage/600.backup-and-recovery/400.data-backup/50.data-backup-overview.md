# 数据备份概述

本节主要介绍数据备份的架构及备份文件的存储机制。

## 数据备份架构

数据备份优先选择 Follower 副本进行备份。数据备份的架构如下图所示。

![数据备份架构图](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oceanbase-database-ai/manage/backup-and-recovery/log-archive/log-archivelog-architeture.jpg)

## 数据备份文件的存储机制

在数据备份场景中，OceanBase Database AI 的备份数据与共享存储上的数据同构，备份目录结构与 OBServer 数据目录保持一致，本质上是对共享存储上特定版本数据的镜像。数据备份以宏块为粒度进行调度和拷贝，宏块之间相互独立。
