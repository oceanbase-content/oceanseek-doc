# 对象存储相关视图/配置项

在基于共享存储的存算分离架构下，可以通过系统视图查看对象存储的配置信息和运行状态。本文介绍对象存储相关的系统视图和配置项。

以下系统视图用于查看 OBServer 集群配置的对象存储信息及 IO 访问资源：

| 名称 | 说明 |

| [GV$OB_SERVER_STORAGE](../../../700.reference/700.system-views/300.system-view-of-sys-tenant/300.performance-view-of-sys-tenant/3250.gv-ob_server_storage-of-sys-tenant.md) | 展示所有 OBServer 节点上集群配置的对象存储的相关信息 |
| [V$OB_SERVER_STORAGE](../../../700.reference/700.system-views/300.system-view-of-sys-tenant/300.performance-view-of-sys-tenant/33650.v-ob_server_storage-of-sys-tenant.md) | 展示当前 OBServer 节点上集群配置的对象存储的相关信息 |
