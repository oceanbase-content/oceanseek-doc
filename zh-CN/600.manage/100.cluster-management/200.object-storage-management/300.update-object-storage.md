# 更新对象存储信息

本文介绍如何更新对象存储的访问凭证（AK/SK）及调整对象存储的带宽/IOPS 限制。

## 更新访问凭证

AK/SK 轮转是对象存储管理中的常见操作，用于定期更新访问凭据以提升安全性。在共享存储架构下，对象存储同时服务于 OBServer 和 LogService 等多个组件，各组件通过独立的凭证管理方式访问对象存储，更新凭证时需根据凭证所属的组件选择对应的操作入口：

| 组件 | 凭证更新方式 | 操作文档 |
|------|------------|---------|
| **OBServer**（计算节点） | <ul><li>`ALTER SYSTEM CHANGE SHARED_STORAGE_DEST`（业务数据凭证）</li><li>`ALTER SYSTEM SET logservice_access_point`（日志存储凭证）</li></ul> | [更新对象存储访问凭证](../100.compute-service-management/300.common-cluster-operations/1320.change-shared-storage-dest.md) |
| **LogService**（日志服务节点） | `ls_ctrl rotate-ak` | [轮转日志服务访问凭证](../300.logservice-management/300.logservice-operations/800.rotate-access-key.md) |

### 注意事项

* `ALTER SYSTEM CHANGE SHARED_STORAGE_DEST` 语句仅支持系统租户（即 `sys` 租户）执行。

* OBServer 的日志存储与 LogService 访问同一个对象存储桶。轮转该存储桶的 AK/SK 时，需同时在 OBServer 侧（`logservice_access_point`）和 LogService 侧（`ls_ctrl rotate-ak`）更新凭证，避免因单侧更新导致访问失败。

* 集群替换为新 AK 后，旧 AK 不会立即从集群中移除，删除旧 AK 需等待至少一个小时。

## 更新带宽和 IOPS 限制

在对象存储使用过程中，如果业务流量变化需要调整对象存储的带宽和 IOPS 限制，可通过 `ALTER SYSTEM CHANGE SHARED_STORAGE_DEST` 语句的 `ATTRIBUTE` 参数进行修改。该语句仅支持系统租户（即 `sys` 租户）执行。

语句语法如下：

```sql
ALTER SYSTEM CHANGE SHARED_STORAGE_DEST
    PATH [=] 'path'
    SET ATTRIBUTE [=] 'attribute';
```

相关参数说明如下：

* `PATH`：对象存储的路径，格式为 `s3://<bucket>/<prefix>?host=<endpoint>`，需与集群当前配置的对象存储路径保持一致。
* `ATTRIBUTE`：新的 IOPS 和带宽限制，格式为 `max_iops=<iops>&max_bandwidth=<bandwidth>`。

示例如下：

```shell
obclient [(none)]> ALTER SYSTEM CHANGE SHARED_STORAGE_DEST
    PATH='s3://xxx?host=cn-hangzhou-alipay-b.oss-cdn.aliyun-inc.com'
    SET ATTRIBUTE='max_iops=10000&max_bandwidth=100MB';
```
