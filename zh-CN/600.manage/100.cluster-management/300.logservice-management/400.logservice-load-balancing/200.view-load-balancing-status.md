# 查看均衡状态

通过 LS-CTRL 工具的 `show v-table` 命令可以查看日志服务集群的负载信息，包括节点负载、可用区负载和日志流副本 IO 统计。

## 查看节点负载

执行以下命令，查看每个 LN 节点的 IOPS 和带宽使用情况：

```shell
ls_ctrl -H <HOST_ADDRESS> show v-table node_load
```

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>上述命令中，<code>HOST_ADDRESS</code> 为日志服务任意节点的 HTTP 地址（带端口号），例如 <code>127.0.0.1:8080</code>。关于 ls-ctrl 命令的更多信息，请参考 <a href="../../../../700.reference/950.logservice-reference/100.logservice-commands/100.ls-ctrl-overview.md">LS-CTRL 概述</a>。</p>
</main>

返回结果中，每个节点一行的信息包括：节点 ID、可用区名称、IOPS 使用量、IOPS 容量、IOPS 利用率、带宽使用量、带宽容量和带宽利用率。

## 查看 AZ 负载

执行以下命令，查看每个 AZ 的 IOPS 和带宽使用情况：

```shell
ls_ctrl -H <HOST_ADDRESS> show v-table az_load
```

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>上述命令中，<code>HOST_ADDRESS</code> 为日志服务任意节点的 HTTP 地址（带端口号），例如 <code>127.0.0.1:8080</code>。关于 ls-ctrl 命令的更多信息，请参考 <a href="../../../../700.reference/950.logservice-reference/100.logservice-commands/100.ls-ctrl-overview.md">LS-CTRL 概述</a>。</p>
</main>

返回结果中，每个 AZ 一行的信息包括：AZ 名称、IOPS 使用量、IOPS 容量、IOPS 利用率、带宽使用量、带宽容量和带宽利用率。

## 查看日志流副本 IO

执行以下命令，查看每个日志流副本的 IO 统计信息：

```shell
ls_ctrl -H <HOST_ADDRESS> show v-table stream_replica_io
```

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>上述命令中，<code>HOST_ADDRESS</code> 为日志服务任意节点的 HTTP 地址（带端口号），例如 <code>127.0.0.1:8080</code>。关于 ls-ctrl 命令的更多信息，请参考 <a href="../../../../700.reference/950.logservice-reference/100.logservice-commands/100.ls-ctrl-overview.md">LS-CTRL 概述</a>。</p>
</main>

返回结果中，每条记录的信息包括：日志流 ID、节点 ID、IO 类型、副本类型、带宽和 IOPS。
