# 配置均衡策略

日志服务支持通过 LS-CTRL 工具配置集群级和节点级配置项来调整负载均衡的行为。

## 开启或关闭自动均衡

通过 `enable_rebalance` 配置项控制是否开启日志流负载均衡，默认开启。

```shell
ls_ctrl -H <HOST_ADDRESS> set param enable_rebalance true
ls_ctrl -H <HOST_ADDRESS> set param enable_rebalance false
```

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>上述命令中，<code>HOST_ADDRESS</code> 为日志服务任意节点的 HTTP 地址（带端口号），例如 <code>127.0.0.1:8080</code>。关于 ls-ctrl 命令的更多信息，请参考 <a href="../../../../700.reference/950.logservice-reference/100.logservice-commands/100.ls-ctrl-overview.md">LS-CTRL 概述</a>。</p>
</main>

## 设置均衡策略

通过 `load_balance_policy` 配置项选择均衡策略，支持 `replica_count_based`（基于副本数）和 `load_based`（基于负载）两种策略，默认 `replica_count_based`。

```shell
ls_ctrl -H <HOST_ADDRESS> set param load_balance_policy replica_count_based
ls_ctrl -H <HOST_ADDRESS> set param load_balance_policy load_based
```

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>上述命令中，<code>HOST_ADDRESS</code> 为日志服务任意节点的 HTTP 地址（带端口号），例如 <code>127.0.0.1:8080</code>。关于 ls-ctrl 命令的更多信息，请参考 <a href="../../../../700.reference/950.logservice-reference/100.logservice-commands/100.ls-ctrl-overview.md">LS-CTRL 概述</a>。</p>
</main>

配置为 `load_based` 时，集群中所有节点的 `disk_max_iops` 和 `disk_max_bandwidth` 必须均大于 0，否则修改会被拒绝。如果集群中节点缺少这些配置，可以通过以下命令设置：

```shell
ls_ctrl -H <HOST_ADDRESS> set param --server-only disk_max_iops <value>
ls_ctrl -H <HOST_ADDRESS> set param --server-only disk_max_bandwidth <value>
```

<main id="notice" type='explain'>
  <h4>说明</h4>
  <ul>
    <li><code>disk_max_iops</code> 和 <code>disk_max_bandwidth</code> 默认值为 <code>0</code>，表示未配置。配置为 <code>load_based</code> 前，需确保集群中所有节点的这两个配置项均已正确设置（大于 0）。</li>
    <li>配置为 <code>load_based</code> 后，如果在运行期间出现节点配置缺失（如新接入节点未配置），集群会自动降级为 <code>replica_count_based</code> 执行调度，并以 ERROR 日志告警。待配置补全后自动恢复为 <code>load_based</code>，期间配置项展示值不变。</li>
  </ul>
</main>

## 调整均衡触发间隔

通过 `rebalance_interval_sec` 配置项控制负载均衡的触发间隔，默认 60 秒。

```shell
ls_ctrl -H <HOST_ADDRESS> set param rebalance_interval_sec 120
```

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>上述命令中，<code>HOST_ADDRESS</code> 为日志服务任意节点的 HTTP 地址（带端口号），例如 <code>127.0.0.1:8080</code>。关于 ls-ctrl 命令的更多信息，请参考 <a href="../../../../700.reference/950.logservice-reference/100.logservice-commands/100.ls-ctrl-overview.md">LS-CTRL 概述</a>。</p>
</main>

## 调整均衡阈值

基于负载的均衡策略通过以下两个配置项控制节点资源利用率阈值：

* `max_utilization_threshold`：节点资源利用率上限（百分比），超过时触发副本迁出，默认 60。
* `min_utilization_threshold`：节点资源利用率下限（百分比），低于时仅记录 UnderUtilized 事件用于观测，不触发操作，默认 30。

```shell
ls_ctrl -H <HOST_ADDRESS> set param max_utilization_threshold 70
ls_ctrl -H <HOST_ADDRESS> set param min_utilization_threshold 20
```

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>上述命令中，<code>HOST_ADDRESS</code> 为日志服务任意节点的 HTTP 地址（带端口号），例如 <code>127.0.0.1:8080</code>。关于 ls-ctrl 命令的更多信息，请参考 <a href="../../../../700.reference/950.logservice-reference/100.logservice-commands/100.ls-ctrl-overview.md">LS-CTRL 概述</a>。</p>
</main>

## 注意事项

* 所有集群级配置项修改后立即生效，不涉及节点重启。
* 节点级配置项 `disk_max_iops` 和 `disk_max_bandwidth` 修改后立即生效，但需使用 `--server-only` 参数。
* 修改均衡策略时，当前正在执行的均衡/调度任务按旧策略继续执行，不中断。
* 配置项取值大小写敏感。
