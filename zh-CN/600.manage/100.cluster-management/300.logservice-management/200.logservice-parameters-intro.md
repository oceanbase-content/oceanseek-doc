# 日志服务配置项

在日志服务（LogService）中，通过配置项的设置可以控制 LogService 集群的功能行为，例如负载均衡、日志管理、资源分配等功能。

LogService 集群首次 Bootstrap 时，需要指定某些必需配置项，如果没有合理的默认值或不设置，则无法完成 Bootstrap。这些必需配置项需要在启动配置文件（etc/config.toml）或启动参数（-g）中显式指定。

LogService 的运行时配置项定义在 ServerConfig 结构体中，通过启动配置文件（TOML 格式）加载，部分项支持通过 HTTP 接口在线变更。

## 配置项级别

LogService 的配置项按作用域分为集群级（cluster）和节点级（server）两种：

| 作用域 | 说明 |
| --- | --- |
| cluster | 集群级配置，由 LogServiceManager（LM）持久化到 t_parameter_info 表，对整个集群所有节点生效。 |
| server | 节点级配置，仅在本地生效。 |

## 配置项生效方式

| 生效方式 | 说明 |
| --- | --- |
| dynamic | 可通过 HTTP /set 修改，立即生效。 |
| static | 可通过 HTTP /set 修改并持久化，语义上需重启进程才能生效（当前为语义标注，运行时不强制阻止立即写入）。 |
| readonly | 运行时只读，启动后不可改。 |

## LogService 集群 Bootstrap 必须设置的配置项

以下配置项没有合理的默认值或不设置则无法完成 Bootstrap，必须在启动配置文件（etc/config.toml）或启动参数（-g）中显式指定。

| 配置项 | 含义 | 类型 | 默认值 | 作用域 | 生效模式 |
| --- | --- | --- | --- | --- | --- |
| cluster_id | 集群唯一标识，所有节点必须相同。默认值 0 无实际意义，必须指定有效的集群 ID。 | u64 | 0 | server | readonly |
| local_ip | 每个节点对外服务的 IP 地址。默认 0.0.0.0 仅适合单机测试，集群部署必须设为节点实际可路由 IP。 | String | "0.0.0.0" | server | readonly |
| local_storage_dir | 本地数据目录路径。Bootstrap 前检查该目录必须存在且为空（仅允许 log_pool 子目录）。 | String | "store" | server | readonly |
