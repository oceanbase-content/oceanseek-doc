# 查看日志服务配置项

日志服务（LogService）的运行时配置项通过 LS-CTRL 工具查询。

## 查看集群级配置项

执行以下命令查看集群级配置项：

```shell
ls_ctrl -H <HOST_ADDRESS> show parameter <name>
```

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>上述命令中，<code>HOST_ADDRESS</code> 为日志服务任意节点的 HTTP 地址（带端口号），例如 <code>127.0.0.1:8080</code>。关于 ls-ctrl 命令的更多信息，请参考 <a href="../../../../700.reference/950.logservice-reference/100.logservice-commands/100.ls-ctrl-overview.md">LS-CTRL 概述</a>。</p>
</main>

## 查看节点级配置项

执行以下命令（需指定 `--server-only`）查看节点级配置项：

```shell
ls_ctrl -H <HOST_ADDRESS> show parameter <name> --server-only
```

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>上述命令中，<code>HOST_ADDRESS</code> 为日志服务任意节点的 HTTP 地址（带端口号），例如 <code>127.0.0.1:8080</code>。关于 ls-ctrl 命令的更多信息，请参考 <a href="../../../../700.reference/950.logservice-reference/100.logservice-commands/100.ls-ctrl-overview.md">LS-CTRL 概述</a>。</p>
</main>

## 参数说明

查询 `show parameter` 命令的相关参数说明如下：

| 参数 | 说明 |
|------|------|
| `<name>` | 参数名称。必填。 |
| `--server-only` | 若指定，则从 `-H` 所指向节点的本地配置读取，而非从 LM leader 读取集群参数。默认 false。 |
