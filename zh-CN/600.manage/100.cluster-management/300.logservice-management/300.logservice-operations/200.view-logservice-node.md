# 查看日志服务节点

日志服务（LogService）节点称为 LN（LogServiceNode），每个节点由一个 ln_id 和地址（host:port）唯一标识。可以通过 LS-CTRL 工具的 `show ln` 命令查看集群中指定 LN 或所有 LN 的信息。

## 操作步骤

* 执行以下命令，查看所有 LN 节点信息：

    ```shell
    ls_ctrl -H <HOST_ADDRESS> show ln
    ```

* 指定 IP 地址查询：

    ```shell
    ls_ctrl -H <HOST_ADDRESS> show ln <host:port>
    ```

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>上述命令中，<code>HOST_ADDRESS</code> 为日志服务任意节点的 HTTP 地址（带端口号），例如 <code>127.0.0.1:8080</code>。关于 ls-ctrl 命令的更多信息，请参考 <a href="../../../../700.reference/950.logservice-reference/100.logservice-commands/100.ls-ctrl-overview.md">LS-CTRL 概述</a>。</p>
</main>
