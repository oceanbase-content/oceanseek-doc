# 删除日志服务节点

日志服务（LogService）支持动态缩容操作，用户可以使用 LS-CTRL 工具的 `delete ln` 命令从日志服务 LogService 集群中删除指定的日志服务节点（LogServiceNode，LN）。

## 操作步骤

执行以下命令，删除 LN：

```shell
ls_ctrl -H <HOST_ADDRESS> delete ln <ln>
```

其中，`<ln>` 为待删除节点的 ID 或地址（`host:port`）。

执行成功后，可以通过 `ls_ctrl show ln` 命令确认节点是否删除成功。

```shell
ls_ctrl -H <HOST_ADDRESS> show ln
```

如果列表中已经查询不到该节点，则表示删除成功。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>上述命令中，<code>HOST_ADDRESS</code> 为日志服务任意节点的 HTTP 地址（带端口号），例如 <code>127.0.0.1:8080</code>。关于 ls-ctrl 命令的更多信息，请参考 <a href="../../../../700.reference/950.logservice-reference/100.logservice-commands/100.ls-ctrl-overview.md">LS-CTRL 概述</a>。</p>
</main>
