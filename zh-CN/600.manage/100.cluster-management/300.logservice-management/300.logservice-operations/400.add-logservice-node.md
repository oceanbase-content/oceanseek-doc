# 添加日志服务节点

日志服务（LogService）支持动态扩容操作，用户可以使用 LS-CTRL 工具的 `add ln` 命令向 LogService 集群中的指定 Zone 添加新的日志节点（LogServiceNode，LN）。

## 操作步骤

向集群中的指定 Zone 添加 LN 节点。

```shell
ls_ctrl -H <HOST_ADDRESS> add ln <host:port> <az>
```

相关参数说明如下：

* `<host:port>`：必填，待添加节点的地址，其中端口与配置文件中 `rpc_port` 一致。
* `<az>`：必填，目标 Zone 名称。

执行成功后，可以通过 `ls_ctrl show ln` 命令确认节点是否添加成功。

```shell
ls_ctrl -H <HOST_ADDRESS> show ln
```

如果列表中包含新添加的节点，则表示添加成功。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>上述命令中，<code>HOST_ADDRESS</code> 为日志服务任意节点的 HTTP 地址（带端口号），例如 <code>127.0.0.1:8080</code>。关于 ls-ctrl 命令的更多信息，请参考 <a href="../../../../700.reference/950.logservice-reference/100.logservice-commands/100.ls-ctrl-overview.md">LS-CTRL 概述</a>。</p>
</main>
