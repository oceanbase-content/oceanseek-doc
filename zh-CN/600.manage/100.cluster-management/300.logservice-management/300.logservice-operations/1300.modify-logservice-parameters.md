# 修改日志服务配置项

日志服务（LogService）的运行时配置项通过 LS-CTRL 工具设置。

## 设置集群级配置项

```shell
ls_ctrl -H <HOST_ADDRESS> set param <name> <value>
```

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>上述命令中，<code>HOST_ADDRESS</code> 为日志服务任意节点的 HTTP 地址（带端口号），例如 <code>127.0.0.1:8080</code>。关于 ls-ctrl 命令的更多信息，请参考 <a href="../../../../700.reference/950.logservice-reference/100.logservice-commands/100.ls-ctrl-overview.md">LS-CTRL 概述</a>。</p>
</main>

示例如下：

```shell
# 开启日志流负载均衡
ls_ctrl -H 127.0.0.1:50052 set param enable_rebalance true

# 设置节点永久离线超时时间为 3600 秒
ls_ctrl -H 127.0.0.1:50052 set param node_permanent_offline_time_sec 3600
```

## 设置节点级配置项

```shell
ls_ctrl -H <HOST_ADDRESS> set param --server-only <name> <value>
```

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>上述命令中，<code>HOST_ADDRESS</code> 为日志服务任意节点的 HTTP 地址（带端口号），例如 <code>127.0.0.1:8080</code>。关于 ls-ctrl 命令的更多信息，请参考 <a href="../../../../700.reference/950.logservice-reference/100.logservice-commands/100.ls-ctrl-overview.md">LS-CTRL 概述</a>。</p>
</main>

示例如下：

```shell
# 设置日志级别为 debug
ls_ctrl -H 127.0.0.1:50052 set param --server-only log_level debug

# 设置日志盘大小上限为 100GB
ls_ctrl -H 127.0.0.1:50052 set param --server-only log_disk_size 100GB
```

## 参数说明

| 参数 | 说明 |
|------|------|
| `--server-only` | 若指定，则仅对 `-H` 所指向的节点生效（server 级别）；否则对整个集群生效（cluster 级别）。默认 false。 |
| `<name>` | 参数名称。必填。 |
| `<value>` | 参数值。必填。 |
